# Структура таблицы стилей

## Типы данных и операции в Sass: От логики до математики

Если обычный CSS оперирует только строками и числами, то Sass расширяет этот список, позволяя создавать сложные структуры и автоматизировать вычисления.

### 1. Типы данных (Литералы)

В Sass значения могут принимать различные формы:

 * **Логические типы:** true и false.
 * **Null:** Единственное значение null (пустота). Часто используется для отмены вывода свойства, если значение не задано.
 * **Списки (Lists):** Наборы значений. Они могут разделяться пробелами (10px 15px) или запятыми (Arial, sans-serif), а также заключаться в квадратные скобки [] или быть без них.
 * **Карты (Maps):** Пары «ключ: значение», напоминающие объекты в JavaScript или словари в Python.

   > Пример: `("primary": #333, "secondary": #fff)`.

### 2. Операции

Sass поддерживает стандартный набор операторов для манипуляции данными.

#### Сравнение и логика

 * **Равенство:** == и != проверяют идентичность значений любого типа.
 * **Математическое сравнение:** <, <=, >, >= работают только с числами.
 * **Булева логика:** Операторы and, or и not.
   * *Интересный факт:* В Sass **любое** значение считается «истинным» (true), кроме false и null.

#### Арифметика

Операторы +, -, *, / и % (остаток от деления) работают так же, как в школьной математике. Sass уникален тем, что он умеет работать с **единицами измерения**:

 * Например, 10px + 5px даст 15px.
 * Попытка сложить 10px + 5em приведет к ошибке, так как эти единицы несовместимы без контекста браузера.

#### Строковые операции

Операторы +, - и / могут использоваться для конкатенации (склеивания) строк.

### 3. Особые выражения и функции

Помимо простых значений, Sass использует специальные конструкции для гибкого управления стилями:

 * **Переменные:** Любое имя, начинающееся с $, например $primary-color.
 * **Вызовы функций:** Как встроенных (например, nth($list, 1) для получения элемента списка), так и пользовательских.
 * **Специальные функции:** Некоторые функции CSS (такие как calc() или url()) имеют свои уникальные правила парсинга, которые Sass бережно сохраняет.
 * **Родительский селектор:** Символ &, который ссылается на внешний селектор (незаменим при написании BEM или псевдоклассов :hover).
 * **Флаг !important:** В Sass он воспринимается как нестроковая константа и передается в CSS «как есть».

### Иерархия операций

Чтобы контролировать приоритет вычислений (например, чтобы сложение выполнилось раньше умножения), используйте круглые скобки ( ).

**Пример сложной логики:**

```scss
$width: 100px;
$padding: 10px;

.container {
  width: if($width > 50px, $width + ($padding * 2), $width);
}
```

Эта гибкость позволяет создавать дизайн-системы, где все размеры и цвета вычисляются автоматически на основе нескольких базовых переменных.
