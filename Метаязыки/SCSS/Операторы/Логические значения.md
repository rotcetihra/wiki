# Логические операторы в Sass: Управление условиями

Логические (булевы) операторы в Sass позволяют строить сложные условия для управления потоком стилей. Они незаменимы в директивах `@if`, `@else if` и при создании функциональных миксинов, которые адаптируются под различные параметры.

В Sass существует три логических оператора: `not`, `and` и `or`.

---

## 1. Оператор `not` (Отрицание)

Оператор `not` — это унарный оператор, который инвертирует логическое значение. Если выражение истинно, `not` вернет `false`, и наоборот.

- **Синтаксис:** `not <expression>`

```SCSS
@debug not true;  // false
@debug not false; // true
@debug not (1px == 1px); // false
```

---

## 2. Оператор `and` (Логическое И)

Оператор `and` возвращает `true`, если **оба** выражения являются истинными. Если хотя бы одно из них ложно, результатом будет `false`.

- **Синтаксис:** `<expression> and <expression>`

```SCSS
@debug true and true;   // true
@debug true and false;  // false
@debug (1px == 1px) and (2px == 2px); // true
```

---

## 3. Оператор `or` (Логическое ИЛИ)

Оператор `or` возвращает `true`, если **хотя бы одно** из выражений является истинным. Он возвращает `false` только в том случае, если оба операнда ложны.

- **Синтаксис:** `<expression> or <expression>`

```SCSS
@debug true or false;   // true
@debug false or false;  // false
@debug (1px == 2px) or (1px == 1px); // true
```

---

## 4. Понятие "Truthiness" (Истинность)

Это критически важный аспект Sass. В отличие от многих других языков программирования (например, JavaScript), где `0`, `""` (пустая строка) или пустые списки могут считаться ложными, в Sass правила намного строже.

**Ложными (falsey) считаются только два значения:**

1. Логическое `false`.
    
2. Значение `null`.
    

**Все остальные значения считаются истинными (truthy):**

- Числа (включая `0`).
    
- Строки (включая пустые `""`).
    
- Списки и карты (даже пустые).
    
- Цвета.

```SCSS
// Пример проверки на "истинность"
@mixin light-theme($color) {
  // Если $color передан (не null), используем его. 
  // Если нет — используем стандартный белый.
  background-color: if($color, $color, #fff);
}
```

---

## 5. Приоритет выполнения (Precedence)

При использовании нескольких операторов в одном выражении Sass соблюдает строгий порядок выполнения:

1. Выражения в **скобках** `()`.
    
2. Оператор **`not`**.
    
3. Оператор **`and`**.
    
4. Оператор **`or`**.

```SCSS
@debug false and not true or true; 
// 1. not true -> false
// 2. false and false -> false
// 3. false or true -> true
// Итоговый результат: true
```

---

## 6. Практический пример: Сложные проверки в миксинах

Логические операторы позволяют создавать гибкие интерфейсы для ваших компонентов. Рассмотрим миксин для адаптивной типографики, который проверяет сразу несколько условий:

```SCSS
$debug-mode: true;

@mixin responsive-text($size, $important: false) {
  @if $size > 20px and $important == true {
    font-size: $size;
    font-weight: bold;
    text-transform: uppercase;
  } @else if $size <= 20px or not $debug-mode {
    font-size: $size;
  }
}

h1 {
  @include responsive-text(24px, true); 
  // Выполнится первое условие (размер > 20 И важно)
}
```

### Основные выводы:

- Используйте **`and`** для строгих ограничений, когда важны все параметры.
    
- Используйте **`or`** для создания альтернативных условий.
    
- Помните, что **`0` и `""` — это `true`** в Sass. Если вам нужно проверить строку на пустоту, используйте явное сравнение: `$str == ""`.
