# Реляционные операторы в Sass: Больше, меньше и магия единиц

Реляционные (сравнительные) операторы позволяют определять, является ли одно число больше или меньше другого. В Sass это основной инструмент для создания логики в адаптивном дизайне, вычисления размеров сеток и управления циклами.

В отличие от операторов равенства, которые работают с любыми типами данных, **реляционные операторы работают исключительно с числами**.

## 1. Список операторов

Sass поддерживает стандартный набор из четырех операторов:

|**Оператор**|**Значение**|**Пример**|**Результат**|
|---|---|---|---|
|`<`|Меньше|`10px < 20px`|`true`|
|`<=`|Меньше или равно|`10px <= 10px`|`true`|
|`>`|Больше|`1in > 50px`|`true`|
|`>=`|Больше или равно|`1000ms >= 1s`|`true`|

---

## 2. Автоматическая конвертация единиц

Sass — это не просто калькулятор, он понимает физический смысл единиц измерения. Если вы сравниваете числа с разными, но **совместимыми** единицами, Sass автоматически приведет их к общему знаменателю.

Например, Sass знает, что `1in` (дюйм) равен `96px`.

```SCSS
@debug 100px > 1in; // true (так как 100px > 96px)
@debug 1000ms <= 1s; // true (они равны)
```

### Совместимые группы:

- **Расстояние:** `px`, `cm`, `mm`, `in`, `pt`, `pc`.
    
- **Углы:** `deg`, `grad`, `rad`, `turn`.
    
- **Время:** `s`, `ms`.
    
- **Частота:** `Hz`, `kHz`.

---

## 3. Сравнение с числами без единиц (Unitless)

Здесь кроется **важное отличие** от операторов равенства (`==`).

- В равенстве: `1 == 1px` вернет `false`.
    
- В сравнении: `1 < 2px` вернет `true`.
    

**Правило:** Число без единиц измерения можно сравнивать с любым числом. Sass автоматически «наделит» его нужной единицей для проведения операции.

```SCSS
@debug 100 > 50px; // true
@debug 10px < 17;   // true
```

---

## 4. Ошибка: Несовместимые единицы

Если вы попытаетесь сравнить числа, которые невозможно конвертировать друг в друга (например, абсолютные `px` и относительные `em`), Sass выдаст **ошибку компиляции**.

Это защищает вас от логических ошибок, так как значение `1em` зависит от контекста (размера шрифта) и не может быть вычислено статически в момент сборки CSS.

```SCSS
// ОШИБКА: Incompatible units px and em.
@debug 10px < 1em; 
```

---

## 5. Практическое применение: Адаптивность

Реляционные операторы часто используются в функциях для проверки границ или создания динамических сеток.

### Пример: Проверка "безопасного" размера шрифта

```SCSS
@function validate-font-size($size) {
  @if $size < 12px {
    @warn "Размер шрифта #{$size} слишком мал для чтения!";
    @return 12px;
  }
  @return $size;
}

.text-small {
  font-size: validate-font-size(10px); // Выведет предупреждение и вернет 12px
}
```

---

## Итог: Сравнение vs Равенство

|**Ситуация**|**Оператор ==**|**Операторы >, <, >=, <=**|
|---|---|---|
|**Типы данных**|Любые (строки, списки, цвета)|Только числа|
|**1 == 1px / 1 < 2px**|`false`|`true`|
|**Разные единицы**|Считает равными только совместимые|Считает только совместимые (иначе ошибка)|

> **Важно:** Всегда следите за тем, чтобы переменные, которые вы сравниваете, были числами. Если в переменную случайно попадет строка `"10px"`, сравнение вызовет ошибку, так как операторы `>`, `<` не умеют работать с текстом.
