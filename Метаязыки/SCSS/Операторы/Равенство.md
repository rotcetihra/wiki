Операторы равенства — это фундамент логики в Sass. Они позволяют создавать гибкие миксины и функции, которые ведут себя по-разному в зависимости от входных данных.

Ниже представлена полная статья, основанная на официальной документации Sass, с расширенными примерами и практическими советами.

# Операторы равенства в Sass: Полный гид

В Sass (как в синтаксисе SCSS, так и в индентированном Sass) существуют два основных оператора для сравнения значений:

- `==` — возвращает `true`, если значения равны.
    
- `!=` — возвращает `true`, если значения **не** равны.
    

Результатом работы этих операторов всегда является логическое значение (**boolean**).

---

## 1. Числа и единицы измерения (Numbers)

Сравнение чисел в Sass — это не просто математика, а еще и логика физических величин.

- **Совместимые единицы:** Если единицы измерения можно конвертировать друг в друга (например, `px` и `in`, `mm` и `cm`), Sass сделает это автоматически перед сравнением.
    
- **Несовместимые единицы:** Если единицы нельзя преобразовать (например, `px` и `em`), значения всегда будут **не равны**.
    
- **Числа без единиц (Unitless):** Важное изменение в Dart Sass — число без единиц измерения **не равно** числу с единицами.

|**Сравнение**|**Результат**|**Комментарий**|
|---|---|---|
|`1px == 1px`|`true`|Идентичные значения.|
|`96px == 1in`|`true`|Sass знает, что в 1 дюйме 96 пикселей.|
|`1px == 1em`|`false`|Несовместимые типы данных.|
|`1 == 1px`|`false`|**Breaking Change!** Раньше это могло быть `true`.|

> **Совет:** Чтобы безопасно сравнить число с единицами и без, сначала приведите их к одному виду с помощью математических операций или функций модуля `sass:math`.

## 2. Строки (Strings)

Sass очень лоялен к строкам. Главное правило: **наличие кавычек не влияет на равенство**, если содержимое идентично.

```SCSS
@debug "Helvetica" == Helvetica; // true
@debug 'Roboto' == "Roboto";     // true
@debug "Arial" != "Verdana";     // true
```

**Особенности:**

- Сравнение чувствительно к регистру (`Arial != arial`).
    
- Если строка содержит интерполяцию, она сначала вычисляется, а затем сравнивается.

---

## 3. Цвета (Colors)

Цвета считаются равными, если они представляют одну и ту же точку в цветовом пространстве.

- Sass сравнивает значения каналов (RGBA).
    
- Формат записи (HEX, RGB, HSL, именованный цвет) не имеет значения.

```SCSS
@debug #f2ece4 == hsl(34, 35%, 92.1%); // true
@debug white == #ffffff;               // true
@debug rgba(0, 0, 0, 0.5) != black;    // true (разная прозрачность)
```

---

## 4. Списки (Lists)

Для того чтобы два списка были равны, они должны полностью совпадать по четырем параметрам:

1. **Содержимое:** одинаковые элементы.
    
2. **Порядок:** элементы должны идти в той же последовательности.
    
3. **Разделитель:** пробел или запятая.
    
4. **Скобки:** оба списка должны быть либо в скобках `[]`, либо без них.

```SCSS
@debug (5px 7px 10px) == (5px 7px 10px);   // true
@debug (5px 7px 10px) != (10px 7px 5px);   // true (разный порядок)
@debug (1px, 2px) != (1px 2px);            // true (разные разделители)
@debug [1px 2px] != (1px 2px);             // true (разные типы скобок)
```

---

## 5. Карты (Maps)

Две карты считаются равными, если у них:

- Одинаковый набор ключей.
    
- Значения, соответствующие этим ключам, также равны.

```SCSS
$theme1: ("primary": #333, "secondary": #999);
$theme2: ("primary": #333, "secondary": #999);

@debug $theme1 == $theme2; // true
```

---

## 6. Null, Boolean и Функции

- **Boolean:** `true == true`, но `true != 1` (в Sass нет приведения типов к числу, как в JS).
    
- **Null:** `null` равен только самому себе. Это полезно для проверки того, передал ли пользователь аргумент в миксин.
    
- **Функции:** Сравниваются по ссылке. Если вы получили функцию через `get-function()`, она будет равна другой функции только если это одна и та же функция, определенная в том же месте.

## Практический пример: Умный миксин

Зачем это нужно в реальной жизни? Например, для создания адаптивных отступов:

```SCSS
@mixin padding-smart($value) {
  // Если передано 0 без единиц или с единицами
  @if $value == 0 or $value == 0px {
    padding: 0;
  } 
  // Если передано специальное значение-строка
  @else if $value == "huge" {
    padding: 100px;
  } 
  @else {
    padding: $value;
  }
}

.card {
  @include padding-smart(0);      // Результат: padding: 0;
  @include padding-smart("huge"); // Результат: padding: 100px;
}
```

---

### Итог

Операторы `==` и `!=` в Sass работают интуитивно, но требуют внимательности при работе со сложными структурами (списками) и единицами измерения. Помните, что **Sass — строго типизированный язык** в плане сравнения: `1` никогда не будет равен `"1"`.
