# Операторы строк в Sass: Слияние и форматирование

В Sass строки — это не просто текст. Они могут быть **в кавычках** (quoted) или **без кавычек** (unquoted). Понимание того, как работают операторы строк, критично для генерации правильного CSS, особенно при работе с динамическими путями к шрифтам, именами селекторов или значениями свойств.

---

## 1. Конкатенация: Оператор `+`

Основным инструментом для работы со строками является оператор `+`. Он соединяет две строки в одну. Однако в Sass есть специфическое правило: **результат наследует тип кавычек левого операнда**.

### Правила кавычек:

|**Левый операнд**|**Правый операнд**|**Результат**|**Пример**|
|---|---|---|---|
|**В кавычках**|Любой|**В кавычках**|`"Foo" + Bar` $\rightarrow$ `"FooBar"`|
|**Без кавычек**|Любой|**Без кавычек**|`Foo + "Bar"` $\rightarrow$ `FooBar`|

### Примеры в коде:

```SCSS
// Левая часть в кавычках -> результат в кавычках
@debug "Helvetica" + " Neue"; // "Helvetica Neue"
@debug "Sans-" + serif;       // "Sans-serif"

// Левая часть без кавычек -> результат без кавычек
@debug Arial + " Black";      // Arial Black
@debug bold + -italic;        // bold-italic
```

## 2. Взаимодействие с другими типами данных

Sass позволяет добавлять к строкам значения других типов (числа, цвета, списки). В этом случае значение преобразуется в строку перед объединением.

```SCSS
@debug "Value: " + 10px;      // "Value: 10px"
@debug "Color is " + #ff0000; // "Color is #ff0000"
@debug "Allowed: " + true;    // "Allowed: true"
```

> **Важное замечание:** Хотя вы можете складывать строки и числа, помните о математических операторах. Если вы попытаетесь сложить `10px + "5px"`, Sass может выдать ошибку или неожиданный результат, если не будет уверен, что вы хотите именно строковую конкатенацию.

---

## 3. Пробелы в конкатенации

Sass сохраняет пробелы внутри строк, но не добавляет их автоматически между операндами. Если вам нужен пробел между словами, его нужно включить в одну из строк.

```SCSS
$first: "First";
$second: "Second";

@debug $first + $second;      // "FirstSecond"
@debug $first + " " + $second; // "First Second"
```

---

## 4. Интерполяция `#{}` против Оператора `+`

Интерполяция — это мощная альтернатива оператору `+`. Она позволяет вставлять выражения прямо внутрь строки.

**Ключевое отличие:** Интерполяция **всегда** превращает результат в строку **без кавычек** (если она не находится внутри другой строки в кавычках).

```SCSS
$weight: bold;

// Использование +
.element {
  font-family: "Robot-" + $weight; // font-family: "Robot-bold";
}

// Использование интерполяции
.element {
  font-family: Robot-#{$weight};   // font-family: Robot-bold;
}
```

---

## 5. Специальные случаи и пустые строки

Если один из операндов является пустой строкой `""`, оператор `+` эффективно преобразует другой операнд в строку с соответствующим типом кавычек.

```SCSS
@debug "" + Helvetica; // "Helvetica" (превратили unquoted в quoted)
@debug #333 + "";      // "#333"
```

## Практический пример: Генератор путей (Asset Helper)

Операторы строк незаменимы при создании динамических путей к файлам.

```SCSS
$asset-path: "/assets/images/";

@function get-icon($name) {
  @return $asset-path + $name + ".svg";
}

.icon-user {
  background-image: url(get-icon("user")); 
  // Результат: url("/assets/images/user.svg")
}
```

### Итог:

1. Используйте **`+`**, если вам нужно сохранить тип кавычек (особенно для путей и семейств шрифтов).
    
2. Помните правило **левого операнда**.
    
3. Используйте **интерполяцию `#{}`**, когда вам нужно динамически собрать имя селектора или свойства, где кавычки недопустимы.
