# Числовые операторы в Sass: Математика и работа с единицами

Числовые операторы в Sass позволяют выполнять арифметические вычисления прямо в таблицах стилей. В отличие от стандартного CSS `calc()`, вычисления в Sass происходят на этапе компиляции, что позволяет использовать их в условиях, циклах и для динамического формирования значений.

Sass поддерживает пять стандартных бинарных операторов и два унарных.

---

## 1. Основные арифметические операторы

|**Оператор**|**Описание**|**Пример**|**Результат**|
|---|---|---|---|
|`+`|Сложение|`10px + 5px`|`15px`|
|`-`|Вычитание|`100% - 20%`|`80%`|
|`*`|Умножение|`5px * 2`|`10px`|
|`/`|Деление|`math.div(10px, 2)`|`5px`|
|`%`|Остаток от деления|`10px % 3`|`1px`|

---

## 2. Работа с единицами измерения

Sass обрабатывает единицы измерения так же, как они обрабатываются в физике. Это одна из самых мощных и одновременно сложных сторон языка.

### Сложение и вычитание

Для выполнения сложения или вычитания единицы должны быть **совместимыми**. Если единицы совместимы (например, `px` и `in`), Sass автоматически преобразует их.

- `5px + 2px = 7px`
    
- `1in + 6px` $\rightarrow$ $96px + 6px = 102px$
    
- `10px - 1em` $\rightarrow$ **Ошибка!** (Несовместимые единицы)
    

### Умножение

При умножении единицы измерения также перемножаются. Хотя CSS не поддерживает «квадратные пиксели», Sass позволяет проводить такие вычисления для промежуточных этапов в функциях.

- `10px * 2 = 20px`
    
- `10px * 2px = 20px*px` (или $20px^2$)
    

### Деление

При делении одинаковые единицы сокращаются.

- `math.div(10px, 2px) = 5` (результат без единиц)
    
- `math.div(10px, 2) = 5px`

---

## 3. Деление: `/` против `math.div()`

Исторически в CSS символ `/` использовался как разделитель (например, в свойстве `font: 12px/1.5` или `grid-column: 1/3`). Чтобы сохранить совместимость с CSS, Sass изменил подход к делению.

**Использование `/` в качестве оператора деления устарело.**

### Современный способ (`math.div`)

Для деления необходимо использовать функцию `math.div()` из встроенного модуля `sass:math`.

```SCSS
@use "sass:math";

.container {
  width: math.div(100%, 3); // 33.3333333333%
}
```

### Когда `/` все еще работает как деление (Legacy):

Sass будет трактовать `/` как деление только в следующих случаях (но все равно выдаст предупреждение):

1. Если значение сохранено в переменной: `$width / 2`.
    
2. Inside parentheses: `(10px / 2)`.
    
3. Если значение является частью другого вычисления: `10px / 2 + 5px`.

> **Важно:** Чтобы использовать `/` как обычный символ (разделитель CSS) и избежать предупреждений, используйте интерполяцию: `font: #{$size} / #{$line-height};`.

## 4. Оператор остатка `%`

Оператор `%` возвращает остаток от деления первого числа на второе. Единица измерения результата совпадает с единицей измерения левого операнда.

```SCSS
@debug 10px % 3;    // 1px
@debug 25% % 10;    // 5%
@debug 15px % 4px;  // 3px
```

---

## 5. Унарные операторы

Унарные операторы работают только с одним числом:

- `+$value` — возвращает значение без изменений.
    
- `-$value` — меняет знак числа на противоположный.

```SCSS
$gap: 10px;
.margin-negative {
  margin-top: -$gap; // -10px
}
```

---

## 6. Приоритет операций

Sass соблюдает стандартный математический порядок операций (PEMDAS/BODMAS):

1. Выражения в **скобках** `()`.
    
2. Унарные операторы `+`, `-`.
    
3. **Умножение** `*`, **Деление** `math.div` и **Остаток** `%`.
    
4. **Сложение** `+` и **Вычитание** `-`.
    

### Пример сложного вычисления:

```SCSS
@use "sass:math";

$base: 10px;
$result: $base + math.div(20px, 2) * 3; 
// 1. math.div(20, 2) = 10
// 2. 10 * 3 = 30
// 3. 10 + 30 = 40px
```

---

## 7. Технические ограничения и точность

Sass поддерживает высокую точность вычислений (по умолчанию до 10 знаков после запятой). При компиляции в CSS очень длинные дроби будут округлены.

Если вам нужно специфическое округление, используйте функции модуля `sass:math`:

- `math.round($number)` — до ближайшего целого.
    
- `math.ceil($number)` — в большую сторону.
    
- `math.floor($number)` — в меньшую сторону.

```SCSS
@use "sass:math";

@debug math.round(10.4px); // 10px
@debug math.ceil(10.1px);  // 11px
```
