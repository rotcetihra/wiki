# @mixin и @include

Миксины — это один из самых мощных инструментов в Sass. Если переменные позволяют хранить отдельные значения, то миксины позволяют переиспользовать **целые блоки стилей**. Это основа принципа DRY (Don't Repeat Yourself) в верстке.

На основе документации разберем, как создавать, настраивать и использовать миксины.

## 1. Основы: Объявление и включение

Миксин создается с помощью директивы **@mixin**, а вызывается — через **@include**.

 * **Объявление:** @mixin name { ... }
 * **Вызов:** @include name;

```scss
@mixin reset-list {
  margin: 0;
  padding: 0;
  list-style: none;
}

nav ul {
  @include reset-list;
}
```

## 2. Аргументы: Гибкость миксинов

Миксины могут принимать аргументы, что делает их похожими на функции в программировании. Это позволяет настраивать стили при каждом вызове.

### Типы аргументов:

 1. **Обязательные:** Если вы указали аргумент в скобках, его нужно передать при вызове.
 2. **Необязательные (Дефолтные):** Можно задать значение по умолчанию через двоеточие.
 3. **Именованные (Keyword Arguments):** При вызове можно указывать имя аргумента, чтобы не соблюдать порядок.
 4. **Произвольное количество (...):** Если вы не знаете заранее, сколько значений будет передано (например, для box-shadow).

**Пример:**

```scss
@mixin square($size, $radius: 0) {
  width: $size;
  height: $size;
  border-radius: $radius;
}

// Вызов с позиционными аргументами
.box { @include square(100px, 10px); }

// Вызов с именованным аргументом (радиус останется 0)
.circle { @include square(50px); }

// Смена порядка через имена
.round { @include square($radius: 50%, $size: 200px); }
```

## 3. Блок @content

Иногда нужно передать внутрь миксина не просто значение, а **целый блок CSS-правил**. Для этого используется директива @content. Она работает как «слот» или «заполнитель», куда попадет всё, что вы напишете внутри фигурных скобок @include.

**Пример (адаптивная верстка):**

```scss
@mixin tablet {
  @media (max-width: 768px) {
    @content; // Сюда подставятся стили из вызова
  }
}

.sidebar {
  width: 300px;
  @include tablet {
    width: 100%; // Этот блок попадет в @content
  }
}
```

### Новинка: Аргументы в @content

В современных версиях Sass миксин может передавать данные обратно в блок контента. Для этого используется синтаксис using.

```scss
@mixin theme-colors($theme) {
  @content($theme);
}

@include theme-colors("dark") using ($name) {
  .theme-#{$name} {
    background: black;
  }
}
```

## 4. Миксины против Функций и Наследования

| Инструмент    | Что возвращает?               | Когда использовать?                                       |
| ------------- | ----------------------------- | --------------------------------------------------------- |
| **@mixin**    | Блоки CSS-кода                | Для переиспользования групп стилей (префиксы, сетки).     |
| **@function** | Значение (число, цвет и т.д.) | Для вычислений (расчет ширины, конвертация единиц).       |
| **@extend**   | Селекторы                     | Для наследования свойств одного класса другим (иерархия). |

## Главные советы по использованию:

 1. **Не переусердствуйте с вложенностью:** Миксины могут генерировать огромный объем CSS, если вызывать их необдуманно.
 2. **Используйте !default:** Если вы создаете библиотеку, делайте аргументы миксинов настраиваемыми.
 3. **Документируйте через ///:** Используйте SassDoc, чтобы ваши коллеги понимали, какие аргументы принимает миксин.

Миксины — это сердце профессиональной разработки на Sass. Они позволяют превратить набор разрозненных стилей в стройную и легко управляемую дизайн-систему.
