# @if и @else

Директива **@if** в Sass — это основной инструмент принятия решений. Она позволяет контролировать, будет ли выведен конкретный блок стилей или выполнен определенный код, основываясь на результате логического выражения.

На основе документации Sass разберем, как работают условия и что считается «истиной» в мире препроцессора.

## 1. Базовый синтаксис

Директива @if принимает выражение и выполняет блок кода в фигурных скобках, если результат выражения не равен false или null.

```scss
@mixin avatar($size, $circle: false) {
  width: $size;
  height: $size;

  @if $circle {
    border-radius: $size / 2;
  }
}

.user-icon {
  @include avatar(40px, $circle: true);
}
```

## 2. Цепочки условий: @else if и @else

Если первое условие не выполняется, вы можете проверить дополнительные варианты с помощью @else if или задать поведение по умолчанию через @else.

**Пример (адаптивная типографика):**

```scss
@mixin text-size($size) {
  @if $size == "large" {
    font-size: 2rem;
  } @else if $size == "medium" {
    font-size: 1.5rem;
  } @else if $size == "small" {
    font-size: 1rem;
  } @else {
    // Если передано число или неизвестная строка
    font-size: $size;
  }
}

.title { @include text-size("large"); }
.subtitle { @include text-size(1.2rem); }
```

## 3. Истинность и Ложность (Truthiness & Falsiness)

Это критически важный момент для понимания Sass. В отличие от многих языков программирования (например, JavaScript), где 0 или пустая строка "" считаются ложными, в Sass ситуация иная.

**В Sass ложными (falsey) являются ТОЛЬКО:**

 1. false
 2. null

**Всё остальное считается истинным (truthy):**

 * Число 0 — **true**
 * Пустая строка "" — **true**
 * Пустой список () — **true**
 * Пустая карта () — **true**

## 4. Операторы сравнения и логики

В выражениях @if вы можете использовать стандартные операторы:

 * **Сравнение:** \==, !=, >, <, >=, <=
 * **Логика:** and, or, not

**Пример сложного условия:**

```scss
$theme: "dark";
$debug: true;

@if $theme == "dark" and $debug {
  body::before {
    content: "DEBUG MODE: DARK THEME";
    color: red;
  }
}
```

## 5. Практические советы

 1. **Проверка аргументов:** Используйте @if вместе с @error, чтобы убедиться, что в миксин переданы правильные данные.
 2. **Конфигурация тем:** Условия позволяют создавать переключатели (флаги) для включения или выключения целых модулей стилей.
 3. **Гибкие сетки:** Вы можете проверять ширину контейнера и динамически менять количество колонок.

## Резюме

Директива @if делает ваши стили «умными». Вместо того чтобы писать сотни похожих классов, вы можете создать один миксин, который сам решит, какие свойства применить в зависимости от контекста.
