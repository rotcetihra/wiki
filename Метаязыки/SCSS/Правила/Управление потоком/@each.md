# @each

Директива **@each** — это, пожалуй, самый популярный и часто используемый цикл в Sass. Если @for завязан на числах, то @each работает с **данными**: списками и картами. Это ваш главный инструмент для автоматизации создания иконок, кнопок, сеток и любых других повторяющихся элементов.

На основе документации разберем, как заставить Sass работать за вас.

## 1. Обход простого списка (Lists)

Это самый базовый сценарий. Вы даете Sass список значений, и он выполняет блок кода для каждого из них.

**Синтаксис:** `@each $var in \<list>`

```scss
$sizes: 40px, 80px, 120px;

@each $size in $sizes {
  .icon-#{$size} {
    width: $size;
    height: $size;
  }
}
```

## 2. Деструктуризация: Списки в списках

Иногда одного значения на итерацию мало. Например, вам нужно имя класса *и* значение. В этом случае вы можете использовать списки списков и «распаковывать» их в несколько переменных.

**Пример (иконки с именами):**

```scss
$icons: ("mail", 20px), ("user", 32px), ("settings", 48px);

@each $name, $size in $icons {
  .icon-#{$name} {
    background-image: url("/icons/#{$name}.svg");
    width: $size;
    height: $size;
  }
}
```

## 3. Обход карт (Maps)

Работа с картами (key: value) — это стандарт современной разработки на Sass. Это делает код максимально чистым и понятным.

**Синтаксис:** @each $key, $value in \<map>

```scss
$theme-colors: (
  "success": #28a745,
  "info": #17a2b8,
  "warning": #ffc107
);

@each $name, $color in $theme-colors {
  .alert-#{$name} {
    background-color: $color;
    border-left: 5px solid darken($color, 15%);
  }
}
```

## 4. Почему @each лучше, чем @for?

Хотя оба могут генерировать классы, разработчики предпочитают @each по нескольким причинам:

| Характеристика | @each | @for |
|---|---|---|
| **Читаемость** | Высокая (работаем с именами) | Средняя (работаем с индексами) |
| **Гибкость** | Легко добавить новое значение в список | Нужно следить за диапазоном чисел |
| **Тип данных** | Любой (строки, цвета, списки) | Только целые числа |
| **Назначение** | Контентно-зависимые стили | Математические сетки, задержки |

## 5. Практические советы

> **Важно про интерполяцию:**
> Когда вы используете переменную из цикла в имени селектора или свойства, её обязательно нужно оборачивать в #{ $var }. В значениях свойств (например, color: $var) интерполяция не нужна.

### Продвинутый кейс: Генерация утилит

Цикл @each часто используют для создания библиотек утилит (по типу Tailwind):

```scss
$displays: none, block, flex, grid;

@each $disp in $displays {
  .d-#{$disp} {
    display: $disp !important;
  }
}
```

### Резюме

Используйте @each всякий раз, когда у вас есть набор однотипных данных, которые нужно превратить в CSS-код. Это избавляет от копипаста и делает проект невероятно легким в поддержке: чтобы добавить новый цвет или размер, вам достаточно дописать одно слово в массив данных.
