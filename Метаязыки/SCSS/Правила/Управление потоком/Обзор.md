# Обзор

Управляющие конструкции в Sass (**Flow Control**) превращают ваши таблицы стилей из простого набора правил в динамический код. Они позволяют решать, стоит ли выводить блок стилей (логика @if) или сколько раз его нужно повторить (циклы @each, @for, @while).

На основе официальной документации разберем каждую конструкцию.

## 1. @if и @else: Условная логика

Эти директивы позволяют выводить стили только при выполнении определенного условия. Это база для создания адаптивных миксинов и гибких тем.

 * **@if <выражение> { ... }**
 * **@else if <выражение> { ... }**
 * **@else { ... }**

**Пример:**

```scss
@mixin theme-colors($light-theme: true) {
  @if $light-theme {
    background-color: #fff;
    color: #333;
  } @else {
    background-color: #333;
    color: #fff;
  }
}

.content { @include theme-colors($light-theme: false); }
```

## 2. @each: Обход списков и карт

Это самая популярная циклическая конструкция в Sass. Она идеально подходит для генерации набора классов на основе списка значений или карты (map).

 * **Для списков:** @each $item in $list { ... }
 * **Для карт:** @each $key, $value in $map { ... }

**Пример (генерация иконок):**

```scss
$sizes: 40px, 80px, 120px;

@each $size in $sizes {
  .icon-#{$size} {
    width: $size;
    height: $size;
  }
}
```

## 3. @for: Цикл с заданным количеством итераций

Используется, когда нужно повторить действие определенное количество раз.

Есть два варианта написания:

 1. **from \<start> through \<end>**: включает конечное число.
 2. **from \<start> to \<end>**: останавливается **до** конечного числа.
    

**Пример (сетка):**

```scss
@for $i from 1 through 3 {
  .col-#{$i} {
    width: 100% / 3 * $i;
  }
}
```

## 4. @while: Цикл с условием

Самый редкий тип цикла. Он повторяет выполнение блока до тех пор, пока условие истинно. Обычно его заменяют на @each или @for, но он незаменим для сложных математических вычислений (например, экспоненциального роста).

```scss
$size: 10px;
@while $size < 50px {
  .padding-#{$size} { padding: $size; }
  $size: $size + 10px; // Важно не забыть изменить условие, чтобы не зависнуть
}
```

## 5. Истинность и Ложность (Truthiness)

В Sass всё, что не является false или null, считается **истинным** (true). Это означает, что числа 0, пустые строки "" и пустые списки () в условиях @if будут трактоваться как true.

| Значение | Результат в @if |
|---|---|
| true | ✅ True |
| false | ❌ False |
| null | ❌ False |
| любая строка, число, список | ✅ True |

## Сравнение: Что выбрать?

| Конструкция | Когда использовать? | Пример |
|---|---|---|
| **@if** | Нужно выбрать один из вариантов. | Переключение светлой/темной темы. |
| **@each** | Есть готовый набор данных (цвета, иконки). | Генерация кнопок разных цветов. |
| **@for** | Нужно пронумеровать элементы. | Сетка, z-index, задержки анимации (nth-child). |
| **@while** | Сложный шаг итерации или условие. | Рекурсивные вычисления размеров. |

## Резюме

Управляющие конструкции превращают Sass из простого препроцессора в мощный язык программирования для CSS. Они позволяют автоматизировать рутину: вместо того чтобы писать 12 классов для колонок вручную, вы пишете 3 строки цикла @for.
