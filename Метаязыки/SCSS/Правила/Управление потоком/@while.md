# @while

Директива **@while** — это наиболее гибкий, но и самый редко используемый цикл в Sass. В отличие от @for (который считает от А до Б) или @each (который перебирает список), @while продолжает выполнять блок кода до тех пор, пока определенное условие истинно.

На основе документации разберем, как работает этот «цикл с условием» и когда он действительно необходим.

## 1. Как работает @while

Цикл @while оценивает логическое выражение перед каждой итерацией. Если результат true, выполняется тело цикла. Если false, цикл завершается.

**Синтаксис:**

```scss
@while <условие> {
  // Код
}
```

**Пример (генерация типографической шкалы):**

```scss
$size: 10px;

@while $size < 50px {
  .text-#{$size} {
    font-size: $size;
  }
  $size: $size + 10px; // Увеличиваем значение, чтобы условие когда-то стало ложным
}
```

## 2. Главная опасность: Бесконечный цикл

В отличие от @for, который гарантированно завершится, в @while вы сами отвечаете за изменение переменной, участвующей в условии. Если вы забудете обновить переменную внутри цикла, Sass будет компилировать его вечно, что приведет к зависанию сборщика или ошибке переполнения памяти.

**Плохой пример (зависнет):**

```scss
$i: 5;
@while $i > 0 {
  .item-#{$i} { width: 10px; }
  // Ошибка: переменная $i не меняется, цикл бесконечен!
}
```

## 3. Когда использовать @while вместо @for?

В 90% случаев @for или @each справляются лучше, так как они безопаснее и нагляднее. Однако @while незаменим, если:

 1. **Сложный шаг:** Вам нужно увеличивать значение не на 1, а, например, умножать его или использовать сложную формулу на каждом шаге.
 2. **Нечисловое условие:** Условие зависит от результата какой-то функции, а не просто от счетчика.

**Пример (экспоненциальный рост):**

```scss
$value: 2;

@while $value <= 64 {
  .z-index-#{$value} {
    z-index: $value;
  }
  $value: $value * 2; // Шаг: 2, 4, 8, 16, 32, 64
}
```

## 4. Сравнение всех циклов Sass

| Цикл | Источник итераций | Лучшее применение |
|---|---|---|
| **@each** | Список или Карта (Map) | Цвета, иконки, темы. Самый безопасный. |
| **@for** | Диапазон чисел (1..12) | Сетки, простые последовательности. |
| **@while** | Произвольное условие | Сложные алгоритмы, математические прогрессии. |

## Практический совет

Если вы ловите себя на написании @while, сначала подумайте: «Могу ли я сделать это через @for или заранее сгенерированный список в @each?». Если ответ «да» — используйте их. Это сделает ваш код более предсказуемым для коллег и защитит от случайных бесконечных циклов.
