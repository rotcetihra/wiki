# @for

Директива **@for** в Sass — это классический цикл со счетчиком, знакомый многим по языкам программирования. Она позволяет повторять блок стилей определенное количество раз, используя числовую переменную (индекс).

Это идеальный инструмент для создания **геометрических структур**, таких как сетки (grid systems), или последовательностей (например, задержек анимации для списка элементов).

## 1. Два варианта синтаксиса

В Sass существует два способа написания цикла @for, которые различаются тем, включается ли конечное число в итерацию.

### Вариант А: through (включительно)

Цикл выполняется от начального до конечного числа **включительно**.

@for $i from 1 through 3 выполнится для 1, 2 и 3.

```scss
@for $i from 1 through 3 {
  .item-#{$i} { width: 10px * $i; }
}
// Результат в CSS: .item-1, .item-2, .item-3
```

### Вариант Б: to (исключая конец)

Цикл выполняется от начального числа до конечного, **не включая** его.

@for $i from 1 to 3 выполнится только для 1 и 2.

```scss
@for $i from 1 to 3 {
  .item-#{$i} { width: 10px * $i; }
}
// Результат в CSS: .item-1, .item-2
```

## 2. Практические примеры

### А. Создание сеточной системы

Самый частый кейс — генерация классов для колонок. Вместо того чтобы писать 12 классов вручную, мы используем цикл:

```scss
$grid-columns: 12;

@for $i from 1 through $grid-columns {
  .col-#{$i} {
    width: (100% / $grid-columns) * $i;
  }
}
```

### Б. Каскадная задержка анимации (Staggered Animation)

Если у вас есть список элементов, которые должны появляться один за другим, @for поможет рассчитать animation-delay:

```scss
.list-item {
  animation: fadeIn 0.5s ease-in-out;

  @for $i from 1 through 5 {
    &:nth-child(#{$i}) {
      animation-delay: $i * 0.1s;
    }
  }
}
```

## 3. Важные технические нюансы

 1. **Интерполяция:** Чтобы использовать переменную цикла $i внутри имени класса или в селекторе nth-child, её нужно обязательно оборачивать в #{}. Внутри значений свойств (например, z-index: $i) интерполяция не требуется.
 2. **Направление:** Вы можете считать в обратную сторону. Если начальное число больше конечного, Sass будет уменьшать счетчик: @for $i from 5 through 1.
 3. **Единицы измерения:** В цикле используются целые числа без единиц измерения. Если вам нужны px или %, вы просто умножаете индекс на нужную величину: $i * 1px.

## 4. Сравнение: @for против @each

Хотя оба инструмента — циклы, они служат разным целям:

| Характеристика | @for | @each |
|---|---|---|
| **Источник данных** | Диапазон чисел | Список или карта (Map) |
| **Когда использовать** | Математические расчеты, нумерация | Цвета, иконки, названия из списка |
| **Пример** | Колонки 1-12 | Цвета: red, blue, green |

## Резюме

Используйте @for, когда ваш CSS-код зависит от **порядкового номера** элемента. Это делает код лаконичным и позволяет мгновенно менять структуру (например, превратить 12-колоночную сетку в 24-колоночную, изменив всего одну переменную).
