# @function

В то время как миксины отвечают за генерацию целых блоков CSS-кода, **функции в Sass (`@function`)** предназначены для одной конкретной задачи: произвести вычисление и вернуть **значение**.

Если миксины — это «штампы» для тиражирования стилей, то функции — это ваши карманные математики, которые помогают рассчитывать размеры, манипулировать цветами и управлять сложной логикой.

---

## 1. Анатомия функции: Как это работает

Функция определяется директивой `@function`, принимает аргументы и **обязательно** заканчивается директивой `@return`. Как только Sass встречает `@return`, выполнение функции прекращается, а результат подставляется в место вызова.

### Простейший пример:

```SCSS
@function multiply($number, $multiplier) {
  @return $number * $multiplier;
}

.container {
  width: multiply(100px, 2); // Результат: 200px
}
```

---

## 2. Аргументы: Гибкость и контроль

Функции в Sass поддерживают все те же фишки с аргументами, что и миксины:

- **Значения по умолчанию:** Позволяют вызывать функцию без передачи всех параметров.
    
- **Именованные аргументы:** Можно передавать значения в любом порядке, указывая имя.
    
- **Произвольное количество аргументов:** Использование `...` для работы со списками аргументов.
    

**Пример продвинутой функции:**

```SCSS
@function calculate-scale($base-size, $factor: 1.2) {
  @return $base-size * $factor;
}

.title {
  font-size: calculate-scale(16px, $factor: 1.5); // 24px
}
```

---

## 3. Математическая мощь (LaTeX)

Функции идеально подходят для реализации типографических сеток или сложных пропорций. Например, если вам нужно рассчитать «золотое сечение» для макета:

Допустим, мы используем формулу золотого сечения:

$$L_{new} = L_{base} \times \phi$$

Где

$$\phi \approx 1.618$$

В Sass это будет выглядеть так:

```SCSS
@function golden-ratio($size) {
  $phi: 1.61803398875;
  @return $size * $phi;
}

.sidebar {
  width: golden-ratio(300px); // ~485.41px
}
```

## 4. Сравнение: Функция или Миксин?

Это самый частый вопрос новичков. Главное правило: **смотрите на результат**.

|**Характеристика**|**@function**|**@mixin**|
|---|---|---|
|**Что возвращает?**|Одиночное значение (цвет, число, строку)|Блок свойств CSS или другие правила|
|**Как используется?**|Внутри значения свойства: `width: func();`|Как отдельная директива: `@include mix();`|
|**Цель**|Расчеты и трансформация данных|Переиспользование кода и структуры|
|**Пример**|Конвертация `px` в `rem`|Создание сетки Flexbox|

## 5. Встроенные функции vs Пользовательские

Sass уже поставляется с огромным багажом встроенных функций (модули `sass:math`, `sass:color`, `sass:map` и т.д.). Прежде чем писать свою функцию, проверьте — возможно, она уже существует.

**Пример использования встроенного модуля:**

```SCSS
@use "sass:color";

.button {
  // Встроенная функция для изменения яркости
  background-color: color.adjust(#3498db, $lightness: -10%);
}
```

## 6. Лучшие практики

1. **Чистота (Pure Functions):** Старайтесь, чтобы функции зависели только от своих аргументов и не меняли глобальные переменные. Это делает код предсказуемым.
    
2. **Обработка ошибок:** Используйте директиву `@error`, если в функцию переданы некорректные данные.

```SCSS
@function get-column-width($total, $count) {
  @if $count <= 0 {
	@error "Количество колонок должно быть больше нуля!";
  }
  @return $total / $count;
}
```

3. **Имена:** Давайте функциям глагольные имена (например, `get-size`, `convert-units`), чтобы сразу было ясно, что они что-то вычисляют.
    

### Резюме

Используйте `@function` каждый раз, когда ловите себя на мысли: «Мне нужно рассчитать это значение». Это сделает вашу таблицу стилей живой и адаптивной, а не просто набором жестко заданных цифр.
