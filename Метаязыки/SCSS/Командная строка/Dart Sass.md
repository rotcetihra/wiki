# Dart Sass: Главный инструмент в экосистеме

Если вы используете Sass в 2026 году, вы, скорее всего, используете именно **Dart Sass**. Это эталонная реализация языка, которая заменила старый Ruby Sass и ныне покойный LibSass (Node Sass). В документации по ссылке подробно описывается именно этот исполняемый файл.

---

## 1. Почему именно Dart Sass?

Раньше выбор реализации был головной болью. Теперь всё просто: Dart Sass — это «золотой стандарт».

- **Первым получает все фичи:** Все новые возможности (модульная система, OKLCH, новые API) появляются сначала здесь.
    
- **Скорость:** Несмотря на то, что он написан на Dart, он компилирует код быстрее своего предшественника на Ruby.
    
- **Простая установка:** Он компилируется в чистый JavaScript (для npm) или в автономные бинарные файлы, которые не требуют установки дополнительных языков программирования.

---

## 2. Как установить Dart Sass

Есть несколько способов «завести» этот движок на вашей машине:

### Способ А: Через Node.js (Самый популярный)

Если вы фронтенд-разработчик, у вас наверняка есть npm.

```Bash
npm install -g sass
```

Это установит пакет `sass`, который под капотом является версией Dart Sass, скомпилированной в JavaScript.

### Способ Б: Системные менеджеры пакетов

Если вы предпочитаете нативные инструменты ОС:

- **macOS (Homebrew):** `brew install sass/sass/sass`
    
- **Windows (Chocolatey):** `choco install sass`
    

### Способ В: Standalone (Автономный бинарник)

Вы можете просто скачать архив с официального репозитория на GitHub, распаковать его и добавить путь к папке в переменную `PATH`. В этом случае вам не нужен ни Node.js, ни что-либо другое.

---

## 3. Командная строка: Dart Sass vs Node Sass

Важно помнить, что интерфейс командной строки (CLI) Dart Sass отличается от старого Node Sass.

**Ключевые отличия в командах:**

1. **Разделитель:** В Dart Sass для указания входного и выходного файла используется **двоеточие** (особенно для папок) или просто пробел.
    
2. **Флаги:** Многие флаги изменились. Например, вместо `--precision` (которая в Dart Sass всегда высокая) или специфических настроек LibSass, здесь используются современные параметры вроде `--style=compressed`.

---

## 4. Использование в качестве библиотеки

Dart Sass можно использовать не только через терминал, но и подключать напрямую в ваш JavaScript-код. Как мы обсуждали ранее (в разделе про JS API), Dart Sass предоставляет два интерфейса:

- **Modern API (`compile`, `compileAsync`):** Быстрый, современный, рекомендуемый.
    
- **Legacy API (`render`):** Оставлен только для совместимости со старыми инструментами.

---

## 5. Производительность: JS vs Native

Интересный факт: пакет `sass` в npm — это JS-версия Dart Sass. Она удобна, но работает медленнее, чем «нативный» Dart-бинарник.

> [!TIP]
> 
> Если у вас огромный проект с тысячами SCSS-файлов и компиляция занимает много времени, попробуйте установить нативную версию (через Homebrew или скачав бинарник). Она работает заметно быстрее, так как не тратит время на интерпретацию JavaScript в среде Node.js.

---

## 6. Что дальше?

Dart Sass активно избавляется от старого наследия. Если вы видите предупреждения о `Deprecation`, это работа Dart Sass, который готовит ваш код к версии **2.0.0**. Большинство этих предупреждений можно исправить автоматически с помощью инструмента `sass-migrator`, который также написан командой Sass.
