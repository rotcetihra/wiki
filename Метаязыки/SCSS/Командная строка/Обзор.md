# Работа с интерфейсом командной строки (CLI) Sass

Sass CLI — это мощный инструмент, который превращает ваш `.scss` или `.sass` код в готовый для браузера `.css` файл. Это «сердце» рабочего процесса для тех, кто не хочет зависеть от тяжелых графических интерфейсов или сложных сборщиков на начальном этапе.

---

## 1. Базовая команда компиляции

Самая простая форма использования CLI — передать путь к исходному файлу и путь к файлу, который должен получиться на выходе.

```Bash
sass input.scss output.css
```

Если вы укажете только один файл, Sass скомпилирует его и выведет результат прямо в терминал (что удобно для быстрой проверки, но редко используется в реальной работе).

---

## 2. Режим отслеживания (`--watch`)

Вместо того чтобы запускать компиляцию вручную после каждого нажатия `Ctrl + S`, вы можете заставить Sass «следить» за вашими файлами.

```Bash
sass --watch input.scss:output.css
```

В этом режиме CLI остается активным. Как только вы сохраняете изменения в `input.scss` (или в любом файле, который в него импортирован через `@use` или `@forward`), Sass мгновенно обновляет `output.css`.

---

## 3. Компиляция целых папок

Если в вашем проекте много файлов, вы можете компилировать их все одной командой, указав исходную папку и папку назначения, разделив их двоеточием.

```Bash
sass --watch src/scss:dist/css
```

> **Важно:** Sass автоматически проигнорирует файлы, имена которых начинаются с нижнего подчеркивания (например, `_variables.scss`). Такие файлы называются **partials** (частичные файлы) — они предназначены для импорта в другие файлы и не должны превращаться в отдельные CSS-файлы.

---

## 4. Ключевые флаги (Options)

CLI позволяет тонко настроить итоговый результат с помощью дополнительных параметров:

- **`--style`**: Определяет внешний вид выходного CSS.
    
    - `expanded` (по умолчанию): Читаемый код со всеми отступами.
        
    - `compressed`: Максимально сжатый код для использования на «проде».
        
- **`--no-source-map`**: Отключает генерацию файлов `.map`. По умолчанию Sass создает их, чтобы инструменты разработчика в браузере могли показать вам строку в `.scss`, а не в скомпилированном `.css`.
    
- **`--load-path`**: Позволяет указать дополнительные папки, в которых Sass будет искать файлы при использовании `@use`. Это критично, если вы подключаете внешние библиотеки или фреймворки.
    
- **`--quiet`**: Заставляет Sass «замолчать» и не выводить предупреждения в терминал (полезно, если вы используете много сторонних библиотек с устаревшим кодом).

---

## 5. Интерактивная оболочка (Sass Shell)

Если вы хотите просто попрактиковаться в синтаксисе Sass или проверить работу какой-то функции, вы можете запустить интерактивный режим:

```Bash
sass --interactive
```

Это позволит вам вводить выражения Sass и мгновенно видеть результат их вычисления.

---

### Резюме

Использование CLI — это самый быстрый способ начать работу с Sass. Вам достаточно установить пакет через npm (`npm install -g sass`) и запустить режим `--watch`. Это обеспечит вам мгновенную обратную связь без необходимости настраивать сложные системы сборки вроде Webpack или Vite.
