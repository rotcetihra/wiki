# Интерполяция

## Что такое интерполяция в Sass?

**Интерполяция** — это способ вставить результат выражения SassScript (например, переменную или вызов функции) в произвольное место вашей таблицы стилей. Если обычные переменные работают только как значения свойств, то интерполяция позволяет внедрять данные в селекторы, имена самих свойств и даже в комментарии.

> **Синтаксис:** Выражение оборачивается в символы #{ }.

### Где можно использовать интерполяцию?

Интерполяцию можно использовать практически везде:

 * **Селекторы** в правилах стиля.
 * **Имена свойств** в объявлениях.
 * **Значения CSS-переменных** (custom properties).
 * **CSS @-правила** (например, @media или @keyframes).
 * **Директивы @extend** и обычный CSS @import.
 * **Строки** (в кавычках и без).
 * **Специальные функции** (например, url()) и имена функций.
 * **Громкие комментарии** (/* ... */).

#### Пример: Универсальный миксин для иконок

```scss
@mixin corner-icon($name, $top-or-bottom, $left-or-right) {
  // Интерполяция в имени класса
  .icon-#{$name} {
    background-image: url("/icons/#{$name}.svg"); // Внутри url()
    position: absolute;
    
    // Интерполяция в именах свойств
    #{$top-or-bottom}: 0;
    #{$left-or-right}: 0;
  }
}

@include corner-icon("mail", top, left);
```

**Результат в CSS:**

```css
.icon-mail {
  background-image: url("/icons/mail.svg");
  position: absolute;
  top: 0;
  left: 0;
}
```

## Интерполяция в SassScript

Внутри выражений SassScript интерполяция используется для создания **некавычечных строк**. Это особенно полезно при динамической генерации имен для анимаций.

### Пример с анимацией:

```scss
@mixin inline-animation($duration) {
  $name: inline-#{unique-id()}; // Генерируем уникальное имя
  
  @keyframes #{$name} {
    @content;
  }
  
  animation-name: $name;
  animation-duration: $duration;
}

.pulse {
  @include inline-animation(2s) {
    from { background-color: yellow; }
    to { background-color: red; }
  }
}
```

## Важные правила и «подводные камни»

### 1. Не используйте интерполяцию там, где она не нужна

Частая ошибка новичков — писать color: #{$accent}. Это избыточно. Если вы просто передаете значение переменной в свойство, пишите напрямую: color: $accent.

### 2. Интерполяция и числа (Опасно!)

Использовать интерполяцию для работы с числами и единицами измерения — плохая идея.

 * Интерполяция превращает число в **строку**, что делает невозможными дальнейшие математические операции.
 * Она обходит встроенные проверки Sass на совместимость единиц.

**Плохо:** #{$width}px (получится строка, с которой нельзя считать).

**Хорошо:** $width * 1px (Sass сохранит числовой тип данных и проверит юниты).

### 3. Особенности кавычек

При интерполяции строки в кавычках эти **кавычки удаляются**. Это позволяет «пробрасывать» в CSS сложные конструкции, которые SassScript мог бы счесть недопустимыми.

```scss
.example {
  content: #{"string"}; // В CSS превратится в content: string;
}
```

> **Совет:** Если ваша цель — просто избавиться от кавычек, лучше использовать функцию string.unquote($string). Это сделает ваш код более понятным для других разработчиков.

### Резюме

Интерполяция — это «клей», который связывает динамику Sass с жесткой структурой CSS. Используйте её для создания имен классов, свойств и путей, но старайтесь избегать её в математических вычислениях, чтобы не потерять преимущества строгой типизации Sass.
