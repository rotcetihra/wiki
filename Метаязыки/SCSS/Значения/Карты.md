# Карты

Карты (**Maps**) в Sass — это наборы пар «ключ: значение», которые позволяют организовывать данные в структурированном виде. Это один из самых мощных инструментов для создания масштабируемых дизайн-систем, тем оформления и конфигураций.

---

## 1. Синтаксис и структура

Карты всегда заключаются в **круглые скобки** `()`. Ключ отделяется от значения **двоеточием**, а пары разделяются **запятыми**.

- **Ключи:** Могут быть любым типом данных Sass (строки, числа, даже другие карты), но чаще всего используются строки без кавычек.
    
- **Значения:** Также могут быть любыми типами данных.
    
- **Пустая карта:** Обозначается как `()`. Технически Sass считает пустую карту и пустой список одним и тем же значением.

```SCSS
$theme-colors: (
  "primary": #007bff,
  "success": #28a745,
  "danger": #dc3545,
  "dark": #343a40
);
```

---

## 2. Работа с модулем `sass:map`

В современном Sass для манипуляций с картами используется встроенный модуль `sass:map`. Все функции этого модуля возвращают **новую карту**, так как исходные данные в Sass неизменяемы.

|**Функция**|**Описание**|**Пример**|
|---|---|---|
|**`map.get($map, $key)`**|Возвращает значение по ключу.|`map.get($theme, "primary")`|
|**`map.has-key($map, $key)`**|Проверяет наличие ключа (возвращает `true/false`).|`map.has-key($theme, "secondary")`|
|**`map.merge($map1, $map2)`**|Объединяет две карты в одну.|`map.merge($base, $new-values)`|
|**`map.keys($map)`**|Возвращает список всех ключей.|`map.keys($theme)` → `"primary", "success"...`|
|**`map.values($map)`**|Возвращает список всех значений.|`map.values($theme)` → `#007bff, #28a745...`|
|**`map.remove($map, $keys...)`**|Удаляет указанные ключи из карты.|`map.remove($theme, "dark")`|

---

## 3. Глубокое вложение (Deep Maps)

Sass позволяет создавать многоуровневые карты. Для работы с ними существуют специальные «глубокие» версии функций (доступны в последних версиях Dart Sass), которые принимают цепочку ключей.

```SCSS
$config: (
  "header": (
    "height": 60px,
    "bg": #fff
  ),
  "footer": (
    "height": 40px,
    "bg": #000
  )
);

// Получение вложенного значения
$header-bg: map.get($config, "header", "bg"); 
```

---

## 4. Итерация через `@each`

Карты идеально подходят для циклов. При обходе карты через `@each` Sass автоматически «распаковывает» каждую пару в две переменные.

```SCSS
@each $name, $color in $theme-colors {
  .btn-#{$name} {
    background-color: $color;
    &:hover {
      background-color: darken($color, 10%);
    }
  }
}
```

---

## 5. Особенности использования

1. **Уникальность ключей:** В карте не может быть двух одинаковых ключей. Если вы попытаетесь объединить две карты с одинаковыми ключами через `map.merge`, значение из второй карты перезапишет значение из первой.
    
2. **Запятые:** Последняя запятая в карте (trailing comma) разрешена и считается хорошим тоном, так как это упрощает добавление новых элементов и чтение диффов в системах контроля версий.
    
3. **Поиск по ключу:** Поиск в картах работает значительно быстрее, чем ручной перебор списка, поэтому для хранения конфигураций всегда стоит отдавать предпочтение картам.

---

## Сравнение: Карты vs Списки

|**Критерий**|**Список (List)**|**Карта (Map)**|
|---|---|---|
|**Доступ к данным**|По индексу (1, 2, 3...)|По семантическому ключу|
|**Читаемость**|Ниже (нужно помнить порядок)|Выше (ключ описывает данные)|
|**Объявление**|`(a, b, c)` или `a b c`|`(key: value)`|
|**Назначение**|Простые перечисления|Сложные структуры и настройки|
