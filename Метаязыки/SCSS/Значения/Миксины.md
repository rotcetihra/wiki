# Миксины

В современном Sass миксины, как и функции, являются **типами данных первого класса**. Это означает, что вы можете получить ссылку на миксин, сохранить её в переменной, передать в другой миксин и вызвать его динамически.

Эта возможность появилась в рамках новой модульной системы и значительно расширяет возможности абстракции в коде.

---

## 1. Получение ссылки на миксин: `get-mixin()`

Для того чтобы работать с миксином как со значением, необходимо получить на него ссылку с помощью функции `get-mixin()` из встроенного модуля `sass:meta`.

- **Синтаксис:** `meta.get-mixin($name)`
    
- **Тип данных:** Результат имеет тип `mixin`.

```SCSS
@use "sass:meta";

@mixin theme-dark {
  background-color: #000;
  color: #fff;
}

// Получаем ссылку на миксин
$my-mixin: meta.get-mixin("theme-dark");
```

---

## 2. Вызов динамического миксина

Вызов миксина, хранящегося в переменной, осуществляется через стандартную директиву `@include`, но вместо имени миксина указывается переменная.

**Пример:**

```SCSS
.header {
  @include $my-mixin;
}
```

---

## 3. Миксины высшего порядка (Higher-Order Mixins)

Основное преимущество миксинов как значений — возможность передавать их в другие миксины. Это позволяет создавать гибкие «обертки» или компоненты, поведение которых определяется переданным кодом.

**Пример (миксин для стилизации списка):**

```SCSS
@use "sass:meta";

@mixin apply-to-items($list, $item-mixin) {
  @each $item in $list {
    li.item-#{$item} {
      @include meta.apply($item-mixin, $item); 
    }
  }
}

@mixin highlight($value) {
  border: 1px solid red;
  content: "Value: #{$value}";
}

$colors: "red", "blue", "green";
.color-list {
  @include apply-to-items($colors, meta.get-mixin("highlight"));
}
```

> **Примечание:** Для вызова миксина-переменной с аргументами внутри другого миксина часто используется `meta.apply($mixin, $args...)`.

---

## 4. Тип данных и проверка

Вы можете проверить, является ли переменная миксином, используя функцию `meta.type-of()`. Это возвращает строку `"mixin"`.

|**Выражение**|**Результат**|
|---|---|
|`meta.type-of(meta.get-mixin("my-mixin"))`|`"mixin"`|
|`meta.type-of($some-string)`|`"string"`|

---

## 5. Область видимости и замыкания

Когда вы получаете ссылку на миксин через `get-mixin()`, эта ссылка «захватывает» область видимости, в которой миксин был определен. Это означает:

1. Миксин будет иметь доступ к тем же переменным, что и в месте своего объявления.
    
2. Даже если вы передадите эту ссылку в другой модуль, она все равно будет работать корректно, используя контекст своего «родного» модуля.

---

## 6. Особенности и ограничения

- **Аргументы:** При вызове `@include $variable` вы можете передавать аргументы точно так же, как при обычном вызове миксина: `@include $variable($arg1, $arg2)`.
    
- **Контентные блоки:** Динамические миксины поддерживают передачу `@content`.

```SCSS
@include $dynamic-mixin {
  .nested { color: red; }
}
```

- **Модули:** Если миксин определен в другом файле, его нужно получить из этого модуля: `meta.get-mixin("mixin-name", $module-name)`.
    

Использование миксинов как значений позволяет строить сложные архитектурные решения, такие как плагиновые системы для CSS-фреймворков или динамические генераторы тем, где конкретные стили передаются как параметры.
