# null

В Sass значение **`null`** — это своего рода «призрак» среди типов данных. Оно представляет собой намеренное отсутствие значения. Несмотря на свою незаметность, это один из самых полезных инструментов для создания гибких и чистых таблиц стилей.

---

## 1. Главная суперсила: Удаление свойств

Самая важная особенность `null` заключается в том, как он ведет себя при компиляции в CSS. Если значение какого-либо CSS-свойства вычисляется как `null`, Sass **полностью удаляет это свойство** из итогового файла.

Это позволяет создавать универсальные миксины, которые не «мусорят» в CSS лишними строками, если какие-то параметры не были переданы.

**Пример:**

```SCSS
@mixin position($top: null, $left: null) {
  position: absolute;
  top: $top;
  left: $left;
}

.icon {
  @include position($top: 10px); 
}
```

**Результат в CSS:**

```CSS
.icon {
  position: absolute;
  top: 10px;
  /* Свойство 'left' не было выведено, так как оно равно null */
}
```

---

## 2. Логика и «Ложность»

В логических выражениях (`@if`, `@while`) значение `null` считается **ложным** (`falsey`). Это делает его идеальным кандидатом для проверки того, передал ли пользователь аргумент в миксин или функцию.

> **Важно помнить:** В Sass только `false` и `null` являются ложными значениями. Все остальные (даже `0` и пустые строки) — истинны.

```SCSS
@mixin text-style($color: null) {
  font-family: sans-serif;
  
  @if $color {
    color: $color;
    border-bottom: 1px solid $color;
  }
}
```

---

## 3. Сравнение: `null` против `false`

Хотя оба значения ведут себя одинаково в условиях `@if`, их результат в CSS кардинально различается:

|**Значение**|**Поведение в CSS**|**Результат для свойства**|
|---|---|---|
|**`null`**|Свойство полностью игнорируется.|(ничего не выводится)|
|**`false`**|Компилируется в строку `"false"`.|`color: false;` (невалидный CSS)|

---

## 4. Работа с данными

`null` часто используется в списках и картах как маркер отсутствия данных.

- В списках: `10px null 5px`.
    
- В функциях: `map.get($map, "non-existent-key")` всегда возвращает `null`. Это позволяет безопасно проверять наличие ключей в конфигурациях.

---

## 5. Итог

Используйте `null`, когда вам нужно:

1. Сделать аргумент миксина **необязательным**, не устанавливая для него «заглушку» (вроде `0` или `none`).
    
2. **Скрыть свойство** в зависимости от логики или текущей темы оформления.
    
3. Проверить, существует ли значение в карте настроек.
    

Это «невидимое» значение — лучший способ держать ваш итоговый CSS-бандл легким и свободным от неиспользуемых правил.
