# true и false

Логические значения (**Booleans**) в Sass — это простейший тип данных, состоящий всего из двух констант: `true` (истина) и `false` (ложь). Они являются фундаментом для всей управляющей логики в ваших таблицах стилей.

---

## 1. Использование в коде

Логические значения почти никогда не выводятся напрямую в CSS. Их основная роль — служить переключателями в директивах `@if` и `@while`, а также выступать в качестве аргументов в миксинах и функциях.

**Пример в миксине:**

```SCSS
@mixin rounded-button($is-rounded: true) {
  padding: 10px 20px;
  
  @if $is-rounded {
    border-radius: 50px;
  } @else {
    border-radius: 4px;
  }
}

.login-btn { @include rounded-button($is-rounded: false); }
```

---

## 2. Логические операторы

Sass поддерживает три основных логических оператора для работы с булевыми значениями:

- **`and`**: Возвращает `true`, если **оба** выражения истинны.
    
- **`or`**: Возвращает `true`, если **хотя бы одно** из выражений истинно.
    
- **`not`**: Инвертирует значение (превращает `true` в `false` и наоборот).

---

## 3. Понятие «Истинности» (Truthiness)

Это самый важный нюанс при работе с логикой в Sass. В отличие от JavaScript или Python, где `0`, пустые строки или пустые списки могут считаться «ложными», в Sass правила строже.

**Ложными (falsy) считаются ТОЛЬКО:**

1. `false`
    
2. `null`
    

**Все остальные значения считаются истинными (truthy):**

- Числа (включая `0` и отрицательные).
    
- Строки (включая пустую строку `""`).
    
- Списки (включая пустой список `()`).
    
- Карты.

|**Значение**|**Результат в @if**|
|---|---|
|`true`|✅ True|
|`false`|❌ False|
|`null`|❌ False|
|`0`|✅ True|
|`""` (пустая строка)|✅ True|
|`( )` (пустой список)|✅ True|

---

## 4. Операторы сравнения

Результатом работы операторов сравнения всегда является логическое значение `true` или `false`.

- **Равенство:** `==` и `!=` (работают для всех типов данных).
    
- **Сравнение чисел:** `<`, `>`, `<=`, `>=`.

```SCSS
$padding: 20px;

.container {
  @if $padding > 15px {
    margin: 10px;
  }
}
```

---

## 5. Практический совет

Поскольку `null` является «ложным», его часто используют как значение по умолчанию для необязательных аргументов. Это позволяет легко проверять, было ли передано значение в миксин:

```SCSS
@mixin shadow($color: null) {
  @if $color {
    box-shadow: 0 2px 5px $color;
  }
  // Если $color равен null, блок @if проигнорируется и тень не создастся
}
```
