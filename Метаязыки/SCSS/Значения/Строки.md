# Строки

Строки в Sass — это один из фундаментальных типов данных, который используется для названий шрифтов, селекторов, путей к файлам и значений свойств. Sass поддерживает два вида строк и предоставляет мощные инструменты для работы с ними через интерполяцию и встроенные модули.

---

## 1. Типы строк

Sass различает два основных вида строк:

### А. Строки в кавычках (Quoted Strings)

Пишутся с использованием двойных (`"`) или одинарных (`'`) кавычек. Они могут содержать пробелы, специальные символы и даже селекторы.

- **Примеры:** `"Lucida Grande"`, `'/images/logo.png'`, `"1.5em"`.
    
- **Особенность:** Если вы используете одинарные кавычки внутри строки, саму строку лучше обернуть в двойные, и наоборот.
    

### Б. Строки без кавычек (Unquoted Strings / Identifiers)

Это стандартные значения CSS, такие как `bold`, `sans-serif` или `auto`.

- **Примеры:** `none`, `underline`, `center`.
    
- **Особенность:** При компиляции они преобразуются в такие же строки без кавычек в CSS.

---

## 2. Интерполяция в строках

Интерполяция (`#{}`) позволяет вставлять значения переменных или результаты функций прямо внутрь строки. Это особенно полезно для динамического формирования путей к изображениям или имен классов.

**Пример:**

```SCSS
$name: "primary";
$path: "/assets/images";

.button-#{$name} {
  background-image: url("#{$path}/icon-#{$name}.svg");
}
```

> **Важно:** При использовании интерполяции внутри кавычек, результат всегда становится строкой в кавычках. Если интерполяция используется без кавычек, результат будет строкой без кавычек.

---

## 3. Экранирование символов

Sass позволяет использовать обратную косую черту (`\`) для экранирования символов, которые иначе имели бы специальное значение (например, кавычки или спецсимволы Юникода).

- `\"` — выведет двойную кавычку внутри строки.
    
- `\2713` — выведет символ галочки (Unicode).

---

## 4. Индексация строк

В отличие от многих языков программирования (таких как JavaScript), где индексация начинается с 0, в Sass **индексация строк начинается с 1**.

- В строке `"Sass"`, символ с индексом `1` — это `"S"`.
    
- Отрицательные индексы позволяют считать с конца строки: `-1` — это последний символ.

---

## 5. Модуль `sass:string`

Для сложной обработки строк в Sass 1.23.0+ используется встроенный модуль `sass:string`. Вот основные функции:

|**Функция**|**Описание**|**Пример**|
|---|---|---|
|`string.length($str)`|Возвращает количество символов.|`string.length("Sass")` → `4`|
|`string.index($str, $sub)`|Находит позицию подстроки.|`string.index("Helvetica", "v")` → `4`|
|`string.slice($str, $start, $end)`|Вырезает часть строки.|`string.slice("Roboto", 1, 3)` → `"Rob"`|
|`string.to-upper-case($str)`|Переводит в верхний регистр.|`"text"` → `"TEXT"`|
|`string.unique-id()`|Генерирует уникальное имя.|Используется для создания уникальных классов.|

---

## 6. Слияние строк (Concatenation)

Вы можете объединять строки с помощью оператора `+`.

- Если к строке в кавычках прибавить другую строку, результат будет **в кавычках**.
    
- Если к строке без кавычек прибавить другую, результат будет **без кавычек**.

```SCSS
$family: "Open" + " " + "Sans"; // "Open Sans"
$status: bold + "-text";       // bold-text
```

## Нюансы преобразования

Если вы передаете в функцию или миксин строку без кавычек, но CSS требует кавычки (например, для `content`), вам придется либо добавить их вручную, либо использовать функцию `string.quote()`. И наоборот, `string.unquote()` удаляет кавычки, что полезно для подстановки сложных селекторов.
