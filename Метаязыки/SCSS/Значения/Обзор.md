# Обзор

В Sass каждое выражение возвращает определенное **значение**. Sass поддерживает как стандартные типы данных CSS, так и свои собственные, расширяющие возможности языка.

Все значения можно разделить на основные категории:

## 1. Числа (Numbers)

Числа в Sass могут быть как целыми, так и дробными. Главная особенность — они могут иметь **единицы измерения** (например, `px`, `em`, `%`, `s`). Sass умеет выполнять математические операции с числами, если их единицы измерения совместимы.

- Примеры: `12`, `100px`, `1.5em`, `20%`.
    

## 2. Строки (Strings)

Sass поддерживает два типа строк:

- **Строки в кавычках** (например, `"Lucida Grande"`, `'http://sass-lang.com'`).
    
- **Строки без кавычек** (например, `bold`, `sans-serif`).
    

    Оба типа обрабатываются как строки, и вы можете использовать интерполяцию `#{}` для вставки значений внутрь строк.

    

## 3. Цвета (Colors)

Sass обладает мощными инструментами для работы с цветами. Вы можете использовать:

- Именованные цвета CSS: `blue`, `transparent`.
    
- Шестнадцатеричные коды: `#ffffff`, `#c6538c`.
    
- Функции цветовых моделей: `rgb(255, 0, 0)`, `hsl(210, 100%, 20%)`.
    

## 4. Списки (Lists)

Список — это набор значений, разделенных пробелами или запятыми. Списки могут быть заключены в квадратные скобки или быть без них.

- Примеры: `10px 20px 10px`, `Helvetica, Arial, sans-serif`, `[line1 line2]`.
    

    Sass предоставляет встроенные функции для работы со списками: добавление элементов, получение индекса или конкретного значения.

    

## 5. Карты (Maps)

Карты представляют собой пары **ключ: значение**. Они всегда заключаются в круглые скобки и позволяют удобно хранить конфигурации или темы.

- Пример: `("background": red, "foreground": pink)`.
    

    Ключи в картах могут быть любыми типами данных Sass, но чаще всего используются строки.

    

## 6. Логические значения (Booleans)

Существует всего два логических значения: `true` (истина) и `false` (ложь). Они используются в условных конструкциях `@if` и циклах.

## 7. Null

Значение `null` представляет собой отсутствие данных. Если свойство CSS принимает значение `null`, Sass полностью удаляет это свойство из итогового CSS-файла. Это полезно для создания необязательных параметров в миксинах.

## 8. Ссылки на функции (Function References)

С помощью функции `get-function($name)` можно получить ссылку на функцию. Это позволяет передавать функции как значения в другие функции или миксины через `call()`.

## Сводная таблица типов данных

|**Тип данных**|**Пример**|**Применение**|
|---|---|---|
|**Number**|`16px`|Размеры, расчеты, интервалы|
|**String**|`"Open Sans"`|Шрифты, контент, пути к файлам|
|**Color**|`#ff0000`|Оформление элементов|
|**List**|`0 10px 5px`|Составные свойства (margin, padding)|
|**Map**|`(key: val)`|Конфигурации, дизайн-системы|
|**Boolean**|`true`|Логика в `@if`, флаги настроек|
|**Null**|`null`|Отмена вывода свойств в CSS|
