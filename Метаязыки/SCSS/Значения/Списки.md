# Списки

Списки в Sass — это аналог массивов в языках программирования. Они представляют собой последовательность значений, разделенных пробелами или запятыми. Списки лежат в основе работы циклов `@each` и многих встроенных функций для манипуляции CSS-свойствами.

---

## 1. Структура и синтаксис

Sass-списки могут быть организованы несколькими способами:

- **Разделители:** Значения могут разделяться **пробелами** (например, `10px 12px 0 0`) или **запятыми** (например, `Helvetica, Arial, sans-serif`).
    
- **Скобки:** Списки могут быть **без скобок** (самый частый вариант) или **в квадратных скобках** (`[top bottom]`). Квадратные скобки часто используются для обозначения именованных линий в CSS Grid.
    
- **Вложенность:** Списки могут содержать другие списки. Чтобы избежать путаницы, вложенные списки обычно разделяются иными знаками (например, список с пробелами внутри списка с запятыми).

---

## 2. Индексация: Начинаем с единицы

Это важнейшая особенность Sass: в отличие от большинства языков программирования, **индексация в списках начинается с 1**, а не с 0.

- Первый элемент имеет индекс `1`.
    
- Последний элемент можно получить, используя отрицательный индекс `-1`.
    
- Предпоследний — `-2` и так далее.

---

## 3. Модуль `sass:list`

Для профессиональной работы со списками используется встроенный модуль `sass:list`. Он предоставляет функции для анализа и изменения данных.

|**Функция**|**Описание**|**Пример**|
|---|---|---|
|**`list.nth($list, $n)`**|Возвращает элемент по индексу `$n`.|`list.nth(10px 20px, 2)` → `20px`|
|**`list.index($list, $val)`**|Возвращает индекс первого вхождения значения.|`list.index(1px 2px, 2px)` → `2`|
|**`list.append($list, $val)`**|Добавляет значение в конец списка.|`list.append(a b, c)` → `a b c`|
|**`list.join($list1, $list2)`**|Объединяет два списка в один.|`list.join(1 2, 3 4)` → `1 2 3 4`|
|**`list.length($list)`**|Возвращает общее количество элементов.|`list.length(a b c)` → `3`|

---

## 4. Специальные типы списков

### Списки с разделителем «слэш» (`/`)

Sass поддерживает списки, где значения разделены косой чертой (например, для сокращенной записи `font: 12px/1.5`).

- Такие списки нельзя создать вручную простым написанием (Sass воспримет `/` как деление или разделитель).
    
- Для их создания используется функция `list.slash($list...)`.
    

### Пустые списки и единичные элементы

- **Пустой список:** Обозначается как `()`. Он не отображается в итоговом CSS, но полезен как начальное значение в циклах.
    
- **Список из одного элемента:** Sass обычно трактует одиночное значение как список из одного элемента. Если нужно явно указать, что это список (например, для передачи в функцию), можно использовать функцию `list.append((), $value)`.

---

## 5. Неизменяемость (Immutability)

Важно помнить, что списки в Sass **неизменяемы**. Это значит, что функции вроде `list.append()` не меняют исходный список, а возвращают **новую копию** списка с изменениями.

```SCSS
$padding: 10px 20px;
$new-padding: list.append($padding, 30px); 

// $padding всё еще равен 10px 20px
// $new-padding равен 10px 20px 30px
```

---

## Практическое применение

Списки идеально подходят для:

1. **Массовой генерации классов:** например, перебор списка названий иконок для создания фоновых изображений.
    
2. **Конфигурации многослойных теней:** хранение нескольких значений `box-shadow` в одной переменной.
    
3. **Передачи аргументов:** использование `...` (rest arguments) в миксинах фактически превращает переданные аргументы в список.
