# Функции

В Sass функции — это не только инструмент для выполнения расчетов, но и полноценный **тип данных**. Это означает, что вы можете сохранять ссылки на функции в переменных, передавать их в другие функции или миксины и вызывать их динамически. Такие функции часто называют «функциями первого класса».

---

## 1. Получение ссылки на функцию: `get-function()`

Чтобы превратить функцию в значение, которое можно передать, используется встроенная функция `get-function($name)`. Она возвращает ссылку на функцию, а не результат её выполнения.

- **Аргумент:** Строка с именем функции.
    
- **Результат:** Объект типа `function`.

```SCSS
@use "sass:meta";

@function double($n) {
  @return $n * 2;
}

// Сохраняем ссылку на функцию в переменную
$my-func: meta.get-function("double");
```

---

## 2. Вызов функции-переменной: `call()`

Поскольку переменная содержит лишь ссылку, вы не можете вызвать её обычным способом (`$my-func(5)` не сработает). Для этого используется функция `call()`.

**Синтаксис:** `meta.call($function, $args...)`

```SCSS
$result: meta.call($my-func, 10px); // Вернет 20px
```

---

## 3. Зачем это нужно? (Callback-функции)

Основная польза функций как значений проявляется при создании универсальных инструментов. Вы можете написать миксин или функцию, которая принимает «логику» извне.

**Пример (математическая трансформация списка):**

```SCSS
@use "sass:list";
@use "sass:meta";

@function transform-list($list, $func) {
  $new-list: ();
  @each $item in $list {
    $new-list: list.append($new-list, meta.call($func, $item));
  }
  @return $new-list;
}

@function square($n) { @return $n * $n; }

$data: 1, 2, 3, 4;
$squared-data: transform-list($data, meta.get-function("square")); 
// Результат: 1, 4, 9, 16
```

---

## 4. Тип данных и проверка

Вы можете проверить, является ли значение функцией, используя `meta.type-of()`. Это полезно для защиты кода от ошибок при передаче неверных аргументов.

|**Выражение**|**Результат**|
|---|---|
|`meta.type-of(meta.get-function("rgb"))`|`"function"`|
|`meta.type-of("rgb")`|`"string"`|

---

## 5. Область видимости и модули

При работе с модулями (`@use`) есть важный нюанс: `get-function()` ищет функцию в той области видимости, где она была вызвана. Если функция находится в другом модуле, её нужно получить из этого модуля.

- **Локальные функции:** Ищутся без проблем.
    
- **Встроенные функции:** Всегда доступны.
    
- **Функции из модулей:** Если вы получили ссылку на функцию через `get-function`, она «запоминает» свой контекст и будет работать корректно при вызове через `call()` в любом месте проекта.

---

## Итог

Функции как значения превращают Sass из простого конфигуратора стилей в гибкий функциональный язык. Это позволяет:

1. Писать высокоуровневые абстракции (например, обработчики данных).
    
2. Передавать кастомную логику внутрь сторонних библиотек.
    
3. Динамически выбирать алгоритм расчета (например, разные формулы для разных тем оформления).
