# sass:color — Профессиональная работа с цветом в Sass

Модуль `sass:color` предоставляет мощный инструментарий для создания, преобразования и анализа цветов. В современном Sass этот модуль полностью заменяет устаревшие глобальные функции (такие как `lighten()` или `darken()`), предлагая более предсказуемый и гибкий подход.

Чтобы начать работу, необходимо подключить модуль:

```SCSS
@use "sass:color";
```

---

## 1. Чтение свойств цвета (Accessors)

Функции-аксессоры позволяют извлечь конкретные параметры цвета (каналы) в различных цветовых пространствах (RGB, HSL, HWB).

|**Функция**|**Описание**|**Возвращаемое значение**|
|---|---|---|
|`color.red($color)`|Извлекает красный канал|0–255|
|`color.hue($color)`|Извлекает оттенок|0deg–360deg|
|`color.lightness($color)`|Извлекает светлоту|0%–100%|
|`color.alpha($color)`|Извлекает прозрачность|0–1|
|`color.whiteness($color)`|Извлекает степень белого (HWB)|0%–100%|

---

## 2. Модификация цвета: Adjust vs Scale

Это самая важная часть модуля. Sass предлагает два принципиально разных способа изменения цвета.

### color.adjust() — Аддитивное изменение

Эта функция прибавляет или вычитает фиксированное значение из указанного канала.

- **Пример:** Если у цвета светлота 40%, и вы делаете `adjust($c, $lightness: 20%)`, результат всегда будет 60%.

```SCSS
$base: #6b717f; // lightness: 46%
$new: color.adjust($base, $lightness: 20%, $red: 10);
```

### color.scale() — Пропорциональное изменение

Эта функция работает более плавно. Она изменяет цвет на процент от _оставшегося_ пути до края диапазона (0 или 100%).

- **Пример:** Если светлота 40%, `scale($c, $lightness: 50%)` не сделает её 90%. Она возьмет 50% от оставшегося пути к белому (от 40 до 100), что даст 70%.

> **Почему это важно?** `color.scale()` защищает от «выбитых» цветов. С его помощью черный или белый цвета не будут мгновенно превращаться в серые при минимальных корректировках, а темные цвета будут осветляться мягче.

---

## 3. Смешивание цветов (Mixing)

Функция `color.mix()` позволяет смешать два цвета в определенной пропорции.

- `color.mix($color1, $color2, $weight)`
    
- `$weight` — это количество первого цвета (по умолчанию 50%).

```SCSS
$primary: #3498db;
$accent: #e74c3c;

// Смесь: 30% синего, 70% красного
$mixed: color.mix($primary, $accent, 30%);
```

---

## 4. Специфические трансформации

В модуле есть быстрые функции для распространенных задач:

1. **`color.complement($color)`** — возвращает комплементарный цвет (поворот Hue на 180°). Идеально для подбора контрастных акцентов.
    
2. **`color.grayscale($color)`** — полностью убирает насыщенность, превращая цвет в серый той же светлоты.
    
3. **`color.invert($color)`** — инвертирует все каналы (создает «негатив»).
    
4. **`color.ie-hex-str($color)`** — специфическая функция, возвращающая цвет в формате `#AARRGGBB` для старых фильтров Internet Explorer.

---

## 5. Работа с прозрачностью

Вместо устаревших `opacify()` и `transparentize()` теперь используются `adjust` и `scale` для канала `$alpha`.

```SCSS
$c: rgba(255, 0, 0, 0.5);

// Сделать на 0.2 более непрозрачным (станет 0.7)
$more: color.adjust($c, $alpha: 0.2);

// Уменьшить прозрачность вполовину от текущей (станет 0.25)
$less: color.scale($c, $alpha: -50%);
```

---

## Практические советы

- **Использование переменных:** Всегда используйте `color.scale()` при создании состояний кнопок (`:hover`, `:active`). Это гарантирует, что эффект будет заметен как на очень светлых, так и на очень темных темах.
    
- **Проверка контраста:** Сочетая аксессоры, можно создавать логику, которая меняет цвет текста в зависимости от фона:

```SCSS
@use "sass:color";

@mixin smart-text($bg) {
  background-color: $bg;
  @if color.lightness($bg) > 50% {
    color: #000;
  } @else {
    color: #fff;
  }
}
```

Модуль `sass:color` — это инструмент математической точности. Он позволяет дизайнерам и разработчикам создавать целые палитры из одного базового цвета, гарантируя их гармоничность и техническую корректность.
