# sass:map — Управление ассоциативными массивами в Sass

Карты (Maps) в Sass — это коллекции пар «ключ-значение», которые позволяют организовывать данные в структурированном виде. Модуль `sass:map` предоставляет набор инструментов для эффективной работы с такими структурами, включая поддержку глубокой вложенности.

Для использования функций модуля подключите его в начале файла:

```SCSS
@use "sass:map";
```

---

## 1. Извлечение данных

В современных версиях Sass функции извлечения поддерживают **вариативные аргументы**, что позволяет работать с вложенными картами без использования дополнительных циклов.

### map.get($map, $key, $keys...)

Возвращает значение, связанное с ключом. Если передано несколько ключей, Sass будет искать значение вглубь вложенных карт.

```SCSS
$config: (
  "colors": (
    "primary": #3498db,
    "secondary": #2ecc71
  )
);

@debug map.get($config, "colors", "primary"); // #3498db
@debug map.get($config, "fonts");             // null (ключа не существует)
```

### map.deep-get($map, $key, $keys...)

Аналог `map.get`, специально предназначенный для глубокого поиска. Хотя в новых версиях `map.get` делает то же самое, `deep-get` явно указывает на работу с вложенной структурой.

---

## 2. Модификация и объединение

### map.set($map, $key, $value) или map.set($map, $key, $keys..., $value)

Устанавливает значение для указанного ключа. Если ключа не существует, он будет создан. Также поддерживает вложенность.

```SCSS
$theme: ("font-size": 16px);
$theme: map.set($theme, "font-size", 18px);      // Изменение
$theme: map.set($theme, "colors", "bg", #fff);   // Создание вложенности
```

### map.merge($map1, $map2)

Объединяет две карты. Если ключи совпадают, значения из второй карты перезаписывают значения из первой.

### map.deep-merge($map1, $map2)

В отличие от обычного `merge`, эта функция рекурсивно объединяет вложенные карты, сохраняя уникальные ключи на всех уровнях вложенности.

---

## 3. Проверка и анализ метаданных

|**Функция**|**Описание**|**Результат**|
|---|---|---|
|`map.has-key($map, $key, $keys...)`|Проверяет наличие ключа (в т.ч. во вложенных картах)|`true` / `false`|
|`map.keys($map)`|Возвращает список всех ключей первого уровня|Список|
|`map.values($map)`|Возвращает список всех значений первого уровня|Список|
|`map.remove($map, $keys...)`|Возвращает копию карты без указанных ключей|Новая карта|

---

## 4. Совместимость со списками

Поскольку карты технически являются набором двухэлементных списков (пара `(ключ значение)`), к ним можно применять функции модуля `sass:list`.

```SCSS
$colors: ("red": #f00, "blue": #00f);

@debug list.length($colors); // 2
@debug list.nth($colors, 1); // "red" #f00
```

## 5. Практический пример: Система Breakpoints

Использование карт — лучший способ управления адаптивностью в проекте.

```SCSS
@use "sass:map";

$breakpoints: (
  "small": 576px,
  "medium": 768px,
  "large": 992px
);

@mixin respond-to($breakpoint) {
  @if map.has-key($breakpoints, $breakpoint) {
    @media (min-width: map.get($breakpoints, $breakpoint)) {
      @content;
    }
  } @else {
    @error "Брейкпоинт '#{$breakpoint}' не найден!";
  }
}

.container {
  width: 100%;
  @include respond-to("medium") {
    width: 750px;
  }
}
```

## 6. Рекомендации по использованию

- **Именуйте ключи осознанно:** Используйте строки в кавычках (например, `"primary"`) для ключей, чтобы избежать конфликтов с зарезервированными словами CSS.
    
- **Используйте deep-merge для конфигураций:** Если вы создаете UI-кит, позволяйте пользователям переопределять только часть настроек через `deep-merge`, сохраняя значения по умолчанию для остальных вложенных параметров.
    
- **Избегайте избыточной вложенности:** Карты глубже 3 уровней становятся трудными для чтения и поддержки.
    

### Итог

Модуль `sass:map` превращает Sass из языка стилей в полноценный инструмент управления данными. Это позволяет создавать темы, дизайн-токены и сложные системы отступов, которые легко изменять в одном месте.
