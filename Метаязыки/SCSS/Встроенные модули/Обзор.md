# Обзор

В Sass встроенные модули (Built-in Modules) предоставляют мощный инструментарий для манипуляции цветами, числами, строками и коллекциями. Вместо того чтобы писать сложные функции с нуля, вы используете готовые методы, которые оптимизированы и встроены в ядро языка.

С момента появления **Dart Sass**, использование встроенных функций через глобальную область видимости (например, `lighten()`) считается устаревшим. Теперь все функции сгруппированы в модули, которые нужно подключать через директиву `@use`.

---

## 1. Основные встроенные модули

Sass предоставляет 7 основных модулей для решения различных задач:

|**Модуль**|**Назначение**|**Популярные функции**|
|---|---|---|
|`sass:color`|Создание, изменение и анализ цветов.|`adjust()`, `mix()`, `scale()`|
|`sass:list`|Работа со списками (массивами).|`nth()`, `join()`, `append()`|
|`sass:map`|Работа с картами (объектами key-value).|`get()`, `merge()`, `keys()`|
|`sass:math`|Продвинутые математические операции.|`div()`, `pow()`, `round()`|
|`sass:meta`|Информация о типах данных и среде Sass.|`type-of()`, `function-exists()`|
|`sass:selector`|Манипуляция CSS-селекторами.|`unify()`, `extend()`|
|`sass:string`|Работа с текстовыми строками.|`unique-id()`, `quote()`, `slice()`|

---

## 2. Как использовать модули

Чтобы получить доступ к функциям модуля, необходимо добавить `@use "sass:<имя_модуля>"` в самом начале вашего файла.

### Пример использования `sass:math` и `sass:color`:

```SCSS
@use "sass:math";
@use "sass:color";

$base-color: #3b5998;

.card {
  // Использование математики для расчета ширины
  width: math.div(100%, 3);
  
  // Создание вариации цвета (осветление на 20%)
  background-color: color.adjust($base-color, $lightness: 20%);
}
```

---

## 3. Обзор ключевых возможностей

### `sass:math`

Этот модуль заменил многие старые арифметические подходы. Самая важная функция здесь — `math.div()`, которая теперь является единственным официальным способом деления в Sass.

- `math.clamp($min, $val, $max)` — ограничивает число заданным диапазоном.
    
- `math.hypot($sizes...)` — вычисляет гипотенузу (длину вектора).
    

### `sass:color`

В отличие от старых функций вроде `lighten()` или `darken()`, современные функции модуля `color` (такие как `color.scale()`) работают более предсказуемо и плавно, учитывая текущую яркость цвета.

- `color.grayscale($color)` — преобразует цвет в серый.
    
- `color.complement($color)` — возвращает комплементарный (противоположный) цвет.
    

### `sass:meta`

Этот модуль незаменим при написании сложных библиотек или миксинов, которые должны проверять входные данные.

- `meta.type-of($value)` — возвращает тип данных (number, string, color и т.д.).
    
- `meta.load-css($url)` — динамически загружает CSS из файла (аналог `@import`, но более гибкий).

## 4. Почему важно использовать модули?

1. **Пространство имен (Namespacing):** Функции больше не конфликтуют друг с другом. Вы всегда знаете, что `list.nth` относится к спискам, а `map.get` к картам.
    
2. **Производительность:** Sass загружает только те модули, которые вы явно указали.
    
3. **Долговечность кода:** Глобальные функции (например, `unitless()`) будут удалены в будущих версиях Sass. Переход на модули гарантирует, что ваш код не сломается при обновлении компилятора.

---

## Практический совет: Псевдонимы (Aliases)

Если имена модулей кажутся вам слишком длинными, вы можете сократить их при подключении:

```SCSS
@use "sass:math" as m;
@use "sass:color" as c;

.element {
  width: m.div(100px, 2);
  color: c.adjust(#000, $lightness: 10%);
}
```

Все встроенные модули подробно задокументированы и стабильны. Они являются частью стандарта **Sass Module System**, принятого в 2019 году для замены устаревшей модели `@import`.
