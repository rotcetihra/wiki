# sass:math — Математические вычисления и константы

Модуль `sass:math` предоставляет полный набор функций для работы с числами: от базового деления до сложных тригонометрических вычислений. Это ядро математической логики в современном Sass, заменяющее устаревшие глобальные функции.

Для использования модуля добавьте в начало файла:

```SCSS
@use "sass:math";
```

---

## 1. Константы

Sass предоставляет две важнейшие математические константы, которые можно использовать в формулах:

- **`math.$e`**: Число Эйлера ($e \approx 2.7182818285$).
    
- **`math.$pi`**: Число Пи ($\pi \approx 3.1415926536$).

---

## 2. Деление: `math.div()`

Это самая важная функция модуля. В современном Sass оператор `/` зарезервирован для использования в качестве разделителя в CSS (например, `font: 12px/1.5`). Для выполнения арифметического деления **необходимо** использовать `math.div()`.

```SCSS
.container {
  // Старый способ (устарел): width: 100% / 3;
  width: math.div(100%, 3); // 33.3333333333%
}
```

---

## 3. Округление (Rounding)

Sass предлагает три способа приведения дробных чисел к целым:

|**Функция**|**Описание**|**Пример**|**Результат**|
|---|---|---|---|
|`math.ceil($n)`|Округляет до ближайшего **большего** целого|`math.ceil(4.1)`|`5`|
|`math.floor($n)`|Округляет до ближайшего **меньшего** целого|`math.floor(4.9)`|`4`|
|`math.round($n)`|Округляет до **ближайшего** целого|`math.round(4.5)`|`5`|

---

## 4. Ограничение и выбор (Clamp, Min, Max)

### `math.clamp($min, $value, $max)`

Функция возвращает `$value`, если оно находится в диапазоне между `$min` и `$max`. Если оно меньше минимума — возвращается `$min`, если больше максимума — `$max`. Это крайне полезно для адаптивной верстки.

```SCSS
.sidebar {
  // Ширина будет 25%, но не меньше 200px и не больше 500px
  width: math.clamp(200px, 25%, 500px);
}
```

### `math.min($numbers...)` и `math.max($numbers...)`

Принимают список чисел и возвращают наименьшее или наибольшее из них соответственно. Все числа должны иметь совместимые единицы измерения.

---

## 5. Степени, корни и логарифмы

Эти функции позволяют вычислять сложные геометрические параметры прямо в коде.

- **`math.pow($base, $exponent)`**: Возводит основание в степень.
    
- **`math.sqrt($number)`**: Вычисляет квадратный корень ($\sqrt{n}$).
    
- **`math.hypot($numbers...)`**: Возвращает длину вектора (квадратный корень из суммы квадратов аргументов). Идеально для вычисления диагоналей.
    
- **`math.log($number, $base: math.$e)`**: Вычисляет логарифм.

---

## 6. Тригонометрия

Все тригонометрические функции в Sass принимают углы в любых единицах (`deg`, `grad`, `rad`, `turn`). Если число передается без единиц измерения, оно трактуется как **радианы**.

- **Основные:** `math.sin()`, `math.cos()`, `math.tan()`.
    
- **Обратные:** `math.asin()`, `math.acos()`, `math.atan()`, `math.atan2()`.

```SCSS
.penta-node {
  // Вычисление координат точки на окружности
  left: math.cos(72deg) * 50px;
  top: math.sin(72deg) * 50px;
}
```

---

## 7. Функции единиц измерения (Units)

Эти функции помогают проверять и очищать входные данные в миксинах.

|**Функция**|**Описание**|
|---|---|
|`math.unit($number)`|Возвращает строку с единицей измерения (например, `"px"`)|
|`math.is-unitless($n)`|Возвращает `true`, если число не имеет единиц|
|`math.compatible($n1, $n2)`|Проверяет, можно ли сложить или сравнить эти числа|

### Удаление единиц измерения

Чтобы получить "чистое" число из значения с единицами, нужно разделить его на 1 единицу того же типа:

```SCSS
$value: 15px;
$pure-number: math.div($value, 1px); // 15
```

---

## Практический пример: Золотое сечение

Используя константы и функции степеней, можно создать сетку на основе золотого сечения $\phi \approx 1.618$:

```SCSS
@use "sass:math";

$phi: math.div(1 + math.sqrt(5), 2);

@function golden-ratio($val, $level) {
  @return $val * math.pow($phi, $level);
}

.header {
  font-size: golden-ratio(16px, 2); // 16px * 1.618^2
}
```

### Итог

Модуль `sass:math` — это замена встроенным калькуляторам браузера (`calc()`) в тех случаях, когда значение должно быть известно на этапе сборки. Использование `math.div()` вместо `/` является обязательным стандартом для всех современных проектов на Sass.
