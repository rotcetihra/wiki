# sass:meta — Интроспекция и управление средой Sass

Модуль `sass:meta` предоставляет инструменты для получения информации о значениях, переменных, миксинах и функциях в процессе компиляции. Он позволяет писать "умный" код, который адаптируется к типам данных или проверяет наличие определенных модулей.

Для использования модуля необходимо подключить его в начале файла:

```SCSS
@use "sass:meta";
```

---

## 1. Определение типов данных

Функция `meta.type-of($value)` — основной инструмент для валидации входных данных в миксинах и функциях. Она возвращает строку, описывающую тип переданного значения.

|**Результат**|**Тип значения**|**Пример**|
|---|---|---|
|`number`|Число (с единицами или без)|`10px`, `5`, `20%`|
|`string`|Строка (в кавычках или без)|`"Arial"`, `bold`|
|`color`|Цвет|`#fff`, `rgba(0,0,0,0.5)`|
|`list`|Список|`1px 2px 5px`|
|`map`|Карта|`("key": value)`|
|`bool`|Логическое значение|`true`, `false`|
|`null`|Отсутствие значения|`null`|
|`function`|Ссылка на функцию|`meta.get-function("rgba")`|

---

## 2. Работа с функциями как с объектами

Sass позволяет передавать функции в качестве аргументов другим функциям (First-class functions).

### meta.get-function($name, $css: false, $module: null)

Возвращает ссылку на функцию. Это необходимо для последующего вызова функции через `meta.call()`.

- `$css`: если `true`, ищет встроенную CSS-функцию.
    
- `$module`: имя модуля (если функция импортирована через `@use`).
    

### meta.call($function, $args...)

Вызывает функцию, полученную через `get-function`.

```SCSS
@use "sass:meta";

@function double($n) { @return $n * 2; }

@function apply-math($func-name, $value) {
  $func: meta.get-function($func-name);
  @return meta.call($func, $value);
}

.result {
  width: apply-math("double", 50px); // 100px
}
```

## 3. Проверка существования (Existence Checks)

Эти функции возвращают `true` или `false` и крайне полезны для создания библиотек, которые должны работать в разных условиях окружения.

- **`meta.variable-exists($name)`**: существует ли переменная в текущей области видимости.
    
- **`meta.global-variable-exists($name)`**: существует ли глобальная переменная.
    
- **`meta.function-exists($name)`**: определена ли такая функция.
    
- **`meta.mixin-exists($name)`**: определен ли такой миксин.

## 4. Динамическая загрузка: `meta.load-css()`

Это современная и мощная альтернатива `@import`. Функция позволяет загружать стили из модуля прямо внутри миксина.

- **Особенности:** В отличие от `@use`, `load-css()` может вызываться внутри блоков кода (например, в `@if`).
    
- **Аргументы:** Принимает URL и карту `$with` для настройки переменных в загружаемом модуле.

```SCSS
@mixin theme-loader($name) {
  @if $name == "dark" {
    @include meta.load-css("themes/dark", $with: ("base-color": #000));
  }
}
```

---

## 5. Интроспекция модулей

Если вам нужно получить данные из загруженного модуля:

- **`meta.module-variables($module)`**: Возвращает карту (`map`) всех переменных, определенных в указанном модуле.
    
- **`meta.module-functions($module)`**: Возвращает карту всех функций модуля.

---

## 6. Отладка: `meta.inspect()`

Функция `meta.inspect($value)` возвращает строковое представление значения так, как его видит Sass. Это незаменимо для отладки списков и карт, так как обычный `@debug` может не показать скрытые детали (например, типы разделителей в списках).

```SCSS
$list: 1px, 2px, 3px;
@debug meta.inspect($list); // "(1px, 2px, 3px)"
```

## Практический пример: Защищенный миксин

Использование `meta.type-of` для предотвращения ошибок при передаче некорректных данных:

```SCSS
@use "sass:meta";

@mixin safe-padding($value) {
  @if meta.type-of($value) != "number" {
    @error "Ошибка: миксин safe-padding ожидает число, но получил #{meta.type-of($value)}.";
  }
  padding: $value;
}

.box {
  @include safe-padding(10px); // Ок
  // @include safe-padding("10px"); // Вызовет ошибку при компиляции
}
```

### Итог

Модуль `sass:meta` — это "рентген" для вашего кода. Он позволяет создавать высокоуровневые абстракции, проверять типы данных перед выполнением операций и динамически управлять загрузкой стилей, что делает архитектуру проекта более надежной и предсказуемой.
