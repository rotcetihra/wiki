# Обзор

В арсенале Sass есть две функции, которые превращают написание стилей из рутины в настоящее программирование: **интерполяция** и **продвинутая вложенность**. С их помощью вы можете не просто писать селекторы, а «конструировать» их на лету.

## Интерполяция: Динамические селекторы

Интерполяция в Sass — это способ вставить значение переменной или результат функции прямо в текст селектора или имя свойства. Она записывается с помощью конструкции #{$variable}.

### Зачем это нужно?

Обычные переменные работают только как **значения** свойств (например, color: $main-color). Но если вы хотите использовать переменную в **имени класса** или **пути к файлу**, вам понадобится интерполяция. Это незаменимо при создании библиотек или миксинов.

#### Пример: Миксин для генерации иконок-эмодзи

Допустим, нам нужно создать десятки классов для разных эмодзи. Вместо того чтобы писать их вручную, мы создаем миксин:

**SCSS Syntax:**

```scss
@mixin define-emoji($name, $glyph) {
  // Используем интерполяцию для создания уникального имени класса
  span.emoji-#{$name} {
    font-family: IconFont;
    content: $glyph;
  }
}

// Вызываем миксин
@include define-emoji("women-holding-hands", "👭");
@include define-emoji("rocket", "🚀");
```

**Результат в CSS:**

```css
span.emoji-women-holding-hands {
  font-family: IconFont;
  content: "👭";
}
span.emoji-rocket {
  font-family: IconFont;
  content: "🚀";
}
```

## «Секретный ингредиент» парсинга

Один из самых важных фактов о Sass: **он анализирует селекторы только после того, как завершена интерполяция.**

> **Почему это круто?** Вы можете генерировать абсолютно любые, даже самые безумные части селекторов. Sass не выдаст ошибку в процессе сборки, потому что он «подождет», пока все переменные внутри #{} превратятся в обычный текст, и только потом проверит, является ли полученный результат валидным CSS.

## Продвинутая вложенность и амперсанд (&)

Вложенность в Sass — это не только пробел между родительским и дочерним элементом. Используя символ **&** (родительский селектор), вы получаете полный контроль над структурой:

 1. **Склейка имен:** .button { &--large { ... } } превратится в .button--large.
 2. **Изменение контекста:** Вы можете использовать & внутри интерполяции или вместе с правилом @at-root.
 3. **Динамическое управление:** Сочетание интерполяции и & позволяет создавать сложные методологии (вроде BEM) максимально лаконично.

### Пример продвинутого сочетания:

```scss
.block {
  $root: &; // Сохраняем ссылку на родителя в переменную
  
  @at-root #{$root}__element {
    color: blue;
    
    &:hover {
      color: red;
    }
  }
}
```

### Итог

Интерполяция — это мост между логикой SassScript и статичным миром CSS-селекторов. Она позволяет:

 * Создавать масштабируемые дизайн-системы.
 * Автоматизировать создание однотипных классов.
 * Держать код чистым и избавляться от дублирования.
