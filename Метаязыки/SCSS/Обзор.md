# SCSS (Sassy Cascading Style Sheets)

**SCSS** (Sassy Cascading Style Sheets) — это метаязык на основе CSS, предназначенный для расширения возможностей каскадных таблиц стилей. Он является наиболее популярным синтаксисом препроцессора **Sass**. SCSS полностью совместим с синтаксисом CSS3, что означает, что любой валидный CSS-файл также является валидным SCSS-файлом.

## История и развитие

Sass был изначально разработан в 2006 году Хэмптоном Кэтлином. Изначально использовался «индентовый» синтаксис (Sass), в котором структура определялась отступами, а точки с запятой отсутствовали. В версии **Sass 3.0** был представлен синтаксис **SCSS**, который максимально приближен к традиционному CSS, что упростило внедрение технологии в существующие проекты.

## Основные концепции

### 1. Переменные

SCSS позволяет хранить информацию, которую можно повторно использовать во всей таблице стилей (цвета, шрифты, размеры). Переменные объявляются с помощью символа $.

```scss
$primary-color: #3bbfce;
$margin: 16px;

.content-navigation {
  border-color: $primary-color;
  color: darken($primary-color, 10%);
}
```

### 2. Вложенность (Nesting)

SCSS позволяет вкладывать селекторы друг в друга, повторяя визуальную иерархию HTML-документа. Это повышает читаемость кода и предотвращает дублирование родительских селекторов.

```scss
nav {
  ul {
    margin: 0;
    padding: 0;
    list-style: none;
  }
  li { display: inline-block; }
  a {
    display: block;
    padding: 6px 12px;
    text-decoration: none;
  }
}
```

### 3. Миксины (Mixins)

Миксины позволяют создавать группы CSS-деклараций, которые можно повторно использовать в разных частях проекта. Это полезно для устранения дублирования кода, например, при написании вендорных префиксов.

 * **Объявление:** @mixin name
 * **Использование:** @include name

### 4. Наследование (Extend/Inheritance)

Позволяет одному селектору наследовать свойства другого селектора без необходимости дублирования кода в итоговом CSS. Используется директива @extend.

### 5. Операторы и функции

SCSS поддерживает математические операции (+, -, *, /, %) и встроенные функции для работы с цветом, строками и числами.

## Сравнение SCSS и Sass

Существует два основных синтаксиса Sass:

| Характеристика       | SCSS (Sassy CSS)                | Sass (Indented)          |
| -------------------- | ------------------------------- | ------------------------ |
| **Расширение файла** | .scss                           | .sass                    |
| **Разделители**      | Фигурные скобки {} и ;          | Отступы и переносы строк |
| **Совместимость**    | Полная совместимость с CSS      | Специфический синтаксис  |
| **Популярность**     | Высокая (промышленный стандарт) | Нишевая                  |

## Процесс компиляции

Браузеры не способны интерпретировать SCSS напрямую. Для работы необходимо преобразовать (скомпилировать) код SCSS в стандартный CSS. Основные инструменты для этого:

 1. **Dart Sass:** Текущая официальная реализация.
 2. **Node-sass:** Устаревшая обертка над LibSass (не рекомендуется для новых проектов).
 3. **Сборщики проектов:** Webpack (sass-loader), Vite, Gulp.

## Преимущества и недостатки

### Преимущества

 * **Модульность:** Возможность разделять стили на мелкие логические файлы с помощью директивы @use или @import.
 * **Масштабируемость:** Облегчает поддержку крупных проектов с тысячами строк стилей.
 * **Логика:** Наличие условий (@if), циклов (@for, @each) и функций.

### Недостатки

 * **Необходимость сборки:** Требуется настройка инструментов компиляции.
 * **Риск чрезмерной вложенности:** Неправильное использование Nesting может привести к созданию слишком специфичных и тяжелых селекторов.
 * **Кривая обучения:** Требуется время на изучение синтаксиса и программных возможностей.
