# Критическое изменение: Переход от `type-of()` к `meta.type-of()`

Это изменение является частью масштабной стратегии Sass по отказу от **глобальных функций** в пользу **встроенных модулей**. Глобальная функция `type-of()` теперь считается устаревшей, и её использование в будущем приведет к ошибке.

---

## 1. Суть изменения

Функция для определения типа данных `type-of()` переносится в модуль `sass:meta`.

- **Раньше:** вы могли вызвать `type-of($value)` в любом месте кода.
    
- **Теперь:** необходимо импортировать модуль `meta` и вызывать функцию как `meta.type-of($value)`.

---

## 2. Почему это происходит?

Главная причина — **конфликты с будущим CSS**.

1. **Чистота имен:** CSS постоянно развивается и добавляет новые функции (например, `calc()`, `min()`, `clamp()`). Существует высокая вероятность того, что в стандарте CSS появится собственная функция `type-of()` или `type()`. Если Sass оставит эту функцию глобальной, он не сможет понять, хотите ли вы использовать логику Sass или просто вывести CSS-строку в браузер.
    
2. **Модульная архитектура:** Модули (`@use`) делают код предсказуемым. Когда вы видите `meta.type-of()`, вы точно знаете, что это встроенный инструмент Sass для анализа данных.

---

## 3. Как теперь выглядит код

Чтобы ваш код соответствовал современным стандартам и не выдавал предупреждений, измените подход к импорту и вызову:

### Старый подход (Устарело):

```SCSS
$width: 100px;

.element {
  @if type-of($width) == "number" {
    width: $width;
  }
}
```

### Новый подход (Правильно):

```SCSS
@use "sass:meta";

$width: 100px;

.element {
  @if meta.type-of($width) == "number" {
    width: $width;
  }
}
```

---

## 4. Что если я использую `type-of` для CSS?

Если вам нужно, чтобы строка `type-of(...)` попала в итоговый CSS-файл «как есть» (например, если какая-то специфическая библиотека или будущий стандарт CSS потребует именно такого имени), вам придется использовать **интерполяцию** или **верхний регистр**:

```SCSS
.element {
  // Выведет в CSS: type-of(10px)
  custom-property: #{"type-of"}(10px);
  
  // Или так (CSS нечувствителен к регистру имен функций)
  custom-property: TYPE-OF(10px);
}
```

---

## 5. Сроки и предупреждения

1. **Текущий момент:** При использовании глобальной `type-of()` компилятор Dart Sass выдает **Deprecation Warning** (предупреждение об устаревании).
    
2. **Sass 2.0.0:** Глобальная функция будет полностью удалена. Любая попытка вызвать её без префикса `meta.` приведет к ошибке компиляции.

---

## Как быстро обновить проект?

Если у вас сотни файлов с использованием `type-of()`, не обязательно менять их вручную. Используйте официальный инструмент для миграции:

```Bash
npm install -g sass-migrator
sass-migrator module --migrate-deps <путь_к_вашему_файлу.scss>
```

Мигратор автоматически добавит `@use "sass:meta"` и заменит все вызовы функции на правильные.

### Резюме

Использование `meta.type-of()` — это не просто прихоть разработчиков Sass, а страховка вашего кода от конфликтов с будущими обновлениями браузеров. Чем раньше вы перейдете на модульную систему, тем стабильнее будет ваша кодовая база.
