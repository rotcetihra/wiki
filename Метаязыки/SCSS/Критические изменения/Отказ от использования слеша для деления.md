# Критическое изменение: Отказ от использования `/` для деления

Это одно из самых заметных изменений в современном Sass. Исторически символ косой черты (`/`) использовался в Sass как оператор деления. Однако в стандартном CSS этот символ всё чаще применяется в качестве **разделителя** значений. Чтобы избежать двусмысленности и соответствовать стандартам CSS, Sass официально переводит деление на функцию `math.div()`.

---

## 1. В чем суть конфликта?

В CSS косая черта используется во многих современных свойствах:

- **Шрифты:** `font: 16px/1.5 sans-serif;` (размер/высота строки)
    
- **Сетка:** `grid-column: 1 / 3;`
    
- **Цвета:** `rgb(255 0 0 / 0.5)` (цвета с прозрачностью)
    
- **Соотношение сторон:** `aspect-ratio: 16 / 9;`
    

Если вы напишете `margin: 10px / 2`, Sass должен решить: это CSS-разделитель (результат: `10px / 2`) или математическая операция (результат: `5px`)? Раньше Sass использовал сложные эвристики, чтобы угадать ваше намерение, но это часто приводило к ошибкам.

---

## 2. Новое правило: `math.div()`

Использование оператора `/` для деления теперь **признано устаревшим**. Для выполнения арифметического деления необходимо использовать функцию `math.div()` из встроенного модуля `sass:math`.

|**Действие**|**Устаревший синтаксис**|**Современный синтаксис**|
|---|---|---|
|**Деление**|`$width / 2`|`math.div($width, 2)`|
|**Переменные**|`$a / $b`|`math.div($a, $b)`|

```SCSS
@use "sass:math";

.container {
  // Правильный способ деления
  width: math.div(100%, 3); 
}
```

---

## 3. Как теперь выводить `/` как разделитель CSS?

Если вам нужно, чтобы косая черта попала в итоговый CSS именно как символ (например, для `grid-column`), у вас есть несколько вариантов:

- **Литералы:** Если вы пишете значения напрямую (без переменных), Sass оставит их как есть.
    
- **Интерполяция:** Это самый надежный способ для работы с переменными.
    
- **Список со слешем:** Использование функций модуля `sass:list`.

```SCSS
@use "sass:list";

.element {
  // 1. Просто текст (если нет переменных, Sass не трогает /)
  grid-column: 1 / 3;

  // 2. С переменными через интерполяцию (рекомендуется)
  $start: 1;
  $end: 3;
  grid-column: #{$start} / #{$end};

  // 3. Через модуль sass:list
  grid-column: list.slash-list($start, $end);
}
```

---

## 4. Почему нельзя просто оставить всё как было?

1. **Предсказуемость:** Вы точно знаете, что `math.div()` всегда делит, а `/` в обычном коде всегда выводится как текст.
    
2. **Будущее CSS:** CSS будет добавлять всё больше функций, использующих `/`. Без этого изменения Sass начал бы "ломать" валидный CSS-код, пытаясь поделить там, где не нужно.
    
3. **Скорость:** Компилятору не нужно тратить ресурсы на анализ контекста вокруг каждого символа `/`.

---

## 5. Как обновить старый проект (Миграция)

Если ваш проект завален предупреждениями "slash as division is deprecated", воспользуйтесь официальным инструментом **Sass Migrator**. Он автоматически заменит все нужные места на `math.div()` и добавит импорт модуля.

**Команда для запуска:**

```Bash
npm install -g sass-migrator
sass-migrator division **/*.scss
```

### Сроки

- **Dart Sass 1.33.0:** Появились предупреждения о делении через `/`.
    
- **Sass 2.0.0:** Оператор `/` окончательно перестанет выполнять деление и будет всегда трактоваться как обычный символ разделителя CSS.

> **Совет:** Не откладывайте обновление. Использование `math.div()` делает ваш код чище и избавляет от неприятных сюрпризов, когда `10px / 2` внезапно превращается в `5px` там, где вы ожидали увидеть дробь для CSS-сетки.
