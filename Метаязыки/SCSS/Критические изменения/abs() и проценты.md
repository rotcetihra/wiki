# Критическое изменение: `abs()` и проценты

Это изменение устраняет непоследовательность в обработке процентов функцией `abs()`. Ранее в Sass функция `abs()` при передаче ей отрицательного процента возвращала число без единиц измерения. Теперь функция сохраняет единицу измерения `%`.

---

## 1. Суть изменения

Функции `math.abs()` и глобальная `abs()` теперь возвращают значение с типом «процент», если им был передан процент. Раньше они возвращали просто число (unitless number).

|**Выражение**|**Старый результат**|**Новый результат**|
|---|---|---|
|`abs(-10%)`|`10`|`10%`|
|`math.abs(-20%)`|`20`|`20%`|

---

## 2. Почему это важно?

1. **Единообразие с другими единицами:** Если вы передаете в `abs()` пиксели (`-10px`), вы ожидаете получить пиксели (`10px`). Проценты долгое время оставались исключением из этого правила, что вызывало ошибки в расчетах.
    
2. **Конфликт с CSS:** В современном CSS появилась нативная функция `abs()`. Согласно спецификации CSS, `abs()` от процента должен возвращать процент. Sass приводит свое поведение в соответствие со стандартами браузеров.
    
3. **Предсказуемость математики:** В сложных формулах автоматическая потеря единиц измерения (превращение процента в обычное число) приводила к тому, что последующие операции (например, сложение с `px`) могли завершиться ошибкой или дать неверный результат.

---

## 3. Как обновить код

Если ваша логика зависела от того, что `abs()` «съедает» символ процента, вам нужно изменить способ получения значения.

### Если вам нужен процент (правильный путь):

Просто продолжайте использовать `math.abs()`. Теперь результат будет содержать `%`, что логически верно для CSS.

### Если вам нужно число без единиц:

Если вам необходимо именно числовое значение процента для дальнейших специфических расчетов, явно разделите результат на `1%`.

```SCSS
@use "sass:math";

$val: -15%;

// УСТАРЕЛО (результат был 15, станет 15%)
$num: abs($val); 

// ПРАВИЛЬНО (если нужно именно число 15)
$num: math.div(math.abs($val), 1%);
```

---

## 4. Глобальная функция `abs()` vs `math.abs()`

Это изменение также является частью процесса отказа от глобальных функций.

- **Глобальная `abs()`**: Теперь считается устаревшей. При её использовании Sass может выдать предупреждение, так как он не знает, хотите ли вы вызвать функцию Sass или оставить `abs()` для вычисления браузером (CSS).
    
- **`math.abs()`**: Рекомендуемый способ. Он четко указывает, что вычисления должны пройти на стороне Sass.

```SCSS
@use "sass:math";

.element {
  // Рекомендуется:
  padding: math.abs(-10px);
  
  // Для нативного CSS (Sass не будет это вычислять):
  width: #{"abs"}(-20%); 
}
```

---

## 5. Сроки внедрения

- **Dart Sass 1.65.0**: Введены предупреждения о том, что поведение `abs()` для процентов изменится.
    
- **Sass 2.0.0**: Изменение вступит в полную силу. `abs()` будет всегда возвращать проценты, а глобальная функция `abs()` может быть удалена или заменена нативным CSS-выводом.
    

Если ваш проект сильно полагается на математические расчеты с процентами, рекомендуется запустить `sass-migrator`, чтобы автоматически обновить вызовы функций и избежать ошибок при переходе на новые версии компилятора.
