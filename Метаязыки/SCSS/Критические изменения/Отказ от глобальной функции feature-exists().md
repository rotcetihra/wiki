# Критическое изменение: Отказ от глобальной функции `feature-exists()`

Это изменение является частью масштабной стратегии Sass по очистке глобального пространства имен и переходу к модульной системе. Глобальная функция `feature-exists()` теперь считается устаревшей и заменяется аналогом из встроенного модуля `sass:meta`.

---

## 1. Суть изменения

Функция `feature-exists($feature)` использовалась для проверки того, поддерживает ли текущая версия Sass ту или иную возможность (например, `@at-root` или `custom-properties`).

**Что изменилось:**

1. Глобальный вызов `feature-exists()` объявлен **deprecated** (устаревшим).
    
2. Функционал перенесен в функцию `meta.feature-exists()` внутри модуля `sass:meta`.

---

## 2. Почему это произошло?

1. **Чистота имен:** Sass постепенно избавляется от всех встроенных глобальных функций, чтобы избежать конфликтов с именами, которые могут появиться в будущем в CSS или ваших собственных функциях.
    
2. **Модульная архитектура:** Теперь все служебные инструменты Sass (работа с типами, селекторами, функциями) сгруппированы в логические блоки. Модуль `sass:meta` — это «центр управления» для получения информации о самом коде.
    
3. **Стандартизация:** Dart Sass стал основным стандартом. Многие функции, которые раньше требовали проверки через `feature-exists`, теперь являются базовыми и поддерживаются повсеместно, что делает саму необходимость частых проверок менее актуальной.

---

## 3. Примеры: Как обновить код

Для перехода на новый синтаксис необходимо импортировать модуль `sass:meta` в начале файла.

### До (Устаревший синтаксис)

```SCSS
// Глобальный вызов без импортов
@if feature-exists("at-root") {
  @at-root .extra { color: red; }
}
```

### После (Правильный синтаксис)

```SCSS
@use "sass:meta";

.element {
  // Вызов через пространство имен модуля meta
  @if meta.feature-exists("at-root") {
    @at-root .child { color: blue; }
  }
}
```

---

## 4. Что можно проверять через `feature-exists`?

Вот некоторые из аргументов, которые принимает функция:

- `at-root`: Поддержка директивы `@at-root`.
    
- `global-variable-shadowing`: Поведение переменных при перекрытии в разных областях видимости.
    
- `extend-selector`: Возможность использовать сложные селекторы в `@extend`.
    
- `units-level-3`: Поддержка единиц измерения из спецификации CSS Values and Units Level 3.

---

## 5. Как исправить весь проект сразу

Если в вашей кодовой базе (или старых библиотеках) часто встречается эта функция, вы можете использовать официальный инструмент миграции.

**Команда для запуска:**

```Bash
npm install -g sass-migrator
sass-migrator module --migrate-deps main.scss
```

Мигратор автоматически добавит `@use "sass:meta"` и заменит `feature-exists` на `meta.feature-exists`.

---

## 6. Сроки внедрения

- **Dart Sass 1.23.0:** Введены предупреждения об устаревании глобальной функции.
    
- **Sass 2.0.0:** Глобальная функция `feature-exists()` будет полностью удалена. Её вызов приведет к ошибке компиляции.

> **Совет:** Большинство современных проектов на Dart Sass уже не нуждаются в этих проверках, так как функционал "at-root" и других фич является стандартным уже много лет. Если вы не пишете библиотеку, которая должна поддерживать древние версии Ruby Sass (которые давно не обновляются), эти проверки можно просто удалить.
