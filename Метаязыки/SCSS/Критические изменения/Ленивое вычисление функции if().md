# Критическое изменение: Ленивое вычисление функции `if()`

Функция `if()` в Sass является встроенным инструментом, который работает аналогично тернарному оператору в других языках программирования. Она принимает три аргумента: условие, значение при истине и значение при лжи.

Долгое время поведение этой функции отличалось от поведения директивы `@if`, что приводило к неожиданным ошибкам. Текущее критическое изменение направлено на синхронизацию этих механизмов.

---

## 1. Суть изменения: От «жадного» к «ленивому»

Исторически функция `if()` использовала **«жадное» вычисление (Eager Evaluation)**. Это означало, что Sass вычислял оба результата — и для `true`, и для `false` — еще до того, как проверял само условие.

**Новое поведение:** Sass переходит к **«ленивому» вычислению (Lazy Evaluation)**. Теперь будет вычисляться только тот аргумент, который соответствует результату условия. Второй аргумент будет полностью игнорироваться.

---

## 2. Почему это важно? (Проблема ошибок)

Главная проблема «жадного» вычисления заключалась в том, что код во «неиспользуемой» ветке мог вызвать ошибку компиляции, даже если условие гарантировало, что эта ветка не должна работать.

### Пример с ошибкой (Старое поведение):

```SCSS
@use "sass:math";

$width: 0;

// Даже если $width равно 0, Sass попытается вычислить math.div(100%, 0)
// Это приведет к ошибке "Division by zero", хотя условие $width != 0 ложно.
$result: if($width != 0, math.div(100%, $width), 100%);
```

### Решение (Новое поведение):

При ленивом вычислении, если `$width` равно `0`, выражение `math.div(100%, $width)` просто не будет запущено, и ошибка не возникнет.

---

## 3. Сравнение `if()` и `@if`

|**Особенность**|**Функция if() (Старая)**|**Функция if() (Новая)**|**Директива @if**|
|---|---|---|---|
|**Тип вычисления**|Жадное (Eager)|Ленивое (Lazy)|Ленивое (Lazy)|
|**Вычисление веток**|Обе ветки|Только нужная|Только нужная|
|**Побочные эффекты**|Вызываются везде|Только в нужной ветке|Только в нужной ветке|

---

## 4. Этапы внедрения изменений

Sass внедряет это изменение постепенно, чтобы разработчики успели исправить свой код:

1. **Текущий этап (Предупреждение):** Если вычисление неиспользуемой ветки приводит к ошибке, Sass выдает **Deprecation Warning**. Компиляция продолжается, если это возможно, но код помечается как устаревший.
    
2. **Будущий этап (Полный переход):** Функция `if()` станет полностью ленивой. Неиспользуемые ветки не будут вычисляться вовсе.

---

## 5. Типичные сценарии, вызывающие предупреждения

Чаще всего предупреждения возникают в следующих случаях:

- **Математические операции:** Деление на потенциальный ноль или передача некорректных единиц измерения.
    
- **Работа с коллекциями:** Попытка получить значение из карты (`map.get`) по ключу, который может отсутствовать.
    
- **Функции цвета:** Передача значений вне допустимого диапазона (например, прозрачность больше 1).
    

**Пример с картой:**

```SCSS
$theme: ( "primary": #333 );

// Раньше это могло вызвать ошибку, если ключа "secondary" нет.
// Теперь это выдаст предупреждение, а в будущем станет безопасным.
$color: if(map.has-key($theme, "secondary"), map.get($theme, "secondary"), #fff);
```

---

## 6. Как подготовить код

Хотя изменение делает код более безопасным, в переходный период рекомендуется:

1. **Проверить логику:** Убедитесь, что вы не полагаетесь на побочные эффекты (например, вызов функций, которые что-то логируют или меняют) в той ветке функции `if()`, которая не должна выполняться.
    
2. **Использовать директиву `@if`:** Если логика внутри веток слишком сложная или потенциально ошибочная, лучше использовать полноценную конструкцию `@if / @else` вместо функции.

```SCSS
// Более надежный способ для сложных проверок
$result: null;
@if $width != 0 {
  $result: math.div(100%, $width);
} @else {
  $result: 100%;
}
```

### Резюме

Переход на ленивое вычисление в функции `if()` делает Sass более интуитивным и избавляет от необходимости писать громоздкие проверки. Это изменение приближает функциональное программирование в Sass к стандартам большинства современных языков.
