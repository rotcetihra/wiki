# Критическое изменение: Имена пользовательских функций

В рамках обновления Sass и обеспечения его полной совместимости с будущими стандартами CSS было введено важное ограничение на именование пользовательских функций. Это изменение направлено на то, чтобы избежать конфликтов между функциями, которые вы создаете сами, и встроенными функциями браузера.

---

## 1. Суть изменения

Sass больше не позволяет (или выдает предупреждение) использовать для пользовательских функций имена, которые уже заняты системными функциями CSS или зарезервированы для будущих расширений CSS.

Если ваша функция называется так же, как и стандартная функция CSS, компилятор Sass может воспринять её вызов как обычный текст, который нужно просто передать в браузер, что приведет к поломке логики.

---

## 2. Зарезервированные имена функций

Вы больше не можете определять функции с именами, которые Sass обрабатывает особым образом или которые являются фундаментальными для CSS. К ним относятся:

- **`calc()`**, **`element()`**, **`expression()`**, **`url()`**: Эти функции имеют специфический синтаксис разбора в CSS. Если вы определите свою функцию `calc()`, Sass не сможет гарантировать, что она будет вызвана корректно во всех контекстах.
    
- **`min()`**, **`max()`**, **`clamp()`**: Эти математические функции теперь являются частью стандарта CSS. Ранее разработчики часто создавали свои миксины или функции с такими именами, но теперь Sass отдает приоритет CSS-синтаксису.

---

## 3. Функции с префиксом `--`

Одним из самых значимых изменений является резервирование имен функций, начинающихся с двух дефисов (например, `--my-custom-function()`).

**Почему это важно?**

Рабочая группа CSS (W3C) зарезервировала этот синтаксис для **пользовательских CSS-функций** (аналогично переменным/custom properties). Чтобы Sass не конфликтовал с будущими нативными функциями браузера, он запрещает использовать такой префикс для функций, написанных на Sass.

```SCSS
// ТЕПЕРЬ ВЫЗЫВАЕТ ОШИБКУ ИЛИ ПРЕДУПРЕЖДЕНИЕ:
@function --theme-color($name) {
  @return map.get($theme, $name);
}
```

---

## 4. Конфликты с CSS-функциями

Когда вы вызываете функцию, имя которой совпадает с функцией CSS, Sass использует следующие правила:

1. Если вызов содержит **интерполяцию** (например, `calc(#{1px + 2px})`) или **переменные**, Sass пытается обработать его.
    
2. Если имя функции зарезервировано, Sass может просто передать строку в CSS "как есть", и ваша логика внутри `@function` не будет выполнена.

---

## 5. Как исправить (Инструкция по миграции)

Если ваш проект выдает предупреждения о именах функций, выполните следующие шаги:

### Шаг 1: Переименование

Самый надежный способ — добавить префикс, специфичный для вашего проекта или компании, к именам ваших функций.

- Вместо `min()` $\rightarrow$ `my-project-min()`
    
- Вместо `--get-size()` $\rightarrow$ `get-size()`
    

### Шаг 2: Использование модулей

Если вы используете систему модулей (`@use`), функции автоматически получают префикс пространства имен, что решает проблему конфликтов.

```SCSS
// _tools.scss
@function min($a, $b) { ... }

// main.scss
@use "tools";
.el {
  width: tools.min(10px, 20px); // Конфликта нет, так как вызывается tools.min
}
```

### Шаг 3: Математический модуль

Для стандартных операций используйте встроенный модуль `sass:math`. Например, вместо попытки написать свою `round()`, используйте `math.round()`.

---

## 6. Почему это полезно в долгосрочной перспективе

1. **Предсказуемость:** Вы можете быть уверены, что новые обновления браузеров не "сломают" ваш сайт, если в CSS внезапно появится функция с таким же именем, как у вас.
    
2. **Чистота кода:** Разделение пользовательской логики и нативных CSS-возможностей делает код более понятным для других разработчиков.
    
3. **Совместимость:** Ваш код будет готов к использованию нативных пользовательских функций CSS, когда они станут поддерживаться браузерами.
    

### Резюме

Избегайте имен `calc`, `url`, `min`, `max`, `clamp` и никогда не начинайте имена своих функций с `--`. Пользуйтесь системой модулей `@use`, чтобы изолировать свои инструменты от глобального пространства имен CSS.
