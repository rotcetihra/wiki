# Википедия

Личная википедия.

Википедия (если быть точным: база знаний) предназначена для сохранения сгенерированной нейросетями информации по той или иной изучаемым мной темам.

>[!NOTE]
>Просмотр Википедии рассчитан на приложение [Obsidian](https://obsidian.md/).

> [!WARNING]
> Википедия сгенерирована нейросетью [Google Gemini](https://gemini.google.com/app). В ней могут быть ошибки.
