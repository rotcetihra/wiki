# Глава 11. Макросы

**Дата написания:** 03.08.2026

## 1. Обзор главы

Глава 11 — примеры распространенных макросов. В ней на практических примерах рассматриваются макросы для нахождения минимального и максимального значений (`MIN`/`MAX`), побочные действия при передаче аргументов в макросы, преобразование операндов в строку (`#`), конкатенация токенов (`##`), макросы для получения длины массива, обмена значениями, безопасной очистки памяти и вычисления смещения поля в структуре, макросы для вывода отладочной информации, создания обобщенных списков, их перебора в стиле for-each и реализации стека на основе макросов. Материал опирается на знания из [[Языки программирования/C/Глава 5. Препроцессор|главы 5]] о макросах и директиве `#define`.
