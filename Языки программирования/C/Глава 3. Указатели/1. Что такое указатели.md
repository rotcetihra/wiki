# Что такое указатели

## 1. Введение

Все определенные в программе данные, например переменные, хранятся в памяти по определенным адресам. **Указатели** позволяют напрямую обращаться к этим адресам и благодаря этому манипулировать данными. Указатели представляют собой объекты, значением которых служат адреса других объектов (переменных, констант, указателей) или функций. Указатели — неотъемлемый компонент для управления памятью в языке Си.

## 2. Определение указателя

Для определения указателя надо указать тип объекта, на который указывает указатель, и символ звездочки `*`:

```
тип_данных* название_указателя;
```

Сначала идет тип данных, на который указывает указатель, и символ звездочки `*`, затем имя указателя.

Например, определим указатель на объект типа `int`:

```c
int *p;
```

Пока указатель не ссылается ни на какой объект. Теперь присвоим ему адрес переменной:

```c
int main(void)
{
    int x = 10;     // определяем переменную
    int *p;         // определяем указатель
    p = &x;         // указатель получает адрес переменной
    return 0;
}
```

> [!NOTE]
> Запись `int* p` и `int *p` эквивалентны — положение звездочки рядом с типом или с именем не влияет на смысл. Но важно помнить: звездочка в объявлении относится к конкретной переменной, поэтому `int* a, b;` объявляет указатель `a` и обычную переменную `b` типа `int`.

## 3. Получение адреса данных

Указатель хранит адрес объекта в памяти компьютера. Для получения адреса переменной применяется операция `&`. Эта операция применяется только к таким объектам, которые хранятся в памяти компьютера, то есть к переменным и элементам массивов.

Важно, что переменная `x` имеет тип `int`, и указатель, который указывает на ее адрес, тоже имеет тип `int`. То есть должно быть соответствие по типу.

Какой именно адрес имеет переменная `x`? Для вывода значения указателя можно использовать специальный спецификатор `%p`:

```c
#include <stdio.h>

int main(void)
{
    int x = 10;
    int *p;
    p = &x;
    printf("%p \n", p);     // 0060FEA8
    return 0;
}
```

В данном случае машинный адрес переменной `x` — `0x0060FEA8`. (Для адресов в памяти применяется шестнадцатеричная система.) Но в каждом отдельном случае адрес может быть иным. Фактически адрес представляет целочисленное значение, выраженное в шестнадцатеричном формате.

То есть в памяти компьютера есть адрес `0x0060FEA8`, по которому располагается переменная `x`.

Так как переменная `x` представляет тип `int`, то на большинстве архитектур она будет занимать следующие 4 байта (на конкретных архитектурах размер памяти для типа `int` может отличаться). Таким образом, переменная типа `int` последовательно займет ячейки памяти с адресами `0x0060FEA8`, `0x0060FEA9`, `0x0060FEAA`, `0x0060FEAB`.

И указатель `p` будет ссылаться на адрес, по которому располагается переменная `x`, то есть на адрес `0x0060FEA8`.

> [!NOTE]
> Спецификатор `%p` ожидает, что аргумент будет представлять тип `void*`, то есть указатель на значение типа `void`. Некоторые компиляторы при некоторых настройках могут при компиляции отображать предупреждения. Чтобы все было канонически правильно, переданный указатель следует преобразовать в указатель типа `void*`:

```c
printf("%p \n", (void *)p);
```

## 4. Получение значения по адресу

Но так как указатель хранит адрес, то можно по этому адресу получить хранящееся там значение, то есть значение переменной `x`. Для этого применяется операция `*` — операция **разыменования** (dereference operator). Результатом этой операции всегда является объект, на который указывает указатель. Применим данную операцию и получим значение переменной `x`:

```c
#include <stdio.h>

int main(void)
{
    int x = 10;
    int *p;
    p = &x;
    printf("Address = %p \n", (void *)p);
    printf("x = %d \n", *p);
    return 0;
}
```

Консольный вывод:

```
Address = 0060FEA8
x = 10
```

Используя значение, полученное в результате операции разыменования, можно присвоить его другой переменной:

```c
int x = 10;
int *p = &x;
int y = *p;     // присваиваем переменной y значение по адресу из указателя p
printf("x = %d \n", y); // 10
```

Здесь переменной `y` присваивается значение по адресу из указателя `p`, то есть значение переменной `x`.

## 5. Изменение значения по адресу

Используя указатель, можно менять значение по адресу, который хранится в указателе:

```c
int x = 10;
int *p = &x;
*p = 45;
printf("x = %d \n", x);  // 45
```

Так как по адресу, на который указывает указатель, располагается переменная `x`, то соответственно ее значение изменится.

> [!WARNING]
> Разыменование неинициализированного указателя — неопределенное поведение: программа может аварийно завершиться или обратиться к произвольной области памяти. Прежде чем разыменовывать указатель, присвойте ему адрес существующего объекта.

## 6. Указатели на разные типы данных

Создадим еще несколько указателей:

```c
#include <stdio.h>

int main(void)
{
    char c = 'N';
    int d = 10;
    short s = 2;

    char *pc = &c;          // получаем адрес переменной c типа char
    int *pd = &d;           // получаем адрес переменной d типа int
    short *ps = &s;         // получаем адрес переменной s типа short

    printf("Variable c: address=%p \t value=%c \n", (void *)pc, *pc);
    printf("Variable d: address=%p \t value=%d \n", (void *)pd, *pd);
    printf("Variable s: address=%p \t value=%hd \n", (void *)ps, *ps);
    return 0;
}
```

Возможный консольный вывод:

```
Variable c: address=0060FEA3	value=N
Variable d: address=0060FE9C	value=10
Variable s: address=0060FE9A	value=2
```

По адресам можно увидеть, что переменные часто расположены в памяти рядом, но не обязательно в том порядке, в котором они определены в тексте программы.

## 7. Резюме

1. Указатель — объект, значением которого является адрес другого объекта (переменной, константы, указателя, функции).
2. Указатель объявляется как `тип_данных* имя`; тип указателя должен соответствовать типу объекта, на который он ссылается.
3. Адрес переменной получается операцией `&`; адрес выводится спецификатором `%p` (аргумент — `void*`).
4. Операция `*` (разыменование) возвращает объект по адресу из указателя; через нее можно как читать, так и изменять значение.
5. Разыменование неинициализированного указателя — неопределенное поведение.
