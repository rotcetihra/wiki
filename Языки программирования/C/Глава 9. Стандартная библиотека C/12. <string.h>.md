## Описание библиотеки

Заголовочный файл `<string.h>` определяет функции для работы со строками (массивами символов, завершающимися нулевым байтом `'\0'`) и с произвольными блоками памяти: копирование, сравнение, поиск, объединение строк, определение длины и сообщения об ошибках. В отличие от `<stdlib.h>`, здесь нет функций преобразования строк в числа — они рассматриваются в статье [[Языки программирования/C/Глава 9. Стандартная библиотека C/11. <stdlib.h>|<stdlib.h>]].

Все строковые функции считают концом строки первый нулевой байт: они никогда не читают и не пишут за его пределами (кроме функций с явным ограничением длины).

### Копирование

| Функция | Описание |
|---|---|
| `memcpy()` | Копирует `n` байт; не обрабатывает перекрытие областей |
| `memmove()` | Копирует `n` байт; безопасна при перекрытии областей |
| `strcpy()` | Копирует строку полностью; не проверяет размер буфера |
| `strncpy()` | Копирует не более `n` символов; не гарантирует завершающий нуль |
| `strdup()` | Создаёт динамическую копию строки (C23) |
| `strndup()` | Создаёт динамическую копию не более `n` символов (C23) |

### Сравнение

| Функция | Описание |
|---|---|
| `memcmp()` | Сравнивает первые `n` байт блоков памяти |
| `strcmp()` | Побайтовое сравнение строк |
| `strncmp()` | Побайтовое сравнение не более `n` символов |
| `strcoll()` | Сравнение строк с учётом правил сортировки локали |
| `strxfrm()` | Преобразует строку в форму для сравнения через `strcmp()` |

### Поиск

| Функция | Описание |
|---|---|
| `memchr()` | Ищет байт среди первых `n` байт блока памяти |
| `strchr()` | Ищет первое вхождение символа в строке |
| `strrchr()` | Ищет последнее вхождение символа в строке |
| `strstr()` | Ищет первое вхождение подстроки |
| `strpbrk()` | Ищет первый символ из набора |
| `strspn()` | Возвращает длину начального сегмента из символов набора |
| `strcspn()` | Возвращает длину начального сегмента без символов из набора |

### Разбиение и длина

| Функция | Описание |
|---|---|
| `strtok()` | Разбивает строку на токены (модифицирует строку, не потокобезопасна) |
| `strlen()` | Возвращает длину строки в байтах |
| `strnlen()` | Безопасная версия `strlen()` с ограничением (C11) |
| `strcat()` | Дописывает строку в конец другой |
| `strncat()` | Дописывает не более `n` символов с гарантированным нулём |

### Ошибки

| Функция | Описание |
|---|---|
| `memset()` | Заполняет `n` байт памяти заданным значением |
| `strerror()` | Возвращает текстовое описание кода ошибки |
