## 1. Введение

Заголовочный файл `<string.h>` определяет функции для работы со строками (массивами символов, завершающимися нулевым байтом `'\0'`) и с произвольными блоками памяти: копирование, сравнение, поиск, объединение строк, определение длины и сообщения об ошибках. В отличие от `<stdlib.h>`, здесь нет функций преобразования строк в числа — они рассматриваются в статье [[Языки программирования/C/Глава 9. Стандартная библиотека C/11. <stdlib.h>|<stdlib.h>]].

Все строковые функции считают концом строки первый нулевой байт: они никогда не читают и не пишут за его пределами (кроме функций с явным ограничением длины).

## 2. Копирование строк и блоков памяти

### 2.1. Функции memcpy и memmove

Функции `memcpy()` и `memmove()` копируют блок памяти заданного размера:

```c
void *memcpy(void *dest, const void *src, size_t n);
void *memmove(void *dest, const void *src, size_t n);
```

Обе копируют `n` байт из `src` в `dest` и возвращают `dest` — результат можно сразу использовать в выражении. Различие — в поведении при перекрытии областей:

- `memcpy()` при перекрытии `dest` и `src` — неопределённое поведение;
- `memmove()` корректно обрабатывает перекрытие (копирует так, как если бы данные сначала были сохранены во временном буфере).

Дополнительные особенности:

- в объявлении `memcpy()` оба указателя помечены `restrict`: компилятор вправе считать, что области не перекрываются, и оптимизировать копирование (например, векторными инструкциями), тогда как `memmove()` такой возможности лишена и в общем случае медленнее;
- функции копируют данные как есть, включая нулевые байты, поэтому подходят для структур и бинарных данных;
- `memcpy()` — стандартный способ переинтерпретации представления одного типа как другого (type punning): копирование байтов объекта в объект другого типа минует правила псевдонимов.

Пример:

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    int src[4] = {1, 2, 3, 4};
    int dest[4];

    memcpy(dest, src, sizeof(src)); // Копирование 16 байт (4 элемента int)
    printf("dest[2]: %d\n", dest[2]); // dest[2]: 3

    // Сдвиг блока вправо — области перекрываются, нужен memmove
    int arr[5] = {1, 2, 3, 4, 5};
    memmove(arr + 1, arr, 4 * sizeof(int));
    printf("arr[0]: %d, arr[1]: %d\n", arr[0], arr[1]); // arr[0]: 1, arr[1]: 1

    return 0;
}
```

>[!WARNING]
>Если области `dest` и `src` могут перекрываться, используйте только `memmove()`. Применение `memcpy()` к перекрывающимся областям — неопределённое поведение, которое на практике проявляется как повреждение данных.

>[!NOTE]
>`memcpy()` при отсутствии перекрытия работает быстрее `memmove()`: последняя вынуждена копировать безопасно (например, проверять направление или использовать временный буфер). Используйте `memmove()` только при реальном перекрытии — например, при сдвиге элементов массива вправо или влево.

Пример — переинтерпретация представления `float` как целого (`memcpy()` как type punning):

```c
#include <stdio.h>
#include <string.h>
#include <stdint.h>

int main(void)
{
    float f = 1.5f;
    uint32_t bits;

    memcpy(&bits, &f, sizeof(bits)); // Копируем байты float в целое
    printf("%08X\n", bits);          // 3FC00000

    return 0;
}
```

### 2.2. Функции strcpy и strncpy

Функции `strcpy()` и `strncpy()` копируют строку (включая завершающий нулевой байт):

```c
char *strcpy(char *dest, const char *src);
char *strncpy(char *dest, const char *src, size_t n);
```

Поведение:

- `strcpy()` копирует строку `src` целиком в `dest` и возвращает `dest`. Буфер `dest` должен быть достаточно большим — иначе неопределённое поведение (запись за границы);
- `strncpy()` копирует не более `n` символов. Если `src` короче `n`, строка дополняется нулевыми байтами; если `src` длиннее `n`, завершающий нуль **не записывается** — строка в `dest` не завершается.

Пример и ловушка `strncpy()`:

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char dest[8];

    strcpy(dest, "привет"); // Полное копирование с завершающим нулём

    char truncated[4];
    strncpy(truncated, "привет", 3); // Копируем ровно 3 символа
    truncated[3] = '\0';             // Нуль вручную — иначе UB при печати

    printf("%s\n", dest);      // привет
    printf("%s\n", truncated); // при

    return 0;
}
```

>[!WARNING]
>`strncpy()` не гарантирует завершающий нуль: если исходная строка не короче `n`, результат не будет строкой. Всегда проверяйте или дописывайте `'\0'` вручную.

Сравнение функций копирования строк:

| Функция | Копирует | Завершающий нуль | Остаток буфера |
|---|---|---|---|
| `strcpy()` | всю строку | всегда записывает | не трогается |
| `strncpy()` | не более `n` символов | только если `src` короче `n` | дополняется нулевыми байтами |

>[!NOTE]
>Обнуление остатка в `strncpy()` — историческое поведение для полей фиксированной длины: некоторые форматы требуют строго `n` байт с нулевой «набивкой». Для обычного копирования строк это лишь дополнительная работа.

Пример — копирование в поле фиксированной длины с гарантированным нулём:

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char field[6] = {0}; // Поле фиксированной длины

    strncpy(field, "hello world", sizeof(field) - 1); // Оставляем место под нуль
    printf("%s\n", field); // hello

    return 0;
}
```

>[!NOTE]
>Для строк с произвольной длиной вместо связки `strncpy()` + ручной нуль проще воспользоваться `strdup()`/`strndup()` (подраздел 2.4), которые сами выделяют память нужного размера.

### 2.3. Функции strcat и strncat

Функции `strcat()` и `strncat()` дописывают строку в конец другой строки:

```c
char *strcat(char *dest, const char *src);
char *strncat(char *dest, const char *src, size_t n);
```

Поведение:

- `strcat()` находит завершающий нуль в `dest` и дописывает с этого места строку `src` (вместе с нулём). Буфер должен вмещать результат — иначе неопределённое поведение;
- `strncat()` дописывает не более `n` символов и **всегда** добавляет завершающий нуль (в отличие от `strncpy()`);
- обе возвращают `dest`. Области `dest` и `src` не должны перекрываться.

Пример:

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char message[32] = "Hello, ";
    strcat(message, "world");
    printf("%s\n", message); // Hello, world

    char line[16] = "C";
    size_t remaining = sizeof(line) - strlen(line) - 1; // Место под дописывание
    strncat(line, " language", remaining);              // и завершающий нуль
    printf("%s\n", line);                               // C language

    return 0;
}
```

>[!WARNING]
>Параметр `n` в `strncat()` — максимум **дописываемых** символов, а не размер буфера `dest`. Передача `sizeof(dest)` вместо `n` — классическая ошибка: при длинном `dest` свободного места не останется, и строка всё равно выйдет за границы. Правильно вычислять свободное место: `sizeof(dest) - strlen(dest) - 1`.

>[!NOTE]
>Каждый вызов `strcat()` заново проходит `dest` до завершающего нуля, поэтому поочерёдное дописывание фрагментов в цикле выполняется за квадратичное время. Чтобы построить строку за линейное время, держат указатель на текущий конец строки и сдвигают его после каждого дописывания.

>[!NOTE]
>`strcat()` и `strcpy()` не проверяют размер буфера: безопасность целиком на программисте. Более безопасные альтернативы — `strncat()`, `strncpy()` (с ручным дописыванием нуля) или версии с суффиксом `_s` из C11 (см. раздел 9).

### 2.4. Функции strdup и strndup

Функции `strdup()` и `strndup()` создают динамическую копию строки, выделяя память в куче:

```c
char *strdup(const char *s);      // C23
char *strndup(const char *s, size_t n); // C23
```

Поведение:

- `strdup()` выделяет память, достаточно большую для строки `s` (вместе с завершающим нулём), копирует её и возвращает указатель на копию; по сути это `malloc(strlen(s) + 1)` с последующим копированием;
- `strndup()` копирует не более `n` символов: если строка короче `n`, копируется вся строка с завершающим нулём; если длиннее — ровно `n` символов, после которых добавляется завершающий ноль; `strndup(s, 0)` возвращает пустую строку;
- при нехватке памяти обе функции возвращают `NULL` (в POSIX при этом дополнительно устанавливается `errno` в `ENOMEM`; стандарт C такого требования не содержит);
- возвращённую память необходимо освобождать с помощью `free()` (см. [[Языки программирования/C/Глава 7. Динамическая память|главу о динамической памяти]]);
- копия удобна, когда строку требуется изменить (например, передать в `strtok()`), не трогая исходный литерал.

Пример:

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    const char* source = "привет";
    char* copy = strdup(source);
    if (copy != NULL) {
        printf("%s\n", copy); // привет
        free(copy);
    }

    char* part = strndup("abcdef", 3);
    if (part != NULL) {
        printf("%s\n", part); // abc
        free(part);
    }

    return 0;
}
```

>[!NOTE]
>До стандарта C23 `strdup()`/`strndup()` были функциями POSIX, объявленными в `<string.h>`; в C23 они вошли в стандартную библиотеку C.

## 3. Сравнение строк и памяти

Функции сравнения возвращают значение < 0, 0 или > 0:

```c
int memcmp(const void *s1, const void *s2, size_t n);
int strcmp(const char *s1, const char *s2);
int strncmp(const char *s1, const char *s2, size_t n);
```

Поведение:

- `memcmp()` сравнивает первые `n` байт блоков памяти как беззнаковые байты;
- `strcmp()` сравнивает строки лексикографически (по значению беззнаковых символов) до первого различающегося символа или до завершающих нулей; нулевой символ меньше любого другого;
- `strncmp()` сравнивает не более `n` символов — удобно для сравнения строк по количеству символов.

Пример:

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    printf("%d\n", strcmp("abc", "abd")); // отрицательное (c < d)
    printf("%d\n", strcmp("abc", "abc")); // 0
    printf("%d\n", strcmp("abd", "abc")); // положительное

    printf("%d\n", strncmp("abc", "abz", 2)); // 0: первые 2 символа равны

    int a = 0x0102, b = 0x0103;
    printf("%d\n", memcmp(&a, &b, sizeof(int))); // отрицательное

    return 0;
}
```

>[!NOTE]
>Сравнение строк работает побайтово и не учитывает локаль: символы в кодировке UTF-8 сравниваются по значениям байтов. Для сравнения в соответствии с локалью используются `strcoll()` и `strxfrm()` (раздел 4).

## 4. Сравнение по локали. strcoll и strxfrm

Функции `strcmp()` и `strncmp()` сравнивают строки побайтово: порядок определяется кодами символов, а не языковыми правилами. Функции `strcoll()` и `strxfrm()` учитывают правила сортировки (колляции) текущей локали — категорию `LC_COLLATE`:

```c
int strcoll(const char *s1, const char *s2);
size_t strxfrm(char *dest, const char *src, size_t n);
```

Поведение `strcoll()`:

- возвращает значение того же смысла, что и `strcmp()`: меньше нуля, если `s1` сортируется раньше `s2`, 0 при равенстве и больше нуля, если позже;
- сравнивает строки целиком по правилам сортировки локали, которые могут отличаться от порядка кодов символов:
  - регистр: «а» и «А» часто располагаются рядом, независимо от значений кодов;
  - диакритика: «ä», «á», «à» могут группироваться с «a»;
  - составные буквы: в некоторых локалях «ch» и «ll» считаются отдельными буквами алфавита;
- разбирает многобайтовые строки (например, UTF-8) по правилам локали, а не по отдельным байтам;
- если локаль не установлена, ведёт себя как `strcmp()`.

Поведение `strxfrm()`:

- преобразует строку `src` в «форму сравнения»: для любых двух строк результат `strcmp(strxfrm(a), strxfrm(b))` эквивалентен вызову `strcoll(a, b)`;
- записывает в `dest` не более `n` байт (вместе с завершающим нулём); если преобразованная строка не поместилась, содержимое `dest` не определено;
- возвращает длину, которая потребовалась бы без ограничения `n` (в байтах, без учёта завершающего нуля): если возвращённое значение не меньше `n`, строка в буфер не поместилась;
- при `n` равном 0 функция лишь возвращает требуемую длину, а содержимое `dest` не определяется;
- областью `dest` и `src` перекрываться не должны (неопределённое поведение).

Сравнение способов упорядочивания строк:

| Функция | Правила сравнения | Где применяется |
|---|---|---|
| `strcmp()`/`strncmp()` | порядок байтов | быстрые сравнения без локали: ключи, имена, префиксы |
| `strcoll()` | колляция `LC_COLLATE` | «человеческая» сортировка небольшого числа строк |
| `strxfrm()` | колляция `LC_COLLATE`; результат сравнивается `strcmp()` | сортировка многих строк: ключ строится один раз |

Пример — разница между побайтовым и локализованным сравнением:

```c
#include <stdio.h>
#include <string.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, ""); // Включаем локаль

    printf("strcmp:  %d\n", strcmp("ä", "z"));  // сравнение по кодам байтов
    printf("strcoll: %d\n", strcoll("ä", "z")); // по правилам сортировки локали

    return 0;
}
```

>[!NOTE]
>Если локаль не установлена (по умолчанию `"C"`), `strcoll()` ведёт себя как `strcmp()`.

>[!NOTE]
>Результат зависит от установленной локали: одна и та же пара строк может упорядочиваться по-разному в разных локалях (например, `ru_RU.UTF-8` и `de_DE.UTF-8`).

Пример — сортировка массива строк по правилам локали: ключ `strxfrm()` строится один раз для каждой строки, затем ключи сортируются обычным `strcmp()`:

```c
#include <stdio.h>
#include <string.h>
#include <locale.h>
#include <stdlib.h>

struct entry {
    const char* word;
    char key[64]; // Форма для сравнения через strcmp
};

int compare_entries(const void* a, const void* b) {
    const struct entry* ea = a;
    const struct entry* eb = b;
    return strcmp(ea->key, eb->key);
}

int main(void)
{
    setlocale(LC_ALL, ""); // Включаем локаль

    struct entry entries[] = {
        { "Äpfel", "" },
        { "zebra", "" },
        { "ananas", "" },
        { "árbol", "" }
    };
    size_t count = sizeof(entries) / sizeof(entries[0]);

    for (size_t i = 0; i < count; i++) {
        size_t len = strxfrm(entries[i].key, entries[i].word, sizeof(entries[i].key));
        if (len >= sizeof(entries[i].key)) {
            printf("Ключ для «%s» не поместился в буфер\n", entries[i].word);
        }
    }

    qsort(entries, count, sizeof(struct entry), compare_entries);

    for (size_t i = 0; i < count; i++) {
        printf("%s\n", entries[i].word);
    }

    return 0;
}
```

>[!NOTE]
>Одноразовое преобразование ключей оправдано при сортировке множества строк: `strcoll()` при каждом сравнении заново разбирает обе строки по правилам локали, тогда как `strcmp()` по готовым ключам работает значительно быстрее.

## 5. Поиск в строках

Функции поиска символа или подстроки:

```c
void *memchr(const void *s, int c, size_t n);
char *strchr(const char *s, int c);
char *strrchr(const char *s, int c);
char *strstr(const char *haystack, const char *needle);
char *strpbrk(const char *s1, const char *s2);
size_t strspn(const char *s1, const char *s2);
size_t strcspn(const char *s1, const char *s2);
```

Поведение `memchr()`:

- ищет байт `c` среди первых `n` байт блока памяти; значение `c` приводится к типу `unsigned char`;
- возвращает указатель на первое вхождение или `NULL`, если байт не найден;
- работает с произвольными данными — не требует завершающего нуля, поэтому подходит для бинарных блоков и структур.

Поведение `strchr()` и `strrchr()`:

- `strchr()` возвращает указатель на **первое** вхождение символа `c` в строке, `strrchr()` — на **последнее**; если символа нет, возвращается `NULL`;
- вхождение завершающего нуля считается: `strchr(s, '\0')` всегда возвращает указатель на конец строки;
- возвращаемый указатель указывает **внутрь** исходной строки, а не на копию: запись через него изменяет строку.

Поведение `strstr()`:

- возвращает указатель на первое вхождение подстроки `needle` в строке `haystack` или `NULL`, если подстрока не найдена;
- если `needle` — пустая строка, возвращается `haystack`;
- подстрока ищется целиком: `strstr("abcab", "cab")` находит вхождение в позиции 2;
- стандарт не ограничивает сложность алгоритма, поэтому в большинстве реализаций поиск выполняется «наивно» и для длинных строк может работать медленнее специализированных алгоритмов.

Поведение `strpbrk()`:

- возвращает указатель на первый символ строки `s1`, который встречается в наборе `s2` (значение символа из `s2` приводится к `char`), или `NULL`, если таких символов нет;
- удобна для поиска первого разделителя без модификации строки (в отличие от `strtok()`, раздел 6).

Поведение `strspn()` и `strcspn()`:

- `strspn()` возвращает длину начального сегмента `s1`, состоящего **только** из символов набора `s2`; если первый же символ не входит в набор, возвращает 0;
- `strcspn()` возвращает длину начального сегмента `s1`, в котором **нет** ни одного символа из набора `s2`; если первый же символ входит в набор, возвращает 0;
- обе возвращают длину в байтах, а не указатель; сумма `strspn(s1, s2) + strcspn(s1, s2)` не обязана равняться длине строки.

Сводка по возвращаемым значениям:

| Функция | Ищет | Возвращает | Если не найдено |
|---|---|---|---|
| `memchr()` | байт в ограниченном блоке памяти | указатель на вхождение | `NULL` |
| `strchr()` | первый символ | указатель на вхождение | `NULL` |
| `strrchr()` | последний символ | указатель на вхождение | `NULL` |
| `strstr()` | подстроку | указатель на вхождение | `NULL` |
| `strpbrk()` | первый символ из набора | указатель на вхождение | `NULL` |
| `strspn()` | символы из набора в начале | длина начального сегмента | 0 |
| `strcspn()` | символы не из набора в начале | длина начального сегмента | 0 |

Пример — базовое использование:

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char* text = "Hello, world!";

    printf("%s\n", strchr(text, 'o'));   // o, world! (с первого вхождения)
    printf("%s\n", strrchr(text, 'o'));  // orld!
    printf("%s\n", strstr(text, "wor")); // world!
    printf("%s\n", strpbrk(text, ",!")); // , world! (первый символ из набора)

    printf("%zu\n", strspn("abcxyz", "abc"));  // 3 (все символы из набора)
    printf("%zu\n", strcspn("xyzabc", "abc")); // 3 (до первого символа набора)

    return 0;
}
```

Пример — выделение имени файла из пути через `strrchr()`:

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char* path = "/home/user/docs/report.txt";

    const char* slash = strrchr(path, '/');
    const char* filename = (slash != NULL) ? slash + 1 : path;

    printf("%s\n", filename); // report.txt

    return 0;
}
```

Пример — поиск данных в бинарном блоке через `memchr()`:

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char data[] = {0x10, 0x00, 0xFF, 0x10, 0x20};

    void* found = memchr(data, 0x10, sizeof(data));
    if (found != NULL) {
        printf("Байт 0x10 найден на позиции %td\n",
               (char*)found - data); // позиция 0
    }

    return 0;
}
```

Пример — разбиение строки на части по разделителям без её модификации (пары `strcspn()`/`strpbrk()`):

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char* str = "key1=value1;key2=value2";
    const char* rest = str;

    while (*rest != '\0') {
        size_t name_len = strcspn(rest, "=;");
        printf("ключ: %.*s\n", (int)name_len, rest);
        rest += name_len;

        if (*rest == '=') {
            rest++;
            size_t value_len = strcspn(rest, ";");
            printf("значение: %.*s\n", (int)value_len, rest);
            rest += value_len;
        }

        if (*rest == ';') {
            rest++;
        }
    }

    return 0;
}
```

>[!NOTE]
>Все функции возвращают указатели **внутрь** исходной строки: они не создают копий. Изменение символа по возвращённому указателю меняет исходную строку.

>[!NOTE]
>Символ для `strchr()`/`strrchr()` принимается как `int`, но в сравнении участвует только его младший байт (значение типа `char`). Это позволяет передавать, например, `'\0'` — поиск конца строки.

## 6. Разбиение на токены. strtok

Функция `strtok()` разбивает строку на токены по разделителям:

```c
char *strtok(char *str, const char *delim);
```

Поведение:

- при первом вызове `str` — строка для разбора; при последующих вызовах передаётся `NULL`, и функция продолжает разбор с того места, где остановилась (состояние хранится внутри функции);
- `delim` — строка, содержащая символы-разделители (каждый символ из неё считается разделителем);
- возвращает указатель на очередной токен или `NULL`, когда токены закончились;
- разделители заменяются нулевыми байтами — исходная строка модифицируется.

Пример:

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char line[] = "apple,banana;cherry";
    char* token = strtok(line, ",;"); // Разделители: запятая и точка с запятой

    while (token != NULL) {
        printf("%s\n", token); // apple, banana, cherry
        token = strtok(NULL, ",;");
    }

    return 0;
}
```

>[!WARNING]
>`strtok()` не потокобезопасна: состояние разбора хранится в статической переменной, поэтому два параллельных разбора конфликтуют. Альтернативы — `strtok_r()` (POSIX, состояние передаётся параметром) или собственная реализация.

>[!NOTE]
>Передавать строковый литерал в `strtok()` нельзя: функция модифицирует строку, а литералы в C неизменяемы. Копируйте строку в массив (как в примере) или в память из `malloc()`.

## 7. Длина строки. strlen и strnlen

Функции `strlen()` и `strnlen()` возвращают длину строки в байтах:

```c
size_t strlen(const char *s);
size_t strnlen(const char *s, size_t maxlen); // C11
```

Поведение:

- `strlen()` считает символы до завершающего нуля (сам нуль не учитывается). Если в строке нет нуля — неопределённое поведение (функция выйдет за границы);
- `strnlen()` возвращает длину, но не более `maxlen` — безопасна для буферов без гарантированного завершения.

Пример:

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char buf[8] = "hello";

    printf("%zu\n", strlen(buf));  // 5
    printf("%zu\n", strnlen(buf, sizeof(buf))); // 5

    char no_term[8];
    memset(no_term, 'a', sizeof(no_term)); // Нет завершающего нуля
    printf("%zu\n", strnlen(no_term, sizeof(no_term))); // 8 — безопасно

    return 0;
}
```

>[!NOTE]
>`strlen()` считает именно байты, а не символы: для строки в UTF-8 она вернёт количество байтов, которое для кириллицы вдвое больше числа символов. Подробнее строки рассматриваются в уроке [[Языки программирования/C/Глава 9. Стандартная библиотека C/2. Работа со строками|«Работа со строками»]].

## 8. Сообщения об ошибках. strerror

Функция `strerror()` возвращает текстовое описание ошибки по её коду:

```c
char *strerror(int errnum);
```

Поведение:

- `errnum` — код ошибки, обычно значение `errno` (например, `ERANGE` из `<errno.h>`);
- возвращается указатель на строку описания; строка не должна изменяться;
- возвращаемый буфер статический — повторный вызов может перезаписать предыдущий результат, а параллельные вызовы из потоков конфликтуют (альтернатива в POSIX — `strerror_r()`).

Пример:

```c
#include <stdio.h>
#include <string.h>
#include <errno.h>

int main(void)
{
    FILE* file = fopen("missing.txt", "r");
    if (file == NULL) {
        printf("Ошибка %d: %s\n", errno, strerror(errno));
    }

    return 0;
}
```

>[!NOTE]
>Значения `errno` не устанавливаются функциями `<string.h>` — `strerror()` лишь переводит уже полученный код в текст.

## 9. Безопасные версии функций (C11)

Стандарт C11 (приложение Annex K) добавляет безопасные версии функций с суффиксом `_s`, которые принимают размер буфера и проверяют его, возвращая код ошибки вместо неопределённого поведения:

```c
errno_t strcpy_s(char *dest, rsize_t destsz, const char *src);
errno_t strcat_s(char *dest, rsize_t destsz, const char *src);
errno_t strncpy_s(char *dest, rsize_t destsz, const char *src, rsize_t count);
errno_t memcpy_s(void *dest, rsize_t destsz, const void *src, rsize_t count);
```

Особенности:

- при нарушении ограничений (малый буфер, `NULL`, перекрытие) функция не выполняет запись и возвращает ненулевой код ошибки;
- доступны только если реализация объявляет поддержку Annex K (макрос `__STDC_LIB_EXT1__`); многие компиляторы (GCC, Clang) эти функции **не** предоставляют — на Linux их аналогами служат POSIX-функции `strlcpy()`/`strlcat()` или собственные проверки.

>[!WARNING]
>Не полагайтесь на `_s`-версии без проверки поддержки: в GCC/Clang их нет, а код, написанный под них, не соберётся. Переносимое решение — ручные проверки размеров или `strncpy()`/`strncat()` с явным дописыванием нуля.

## 10. Резюме

1. Копирование: `memcpy` (без перекрытий), `memmove` (с перекрытиями), `strcpy`, `strncpy` (нуль не гарантируется), `strcat`, `strncat` (нуль дописывается всегда), динамические копии `strdup`/`strndup` (C23).
2. Сравнение: `memcmp`, `strcmp`, `strncmp` — побайтовое; `strcoll`, `strxfrm` — по локали.
3. Поиск: `memchr`, `strchr`, `strrchr`, `strstr`, `strpbrk`, `strspn`, `strcspn`.
4. Разбиение: `strtok` (модифицирует строку, не потокобезопасна).
5. Длина: `strlen`, `strnlen`.
6. Ошибки: `strerror`.
7. Безопасные версии `_s` (C11/Annex K) поддерживаются не всеми компиляторами.
