## Прототип

```c
#include <stdlib.h>

long long llabs(long long n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `n` | Целое число |

## Возвращаемое значение

Абсолютное значение аргумента (модуль числа).

## Что делает

Возвращает модуль числа для типа `long long`. Для `LLONG_MIN` результат не помещается в `long long` — поведение не определено (в glibc возвращается `LLONG_MIN`).

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    printf("%lld\n", llabs(-9223372036854775807LL - 1LL)); // LLONG_MIN — неопределённое поведение!
    printf("%lld\n", llabs(42LL));                         // 42

    return 0;
}
```

>[!WARNING]
>`llabs(LLONG_MIN)` — неопределённое поведение: модуль наименьшего значения `long long` не представим в `long long`.

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и быстрая | Неопределённое поведение для `LLONG_MIN` |
