## Прототип

```c
#include <stdlib.h>

double strtod(const char *restrict str, char **restrict endptr);
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | Строка для преобразования |
| `endptr` | Указатель на место для записи указателя на первый нераспознанный символ (или `NULL`) |

## Возвращаемое значение

Преобразованное значение или 0, если ничего не распознано.

## Что делает

Преобразует строку в `double`. Пропускает ведущие пробельные символы, затем разбирает необязательный знак, десятичное число с точкой, экспоненту `e`/`E`, а также `INF`/`INFINITY`/`NAN` (в любом регистре, `NAN` может иметь `(последовательность)`). В `*endptr` записывается указатель на первый символ, не участвовавший в разборе. При переполнении возвращает `±HUGE_VAL` и устанавливает `errno = ERANGE`; при потере точности (subnormal/нуль) — также `ERANGE`. При невозможности разбора возвращает 0 и устанавливает `*endptr = str`.

## Примеры

```c
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char *s = "  3.14 остаток";
    char *end;

    errno = 0;
    double d = strtod(s, &end);
    if (errno == ERANGE) {
        printf("Переполнение\n");
    } else {
        printf("%g; хвост: %s\n", d, end); // 3.14; хвост: " остаток"
    }

    return 0;
}
```

## Ошибки и errno

Устанавливает `errno = ERANGE` при переполнении или потере значимости. Для полной проверки сбрасывайте `errno` перед вызовом: `errno = 0; strtod(...)`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Полный разбор с позицией остановки | Нужно проверять `endptr` и `errno` |
| Обработка переполнения через `ERANGE` | Пустая строка и 0 неотличимы без `endptr` |

## Альтернативы

- **`strtof()`** — для `float`
- `strtold()` — для `long double`
- `atof()` — без проверок ошибок (проще, но опаснее)
