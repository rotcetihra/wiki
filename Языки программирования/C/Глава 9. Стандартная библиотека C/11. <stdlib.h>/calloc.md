## Прототип

```c
#include <stdlib.h>

void *calloc(size_t nmemb, size_t size);
```

## Параметры

| Параметр | Описание |
|---|---|
| `nmemb` | Количество элементов |
| `size` | Размер одного элемента в байтах |

## Возвращаемое значение

Указатель на начало блока из `nmemb × size` байт или `NULL` при неудаче.

## Что делает

Выделяет память и обнуляет её (все биты равны нулю). Отличается от `malloc()` тем, что память гарантированно заполнена нулями. Если `nmemb` или `size` равно нулю, поведение зависит от реализации: либо возвращается `NULL`, либо уникальный указатель, который нельзя разыменовывать (но можно передать в `free()`). При переполнении `nmemb × size` (размер не помещается в `size_t`) память не выделяется и возвращается `NULL` — glibc это проверяет.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *arr = calloc(10, sizeof(int));
    if (arr == NULL) {
        return 1;
    }

    printf("%d\n", arr[0]); // 0 — память обнулена
    printf("%d\n", arr[9]); // 0

    free(arr);
    return 0;
}
```

## Ошибки и errno

При неудаче возвращает `NULL` и устанавливает `errno = ENOMEM`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Память гарантированно обнулена | Обнуление требует времени — медленнее `malloc()` |
| Проверка переполнения `nmemb × size` | `NULL` при `nmemb == 0 && size == 0` — поведение зависит от реализации |

## Альтернативы

- **`malloc()` + явное обнуление** (например, `memset()`) — когда хочется контролировать, когда занулять
- `realloc()` — когда память уже выделена
