## Прототип

```c
#include <stdlib.h> // C11

int at_quick_exit(void (*func)(void));
```

## Параметры

| Параметр | Описание |
|---|---|
| `func` | Указатель на функцию без параметров, вызываемую при `quick_exit()` |

## Возвращаемое значение

0 при успешной регистрации, ненулевое значение, если зарегистрировать больше нельзя (лимит — не менее 32 функций).

## Что делает

Регистрирует функцию, которая будет вызвана при завершении программы через `quick_exit()`, в порядке, обратном порядку регистрации. Аналог `atexit()`, но для быстрого завершения: функции вызываются без ожидания «тяжёлой» уборки (сброса буферов, закрытия потоков).

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

void cleanup(void)
{
    printf("Быстрая очистка\n");
}

int main(void)
{
    at_quick_exit(cleanup);
    quick_exit(EXIT_SUCCESS); // вывод: «Быстрая очистка»
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простой способ «быстрой» очистки ресурсов | Функций ограниченное количество (не менее 32) |
| Не зависит от состояния потоков ввода-вывода | Вызовы выполняются без гарантий порядка с внешними действиями |

## Альтернативы

- **`atexit()`** — регистрация для `exit()` (с полной «уборкой»)
