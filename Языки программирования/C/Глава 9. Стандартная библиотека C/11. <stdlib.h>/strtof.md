## Прототип

```c
#include <stdlib.h>

float strtof(const char *restrict str, char **restrict endptr);
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | Строка для преобразования |
| `endptr` | Указатель на место для записи указателя на первый нераспознанный символ (или `NULL`) |

## Возвращаемое значение

Преобразованное значение или 0, если ничего не распознано.

## Что делает

Аналог `strtod()` для типа `float`. Правила разбора те же: пробелы, знак, десятичная точка, экспонента, `INF`/`NAN`. При переполнении возвращает `±HUGE_VALF` и устанавливает `errno = ERANGE`. Доступна с C99. В C23 правила округления при сужении до `float` — по текущему режиму округления.

## Примеры

```c
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char *s = "-2.5e2";
    char *end;

    errno = 0;
    float f = strtof(s, &end);
    if (errno == ERANGE) {
        printf("Переполнение\n");
    } else {
        printf("%g; хвост: %s\n", f, end); // -250; хвост: ""
    }

    return 0;
}
```

## Ошибки и errno

Устанавливает `errno = ERANGE` при переполнении или потере значимости. Для полной проверки сбрасывайте `errno` перед вызовом.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Полный разбор с позицией остановки | Нужно проверять `endptr` и `errno` |
| Обработка переполнения через `ERANGE` | Пустая строка и 0 неотличимы без `endptr` |

## Альтернативы

- **`strtod()`** — для `double`
- `strtold()` — для `long double`
