## Прототип

```c
#include <stdlib.h>

int mblen(const char *s, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Указатель на многобайтовую строку (или `NULL` для сброса состояния) |
| `n` | Максимальное количество байт для анализа |

## Возвращаемое значение

- 0 — если `s` указывает на нулевой байт (`'\0'`);
- число байт в многобайтовом символе (1..n), если символ распознан;
- -1 — если первые `n` байт не образуют полный многобайтовый символ.

## Что делает

Определяет длину первого многобайтового символа в строке (в текущей локали, категория `LC_CTYPE`), не изменяя состояние преобразования. Вызов с `s == NULL` сбрасывает внутреннее состояние и возвращает ненулевое значение, если многобайтовые символы в локали имеют переменную длину (например, UTF-8). В главе 9 многобайтовые строки рассматриваются в статье [[Языки программирования/C/Глава 9. Стандартная библиотека C/8. Поддержка Unicode и кодировки UTF-8, UTF-16 и UTF-32|«Поддержка Unicode и кодировки UTF-8, UTF-16 и UTF-32»]].

## Примеры

```c
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    setlocale(LC_ALL, ""); // включаем UTF-8

    const char *str = "Привет";
    if (str[0] != '\0') {
        int len = mblen(str, MB_CUR_MAX);
        printf("%d\n", len); // 2 — «П» в UTF-8 занимает 2 байта
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простой способ определить длину символа | Сохраняет внутреннее состояние — небезопасна для многопоточности (нужен `mbrlen()` из `<wchar.h>`) |
| Не модифицирует строку | Работает с одним символом за раз |

## Альтернативы

- **`mbrlen()`** из `<wchar.h>` — потокобезопасный вариант с явным состоянием
- `mbtowc()` — преобразование символа в широкий
