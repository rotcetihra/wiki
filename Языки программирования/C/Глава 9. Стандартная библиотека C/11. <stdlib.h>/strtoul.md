## Прототип

```c
#include <stdlib.h>

unsigned long strtoul(const char *restrict str, char **restrict endptr, int base);
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | Строка для преобразования |
| `endptr` | Указатель на место для записи указателя на первый нераспознанный символ (или `NULL`) |
| `base` | Основание системы счисления (2..36) или 0 для автоопределения |

## Возвращаемое значение

Преобразованное значение или 0, если ничего не распознано.

## Что делает

Аналог `strtol()` для беззнакового типа `unsigned long`. Допускает необязательный знак: минус отрицает результат по правилам беззнаковой арифметики (двухкомплементная обёртка), плюс — игнорируется. При переполнении возвращает `ULONG_MAX` и устанавливает `errno = ERANGE`.

## Примеры

```c
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char *s = "0xFFFFFFFF";
    char *end;

    errno = 0;
    unsigned long v = strtoul(s, &end, 0); // 0x — автоопределение 16
    if (errno == ERANGE) {
        printf("Переполнение\n");
    } else {
        printf("%lu; хвост: %s\n", v, end); // 4294967295; хвост: ""
    }

    return 0;
}
```

## Ошибки и errno

Устанавливает `errno = ERANGE` при переполнении. Для полной проверки сбрасывайте `errno` перед вызовом.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Подходит для беззнаковых значений и битовых масок | Отрицательные числа «оборачиваются» — легко ошибиться |
| Обработка переполнения через `ERANGE` | Нужно проверять `endptr` и `errno` |

## Альтернативы

- **`strtoull()`** — для `unsigned long long`
- `strtol()` — когда нужен знак
