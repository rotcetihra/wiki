## Определение

```c
#include <stdlib.h>

typedef struct {
    long quot; // частное
    long rem;  // остаток
} ldiv_t;
```

## Описание

Тип структуры, возвращаемой функцией `ldiv()`. Поля `quot` и `rem` — частное и остаток от целочисленного деления: `quot * denom + rem == numer`. Аналог `div_t`, но для `long`.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    ldiv_t r = ldiv(170L, 5L);

    printf("%ld %ld\n", r.quot, r.rem); // 34 0

    return 0;
}
```
