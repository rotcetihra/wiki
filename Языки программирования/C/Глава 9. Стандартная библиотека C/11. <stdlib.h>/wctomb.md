## Прототип

```c
#include <stdlib.h>

int wctomb(char *s, wchar_t wc);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Буфер для многобайтового символа (не менее `MB_CUR_MAX` байт; в C23 — `char *`) |
| `wc` | Широкий символ (кодовая точка) |

## Возвращаемое значение

- при `s == NULL`: ненулевое значение, если кодировка локали имеет символы переменной длины;
- при `s != NULL`: количество байт в многобайтовом представлении (1..MB_CUR_MAX), либо -1, если символ не представим в текущей локали.

## Что делает

Преобразует широкий символ в многобайтовый (обратная операция для `mbtowc()`), в текущей локали (категория `LC_CTYPE`). Вызов с `s == NULL` сбрасывает внутреннее состояние. В главе 9 многобайтовые строки рассматриваются в статье [[Языки программирования/C/Глава 9. Стандартная библиотека C/8. Поддержка Unicode и кодировки UTF-8, UTF-16 и UTF-32|«Поддержка Unicode и кодировки UTF-8, UTF-16 и UTF-32»]].

## Примеры

```c
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <wchar.h>

int main(void)
{
    setlocale(LC_ALL, "");

    char buf[MB_CUR_MAX];

    int len = wctomb(buf, L'П');
    if (len < 0) {
        printf("Символ не представим в текущей локали\n");
        return 1;
    }

    buf[len] = '\0';
    printf("%d байт: %s\n", len, buf); // 2 байт: П

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`; об ошибке свидетельствует возврат -1.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая работа с одним символом | Непотокобезопасна (нужен `wcrtomb()` из `<wchar.h>`) |
| | Требует `MB_CUR_MAX`-буфер — легко промахнуться с размером |

## Альтернативы

- **`wcrtomb()`** из `<wchar.h>` — потокобезопасный вариант с явным состоянием
- `mbtowc()` — обратное преобразование
