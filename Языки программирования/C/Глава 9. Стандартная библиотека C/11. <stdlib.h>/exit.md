## Прототип

```c
#include <stdlib.h>

void exit(int status);
```

## Параметры

| Параметр | Описание |
|---|---|
| `status` | Код завершения программы; `EXIT_SUCCESS` (0) — успех, `EXIT_FAILURE` — ошибка |

## Возвращаемое значение

Не возвращает управление.

## Что делает

Завершает программу «штатно»: вызывает функции, зарегистрированные через `atexit()`, в порядке, обратном регистрации, сбрасывает буферы потоков ввода-вывода, закрывает открытые файлы и возвращает управление операционной системе со статусом `status`. Память, выделенная через `malloc()`, не освобождается автоматически — это делает операционная система (поэтому утечки памяти при `exit()` — обычная практика). Терминальные записи в `stdio` буферы сбрасываются.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[])
{
    if (argc < 2) {
        fprintf(stderr, "Ошибка: аргумент не передан\n");
        exit(EXIT_FAILURE);
    }

    printf("Передан аргумент: %s\n", argv[1]);

    return EXIT_SUCCESS;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Полная «уборка»: atexit, сброс буферов | Память не освобождается (это делает ОС) |
| Стандартный способ завершения | Не подходит если нужно вернуть управление в `main` |

## Альтернативы

- **`abort()`** — аварийное завершение без «уборки»
- `_Exit()` — немедленное завершение без «уборки»
- `quick_exit()` — завершение с функциями `at_quick_exit()` (C11)
