## Прототип

```c
#include <stdlib.h>

void qsort(void *base, size_t nmemb, size_t size,
           int (*compar)(const void *, const void *));
```

## Параметры

| Параметр | Описание |
|---|---|
| `base` | Указатель на начало массива |
| `nmemb` | Количество элементов |
| `size` | Размер одного элемента в байтах |
| `compar` | Функция сравнения, возвращающая < 0, 0 или > 0 |

## Возвращаемое значение

Не возвращает значения.

## Что делает

Сортирует массив in-place. Функция `compar` получает указатели на два элемента массива и должна вернуть отрицательное число, если первый «меньше» второго, ноль — если равны, положительное — если «больше». Порядок равных элементов не сохраняется (сортировка нестабильная). Порядок сортировки в C23 формально требует, чтобы `compar` возвращала знак, согласованный с отношением полного порядка — транзитивным и антисимметричным.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int cmp_int(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;
    return (x > y) - (x < y);
}

int main(void)
{
    int arr[] = {3, 1, 4, 1, 5, 9, 2, 6};
    size_t n = sizeof arr / sizeof arr[0];

    qsort(arr, n, sizeof(int), cmp_int);

    for (size_t i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n"); // 1 1 2 3 4 5 6 9

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Сортирует массивы любых типов | Нестабильна (равные элементы меняют порядок) |
| Сложность в среднем O(n·log n) | Вызов функции сравнения через указатель — накладные расходы |

## Альтернативы

- **Собственная сортировка** — когда нужна стабильность или сравнение без указателя на функцию
- `bsearch()` — поиск в отсортированном массиве
