## Прототип

```c
#include <stdlib.h> // C23

int strfromd(char *restrict s, size_t n, const char *restrict format, double value);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Буфер для результата |
| `n` | Размер буфера |
| `format` | Спецификатор формата: `"%f"`, `"%e"`, `"%g"`, `"%a"` (с необязательными модификаторами длины и точностью) |
| `value` | Преобразуемое число |

## Возвращаемое значение

Число символов, которые были бы записаны, если бы буфер был достаточно большим (без учёта завершающего `'\0'`).

## Что делает

Преобразует число с плавающей точкой в строку без локализации: в отличие от `snprintf()`, не зависит от категории `LC_NUMERIC` (всегда используется точка `.` как десятичный разделитель). Не добавляет завершающий ноль, если строка не влезла в `n` байт — результат просто обрезается. Если `n == 0`, в буфер ничего не записывается. Поддерживает форматы `f`, `e`, `g`, `a` (для `%a` — hex-представление). Доступна с C23.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char buf[32];

    int len = strfromd(buf, sizeof buf, "%g", 3.1415926535);
    printf("%s (длина %d)\n", buf, len); // 3.14159 (длина 7)

    strfromd(buf, sizeof buf, "%.2f", 2.7182818);
    printf("%s\n", buf); // 2.72

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Не зависит от локали — предсказуемый вывод | Только три типа: `strfromd`, `strfromf`, `strfroml` (нет ширины/выравнивания) |
| Не переполняет буфер (обрезает) | Не добавляет `'\0'` при обрезке — нужно проверять длину |
| Доступна с C23 | Требует C23-компилятора и библиотеки |

## Альтернативы

- **`snprintf(buf, n, format, value)`** — более гибкий, но зависит от локали
- Ручная сборка через `gcvt()`/`ecvt()` — устаревшие функции glibc
