## Прототип

```c
#include <stdlib.h>

size_t wcstombs(char *restrict dst, const wchar_t *restrict src, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dst` | Буфер для многобайтовой строки (в C23 — `char *`) |
| `src` | Широкая строка (массив `wchar_t`), завершающаяся `L'\0'` |
| `n` | Максимальное количество байт для записи |

## Возвращаемое значение

- число байт в записанной многобайтовой строке (без завершающего `'\0'`), при успехе;
- `(size_t)-1` — если встретился широкий символ, не представимый в текущей локали.

## Что делает

Преобразует широкую строку в многобайтовую (обратная операция для `mbstowcs()`), в текущей локали (категория `LC_CTYPE`). Записывает не более `n` байт и завершает строку нулём (если `dst` не `NULL`). Если `dst == NULL`, возвращает длину, которая понадобилась бы — удобно для оценки размера буфера. В главе 9 многобайтовые строки рассматриваются в статье [[Языки программирования/C/Глава 9. Стандартная библиотека C/8. Поддержка Unicode и кодировки UTF-8, UTF-16 и UTF-32|«Поддержка Unicode и кодировки UTF-8, UTF-16 и UTF-32»]].

>[!WARNING]
>Функция небезопасна при частичном обрезании: если символ не влезает в оставшиеся `n` байт, преобразование завершается без записи неполного символа. Для точной работы с обрезанием используйте `wcsrtombs()` из `<wchar.h>`.

## Примеры

```c
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <wchar.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *wide = L"Привет";
    char multi[32];

    size_t len = wcstombs(multi, wide, sizeof multi);
    if (len == (size_t)-1) {
        printf("Недопустимый символ\n");
        return 1;
    }

    printf("%zu\n", len);   // 12 («Привет» в UTF-8)
    printf("%s\n", multi);  // Привет

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`; об ошибке свидетельствует возврат `(size_t)-1`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гибкое преобразование целых строк | Непотокобезопасна (нужен `wcsrtombs()` из `<wchar.h>`) |
| `dst == NULL` позволяет узнать нужный размер буфера | Обрезание по `n` может оставить недопреобразованную строку |

## Альтернативы

- **`wcsrtombs()`** из `<wchar.h>` — потокобезопасный вариант с явным состоянием
- `mbstowcs()` — обратное преобразование
