## Определение

```c
#include <stddef.h>

typedef unsigned long int size_t; // в glibc на 64-битных системах
```

## Описание

Беззнаковый целочисленный тип результата оператора `sizeof`: размер любого объекта в байтах представим значением `size_t`. Также тип аргументов и результатов функций, работающих с размерами: `strlen()`, `malloc()`, `memset()`, параметров длины `n` в функциях строк и памяти. Максимальное значение — `SIZE_MAX` из `<stdint.h>`. На 64-битных системах занимает 64 бита (`unsigned long`), на 32-битных — 32 (`unsigned int`). Для печати используется спецификатор `%zu`.

## Примеры

```c
#include <stddef.h>
#include <stdio.h>
#include <string.h>

int main(void)
{
    size_t n = strlen("hello");

    printf("%zu\n", n); // 5
    printf("%zu\n", sizeof(int)); // 4 (зависит от платформы)

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантированно вмещает размер любого объекта | Не хранит отрицательные значения: `size_t - 1` — огромное число |
| Тип «по умолчанию» для размеров и индексов | Переполнение без знака незаметно (оборачивание) |
