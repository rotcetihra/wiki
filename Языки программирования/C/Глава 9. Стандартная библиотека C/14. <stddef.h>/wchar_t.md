## Определение

```c
#include <stddef.h>

typedef int wchar_t; // в glibc на Linux
```

## Описание

Тип широкого символа: достаточен для хранения любого символа текущей локали (включая многобайтовые символы локалей с расширенным набором). Реальный размер зависит от платформы: в glibc на Linux — `int` (4 байта, кодировка Unicode/UTF-32), на Windows — 2 байта (UTF-16). Используется с функциями `<wchar.h>` (`wcscpy()`, `wcslen()`, `wprintf()`) и литералами `L"..."`. Для печати используется спецификатор `%lc` (символ) и `%ls` (строка).

## Примеры

```c
#include <locale.h>
#include <stddef.h>
#include <stdio.h>
#include <wchar.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wchar_t s[] = L"привет";
    wprintf(L"%ls — %zu широких символов\n", s, wcslen(s));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Часть стандарта C, есть в любом компиляторе | Размер зависит от платформы (2 или 4 байта) |
| Прямая работа с символами локали | Не фиксированная кодировка: неудобен для Unicode |

## Альтернативы

- `char32_t` / `char16_t` — типы фиксированного размера (C11, `<uchar.h>`)
- `char` + UTF-8 — «узкие» строки в современных программах

## Похожие определения

- В `<stddef.h>` рядом определений нет: функции для `wchar_t` — в `<wchar.h>`
