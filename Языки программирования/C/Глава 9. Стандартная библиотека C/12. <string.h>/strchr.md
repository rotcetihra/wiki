## Прототип

```c
#include <string.h>

char *strchr(const char *s, int c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Указатель на строку для поиска |
| `c` | Искомый символ (приводится к `char` перед сравнением) |

## Возвращаемое значение

Возвращает указатель на первое вхождение символа `c` в строке `s`. Если символ не найден, возвращает `NULL`. Вхождение завершающего нуля считается: `strchr(s, '\0')` всегда возвращает указатель на конец строки.

## Что делает

Ищет первое вхождение символа `c` в завершённой строке `s`. Возвращаемый указатель указывает внутрь исходной строки, а не на копию: запись через него изменяет строку. Символ для поиска принимается как `int`, но в сравнении участвует только его младший байт (значение `char`). Это позволяет передавать, например, `'\0'` — поиск конца строки.

## Примеры

### Базовый поиск символа

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *text = "Hello, world!";
    char *found = strchr(text, 'w');
    if (found != NULL) {
        printf("Найден на позиции: %td\n", found - text); // 7
        printf("Остаток строки: %s\n", found);             // world!
    }
    return 0;
}
```

### Поиск завершающего нуля

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *str = "test";
    char *end = strchr(str, '\0');
    printf("Длина строки: %td\n", end - str); // 4

    return 0;
}
```

### Поиск символа-разделителя

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *line = "user:password:home";
    const char *colon = strchr(line, ':');
    if (colon != NULL) {
        printf("Имя пользователя: %.*s\n", (int)(colon - line), line); // user
    }
    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Если `s` указывает на невалидную память — неопределённое поведение.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и быстрая | Линейная сложность O(n) |
| Возвращает указатель на остаток строки | Не потокобезопасна (модифицирует строку при записи) |
| Стандартная и переносимая | Ищет только первое вхождение |

## Альтернативы

- **`strrchr()`** — поиск последнего вхождения символа
- **`memchr()`** — поиск байта в ограниченном блоке памяти
- **`strstr()`** — поиск подстроки (для строк длиннее 1 символа)
