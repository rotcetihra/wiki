## Прототип

```c
#include <string.h>

int strcoll(const char *s1, const char *s2);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1` | Первая строка для сравнения |
| `s2` | Вторая строка для сравнения |

## Возвращаемое значение

Возвращает значение < 0, если `s1` сортируется раньше `s2`; 0 при равенстве; > 0, если `s1` сортируется позже. Значение того же смысла, что и у `strcmp()`.

## Что делает

Сравнивает строки по правилам сортировки (колляции) текущей локали — категории `LC_COLLATE`. В отличие от `strcmp()`, учитывает языковые правила:

- **Регистр**: «а» и «А» часто располагаются рядом
- **Диакритика**: «ä», «á», «à» могут группироваться с «a»
- **Составные буквы**: в некоторых локалях «ch» и «ll» считаются отдельными буквами алфавита
- **Многобайтовые символы**: строки UTF-8 разбираются по правилам локали, а не по отдельным байтам

Если локаль не установлена (по умолчанию `"C"`), ведёт себя как `strcmp()`.

## Примеры

### Разница между побайтовым и локализованным сравнением

```c
#include <stdio.h>
#include <string.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    printf("strcmp:  %d\n", strcmp("ä", "z"));  // по кодам байтов
    printf("strcoll: %d\n", strcoll("ä", "z")); // по правилам локали

    return 0;
}
```

### Сортировка массива строк

```c
#include <stdio.h>
#include <string.h>
#include <locale.h>
#include <stdlib.h>

int compare(const void *a, const void *b)
{
    return strcoll(*(const char **)a, *(const char **)b);
}

int main(void)
{
    setlocale(LC_ALL, "");

    const char *words[] = {"Äpfel", "zebra", "ananas", "árbol"};
    size_t n = sizeof(words) / sizeof(words[0]);

    qsort(words, n, sizeof(char *), compare);

    for (size_t i = 0; i < n; i++) {
        printf("%s\n", words[i]);
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Неопределённое поведение возникает при обращении по невалидным указателям.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Учитывает правила сортировки локали | Медленнее `strcmp()` (разбор по правилам локали) |
| Результат можно использовать в `qsort()` | Результат зависит от установленной локали |
| Стандартная и переносимая | |

## Альтернативы

- **`strcmp()`** — быстрое побайтовое сравнение без локали
- **`strxfrm()`** + `strcmp()` — ключ строится один раз, потом сравнение быстрое
- **`strcoll_l()`** (POSIX) — сравнение с указанной локалью
