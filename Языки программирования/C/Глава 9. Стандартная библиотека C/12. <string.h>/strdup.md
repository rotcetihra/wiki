## Прототип

```c
#include <string.h>

char *strdup(const char *s); // C23
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Строка для дублирования |

## Возвращаемое значение

Возвращает указатель на динамически выделенную копию строки `s`. При нехватке памяти возвращает `NULL` (в POSIX при этом устанавливается `errno` в `ENOMEM`; стандарт C такого требования не содержит). Вызывающий обязан освободить память через `free()`.

## Что делает

Выделяет память через `malloc()`, достаточную для строки `s` (вместе с завершающим нулём), копирует её и возвращает указатель на копию. По сути это `malloc(strlen(s) + 1)` с последующим копированием. Копия удобна, когда строку требуется изменить (например, передать в `strtok()`), не трогая исходный литерал.

> [!NOTE]
>До стандарта C23 функция `strdup()` была функцией POSIX, объявленной в `<string.h>`. В C23 она вошла в стандартную библиотеку C.

## Примеры

### Базовое дублирование

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    const char *source = "привет";
    char *copy = strdup(source);
    if (copy != NULL) {
        printf("%s\n", copy); // привет
        free(copy);
    }

    return 0;
}
```

### Дублирование для модификации

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    const char *original = "hello world";
    char *modified = strdup(original);
    if (modified != NULL) {
        modified[0] = 'H'; // Модифицируем копию
        printf("%s\n", modified); // Hello world
        free(modified);
    }

    return 0;
}
```

### Сохранение строки из временного буфера

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    char buf[64];
    snprintf(buf, sizeof(buf), "%s_%d", "config", 42);

    char *saved = strdup(buf);
    if (saved != NULL) {
        printf("Сохранено: %s\n", saved); // config_42
        free(saved);
    }

    return 0;
}
```

## Ошибки и errno

- Возвращает `NULL` при нехватке памяти
- В POSIX устанавливает `errno` в `ENOMEM`
- Стандарт C не требует установки `errno`

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простое дублирование строки | Требует `free()` — утечка памяти при забывании |
| Позволяет модифицировать копию | В C23 стандартная, до C23 — только POSIX |
| Автоматически вычисляет размер | При нехватке памяти возвращает `NULL` |

## Альтернативы

- **`strndup()`** (C23) — дублирует не более `n` символов
- **`malloc()` + `strcpy()`** — ручное выделение и копирование
- **`realloc()`** — перераспределение существующего блока
