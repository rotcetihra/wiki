## Прототип

```c
#include <string.h>

int memcmp(const void *s1, const void *s2, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1` | Указатель на первый блок памяти |
| `s2` | Указатель на второй блок памяти |
| `n` | Количество байт для сравнения |

## Возвращаемое значение

Возвращает значение < 0, если `s1` меньше `s2`; 0, если блоки равны; > 0, если `s1` больше `s2`. Сравнение побайтовое, каждый байт интерпретируется как `unsigned char`.

## Что делает

Сравнивает первые `n` байт двух блоков памяти побайтово. Работает с произвольными данными — не требует завершающих нулей, поэтому подходит для структур, бинарных данных и сравнения массивов фиксированной длины. Функция не имеет специфических оптимизаций для строк: сравнивает ровно `n` байт даже при встрече нулевого байта.

## Примеры

### Базовое сравнение

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    int a = 0x0102;
    int b = 0x0103;

    int result = memcmp(&a, &b, sizeof(int));
    printf("%d\n", result); // отрицательное (байт 0x02 < 0x03)

    return 0;
}
```

### Сравнение строк как буферов

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *s1 = "abc\0def";
    const char *s2 = "abc\0xyz";

    // Сравниваем первые 4 байта (включая нуль)
    int result = memcmp(s1, s2, 4);
    printf("Первые 4 байта: %d\n", result); // 0: "abc\0" == "abc\0"

    // Сравниваем 7 байтов
    result = memcmp(s1, s2, 7);
    printf("Все 7 байт: %d\n", result); // отрицательное (d < x)

    return 0;
}
```

### Сравнение структур

```c
#include <stdio.h>
#include <string.h>

struct Point {
    int x;
    int y;
    char label[8];
};

int main(void)
{
    struct Point p1 = {1, 2, "A"};
    struct Point p2 = {1, 2, "A"};

    if (memcmp(&p1, &p2, sizeof(struct Point)) == 0) {
        printf("Структуры идентичны\n");
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Нет способа обнаружить ошибку — результат всегда корректен при корректных аргументах.

>[!WARNING]
>Сравнение структур через `memcmp()` ненадёжно: из-за выравнивания компилятор может оставлять «дырки» (padding) между полями, которые содержат неопределённые значения. Две логически равные структуры могут иметь разное побайтовое представление.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Работает с произвольными данными | Не учитывает локаль и кодировку |
| Не требует завершающих нулей | Сравнивает ровно `n` байт (медленнее при раннем отличии) |
| Быстрая (обычно SIMD-оптимизирована) | Padding в структурах может дать ложноотрицательный результат |

## Альтернативы

- **`strcmp()`** — сравнение завершённых строк, останавливается на нуле
- **`strncmp()`** — сравнение строк с ограничением длины
- **`strcoll()`** — сравнение строк с учётом локали
