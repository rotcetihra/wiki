## Прототип

```c
#include <string.h>

int strcmp(const char *s1, const char *s2);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1` | Первая строка для сравнения |
| `s2` | Вторая строка для сравнения |

## Возвращаемое значение

Возвращает значение < 0, если `s1` лексикографически меньше `s2`; 0, если строки равны; > 0, если `s1` больше `s2`. Сравнение побайтовое, каждый символ интерпретируется как `unsigned char`.

## Что делает

Сравнивает строки `s1` и `s2` лексикографически побайтово. Останавливается на первом различающемся символе или на завершающем нуле. Нулевой символ `'\0'` считается меньше любого другого: `"a" < "ab"`. Результат не зависит от локали — это побайтовое сравнение по кодам символов.

## Примеры

### Базовое сравнение

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    printf("%d\n", strcmp("abc", "abd")); // отрицательное (c < d)
    printf("%d\n", strcmp("abc", "abc")); // 0
    printf("%d\n", strcmp("abd", "abc")); // положительное

    return 0;
}
```

### Проверка совпадения строки

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *cmd = "quit";
    if (strcmp(cmd, "quit") == 0) {
        printf("Выход\n");
    }
    return 0;
}
```

### Сортировка строк

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

int compare(const void *a, const void *b)
{
    return strcmp(*(const char **)a, *(const char **)b);
}

int main(void)
{
    const char *words[] = {"banana", "apple", "cherry"};
    size_t n = sizeof(words) / sizeof(words[0]);

    qsort(words, n, sizeof(char *), compare);

    for (size_t i = 0; i < n; i++) {
        printf("%s\n", words[i]); // apple, banana, cherry
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Неопределённое поведение возникает при обращении по невалидным указателям.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и быстрая | Не учитывает локаль и кодировку |
| Стандартная и переносимая | Линейная сложность O(n) |
| Не модифицирует строки | Возвращает только знак, не величину различия |

## Альтернативы

- **`strncmp()`** — сравнение с ограничением длины
- **`strcoll()`** — сравнение с учётом локали
- **`strcasecmp()`** (POSIX) — сравнение без учёта регистра
