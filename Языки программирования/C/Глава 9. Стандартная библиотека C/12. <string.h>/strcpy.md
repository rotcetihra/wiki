## Прототип

```c
#include <string.h>

char *strcpy(char *dest, const char *src);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dest` | Указатель на.destination-буфер, куда копируется строка |
| `src` | Указатель на.source-строку для копирования |

## Возвращаемое значение

Возвращает `dest`.

## Что делает

Копирует строку `src` целиком в `dest` (вместе с завершающим нулём). Буфер `dest` должен быть достаточно большим — иначе неопределённое поведение (запись за границы). Функция не проверяет размер буфера: безопасность целиком на программисте.

## Примеры

### Базовое копирование

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char dest[16];
    strcpy(dest, "Hello");
    printf("%s\n", dest); // Hello

    return 0;
}
```

### Копирование с последующим изменением

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *original = "hello";
    char copy[16];
    strcpy(copy, original);

    // Изменяем копию, оригинал не затронут
    copy[0] = 'H';
    printf("%s -> %s\n", original, copy); // hello -> Hello

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Неопределённое поведение возникает при недостаточном размере буфера `dest` или обращении по невалидным указателям.

>[!WARNING]
>`strcpy()` не проверяет размер буфера `dest`. Если строка `src` длиннее `dest`, происходит переполнение. Используйте `strncpy()` или `strlcpy()` (BSD).

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и быстрая | Не проверяет размер буфера |
| Гарантирует завершающий нуль | Переполнение при длинной строке |
| Стандартная и переносимая | |

## Альтернативы

- **`strncpy()`** — копирует не более `n` символов (но не гарантирует нуль!)
- **`strlcpy()`** (BSD) — безопасное копирование с проверкой размера
- **`strcpy_s()`** (C11 Annex K) — проверка размера, код ошибки
- **`memcpy()`** — копирование блоков памяти с явным указанием размера
