## 1. Введение

Заголовочный файл `<errno.h>` определяет механизм сообщения об ошибках для функций стандартной библиотеки: макрос `errno` (целая переменная) и стандартные коды ошибок `EDOM`, `ERANGE`, `EILSEQ`. В отличие от исключений в языках высокого уровня, об ошибках в C сообщают возвращаемые значения функций, а `errno` уточняет, что именно пошло не так.

Механизм `errno` используют функции преобразования строк в числа (см. [[Языки программирования/C/Глава 9. Стандартная библиотека C/11. <stdlib.h>|<stdlib.h>]]), математические функции (`<math.h>`), функции ввода-вывода (`<stdio.h>`) и другие.

## 2. Переменная errno

`errno` — макрос, разворачивающийся в изменяемое lvalue целочисленного типа:

```c
#include <errno.h>

errno = 0;      // Присваивание значения
if (errno != 0) // Проверка значения
{
}
```

Особенности:

- с `errno` допустимы обычные операции с целыми числами: присваивание, сравнение, инкремент;
- в реализации (например, в glibc) объект скрыт за вызовом функции, возвращающей указатель, но для программы способ скрыт — важна возможность присваивания и чтения;
- в начале работы программы `errno` равен 0; никакая функция не обязана сбрасывать его в ноль, поэтому проверка должна выполняться сразу после вызова.

>[!NOTE]
>`errno` — это макрос, поэтому переопределить его в своём коде нельзя; также до первого использования должен быть включён `<errno.h>`.

## 3. Стандартные коды ошибок

`<errno.h>` определяет макросы-константы. Три из них обязательны для всех реализаций:

| Макрос  | Смысл                      | Где устанавливается                                                |
| :------ | :------------------------- | :----------------------------------------------------------------- |
| `EDOM`  | ошибка области определения | математические функции (`sqrt`, `log`, `pow` и др.) для значений вне допустимой области |
| `ERANGE` | ошибка диапазона          | функции преобразования чисел (`strtol`, `strtod` — результат вне диапазона), математические функции (переполнение) |
| `EILSEQ` | ошибка последовательности символов | функции работы с многобайтовыми символами (`wcrtomb` и др.) при неверной последовательности |

Остальные коды (например, `EACCES`, `ENOENT`, `EINVAL`, `ENOSPC`, `EEXIST`) определяются платформой; они используются системными функциями POSIX (см. [[Языки программирования/C/Глава 10. POSIX|главу 10]]).

>[!NOTE]
>Коды ошибок в `<errno.h>` — положительные константы. Реализации разрешено добавлять свои коды, поэтому полный список значений конкретной системы нельзя переносить в другой код без изменений.

## 4. Момент установки и сброс errno

`errno` ведёт себя по строго определённым правилам:

- в начале работы программы `errno` равен нулю;
- при ошибке функция может установить `errno` в ненулевое значение, но не обязана делать это при успешном вызове;
- функции не гарантируют, что `errno` останется нулём после успешного вызова — они просто не обязаны его трогать;
- значение `errno` может быть перезаписано любой следующей неудачной функцией.

Отсюда обязательное правило работы:

> перед вызовом функции сбросьте `errno = 0`, а сразу после вызова проверьте его значение — до этого не вызывайте другие функции, которые могут изменить `errno`.

>[!WARNING]
>Не сравнивайте `errno` с нулём после того, как успели сработать другие вызовы функций: они могли перезаписать значение, и результат проверки станет неверным.

## 5. Проверка ошибок с помощью errno

Рассмотрим преобразование строки в число функцией `strtol()` из [[Языки программирования/C/Глава 9. Стандартная библиотека C/11. <stdlib.h>|<stdlib.h>]]. Возвращаемое значение само по себе не отличает успешный ноль от ошибки, поэтому дополнительно проверяют `errno`:

```c
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
#include <limits.h>

int main(void)
{
    const char* input = "12345";
    char* end;

    errno = 0;                 // Сброс перед вызовом
    long value = strtol(input, &end, 10);

    if (errno == ERANGE) {
        printf("Результат вне диапазона long\n"); // пример: strtol("9999999999999999999999", ...)
    } else if (errno != 0) {
        printf("Ошибка при преобразовании\n");
    } else if (end == input) {
        printf("Число не найдено\n");
    } else {
        printf("Получено %ld\n", value); // Получено 12345
    }

    return 0;
}
```

Математические функции устанавливают `EDOM` при ошибке области определения и `ERANGE` при переполнении:

```c
#include <stdio.h>
#include <math.h>
#include <errno.h>

int main(void)
{
    errno = 0;
    double r = sqrt(-1.0); // Отрицательный аргумент: вне области определения sqrt

    if (errno == EDOM)
        printf("Ошибка области определения\n"); // Ошибка области определения

    return 0;
}
```

>[!NOTE]
>Математические функции не гарантируют, что `errno` установится при любой ошибке; надёжнее проверять и результат функции (например, `NAN`/`HUGE_VAL`), и `errno`.

## 6. Сообщения об ошибках: strerror и perror

Числовой код ошибки неудобен для вывода; переводятся в текст две функции:

- `strerror()` из `<string.h>` возвращает строку описания по коду `errno` (подробно в уроке [[Языки программирования/C/Глава 9. Стандартная библиотека C/12. <string.h>|<string.h>]]);
- `perror()` из `<stdio.h>` выводит сообщение в поток ошибок `stderr`, добавляя описание текущего `errno`.

```c
#include <stdio.h>
#include <string.h>
#include <errno.h>

int main(void)
{
    FILE* file = fopen("nothere.txt", "r");
    if (file == NULL) {
        perror("fopen"); // fopen: No such file or directory
        printf("errno = %d (%s)\n", errno, strerror(errno));
    }

    return 0;
}
```

## 7. errno в многопоточных программах

`errno` реализован как потоково-локальная переменная: каждый поток имеет собственную копию, поэтому ошибки, возникшие в разных потоках (см. [[Языки программирования/C/Глава 11. Многопоточность|главу 11]]), не затирают друг друга.

Из этого следует, что `errno = 0` сбрасывает значение только в текущем потоке, а проверка внутри потока видит ошибки именно этого потока.

>[!NOTE]
Потоково-локальность `errno` обеспечивается механизмом thread-local storage; способ хранения — деталь конкретной реализации и не входит в стандарт.

## 8. Резюме

1. `errno` — макрос переменной из `<errno.h>` для сообщения об ошибках стандартных и системных функций.
2. Стандартные коды: `EDOM`, `ERANGE`, `EILSEQ`; прочие определяются платформой.
3. Паттерн проверки: `errno = 0` перед вызовом, проверка сразу после, без промежуточных вызовов.
4. Для вывода текста ошибки используются `strerror()` из `<string.h>` и `perror()` из `<stdio.h>`.
5. `errno` потоково-локальна в многопоточных программах.
