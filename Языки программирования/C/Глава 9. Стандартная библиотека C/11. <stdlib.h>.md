## Описание библиотеки

Заголовочный файл `<stdlib.h>` — «общие утилиты» (general utilities): один из основных заголовков стандартной библиотеки. Определяет функции преобразования строк в числа и обратно, управления памятью, сортировки и поиска, завершения программы, работы с окружением, псевдослучайными числами, целочисленной математикой и многобайтовыми символами, а также сопутствующие типы и константы. Многобайтовые функции из `<stdlib.h>` дополняются более современными аналогами из `<wchar.h>` (см. статью [[Языки программирования/C/Глава 9. Стандартная библиотека C/8. Поддержка Unicode и кодировки UTF-8, UTF-16 и UTF-32|«Поддержка Unicode и кодировки UTF-8, UTF-16 и UTF-32»]]).

Функции `ato*` просты, но не сообщают об ошибках (переполнение неотличимо от нуля) — для надёжного разбора чисел следует использовать `strto*`.

### Преобразование строк в числа

| Функция | Описание |
|---|---|
| `atof()` | Строка в `double`; без проверки ошибок |
| `atoi()` | Строка в `int`; без проверки ошибок |
| `atol()` | Строка в `long`; без проверки ошибок |
| `atoll()` | Строка в `long long`; без проверки ошибок |
| `strtod()` | Строка в `double`; `endptr`, `errno = ERANGE` |
| `strtof()` | Строка в `float`; `endptr`, `errno = ERANGE` |
| `strtold()` | Строка в `long double`; `endptr`, `errno = ERANGE` |
| `strtol()` | Строка в `long`; основание 2–36 или автоопределение |
| `strtoll()` | Строка в `long long`; основание 2–36 или автоопределение |
| `strtoul()` | Строка в `unsigned long`; основание 2–36 или автоопределение |
| `strtoull()` | Строка в `unsigned long long`; основание 2–36 или автоопределение |

### Преобразование чисел в строки

| Функция | Описание |
|---|---|
| `strfromd()` | `double` в строку без учёта локали (C23) |
| `strfromf()` | `float` в строку без учёта локали (C23) |
| `strfroml()` | `long double` в строку без учёта локали (C23) |

### Управление памятью

| Функция | Описание |
|---|---|
| `malloc()` | Выделяет блок без инициализации |
| `calloc()` | Выделяет блок, заполненный нулями |
| `realloc()` | Меняет размер блока, сохраняя содержимое |
| `free()` | Освобождает блок |
| `aligned_alloc()` | Выделяет блок с заданным выравниванием (C11) |

### Сортировка и поиск

| Функция | Описание |
|---|---|
| `qsort()` | Сортировка массива произвольного типа (нестабильная) |
| `bsearch()` | Бинарный поиск в отсортированном массиве |

### Завершение программы

| Функция | Описание |
|---|---|
| `exit()` | Штатное завершение: `atexit`-функции, сброс буферов |
| `_Exit()` | Немедленное завершение без «уборки» |
| `quick_exit()` | Быстрое завершение: только `at_quick_exit`-функции (C11) |
| `abort()` | Аварийное завершение через `SIGABRT` |
| `atexit()` | Регистрация функции для `exit()` (до 32 и более) |
| `at_quick_exit()` | Регистрация функции для `quick_exit()` (C11) |
| `EXIT_SUCCESS` | Код успешного завершения (0) |
| `EXIT_FAILURE` | Код завершения с ошибкой (ненулевой) |

### Целочисленная математика

| Функция/тип | Описание |
|---|---|
| `abs()` / `labs()` / `llabs()` | Модуль `int` / `long` / `long long` |
| `div()` / `ldiv()` / `lldiv()` | Деление с остатком; `quot` усекается к нулю, `rem` берёт знак делимого |
| `div_t` / `ldiv_t` / `lldiv_t` | Типы результатов `div*()` |

### Случайные числа

| Функция | Описание |
|---|---|
| `rand()` | Псевдослучайное число из `[0; RAND_MAX]` |
| `srand()` | Инициализация генератора зерном |
| `RAND_MAX` | Максимальное значение `rand()` (не менее 32767) |
