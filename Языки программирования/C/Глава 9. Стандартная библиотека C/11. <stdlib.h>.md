## 1. Введение

Заголовочный файл `<stdlib.h>` является одним из основных заголовочных файлов стандартной библиотеки C. В нем определены функции для преобразования строк в числа, генерации случайных чисел, завершения программы, взаимодействия с окружением, поиска и сортировки, целочисленной математики, управления памятью и работы с многобайтовыми символами.

## 2. Преобразование строк в числа

### 2.1. Функции atof, atoi, atol, atoll

Функции `atof()`, `atoi()`, `atol()`, `atoll()` преобразуют строку в число с плавающей точкой или целое число:

```c
double atof(const char *str);
int atoi(const char *str);
long atol(const char *str);
long long atoll(const char *str);
```

Параметр один — `str`, указатель на строку. Поведение функций одинаково:

1. Пропускаются ведущие пробельные символы (пробелы, табуляция, перевод строки).
2. Разбирается необязательный знак `+` или `-`.
3. Разбираются десятичные цифры; `atof()` дополнительно распознаёт десятичную точку, экспоненту `e`/`E` и специальные значения `INF`/`NAN`.
4. Преобразование прекращается на первом символе, который не может быть частью числа (например, `atoi("3.1415")` вернёт 3, остановившись на точке).
5. Если в начале строки не оказалось цифр, возвращается 0.

Пример использования:

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char* str1 = "234";
    char* str2 = "3.14";
    char* str3 = "3.1415";

    int num = atoi(str1);
    double d = atof(str2);
    int truncated = atoi(str3); // Преобразование останавливается на точке

    printf("num: %d\n", num);         // num: 234
    printf("d: %.2f\n", d);           // d: 3.14
    printf("truncated: %d\n", truncated); // truncated: 3

    return 0;
}
```

>[!WARNING]
>Главная проблема этих функций — невозможность отличить успешное преобразование строки `"0"` от неудачного, так как в обоих случаях возвращается 0. Кроме того, при переполнении (когда результат не помещается в тип) поведение по стандарту **не определено** — в отличие от `strtol()`/`strtod()`, которые сигнализируют об ошибке через `errno`.

### 2.2. Функции strtol, strtoll, strtoul, strtoull

Функции `strtol()`, `strtoll()`, `strtoul()`, `strtoull()` преобразуют строку в целое число (соответственно `long`, `long long`, `unsigned long`, `unsigned long long`) с указанием основания системы счисления и возможностью определить, на каком символе остановилось преобразование:

```c
long strtol(const char *str, char **endptr, int base);
long long strtoll(const char *str, char **endptr, int base);
unsigned long strtoul(const char *str, char **endptr, int base);
unsigned long long strtoull(const char *str, char **endptr, int base);
```

Параметры:

- `str` — строка для преобразования;
- `endptr` — указатель на указатель, в который будет записан адрес первого нераспознанного символа (или `NULL`, если адрес не нужен);
- `base` — основание системы счисления (от 2 до 36), либо 0 или 16 для автоматического определения по префиксу.

Порядок разбора строки:

1. Пропускаются ведущие пробельные символы.
2. Разбирается необязательный знак `+` или `-`.
3. Если `base` равно 0, основание определяется автоматически: по ведущему `0x`/`0X` — шестнадцатеричное, по ведущему `0` — восьмеричное, иначе — десятичное. Если `base` равно 16, допускается префикс `0x`/`0X`.
4. Разбираются цифры, допустимые в данной системе счисления (для основания больше 10 — латинские буквы `a`–`z` без учёта регистра).
5. Преобразование прекращается на первом недопустимом символе; его адрес сохраняется в `*endptr` (если `endptr` не `NULL`).

Возвращаемое значение:

- результат преобразования, либо `LONG_MAX`/`LONG_MIN` (или беззнаковый максимум) при переполнении с установкой `errno` в `ERANGE`;
- 0, если не распознано ни одного символа числа (при этом `*endptr == str`);
- `*endptr` указывает на конец строки (`'\0'`), если преобразование прошло полностью.

Пример с основанием 0 (автоматическое определение):

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char* endptr;

    printf("%ld\n", strtol("255", &endptr, 10));      // 255 (десятичное)
    printf("%ld\n", strtol("0377", &endptr, 0));      // 255 (восьмеричное)
    printf("%ld\n", strtol("0xFF", &endptr, 0));      // 255 (шестнадцатеричное)
    printf("%ld\n", strtol("z", &endptr, 36));        // 35 (цифры 0-9 и буквы a-z)

    return 0;
}
```

Пример с проверкой ошибок:

```c
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>

int main(void)
{
    char* str = "123abc";
    char* endptr;
    long num;

    errno = 0;
    num = strtol(str, &endptr, 10);
    if (errno == ERANGE) {
        printf("Переполнение!\n");
    } else if (endptr == str) {
        printf("Цифры не найдены\n");
    } else if (*endptr != '\0') {
        printf("Преобразование остановилось на: %s\n", endptr);
    } else {
        printf("Преобразование полностью: %ld\n", num);
    }

    return 0;
}
```

### 2.3. Функции strtod, strtof, strtold

Функции `strtod()`, `strtof()`, `strtold()` преобразуют строку в число с плавающей точкой (соответственно `double`, `float`, `long double`):

```c
double strtod(const char *str, char **endptr);
float strtof(const char *str, char **endptr);
long double strtold(const char *str, char **endptr);
```

Второй параметр `endptr` — указатель на указатель на символ. Если он не равен `NULL`, функция записывает в `*endptr` адрес первого символа, который не участвовал в преобразовании. Это позволяет проверить, была ли распознана вся строка, и продолжить разбор оставшейся части. Если `endptr` равен `NULL`, адрес не сохраняется.

#### 2.3.1. Формат разбираемого числа

Функция разбирает строку по следующим правилам (порядок обязателен):

1. Пропускаются ведущие пробельные символы (по `isspace()`).
2. Затем разбирается необязательный знак `+` или `-`.
3. Далее — одна из двух форм числа:

   - **десятичная форма:** последовательность десятичных цифр с необязательной десятичной точкой и необязательной дробной частью, за которой может следовать экспонента `e`/`E` со знаком и десятичными цифрами. Например: `-42.5e2`;
   - **шестнадцатеричная форма:** префикс `0x`/`0X`, шестнадцатеричные цифры, необязательная точка и шестнадцатеричная дробная часть, за которыми должна следовать экспонента `p`/`P` со знаком и десятичными цифрами. Например: `0x1.8p3`. Экспонента в этом случае означает степень двойки.

4. Распознаются также специальные значения без учёта регистра: `INF`, `INFINITY` (бесконечность) и `NAN` (не число), с необязательным знаком, а для `NAN` — с необязательной последовательностью символов в скобках (например, `nan(123)`).

Если в начале строки не распознано ни одного символа числа (например, строка `"abc"`), преобразование не выполняется: функция возвращает 0, а `*endptr` получает значение `str`.

#### 2.3.2. Возвращаемое значение

Функция возвращает результат преобразования, округлённый до ближайшего представимого значения соответствующего типа (`double`, `float`, `long double`) в соответствии с текущим режимом округления. Разбор числа зависит от текущей локали: десятичный разделитель берётся из категории `LC_NUMERIC` (по умолчанию — точка).

#### 2.3.3. Обработка ошибок

- Если результат невозможно представить в типе (переполнение — overflow), функция возвращает `±HUGE_VAL` (для `strtof` — `HUGE_VALF`, для `strtold` — `HUGE_VALL`) и устанавливает `errno` в `ERANGE`.
- Если результат меньше наименьшего нормализованного значения (исчерпание точности — underflow), возвращается значение, не превосходящее его по модулю (вплоть до 0); `errno` в большинстве реализаций также устанавливается в `ERANGE` (стандарт оставляет это на усмотрение реализации).
- Если преобразование не выполнено вовсе, возвращается 0 без установки `errno`; об этом сигнализирует только `endptr == str`.

Перед вызовом `errno` следует сбрасывать в 0, так как успешное преобразование его не обнуляет. Пример:

```c
#include <stdio.h>
#include <stdlib.h>
#include <errno.h>

int main(void)
{
    char* str = "abc";
    char* endptr;
    double num;

    errno = 0;
    num = strtod("1e400", &endptr);
    // Переполнение: возвращается HUGE_VAL (бесконечность)
    if (errno == ERANGE) {
        printf("Переполнение: %g\n", num);
    }

    errno = 0;
    num = strtod(str, &endptr);
    // Ни одного символа не распознано: возвращается 0, endptr == str
    if (endptr == str) {
        printf("Преобразование не выполнено: %g\n", num);
    }

    return 0;
}
```

#### 2.3.4. Примеры использования

Пропуск ведущих пробелов, знак и экспонента:

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char* endptr;

    double num = strtod("  -42.5e2", &endptr);
    printf("num: %g\n", num);        // num: -4250
    printf("endptr: '%s'\n", endptr); // endptr: '' (дошли до конца строки)

    return 0;
}
```

Шестнадцатеричная форма (`0x1.8p3` = 1,5 · 2³ = 12):

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char* endptr;

    double num = strtod("0x1.8p3", &endptr);
    printf("num: %g\n", num); // num: 12

    return 0;
}
```

Специальные значения:

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char* endptr;

    printf("inf: %g\n", strtod("inf", &endptr));   // inf: inf
    printf("nan: %g\n", strtod("-nan", &endptr));  // nan: -nan

    return 0;
}
```

Частичное преобразование — `endptr` указывает на первый нераспознанный символ, разбор можно продолжить:

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char* str = "3.14x25.5";
    char* endptr;

    double first = strtod(str, &endptr);
    printf("first: %g\n", first);            // first: 3.14
    printf("остаток: %s\n", endptr);         // остаток: x25.5

    double second = strtod(endptr + 1, &endptr); // Продолжаем со следующего числа
    printf("second: %g\n", second);          // second: 25.5

    return 0;
}
```

>[!NOTE]
>Функции `strtof()` и `strtold()` работают полностью аналогично `strtod()` и отличаются только типом результата (`float` и `long double` соответственно) и константами переполнения (`HUGE_VALF` и `HUGE_VALL`).

## 3. Генерация случайных чисел. rand и srand

Функция `rand()` возвращает псевдослучайное целое число в диапазоне от 0 до `RAND_MAX`. Функция `srand()` инициализирует генератор псевдослучайных чисел начальным значением (seed):

```c
int rand(void);
void srand(unsigned int seed);
```

Поведение:

- последовательность чисел, выдаваемая `rand()` после `srand(seed)`, детерминирована: при одном и том же начальном значении она всегда одинакова;
- если `srand()` не вызывалась, генератор ведёт себя так, как если бы `srand(1)` была вызвана;
- `RAND_MAX` — константа из `<stdlib.h>` (обычно 32767), максимальное значение, возвращаемое `rand()`.

Пример: случайное число из произвольного диапазона `[min; max]`:

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void)
{
    int min = 10, max = 20;

    srand(time(NULL)); // Инициализация генератора текущим временем

    int value = min + rand() % (max - min + 1);
    printf("Случайное число от %d до %d: %d\n", min, max, value);

    return 0;
}
```

>[!NOTE]
>Если не вызвать `srand()`, генератор каждый раз будет выдавать одну и ту же последовательность чисел, так как начальное значение по умолчанию равно 1. Константа `RAND_MAX` определяется в `<stdlib.h>` и обычно равна 32767.

>[!NOTE]
>Операция `%` незначительно смещает распределение: младшие диапазоны значений выпадают чуть чаще. Для задач, где это критично (криптография, строгая статистика), `rand()` непригоден — нужен генератор с гарантированной равномерностью.

## 4. Завершение программы. exit, _Exit, abort, atexit

### 4.1. exit

Функция `exit()` завершает выполнение программы:

```c
void exit(int status);
```

Порядок действий при вызове:

1. Вызываются функции, зарегистрированные через `atexit()`, в порядке, обратном порядку регистрации;
2. сбрасываются буферы и закрываются все открытые потоки (включая `stdout`/`stderr`);
3. удаляются временные файлы, созданные `tmpfile()`;
4. управление возвращается операционной системе со статусом `status`.

Параметр `status` — статус завершения: константы `EXIT_SUCCESS` (обычно 0) и `EXIT_FAILURE` (обычно 1), либо произвольное значение (в POSIX системе передаётся младший байт). `exit()` не возвращает управление: код после вызова не выполняется.

Пример с проверкой статуса:

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    FILE* file = fopen("data.txt", "r");
    if (file == NULL) {
        fprintf(stderr, "Не удалось открыть файл\n");
        exit(EXIT_FAILURE); // Завершение с кодом 1
    }
    fclose(file);

    return 0;
}
```

### 4.2. _Exit

Функция `_Exit()` завершает программу немедленно, без вызова функций `atexit()`, без сброса буферов и закрытия потоков:

```c
void _Exit(int status);
```

Она нужна для ситуаций, когда промежуточные действия `exit()` нежелательны или опасны (например, при завершении после сбоя). Содержимое буферов при этом может быть потеряно.

### 4.3. abort

Функция `abort()` аварийно завершает программу:

```c
void abort(void);
```

Особенности:

- не вызываются функции, зарегистрированные через `atexit()`, и не сбрасываются буферы;
- в системах с сигналами генерируется сигнал `SIGABRT`: если сигнал не перехвачен и не игнорируется, программа завершается с аварийным статусом (дамп памяти);
- если сигнал перехвачен обработчиком и функция возвращает управление, программа всё равно завершается аварийно.

### 4.4. atexit

Функция `atexit()` регистрирует функцию, которая будет вызвана при завершении программы через `exit()` или при возврате из `main()`:

```c
int atexit(void (*func)(void));
```

Возвращаемое значение: 0 при успешной регистрации, ненулевое — если зарегистрировать больше нельзя (лимит задаётся константой `ATEXIT_MAX`, не менее 32). Функции вызываются в порядке, обратном порядку регистрации. Пример:

```c
#include <stdio.h>
#include <stdlib.h>

void cleanup() {
    printf("Очистка ресурсов\n");
}

int main(void)
{
    atexit(cleanup);
    printf("Программа работает\n");

    return 0;
}
```

Консольный вывод:

```
Программа работает
Очистка ресурсов
```

## 5. Окружение. getenv и system

### 5.1. getenv

Функция `getenv()` возвращает значение переменной окружения по ее имени или `NULL`, если переменная не найдена:

```c
char *getenv(const char *name);
```

Поведение:

- `name` — имя переменной окружения (без учёта регистра в Windows, с учётом регистра в POSIX);
- возвращается указатель на строку значения. Изменять эту строку нельзя — она принадлежит среде выполнения;
- если переменной нет, возвращается `NULL` — проверка обязательна, иначе обращение к строке вызовет ошибку.

Пример:

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char* path = getenv("PATH");
    if (path != NULL) {
        printf("PATH: %s\n", path);
    } else {
        printf("Переменная PATH не найдена\n");
    }

    return 0;
}
```

>[!NOTE]
>Указатель, полученный от `getenv()`, не стоит хранить между вызовами: в некоторых реализациях (например, при вызове `setenv()`) строка может быть перезаписана или освобождена.

### 5.2. system

Функция `system()` выполняет команду операционной системы:

```c
int system(const char *command);
```

Поведение:

- если `command` не `NULL`, команда передаётся командному интерпретатору (`/bin/sh` в POSIX, `cmd.exe` в Windows); возвращается код её завершения (конкретное значение зависит от реализации);
- если `command` равен `NULL`, функция не выполняет команду, а лишь проверяет доступность командного интерпретатора: возвращает ненулевое значение, если он доступен, и 0 в противном случае;
- пока команда выполняется, программа ожидает её завершения.

Пример:

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    if (system(NULL) == 0) {
        printf("Командный интерпретатор недоступен\n");
        return 1;
    }

    int result = system("ls -l"); // Вывод списка файлов в Linux
    printf("Команда завершилась с кодом: %d\n", result);

    return 0;
}
```

## 6. Поиск и сортировка. qsort и bsearch

### 6.1. qsort

Функция `qsort()` сортирует массив произвольного типа, используя функцию сравнения:

```c
void qsort(void *base, size_t num, size_t size,
           int (*compare)(const void *, const void *));
```

Параметры:

- `base` — указатель на начало массива;
- `num` — количество элементов;
- `size` — размер одного элемента в байтах;
- `compare` — функция сравнения, возвращающая отрицательное число, если первый элемент меньше второго, 0 при равенстве и положительное число, если первый элемент больше второго.

Пример:

```c
#include <stdio.h>
#include <stdlib.h>

int compare(const void* a, const void* b) {
    return (*(int*)a - *(int*)b);
}

int main(void)
{
    int numbers[] = {5, 2, 8, 1, 9, 3};
    size_t count = sizeof(numbers) / sizeof(numbers[0]);

    qsort(numbers, count, sizeof(int), compare);

    for (size_t i = 0; i < count; i++) {
        printf("%d ", numbers[i]); // 1 2 3 5 8 9
    }
    printf("\n");

    return 0;
}
```

Сортировка строк (массива указателей) — функция сравнения передаёт элементы в `strcmp()`:

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int compare_strings(const void* a, const void* b) {
    // a и b — указатели на элементы массива, то есть на char*
    return strcmp(*(const char**)a, *(const char**)b);
}

int main(void)
{
    const char* words[] = {"банан", "яблоко", "арбуз", "груша"};
    size_t count = sizeof(words) / sizeof(words[0]);

    qsort(words, count, sizeof(char*), compare_strings);

    for (size_t i = 0; i < count; i++) {
        printf("%s ", words[i]); // арбуз банан груша яблоко
    }
    printf("\n");

    return 0;
}
```

>[!NOTE]
>В функции сравнения разность значений не должна выходить за пределы `int`: `*(int*)a - *(int*)b` переполняется при разности больших чисел (например, `INT_MAX - (-1)`). Безопасный способ — сравнивать через `<` и `>`:

```c
int compare(const void* a, const void* b) {
    int x = *(const int*)a;
    int y = *(const int*)b;
    return (x > y) - (x < y);
}
```

>[!NOTE]
>Функция сравнения должна быть согласована: если `compare(a, b)` даёт положительное значение, то `compare(b, a)` должно давать отрицательное, а при равенстве — 0. Нарушение этого свойства делает поведение сортировки неопределённым. Стабильность сортировки (сохранение порядка равных элементов) не гарантируется.

### 6.2. bsearch

Функция `bsearch()` ищет элемент в отсортированном массиве с помощью бинарного поиска и возвращает указатель на найденный элемент или `NULL`:

```c
void *bsearch(const void *key, const void *base, size_t num, size_t size,
              int (*compare)(const void *, const void *));
```

Параметры:

- `key` — указатель на искомое значение;
- `base` — указатель на начало массива;
- `num` — количество элементов;
- `size` — размер одного элемента в байтах;
- `compare` — функция сравнения: вызывается как `compare(key, элемент)` и должна возвращать 0 при совпадении.

Важное требование: массив должен быть предварительно отсортирован тем же правилом сравнения, иначе результат поиска не определён. Возвращается указатель на первый найденный элемент (при совпадении нескольких — на любой из них) или `NULL`.

Пример:

```c
#include <stdio.h>
#include <stdlib.h>

int compare(const void* a, const void* b) {
    return (*(int*)a - *(int*)b);
}

int main(void)
{
    int numbers[] = {1, 2, 3, 5, 8, 9};
    int key = 5;

    int* result = bsearch(&key, numbers, 6, sizeof(int), compare);
    if (result != NULL) {
        printf("Найдено: %d\n", *result); // Найдено: 5
    } else {
        printf("Не найдено\n");
    }

    return 0;
}
```

## 7. Целочисленная математика. abs, labs, llabs, div, ldiv, lldiv

### 7.1. Функции abs, labs, llabs

Функции `abs()`, `labs()`, `llabs()` возвращают абсолютное значение числа (соответственно `int`, `long`, `long long`):

```c
int abs(int n);
long labs(long n);
long long llabs(long long n);
```

Пример:

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    printf("%d\n", abs(-5));     // 5
    printf("%ld\n", labs(-123)); // 123

    return 0;
}
```

>[!WARNING]
>Для наименьшего значения типа результат не помещается в тип: `abs(INT_MIN)`, `labs(LONG_MIN)` и `llabs(LLONG_MIN)` — неопределённое поведение.

### 7.2. Функции div, ldiv, lldiv

Функции `div()`, `ldiv()`, `lldiv()` выполняют целочисленное деление и возвращают структуру с частным и остатком:

```c
div_t div(int numerator, int denominator);
ldiv_t ldiv(long numerator, long denominator);
lldiv_t lldiv(long long numerator, long long denominator);
```

Структуры `div_t`, `ldiv_t`, `lldiv_t` содержат поля `quot` (частное) и `rem` (остаток). Всегда выполняется тождество `quot * denominator + rem == numerator`. Деление выполняется с усечением к нулю (как и обычная операция `/` для целых). Пример:

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    div_t result = div(17, 5);

    printf("Частное: %d\n", result.quot); // Частное: 3
    printf("Остаток: %d\n", result.rem);  // Остаток: 2

    div_t neg = div(-7, 3);
    printf("Частное: %d, Остаток: %d\n", neg.quot, neg.rem); // Частное: -2, Остаток: -1

    return 0;
}
```

>[!WARNING]
>Деление на ноль в `div()`, `ldiv()`, `lldiv()` — неопределённое поведение (так же, как и операция `/` для целых).

## 8. Управление памятью. malloc, calloc, realloc, free

В `<stdlib.h>` определены функции для динамического выделения и освобождения памяти:

```c
void *malloc(size_t size);
void *calloc(size_t num, size_t size);
void *realloc(void *ptr, size_t size);
void free(void *ptr);
void *aligned_alloc(size_t alignment, size_t size); // C11
```

Поведение каждой функции:

- `malloc(size)` — выделяет блок из `size` байт; содержимое не инициализируется. При неудаче возвращает `NULL`;
- `calloc(num, size)` — выделяет блок под `num` элементов по `size` байт (всего `num * size` байт) и обнуляет его. При неудаче возвращает `NULL`;
- `realloc(ptr, size)` — изменяет размер ранее выделенного блока. При расширении содержимое сохраняется, добавленная часть не инициализируется. Блок может быть перемещён в другое место памяти — возвращается новый указатель. При неудаче возвращает `NULL`, **не освобождая** исходный блок (указатель `ptr` остаётся действительным);
- `free(ptr)` — освобождает блок, выделенный `malloc()`/`calloc()`/`realloc()`. Передача `NULL` допустима и ничего не делает; повторное освобождение того же указателя — неопределённое поведение;
- `aligned_alloc(alignment, size)` — выделяет блок, выровненный по границе `alignment` (степень двойки), размер должен быть кратен выравниванию (C11).

Функции подробно рассматриваются в [[Языки программирования/C/Глава 7. Динамическая память|главе 7]] и в уроке [[Языки программирования/C/Глава 9. Стандартная библиотека C/3. Работа с памятью|«Работа с памятью»]]. Пример:

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int* arr = malloc(5 * sizeof(int)); // Выделение памяти под 5 целых
    if (arr == NULL) {
        return 1;
    }

    for (int i = 0; i < 5; i++) {
        arr[i] = i + 1;
    }
    printf("arr[0]: %d\n", arr[0]); // arr[0]: 1

    free(arr); // Освобождение памяти

    return 0;
}
```

## 9. Многобайтовые символы

В `<stdlib.h>` определены функции для работы с многобайтовыми символами:

```c
int mblen(const char *s, size_t n);
int mbtowc(wchar_t *restrict pwc, const char *restrict s, size_t n);
int wctomb(char *s, wchar_t wchar);
size_t mbstowcs(wchar_t *restrict pwcs, const char *restrict s, size_t n);
size_t wcstombs(char *restrict s, const wchar_t *restrict pwcs, size_t n);
```

Поведение каждой функции:

- `mblen(s, n)` — возвращает длину в байтах многобайтового символа в строке `s` (не более `n` байт); 0 — если `s` указывает на нулевой символ, -1 — если символ не является корректным;
- `mbtowc(pwc, s, n)` — преобразует многобайтовый символ в широкий и сохраняет его в `*pwc`; возвращает длину символа в байтах или -1 при ошибке;
- `wctomb(s, wchar)` — преобразует широкий символ в многобайтовый и сохраняет его в `s`; возвращает длину в байтах или -1 при ошибке;
- `mbstowcs(pwcs, s, n)` — преобразует многобайтовую строку в широкую; возвращает количество преобразованных символов (без учёта завершающего нуля) или `(size_t)-1` при ошибке;
- `wcstombs(s, pwcs, n)` — преобразует широкую строку в многобайтовую; возвращает количество записанных байт или `(size_t)-1` при ошибке.

>[!NOTE]
>Функции преобразуют символы в соответствии с текущей локалью (категория `LC_CTYPE`). По умолчанию (локали `"C"`) многобайтовые символы не поддерживаются — для работы с UTF-8 нужно установить локаль через `setlocale(LC_ALL, "")`.

Пример с `mbstowcs()`:

```c
#include <stdio.h>
#include <stdlib.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, ""); // Включаем локаль (поддержка UTF-8)

    char* str = "Привет";
    wchar_t wstr[10];

    size_t count = mbstowcs(wstr, str, 10);
    printf("Количество символов: %zu\n", count);
    wprintf(L"%ls\n", wstr);

    return 0;
}
```

## 10. Константы и типы

В `<stdlib.h>` определены:

- `NULL` — нулевой указатель;
- `EXIT_SUCCESS` и `EXIT_FAILURE` — статусы завершения программы для `exit()`;
- `RAND_MAX` — максимальное значение, возвращаемое `rand()`;
- `MB_CUR_MAX` — максимальная длина многобайтового символа в текущей локали;
- `size_t` — беззнаковый целочисленный тип для размеров (обычно также доступен через другие заголовочные файлы);
- `div_t`, `ldiv_t`, `lldiv_t` — структуры, возвращаемые функциями `div()`, `ldiv()`, `lldiv()`.
