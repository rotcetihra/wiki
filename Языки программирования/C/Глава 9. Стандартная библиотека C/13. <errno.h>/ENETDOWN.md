## Определение

```c
#include <errno.h>

#define ENETDOWN 100 // "Network is down"
```

## Описание

«Сеть не работает»: локальная сеть недоступна. POSIX (XSI). Возвращается сокетными операциями, когда сетевой интерфейс/подсистема не активна.

## Когда возникает

- `connect()`/`send()`/`sendto()` при выключенном интерфейсе или отсутствии сетевой подсистемы;
- интерфейс опущен (`ip link set down`).

## Похожие коды

- `ENETUNREACH` — сеть недостижима (нет маршрута)
- `EHOSTDOWN` — конкретный хост не работает
- `ENETRESET` — соединение сброшено сетью
