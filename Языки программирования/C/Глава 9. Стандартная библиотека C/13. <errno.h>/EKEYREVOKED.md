## Определение

```c
#include <errno.h>

#define EKEYREVOKED 128 // "Key has been revoked"
```

## Описание

«Ключ отозван»: доступ к ключу, отозванному через `keyctl_revoke()`/`KEYCTL_REVOKE`. Linux-специфичный код (семейство кодов keyrings).

## Когда возникает

- операции с отозванным ключом в keyring (`add_key`/`keyctl`).

## Похожие коды

- `ENOKEY` — ключ не найден
- `EKEYEXPIRED` — ключ истёк
- `EKEYREJECTED` — ключ отклонён службой

## Источники

- Linux: `asm-generic/errno.h`, man-страница `keyctl(2)`
