## Определение

```c
#include <errno.h>

#define EEXIST 17 // "File exists"
```

## Описание

«Файл уже существует». Возвращается, когда операция, требующая отсутствия файла, выполнена над существующим. POSIX-код.

## Когда возникает

- `open()` с `O_CREAT | O_EXCL` — файл уже есть (классический способ атомарного создания);
- `mkdir()`/`mkfifo()`/`mknod()` — узел уже существует;
- `link()`/`symlink()` — имя уже занято;
- `rename()` — в некоторых случаях с существующим каталогом назначения.

## Похожие коды

- `ENOTEMPTY` — каталог не пуст (для rmdir)
- `ENOTDIR` — компонента пути не каталог

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno-base.h`, man-страница `open(2)`
