## Определение

```c
#include <errno.h>

#define EREMOTE 66 // "Object is remote"
```

## Описание

«Объект удалённый»: попытка выполнить локальную операцию (например, mount точки) с объектом, находящимся на удалённом узле (пересечение границ машины). POSIX (XSI) — исторический код распределённых систем. На Linux существует для совместимости.

## Когда возникает

- исторически — RFS: операции с удалёнными объектами; на современных Linux практически не возникает.

## Похожие коды

- `EREMOTEIO` — ошибка удалённого ввода-вывода
- `ENOLINK` — связь разорвана

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno.h`
