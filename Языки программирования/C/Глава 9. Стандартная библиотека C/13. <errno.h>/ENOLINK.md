## Определение

```c
#include <errno.h>

#define ENOLINK 67 // "Link has been severed"
```

## Описание

«Связь разорвана» — код RFS/распределённых систем: потеряно соединение между узлами. POSIX (XSI) определяет его как исторический. На Linux существует для совместимости; встречается редко (например, в samba-клиентах).

## Когда возникает

- исторически — RFS: обрыв канала; на Linux возможен в некоторых сетевых протоколах при разрыве связи узла.

## Похожие коды

- `ECOMM` — ошибка связи при передаче
- `EMULTIHOP` — многошаговый переход
- `EPROTO` — ошибка протокола

## Источники
