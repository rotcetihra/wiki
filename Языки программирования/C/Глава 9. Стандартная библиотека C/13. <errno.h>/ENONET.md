## Определение

```c
#include <errno.h>

#define ENONET 64 // "Machine is not on the network"
```

## Описание

«Машина не в сети» — исторический код RFS: узел не подключён к сети. На Linux существует для совместимости, не используется. Не входит в POSIX.

## Когда возникает

- исторически — RFS: операции с удалёнными ресурсами без сети; на современных Linux не возникает.

## Похожие коды

- `ENETDOWN` — сеть не работает
- `EREMOTE` — объект удалённый

## Источники

- Linux: `asm-generic/errno.h`
