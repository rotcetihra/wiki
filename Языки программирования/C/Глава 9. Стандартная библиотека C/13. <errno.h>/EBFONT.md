## Определение

```c
#include <errno.h>

#define EBFONT 59 // "Bad font file format"
```

## Описание

«Некорректный формат файла шрифта» — код, появившийся для работы с консольными шрифтами XENIX. На Linux сохраняется для совместимости; не используется современными программами. Не входит в POSIX.

## Когда возникает

- исторически — загрузка повреждённого/неподдерживаемого файла шрифта; на современных Linux не возникает.
