## Определение

```c
#include <errno.h>

#define EHOSTDOWN 112 // "Host is down"
```

## Описание

«Хост не работает»: удалённый хост не отвечает на сетевом уровне (отличается от `EHOSTUNREACH` — «нет маршрута»). POSIX (XSI).

## Когда возникает

- `connect()`/`sendto()` — хост выключен или сетевой стек не отвечает (ICMP host down);
- сетевые ФС при недоступности сервера.

## Похожие коды

- `EHOSTUNREACH` — нет маршрута к хосту
- `ENETUNREACH` — сеть недостижима
- `ETIMEDOUT` — таймаут ожидания
