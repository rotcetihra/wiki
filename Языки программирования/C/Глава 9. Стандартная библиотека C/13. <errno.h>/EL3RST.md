## Определение

```c
#include <errno.h>

#define EL3RST 47 // "Level 3 reset"
```

## Описание

«Уровень 3 сброшен» — код STREAMS System V. На Linux сохраняется для совместимости, не применяется. Не входит в POSIX.

## Когда возникает

- исторически — STREAMS: сброс уровня 3; на современных Linux не возникает.

## Похожие коды

- `EL3HLT` — уровень 3 остановлен
- `EL2NSYNC` — уровень 2 не синхронизирован

## Источники

- Linux: `asm-generic/errno.h`
