## Определение

```c
#include <errno.h>

#define EDEADLOCK EDEADLK // "Resource deadlock avoided"
```

## Описание

Дубликат `EDEADLK` (в glibc: `#define EDEADLOCK EDEADLK`) — то же значение 35. Имя добавлено в системах System V для совместимости с `fcntl()`-блокировками; программы могут использовать любую форму. На Linux оба имени эквивалентны.
