## Определение

```c
#include <errno.h>

#define EPROTONOSUPPORT 93 // "Protocol not supported"
```

## Описание

«Протокол не поддерживается»: запрошенный протокол отсутствует в семействе/ядре. POSIX (XSI).

## Когда возникает

- `socket()` с протоколом, не реализованным в ядре (например, `SCTP` без модуля);
- `socket()` с несовместимым сочетанием тип/протокол.

## Похожие коды

- `EPROTOTYPE` — протокол не подходит типу сокета
- `EAFNOSUPPORT` — семейство адресов не поддерживается
- `ESOCKTNOSUPPORT` — тип сокета не поддерживается

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno.h`, man-страница `socket(2)`
