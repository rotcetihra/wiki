## Определение

```c
#include <errno.h>

#define ENOTNAM 118 // "Not a XENIX named type file"
```

## Описание

«Не файл именованного типа XENIX» — исторический код XENIX. На Linux существует для совместимости, не используется. Не входит в POSIX.

## Когда возникает

- исторически — XENIX: операция требовала файл именованного типа; на современных Linux не возникает.

## Похожие коды

- `EISNAM` — файл именованного типа (XENIX)
- `ENAVAIL` — нет XENIX-семафоров
