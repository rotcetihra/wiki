## Определение

```c
#include <errno.h>

#define ENOTBLK 15 // "Block device required"
```

## Описание

«Требуется блочное устройство»: операция, требующая блочное устройство, выполнена над файлом другого типа (например, монтирование обычного файла без параметра loop). POSIX-код.

## Когда возникает

- `mount()` на обычный файл без `-o loop` в старых ядрах;
- системные вызовы, требующие `bdev`.

## Похожие коды

- `ENODEV` — нет такого устройства
- `EINVAL` — неверный аргумент

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno-base.h`, man-страница `mount(2)`
