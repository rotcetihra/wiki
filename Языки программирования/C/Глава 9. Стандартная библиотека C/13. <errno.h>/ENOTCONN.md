## Определение

```c
#include <errno.h>

#define ENOTCONN 107 // "Transport endpoint is not connected"
```

## Описание

«Транспортная конечная точка не соединена»: сокетная операция, требующая установленного соединения, выполнена на неподключённом сокете. POSIX (XSI).

## Когда возникает

- `send()`/`recv()` на сокете без установленного соединения (для потоковых сокетов);
- `getsockopt(SO_ERROR)` при разорванном соединении;
- `shutdown()` на несоединённом сокете.

## Похожие коды

- `EISCONN` — сокет уже соединён
- `EPIPE` — запись в разорванное соединение
- `ECONNRESET` — соединение сброшено
