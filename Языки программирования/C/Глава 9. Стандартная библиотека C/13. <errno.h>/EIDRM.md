## Определение

```c
#include <errno.h>

#define EIDRM 43 // "Identifier removed"
```

## Описание

«Идентификатор удалён»: объект IPC (очередь сообщений, семафор, разделяемая память), с которым связана операция, был удалён из системы через `IPC_RMID`. POSIX (XSI).

## Когда возникает

- `msgrcv()`/`msgsnd()` — очередь удалена после операции `msgctl(IPC_RMID)`;
- `semop()`/`shmat()` — семафор/сегмент удалён, пока процесс ждал или работал;
- POSIX IPC (`mq_*`, `sem_*`) в аналогичных ситуациях.

## Похожие коды

- `ENOMSG` — сообщение нужного типа нет в очереди
- `EINTR` — операция IPC прервана сигналом

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno.h`, man-страницы `msgctl(2)`, `semctl(2)`
