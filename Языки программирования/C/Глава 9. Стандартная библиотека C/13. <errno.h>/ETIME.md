## Определение

```c
#include <errno.h>

#define ETIME 62 // "Timer expired"
```

## Описание

«Таймер истёк» — код STREAMS System V (срабатывание таймера потока). POSIX (XSI) определяет его как исторический STREAMS-код. Важно не путать с `ETIMEDOUT` (110). В glibc используется в редких внутренних путях.

## Когда возникает

- исторически — STREAMS: истечение таймера потока; на современных Linux фактически не возникает.

## Похожие коды

- `ETIMEDOUT` — таймаут соединения (110)
- `ENODATA` — нет данных (STREAMS)

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno.h`
