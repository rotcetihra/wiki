## Определение

```c
#include <errno.h>

#define ENODATA 61 // "No data available"
```

## Описание

«Нет доступных данных» — код STREAMS (чтение из потока, когда данных ещё нет). POSIX (XSI) определяет его для STREAMS. На Linux существует, но STREAMS фактически не поддерживается — код редко встречается в новых программах.

## Когда возникает

- исторически — `read()` на потоке STREAMS без данных;
- в glibc используется некоторыми функциями (например, POSIX timer) в специфических путях — редко.

## Похожие коды

- `EAGAIN` — данные ещё не готовы
- `ENOSTR` — устройство не поток (STREAMS)
- `ETIME` — истекло время (STREAMS)

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno.h`
