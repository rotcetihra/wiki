## Определение

```c
#include <errno.h>

#define EUNATCH 49 // "Protocol driver not attached"
```

## Описание

«Драйвер протокола не подключён» — код STREAMS System V: протокольный драйвер не присоединён к потоку. На Linux существует для совместимости, не используется. Не входит в POSIX.

## Когда возникает

- исторически — STREAMS: операции с потоком без присоединённого драйвера; на современных Linux не возникает.

## Похожие коды

- `ENOSTR` — устройство не поток (STREAMS)
- `ENOCSI` — нет структуры CSI (STREAMS)
