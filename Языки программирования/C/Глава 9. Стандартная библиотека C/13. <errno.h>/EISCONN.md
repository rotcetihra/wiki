## Определение

```c
#include <errno.h>

#define EISCONN 106 // "Transport endpoint is already connected"
```

## Описание

«Транспортная конечная точка уже соединена»: сокет, на котором требуется установить соединение, уже подключён. POSIX (XSI). Возникает при повторном `connect()` на уже соединённом потоковом сокете (см. `listen()`/`accept()` пути), особенно если сокет переведён в режим `O_NONBLOCK` и первая попытка уже прошла.

## Когда возникает

- второй `connect()` на установившемся TCP-сокете;
- `connect()` на сокете, уже подключённом через `accept()` (в сторону серверного потока);
- `sendto()` на подключённом сокете с неверным адресом в некоторых путях.

## Похожие коды

- `EALREADY` — операция уже выполняется (неблокирующий connect)
- `EINPROGRESS` — соединение устанавливается
- `EDESTADDRREQ` — нет адреса назначения (для дейтаграмм)

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno.h`, man-страница `connect(2)`
