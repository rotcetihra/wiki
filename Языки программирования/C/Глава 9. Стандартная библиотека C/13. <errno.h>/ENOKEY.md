## Определение

```c
#include <errno.h>

#define ENOKEY 126 // "Required key not available"
```

## Описание

«Требуемый ключ недоступен»: запрошенный ключ не найден в связке ключей (keyring) ядра Linux. Linux-специфичный код (часть семейства кодов keyrings).

## Когда возникает

- `keyctl()`/`add_key()` — ссылка на несуществующий ключ;
- операции dm-crypt/подпись ядра при отсутствии ключа.

## Похожие коды

- `EKEYEXPIRED` — ключ истёк
- `EKEYREVOKED` — ключ отозван
- `EKEYREJECTED` — ключ отклонён

## Источники

- Linux: `asm-generic/errno.h`, man-страница `keyctl(2)`
