## Определение

```c
#include <errno.h>

#define EISNAM 120 // "Is a named type file"
```

## Описание

«Это файл именованного типа»: код XENIX для «named type file» — файла с особым типом (использовался для XENIX-специфичных операций). На Linux сохраняется для совместимости, фактически не используется. Не входит в POSIX.

## Когда возникает

- исторически — операции XENIX с файлами специального типа; на современных Linux не встречается.

## Похожие коды

- `ENOTNAM` — не файл именованного типа (XENIX)
- `ENAVAIL` — нет XENIX-семафоров
