## Определение

```c
#include <errno.h>

#define ENOSR 63 // "Out of streams resources"
```

## Описание

«Исчерпаны ресурсы потоков STREAMS» — код STREAMS System V. POSIX (XSI) сохраняет его как исторический. На Linux не используется.

## Когда возникает

- исторически — STREAMS: исчерпание ресурсов потоков; на современных Linux не возникает.

## Похожие коды

- `ENOSTR` — устройство не поток (STREAMS)
- `ENODATA` — нет данных (STREAMS)

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno.h`
