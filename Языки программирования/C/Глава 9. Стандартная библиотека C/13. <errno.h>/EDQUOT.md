## Определение

```c
#include <errno.h>

#define EDQUOT 122 // "Disk quota exceeded"
```

## Описание

«Превышена дисковая квота». Возвращается при превышении лимитов квот (блоки или inode) пользователя или группы на ФС с поддержкой квот. POSIX (XSI).

## Когда возникает

- запись `write()`/`truncate()` превышает квоту блоков;
- создание файла/каталога превышает квоту inode;
- `open()` с `O_CREAT` при исчерпанной квоте каталога.

## Похожие коды

- `ENOSPC` — место на устройстве закончилось (не квота)
- `EFBIG` — файл превышает максимальный размер

## Источники
