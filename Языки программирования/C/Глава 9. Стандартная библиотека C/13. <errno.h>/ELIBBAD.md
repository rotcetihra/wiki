## Определение

```c
#include <errno.h>

#define ELIBBAD 80 // "Accessing a corrupted shared library"
```

## Описание

«Доступ к повреждённой разделяемой библиотеке»: файл библиотеки не соответствует формату (повреждён или не ELF). Linux-специфичный; в современном glibc загрузчик обычно возвращает свои сообщения об ошибках (`dlerror()`), а не errno, но код сохранён.

## Когда возникает

- `dlopen()`/запуск — файл повреждён, не является корректным ELF;
- усечённый файл библиотеки.

## Похожие коды

- `ELIBACC` — доступ к библиотеке запрещён
- `ELIBSCN` — повреждён раздел .lib
- `ELIBEXEC` — нельзя exec библиотеку
