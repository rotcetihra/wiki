## Определение

```c
#include <errno.h>

#define ELIBACC 79 // "Can not access a needed shared library"
```

## Описание

«Невозможно получить доступ к требуемой разделяемой библиотеке»: библиотека существует в системе, но не может быть открыта (нет прав, повреждена) при загрузке. Linux-специфичный код (не POSIX): появляются при сбое динамического загрузчика.

## Когда возникает

- `dlopen()`/запуск программы — у библиотеки нет права чтения или путь недоступен;
- права на каталог с библиотекой не позволяют чтение.

## Похожие коды

- `ELIBBAD` — библиотека повреждена
- `ELIBSCN` — повреждён раздел .lib
- `ELIBMAX` — слишком много библиотек
- `ELIBEXEC` — нельзя exec разделяемую библиотеку
