## Определение

```c
#include <errno.h>

#define EL3HLT 46 // "Level 3 halted"
```

## Описание

«Уровень 3 остановлен» — код STREAMS System V. На Linux существует для совместимости, не используется. Не входит в POSIX.

## Когда возникает

- исторически — STREAMS: остановка уровня 3; на современных Linux не возникает.

## Похожие коды

- `EL2HLT` — уровень 2 остановлен
- `EL3RST` — уровень 3 сброшен
- `ELNRNG` — номер звена вне диапазона
