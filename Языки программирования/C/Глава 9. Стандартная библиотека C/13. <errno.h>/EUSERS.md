## Определение

```c
#include <errno.h>

#define EUSERS 87 // "Too many users"
```

## Описание

«Слишком много пользователей» — исторический код: превышено число пользователей, подключённых через сетевое устройство (или таблица соединений переполнена). POSIX (XSI) — исторический код сокетов. На Linux практически не возникает.

## Когда возникает

- исторически — сетевые устройства с таблицей пользователей; на современных Linux не встречается.

## Похожие коды

- `EMFILE` — исчерпаны дескрипторы процесса
- `ENFILE` — исчерпана система таблица файлов

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno.h`
