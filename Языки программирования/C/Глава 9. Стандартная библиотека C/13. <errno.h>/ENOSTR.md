## Определение

```c
#include <errno.h>

#define ENOSTR 60 // "Device not a stream"
```

## Описание

«Устройство не является потоком STREAMS» — код STREAMS System V: операция потока над устройством без STREAMS-поддержки. POSIX (XSI) — исторический код. На Linux не используется (STREAMS нет).

## Когда возникает

- исторически — STREAMS: `read()`/`write()`/`ioctl()` над не-потоковым устройством; на современных Linux не возникает.

## Похожие коды

- `ENODATA` — нет данных (STREAMS)
- `ENOSR` — исчерпаны ресурсы потоков (STREAMS)
- `ETIME` — таймер истёк (STREAMS)

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno.h`
