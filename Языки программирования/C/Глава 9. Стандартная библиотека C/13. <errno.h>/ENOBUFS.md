## Определение

```c
#include <errno.h>

#define ENOBUFS 105 // "No buffer space available"
```

## Описание

«Нет свободного буферного пространства»: не удалось выделить буфер ядра (skbuff и т. п.) для операции. POSIX (XSI). Часто временная ошибка — повтор операции допустим.

## Когда возникает

- `send()`/`sendto()` — переполнены буферы сокета или исчерпаны буферы ядра;
- `socket()`/приём пакетов при нехватке памяти ядра.

## Похожие коды

- `ENOMEM` — нехватка памяти (пространство процесса/ядра)
- `EAGAIN` — ресурс временно недоступен
- `EMSGSIZE` — сообщение слишком длинное

## Источники
