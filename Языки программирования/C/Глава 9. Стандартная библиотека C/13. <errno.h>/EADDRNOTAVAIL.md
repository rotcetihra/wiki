## Определение

```c
#include <errno.h>

#define EADDRNOTAVAIL 99 // "Cannot assign requested address"
```

## Описание

«Невозможно назначить запрошенный адрес». Сокетный код ошибки: локальный адрес (IP-адрес интерфейса, порт) не может быть назначен сокету — например, адрес не принадлежит ни одному интерфейсу хоста. POSIX (XSI).

## Когда возникает

- `bind()`: IP-адрес не настроен ни на одном интерфейсе;
- `connect()`: нет подходящего локального адреса (все заняты или отсутствуют).

## Похожие коды

- `EADDRINUSE` — адрес уже занят
- `EHOSTUNREACH` — хост недостижим
- `ENETUNREACH` — сеть недостижима
