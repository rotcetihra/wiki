## Определение

```c
#include <errno.h>

#define ESHUTDOWN 108 // "Cannot send after transport endpoint shutdown"
```

## Описание

«Нельзя отправлять после shutdown транспортной конечной точки»: попытка `send()`/`sendto()` на сокете, закрытом для отправки через `shutdown(SHUT_WR)`. POSIX (XSI).

## Когда возникает

- `send()` после `shutdown(fd, SHUT_WR)` (полузакрытое соединение);
- `sendmsg()` с флагом, требующим отправки, на закрытом для записи сокете.

## Похожие коды

- `EPIPE` — запись в разорванное соединение
- `ENOTCONN` — сокет не соединён
- `EISCONN` — сокет уже соединён

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno.h`, man-страница `shutdown(2)`
