## Определение

```c
#include <errno.h>

#define ENOLCK 37 // "No record locks available"
```

## Описание

«Нет доступных блокировок записей»: системный лимит на число файловых блокировок (fcntl-блокировок) исчерпан. POSIX-код.

## Когда возникает

- `fcntl(F_SETLK/F_SETLKW)` при исчерпании лимита блокировок ядра;
- массовые блокировки файлов длинными процессами;
- `flock()` в ограниченных конфигурациях.

## Похожие коды

- `EAGAIN` — блокировка уже удерживается (F_SETLK без ожидания)
- `EDEADLK` — взаимоблокировка блокировок
