## Прототип

```c
#include <strings.h>

int strncasecmp(const char *s1, const char *s2, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1`, `s2` | Сравниваемые строки |
| `n` | Максимальное количество сравниваемых символов |

## Возвращаемое значение

Отрицательное число, 0 или положительное число — результат сравнения первых `n` символов строк без учёта регистра.

## Что делает

Сравнивает не более `n` символов двух строк без учёта регистра — аналог `strncmp()` без учёта регистра. Сравнение останавливается на завершающем нуле: если одна из строк короче `n` символов, результат определяется по ней.

## Примеры

```c
#include <stdio.h>
#include <strings.h>

int main(void)
{
    // Первые 3 символа равны, дальше различие не проверяется
    printf("%d\n", strncasecmp("abcXYZ", "ABC", 3)); // 0
    printf("%d\n", strncasecmp("abc", "abD", 3));    // отрицательное

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Можно сравнивать префиксы без копирования | Не входит в ISO C: нет на Windows |
| Не читает за пределами `n` символов | |
