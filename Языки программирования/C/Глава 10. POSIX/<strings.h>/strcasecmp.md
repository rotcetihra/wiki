## Прототип

```c
#include <strings.h>

int strcasecmp(const char *s1, const char *s2);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1`, `s2` | Сравниваемые строки |

## Возвращаемое значение

Отрицательное число, 0 или положительное число — результат сравнения строк без учёта регистра (как у `strcmp()`).

## Что делает

Сравнивает строки без учёта регистра символов: `"HELLO"` и `"hello"` считаются равными. В glibc сравнение выполняется по правилам текущей локали (категория `LC_CTYPE`) — результат может зависеть от установленной локали. Главная функция заголовочного файла `<strings.h>`.

>[!WARNING]
>`<strings.h>` — не стандарт C: на Windows код с `strcasecmp()` не скомпилируется (аналог — `_stricmp()` из `<string.h>`). Для переносимого кода определяют собственную обёртку через `#ifdef _WIN32`.

## Примеры

```c
#include <stdio.h>
#include <strings.h>

int main(void)
{
    printf("%d\n", strcasecmp("Hello", "hello")); // 0 — равны
    printf("%d\n", strcasecmp("abc", "ABD"));     // отрицательное (c < d)

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Единственное готовое регистронезависимое сравнение | Не входит в ISO C: нет на Windows |
| Правильная обработка локали (например, кириллицы) | Результат может различаться между локалями |
