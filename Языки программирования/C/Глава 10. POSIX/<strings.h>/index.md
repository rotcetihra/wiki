## Прототип

```c
#include <strings.h>

char *index(const char *s, int c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Строка для поиска |
| `c` | Искомый символ (преобразуется в `unsigned char`) |

## Возвращаемое значение

Указатель на первое вхождение символа `c` в строке `s` или `NULL`, если символ не найден.

## Что делает

Ищет первое вхождение символа в строке — аналог `strchr()`. Как и `strchr()`, находит завершающий нуль: `index(s, '\0')` возвращает указатель на конец строки. Устаревшая (LEGACY) функция BSD: вместо неё следует использовать `strchr()` из `<string.h>`.

## Примеры

```c
#include <stdio.h>
#include <strings.h>

int main(void)
{
    const char *text = "Hello, world!";

    printf("%s\n", index(text, 'o'));   // o, world!
    printf("%p\n", (void *)index(text, 'z')); // NULL

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Короткое имя | Устаревшая (LEGACY) |
