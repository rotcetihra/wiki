## Прототип

```c
#include <string.h> // POSIX.1-2001

char *strtok_r(char *str, const char *delim, char **saveptr);
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | Строка для разбора (при первом вызове) или `NULL` (при последующих) |
| `delim` | Строка символов-разделителей |
| `saveptr` | Указатель на переменную состояния (заполняется функцией) |

## Возвращаемое значение

Возвращает указатель на очередной токен или `NULL`, когда токены закончились.

## Что делает

Потокобезопасная версия [[Языки программирования/C/Глава 9. Стандартная библиотека C/12. <string.h>/strtok|strtok()]]: состояние разбора хранится не в статической переменной, а в `*saveptr`, который передаёт вызывающий. Несколько параллельных разборов разных строк не конфликтуют. Как и `strtok()`, модифицирует строку (разделители заменяются нулями) и пропускает пустые токены.

## Примеры

### Стандартный разбор

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char line[] = "apple,banana,cherry";
    char *saveptr;
    char *token = strtok_r(line, ",", &saveptr);

    while (token != NULL) {
        printf("%s\n", token);
        token = strtok_r(NULL, ",", &saveptr);
    }

    return 0;
}
```

### Параллельный разбор двух строк

```c
#include <stdio.h>
#include <string.h>

void print_tokens(char *str, const char *name)
{
    char *saveptr;
    char *token = strtok_r(str, ";", &saveptr);
    while (token != NULL) {
        printf("%s: %s\n", name, token);
        token = strtok_r(NULL, ";", &saveptr);
    }
}

int main(void)
{
    char s1[] = "a;b;c";
    char s2[] = "x;y";

    print_tokens(s1, "первая");  // не конфликтует со второй
    print_tokens(s2, "вторая");

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Передача литерала — неопределённое поведение (строка модифицируется).

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Потокобезопасна | Модифицирует строку |
| Состояние у вызывающего | Пропускает пустые токены |
| Вложенные разборы возможны | Не входит в C (только POSIX) |
