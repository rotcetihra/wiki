## Прототип

```c
#include <string.h> // GNU (glibc ≥ 2.32)

const char *strerrorname_np(int errnum);
```

## Параметры

| Параметр | Описание |
|---|---|
| `errnum` | Код ошибки (обычно `errno`) |

## Возвращаемое значение

Возвращает указатель на строку с **именем константы** ошибки (например, `"ENOENT"`). Если код неизвестен — возвращает `NULL`.

## Что делает

Возвращает символическое имя константы из `<errno.h>` по её числовому значению: `strerrorname_np(2)` возвращает `"ENOENT"`. Удобно для логов и диагностики, где нужно показать имя стандартной константы, а не только числовой код. Суффикс `_np` — «non-portable».

## Примеры

### Вывод имени ошибки в лог

```c
#include <stdio.h>
#include <string.h>
#include <errno.h>

int main(void)
{
    FILE *file = fopen("missing.txt", "r");
    if (file == NULL) {
        const char *name = strerrorname_np(errno);
        printf("Ошибка %s (%d): %s\n",
               name != NULL ? name : "UNKNOWN", errno, strerror(errno));
        // Ошибка ENOENT (2): No such file or directory
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Для неизвестного кода возвращает `NULL`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Наглядное имя константы | Только glibc (не переносима) |
| `NULL` для неизвестного кода | Статическая строка — только для чтения |
| Безопасна в многопоточных программах | |
