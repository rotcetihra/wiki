## Прототип

```c
#include <string.h> // GNU

void *mempcpy(void *dest, const void *src, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dest` | Буфер для копирования |
| `src` | Исходный блок памяти |
| `n` | Количество байт для копирования |

## Возвращаемое значение

Возвращает указатель на байт, следующий **после последнего скопированного** байта (`dest + n`). В отличие от `memcpy()`, которая возвращает начало `dest`.

## Что делает

Копирует `n` байт как `memcpy()`, но возвращает конец скопированной области. Это позволяет последовательно наращивать буфер без пересчёта позиций — удобно при построении пакетов, сериализации и конкатенации памяти.

## Примеры

### Последовательная сборка пакета

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char packet[64];
    char *p = packet;

    p = mempcpy(p, "GET ", 4);        // p указывает на конец
    p = mempcpy(p, "/index.html ", 12);
    p = mempcpy(p, "HTTP/1.1", 8);
    *p = '\0';

    printf("%s\n", packet); // GET /index.html HTTP/1.1

    return 0;
}
```

### Сериализация двух чисел

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    int a = 42, b = 7;
    char buf[sizeof(a) + sizeof(b)];
    char *p = buf;

    p = mempcpy(p, &a, sizeof(a));
    mempcpy(p, &b, sizeof(b)); // Возврат не обязателен на последнем шаге

    int ra, rb;
    memcpy(&ra, buf, sizeof(ra));
    memcpy(&rb, buf + sizeof(ra), sizeof(rb));
    printf("a=%d b=%d\n", ra, rb);

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Как и `memcpy()`, не обрабатывает перекрытие областей — при перекрытии поведение не определено.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Упрощает последовательную сборку буферов | Только GNU-расширение |
| Один возврат вместо вычислений | Не обрабатывает перекрытие |
| | Возвращаемый указатель можно использовать сразу |
