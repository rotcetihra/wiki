## Прототип

```c
#include <string.h> // POSIX.1-2008

int strcoll_l(const char *s1, const char *s2, locale_t locale);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1` | Первая строка для сравнения |
| `s2` | Вторая строка для сравнения |
| `locale` | Локаль (тип `locale_t` из `<locale.h>`), чьи правила колляции применять |

## Возвращаемое значение

Возвращает значение < 0, если `s1` сортируется раньше `s2`; 0 при равенстве; > 0, если позже — по правилам сортировки заданной локали.

## Что делает

Вариант [[Языки программирования/C/Глава 9. Стандартная библиотека C/12. <string.h>/strcoll|strcoll()]], в котором локаль передаётся явно параметром, а не берётся из глобального окружения. Позволяет сравнивать строки по правилам конкретной локали независимо от того, что установлено в программе, и безопасна в многопоточных программах (не зависит от глобального состояния).

## Примеры

### Сравнение с явной локалью

```c
#include <stdio.h>
#include <string.h>
#include <locale.h>

int main(void)
{
    locale_t ru = newlocale(LC_ALL_MASK, "ru_RU.UTF-8", NULL);
    if (ru == NULL) {
        printf("Локаль недоступна\n");
        return 1;
    }

    int result = strcoll_l("ж", "я", ru); // по русским правилам
    printf("%d\n", result); // отрицательное: «ж» раньше «я»

    freelocale(ru);
    return 0;
}
```

### Сравнение в двух локалях сразу

```c
#include <stdio.h>
#include <string.h>
#include <locale.h>

int main(void)
{
    locale_t ru = newlocale(LC_COLLATE_MASK, "ru_RU.UTF-8", NULL);
    locale_t de = newlocale(LC_COLLATE_MASK, "de_DE.UTF-8", NULL);

    int r = strcoll_l("Ä", "z", ru);
    int d = strcoll_l("Ä", "z", de);

    printf("ru: %d, de: %d\n", r, d); // Результаты могут различаться

    freelocale(ru);
    freelocale(de);
    return 0;
}
```

## Ошибки и errno

Может установить `errno` в `EINVAL`, если `locale` невалидна. Возвращаемое значение не определено, если `locale` — `NULL`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Локаль передаётся явно | Только POSIX.1-2008 |
| Безопасна в многопоточных программах | Нужно управлять локалью (`newlocale`/`freelocale`) |
| Можно сравнивать в разных локалях | Медленнее `strcmp()` |
