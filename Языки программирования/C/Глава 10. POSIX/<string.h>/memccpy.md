## Прототип

```c
#include <string.h>

void *memccpy(void *dest, const void *src, int c, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dest` | Буфер для копирования |
| `src` | Исходный блок памяти |
| `c` | Стоп-символ (приводится к `unsigned char`) |
| `n` | Максимальное количество байт для копирования |

## Возвращаемое значение

Возвращает указатель на байт **сразу после** скопированного стоп-символа `c`, если он был найден. Если символ `c` не встретился в первых `n` байтах — возвращает `NULL`, при этом все `n` байт скопированы.

## Что делает

Копирует байты из `src` в `dest`, пока не скопирует `n` байт или не встретит байт со значением `c`. Удобна для копирования префикса данных до определённого маркера: скобки, конца строки, разделителя. Вошла в стандарт C23; до этого была расширением POSIX (XSI).

## Примеры

### Копирование до разделителя

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *src = "key=value";
    char dest[32] = {0};

    char *after = memccpy(dest, src, '=', 32);
    if (after != NULL) {
        *after = '\0'; // Завершаем строку после '='
    }
    printf("%s\n", dest); // key=

    return 0;
}
```

### Копирование с обнаружением обрыва

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char data[] = {0x01, 0x02, 0x03, 0x04};
    char dest[4];

    // Ищем байт 0xFF, которого нет — NULL, но все 4 байта скопированы
    void *result = memccpy(dest, data, 0xFF, sizeof(data));
    if (result == NULL) {
        printf("Стоп-байт не найден, скопировано 4 байта\n");
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Как и `memcpy()`, не обрабатывает перекрытие областей `dest` и `src` — при перекрытии поведение не определено.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Копирует «до маркера» за один вызов | Не обрабатывает перекрытие областей |
| Позволяет обнаружить, найден ли маркер | В C23; до C23 — только POSIX |
| Работает с бинарными данными | |
