## Прототип

```c
#include <string.h> // GNU

void *memmem(const void *haystack, size_t haystacklen,
             const void *needle, size_t needlelen);
```

## Параметры

| Параметр | Описание |
|---|---|
| `haystack` | Блок памяти, в котором ищется подстрока |
| `haystacklen` | Длина блока поиска |
| `needle` | Искомая последовательность байт |
| `needlelen` | Длина искомой последовательности |

## Возвращаемое значение

Возвращает указатель на первое вхождение последовательности `needle` в блоке `haystack`. Если вхождение не найдено — `NULL`. Пустая последовательность (`needlelen == 0`) возвращает `haystack`.

## Что делает

Аналог [[Языки программирования/C/Глава 9. Стандартная библиотека C/12. <string.h>/strstr|strstr()]] для бинарных данных с явно заданными длинами: ищет подстроку в блоке памяти без завершающих нулей. Реализация в glibc использует алгоритм с линейной сложностью в лучшем случае.

## Примеры

### Поиск в бинарных данных

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char data[] = {0x00, 0xFF, 0x0A, 0x0B, 0x0C, 0x00};
    char needle[] = {0x0A, 0x0B};

    void *found = memmem(data, sizeof(data), needle, sizeof(needle));
    if (found != NULL) {
        printf("Найдено на позиции %td\n", (char *)found - data); // 2
    }

    return 0;
}
```

### Поиск строки в загруженном файле

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    FILE *file = fopen("app.bin", "rb");
    char buf[1024];
    size_t read = fread(buf, 1, sizeof(buf), file);
    fclose(file);

    const char *magic = "MZ"; // Сигнатура PE-файлов
    void *found = memmem(buf, read, magic, strlen(magic));
    if (found != NULL) {
        printf("Сигнатура найдена на позиции %td\n", (char *)found - buf);
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Неопределённое поведение при выходе за границы заданных длин.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Работает с бинарными данными | Только GNU-расширение |
| Не требует завершающих нулей | Не переносится на Windows/BSD |
| Быстрее ручного поиска | |
