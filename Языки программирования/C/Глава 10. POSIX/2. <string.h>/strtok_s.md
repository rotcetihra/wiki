## Прототип

```c
#include <string.h> // C11, Annex K

errno_t strtok_s(char *str, rsize_t *strmax, const char *delim, char **ptr);
```

Тип `errno_t` — целый тип для кодов ошибок; `rsize_t` — беззнаковый целый с проверкой на `RSIZE_MAX`.

## Параметры

| Параметр | Описание |
|---|---|
| `str` | Строка для разбора (при первом вызове) или `NULL` (при последующих) |
| `strmax` | Указатель на размер строки `str` (уменьшается по мере разбора) |
| `delim` | Строка символов-разделителей |
| `ptr` | Указатель на переменную состояния (аналог `saveptr` в `strtok_r()`) |

## Возвращаемое значение

Возвращает 0 при успехе; ненулевой код ошибки при нарушении ограничений (например, `EINVAL`). Токен при успехе доступен через `*ptr`.

## Что делает

Безопасная версия разбиения на токены из приложения Annex K стандарта C11: комбинация `strtok_r()` и проверок ограничений. В отличие от `strtok_r()`, принимает размер буфера и не может выйти за его пределы; возвращает код ошибки вместо неопределённого поведения.

>[!WARNING]
>Функции Annex K реализованы не всеми компиляторами: GCC и Clang их не предоставляют (полная поддержка — в MSVC). Проверяйте макрос `__STDC_LIB_EXT1__` и используйте `strtok_r()` на Linux.

## Примеры

### Разбиение с проверкой ограничений

```c
#include <stdio.h>
#include <string.h>

#ifdef __STDC_LIB_EXT1__
int main(void)
{
    char line[] = "a,b,c";
    rsize_t size = sizeof(line) - 1;
    char *ptr = NULL;
    char *token = line;

    while (token != NULL) {
        if (strtok_s(token, &size, ",", &ptr) != 0) {
            printf("Ошибка разбора\n");
            return 1;
        }
        printf("Токен: %s\n", ptr);
        token = NULL; // Последующие вызовы с NULL
    }

    return 0;
}
#else
int main(void)
{
    printf("Annex K не поддерживается\n");
    return 0;
}
#endif
```

## Ошибки и errno

Ненулевой код ошибки при: `strmax == NULL`, `*strmax > RSIZE_MAX`, `delim == NULL`, `ptr == NULL`, невалидных значениях. Успех — 0.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Проверяет размер строки | Не поддерживается GCC/Clang |
| Возвращает код ошибки | Сложная сигнатура |
| Потокобезопасна | Семантика `*ptr` непривычна |
