## Прототип

```c
#include <string.h> // GNU

char *strcasestr(const char *haystack, const char *needle);
```

## Параметры

| Параметр | Описание |
|---|---|
| `haystack` | Строка, в которой ищется подстрока |
| `needle` | Искомая подстрока (регистр не учитывается) |

## Возвращаемое значение

Возвращает указатель на первое вхождение `needle` в `haystack` без учёта регистра. Если вхождение не найдено — `NULL`. Пустой `needle` возвращает `haystack`.

## Что делает

Аналог [[Языки программирования/C/Глава 9. Стандартная библиотека C/12. <string.h>/strstr|strstr()]], который игнорирует регистр символов: `strcasestr("Hello", "HELLO")` находит вхождение. Применима для поиска ключевых слов, расширений файлов и имён в пользовательском вводе.

## Примеры

### Поиск без учёта регистра

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *text = "The Quick Brown Fox";

    char *found = strcasestr(text, "brown");
    if (found != NULL) {
        printf("Найдено: %s\n", found); // brown Fox
    }

    return 0;
}
```

### Проверка расширения файла

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *file = "PHOTO.PNG";

    if (strcasestr(file, ".png") != NULL) {
        printf("Это изображение PNG\n");
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Передача невалидных указателей — неопределённое поведение.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Игнорирует регистр | Только GNU-расширение |
| Простая в использовании | Не учитывает многобайтовые кодировки корректно |
| | Обычно медленнее `strstr()` |
