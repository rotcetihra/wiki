## Прототип

```c
#include <string.h> // POSIX (XSI), в glibc — при __USE_MISC

char *strsep(char **stringp, const char *delim);
```

## Параметры

| Параметр | Описание |
|---|---|
| `stringp` | Указатель на указатель строки, которая разбирается (меняется между вызовами) |
| `delim` | Строка символов-разделителей |

## Возвращаемое значение

Возвращает указатель на очередной токен, обрезанный нулём. Если строки закончились — `NULL`.

## Что делает

Разбивает строку на токены по символам `delim`, сохраняя состояние в переменной вызывающего (не в статической, как `strtok()`). В отличие от `strtok()`, **не сжимает** последовательные разделители: для `"a,,b"` вернёт `"a"`, пустой токен, `"b"`. Модифицирует исходную строку, заменяя разделители нулями. Отмечена как устаревшая (obsolescent) в POSIX — заменяйте на `strtok_r()`.

## Примеры

### Разбиение с пустыми токенами

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char line[] = "a,,b,c";
    char *p = line;
    char *token;

    while ((token = strsep(&p, ",")) != NULL) {
        printf("[%s]\n", token); // [a] [] [b] [c]
    }

    return 0;
}
```

### Разбор CSV

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char csv[] = "name;age;city";
    char *p = csv;
    char *field;

    while ((field = strsep(&p, ";")) != NULL) {
        printf("Поле: %s\n", field);
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Неопределённое поведение при передаче литерала (строка модифицируется).

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Состояние хранится у вызывающего | Отмечена устаревшей в POSIX |
| Не пропускает пустые токены | Модифицирует строку |
| Простая в использовании | Нужен указатель на указатель |
