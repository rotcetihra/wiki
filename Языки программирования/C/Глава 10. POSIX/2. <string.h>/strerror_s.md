## Прототип

```c
#include <string.h> // C11, Annex K

errno_t strerror_s(char *buf, rsize_t buflen, int errnum);
```

Тип `errno_t` — целый тип, способный хранить код ошибки (обычно `int`); `rsize_t` — беззнаковый целый с проверкой на `RSIZE_MAX`.

## Параметры

| Параметр | Описание |
|---|---|
| `buf` | Буфер для текста описания |
| `buflen` | Размер буфера (не должен превышать `RSIZE_MAX`) |
| `errnum` | Код ошибки |

## Возвращаемое значение

Возвращает 0 при успехе и ненулевой код ошибки при нарушении ограничений (например, `EINVAL`, если `errnum` невалиден).

## Что делает

Безопасная версия [[Языки программирования/C/Глава 9. Стандартная библиотека C/12. <string.h>/strerror|strerror()]] из приложения Annex K стандарта C11: принимает размер буфера и проверяет его, возвращая код ошибки вместо неопределённого поведения. При неизвестном `errnum` в буфер пишется сообщение об ошибке (типа «unknown error»).

>[!WARNING]
>Функции Annex K реализованы не всеми компиляторами: GCC и Clang их не предоставляют (кроме режима совместимости), полная поддержка есть в MSVC. Проверяйте макрос `__STDC_LIB_EXT1__` и используйте альтернативы на Linux.

## Примеры

### Получение описания ошибки

```c
#include <stdio.h>
#include <string.h>
#include <errno.h>

#ifdef __STDC_LIB_EXT1__
int main(void)
{
    char buf[256];
    if (strerror_s(buf, sizeof(buf), ENOENT) == 0) {
        printf("Ошибка: %s\n", buf);
    }
    return 0;
}
#else
int main(void)
{
    printf("Annex K не поддерживается\n");
    return 0;
}
#endif
```

## Ошибки и errno

Возвращает ненулевой код ошибки при: `buf == NULL`, `buflen == 0`, `buflen > RSIZE_MAX`, невалидном `errnum` или когда текст не помещается в буфер.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Проверяет размер буфера | Не поддерживается GCC/Clang |
| Возвращает код ошибки | Требует `__STDC_LIB_EXT1__` |
| Безопасна в многопоточных программах | |
