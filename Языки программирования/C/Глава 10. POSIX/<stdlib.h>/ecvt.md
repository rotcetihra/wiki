## Прототип

```c
#include <stdlib.h> // SVID, устаревшие

char *ecvt(double value, int ndigit, int *decpt, int *sign);
char *fcvt(double value, int ndigit, int *decpt, int *sign);
char *gcvt(double value, int ndigit, char *buf);
```

## Параметры

| Параметр | Описание |
|---|---|
| `value` | Преобразуемое число |
| `ndigit` | Запрашиваемое количество значащих цифр (`ecvt`) или цифр после точки (`fcvt`) |
| `decpt` | Позиция десятичной точки (записывается число знаков до неё) |
| `sign` | Признак отрицательного числа (1 — отрицательное) |
| `buf` | Буфер для результата `gcvt()` |

## Возвращаемое значение

Указатель на статический буфер с цифрами числа (**без десятичной точки и знака**) — `ecvt()`/`fcvt()`; `gcvt()` возвращает `buf`. При переполнении `value` — `NULL`.

## Что делает

Устаревшие функции форматирования чисел с плавающей точкой в строку цифр. Позиция точки и знак возвращаются отдельно через `decpt` и `sign` — строку нужно собирать вручную. Используют статический буфер: каждый вызов затирает результат предыдущего, функции не потокобезопасны. Удалены из POSIX.1-2008; для новых программ используйте `snprintf()`. В glibc есть варианты `_r` (`ecvt_r()` и др.) с явным буфером.

>[!WARNING]
>Статический буфер делает функции непригодными для многопоточных программ. Формат результата нестандартен: точка и знак не входят в строку.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int decpt, sign;

    char *digits = ecvt(3.14159, 4, &decpt, &sign);
    printf("sign=%d decpt=%d digits=%s\n", sign, decpt, digits); // sign=0 decpt=1 digits=3141

    return 0;
}
```

## Ошибки и errno

`errno` не используется; о переполнении свидетельствует возврат `NULL`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Контроль числа значащих цифр | Статический буфер, не потокобезопасны |
| Не зависит от локали | Точка и знак возвращаются отдельно — ручная сборка строки |

## Альтернативы
