## Прототип

```c
#include <stdlib.h> // XSI

long a64l(const char *str64);
char *l64a(long value);
```

## Параметры

| Параметр | Описание |
|---|---|
| `str64` | Строка, закодированная через `l64a()` |
| `value` | Кодируемое целое число (не более 36 бит) |

## Возвращаемое значение

- `a64l()` — раскодированное число или 0 при ошибке (неотличимо от корректного нуля);
- `l64a()` — указатель на статический буфер со строкой (не потокобезопасна) или `NULL`, если `value` не помещается в 36 бит.

## Что делает

Пара устаревших XSI-функций кодирования чисел в строку по 6 бит на символ. Используется алфавит `./0–9A–Z a–z` (64 символа): `'.'` = 0, `'/'` = 1, `'0'`–`'9'` = 2–11 и т. д. `l64a()` кодирует младшие 36 бит в 6 символов без завершающего нуля и без разделителей. `a64l()` — обратная операция. Применялись для компактного хранения чисел в окружении и конфигурационных файлах; для новых программ предпочтителен `snprintf()` с шестнадцатеричным или десятичным выводом.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char *s = l64a(123456789L);
    printf("%s\n", s);          // закодированное значение
    printf("%ld\n", a64l(s));   // 123456789 — обратное преобразование

    return 0;
}
```

## Ошибки и errno

Функции не устанавливают `errno`. Успешное кодирование нуля и ошибка неразличимы — проверяйте аргументы заранее.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Компактное кодирование (6 бит на символ) | `l64a()` возвращает статический буфер — не потокобезопасна |
| Стандарт XSI | Устаревшие; ошибки неотличимы от нуля |

## Альтернативы

- **`snprintf(buf, n, "%lx", value)`** — переносимое шестнадцатеричное представление
- Стандартное кодирование base64 (библиотеки) — если нужен стек вывода
