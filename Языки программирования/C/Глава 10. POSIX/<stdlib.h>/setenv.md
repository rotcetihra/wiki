## Прототип

```c
#include <stdlib.h> // POSIX

int setenv(const char *name, const char *value, int overwrite);
int unsetenv(const char *name);
```

## Параметры

| Параметр | Описание |
|---|---|
| `name` | Имя переменной (без `=`) |
| `value` | Значение |
| `overwrite` | Ненулевое — заменять существующую переменную; ноль — не трогать |

## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

`setenv()` добавляет или заменяет переменную окружения, **копируя** `name` и `value` в память, принадлежащую окружению (в отличие от `putenv()`). Повторный вызов с тем же именем и `overwrite != 0` заменяет значение. `unsetenv()` удаляет переменную. POSIX-функции; ошибки: `EINVAL` — `name` содержит `=` или пуст, `ENOMEM` — не хватило памяти.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    if (setenv("MYVAR", "first", 0) != 0) return 1;
    setenv("MYVAR", "second", 0); // не заменит: overwrite == 0
    printf("%s\n", getenv("MYVAR")); // first

    setenv("MYVAR", "second", 1); // заменит
    printf("%s\n", getenv("MYVAR")); // second

    unsetenv("MYVAR");
    printf("%s\n", getenv("MYVAR") ? getenv("MYVAR") : "(отсутствует)"); // (отсутствует)

    return 0;
}
```

## Ошибки и errno

При неудаче возвращают -1 и устанавливают `errno = EINVAL` (недопустимое имя) или `ENOMEM`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Копирует строки — безопасно для локальных буферов | На каждую установку — выделение памяти |
| Различает добавление/замену (`overwrite`) | Изменение окружения не атомарно для других потоков |
