## Прототип

```c
#include <stdlib.h> // POSIX XSI

int putenv(char *string);
```

## Параметры

| Параметр | Описание |
|---|---|
| `string` | Строка вида `"ИМЯ=значение"` |

## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Добавляет или заменяет переменную окружения. Принципиальное отличие от `setenv()`: **строка не копируется** — в окружение помещается сам указатель `string`. Поэтому строку нельзя освобождать, модифицировать или повторно использовать после вызова, пока переменная нужна (в glibc `putenv()` теперь копирует строку — но переносимый код не должен на это рассчитывать). Замена существующей переменной: в glibc новый указатель записывается в ту же позицию — прежняя строка аннулируется.

>[!WARNING]
>По стандарту нельзя полагаться на срок жизни строки. Правило переносимости: передавайте `putenv()` только литералы и буферы, которые живут всё время программы. Для копирования строки используйте `setenv()`.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    static char var[] = "MYVAR=42"; // живёт всё время программы

    if (putenv(var) != 0) {
        return 1;
    }

    printf("%s\n", getenv("MYVAR")); // 42

    return 0;
}
```

## Ошибки и errno

При неудаче возвращает -1 и устанавливает `errno = ENOMEM`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая (XSI) | Строка не копируется — чужие указатели попадают в окружение |
| Изменяет окружение «на месте» | Строка должна жить всё время программы |
| | Не различает установку и замену (нет `overwrite`) |
