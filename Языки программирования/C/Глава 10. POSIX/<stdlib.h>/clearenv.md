## Прототип

```c
#include <stdlib.h> // GNU (в glibc — при __USE_GNU)

int clearenv(void);
```

## Возвращаемое значение

0 при успехе, ненулевое значение при ошибке (если окружение не удалось очистить из-за ограничений).

## Что делает

Очищает окружение: удаляет все переменные (устанавливает `environ = NULL`). GNU-расширение glibc; в POSIX не входит. После вызова `getenv()` возвращает `NULL` для любых имён. Полезно перед вызовом недоверенных программ через `system()`/`exec*()` — чтобы не передавать им секретные переменные окружения.

>[!WARNING]
>`clearenv()` делает недействительными все строки, ранее возвращённые `getenv()`, и не освобождает память, выделенную `setenv()`. Не переносима — в других реализациях для очистки окружения может не быть стандартного способа.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    putenv("SECRET=value");

    if (clearenv() != 0) {
        return 1;
    }

    printf("%s\n", getenv("SECRET") ? getenv("SECRET") : "(очищено)"); // (очищено)

    return 0;
}
```

## Ошибки и errno

Если очистка невозможна (например, из-за ограничения на количество переменных), возвращает ненулевое значение; `errno` может быть установлен в `ENOMEM`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая полная очистка окружения | Только в glibc — не переносима |
| Полезна для изолированного запуска программ | Оставляет выделенную память (утечка) |

## Альтернативы

- **`unsetenv()`** для каждой нужной переменной — переносимо (и это статья [[Языки программирования/C/Глава 10. POSIX/<stdlib.h>/setenv|setenv]])
- Сборка чистого окружения вручную и передача его через `execvpe()`
