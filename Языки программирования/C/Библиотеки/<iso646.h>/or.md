## Определение

```c
#include <iso646.h>

#define or ||
```

## Описание

Макрос (C95) — альтернативное написание оператора логического ИЛИ `||`. `a or b` эквивалентно `a || b`.

## Примеры

```c
#include <iso646.h>
#include <stdio.h>

int main(void)
{
    int code = 404;

    if (code == 400 or code == 404) {
        printf("Ошибка клиента\n");
    }

    return 0;
}
```
