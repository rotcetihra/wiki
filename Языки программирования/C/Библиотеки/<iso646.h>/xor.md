## Определение

```c
#include <iso646.h>

#define xor ^
```

## Описание

Макрос (C95) — альтернативное написание оператора исключающего ИЛИ `^`. `a xor b` эквивалентно `a ^ b`.

## Примеры

```c
#include <iso646.h>
#include <stdio.h>

int main(void)
{
    int a = 0b1100;
    int b = 0b1010;

    printf("%d\n", a xor b); // 6 (0b0110)

    return 0;
}
```
