## Определение

```c
#include <iso646.h>

#define and &&
```

## Описание

Макрос (C95) — альтернативное написание оператора логического И `&&`. Раскрывается препроцессором в обычный `&&`, поэтому `a and b` эквивалентно `a && b`. Полезен на клавиатурах и кодировках без символа `&`; сегодня используется редко.

## Примеры

```c
#include <iso646.h>
#include <stdio.h>

int main(void)
{
    int a = 5, b = 10;

    if (a > 0 and b > 0) {
        printf("Оба положительные\n");
    }

    return 0;
}
```
