## Определение

```c
#include <iso646.h>

#define compl ~
```

## Описание

Макрос (C95) — альтернативное написание унарного оператора побитового НЕ `~`. `compl x` эквивалентно `~x`.

## Примеры

```c
#include <iso646.h>
#include <stdio.h>

int main(void)
{
    int x = 0b00001111;

    printf("%d\n", compl x); // -16 (0b...11110000)

    return 0;
}
```
