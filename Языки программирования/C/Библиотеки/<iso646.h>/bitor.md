## Определение

```c
#include <iso646.h>

#define bitor |
```

## Описание

Макрос (C95) — альтернативное написание оператора побитового ИЛИ `|`. `a bitor b` эквивалентно `a | b`.

## Примеры

```c
#include <iso646.h>
#include <stdio.h>

int main(void)
{
    int a = 0b1100;
    int b = 0b1010;

    printf("%d\n", a bitor b); // 14 (0b1110)

    return 0;
}
```
