## Определение

```c
#include <iso646.h>

#define and_eq &=
```

## Описание

Макрос (C95) — альтернативное написание оператора присваивания с побитовым И `&=`. `x and_eq y` эквивалентно `x &= y`.

## Примеры

```c
#include <iso646.h>
#include <stdio.h>

int main(void)
{
    int flags = 0b1100;
    int mask = 0b1010;

    flags and_eq mask; // flags &= mask

    printf("%d\n", flags); // 8 (0b1000)

    return 0;
}
```
