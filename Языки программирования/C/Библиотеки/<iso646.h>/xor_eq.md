## Определение

```c
#include <iso646.h>

#define xor_eq ^=
```

## Описание

Макрос (C95) — альтернативное написание оператора присваивания с исключающим ИЛИ `^=`. `x xor_eq y` эквивалентно `x ^= y`.

## Примеры

```c
#include <iso646.h>
#include <stdio.h>

int main(void)
{
    int flags = 0b1100;
    int toggle = 0b1010;

    flags xor_eq toggle; // flags ^= toggle

    printf("%d\n", flags); // 6 (0b0110)

    return 0;
}
```
