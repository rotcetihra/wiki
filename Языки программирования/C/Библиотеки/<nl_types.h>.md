## Описание библиотеки

Заголовочный файл `<nl_types.h>` — типы данных для локализации. Определяет типы `nl_catd` и `nl_item`, константы и функции для работы с каталогами сообщений.

### Типы

| Тип | Описание |
|---|---|
| `nl_catd` | Дескриптор каталога сообщений (для `catopen()`/`catgets()`/`catclose()`) |
| `nl_item` | Элемент языковой информации (для `nl_langinfo()`; значения определены в `<langinfo.h>`) |

### Константы

| Константа | Описание |
|---|---|
| `NL_SETD` | Набор сообщений по умолчанию (значение определено реализацией) |
| `NL_CAT_LOCALE` | Зависимость выбора каталога от `LC_MESSAGES` (а не от `LANG`) |

### Функции

| Функция | Описание |
|---|---|
| `catopen(const char *, int)` | Открытие каталога сообщений |
| `catgets(nl_catd, int, int, const char *)` | Получение сообщения из каталога |
| `catclose(nl_catd)` | Закрытие каталога сообщений |

## Исключения

- **NULL:** `catopen()` не принимает `NULL`.
- **(nl_catd)-1:** возвращается при ошибке `catopen()`.
- **catgets:** возвращает `message` если сообщение не найдено.
- **catclose:** возвращает 0 при успехе или -1 при ошибке.
- **Многопоточность:** дескриптор каталога может использоваться несколькими потоками.

## Стандарты
