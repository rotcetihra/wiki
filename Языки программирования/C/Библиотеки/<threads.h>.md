## Описание библиотеки

Заголовочный файл `<threads.h>` — многопоточность. Этот заголовок предоставляет типы и функции для создания и управления потоками, синхронизации и потоковой локальной памяти.

> [!NOTE]
> `<threads.h>` является частью стандарта C11, но на POSIX-системах (Linux, macOS) рекомендуется использовать POSIX pthreads (`<pthread.h>`), который提供更多 возможностей.

### Типы

| Тип | Описание |
|---|---|
| `thrd_t` | Идентификатор потока |
| `mtx_t` | Мьютекс для синхронизации |
| `cnd_t` | Условная переменная для ожидания условия |
| `tss_t` | Ключ потоковой локальной памяти |
| `once_flag` | Флаг для однократной инициализации |

### Константы

| Константа | Описание |
|---|---|
| `mtx_plain` | Простой (нерекурсивный) мьютекс |
| `mtx_recursive` | Рекурсивный мьютекс |
| `mtx_try` | Мьютекс с поддержкой `mtx_trylock` |
| `thrd_success` | Успешное завершение операции |
| `thrd_timedout` | Истечение времени ожидания |
| `thrd_error` | Ошибка выполнения |
| `thrd_busy` | Ресурс временно недоступен |
| `thrd_nomem` | Нехватка памяти |

## Исключения

- **NULL:** функции не принимают `NULL` в качестве указателя на объекты; передача `NULL` — неопределённое поведение.
- **errno:** функции не устанавливают `errno`; коды ошибок возвращаются через возвращаемое значение.
- **Переполнение:** не применимо.
- **Нехватка памяти:** `thrd_create`, `mtx_init`, `cnd_init`, `tss_create` могут вернуть `thrd_nomem`.
- **Граничные случаи:** `thrd_join` может быть вызван только один раз для каждого потока; повторный вызов — неопределённое поведение.
- **Многопоточность:** этот заголовок предназначен для многопоточной среды; все функции являются потокобезопасными по определению.
- **Отсутствие в glibc:** реализация `<threads.h>` может отсутствовать в некоторых системах (например, в glibc до версии 2.28).
