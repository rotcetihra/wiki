## Описание библиотеки

Заголовочный файл `<stdbit.h>` — макросы для работы с битовым и байтовым представлением типов. Этот заголовок был добавлен в стандарт C23 и предоставляет обобщённые макросы для анализа битовой структуры беззнаковых целочисленных значений.

> [!NOTE]
> Все макросы принимают беззнаковые целочисленные аргументы и работают по модулю размера типа.

### Пример использования

```c
#include <stdbit.h>
#include <stdio.h>

int main(void) {
    unsigned int x = 0b10110100;

    printf("Ведущих нулей: %u\n", stdc_leading_zeros(x));
    printf("Замыкающих нулей: %u\n", stdc_trailing_zeros(x));
    printf("Количество единиц: %u\n", stdc_count_ones(x));
    printf("Ширина: %u\n", stdc_bit_width(x));
    printf("Степень двойки: %s\n", stdc_has_single_bit(x) ? "да" : "нет");

    return 0;
}
```

## Исключения

- **NULL:** макросы не принимают указатели, поэтому `NULL` не применим.
- **Переполнение:** макросы определены для любых беззнаковых целочисленных значений.
- **Нулевой аргумент:** `stdc_leading_zeros(0)` возвращает размер типа в битах; `stdc_first_leading_one(0)` возвращает размер типа в битах + 1.
- **Многопоточность:** макросы не генерируют код, поэтому потокобезопасны.
- **Только беззнаковые:** макросы предназначены для беззнаковых целочисленных типов; использование со знаковыми типами приводит к неопределённому поведению.
