## Описание библиотеки

Заголовочный файл `<stdio.h>` определяет типы, макросы и функции для стандартного буферизованного ввода-вывода. Этот заголовок является основным средством работы с файлами и потоками данных в C.

### Типы

| Тип | Описание |
|---|---|
| `FILE` | Структура, содержащая информацию о файле |
| `fpos_t` | Тип, содержащий всю информацию для точного указания позиции в файле |
| `size_t` | Беззнаковый целочисленный тип размера (из `<stddef.h>`) |
| `ssize_t` | Знаковый целочисленный тип размера (POSIX) |
| `va_list` | Тип для передачи переменного числа аргументов (из `<stdarg.h>`) |

### Константы

| Константа | Описание |
|---|---|
| `BUFSIZ` | Размер буфера `<stdio.h>` (положительное значение) |
| `EOF` | Возвращаемое значение при конце файла (отрицательное `int`) |
| `FILENAME_MAX` | Максимальный размер в байтах пути к файлу |
| `FOPEN_MAX` | Гарантированно количество одновременно открытых потоков (не менее 8) |
| `TMP_MAX` | Минимальное количество уникальных имён, генерируемых `tmpnam()` (не менее 25) |
| `L_tmpnam` | Максимальный размер массива символов для вывода `tmpnam()` |
| `L_ctermid` | Максимальный размер массива символов для вывода `ctermid()` |
| `SEEK_SET` | Позиционирование относительно начала файла |
| `SEEK_CUR` | Позиционирование относительно текущей позиции |
| `SEEK_END` | Позиционирование относительно конца файла |
| `_IOFBF` | Полная буферизация |
| `_IOLBF` | Построчная буферизация |
| `_IONBF` | Без буферизации |
| `P_tmpdir` | Каталог по умолчанию для `tempnam()` |

### Стандартные потоки

| Поток | Описание |

| `stdin` | Стандартный поток ввода |
| `stdout` | Стандартный поток вывода |
| `stderr` | Стандартный поток ошибок |

## Исключения

- **NULL:** все функции, принимающие указатель на `FILE*`, определены для `NULL` (поведение не определено).
- **errno:** при ошибке устанавливается `errno`; конкретные значения зависят от функции (например, `EDOM`, `ERANGE`, `EILSEQ`).
- **Безопасность:** функции `sprintf`, `gets`, `scanf` без ограничения длины небезопасны; предпочтительнее `snprintf`, `fgets`, `sscanf`.
- **Потоки:** стандартные потоки `stdin`, `stdout`, `stderr` инициализируются автоматически и не требуют открытия.
- **Буферизация:** по умолчанию `stdout` буферизуется построчно (при подключении к терминалу) или полностью (при перенаправлении).
- **Многопоточность:** функции ввода-вывода являются MT-Safe, но для защиты отacedni的竞争状态 необходимо использовать блокировку (`flockfile`/`funlockfile`) или функции `*_unlocked`.
- **Временные файлы:** `tmpfile()` создаёт файл, который автоматически удаляется при закрытии; `tmpnam()` небезопасна для многопоточной среды.
