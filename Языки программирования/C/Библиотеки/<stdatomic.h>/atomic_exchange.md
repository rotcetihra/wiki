## Определение

```c
#include <stdatomic.h>

C atomic_exchange(volatile A *object, C value);
C atomic_exchange_explicit(volatile A *object, C value, memory_order order);
```

## Описание

Функция `atomic_exchange` атомарно заменяет значение атомарной переменной `object` на `value` и возвращает предыдущее значение. Операция выполняется немедленно и гарантированно атомарно.

Версия `atomic_exchange_explicit` позволяет указать модель памяти.

## Пример

```c
#include <stdio.h>
#include <stdatomic.h>

atomic_int flag = 0;

int main(void)
{
    int old = atomic_exchange(&flag, 1);
    printf("Старое значение: %d, новое: %d\n", old, atomic_load(&flag));
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `object` | Указатель на атомарную переменную |
| `value` | Новое значение |
| `order` | Модель памяти (только `_explicit` версия) |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `C` | Предыдущее значение переменной до обмена |

## Обработка ошибок

- **Поведение при передаче NULL:** поведение не определено. Указатель `object` должен указывать на валидную атомарную переменную.
- **Установление errno:** функция не устанавливает `errno`.
- **Возвращаемое значение при ошибке:** не применимо — функция всегда возвращает предыдущее значение.
- **Многопоточность:** операция является атомарной и потокобезопасной. Замена значения и возврат старого выполняются за одну атомарную операцию.
- **Связанные функции:** `atomic_compare_exchange` — атомарное сравнение и обмен (более гибкий, но сложнее); `atomic_store` — простая атомарная запись без возврата старого значения.
