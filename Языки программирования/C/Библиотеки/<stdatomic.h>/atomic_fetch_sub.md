## Определение

```c
#include <stdatomic.h>

C atomic_fetch_sub(volatile A *object, C operand);
C atomic_fetch_sub_explicit(volatile A *object, C operand, memory_order order);
```

## Описание

Функция `atomic_fetch_sub` атомарно вычитает `operand` из значения атомарной переменной `object` и возвращает предыдущее значение.

Версия `atomic_fetch_sub_explicit` позволяет указать модель памяти.

## Пример

```c
#include <stdio.h>
#include <stdatomic.h>

atomic_int counter = 10;

void decrement(void)
{
    atomic_fetch_sub(&counter, 1);
}

int main(void)
{
    decrement();
    decrement();
    printf("Счётчик: %d\n", atomic_load(&counter));
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `object` | Указатель на атомарную переменную |
| `operand` | Значение для вычитания |
| `order` | Модель памяти (только `_explicit` версия) |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `C` | Предыдущее значение переменной до вычитания |

## Плюсы и минусы

## Обработка ошибок

- **Поведение при передаче NULL:** поведение не определено. Указатель `object` должен указывать на валидную атомарную переменную.
- **Установление errno:** функция не устанавливает `errno`.
- **Возвращаемое значение при ошибке:** не применимо — функция всегда возвращает предыдущее значение.
- **Многопоточность:** операция является атомарной и потокобезопасной. Вычитание и возврат предыдущего значения выполняются за одну атомарную операцию.
- **Связанные функции:** `atomic_fetch_add` — атомарное сложение; `atomic_thread_fence` — барьер памяти.
