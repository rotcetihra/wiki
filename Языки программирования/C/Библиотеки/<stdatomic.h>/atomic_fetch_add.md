## Определение

```c
#include <stdatomic.h>

C atomic_fetch_add(volatile A *object, C operand);
C atomic_fetch_add_explicit(volatile A *object, C operand, memory_order order);
```

## Описание

Функция `atomic_fetch_add` атомарно прибавляет `operand` к значению атомарной переменной `object` и возвращает предыдущее значение. Операция выполняется немедленно и гарантированно атомарно.

Версия `atomic_fetch_add_explicit` позволяет указать модель памяти.

## Пример

```c
#include <stdio.h>
#include <stdatomic.h>

atomic_int counter = 0;

void increment(void)
{
    atomic_fetch_add(&counter, 1);
}

int main(void)
{
    increment();
    increment();
    increment();
    printf("Счётчик: %d\n", atomic_load(&counter));
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `object` | Указатель на атомарную переменную |
| `operand` | Значение для прибавления |
| `order` | Модель памяти (только `_explicit` версия) |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `C` | Предыдущее значение переменной до сложения |

## Обработка ошибок

- **Поведение при передаче NULL:** поведение не определено. Указатель `object` должен указывать на валидную атомарную переменную.
- **Установление errno:** функция не устанавливает `errno`.
- **Возвращаемое значение при ошибке:** не применимо — функция всегда возвращает предыдущее значение.
- **Многопоточность:** операция является атомарной и потокобезопасной. Сложение и возврат предыдущего значения выполняются за одну атомарную операцию.
- **Связанные функции:** `atomic_fetch_sub` — атомарное вычитание; `atomic_compare_exchange` — атомарное сравнение и обмен.
