## Определение

```c
#include <stdatomic.h>

C atomic_load(volatile A *object);
C atomic_load_explicit(volatile A *object, memory_order order);
```

## Описание

Функция `atomic_load` выполняет атомарное чтение значения из атомарной переменной `object`. Возвращает значение переменной.

Версия `atomic_load_explicit` позволяет указать модель памяти для управления порядком выполнения операций.

## Пример

```c
#include <stdio.h>
#include <stdatomic.h>
#include <threads.h>

atomic_int shared = 0;

void worker(void *arg)
{
    (void)arg;
    while (atomic_load_explicit(&shared, memory_order_acquire) == 0) {
        /* ожидание */
    }
    printf("Получено: %d\n", atomic_load(&shared));
}

int main(void)
{
    thrd_t t;
    thrd_create(&t, worker, NULL);
    atomic_store(&shared, 42);
    thrd_join(t, NULL);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `object` | Указатель на атомарную переменную |
| `order` | Модель памяти (только `_explicit` версия) |

| Значение | Описание |

| `C` | Атомарно прочитанное значение переменной |

## Обработка ошибок

- **Поведение при передаче NULL:** поведение не определено. Указатель `object` должен указывать на валидную атомарную переменную.
- **Установление errno:** функция не устанавливает `errno`.
- **Возвращаемое значение при ошибке:** не применимо — функция всегда возвращает текущее значение переменной.
- **Многопоточность:** операция является атомарной и потокобезопасной по определению. Гарантирует правильную видимость значения в соответствии с указанной моделью памяти.
- **Связанные функции:** `atomic_store` — атомарная запись; `atomic_exchange` — атомарный обмен с возвратом старого значения.
