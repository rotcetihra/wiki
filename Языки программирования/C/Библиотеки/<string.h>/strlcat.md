## Прототип

```c
#include <string.h> // BSD (в glibc — при __USE_MISC)

size_t strlcat(char *dest, const char *src, size_t size);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dest` | Строка, в конец которой дописывается `src` |
| `src` | Дописываемая строка |
| `size` | Полный размер буфера `dest` |

## Возвращаемое значение

Возвращает длину, которую имела бы итоговая строка без ограничения буфера (`strlen(dest) + strlen(src)`). Если возвращённое значение ≥ `size` — произошло усечение.

## Что делает

Безопасно дописывает `src` в конец `dest`: гарантирует завершающий нуль, никогда не пишет за пределы буфера размером `size` и позволяет обнаружить усечение по возвращаемому значению. Пришла из BSD, во многих последних версиях glibc отсутствует (по лицензионным соображениям) — используйте с осторожностью.

>[!NOTE]
>Возвращаемое значение — длина **желаемого** результата, а не записанного. Проверка `strlcat(dest, src, size) >= size` обнаруживает усечение.

## Примеры

### Безопасное дописывание

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char path[16] = "/home";

    size_t needed = strlcat(path, "/user", sizeof(path));
    if (needed >= sizeof(path)) {
        printf("Усечено: %s\n", path);
    } else {
        printf("%s\n", path); // /home/user
    }

    return 0;
}
```

### Обнаружение усечения

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char buf[8] = "Hi";
    size_t needed = strlcat(buf, " there, world", sizeof(buf));

    printf("Строка: %s\n", buf);        // Hi ther (усечена)
    printf("Нужно было: %zu\n", needed); // 14

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Усечение не является ошибкой — оно обнаруживается сравнением возвращаемого значения с `size`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантированный завершающий нуль | Нет в glibc по умолчанию |
| Не пишет за пределы буфера | Семантика возврата неочевидна |
| Обнаружение усечения | Не входит в POSIX |
