## Прототип

```c
#include <string.h>

void *memset(void *s, int c, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Указатель на блок памяти для заполнения |
| `c` | Значение для заполнения (приводится к `unsigned char`) |
| `n` | Количество байт для заполнения |

## Возвращаемое значение

Возвращает `s`.

## Что делает

Заполняет первые `n` байт блока памяти `s` значением `c` (младший байт `int`). Применяется для обнуления массивов, инициализации структур, заполнения буферов нулями. Работает с произвольными данными — не требует завершающего нуля.

## Примеры

### Обнуление массива

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    int arr[4] = {1, 2, 3, 4};
    memset(arr, 0, sizeof(arr));
    printf("%d %d %d %d\n", arr[0], arr[1], arr[2], arr[3]); // 0 0 0 0

    return 0;
}
```

### Заполнение строки пробелами

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char line[20];
    memset(line, ' ', sizeof(line) - 1);
    line[sizeof(line) - 1] = '\0';
    printf("|%s|\n", line); // |                   |

    return 0;
}
```

### Заполнение буфера определённым байтом

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char buf[8];
    memset(buf, 0xFF, sizeof(buf));
    printf("%02X %02X %02X\n", buf[0], buf[1], buf[2]); // FF FF FF

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Неопределённое поведение возникает при обращении по невалидному указателю.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и быстрая (SIMD-оптимизация) | Заполняет байты, а не элементы (ОСТОРОЖНО с `int`) |
| Работает с произвольными данными | Не проверяет размер буфера |
| Стандартная и переносимая | |

>[!WARNING]
>`memset(arr, 1, sizeof(arr))` для массива `int` заполнит каждый байт единицей (0x01), а не каждое целое числом единицей. Для заполнения массива значением, отличным от нуля, используйте цикл.

## Альтернативы

- **`memset_s()` (C11, Annex K)** — безопасная версия с проверкой размера
- **`explicit_bzero()` (POSIX)** — обнуление, которое компилятор не удалит при неиспользовании результата
- **Цикл `for`** — заполнение элементами, а не байтами
