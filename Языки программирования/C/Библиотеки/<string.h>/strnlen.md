## Прототип

```c
#include <string.h>

size_t strnlen(const char *s, size_t maxlen); // C11
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Строка, длина которой определяется |
| `maxlen` | Максимальная проверяемая длина |

## Возвращаемое значение

Возвращает длину строки `s`, но не более `maxlen`. Если в первых `maxlen` байтах нуль не найден, возвращает `maxlen`.

## Что делает

Безопасная версия `strlen()` с ограничением максимальной длины. Если строка не завершена нулём в пределах `maxlen` байт, функция не выходит за границы массива и возвращает `maxlen`. Подходит для буферов без гарантированного завершающего нуля.

## Примеры

### Определение длины безопасной строки

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char buf[8] = "hello";

    printf("%zu\n", strnlen(buf, sizeof(buf))); // 5

    return 0;
}
```

### Буфер без завершающего нуля

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char no_term[8];
    memset(no_term, 'a', sizeof(no_term)); // Нет завершающего нуля

    printf("%zu\n", strnlen(no_term, sizeof(no_term))); // 8 — безопасно

    return 0;
}
```

### Ограничение поиска

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *str = "hello world";

    // Ищем нуль только в первых 5 байтах
    printf("%zu\n", strnlen(str, 5));  // 5 (нуль не найден)
    printf("%zu\n", strnlen(str, 20)); // 11 (полная длина)

    return 0;
}
```

## Ошибки и errno

- **Возвращаемое значение при ошибке:** `maxlen` если нуль не найден в первых `maxlen` байтах
- **Установление errno:** функция не устанавливает `errno`
- **Поведение при передаче NULL:** неопределённое поведение (аварийный завершение или некорректный доступ к памяти)
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние)
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<string.h>/strlen|strlen]] — определение длины строки (требует завершающий нуль); [[Языки программирования/C/Библиотеки/<string.h>/memchr|memchr]] — поиск байта в ограниченном блоке памяти

Неопределённое поведение также возникает при обращении по невалидному указателю.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Безопасна для буферов без нуля | Возвращает `maxlen` при отсутствии нуля (не реальную длину) |
| Ограничивает количество проверяемых байт | Стандартная только с C11 |
| Быстрая (SIMD-оптимизация) | |

## Альтернативы

- **`strlen()`** — определение длины (требует завершающий нуль)
- **`wcslen()`** — длина宽 символа (из `<wchar.h>`)
- **Ручной цикл** — посимвольный подсчёт с ограничением
