## Прототип

```c
#include <string.h> // GNU

void *memfrob(void *s, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Блок памяти для «шифрования» |
| `n` | Количество байт |

## Возвращаемое значение

Возвращает указатель `s`.

## Что делает

«Шифрует» каждый байт блока `s` операцией XOR с константой `42` (0x2A). Повторное применение восстанавливает исходные данные (XOR самодвойственен). Не является настоящим шифрованием — только обфускация.

>[!WARNING]
>Это не шифрование! Любой, кто знает константу 42, мгновенно восстановит данные. Функция служит для обфускации (например, строк в исполняемом файле) и не даёт никакой защиты.

## Примеры

### Кодирование и декодирование строки

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char secret[] = "Hello, secret!";

    memfrob(secret, strlen(secret)); // «Шифруем»
    printf("Зашифровано: %s\n", secret); // Нечитаемые символы

    memfrob(secret, strlen(secret)); // Второй раз — расшифровка
    printf("Расшифровано: %s\n", secret); // Hello, secret!

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Передача невалидного указателя — неопределённое поведение.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая обфускация строк | Не настоящая защита |
| Работает на месте, без выделения памяти | Может не сработать для многобайтовых кодировок |
| Обратима повторным вызовом | |
