## Прототип

```c
#include <string.h>

char *strstr(const char *haystack, const char *needle);
```

## Параметры

| Параметр | Описание |
|---|---|
| `haystack` | Строка, в которой ищется подстрока |
| `needle` | Искомая подстрока |

## Возвращаемое значение

Возвращает указатель на первое вхождение подстроки `needle` в строке `haystack`. Если подстрока не найдена, возвращает `NULL`. Если `needle` — пустая строка, возвращается `haystack`.

## Что делает

Ищет первое вхождение подстроки `needle` в строке `haystack`. Подстрока ищется целиком: `strstr("abcab", "cab")` находит вхождение в позиции 2. Стандарт не ограничивает сложность алгоритма, поэтому в большинстве реализаций поиск выполняется «наивно» и для длинных строк может работать медленнее специализированных алгоритмов.

Возвращаемый указатель указывает внутрь исходной строки: запись через него изменяет строку.

## Примеры

### Базовый поиск подстроки

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *text = "Hello, world!";
    char *found = strstr(text, "world");
    if (found != NULL) {
        printf("Найден на позиции: %td\n", found - text); // 7
        printf("Остаток: %s\n", found); // world!
    }

    return 0;
}
```

### Поиск пустой подстроки

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *text = "hello";
    char *found = strstr(text, "");
    printf("Пустая подстрока: %s\n", found); // hello (возвращает haystack)

    return 0;
}
```

### Подсчёт вхождений подстроки

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *text = "abababa";
    const char *needle = "aba";
    int count = 0;

    const char *p = text;
    while ((p = strstr(p, needle)) != NULL) {
        count++;
        p++; // Сдвигаемся на 1 символ для поиска перекрывающихся вхождений
    }

    printf("Вхождений: %d\n", count); // 3

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Неопределённое поведение возникает при обращении по невалидным указателям.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая в использовании | Наивный алгоритм O(n*m) |
| Стандартная и переносимая | Медленнее специализированных алгоритмов |
| Возвращает указатель на остаток строки | |

## Альтернативы

- **`memmem()`** (GNU/POSIX) — поиск подстроки в ограниченном блоке памяти
- **`strcasestr()`** (GNU/POSIX) — поиск без учёта регистра
- **Алгоритм Кнута-Морриса-Пратта** — для длинных строк
