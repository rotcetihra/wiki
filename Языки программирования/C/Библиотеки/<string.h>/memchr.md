## Прототип

```c
#include <string.h>

void *memchr(const void *s, int c, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Указатель на блок памяти для поиска |
| `c` | Искомый байт (приводится к `unsigned char` перед сравнением) |
| `n` | Максимальное количество байт для проверки |

## Возвращаемое значение

Возвращает указатель на первое вхождение байта `c` в первых `n` байтах блока `s`. Если байт не найден, возвращает `NULL`.

## Что делает

Ищет первый байт со значением `c` среди первых `n` байт блока памяти `s`. В отличие от `strchr()`, не требует завершающего нуля — работает с произвольными данными: структурами, бинарными блоками, файловыми буферами. Значение `c` приводится к `unsigned char`, поэтому можно искать и нулевой байт: `memchr(data, 0, size)`.

## Примеры

### Базовый поиск

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char text[] = "Hello, world!";
    void *found = memchr(text, 'w', sizeof(text) - 1);
    if (found != NULL) {
        printf("Найден на позиции: %td\n", (const char *)found - text); // 7
    }
    return 0;
}
```

### Поиск нулевого байта в бинарных данных

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char data[] = {0x10, 0x00, 0xFF, 0x20};
    void *found = memchr(data, 0x00, sizeof(data));
    if (found != NULL) {
        printf("Нуль найден на позиции: %td\n", (char *)found - data); // 1
    }
    return 0;
}
```

### Поиск без ограничения длины строки

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    // Буфер без завершающего нуля
    char buf[8] = {'a', 'b', 'c', 'd', 'e', 'f', 'g', 'h'};
    void *found = memchr(buf, 'e', sizeof(buf));
    if (found != NULL) {
        printf("Найден на позиции: %td\n", (char *)found - buf); // 4
    }
    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Единственный способ проверить, найден ли байт — проверить возвращаемое значение на `NULL`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Работает с произвольными данными | Ограничивает поиск первыми `n` байтами |
| Не требует завершающего нуля | Возвращает `NULL` без информации о позиции |
| Простая и быстрая (обычно SIMD-оптимизирована) | Не заменяет `strchr()` для строк (ищет байты, а не символы) |

## Альтернативы

- **`strchr()`** (ISO C89) — поиск символа в завершённой строке, возвращает указатель на строку
- **`memrchr()`** (GNU extension) — поиск последнего вхождения, не в стандарте C
- **Цикл с `for`** — ручной поиск, медленнее оптимизированных реализаций
