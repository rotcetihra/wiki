## Прототип

```c
#include <string.h>

void *memmove(void *dest, const void *src, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dest` | Указатель на.destination — куда копируются данные |
| `src` | Указатель на.source — откуда копируются данные |
| `n` | Количество байт для копирования |

## Возвращаемое значение

Возвращает `dest`.

## Что делает

Копирует `n` байт из блока `src` в блок `dest`. В отличие от `memcpy()`, корректно обрабатывает перекрытие областей: копирование безопасно даже если `dest` и `src` указывают на общую область памяти. Функция копирует данные как есть, включая нулевые байты. Поскольку функция не может предполагать отсутствия перекрытия, она лишена оптимизаций, доступных `memcpy()`.

## Примеры

### Сдвиг массива вправо

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    int arr[5] = {1, 2, 3, 4, 5};
    // Сдвигаем элементы на 1 позицию вправо: arr[1..4] ← arr[0..3]
    memmove(arr + 1, arr, 4 * sizeof(int));
    printf("arr[0]: %d, arr[1]: %d, arr[4]: %d\n", arr[0], arr[1], arr[4]); // 1, 1, 4

    return 0;
}
```

### Сдвиг массива влево

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    int arr[5] = {1, 2, 3, 4, 5};
    // Сдвигаем элементы на 1 позицию влево: arr[0..3] ← arr[1..4]
    memmove(arr, arr + 1, 4 * sizeof(int));
    printf("arr[0]: %d, arr[3]: %d, arr[4]: %d\n", arr[0], arr[3], arr[4]); // 2, 5, 5

    return 0;
}
```

### Удаление элемента из середины массива

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    int arr[] = {1, 2, 3, 4, 5, 6};
    size_t len = 6;
    size_t idx = 2; // Удаляем элемент с индексом 2 (значение 3)

    memmove(arr + idx, arr + idx + 1, (len - idx - 1) * sizeof(int));
    len--;

    for (size_t i = 0; i < len; i++) {
        printf("%d ", arr[i]); // 1 2 4 5 6
    }

    return 0;
}
```

## Ошибки и errno

- **Возвращаемое значение при ошибке:** не применимо (всегда возвращает `dest`)
- **Установление errno:** функция не устанавливает `errno`
- **Поведение при передаче NULL:** неопределённое поведение (аварийный завершение или некорректный доступ к памяти)
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние)
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<string.h>/memcpy|memcpy]] — быстрее, но не обрабатывает перекрытие областей

Неопределённое поведение также возникает при обращении по невалидным указателям.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Безопасна при перекрытии областей | Медленнее `memcpy()` при отсутствии перекрытия |
| Копирует произвольные данные | Не проверяет размер буфера `dest` |
| Стандартная и переносимая | |

## Альтернативы

- **`memcpy()`** — быстрее, но не обрабатывает перекрытие
- **Цикл с копированием элементов** — корректен при перекрытии, но медленнее
