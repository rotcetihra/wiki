## Прототип

```c
#include <string.h>

int strncmp(const char *s1, const char *s2, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1` | Первая строка для сравнения |
| `s2` | Вторая строка для сравнения |
| `n` | Максимальное количество символов для сравнения |

## Возвращаемое значение

Возвращает значение < 0, если `s1` меньше `s2` в пределах `n` символов; 0, если строки равны в пределах `n` символов или до нуля; > 0, если `s1` больше `s2`. Сравнение побайтовое.

## Что делает

Сравнивает не более `n` символов строк `s1` и `s2`. Если строки равны в пределах `n` символов (или до завершающего нуля), возвращает 0. Удобно для проверки префиксов: `strncmp(s, "prefix", 6) == 0`. В отличие от `strncpy()`, не дополняет результат — просто ограничивает количество сравниваемых символов.

## Примеры

### Проверка префикса

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *filename = "report.txt";

    if (strncmp(filename, "report", 6) == 0) {
        printf("Это отчёт\n");
    }

    return 0;
}
```

### Проверка суффикса

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *file = "image.png";
    size_t name_len = strlen(file);
    size_t ext_len = strlen(".png");

    if (name_len >= ext_len &&
        strcmp(file + name_len - ext_len, ".png") == 0) {
        printf("PNG файл\n");
    }

    return 0;
}
```

### Сравнение с ограничением длины

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    printf("%d\n", strncmp("abc", "abz", 2)); // 0: первые 2 символа равны
    printf("%d\n", strncmp("abc", "abd", 3)); // отрицательное

    return 0;
}
```

## Ошибки и errno

- **Возвращаемое значение при ошибке:** не применимо (возвращает знаковый результат сравнения)
- **Установление errno:** функция не устанавливает `errno`
- **Поведение при передаче NULL:** неопределённое поведение (аварийный завершение или некорректный доступ к памяти)
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние)
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<string.h>/strcmp|strcmp]] — сравнение без ограничения длины; [[Языки программирования/C/Библиотеки/<string.h>/memcmp|memcmp]] — сравнение блоков памяти

Неопределённое поведение также возникает при обращении по невалидным указателям.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Удобна для проверки префиксов | Не возвращает длину совпадения |
| Не сравнивает лишние символы | Сравнивает побайтово, без локали |
| Стандартная и переносимая | |

## Альтернативы

- **`strcmp()`** — сравнение без ограничения длины
- **`strcoll()`** — сравнение с учётом локали
- **`memcmp()`** — сравнение блоков памяти
