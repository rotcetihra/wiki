## Прототип

```c
#include <string.h> // POSIX.1-2008

char *strerror_l(int errnum, locale_t locale);
```

## Параметры

| Параметр | Описание |
|---|---|
| `errnum` | Код ошибки (обычно `errno`) |
| `locale` | Локаль, в которой переводить описание (тип `locale_t`) |

## Возвращаемое значение

Возвращает указатель на строку с описанием ошибки в нужной локали. Строка статическая — не изменяйте её.

## Что делает

Вариант [[Языки программирования/C/Библиотеки/<string.h>/strerror|strerror()]], который переводит описание в заданную локаль явно, а не в текущую глобальную. Удобно, когда программа выводит сообщения на языке пользователя, отличном от языка системы.

## Примеры

### Перевод описания в нужную локаль

```c
#include <stdio.h>
#include <string.h>
#include <locale.h>

int main(void)
{
    locale_t ru = newlocale(LC_MESSAGES_MASK, "ru_RU.UTF-8", NULL);
    if (ru != NULL) {
        printf("%s\n", strerror_l(ENOENT, ru)); // «Нет такого файла...» (если локализация доступна)
        freelocale(ru);
    }

    return 0;
}
```

## Ошибки и errno

- **Возвращаемое значение при ошибке:** не определено при невалидной локали
- **Установление errno:** функция не устанавливает `errno`
- **Поведение при передаче NULL:** не применимо (принимает целое число и локаль, а не указатель на строку)
- **Многопоточность:** потокобезопасна (не использует глобальную локаль, в отличие от `strerror()`)
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<string.h>/strerror|strerror]] — описание в глобальной локали; [[Языки программирования/C/Библиотеки/<string.h>/strerror_r|strerror_r]] — потокобезопасный вариант; [[Языки программирования/C/Библиотеки/<string.h>/strerror_s|strerror_s]] — безопасный вариант (C11 Annex K)

Если `locale` невалидна — поведение не определено. Значение `errno` не изменяется.

>[!NOTE]
>Наличие перевода зависит от установленных языковых пакетов системы: даже при запросе `ru_RU.UTF-8` описание может остаться английским, если локализация не установлена.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Явное управление языком | Статический буфер — не для хранения |
| Независима от глобальной локали | Только POSIX.1-2008 |
| | Нужно управлять локалью |
