## Прототип

```c
#include <string.h> // GNU

char *strchrnul(const char *s, int c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Строка для поиска |
| `c` | Искомый символ (приводится к `char`) |

## Возвращаемое значение

Возвращает указатель на первое вхождение символа `c` в строке `s`. Если символ не найден — возвращает указатель на завершающий нуль строки `s` (вместо `NULL`, как `strchr()`).

## Что делает

Похожа на [[Языки программирования/C/Библиотеки/<string.h>/strchr|strchr()]], но вместо `NULL` при отсутствии символа возвращает указатель на конец строки. Результат всегда не `NULL` — это удобно, когда вызывающий и так собирается обрабатывать конец строки: не нужно проверять `NULL` отдельно.

## Примеры

### Поиск без проверки NULL

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *msg = "key:value";

    // Найдётся ':' или конец строки — NULL не бывает
    char *colon = strchrnul(msg, ':');
    if (*colon == ':') {
        printf("Разделитель на позиции %td\n", colon - msg); // 3
    } else {
        printf("Разделителя нет\n");
    }

    return 0;
}
```

### Отрезка хвоста строки

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char path[] = "/home/user/file.txt";

    // Обрезаем по первому слэшу (или до конца — тогда ничего не меняем)
    char *slash = strchrnul(path, '/');
    if (*slash != '\0') {
        slash++;
    }
    printf("%s\n", slash); // home/user/file.txt

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Передача невалидного указателя — неопределённое поведение.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Никогда не возвращает NULL | Только GNU-расширение |
| Удобна в цикле разбора | Нужно проверять, `'\0'` это или символ |
| | Может ввести в заблуждение при переносе |
