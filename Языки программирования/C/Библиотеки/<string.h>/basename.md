## Прототип

```c
#include <string.h> // GNU-вариант (glibc)

char *basename(const char *filename);
```

>[!WARNING]
>Существуют **два несовместимых** варианта `basename()`: GNU-вариант из `<string.h>` (в glibc) и POSIX-вариант из `<libgen.h>`, который может модифицировать переданную строку. Код, написанный под один вариант, может некорректно работать под другим.

## Параметры

| Параметр | Описание |
|---|---|
| `filename` | Полный путь к файлу (например, `/home/user/docs/report.txt`) |

## Возвращаемое значение

Возвращает указатель на последний компонент пути — имя файла без каталогов. GNU-вариант не модифицирует входную строку и возвращает указатель внутрь неё.

## Что делает

Выделяет из полного пути имя файла: `basename("/home/user/report.txt")` возвращает `"report.txt"`. GNU-вариант (glibc) не изменяет аргумент — это безопаснее POSIX-версии из `<libgen.h>`, которая может перезаписать строку.

## Примеры

### Извлечение имени файла

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *path = "/home/user/docs/report.txt";
    printf("%s\n", basename(path)); // report.txt

    return 0;
}
```

### Обработка краевых случаев

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    printf("%s\n", basename("/usr/lib/")); // lib — хвостовой слэш отбрасывается
    printf("%s\n", basename("file.txt"));  // file.txt — без каталогов
    printf("%s\n", basename("/"));         // / — корень возвращает слэш

    return 0;
}
```

## Ошибки и errno

- **Возвращаемое значение при ошибке:** не определено при невалидном указателе
- **Установление errno:** функция не устанавливает `errno`
- **Поведение при передаче NULL:** неопределённое поведение (аварийный завершение или некорректный доступ к памяти)
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние)
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<string.h>/strrchr|strrchr]] — поиск последнего вхождения символа для извлечения имени файла

Результат не определён, если передать указатель на невалидную память.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и удобная | Два несовместимых варианта (GNU и POSIX) |
| GNU-вариант не модифицирует строку | POSIX-вариант может перезаписать аргумент |
| | Не переносима между glibc и POSIX-системами |
