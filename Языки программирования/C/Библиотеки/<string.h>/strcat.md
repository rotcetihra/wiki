## Прототип

```c
#include <string.h>

char *strcat(char *dest, const char *src);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dest` | Указатель на.destination-строку, в которую дописывается `src` |
| `src` | Указатель на.source-строку для дописывания |

## Возвращаемое значение

Возвращает `dest`.

## Что делает

Находит завершающий нуль в строке `dest` и дописывает с этого места строку `src` (вместе с завершающим нулём). Буфер `dest` должен вмещать результат — иначе неопределённое поведение (запись за границы). Области `dest` и `src` не должны перекрываться.

>[!WARNING]
>Каждый вызов `strcat()` заново проходит `dest` до завершающего нуля, поэтому поочерёдное дописывание фрагментов в цикле выполняется за квадратичное время O(n²).

## Примеры

### Базовое дописывание

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char message[32] = "Hello, ";
    strcat(message, "world");
    printf("%s\n", message); // Hello, world

    return 0;
}
```

### Формирование полного пути

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char path[64] = "/home/user";
    strcat(path, "/documents");
    strcat(path, "/report.txt");
    printf("%s\n", path); // /home/user/documents/report.txt

    return 0;
}
```

### Оптимизация: дописывание с хвоста

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char buf[64] = "Hello";
    char *end = buf + strlen(buf); // Указатель на конец строки

    strcpy(end, ", ");
    end += 2;
    strcpy(end, "world");
    printf("%s\n", buf); // Hello, world

    return 0;
}
```

## Ошибки и errno

- **Возвращаемое значение при ошибке:** не применимо (всегда возвращает `dest`)
- **Установление errno:** функция не устанавливает `errno`
- **Поведение при передаче NULL:** неопределённое поведение (аварийный завершение или некорректный доступ к памяти)
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние)
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<string.h>/strncat|strncat]] — безопасное дописывание с ограничением длины; [[Языки программирования/C/Библиотеки/<string.h>/strlcat|strlcat]] — безопасная версия с проверкой размера (BSD)

Неопределённое поведение также возникает при недостаточном размере буфера `dest` или перекрытии областей.

>[!WARNING]
>`strcat()` не проверяет размер буфера. Безопаснее использовать `strncat()` или `strcat_s()` (C11 Annex K).

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая в использовании | Не проверяет размер буфера |
| Гарантирует завершающий нуль | O(n) на каждый вызов для поиска конца dest |
| Стандартная и переносимая | O(n²) при многократном дописывании в цикле |

## Альтернативы

- **`strncat()`** — дописывает не более `n` символов, гарантированно добавляет нуль
- **`strlcat()`** (BSD) — безопасное конкатенирование с проверкой размера
- **`strcat_s()`** (C11 Annex K) — проверка размера буфера, код ошибки
- **Ручное копирование через указатель** — как в примере с `end`, избегает повторного прохода
