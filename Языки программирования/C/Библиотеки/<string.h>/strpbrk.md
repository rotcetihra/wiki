## Прототип

```c
#include <string.h>

char *strpbrk(const char *s1, const char *s2);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1` | Строка, в которой ищется первый символ из набора |
| `s2` | Набор символов для поиска |

## Возвращаемое значение

Возвращает указатель на первый символ строки `s1`, который встречается в наборе `s2`. Если таких символов нет, возвращает `NULL`.

## Что делает

Ищет первый символ строки `s1`, который является одним из символов строки `s2`. Возвращаемый указатель указывает внутрь исходной строки `s1`. Удобна для поиска первого разделителя без модификации строки (в отличие от `strtok()`).

## Примеры

### Поиск первого разделителя

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *line = "user:password:home";
    char *colon = strpbrk(line, ":");
    if (colon != NULL) {
        printf("Разделитель на позиции: %td\n", colon - line); // 4
        printf("Остаток: %s\n", colon); // :password:home
    }

    return 0;
}
```

### Определение типа строки

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *str = "42";
    if (strpbrk(str, ".eE") != NULL) {
        printf("Вещественное число\n");
    } else {
        printf("Целое число\n");
    }

    return 0;
}
```

### Разбиение строки без модификации

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *csv = "apple,banana,cherry";
    const char *p = csv;

    while (p != NULL) {
        printf("Элемент: %.*s\n",
               (int)(strcspn(p, ",") , strcspn(p, ","));
        p = strpbrk(p, ",");
        if (p != NULL) p++; // Пропускаем разделитель
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Неопределённое поведение возникает при обращении по невалидным указателям.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Не модифицирует строку | Ищет только первый символ из набора |
| Простая семантика | Линейная сложность O(n*m) |
| Стандартная и переносимая | |

## Альтернативы

- **`strtok()`** — разбиение на токены с модификацией строки
- **`strcspn()`** — длина начального сегмента без символов из набора
- **Цикл с `strchr()`** — поиск каждого разделителя по очереди
