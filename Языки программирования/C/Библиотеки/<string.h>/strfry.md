## Прототип

```c
#include <string.h> // GNU

char *strfry(char *string);
```

## Параметры

| Параметр | Описание |
|---|---|
| `string` | Строка, символы которой нужно «перемешать» |

## Возвращаемое значение

Возвращает указатель `string` (строка изменяется на месте).

## Что делает

Случайным образом переставляет символы строки (каждый символ равновероятно меняется местами с любым другим). Применение — обфускация строк, игровые механики, генерация «бессмысленного» текста. Не является криптографическим перемешиванием.

>[!WARNING]
>Функция изменяет строку на месте — передавать строковый литерал нельзя (неизменяемая память). Результат недетерминирован: зависит от генератора случайных чисел.

## Примеры

### Перемешивание строки

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char word[] = "abcdef";

    strfry(word);
    printf("%s\n", word); // Например: "dfcaeb"

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Передача литерала или невалидного указателя — неопределённое поведение.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая обфускация | Только GNU-расширение |
| Работает на месте | Изменяет строку (литералы нельзя) |
| | Не криптографический генератор |
