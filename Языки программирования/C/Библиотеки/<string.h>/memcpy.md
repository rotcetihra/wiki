## Прототип

```c
#include <string.h>

void *memcpy(void *dest, const void *src, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dest` | Указатель на.destination — массив или блок памяти, куда копируются данные |
| `src` | Указатель на.source — откуда копируются данные |
| `n` | Количество байт для копирования |

## Возвращаемое значение

Возвращает `dest` — результат можно использовать в выражении.

## Что делает

Копирует `n` байт из блока `src` в блок `dest`. Оба указателя помечены `restrict`: компилятор вправе считать, что области не перекрываются, и оптимизировать копирование (например, векторными инструкциями). Функция копирует данные как есть, включая нулевые байты, поэтому подходит для структур и бинарных данных. Также является стандартным способом переинтерпретации представления одного типа как другого (type punning).

>[!WARNING]
>Если области `dest` и `src` могут перекрываться, используйте `memmove()`. Применение `memcpy()` к перекрывающимся областям — неопределённое поведение.

## Примеры

### Базовое копирование

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    int src[4] = {1, 2, 3, 4};
    int dest[4];

    memcpy(dest, src, sizeof(src)); // Копирование 16 байт (4 элемента int)
    printf("dest[2]: %d\n", dest[2]); // 3

    return 0;
}
```

### Копирование строки в массив

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char dest[16];
    const char *src = "Hello";

    memcpy(dest, src, strlen(src) + 1); // +1 для завершающего нуля
    printf("%s\n", dest); // Hello

    return 0;
}
```

### Type punning: float как целое

```c
#include <stdio.h>
#include <string.h>
#include <stdint.h>

int main(void)
{
    float f = 1.5f;
    uint32_t bits;

    memcpy(&bits, &f, sizeof(bits)); // Копируем байты float в целое
    printf("%08X\n", bits);          // 3FC00000

    return 0;
}
```

### Копирование структуры

```c
#include <stdio.h>
#include <string.h>

struct Config {
    int width;
    int height;
    char name[32];
};

int main(void)
{
    struct Config src = {800, 600, "monitor"};
    struct Config dest;

    memcpy(&dest, &src, sizeof(struct Config));
    printf("%s: %dx%d\n", dest.name, dest.width, dest.height);

    return 0;
}
```

## Ошибки и errno

- **Возвращаемое значение при ошибке:** не применимо (всегда возвращает `dest`)
- **Установление errno:** функция не устанавливает `errno`
- **Поведение при передаче NULL:** неопределённое поведение (аварийный завершение или некорректный доступ к памяти)
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние)
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<string.h>/memmove|memmove]] — безопасна при перекрытии областей; [[Языки программирования/C/Библиотеки/<string.h>/memset|memset]] — заполнение блока памяти

Неопределённое поведение также возникает при перекрытии областей `dest` и `src`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Максимально быстрая (SIMD-оптимизация) | Не обрабатывает перекрытие областей |
| Копирует произвольные данные (включая нули) | Не проверяет размер буфера `dest` |
| Подходит для type punning | Длина копирования — в байтах, не в элементах |

## Альтернативы

- **`memmove()`** — безопасна при перекрытии областей, но медленнее
- **`strcpy()`** — копирование строк (только до нуля)
- **`memccpy()`** — копирование с остановкой на заданном символе (POSIX)
