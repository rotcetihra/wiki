## Прототип

```c
#include <string.h>

size_t strspn(const char *s1, const char *s2);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1` | Строка, в которой ищется начальный «безопасный» сегмент |
| `s2` | Набор допустимых символов |

## Возвращаемое значение

Возвращает длину начального сегмента строки `s1`, состоящего **только** из символов набора `s2`. Если первый же символ не входит в набор, возвращает 0.

## Что делает

Измеряет, сколько символов в начале строки `s1` принадлежат набору `s2`. Это «положительный» поиск: `strspn()` измеряет «безопасную» длину строки, состоящую только из символов заданного набора. В сочетании с `strcspn()` образует удобный паттерн разбиения строки.

## Примеры

### Базовое использование

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    printf("%zu\n", strspn("abcxyz", "abc"));  // 3 (все символы из набора)
    printf("%zu\n", strspn("abcxyz", "xyz"));  // 0 (первый символ не в наборе)
    printf("%zu\n", strspn("abcabc", "abc"));  // 6 (все символы из набора)

    return 0;
}
```

### Пропуск пробелов

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *text = "   hello";
    size_t skip = strspn(text, " \t\n");
    printf("Пропущено %zu пробелов: %s\n", skip, text + skip);

    return 0;
}
```

### Подсчёт слов

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *text = "  hello   world  ";
    const char *p = text;
    int count = 0;

    while (*p) {
        p += strspn(p, " \t\n");    // Пропускаем пробелы
        size_t word_len = strcspn(p, " \t\n"); // Длина слова
        if (word_len > 0) {
            count++;
            p += word_len;
        } else {
            break;
        }
    }

    printf("Слов: %d\n", count); // 2

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Неопределённое поведение возникает при обращении по невалидным указателям.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Не модифицирует строку | Возвращает длину, а не указатель |
| Быстрая | Сложная семантика |
| Стандартная и переносимая | |

## Альтернативы

- **`strcspn()`** — «обратный» поиск (символы НЕ из набора)
- **`strpbrk()`** — указатель на первый символ из набора
- **Цикл с проверкой `strchr()`** — ручной подсчёт символов
