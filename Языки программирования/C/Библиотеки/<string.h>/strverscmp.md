## Прототип

```c
#include <string.h> // GNU

int strverscmp(const char *s1, const char *s2);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1` | Первая строка (обычно имя с версией) |
| `s2` | Вторая строка |

## Возвращаемое значение

Возвращает значение < 0, если `s1` — младшая версия; 0 при равенстве; > 0, если `s1` старше. Знак результата пригоден для `qsort()`.

## Что делает

Сравнивает строки в порядке «версий»: числовые последовательности сравниваются как числа, а не лексикографически. Так `strverscmp("file2", "file10")` даёт отрицательное значение (2 < 10), тогда как `strcmp()` посчитала бы `"file10" < "file2"`. Используется для сортировки версий пакетов, имён файлов с номерами и т. п.

## Примеры

### Сравнение версий

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    printf("%d\n", strverscmp("v1.2", "v1.10")); // отрицательное (2 < 10)
    printf("%d\n", strverscmp("file2", "file10")); // отрицательное
    printf("%d\n", strverscmp("1.0", "1.0"));      // 0

    return 0;
}
```

### Сортировка имён файлов

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>

int compare(const void *a, const void *b)
{
    return strverscmp(*(const char **)a, *(const char **)b);
}

int main(void)
{
    const char *files[] = {"img10.png", "img2.png", "img1.png"};
    size_t n = sizeof(files) / sizeof(files[0]);

    qsort(files, n, sizeof(char *), compare);

    for (size_t i = 0; i < n; i++) {
        printf("%s\n", files[i]); // img1.png, img2.png, img10.png
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Передача невалидных указателей — неопределённое поведение.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Числовое сравнение версий | Только GNU-расширение |
| Готова для `qsort()` | Сложная семантика пограничных случаев |
| | Не понимает точки-разделители как структуру |
