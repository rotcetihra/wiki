## Прототип

```c
#include <string.h> // POSIX.1-2008

char *stpncpy(char *dest, const char *src, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dest` | Буфер, куда копируется строка |
| `src` | Копируемая строка |
| `n` | Максимальное количество символов для копирования |

## Возвращаемое значение

- если `n > strlen(src)` — возвращает `dest + strlen(src)` (конец строки без дополнения);
- если `n <= strlen(src)` — возвращает `dest + n` (конец скопированного фрагмента, где будет завершающий нуль).

## Что делает

Копирует не более `n` символов из `src` в `dest`, дополняя остаток нулями, и возвращает указатель на записанный завершающий нуль (или место, где он должен быть). Ведёт себя как `strncpy()`, но с полезным возвратом — удобно при посимвольной сборке фиксированных полей.

## Примеры

### Копирование в поле фиксированной длины

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char field[8];
    char *end = stpncpy(field, "abcdef", sizeof(field));

    printf("Строка: %s\n", field);      // abcdef (дополнено нулями)
    printf("Длина: %td\n", end - field); // 6

    return 0;
}
```

### Заполнение поля символами построчно

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char record[16] = {0};
    char *p = record;

    p = stpncpy(p, "name=", 5);
    p = stpncpy(p, "value", 5);

    printf("%s\n", record); // name=value

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Как и `strncpy()`, если `src` длиннее `n` — завершающий нуль в `dest` не записывается, строка не завершена.

>[!WARNING]
>Если `src` длиннее `n`, завершающего нуля в `dest` не будет. Нуль записывается на позицию `dest + n` только если `n > strlen(src)` (вместе с дополнением). Проверяйте возвращённое значение или дописывайте `'\0'` вручную после вызова.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Возврат конца скопированной области | Не гарантирует нуль при длинной `src` |
| Дополняет поле нулями | Только POSIX (нет в C) |
| | Дополнительная работа при короткой `src` |
