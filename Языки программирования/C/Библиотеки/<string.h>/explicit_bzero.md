## Прототип

```c
#include <string.h> // BSD / glibc (__USE_MISC)

void explicit_bzero(void *s, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Блок памяти для обнуления |
| `n` | Количество байт для обнуления |

## Возвращаемое значение

Функция ничего не возвращает.

## Что делает

Заполняет `n` байт блока `s` нулями, но, в отличие от `memset()`, компилятор **не может удалить вызов** как оптимизацию, даже если после обнуления память больше не используется. Это критично для затирания секретных данных: паролей, ключей шифрования, токенов.

>[!WARNING]
>Обычный `memset()` компилятор вправе удалить, если докажет, что результат не используется. `explicit_bzero()` гарантирует, что обнуление действительно произойдёт. Не полагайтесь на `memset()` при затирании секретов.

## Примеры

### Затирание пароля

```c
#include <string.h>

int main(void)
{
    char password[64];
    strcpy(password, "s3cret!");
    // ... использование пароля ...
    explicit_bzero(password, sizeof(password)); // Гарантированно затираем

    return 0;
}
```

### Затирание криптографического ключа

```c
#include <string.h>

void burn_buffer(void *buf, size_t len)
{
    explicit_bzero(buf, len);
}
```

## Ошибки и errno

- **Возвращаемое значение при ошибке:** не применимо (ничего не возвращает)
- **Установление errno:** функция не устанавливает `errno`
- **Поведение при передаче NULL:** неопределённое поведение (аварийный завершение или некорректный доступ к памяти)
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние)
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<string.h>/memset|memset]] — обычное обнуление (может быть удалено компилятором); [[Языки программирования/C/Библиотеки/<string.h>/memset_explicit|memset_explicit]] — стандартная версия C23

Передача невалидного указателя — неопределённое поведение.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантированно выполняется | Нестандартная (BSD, glibc) |
| Предотвращает утечку секретов | Компилятор не может оптимизировать |
| | Медленнее обычного `memset()` |

## Альтернативы

- **`memset_s()`** (C11, Annex K) — стандартная версия, которую нельзя удалить
- **`memset_explicit()`** — функция C23 из `<string.h>` с тем же назначением
- Собственный волатильный цикл — менее надёжно
