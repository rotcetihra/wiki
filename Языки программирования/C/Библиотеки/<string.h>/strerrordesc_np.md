## Прототип

```c
#include <string.h> // GNU (glibc ≥ 2.32)

const char *strerrordesc_np(int errnum);
```

## Параметры

| Параметр | Описание |
|---|---|
| `errnum` | Код ошибки (обычно значение `errno`) |

## Возвращаемое значение

Возвращает указатель на **непереведённое** (англоязычное) описание ошибки. Если код неизвестен — возвращает `NULL` (в отличие от `strerror()`, которая всегда возвращает строку).

## Что делает

Аналог [[Языки программирования/C/Библиотеки/<string.h>/strerror|strerror()]], которая всегда выдаёт английский текст независимо от локали. Полезно для логов, которые должны быть единообразными, и для диагностики, когда локализация нежелательна. Суффикс `_np` означает «non-portable» — функция не переносима.

## Примеры

### Получение описания без перевода

```c
#include <stdio.h>
#include <string.h>
#include <errno.h>

int main(void)
{
    const char *desc = strerrordesc_np(ENOENT);
    if (desc != NULL) {
        printf("%s\n", desc); // No such file or directory (всегда по-английски)
    }

    return 0;
}
```

### Проверка неизвестного кода

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *desc = strerrordesc_np(-999);
    if (desc == NULL) {
        printf("Неизвестный код ошибки\n");
    }

    return 0;
}
```

## Ошибки и errno

- **Возвращаемое значение при ошибке:** `NULL` для неизвестного кода ошибки
- **Установление errno:** функция не устанавливает `errno`
- **Поведение при передаче NULL:** не применимо (принимает целое число, а не указатель)
- **Многопоточность:** потокобезопасна (возвращает статическую строку, доступную для чтения)
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<string.h>/strerrorname_np|strerrorname_np]] — имя константы ошибки; [[Языки программирования/C/Библиотеки/<string.h>/strerror|strerror]] — описание с учётом локали

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Единообразный английский текст | Только glibc (не переносима) |
| `NULL` для неизвестного кода | Не учитывает локаль |
| Безопасна в многопоточных программах | Строка статическая — только для чтения |
