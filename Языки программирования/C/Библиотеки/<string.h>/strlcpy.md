## Прототип

```c
#include <string.h> // BSD (в glibc — при __USE_MISC)

size_t strlcpy(char *dest, const char *src, size_t size);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dest` | Буфер для копирования |
| `src` | Копируемая строка |
| `size` | Полный размер буфера `dest` |

## Возвращаемое значение

Возвращает длину строки `src` (`strlen(src)`) — длину, которую имел бы результат без ограничения. Если возвращённое значение ≥ `size` — произошло усечение.

## Что делает

Безопасно копирует строку: всегда завершает результат нулём (если `size > 0`) и никогда не пишет за пределы буфера. Усечение обнаруживается по возвращаемому значению. Пришла из BSD; в glibc долгое время отсутствовала (лицензионные причины) — при переносе кода проверяйте доступность.

>[!NOTE]
>Возвращается длина `src`, а не копии. Проверка `strlcpy(dest, src, size) >= size` означает, что строка не поместилась целиком.

## Примеры

### Безопасное копирование

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char dest[8];

    size_t len = strlcpy(dest, "Hello", sizeof(dest));
    printf("%s (len %zu)\n", dest, len); // Hello (len 5)

    return 0;
}
```

### Обнаружение усечения

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char dest[5];

    size_t len = strlcpy(dest, "Hello world", sizeof(dest));
    printf("Строка: %s\n", dest);       // Hell (усечена)
    printf("Нужно было: %zu\n", len);    // 11

    return 0;
}
```

## Ошибки и errno

- **Возвращаемое значение при ошибке:** длина `src`, если произошло усечение (≥ `size`)
- **Установление errno:** функция не устанавливает `errno`
- **Поведение при передаче NULL:** неопределённое поведение (аварийный завершение или некорректный доступ к памяти)
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние)
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<string.h>/strncpy|strncpy]] — стандартная, но без гарантии нуля; [[Языки программирования/C/Библиотеки/<string.h>/strcpy|strcpy]] — небезопасная

Усечение обнаруживается сравнением возвращаемого значения с `size`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантированный завершающий нуль | Нет в glibc по умолчанию |
| Безопасна при усечении | Возвращает длину `src`, не копии |
| Простая проверка усечения | Сильно медленнее `strcpy()` (обходит всю `src`) |
