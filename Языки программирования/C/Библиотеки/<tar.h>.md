## Описание библиотеки

Заголовочный файл `<tar.h>` — расширенные определения tar. Определяет константы для формата архива `ustar`, используемого утилитой `tar` и архиватором `pax`.

### Константы общие

| Константа | Значение | Описание |
|---|---|---|
| `TMAGIC` | `"ustar"` | Магическая строка формата ustar |
| `TMAGLEN` | `6` | Длина магической строки |
| `TVERSION` | `"00"` | Номер версии формата |
| `TVERSLEN` | `2` | Длина строки версии |

### Константы typeflag

| Константа | Значение | Описание |
|---|---|---|
| `REGTYPE` | `'0'` | Обычный файл |
| `AREGTYPE` | `'\0'` | Обычный файл (аналог `REGTYPE`) |
| `LNKTYPE` | `'1'` | Ссылка (hard link) |
| `SYMTYPE` | `'2'` | Символическая ссылка |
| `CHRTYPE` | `'3'` | Символьный файл |
| `BLKTYPE` | `'4'` | Блочный файл |
| `DIRTYPE` | `'5'` | Каталог |
| `FIFOTYPE` | `'6'` | FIFO |
| `CONTTYPE` | `'7'` | Зарезервировано |

### Константы mode (восьм.)

| Константа | Значение (восьм.) | Описание |
|---|---|---|
| `TSUID` | 04000 | Установка ID при выполнении |
| `TSGID` | 02000 | Установка группы при выполнении |
| `TSVTX` | 01000 | Ограниченное удаление |
| `TUREAD` | 00400 | Чтение владельцем |
| `TUWRITE` | 00200 | Запись владельцем |
| `TUEXEC` | 00100 | Выполнение владельцем |
| `TGREAD` | 00040 | Чтение группой |
| `TGWRITE` | 00020 | Запись группой |
| `TGEXEC` | 00010 | Выполнение группой |
| `TOREAD` | 00004 | Чтение другими |
| `TOWRITE` | 00002 | Запись другими |
| `TOEXEC` | 00001 | Выполнение другими |

### Использование

```c
#include <tar.h>

/* Проверка типа файла из typeflag */
if (typeflag == REGTYPE || typeflag == AREGTYPE) {
    printf("Обычный файл\n");
}
if (typeflag == DIRTYPE) {
    printf("Каталог\n");
}
```

## Исключения

- **Константы:** все значения определены как константы времени компиляции.
- **Формат:** заголовочный файл описывает только формат архива, не предоставляет функций для работы с ним.
- **REGTYPE vs AREGTYPE:** `AREGTYPE` (`'\0'`) — обратная совместимость со старыми форматами.
- **Многопоточность:** не применимо (только константы).
