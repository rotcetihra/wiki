## Описание библиотеки

Заголовочный файл `<uchar.h>` — обработка символов Unicode. Этот заголовок предоставляет типы и функции для работы с символами Unicode в кодировках UTF-16 и UTF-32.

> [!NOTE]
> В C23 добавлены также функции `mbrtoc8` и `c8rtomb` для работы с UTF-8, а также тип `char8_t`.

### Типы

| Тип | Описание |
|---|---|
| `char16_t` | Беззнаковый целочисленный тип, идентичный `uint_least16_t`; используется для представления символов UTF-16 |
| `char32_t` | Беззнаковый целочисленный тип, идентичный `uint_least32_t`; используется для представления символов UTF-32 |
| `mbstate_t` | Объектный тип для хранения состояния преобразования (из `<wchar.h>`) |
| `size_t` | Беззнаковый целочисленный тип размера (из `<stddef.h>`) |

### Функции

| Функция | Описание |
|---|---|
| `c16rtomb(char *restrict, char16_t, mbstate_t *restrict)` | Преобразование символа UTF-16 в многобайтовую последовательность |
| `c32rtomb(char *restrict, char32_t, mbstate_t *restrict)` | Преобразование символа UTF-32 в многобайтовую последовательность |
| `mbrtoc16(char16_t *restrict, const char *restrict, size_t, mbstate_t *restrict)` | Преобразование многобайтовой последовательности в символ UTF-16 |
| `mbrtoc32(char32_t *restrict, const char *restrict, size_t, mbstate_t *restrict)` | Преобразование многобайтовой последовательности в символ UTF-32 |

## Исключения

- **NULL:** функции не принимают `NULL` в качестве указателя на строку; передача `NULL` — неопределённое поведение.
- **errno:** функции не устанавливают `errno`.
- **Неполные последовательности:** если входная строка содержит неполную многобайтовую последовательность, функции сохраняют состояние в `mbstate_t` и возвращают `(size_t)-2`.
- **Неверные последовательности:** при обнаружении неверной последовательности функции устанавливают `errno = EILSEQ` и возвращают `(size_t)-1`.
- **Многопоточность:** функции не являются потокобезопасными; для безопасного использования требуют блокировки.
- **Размер буфера:** `c16rtomb` и `c32rtomb` записывают не более `MB_LEN_MAX` байт в выходной буфер.
