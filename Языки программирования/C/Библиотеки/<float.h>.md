## Описание

Заголовочный файл `<float.h>` определяет константы, описывающие характеристики типов с плавающей запятой: диапазоны, точность и особые значения. Точность операций с плавающей запятой (`+`, `-`, `*`, `/`) и функций в `<math.h>` и `<complex.h>`, возвращающих результаты с плавающей запятой, определяется реализацией, как и точность преобразования между внутренними представлениями и строковыми представлениями, выполняемого функциями в `<stdio.h>`, `<stdlib.h>` и `<wchar.h>`.

### Модель представления

Все целочисленные значения в заголовочном файле `<float.h>`, за исключением `FLT_ROUNDS`, являются константными выражениями, пригодными для использования в директивах препроцессора; все значения с плавающей запятой являются константными выражениями. Все, за исключением `DECIMAL_DIG`, `FLT_EVAL_METHOD`, `FLT_RADIX` и `FLT_ROUNDS`, имеют отдельные имена для всех трёх типов с плавающей запятой.

Параметры модели для каждого типа с плавающей запятой:

- `s` — знак (±1)
- `b` — основание или radix экспоненты (для IEEE-754: 2)
- `e` — показатель экспоненты
- `f` — significand ( mantissa )
- `p` — количество цифр significand

### Режим округления

Режим округления для сложения чисел с плавающей запятой характеризуется определённым реализацией значением `FLT_ROUNDS`:

- `-1` — не определяется
- `0` — в сторону нуля
- `1` — до ближайшего
- `2` — в сторону положительной бесконечности
- `3` — в сторону отрицательной бесконечности

Все другие значения `FLT_ROUNDS` характеризуют определённое реализацией поведение округления.

### Метод оценки

Значения операций с операндами с плавающей запятой и значения, подчинённые обычным арифметическим преобразованиям, а также константы с плавающей запятой вычисляются в формате, чей диапазон и точность могут быть больше требуемого типом. Использование форматов оценки характеризуется определённым реализацией значением `FLT_EVAL_METHOD`:

- `-1` — не определяется
- `0` — вычислять все операции и константы только до диапазона и точности типа
- `1` — вычислять операции и константы типа `float` и `double` до диапазона и точности типа `double`; вычислять операции и константы типа `long double` до диапазона и точности типа `long double`
- `2` — вычислять все операции и константы до диапазона и точности типа `long double`

### Значения

Заголовочный файл `<float.h>` определяет следующие значения как константные выражения с определёнными реализацией значениями, которые больше или равны (по модулю) показанным, с тем же знаком:

- `FLT_RADIX` — основание экспонентного представления (обычно 2)
- `FLT_MANT_DIG` / `DBL_MANT_DIG` / `LDBL_MANT_DIG` — количество цифр significand в основании `FLT_RADIX`
- `FLT_MIN_EXP` / `DBL_MIN_EXP` / `LDBL_MIN_EXP` — минимальная отрицательная целая, такая, что `FLT_RADIX` в этой степени минус 1 является нормализованным числом с плавающей запятой
- `FLT_MIN_10_EXP` / `DBL_MIN_10_EXP` / `LDBL_MIN_10_EXP` — минимальная отрицательная целая, такая, что 10 в этой степени находится в диапазоне нормализованных чисел
- `FLT_MAX_EXP` / `DBL_MAX_EXP` / `LDBL_MAX_EXP` — максимальная целая, такая, что `FLT_RADIX` в этой степени минус 1 является представимым конечным числом с плавающей запятой
- `FLT_MAX_10_EXP` / `DBL_MAX_10_EXP` / `LDBL_MAX_10_EXP` — максимальная целая, такая, что 10 в этой степени находится в диапазоне представимых конечных чисел

### Максимальные и минимальные значения

Заголовочный файл `<float.h>` определяет следующие значения как константные выражения с определёнными реализацией значениями, которые больше или равны показанным:

- `FLT_MAX` / `DBL_MAX` / `LDBL_MAX` — максимальное представимое конечное число с плавающей запятой

Заголовочный файл `<float.h>` определяет следующие значения как константные выражения с определёнными реализацией (положительными) значениями, которые меньше или равны показанным:

- `FLT_EPSILON` / `DBL_EPSILON` / `LDBL_EPSILON` — разница между 1 и наименьшим значением больше 1, представимым в данном типе
- `FLT_MIN` / `DBL_MIN` / `LDBL_MIN` — минимальное нормализованное положительное число с плавающей запятой

> [!NOTE]
> Значения в glibc на x86-64 соответствуют IEEE-754: `float` — binary32 (24 бита мантиссы), `double` — binary64 (53 бита), `long double` — расширенный формат x87 (64 бита мантиссы). На других платформах (например, aarch64) `long double` может быть binary128 — тогда значения `LDBL_*` отличаются.

## Исключения

- **Установление `errno`:** не применимо — заголовок содержит только макросы.
- **Поведение при передаче `NULL`:** не применимо.
- **Поведение при переполнении/нехватке памяти:** не применимо.
- **Граничные случаи:** знание значений `FLT_MAX` и `DBL_MAX` позволяет определить, что вызов `math`-функции (например, `exp()`) приведёт к переполнению. Значение `FLT_EPSILON` необходимо для тестирования относительной точности.
- **Многопоточность:** не применимо — макросы являются константными выражениями, вычисляемыми на этапе компиляции.
- **Предупреждение:** значения `FLT_ROUNDS` и `FLT_EVAL_METHOD` определяются реализацией и могут отличаться на разных платформах и компиляторах. Не предполагайте фиксированных значений.
