## Определение

```c
#include <stdint.h>

#define INTPTR_MIN /* целочисленная константа */
```

## Описание

Макрос `INTPTR_MIN` — минимальное значение типа `intptr_t`. Представляет собой целочисленную константу, вычисляемую на этапе компиляции.

Значение определяется реализацией в соответствии со стандартом C23 (ISO/IEC 9899:2024).

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    printf("INTPTR_MIN = %jd\n", (long long)INTPTR_MIN);
    printf("Тип: intptr_t\n");
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Вычисляется на этапе компиляции | Значение зависит от платформы |
| Гарантирует корректность для типа | Нельзя использовать в `#if` |
| Стандартная часть C99/C23 | — |
