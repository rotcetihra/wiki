## Определение

```c
#include <stdint.h>

typedef int32_t;
```

## Описание

Тип `int32_t` — int32_t. Гарантирует точное количество бит в знаковом/беззнаковом целочисленном представлении.

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    int32_t value = 42;
    printf("Размер: %zu бит\n", sizeof(value) * 8);
    printf("Минимум: %jd\n", (long long)INT32_T_MIN);
    printf("Максимум: %jd\n", (long long)INT32_T_MAX);
    printf("Значение: %jd\n", (long long)value);
    return 0;
}
```

## Лимиты

| Макрос | Описание |
|---|---|
| `INT32_T_MIN` | Минимальное значение типа int32_t |
| `INT32_T_MAX` | Максимальное значение типа int32_t |

| Преимущество | Недостаток |
