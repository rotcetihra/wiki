## Определение

```c
#include <stdint.h>

#define UINT64_C(value) /* целочисленный литерал */
```

## Описание

Макрос `UINT64_C` создаёт целочисленный литерал типа `uint_least64_t`. Используется для формирования констант, которые гарантированно имеют тип `uint_least64_t` независимо от размера целочисленного литерала.

Параметр `value` — целочисленное выражение, которое должно быть представимо в типе `uint_least64_t`.

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    uint_least64_t val1 = UINT64_C(42);
    uint_least64_t val2 = UINT64_C(0xFF);
    
    printf("val1 = %jd\n", (long long)val1);
    printf("val2 = %jd\n", (long long)val2);
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует тип литерала | Значение должно быть представимо в типе |
| Портативен между платформами | Только для целочисленных констант |
| Стандартная часть C99/C23 | — |
