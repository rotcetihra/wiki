## Определение

```c
#include <stdint.h>

#define INT8_C(value) /* целочисленный литерал */
```

## Описание

Макрос `INT8_C` создаёт целочисленный литерал типа `int_least8_t`. Используется для формирования констант, которые гарантированно имеют тип `int_least8_t` независимо от размера целочисленного литерала.

Параметр `value` — целочисленное выражение, которое должно быть представимо в типе `int_least8_t`.

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    int_least8_t val1 = INT8_C(42);
    int_least8_t val2 = INT8_C(0xFF);
    
    printf("val1 = %jd\n", (long long)val1);
    printf("val2 = %jd\n", (long long)val2);
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует тип литерала | Значение должно быть представимо в типе |
| Портативен между платформами | Только для целочисленных констант |
| Стандартная часть C99/C23 | — |
