```c
#include <stdint.h>

typedef uint_fast64_t;
```

## Описание

Тип `uint_fast64_t` — uint_fast64_t. Гарантирует точное количество бит в знаковом/беззнаковом целочисленном представлении.

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    uint_fast64_t value = 42;
    printf("Размер: %zu бит\n", sizeof(value) * 8);
    printf("Минимум: %jd\n", (long long)UINT_FAST64_T_MIN);
    printf("Максимум: %jd\n", (long long)UINT_FAST64_T_MAX);
    printf("Значение: %jd\n", (long long)value);
    return 0;
}
```

## Лимиты

| Макрос | Описание |

| `UINT_FAST64_T_MAX` | Максимальное значение типа uint_fast64_t |
