## Определение

```c
#include <stdint.h>

#define SIG_ATOMIC_MAX /* целочисленная константа */
```

## Описание

Макрос `SIG_ATOMIC_MAX` — максимальное значение типа `sig_atomic_t`. Представляет собой целочисленную константу, вычисляемую на этапе компиляции.

Значение определяется реализацией в соответствии со стандартом C23 (ISO/IEC 9899:2024).

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    printf("SIG_ATOMIC_MAX = %jd\n", (long long)SIG_ATOMIC_MAX);
    printf("Тип: sig_atomic_t\n");
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Вычисляется на этапе компиляции | Значение зависит от платформы |
| Гарантирует корректность для типа | Нельзя использовать в `#if` |
| Стандартная часть C99/C23 | — |
