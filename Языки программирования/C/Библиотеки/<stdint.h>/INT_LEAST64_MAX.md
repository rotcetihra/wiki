```c
#include <stdint.h>

#define INT_LEAST64_MAX /* целочисленная константа */
```

## Описание

Макрос `INT_LEAST64_MAX` — максимальное значение типа `int_least64_t`. Представляет собой целочисленную константу, вычисляемую на этапе компиляции.

Значение определяется реализацией в соответствии со стандартом C23 (ISO/IEC 9899:2024).

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    printf("INT_LEAST64_MAX = %jd\n", (long long)INT_LEAST64_MAX);
    printf("Тип: int_least64_t\n");
    return 0;
}
```
