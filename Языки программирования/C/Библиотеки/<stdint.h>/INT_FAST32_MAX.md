```c
#include <stdint.h>

#define INT_FAST32_MAX /* целочисленная константа */
```

## Описание

Макрос `INT_FAST32_MAX` — максимальное значение типа `int_fast32_t`. Представляет собой целочисленную константу, вычисляемую на этапе компиляции.

Значение определяется реализацией в соответствии со стандартом C23 (ISO/IEC 9899:2024).

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    printf("INT_FAST32_MAX = %jd\n", (long long)INT_FAST32_MAX);
    printf("Тип: int_fast32_t\n");
    return 0;
}
```
