## Определение

```c
#include <stdint.h>

#define INTMAX_C(value) /* целочисленный литерал */
```

## Описание

Макрос `INTMAX_C` создаёт целочисленный литерал типа `intmax_t`. Используется для формирования констант, которые гарантированно имеют тип `intmax_t` независимо от размера целочисленного литерала.

Параметр `value` — целочисленное выражение, которое должно быть представимо в типе `intmax_t`.

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    intmax_t val1 = INTMAX_C(42);
    intmax_t val2 = INTMAX_C(0xFF);
    
    printf("val1 = %jd\n", (long long)val1);
    printf("val2 = %jd\n", (long long)val2);
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует тип литерала | Значение должно быть представимо в типе |
| Портативен между платформами | Только для целочисленных констант |
| Стандартная часть C99/C23 | — |
