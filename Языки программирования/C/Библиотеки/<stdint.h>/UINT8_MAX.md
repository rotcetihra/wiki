## Определение

```c
#include <stdint.h>

#define UINT8_MAX /* целочисленная константа */
```

## Описание

Макрос `UINT8_MAX` — максимальное значение типа `uint8_t`. Представляет собой целочисленную константу, вычисляемую на этапе компиляции.

Значение определяется реализацией в соответствии со стандартом C23 (ISO/IEC 9899:2024).

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    printf("UINT8_MAX = %jd\n", (long long)UINT8_MAX);
    printf("Тип: uint8_t\n");
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Вычисляется на этапе компиляции | Значение зависит от платформы |
| Гарантирует корректность для типа | Нельзя использовать в `#if` |
| Стандартная часть C99/C23 | — |
