## Определение

```c
#include <stdint.h>

#define INT64_MIN /* целочисленная константа */
```

## Описание

Макрос `INT64_MIN` — минимальное значение типа `int64_t`. Представляет собой целочисленную константу, вычисляемую на этапе компиляции.

Значение определяется реализацией в соответствии со стандартом C23 (ISO/IEC 9899:2024).

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    printf("INT64_MIN = %jd\n", (long long)INT64_MIN);
    printf("Тип: int64_t\n");
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Вычисляется на этапе компиляции | Значение зависит от платформы |
| Гарантирует корректность для типа | Нельзя использовать в `#if` |
| Стандартная часть C99/C23 | — |

## Похожие макросы

- Макросы `<limits.h>` для стандартных целочисленных типов
