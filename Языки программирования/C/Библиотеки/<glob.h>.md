## Описание библиотеки

Заголовочный файл `<glob.h>` — типы сопоставления шаблонов путей. Определяет структуру `glob_t`, константы и функции для поиска файлов по шаблонам (как в shell).

### Структура `glob_t`

```c
typedef struct {
    size_t   gl_pathc;   /* Количество совпавших путей */
    char   **gl_pathv;   /* Массив строк с путями */
    size_t   gl_offs;    /* Резерв в начале gl_pathv */
} glob_t;
```

### Константы флагов

| Константа | Описание |
|---|---|
| `GLOB_APPEND` | Добавить результат к предыдущему вызову |
| `GLOB_DOOFFS` | Резервировать `gl_offs` null-указателей в начале |
| `GLOB_ERR` | Остановить обработку при ошибке чтения каталога |
| `GLOB_MARK` | Добавлять `/` к совпавшим каталогам |
| `GLOB_NOCHECK` | Вернуть шаблон если нет совпадений |
| `GLOB_NOESCAPE` | Отключить экранирование `\` |
| `GLOB_NOSORT` | Не сортировать результат |

### Функции

| Функция | Описание |
|---|---|
| `glob(const char *restrict, int, int (*)(const char *, int), glob_t *restrict)` | Поиск путей по шаблону |
| `globfree(glob_t *)` | Освобождение памяти выделенной `glob()` |

### Возвращаемое значение

- `glob()`: `0` при успехе, `GLOB_ABORTED`/`GLOB_NOMATCH`/`GLOB_NOSPACE` при ошибке.
- `globfree()`: ничего не возвращает.

### Использование

```c
#include <glob.h>

glob_t results;
glob("/home/*/*.txt", GLOB_NOSORT, NULL, &results);

for (size_t i = 0; i < results.gl_pathc; i++) {
    printf("%s\n", results.gl_pathv[i]);
}

globfree(&results);
```

## Исключения

- **NULL:** `glob()` не принимает `NULL` в качестве шаблона.
- **GLOB_ERR:** полезно для остановки при ошибках чтения каталогов.
- **Память:** `glob()` выделяет память; освобождайте через `globfree()`.
- **Шаблоны:** используются те же что и в shell (`*`, `?`, `[...]`).
- **Многопоточность:** функция потокобезопасна.

## Стандарты

POSIX.1-2017.
