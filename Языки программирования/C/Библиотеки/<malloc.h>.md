## Описание библиотеки

Заголовочный файл `<malloc.h>` — управление динамической памятью (glibc extension). Определяет функции для выделения, освобождения и управления динамической памятью. Основные функции (`malloc()`, `free()`, `calloc()`, `realloc()`) определены в `<stdlib.h>`, но `<malloc.h>` предоставляет дополнительные функции информации и настройки.

### Функции

| Функция | Описание |
|---|---|
| `malloc(size_t size)` | Выделение `size` байтов (не инициализируется) |
| `free(void *p)` | Освобождение блока (NULL безопасен) |
| `calloc(size_t n, size_t size)` | Выделение массива из `n` элементов по `size` байтов (обнуляется) |
| `realloc(void *p, size_t size)` | Изменение размера блока |
| `reallocarray(void *p, size_t n, size_t size)` | Изменение размера с проверкой переполнения `n * size` |
| `malloc_usable_size(void *p)` | Возвращает реальный размер выделенного блока |
| `malloc_info(int, FILE *)` | Вывод информации о куче в XML |
| `malloc_stats(void)` | Вывод статистики в stderr |
| `malloc_trim(size_t)` | Освобождение неиспользуемой памяти |
| `mallopt(int, int)` | Настройка параметров аллокатора |
| `memalign(size_t, size_t)` | Выделение с выравниванием |
| `aligned_alloc(size_t, size_t)` | Выделение с выравниванием (C11) |

### Возвращаемое значение

- `malloc()`, `calloc()`, `realloc()`, `reallocarray()`: указатель на выделенную память или `NULL` при ошибке.
- `free()`, `malloc_stats()`, `malloc_trim()`, `mallopt()`: ничего не возвращают.
- `malloc_usable_size()`: размер блока в байтах.

### Использование

```c
#include <malloc.h>

void *p = malloc(1024);
if (p == NULL) {
    perror("malloc");
    return 1;
}

/* Узнать реальный размер */
size_t real_size = malloc_usable_size(p);

free(p);
```

## Исключения

- **NULL:** `malloc()` возвращает `NULL` при ошибке (нехватка памяти).
- **ENOMEM:** устанавливается при ошибке выделения.
- **free(NULL):** безопасен — ничего не делает.
- **Двойное освобождение:** приводит к неопределённому поведению.
- **Переполнение:** `reallocarray()` проверяет переполнение `n * size`.
- **Linux:** по умолчанию используется «оптимистичное» выделение (выделение может завершиться OOM killer).
- **Многопоточность:** функции потокобезопасны (MT-Safe).

## Стандарты

`malloc()`, `free()`, `calloc()`, `realloc()`: C23, POSIX.1-2024.
`reallocarray()`: POSIX.1-2024.
Остальные: glibc extension.
