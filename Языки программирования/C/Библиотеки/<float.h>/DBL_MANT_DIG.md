## Определение

```c
#include <float.h>

#define DBL_MANT_DIG 53 // в glibc
```

## Описание

Константа — количество цифр мантиссы `double` в системе счисления с основанием `FLT_RADIX` (включая скрытый бит). Для IEEE-754 binary64: 52 бита хранения + 1 скрытый = 53. Показывает, сколько значащих двоичных разрядов хранит тип; из него вычисляется точность в десятичных цифрах `DBL_DIG`.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("Мантисса double: %d цифр по основанию %d\n",
           DBL_MANT_DIG, FLT_RADIX);

    return 0;
}
```
