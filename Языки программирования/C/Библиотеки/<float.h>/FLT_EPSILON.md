## Определение

```c
#include <float.h>

#define FLT_EPSILON 1.19209289550781250000e-7F // в glibc
```

## Описание

Константа — _машинный эпсилон_ типа `float`: разница между 1.0f и ближайшим большим представимым числом. Для binary32 — 2⁻²³ ≈ 1.19·10⁻⁷ (минимум по стандарту — 1e-5). Используется как порог «практического равенства» при сравнении вещественных чисел: разница меньше `FLT_EPSILON` считается нулевой.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    float a = 1.0f;
    float b = a + FLT_EPSILON;

    printf("Разница 1.0f: %g\n", b - a);        // 1.19209e-07
    printf("1.0f + eps == 1.0f: %d\n", b == a); // 0

    return 0;
}
```
