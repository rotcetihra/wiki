## Определение

```c
#include <float.h>

#define LDBL_MAX_10_EXP 4932 // в glibc
```

## Описание

Константа — максимальное целое e такое, что 10ᵉ представимо как нормализованный `long double`. Для 80-битного формата x87 — 4932 (как и для binary128). Стандарт гарантирует минимум 37.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("Верхняя граница long double: 10^%d\n", LDBL_MAX_10_EXP);

    return 0;
}
```
