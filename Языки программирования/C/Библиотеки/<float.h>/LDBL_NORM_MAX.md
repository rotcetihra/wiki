## Определение

```c
#include <float.h>

#define LDBL_NORM_MAX 1.18973149535723176502e+4932L // в glibc
```

## Описание

Константа (C23) — максимальное _нормализованное_ конечное значение типа `long double`; на платформах IEEE-754 совпадает с `LDBL_MAX`. Введена в C23 как парная к `LDBL_MIN`/`LDBL_TRUE_MIN` для выборочной работы с нормализованным диапазоном.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("%.21Lg\n", LDBL_NORM_MAX);

    return 0;
}
```
