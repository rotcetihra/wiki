## Определение

```c
#include <float.h>

#define DBL_MAX_10_EXP 308 // в glibc
```

## Описание

Константа — максимальное целое e такое, что 10ᵉ представимо как нормализованное `double`. Для binary64: 10³⁰⁸ представимо, 10³⁰⁹ — уже нет. Стандарт гарантирует минимум 37. Полезна при оценке диапазона результатов, выраженных в десятичной степени.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("Диапазон double: 10^-%d ... 10^%d\n",
           -DBL_MIN_10_EXP, DBL_MAX_10_EXP);

    return 0;
}
```
