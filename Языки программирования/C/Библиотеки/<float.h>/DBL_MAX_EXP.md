## Определение

```c
#include <float.h>

#define DBL_MAX_EXP 1024 // в glibc
```

## Описание

Константа — максимальное целое e такое, что `FLT_RADIX^e − 1` представимо как нормализованное число с плавающей точкой типа `double`. Для binary64 при основании 2: 2¹⁰²⁴ не представимо, но 2¹⁰²³ — это диапазон экспонент [−1021; 1024]. Используется в коде, манипулирующем представлением чисел (через `frexp()`/`ldexp()`).

## Примеры

```c
#include <float.h>
#include <math.h>
#include <stdio.h>

int main(void)
{
    // Наибольшая степень двойки, представимая в double
    double x = ldexp(1.0, DBL_MAX_EXP - 1);

    printf("%.17g\n", x); // 8.9884656743115795e+307

    return 0;
}
```
