## Определение

```c
#include <float.h>

#define FLT_MIN_EXP (-125) // в glibc
```

## Описание

Константа — минимальное целое e такое, что `FLT_RADIX^(e−1)` — нормализованный `float`. Для binary32: минимальный нормализованный порядок 2⁻¹²⁶ (значение `FLT_MIN`). Порядки ниже соответствуют денормализованным числам.

## Примеры

```c
#include <float.h>
#include <math.h>
#include <stdio.h>

int main(void)
{
    float x = ldexpf(1.0f, FLT_MIN_EXP - 1);

    printf("%.9g\n", x); // 1.17549435e-38

    return 0;
}
```
