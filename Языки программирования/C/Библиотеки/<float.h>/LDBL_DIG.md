## Определение

```c
#include <float.h>

#define LDBL_DIG 18 // в glibc на x86-64
```

## Описание

Константа — количество десятичных цифр q, при котором округление `long double` до q цифр и обратно не меняет значение. На x86-64 (80-битный x87) — 18; на платформах с binary128 (aarch64) — 33. Стандарт гарантирует минимум 10.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    long double x = 1.0L / 3.0L;

    printf("%.*Lf\n", LDBL_DIG, x); // 0.333333333333333333

    return 0;
}
```
