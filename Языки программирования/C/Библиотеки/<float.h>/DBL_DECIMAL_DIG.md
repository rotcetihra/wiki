## Определение

```c
#include <float.h>

#define DBL_DECIMAL_DIG 17 // в glibc
```

## Описание

Константа (C11) — количество десятичных цифр, необходимое для однозначного представления значения `double` (число цифр n такое, что любой `double` воспроизводится при печати с n значащими цифрами и обратном преобразовании). Практическое применение — формат `%.17g` вместо `%.15g` при сериализации: 17 цифр гарантируют точное восстановление числа, 15 — нет.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    double x = 0.1;

    printf("%.*g\n", DBL_DECIMAL_DIG, x); // 0.10000000000000001
    printf("%.*g\n", DBL_DIG, x);         // 0.1

    return 0;
}
```
