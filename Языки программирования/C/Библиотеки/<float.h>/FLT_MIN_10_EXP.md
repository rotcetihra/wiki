## Определение

```c
#include <float.h>

#define FLT_MIN_10_EXP (-37) // в glibc
```

## Описание

Константа — минимальное целое e такое, что 10ᵉ представимо как нормализованный `float`. Для binary32: 10⁻³⁷ — минимальная нормализованная степень (около 1e-38). Стандарт гарантирует значение не больше −37.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("Нижняя граница float: 10^%d\n", FLT_MIN_10_EXP);

    return 0;
}
```
