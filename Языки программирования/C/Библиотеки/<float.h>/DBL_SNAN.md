## Определение

```c
#include <float.h>

#define DBL_SNAN __builtin_nans("") // в glibc
```

## Описание

Константа (C23) — значение сигнализирующего NaN (signaling NaN) типа `double`. В отличие от тихого NaN (quiet NaN), который лишь «молча» распространяет неопределённость, любая операция с сигнализирующим NaN вызывает исключение с плавающей точкой. В glibc определяется через встроенную функцию GCC `__builtin_nans()`. Используется для тестирования обработчиков исключений и систем FPU.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    double qnan = __builtin_nan(""); // тихое NaN
    double snan = DBL_SNAN;          // сигнализирующее NaN

    printf("Тихое NaN: %g\n", qnan);

    return 0;
}
```

> [!WARNING]
> Арифметические операции с `DBL_SNAN` (например, `DBL_SNAN + 1.0`) генерируют аппаратное исключение — программа может завершиться аварийно, если исключение не обрабатывается.
