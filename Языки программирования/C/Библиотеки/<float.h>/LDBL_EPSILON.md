## Определение

```c
#include <float.h>

#define LDBL_EPSILON 1.08420217248550443401e-19L // в glibc на x86-64
```

## Описание

Константа — _машинный эпсилон_ типа `long double`: разница между 1.0L и ближайшим большим представимым числом. Для 80-битного формата x87 (64-битная мантисса) — 2⁻⁶³ ≈ 1.084·10⁻¹⁹; для binary128 — 2⁻¹¹² ≈ 1.93·10⁻³⁴.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    long double a = 1.0L;
    long double b = a + LDBL_EPSILON;

    printf("%.21Lg\n", b - a); // 1.08420217248550443401e-19

    return 0;
}
```
