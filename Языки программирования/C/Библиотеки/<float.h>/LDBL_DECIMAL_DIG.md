## Определение

```c
#include <float.h>

#define LDBL_DECIMAL_DIG 21 // в glibc на x86-64
```

## Описание

Константа (C11) — количество десятичных цифр, необходимое для однозначного представления значения `long double` при печати и обратном чтении. На x86-64 (80-битный формат x87) — 21; на платформах с binary128 (aarch64) — 36. Формат вывода `%.*Lg` с этой точностью гарантирует восстановление исходного значения.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    long double x = 0.1L;

    printf("%.*Lg\n", LDBL_DECIMAL_DIG, x);

    return 0;
}
```
