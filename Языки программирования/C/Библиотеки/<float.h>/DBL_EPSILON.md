## Определение

```c
#include <float.h>

#define DBL_EPSILON 2.22044604925031308085e-16 // в glibc
```

## Описание

Константа — _машинный эпсилон_: разница между 1.0 и ближайшим к нему большим представимым числом `double`. Относительная точность типа: при нормализации результатов вычислений эта величина показывает, с какой относительной ошибкой работает арифметика. Для binary64 значение равно 2⁻⁵² ≈ 2.22·10⁻¹⁶. Стандарт гарантирует не более 1e-9.

## Примеры

```c
#include <float.h>
#include <math.h>
#include <stdio.h>

int main(void)
{
    double a = 1.0;
    double b = 1.0 + DBL_EPSILON;

    printf("a == b: %d\n", a == b); // 0
    printf("1.0 == 1.0 + eps/2: %d\n", a == 1.0 + DBL_EPSILON / 2); // 1

    return 0;
}
```
