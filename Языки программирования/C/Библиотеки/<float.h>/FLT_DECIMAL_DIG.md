## Определение

```c
#include <float.h>

#define FLT_DECIMAL_DIG 9 // в glibc
```

## Описание

Константа (C11) — количество десятичных цифр, необходимое для однозначного представления значения `float` при печати и обратном чтении. Для binary32 — 9 цифр (формат `%.9g`). Если печатать с `FLT_DIG` (6 цифр), разные значения `float` могут совпасть после округления — для сериализации нужно именно `FLT_DECIMAL_DIG`.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    float x = 0.1f;

    printf("%.*g\n", FLT_DECIMAL_DIG, x); // 0.100000001
    printf("%.*g\n", FLT_DIG, x);         // 0.1

    return 0;
}
```
