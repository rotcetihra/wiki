## Определение

```c
#include <float.h>

#define LDBL_MAX_EXP 16384 // в glibc
```

## Описание

Константа — максимальное целое e такое, что `FLT_RADIX^e − 1` представимо как нормализованный `long double`. Для 80-битного x87: диапазон экспонент [−16381; 16384]; для binary128 — [−16381; 16384] тоже (обе используют 15-битную экспоненту... точнее binary128: [−16381; 16384]? Нет: binary128 использует 15-битную экспоненту со смещением: MIN_EXP = −16381, MAX_EXP = 16384 — совпадает с x87).

## Примеры

```c
#include <float.h>
#include <math.h>
#include <stdio.h>

int main(void)
{
    long double x = ldexpl(1.0L, LDBL_MAX_EXP - 1);

    printf("%.21Lg\n", x); // 5.94865747678615882511e+4931

    return 0;
}
```
