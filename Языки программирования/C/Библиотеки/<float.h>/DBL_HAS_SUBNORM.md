## Определение

```c
#include <float.h>

#define DBL_HAS_SUBNORM 1 // в glibc
```

## Описание

Константа (C11) — признак поддержки денормализованных (субнормальных) чисел типа `double`: −1 — не определяется стандартом, 0 — не поддерживаются, 1 — поддерживаются. Денормализованные числа заполняют диапазон между нулём и `DBL_MIN` (например, `5e-324`) ценой потери точности. В glibc значение равно 1; в редких реализациях с отключёнными субнормальными числами поведение может отличаться.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    if (DBL_HAS_SUBNORM == 1) {
        printf("Денормализованные double поддерживаются\n");
    }

    return 0;
}
```
