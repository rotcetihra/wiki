## Определение

```c
#include <float.h>

#define FLT_MAX_10_EXP 38 // в glibc
```

## Описание

Константа — максимальное целое e такое, что 10ᵉ представимо как нормализованный `float`. Для binary32 — 38 (10³⁸ представимо, 10³⁹ — уже нет; `3.4e38` — «край» диапазона). Стандарт гарантирует минимум 37.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("Верхняя граница float: 10^%d\n", FLT_MAX_10_EXP);

    return 0;
}
```
