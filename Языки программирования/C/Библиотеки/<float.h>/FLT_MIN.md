## Определение

```c
#include <float.h>

#define FLT_MIN 1.17549435082228750797e-38F // в glibc
```

## Описание

Константа — минимальное _нормализованное_ положительное значение типа `float`: для binary32 это 2⁻¹²⁶ ≈ 1.175·10⁻³⁸. Меньшие числа — денормализованные, вплоть до `FLT_TRUE_MIN` ≈ 1.4·10⁻⁴⁵. Как и в случае с `DBL_MIN`, при сравнении с нулём корректнее использовать `FLT_EPSILON`, а не `FLT_MIN`.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    float x = FLT_MIN;

    printf("%.9g\n", x); // 1.17549435e-38

    return 0;
}
```
