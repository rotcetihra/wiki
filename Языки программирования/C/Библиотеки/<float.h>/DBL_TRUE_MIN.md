## Определение

```c
#include <float.h>

#define DBL_TRUE_MIN 4.94065645841246544177e-324 // в glibc
```

## Описание

Константа (C11) — минимальное положительное _денормализованное_ значение типа `double`: наименьшее число, большее нуля, представимое в типе. Для binary64 это 2⁻¹⁰⁷⁴ ≈ 4.94·10⁻³²⁴. Все значения между нулём и `DBL_TRUE_MIN` не представимы; между `DBL_MIN` и `DBL_TRUE_MIN` лежат денормализованные числа с уменьшающейся точностью.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    double x = DBL_TRUE_MIN;

    printf("%.17g\n", x); // 4.9406564584124654e-324
    x = x / 2.0;
    printf("При делении на 2: %g\n", x); // 0 — исчерпание

    return 0;
}
```
