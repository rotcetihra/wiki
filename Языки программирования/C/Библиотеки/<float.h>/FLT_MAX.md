## Определение

```c
#include <float.h>

#define FLT_MAX 3.40282346638528859812e+38F // в glibc
```

## Описание

Константа — максимальное конечное значение типа `float`. Для binary32: (2−2⁻²³)·2¹²⁷ ≈ 3.403·10³⁸. Суффикс `F` гарантирует тип `float` константы. Стандарт гарантирует минимум 1e37. Используется в проверках переполнения и как «бесконечный» порог в алгоритмах поиска минимума/максимума.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    float x = FLT_MAX;

    printf("%.9g\n", x); // 3.40282347e+38

    return 0;
}
```
