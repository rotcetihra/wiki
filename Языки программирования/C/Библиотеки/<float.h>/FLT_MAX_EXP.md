## Определение

```c
#include <float.h>

#define FLT_MAX_EXP 128 // в glibc
```

## Описание

Константа — максимальное целое e такое, что `FLT_RADIX^e − 1` представимо как нормализованный `float`. Для binary32 при основании 2: 2¹²⁸ не представимо, диапазон экспонент — [−125; 128]. Пригодится при работе с `frexpf()`/`ldexpf()`, когда нужно вычислить наибольшую степень двойки, представимую в `float`.

## Примеры

```c
#include <float.h>
#include <math.h>
#include <stdio.h>

int main(void)
{
    float x = ldexpf(1.0f, FLT_MAX_EXP - 1);

    printf("%.9g\n", x); // 1.70141173e+38

    return 0;
}
```
