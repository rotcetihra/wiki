## Определение

```c
#include <float.h>

#define DBL_MIN 2.22507385850720138309e-308 // в glibc
```

## Описание

Константа — минимальное _нормализованное_ положительное значение типа `double`: число вида 2⁻¹⁰²² ≈ 2.225·10⁻³⁰⁸. Меньшие положительные числа — денормализованные (вплоть до `DBL_TRUE_MIN`). Частая ошибка начинающих: использование `DBL_MIN` как «минимального представимого» при сравнении с нулём; корректный критерий «практического нуля» — `DBL_EPSILON`, а абсолютного минимума — `DBL_TRUE_MIN`.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    double small = 1e-300; // больше DBL_MIN — нормализованное

    printf("small: %g\n", small);

    return 0;
}
```
