## Определение

```c
#include <float.h>

#define FLT_MANT_DIG 24 // в glibc
```

## Описание

Константа — количество цифр мантиссы `float` в системе счисления с основанием `FLT_RADIX`, включая скрытый бит. Для binary32: 23 хранимых бита + 1 скрытый = 24. Стандарт гарантирует минимум 6; фактически 24. Из этого значения выводится десятичная точность `FLT_DIG` (24·log₁₀2 ≈ 7,2, но гарантированных цифр 6, надёжных — через `FLT_DECIMAL_DIG` — 9).

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("Мантисса float: %d цифр по основанию %d\n",
           FLT_MANT_DIG, FLT_RADIX);

    return 0;
}
```
