## Определение

```c
#include <float.h>

#define FLT_HAS_SUBNORM 1 // в glibc
```

## Описание

Константа (C11) — признак поддержки денормализованных чисел типа `float`: 1 — поддерживаются, 0 — нет, −1 — не определяется стандартом (например, при компиляции GCC с `-fno-fast-math` и т. п.). Денормализованные `float` занимают диапазон до `FLT_TRUE_MIN` ≈ 1.4·10⁻⁴⁵ (binary32). Некоторые реализации по производительности отключают их через флаги компилятора.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    if (FLT_HAS_SUBNORM != 1) {
        printf("Денормализованные float могут не поддерживаться\n");
    }

    return 0;
}
```
