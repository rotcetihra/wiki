## Определение

```c
#include <float.h>

#define LDBL_MANT_DIG 64 // в glibc на x86-64
```

## Описание

Константа — количество цифр мантиссы `long double` в системе счисления с основанием `FLT_RADIX`. На x86-64 (80-битный расширенный формат x87) — 64 (явный, не скрытый бит); на aarch64 (binary128) — 113. Стандарт гарантирует минимум 10 цифр мантиссы.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("Мантисса long double: %d цифр по основанию %d\n",
           LDBL_MANT_DIG, FLT_RADIX);

    return 0;
}
```
