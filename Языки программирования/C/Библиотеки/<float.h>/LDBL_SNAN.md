## Определение

```c
#include <float.h>

#define LDBL_SNAN __builtin_nansl("") // в glibc
```

## Описание

Константа (C23) — сигнализирующее NaN (signaling NaN) типа `long double`. Любая арифметическая операция с ним возбуждает исключение с плавающей точкой; в glibc определяется через встроенную функцию GCC `__builtin_nansl()`. Используется при тестировании обработчиков исключений FPU.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    long double qnan = __builtin_nanl("");

    printf("Тихое NaN: %Lg\n", qnan);

    return 0;
}
```

> [!WARNING]
> Операции с `LDBL_SNAN` генерируют аппаратное исключение — без обработчика программа завершается аварийно.
