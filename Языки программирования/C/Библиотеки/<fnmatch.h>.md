## Описание библиотеки

Заголовочный файл `<fnmatch.h>` — типы сопоставления имён файлов. Определяет константы и функцию `fnmatch()` для сопоставления строк с шаблонами имён файлов (shell-паттернами).

### Константы

| Константа | Описание |
|---|---|
| `FNM_NOMATCH` | Возвращается если строка не соответствует шаблону |
| `FNM_PATHNAME` | Символ `/` в строке соответствует только `/` в шаблоне |
| `FNM_PERIOD` | Начальная `.` должна точно соответствовать `.` в шаблоне |
| `FNM_NOESCAPE` | Отключение экранирования обратным слэшем `\` |

### Функция `fnmatch()`

```c
int fnmatch(const char *pattern, const char *string, int flags);
```

| Параметр | Описание |
|---|---|
| `pattern` | Шаблон (содержит `*`, `?`, `[...]`) |
| `string` | Сопоставляемая строка |
| `flags` | Битовая маска флагов |

### Возвращаемое значение

- `0` — строка соответствует шаблону.
- `FNM_NOMATCH` — строка не соответствует шаблону.
- Другое значение — ошибка.

### Использование

```c
#include <fnmatch.h>

if (fnmatch("*.txt", "file.txt", 0) == 0) {
    printf("Это текстовый файл\n");
}

if (fnmatch("*/src/*.c", "/home/user/src/main.c", FNM_PATHNAME) == 0) {
    printf("Файл C в каталоге src\n");
}
```

## Исключения

- **NULL:** функция не принимает `NULL`.
- **FNM_NOMATCH:** не является ошибкой — просто несовпадение.
- **Шаблоны:** `*` — любые символы, `?` — один символ, `[...]` — набор символов.
- **FNM_PATHNAME:** полезно для поиска файлов в каталогах.
- **Многопоточность:** функция потокобезопасна.

## Стандарты

POSIX.1-2017.
