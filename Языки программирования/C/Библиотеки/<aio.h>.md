## Описание библиотеки

Заголовочный файл `<aio.h>` — асинхронный ввод-вывод (Realtime). Определяет структуру `aiocb` и функции для асинхронного чтения/записи данных.

### Структура `struct aiocb`

```c
struct aiocb {
    int             aio_fildes;     /* Файловый дескриптор */
    off_t           aio_offset;     /* Смещение в файле */
    volatile void  *aio_buf;        /* Буфер данных */
    size_t          aio_nbytes;     /* Размер передачи */
    int             aio_reqprio;    /* Приоритет запроса */
    struct sigevent aio_sigevent;   /* Уведомление о завершении */
    int             aio_lio_opcode; /* Операция для lio_listio() */
};
```

### Константы

| Константа | Описание |
|---|---|
| `AIO_ALLDONE` | Ни одну операцию невозможно отменить (уже завершены) |
| `AIO_CANCELED` | Все операции отменены |
| `AIO_NOTCANCELED` | Некоторые операции выполняются |
| `LIO_NOP` | Без операции |
| `LIO_NOWAIT` | Асинхронное выполнение (без уведомления) |
| `LIO_READ` | Операция чтения |
| `LIO_WAIT` | Синхронное ожидание завершения |
| `LIO_WRITE` | Операция записи |

### Функции

| Функция | Описание |
|---|---|
| `aio_read(struct aiocb *)` | Асинхронное чтение |
| `aio_write(struct aiocb *)` | Асинхронная запись |
| `aio_error(const struct aiocb *)` | Получение статуса ошибки операции |
| `aio_return(struct aiocb *)` | Получение результата (количества байтов) |
| `aio_suspend(const struct aiocb *const [], int, const struct timespec *)` | Ожидание завершения хотя бы одной операции |
| `aio_cancel(int, struct aiocb *)` | Попытка отмены операций |
| `aio_fsync(int, struct aiocb *)` | Асинхронная синхронизация с диском |
| `lio_listio(int, struct aiocb *restrict const [], int, struct sigevent *restrict)` | Пакетное выполнение нескольких операций |

## Исключения

- **NULL:** функции не принимают `NULL` в качестве `aiocb`.
- **errno:** при ошибке устанавливается `errno`.
- **EINPROGRESS:** операция выполняется (не ошибка для асинхронных операций).
- **ECANCELED:** операция была отменена.
- **aio_error:** возвращает `EINPROGRESS` пока операция не завершена.
- **aio_suspend:** возвращает -1 с `EINTR` при прерывании сигналом.
- **Память:** буферы `aio_buf` должны оставаться валидными до завершения операции.
- **Многопоточность:** функции потокобезопасны.

## Стандарты

POSIX.1-2017, Realtime.
