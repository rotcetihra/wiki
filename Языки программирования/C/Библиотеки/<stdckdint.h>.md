## Описание библиотеки

Заголовочный файл `<stdckdint.h>` — макросы для проверки переполнения при арифметических операциях с целыми числами. Этот заголовок был добавлен в стандарт C23 и предоставляет безопасные макросы для выполнения арифметики с проверкой на переполнение.

> [!NOTE]
> Макросы возвращают `_Bool`: `true` если произошло переполнение, `false` если операция выполнена успешно. Результат записывается в первый аргумент.

### Макросы

| Макрос | Описание |
|---|---|
| `ckd_add(result, a, b)` | `result = a + b` с проверкой переполнения |
| `ckd_sub(result, a, b)` | `result = a - b` с проверкой переполнения |
| `ckd_mul(result, a, b)` | `result = a * b` с проверкой переполнения |
| `ckd_neg(result, a)` | `result = -a` с проверкой переполнения |
| `ckd_shl(result, a, b)` | `result = a << b` с проверкой переполнения |

### Пример использования

```c
#include <stdckdint.h>
#include <stdio.h>

int main(void) {
    int result;
    int a = INT_MAX;
    int b = 1;

    if (ckd_add(&result, a, b)) {
        printf("Переполнение при сложении!\n");
    } else {
        printf("Результат: %d\n", result);
    }

    return 0;
}
```

## Исключения

- **NULL:** макросы принимают указатель на результат; передача `NULL` — неопределённое поведение.
- **Переполнение:** макросы специально предназначены для обнаружения переполнения; при переполнении результат не определён.
- **Знаковые типы:** макросы работают с любыми целочисленными типами, включая знаковые; переполнение знаковых типов определено как неопределённое поведение в C, но макросы корректно его обнаруживают.
- **Многопоточность:** макросы не генерируют код, поэтому потокобезопасны.
- **Порядок вычислений:** аргументы вычисляются в неопределённом порядке; не используйте макросы с побочными эффектами.
