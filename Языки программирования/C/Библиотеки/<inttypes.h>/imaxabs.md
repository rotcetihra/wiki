## Определение

```c
#include <inttypes.h>

intmax_t imaxabs(intmax_t j);
```

## Описание

Функция `imaxabs` -- абсолютное значение `intmax_t`.

Функция `imaxabs` вычисляет модуль значения `j` типа `intmax_t`. Если результат не может быть представлен (например, `imaxabs(INTMAX_MIN)`), поведение не определено.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    intmax_t value = imaxabs(-42);
    printf("Значение: %jd\n", value);
    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** не применимо — параметр `j` является значением типа `intmax_t`, а не указателем.
- **Установление errno:** функция не устанавливает `errno`.
- **Возвращаемое значение при ошибке:** результат не определён при передаче `INTMAX_MIN` (переполнение знакового типа).
- **Многопоточность:** функция чистая (pure function) и безопасна в многопоточной среде.
- **Связанные функции:** аналог `abs` из `<stdlib.h>`, но для типа `intmax_t`; см. также `imaxdiv`.
