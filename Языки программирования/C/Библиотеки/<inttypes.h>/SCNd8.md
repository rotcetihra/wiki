## Определение

```c
#include <inttypes.h>

#define SCNd8 /* строковый литерал, раскрываемый в спецификатор формата */
```

## Описание

Макрос `SCNd8` -- строковый литерал, используемый в строке формата функции `scanf` (и родственных: `fscanf`, `sscanf`). Заменяет собой спецификатор формата для типа `int8_t` в формате **десятичный**.

Аргумент, соответствующий этому спецификатору, должен быть указателем на `int8_t`.

Макрос предназначен для переносимого чтения целочисленных типов фиксированной ширины. На разных платформах один и тот же тип может объявляться как `long`, `long long` или другой тип, поэтому `SCNd8` подставляет корректный спецификатор автоматически.

Использование в строке формата:

```c
int8_t value;
scanf("%" SCNd8, &value);
```

> [!NOTE]
> Макрос `SCNd8` не является самостоятельным строковым литералом и не должен использоваться отдельно. Он всегда подставляется внутрь строки формата.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    int8_t value;
    printf("Введите число: ");
    scanf("%" SCNd8, &value);
    printf("Вы ввели: %" SCNd8 "\n", value);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантированно корректный спецификатор для `int8_t` | Требует конкатенации строк в строке формата |
| Переносимость между платформами | Некоторые компиляторы могут определять макрос как пустую строку |
| Стандартный способ (ISO C99/C23) | -- |
