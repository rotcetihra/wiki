## Определение

```c
#include <inttypes.h>

#define PRIo16 /* строковый литерал, раскрываемый в спецификатор формата */
```

## Описание

Макрос `PRIo16` -- строковый литерал, используемый в строке формата функции `printf` (и родственных: `fprintf`, `snprintf`, `sprintf`). Заменяет собой спецификатор формата для типа `int16_t` в формате **восьмеричный**.

Макрос предназначен для переносимого форматирования целочисленных типов фиксированной ширины. На разных платформах один и тот же тип может объявляться как `long`, `long long` или другой тип, поэтому `PRIo16` подставляет корректный спецификатор автоматически.

Использование в строке формата:

```c
printf("%" PRIo16 "\n", value);
```

> [!NOTE]
> Макрос `PRIo16` не является самостоятельным строковым литералом и не должен использоваться отдельно. Он всегда подставляется внутрь строки формата.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    int16_t value = 42;
    printf("Значение: %" PRIo16 "\n", value);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантированно корректный спецификатор для `int16_t` | Требует конкатенации строк в строке формата |
| Переносимость между платформами | Некоторые компиляторы могут определять макрос как пустую строку |
| Стандартный способ (ISO C99/C23) | -- |
