## Определение

```c
#include <inttypes.h>

intmax_t strtoimax(const char * restrict nptr, char ** restrict endptr, int base);
```

## Описание

Функция `strtoimax` -- преобразование строки в `intmax_t`.

Функция `strtoimax` преобразует строку `nptr` в значение типа `intmax_t`. Параметр `base` определяет основание системы счисления (от 2 до 36, или 0 для автоопределения по префиксу `0x`/`0`). Параметр `endptr`, если не равен `NULL`, получает указатель на первый необработанный символ. При переполнении возвращается `INTMAX_MAX` или `INTMAX_MIN`, а `errno` устанавливается в `ERANGE`.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    intmax_t value = strtoimax("12345", NULL, 10);
    printf("Значение: %jd\n", value);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `nptr` | Указатель на преобразуемую строку |
| `endptr` | Указатель на указатель, получающий первый необработанный символ (`NULL` если не используется) |
| `base` | Основание системы счисления (2--36 или 0 для автоопределения) |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Успешное преобразование | Значение типа `intmax_t` |
| Переполнение | `INTMAX_MAX` или `INTMAX_MIN`, `errno = ERANGE` |
| Неверный формат | `0`, `errno` не изменяется |

## Обработка ошибок

- **Поведение при передаче NULL:** поведение не определено. Согласно стандарту, `nptr` не должен быть `NULL`; передача `NULL` приводит к неопределённому поведению. Параметр `endptr` может быть `NULL` — в этом случае информация о первом необработанном символе не сохраняется.
- **Установление errno:** при переполнении (результат не представим в `intmax_t`) `errno` устанавливается в `ERANGE`. При передаче `NULL` в `nptr` значение `errno` не определено.
- **Возвращаемое значение при ошибке:** `INTMAX_MAX` или `INTMAX_MIN` при переполнении; `0` при некорректном формате.
- **Многопоточность:** функция безопасна в многопоточной среде, если `endptr` и `nptr` указывают на разные объекты (или `endptr` равен `NULL`). Локальный буфер `errno` не разделяется между потоками.
- **Связанные функции:** пары с `strtoumax` (для беззнакового типа); аналог `strtol` из `<stdlib.h>`, но для типа `intmax_t`.
