## Определение

```c
#include <inttypes.h>

imaxdiv_t imaxdiv(intmax_t lhs, intmax_t rhs);
```

## Описание

Функция `imaxdiv` -- деление `intmax_t` с возвратом частного и остатка.

Функция `imaxdiv` вычисляет частное и остаток от деления `lhs` на `rhs`. Возвращает структуру `imaxdiv_t` с полями `quot` (частное) и `rem` (остаток). Если `rhs` равен нулю, поведение не определено.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    imaxdiv_t result = imaxdiv(100, 7);
    printf("Частное: %jd, остаток: %jd\n", result.quot, result.rem);
    return 0;
}
```

| `rhs` | Делитель типа `intmax_t` |

## Обработка ошибок

- **Поведение при передаче NULL:** не применимо — оба параметра являются значениями типа `intmax_t`, а не указателями.
- **Установление errno:** функция не устанавливает `errno`.
- **Возвращаемое значение при ошибке:** не определено при делении на ноль (`rhs == 0`).
- **Многопоточность:** функция чистая (pure function) и безопасна в многопоточной среде.
- **Связанные функции:** аналог `div` из `<stdlib.h>`, но для типа `intmax_t`; см. также `imaxabs`.
