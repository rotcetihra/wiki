## Определение

```c
#include <inttypes.h>

intmax_t wcstoimax(const wchar_t * restrict nptr, wchar_t ** restrict endptr, int base);
```

## Описание

Функция `wcstoimax` -- преобразование широкой строки в `intmax_t`.

Функция `wcstoimax` преобразует широкую строку `nptr` в значение типа `intmax_t`. Аналог `strtoimax`, но работает с типом `wchar_t`. Параметры и поведение аналогичны `strtoimax`.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    intmax_t value = wcstoimax(L"12345", NULL, 10);
    printf("Значение: %jd\n", value);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `nptr` | Указатель на преобразуемую широкую строку |
| `endptr` | Указатель на указатель, получающий первый необработанный символ (`NULL` если не используется) |
| `base` | Основание системы счисления (2--36 или 0 для автоопределения) |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Успешное преобразование | Значение типа `intmax_t` |
| Переполнение | `INTMAX_MAX` или `INTMAX_MIN`, `errno = ERANGE` |
| Неверный формат | `0`, `errno` не изменяется |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Работает с типом максимальной ширины | Некорректный `base` -- неопределённое поведение |
| Стандартная функция ISO C99/C23 | -- |
