## Определение

```c
#include <inttypes.h>

#define SCNuMAX /* строковый литерал, раскрываемый в спецификатор формата */
```

## Описание

Макрос `SCNuMAX` -- строковый литерал, используемый в строке формата функции `scanf` (и родственных: `fscanf`, `sscanf`). Заменяет собой спецификатор формата для типа `uintmax_t` в формате **десятичный без знака**.

Аргумент, соответствующий этому спецификатору, должен быть указателем на `uintmax_t`.

Макрос предназначен для переносимого чтения целочисленных типов фиксированной ширины. На разных платформах один и тот же тип может объявляться как `long`, `long long` или другой тип, поэтому `SCNuMAX` подставляет корректный спецификатор автоматически.

Использование в строке формата:

```c
uintmax_t value;
scanf("%" SCNuMAX, &value);
```

> [!NOTE]
> Макрос `SCNuMAX` не является самостоятельным строковым литералом и не должен использоваться отдельно. Он всегда подставляется внутрь строки формата.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    uintmax_t value;
    printf("Введите число: ");
    scanf("%" SCNuMAX, &value);
    printf("Вы ввели: %" SCNuMAX "\n", value);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантированно корректный спецификатор для `uintmax_t` | Требует конкатенации строк в строке формата |
| Переносимость между платформами | Некоторые компиляторы могут определять макрос как пустую строку |
| Стандартный способ (ISO C99/C23) | -- |
