## Определение

```c
#include <inttypes.h>

uintmax_t wcstoumax(const wchar_t * restrict nptr, wchar_t ** restrict endptr, int base);
```

## Описание

Функция `wcstoumax` -- преобразование широкой строки в `uintmax_t`.

Функция `wcstoumax` преобразует широкую строку `nptr` в значение типа `uintmax_t`. Аналог `strtoumax`, но работает с типом `wchar_t`. Параметры и поведение аналогичны `strtoumax`.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    uintmax_t value = wcstoumax(L"0xFF", NULL, 16);
    printf("Значение: %ju\n", value);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `nptr` | Указатель на преобразуемую широкую строку |
| `endptr` | Указатель на указатель, получающий первый необработанный символ (`NULL` если не используется) |
| `base` | Основание системы счисления (2--36 или 0 для автоопределения) |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Успешное преобразование | Значение типа `uintmax_t` |
| Переполнение | `UINTMAX_MAX`, `errno = ERANGE` |
| Неверный формат | `0`, `errno` не изменяется |

## Плюсы и минусы

| Преимущество | Недостаток |

| Работает с типом максимальной ширины | Некорректный `base` -- неопределённое поведение |
