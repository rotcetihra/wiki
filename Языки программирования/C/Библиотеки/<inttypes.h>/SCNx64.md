## Определение

```c
#include <inttypes.h>

#define SCNx64 /* строковый литерал, раскрываемый в спецификатор формата */
```

## Описание

Макрос `SCNx64` -- строковый литерал, используемый в строке формата функции `scanf` (и родственных: `fscanf`, `sscanf`). Заменяет собой спецификатор формата для типа `uint64_t` в формате **шестнадцатеричный**.

Аргумент, соответствующий этому спецификатору, должен быть указателем на `uint64_t`.

Макрос предназначен для переносимого чтения целочисленных типов фиксированной ширины. На разных платформах один и тот же тип может объявляться как `long`, `long long` или другой тип, поэтому `SCNx64` подставляет корректный спецификатор автоматически.

Использование в строке формата:

```c
uint64_t value;
scanf("%" SCNx64, &value);
```

> [!NOTE]
> Макрос `SCNx64` не является самостоятельным строковым литералом и не должен использоваться отдельно. Он всегда подставляется внутрь строки формата.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    uint64_t value;
    printf("Введите число: ");
    scanf("%" SCNx64, &value);
    printf("Вы ввели: %" SCNx64 "\n", value);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантированно корректный спецификатор для `uint64_t` | Требует конкатенации строк в строке формата |
| Переносимость между платформами | Некоторые компиляторы могут определять макрос как пустую строку |
| Стандартный способ (ISO C99/C23) | -- |
