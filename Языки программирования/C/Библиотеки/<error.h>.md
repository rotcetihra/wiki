## Описание библиотеки

Заголовочный файл `<error.h>` — функции отчёта об ошибках. Определяет функции `error()` и `error_at_line()` для вывода сообщений об ошибках в stderr и опционального завершения программы.

### Функции

| Функция | Описание |
|---|---|
| `error(int status, int errnum, const char *format, ...)` | Вывод имени программы, форматированного сообщения и (если `errnum != 0`) strerror(errnum); если `status != 0` — завершение через `exit(status)` |
| `error_at_line(int status, int errnum, const char *fname, unsigned int lineno, const char *format, ...)` | То же, но с указанием имени файла и номера строки |

### Переменные

| Переменная | Описание |
|---|---|
| `error_print_progname` | Указатель на функцию вывода имени программы (по умолчанию выводит `program_name: `) |
| `error_message_count` | Счётчик вызовов `error()` |
| `error_one_per_line` | Если ненулевое, выводит одну ошибку на строку файла |

### Возвращаемое значение

- `error()`: ничего не возвращает (завершает программу если `status != 0`).
- `error_at_line()`: ничего не возвращает.

### Использование

```c
#include <error.h>

error(0, 0, "Программа завершена успешно");
error(EXIT_FAILURE, errno, "Ошибка чтения файла");
error_at_line(EXIT_FAILURE, ENOENT, __FILE__, __LINE__, "%s: файл не найден", filename);
```

## Исключения

- **NULL:** `error()` и `error_at_line()` не принимают `NULL` для format.
- **status = 0:** не завершает программу (выводит сообщение).
- **errnum = 0:** не добавляет strerror().
- **error_print_progname:** установите в свою функцию для кастомного вывода имени.
- **error_one_per_line:** полезно для дедупликации ошибок.
- **Не POSIX:** функции из GNU C Library (glibc).
- **Многопоточность:** `error_message_count` увеличивается атомарно; остальные функции потокобезопасны.

## Стандарты

glibc (не POSIX).
