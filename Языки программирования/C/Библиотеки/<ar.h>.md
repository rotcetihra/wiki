## Описание библиотеки

Заголовочный файл `<ar.h>` — описание формата архива `ar`. Определяет константы и структуру заголовка для чтения и записи архивных файлов (`.a` библиотеки, объектные архивы).

### Константы

| Константа | Значение | Описание |
|---|---|---|
| `ARMAG` | `"!<arch>\n"` | Строка начинающая архивный файл |
| `SARMAG` | `8` | Длина строки `ARMAG` |
| `ARFMAG` | `` "`\n" `` | Магическая строка в конце каждого заголовка |

### Структура `struct ar_hdr`

```c
struct ar_hdr {
    char ar_name[16];   /* Имя файла-члена (иногда завершается /) */
    char ar_date[12];   /* Дата файла, десятичные секунды с Epoch */
    char ar_uid[6];     /* ID владельца, ASCII восьмеричное */
    char ar_gid[6];     /* ID группы, ASCII восьмеричное */
    char ar_mode[8];    /* Режим доступа, ASCII восьмеричное */
    char ar_size[10];   /* Размер файла, ASCII десятичное */
    char ar_fmag[2];    /* Всегда содержит ARFMAG */
};
```

### Формат архива

```
!<arch>\n           /* Начало архива */
[заголовок ar_hdr]  /* Заголовок файла 1 */
[данные файла 1]    /* ar_size байтов */
[заголовок ar_hdr]  /* Заголовок файла 2 */
[данные файла 2]    /* ar_size байтов */
...
```

### Использование

```c
#include <ar.h>
#include <stdio.h>

int main(void) {
    printf("Размер заголовка: %zu байтов\n", sizeof(struct ar_hdr));
    printf("Начало архива: %s\n", ARMAG);
    return 0;
}
```

## Исключения

- **Память:** структура `ar_hdr` фиксированного размера; данные файлов следуют непосредственно за заголовком.
- **Формат:** все поля хранятся как ASCII строки фиксированной длины.
- **Типы файлов:** формат `ar` не определяет тип файлов (в отличие от `tar`).
- **Многопоточность:** заголовок не является потокобезопасным; используется программистом вручную.
