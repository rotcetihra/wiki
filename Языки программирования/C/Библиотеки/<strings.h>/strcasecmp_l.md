## Прототип

```c
#define _POSIX_C_SOURCE 200809L
#include <strings.h>

int strcasecmp_l(const char *s1, const char *s2, locale_t loc);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1`, `s2` | Сравниваемые строки |
| `loc` | Локаль, правила которой используются для сравнения (тип `locale_t` из `<locale.h>`) |

## Возвращаемое значение

Отрицательное число, 0 или положительное число — результат сравнения строк без учёта регистра по правилам локали `loc`.

## Что делает

Аналог `strcasecmp()`, но локаль задаётся явно через `locale_t` и не зависит от глобальной локали процесса: не нужно вызывать `setlocale()`, функция пригодна для многопоточных программ. Требует POSIX.1-2008 (в glibc — определение `_POSIX_C_SOURCE` или `_GNU_SOURCE`).

## Примеры

```c
#include <locale.h>
#include <stdio.h>
#include <strings.h>

int main(void)
{
    locale_t ru = newlocale(LC_ALL_MASK, "ru_RU.UTF-8", NULL);

    printf("%d\n", strcasecmp_l("Ёлка", "ёлка", ru)); // 0 — равны

    freelocale(ru);
    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Некорректный `loc` — неопределённое поведение.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Не зависит от глобальной локали (потокобезопасна) | Менее известна, чем `strcasecmp()` |
| Работает с локалями, созданными через `newlocale()` | Требует POSIX.1-2008 |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (возвращает отрицательное, нулевое или положительное значение).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `s1`, `s2` или `loc`.
- **Многопоточность:** потокобезопасна (использует явную локаль, не зависит от глобальной).
