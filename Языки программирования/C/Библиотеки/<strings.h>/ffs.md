## Прототип

```c
#include <strings.h>

int ffs(int i);
```

## Параметры

| Параметр | Описание |
|---|---|
| `i` | Проверяемое целое |

## Возвращаемое значение

Позицию первого (наименее значимого) установленного бита с нумерацией от 1 (младший бит — позиция 1, старший — 32) или 0, если установленных битов нет.

## Что делает

Находит позицию первого установленного бита в `int` (от англ. _find first set_). На большинстве платформ компилируется в одну инструкцию процессора.

## Примеры

```c
#include <stdio.h>
#include <strings.h>

int main(void)
{
    printf("%d\n", ffs(12)); // 3 — 12 == 0b1100
    printf("%d\n", ffs(1));  // 1
    printf("%d\n", ffs(0));  // 0 — установленных битов нет

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и эффективная | Нумерация с 1 непривычна (обычно отсчёт от 0) |
| Стандартизована POSIX.1-2008 (XSI) | |

## Альтернативы

- `(i & -i)` — выделить младший установленный бит, затем вычислить его позицию
- В C23 — `stdc_first_trailing_one()` из `<stdbit.h>`

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (возвращает позицию бита или 0).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** не применимо (аргумент — целое число, не указатель).
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние).
