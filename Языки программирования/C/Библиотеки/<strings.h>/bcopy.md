## Прототип

```c
#include <strings.h>

void bcopy(const void *src, void *dest, size_t n);
```

>[!WARNING]
>Порядок аргументов обратный по сравнению с `memcpy()`: на первом месте источник, на втором — приёмник. `bcopy(src, dest, n)` эквивалентна `memmove(dest, src, n)` — при переносе кода легко ошибиться.

## Параметры

| Параметр | Описание |
|---|---|
| `src` | Источник |
| `dest` | Приёмник |
| `n` | Количество копируемых байт |

## Возвращаемое значение

Ничего не возвращает.

## Что делает

Копирует `n` байт из `src` в `dest`. Перекрывающиеся области допустимы (как `memmove()`). Устаревшая (LEGACY) функция BSD: вместо неё следует использовать `memmove()` или `memcpy()` из `<string.h>`.

## Примеры

```c
#include <stdio.h>
#include <strings.h>

int main(void)
{
    char buf[16] = "hello";
    bcopy("world", buf, 5); // теперь buf == "world"

    printf("%s\n", buf);
    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Поддерживает перекрытие областей | Устаревшая (LEGACY) |
| | Порядок аргументов «наоборот» — источник ошибок при переносе кода |

## Альтернативы

- **`memmove()`** — стандартная замена с поддержкой перекрытия
- `memcpy()` — если перекрытие не требуется

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (ничего не возвращает).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `src` или `dest`.
- **Многопоточность:** потокобезопасна при использовании различных буферов; приshared.dest не потокобезопасна.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<string.h>/memmove|memmove]], [[Языки программирования/C/Библиотеки/<string.h>/memcpy|memcpy]].
