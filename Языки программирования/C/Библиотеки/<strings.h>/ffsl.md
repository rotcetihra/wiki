## Прототип

```c
#include <strings.h>

int ffsl(long int l);
```

## Параметры

| Параметр | Описание |
|---|---|
| `l` | Проверяемое целое |

## Возвращаемое значение

Позицию первого (наименее значимого) установленного бита с нумерацией от 1 или 0, если установленных битов нет.

## Что делает

Аналог `ffs()` для типа `long`. В glibc доступна как расширение GNU (не входит в POSIX).

## Примеры

```c
#include <stdio.h>
#include <strings.h>

int main(void)
{
    printf("%d\n", ffsl(0x100000000L)); // 33 — 33-й бит
    printf("%d\n", ffsl(0L));           // 0

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Работает с `long` (на 64-битных системах — 64 бита) | Расширение GNU: не переносится на другие POSIX-системы |
