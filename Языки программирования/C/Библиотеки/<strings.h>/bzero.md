## Прототип

```c
#include <strings.h>

void bzero(void *s, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Блок памяти для обнуления |
| `n` | Количество обнуляемых байт |

## Возвращаемое значение

Ничего не возвращает.

## Что делает

Заполняет первые `n` байт блока `s` нулями — эквивалент `memset(s, 0, n)`. Устаревшая (LEGACY) функция BSD: вместо неё следует использовать `memset()` из `<string.h>`.

## Примеры

```c
#include <stdio.h>
#include <strings.h>

int main(void)
{
    char buf[8] = "abcdefgh";
    bzero(buf, 4); // первые 4 байта — нули

    printf("%d\n", buf[0]); // 0
    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Короткое имя | Устаревшая (LEGACY) |

## Альтернативы

- **`memset(s, 0, n)`** — стандартная замена из `<string.h>`

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (ничего не возвращает).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `s`.
- **Многопоточность:** потокобезопасна при использовании различных буферов; приshared.s не потокобезопасна.
