## Прототип

```c
#define _POSIX_C_SOURCE 200809L
#include <strings.h>

int strncasecmp_l(const char *s1, const char *s2, size_t n, locale_t loc);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1`, `s2` | Сравниваемые строки |
| `n` | Максимальное количество сравниваемых символов |
| `loc` | Локаль, правила которой используются для сравнения (тип `locale_t` из `<locale.h>`) |

## Возвращаемое значение

Отрицательное число, 0 или положительное число — результат сравнения первых `n` символов строк без учёта регистра по правилам локали `loc`.

## Что делает

Комбинация `strncasecmp()` и `strcasecmp_l()`: сравнивает не более `n` символов без учёта регистра по правилам явно заданной локали. Не зависит от глобальной локали процесса. Требует POSIX.1-2008 (в glibc — определение `_POSIX_C_SOURCE` или `_GNU_SOURCE`).

## Примеры

```c
#include <locale.h>
#include <stdio.h>
#include <strings.h>

int main(void)
{
    locale_t ru = newlocale(LC_ALL_MASK, "ru_RU.UTF-8", NULL);

    printf("%d\n", strncasecmp_l("ЁЛКА-1", "ёлка", 4, ru)); // 0

    freelocale(ru);
    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Некорректный `loc` — неопределённое поведение.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Не зависит от глобальной локали (потокобезопасна) | Менее известна |
| Ограничение длины защищает от переполнения | Требует POSIX.1-2008 |
