## Прототип

```c
#include <stdlib.h>

long labs(long n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `n` | Целое число |

## Возвращаемое значение

Абсолютное значение аргумента (модуль числа).

## Что делает

Возвращает модуль числа. Для `LONG_MIN` результат не помещается в `long` — поведение не определено (в glibc возвращается `LONG_MIN`).

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    printf("%ld\n", labs(-123456789L)); // 123456789
    printf("%ld\n", labs(42L));         // 42

    return 0;
}
```

>[!WARNING]
>`labs(LONG_MIN)` — неопределённое поведение: модуль наименьшего значения `long` не представим в `long`.

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и быстрая | Неопределённое поведение для `LONG_MIN` |
