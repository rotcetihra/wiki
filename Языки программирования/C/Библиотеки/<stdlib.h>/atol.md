## Прототип

```c
#include <stdlib.h>

long atol(const char *str);
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | Строка, содержащая целое число |

## Возвращаемое значение

Результат преобразования или 0, если в начале строки не оказалось распознаваемого числа.

## Что делает

Преобразует строку в `long`: пропускает ведущие пробельные символы, разбирает необязательный знак `+`/`-` и десятичные цифры, останавливаясь на первом нераспознанном символе. Работает как `atoi()`, но с типом `long`.

>[!WARNING]
>Невозможно отличить успешное преобразование строки `"0"` от неудачного. При переполнении поведение по стандарту не определено (в отличие от `strtol()`, которая сигнализирует через `errno`).

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    printf("%ld\n", atol("123456789")); // 123456789
    printf("%ld\n", atol("-42"));       // -42

    return 0;
}
```

## Ошибки и errno

Не даёт надёжного способа обнаружить ошибку: переполнение и отсутствие распознаваемого числа неотличимы от успешного преобразования (по стандарту поведение при переполнении не определено).

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая, короткая | Нет проверки ошибок (0 и переполнение неотличимы) |
| | Нельзя узнать, где остановилось преобразование |

## Альтернативы

- **`strtol()`** — с указателем `endptr`, основанием системы счисления и обработкой ошибок через `errno`
