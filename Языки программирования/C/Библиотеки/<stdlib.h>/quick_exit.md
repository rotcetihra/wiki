## Прототип

```c
#include <stdlib.h> // C11

void quick_exit(int status);
```

## Параметры

| Параметр | Описание |
|---|---|
| `status` | Код завершения программы |

## Возвращаемое значение

Не возвращает управление.

## Что делает

Завершает программу быстро: вызывает функции, зарегистрированные через `at_quick_exit()`, в порядке, обратном регистрации, и затем немедленно передаёт управление операционной системе (как `_Exit()`). Отличие от `exit()`: не вызываются `atexit()`-функции и не сбрасываются буферы `stdio` — поэтому завершение не зависает, если, например, терминал не готов принимать вывод. Буферы могут остаться незаписанными.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

void quick_cleanup(void)
{
    printf("Быстрая очистка\n");
}

int main(void)
{
    at_quick_exit(quick_cleanup);

    printf("Данные в буфере\n");
    quick_exit(EXIT_SUCCESS); // «Данные в буфере» может не вывестись
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Завершение без ожидания сброса буферов | Буферы `stdio` не сбрасываются — вывод может потеряться |
| Гарантированный вызов `at_quick_exit()`-функций | Не вызываются `atexit()`-функции |

## Альтернативы

- **`exit()`** — полное завершение с «уборкой»
- `_Exit()` — немедленное завершение без «уборки»
- `abort()` — аварийное завершение
