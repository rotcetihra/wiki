## Определение

```c
#include <stdlib.h>

#define EXIT_SUCCESS 0 // в glibc
```

## Описание

Константа — статус завершения программы при успешном выполнении, передаваемая функциям `exit()`, `_Exit()` и `quick_exit()`. Фактическое значение определяется реализацией (в glibc — 0). `return 0` из `main()` эквивалентно `return EXIT_SUCCESS`, так как возврат 0 из `main()` всегда означает успешное завершение; использование константы делает намерение явным и код переносимым.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    printf("Программа отработала успешно\n");
    return EXIT_SUCCESS;
}
```
