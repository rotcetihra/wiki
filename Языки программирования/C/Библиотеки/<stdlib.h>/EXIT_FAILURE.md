## Определение

```c
#include <stdlib.h>

#define EXIT_FAILURE 1 // в glibc
```

## Описание

Константа — статус завершения программы при ошибке, передаваемая функциям `exit()`, `_Exit()` и `quick_exit()` (в C23 — также `return EXIT_FAILURE` из `main()`). Фактическое значение определяется реализацией (в glibc — 1). Использование константы вместо «магического» числа делает код переносимым. Статусы `EXIT_SUCCESS` и `EXIT_FAILURE` не обязаны быть 0 и 1 — за их значение отвечает реализация.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    FILE *f = fopen("data.txt", "r");
    if (f == NULL) {
        fprintf(stderr, "Не удалось открыть файл\n");
        return EXIT_FAILURE;
    }

    fclose(f);
    return EXIT_SUCCESS;
}
```
