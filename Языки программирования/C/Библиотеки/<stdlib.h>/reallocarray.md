## Прототип

```c
#include <stdlib.h> // BSD, GNU (glibc 2.26+)

void *reallocarray(void *ptr, size_t nmemb, size_t size);
```

## Параметры

| Параметр | Описание |
|---|---|
| `ptr` | Указатель на блок (или `NULL` — как `malloc(nmemb * size)`) |
| `nmemb` | Количество элементов |
| `size` | Размер одного элемента |

## Возвращаемое значение

Указатель на блок `nmemb × size` байт или `NULL` при неудаче (старый блок при этом не освобождается).

## Что делает

`realloc()` с защитой от переполнения умножения: если `nmemb × size` не помещается в `size_t`, возвращает `NULL` и устанавливает `errno = ENOMEM`, не трогая старый блок. Появилась в OpenBSD (2014), в glibc — с 2.26 (2017). Устраняет классическую уязвимость целочисленного переполнения при вычислении размера вручную.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *arr = NULL;
    size_t n = 8;

    // Безопасное изменение размера массива
    int *tmp = reallocarray(arr, n, sizeof(int));
    if (tmp == NULL) {
        free(arr);
        return 1;
    }
    arr = tmp;

    printf("%zu\n", n * sizeof(int)); // 32 — размер блока

    free(arr);
    return 0;
}
```

## Ошибки и errno

При неудаче возвращает `NULL` и устанавливает `errno = ENOMEM` (в том числе при переполнении умножения).

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Проверка переполнения `nmemb × size` | Не входит в POSIX (BSD, glibc с 2.26) |
| Старый блок сохраняется при неудаче | Нет версии для `calloc`-подобного обнуления при расширении |

## Альтернативы

- **`realloc(ptr, nmemb * size)`** — с ручной проверкой переполнения (`if (nmemb > SIZE_MAX / size)`)
- `calloc()` — для выделения с нулями
