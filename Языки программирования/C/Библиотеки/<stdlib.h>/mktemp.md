## Прототип

```c
#include <stdlib.h> // BSD, устаревшая (LEGACY)

char *mktemp(char *template);
```

## Параметры

| Параметр | Описание |
|---|---|
| `template` | Шаблон, заканчивающийся на `XXXXXX` |

## Возвращаемое значение

Указатель на `template` с уникальным именем, или `NULL`, если сгенерировать имя не удалось.

## Что делает

Только генерирует уникальное *имя* файла, не создавая его. Разница с `mkstemp()` принципиальна: между проверкой и созданием файла проходит время — другой процесс (или злоумышленник) может успеть создать файл этим именем (гонка TOCTOU). Отмечена в POSIX как LEGACY. Для новых программ не используйте — всегда есть `mkstemp()`.

>[!WARNING]
>Имя, возвращённое `mktemp()`, используется программой после возврата — к этому моменту файл с этим именем может быть уже создан посторонним процессом. Это классическая уязвимость.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char name[] = "/tmp/wiki-XXXXXX";

    if (mktemp(name) == NULL) {
        return 1;
    }

    // Гонка: между возвратом и open() имя может быть «захвачено»
    printf("%s\n", name);

    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Поведение не определено — функция не проверяет указатель.
- **Установление errno:** `errno` не устанавливается (по некоторым реализациям устанавливается `EINVAL`).
- **Возвращаемое значение при ошибке:** Возвращает `NULL` при ошибке.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<stdlib.h>/mkstemp|mkstemp]] — безопасная замена без гонки TOCTOU.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простое имя без создания файла | Небезопасна — гонка TOCTOU |
| | Может возвращать имя существующего файла |
