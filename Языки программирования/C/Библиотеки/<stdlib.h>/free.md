## Прототип

```c
#include <stdlib.h>

void free(void *ptr);
```

## Параметры

| Параметр | Описание |
|---|---|
| `ptr` | Указатель на блок памяти, возвращённый `malloc()`, `calloc()`, `realloc()` или `aligned_alloc()` |

## Возвращаемое значение

Не возвращает значения.

## Что делает

Освобождает память, возвращённую функцией выделения. После `free()` указатель использовать нельзя — это неопределённое поведение (например, повторная `free()` того же указателя). Передача `NULL` — допустимо и ничего не делает. Память, выделенная через `malloc()` и не освобождённая, возвращается операционной системе после завершения программы автоматически.

>[!WARNING]
>Повторный вызов `free()` с одним и тем же указателем — неопределённое поведение. По стандарту C23 любое использование освобождённой памяти, включая чтение по указателю, — также неопределённое поведение.

## Примеры

```c
#include <stdlib.h>

int main(void)
{
    int *arr = malloc(10 * sizeof(int));
    if (arr == NULL) {
        return 1;
    }

    // ... работа с arr ...

    free(arr);
    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Обязательна для освобождения выделенной памяти | Ошибки использования (двойное освобождение) — неопределённое поведение |
| `free(NULL)` безопасен | Не освобождает автоматически вложенные указатели |

## Альтернативы

- **Ленивое освобождение** — память освобождается ОС при завершении программы (для коротких программ)
- Управляемые контейнеры и умные указатели — в других языках
