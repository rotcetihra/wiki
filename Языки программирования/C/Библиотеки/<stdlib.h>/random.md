## Прототип

```c
#include <stdlib.h> // POSIX XSI

long random(void);
void srandom(unsigned seed);
char *initstate(unsigned seed, char *state, size_t n);
char *setstate(char *state);
```

## Параметры

| Функция | Параметр | Описание |
|---|---|---|
| `srandom` | `seed` | Зерно генератора |
| `initstate` | `seed`, `state`, `n` | Зерно, буфер состояния (не менее 8 байт, размер кратный 32... в glibc — от 8) и его размер |
| `setstate` | `state` | Переключение на другое состояние (возвращает предыдущее) |

## Возвращаемое значение

- `random()` — число из [0, 2³¹);
- `initstate()`/`setstate()` — указатель на предыдущее состояние (или `NULL` при ошибке).

## Что делает

Семейство генераторов псевдослучайных чисел на основе линейной рекуррентной последовательности с 31-битным выходом — качественнее, чем `rand()`. Диапазон — до 2³¹−1. `initstate()` и `setstate()` позволяют хранить состояние в собственном буфере (для воспроизводимости и нескольких генераторов), а вариант `random_r()`/`srandom_r()` (GNU) — потокобезопасен. Рекомендуется `srandom()` вместо `srand()` для новых программ; качество всё равно недостаточно для криптографии.

>[!WARNING]
>Функции с глобальным состоянием не потокобезопасны; для многопоточных программ используйте `random_r()`/`srandom_r()` (GNU). Генератор не криптостойкий.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    srandom(42); // инициализация

    printf("%ld\n", random());

    // Воспроизводимое состояние в собственном буфере
    char state[128];
    initstate(7, state, sizeof state);
    printf("%ld\n", random());

    return 0;
}
```

## Ошибки и errno

Функции не устанавливают `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Лучше `rand()` (31 бит) | Глобальное состояние — не потокобезопасно |
| Управление состоянием через `initstate`/`setstate` | Не криптостойкий |
| Стандарт POSIX XSI | Сигнатуры вариантов различаются на BSD/Linux |
