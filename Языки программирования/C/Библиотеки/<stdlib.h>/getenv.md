## Прототип

```c
#include <stdlib.h>

char *getenv(const char *name);
```

## Параметры

| Параметр | Описание |
|---|---|
| `name` | Имя переменной окружения |

## Возвращаемое значение

Указатель на строку со значением переменной или `NULL`, если переменная не найдена.

## Что делает

Возвращает значение переменной окружения. Возвращённая строка принадлежит системе: её нельзя освобождать через `free()`, а после вызовов `setenv()`/`unsetenv()` (POSIX) или других изменений окружения указатель может стать недействительным. Значение можно сразу копировать в свой буфер.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char *user = getenv("USER");
    if (user != NULL) {
        printf("Пользователь: %s\n", user);
    } else {
        printf("Переменная USER не установлена\n");
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простой доступ к настройкам окружения | Указатель может стать недействительным при изменении окружения |
| Переносимая (C89+) | Пустая строка и отсутствие переменной различимы, но `""` неотличимо от установленной пустой переменной |

## Альтернативы

- **Аргументы командной строки** (`argv`) — чаще предпочтительнее для настроек
- POSIX-функции `setenv()`, `unsetenv()`, `getenv()` — расширения, верифицируются на своей платформе
