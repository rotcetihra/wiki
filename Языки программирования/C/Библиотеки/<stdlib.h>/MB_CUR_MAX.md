## Определение

```c
#include <stdlib.h>

#define MB_CUR_MAX (__ctype_get_mb_cur_max ()) // в glibc
```

## Описание

Макрос, возвращающий максимальное количество байт в многобайтовом символе для текущей локали (категория `LC_CTYPE`). В локали `"C"` значение равно 1; в локали UTF-8 — 4 (максимальная длина кодовой точки UTF-8). Используется при работе с многобайтовыми функциями `mblen()`, `mbtowc()`, `mbstowcs()`: задаёт размер буфера, достаточный для любого символа текущей локали.

## Примеры

```c
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    printf("%zu\n", MB_CUR_MAX); // 1 — локаль "C" по умолчанию

    setlocale(LC_ALL, "");       // включаем локаль (например, UTF-8)
    printf("%zu\n", MB_CUR_MAX); // 4 — в UTF-8

    return 0;
}
```
