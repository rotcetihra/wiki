## Прототип

```c
#include <stdlib.h>

void abort(void);
```

## Возвращаемое значение

Не возвращает управление (если не считать аварийного завершения).

## Что делает

Аварийно завершает программу: не вызывает функции, зарегистрированные через `atexit()`, и не сбрасывает буферы. В системах с сигналами генерирует сигнал `SIGABRT`; если сигнал не перехвачен или не игнорируется, программа завершается с аварийным статусом (обычно с дампом памяти — core). Даже если обработчик `SIGABRT` вернёт управление, программа всё равно завершается аварийно.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

double divide(double a, double b)
{
    if (b == 0.0) {
        fprintf(stderr, "Деление на ноль\n");
        abort(); // аварийное завершение вместо возврата ошибочного результата
    }
    return a / b;
}

int main(void)
{
    divide(1.0, 0.0);
    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Надёжно сигнализирует о фатальной ошибке | Ресурсы не освобождаются, буферы не сбрасываются |
| Работает даже при повреждённом состоянии программы | Дамп памяти и аварийный статус не подходят для «мягкого» завершения |

## Альтернативы

- **`exit(EXIT_FAILURE)`** — завершение с «уборкой» (atexit, сброс буферов)
- `_Exit(EXIT_FAILURE)` — немедленное завершение без «уборки»
- `assert()` — проверка инвариантов с диагностикой в отладочных сборках
