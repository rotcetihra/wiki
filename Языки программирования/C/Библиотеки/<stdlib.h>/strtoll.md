## Прототип

```c
#include <stdlib.h>

long long strtoll(const char *restrict str, char **restrict endptr, int base);
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | Строка для преобразования |
| `endptr` | Указатель на место для записи указателя на первый нераспознанный символ (или `NULL`) |
| `base` | Основание системы счисления (2..36) или 0 для автоопределения |

## Возвращаемое значение

Преобразованное значение или 0, если ничего не распознано.

## Что делает

Аналог `strtol()` для типа `long long`. Правила разбора те же: пробелы, знак, префиксы `0x`/`0` при `base == 0`. При переполнении возвращает `LLONG_MAX`/`LLONG_MIN` и устанавливает `errno = ERANGE`. Доступна с C99.

## Примеры

```c
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char *s = "-9223372036854775808";
    char *end;

    errno = 0;
    long long v = strtoll(s, &end, 10);
    if (errno == ERANGE) {
        printf("Переполнение\n");
    } else {
        printf("%lld; хвост: %s\n", v, end); // -9223372036854775808; хвост: ""
    }

    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Поведение не определено — функция не проверяет указатель.
- **Установление errno:** Устанавливает `errno = ERANGE` при переполнении.
- **Возвращаемое значение при ошибке:** Возвращает `0`, если ничего не распознано; при переполнении возвращает `LLONG_MAX` или `LLONG_MIN`.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<stdlib.h>/strtol|strtol]] — для `long`, [[Языки программирования/C/Библиотеки/<stdlib.h>/strtoull|strtoull]] — для `unsigned long long`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| 64-битный диапазон | Нужно проверять `endptr` и `errno` |
| Обработка переполнения через `ERANGE` | Пустая строка и 0 неотличимы без `endptr` |

## Альтернативы

- **`strtol()`** — для `long`
- `strtoull()` — для `unsigned long long`
