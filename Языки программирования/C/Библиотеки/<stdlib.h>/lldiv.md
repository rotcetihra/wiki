## Прототип

```c
#include <stdlib.h>

lldiv_t lldiv(long long numer, long long denom);
```

## Параметры

| Параметр | Описание |
|---|---|
| `numer` | Делимое |
| `denom` | Делитель |

## Возвращаемое значение

Структура `lldiv_t` с полями `quot` (частное) и `rem` (остаток).

## Что делает

Аналог [функции `div()`](div.md) для типа `long long`: выполняет целочисленное деление с определённым поведением для отрицательных операндов (частное усекается к нулю, остаток берёт знак делимого). Значение остатка удовлетворяет соотношению `quot * denom + rem == numer`. Поведение при `denom == 0` не определено. Доступна с C99.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    lldiv_t r = lldiv(-7LL, 3LL);

    printf("quot = %lld, rem = %lld\n", r.quot, r.rem); // quot = -2, rem = -1

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Определённое поведение для отрицательных чисел | Возвращает структуру, а не пару значений |
| Частное и остаток вычисляются за один вызов | Не определена для `denom == 0` |

## Альтернативы

- **Операторы `/` и `%`** — для неотрицательных операндов
- `div()`, `ldiv()` — для `int` и `long`
