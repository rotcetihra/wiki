## Прототип

```c
#include <stdlib.h> // GNU (в glibc — при _GNU_SOURCE)

void qsort_r(void *base, size_t nmemb, size_t size,
             int (*compar)(const void *, const void *, void *), void *arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `base` | Указатель на начало массива |
| `nmemb` | Количество элементов |
| `size` | Размер одного элемента в байтах |
| `compar` | Функция сравнения, получающая дополнительный аргумент `arg` |
| `arg` | Контекст, передаваемый в `compar` (например, локаль, параметры сравнения) |

## Возвращаемое значение

Не возвращает значения.

## Что делает

Вариант `qsort()` с передачей контекста в функцию сравнения — избавляет от глобальных переменных и делает сортировку пригодной для многопоточных программ. В glibc `compar(arg, a, b)` вызывается с контекстом **первым** аргументом.

>[!WARNING]
>Сигнатуры `qsort_r()` различаются между реализациями: в glibc контекст `arg` — последний параметр функции и передаётся `compar` первым; в BSD-традиции (FreeBSD, macOS) порядок другой (`compar(a, b, arg)` и `arg` передаётся как третий параметр `qsort_r()`). Скрипты переноса должны учитывать платформу.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

struct item { int id; double score; };

int cmp_score(const void *a, const void *b, void *arg)
{
    int reverse = *(int *)arg;
    double x = ((const struct item *)a)->score;
    double y = ((const struct item *)b)->score;
    return reverse ? ((x < y) - (x > y)) : ((x > y) - (x < y));
}

int main(void)
{
    struct item arr[] = {{1, 2.5}, {2, 0.5}, {3, 1.5}};
    int desc = 1;

    qsort_r(arr, 3, sizeof arr[0], cmp_score, &desc);

    printf("%.1f\n", arr[0].score); // 2.5 — по убыванию

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Контекст без глобальных переменных | Сигнатура различается на glibc и BSD — не переносима |
| Реентрабельна | Не входит в POSIX |
