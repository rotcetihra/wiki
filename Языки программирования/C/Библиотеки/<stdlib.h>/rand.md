## Прототип

```c
#include <stdlib.h>

int rand(void);
```

## Возвращаемое значение

Псевдослучайное целое число в диапазоне от 0 до `RAND_MAX` включительно.

## Что делает

Возвращает очередное псевдослучайное число линейного конгруэнтного генератора (LCG) с периодом до 2³¹. При каждой новой инициализации `srand()` последовательность воспроизводится — это удобно для воспроизводимых тестов, но не годится для криптографии. Рекомендуется использовать функцию в вычислениях через `rand() / (double)RAND_MAX`, чтобы получить число из диапазона [0; 1], а диапазоны задавать через масштабирование. В C11 добавлены потокобезопасные варианты с суффиксом `_r` (в glibc) и функции `rand_r()`.

>[!WARNING]
>`rand()` не предназначена для криптографии и моделирования с высокими требованиями к распределению. Ограничение диапазона через `%` даёт смещение распределения, если верхняя граница не делит `RAND_MAX` нацело.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void)
{
    srand(time(NULL)); // инициализация по текущему времени

    int r = rand();
    printf("%d\n", r);

    // Бросок кубика (1..6) без смещения через масштабирование
    int dice = 1 + rand() / (RAND_MAX / 6 + 1);
    printf("%d\n", dice);

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая, быстрая, повсеместная | Не криптостойкая |
| Воспроизводимая последовательность | Диапазон ограничен `RAND_MAX`, распределение невысокого качества |

## Альтернативы

- **`srand()`** — инициализация генератора (обязательна для разнообразия)
- Генераторы из `<random>` в C++ / `arc4random()` — если нужна криптостойкость
- `rand_r()` — потокобезопасный вариант (POSIX)
