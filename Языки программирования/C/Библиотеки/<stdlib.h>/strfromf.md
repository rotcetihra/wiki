## Прототип

```c
#include <stdlib.h> // C23

int strfromf(char *restrict s, size_t n, const char *restrict format, float value);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Буфер для результата |
| `n` | Размер буфера |
| `format` | Спецификатор формата: `"%f"`, `"%e"`, `"%g"`, `"%a"` (с необязательными модификаторами длины и точностью) |
| `value` | Преобразуемое число |

## Возвращаемое значение

Число символов, которые были бы записаны, если бы буфер был достаточно большим (без учёта завершающего `'\0'`).

## Что делает

Аналог `strfromd()` для типа `float`: преобразует число с плавающей точкой в строку без учёта локали (всегда точка `.` как разделитель). Не добавляет завершающий ноль при обрезке по `n`. Доступна с C23.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char buf[32];

    int len = strfromf(buf, sizeof buf, "%g", 3.14f);
    printf("%s (длина %d)\n", buf, len); // 3.14 (длина 4)

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Не зависит от локали | Только базовые форматы — нет ширины/выравнивания |
| Не переполняет буфер | Не добавляет `'\0'` при обрезке |

## Альтернативы

- **`snprintf(buf, n, format, value)`** — более гибкий, но зависит от локали
