## Прототип

```c
#include <stdlib.h>

int atexit(void (*func)(void));
```

## Параметры

| Параметр | Описание |
|---|---|
| `func` | Указатель на функцию без параметров, вызываемую при завершении программы |

## Возвращаемое значение

0 при успешной регистрации, ненулевое значение, если зарегистрировать больше нельзя (лимит задаётся константой `ATEXIT_MAX`, не менее 32).

## Что делает

Регистрирует функцию, которая будет вызвана при завершении программы через `exit()` или при возврате из `main()`. Функции вызываются в порядке, обратном порядку регистрации.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

void cleanup(void)
{
    printf("Очистка ресурсов\n");
}

int main(void)
{
    atexit(cleanup);
    printf("Программа работает\n");

    return 0;
}
```

Вывод:

```
Программа работает
Очистка ресурсов
```

## Ошибки и errno

Функция не устанавливает `errno`; о неудаче свидетельствует только ненулевое возвращаемое значение.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая регистрация «уборки» перед завершением | Порядок обратный регистрации — легко запутаться |
| Гарантируется вызов даже при `exit()` из любой функции | Не вызывается при `abort()` и `_Exit()` |
