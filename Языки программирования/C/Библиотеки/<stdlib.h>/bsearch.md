## Прототип

```c
#include <stdlib.h>

void *bsearch(const void *key, const void *base, size_t nmemb,
              size_t size, int (*compar)(const void *, const void *));
```

## Параметры

| Параметр | Описание |
|---|---|
| `key` | Указатель на элемент, который нужно найти |
| `base` | Указатель на начало отсортированного массива |
| `nmemb` | Количество элементов в массиве |
| `size` | Размер одного элемента в байтах |
| `compar` | Функция сравнения, возвращающая < 0, 0 или > 0 |

## Возвращаемое значение

Указатель на найденный элемент или `NULL`, если элемент не найден.

## Что делает

Двоичный (бинарный) поиск в отсортированном массиве. Функция `compar` получает указатели на два элемента массива и должна возвращать отрицательное число, ноль или положительное число в зависимости от соотношения первого аргумента и второго. Элементы массива должны быть отсортированы в том же порядке, который задаёт `compar` — иначе результат не определён. При равных элементах не гарантируется, какой из них будет найден.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int cmp_int(const void *a, const void *b)
{
    int x = *(const int *)a;
    int y = *(const int *)b;
    return (x > y) - (x < y);
}

int main(void)
{
    int arr[] = {1, 3, 5, 7, 9};
    int key = 5;

    int *found = bsearch(&key, arr, sizeof arr / sizeof arr[0],
                         sizeof(int), cmp_int);
    if (found != NULL) {
        printf("%d\n", *found); // 5
    } else {
        printf("Не найдено\n");
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Логарифмическая сложность O(log n) | Требует отсортированного массива |
| Работает с любыми типами данных | Функция сравнения вызывается многократно — накладные расходы |

## Альтернативы

- **Линейный поиск в цикле** — для маленьких массивов
- `lsearch()`/`lfind()` — линейный поиск (расширение POSIX)
- Словари и хеш-таблицы — когда нужен частый поиск по ключу
