## Прототип

```c
#include <stdlib.h> // GNU (glibc 2.17+)

char *secure_getenv(const char *name);
```

## Параметры

| Параметр | Описание |
|---|---|
| `name` | Имя переменной окружения |

## Возвращаемое значение

Значение переменной или `NULL` — в том числе если программа выполняется в «привилегированном» режиме (set-user-ID/set-group-ID).

## Что делает

Версия `getenv()` для setuid/setgid-программ: если эффективные ID процесса отличаются от реальных (программа запущена с привилегиями), в окружение «не доверяют» и функция всегда возвращает `NULL`. Это защищает от атак, когда вызывающий подсовывает setuid-программе переменные окружения (например, `LD_PRELOAD`). GNU-расширение; для переносимости в таких программах следует проверять режим самостоятельно (изолированно) или использовать `issetugid()` (BSD).

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    // В обычном режиме — как getenv(); в setuid — всегда NULL
    const char *lang = secure_getenv("LANG");
    printf("%s\n", lang ? lang : "(недоступно)");

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Защита привилегированных программ от поддельного окружения | Только glibc (Linux) |
| Та же семантика, что `getenv()` | Вне GNU нет стандартной замены |
