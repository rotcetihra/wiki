## Прототип

```c
#include <stdlib.h>

double atof(const char *str);
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | Строка, содержащая число с плавающей точкой |

## Возвращаемое значение

Результат преобразования или 0, если в начале строки не оказалось распознаваемого числа.

## Что делает

Преобразует строку в `double`: пропускает ведущие пробельные символы, разбирает знак, десятичные цифры с точкой и экспонентой `e`/`E`, а также `INF`/`NAN`. Преобразование останавливается на первом символе, который не может быть частью числа.

>[!WARNING]
>Невозможно отличить успешное преобразование строки `"0"` от неудачного — в обоих случаях возвращается 0. При переполнении поведение по стандарту не определено (в отличие от `strtod()`, которая сигнализирует через `errno`).

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    printf("%g\n", atof("  -42.5e2")); // -4250
    printf("%g\n", atof("3.14abc"));   // 3.14 — остановились на 'a'
    printf("%g\n", atof("abc"));       // 0 — не распознано

    return 0;
}
```

## Ошибки и errno

Не даёт надёжного способа обнаружить ошибку: переполнение и отсутствие распознаваемого числа неотличимы от успешного преобразования (по стандарту поведение при переполнении не определено).

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая, короткая | Нет проверки ошибок (0 и переполнение неотличимы) |
| | Нельзя узнать, где остановилось преобразование |
