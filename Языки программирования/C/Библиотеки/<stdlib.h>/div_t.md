## Определение

```c
#include <stdlib.h>

typedef struct {
    int quot; // частное
    int rem;  // остаток
} div_t;
```

## Описание

Тип структуры, возвращаемой функцией `div()`. Поля `quot` и `rem` — частное и остаток от целочисленного деления: `quot * denom + rem == numer`. Аналогичные типы для более широких целых — `ldiv_t` (для `long`) и `lldiv_t` (для `long long`).

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    div_t r = div(17, 5);

    printf("%d %d\n", r.quot, r.rem); // 3 2

    return 0;
}
```
