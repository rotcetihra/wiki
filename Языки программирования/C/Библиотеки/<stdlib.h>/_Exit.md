## Прототип

```c
#include <stdlib.h>

void _Exit(int status);
```

## Параметры

| Параметр | Описание |
|---|---|
| `status` | Статус завершения программы (константы `EXIT_SUCCESS`, `EXIT_FAILURE` или произвольное значение) |

## Возвращаемое значение

Не возвращает управление (программа завершается).

## Что делает

Завершает программу немедленно: без вызова функций, зарегистрированных через `atexit()`/`at_quick_exit()`, без сброса буферов и закрытия открытых потоков. Отличается от `exit()` тем, что не выполняет «уборку» — содержимое буферов может быть потеряно. Применяется, когда действия `exit()` нежелательны или опасны (например, при завершении после критического сбоя). В POSIX-системах операционной системе передаётся младший байт `status`.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    printf("До _Exit\n");
    fflush(stdout); // буферы нужно сбросить вручную

    _Exit(EXIT_FAILURE); // вывод после этой строки не выполнится
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Немедленное завершение без побочных действий | Буферы вывода не сбрасываются — вывод может потеряться |
| Подходит для аварийного завершения | Ресурсы не освобождаются |

## Альтернативы

- **`exit()`** — завершение с вызовом зарегистрированных функций и сбросом буферов
- `abort()` — аварийное завершение с сигналом `SIGABRT`
- `quick_exit()` — завершение с вызовом функций `at_quick_exit()` (C11)
