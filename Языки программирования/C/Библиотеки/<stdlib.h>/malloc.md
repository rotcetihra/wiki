## Прототип

```c
#include <stdlib.h>

void *malloc(size_t size);
```

## Параметры

| Параметр | Описание |
|---|---|
| `size` | Размер блока памяти в байтах |

## Возвращаемое значение

Указатель на начало блока из `size` байт или `NULL` при неудаче.

## Что делает

Выделяет `size` байт памяти и возвращает указатель, выровненный под `max_align_t` (в большинстве реализаций — под `long double` и 16 байт). Содержимое блока не инициализировано — значения в нём неопределённы. При `size == 0` поведение зависит от реализации: `NULL` или уникальный указатель, который нельзя разыменовывать (но можно передать в `free()`). Освобождается через `free()`. В главе 9 память рассматривается подробнее в статье [[Языки программирования/C/Глава 9. Стандартная библиотека C/3. Работа с памятью|«Работа с памятью»]].

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *arr = malloc(10 * sizeof(int));
    if (arr == NULL) {
        return 1; // память не выделена
    }

    arr[0] = 42;
    printf("%d\n", arr[0]);

    free(arr);
    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Не применимо (аргумент `size` — целое число, не указатель).
- **Установление errno:** При неудаче устанавливает `errno = ENOMEM`.
- **Возвращаемое значение при ошибке:** Возвращает `NULL` при неудаче.
- **Поведение при size == 0:** Поведение зависит от реализации: возвращает `NULL` или уникальный указатель, который нельзя разыменовывать (но можно передать в `free()`).

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Скорость — не обнуляет память | Память не инициализирована — нужно заполнять самому |
| Гибкий размер | Утечки при потере указателя |

## Альтернативы

- **`calloc()`** — выделение с обнулением
- `realloc()` — изменение размера существующего блока
- `aligned_alloc()` — выделение с заданным выравниванием (C11)
