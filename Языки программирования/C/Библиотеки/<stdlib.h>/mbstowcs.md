## Прототип

```c
#include <stdlib.h>

size_t mbstowcs(wchar_t *restrict dst, const char *restrict src, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dst` | Буфер для широких символов (в C23 — `wchar_t *`) |
| `src` | Многобайтовая строка, завершающаяся нулём |
| `n` | Максимальное количество широких символов для записи |

## Возвращаемое значение

- число преобразованных широких символов (без учёта завершающего `L'\0'`), при успехе;
- `(size_t)-1` — если встретился недопустимый многобайтовый символ.

## Что делает

Преобразует многобайтовую строку в широкую (в кодовые точки `wchar_t`), в текущей локали (категория `LC_CTYPE`). Записывает не более `n` широких символов и всегда завершает строку нулём (если `dst` не `NULL`). Если `dst == NULL`, функция лишь возвращает длину, которая понадобилась бы — удобно для оценки размера буфера. В главе 9 многобайтовые строки рассматриваются в статье [[Языки программирования/C/Глава 9. Стандартная библиотека C/8. Поддержка Unicode и кодировки UTF-8, UTF-16 и UTF-32|«Поддержка Unicode и кодировки UTF-8, UTF-16 и UTF-32»]].

>[!WARNING]
>Функция работает по состоянию сдвига из начального состояния. В локалях с переменной длиной символа (UTF-8) каждый байт должен образовывать полный символ, иначе возвращается `(size_t)-1`.

## Примеры

```c
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <wchar.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const char *multi = "Привет";
    wchar_t wide[32];

    size_t len = mbstowcs(wide, multi, 32);
    if (len == (size_t)-1) {
        printf("Недопустимый символ\n");
        return 1;
    }

    wprintf(L"%zu\n", len);   // 6
    wprintf(L"%ls\n", wide);  // Привет

    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Если `dst == NULL`, функция лишь возвращает длину, которая понадобилась бы (без преобразования).
- **Установление errno:** Функция не устанавливает `errno`.
- **Возвращаемое значение при ошибке:** Возвращает `(size_t)-1`, если встретился недопустимый многобайтовый символ.
- **Многопоточность:** Не потокобезопасна (использует внутреннее состояние сдвига). Потокобезопасный вариант — `mbsrtowcs()` из `<wchar.h>`.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<stdlib.h>/mbtowc|mbtowc]] — один символ, [[Языки программирования/C/Библиотеки/<stdlib.h>/wcstombs|wcstombs]] — обратное преобразование.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гибкое преобразование целых строк | Непотокобезопасна (нужен `mbsrtowcs()` из `<wchar.h>`) |
| `dst == NULL` позволяет узнать нужный размер буфера | Обрезание по `n` может оставить недопреобразованную строку |

## Альтернативы

- **`mbsrtowcs()`** из `<wchar.h>` — потокобезопасный вариант с явным состоянием
- `wcsrtombs()` — обратное преобразование
