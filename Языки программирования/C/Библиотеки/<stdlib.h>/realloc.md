## Прототип

```c
#include <stdlib.h>

void *realloc(void *ptr, size_t size);
```

## Параметры

| Параметр | Описание |
|---|---|
| `ptr` | Указатель на блок, возвращённый `malloc()`, `calloc()` или `realloc()`; может быть `NULL` |
| `size` | Новый размер блока в байтах |

## Возвращаемое значение

Указатель на блок нового размера или `NULL` при неудаче.

## Что делает

Изменяет размер блока памяти. Содержимое старой части блока (до `min(старый, новый)` размера) сохраняется. Если размер увеличивается, новые байты не инициализируются. При неудаче старый блок **не освобождается** — указатель остаётся действительным, а функция возвращает `NULL` (нужно сохранить исходный указатель до вызова). Если `ptr == NULL`, ведёт себя как `malloc(size)`; при `size == 0` поведение зависит от реализации (в glibc — `free(ptr)` + возврат `NULL`, но это нельзя считать переносимым).

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *arr = malloc(4 * sizeof(int));
    if (arr == NULL) {
        return 1;
    }

    int *bigger = realloc(arr, 8 * sizeof(int));
    if (bigger == NULL) {
        free(arr); // старый блок не освобождён — освобождаем вручную
        return 1;
    }
    arr = bigger;

    printf("%d\n", arr[3]); // старое содержимое сохранено (мусор, но блок жив)

    free(arr);
    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Если `ptr == NULL`, ведёт себя как `malloc(size)`.
- **Установление errno:** При неудаче устанавливает `errno = ENOMEM`.
- **Возвращаемое значение при ошибке:** Возвращает `NULL` при неудаче (старый блок при этом не освобождается).
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<stdlib.h>/malloc|malloc]] — первое выделение, [[Языки программирования/C/Библиотеки/<stdlib.h>/calloc|calloc]] — выделение с обнулением, [[Языки программирования/C/Библиотеки/<stdlib.h>/free|free]] — освобождение.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Часто дешевле, чем `malloc` + `memcpy` + `free` | При неудаче нужно сохранять старый указатель |
| Сохраняет содержимое | Новые байты не инициализированы |

## Альтернативы

- **`malloc()` + `memcpy()` + `free()`** — когда нужен полный контроль
- Динамические структуры (списки, деревья) — когда размер меняется часто
