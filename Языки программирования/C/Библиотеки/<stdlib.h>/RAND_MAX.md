## Определение

```c
#include <stdlib.h>

#define RAND_MAX 2147483647 // в glibc
```

## Описание

Константа — максимальное значение, возвращаемое функцией `rand()`. Стандарт гарантирует, что `RAND_MAX` не меньше 32767; фактическое значение зависит от реализации (в glibc — 2147483647, в стандартной реализации MSVC — 32767). Используется для нормализации результата `rand()` в диапазон `[0; 1]` и при генерации чисел из произвольного диапазона.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    srand(42);

    // Случайное число из диапазона [0; 1] с фиксированной точкой
    int unit = rand() / (RAND_MAX / 100 + 1);
    printf("%d\n", unit);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Переносимое определение максимума `rand()` | Значение различается между реализациями (32767 в MSVC, 2³¹−1 в glibc) |
