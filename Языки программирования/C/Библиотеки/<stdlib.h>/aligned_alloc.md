## Прототип

```c
#include <stdlib.h> // C11

void *aligned_alloc(size_t alignment, size_t size);
```

## Параметры

| Параметр | Описание |
|---|---|
| `alignment` | Выравнивание блока (обычно степень двойки) |
| `size` | Размер блока в байтах |

## Возвращаемое значение

Указатель на начало блока из `size` байт, выровненный по границе `alignment`, или `NULL` при неудаче.

## Что делает

Выделяет блок памяти с заданным выравниванием — для «сверхвыравнивания» (SIMD-типы, кэш-линии, границы страниц). Если `alignment` не поддерживается реализацией или `size` не кратен `alignment`, функция завершается неудачей и возвращает `NULL` (в первоначальной редакции C11 это было неопределённым поведением — исправлено отчётом DR460). Освобождается обычной `free()`.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *p = aligned_alloc(64, 64 * sizeof(int)); // блок выровнен по 64 байта
    if (p == NULL) {
        return 1;
    }

    printf("%zu\n", (size_t)p % 64); // 0 — выравнивание соблюдено

    free(p);
    return 0;
}
```

## Ошибки и errno

По стандарту не устанавливает `errno`; об ошибке свидетельствует только возврат `NULL` (установка `errno = ENOMEM` — расширение POSIX).

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартное выравнивание сверх `malloc()` | `size` должен быть кратен `alignment` |
| Переносимая альтернатива `posix_memalign()` | Доступна только с C11 |

## Альтернативы

- `posix_memalign()` — POSIX-вариант (в `<stdlib.h>`)
- `max_align_t` + `malloc()` — максимальное стандартное выравнивание без специальных функций
