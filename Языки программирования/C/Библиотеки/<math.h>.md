## Описание библиотеки

Заголовочный файл `<math.h>` — математические объявления.

### Типы

| Тип | Описание |
|---|---|
| `float_t` | Вещественный тип не менее широкий, чем `float` |
| `double_t` | Вещественный тип не менее широкий, чем `double` и не менее широкий, чем `float_t` |

Если `FLT_EVAL_METHOD` равен 0, `float_t` и `double_t` — это `float` и `double` соответственно; если 1 — оба `double`; если 2 — оба `long double`.

### Макросы классификации

| Макрос | Описание |
|---|---|
| `FP_INFINITE` | Бесконечность |
| `FP_NAN` | Не число (NaN) |
| `FP_NORMAL` | Нормализованное число |
| `FP_SUBNORMAL` | Денормализованное число |
| `FP_ZERO` | Ноль |

### Константы

| Константа | Описание |
|---|---|
| `M_E` | Значение e |
| `M_LOG2E` | Значение log₂e |
| `M_LOG10E` | Значение log₁₀e |
| `M_LN2` | Значение ln 2 |
| `M_LN10` | Значение ln 10 |
| `M_PI` | Значение π |
| `M_PI_2` | Значение π/2 |
| `M_PI_4` | Значение π/4 |
| `M_1_PI` | Значение 1/π |
| `M_2_PI` | Значение 2/π |
| `M_2_SQRTPI` | Значение 2/√π |
| `M_SQRT2` | Значение √2 |
| `M_SQRT1_2` | Значение 1/√2 |
| `MAXFLOAT` | То же, что `FLT_MAX` в `<float.h>` |
| `HUGE_VAL` | Положительная константа `double` (ошибка); на IEEE 754 — +∞ |
| `HUGE_VALF` | То же для `float` |
| `HUGE_VALL` | То же для `long double` |
| `INFINITY` | Положительная или unsigned бесконечность `float` |
| `NAN` | Quiet NaN типа `float` |

### Коды возврата ошибок

| Макрос | Описание |
|---|---|
| `MATH_ERRNO` | Ошибки отображаются через `errno` |
| `MATH_ERREXCEPT` | Ошибки генерируют исключения плавающей запятой |
| `math_errhandling` | Битовая комбинация `MATH_ERRNO` и/или `MATH_ERREXCEPT` |

## Исключения

- **NULL:** математические функции не принимают указатели, поэтому `NULL` не применим.
- **errno:** при `MATH_ERRNO` ошибки устанавливают `errno`: `EDOM` (аргумент вне области), `ERANGE` (результат вне диапазона).
- **Переполнение:** `HUGE_VAL`, `HUGE_VALF`, `HUGE_VALL` возвращаются при переполнении.
- **Нехватка памяти:** не применимо к математическим функциям.
- **Граничные случаи:** функции определены для всех представимых значений аргументов, за исключением случаев, указанных в стандарте.
- **Многопоточность:** функции не генерируют внешних видимых исключений и могут вызываться из любого потока.
- **Ошибки:** `pow(0, 0)`, `pow(neg, non-integer)`, `sqrt(neg)`, `log(neg)` и т. д. генерируют доменные ошибки.
