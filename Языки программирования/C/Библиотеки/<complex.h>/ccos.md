## Определение

```c
#include <complex.h>

double ccos(double complex z);
float ccosf(float complex z);
long double ccosl(long double complex z);
```

## Описание

Функция `ccos` вычисляет косинус комплексного числа. Косинус комплексного числа `z = x + yi` определяется как `cos(x) * cosh(y) - i * sin(x) * sinh(y)`.

Результат является комплексным числом. Для вещественного аргумента `ccos` эквивалентен `cos`, а для чисто мнимого — `cosh`.

Существуют три варианта функции: `ccosf` для `float complex`, `ccos` для `double complex` и `ccosl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>
#include <math.h>

int main(void)
{
    double complex z = M_PI + 0.0 * I;
    printf("cos(π + 0i) = %.4f + %.4fi\n", creal(ccos(z)), cimag(ccos(z)));

    z = 0.0 + M_PI * I;
    printf("cos(0 + πi) = %.4f + %.4fi\n", creal(ccos(z)), cimag(ccos(z)));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция для косинуса | Результат может быть неожиданным для больших мнимых частей |
| Три варианта для разных точностей | Для вещественных чисел лучше использовать `cos` |
