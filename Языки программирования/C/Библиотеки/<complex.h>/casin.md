## Определение

```c
#include <complex.h>

double casin(double complex z);
float casinf(float complex z);
long double casinl(long double complex z);
```

## Описание

Функция `casin` вычисляет арксинус комплексного числа. Арксинус является обратной функцией к синусу: если `w = casin(z)`, то `z = csin(w)`.

Результат представляет собой комплексное число, действительная часть которого лежит в диапазоне `[-π/2, π/2]`. Мнимая часть может быть положительной или отрицательной.

Существуют три варианта функции: `casinf` для `float complex`, `casin` для `double complex` и `casinl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z = 0.5 + 0.5 * I;
    double complex result = casin(z);
    printf("casin(%.1f + %.1fi) = %.4f + %.4fi\n",
           creal(z), cimag(z), creal(result), cimag(result));

    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** Функции в подмножестве комплексных математических функций не устанавливают `errno` (согласно C11 7.3.8).
- **Возвращаемое значение при ошибке:** Для конечных комплексных аргументов результат всегда конечен и определён на всей комплексной плоскости.
- **Многопоточность:** Функция является потокобезопасной.
