## Определение

```c
#include <complex.h>

double casinh(double complex z);
float casinhf(float complex z);
long double casinhl(long double complex z);
```

## Описание

Функция `casinh` вычисляет арксинус гиперболический комплексного числа. Арксинус гиперболический является обратной функцией к синусу гиперболическому: если `w = casinh(z)`, то `z = csinh(w)`.

Результат представляет собой комплексное число, действительная часть которого может быть положительной или отрицательной. Мнимая часть лежит в диапазоне `[-π/2, π/2]`.

Существуют три варианта функции: `casinhf` для `float complex`, `casinh` для `double complex` и `casinhl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z = 2.0 + 1.0 * I;
    double complex result = casinh(z);
    printf("casinh(%.1f + %.1fi) = %.4f + %.4fi\n",
           creal(z), cimag(z), creal(result), cimag(result));

    return 0;
}
```
