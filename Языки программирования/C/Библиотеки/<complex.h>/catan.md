## Определение

```c
#include <complex.h>

double catan(double complex z);
float catanf(float complex z);
long double catanl(long double complex z);
```

## Описание

Функция `catan` вычисляет арктангенс комплексного числа. Арктангенс является обратной функцией к тангенсу: если `w = catan(z)`, то `z = ctan(w)`.

Результат представляет собой комплексное число, действительная часть которого лежит в диапазоне `[-π/2, π/2]`. Мнимая часть может быть положительной или отрицательной.

Существуют три варианта функции: `catanf` для `float complex`, `catan` для `double complex` и `catanl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z = 1.0 + 1.0 * I;
    double complex result = catan(z);
    printf("catan(%.1f + %.1fi) = %.4f + %.4fi\n",
           creal(z), cimag(z), creal(result), cimag(result));

    return 0;
}
```
