## Определение

```c
#include <complex.h>

double ctan(double complex z);
float ctanf(float complex z);
long double ctanl(long double complex z);
```

## Описание

Функция `ctan` вычисляет тангенс комплексного числа. Тангенс комплексного числа `z = x + yi` определяется как `sin(z) / cos(z)` или `(sin(x) * cosh(y) + i * cos(x) * sinh(y)) / (cos(x) * cosh(y) - i * sin(x) * sinh(y))`.

Результат является комплексным числом. Для вещественного аргумента `ctan` эквивалентен `tan`.

Существуют три варианта функции: `ctanf` для `float complex`, `ctan` для `double complex` и `ctanl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>
#include <math.h>

int main(void)
{
    double complex z = M_PI / 4.0 + 0.0 * I;
    printf("tan(π/4 + 0i) = %.4f + %.4fi\n", creal(ctan(z)), cimag(ctan(z)));

    z = 0.0 + M_PI / 4.0 * I;
    printf("tan(0 + πi/4) = %.4f + %.4fi\n", creal(ctan(z)), cimag(ctan(z)));

    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** Функции в подмножестве комплексных математических функций не устанавливают `errno` (согласно C11 7.3.8).
- **Возвращаемое значение при ошибке:** В точках π/2 + kπ может иметь полюса (результат стремится к ±∞). Для остальных конечных аргументов результат конечен.
- **Многопоточность:** Функция является потокобезопасной.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<complex.h>/catan|catan]] — арктангенс комплексного числа, [[Языки программирования/C/Библиотеки/<complex.h>/ctanh|ctanh]] — тангенс гиперболический, [[Языки программирования/C/Библиотеки/<complex.h>/csin|csin]] — синус комплексного числа.
