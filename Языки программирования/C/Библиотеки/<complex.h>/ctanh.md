## Определение

```c
#include <complex.h>

double ctanh(double complex z);
float ctanhf(float complex z);
long double ctanhl(long double complex z);
```

## Описание

Функция `ctanh` вычисляет тангенс гиперболический комплексного числа. Тангенс гиперболический комплексного числа `z = x + yi` определяется как `sinh(z) / cosh(z)` или `(sinh(x) * cos(y) + i * cosh(x) * sin(y)) / (cosh(x) * cos(y) + i * sinh(x) * sin(y))`.

Результат является комплексным числом. Для вещественного аргумента `ctanh` эквивалентен `tanh`.

Существуют три варианта функции: `ctanhf` для `float complex`, `ctanh` для `double complex` и `ctanhl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>
#include <math.h>

int main(void)
{
    double complex z = 1.0 + 0.0 * I;
    printf("tanh(1 + 0i) = %.4f + %.4fi\n", creal(ctanh(z)), cimag(ctanh(z)));

    z = 0.0 + M_PI / 4.0 * I;
    printf("tanh(0 + πi/4) = %.4f + %.4fi\n", creal(ctanh(z)), cimag(ctanh(z)));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** Функции в подмножестве комплексных математических функций не устанавливают `errno` (согласно C11 7.3.8).
- **Возвращаемое значение при ошибке:** В точках πi/2 + kπi может иметь полюса (результат стремится к ±∞). Для остальных конечных аргументов результат конечен.
- **Многопоточность:** Функция является потокобезопасной.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<complex.h>/catanh|catanh]] — арктангенс гиперболический, [[Языки программирования/C/Библиотеки/<complex.h>/ctan|ctan]] — тангенс комплексного числа.
