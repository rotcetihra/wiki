## Определение

```c
#include <complex.h>

double cpow(double complex x, double complex y);
float cpowf(float complex x, float complex y);
long double cpowl(long double complex x, long double complex y);
```

## Описание

Функция `cpow` вычисляет возведение комплексного числа в комплексную степень. Определяется как `x^y = cexp(y * clog(x))`.

Второй аргумент является степенью. Результат является комплексным числом. Функция использует натуральный логарифм и экспоненту для вычисления результата.

Существуют три варианта функции: `cpowf` для `float complex`, `cpow` для `double complex` и `cpowl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex base = 2.0 + 0.0 * I;
    double complex exp = 3.0 + 0.0 * I;
    double complex result = cpow(base, exp);
    printf("(2 + 0i)^3 = %.1f + %.1fi\n", creal(result), cimag(result));

    base = 1.0 + 1.0 * I;
    exp = 2.0 + 0.0 * I;
    result = cpow(base, exp);
    printf("(1 + i)^2 = %.1f + %.1fi\n", creal(result), cimag(result));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция для возведения в степень | Может быть сложной для понимания |
| Три варианта для разных точностей | Для вещественных чисел лучше использовать `pow` |
| Работает с комплексными основанием и показателем | |
