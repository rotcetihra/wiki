## Определение

```c
#include <complex.h>

double cacosh(double complex z);
float cacoshf(float complex z);
long double cacoshl(long double complex z);
```

## Описание

Функция `cacosh` вычисляет арккосинус гиперболический комплексного числа. Арккосинус гиперболический является обратной функцией к косинусу гиперболическому: если `w = cacosh(z)`, то `z = ccosh(w)`.

Результат представляет собой комплексное число, действительная часть которого неотрицательна. Мнимая часть может быть положительной или отрицательной.

Существуют три варианта функции: `cacoshf` для `float complex`, `cacosh` для `double complex` и `cacoshl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z = 2.0 + 1.0 * I;
    double complex result = cacosh(z);
    printf("cacosh(%.1f + %.1fi) = %.4f + %.4fi\n",
           creal(z), cimag(z), creal(result), cimag(result));

    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** Функции в подмножестве комплексных математических функций не устанавливают `errno` (согласно C11 7.3.8).
- **Возвращаемое значение при ошибке:** Для конечных комплексных аргументов результат всегда конечен и определён на всей комплексной плоскости.
- **Многопоточность:** Функция является потокобезопасной.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<complex.h>/ccosh|ccosh]] — косинус гиперболический комплексного числа, [[Языки программирования/C/Библиотеки/<complex.h>/casinh|casinh]] — арксинус гиперболический.
