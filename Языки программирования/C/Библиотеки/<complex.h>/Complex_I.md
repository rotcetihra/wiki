## Определение

```c
#include <complex.h>

#define _Complex_I _Complex_I
```

## Описание

Макрос `_Complex_I` определяет мнимую единицу типа `float complex`. Используется для конструирования комплексных чисел: произведение вещественного числа на `_Complex_I` даёт мнимую часть комплексного числа.

Мнимая единица `_Complex_I` определяется как выражение, вычисляющееся в значение типа `float complex`, которое при умножении на вещественное число даёт комплексное число с нулевой действительной частью и заданным значением мнимой части.

## Примеры

```c
#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z1 = 3.0 + 4.0 * _Complex_I;
    printf("z1 = %.1f + %.1fi\n", creal(z1), cimag(z1));

    double complex z2 = 1.0 - 2.0 * _Complex_I;
    printf("z2 = %.1f + %.1fi\n", creal(z2), cimag(z2));

    double complex product = z1 * z2;
    printf("z1 * z2 = %.1f + %.1fi\n", creal(product), cimag(product));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный способ указать мнимую единицу | Требует явного умножения для записи мнимой части |
| Портативен между реализациями | Less удобен, чем макрос `I` |
| Гарантированно `float complex` | Введён только в C11 |
