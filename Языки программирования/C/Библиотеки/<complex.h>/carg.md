## Определение

```c
#include <complex.h>

double carg(double complex z);
float cargf(float complex z);
long double cargl(long double complex z);
```

## Описание

Функция `carg` вычисляет аргумент (угол) комплексного числа. Аргумент комплексного числа `z = x + yi` определяется как `atan2(y, x)` и представляет собой угол между положительной вещественной осью и вектором, представляющим комплексное число в комплексной плоскости.

Результат лежит в диапазоне `(-π, π]`. Аргумент числа `0 + 0i` определяется реализацией.

Существуют три варианта функции: `cargf` для `float complex`, `carg` для `double complex` и `cargl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>
#include <math.h>

int main(void)
{
    double complex z1 = 1.0 + 1.0 * I;
    printf("arg(%.1f + %.1fi) = %.4f rad (%.1f°)\n",
           creal(z1), cimag(z1), carg(z1), carg(z1) * 180.0 / M_PI);

    double complex z2 = -1.0 + 0.0 * I;
    printf("arg(%.1f + %.1fi) = %.4f rad (%.1f°)\n",
           creal(z2), cimag(z2), carg(z2), carg(z2) * 180.0 / M_PI);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** Функции в подмножестве комплексных математических функций не устанавливают `errno` (согласно C11 7.3.8).
- **Возвращаемое значение при ошибке:** Для z = 0 результат определяется реализацией. Для конечных аргументов результат лежит в диапазоне (-π, π].
- **Многопоточность:** Функция является потокобезопасной.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<complex.h>/cabs|cabs]] — модуль комплексного числа, [[Языки программирования/C/Библиотеки/<math.h>/atan2|atan2]] — арктангенс от двух аргументов.
