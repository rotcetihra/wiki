## Определение

```c
#include <complex.h>

double csinh(double complex z);
float csinhf(float complex z);
long double csinhl(long double complex z);
```

## Описание

Функция `csinh` вычисляет синус гиперболический комплексного числа. Синус гиперболический комплексного числа `z = x + yi` определяется как `sinh(x) * cos(y) + i * cosh(x) * sin(y)`.

Результат является комплексным числом. Для вещественного аргумента `csinh` эквивалентен `sinh`, а для чисто мнимого — `sin * i`.

Существуют три варианта функции: `csinhf` для `float complex`, `csinh` для `double complex` и `csinhl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>
#include <math.h>

int main(void)
{
    double complex z = 1.0 + 0.0 * I;
    printf("sinh(1 + 0i) = %.4f + %.4fi\n", creal(csinh(z)), cimag(csinh(z)));

    z = 0.0 + M_PI * I;
    printf("sinh(0 + πi) = %.4f + %.4fi\n", creal(csinh(z)), cimag(csinh(z)));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция для синуса гиперболического | Результат может быть неожиданным для больших вещественных частей |
| Три варианта для разных точностей | Для вещественных чисел лучше использовать `sinh` |
| Связь с гиперболическими функциями | |
