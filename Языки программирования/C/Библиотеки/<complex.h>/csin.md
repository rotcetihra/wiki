## Определение

```c
#include <complex.h>

double csin(double complex z);
float csinf(float complex z);
long double csinl(long double complex z);
```

## Описание

Функция `csin` вычисляет синус комплексного числа. Синус комплексного числа `z = x + yi` определяется как `sin(x) * cosh(y) + i * cos(x) * sinh(y)`.

Результат является комплексным числом. Для вещественного аргумента `csin` эквивалентен `sin`, а для чисто мнимого — `sinh * i`.

Существуют три варианта функции: `csinf` для `float complex`, `csin` для `double complex` и `csinl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>
#include <math.h>

int main(void)
{
    double complex z = M_PI / 2.0 + 0.0 * I;
    printf("sin(π/2 + 0i) = %.4f + %.4fi\n", creal(csin(z)), cimag(csin(z)));

    z = 0.0 + M_PI * I;
    printf("sin(0 + πi) = %.4f + %.4fi\n", creal(csin(z)), cimag(csin(z)));

    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** Функции в подмножестве комплексных математических функций не устанавливают `errno` (согласно C11 7.3.8).
- **Возвращаемое значение при ошибке:** Для конечных комплексных аргументов результат всегда конечен. Для больших мнимых частей результат может содержать очень большие значения.
- **Многопоточность:** Функция является потокобезопасной.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<complex.h>/casin|casin]] — арксинус комплексного числа, [[Языки программирования/C/Библиотеки/<complex.h>/csinh|csinh]] — синус гиперболический, [[Языки программирования/C/Библиотеки/<complex.h>/ccos|ccos]] — косинус комплексного числа.
