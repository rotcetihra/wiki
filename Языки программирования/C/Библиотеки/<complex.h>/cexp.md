## Определение

```c
#include <complex.h>

double cexp(double complex z);
float cexpf(float complex z);
long double cexpl(long double complex z);
```

## Описание

Функция `cexp` вычисляет экспоненту комплексного числа. Экспонента комплексного числа `z = x + yi` определяется как `e^x * (cos(y) + i * sin(y))`.

Результат является комплексным числом. Действительная часть — это `e^x * cos(y)`, мнимая — `e^x * sin(y)`. Функция тесно связана с формулой Эйлера: `e^(iy) = cos(y) + i * sin(y)`.

Существуют три варианта функции: `cexpf` для `float complex`, `cexp` для `double complex` и `cexpl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>
#include <math.h>

int main(void)
{
    double complex z = 0.0 + M_PI * I;
    printf("e^(πi) = %.4f + %.4fi\n", creal(cexp(z)), cimag(cexp(z)));

    z = 1.0 + 0.0 * I;
    printf("e^(1 + 0i) = %.4f + %.4fi\n", creal(cexp(z)), cimag(cexp(z)));

    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** Функции в подмножестве комплексных математических функций не устанавливают `errno` (согласно C11 7.3.8).
- **Возвращаемое значение при ошибке:** При переполнении (большая вещественная часть) результат может содержать ±∞ в компонентах.
- **Многопоточность:** Функция является потокобезопасной.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<complex.h>/clog|clog]] — натуральный логарифм комплексного числа, [[Языки программирования/C/Библиотеки/<math.h>/exp|exp]] — экспонента вещественного числа.
