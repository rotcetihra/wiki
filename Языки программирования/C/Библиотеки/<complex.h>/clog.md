## Определение

```c
#include <complex.h>

double clog(double complex z);
float clogf(float complex z);
long double clogl(long double complex z);
```

## Описание

Функция `clog` вычисляет натуральный логарифм комплексного числа. Натуральный логарифм комплексного числа `z = x + yi` определяется как `ln|z| + i * arg(z)`, где `|z|` — модуль, а `arg(z)` — аргумент (угол) комплексного числа.

Действительная часть результата — это `ln(sqrt(x² + y²))`, мнимая — `atan2(y, x)`. Результат является комплексным числом.

Существуют три варианта функции: `clogf` для `float complex`, `clog` для `double complex` и `clogl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>
#include <math.h>

int main(void)
{
    double complex z = 1.0 + 0.0 * I;
    printf("ln(1 + 0i) = %.4f + %.4fi\n", creal(clog(z)), cimag(clog(z)));

    z = M_E + 0.0 * I;
    printf("ln(e + 0i) = %.4f + %.4fi\n", creal(clog(z)), cimag(clog(z)));

    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** Функции в подмножестве комплексных математических функций не устанавливают `errno` (согласно C11 7.3.8).
- **Возвращаемое значение при ошибке:** Для z = 0 результат может содержать −∞ в действительной части (результат не определён стандартом).
- **Многопоточность:** Функция является потокобезопасной.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<complex.h>/cexp|cexp]] — экспонента комплексного числа, [[Языки программирования/C/Библиотеки/<complex.h>/cabs|cabs]] — модуль комплексного числа.
