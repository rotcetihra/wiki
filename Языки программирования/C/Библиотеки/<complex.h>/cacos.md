## Определение

```c
#include <complex.h>

double cacos(double complex z);
float cacosf(float complex z);
long double cabsl(long double complex z);
```

## Описание

Функция `cacos` вычисляет арккосинус комплексного числа. Арккосинус является обратной функцией к косинусу: если `w = cacos(z)`, то `z = ccos(w)`.

Результат представляет собой комплексное число, действительная часть которого лежит в диапазоне `[0, π]`. Мнимая часть может быть положительной или отрицательной в зависимости от знака мнимой части аргумента.

Существуют три варианта функции: `cacosf` для `float complex`, `cacos` для `double complex` и `cabsl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z = 0.5 + 0.5 * I;
    double complex result = cacos(z);
    printf("cacos(%.1f + %.1fi) = %.4f + %.4fi\n",
           creal(z), cimag(z), creal(result), cimag(result));

    return 0;
}
```
