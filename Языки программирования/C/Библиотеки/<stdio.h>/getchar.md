## Определение

```c
#include <stdio.h>

int getchar(void);
```

## Описание

Функция `getchar` считывает один символ из `stdin`. Эквивалентна `getc(stdin)`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    printf("Нажмите клавишу: ");
    int ch = getchar();
    printf("Вы нажали: %c\n", ch);
    return 0;
}
```

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `unsigned char` → `int` | Считанный символ |
| `EOF` | Ошибка или конец файла |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простое чтение одного символа | Медленно для строк |
| Стандартная функция ISO C | Только из `stdin` |
