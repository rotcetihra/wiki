## Определение

```c
#include <stdio.h>
#include <stdarg.h>

int vsscanf(const char *s, const char *format, va_list arg);
```

## Описание

Функция `vsscanf` — аналог `sscanf`, принимающий `va_list` вместо переменного числа аргументов.

## Пример

```c
#include <stdio.h>
#include <stdarg.h>

int parse_ints(const char *str, int *a, int *b)
{
    return vsscanf(str, "%d %d", a, b);
}

int main(void)
{
    int a, b;
    parse_ints("10 20", &a, &b);
    printf("%d %d\n", a, b);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Входная строка |
| `format` | Строка формата |
| `arg` | Список аргументов `va_list` |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Количество элементов | Успешно считанные элементы |
| `EOF` | Ошибка до первого преобразования |

## Плюсы и минусы

| Преимущество | Недостаток |
