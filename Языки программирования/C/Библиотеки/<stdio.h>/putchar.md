## Определение

```c
#include <stdio.h>

int putchar(int c);
```

## Описание

Функция `putchar` записывает символ `c` в `stdout`. Эквивалентна `putc(c, stdout)`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    putchar('H');
    putchar('i');
    putchar('\n');
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Записываемый символ |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Записанный символ | Успешная запись |
| `EOF` | Произошла ошибка |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простой вывод символа | Только в `stdout` |
| Стандартная функция ISO C | Медленно для строк |
