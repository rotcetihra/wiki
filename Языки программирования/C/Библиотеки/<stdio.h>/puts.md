## Определение

```c
#include <stdio.h>

int puts(const char *s);
```

## Описание

Функция `puts` записывает строку `s` в `stdout` и добавляет символ новой строки `\n` после неё. Эквивалентна `fputs(s, stdout)`, за которым следует `fputc('\n', stdout)`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    puts("Привет, мир!");
    puts("Вторая строка");
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Выводимая строка |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Неотрицательное | Успешная запись |
| `EOF` | Произошла ошибка |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Добавляет `\n` автоматически | Только в `stdout` |
| Простой интерфейс | Нет ограничения длины |
| Стандартная функция ISO C | Не форматирует данные |

## Обработка ошибок

- **Поведение при передаче NULL:** Поведение не определено, если `s` равен `NULL`.
- **Установление errno:** При ошибке может установить `EBADF` (поток не открыт для записи) или `EIO` (ошибка ввода-вывода).
- **Многопоточность:** Не потокобезопасна — запись в общий `stdout`.
