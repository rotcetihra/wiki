## Определение

```c
#include <stdio.h>

char *tmpnam(char *s);
```

## Описание

Функция `tmpnam` генерирует уникальное имя временного файла. Если `s` равен `NULL`, имя сохраняется во внутреннем статическом буфере (непотокобезопасно). Если `s` не `NULL`, имя копируется в буфер размером не менее `L_tmpnam`.

> [!WARNING]
> Функция `tmpnam` небезопасна для использования в многопоточных программах и подвержена атаке TOCTOU (time-of-check to time-of-use). Используйте `tmpfile` или POSIX `mkstemp`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    char name[L_tmpnam];
    const char *n = tmpnam(name);
    if (n != NULL) {
        printf("Имя: %s\n", n);
    }
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Буфер для имени или `NULL` |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Указатель на строку | Уникальное имя сгенерировано |
| `NULL` | Не удалось сгенерировать имя |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция ISO C | Небезопасна (TOCTOU) |
| Простой интерфейс | Непотокобезопасна с `NULL` |
| — | Предпочтительнее `tmpfile` |
