## Определение

```c
#include <stdio.h>
#include <stdarg.h>

int vscanf(const char *format, va_list arg);
```

## Описание

Функция `vscanf` — аналог `scanf`, принимающий `va_list` вместо переменного числа аргументов. Эквивалентна `vfscanf(stdin, format, arg)`.

## Пример

```c
#include <stdio.h>
#include <stdarg.h>

int read_ints(int *a, int *b)
{
    return vscanf("%d %d", a, b);
}

int main(void)
{
    int a, b;
    read_ints(&a, &b);
    printf("%d %d\n", a, b);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `format` | Строка формата |
| `arg` | Список аргументов `va_list` |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Количество элементов | Успешно считанные элементы |
| `EOF` | Ошибка или конец файла |

## Обработка ошибок

- **Поведение при передаче NULL:** Поведение не определено, если `format` равен `NULL`.
- **Установление errno:** При ошибке кодирования может установить `EILSEQ`.
- **Многопоточность:** Не потокобезопасна — читает из `stdin`.
