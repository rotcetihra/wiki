## Определение

```c
#include <stdio.h>
#include <stdarg.h>

int vsnprintf(char *s, size_t n, const char *format, va_list arg);
```

## Описание

Функция `vsnprintf` — аналог `snprintf`, принимающий `va_list`. Записывает форматированный текст в строку `s` с ограничением размера `n`. Возвращает количество символов, которое было бы записано без ограничения.

## Пример

```c
#include <stdio.h>
#include <stdarg.h>

void format_error(char *buf, size_t n, const char *fmt, ...)
{
    va_list args;
    va_start(args, fmt);
    vsnprintf(buf, n, fmt, args);
    va_end(args);
}

int main(void)
{
    char buf[64];
    format_error(buf, sizeof(buf), "Ошибка %d: %s", 404, "не найдено");
    printf("%s\n", buf);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Целевая строка |
| `n` | Максимальный размер буфера |
| `format` | Строка формата |
| `arg` | Список аргументов `va_list` |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Положительное | Количество символов без ограничения |
| Отрицательное | Произошла ошибка |

## Обработка ошибок

- **Поведение при передаче NULL:** Если `s` равен `NULL` и `n` равна 0, запись не происходит — поведение корректно. Поведение не определено, если `format` равен `NULL`.
- **Установление errno:** При ошибке кодирования может установить `EILSEQ`.
- **Многопоточность:** Потокобезопасна — записывает в пользовательский буфер, не используя общее состояние.
