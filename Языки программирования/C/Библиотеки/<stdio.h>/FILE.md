## Определение

```c
#include <stdio.h>

typedef /* unspecified object type */ FILE;
```

## Описание

Тип `FILE` представляет объект потока ввода-вывода, содержащий всю информацию, необходимую для управления потоком: указатель на буфер, текущую позицию, флаги ошибок и конца файла, а также платформо-зависимые данные.

Объекты типа `FILE` создаются функциями `fopen` и `tmpfile` и уничляются через `fclose`. Стандартные потоки `stdin`, `stdout` и `stderr` также являются объектами типа `FILE`.

> [!NOTE]
> Внутренняя структура `FILE` неизвестна программисту. Доступ к полям объекта осуществляется только через функции библиотеки `<stdio.h>`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("example.txt", "w");
    if (fp == NULL) {
        perror("Ошибка открытия файла");
        return 1;
    }

    fprintf(fp, "Привет, мир!\n");
    fclose(fp);

    fp = fopen("example.txt", "r");
    if (fp == NULL) {
        perror("Ошибка чтения файла");
        return 1;
    }

    char buffer[64];
    fgets(buffer, sizeof(buffer), fp);
    printf("Прочитано: %s", buffer);

    fclose(fp);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Единый интерфейс для файлов и потоков | Структура скрыта от программиста |
| Поддержка буферизации | Высокое потребление памяти для каждого потока |
| Стандартная часть ISO C | Не потокобезопасен без блокировок |
