## Определение

```c
#include <stdio.h>
#include <stdarg.h>

int vsprintf(char *s, const char *format, va_list arg);
```

## Описание

Функция `vsprintf` — аналог `sprintf`, принимающий `va_list`. Записывает форматированный текст в строку `s` без ограничения размера.

> [!WARNING]
> Аналогично `sprintf`, функция `vsprintf` небезопасна — нет ограничения длины результирующей строки. Используйте `vsnprintf` вместо неё.

## Пример

```c
#include <stdio.h>
#include <stdarg.h>

void format_str(char *buf, const char *fmt, ...)
{
    va_list args;
    va_start(args, fmt);
    vsprintf(buf, fmt, args);
    va_end(args);
}

int main(void)
{
    char buf[64];
    format_str(buf, "%s = %d", "Ответ", 42);
    printf("%s\n", buf);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Целевая строка |
| `format` | Строка формата |
| `arg` | Список аргументов `va_list` |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Положительное | Количество записанных символов |
| Отрицательное | Произошла ошибка |

## Обработка ошибок

- **Поведение при передаче NULL:** Поведение не определено, если `s` или `format` равны `NULL`.
- **Установление errno:** При ошибке кодирования может установить `EILSEQ`.
- **Многопоточность:** Потокобезопасна — записывает в пользовательский буфер.
