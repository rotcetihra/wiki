## Определение

```c
#include <stdio.h>

int printf(const char *format, ...);
```

## Описание

Функция `printf` выводит форматированный текст в `stdout`. Эквивалентна `fprintf(stdout, format, ...)`. Возвращает количество выведенных символов или отрицательное значение при ошибке.

## Пример

```c
#include <stdio.h>

int main(void)
{
    int n = 42;
    double pi = 3.14159;
    printf("Целое: %d, Вещественное: %.2f\n", n, pi);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `format` | Строка формата |
| `...` | Аргументы для подстановки |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Положительное | Количество выведенных символов |
| Отрицательное | Произошла ошибка |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Самая используемая функция вывода | Нет ограничения длины результата |
