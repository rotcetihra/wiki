## Определение

```c
#include <stdio.h>

#define _IOFBF /* целочисленная константа */
```

## Описание

Макрос `_IOFBF` задаёт стратегию полной буферизации (`full buffering`). При использовании в `setvbuf` данные копируются в буфер целиком и сбрасываются в файл только при заполнении буфера, вызове `fflush` или закрытии потока.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "w");
    if (fp == NULL) return 1;

    char buf[BUFSIZ];
    setvbuf(fp, buf, _IOFBF, BUFSIZ);

    fprintf(fp, "Данные в полном буфере\n");
    fclose(fp);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Максимальная производительность при записи больших объёмов | Данные могут быть потеряны при аварийном завершении |
| Стандартная часть ISO C | Не подходит для интерактивных потоков |

## Похожие макросы

- `_IOLBF` — построчная буферизация
- `_IONBF` — без буферизации
- `setvbuf` — установка стратегии буферизации
