## Описание

Тип `fpos_t` представляет позицию в потоке, включая смещение и мультибайтовое состояние (для многобайтовых потоков). Используется функциями `fgetpos` и `fsetpos` для сохранения и восстановления точной позиции в потоке.

> [!NOTE]
> Значение `fpos_t` не应当被 интерпретироваться напрямую — его можно только сохранять через `fgetpos` и восстанавливать через `fsetpos`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("example.txt", "w+");
    if (fp == NULL) {
        perror("Ошибка");
        return 1;
    }

    fprintf(fp, "АБВГД\n");

    fpos_t pos;
    fgetpos(fp, &pos);

    fprintf(fp, "ЕЖЗИЙ\n");
    fsetpos(fp, &pos);

    char buffer[64];
    fgets(buffer, sizeof(buffer), fp);
    printf("С позиции: %s", buffer);

    fclose(fp);
    return 0;
}
```

## Плюсы и минусы
