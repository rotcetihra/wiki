## Определение

```c
#include <stdio.h>

void setbuf(FILE *stream, char *buf);
```

## Описание

Функция `setbuf` задаёт буфер для потока `stream`. Если `buf` не `NULL`, используется буфер размером `BUFSIZ`. Если `buf` равен `NULL`, буферизация отключается (эквивалент `setvbuf(stream, NULL, _IONBF, 0)`).

## Пример

```c
#include <stdio.h>

int main(void)
{
    char buf[BUFSIZ];
    setbuf(stdout, buf);
    printf("Вывод с пользовательским буфером\n");
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Поток |
| `buf` | Буфер размером `BUFSIZ` или `NULL` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая настройка буфера | Размер буфера только `BUFSIZ` |
| Стандартная функция ISO C | Предпочтительнее `setvbuf` |
| — | Буфер должен оставаться в памяти до закрытия потока |

## Обработка ошибок

- **Поведение при передаче NULL:** Параметр `buf` может быть `NULL` — буферизация отключается. Поведение не определено, если `stream` равен `NULL`.
- **Многопоточность:** Не потокобезопасна — изменяет настройки потока.
