## Определение

```c
#include <stdio.h>

void rewind(FILE *stream);
```

## Описание

Функция `rewind` перематывает поток `stream` в начало и сбрасывает индикатор ошибки. Эквивалентна `fseek(stream, 0, SEEK_SET)` с последующим `clearerr(stream)`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "r");
    char buf[64];

    fgets(buf, sizeof(buf), fp);
    printf("Первое чтение: %s", buf);

    rewind(fp);
    fgets(buf, sizeof(buf), fp);
    printf("После rewind: %s", buf);

    fclose(fp);
    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Поведение не определено, если `stream` равен `NULL`.
- **Многопоточность:** Не потокобезопасна — перемотка потока, который используется из другого потока.
