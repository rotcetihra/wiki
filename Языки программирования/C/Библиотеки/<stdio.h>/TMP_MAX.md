## Определение

```c
#include <stdio.h>

#define TMP_MAX /* целочисленная константа */
```

## Описание

Макрос `TMP_MAX` определяет максимальное количество уникальных имён, которые может сгенерировать функция `tmpnam` перед началом повторения имён. По стандарту не менее 25.

## Пример

```c
#include <stdio.h>

int main(void)
{
    printf("Максимум уникальных имён tmpnam: %d\n", TMP_MAX);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует минимальное количество уникальных имён | Использование `tmpnam` небезопасно |
| Стандартная часть ISO C | Предпочтительнее `tmpfile` |

## Похожие макросы

- `L_tmpnam` — размер буфера для имени
- `FOPEN_MAX` — максимальное количество открытых файлов
