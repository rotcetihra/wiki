## Определение

```c
#include <stdio.h>

#define _IONBF /* целочисленная константа */
```

## Описание

Макрос `_IONBF` задаёт стратегию без буферизации (`unbuffered`). Каждый вызов функции вывода приводит к немедленной записи данных. По умолчанию используется для потока `stderr`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "w");
    if (fp == NULL) return 1;

    setvbuf(fp, NULL, _IONBF, 0);

    fprintf(fp, "Немедленная запись\n");
    fclose(fp);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Данные записываются немедленно | Низкая производительность из-за большого количества системных вызовов |
| Стандартная часть ISO C | Подходит только для.stderr и отладки |

## Похожие макросы

- `_IOFBF` — полная буферизация
- `_IOLBF` — построчная буферизация
- `setvbuf` — установка стратегии буферизации
