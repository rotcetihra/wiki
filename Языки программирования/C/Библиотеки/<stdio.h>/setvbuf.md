# setvbuf

## Определение

```c
#include <stdio.h>

int setvbuf(FILE *stream, char *buf, int mode, size_t size);
```

## Описание

Функция `setvbuf` устанавливает стратегию и размер буфера для потока `stream`. Должна вызываться после открытия потока и до любой другой операции ввода-вывода.

Параметр `mode` принимает значение `_IOFBF` (полная), `_IOLBF` (построчная) или `_IONBF` (без буферизации). Если `buf` равен `NULL`, буфер выделяется автоматически.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "w");
    char buf[4096];
    setvbuf(fp, buf, _IOFBF, sizeof(buf));

    fprintf(fp, "Данные в пользовательском буфере\n");
    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Поток |
| `buf` | Пользовательский буфер или `NULL` |
| `mode` | Стратегия: `_IOFBF`, `_IOLBF`, `_IONBF` |
| `size` | Размер буфера |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Буфер успешно настроен |
| Ненулевое | Ошибка установки параметров |

## Плюсы и минусы

| Преимущество | Недостаток |
