## Определение

```c
#include <stdio.h>

int fsetpos(FILE *stream, const fpos_t *pos);
```

## Описание

Функция `fsetpos` устанавливает позицию в потоке `stream` в значение, сохранённое ранее через `fgetpos`. Все буферы сбрасываются.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "w+");
    fprintf(fp, "АБВГД");

    fpos_t pos;
    fgetpos(fp, &pos);

    fprintf(fp, "ЕЖЗИЙ");

    fsetpos(fp, &pos);
    char buf[64];
    fgets(buf, sizeof(buf), fp);
    printf("С позиции: %s\n", buf);

    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Поток |
| `pos` | Указатель на позицию, полученную через `fgetpos` |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Позиция успешно установлена |
| Ненулевое | Произошла ошибка |

## Плюсы и минусы

| Преимущество | Недостаток |

| Стандартная функция ISO C | — |

## Обработка ошибок

- **Поведение при передаче NULL:** Поведение не определено, если `stream` или `pos` равны `NULL`.
- **Установление errno:** При ошибке может установить `EILSEQ` (для текстовых потоков с мультибайтовой кодировкой) или `EBADF` (если поток не открыт).
- **Многопоточность:** Не потокобезопасна — вызов для одного потока из разных потоков приводит к состоянию гонки.
