## Определение

```c
#include <stdio.h>

int putc(int c, FILE *stream);
```

## Описание

Макрос `putc` записывает символ `c` в поток `stream`. Аналогичен `fputc`, но может быть реализован как макрос.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "w");
    putc('A', fp);
    putc('B', fp);
    putc('\n', fp);
    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Записываемый символ |
| `stream` | Выходной поток |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Записанный символ | Успешная запись |
| `EOF` | Произошла ошибка |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Может быть быстрее `fputc` (макрос) | Побочные эффекты в аргументе |
| Стандартная функция ISO C | Не потокобезопасна как макрос |

## Обработка ошибок

- **Поведение при передаче NULL:** Поведение не определено, если `stream` равен `NULL`.
- **Установление errno:** При ошибке может установить `EBADF` (поток не открыт для записи) или `EIO` (ошибка ввода-вывода).
- **Многопоточность:** Не потокобезопасна как макрос — вычисляет `stream` несколько раз. Используйте `fputc` для потокобезопасной записи.
