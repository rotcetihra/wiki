# feof

## Определение

```c
#include <stdio.h>

int feof(FILE *stream);
```

## Описание

Функция `feof` проверяет, достигнут ли конец файла для потока `stream`. Возвращает ненулевое значение, если флаг конца файла установлен, и `0` в противном случае.

> [!NOTE]
> Флаг конца файла устанавливается только **после** неудачной попытки чтения за концом файла. Функция `feof` не предсказывает, что следующее чтение завершится неудачей.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "r");
    int ch;
    while ((ch = fgetc(fp)) != EOF) {
        putchar(ch);
    }

    if (feof(fp)) {
        printf("\nДостигнут конец файла\n");
    } else if (ferror(fp)) {
        printf("\nПроизошла ошибка\n");
    }

    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Поток |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Ненулевое | Флаг конца файла установлен |
| `0` | Конец файла не достигнут |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая проверка конца файла | Не предсказывает результат следующего чтения |
| Стандартная функция ISO C | Флаг устанавливается после ошибки |
