## Определение

```c
#include <stdio.h>

#define _IOLBF /* целочисленная константа */
```

## Описание

Макрос `_IOLBF` задаёт стратегию построчной буферизации (`line buffering`). Буфер сбрасывается при записи символа новой строки `\n`. По умолчанию используется для потоков `stdout` (если он связан с терминалом).

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "w");
    if (fp == NULL) return 1;

    setvbuf(fp, NULL, _IOLBF, 0);

    fprintf(fp, "Строка 1\n");
    fprintf(fp, "Строка 2\n");
    fclose(fp);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Данные появляются в файле после каждой строки | Меньшая производительность чем `_IOFBF` |
| Стандартная часть ISO C | Промежуточные записи без `\n` задерживаются |

## Похожие макросы

- `_IOFBF` — полная буферизация
- `_IONBF` — без буферизации
- `setvbuf` — установка стратегии буферизации
