## Определение

```c
#include <stdio.h>

#define L_tmpnam /* целочисленная константа */
```

## Описание

Макрос `L_tmpnam` определяет размер буфера (включая завершающий нуль-символ), достаточный для хранения имени временного файла, возвращаемого функцией `tmpnam`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    char tmpname[L_tmpnam];
    const char *name = tmpnam(tmpname);
    if (name != NULL) {
        printf("Имя временного файла: %s\n", name);
    }
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует безопасный размер буфера | Использование `tmpnam` небезопасно |
| Стандартная часть ISO C | Предпочтительнее `tmpfile` |

## Похожие макросы

- `FILENAME_MAX` — максимальная длина имени файла
- `TMP_MAX` — максимальное количество уникальных имён
