## Определение

```c
#include <stdio.h>

long ftell(FILE *stream);
```

## Описание

Функция `ftell` возвращает текущую позицию в потоке `stream` (смещение от начала файла в байтах). Для бинарных потоков это количество байтов от начала; для текстовых — Implementation-defined значение, пригодное только для `fseek`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "w+");
    fprintf(fp, "Привет, мир!");
    printf("Текущая позиция: %ld\n", ftell(fp));
    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Поток |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `long` | Текущая позиция в байтах |
| `-1L` | Произошла ошибка |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простое получение текущей позиции | `long` может быть недостаточен для больших файлов |
| Стандартная функция ISO C | Для текстовых потоков значение implementation-defined |

## Обработка ошибок

- **Поведение при передаче NULL:** Поведение не определено, если `stream` равен `NULL`.
- **Установление errno:** При ошибке может установить `EBADF` (поток не открыт) или `EOVERFLOW` (позиция не представима в `long`).
- **Многопоточность:** Не потокобезопасна — чтение позиции потока, который модифицируется из другого потока.
