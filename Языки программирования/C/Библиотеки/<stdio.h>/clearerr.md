## Определение

```c
#include <stdio.h>

void clearerr(FILE *stream);
```

## Описание

Функция `clearerr` сбрасывает индикаторы ошибки и конца файла для потока `stream`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "r");
    int ch;
    while ((ch = fgetc(fp)) != EOF)
        ;

    if (feof(fp)) {
        printf("Конец файла достигнут\n");
        clearerr(fp);
        printf("Флаги сброшены,feof: %d\n", feof(fp));
    }

    fclose(fp);
    return 0;
}
```

| Параметр | Описание |

## Возвращаемое значение

Функция ничего не возвращает.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет продолжить чтение после ошибки | Не устраняет причину ошибки |
| Стандартная функция ISO C | Для полного восстановления может потребоваться `fseek` |
