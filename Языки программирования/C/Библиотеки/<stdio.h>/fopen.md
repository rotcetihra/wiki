## Определение

```c
#include <stdio.h>

FILE *fopen(const char *filename, const char *mode);
```

## Описание

Функция `fopen` открывает файл с именем `filename` в режиме `mode`. Возвращает указатель на `FILE` или `NULL` при ошибке.

### Режимы открытия

| Режим | Описание |
|---|---|
| `"r"` | Чтение (файл должен существовать) |
| `"r+"` | Чтение и запись (файл должен существовать) |
| `"w"` | Запись (создаёт новый файл или очищает существующий) |
| `"w+"` | Чтение и запись (создаёт новый файл или очищает существующий) |
| `"a"` | Дописывание в конец (создаёт, если не существует) |
| `"a+"` | Чтение и дописывание (создаёт, если не существует) |
| `"b"` | Добавляется к любому режиму — бинарный режим |

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "w");
    if (fp == NULL) {
        perror("Ошибка открытия");
        return 1;
    }

    fprintf(fp, "Привет, мир!\n");
    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `filename` | Имя файла |
| `mode` | Режим открытия (`"r"`, `"w"`, `"a"`, `"r+"`, `"w+"`, `"a+"`, с `"b"`) |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Указатель на `FILE` | Файл успешно открыт |
| `NULL` | Произошла ошибка |
