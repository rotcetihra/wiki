## Определение

```c
#include <stdio.h>

#define SEEK_END /* целочисленная константа */
```

## Описание

Макрос `SEEK_END` используется вторым аргументом функции `fseek` для указания, что смещение отсчитывается от конца файла.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "r");
    if (fp == NULL) return 1;

    fseek(fp, 0, SEEK_END);
    printf("Размер файла: %ld байт\n", ftell(fp));

    fclose(fp);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Удобно для определения размера файла | Для текстовых потоков `ftell` может возвращать неизвестное значение |
| Стандартная часть ISO C | — |

## Похожие макросы

- `SEEK_SET` — от начала файла
- `SEEK_CUR` — от текущей позиции
- `fseek`, `ftell` — работа с позицией
