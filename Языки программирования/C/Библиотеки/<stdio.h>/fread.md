## Определение

```c
#include <stdio.h>

size_t fread(void *ptr, size_t size, size_t nmemb, FILE *stream);
```

## Описание

Функция `fread` считывает до `nmemb` элементов размером `size` байт из потока `stream` в массив `ptr`. Возвращает количество успешно прочитанных элементов (меньше `nmemb` при ошибке или достижении конца файла).

## Пример

```c
#include <stdio.h>

int main(void)
{
    int data[] = {10, 20, 30, 40, 50};
    FILE *fp = fopen("data.bin", "wb");
    fwrite(data, sizeof(int), 5, fp);
    fclose(fp);

    int read_data[5];
    fp = fopen("data.bin", "rb");
    size_t n = fread(read_data, sizeof(int), 5, fp);
    printf("Прочитано %zu элементов\n", n);
    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `ptr` | Указатель на массив для приёма данных |
| `size` | Размер одного элемента в байтах |
| `nmemb` | Количество элементов для чтения |
| `stream` | Входной поток |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Количество элементов | Успешно прочитанные элементы (≤ `nmemb`) |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Эффективное чтение блоков данных | Не отслеживает ошибки формата |
| Стандартная функция ISO C | Нужно вычислять количество элементов |
