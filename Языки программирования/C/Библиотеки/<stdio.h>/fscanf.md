## Определение

```c
#include <stdio.h>

int fscanf(FILE *stream, const char *format, ...);
```

## Описание

Функция `fscanf` считывает данные из потока `stream` в соответствии с форматом `format` и сохраняет их по указателям, переданным в аргументах. Возвращает количество успешно считанных элементов или `EOF` при ошибке/достижении конца файла.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("data.txt", "w+");
    fprintf(fp, "25 Иван");

    rewind(fp);
    int age;
    char name[32];
    fscanf(fp, "%d %s", &age, name);
    printf("Возраст: %d, Имя: %s\n", age, name);

    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Входной поток |
| `format` | Строка формата |
| `...` | Указатели на переменные для чтения |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Количество элементов | Успешно считанные и сопоставленные элементы |
| `EOF` | Ошибка или конец файла до первого преобразования |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гибкий формат ввода | Переполнение буферов при `%s` |
| Чтение из любого потока | Нет ограничения длины строк |
| Стандартная функция ISO C | Ошибки формата трудно обнаружить |

## Обработка ошибок

- **Поведение при передаче NULL:** Поведение не определено, если `stream` или `format` равны `NULL`.
- **Установление errno:** При ошибке кодирования может установить `EILSEQ`.
- **Многопоточность:** Не потокобезопасна — чтение из общего потока. В многопоточных программах используйте блокировку или отдельные потоки.
