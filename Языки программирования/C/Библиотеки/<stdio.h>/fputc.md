## Определение

```c
#include <stdio.h>

int fputc(int c, FILE *stream);
```

## Описание

Функция `fputc` записывает символ `c` (преобразованный в `unsigned char`) в поток `stream`. Возвращает записанный символ или `EOF` при ошибке.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "w");
    if (fp == NULL) return 1;

    fputc('H', fp);
    fputc('i', fp);
    fputc('\n', fp);

    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Записываемый символ |
| `stream` | Выходной поток |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Записанный символ | Успешная запись |
| `EOF` | Произошла ошибка |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая запись посимвольно | Медленно для больших объёмов |
| Стандартная функция ISO C | Каждый вызов может означать системный вызов |
