## Определение

```c
#include <stdio.h>

FILE *tmpfile(void);
```

## Описание

Функция `tmpfile` создаёт временный файл с уникальным именем и открывает его в режиме чтения и записи (`"w+b"`). Файл автоматически удаляется при вызове `fclose` или завершении программы.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = tmpfile();
    if (fp == NULL) {
        perror("Ошибка создания временного файла");
        return 1;
    }

    fprintf(fp, "Временные данные\n");
    rewind(fp);

    char buf[64];
    fgets(buf, sizeof(buf), fp);
    printf("Прочитано: %s", buf);

    fclose(fp);
    return 0;
}
```

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Указатель на `FILE` | Временный файл успешно создан |
| `NULL` | Произошла ошибка |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматическое удаление файла | Имя файла недоступно программисту |
