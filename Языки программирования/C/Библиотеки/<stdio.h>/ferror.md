## Определение

```c
#include <stdio.h>

int ferror(FILE *stream);
```

## Описание

Функция `ferror` проверяет, произошла ли ошибка для потока `stream`. Возвращает ненулевое значение, если флаг ошибки установлен, и `0` в противном случае. Флаг сбрасывается через `clearerr` или `rewind`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("nonexistent.txt", "r");
    if (fp == NULL) {
        perror("Ошибка открытия");
        return 1;
    }

    int ch = fgetc(fp);
    if (ferror(fp)) {
        printf("Ошибка чтения\n");
    }

    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Поток |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Ненулевое | Флаг ошибки установлен |
| `0` | Ошибок не было |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая проверка ошибок | Не определяет тип ошибки |
| Стандартная функция ISO C | Флаг не сбрасывается автоматически |

## Обработка ошибок

- **Поведение при передаче NULL:** Поведение не определено, если `stream` равен `NULL`.
- **Многопоточность:** Не потокобезопасна — чтение флага потока, который модифицируется из другого потока.
