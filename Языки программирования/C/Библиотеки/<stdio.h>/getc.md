## Определение

```c
#include <stdio.h>

int getc(FILE *stream);
```

## Описание

Макрос `getc` считывает один символ из потока `stream`. Аналогичен `fgetc`, но может быть реализован как макрос с вычислением `stream` несколько раз (побочные эффекты в аргументе).

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "r");
    if (fp == NULL) return 1;

    int ch;
    while ((ch = getc(fp)) != EOF) {
        putchar(ch);
    }

    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Входной поток |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `unsigned char` → `int` | Считанный символ |
| `EOF` | Ошибка или конец файла |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Может быть быстрее `fgetc` (макрос) | Побочные эффекты в аргументе |
| Стандартная функция ISO C | Не потокобезопасна как макрос |
