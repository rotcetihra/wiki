## Определение

```c
#include <stdio.h>

int rename(const char *old_name, const char *new_name);
```

## Описание

Функция `rename` переименовывает файл с именем `old_name` в `new_name`. Если файл с именем `new_name` уже существует, он заменяется (поведение не определено, если `new_name` открыт). Возвращает `0` при успехе.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("old.txt", "w");
    fprintf(fp, "Данные\n");
    fclose(fp);

    if (rename("old.txt", "new.txt") == 0) {
        printf("Файл переименован\n");
    } else {
        perror("Ошибка переименования");
    }
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `old_name` | Текущее имя файла |
| `new_name` | Новое имя файла |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Файл успешно переименован |
| Ненулевое | Произошла ошибка |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция ISO C | Поведение не определено для открытых файлов `new_name` |
| Может перемещать файлы между каталогами | Платформо-зависимые ограничения |
| — | Не работает для каталогов на некоторых платформах |

## Обработка ошибок

- **Поведение при передаче NULL:** Поведение не определено, если `old_name` или `new_name` равны `NULL`.
- **Установление errno:** При ошибке может установить `ENOENT` (файл не найден), `EACCES` (отсутствуют права), `EBUSY` (файл используется) или `ENOTEMPTY` (каталог не пуст — на некоторых платформах).
- **Многопоточность:** Потокобезопасна — переименование файлов является атомарной операцией на большинстве файловых систем.
