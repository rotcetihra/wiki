## Определение

```c
#include <stdio.h>

int fflush(FILE *stream);
```

## Описание

Функция `fflush` сбрасывает (записывает) буфер вывода потока `stream` в файл. Для потоков ввода поведение не определено. Если `stream` равен `NULL`, сбрасываются все открытые потоки вывода.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("log.txt", "w");
    fprintf(fp, "Запись в буфер\n");
    fflush(fp);
    printf("Данные сброшены в файл\n");
    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Указатель на поток или `NULL` для всех потоков |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Буфер успешно сброшен |
| `EOF` | Произошла ошибка |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует запись данных немедленно | Может снизить производительность |
| Для потоков `NULL` — сброс всех потоков | Поведение для потоков ввода не определено |
