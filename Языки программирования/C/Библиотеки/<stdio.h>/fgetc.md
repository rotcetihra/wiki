## Определение

```c
#include <stdio.h>

int fgetc(FILE *stream);
```

## Описание

Функция `fgetc` считывает один символ из потока `stream` и возвращает его как `unsigned char`, преобразованный в `int`, или `EOF` при ошибке/достижении конца файла.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "r");
    if (fp == NULL) return 1;

    int ch;
    while ((ch = fgetc(fp)) != EOF) {
        putchar(ch);
    }

    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Входной поток |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `unsigned char` → `int` | Считанный символ |
| `EOF` | Ошибка или конец файла |

## Обработка ошибок

- **Поведение при передаче NULL:** Поведение не определено, если `stream` равен `NULL`.
- **Установление errno:** При ошибке может установить `EBADF` (поток не открыт для чтения) или `EIO` (ошибка ввода-вывода).
- **Многопоточность:** Не потокобезопасна — чтение из общего потока. Является функцией (в отличие от `getc`), поэтому безопасна при вызове с побочными эффектами.
