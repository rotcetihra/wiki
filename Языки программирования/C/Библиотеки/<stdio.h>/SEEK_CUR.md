## Определение

```c
#include <stdio.h>

#define SEEK_CUR /* целочисленная константа */
```

## Описание

Макрос `SEEK_CUR` используется вторым аргументом функции `fseek` для указания, что смещение отсчитывается от текущей позиции в потоке.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "r");
    if (fp == NULL) return 1;

    fseek(fp, 10, SEEK_CUR);
    printf("Текущая позиция: %ld\n", ftell(fp));

    fclose(fp);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Удобно для смещения относительно текущей позиции | Не работает с бинарными потоками во всех реализациях |
| Стандартная часть ISO C | — |

## Похожие макросы

- `SEEK_SET` — от начала файла
- `SEEK_END` — от конца файла
- `fseek`, `ftell` — работа с позицией
