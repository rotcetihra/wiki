## Определение

```c
#include <stdio.h>

FILE *freopen(const char *filename, const char *mode, FILE *stream);
```

## Описание

Функция `freopen` открывает файл с именем `filename` в режиме `mode` и привязывает его к существующему потоку `stream`. Предыдущее содержимое потока сбрасывается. Используется для перенаправления `stdin`, `stdout` или `stderr`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    if (freopen("output.txt", "w", stdout) == NULL) {
        perror("Ошибка перенаправления");
        return 1;
    }

    printf("Этот вывод идёт в файл\n");
    fclose(stdout);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `filename` | Имя файла |
| `mode` | Режим открытия (аналогично `fopen`) |
| `stream` | Существующий поток для привязки |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Указатель на `stream` | Файл успешно открыт и привязан |
| `NULL` | Произошла ошибка |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Перенаправление стандартных потоков | Закрывает предыдущий файл, привязанный к `stream` |
