## Определение

```c
#include <stdio.h>

extern FILE *stderr;
```

## Описание

`stderr` — стандартный поток ошибок. По умолчанию не буферизуется (`_IONBF`), что гарантирует немедленный вывод сообщений об ошибках. Связан с тем же устройством ввода-вывода, что и `stdout`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    fprintf(stderr, "Ошибка: файл не найден\n");
    fprintf(stderr, "Код ошибки: %d\n", 42);
    return 1;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Немедленный вывод ошибок | Не буферизуется — низкая производительность |
| Не смешивается с обычным выводом | Может быть перенаправлен отдельно от `stdout` |
| Стандартная часть ISO C | — |
