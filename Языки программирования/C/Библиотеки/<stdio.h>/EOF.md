## Определение

```c
#include <stdio.h>

#define EOF /* целочисленная константа отрицательного значения */
```

## Описание

Макрос `EOF` определяет константу, возвращаемую функциями чтения при достижении конца файла или ошибке. Обычно это `-1`. Функции `fgetc`, `getc`, `getchar` и `ungetc` возвращают `EOF` при ошибке или конце потока.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "r");
    if (fp == NULL) {
        perror("Ошибка");
        return 1;
    }

    int ch;
    while ((ch = fgetc(fp)) != EOF) {
        putchar(ch);
    }

    fclose(fp);
    return 0;
}
```
