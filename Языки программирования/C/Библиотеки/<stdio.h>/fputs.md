## Определение

```c
#include <stdio.h>

int fputs(const char *s, FILE *stream);
```

## Описание

Функция `fputs` записывает строку `s` в поток `stream`. Завершающий `\0` не записывается. Возвращает неотрицательное значение при успехе или `EOF` при ошибке.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "w");
    fputs("Привет, мир!\n", fp);
    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Записываемая строка |
| `stream` | Выходной поток |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Неотрицательное | Успешная запись |
| `EOF` | Произошла ошибка |
