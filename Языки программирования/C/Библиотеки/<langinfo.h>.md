## Описание библиотеки

Заголовочный файл `<langinfo.h>` — константы информации о языке. Определяет константы для функции `nl_langinfo()`, используемые для получения информации о форматах даты, времени, чисел и валюты в зависимости от текущей локали.

### Константы (выборочные)

| Константа | Категория | Описание |
|---|---|---|
| `CODESET` | `LC_CTYPE` | Имя кодовой страницы (например, "UTF-8") |
| `D_T_FMT` | `LC_TIME` | Строка формата даты и времени |
| `D_FMT` | `LC_TIME` | Строка формата даты |
| `T_FMT` | `LC_TIME` | Строка формата времени |
| `DAY_1`–`DAY_7` | `LC_TIME` | Полные названия дней недели |
| `MON_1`–`MON_12` | `LC_TIME` | Полные названия месяцев |
| `RADIXCHAR` | `LC_NUMERIC` | Символ десятичного разделителя |
| `YESEXPR` | `LC_MESSAGES` | Регулярное выражение для "да" |
| `NOEXPR` | `LC_MESSAGES` | Регулярное выражение для "нет" |
| `CRNCYSTR` | `LC_MONETARY` | Символ валюты |

### Функции

| Функция | Описание |
|---|---|
| `nl_langinfo(nl_item)` | Получение строки информации о языке для текущей локали |
| `nl_langinfo_l(nl_item, locale_t)` | То же для указанной локали |

### Возвращаемое значение

Возвращает указатель на статическую строку (не копию). Не изменяйте эту строку.

## Исключения

- **NULL:** функции не принимают `NULL`.
- **Память:** возвращаемые строки являются статическими; не освобождайте их.
- **Категория:** некоторые константы определены только для определённых категорий локали.
- **Используйте `strftime()`:** для форматирования даты и времени лучше использовать `strftime()`.
- **Используйте `localeconv()`:** для RADIXCHAR, THOUSEP и CRNCYSTR лучше использовать `localeconv()`.
- **Многопоточность:** функции потокобезопасны.

## Стандарты
