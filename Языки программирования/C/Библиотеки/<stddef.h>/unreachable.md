## Определение

```c
#include <stddef.h> // C23

#define unreachable() (__builtin_unreachable()) // в GCC
```

## Описание

Макрос (C23), сообщающий компилятору, что управление не может достигнуть данной точки. Если выполнение всё же доходит до вызова — неопределённое поведение (как и для любой «недостижимой» точки). Используется при исчерпывающих переключателях и инвариантах, которые компилятор не может доказать: позволяет убрать лишний код и проверки, улучшить оптимизацию. В отличие от `assert()`, не отключается в релизных сборках (нет аналога `NDEBUG`) и ничего не выводит.

## Примеры

```c
#include <stddef.h>

enum Color { RED, GREEN, BLUE };

const char *name(enum Color c)
{
    switch (c) {
    case RED:   return "red";
    case GREEN: return "green";
    case BLUE:  return "blue";
    default:    unreachable(); // все значения перечислены выше
    }
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет компилятору удалять недостижимый код и проверки | Попадание в вызов — неопределённое поведение |
| Активна всегда (не отключается, как `assert`) | Никакой диагностики в отладочных сборках |

## Альтернативы

- `assert(0)` — с сообщением в отладочной сборке, но отключается `NDEBUG`
- `__builtin_unreachable()` — прямое расширение GCC

## Похожие определения

- Определений в `<stddef.h>` рядом нет
