## Определение

```c
#include <stddef.h>

#define NULL ((void *)0) // в C
#define NULL 0           // в C++
```

## Описание

Макрос — константа нулевого указателя (null pointer constant): значение, которое не указывает ни на один объект или функцию. В C стандарт позволяет определение как `((void *)0)` или `0`; в glibc в языке C используется `((void *)0)`, в C++ — `0` (или `__null` в GNU). Перед определением в `<stddef.h>` макрос сбрасывается (`#undef NULL`), так как его могли определить другие заголовки (например, `<stdio.h>`). Сравнение указателя с `NULL` — стандартный способ проверить, указывает ли он на объект.

## Примеры

```c
#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int *p = malloc(sizeof(int) * 10);

    if (p == NULL) {
        printf("Память не выделена\n");
        return 1;
    }

    free(p);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Явная проверка на «нет объекта» | Не имеет собственного типа |
| Доступен из многих заголовков | Может конфликтовать с другими определениями макроса |

## Альтернативы

- **`nullptr`** (C23) — типизированная константа нулевого указателя типа `nullptr_t`
- `0` — неявное преобразование нуля в нулевой указатель
