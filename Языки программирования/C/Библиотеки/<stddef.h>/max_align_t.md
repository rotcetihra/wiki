## Определение

```c
#include <stddef.h> // C11

typedef struct {
    long long __max_align_ll;
    long double __max_align_ld;
} max_align_t;
```

## Описание

Тип (C11), чьё выравнивание не меньше выравнивания любого стандартного типа и поддерживается в любом контексте. Применяется как тип буферов «с запасом» по выравниванию: массив `max_align_t` гарантированно выровнен для любого стандартного типа. С `alignof(max_align_t)` связаны требования к выравниванию памяти, возвращаемой `aligned_alloc()`. В GCC реализован как структура с полями `long long` и `long double` (на некоторых 32-битных платформах — с дополнительным полем для максимального выравнивания).

## Примеры

```c
#include <stddef.h>
#include <stdio.h>

int main(void)
{
    // Обычно 8 или 16 — максимальное выравнивание платформы
    printf("%zu\n", alignof(max_align_t));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантированное максимальное выравнивание | Не входит в C89/C99 (только C11) |
| Единый тип для буферов и выделения памяти | Реализация зависит от платформы |

## Альтернативы

- `alignas(тип)` / `_Alignas` — задать выравнивание конкретной переменной (C11)
- `aligned_alloc()` — выделение памяти с заданным выравниванием (C11)
