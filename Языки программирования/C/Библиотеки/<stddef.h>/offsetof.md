## Определение

```c
#include <stddef.h>

size_t offsetof(тип, поле);
```

## Описание

Макрос, вычисляющий во время компиляции смещение поля `поле` структуры или объединения `тип` от начала объекта (тип результата — `size_t`). В GCC реализован через встроенную функцию `__builtin_offsetof()`. Применяется в низкоуровневом коде: сериализация структур, реализация контейнерных макросов (например, получение указателя на «родительскую» структуру из указателя на поле) и проверка компоновки структур. Нельзя применять к битовым полям; `тип` должен быть именем структурного типа (не `typedef`-указателем).

## Примеры

```c
#include <stddef.h>
#include <stdio.h>

struct Point {
    int x;
    int y;
};

int main(void)
{
    printf("%zu\n", offsetof(struct Point, x)); // 0
    printf("%zu\n", offsetof(struct Point, y)); // 4 (зависит от платформы)

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Переносимое определение смещения | Нельзя использовать с битовыми полями |
| Вычисляется во время компиляции | Результат зависит от выравнивания платформы |

## Альтернативы

- Классический трюк `&((тип *)0)->поле` — вычисление смещения вручную (нетипизированный результат, требует приведения)
- `__builtin_offsetof(тип, поле)` — расширение GCC
