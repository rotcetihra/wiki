## Определение

```c
#include <stddef.h>

typedef long int ptrdiff_t; // в glibc на 64-битных системах
```

## Описание

Знаковый целочисленный тип результата вычитания двух указателей: выражение `p2 - p1` имеет тип `ptrdiff_t`. Подходит для хранения расстояния между указателями и для смещений, которые могут быть отрицательными. В отличие от `size_t`, знаковый: применяется в арифметике указателей и циклах, где индекс может уменьшаться. В glibc — `long int`; на 32-битных системах — `int`. Для печати используется спецификатор `%td`.

## Примеры

```c
#include <stddef.h>
#include <stdio.h>

int main(void)
{
    int a[10] = {0};
    int *p = &a[5];
    int *q = &a[2];

    ptrdiff_t d = p - q;
    printf("%td\n", d); // 3
    printf("%td\n", q - p); // -3

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Знаковый: хранит отрицательные смещения | Размер зависит от платформы |
| Гарантированно вмещает разность любых указателей внутри одного массива | Для индексов обычно удобнее `size_t` |

## Альтернативы

- **`size_t`** — беззнаковый тип для размеров и индексов; `(size_t)(p2 - p1)` не переносим для отрицательных значений
