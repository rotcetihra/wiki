## Описание библиотеки

Заголовочный файл `<assert.h>` — макросы для отладки и проверки инвариантов программы.

### Макросы

| Макрос | Описание | Стандарт |
|---|---|---|
| `assert(выражение)` | Проверка во время выполнения; при ложном выражении завершает программу с сообщением | C89 |
| `assert(выражение, сообщение)` | То же, с пользовательским сообщением | C23 |
| `static_assert(выражение, сообщение)` | Проверка на этапе компиляции | C11 |
| `static_assert(выражение)` | То же, без сообщения | C23 |
| `NDEBUG` | Ключевое определение: отключает `assert()` | C89 |

> [!NOTE]
> Макрос `assert()` реализован как макрос; если проверяемое выражение имеет побочные эффекты, поведение программы будет различаться в зависимости от того, определён ли `NDEBUG`. Это может создавать Heisenbugs.
