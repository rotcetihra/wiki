## Описание библиотеки

Заголовочный файл `<dlfcn.h>` — динамическое связывание. Определяет функции для загрузки разделяемых библиотек во время выполнения и поиска символов в них.

### Константы для `dlopen()`

| Константа | Описание |
|---|---|
| `RTLD_LAZY` | Разрешение символов откладывается до первого использования |
| `RTLD_NOW` | Все символы разрешаются немедленно при загрузке |
| `RTLD_GLOBAL` | Символы доступны для разрешения ссылок в других модулях |
| `RTLD_LOCAL` | Символы доступны только в текущем модуле |

### Функции

| Функция | Описание |
|---|---|
| `dlopen(const char *, int)` | Открытие разделяемой библиотеки |
| `dlclose(void *)` | Закрытие разделяемой библиотеки |
| `dlsym(void *, const char *)` | Получение указателя на символ |
| `dlerror(void)` | Строковое описание последней ошибки |

### Возвращаемое значение

- `dlopen()` возвращает дескриптор библиотеки или `NULL` при ошибке.
- `dlclose()` возвращает `0` при успехе или ненулевое значение при ошибке.
- `dlsym()` возвращает адрес символа или `NULL`, если символ не найден.
- `dlerror()` возвращает `NULL`, если ошибок нет, или строку с описанием.

### Использование

```c
#include <dlfcn.h>

void *handle = dlopen("libm.so", RTLD_LAZY);
if (!handle) {
    fprintf(stderr, "%s\n", dlerror());
    return 1;
}

double (*sqrt_func)(double) = dlsym(handle, "sqrt");
char *error = dlerror();
if (error) {
    fprintf(stderr, "%s\n", error);
    dlclose(handle);
    return 1;
}

double result = sqrt_func(2.0);
dlclose(handle);
```

## Исключения

- **NULL:** `dlopen()` и `dlsym()` возвращают `NULL` при ошибке.
- **dlerror:** вызовите `dlerror()` после каждой функции для проверки ошибок.
- **RTLD_LAZY и RTLD_NOW:** нельзя использовать одновременно.
- **RTLD_GLOBAL:** конфликтует с `RTLD_LOCAL`; используйте один из них.
- **dlclose:** может не выгрузить библиотеку, если есть ссылки на неё.
- **Память:** `dlopen()` может выделять память; `dlclose()` освобождает.
- **Многопоточность:** функции потокобезопасны.
- **Циклические зависимости:** `RTLD_NOW` обнаруживает циклы; `RTLD_LAZY` — нет.
