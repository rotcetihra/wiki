## Описание библиотеки

Заголовочный файл `<wordexp.h>` — типы расширения слов. Определяет структуру `wordexp_t`, константы и функции для расширения строк по правилам shell (подстановка переменных, команд, подстановка имён файлов).

### Структура `wordexp_t`

```c
typedef struct {
    size_t   we_wordc;   /* Количество расширенных слов */
    char   **we_wordv;   /* Массив строк с словами */
    size_t   we_offs;    /* Резерв в начале we_wordv */
} wordexp_t;
```

### Константы флагов

| Константа | Описание |
|---|---|
| `WRDE_APPEND` | Добавить результат к предыдущему вызову |
| `WRDE_DOOFFS` | Резервировать `we_offs` null-указателей в начале |
| `WRDE_NOCMD` | Запретить подстановку команд |
| `WRDE_REUSE` | Повторное использование структуры (эквивалент `wordfree()` + `wordexp()`) |
| `WRDE_SHOWERR` | Не перенаправлять stderr в `/dev/null` |
| `WRDE_UNDEF` | Ошибка при обращении к неопределённой переменной |

### Константы ошибок

| Константа | Описание |
|---|---|
| `WRDE_BADCHAR` | Недопустимый символ (новая строка, `|`, `&`, `;`, `<`, `>`, `(`, `)`, `{`, `}`) |
| `WRDE_BADVAL` | Обращение к неопределённой переменной (с `WRDE_UNDEF`) |
| `WRDE_CMDSUB` | Подстановка команд (с `WRDE_NOCMD`) |
| `WRDE_NOSPACE` | Нехватка памяти |
| `WRDE_SYNTAX` | Синтаксическая ошибка (незакрытые скобки, кавычки) |

### Функции

| Функция | Описание |
|---|---|
| `wordexp(const char *restrict, wordexp_t *restrict, int)` | Расширение строки по правилам shell |
| `wordfree(wordexp_t *)` | Освобождение памяти |

### Возвращаемое значение

- `wordexp()`: `0` при успехе, константа ошибки при ошибке.
- `wordfree()`: ничего не возвращает.

### Использование

```c
#include <wordexp.h>

wordexp_t p;
wordexp("$HOME/*.txt", &p, 0);

for (size_t i = 0; i < p.we_wordc; i++) {
    printf("%s\n", p.we_wordv[i]);
}

wordfree(&p);
```

## Исключения

- **NULL:** `wordexp()` не принимает `NULL`.
- **WRDE_REUSE:** перед повторным использованием вызовите `wordfree()`.
- **Безопасность:** `wordexp()` выполняет подстановку команд; используйте `WRDE_NOCMD` для безопасности.
- **WRDE_SHOWERR:** по умолчанию stderr перенаправляется в `/dev/null`.
- **Многопоточность:** функция потокобезопасна.
