## Исключения

- **NULL:** все функции, принимающие указатели на строки, определены для `NULL` (поведение не определено); исключение — `strerror_r`.
- **errno:** функция `strerror()` не устанавливает `errno`; `strerror_r()` устанавливает `errno` при ошибке.
- **Переполнение:** `memcpy()`, `memmove()` не проверяют размер буфера; при недостатке места — неопределённое поведение.
- **Нехватка памяти:** `strdup()`, `strndup()` возвращают `NULL` при нехватке памяти и устанавливают `errno = ENOMEM`.
- **Граничные случаи:** `strlen()` не учитывает нулевой терминатор; `strtok()` изменяет исходную строку.
- **Многопоточность:** функции не являются потокобезопасными; для безопасного использования требуют блокировки.
- **Безопасность:** `strcpy()`, `strcat()`, `sprintf()` небезопасны; предпочтительнее `strncpy()`, `strncat()`, `snprintf()`.
