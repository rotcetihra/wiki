## Описание библиотеки

Заголовочный файл `<string.h>` определяет функции для работы со строками (массивами символов, завершающимися нулевым байтом `'\0'`) и с произвольными блоками памяти: копирование, сравнение, поиск, объединение строк, определение длины и сообщения об ошибках. В отличие от `<stdlib.h>`, здесь нет функций преобразования строк в числа — они рассматриваются в статье [[Языки программирования/C/Библиотеки/<stdlib.h>|<stdlib.h>]].

Все строковые функции считают концом строки первый нулевой байт: они никогда не читают и не пишут за его пределами (кроме функций с явным ограничением длины).

В POSIX-системах `<string.h>` расширяет стандартную библиотеку C дополнительными функциями работы со строками и памятью. Все они объявлены в том же файле `<string.h>`, но не входят в стандарт ISO C (кроме `memccpy`, которая с 2024 года включена в C23): это расширения POSIX, BSD и GNU, доступные в glibc при определении соответствующих макросов тестирования возможностей (`_GNU_SOURCE`, `_POSIX_C_SOURCE`, `_DEFAULT_SOURCE`).

### Стандарт C

#### Копирование

| Функция | Описание |
|---|---|
| `memcpy()` | Копирует `n` байт; не обрабатывает перекрытие областей |
| `memmove()` | Копирует `n` байт; безопасна при перекрытии областей |
| `strcpy()` | Копирует строку полностью; не проверяет размер буфера |
| `strncpy()` | Копирует не более `n` символов; не гарантирует завершающий нуль |
| `strdup()` | Создаёт динамическую копию строки (C23) |
| `strndup()` | Создаёт динамическую копию не более `n` символов (C23) |

#### Сравнение

| Функция | Описание |
|---|---|
| `memcmp()` | Сравнивает первые `n` байт блоков памяти |
| `strcmp()` | Побайтовое сравнение строк |
| `strncmp()` | Побайтовое сравнение не более `n` символов |
| `strcoll()` | Сравнение строк с учётом правил сортировки локали |
| `strxfrm()` | Преобразует строку в форму для сравнения через `strcmp()` |

#### Поиск

| Функция | Описание |
|---|---|
| `memchr()` | Ищет байт среди первых `n` байт блока памяти |
| `strchr()` | Ищет первое вхождение символа в строке |
| `strrchr()` | Ищет последнее вхождение символа в строке |
| `strstr()` | Ищет первое вхождение подстроки |
| `strpbrk()` | Ищет первый символ из набора |
| `strspn()` | Возвращает длину начального сегмента из символов набора |
| `strcspn()` | Возвращает длину начального сегмента без символов из набора |

#### Разбиение и длина

| Функция | Описание |
|---|---|
| `strtok()` | Разбивает строку на токены (модифицирует строку, не потокобезопасна) |
| `strlen()` | Возвращает длину строки в байтах |
| `strnlen()` | Безопасная версия `strlen()` с ограничением (C11) |
| `strcat()` | Дописывает строку в конец другой |
| `strncat()` | Дописывает не более `n` символов с гарантированным нулём |

#### Ошибки

| Функция | Описание |
|---|---|
| `memset()` | Заполняет `n` байт памяти заданным значением |
| `strerror()` | Возвращает текстовое описание кода ошибки |

### Расширения POSIX и GNU

#### Копирование и конкатенация

| Функция | Описание |
|---|---|
| `stpcpy()` | Копирует строку, возвращает указатель на её конец |
| `stpncpy()` | Копирует не более `n` символов, возвращает конец |
| `strlcpy()` | Безопасное копирование с гарантированным нулём (BSD) |
| `strlcat()` | Безопасная конкатенация с гарантированным нулём (BSD) |
| `mempcpy()` | Копирует блок памяти, возвращает конец |
| `memccpy()` | Копирует до стоп-байта (C23; ранее POSIX) |

#### Поиск в памяти и строках

| Функция | Описание |
|---|---|
| `memmem()` | Поиск подстроки в блоке памяти |
| `memrchr()` | Поиск последнего вхождения байта |
| `rawmemchr()` | Поиск байта без ограничения длины |
| `strchrnul()` | Поиск символа, при отсутствии — конец строки |
| `strcasestr()` | Поиск подстроки без учёта регистра |

#### Разбиение на токены

| Функция | Описание |
|---|---|
| `strtok_r()` | Потокобезопасная версия `strtok()` (состояние у вызывающего) |
| `strtok_s()` | Безопасная версия с проверкой размера (C11 Annex K) |
| `strsep()` | Версия, не пропускающая пустые токены (устаревшая) |

#### Сравнение и сортировка

| Функция | Описание |
|---|---|
| `strcoll_l()` | Сравнение строк по правилам явно заданной локали |
| `strxfrm_l()` | Преобразование строки в ключ сравнения для явной локали |
| `strverscmp()` | Сравнение строк как версий (числовые части — как числа) |

#### Ошибки и сигналы

| Функция | Описание |
|---|---|
| `strerror_r()` | Потокобезопасное описание ошибки |
| `strerror_l()` | Описание ошибки в заданной локали |
| `strerror_s()` | Безопасное описание ошибки (C11 Annex K) |
| `strerrordesc_np()` | Описание ошибки без перевода (всегда по-английски) |
| `strerrorname_np()` | Имя константы ошибки (например, `ENOENT`) |
| `strsignal()` | Описание сигнала по его номеру |

#### Прочие

| Функция | Описание |
|---|---|
| `basename()` | Последний компонент пути (GNU-вариант) |
| `explicit_bzero()` | Обнуление, которое компилятор не удалит (BSD) |
| `memfrob()` | XOR-обфускация блока памяти |
| `strfry()` | Случайное перемешивание строки |
