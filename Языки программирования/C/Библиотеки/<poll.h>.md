## Описание библиотеки

Заголовочный файл `<poll.h>` — определения для функции `poll()`. Определяет структуру `pollfd`, тип `nfds_t` и флаги для мультиплексирования ввода-вывода.

### Структура `struct pollfd`

```c
struct pollfd {
    int    fd;       /* Опрашиваемый файловый дескриптор */
    short  events;   /* Входные флаги событий */
    short  revents;  /* Выходные флаги результатов */
};
```

### Константы событий

| Константа | events | revents | Описание |
|---|---|---|---|
| `POLLIN` | + | + | Данные доступны для чтения |
| `POLLRDNORM` | + | + | Нормальные данные доступны |
| `POLLRDBAND` | + | + | Приоритетные данные доступны |
| `POLLPRI` | + | + | Данные высокого приоритета |
| `POLLOUT` | + | + | Запись без блокировки |
| `POLLWRNORM` | + | + | Запись нормальных данных |
| `POLLWRBAND` | + | + | Запись приоритетных данных |
| `POLLERR` | — | + | Ошибка |
| `POLLHUP` | — | + | Устройство отключено |
| `POLLNVAL` | — | + | Неверный файловый дескриптор |

### Функция `poll()`

```c
int poll(struct pollfd fds[], nfds_t nfds, int timeout);
```

| Параметр | Описание |
|---|---|
| `fds` | Массив опрашиваемых дескрипторов |
| `nfds` | Количество элементов в массиве |
| `timeout` | Таймаут в миллисекундах; -1 — бесконечное ожидание; 0 — немедленный возврат |

### Возвращаемое значение

- Количество готовых файловых дескрипторов (положительное число).
- 0 при таймауте.
- -1 при ошибке (`errno`).

## Исключения

- **NULL:** функция не принимает `NULL` в качестве массива.
- **errno:** при ошибке устанавливается `errno` (например, `EFAULT`, `EINTR`, `EINVAL`).
- **EFAULT:** неверный указатель на массив `pollfd`.
- **EINTR:** вызов прерван сигналом.
- **EINVAL:** `nfds` превышает системный лимит.
- **nfds_t:** ширина типа не должна превышать ширину `long`.
- **Многопоточность:** функция потокобезопасна.
- **timeout = -1:** бесконечное ожидание; прерывается сигналами.

## Стандарты

POSIX.1-2017, XSI.
