## Определение

```c
#include <threads.h>

typedef /* неопределённый тип */ thrd_t;
```

## Описание

Тип `thrd_t` представляет идентификатор потока. Конкретное внутреннее представление определяется реализацией. Значение типа `thrd_t` получается при создании потока (`thrd_create`) и может быть скопировано.

Идентификатор потока не является указателем и не может быть освобождён вручную — для этого предназначены `thrd_join` или `thrd_detach`.

## Пример

```c
#include <stdio.h>
#include <threads.h>

int func(void *arg)
{
    printf("Поток запущен\n");
    return 0;
}

int main(void)
{
    thrd_t t;
    thrd_create(&t, func, NULL);
    thrd_join(t, NULL);
    return 0;
}
```

## Плюсы и минусы
