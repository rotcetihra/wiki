## Определение

```c
#include <threads.h>

int tss_set(tss_t key, void *val);
```

## Описание

Функция `tss_set` устанавливает значение `val` для ключа `key` в текущем потоке. Предыдущее значение для этого ключа не удаляется автоматически — его нужно освободить вручную.

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `thrd_success` | Значение установлено |
| `thrd_error` | Ошибка |

## Пример

```c
#include <stdio.h>
#include <threads.h>

tss_t key;

int func(void *arg)
{
    int *p = malloc(sizeof(int));
    *p = 42;
    tss_set(key, p);
    printf("Значение: %d\n", *(int *)tss_get(key));
    free(p);
    return 0;
}

int main(void)
{
    tss_create(&key, NULL);
    thrd_t t;
    thrd_create(&t, func, NULL);
    thrd_join(t, NULL);
    tss_delete(key);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `key` | Ключ потокового хранилища |
| `val` | Значение для установки (или `NULL`) |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Потокобезопасная установка значения | Не удаляет предыдущее значение автоматически |
| Простой интерфейс | — |
