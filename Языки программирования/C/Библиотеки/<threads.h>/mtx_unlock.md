## Определение

```c
#include <threads.h>

int mtx_unlock(mtx_t *mtx);
```

## Описание

Функция `mtx_unlock` разблокирует ранее заблокированный мьютекс `mtx`. Мьютекс должен быть заблокирован текущим потоком.

Для рекурсивного мьютекса каждая блокировка должна быть соответствующим образом разблокирована.

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `thrd_success` | Мьютекс разблокирован |
| `thrd_error` | Мьютекс не был заблокирован текущим потоком |

## Пример

```c
#include <threads.h>

mtx_t m;

int func(void *arg)
{
    mtx_lock(&m);
    /* критическая секция */
    mtx_unlock(&m);
    return 0;
}

int main(void)
{
    mtx_init(&m, mtx_plain);
    thrd_t t;
    thrd_create(&t, func, NULL);
    thrd_join(t, NULL);
    mtx_destroy(&m);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `mtx` | Заблокированный мьютекс |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая разблокировка | Ошибка, если мьютекс не был заблокирован |
