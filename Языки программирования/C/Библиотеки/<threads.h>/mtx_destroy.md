## Определение

```c
#include <threads.h>

void mtx_destroy(mtx_t *mtx);
```

## Описание

Функция `mtx_destroy` уничтожает мьютекс `mtx` и освобождает связанные ресурсы. Мьютекс не должен быть заблокирован в момент уничтожения.

## Пример

```c
#include <threads.h>

int main(void)
{
    mtx_t m;
    mtx_init(&m, mtx_plain);
    /* использование */
    mtx_destroy(&m);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `mtx` | Указатель на инициализированный мьютекс |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Освобождает ресурсы | Нельзя вызывать для заблокированного мьютекса |
