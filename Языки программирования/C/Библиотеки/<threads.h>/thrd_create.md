## Определение

```c
#include <threads.h>

int thrd_create(thrd_t *thr, thrd_start_t func, void *arg);
```

## Описание

Функция `thrd_create` создаёт новый поток, который выполняет функцию `func` с аргументом `arg`. Идентификатор нового потока сохраняется по указателю `thr`.

Поток начинает выполняться немедленно (или вскоре после создания). Родительский поток не блокируется.

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `thrd_success` | Поток создан успешно |
| `thrd_nomem` | Не хватило памяти для создания потока |
| `thrd_error` | Другая ошибка |

## Пример

```c
#include <stdio.h>
#include <threads.h>

int worker(void *arg)
{
    int n = *(int *)arg;
    printf("Поток: %d\n", n);
    return n * 2;
}

int main(void)
{
    int val = 21;
    thrd_t t;
    thrd_create(&t, worker, &val);
    int res;
    thrd_join(t, &res);
    printf("Результат: %d\n", res);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `thr` | Указатель для сохранения идентификатора потока |
| `func` | Функция потока типа `thrd_start_t` |
| `arg` | Аргумент, передаваемый функции потока |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простое создание потока | Нет способа отменить создание потока |
| Стандартный переносимый API | Аргумент `arg` должен оставаться валидным до чтения |
