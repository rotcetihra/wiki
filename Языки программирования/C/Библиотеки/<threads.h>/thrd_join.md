## Определение

```c
#include <threads.h>

int thrd_join(thrd_t thr, int *res);
```

## Описание

Функция `thrd_join` блокирует вызывающий поток до тех пор, пока поток `thr` не завершится. Код возврата завершённого потока сохраняется по указателю `res` (если он не `NULL`).

После завершения поток не может быть повторно присоединён или отсоединён — ресурсы освобождаются автоматически.

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `thrd_success` | Поток завершён, результат получен |
| `thrd_error` | Ошибка |

## Пример

```c
#include <stdio.h>
#include <threads.h>

int func(void *arg)
{
    return *(int *)arg + 1;
}

int main(void)
{
    int val = 41;
    thrd_t t;
    thrd_create(&t, func, &val);
    int res;
    thrd_join(t, &res);
    printf("Результат: %d\n", res);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `thr` | Идентификатор потока для ожидания |
| `res` | Указатель для сохранения кода возврата (или `NULL`) |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет получить результат потока | Блокирующий вызов |
| Автоматическое освобождение ресурсов | Нельзя присоединить поток повторно |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** `thrd_error` — ошибка присоединения.
- **Установление errno:** функция не устанавливает `errno` (стандарт C23 не определяет использование `errno` для `<threads.h>`).
- **Поведение при передаче NULL:** если `res` равен `NULL`, код возврата потока игнорируется. Параметр `thr` передаётся по значению — передача недействительного идентификатора или уже присоединённого потока приводит к UB.
- **Многопоточность:** блокирующий вызов — вызывающий поток приостанавливается до завершения потока `thr`. После завершения поток не может быть повторно присоединён или отсоединён — ресурсы освобождаются автоматически.
- **Связанные функции:** `thrd_create` — создание потока; `thrd_detach` — отсоединение потока; `thrd_exit` — завершение потока.
