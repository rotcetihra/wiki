## Определение

```c
#include <threads.h>

int mtx_trylock(mtx_t *mtx);
```

## Описание

Функция `mtx_trylock` пытается заблокировать мьютекс `mtx` без ожидания. Если мьютекс свободен, он блокируется и возвращается `thrd_success`. Если занят — возвращается `thrd_busy` без блокировки.

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `thrd_success` | Мьютекс заблокирован |
| `thrd_busy` | Мьютекс занят |
| `thrd_error` | Ошибка |

## Пример

```c
#include <stdio.h>
#include <threads.h>

mtx_t m;

int func(void *arg)
{
    if (mtx_trylock(&m) == thrd_success) {
        printf("Поток заблокировал мьютекс\n");
        mtx_unlock(&m);
    } else {
        printf("Поток не смог заблокировать\n");
    }
    return 0;
}

int main(void)
{
    mtx_init(&m, mtx_plain);
    thrd_t t;
    thrd_create(&t, func, NULL);
    thrd_join(t, NULL);
    mtx_destroy(&m);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `mtx` | Указатель на инициализированный мьютекс |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Неблокирующий вызов | Требуется проверка кода возврата |
| Позволяет избежать dead-lock | Может потребоваться повторная попытка |
