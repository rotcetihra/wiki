## Определение

```c
#include <threads.h>

typedef /* неопределённый тип */ mtx_t;
```

## Описание

Тип `mtx_t` представляет мьютекс (взаимное исключение) для синхронизации доступа к разделяемым данным между потоками. Инициализируется через `mtx_init` с указанием типа (`mtx_plain`, `mtx_recursive` или `mtx_timed`).

## Пример

```c
#include <stdio.h>
#include <threads.h>

mtx_t mutex;

int func(void *arg)
{
    mtx_lock(&mutex);
    printf("Критическая секция\n");
    mtx_unlock(&mutex);
    return 0;
}

int main(void)
{
    mtx_init(&mutex, mtx_plain);
    thrd_t t;
    thrd_create(&t, func, NULL);
    thrd_join(t, NULL);
    mtx_destroy(&mutex);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный мьютекс C11 | Только базовая функциональность |
| Поддерживает рекурсию (`mtx_recursive`) | Нет условных переменных и барьеров |
