## Определение

```c
#include <threads.h>

int mtx_init(mtx_t *mtx, int type);
```

## Описание

Функция `mtx_init` инициализирует мьютекс `mtx` с указанием типа:

| Тип | Описание |
|---|---|
| `mtx_plain` | Простой нерекурсивный мьютекс без тайм-аута |
| `mtx_recursive` | Рекурсивный мьютекс без тайм-аута |
| `mtx_timed` | Мьютекс с тайм-аутом, без рекурсии |

Мьютекс должен быть уничтожен через `mtx_destroy` после использования.

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `thrd_success` | Мьютекс инициализирован |
| `thrd_error` | Ошибка (неверный тип) |

## Пример

```c
#include <threads.h>

int main(void)
{
    mtx_t m;
    mtx_init(&m, mtx_plain);
    /* использование мьютекса */
    mtx_destroy(&m);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `mtx` | Указатель на мьютекс для инициализации |
| `type` | Тип мьютекса (`mtx_plain`, `mtx_recursive`, `mtx_timed`) |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гибкий выбор типа мьютекса | Тип нельзя изменить после инициализации |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** `thrd_error` — неверный тип мьютекса.
- **Установление errno:** функция не устанавливает `errno` (стандарт C23 не определяет использование `errno` для `<threads.h>`).
- **Поведение при передаче NULL:** если `mtx` равен `NULL`, поведение не определено (UB).
- **Многопоточность:** инициализированный мьютекс может безопасно использоваться из любого потока. Тип мьютекса (`mtx_plain`, `mtx_recursive`, `mtx_timed`) определяет поведение при повторной блокировке и поддержку тайм-аута.
- **Связанные функции:** `mtx_lock` — блокировка мьютекса; `mtx_destroy` — уничтожение мьютекса; `MTX_INIT` — статический инициализатор.
