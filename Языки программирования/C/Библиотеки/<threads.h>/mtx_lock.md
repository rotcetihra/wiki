## Определение

```c
#include <threads.h>

int mtx_lock(mtx_t *mtx);
```

## Описание

Функция `mtx_lock` блокирует мьютекс `mtx`. Если мьютекс уже заблокирован другим потоком, вызывающий поток приостанавливается до тех пор, пока мьютекс не будет освобождён.

При рекурсивном мьютексе (`mtx_recursive`) один и тот же поток может блокировать его несколько раз.

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `thrd_success` | Мьютекс заблокирован |
| `thrd_error` | Ошибка |

## Пример

```c
#include <stdio.h>
#include <threads.h>

mtx_t m;
int counter = 0;

int func(void *arg)
{
    mtx_lock(&m);
    counter++;
    mtx_unlock(&m);
    return 0;
}

int main(void)
{
    mtx_init(&m, mtx_plain);
    thrd_t t;
    thrd_create(&t, func, NULL);
    mtx_lock(&m);
    counter++;
    mtx_unlock(&m);
    thrd_join(t, NULL);
    printf("Счётчик: %d\n", counter);
    mtx_destroy(&m);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `mtx` | Указатель на инициализированный мьютекс |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует взаимное исключение | Блокирующий вызов — может привести к dead-lock |
| Работает с рекурсивными мьютексами | — |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** `thrd_error` — ошибка блокировки.
- **Установление errno:** функция не устанавливает `errno` (стандарт C23 не определяет использование `errno` для `<threads.h>`).
- **Поведение при передаче NULL:** если `mtx` равен `NULL`, поведение не определено (UB).
- **Многопоточность:** функция является основным механизмом синхронизации. Блокирует мьютекс с ожиданием — если мьютекс занят другим потоком, вызывающий поток приостанавливается. Для рекурсивного мьютекса (`mtx_recursive`) один и тот же поток может блокировать его несколько раз.
- **Связанные функции:** `mtx_trylock` — неблокирующая попытка; `mtx_timedlock` — блокировка с тайм-аутом; `mtx_unlock` — разблокировка.
