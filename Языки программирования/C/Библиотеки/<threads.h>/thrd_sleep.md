## Определение

```c
#include <threads.h>

int thrd_sleep(const struct timespec *duration, struct timespec *remaining);
```

## Описание

Функция `thrd_sleep` приостанавливает текущий поток на время, указанное в `duration`. Если прерывание occurred, в `remaining` сохраняется оставшееся время (если указатель не `NULL`).

Время задаётся в секундах и наносекундах через `struct timespec`.

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Сон завершён успешно |
| `-1` | Сон прерван сигналом |

## Пример

```c
#include <stdio.h>
#include <threads.h>

int func(void *arg)
{
    struct timespec ts = { .tv_sec = 1, .tv_nsec = 0 };
    printf("Поток спит 1 секунду\n");
    thrd_sleep(&ts, NULL);
    printf("Поток проснулся\n");
    return 0;
}

int main(void)
{
    thrd_t t;
    thrd_create(&t, func, NULL);
    thrd_join(t, NULL);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `duration` | Время сна в `struct timespec` |
| `remaining` | Оставшееся время после прерывания (или `NULL`) |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Точное управление временем сна | Может быть прерван сигналом |
| Стандартная функция C11 | Зависит от точности таймера ОС |
