## Определение

```c
#include <threads.h>

void *tss_get(tss_t key);
```

## Описание

Функция `tss_get` возвращает значение, связанное с ключом `key` для текущего потока. Если значение не установлено или ключ недействителен, возвращается `NULL`.

## Пример

```c
#include <stdio.h>
#include <threads.h>

tss_t key;

int func(void *arg)
{
    int *p = malloc(sizeof(int));
    *p = 100;
    tss_set(key, p);
    int *val = tss_get(key);
    printf("Значение: %d\n", *val);
    free(val);
    return 0;
}

int main(void)
{
    tss_create(&key, NULL);
    thrd_t t;
    thrd_create(&t, func, NULL);
    thrd_join(t, NULL);
    tss_delete(key);
    return 0;
}
```

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Указатель | Значение для текущего потока |
| `NULL` | Значение не установлено или ключ недействителен |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрый доступ к потоковому значению | Возвращает `void *` — необходимость приведения типа |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** `NULL` — значение не установлено или ключ недействителен.
- **Установление errno:** функция не устанавливает `errno` (стандарт C23 не определяет использование `errno` для `<threads.h>`).
- **Поведение при передаче NULL:** ключ `key` передаётся по значению (не указатель), поэтому NULL не применимо. Если ключ недействителен или значение не установлено, возвращается `NULL`.
- **Многопоточность:** функция возвращает значение, специфичное для текущего потока. Каждый поток видит только свои значения, установленные через `tss_set`.
- **Связанные функции:** `tss_set` — установка значения; `tss_create` — создание ключа.
