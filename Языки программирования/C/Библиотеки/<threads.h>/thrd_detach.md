## Определение

```c
#include <threads.h>

int thrd_detach(thrd_t thr);
```

## Описание

Функция `thrd_detach` отсоединяет поток `thr`. Ресурсы потока автоматически освобождаются при его завершении. После отсоединения нельзя вызывать `thrd_join` для этого потока.

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `thrd_success` | Поток отсоединён |
| `thrd_error` | Ошибка |

## Пример

```c
#include <stdio.h>
#include <threads.h>

int func(void *arg)
{
    printf("Фоновый поток\n");
    return 0;
}

int main(void)
{
    thrd_t t;
    thrd_create(&t, func, NULL);
    thrd_detach(t);
    /* Нельзя вызвать thrd_join(t, ...) */
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `thr` | Идентификатор потока для отсоединения |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Освобождает ресурсы автоматически | Нельзя получить результат потока |
| Поток работает в фоновом режиме | Нельзя отменить отсоединение |
