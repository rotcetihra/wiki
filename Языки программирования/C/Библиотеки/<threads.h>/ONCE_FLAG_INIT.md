## Определение

```c
#include <threads.h>

#define ONCE_FLAG_INIT /* инициализатор */
```

## Описание

Макрос `ONCE_FLAG_INIT` является инициализатором для переменной типа `once_flag`. Используется для статической инициализации или при первоначальной настройке флага.

## Пример

```c
#include <threads.h>

once_flag flag = ONCE_FLAG_INIT;
```
