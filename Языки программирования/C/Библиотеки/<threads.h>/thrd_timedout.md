## Определение

```c
#include <threads.h>

#define thrd_timedout /* константа (ненулевое) */
```

## Описание

Константа `thrd_timedout` возвращается, если операция с ограничением по времени не завершилась вовремя. Например, `mtx_timedlock` и `thrd_sleep` могут вернуть `thrd_timedout`.
