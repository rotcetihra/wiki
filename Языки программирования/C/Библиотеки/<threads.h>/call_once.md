## Определение

```c
#include <threads.h>

void call_once(once_flag *flag, void (*func)(void));
```

## Описание

Функция `call_once` гарантирует, что функция `func` будет вызвана ровно один раз, даже если несколько потоков вызывают `call_once` одновременно. Флаг `flag` определяет, была ли функция уже вызвана.

Флаг `flag` должен быть инициализирован через `ONCE_FLAG_INIT` до первого вызова `call_once`.

## Пример

```c
#include <stdio.h>
#include <threads.h>

once_flag init_flag = ONCE_FLAG_INIT;

void init(void)
{
    printf("Инициализация выполнена\n");
}

int func(void *arg)
{
    call_once(&init_flag, init);
    return 0;
}

int main(void)
{
    thrd_t t1, t2;
    thrd_create(&t1, func, NULL);
    thrd_create(&t2, func, NULL);
    thrd_join(t1, NULL);
    thrd_join(t2, NULL);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `flag` | Указатель на инициализированный `once_flag` |
| `func` | Функция для однократного вызова |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантия однократного выполнения | Функция не должна вызывать `call_once` |
| Потокобезопасный | Если `func` завершается аварийно, повторный вызов не гарантирован |
| Эффективнее ручной синхронизации | — |
