## Определение

```c
#include <threads.h>

void tss_delete(tss_t key);
```

## Описание

Функция `tss_delete` удаляет ключ потокового хранилища `key`. Значения, установленные для данного ключа в других потоках, не удаляются автоматически — их нужно удалить вручную или через деструктор при завершении потока.

## Пример

```c
#include <threads.h>

tss_t key;

int main(void)
{
    tss_create(&key, NULL);
    /* использование */
    tss_delete(key);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `key` | Ключ потокового хранилища для удаления |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Освобождает ресурсы ключа | Не удаляет значения в других потоках |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** функция не возвращает значения (`void`).
- **Установление errno:** функция не устанавливает `errno` (стандарт C23 не определяет использование `errno` для `<threads.h>`).
- **Поведение при передаче NULL:** ключ `key` передаётся по значению (не указатель), поэтому NULL не применимо. Однако передача недействительного ключа приводит к UB.
- **Многопоточность:** значения, установленные для данного ключа в других потоках, не удаляются автоматически — их нужно удалить вручную или через деструктор при завершении потока. Ключ нельзя использовать после `tss_delete`.
- **Связанные функции:** `tss_create` — создание ключа; `tss_set` — установка значения; `tss_get` — получение значения.
