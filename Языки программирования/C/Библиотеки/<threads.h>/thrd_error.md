## Определение

```c
#include <threads.h>

#define thrd_error /* константа (ненулевое) */
```

## Описание

Константа `thrd_error` возвращается при неуточнённой ошибке, если не подходит ни одна другая константа (`thrd_nomem`, `thrd_busy`, `thrd_timedout`).

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Универсальный код ошибки | Не даёт информации о причине |
