## Определение

```c
#include <tgmath.h>

#define tgpow(x, y) /* обобщённый макрос */
```

## Описание

Макрос `tgpow` — обобщённая версия возведения в степень. Автоматически выбирает функцию `powf`, `pow`, `powl`, `cpowf`, `cpow` или `cpowl` в зависимости от типа аргументов.

Вычисляет `x^y`. Для вещественных типов: `x` должен быть `≥ 0` (если `y` не целое); `0^0` даёт 1.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    printf("2^10 = %.0f\n", tgpow(2.0, 10.0));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Основание. Для вещественных типов: `≥ 0` (если `y` дробное). |
| `y` | Показатель степени. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | `x^y` |
| Комплексный | `z^w` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргументов | Отрицательное основание с дробным показателем — ошибка |
| Работает с вещественными и комплексными типами | Переполнение при больших значениях |

## Обработка ошибок

- Если `x < 0` и `x` не является целым, или `x = 0` и `y ≤ 0`, результат не определён (может быть `NaN` или сбой домена).
- Переполнение при вычислении — результат `±HUGE_VAL`, `errno` может быть установлена в `ERANGE`.
- Если один из аргументов — комплексное число, результат определяется комплексным возведением в степень.
- Поведение не определено для нечисловых аргументов (кроме `NaN`).
- Потокобезопасность: безопасен (нет разделяемых данных).
