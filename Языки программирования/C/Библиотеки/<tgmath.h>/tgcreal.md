## Определение

```c
#include <tgmath.h>

#define tgcreal(x) /* обобщённый макрос */
```

## Описание

Макрос `tgcreal` — обобщённая версия извлечения вещественной части. Автоматически выбирает `crealf`, `creal` или `creall`.

Возвращает вещественную часть комплексного числа. Только для комплексных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double _Complex z = 3.0 + 4.0 * I;
    printf("Re(3+4i) = %.1f\n", tgcreal(z));

    return 0;
}
```

| Параметр | Описание |
