## Определение

```c
#include <tgmath.h>

#define tglog1p(x) /* обобщённый макрос */
```

## Описание

Макрос `tglog1p` — обобщённая версия «натуральный логарифм плюс один». Автоматически выбирает функцию `log1pf`, `log1p` или `log1pl` в зависимости от типа аргумента `x`.

Вычисляет `ln(1 + x)`. Функция предназначена для точного вычисления значения, близкого к нулю, где прямое вычисление `log(1 + x)` теряет точность.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 1e-15;
    printf("log(1 + %.1e) = %.1e\n", x, tglog(1.0 + x));
    printf("log1p(%.1e)  = %.1e\n", x, tglog1p(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Значение `> -1`. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | `ln(1 + x)` |
| `double` | `ln(1 + x)` |
| `long double` | `ln(1 + x)` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Высокая точность для малых `x` | Только для вещественных типов |
| Автоматический выбор версии по типу аргумента | Аргумент `x ≤ -1` приводит к ошибке |

## Обработка ошибок

- Если `x ≤ -1`, результат не определён (может быть `NaN` или сбой домена).
- Поведение не определено для нечисловых аргументов (кроме `NaN`).
- Потокобезопасность: безопасен (нет разделяемых данных).
