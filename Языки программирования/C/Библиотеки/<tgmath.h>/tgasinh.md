## Определение

```c
#include <tgmath.h>

#define tgasinh(x) /* обобщённый макрос */
```

## Описание

Макрос `tgasinh` — обобщённая версия обратного гиперболического синуса. Автоматически выбирает функцию `asinhf`, `asinh` или `asinhl` в зависимости от типа аргумента `x`.

Обратный гиперболический синус возвращает угол, гиперболический синус которого равен `x`. Аргумент `x` может быть любым конечным вещественным числом.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 1.0;
    printf("asinh(%.1f) = %.4f\n", x, tgasinh(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Любое конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | Угол, `sinh(result) = x` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Только для вещественных типов |
| Аргумент любое конечное значение | Для нечисловых аргументов поведение не определено |
