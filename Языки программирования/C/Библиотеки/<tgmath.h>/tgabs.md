## Определение

```c
#include <tgmath.h>

#define tgabs(x) /* обобщённый макрос */
```

## Описание

Макрос `tgabs` — обобщённая версия модуля. Автоматически выбирает функцию в зависимости от типа аргумента:

| Тип аргумента | Вызываемая функция | Результат |
|---|---|---|
| `float` | `fabsf` | модуль `float` |
| `double` | `fabs` | модуль `double` |
| `long double` | `fabsl` | модуль `long double` |
| `float _Complex` | `cabsf` | модуль комплексного числа (`float`) |
| `double _Complex` | `cabs` | модуль комплексного числа (`double`) |
| `long double _Complex` | `cabsl` | модуль комплексного числа (`long double`) |

Для вещественных типов возвращает `|x|`. Для комплексных — модуль `√(Re² + Im²)`.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    printf("abs(-5) = %.1f\n", tgabs(-5.0));

    double _Complex z = 3.0 + 4.0 * I;
    printf("|3+4i| = %.1f\n", tgabs(z));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | `\|x\| ≥ 0` |
| Комплексный | `\|z\| ≥ 0` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Нет целочисленных версий |
| Работает с вещественными и комплексными типами | — |

## Обработка ошибок

- Для `+∞` и `-∞` результат — `+∞`.
- Для `NaN` результат — `NaN`.
- Для комплексных типов: `|z| ≥ 0`, бесконечность в любой части даёт `+∞`.
- Поведение не определено для нечисловых аргументов (кроме `NaN`).
- Потокобезопасность: безопасен (нет разделяемых данных).
