## Определение

```c
#include <tgmath.h>

#define tgcarg(x) /* обобщённый макрос */
```

## Описание

Макрос `tgcarg` — обобщённая версия аргумента комплексного числа. Автоматически выбирает `cargf`, `carg` или `cargl`.

Возвращает аргумент (угол) комплексного числа в радианах из диапазона `(-π, π]`. Только для комплексных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double _Complex z = 1.0 + 1.0 * I;
    printf("arg(1+i) = %.4f\n", tgcarg(z));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Комплексное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | Аргумент в радианах `(-π, π]` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу | Только для комплексных типов |
| — | Результат всегда вещественный |
