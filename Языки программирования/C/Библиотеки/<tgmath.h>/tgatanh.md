## Определение

```c
#include <tgmath.h>

#define tgatanh(x) /* обобщённый макрос */
```

## Описание

Макрос `tgatanh` — обобщённая версия обратного гиперболического тангенса. Автоматически выбирает функцию `atanhf`, `atanh` или `atanhl` в зависимости от типа аргумента `x`.

Обратный гиперболический тангенс возвращает угол, тангенс которого равен `x`. Аргумент `x` должен принадлежать диапазону `(-1, +1)`.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 0.5;
    printf("atanh(%.1f) = %.4f\n", x, tgatanh(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Значение из `(-1, +1)`. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | Угол, `tanh(result) = x` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Только для вещественных типов |
| Упрощает написание обобщённого кода | Аргумент `|x| ≥ 1` приводит к ошибке домена |
