## Определение

```c
#include <tgmath.h>

#define tgsin(x) /* обобщённый макрос */
```

## Описание

Макрос `tgsin` — обобщённая версия синуса. На основе типа аргумента `x` автоматически выбирается соответствующая функция:

| Тип аргумента | Вызываемая функция |
|---|---|
| `float` | `sinf` |
| `double` | `sin` |
| `long double` | `sinl` |
| `float _Complex` | `csinf` |
| `double _Complex` | `csin` |
| `long double _Complex` | `csinl` |

Синус возвращает значение из диапазона `[-1, +1]` для вещественных типов. Аргумент `x` задаёт угол в радианах.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 1.5707963267948966;  /* π/2 */
    printf("sin(π/2) = %.4f\n", tgsin(x));

    float xf = 1.5707963267948966f;
    printf("sinf(π/2) = %.4f\n", tgsin(xf));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Угол в радианах. Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | Синус угла, `[-1, +1]` |
| Комплексный | Комплексный синус |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Не replacement для `sin` при работе только с `double` |
| Работает с вещественными и комплексными типами | Для нечисловых аргументов поведение не определено |
| Упрощает написание обобщённого кода | Нет явного контроля над типом результата |
