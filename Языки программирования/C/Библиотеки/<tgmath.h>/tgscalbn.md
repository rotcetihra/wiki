## Определение

```c
#include <tgmath.h>

#define tgscalbn(x, n) /* обобщённый макрос */
```

## Описание

Макрос `tgscalbn` — обобщённая версия масштабирования по основанию 2. Автоматически выбирает `scalbnf`, `scalbn` или `scalbnl`.

Вычисляет `x * FLT_RADIX^n`. Обычно `FLT_RADIX = 2`, поэтому результат эквивалентен `ldexp`. Только для вещественных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    printf("scalbn(1.5, 3) = %.1f\n", tgscalbn(1.5, 3));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Множитель. Конечное значение. |
| `n` | Целый показатель. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | `x * FLT_RADIX^n` |
| `double` | `x * FLT_RADIX^n` |
| `long double` | `x * FLT_RADIX^n` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Учитывает `FLT_RADIX` (может быть не 2) | Только для вещественных типов |
| — | Переполнение при больших `n` |

## Обработка ошибок

- Переполнение при вычислении — результат `±HUGE_VAL`, `errno` может быть установлена в `ERANGE`.
- Недополнение — результат `±0`, `errno` может быть установлена в `ERANGE`.
- Для `±∞` результат — `±∞`.
- Поведение не определено для нечисловых аргументов (кроме `NaN`).
- Потокобезопасность: безопасен (нет разделяемых данных).
