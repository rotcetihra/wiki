## Определение

```c
#include <tgmath.h>

#define tgtan(x) /* обобщённый макрос */
```

## Описание

Макрос `tgtan` — обобщённая версия тангенса. На основе типа аргумента `x` автоматически выбирается соответствующая функция:

| Тип аргумента | Вызываемая функция |
|---|---|
| `float` | `tanf` |
| `double` | `tan` |
| `long double` | `tanl` |
| `float _Complex` | `ctanf` |
| `double _Complex` | `ctan` |
| `long double _Complex` | `ctanl` |

Тангенс возвращает `sin(x) / cos(x)`. Значение не определено, когда `cos(x)` равен нулю (углы `π/2 + kπ`).

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 0.7853981633974483;  /* π/4 */
    printf("tan(π/4) = %.4f\n", tgtan(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Угол в радианах. Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | Тангенс угла |
| Комплексный | Комплексный тангенс |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Не replacement для `tan` при работе только с `double` |
| Работает с вещественными и комплексными типами | Не определён при `cos(x) = 0` |
| Упрощает написание обобщённого кода | Нет явного контроля над типом результата |
