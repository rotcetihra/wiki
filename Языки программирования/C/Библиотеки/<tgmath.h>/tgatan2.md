## Определение

```c
#include <tgmath.h>

#define tgatan2(y, x) /* обобщённый макрос */
```

## Описание

Макрос `tgatan2` — обобщённая версия арктангенса двух аргументов. На основе типа аргументов `y` и `x` автоматически выбирается соответствующая функция:

| Тип аргументов | Вызываемая функция |
|---|---|
| `float` | `atan2f` |
| `double` | `atan2` |
| `long double` | `atan2l` |

Функция `atan2` возвращает угол в радианах из диапазона `[-π, π]`, тангенс которого равен `y / x`, с учётом квадранта, определяемого знаками обоих аргументов. Оба аргумента не могут быть одновременно равны нулю.

> [!NOTE]
> Макрос `tgatan2` определён только для вещественных типов — комплексные версии отсутствуют.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double y = 1.0, x = 1.0;
    printf("atan2(%.1f, %.1f) = %.4f\n", y, x, tgatan2(y, x));

    printf("atan2(%.1f, %.1f) = %.4f\n", 0.0, -1.0, tgatan2(0.0, -1.0));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `y` | Координата Y (противолежащий катет). Конечное значение. |
| `x` | Координата X (прилежащий катет). Конечное значение. Не оба нуля. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | Угол в радианах `[-π, π]` |
| `double` | Угол в радианах `[-π, π]` |
| `long double` | Угол в радианах `[-π, π]` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргументов | Только для вещественных типов (нет комплексных версий) |
| Учитывает квадрант (в отличие от `atan`) | Оба аргумента не могут быть одновременно нулём |
| Упрощает написание обобщённого кода | Нет явного контроля над типом результата |
