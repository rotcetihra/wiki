## Определение

```c
#include <tgmath.h>

#define tgsinh(x) /* обобщённый макрос */
```

## Описание

Макрос `tgsinh` — обобщённая версия гиперболического синуса. Автоматически выбирает функцию `sinhf`, `sinh`, `sinhl`, `csinhf`, `csinh` или `csinhl` в зависимости от типа аргумента `x`.

Гиперболический синус определяется как `sinh(x) = (e^x - e^(-x)) / 2`.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 1.0;
    printf("sinh(%.1f) = %.4f\n", x, tgsinh(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Аргумент. Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | `sinh(x)` |
| Комплексный | Комплексный гиперболический синус |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Не replacement для `sinh` при работе только с `double` |
| Работает с вещественными и комплексными типами | Для нечисловых аргументов поведение не определено |

## Обработка ошибок

- Переполнение при вычислении для очень больших значений (|x| > ~710) — результат `±HUGE_VAL`, `errno` может быть установлена в `ERANGE`.
- Если `x` — комплексное число с бесконечной или нечисловой мнимой частью, результат — `NaN + i*NaN`.
- Поведение не определено для нечисловых аргументов (кроме `NaN`).
- Потокобезопасность: безопасен (нет разделяемых данных).
