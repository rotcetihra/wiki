## Определение

```c
#include <tgmath.h>

#define tgcos(x) /* обобщённый макрос */
```

## Описание

Макрос `tgcos` — обобщённая версия косинуса. На основе типа аргумента `x` автоматически выбирается соответствующая функция:

| Тип аргумента | Вызываемая функция |
|---|---|
| `float` | `cosf` |
| `double` | `cos` |
| `long double` | `cosl` |
| `float _Complex` | `ccosf` |
| `double _Complex` | `ccos` |
| `long double _Complex` | `ccosl` |

Косинус возвращает значение из диапазона `[-1, +1]` для вещественных типов. Аргумент `x` задаёт угол в радианах.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 0.0;
    printf("cos(%.1f) = %.4f\n", x, tgcos(x));

    float xf = 3.14159f;
    printf("cosf(%.5f) = %.4f\n", xf, tgcos(xf));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Угол в радианах. Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | Косинус угла, `[-1, +1]` |
| Комплексный | Комплексный косинус |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Не replacement для `cos` при работе только с `double` |
| Работает с вещественными и комплексными типами | Для нечисловых аргументов поведение не определено |
| Упрощает написание обобщённого кода | Нет явного контроля над типом результата |

## Обработка ошибок

- Если `x` — комплексное число с бесконечной или нечисловой мнимой частью, результат — `NaN + i*NaN`.
- Переполнение при вычислении для очень больших значений не определено.
- Поведение не определено для нечисловых аргументов (кроме `NaN`).
- Потокобезопасность: безопасен (нет разделяемых данных).
