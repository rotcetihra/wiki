## Определение

```c
#include <tgmath.h>

#define tgatan(x) /* обобщённый макрос */
```

## Описание

Макрос `tgatan` — обобщённая версия арктангенса. На основе типа аргумента `x` автоматически выбирается соответствующая функция:

| Тип аргумента | Вызываемая функция |
|---|---|
| `float` | `atanf` |
| `double` | `atan` |
| `long double` | `atanl` |
| `float _Complex` | `catanf` |
| `double _Complex` | `catan` |
| `long double _Complex` | `catanl` |

Арктангенс возвращает угол в радианах из диапазона `[-π/2, π/2]`, тангенс которого равен `x`. Аргумент `x` может быть любым конечным вещественным числом.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 1.0;
    printf("atan(%.1f) = %.4f\n", x, tgatan(x));

    float xf = 1.0f;
    printf("atanf(%.1f) = %.4f\n", xf, tgatan(xf));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Значение, тангенс которого ищется. Любое конечное значение для вещественных типов. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | Угол в радианах `[-π/2, π/2]` |
| Комплексный | Комплексный угол, тангенс которого равен `x` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Не replacement для `atan` при работе только с `double` |
| Работает с вещественными и комплексными типами | Для нечисловых аргументов поведение не определено |
| Упрощает написание обобщённого кода | Нет явного контроля над типом результата |
