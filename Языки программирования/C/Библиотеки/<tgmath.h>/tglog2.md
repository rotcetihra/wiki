## Определение

```c
#include <tgmath.h>

#define tglog2(x) /* обобщённый макрос */
```

## Описание

Макрос `tglog2` — обобщённая версия логарифма по основанию 2. Автоматически выбирает функцию `log2f`, `log2` или `log2l` в зависимости от типа аргумента `x`.

Вычисляет `log₂(x)`. Только для вещественных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 1024.0;
    printf("log2(%.1f) = %.1f\n", x, tglog2(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Положительное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | `log₂(x)` |
| `double` | `log₂(x)` |
| `long double` | `log₂(x)` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Только для вещественных типов |
| Может быть быстрее, чем `log(x)/log(2)` | Аргумент `x ≤ 0` приводит к ошибке |
