## Определение

```c
#include <tgmath.h>

#define tgacos(x) /* обобщённый макрос */
```

## Описание

Макрос `tgacos` — обобщённая версия арккосинуса. На основе типа аргумента `x` автоматически выбирается соответствующая функция:

| Тип аргумента | Вызываемая функция |
|---|---|
| `float` | `acosf` |
| `double` | `acos` |
| `long double` | `acosl` |
| `float _Complex` | `cacosf` |
| `double _Complex` | `cacos` |
| `long double _Complex` | `cacosl` |

Арккосинус возвращает угол в радианах из диапазона `[0, π]`, косинус которого равен `x`. Аргумент `x` должен принадлежать диапазону `[-1, +1]`.

Для вещественных типов результат лежит в `[0, π]`. Для комплексных типов используется основное значение арккосинуса (сplement角 на косинусной ветви).

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 0.5;
    printf("acos(%.1f) = %.4f\n", x, tgacos(x));

    float xf = 0.5f;
    printf("acosf(%.1f) = %.4f\n", xf, tgacos(xf));

    double _Complex z = 1.0 + 2.0 * I;
    printf("cacos(1+2i) = %.4f%+.4fi\n", creal(tgacos(z)), cimag(tgacos(z)));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Значение, косинус которого ищется. Для вещественных типов: `[-1, +1]`. Для комплексных: любое. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | Угол в радианах `[0, π]` |
| Комплексный | Комплексный угол, косинус которого равен `x` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Не replacement для `acos` при работе только с `double` |
| Работает с вещественными и комплексными типами | Для нечисловых аргументов поведение не определено |
| Упрощает написание обобщённого кода | Нет явного контроля над типом результата |
