## Определение

```c
#include <tgmath.h>

#define tground(x) /* обобщённый макрос */
```

## Описание

Макрос `tground` — обобщённая версия округления к ближайшему целому. Автоматически выбирает `roundf`, `round` или `roundl`.

Округляет `x` к ближайшему целому, от нуля (_HALF_UP). В отличие от `nearbyint`, не зависит от направления округления.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    printf("round(2.3) = %.1f\n", tground(2.3));
    printf("round(2.5) = %.1f\n", tground(2.5));
    printf("round(-2.5) = %.1f\n", tground(-2.5));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | Ближайшее целое (от нуля) |
| `double` | Ближайшее целое (от нуля) |
| `long double` | Ближайшее целое (от нуля) |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Не зависит от направления округления | Только для вещественных типов |
| Предсказуемое поведение для .5 | Результат может не помещаться в `int` |
