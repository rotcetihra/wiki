## Определение

```c
#include <tgmath.h>

#define tgfdim(x, y) /* обобщённый макрос */
```

## Описание

Макрос `tgfdim` — обобщённая версия положительной разности. Автоматически выбирает `fdimf`, `fdim` или `fdiml`.

Возвращает положительную разность `x - y` (или 0, если `x ≤ y`). Только для вещественных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    printf("fdim(5, 3) = %.1f\n", tgfdim(5.0, 3.0));
    printf("fdim(3, 5) = %.1f\n", tgfdim(3.0, 5.0));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Первый аргумент. Конечное значение. |
| `y` | Второй аргумент. Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | `max(x - y, 0)` |
| `double` | `max(x - y, 0)` |
| `long double` | `max(x - y, 0)` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргументов | Только для вещественных типов |
| — | Простая операция — `fmax(x - y, 0)` эквивалентна |
