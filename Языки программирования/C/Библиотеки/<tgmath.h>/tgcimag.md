## Определение

```c
#include <tgmath.h>

#define tgcimag(x) /* обобщённый макрос */
```

## Описание

Макрос `tgcimag` — обобщённая версия извлечения мнимой части. Автоматически выбирает `cimagf`, `cimag` или `cimagl`.

Возвращает мнимую часть комплексного числа. Только для комплексных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double _Complex z = 3.0 + 4.0 * I;
    printf("Im(3+4i) = %.1f\n", tgcimag(z));

    return 0;
}
```

## Обработка ошибок

- Если `x` — бесконечность, результат — бесконечность.
- Если `x` — `NaN`, результат — `NaN`.
- Поведение не определено для нечисловых аргументов (кроме `NaN`).
- Потокобезопасность: безопасен (нет разделяемых данных).
