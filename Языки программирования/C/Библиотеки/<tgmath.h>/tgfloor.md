## Определение

```c
#include <tgmath.h>

#define tgfloor(x) /* обобщённый макрос */
```

## Описание

Макрос `tgfloor` — обобщённая версия округления вниз. Автоматически выбирает `floorf`, `floor` или `floorl` в зависимости от типа аргумента.

Округляет `x` к ближайшему целому числу, не большему `x`. Только для вещественных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    printf("floor(2.7) = %.1f\n", tgfloor(2.7));
    printf("floor(-2.7) = %.1f\n", tgfloor(-2.7));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | Ближайшее целое `≤ x` |
| `double` | Ближайшее целое `≤ x` |
| `long double` | Ближайшее целое `≤ x` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Только для вещественных типов |
| — | Результат может не помещаться в `int` |

## Обработка ошибок

- Для `±∞` результат — `±∞`.
- Для `NaN` результат — `NaN`.
- Результат может не помещаться в `int` — поведение не определено в этом случае.
- Поведение не определено для нечисловых аргументов (кроме `NaN`).
- Потокобезопасность: безопасен (нет разделяемых данных).
