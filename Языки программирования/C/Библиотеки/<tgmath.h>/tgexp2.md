## Определение

```c
#include <tgmath.h>

#define tgexp2(x) /* обобщённый макрос */
```

## Описание

Макрос `tgexp2` — обобщённая версия экспоненты по основанию 2. Автоматически выбирает функцию `exp2f`, `exp2` или `exp2l` в зависимости от типа аргумента `x`.

Вычисляет `2^x`. Только для вещественных типов (комплексные версии отсутствуют).

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 10.0;
    printf("exp2(%.1f) = %.1f\n", x, tgexp2(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Показатель степени. Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | `2^x` |
| `double` | `2^x` |
| `long double` | `2^x` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Только для вещественных типов |
| Может быть быстрее, чем `pow(2, x)` | Переполнение для больших `x` |
