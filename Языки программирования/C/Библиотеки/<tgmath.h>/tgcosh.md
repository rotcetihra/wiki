## Определение

```c
#include <tgmath.h>

#define tgcosh(x) /* обобщённый макрос */
```

## Описание

Макрос `tgcosh` — обобщённая версия гиперболического косинуса. Автоматически выбирает функцию `coshf`, `cosh`, `coshl`, `ccoshf`, `ccosh` или `ccoshl` в зависимости от типа аргумента `x`.

Гиперболический косинус определяется как `cosh(x) = (e^x + e^(-x)) / 2`. Результат всегда ≥ 1 для вещественных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 1.0;
    printf("cosh(%.1f) = %.4f\n", x, tgcosh(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Аргумент. Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | `cosh(x) ≥ 1` |
| Комплексный | Комплексный гиперболический косинус |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Не replacement для `cosh` при работе только с `double` |
| Работает с вещественными и комплексными типами | Для нечисловых аргументов поведение не определено |

## Обработка ошибок

- Переполнение при вычислении для очень больших значений (|x| > ~710) — результат `+HUGE_VAL`, `errno` может быть установлена в `ERANGE`.
- Если `x` — комплексное число с бесконечной или нечисловой мнимой частью, результат — `NaN + i*NaN`.
- Поведение не определено для нечисловых аргументов (кроме `NaN`).
- Потокобезопасность: безопасен (нет разделяемых данных).
