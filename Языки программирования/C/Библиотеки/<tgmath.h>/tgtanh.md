## Определение

```c
#include <tgmath.h>

#define tgtanh(x) /* обобщённый макрос */
```

## Описание

Макрос `tgtanh` — обобщённая версия гиперболического тангенса. Автоматически выбирает функцию `tanhf`, `tanh`, `tanhl`, `ctanhf`, `ctanh` или `ctanhl` в зависимости от типа аргумента `x`.

Гиперболический тангенс определяется как `tanh(x) = sinh(x) / cosh(x)`. Результат всегда лежит в диапазоне `(-1, +1)`.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 1.0;
    printf("tanh(%.1f) = %.4f\n", x, tgtanh(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Аргумент. Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | `tanh(x)`, `(-1, +1)` |
| Комплексный | Комплексный гиперболический тангенс |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Не replacement для `tanh` при работе только с `double` |
| Работает с вещественными и комплексными типами | Для нечисловых аргументов поведение не определено |

## Обработка ошибок

- Если `x` — комплексное число с бесконечной или нечисловой мнимой частью, результат — `NaN + i*NaN`.
- Результат всегда лежит в диапазоне `(-1, +1)` для вещественных типов, переполнения не происходит.
- Поведение не определено для нечисловых аргументов (кроме `NaN`).
- Потокобезопасность: безопасен (нет разделяемых данных).
