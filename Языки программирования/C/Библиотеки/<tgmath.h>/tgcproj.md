## Определение

```c
#include <tgmath.h>

#define tgcproj(x) /* обобщённый макрос */
```

## Описание

Макрос `tgcproj` — обобщённая версия стереографического проецирования. Автоматически выбирает `cprojf`, `cproj` или `cprojl`.

Вычисляет стереографическое проецирование комплексного числа на сферу Римана. Для конечных значений результат совпадает с аргументом. Для бесконечных значений возвращает «бесконечную точку» с аргументом 0 или ±π. Только для комплексных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double _Complex z = 3.0 + 4.0 * I;
    double _Complex p = tgcproj(z);
    printf("proj(3+4i) = %.1f%+.1fi\n", creal(p), cimag(p));

    return 0;
}
```

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу | Только для комплексных типов |
| Определяет поведение для бесконечностей | Для конечных значений — тривиальная операция |
