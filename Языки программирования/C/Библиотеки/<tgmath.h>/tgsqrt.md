## Определение

```c
#include <tgmath.h>

#define tgsqrt(x) /* обобщённый макрос */
```

## Описание

Макрос `tgsqrt` — обобщённая версия квадратного корня. Автоматически выбирает функцию `sqrtf`, `sqrt`, `sqrtl`, `csqrtf`, `csqrt` или `csqrtl` в зависимости от типа аргумента `x`.

Квадратный корень возвращает неотрицательное значение `y`, такое что `y² = x`. Аргумент `x` должен быть `≥ 0` для вещественных типов (для комплексных — любое значение).

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 16.0;
    printf("sqrt(%.1f) = %.4f\n", x, tgsqrt(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | `≥ 0` для вещественных типов; любое для комплексных. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | `√x ≥ 0` |
| Комплексный | Основной корень |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Для отрицательных вещественных — ошибка домена |
| Работает с вещественными и комплексными типами | Для нечисловых аргументов поведение не определено |
