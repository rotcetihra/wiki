## Определение

```c
#include <tgmath.h>

#define tgcbrt(x) /* обобщённый макрос */
```

## Описание

Макрос `tgcbrt` — обобщённая версия кубического корня. Автоматически выбирает функцию `cbrtf`, `cbrt` или `cbrtl` в зависимости от типа аргумента `x`.

Кубический корень возвращает значение `y`, такое что `y³ = x`. Аргумент `x` может быть любым конечным вещественным числом (включая отрицательные).

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 27.0;
    printf("cbrt(%.1f) = %.4f\n", x, tgcbrt(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Любое конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | `³√x` |
| `double` | `³√x` |
| `long double` | `³√x` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Только для вещественных типов |
| Работает с отрицательными числами | Для нечисловых аргументов поведение не определено |
