## Определение

```c
#include <tgmath.h>

#define tgexp(x) /* обобщённый макрос */
```

## Описание

Макрос `tgexp` — обобщённая версия экспоненты. Автоматически выбирает функцию `expf`, `exp`, `expl`, `cexpf`, `cexp` или `cexpl` в зависимости от типа аргумента `x`.

Экспонента вычисляет `e^x`, где `e` — основание натурального логарифма (≈ 2.71828).

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 1.0;
    printf("exp(%.1f) = %.4f\n", x, tgexp(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Показатель степени. Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | `e^x` |
| Комплексный | `e^z` (комплексная экспонента) |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Может переполниться для больших `x` |
| Работает с вещественными и комплексными типами | Для нечисловых аргументов поведение не определено |

## Обработка ошибок

- Переполнение при вычислении для очень больших значений (x > ~709) — результат `+HUGE_VAL`, `errno` может быть установлена в `ERANGE`.
- Недополнение для очень малых отрицательных значений (x < ~-745) — результат `+0`, `errno` может быть установлена в `ERANGE`.
- Если `x` — комплексное число с нечисловой мнимой частью, результат — `NaN + i*NaN`.
- Поведение не определено для нечисловых аргументов (кроме `NaN`).
- Потокобезопасность: безопасен (нет разделяемых данных).
