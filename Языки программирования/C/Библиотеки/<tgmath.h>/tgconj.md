## Определение

```c
#include <tgmath.h>

#define tgconj(x) /* обобщённый макрос */
```

## Описание

Макрос `tgconj` — обобщённая версия комплексного сопряжения. Автоматически выбирает `conjf`, `conj` или `conjl`.

Возвращает комплексное сопряжение: для `z = a + bi` результат `a - bi`. Только для комплексных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double _Complex z = 3.0 + 4.0 * I;
    double _Complex c = tgconj(z);
    printf("conj(3+4i) = %.1f%+.1fi\n", creal(c), cimag(c));

    return 0;
}
```
