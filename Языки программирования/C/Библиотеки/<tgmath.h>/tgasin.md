## Определение

```c
#include <tgmath.h>

#define tgasin(x) /* обобщённый макрос */
```

## Описание

Макрос `tgasin` — обобщённая версия арксинуса. На основе типа аргумента `x` автоматически выбирается соответствующая функция:

| Тип аргумента | Вызываемая функция |
|---|---|
| `float` | `asinf` |
| `double` | `asin` |
| `long double` | `asinl` |
| `float _Complex` | `casinf` |
| `double _Complex` | `casin` |
| `long double _Complex` | `casinl` |

Арксинус возвращает угол в радианах из диапазона `[-π/2, π/2]`, синус которого равен `x`. Аргумент `x` должен принадлежать диапазону `[-1, +1]`.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 0.5;
    printf("asin(%.1f) = %.4f\n", x, tgasin(x));

    float xf = 0.5f;
    printf("asinf(%.1f) = %.4f\n", xf, tgasin(xf));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Значение, синус которого ищется. Для вещественных типов: `[-1, +1]`. Для комплексных: любое. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | Угол в радианах `[-π/2, π/2]` |
| Комплексный | Комплексный угол, синус которого равен `x` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Не replacement для `asin` при работе только с `double` |
| Работает с вещественными и комплексными типами | Для нечисловых аргументов поведение не определено |
| Упрощает написание обобщённого кода | Нет явного контроля над типом результата |

## Обработка ошибок

- Если `|x| > 1` для вещественного типа, результат не определён (сбой домена).
- Если `x` — комплексное число, домен не ограничен.
- Если `x` — бесконечность, результат — `NaN`.
- Поведение не определено для нечисловых аргументов (кроме `NaN`).
- Потокобезопасность: безопасен (нет разделяемых данных).
