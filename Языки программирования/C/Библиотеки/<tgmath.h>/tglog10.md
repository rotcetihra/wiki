## Определение

```c
#include <tgmath.h>

#define tglog10(x) /* обобщённый макрос */
```

## Описание

Макрос `tglog10` — обобщённая версия десятичного логарифма. Автоматически выбирает функцию `log10f`, `log10` или `log10l` в зависимости от типа аргумента `x`.

Вычисляет `log₁₀(x)` — логарифм по основанию 10. Только для вещественных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 100.0;
    printf("log10(%.1f) = %.1f\n", x, tglog10(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Положительное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | `log₁₀(x)` |
| `double` | `log₁₀(x)` |
| `long double` | `log₁₀(x)` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Только для вещественных типов |
| Аргумент `x ≤ 0` приводит к ошибке | Для нечисловых аргументов поведение не определено |

## Обработка ошибок

- Если `x ≤ 0`, результат не определён (может быть `NaN` или сбой домена).
- Поведение не определено для нечисловых аргументов (кроме `NaN`).
- Потокобезопасность: безопасен (нет разделяемых данных).
