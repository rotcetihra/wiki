## Определение

```c
#include <tgmath.h>

#define tghypot(x, y) /* обобщённый макрос */
```

## Описание

Макрос `tghypot` — обобщённая версия гипотенузы. Автоматически выбирает функцию `hypotf`, `hypot` или `hypotl` в зависимости от типа аргументов.

Вычисляет `√(x² + y²)` без промежуточного переполнения. Только для вещественных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    printf("hypot(3, 4) = %.1f\n", tghypot(3.0, 4.0));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Катет. Конечное значение. |
| `y` | Катет. Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | `√(x² + y²)` |
| `double` | `√(x² + y²)` |
| `long double` | `√(x² + y²)` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Без промежуточного переполнения | Только для вещественных типов |
