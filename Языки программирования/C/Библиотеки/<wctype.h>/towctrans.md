## Определение

```c
#include <wctype.h>

wint_t towctrans(wint_t wc, wctrans_t desc);
```

## Описание

Преобразует широкий символ `wc` в соответствии с описателем `desc`, полученным функцией `wctrans()`.

Описатель `desc` не должен быть равен `0`. Аргумент `wc` не должен равняться `WEOF`.

Пара функций `wctrans()` + `towctrans()` позволяет преобразовывать символ по имени преобразования, переданному строкой. Стандартные значения: `"tolower"` и `"toupper"`.

Если для символа преобразование не предусмотрено, возвращает `wc` без изменений.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wctrans_t to_lower = wctrans("tolower");
    wctrans_t to_upper = wctrans("toupper");

    if (to_lower && to_upper) {
        wint_t ch = L'Я';
        printf("'%lc' →tolower→ '%lc'\n", (wint_t)ch, towctrans(ch, to_lower));
        printf("'%lc' →toupper→ '%lc'\n", (wint_t)ch, towctrans(ch, to_upper));
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет преобразовывать по строковому имени | Только два стандартных преобразования: `tolower` и `toupper` |
| Кешированный описатель ускоряет повторные вызовы | Не поддерживает пользовательские преобразования |
| Альтернатива прямым вызовам `towlower()`/`towupper()` | Менее читаема, чем прямые функции |
