## Определение

```c
#include <wctype.h>

int iswdigit(wint_t wc);
```

## Описание

Проверяет, является ли широкий символ `wc` десятичной цифрой: `L'0'`–`L'9'`. Широкая версия функции `isdigit()` из `<ctype.h>`.

В отличие от `iswxdigit()`, эта функция не распознаёт буквы `a–f` / `A–F` как шестнадцатеричные цифры.

Аргумент `wc` должен быть представим как `wint_t` и не должен равняться `WEOF`.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wint_t chars[] = {L'0', L'9', L'A', L' '};
    size_t n = sizeof(chars) / sizeof(chars[0]);

    for (size_t i = 0; i < n; i++)
        printf("iswdigit(L'%lc') = %d\n", (wint_t)chars[i], iswdigit(chars[i]));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная и портируемая | Работает с одним символом |
| Простая и быстрая проверка | Не отличает цифру от символа схожего начертания (например, `L'٣'`) |
