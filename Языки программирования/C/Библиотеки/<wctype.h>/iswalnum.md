## Определение

```c
#include <wctype.h>

int iswalnum(wint_t wc);
```

## Описание

Проверяет, является ли широкий символ `wc` буквой или цифрой. Широкая версия функции `iswalnum()` из `<ctype.h>`.

Аргумент `wc` должен быть представим как `wint_t` и не должен равняться `WEOF` — передача `WEOF` приводит к неопределённому поведению. В отличие от `iswalnum()` для `unsigned char`, здесь обрабатывается весь диапазон `wchar_t`.

Функция доступна как функция, так и макрос. Макрос может вычислить аргумент несколько раз.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wint_t chars[] = {L'A', L'z', L'5', L' ', L'Я', L'д'};
    size_t n = sizeof(chars) / sizeof(chars[0]);

    for (size_t i = 0; i < n; i++)
        printf("iswalnum(L'%lc') = %d\n", (wint_t)chars[i], iswalnum(chars[i]));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная и портируемая | Работает с одним символом |
| Поддерживает символы за пределами ASCII | Не определяет, является ли символ буквой или цифрой отдельно |
| Доступна как функция и как макрос | Результат зависит от текущей локали |
