## Определение

```c
#include <wctype.h>

wctype_t wctype(const char *property);
```

## Описание

Возвращает описатель классификации `wctype_t` для категории символов, заданной строкой `property`. Полученный описатель используется в функции `iswctype()`.

Стандартные значения `property`: `"alnum"`, `"alpha"`, `"blank"`, `"cntrl"`, `"digit"`, `"graph"`, `"lower"`, `"print"`, `"punct"`, `"space"`, `"upper"`, `"xdigit"`. Реализация может поддерживать дополнительные имена.

Если `property` не соответствует ни одной категории, возвращается `0`.

> [!NOTE]
> Функция `wctype()` является расширением C99/POSIX, а не частью стандарта C89. В ISO C23 она включена в стандарт.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    const char *categories[] = {"alpha", "digit", "space", "punct", "invalid"};
    size_t n = sizeof(categories) / sizeof(categories[0]);

    for (size_t i = 0; i < n; i++) {
        wctype_t desc = wctype(categories[i]);
        printf("wctype(\"%s\") = %s\n", categories[i], desc ? "ok" : "0");
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет классифицировать символы по строковому имени | Все стандартные имена фиксированы, расширения зависят от реализации |
| Кешированный описатель ускоряет повторную классификацию | Возвращает `0` при неизвестном имени — нет способа отличить «нет» от «ошибка» |
| Полезна для универсальных фильтров символов | Менее читаема, чем прямые функции `isw*()` |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** `0` (некорректный дескриптор), если категория не распознана.
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `property`.
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние).
