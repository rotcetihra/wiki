## Определение

```c
#include <wctype.h>

int iswupper(wint_t wc);
```

## Описание

Проверяет, является ли широкий символ `wc` заглавной (большой) буквой. Широкая версия функции `isupper()` из `<ctype.h>`.

В локали `C` верно следующее: только латинские буквы `A–Z`. В локалях с расширенными алфавитами — также заглавные буквы национальных алфавитов.

Аргумент `wc` должен быть представим как `wint_t` и не должен равняться `WEOF`.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wint_t chars[] = {L'A', L'Z', L'a', L'Я'};
    size_t n = sizeof(chars) / sizeof(chars[0]);

    for (size_t i = 0; i < n; i++)
        printf("iswupper(L'%lc') = %d\n", (wint_t)chars[i], iswupper(chars[i]));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная и портируемая | Работает с одним символом |
| Поддерживает полный набор символов `wchar_t` | Зависит от локали |
| Используется совместно с `towupper()` | Не различает тип символа (буква или нет) |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (возвращает ненулевое значение, если символ является заглавной буквой, иначе 0).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** не применимо (аргумент — целое число, не указатель).
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние).
