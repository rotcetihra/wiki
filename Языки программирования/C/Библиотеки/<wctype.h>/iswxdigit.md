## Определение

```c
#include <wctype.h>

int iswxdigit(wint_t wc);
```

## Описание

Проверяет, является ли широкий символ `wc` шестнадцатеричной цифрой: `L'0'`–`L'9'`, `L'a'`–`L'f'` или `L'A'`–`L'F'`. Широкая версия функции `isxdigit()` из `<ctype.h>`.

Аргумент `wc` должен быть представим как `wint_t` и не должен равняться `WEOF`.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wint_t chars[] = {L'0', L'9', L'A', L'f', L'G', L' '};
    size_t n = sizeof(chars) / sizeof(chars[0]);

    for (size_t i = 0; i < n; i++)
        printf("iswxdigit(L'%lc') = %d\n", (wint_t)chars[i], iswxdigit(chars[i]));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная и портируемая | Работает с одним символом |
| Поддерживает символы за пределами ASCII | Не различает десятичные и шестнадцатеричные цифры отдельно |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (возвращает ненулевое значение, если символ является шестнадцатеричной цифрой, иначе 0).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** не применимо (аргумент — целое число, не указатель).
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние).
