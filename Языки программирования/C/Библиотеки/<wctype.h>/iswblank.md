## Определение

```c
#include <wctype.h>

int iswblank(wint_t wc);
```

## Описание

Проверяет, является ли широкий символ `wc` символом пробела: стандартным пробелом (`L' '`) или горизонтальной табуляцией (`L'\t'`). Широкая версия функции `isblank()` из `<ctype.h>`.

> [!NOTE]
> Функция `iswblank()` является расширением POSIX, а не частью стандарта C. В ISO C23 аналогичная проверка отсутствует; для проверки пробельных символов в стандартном C используется `iswspace()`.

Аргумент `wc` должен быть представим как `wint_t` и не должен равняться `WEOF`.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wint_t chars[] = {L' ', L'\t', L'\n', L'A'};
    size_t n = sizeof(chars) / sizeof(chars[0]);

    for (size_t i = 0; i < n; i++)
        printf("iswblank(L'...') = %d\n", iswblank(chars[i]));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Узкая проверка: только пробел и табуляция | Расширение POSIX, не в ISO C |
| Поддерживает широкие символы | Работает с одним символом |
