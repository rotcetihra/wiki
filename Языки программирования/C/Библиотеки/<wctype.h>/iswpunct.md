## Определение

```c
#include <wctype.h>

int iswpunct(wint_t wc);
```

## Описание

Проверяет, является ли широкий символ `wc` знаком пунктуации. Широкая версия функции `ispunct()` из `<ctype.h>`.

В локали `C` знаками пунктуации считаются символы `!`, `"`, `#`, `$`, `%`, `&`, `'`, `(`, `)`, `*`, `+`, `,`, `-`, `.`, `/`, `:`, `;`, `<`, `=`, `>`, `?`, `@`, `[`, `\`, `]`, `^`, `_`, `` ` ``, `{`, `|`, `}`, `~`. В расширенных локалях — также символы национальной пунктуации.

Аргумент `wc` должен быть представим как `wint_t` и не должен равняться `WEOF`.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wint_t chars[] = {L'.', L',', L'A', L'5'};
    size_t n = sizeof(chars) / sizeof(chars[0]);

    for (size_t i = 0; i < n; i++)
        printf("iswpunct(L'%lc') = %d\n", (wint_t)chars[i], iswpunct(chars[i]));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная и портируемая | Работает с одним символом |
| Поддерживает символы за пределами ASCII | Набор символов зависит от локали |
| Не включает буквы и цифры | Не区分ает тип пунктуации |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (возвращает ненулевое значение, если символ является знаком пунктуации, иначе 0).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** не применимо (аргумент — целое число, не указатель).
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние).
