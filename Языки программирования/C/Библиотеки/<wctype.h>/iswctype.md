## Определение

```c
#include <wctype.h>

int iswctype(wint_t wc, wctype_t desc);
```

## Описание

Классифицирует широкий символ `wc` по описателю `desc`, полученному функцией `wctype()`. Возвращает ненулевое значение, если символ принадлежит указанной категории.

Описатель `desc` не должен быть равен `0`. Аргумент `wc` не должен равняться `WEOF`.

Пара функций `wctype()` + `iswctype()` позволяет классифицировать символ по имени категории, переданному строкой, без необходимости перебора всех функций `isw*()`.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wctype_t desc_alpha = wctype("alpha");
    wctype_t desc_digit = wctype("digit");

    if (desc_alpha && desc_digit) {
        wint_t ch = L'Я';
        printf("iswctype(L'%lc', alpha) = %d\n", (wint_t)ch, iswctype(ch, desc_alpha));
        printf("iswctype(L'7', digit) = %d\n", iswctype(L'7', desc_digit));
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет классифицировать по имени категории из строки | Требует предварительного вызова `wctype()` |
| Одна функция вместо 12 функций `isw*()` | Менее читаема, чем прямой вызов `iswalpha()` и т. п. |
| Полезна при обработке пользовательских фильтров | Не все категории гарантированно поддерживаются реализацией |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (возвращает ненулевое значение, если символ принадлежит категории, иначе 0).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** не применимо (аргументы — целые числа, не указатели).
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние).
