## Определение

```c
#include <wctype.h>

int iswalpha(wint_t wc);
```

## Описание

Проверяет, является ли широкий символ `wc` буквой. Широкая версия функции `isalpha()` из `<ctype.h>`.

В локали `C` верно следующее: только латинские буквы `A–Z` и `a–z`. В локалях с расширенными алфавитами — также буквы национальных алфавитов (например, кириллица, греческие, японские иероглифы и т. д.).

Аргумент `wc` должен быть представим как `wint_t` и не должен равняться `WEOF`.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wint_t chars[] = {L'A', L'я', L'5', L' ', L'日'};
    size_t n = sizeof(chars) / sizeof(chars[0]);

    for (size_t i = 0; i < n; i++)
        printf("iswalpha(L'%lc') = %d\n", (wint_t)chars[i], iswalpha(chars[i]));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная и портируемая | Работает с одним символом |
| Поддерживает полный набор символов `wchar_t` | Не различает регистр буквы |
| Зависит от локали, а не от языка программы | Результат зависит от текущей локали |
