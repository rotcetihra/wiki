## Определение

```c
#include <errno.h>

#define EPROTOTYPE 91 // "Protocol wrong type for socket"
```

## Описание

«Протокол не подходит типу сокета»: тип сокета (`SOCK_STREAM`/`SOCK_DGRAM`/...) несовместим с выбранным протоколом. POSIX (XSI).

## Когда возникает

- `socket()` с типом и протоколом, которые не сочетаются (например, `SOCK_STREAM` с UDP-протоколом «0» для некоторых семейств);
- попытка использовать потоковый протокол в дейтаграммном сокете.

## Похожие коды

- `EPROTONOSUPPORT` — протокол не поддерживается
- `ESOCKTNOSUPPORT` — тип сокета не поддерживается
- `EINVAL` — неверный аргумент
