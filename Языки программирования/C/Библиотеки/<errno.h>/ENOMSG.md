## Определение

```c
#include <errno.h>

#define ENOMSG 42 // "No message of desired type"
```

## Описание

«Нет сообщения нужного типа». POSIX (XSI). Возвращается очередями сообщений System V, когда запрошенное сообщение отсутствует.

## Когда возникает

- `msgrcv()` с флагом `IPC_NOWAIT` — в очереди нет сообщения нужного типа (без блокировки);
- `msgrcv()` с типом, которого нет, и долгим ожиданием — очередь пуста.

## Похожие коды

- `EIDRM` — очередь удалена во время ожидания
- `EAGAIN` — очередь полна (msgsnd с IPC_NOWAIT)
