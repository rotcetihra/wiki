## Определение

```c
#include <errno.h>

#define ERANGE 34 // "Math result not representable"
```

## Описание

«Результат не представим» — один из трёх кодов стандарта C (наряду с `EDOM` и `EILSEQ`). Стандарт требует положительное значение, определяемое реализацией (Linux: 34). Устанавливается математическими и строковыми функциями при переполнении результата или его недостаточной точности.

## Когда возникает

- `<math.h>`: `exp()`, `log()`, `hypot()` и др. — результат вне диапазона `double` (возврат `±HUGE_VAL`);
- `strtol()`/`strtod()` и аналоги — число вне диапазона типа (возврат `LONG_MAX`/`±HUGE_VAL` и т. п.);
- переполнение при преобразованиях чисел.

## Похожие коды

- `EDOM` — аргумент вне области определения
- `EOVERFLOW` — значение не помещается в тип (системные вызовы)
