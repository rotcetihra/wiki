## Определение

```c
#include <errno.h>

#define EPROTO 71 // "Protocol error"
```

## Описание

«Ошибка протокола»: нарушение протокола связи (неверные данные/состояние на транспортном уровне). POSIX (XSI); в glibc иногда возвращается как общий код сетевых ошибок.

## Когда возникает

- сброс или некорректные пакеты TCP/IP;
- USB-устройства при нарушении протокола;
- `getsockopt()`/операции, когда стек сообщает об ошибке протокола.

## Похожие коды

- `EPROTOTYPE` — протокол не подходит типу сокета
- `EBADMSG` — повреждённые данные
- `ECOMM` — ошибка передачи

## Источники

- POSIX.1-2024, раздел `errno.h`
