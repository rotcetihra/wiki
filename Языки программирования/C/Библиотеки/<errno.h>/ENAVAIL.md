## Определение

```c
#include <errno.h>

#define ENAVAIL 119 // "No XENIX semaphores available"
```

## Описание

«Нет доступных XENIX-семафоров» — исторический код XENIX. На Linux существует для совместимости, не используется. Не входит в POSIX.

## Когда возникает

- исторически — XENIX: исчерпан лимит семафоров; на современных Linux не возникает.

## Похожие коды

- `ENOTNAM` — не файл именованного типа (XENIX)
- `EISNAM` — файл именованного типа (XENIX)
