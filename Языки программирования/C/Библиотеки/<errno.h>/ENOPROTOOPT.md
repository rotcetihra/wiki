## Определение

```c
#include <errno.h>

#define ENOPROTOOPT 92 // "Protocol not available"
```

## Описание

«Протокол недоступен»: запрошенный параметр протокола не существует или не поддерживается. POSIX (XSI). Частая ошибка при `setsockopt()`/`getsockopt()` с неизвестной опцией.

## Когда возникает

- `getsockopt()`/`setsockopt()` с неизвестным уровнем/опцией;
- запрос опции, недоступной для данного протокола.

## Похожие коды

- `EPROTONOSUPPORT` — протокол не поддерживается
- `EOPNOTSUPP` — операция не поддерживается
- `EINVAL` — неверные аргументы опции

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno.h`, man-страница `setsockopt(2)`
