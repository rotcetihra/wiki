## Определение

```c
#include <errno.h>

#define EBADMSG 74 // "Not a data message"
```

## Описание

«Не сообщение с данными»: полученное сообщение не того типа, что ожидалось. Входит в POSIX (XSI) как код для механизма сообщений (STREAMS); на Linux используется, например, при чтении повреждённых данных на файловых системах (ext4) и в `recvmsg()` с аномальным пакетом. Определён в POSIX.

## Когда возникает

- `recvmsg()`/`read()` на сокете — получен пакет, не соответствующий ожидаемому формату;
- повреждённая структура на диске (ext4 → «not a data message»).

## Похожие коды

- `ECOMM` — ошибка при передаче сообщения
- `EPROTO` — ошибка протокола
- `EMSGSIZE` — сообщение слишком длинное
