## Определение

```c
#include <errno.h>

#define EOPNOTSUPP 95 // "Operation not supported on transport endpoint"
```

## Описание

«Операция не поддерживается»: сокет/объект существует, но операция для него не реализована (в отличие от `ENOSYS` — «системный вызов не реализован»). POSIX (XSI). В glibc `ENOTSUP` — синоним.

## Когда возникает

- сокетные опции, не поддерживаемые протоколом (`SO_BINDTODEVICE` на не-сокете и т. п.);
- `fallocate()`/`ftruncate()` на ФС без поддержки;
- `mmap()` на объектах без mmap-поддержки.

## Похожие коды

- `ENOTSUP` — синоним в glibc
- `ENOSYS` — функция не реализована
- `EPROTONOSUPPORT` — протокол не поддерживается

## Источники

- POSIX.1-2024, раздел `errno.h`
