## Определение

```c
#include <errno.h>

#define EROFS 30 // "Read-only file system"
```

## Описание

«Файловая система только для чтения»: попытка изменения на смонтированной в режиме `ro` ФС. POSIX-код.

## Когда возникает

- `open(O_WRONLY|O_CREAT)`/`write()`/`truncate()`/`mkdir()`/`unlink()` на read-only точках монтирования;
- перезапись файлов на смонтированных `ro` разделах (например, `/` в live-системах, CD-ROM).

## Похожие коды

- `EACCES` — нет прав (но ФС разрешает запись)
- `EPERM` — привилегии
- `EBUSY` — ресурс занят

## Источники
