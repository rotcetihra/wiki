## Определение

```c
#include <errno.h>

#define ELIBSCN 81 // ".lib section in a.out corrupted"
```

## Описание

«Раздел .lib в a.out повреждён» — код для старых форматов a.out, где таблица разделяемых библиотек хранилась в разделе `.lib`. Linux-специфичный, исторический.

## Когда возникает

- исторически — загрузка a.out-файла с повреждённым разделом `.lib`; на современных ELF-системах не возникает.

## Похожие коды

- `ELIBBAD` — повреждённая библиотека
- `ELIBACC` — доступ запрещён
