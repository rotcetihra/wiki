## Определение

```c
#include <errno.h>

#define ENOTDIR 20 // "Not a directory"
```

## Описание

«Не каталог»: компонента пути, которая должна быть каталогом, не является им. POSIX-код.

## Когда возникает

- `chdir()`/`stat()`/`open()` на путь, где промежуточная компонента — обычный файл;
- `rename()`/`mkdir()` с компонентой-файлом;
- `readdir()` на дескрипторе не каталога.

## Похожие коды

- `ENOENT` — компонента пути отсутствует
- `EISDIR` — операция неприменима к каталогу
- `EACCES` — нет прав на компоненту
