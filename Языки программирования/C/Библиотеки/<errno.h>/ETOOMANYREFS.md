## Определение

```c
#include <errno.h>

#define ETOOMANYREFS 109 // "Too many references: cannot splice"
```

## Описание

«Слишком много ссылок: невозможно splice» — исторический сокетный код (когда сокет нельзя преобразовать/перехватить из-за множества ссылок, например, при захвате сокета после `fork`-сценариев). POSIX (XSI). Практически не возникает на современных Linux.

## Когда возникает

- исторически — передача сокетов между процессами при переполнении таблицы ссылок; на современных Linux не встречается.

## Похожие коды

- `EMFILE`/`ENFILE` — исчерпание таблицы дескрипторов
- `EBUSY` — ресурс занят

## Источники
