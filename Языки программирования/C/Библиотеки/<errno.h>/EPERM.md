## Определение

```c
#include <errno.h>

#define EPERM 1 // "Operation not permitted"
```

## Описание

«Операция не разрешена»: процесс не имеет привилегий (root, capabilities) для операции, либо операция запрещена свойствами объекта. POSIX-код. Отличие от `EACCES`: `EPERM` — не хватает привилегий/полномочий уровня ядра, `EACCES` — не хватает прав доступа по битам режима файла.

## Когда возникает

- системные вызовы, требующие root или `CAP_*` (например, `mount()`, `chroot()`, `setuid()`, `kill()` чужого процесса);
- удаление файла из каталога с липким битом (`sticky bit`) чужим пользователем;
- операции с невозможными для процесса действиями над файлами (например, `chmod` на чужих ФС без прав).

## Похожие коды

- `EACCES` — отказ в доступе (права файла)
- `EROFS` — ФС только для чтения
- `EPERM` также возвращается при попытке `ptrace` не-родительского процесса
