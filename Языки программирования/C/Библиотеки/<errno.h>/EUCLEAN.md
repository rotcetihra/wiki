## Определение

```c
#include <errno.h>

#define EUCLEAN 117 // "Structure needs cleaning"
```

## Описание

«Структура требует очистки»: файловая система (или драйвер) обнаружила, что структуры данных нуждаются в восстановлении/чистке (например, ФС в состоянии после сбоя, для которой требуется fsck). Linux-специфичный код.

## Когда возникает

- операции с ФС, помеченной как требующей проверки (ext4 после сбоя при монтировании без журнала);
- драйверы, сообщающие о необходимости очистки.

## Похожие коды

- `EIO` — ошибка ввода-вывода
- `EBADMSG` — повреждённые данные на ФС
