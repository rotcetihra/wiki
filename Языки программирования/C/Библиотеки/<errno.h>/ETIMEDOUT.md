## Определение

```c
#include <errno.h>

#define ETIMEDOUT 110 // "Connection timed out"
```

## Описание

«Соединение прервано по таймауту»: ожидание ответа превысило лимит (обычно TCP-ретранисмиссии). POSIX (XSI). Отличается от `ETIME` (62, STREAMS).

## Когда возникает

- `connect()` — SYN не получил ответа (удалённый хост молчит: фильтры, egg-firewall);
- `send()`/`recv()` — соединение зависло, таймер истёк;
- `select()`/`poll()` — нет, там возврат по истечении в аргументах.

## Похожие коды

- `ECONNREFUSED` — активный отказ (RST)
- `EHOSTUNREACH` — хост недостижим (ICMP)
- `ETIME` — истёк таймер STREAMS (62)
