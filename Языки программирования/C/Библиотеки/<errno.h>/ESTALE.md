## Определение

```c
#include <errno.h>

#define ESTALE 116 // "Stale file handle"
```

## Описание

«Устаревший файловый дескриптор»: file handle, хранимый в структуре файла, более недействителен (файл удалён на сервере, сервер перезапущен, NFS-экспорт изменился). POSIX (XSI), также Linux-код для сетевых ФС.

## Когда возникает

- NFS/CIFS: операции с файлом после удаления на сервере (`unlink`), реэкспорта ФС или перезапуска сервера;
- `open()`/`stat()`/`read()` по устаревшему дескриптору, кешированному клиентом.

## Похожие коды

- `ENOENT` — файл не существует
- `EREMOTEIO` — ошибка удалённого ввода-вывода
- `EIO` — ошибка ввода-вывода

## Источники

- POSIX.1-2024, раздел `errno.h`
