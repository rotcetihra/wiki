## Определение

```c
#include <errno.h>

#define EOWNERDEAD 130 // "Owner died"
```

## Описание

«Владелец умер»: поток/процесс, владевший ресурсом (mutex, очередь POSIX), завершился, не освободив его. POSIX (XSI). Используется приоритетными блокировками `pthread_mutex` (`PTHREAD_MUTEX_ROBUST`): следующий поток должен восстановить состояние ресурса.

## Когда возникает

- `pthread_mutex_lock()` ROBUST-мутекса, чей владелец умер;
- `mq_open()`/очереди POSIX — повреждённый объект после смерти владельца.

## Похожие коды

- `ENOTRECOVERABLE` — состояние невосстановимо
- `EDEADLK` — взаимоблокировка
