## Определение

```c
#include <errno.h>

#define EAGAIN 11 // "Try again" (ядро), "Resource temporarily unavailable" (glibc)
```

## Описание

«Попробуйте позже»: ресурс временно недоступен, операцию можно повторить. Один из самых распространённых кодов. На Linux `EWOULDBLOCK` — синоним (`#define EWOULDBLOCK EAGAIN`). POSIX требует, чтобы оба имени имели одно значение. glibc выводит через `strerror()` текст «Resource temporarily unavailable».

## Когда возникает

- неблокирующий `read()`/`write()`/`accept()`/`connect()` — данные ещё не готовы;
- `fork()`: превышен лимит потоков/процессов или памяти (для `fork` — ошибочно);
- `open()` файла без `O_NONBLOCK` при отсутствии лимита? (см. `RLIMIT_NOFILE` — обычно `EMFILE`); типично: `sem_wait()` без блокировки;
- `malloc()`/`mmap()` при нехватке памяти (overcommit отключён) — встречается.

## Похожие коды

- `EWOULDBLOCK` — синоним на Linux (POSIX допускает отдельные значения)
- `ENOMEM` — нехватка памяти
- `EINTR` — прервано сигналом
