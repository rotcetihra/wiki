## Определение

```c
#include <errno.h>

#define EXDEV 18 // "Cross-device link"
```

## Описание

«Связь между устройствами»: операция `rename()`/`link()`, требующая, чтобы источник и назначение находились на одной ФС, выполнена между разными устройствами. POSIX-код. Классическая реакция — копирование с последующим удалением.

## Когда возникает

- `rename()` между разными точками монтирования;
- `link()` жёсткой ссылки между ФС (для `symlink()` не применимо — она просто создаёт файл).

## Похожие коды

- `ENOENT` — источник не существует
- `EEXIST` — назначение существует (в части случаев)
- `EPERM` — нет прав
