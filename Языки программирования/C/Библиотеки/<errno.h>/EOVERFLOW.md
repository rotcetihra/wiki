## Определение

```c
#include <errno.h>

#define EOVERFLOW 75 // "Value too large for defined data type"
```

## Описание

«Значение слишком велико для данного типа данных»: результат не помещается в тип (например, 64-битное значение в 32-битное поле). POSIX (XSI). Связан с арифметикой типов и переполнением.

## Когда возникает

- `lseek()`/`ftruncate()` — смещение не помещается в `off_t` (на 32-битных платформах с большими файлами);
- `stat()` через 32-битные структуры для больших файлов;
- `calloc()` (glibc) — переполнение `nmemb × size` → `EOVERFLOW` (или `ENOMEM` в разных версиях);
- `strtoll()` при превышении диапазона типа — нет, там `ERANGE`; `EOVERFLOW` — в основном системные вызовы.

## Похожие коды

- `ERANGE` — результат вне диапазона (математика)
- `EFBIG` — файл слишком большой
