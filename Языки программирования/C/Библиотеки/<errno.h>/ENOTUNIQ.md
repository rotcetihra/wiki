## Определение

```c
#include <errno.h>

#define ENOTUNIQ 76 // "Name not unique on network"
```

## Описание

«Имя не уникально в сети» — исторический код RFS: имя сетевой записи не уникально. На Linux существует для совместимости, не используется. Не входит в POSIX.

## Когда возникает

- исторически — RFS: совпадающие сетевые имена; на современных Linux не возникает.

## Похожие коды

- `ENONET` — узел не в сети (RFS)
- `EREMOTE` — объект удалённый
