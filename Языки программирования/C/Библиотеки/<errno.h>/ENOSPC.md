## Определение

```c
#include <errno.h>

#define ENOSPC 28 // "No space left on device"
```

## Описание

«Нет места на устройстве»: устройство/ФС полностью заполнено (блоки данных или inode). POSIX-код. Одна из самых частых ошибок при записи файлов.

## Когда возникает

- `write()`/`open(O_CREAT)` — закончилось место на диске;
- создание файла при исчерпанных inode;
- `fsync()`/`sync()` — ошибка записи из-за нехватки места.

## Похожие коды

- `EDQUOT` — превышена квота (не место)
- `EFBIG` — файл превышает максимум
- `ENOMEM` — нехватка памяти
