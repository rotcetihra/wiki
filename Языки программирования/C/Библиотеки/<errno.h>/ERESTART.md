## Определение

```c
#include <errno.h>

#define ERESTART 85 // "Interrupted system call should be restarted"
```

## Описание

«Прерванный системный вызов следует перезапустить» — внутренний код ядра Linux: сигнал с флагом `SA_RESTART` прервал системный вызов, ядро возвращает его, чтобы libc (или сам обработчик) повторил вызов. В пользовательском пространстве никогда не должен появляться: ядро само перезапускает вызов, а библиотеки не отдают его наружу. Не входит в POSIX.

## Когда возникает

- только внутри ядра при обработке сигналов (входной/выходной переходы); пользовательские программы его не видят.

## Похожие коды

- `EINTR` — пользовательская форма «прервано сигналом»
