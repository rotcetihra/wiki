## Определение

```c
#include <errno.h>

#define EKEYEXPIRED 127 // "Key has expired"
```

## Описание

«Ключ истёк»: доступ к ключу, у которого истёк срок действия. Linux-специфичный код (семейство кодов keyrings).

## Когда возникает

- операции с ключом, чьё время жизни истекло (`keyctl`/`add_key`), например в dm-crypt или доверенной загрузке.

## Похожие коды

- `ENOKEY` — ключ не найден
- `EKEYREVOKED` — ключ отозван
- `EKEYREJECTED` — ключ отклонён

## Источники

- Linux: `asm-generic/errno.h`, man-страница `keyctl(2)`
