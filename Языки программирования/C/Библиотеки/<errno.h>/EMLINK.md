## Определение

```c
#include <errno.h>

#define EMLINK 31 // "Too many links"
```

## Описание

«Слишком много жёстких ссылок»: превышен максимум количества имён для одного файла (Linux: 65000). POSIX-код.

## Когда возникает

- `link()` — исчерпан лимит ссылок на inode;
- создание новых имён для файла с уже максимальным числом ссылок.

## Похожие коды

- `EEXIST` — имя уже существует
- `ENOSPC` — нет места (для метаданных на старых ФС)

## Источники
