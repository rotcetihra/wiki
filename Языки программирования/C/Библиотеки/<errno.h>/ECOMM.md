## Определение

```c
#include <errno.h>

#define ECOMM 70 // "Communication error on send"
```

## Описание

«Ошибка связи при передаче» — код RFS/STREAMS: сбой передачи сообщения между машинами в распределённой системе. На Linux сохраняется для совместимости; входит в POSIX (XSI) как код, связанный с сетевыми операциями (иногда возвращается `recvmsg()` на повреждённых соединениях).

## Когда возникает

- исторически — сбой RFS; на Linux возможен с исчезающих сетевых путей при некоторых протоколах.

## Похожие коды

- `EPROTO` — ошибка протокола
- `EBADMSG` — не сообщение с данными
- `ENOLINK` — связь потеряна
