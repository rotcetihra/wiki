## Определение

```c
#include <errno.h>

#define EMFILE 24 // "Too many open files"
```

## Описание

«Слишком много открытых файлов»: процесс исчерпал лимит открытых дескрипторов `RLIMIT_NOFILE` (обычно 1024). POSIX-код. Частая причина — утечка дескрипторов (незакрытые файлы/сокеты в цикле).

## Когда возникает

- `open()`/`socket()`/`accept()` при достижении лимита процесса;
- `dup()`/`fcntl(F_DUPFD)` — превышение лимита.

## Похожие коды

- `ENFILE` — исчерпан системный лимит открытых файлов
- `ENOMEM` — нехватка памяти (другие ограничения)
