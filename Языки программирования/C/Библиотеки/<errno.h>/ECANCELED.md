## Определение

```c
#include <errno.h>

#define ECANCELED 125 // "Operation canceled"
```

## Описание

«Операция отменена»: асинхронная операция прервана запросом отмены до завершения. Определён в POSIX (XSI) для aio (asynchronous I/O) и входит в стандарт C23 (список кодов errno). В glibc используется также как внутренний код для отменённых операций блокировок.

## Когда возникает

- `aio_cancel()` отменила операцию AIO;
- системные вызовы, прерванные запросом отмены (POSIX AIO, futex-операции glibc).

## Похожие коды

- `EINTR` — прервано сигналом
- `EINPROGRESS` — операция ещё выполняется
