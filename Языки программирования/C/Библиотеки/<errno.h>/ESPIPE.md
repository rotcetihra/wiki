## Определение

```c
#include <errno.h>

#define ESPIPE 29 // "Illegal seek"
```

## Описание

«Недопустимое смещение» (`seek`): операция позиционирования (`lseek()`) или зависящая от позиции операция применена к объекту без позиции — pipe, сокет, терминал. POSIX-код.

## Когда возникает

- `lseek()` на pipe/FIFO/сокете/терминальном устройстве;
- чтение определённых типов special-файлов (например, `/proc` записи с «дырами»);
- `ftruncate()`/`fstat()`? — нет; классический случай — `lseek`.

## Похожие коды

- `EINVAL` — неверный аргумент
- `EBADF` — неверный дескриптор
