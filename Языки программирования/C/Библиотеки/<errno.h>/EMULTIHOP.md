## Определение

```c
#include <errno.h>

#define EMULTIHOP 72 // "Multihop attempted"
```

## Описание

«Предпринят многошаговый переход» — код RFS/Transport Independent: операция требует передачи через несколько узлов сети, что не поддерживается. Входит в POSIX (XSI) как исторический. На Linux существует для совместимости; не возникает.

## Когда возникает

- исторически — RFS/OSI-стеки; на современных Linux практически не встречается.

## Похожие коды

- `ENOLINK` — связь разорвана
- `EPROTO` — ошибка протокола

## Источники

- POSIX.1-2024, раздел `errno.h`
