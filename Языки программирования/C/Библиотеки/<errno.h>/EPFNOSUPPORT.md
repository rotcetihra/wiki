## Определение

```c
#include <errno.h>

#define EPFNOSUPPORT 96 // "Protocol family not supported"
```

## Описание

«Семейство протоколов не поддерживается»: сокетное семейство протоколов (домен) не реализовано. POSIX (XSI). Во многом синоним `EAFNOSUPPORT`, на Linux значения отличаются.

## Когда возникает

- `socket()` с семейством, отсутствующим в ядре;
- `connect()`/`bind()` с адресом не поддерживаемого семейства.

## Похожие коды

- `EAFNOSUPPORT` — не поддерживается семейство адресов
- `EPROTONOSUPPORT` — не поддерживается протокол
- `ESOCKTNOSUPPORT` — не поддерживается тип сокета

## Источники

- POSIX.1-2024, раздел `errno.h`
