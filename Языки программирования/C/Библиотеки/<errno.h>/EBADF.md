## Определение

```c
#include <errno.h>

#define EBADF 9 // "Bad file number" (ядро), "Bad file descriptor" (glibc)
```

## Описание

«Некорректный файловый дескриптор». Возвращается, когда переданный дескриптор не открыт (закрыт, не существует, испорчен) или открыт с неподходящим режимом (например, запись в дескриптор, открытый только на чтение). Один из самых частых кодов при ошибках программирования. POSIX.

## Когда возникает

- `read()`/`write()`/`close()` на уже закрытый дескриптор;
- `read()` на дескрипторе, открытом `O_WRONLY` (и наоборот);
- `fcntl()`/`ioctl()`/`mmap()` с некорректным `fd`.

## Похожие коды

- `EBADFD` — дескриптор существует, но в недопустимом состоянии
- `EINVAL` — неверный аргумент
- `ENOTTY` — дескриптор не терминал (ioctl)
