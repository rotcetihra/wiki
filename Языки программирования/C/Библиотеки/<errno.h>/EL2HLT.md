## Определение

```c
#include <errno.h>

#define EL2HLT 51 // "Level 2 halted"
```

## Описание

«Уровень 2 остановлен» — код из набора STREAMS System V (уровни 2/3 Link). На Linux сохраняется для совместимости; не используется. Не входит в POSIX.

## Когда возникает

- исторически — STREAMS: остановка уровня 2 в протокольном стеке; на современных Linux не возникает.

## Похожие коды

- `EL2NSYNC` — уровень 2 не синхронизирован
- `EL3HLT` — уровень 3 остановлен
- `EL3RST` — уровень 3 сброшен
