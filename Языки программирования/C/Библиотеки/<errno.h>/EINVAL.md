## Определение

```c
#include <errno.h>

#define EINVAL 22 // "Invalid argument"
```

## Описание

«Неверный аргумент»: один из переданных аргументов имеет недопустимое значение или комбинацию. Универсальный код ошибки (наряду с `EINVAL` в POSIX), возвращаемый при нарушении контракта вызова. POSIX-код.

## Когда возникает

- неверное значение `whence` в `lseek()`, отрицательный `offset` в `mmap()`;
- `fcntl()` с недопустимым сочетанием флагов;
- `ioctl()` с некорректным кодом команды;
- `mmap()` нулевой длины, `mount()` с пустым источником и т. п.

## Похожие коды

- `EBADF` — неверный дескриптор
- `ENOTTY` — дескриптор не поддерживает ioctl
- `EFAULT` — недопустимый указатель
