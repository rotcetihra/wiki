## Определение

```c
#include <errno.h>

#define ELIBMAX 82 // "Attempting to link in too many shared libraries"
```

## Описание

«Слишком много разделяемых библиотек»: превышен лимит на число динамически загружаемых библиотек (в старых системах — жёсткий лимит загрузчика). Linux-специфичный; в современных системах лимит практически не достижим.

## Когда возникает

- исторически — загрузчик a.out: превышение числа библиотек; на современных ELF-системах не возникает.

## Похожие коды

- `ELIBACC` — доступ к библиотеке запрещён
- `ELIBBAD` — повреждённая библиотека
