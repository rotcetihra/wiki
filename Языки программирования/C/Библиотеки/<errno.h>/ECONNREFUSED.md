## Определение

```c
#include <errno.h>

#define ECONNREFUSED 111 // "Connection refused"
```

## Описание

«Соединение отклонено»: удалённый узел активно отклонил попытку соединения (нет слушающего процесса на порту, RST в ответ на SYN). POSIX (XSI). Самая частая ошибка клиентских программ при недоступном сервисе.

## Когда возникает

- `connect()` на порт, где никто не слушает;
- прокси/файрвол вернул RST;
- UNIX-сокет: файл сокета существует, но процесс не слушает.

## Похожие коды

- `ETIMEDOUT` — пакеты не доходят (нет ответа)
- `ENETUNREACH` — сеть недостижима
- `EHOSTUNREACH` — хост недостижим
