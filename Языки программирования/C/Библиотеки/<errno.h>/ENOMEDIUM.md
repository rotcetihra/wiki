## Определение

```c
#include <errno.h>

#define ENOMEDIUM 123 // "No medium found"
```

## Описание

«Носитель не найден»: съёмный носитель (CD/DVD, карта, диск в приводе) отсутствует в устройстве. Linux-специфичный код.

## Когда возникает

- операции чтения с пустого привода;
- мультимедиа-устройства без носителя (cardreader без карты и т. п.).

## Похожие коды

- `EMEDIUMTYPE` — носитель неправильного типа
- `ENXIO` — устройство недоступно
