## Определение

```c
#include <fenv.h>

#define FE_DIVBYZERO /* битовая маска */
```

## Описание

Константа `FE_DIVBYZERO` представляет битовую маску исключения деления на ноль. Исключение возникает при вычислении выражения вида `x / 0.0`, где `x` — ненулевое конечное значение или бесконечность. Операция `0.0 / 0.0` относится к другому типу исключения — `FE_INVALID`.

Значение константы определяется реализацией, так как на разных платформах используется разный набор битовых позиций. Для проверки наличия исключения используется побитовое И: `(fetestexcept(FE_DIVBYZERO) & FE_DIVBYZERO)`.

В IEEE 754 деление на ноль даёт результат ±∞ (в зависимости от знака делимого), но при включённом обработчике исключений операция генерирует сигнал.

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    feclearexcept(FE_ALL_EXCEPT);

    volatile double x = 1.0;
    volatile double y = 0.0;
    double result = x / y;

    if (fetestexcept(FE_DIVBYZERO)) {
        printf("Обнаружено исключение деления на ноль\n");
    }

    printf("Результат: %f\n", result);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет обнаружить деление на ноль после вычисления | По умолчанию исключение игнорируется |
| Стандартный способ проверки (IEEE 754) | Точное поведение зависит от реализации |
| Совместим с `feclearexcept`, `fetestexcept`, `feraiseexcept` | Не работает при отключённых исключениях ( expressly) |
