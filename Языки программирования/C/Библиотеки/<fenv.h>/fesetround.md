## Определение

```c
#include <fenv.h>

int fesetround(int round);
```

## Описание

Функция `fesetround` устанавливает направление округления для операций с плавающей точкой. Параметр `round` должен быть одной из констант: `FE_DOWNWARD`, `FE_TONEAREST`, `FE_TOWARDZERO` или `FE_UPWARD`.

Если параметр не является допустимым значением, направление округления не изменяется.

Функция возвращает `0` при успешной установке и ненулевое значение, если направление не было изменено.

Направление округления влияет на результаты всех последующих арифметических операций с плавающей точкой, пока оно не будет изменено снова.

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    double a = 1.0;
    double b = 3.0;

    fesetround(FE_TONEAREST);
    printf("FE_TONEAREST: 1.0/3.0 = %.20f\n", a / b);

    fesetround(FE_TOWARDZERO);
    printf("FE_TOWARDZERO: 1.0/3.0 = %.20f\n", a / b);

    fesetround(FE_DOWNWARD);
    printf("FE_DOWNWARD:   1.0/3.0 = %.20f\n", a / b);

    fesetround(FE_UPWARD);
    printf("FE_UPWARD:     1.0/3.0 = %.20f\n", a / b);

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `round` | Направление округления: `FE_DOWNWARD`, `FE_TONEAREST`, `FE_TOWARDZERO` или `FE_UPWARD` |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Направление округления успешно установлено |
| Ненулевое | Направление не было изменено (недопустимое значение параметра) |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Мгновенное изменение направления округления | Влияет на все последующие операции — легко забыть восстановить |
| Простая и понятная функция | Не сохраняет предыдущее направление — нужен `fegetround` |
| Стандартная функция ISO C99/C23 | — |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** ненулевое значение, если направление не было изменено (недопустимое значение параметра).
- **Установление errno:** функция не устанавливает `errno` — код ошибки возвращается напрямую.
- **Поведение при передаче NULL:** не применимо (аргумент `round` — целое число, не указатель).
- **Многопоточность:** среда вычислений с плавающей точкой является потоковой (каждый поток имеет свою копию). Функция безопасна в многопоточной среде при условии, что каждый поток работает со своей средой.
- **Связанные функции:** `fegetround` — получение текущего направления округления; `fegetenv` — сохранение полной среды (включая округление).
