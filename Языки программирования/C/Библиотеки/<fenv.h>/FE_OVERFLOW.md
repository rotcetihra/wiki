## Определение

```c
#include <fenv.h>

#define FE_OVERFLOW /* битовая маска */
```

## Описание

Константа `FE_OVERFLOW` представляет битовую маску исключения переполнения. Исключение возникает, когда результат операции с плавающей точкой по модулю слишком велик для представления в данном типе. При переполнении результат通常 становится ±∞ (в IEEE 754), но если обработчик исключений включён, генерируется сигнал.

Примеры операций, вызывающих `FE_OVERFLOW`:

- `DBL_MAX * 2.0` — произведение, превышающее максимальное значение
- `exp(1000.0)` — экспонента слишком большого аргумента
- `pow(2.0, 1024.0)` — степень, превышающая диапазон

При переполнении также устанавливается флаг `FE_INEXACT`, так как результат обычно округляется до бесконечности.

## Пример

```c
#include <stdio.h>
#include <math.h>
#include <fenv.h>
#include <float.h>

int main(void)
{
    feclearexcept(FE_ALL_EXCEPT);

    volatile double x = DBL_MAX;
    volatile double y = 2.0;
    double result = x * y;

    if (fetestexcept(FE_OVERFLOW)) {
        printf("Обнаружено исключение переполнения\n");
    }

    if (fetestexcept(FE_INEXACT)) {
        printf("Также обнаружено FE_INEXACT (результат округлён до бесконечности)\n");
    }

    printf("Результат: %f\n", result);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет обнаружить переполнение до использования результата | По умолчанию игнорируется |
| Часто сопровождается `FE_INEXACT` — полезная комбинация | Результат обычно ±∞ — может маскировать проблему |
| Стандартный способ контроля диапазона | Точное поведение зависит от реализации |
