## Определение

```c
#include <fenv.h>

#define FE_TONEAREST /* целочисленная константа */
```

## Описание

Константа `FE_TONEAREST` задаёт направление округления к ближайшему целому. Это стандартное (по умолчанию) поведение округления в соответствии со стандартом IEEE 754. При таком округлении результат округляется к ближайшему представимому значению.

Если результат находится ровно посередине между двумя представимыми значениями, используется «округление к чётному» (banker's rounding) — выбирается значение с чётной последней цифрой мантиссы.

Например:

- `3.5` → `4.0` (к чётному)
- `2.5` → `2.0` (к чётному)
- `3.7` → `4.0`
- `-3.7` → `-4.0`

Это направление обеспечивает наименьшую систематическую погрешность при большинстве вычислений.

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    fesetround(FE_TONEAREST);
    printf("Направление: FE_TONEAREST (по умолчанию)\n");

    printf("3.5 → %.1f\n", 3.5);
    printf("2.5 → %.1f\n", 2.5);
    printf("3.7 → %.1f\n", 3.7);
    printf("-3.7 → %.1f\n", -3.7);
    printf("3.14159 → %.4f\n", 3.14159);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартное поведение IEEE 754 —预测имо | Округление к чётному может быть неинтуитивным |
| Минимальная систематическая погрешность | Не подходит для интервальных вычислений |
| Работает по умолчанию без установки | — |
