## Определение

```c
#include <fenv.h>

#define FE_TOWARDZERO /* целочисленная константа */
```

## Описание

Константа `FE_TOWARDZERO` задаёт направление округления к нулю (усечение). При таком округлении дробная часть просто отбрасывается — результат всегда по модулю не больше исходного значения.

Например:

- `3.7` → `3.0`
- `-3.7` → `-3.0` (не `-4.0`!)
- `3.0` → `3.0`

Это направление также известно как «усечение» (truncation). Функция `trunc` из `<math.h>` всегда использует именно это направление, независимо от текущей настройки `fesetround`.

`FE_TOWARDZERO` полезно для целочисленного преобразования浮点数, где нужно гарантировать, что результат по модулю не превышает исходное значение.

## Пример

```c
#include <stdio.h>
#include <math.h>
#include <fenv.h>

int main(void)
{
    fesetround(FE_TOWARDZERO);
    printf("Направление: FE_TOWARDZERO\n");

    printf("3.7 → %.1f\n", 3.7);
    printf("-3.7 → %.1f\n", -3.7);
    printf("3.0 → %.1f\n", 3.0);

    printf("\nСравнение с trunc:\n");
    printf("trunc(3.7) = %.1f\n", trunc(3.7));
    printf("trunc(-3.7) = %.1f\n", trunc(-3.7));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Результат по модулю ≤ исходного значения | Систематическая погрешность (всегда в сторону нуля) |
| Интуитивно понятно — дробная часть отбрасывается | Не является стандартным IEEE 754 по умолчанию |
| Аналог `trunc()` для целочисленных преобразований | Может замедлять сходимость итеративных алгоритмов |
