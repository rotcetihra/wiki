## Определение

```c
#include <fenv.h>

#define FE_INEXACT /* битовая маска */
```

## Описание

Константа `FE_INEXACT` представляет битовую маску исключения неточного результата. Исключение возникает, когда результат операции с плавающей точкой не может быть представлен точно и должен быть округлён. Это самое частое исключение — оно возникает при большинстве вычислений с `double` и `float`, поскольку лишь少数 значений может быть представлена точно.

Например, выражение `1.0 / 3.0` генерирует `FE_INEXACT`, так как результат является бесконечной десятичной дробью.

По умолчанию это исключение игнорируется. Однако его можно использовать для определения потерянной точности в вычислениях.

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    feclearexcept(FE_ALL_EXCEPT);

    volatile double a = 1.0;
    volatile double b = 3.0;
    double result = a / b;

    if (fetestexcept(FE_INEXACT)) {
        printf("Обнаружено исключение неточного результата\n");
    }

    printf("Результат: %.20f\n", result);

    feclearexcept(FE_ALL_EXCEPT);

    volatile double c = 4.0;
    volatile double d = 2.0;
    result = c / d;

    if (fetestexcept(FE_INEXACT)) {
        printf("FE_INEXACT для 4.0/2.0\n");
    } else {
        printf("Нет исключения для 4.0/2.0 (точный результат)\n");
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет обнаружить потерю точности | По умолчанию игнорируется — не влияет на результат |
| Возникает автоматически при округлении | Может генерироваться очень часто (каждое нечётное деление) |
| Стандартный способ контроля точности | Использование требует явного включения |
