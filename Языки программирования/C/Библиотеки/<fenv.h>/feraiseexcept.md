## Определение

```c
#include <fenv.h>

int feraiseexcept(int excepts);
```

## Описание

Функция `feraiseexcept` пытается сгенерировать («поднять») указанные исключения с плавающей точкой. Параметр `excepts` — побитовая маска исключений (`FE_DIVBYZERO`, `FE_INEXACT`, `FE_INVALID`, `FE_OVERFLOW`, `FE_UNDERFLOW`).

Реализация пытается имитировать возникновение каждого из указанных исключений. Порядок генерации не определён — если несколько исключений связаны (например, `FE_OVERFLOW` обычно сопровождается `FE_INEXACT`), реализация может установить несколько флагов за один вызов.

Функция возвращает `0`, если все указанные исключения успешно сгенерированы, и ненулевое значение, если хотя бы одно не удалось сгенерировать.

> [!NOTE]
> Эта функция полезна для тестирования обработчиков исключений — можно сгенерировать конкретное исключение без выполнения арифметической операции, которая его вызвала бы.

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    feclearexcept(FE_ALL_EXCEPT);

    feraiseexcept(FE_INVALID);
    printf("После FE_INVALID: 0x%x\n", fetestexcept(FE_ALL_EXCEPT));

    feclearexcept(FE_ALL_EXCEPT);

    feraiseexcept(FE_DIVBYZERO | FE_OVERFLOW);
    printf("После DIVBYZERO | OVERFLOW: 0x%x\n", fetestexcept(FE_ALL_EXCEPT));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `excepts` | Побитовая маска генерируемых исключений |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Все указанные исключения успешно сгенерированы |
| Ненулевое | Хотя бы одно исключение не удалось сгенерировать |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет тестировать обработчики без реальных вычислений | Порядок генерации не определён |
| Может генерировать несколько исключений за вызов | Не все исключения могут быть сгенерированы на всех платформах |
| Стандартная функция ISO C99/C23 | Реализация может быть реализована как макрос |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** ненулевое значение, если хотя бы одно исключение не удалось сгенерировать.
- **Установление errno:** функция не устанавливает `errno` — код ошибки возвращается напрямую.
- **Поведение при передаче NULL:** не применимо (аргумент `excepts` — целое число, не указатель).
- **Многопоточность:** среда вычислений с плавающей точкой является потоковой (каждый поток имеет свою копию). Функция безопасна в многопоточной среде при условии, что каждый поток работает со своей средой.
- **Связанные функции:** `feclearexcept` — сброс исключений; `fetestexcept` — проверка активных исключений.
