## Определение

```c
#include <fenv.h>

#define FE_UNDERFLOW /* битовая маска */
```

## Описание

Константа `FE_UNDERFLOW` представляет битовую маску исключения недополнения. Исключение возникает, когда результат операции с плавающей точкой по модулю настолько мал, что не может быть представлен как нормальное число в данном типе.

В IEEE 754 результатом недополнения обычно является так называемое «denormalized» (denorm) значение — число с уменьшенным экспонентным смещением и ненулевой мантиссой. Если denorm не поддерживается, результат округляется до нуля.

Примеры операций, вызывающих `FE_UNDERFLOW`:

- `DBL_MIN / 2.0` — деление наименьшего нормального числа на 2
- `exp(-1000.0)` — экспонента очень малого аргумента
- `pow(2.0, -1075.0)` — степень, приводящая к очень малому значению

При недополнении также устанавливается флаг `FE_INEXACT`, если результат был округлён.

## Пример

```c
#include <stdio.h>
#include <math.h>
#include <fenv.h>
#include <float.h>

int main(void)
{
    feclearexcept(FE_ALL_EXCEPT);

    volatile double x = DBL_MIN;
    volatile double y = 2.0;
    double result = x / y;

    if (fetestexcept(FE_UNDERFLOW)) {
        printf("Обнаружено исключение недополнения\n");
    }

    if (fetestexcept(FE_INEXACT)) {
        printf("Также обнаружено FE_INEXACT (результат округлён)\n");
    }

    printf("Результат: %e\n", result);
    printf("DBL_MIN: %e\n", DBL_MIN);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет обнаружить потерю нормального представления | По умолчанию игнорируется |
| Полезно для численных алгоритмов, чувствительных к масштабу | Denorm-значения могут замедлять вычисления на некоторых архитектурах |
| Сопровождается `FE_INEXACT` при округлении | Поведение denorm зависит от硬件 |
