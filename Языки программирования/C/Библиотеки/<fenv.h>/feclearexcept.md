## Определение

```c
#include <fenv.h>

int feclearexcept(int excepts);
```

## Описание

Функция `feclearexcept` сбрасывает (очищает) указанные флаги исключений с плавающей точкой. Параметр `excepts` — побитовая маска исключений (например, `FE_DIVBYZERO`, `FE_INVALID`, `FE_ALL_EXCEPT`).

Если в маске указаны константы, не поддерживаемые реализацией, поведение не определено.

Функция возвращает `0` при успешном выполнении и ненулевое значение, если хотя бы одно из указанных исключений не удалось сбросить.

> [!NOTE]
> Сброс флагов исключений не отменяет уже выполненных вычислений — он лишь удаляет запись о том, что исключение произошло. Если исключение возникло в результате операции, оно не будет повторно обнаружено после сброса.

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    volatile double a = 0.0;
    volatile double b = 0.0;
    volatile double c = a / b;

    printf("Исключения после деления: 0x%x\n", fetestexcept(FE_ALL_EXCEPT));

    feclearexcept(FE_INVALID);
    printf("После сброса FE_INVALID: 0x%x\n", fetestexcept(FE_ALL_EXCEPT));

    feclearexcept(FE_ALL_EXCEPT);
    printf("После сброса всех: 0x%x\n", fetestexcept(FE_ALL_EXCEPT));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `excepts` | Побитовая маска сбрасываемых исключений (`FE_DIVBYZERO`, `FE_INEXACT`, `FE_INVALID`, `FE_OVERFLOW`, `FE_UNDERFLOW`, `FE_ALL_EXCEPT` или их комбинация через `|`) |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Все указанные флаги успешно сброшены |
| Ненулевое | Хотя бы одно из указанных исключений не удалось сбросить |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет сбросить конкретные флаги без затрагивания других | Не отменяет уже выполненных вычислений |
| Поддерживает массовый сброс через `FE_ALL_EXCEPT` | Поведение не определено для неподдерживаемых исключений |
| Стандартная функция ISO C99/C23 | — |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** ненулевое значение, если хотя бы одно из указанных исключений не удалось сбросить.
- **Установление errno:** функция не устанавливает `errno` — код ошибки возвращается напрямую.
- **Поведение при передаче NULL:** не применимо (аргумент `excepts` — целое число, не указатель).
- **Многопоточность:** среда вычислений с плавающей точкой является потоковой (каждый поток имеет свою копию). Функция безопасна в многопоточной среде при условии, что каждый поток работает со своей средой.
- **Связанные функции:** `fetestexcept` — проверка активных исключений; `feraiseexcept` — генерация исключений; `fegetexceptflag` — сохранение флагов в `fexcept_t`.
