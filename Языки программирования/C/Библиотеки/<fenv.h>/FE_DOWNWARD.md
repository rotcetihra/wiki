## Определение

```c
#include <fenv.h>

#define FE_DOWNWARD /* целочисленная константа */
```

## Описание

Константа `FE_DOWNWARD` задаёт направление округления к минус бесконечности («вниз»). При таком округлении любой результат, не являющийся целым числом, округляется к ближайшему меньшему целому.

Например:

- `3.7` → `3.0`
- `-3.7` → `-4.0`
- `3.0` → `3.0` (уже целое)

Это направление округления полезно для реализации интервальных вычислений, где необходимо гарантировать, что результат не превышает точное значение.

Для установки направления округления используется функция `fesetround(FE_DOWNWARD)`.

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    int saved_rounding = fegetround();

    fesetround(FE_DOWNWARD);
    printf("Направление: FE_DOWNWARD\n");

    double a = 1.0;
    double b = 3.0;
    printf("1.0 / 3.0 = %.20f\n", a / b);
    printf("(ожидается 0.333... с округлением вниз)\n");

    volatile double x = -2.7;
    printf("Округление -2.7 = %.1f\n", x);

    fesetround(saved_rounding);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует, что результат ≤ точное значение | Не является стандартным поведением IEEE 754 |
| Полезно для интервальных вычислений | Может приводить к систематической погрешности |
| Стандартная константа C99/C23 | Изменение направления влияет на все последующие операции |
