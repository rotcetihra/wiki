## Описание библиотеки

Заголовочный файл `<stdalign.h>` — макросы выравнивания.

> [!WARNING]
> В C23 макросы `alignas` и `alignof` стали ключевыми словами языка, поэтому заголовок `<stdalign.h>` объявлен устаревшим и в C23 не требуется.

### Макросы

| Макрос | Описание |
|---|---|
| `alignas` | Расширяется до `_Alignas`. Указывает требуемое выравнивание для объекта или типа |
| `alignof` | Расширяется до `_Alignof`. Возвращает минимальное выравнивание для типа |
| `__alignas_is_defined` | Расширяется до целой константы 1. Подходит для использования в директивах `#if` |
| `__alignof_is_defined` | Расширяется до целой константы 1. Подходит для использования в директивах `#if` |

### Пример использования

```c
#include <stdalign.h>
#include <stdio.h>

struct Foo {
    char a;
    alignas(16) int b;  // выравнивание на 16 байт
    char c;
};

int main(void) {
    printf("Выравнивание Foo: %zu\n", alignof(struct Foo));
    printf("Выравнивание b: %zu\n", alignof(int));
    return 0;
}
```

## Исключения

- **NULL:** не применимо.
- **Переполнение:** не применимо.
- **Нехватка памяти:** не применимо.
- **Граничные случаи:** в C23 макросы `alignas` и `alignof` являются ключевыми словами; заголовок `<stdalign.h>` устаревший.
- **Многопоточность:** макросы не генерируют код, поэтому потокобезопасны.
