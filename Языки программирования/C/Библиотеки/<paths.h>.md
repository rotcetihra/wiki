## Описание библиотеки

Заголовочный файл `<paths.h>` — стандартные пути файлов. Определяет константы с путями к стандартным файлам и каталогам системы (BSD).

### Константы (выборочные)

| Константа | Значение | Описание |
|---|---|---|
| `_PATH_DEFPATH` | `"/usr/bin:/bin"` | Путь поиска по умолчанию |
| `_PATH_STDPATH` | `"/usr/bin:/bin:/usr/sbin:/sbin"` | Путь стандартных утилит |
| `_PATH_BSHELL` | `"/bin/sh"` | Bourne shell |
| `_PATH_DEVNULL` | `"/dev/null"` | Файл «нуля» |
| `_PATH_TMP` | `"/tmp/"` | Временный каталог |
| `_PATH_VARRUN` | `"/var/run/"` | Каталог запущенных процессов |
| `_PATH_SHADOW` | `"/etc/shadow"` | Файл теней паролей |
| `_PATH_SHELLS` | `"/etc/shells"` | Список оболочек |

### Использование

```c
#include <paths.h>

/* Использование стандартного пути */
FILE *f = fopen(_PATH_DEVNULL, "w");

/* Путь для поиска программ */
printf("PATH: %s\n", _PATH_DEFPATH);
```

## Исключения

- **Константы:** все значения определены как строковые литералы времени компиляции.
- **Зависимость от платформы:** значения могут отличаться в разных реализациях (BSD, Linux).
- **Каталоги:** константы `_PATH_DEV`, `_PATH_TMP`, `_PATH_VARRUN`, `_PATH_VARTMP` содержат завершающий `/` для построения путей.
- **Многопоточность:** не применимо (только константы).

## Стандарты

BSD (не POSIX).
