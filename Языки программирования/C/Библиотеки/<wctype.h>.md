## Описание библиотеки

Заголовочный файл `<wctype.h>` — классификация и Преобразование宽幅ных символов. Этот заголовок предоставляет функции для классификации и Преобразования宽幅ных символов с учётом локали.

### Типы

| Тип | Описание |
|---|---|
| `wint_t` | Целочисленный тип, способный хранить любой `wchar_t` или `WEOF` |
| `wctrans_t` | Скалярный тип для хранения информации о Преобразовании символов |
| `wctype_t` | Тип для хранения информации о классификации символов |

### Константы

| Константа | Описание |
|---|---|
| `WEOF` | Константа типа `wint_t`, возвращаемая функциями宽幅ного ввода-вывода для указания конца файла |

## Исключения

- **NULL:** функции не принимают указатели, поэтому `NULL` не применим.
- **WEOF:** функции классификации возвращают ненулевое значение для `WEOF`.
- **Многопоточность:** функции не являются потокобезопасными; для безопасного использования требуют блокировки.
- **Локаль:** поведение функций зависит от категории `LC_CTYPE` текущей локали; функции `_l` используют явную локаль.
- **Граничные случаи:** для всех функций, принимающих `wint_t`, значение должно быть представимым как `wchar_t` или равно `WEOF`.
