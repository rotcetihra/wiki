## Определение

```c
#include <stdalign.h>

#define alignas _Alignas // C11
alignas                  // C23: ключевое слово
```

## Описание

Спецификатор выравнивания: задаёт требование к выравниванию объекта при объявлении: `alignas(16) int buf[4];` размещает массив по адресу, кратному 16. Аргументом может быть тип (`alignas(double)`) или целочисленное выражение, равное степени двойки, не превышающее `alignof(max_align_t)` (в C23 при поддержке компилятора допускаются и большие выравнивания).

Основные применения: выравнивание буферов под инструкции SSE/AVX, DMA, атомарные операции, исключение кэш-конфликтов в структурах.

## Примеры

```c
#include <stdalign.h>
#include <stdio.h>

struct Packet {
    alignas(16) unsigned char data[64];
    int size;
};

int main(void)
{
    alignas(32) int buffer[8];

    printf("Выравнивание buffer: %zu\n", (size_t)&buffer % 32);
    printf("Выравнивание data: %zu\n",
           offsetof(struct Packet, data) % 16);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Контроль размещения данных под аппаратные требования | Слишком большое выравнивание увеличивает расход памяти |

## Альтернативы

- `aligned_alloc()` — выделение выровненной памяти в куче
- `max_align_t` — максимальное «стандартное» выравнивание
