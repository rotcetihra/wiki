## Описание библиотеки

Заголовочный файл `<grp.h>` — структура group. Определяет структуру `group` и функции для доступа к базе данных групп.

### Структура `struct group`

```c
struct group {
    char  *gr_name;   /* Имя группы */
    gid_t  gr_gid;    /* Числовой ID группы */
    char **gr_mem;    /* Массив имён участников (завершается NULL) */
};
```

### Функции

| Функция | Описание |
|---|---|
| `getgrgid(gid_t)` | Поиск группы по числовому ID |
| `getgrgid_r(gid_t, struct group *, char *, size_t, struct group **)` | Потокобезопасный поиск по GID |
| `getgrnam(const char *)` | Поиск группы по имени |
| `getgrnam_r(const char *, struct group *, char *, size_t, struct group **)` | Потокобезопасный поиск по имени |
| `getgrent(void)` | Получение следующей записи из базы групп |
| `setgrent(void)` | Начало последовательного чтения базы групп |
| `endgrent(void)` | Завершение последовательного чтения |

### Возвращаемое значение

- `getgrgid()` и `getgrnam()` возвращают указатель на `struct group` или `NULL` (группа не найдена).
- Потокобезопасные функции `_r` возвращают `0` при успехе, `ENOENT` (не найдено) или другой код ошибки.

### Использование

```c
#include <grp.h>

struct group *grp = getgrnam("users");
if (grp) {
    printf("Группа: %s (GID: %d)\n", grp->gr_name, grp->gr_gid);
    for (int i = 0; grp->gr_mem[i]; i++) {
        printf("  Участник: %s\n", grp->gr_mem[i]);
    }
}
```

## Исключения

- **NULL:** функции возвращают `NULL` при ошибке или если группа не найдена.
- **Память:** указатель на `struct group` указывает на статический буфер; не освобождайте его.
- **getgrgid_r/getgrnam_r:** выделяют память через буфер вызывающего; при `ERANGE`增大 буфер.
- **Многопоточность:** потокобезопасные функции `_r` рекомендуются для многопоточных программ.
- **setgrent/endgrent:** используют статические буферы; не используйте в многопоточной среде без синхронизации.
