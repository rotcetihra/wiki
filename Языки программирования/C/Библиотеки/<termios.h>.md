## Описание библиотеки

Заголовочный файл `<termios.h>` — определения для терминала. Определяет структуру `termios` и функции для управления параметрами терминала (скорость, режимы ввода-вывода, управляющие символы).

### Структура `struct termios`

```c
struct termios {
    tcflag_t  c_iflag;    /* Входные режимы */
    tcflag_t  c_oflag;    /* Выходные режимы */
    tcflag_t  c_cflag;    /* Контрольные режимы */
    tcflag_t  c_lflag;    /* Локальные режимы */
    cc_t      c_cc[NCCS]; /* Управляющие символы */
};
```

### Функции

| Функция | Описание |
|---|---|
| `tcgetattr(int, struct termios *)` | Получение текущих параметров терминала |
| `tcsetattr(int, int, const struct termios *)` | Установка параметров терминала |
| `cfgetispeed(const struct termios *)` | Получение входной скорости |
| `cfgetospeed(const struct termios *)` | Получение выходной скорости |
| `cfsetispeed(struct termios *, speed_t)` | Установка входной скорости |
| `cfsetospeed(struct termios *, speed_t)` | Установка выходной скорости |
| `tcdrain(int)` | Ожидание завершения физического вывода |
| `tcflow(int, int)` | Управление вводом/выводом |

| `tcsendbreak(int, int)` | Отправка последовательности break |
| `tcgetsid(int)` | Получение ID сеанса терминала |

## Исключения

- **NULL:** функции не принимают `NULL`.
- **errno:** при ошибке устанавливается `errno` (например, `EBADF`, `ENOTTY`, `EINVAL`).
- **EBADF:** неверный файловый дескриптор.
- **ENOTTY:** файловый дескриптор не является терминалом.
- **ICANON:** в каноническом режиме ввод буферизуется по строкам.
- **VMIN и VTIME:** могут иметь одинаковые значения с VEOF и VEOL.
- **Многопоточность:** функции потокобезопасны.
