## Определение

```c
#include <signal.h>

#define SIG_DFL /* implementation-defined */
```

## Описание

Макрос `SIG_DFL` определяет значение обработчика сигнала по умолчанию. При установке `SIG_DFL` в качестве обработчика для сигнала выполняется действие по умолчанию для этого сигнала (например, завершение программы для `SIGSEGV` или `SIGABRT`, игнорирование для `SIGCHLD`).

Используется как аргумент функции `signal` для восстановления обработчика по умолчанию после временного перехвата сигнала.

> [!NOTE]
> Действия по умолчанию определяются реализацией, но стандарт гарантирует: `SIGABRT`, `SIGFPE`, `SIGILL`, `SIGSEGV` завершают программу, `SIGINT` и `SIGTERM` также завершают.

## Пример

```c
#include <stdio.h>
#include <signal.h>

void custom_handler(int sig)
{
    printf("Перехвачен сигнал %d\n", sig);
    signal(sig, SIG_DFL);
}

int main(void)
{
    signal(SIGINT, custom_handler);
    printf("Нажмите Ctrl+C — первый раз перехватим, второй — по умолчанию\n");
    while (1) {}
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет восстановить поведение по умолчанию | Не является функцией (макрос) |
| Простой способ отмены временного перехвата | Действие по умолчанию определяется реализацией |
