## Определение

```c
#include <signal.h>

#define SIGTERM /* implementation-defined */
```

## Описание

Макрос `SIGTERM` определяет сигнал запроса на завершение программы. Этот сигнал отправляется операционной системой или другой программой (например, при вызове `kill` или завершении через `systemctl`). В отличие от `SIGKILL`, обработчик может перехватить `SIGTERM` и выполнить корректное завершение.

Действие по умолчанию — завершение программы. Установка обработчика позволяет выполнить очистку перед завершением.

> [!NOTE]
> `SIGTERM` — основной способ запроса завершения демонов и фоновых процессов в POSIX-системах. Правильно написанные программы должны обрабатывать `SIGTERM` и завершаться корректно.

## Пример

```c
#include <stdio.h>
#include <signal.h>

volatile sig_atomic_t running = 1;

void term_handler(int sig)
{
    (void)sig;
    running = 0;
}

int main(void)
{
    signal(SIGTERM, term_handler);
    printf("Программа ожидает SIGTERM (PID: %d)\n", getpid());
    while (running) {
        /* основная работа */
    }
    printf("Получен SIGTERM, корректное завершение\n");
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет корректно завершить программу | Не guaranteeируется доставка |
| Стандартный способ завершения демонов | Обработчик должен быть простым |
| Можно перехватить и отложить завершение | Не является替代 для `SIGKILL` |
