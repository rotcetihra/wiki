## Определение

```c
#include <signal.h>

void (*signal(int sig, void (*handler)(int)))(int);
```

## Описание

Функция `signal` устанавливает обработчик для сигнала `sig`. Параметр `handler` может быть одним из трёх стандартных значений:

- `SIG_DFL` — обработка по умолчанию;
- `SIG_IGN` — игнорирование сигнала;
- указатель на функцию `void handler(int)` — пользовательский обработчик.

При успешном вызове `signal` возвращает предыдущий обработчик для данного сигнала. При ошибке возвращает `SIG_ERR`.

> [!WARNING]
> Поведение функции `signal` при повторной генерации сигнала (если сигнал возникает во время обработки предыдущего) зависит от реализации. На многих POSIX-системах по умолчанию обработчик сбрасывается на `SIG_DFL` после вызова (เนื่องจาก historical behavior). Для предсказуемого поведения используйте `sigaction`.

## Пример

```c
#include <stdio.h>
#include <signal.h>

void int_handler(int sig)
{
    printf("Пойман сигнал %d\n", sig);
}

int main(void)
{
    void (*old_handler)(int) = signal(SIGINT, int_handler);
    if (old_handler == SIG_ERR) {
        perror("signal");
        return 1;
    }
    printf("Обработчик установлен. Предыдущий: %s\n",
           old_handler == SIG_DFL ? "SIG_DFL" : "пользовательский");
    signal(SIGINT, old_handler);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `sig` | Номер сигнала (стандартные: `SIGABRT`, `SIGFPE`, `SIGILL`, `SIGINT`, `SIGSEGV`, `SIGTERM`) |
| `handler` | Обработчик: `SIG_DFL`, `SIG_IGN` или указатель на функцию `void(int)` |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `void (*)(int)` | Предыдущий обработчик для данного сигнала |
| `SIG_ERR` | Ошибка установки обработчика |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный способ установки обработчиков сигналов | Портативность поведения зависит от реализации |
| Простой интерфейс | Не потокобезопасна |
| Поддерживает стандартные обработчики | Повторная генерация сигнала — непредсказуема |
