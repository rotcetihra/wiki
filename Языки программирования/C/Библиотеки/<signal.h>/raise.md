## Определение

```c
#include <signal.h>

int raise(int sig);
```

## Описание

Функция `raise` отправляет сигнал `sig` текущему процессу. Это позволяет программе сгенерировать сигнал программно — например, для тестирования обработчиков или для аварийного завершения.

При успешном вызове функция возвращает 0. Если сигнал не может быть отправлен, возвращается ненулевое значение.

> [!NOTE]
> В однопоточной программе `raise(sig)` эквивалентна `signalraise(sig)`. В многопоточных программах `raise` отправляет сигнал вызывающему потоку, а `kill` (POSIX) — всему процессу.

## Пример

```c
#include <stdio.h>
#include <signal.h>

void abort_handler(int sig)
{
    printf("Пойман SIGABRT (сигнал %d)\n", sig);
}

int main(void)
{
    signal(SIGABRT, abort_handler);
    printf("Отправляем SIGABRT\n");
    raise(SIGABRT);
    printf("Программа продолжает работу\n");
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `sig` | Номер сигнала для отправки (стандартные: `SIGABRT`, `SIGFPE`, `SIGILL`, `SIGINT`, `SIGSEGV`, `SIGTERM`) |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Сигнал успешно отправлен |
| Ненулевое значение | Ошибка отправки сигнала |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простой способ отправить сигнал программно | Ограничен стандартными сигналами |
| Портативна (стандартная часть C89) | Не поддерживает пользовательские сигналы |
| Можно использовать для тестирования | В многопоточных программах отправляет только вызывающему потоку |

## Обработка ошибок

- **Поведение при передаче NULL:** не применимо — параметр `sig` является целым числом, а не указателем.
- **Возвращаемое значение при ошибке:** ненулевое значение, если сигнал не может быть отправлен.
- **Установление errno:** функция не определяет значение `errno`.
- **Многопоточность:** в однопоточной программе `raise(sig)` эквивалентна `kill(getpid(), sig)`. В многопоточных программах `raise()` отправляет сигнал вызывающему потоку, а `kill()` (POSIX) — всему процессу.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<signal.h>/signal|signal]] — установка обработчика сигнала; [[Языки программирования/C/Библиотеки/<signal.h>/sig_atomic_t|sig_atomic_t]] — атомарный тип для обработки сигналов; `kill()` (POSIX) — отправка сигналов другому процессу.
