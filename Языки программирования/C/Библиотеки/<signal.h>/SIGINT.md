## Определение

```c
#include <signal.h>

#define SIGINT /* implementation-defined */
```

## Описание

Макрос `SIGINT` определяет сигнал прерывания программы. Обычно генерируется при нажатии `Ctrl+C` в терминале. Сигнал предназначен для запроса вежливого завершения программы с возможностью освобождения ресурсов.

Действие по умолчанию — завершение программы. Установка собственного обработчика позволяет корректно завершить программу, закрыть файлы и освободить память.

> [!NOTE]
> Сигнал `SIGINT` асинхронен — он может прийти в любой момент. Обработчик должен быть простым и использовать только `volatile sig_atomic_t` для обмена данными с основной программой.

## Пример

```c
#include <stdio.h>
#include <signal.h>

volatile sig_atomic_t running = 1;

void int_handler(int sig)
{
    (void)sig;
    running = 0;
}

int main(void)
{
    signal(SIGINT, int_handler);
    printf("Программа работает. Нажмите Ctrl+C для завершения.\n");
    while (running) {
        /* основная работа */
    }
    printf("Корректное завершение\n");
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный способ обработки Ctrl+C | Асинхронный — ограничения в обработчике |
| Позволяет корректно завершить программу | Может прийти в любой момент |
