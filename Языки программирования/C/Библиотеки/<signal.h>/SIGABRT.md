## Определение

```c
#include <signal.h>

#define SIGABRT /* implementation-defined */
```

## Описание

Макрос `SIGABRT` определяет сигнал аварийного завершения программы. Этот сигнал генерируется функцией `abort()` из `<stdlib.h>` и указывает на критическую ошибку, из которой программа не может восстановиться.

Действие по умолчанию для `SIGABRT` — завершение программы с кодом завершения и создание дампа памяти (core dump), если это поддерживается операционной системой.

> [!NOTE]
> Функция `abort()` сначала сбрасывает обработчик `SIGABRT` на значение по умолчанию, а затем отправляет сигнал. Это гарантирует завершение даже если обработчик заблокирован.

## Пример

```c
#include <stdio.h>
#include <stdlib.h>
#include <signal.h>

void abort_handler(int sig)
{
    printf("Поймали SIGABRT, аварийное завершение\n");
    _Exit(1);
}

int main(void)
{
    signal(SIGABRT, abort_handler);
    printf("Перед abort()\n");
    abort();
    printf("Это не будет выведено\n");
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует завершение программы | Стандартная константа — доступна на всех платформах |
| Можно перехватить для очистки | Перехват не отменяет завершение |
| Генерируется `abort()` | Не保证ирует создание core dump |
