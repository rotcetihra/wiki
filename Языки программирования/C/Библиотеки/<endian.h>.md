## Описание библиотеки

Заголовочный файл `<endian.h>` — порядок байтов. Определяет макросы для определения порядка байтов системы и преобразования между хост-порядком и сетевым (big-endian) или little-endian порядком.

### Константы

| Константа | Описание |
|---|---|
| `LITTLE_ENDIAN` | Константа little-endian порядка |
| `BIG_ENDIAN` | Константа big-endian порядка |
| `PDP_ENDIAN` | Константа PDP Endian порядка |
| `BYTE_ORDER` | Текущий порядок байтов системы |

### Макросы преобразования

| Макрос | Описание |
|---|---|
| `htobe16(x)` / `htobe32(x)` / `htobe64(x)` | Преобразование из хост-порядка в big-endian |
| `htole16(x)` / `htole32(x)` / `htole64(x)` | Преобразование из хост-порядка в little-endian |
| `be16toh(x)` / `be32toh(x)` / `be64toh(x)` | Преобразование из big-endian в хост-порядок |
| `le16toh(x)` / `le32toh(x)` / `le64toh(x)` | Преобразование из little-endian в хост-порядок |

### Использование

```c
#include <endian.h>

uint32_t network_order = htobe32(0x12345678);
uint32_t host_order = be32toh(network_order);

#if BYTE_ORDER == LITTLE_ENDIAN
    printf("Система использует Little-Endian\n");
#elif BYTE_ORDER == BIG_ENDIAN
    printf("Система использует Big-Endian\n");
#endif
```

## Исключения

- **NULL:** макросы не принимают `NULL`.
- **Безопасность типов:** макросы работают с любыми целочисленными типами (рекомендуется явное приведение).
- **Кросс-компиляция:** порядок байтов определяется при компиляции, не во время выполнения.
- **Многопоточность:** макросы не имеют побочных эффектов; потокобезопасны.

## Стандарты

BSD, glibc (не POSIX).
