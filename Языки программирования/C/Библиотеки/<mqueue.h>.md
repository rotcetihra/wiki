## Описание библиотеки

Заголовочный файл `<mqueue.h>` — очереди сообщений (Realtime). Определяет тип `mqd_t`, структуру `mq_attr` и функции для работы с POSIX-очередями сообщений.

### Структура `struct mq_attr`

```c
struct mq_attr {
    long mq_flags;    /* Флаги очереди (0) */
    long mq_maxmsg;   /* Максимальное количество сообщений */
    long mq_msgsize;  /* Максимальный размер сообщения */
    long mq_curmsgs;  /* Текущее количество сообщений в очереди */
};
```

### Функции

| Функция | Описание |
|---|---|
| `mq_open(const char *, int, ...)` | Создание/открытие очереди сообщений |
| `mq_close(mqd_t)` | Закрытие дескриптора очереди |
| `mq_unlink(const char *)` | Удаление очереди из системы |
| `mq_send(mqd_t, const char *, size_t, unsigned)` | Отправка сообщения с приоритетом |
| `mq_timedsend(...)` | Отправка с таймаутом |
| `mq_receive(mqd_t, char *, size_t, unsigned *)` | Приём сообщения |
| `mq_timedreceive(...)` | Приём с таймаутом |
| `mq_notify(mqd_t, const struct sigevent *)` | Регистрация уведомления |
| `mq_getattr(mqd_t, struct mq_attr *)` | Получение атрибутов очереди |
| `mq_setattr(mqd_t, const struct mq_attr *, struct mq_attr *)` | Установка атрибутов |

### Возвращаемое значение

- `mq_open()` возвращает дескриптор очереди или `(mqd_t)-1` при ошибке.
- `mq_send()`/`mq_receive()` возвращают `0` или количество прочитанных байтов или -1 при ошибке.
- `mq_close()`/`mq_unlink()` возвращают `0` или -1 при ошибке.

### Использование

```c
#include <mqueue.h>

mqd_t mq = mq_open("/my_queue", O_CREAT | O_RDWR, 0644, NULL);
if (mq == (mqd_t)-1) {
    perror("mq_open");
    return 1;
}

mq_send(mq, "Привет", 6, 0);

char buf[256];
unsigned prio;
ssize_t len = mq_receive(mq, buf, sizeof(buf), &prio);

mq_close(mq);
mq_unlink("/my_queue");
```

## Исключения

- **NULL:** `mq_open()` принимает `NULL` для атрибутов (по умолчанию).
- **(mqd_t)-1:** возвращается при ошибке `mq_open()`.
- **errno:** при ошибке устанавливается `errno` (например, `EACCES`, `EAGAIN`, `ENOMEM`, `ENOENT`).
- **EAGAIN:** очередь полна (для `mq_send()` без `O_NONBLOCK`).
- **ENOSYS:** функции очередей сообщений не поддерживаются (нет `CONFIG_POSIX_MQUEUE`).
- **Имена очередей:** должны начинаться с `/` и не содержать других символов `/`.
- **Многопоточность:** дескриптор очереди может использоваться несколькими потоками.

## Стандарты

POSIX.1-2017, Realtime.
