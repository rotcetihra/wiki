## Исключения

- **NULL:** `malloc()`, `calloc()`, `realloc()` возвращают `NULL` при нехватке памяти; поведение при передаче `NULL` в `free()` не определено.
- **errno:** функции преобразования строк (`strtod`, `strtol` и т. д.) устанавливают `errno = ERANGE` при переполнении и `errno = EINVAL` при неверном основании.
- **Переполнение:** функции `abs()`, `labs()`, `llabs()` не определены для минимального значения своего типа (например, `abs(INT_MIN)`).
- **Нехватка памяти:** `malloc()`, `calloc()`, `realloc()` возвращают `NULL` и устанавливают `errno = ENOMEM`.
- **Граничные случаи:** функции `ato*` не сообщают об ошибках; `rand()` возвращает числа от 0 до `RAND_MAX`.
- **Многопоточность:** функции не являются потокобезопасными; для безопасного использования требуют блокировки.
- **Завершение программы:** `exit()` вызывает функции, зарегистрированные через `atexit()`, и сбрасывает буферы; `_Exit()` — немедленное завершение без «уборки».
