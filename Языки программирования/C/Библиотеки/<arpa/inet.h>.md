## Описание библиотеки

Заголовочный файл `<arpa/inet.h>` — определения для Internet-операций. Определяет функции преобразования порядка байтов и строковых представлений IP-адресов.

### Функции преобразования порядка байтов

| Функция | Описание |
|---|---|
| `htonl(uint32_t)` | Преобразование 32-битного значения из порядка хоста в сетевой |
| `htons(uint16_t)` | Преобразование 16-битного значения из порядка хоста в сетевой |
| `ntohl(uint32_t)` | Преобразование 32-битного значения из сетевого порядка в порядок хоста |
| `ntohs(uint16_t)` | Преобразование 16-битного значения из сетевого порядка в порядок хоста |

### Функции преобразования адресов

| Функция | Описание |
|---|---|
| `inet_addr(const char *)` | Строка IPv4 → `in_addr_t` (устаревшая, не рекомендуется) |
| `inet_ntoa(struct in_addr)` | `in_addr` → строка IPv4 (устаревшая, не рекомендуется) |
| `inet_pton(int, const char *, void *)` | Строка → бинарный адрес (IPv4 или IPv6) |
| `inet_ntop(int, const void *, char *, socklen_t)` | Бинарный адрес → строка (IPv4 или IPv6) |

### Возвращаемое значение

- `htonl()`/`htons()`/`ntohl()`/`ntohs()` возвращают преобразованное значение.
- `inet_pton()` возвращает `1` при успехе, `0` при неверном адресе, -1 при ошибке.
- `inet_ntop()` возвращает указатель на строку или `NULL` при ошибке.

### Использование

```c
#include <arpa/inet.h>

/* Преобразование строка → адрес */
struct in_addr addr4;
inet_pton(AF_INET, "192.168.1.1", &addr4);

/* Преобразование адрес → строка */
char str[INET_ADDRSTRLEN];
inet_ntop(AF_INET, &addr4, str, sizeof(str));

/* Преобразование порта */
uint16_t port_net = htons(8080);
uint16_t port_host = ntohs(port_net);
```

## Исключения

- **NULL:** функции не принимают `NULL`.
- **errno:** `inet_pton()` может устанавливать `errno` (например, `EAFNOSUPPORT`).
- **EAFNOSUPPORT:** `af` не поддерживается (`AF_INET` или `AF_INET6`).
- **inet_addr:** не различает `INADDR_NONE` и ошибку; используйте `inet_pton()`.
- **inet_ntoa:** возвращает указатель на статический буфер; не потокобезопасна.
- **inet_ntop:** буфер `dst` должен быть достаточно большим (`INET_ADDRSTRLEN` или `INET6_ADDRSTRLEN`).
- **inet_pton:** принимает только строки; не принимает `::ffff:192.168.1.1` для `AF_INET`.
- **Многопоточность:** `inet_ntop()` потокобезопасна; `inet_ntoa()` — нет.
