## Определение

```c
#include <stdbool.h>

#define false 0  // C99–C17
false            // C23: ключевое слово
```

## Описание

Константа — логическая ложь, значение 0. В C99–C17 `false` — макрос, раскрывающийся в 0; в C23 — ключевое слово. Эквивалентна любому нулевому значению: `false == 0`, `0 == false`. При присваивании в `bool` получается значение 0.

## Примеры

```c
#include <stdbool.h>
#include <stdio.h>

int main(void)
{
    bool running = false;

    printf("running: %d\n", running);      // 0
    printf("false == 0: %d\n", false == 0); // 1

    if (!running) {
        printf("Не запущено\n");
    }

    return 0;
}
```
