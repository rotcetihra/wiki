## Определение

```c
#include <assert.h>

void assert(bool expression);
```

## Описание

Макрос `assert` проверяет выражение во время выполнения. Если выражение ложно (равно нулю), `assert()` выводит диагностическое сообщение в поток ошибок и завершает программу вызовом `abort()`. Сообщение содержит имя файла и функции, номер строки и текст выражения:

```
prog: some_file.c:16: some_func: Assertion `val == 0' failed.
```

Если перед включением `<assert.h>` определён макрос `NDEBUG`, макрос `assert()` не генерирует никакого кода и ничего не делает.

> [!WARNING]
> `assert()` реализован как макрос; если проверяемое выражение имеет побочные эффекты, поведение программы будет различаться в зависимости от того, определён ли `NDEBUG`. Это может создавать Heisenbugs.

## Возвращаемое значение

Не возвращает значения.

## Потоковая безопасность

MT-Safe.

## Примеры

```c
#include <assert.h>
#include <stdio.h>

int divide(int a, int b)
{
    assert(b != 0);
    return a / b;
}

int main(void)
{
    divide(10, 2);
    return 0;
}
```

## Стандарты

C11, POSIX.1-2008.

## История

C89, C99, POSIX.1-2001.

В C89 выражение должно быть типа `int`, но в C99 оно может быть любого скалярного типа.
