## Определение

```c
#define NDEBUG // определить до #include <assert.h> или флагом -DNDEBUG
```

## Описание

Если `NDEBUG` определён на момент последнего включения `<assert.h>`, макрос `assert()` не генерирует никакого кода и ничего не делает.

Обычно `NDEBUG` задают флагом компилятора `-DNDEBUG` при сборке релизных версий.

> [!WARNING]
> Не рекомендуется определять `NDEBUG`, если `assert()` используется для обработки ошибок — программа может вести себя недетерминировано.

## Примеры

```bash
gcc -DNDEBUG program.c -o program
```

```c
#include <assert.h>

void print(int *p)
{
    assert(p != NULL);
    printf("%d\n", *p);
}
```
