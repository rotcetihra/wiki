## Описание библиотеки

Заголовочный файл `<tgmath.h>` — обобщённые математические макросы. Этот заголовок включает заголовки `<math.h>` и `<complex.h>` и определяет обобщённые макросы, которые позволяют вызывать математические функции без необходимости указания суффиксов (`f` для `float`, `l` для `long double`).

### Принцип работы

Для каждой функции без суффикса в `<math.h>`, у которой есть соответствующая функция с префиксом `c` в `<complex.h>`, определён обобщённый макрос с тем же именем, что и функция в `<math.h>`.

### Правила определения типа

При использовании макроса вызывается функция, чей тип определяется следующим образом:

1. Если хотя бы один из аргументов для generic-параметров имеет тип `long double`, определяемый тип — `long double`.
2. В противном случае, если хотя бы один из аргументов для generic-параметров имеет тип `double` или является целочисленным, определяемый тип — `double`.
3. В противном случае определяемый тип — `float`.

### Функции без complex-аналога

Для функций в `<math.h>` без `c`-префикса в `<complex.h>` (кроме `modf`, `j0`, `j1`, `jn`, `y0`, `y1`, `yn`) обобщённые макросы имеют то же имя:

`atan2`, `cbrt`, `ceil`, `copysign`, `erf`, `erfc`, `exp2`, `expm1`, `fdim`, `floor`, `fma`, `fmax`, `fmin`, `fmod`, `frexp`, `hypot`, `ilogb`, `ldexp`, `lgamma`, `llrint`, `llround`, `log10`, `log1p`, `log2`, `logb`, `lrint`, `lround`, `nearbyint`, `nextafter`, `nexttoward`, `remainder`, `remquo`, `rint`, `round`, `scalbln`, `scalbn`, `tgamma`, `trunc`

### Функции только для комплексных чисел

Для функций в `<complex.h>`, не имеющих `c`-префикса:

`carg`, `cimag`, `conj`, `cproj`, `creal`

### Пример использования

```c
#include <tgmath.h>

int main(void) {
    int n = 5;
    float f = 3.14f;
    double d = 2.718;
    long double ld = 1.414L;
    float complex fc = 1.0f + 2.0fi;
    double complex dc = 3.0 + 4.0i;

    // Вызов sinh(int) → sinh(double)
    double r1 = sinh(n);

    // Вызов acosf(float)
    float r2 = acosf(f);

    // Вызов atanl(long double)
    long double r3 = atanl(ld);

    // Вызов clogf(float complex)
    float complex r4 = clogf(fc);

    // Вызов csqrt(double complex)
    double complex r5 = csqrt(dc);

    return 0;
}
```

> [!NOTE]
> Использование макроса с аргументами смешанного типа (например, `ceil(fc)`) приводит к неопределённому поведению.

## Исключения

- **NULL:** математические функции не принимают указатели, поэтому `NULL` не применим.
- **Неопределённое поведение:** использование обобщённого макроса с комплексным аргументом для функции, определённой только для вещественных чисел (например, `ceil(complex)`), приводит к неопределённому поведению.
- **Многопоточность:** макросы не генерируют внешних видимых исключений.
- **Совместимость:** большинство существующих C-программ не затрагивается при замене `<math.h>` на `<tgmath.h>`.
