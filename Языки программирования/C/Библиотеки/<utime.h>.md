## Описание библиотеки

Заголовочный файл `<utime.h>` — структура времени доступа и модификации. Определяет структуру `utimbuf` и функцию `utime()` для установки времён доступа и модификации файла.

### Структура `struct utimbuf`

```c
struct utimbuf {
    time_t actime;   /* Время доступа (секунды с Epoch) */
    time_t modtime;  /* Время модификации (секунды с Epoch) */
};
```

### Функция `utime()`

```c
int utime(const char *filename, const struct utimbuf *times);
```

| Параметр | Описание |
|---|---|
| `filename` | Имя файла |
| `times` | Указатель на структуру с временами; `NULL` — текущее время |

### Возвращаемое значение

Возвращает `0` при успехе или -1 при ошибке.

### Использование

```c
#include <utime.h>

struct utimbuf times;
times.actime = 1609459200;   /* 1 января 2021 */
times.modtime = 1609545600;  /* 2 января 2021 */
utime("file.txt", &times);

/* Установить текущее время */
utime("file.txt", NULL);
```

## Исключения

- **NULL:** `utime()` принимает `NULL` для `times` (устанавливает текущее время).
- **errno:** при ошибке устанавливается `errno` (например, `EACCES`, `ENOENT`).
- **Точность:** `utime()` работает с точностью до секунды.
- **Рекомендация:** используйте `utimensat()` из `<fcntl.h>` для наносекундной точности.
- **Будущее:** заголовок может быть удалён в будущих версиях стандарта.
- **Многопоточность:** функция потокобезопасна.

## Стандарты
