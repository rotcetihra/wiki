## Описание библиотеки

Заголовочный файл `<search.h>` — таблицы поиска. Определяет функции для работы с хеш-таблицами, линейными массивами, связными списками и бинарными деревьями.

### Типы и константы

```c
typedef struct {
    char *key;
    void *data;
} ENTRY;

enum { FIND, ENTER } ACTION;
enum { preorder, postorder, endorder, leaf } VISIT;
```

### Функции хеш-таблиц

| Функция | Описание |
|---|---|
| `hcreate(size_t)` | Создание хеш-таблицы с указанным количеством элементов |
| `hdestroy(void)` | Уничтожение хеш-таблицы |
| `hsearch(ENTRY, ACTION)` | Поиск или вставка элемента |

### Функции линейного поиска

| Функция | Описание |
|---|---|
| `lfind(const void *, const void *, size_t *, size_t, int (*)(const void *, const void *))` | Поиск элемента в массиве |
| `lsearch(const void *, void *, size_t *, size_t, int (*)(const void *, const void *))` | Поиск с вставкой |

### Функции деревьев

| Функция | Описание |
|---|---|
| `tsearch(const void *, void **, int (*)(const void *, const void *))` | Вставка в бинарное дерево |
| `tfind(const void *, void *const *, int (*)(const void *, const void *))` | Поиск в дереве |
| `tdelete(const void *restrict, void **restrict, int (*)(const void *, const void *))` | Удаление из дерева |
| `twalk(const void *, void (*)(const void *, VISIT, int))` | Обход дерева |

## Исключения

- **NULL:** `hsearch()` возвращает `NULL` при ошибке или если `action = FIND` и элемент не найден.
- **hcreate:** при ошибке (нехватка памяти) возвращает 0.
- **tsearch:** возвращает указатель на новый узел или `NULL` при ошибке.
- **twalk:** callback вызывается для каждого узла; не изменяйте дерево во время обхода.
- **Память:** хеш-таблицы и деревья выделяют память; освобождайте через `hdestroy()` и `tdelete()`.
- **Многопоточность:** функции не являются потокобезопасными.
