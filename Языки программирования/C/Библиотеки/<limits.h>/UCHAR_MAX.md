## Определение

```c
#include <limits.h>

#define UCHAR_MAX 255 // в glibc
```

## Описание

Константа — максимальное значение типа `unsigned char`. Стандарт гарантирует, что `UCHAR_MAX` не меньше 255; на всех распространённых платформах значение равно 255 (2⁸−1). `unsigned char` — единственный тип, для которого стандарт гарантирует отсутствие битов заполнения, поэтому `UCHAR_MAX` всегда точно равен 2ⁿ−1.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    for (unsigned char c = 0; ; c++) {
        printf("%u ", c);
        if (c == UCHAR_MAX) {
            break;
        }
    }

    printf("\n");

    return 0;
}
```
