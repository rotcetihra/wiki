## Определение

```c
#include <limits.h>

#define SCHAR_MIN (-128) // в glibc
```

## Описание

Константа — минимальное значение типа `signed char`. Стандарт гарантирует, что `SCHAR_MIN` не больше −127; на всех распространённых платформах значение равно −128. Записана в скобках с минусом, так как литерал −128 уже не помещается в `signed char` и требовал бы приведения.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("Минимум signed char: %d\n", SCHAR_MIN);

    return 0;
}
```
