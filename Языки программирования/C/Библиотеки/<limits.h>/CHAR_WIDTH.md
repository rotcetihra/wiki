## Определение

```c
#include <limits.h>

#define CHAR_WIDTH 8 // в glibc
```

## Описание

Константа (C23) — ширина типа `char`: количество битов в значении типа без учёта бита знака (для знакового `char` ширина на 1 меньше, чем `CHAR_BIT`). Значение всегда равно `CHAR_BIT` независимо от знаковости `char`. До C23 ширину приходилось вычислять как `CHAR_BIT * sizeof(тип)`.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("Ширина char: %d\n", CHAR_WIDTH);

    return 0;
}
```
