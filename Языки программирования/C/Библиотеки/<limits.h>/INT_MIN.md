## Определение

```c
#include <limits.h>

#define INT_MIN (-2147483647 - 1) // в glibc
```

## Описание

Константа — минимальное значение типа `int`. Стандарт гарантирует, что `INT_MIN` не больше −32767; на 32/64-битных платформах значение равно −2147483648. В glibc константа записана как `(-2147483647 - 1)`, потому что литерал −2147483648 не помещается в тип `int` и требует `long`.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    // Вычитание с проверкой переполнения
    int a = INT_MIN;
    int b = 1;

    if (a < INT_MIN + b) {
        printf("Переполнение\n");
    }

    return 0;
}
```
