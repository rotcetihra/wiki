## Определение

```c
#include <limits.h>

#define SHRT_MIN (-32768) // в glibc
```

## Описание

Константа — минимальное значение типа `short`. Стандарт гарантирует, что `SHRT_MIN` не больше −32767; на всех распространённых платформах значение равно −32768. Используется при работе с короткими целыми, когда требуется проверить переполнение.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("Минимум short: %d\n", SHRT_MIN);

    return 0;
}
```
