## Определение

```c
#include <limits.h>

#define SCHAR_MAX 127 // в glibc
```

## Описание

Константа — максимальное значение типа `signed char`. Стандарт гарантирует, что `SCHAR_MAX` не меньше 127; на всех распространённых платформах `signed char` занимает 8 бит, и это максимальное значение равно 127. От типа `char` отличается гарантированной знаковостью.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    signed char c = SCHAR_MAX;

    printf("Максимум signed char: %d\n", SCHAR_MAX);

    return 0;
}
```
