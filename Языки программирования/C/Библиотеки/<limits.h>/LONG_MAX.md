## Определение

```c
#include <limits.h>

#define LONG_MAX 9223372036854775807L // в glibc на 64-битных системах
```

## Описание

Константа — максимальное значение типа `long`. Стандарт гарантирует, что `LONG_MAX` не меньше 2147483647. На 64-битных платформах (Linux x86-64, aarch64 — модель LP64) `long` занимает 64 бита и значение равно 9223372036854775807; на 32-битных (Windows, Linux x86) — 32 бита и значение равно 2147483647. Это единственный целочисленный тип, размер которого различается между популярными платформами.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("Максимум long: %ld\n", LONG_MAX);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Доступен с C89 | Размер различается между 32/64-битными платформами |
