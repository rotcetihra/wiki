## Определение

```c
#include <limits.h>

#define BITINT_MAXWIDTH 65535 // в GCC/glibc
```

## Описание

Константа — максимальная ширина (количество битов) типа `_BitInt(n)` (C23), которую поддерживает реализация. Стандарт не требует, чтобы `BITINT_MAXWIDTH` был числом, представимым в стандартном целочисленном типе — в GCC это 65535. Типы `_BitInt(n)` с шириной больше максимума программа использовать не может.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("Максимальная ширина _BitInt: %d\n", BITINT_MAXWIDTH);

    return 0;
}
```
