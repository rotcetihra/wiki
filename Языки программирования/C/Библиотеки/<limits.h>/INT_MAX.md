## Определение

```c
#include <limits.h>

#define INT_MAX 2147483647 // в glibc
```

## Описание

Константа — максимальное значение типа `int`. Стандарт гарантирует, что `INT_MAX` не меньше 32767; на всех распространённых платформах (32/64-битных) `int` занимает 32 бита, поэтому значение равно 2147483647. Используется для проверки переполнения и как верхняя граница циклов и индексов.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    // Надёжная проверка переполнения при сложении
    int a = INT_MAX;
    int b = 1;

    if (a > INT_MAX - b) {
        printf("Переполнение\n");
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая проверка переполнения | Значение зависит от платформы (минимум 32767) |
