## Определение

```c
#include <limits.h>

#define UINT_MAX 4294967295U // в glibc
```

## Описание

Константа — максимальное значение типа `unsigned int`. Стандарт гарантирует, что `UINT_MAX` не меньше 65535; на всех распространённых платформах `unsigned int` занимает 32 бита, и значение равно 4294967295 (2³²−1). Суффикс `U` в определении гарантирует беззнаковый тип константы.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    unsigned int n = UINT_MAX;

    printf("Максимум unsigned int: %u\n", UINT_MAX);

    return 0;
}
```
