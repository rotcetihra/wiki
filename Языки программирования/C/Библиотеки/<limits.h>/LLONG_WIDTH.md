## Определение

```c
#include <limits.h>

#define LLONG_WIDTH 64 // в glibc
```

## Описание

Константа (C23) — ширина типа `long long`: количество битов в значении типа без учёта бита знака. По стандарту не меньше 63 (при минимуме `LLONG_MAX` 9223372036854775807), на всех распространённых платформах равна 64.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("Ширина long long: %d\n", LLONG_WIDTH);

    return 0;
}
```
