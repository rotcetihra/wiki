## Определение

```c
#include <limits.h>

#define LLONG_MIN (-LLONG_MAX - 1LL) // в glibc
```

## Описание

Константа (C99) — минимальное значение типа `long long`. Стандарт гарантирует, что `LLONG_MIN` не больше −9223372036854775807; на распространённых платформах значение равно −9223372036854775808. Как и `INT_MIN`, записана через `(-LLONG_MAX - 1LL)`, чтобы избежать литерала, не помещающегося в тип.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("Минимум long long: %lld\n", LLONG_MIN);

    return 0;
}
```
