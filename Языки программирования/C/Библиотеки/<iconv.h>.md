## Описание библиотеки

Заголовочный файл `<iconv.h>` — средство преобразования кодировок. Определяет тип `iconv_t` и функции для преобразования текста между различными кодировками символов.

### Тип `iconv_t`

Тип `iconv_t` идентифицирует преобразование из одной кодировки в другую.

### Функции

| Функция | Описание |
|---|---|
| `iconv_open(const char *, const char *)` | Открытие преобразования из `fromcode` в `tocode` |
| `iconv(iconv_t, char **restrict, size_t *restrict, char **restrict, size_t *restrict)` | Выполнение преобразования |
| `iconv_close(iconv_t)` | Закрытие дескриптора преобразования |

### Возвращаемое значение

- `iconv_open()` возвращает `(iconv_t)-1` при ошибке.
- `iconv()` возвращает количество полностью обработанных символов или `(size_t)-1` при ошибке.
- `iconv_close()` возвращает `0` при успехе или -1 при ошибке.

### Использование

```c
#include <iconv.h>

iconv_t cd = iconv_open("UTF-8", "ISO-8859-1");
if (cd == (iconv_t)-1) {
    perror("iconv_open");
    return 1;
}

char *inbuf = "Текст в ISO-8859-1";
size_t inbytesleft = strlen(inbuf);
char outbuf[256];
char *outptr = outbuf;
size_t outbytesleft = sizeof(outbuf);

size_t ret = iconv(cd, &inbuf, &inbytesleft, &outptr, &outbytesleft);
if (ret == (size_t)-1) {
    perror("iconv");
}

iconv_close(cd);
```

## Исключения

- **NULL:** `iconv_open()` не принимает `NULL`.
- **(iconv_t)-1:** возвращается при ошибке `iconv_open()`.
- **(size_t)-1:** возвращается при ошибке `iconv()` (например, `EILSEQ`, `EINVAL`).
- **EILSEQ:** неверная последовательность байтов во входных данных.
- **EINVAL:** неполная或多步овая последовательность на входе.
- **E2BIG:** выходной буфер заполнен.
- **Многопоточность:** `iconv_t` не является потокобезопасным; каждый поток должен использовать свой дескриптор.
