## Описание библиотеки

Заголовочный файл `<fcntl.h>` — параметры управления файлами. Этот заголовок определяет константы, структуры и функции для управления файловыми дескрипторами, блокировками и режимами доступа.

### Структура `struct flock`

```c
struct flock {
    short  l_type;    /* Тип блокировки: F_RDLCK, F_WRLCK, F_UNLCK */
    short  l_whence;  /* Флаг начального смещения: SEEK_SET, SEEK_CUR, SEEK_END */
    off_t  l_start;   /* Относительное смещение в байтах */
    off_t  l_len;     /* Размер; если 0, то до EOF */
    pid_t  l_pid;     /* PID процесса, владеющего блокировкой */
};
```

### Функции

| Функция | Описание |
|---|---|
| `open(const char *, int, ...)` | Открытие файла с флагами и режимом |
| `openat(int, const char *, int, ...)` | Открытие файла относительно каталога |
| `creat(const char *, mode_t)` | Создание файла (эквивалент `open` с `O_CREAT|O_WRONLY|O_TRUNC`) |
| `fcntl(int, int, ...)` | Управление файловым дескриптором |
| `posix_fadvise(int, off_t, off_t, int)` | Совет ядру о паттерне доступа |
| `posix_fallocate(int, off_t, off_t)` | Гарантированное выделение места |

## Исключения

- **NULL:** функции не принимают `NULL` в качестве имени файла.
- **errno:** при ошибке устанавливается `errno` (например, `EACCES`, `EEXIST`, `ENOENT`, `EINTR`).
- **Переполнение:** `open()` может открыть не более `OPEN_MAX` файловых дескрипторов.
- **Блокировки:** `F_SETLKW` блокирует процесс до получения блокировки; `F_SETLK` возвращает -1 с `EAGAIN` или `EACCES`.
- **Многопоточность:** блокировки файлов видны всем потокам процесса.
- **O_EXCL и O_CREAT:** атомарно создают файл; если файл существует — ошибка `EEXIST`.
