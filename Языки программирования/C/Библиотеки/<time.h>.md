## Описание библиотеки

Заголовочный файл `<time.h>` — типы даты и времени.

### Типы

| Тип | Описание |
|---|---|
| `clock_t` | Тип для представления времени процессора (определяется в `<sys/types.h>`) |
| `time_t` | Тип для представления календарного времени (определяется в `<sys/types.h>`) |
| `clockid_t` | Тип идентификатора часов (определяется в `<sys/types.h>`) |
| `timer_t` | Тип таймера (определяется в `<sys/types.h>`) |
| `locale_t` | Определяется в `<locale.h>` |
| `pid_t` | Определяется в `<sys/types.h>` |
| `struct tm` | Структура с разбитым временем |
| `struct timespec` | Структура с наносекундной точностью |
| `struct itimerspec` | Структура таймера |

### Структура `struct tm`

```c
struct tm {
    int tm_sec;    /* Секунды [0,60] */
    int tm_min;    /* Минуты [0,59] */
    int tm_hour;   /* Часы [0,23] */
    int tm_mday;   /* День месяца [1,31] */
    int tm_mon;    /* Месяц года [0,11] */
    int tm_year;   /* Годы с 1900 */
    int tm_wday;   /* День недели [0,6] (Воскресенье = 0) */
    int tm_yday;   /* День года [0,365] */
    int tm_isdst;  /* Флаг летнего времени */
};
```

Значение `tm_isdst` положительно, если действует летнее время; 0, если не действует; отрицательно, если информация недоступна.

### Структура `struct timespec`

```c
struct timespec {
    time_t  tv_sec;   /* Секунды */
    long    tv_nsec;  /* Наносекунды */
};
```

### Константы

| Константа | Описание |
|---|---|
| `CLOCKS_PER_SEC` | Число для преобразования значения `clock()` в секунды; на XSI-совместимых системах — 1 000 000 |
| `CLOCK_REALTIME` | Системные часы реального времени |
| `CLOCK_MONOTONIC` | Монотонные часы (не могут быть изменены через `clock_settime`) |
| `CLOCK_PROCESS_CPUTIME_ID` | Время процессора процесса |
| `CLOCK_THREAD_CPUTIME_ID` | Время процессора потока |
| `TIMER_ABSTIME` | Флаг, указывающий, что время является абсолютным |

## Исключения

- **NULL:** `localtime()`, `gmtime()`, `asctime()`, `ctime()` возвращают `NULL` при ошибке.
- **errno:** `clock_getres()`, `clock_gettime()`, `clock_settime()` устанавливают `errno` при ошибке.
- **Переполнение:** `mktime()` может вернуть `(time_t)-1` при переполнении.
- **Нехватка памяти:** `timer_create()` устанавливает `errno = ENOMEM` при нехватке памяти.
- **Граничные случаи:** `tm_sec` варьируется от 0 до 60 (включая високосную секунду); `tm_year` — число лет с 1900 (отрицательные значения допустимы для лет до 1900).
- **Многопоточность:** функции `asctime()`, `ctime()`, `gmtime()`, `localtime()` не являются потокобезопасными; используйте `_r` версии.
- **Летнее время:** `tm_isdst` положительно при действии летнего времени, 0 при его отсутствии, отрицательно при неизвестной информации.
