## Описание библиотеки

Заголовочный файл `<time.h>` — «дата и время» (date and time): функции для работы с календарным временем, временем процессора и форматированием дат. Определяет типы `time_t` (абсолютное время), `struct tm` (разбитое на компоненты), `clock_t` (время процессора) и `struct timespec` (время с наносекундной точностью), константы `CLOCKS_PER_SEC` и `TIME_UTC`, а также функции получения текущего времени, его преобразования и форматирования.

Стандартная библиотека C определяет минимальный набор функций для работы со временем. POSIX расширяет его функциями для наносекундной точности (`clock_gettime`, `timespec_get`), разбора строк (`strptime`, `getdate`) и управления часовыми поясами (`tzset`).

### Типы времени

| Тип | Описание |
|---|---|
| `time_t` | Абсолютное время (обычно количество секунд с эпохи) |
| `struct tm` | Разбитое время: секунды, минуты, часы, день, месяц, год и т. д. |
| `clock_t` | Время процессора (тики) |
| `struct timespec` | Секунды + наносекунды (C11) |

### Функции

| Функция | Описание |
|---|---|
| `time()` | Текущее календарное время |
| `clock()` | Время процессора |
| `difftime()` | Разность двух `time_t` в секундах |
| `mktime()` | `struct tm` → `time_t` |
| `localtime()` / `gmtime()` | `time_t` → `struct tm` (локальное/UTC) |
| `asctime()` / `ctime()` | Время в фиксированную строку |
| `strftime()` | Форматирование `struct tm` по шаблону |
| `timespec_get()` | Текущее время с наносекундной точностью (C11) |
| `clock_gettime()` | Время с наносекундной точностью (POSIX) |

> [!NOTE]
> Функции `asctime()`, `ctime()`, `localtime()` и `gmtime()` возвращают указатель на статический буфер — они не потокобезопасны. В POSIX-системах доступны потокобезопасные варианты `_r`: `asctime_r()`, `ctime_r()`, `localtime_r()`, `gmtime_r()`.
