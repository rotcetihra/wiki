## Описание библиотеки

Заголовочный файл `<sys/socket.h>` — основной заголовочный файл сокетов. Определяет типы, структуры и функции для работы с сетевыми сокетами.

### Структуры

#### `struct sockaddr`

```c
struct sockaddr {
    sa_family_t  sa_family;   /* Семейство адресов */
    char         sa_data[];   /* Адрес сокета (переменная длина) */
};
```

#### `struct sockaddr_storage`

```c
struct sockaddr_storage {
    sa_family_t  ss_family;
    /* ... реализация-зависимые поля ... */
};
```

Достаточно велика для хранения любого поддерживаемого протокольного адреса.

#### `struct msghdr`

```c
struct msghdr {
    void          *msg_name;       /* Опциональный адрес */
    socklen_t      msg_namelen;    /* Размер адреса */
    struct iovec  *msg_iov;        /* Массив scatter/gather */
    int            msg_iovlen;     /* Количество элементов */
    void          *msg_control;    /* Вспомогательные данные */
    socklen_t      msg_controllen; /* Размер буфера */
    int            msg_flags;      /* Флаги принятого сообщения */
};
```

## Исключения

- **NULL:** функции не принимают `NULL` в качестве адреса.
- **errno:** при ошибке устанавливается `errno` (например, `EACCES`, `EADDRINUSE`, `ECONNREFUSED`, `ENOTSOCK`).
- **EACCES:** нет прав для привязки к адресу.
- **EADDRINUSE:** адрес уже используется.
- **ECONNREFUSED:** соединение отклонено.
- **EINVAL:** неверный аргумент.
- **ENOTSOCK:** файловый дескриптор не является сокетом.
- **EWOULDBLOCK/BLOCK:** операция заблокирована (неблокирующий режим).
- **Многопоточность:** функции потокобезопасны.
- **socklen_t:** рекомендуется не использовать значения больше 2^31 - 1.
