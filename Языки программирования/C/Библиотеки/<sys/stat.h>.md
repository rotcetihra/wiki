## Описание библиотеки

Заголовочный файл `<sys/stat.h>` — данные, возвращаемые функцией `stat()`. Определяет структуру `stat` и константы для работы с информацией о файлах.

### Структура `struct stat`

```c
struct stat {
    dev_t     st_dev;       /* ID устройства, содержащего файл */
    ino_t     st_ino;       /* Серийный номер файла */
    mode_t    st_mode;      /* Режим файла */
    nlink_t   st_nlink;     /* Количество жёстких ссылок */
    uid_t     st_uid;       /* ID пользователя */
    gid_t     st_gid;       /* ID группы */
    dev_t     st_rdev;      /* ID устройства (для спец. файлов) */
    off_t     st_size;      /* Размер в байтах (для обычных файлов) */
    struct timespec st_atim; /* Последний доступ */
    struct timespec st_mtim; /* Последнее изменение */
    struct timespec st_ctim; /* Последнее изменение статуса */
    blksize_t st_blksize;   /* Предпочтительный размер блока I/O */
    blkcnt_t  st_blocks;    /* Количество выделенных блоков */
};
```

Поля `st_ino` и `st_dev` вместе уникально идентифицируют файл в системе.

Макросы совместимости: `st_atime` = `st_atim.tv_sec`, `st_mtime` = `st_mtim.tv_sec`, `st_ctime` = `st_ctim.tv_sec`.

## Исключения

- **NULL:** `stat()`, `lstat()`, `chmod()` и т.д. возвращают -1 при ошибке и устанавливают `errno`.
- **errno:** при ошибке устанавливается `errno` (например, `EACCES`, `ENOENT`, `ENOTDIR`).
- **S_ISUID и S_ISGID:** могут быть очищены при любой операции записи, а не только при `open()`.
- **st_blocks:** единица измерения не определена POSIX (обычно 512 байтов).
- **Время:**.timestamps немедленно приводятся к разрешению файловой системы путём усечения.
- **Многопоточность:** функции потокобезопасны.
