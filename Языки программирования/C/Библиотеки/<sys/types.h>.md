## Описание библиотеки

Заголовочный файл `<sys/types.h>` — типы данных. Определяет типы, используемые в системных вызовах POSIX.

### Типы, определённые стандартом

| Тип | Описание | Категория |
|---|---|---|
| `blkcnt_t` | Количество блоков файла | Арифметический знаковый |
| `blksize_t` | Размер блока | Арифметический знаковый |
| `clock_t` | Системное время в тиках | Арифметический (знаковый или float) |
| `clockid_t` | ID таймера | Арифметический |
| `dev_t` | ID устройства | Арифметический целый |
| `fsblkcnt_t` | Количество блоков ФС | Арифметический беззнаковый |
| `fsfilcnt_t` | Количество файлов ФС | Арифметический беззнаковый |
| `gid_t` | ID группы | Арифметический целый |
| `id_t` | Общий идентификатор | Арифметический |
| `ino_t` | Серийный номер файла | Арифметический беззнаковый |
| `key_t` | Ключ IPC XSI | Арифметический |
| `mode_t` | Режим файла | Арифметический целый |
| `nlink_t` | Количество ссылок | Арифметический целый |
| `off_t` | Размер файла | Арифметический знаковый |
| `pid_t` | ID процесса | Арифметический знаковый |
| `size_t` | Беззнаковый размер | Арифметический беззнаковый |
| `ssize_t` | Знаковый размер или ошибка | Арифметический знаковый |
| `suseconds_t` | Время в микросекундах | Арифметический знаковый |
| `time_t` | Время в секундах | Арифметический целый |
| `uid_t` | ID пользователя | Арифметический целый |

Тип `ssize_t` должен хранить значения в диапазоне [-1, {SSIZE_MAX}].
Тип `suseconds_t` должен хранить значения в диапазоне [-1, 1000000].

## Исключения

- **NULL:** заголовок не содержит функций.
- **Определения:** этот заголовок определяет только типы; конкретные значения зависят от реализации.
- **Типы потоков:** типы `pthread_*` не являются арифметическими и не поддерживают операции сравнения/присваивания.
- **Размеры:** ширина `blksize_t`, `pid_t`, `size_t`, `ssize_t` и `suseconds_t` не должна превышать ширину `long`.

## Стандарты

POSIX.1-2017.
