## Описание библиотеки

Заголовочный файл `<sys/mman.h>` — объявления управления памятью. Определяет функции и константы для отображения файлов в память, управления защитой страниц и работы с разделяемой памятью.

### Константы защиты

| Константа | Описание |
|---|---|
| `PROT_NONE` | Страница недоступна |
| `PROT_READ` | Страница доступна для чтения |
| `PROT_WRITE` | Страница доступна для записи |
| `PROT_EXEC` | Страница исполняемая |

### Константы отображения

| Константа | Описание |
|---|---|
| `MAP_SHARED` | Изменения видимы другим процессам |
| `MAP_PRIVATE` | Изменения приватны (copy-on-write) |
| `MAP_FIXED` | Интерпретировать `addr` точно |

### Функции

| Функция | Описание |
|---|---|
| `mmap(void *, size_t, int, int, int, off_t)` | Отображение файла или устройства в память |
| `munmap(void *, size_t)` | Отмена отображения |
| `mprotect(void *, size_t, int)` | Изменение защиты страниц |
| `msync(void *, size_t, int)` | Синхронизация отображённой памяти с файлом |
| `mlock(const void *, size_t)` | Блокировка страниц в оперативной памяти |
| `munlock(const void *, size_t)` | Разблокировка страниц |
| `mlockall(int)` | Блокировка всех страниц процесса |
| `munlockall(void)` | Разблокировка всех страниц |
| `posix_madvise(void *, size_t, int)` | Совет по паттерну доступа |
| `shm_open(const char *, int, mode_t)` | Открытие объекта разделяемой памяти |
| `shm_unlink(const char *)` | Удаление объекта разделяемой памяти |

### Возвращаемое значение

- `mmap()` возвращает отображённый адрес или `MAP_FAILED` при ошибке.
- Остальные функции возвращают `0` при успехе или -1 при ошибке.

## Исключения

- **NULL:** функции не принимают `NULL`.
- **errno:** при ошибке устанавливается `errno` (например, `EACCES`, `EBADF`, `EINVAL`, `ENODEV`, `ENOMEM`, `ENXIO`, `EOVERFLOW`).
- **EACCES:** нет прав для отображения файла.
- **EBADF:** неверный файловый дескриптор.
- **EINVAL:** неверные аргументы (например, не выровнено на границу страницы для `MAP_FIXED`).
- **ENOMEM:** недостаточно памяти.
- **MAP_FAILED:** `mmap()` возвращает `(void *)-1` при ошибке.
- **mlock:** ограничивается системными лимитами (`RLIMIT_MEMLOCK`).
- **Многопоточность:** функции потокобезопасны.
- **fork:** отображения `MAP_SHARED` наследуются дочерним процессом.

## Стандарты

POSIX.1-2017, SIO.
