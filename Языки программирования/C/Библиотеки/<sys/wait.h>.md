## Описание библиотеки

Заголовочный файл `<sys/wait.h>` — объявления для ожидания. Определяет константы, макросы и функции для ожидания завершения дочерних процессов.

### Константы для `waitpid`

| Константа | Описание |
|---|---|
| `WCONTINUED` | Возвращать статус продолжённого процесса |
| `WNOHANG` | Если статус недоступен — вернуть немедленно |
| `WUNTRACED` | Возвращать статус остановленного процесса |

### Макросы анализа статуса

| Макрос | Описание |
|---|---|
| `WIFEXITED(status)` | Истинно, если процесс завершился нормально |
| `WEXITSTATUS(status)` | Получить код возврата (младшие 8 бит) |
| `WIFSIGNALED(status)` | Истинно, если процесс завершён сигналом |
| `WTERMSIG(status)` | Получить номер сигнала завершения |
| `WIFSTOPPED(status)` | Истинно, если процесс остановлен |
| `WSTOPSIG(status)` | Получить номер сигнала остановки |
| `WIFCONTINUED(status)` | Истинно, если процесс продолжен |

### Константы для `waitid`

| Константа | Описание |
|---|---|
| `WEXITED` | Ожидать завершённые процессы |
| `WNOWAIT` | Оставить процесс в состоянии ожидания |
| `WSTOPPED` | Статус для остановленных процессов |

### Функции

| Функция | Описание |
|---|---|
| `wait(int *)` | Ожидание завершения любого дочернего процесса |
| `waitpid(pid_t, int *, int)` | Ожидание конкретного процесса с флагами |
| `waitid(idtype_t, id_t, siginfo_t *, int)` | Расширенное ожидание с информацией |

### Значение возврата

- `wait()` и `waitpid()` возвращают PID завершённого процесса или -1 при ошибке.
- `waitid()` возвращает 0 при успехе или -1 при ошибке.

## Исключения

- **NULL:** `wait()`, `waitpid()` и `waitid()` не принимают `NULL`.
- **errno:** при ошибке устанавливается `errno` (например, `ECHILD`, `EINTR`).
- **ECHILD:** нет дочерних процессов.
- **EINTR:** вызов прерван сигналом.
- **WNOHANG:** если нет завершённых процессов — возвращает 0 (для `waitpid`) или 0 (для `waitid` с `WNOWAIT`).
- **Многопоточность:** один и тот же дочерний процесс не может быть ожидаем несколькими потоками одновременно.
- **Одновременное использование:** не используйте `wait()` и `waitpid()` одновременно для одних и тех же дочерних процессов.

## Стандарты

POSIX.1-2017, XSI.
