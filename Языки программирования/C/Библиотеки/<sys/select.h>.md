## Описание библиотеки

Заголовочный файл `<sys/select.h>` — типы select. Определяет функцию `select()` для мультиплексирования ввода-вывода по нескольким файловым дескрипторам.

### Структура `struct timeval`

```c
struct timeval {
    time_t      tv_sec;   /* Секунды */
    suseconds_t tv_usec;  /* Микросекунды */
};
```

### Тип `fd_set`

Тип `fd_set` — структура для хранения набора файловых дескрипторов. Максимальное количество определяется `FD_SETSIZE`.

### Макросы

| Макрос | Описание |
|---|---|
| `FD_ZERO(fd_set *)` | Очистка набора (установка всех бит в 0) |
| `FD_SET(int, fd_set *)` | Добавление файлового дескриптора в набор |
| `FD_CLR(int, fd_set *)` | Удаление файлового дескриптора из набора |
| `FD_ISSET(int, fd_set *)` | Проверка: находится ли дескриптор в наборе (возвращает 0 или не 0) |

> **Важно:** если макросы реализованы как функции, они могут вычислять аргументы несколько раз. Не передавайте выражения с побочными эффектами.

### Функции

| Функция | Описание |
|---|---|
| `select(int, fd_set *, fd_set *, fd_set *, struct timeval *)` | Ожидание события на одном или нескольких дескрипторах |
| `pselect(int, fd_set *, fd_set *, fd_set *, const struct timespec *, const sigset_t *)` | То же, но с маской сигналов |

### Возвращаемое значение

- `select()` и `pselect()` возвращают количество готовых файловых дескрипторов, 0 при таймауте или -1 при ошибке.

### Использование

```c
#include <sys/select.h>

fd_set read_fds;
struct timeval timeout;

FD_ZERO(&read_fds);
FD_SET(fd1, &read_fds);
FD_SET(fd2, &read_fds);

timeout.tv_sec = 5;
timeout.tv_usec = 0;

int ready = select(FD_SETSIZE, &read_fds, NULL, NULL, &timeout);
if (ready > 0) {
    if (FD_ISSET(fd1, &read_fds)) { /* fd1 готов */ }
    if (FD_ISSET(fd2, &read_fds)) { /* fd2 готов */ }
}
```

## Исключения

- **NULL:** функции не принимают `NULL` в качестве набора (хотя `NULL` допустим для неиспользуемых наборов).
- **errno:** при ошибке устанавливается `errno` (например, `EBADF`, `EINTR`, `EINVAL`).
- **EBADF:** неверный файловый дескриптор в наборе.
- **EINTR:** вызов прерван сигналом.
- **EINVAL:** неверный аргумент (например, таймаут отрицательный).
- **FD_SETSIZE:** стандарт POSIX не определяет значение `FD_SETSIZE`; на Linux оно равно 1024.
- **Многопоточность:** функции потокобезопасны.
- **pselect:**原子арно блокирует и ждёт сигналы (в отличие от `select()`).

## Стандарты

POSIX.1-2017, XSI.
