## Описание библиотеки

Заголовочный файл `<syslog.h>` — определения для системного журналирования. Определяет константы и функции для отправки сообщений в системный журнал (syslog).

### Константы logopt (для `openlog()`)

| Константа | Описание |
|---|---|
| `LOG_PID` | Регистрация PID с каждым сообщением |
| `LOG_CONS` | Вывод в консоль при ошибке доставки |
| `LOG_NDELAY` | Немедленное подключение к демону |
| `LOG_ODELAY` | Отсрочка подключения до первого `syslog()` |
| `LOG_NOWAIT` | Не ожидать дочерние процессы |

### Константы facility

| Константа | Описание |
|---|---|
| `LOG_KERN` | Сообщения ядра |
| `LOG_USER` | Сообщения процесса |
| `LOG_MAIL` | Почтовая система |
| `LOG_DAEMON` | Системный демон |
| `LOG_AUTH` | Авторизация |
| `LOG_CRON` | Часовой демон |
| `LOG_LPR` | Система печати |
| `LOG_LOCAL0`–`LOG_LOCAL7` | Локальное использование |

### Константы priority

| Константа | Описание |
|---|---|
| `LOG_EMERG` | Паническое состояние (все процессы) |
| `LOG_ALERT` | Требующее немедленного исправления |
| `LOG_CRIT` | Критическое состояние |
| `LOG_ERR` | Сообщение об ошибке |
| `LOG_WARNING` | Предупреждение |
| `LOG_NOTICE` | Требующее особой обработки |
| `LOG_INFO` | Информационное сообщение |
| `LOG_DEBUG` | Отладочное сообщение |

### Функции

| Функция | Описание |
|---|---|
| `openlog(const char *ident, int logopt, int facility)` | Открытие соединения с syslog |
| `syslog(int priority, const char *format, ...)` | Отправка сообщения |
| `closelog(void)` | Закрытие соединения |
| `setlogmask(int maskpri)` | Установка маски приоритетов |

### Использование

```c
#include <syslog.h>

openlog("myapp", LOG_PID | LOG_NDELAY, LOG_USER);
syslog(LOG_INFO, "Программа запущена");
syslog(LOG_ERR, "Ошибка чтения файла: %s", strerror(errno));
closelog();
```

## Исключения

- **NULL:** `openlog()` и `syslog()` принимают `NULL` для `ident`/`format`.
- **setlogmask():** возвращает предыдущую маску.
- **LOG_MASK(pri):** макрос для создания маски приоритета.
- **Отсутствие syslog:** если демон не запущен, сообщения могут быть потеряны.
- **Многопоточность:** функции потокобезопасны.
