## Описание библиотеки

Заголовочный файл `<cpio.h>` — константы архива cpio. Определяет константы прав доступа и типов файлов для формата архива `cpio`, используемые в поле `c_mode` заголовка архива.

### Константы прав доступа

| Константа | Значение (восьм.) | Описание |
|---|---|---|
| `C_IRUSR` | 0000400 | Чтение владельцем |
| `C_IWUSR` | 0000200 | Запись владельцем |
| `C_IXUSR` | 0000100 | Выполнение владельцем |
| `C_IRGRP` | 0000040 | Чтение группой |
| `C_IWGRP` | 0000020 | Запись группой |
| `C_IXGRP` | 0000010 | Выполнение группой |
| `C_IROTH` | 0000004 | Чтение другими |
| `C_IWOTH` | 0000002 | Запись другими |
| `C_IXOTH` | 0000001 | Выполнение другими |

### Константы типов файлов

| Константа | Значение (восьм.) | Описание |
|---|---|---|
| `C_ISUID` | 0004000 | Установка ID при выполнении |
| `C_ISGID` | 0002000 | Установка группы при выполнении |
| `C_ISVTX` | 0001000 | Ограниченное удаление |
| `C_ISDIR` | 0040000 | Каталог |
| `C_ISFIFO` | 0010000 | FIFO |
| `C_ISREG` | 0100000 | Обычный файл |
| `C_ISBLK` | 0060000 | Блочный устройственный файл |
| `C_ISCHR` | 0020000 | Символьный устройственный файл |
| `C_ISLNK` | 0120000 | Символическая ссылка |
| `C_ISSOCK` | 0140000 | Сокет |

### Константа

| Константа | Значение | Описание |
|---|---|---|
| `MAGIC` | `"070707"` | Магическая строка формата cpio |

### Использование

```c
#include <cpio.h>

/* Проверка типа файла из c_mode */
if (c_mode & C_ISREG) {
    printf("Обычный файл\n");
}
if (c_mode & C_ISDIR) {
    printf("Каталог\n");
}
```

## Исключения

- **Константы:** все значения определены как константы времени компиляции.
- **Формат:** заголовочный файл описывает только формат архива, не предоставляет функций для работы с ним.
- **MAGIC:** константа `MAGIC` не является макросом времени компиляции (строковый литерал).
- **Многопоточность:** не применимо (только константы).
