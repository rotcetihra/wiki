## Описание библиотеки

Заголовочный файл `<fenv.h>` — «окружение с плавающей точкой» (floating-point environment): функции для управления исключениями, направлением округления и средой вычислений с плавающей точкой. Определяет типы `fenv_t` (текущая среда) и `fexcept_t` (флаги исключений), константы исключений (`FE_DIVBYZERO`, `FE_INEXACT`, `FE_INVALID`, `FE_OVERFLOW`, `FE_UNDERFLOW`, `FE_ALL_EXCEPT`), константы направления округления (`FE_DOWNWARD`, `FE_TONEAREST`, `FE_TOWARDZERO`, `FE_UPWARD`), константу среды по умолчанию `FE_DFL_ENV`, а также функции управления исключениями, округлением и средой.

Библиотека введена в стандарт C99 и позволяет приложениям контролировать поведение арифметических операций с плавающей точкой: определять, какие исключения обрабатываются, как округляются результаты, и сохранять/восстанавливать среду вычислений. Это полезно для реализации пользовательской обработки ошибок, портирования кода между платформами с разным поведением по умолчанию и написания тестов с точным контролем над арифметикой.

> [!NOTE]
> Константы `FE_*` являются битовыми масками и могут комбинироваться через побитовое ИЛИ (`|`). Точные значения бит определены реализацией, поэтому для проверки конкретного исключения следует использовать побитовое И (`&`), а не сравнение на равенство.

> [!WARNING]
> По умолчанию большинство исключений с плавающей точкой игнорируются (не приводят к аварийному завершению программы). Для обнаружения ошибок необходимо явно запросить генерацию исключения через `feraiseexcept` или аналогичные средства.

### Типы

| Тип | Описание |
|---|---|
| `fenv_t` | Текущая среда с плавающей точкой (направление округления, флаги исключений) |
| `fexcept_t` | Состояние флагов исключений с плавающей точкой |

### Константы исключений

| Константа | Описание |
|---|---|
| `FE_DIVBYZERO` | Деление на ноль (не `0.0/0.0`, а `x/0.0` где `x ≠ 0`) |
| `FE_INEXACT` | Результат не может быть представлен точно |
| `FE_INVALID` | Недопустимая операция (например, `0.0/0.0`, `sqrt(-1)`) |
| `FE_OVERFLOW` | Результат слишком велик для представления |
| `FE_UNDERFLOW` | Результат слишком мал для нормального представления |
| `FE_ALL_EXCEPT` | Битовая маска всех поддерживаемых исключений |

### Константы направления округления

| Константа | Описание |
|---|---|
| `FE_DOWNWARD` | Округление к минус бесконечности |
| `FE_TONEAREST` | Округление к ближайшему (стандартное поведение IEEE 754) |
| `FE_TOWARDZERO` | Округление к нулю (усечение) |
| `FE_UPWARD` | Округление к плюс бесконечности |
| `FE_DFL_ENV` | Среда по умолчанию (уникальный объект, не указатель) |

### Функции

| Функция | Описание |
|---|---|
| `feclearexcept()` | Сброс указанных флагов исключений |
| `fegetexceptflag()` | Копирование флагов исключений в `fexcept_t` |
| `feraiseexcept()` | Генерация указанных исключений |
| `fesetexceptflag()` | Восстановление флагов из `fexcept_t` |
| `fetestexcept()` | Проверка, какие из указанных исключений активны |
| `fegetround()` | Получение текущего направления округления |
| `fesetround()` | Установка направления округления |
| `fegetenv()` | Сохранение текущей среды в `fenv_t` |
| `feholdexcept()` | Сохранение среды, сброс исключений и возврат предыдущего состояния |
| `fesetenv()` | Установка среды из `fenv_t` |
| `feupdateenv()` | Восстановление среды и повторная генерация сохранённых исключений |

> [!NOTE]
> Функции `<fenv.h>` могут быть реализованы как макросы. Установка направления округления или сброс исключений может повлиять на результаты ранее выполненных вычислений, если они ещё не были записаны в память.
