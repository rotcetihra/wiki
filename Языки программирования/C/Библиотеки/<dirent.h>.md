## Описание библиотеки

Заголовочный файл `<dirent.h>` — формат записей каталога. Внутренний формат каталогов не определён стандартом.

### Структура `struct dirent`

```c
struct dirent {
    ino_t  d_ino;    /* Серийный номер файла */
    char   d_name[]; /* Имя файла (массив неизвестного размера) */
};
```

Массив `d_name` имеет неопределённый размер, но должен содержать имя файла размером не более `{NAME_MAX}` байтов с завершающим нулевым символом. Не используйте `sizeof(d_name)` — используйте `strlen(d_name)`.

## Исключения

- **NULL:** `opendir()` и `fdopendir()` возвращают `NULL` при ошибке и устанавливают `errno`.
- **errno:** при ошибке устанавливается `errno` (например, `ENOENT`, `ENOTDIR`, `EACCES`).
- ** readdir:** возвращает `NULL` при ошибке или конце каталога; различие определяется через `errno`.
- **readdir_r:** возвращает `0` при успехе, `EBADF` при неверном дескрипторе.
- **Память:** `scandir()` выделяет память через `malloc()`; освобождайте через `free()`.
- **Многопоточность:** `readdir_r()` потокобезопасна; `readdir()` может возвращать одну и ту же запись в разных потоках.
