## Описание библиотеки

Заголовочный файл `<byteswap.h>` — обращение порядка байтов. Определяет макросы для обращения (swap) порядка байтов 16-, 32- и 64-битных значений.

### Макросы

| Макрос | Описание |
|---|---|
| `bswap_16(x)` | Обращение байтов 16-битного значения |
| `bswap_32(x)` | Обращение байтов 32-битного значения |
| `bswap_64(x)` | Обращение байтов 64-битного значения |

### Использование

```c
#include <byteswap.h>

uint32_t value = 0x12345678;
uint32_t swapped = bswap_32(value);
/* swapped = 0x78563412 */
```

## Исключения

- **NULL:** макросы не принимают `NULL`.
- **Оптимизация:** макросы оптимизированы для целочисленных типов.
- **Побочные эффекты:** аргумент вычисляется дважды (макрос).
- **Многопоточность:** макросы не имеют побочных эффектов; потокобезопасны.

## Стандарты
