## Описание библиотеки

Заголовочный файл `<sysexits.h>` — коды завершения системных программ. Определяет стандартные коды возврата для системных программ (sendmail, сетевые утилиты и т. д.).

### Константы

| Константа | Значение | Описание |
|---|---|---|
| `EX_OK` | 0 | Успешное завершение |
| `EX_USAGE` | 64 | Неправильное использование команды |
| `EX_DATAERR` | 65 | Ошибка формата данных |
| `EX_NOINPUT` | 66 | Невозможно открыть входной файл |
| `EX_NOUSER` | 67 | Пользователь не найден |
| `EX_NOHOST` | 68 | Хост не найден |
| `EX_UNAVAILABLE` | 69 | Сервис недоступен |
| `EX_SOFTWARE` | 70 | Внутренняя ошибка ПО |
| `EX_OSERR` | 71 | Ошибка ОС (fork, pipe и т. д.) |
| `EX_OSFILE` | 72 | Отсутствует критический системный файл |
| `EX_CANTCREAT` | 73 | Невозможно создать выходной файл |
| `EX_IOERR` | 74 | Ошибка ввода-вывода |
| `EX_TEMPFAIL` | 75 | Временная ошибка (повторите позже) |
| `EX_PROTOCOL` | 76 | Ошибка протокола |
| `EX_NOPERM` | 77 | Недостаточно прав |
| `EX_CONFIG` | 78 | Ошибка конфигурации |

### Использование

```c
#include <sysexits.h>
#include <stdlib.h>

if (argc < 2) {
    fprintf(stderr, "Использование: %s <файл>\n", argv[0]);
    exit(EX_USAGE);
}

FILE *f = fopen(argv[1], "r");
if (f == NULL) {
    perror(argv[1]);
    exit(EX_NOINPUT);
}
```

## Исключения

- **Константы:** все значения определены как макросы времени компиляции.
- **Диапазон:** коды от 64 до 78 (оставлены для системных программ).
- **Не POSIX:** заголовок не является частью POSIX; используется в BSD и Linux.
- **Применение:** рекомендуется для системных программ и утилит.
- **Многопоточность:** не применимо (только константы).

## Стандарты

BSD (не POSIX).
