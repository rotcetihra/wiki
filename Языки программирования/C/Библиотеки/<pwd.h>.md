## Описание библиотеки

Заголовочный файл `<pwd.h>` — структура passwd. Определяет структуру `passwd` и функции для доступа к базе данных пользователей.

### Структура `struct passwd`

```c
struct passwd {
    char  *pw_name;   /* Имя пользователя (логин) */
    uid_t  pw_uid;    /* Числовой ID пользователя */
    gid_t  pw_gid;    /* Числовой ID группы */
    char  *pw_dir;    /* Начальный рабочий каталог */
    char  *pw_shell;  /* Программа-оболочка по умолчанию */
    /* ... дополнительные поля ... */
};
```

### Функции

| Функция | Описание |
|---|---|
| `getpwnam(const char *)` | Поиск пользователя по имени |
| `getpwnam_r(const char *, struct passwd *, char *, size_t, struct passwd **)` | Потокобезопасный поиск по имени |
| `getpwuid(uid_t)` | Поиск пользователя по числовому ID |
| `getpwuid_r(uid_t, struct passwd *, char *, size_t, struct passwd **)` | Потокобезопасный поиск по UID |
| `getpwent(void)` | Получение следующей записи из базы пользователей |
| `setpwent(void)` | Начало последовательного чтения базы |
| `endpwent(void)` | Завершение последовательного чтения |

### Возвращаемое значение

- `getpwnam()` и `getpwuid()` возвращают указатель на `struct passwd` или `NULL` (пользователь не найден).
- Потокобезопасные функции `_r` возвращают `0` при успехе, `ENOENT` (не найдено) или другой код ошибки.

### Использование

```c
#include <pwd.h>

struct passwd *pw = getpwnam("username");
if (pw) {
    printf("Имя: %s\n", pw->pw_name);
    printf("UID: %d\n", pw->pw_uid);
    printf("GID: %d\n", pw->pw_gid);
    printf("Домашний каталог: %s\n", pw->pw_dir);
    printf("Оболочка: %s\n", pw->pw_shell);
}

/* Текущий пользователь */
uid_t uid = getuid();
pw = getpwuid(uid);
```

## Исключения

- **NULL:** функции возвращают `NULL` при ошибке или если пользователь не найден.
- **Память:** указатель на `struct passwd` указывает на статический буфер; не освобождайте его.
- **getpwnam_r/getpwuid_r:** выделяют память через буфер вызывающего; при `ERANGE`增大 буфер.
- **Многопоточность:** потокобезопасные функции `_r` рекомендуются для многопоточных программ.
- **setpwent/endpwent:** используют статические буферы; не используйте в многопоточной среде без синхронизации.
