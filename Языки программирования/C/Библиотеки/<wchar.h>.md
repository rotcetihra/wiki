## Описание библиотеки

Заголовочный файл `<wchar.h>` — обработка широких символов. Этот заголовок предоставляет функции для работы со строками宽幅ных символов, включая ввод-вывод, преобразование, классификацию и манипуляции памятью.

### Типы

| Тип | Описание |
|---|---|
| `mbstate_t` | Объектный тип для хранения состояния преобразования между многобайтовыми и宽幅ными символами |
| `wint_t` | Целочисленный тип, способный хранить любой `wchar_t` или `WEOF` |
| `wctype_t` | Скалярный тип для хранения информации о классификации символов |
| `wchar_t` | Тип宽幅ного символа (из `<stddef.h>`) |

### Константы

| Константа | Описание |
|---|---|
| `WCHAR_MAX` | Максимальное значение `wchar_t` |
| `WCHAR_MIN` | Минимальное значение `wchar_t` |
| `WEOF` | Константа типа `wint_t`, возвращаемая функциями宽幅ного ввода-вывода для указания конца файла |
| `NULL` | Нулевой указатель |

## Исключения

- **NULL:** функции, принимающие указатели на строки, не определены для `NULL`.
- **errno:** функции ввода-вывода устанавливают `errno` при ошибке.
- **WEOF:** функции ввода-вывода возвращают `WEOF` при ошибке или конце файла.
- **Многобайтовые последовательности:** функции преобразования обрабатывают неполные последовательности через `mbstate_t`.
- **Многопоточность:** функции не являются потокобезопасными; для безопасного использования требуют блокировки.
- **Локаль:** поведение функций классификации зависит от категории `LC_CTYPE` текущей локали.
