## Описание

Заголовочный файл `<inttypes.h>` определяет макросы форматирования для функций `printf` и `scanf`, которые позволяют портированно печатать и читать целочисленные типы фиксированной ширины (`int8_t`, `uint16_t`, `intmax_t` и т. д.), а также тип `imaxdiv_t` для результата деления. Макросы форматирования подставляются в строку формата: `PRId64` — для десятичного вывода `int64_t`, `PRIx32` — для шестнадцатеричного вывода `uint32_t`, `SCNuMAX` — для чтения `uintmax_t` через `scanf`.

### Типы

Заголовочный файл `<inttypes.h>` определяет как минимум следующие типы:

- `imaxdiv_t` — структурный тип, являющийся типом значения, возвращаемого функцией `imaxdiv()`

### Макросы форматирования

Каждый макрос расширяется в строковый литерал, содержащий спецификатор преобразования, возможно, модифицированный модификатором длины, пригодный для использования в аргументе `format` форматированной функции ввода-вывода при преобразовании соответствующего целочисленного типа. Макросы имеют общую форму PRI (строковые литералы для семейства функций `fprintf()` и `fwprintf()`) или SCN (строковые литералы для семейства функций `fscanf()` и `fwscanf()`), за спецификатором преобразования, за которым следует имя, соответствующее похожему имени типа в `<stdint.h>`.

### Функции

```c
intmax_t  imaxabs(intmax_t);
imaxdiv_t imaxdiv(intmax_t, intmax_t);
intmax_t  strtoimax(const char *restrict, char **restrict, int);
uintmax_t strtoumax(const char *restrict, char **restrict, int);
intmax_t  wcstoimax(const wchar_t *restrict, wchar_t **restrict, int);
uintmax_t wcstoumax(const wchar_t *restrict, wchar_t **restrict, int);
```

> [!NOTE]
> Макросы `PRI*` и `SCN*` используются **только** в строках формата — они не являются строковыми литералами сами по себе и должны конкатенироваться с остальной частью строки формата через `##` или просто подставляться непосредственно.

## Пример

```c
#include <inttypes.h>
#include <wchar.h>

int main(void)
{
    uintmax_t i = UINTMAX_MAX; // Этот тип всегда существует.
    wprintf(L"Наибольшее целое значение: %020"
        PRIxMAX "\n", i);
    return 0;
}
```

## Исключения

- **Установление `errno`:** функции `strtoimax()`, `strtoumax()`, `wcstoimax()` и `wcstoumax()` устанавливают `errno` в `ERANGE` при переполнении или исчерпании диапазона.
- **Поведение при передаче `NULL`:** функции преобразования строк (`strtoimax`, `strtoumax`) — вторичный аргумент `restrict` может быть `NULL`, тогда значение не сохраняется.
- **Поведение при переполнении/нехватке памяти:** при переполнении возвращается `INTMAX_MAX`/`UINTMAX_MAX` и устанавливается `errno = ERANGE`.
- **Граничные случаи:** при пустой строке или строке, не содержащей числа, возвращается `0`, а первый аргумент указывает на начальную строку.
- **Многопоточность:** функции не являются потокобезопасными для внутреннего состояния (см. `strtol(3)`).
- **Назначение:** цель `<inttypes.h>` — предоставить набор целочисленных типов, определения которых согласованы между машинами и не зависят от операционных систем и других особенностей реализации.

## Применение

Цель `<inttypes.h>` — предоставить набор целочисленных типов, определения которых согласованы между машинами и не зависят от операционных систем и других особенностей реализации. Он определяет через `typedef` целочисленные типы различных размеров. Реализации могут свободно определять их как стандартные целочисленные типы ISO C или расширения, которые они поддерживают. Последовательное использование этого заголовочного файла значительно повысит переносимость приложений между платформами.
