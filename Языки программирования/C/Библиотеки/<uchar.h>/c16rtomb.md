## Определение

```c
#include <uchar.h>

size_t c16rtomb(char *restrict s,
                char16_t c16,
                mbstate_t *restrict ps);
```

## Описание

Функция `c16rtomb` преобразует символ `char16_t` (кодовый элемент UTF-16) в соответствующую многобайтовую последовательность и записывает результат в буфер `s`.

Параметры:

- `s` — указатель на буфер для записи многобайтовой последовательности; может быть `NULL`.
- `c16` — преобразуемый символ `char16_t`.
- `ps` — указатель на состояние преобразования `mbstate_t`; если `NULL`, используется внутреннее статическое состояние.

Возвращаемое значение:

- Количество записанных байт (от 1 до `MB_LEN_MAX`).
- `(size_t)-1` — символ `c16` не является допустимым кодовым элементом UTF-16.

Если `s` равен `NULL`, функция сбрасывает состояние `ps` в начальное.

> [!NOTE]
> Для символов из диапазона U+10000 и выше функция может записать сурrogate pair — два элемента `char16_t`, каждый из которых будет преобразован отдельно. При этом состояние `ps` сохраняется между вызовами.

## Примеры

```c
#include <stdio.h>
#include <uchar.h>

int main(void)
{
    char16_t chars[] = {u'A', u'я', u'€', 0};
    mbstate_t state = {0};
    char buf[MB_LEN_MAX];
    size_t len;

    for (size_t i = 0; chars[i] != 0; i++) {
        len = c16rtomb(buf, chars[i], &state);
        if (len != (size_t)-1) {
            printf("Символ U+%04X → %zu байт: ", chars[i], len);
            for (size_t j = 0; j < len; j++)
                printf("%02X ", (unsigned char)buf[j]);
            printf("\n");
        }
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция C11 | Суррогатные пары требуют двух вызовов |
| Позволяет получить размер кодировки символа | Сложный интерфейс с состоянием `mbstate_t` |
| Потокобезопасна при использовании собственного `ps` | Зависит от настроек локали (`LC_CTYPE`) |

## Обработка ошибок

- **Поведение при передаче NULL:** параметр `s` может быть `NULL` — в этом случае функция сбрасывает состояние `ps` в начальное (полезно для сброса состояния после ошибки). Параметр `ps` может быть `NULL` — используется внутреннее статическое состояние.
- **Установление errno:** функция не устанавливает `errno`.
- **Возвращаемое значение при ошибке:** `(size_t)-1` — символ `c16` не является допустимым кодовым элементом UTF-16 (например, суррогат из диапазона U+D800–U+DFFF).
- **Многопоточность:** функция потокобезопасна при использовании собственного объекта `ps`. При `ps == NULL` используется разделяемое состояние — небезопасно в многопоточной среде.
- **Связанные функции:** `c32rtomb` — обратное преобразование `char32_t` → многобайтовая строка; `wcrtomb` из `<wchar.h>` — обратное преобразование `wchar_t`; `mbrtoc16` — прямое преобразование многобайтовой строки → `char16_t`.
