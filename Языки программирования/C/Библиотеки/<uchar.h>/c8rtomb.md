## Определение

```c
#include <uchar.h>

size_t c8rtomb(char *restrict s,
               char8_t c8,
               mbstate_t *restrict ps);
```

## Описание

Функция `c8rtomb` преобразует один символ `char8_t` (кодовый элемент UTF-8) в его многобайтовое представление и записывает результат в массив, на который указывает `s`.

Параметры:

- `s` — указатель на массив `char` для записи многобайтовой последовательности; может быть `NULL`.
- `c8` — символ `char8_t` для преобразования.
- `ps` — указатель на состояние преобразования `mbstate_t`; если `NULL`, используется внутреннее статическое состояние.

Возвращаемое значение:

- Между 1 и `MB_CUR_MAX` — количество байт, записанных в массив `s`.
- `0` — `c8` является ведущим элементом последовательности (для UTF-8这种情况 не возникает).
- `(size_t)-1` — обнаружен неверный символ.

> [!NOTE]
> Функция `c8rtomb` является обратной к `mbrtoc8` и преобразует отдельные кодовые элементы `char8_t` в многобайтовую строку (обычно UTF-8).

## Примеры

```c
#include <stdio.h>
#include <uchar.h>

int main(void)
{
    char8_t input[] = u8"Привет";
    char output[64];
    mbstate_t state = {0};
    char *ptr = output;

    for (size_t i = 0; input[i] != 0; i++) {
        size_t ret = c8rtomb(ptr, input[i], &state);
        if (ret == (size_t)-1) {
            printf("Ошибка преобразования\n");
            break;
        }
        ptr += ret;
    }
    *ptr = '\0';

    printf("Результат: %s\n", output);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция C23 | Сложный интерфейс с состоянием `mbstate_t` |
| Обратная совместимость с UTF-8 | Может вернуть 0 для суррогатных пар |
| Потокобезопасна при использовании собственного `ps` | Зависит от настроек локали (`LC_CTYPE`) |

## Обработка ошибок

- **Поведение при передаче NULL:** параметр `s` может быть `NULL` — в этом случае функция возвращает количество байт, необходимых для представления символа. Параметр `ps` может быть `NULL` — используется внутреннее статическое состояние.
- **Установление errno:** при ошибке устанавливает `EILSEQ`.
- **Возвращаемое значение при ошибке:** `(size_t)-1` — обнаружен неверный символ.
- **Многопоточность:** функция потокобезопасна при использовании собственного объекта `ps` для каждого потока. При передаче `NULL` в `ps` используется разделяемое внутреннее состояние — это небезопасно в многопоточной среде.
- **Связанные функции:** `mbrtoc8` — обратное преобразование многобайтовой строки → `char8_t`; `c16rtomb` — преобразование `char16_t` → многобайтовая строка; `c32rtomb` — преобразование `char32_t` → многобайтовая строка.
