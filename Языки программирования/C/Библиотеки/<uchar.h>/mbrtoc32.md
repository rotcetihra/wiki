## Определение

```c
#include <uchar.h>

size_t mbrtoc32(char32_t *restrict pc32,
                const char *restrict s,
                size_t n,
                mbstate_t *restrict ps);
```

## Описание

Функция `mbrtoc32` преобразует многобайтовую последовательность, начинающуюся с позиции `s`, в символ `char32_t` (кодовый элемент UTF-32) и записывает результат в `pc32`.

Параметры:

- `pc32` — указатель на переменную `char32_t` для записи результата; может быть `NULL`.
- `s` — указатель на начало многобайтовой последовательности.
- `n` — максимальное количество байт для чтения из `s`.
- `ps` — указатель на состояние преобразования `mbstate_t`; если `NULL`, используется внутреннее статическое состояние.

Возвращаемое значение:

- `0` — преобразован нулевой символ (`L'\0'`).
- Between 1 и `n` — количество байт, составляющих обработанную многобайтовую последовательность.
- `(size_t)-1` — обнаружен неверный многобайтовый символ.
- `(size_t)-2` — прочитана неполная последовательность (недостаточно байт в `n`).

В отличие от `mbrtoc16`, функция `mbrtoc32` всегда возвращает количество байт для одного символа, так как один элемент `char32_t` всегда представляет один кодовый элемент Unicode.

## Примеры

```c
#include <stdio.h>
#include <uchar.h>

int main(void)
{
    const char *utf8 = "Привет";
    mbstate_t state = {0};
    char32_t buf[32];
    size_t len = 0;
    const char *ptr = utf8;

    while (len < 31) {
        size_t ret = mbrtoc32(&buf[len], ptr, strlen(ptr), &state);
        if (ret == 0 || ret == (size_t)-1)
            break;
        ptr += ret;
        len++;
    }
    buf[len] = 0;

    printf("Преобразовано %zu символов UTF-32\n", len);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция C11 | Один символ всегда занимает 4 байта |
| Один вызов — один символ (нет суррогатных пар) | Сложный интерфейс с состоянием `mbstate_t` |
| Потокобезопасна при использовании собственного `ps` | Зависит от настроек локали (`LC_CTYPE`) |

## Обработка ошибок

- **Поведение при передаче NULL:** параметр `pc32` может быть `NULL` — в этом случае результат не записывается. Параметр `ps` может быть `NULL` — используется внутреннее статическое состояние. Параметр `s` не должен быть `NULL`.
- **Установление errno:** функция не устанавливает `errno`.
- **Возвращаемое значение при ошибке:** `(size_t)-1` — обнаружен неверный многобайтовый символ; `(size_t)-2` — прочитана неполная последовательность.
- **Многопоточность:** функция потокобезопасна при использовании собственного объекта `ps`. При `ps == NULL` используется разделяемое состояние — небезопасно в многопоточной среде.
- **Связанные функции:** `mbrtoc16` — аналогичное преобразование в `char16_t`; `c32rtomb` — обратное преобразование `char32_t` → многобайтовая строка; `mbrtowc` из `<wchar.h>` — преобразование в `wchar_t`.
