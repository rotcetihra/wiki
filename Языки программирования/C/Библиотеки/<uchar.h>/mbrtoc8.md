## Определение

```c
#include <uchar.h>

size_t mbrtoc8(char8_t *restrict pc8,
               const char *restrict s,
               size_t n,
               mbstate_t *restrict ps);
```

## Описание

Функция `mbrtoc8` преобразует многобайтовую последовательность, начинающуюся с позиции `s`, в символ `char8_t` (кодовый элемент UTF-8) и записывает результат в `pc8`.

Параметры:

- `pc8` — указатель на переменную `char8_t` для записи результата; может быть `NULL`.
- `s` — указатель на начало многобайтовой последовательности.
- `n` — максимальное количество байт для чтения из `s`.
- `ps` — указатель на состояние преобразования `mbstate_t`; если `NULL`, используется внутреннее статическое состояние.

Возвращаемое значение:

- `0` — преобразован нулевой символ (`'\0'`).
- Между 1 и `n` — количество байт, составляющих обработанную многобайтовую последовательность.
- `(size_t)-1` — обнаружен неверный многобайтовый символ.
- `(size_t)-2` — прочитана неполная последовательность (недостаточно байт в `n`).

> [!NOTE]
> Функция `mbrtoc8` является обратной к `c8rtomb` и преобразует многобайтовую строку (обычно UTF-8) в отдельные кодовые элементы `char8_t`.

## Примеры

```c
#include <stdio.h>
#include <string.h>
#include <uchar.h>

int main(void)
{
    const char *utf8 = "Привет";
    mbstate_t state = {0};
    char8_t buf[32];
    size_t len = 0;
    const char *ptr = utf8;
    size_t remaining = strlen(utf8);

    while (remaining > 0) {
        size_t ret = mbrtoc8(&buf[len], ptr, remaining, &state);
        if (ret == 0 || ret == (size_t)-1)
            break;
        ptr += ret;
        remaining -= ret;
        len++;
    }
    buf[len] = 0;

    printf("Преобразовано %zu символов UTF-8\n", len);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция C23 | Сложный интерфейс с состоянием `mbstate_t` |
| Обратная совместимость с UTF-8 | Может потребоваться несколько вызовов для одного символа |
| Потокобезопасна при использовании собственного `ps` | Зависит от настроек локали (`LC_CTYPE`) |

## Обработка ошибок

- **Поведение при передаче NULL:** параметр `pc8` может быть `NULL` — в этом случае результат не записывается. Параметр `ps` может быть `NULL` — используется внутреннее статическое состояние (тогда функция не потокобезопасна). Параметр `s` не должен быть `NULL`.
- **Установление errno:** функция не устанавливает `errno`.
- **Возвращаемое значение при ошибке:** `(size_t)-1` — обнаружен неверный многобайтовый символ; `(size_t)-2` — прочитана неполная последовательность.
- **Многопоточность:** функция потокобезопасна при использовании собственного объекта `ps` для каждого потока. При передаче `NULL` в `ps` используется разделяемое внутреннее состояние — это небезопасно в многопоточной среде.
- **Связанные функции:** `c8rtomb` — обратное преобразование `char8_t` → многобайтовая строка; `mbrtoc16` — преобразование в `char16_t`; `mbrtoc32` — преобразование в `char32_t`.
