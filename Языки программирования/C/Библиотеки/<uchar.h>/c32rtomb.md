## Определение

```c
#include <uchar.h>

size_t c32rtomb(char *restrict s,
                char32_t c32,
                mbstate_t *restrict ps);
```

## Описание

Функция `c32rtomb` преобразует символ `char32_t` (кодовый элемент UTF-32) в соответствующую многобайтовую последовательность и записывает результат в буфер `s`.

Параметры:

- `s` — указатель на буфер для записи многобайтовой последовательности; может быть `NULL`.
- `c32` — преобразуемый символ `char32_t`.
- `ps` — указатель на состояние преобразования `mbstate_t`; если `NULL`, используется внутреннее статическое состояние.

Возвращаемое значение:

- Количество записанных байт (от 1 до `MB_LEN_MAX`).
- `(size_t)-1` — символ `c32` не является допустимым кодовым элементом Unicode.

Если `s` равен `NULL`, функция сбрасывает состояние `ps` в начальное.

В отличие от `c16rtomb`, функция `c32rtomb` всегда преобразует один символ за один вызов, так как один элемент `char32_t` всегда представляет один кодовый элемент Unicode.

## Примеры

```c
#include <stdio.h>
#include <uchar.h>

int main(void)
{
    char32_t chars[] = {U'A', U'я', U'€', U'𝄞', 0};
    mbstate_t state = {0};
    char buf[MB_LEN_MAX];
    size_t len;

    for (size_t i = 0; chars[i] != 0; i++) {
        len = c32rtomb(buf, chars[i], &state);
        if (len != (size_t)-1) {
            printf("Символ U+%04X → %zu байт: ", chars[i], len);
            for (size_t j = 0; j < len; j++)
                printf("%02X ", (unsigned char)buf[j]);
            printf("\n");
        }
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция C11 | Один вызов всегда — один символ (нет суррогатных пар) |
| Простая обработка (один элемент = один символ) | Один символ всегда занимает 4 байта в памяти |
| Потокобезопасна при использовании собственного `ps` | Зависит от настроек локали (`LC_CTYPE`) |

## Обработка ошибок

- **Поведение при передаче NULL:** параметр `s` может быть `NULL` — в этом случае функция сбрасывает состояние `ps` в начальное. Параметр `ps` может быть `NULL` — используется внутреннее статическое состояние.
- **Установление errno:** функция не устанавливает `errno`.
- **Возвращаемое значение при ошибке:** `(size_t)-1` — символ `c32` не является допустимым кодовым элементом Unicode (например, суррогат из диапазона U+D800–U+DFFF или значение превышает U+10FFFF).
- **Многопоточность:** функция потокобезопасна при использовании собственного объекта `ps`. При `ps == NULL` используется разделяемое состояние — небезопасно в многопоточной среде.
- **Связанные функции:** `c16rtomb` — обратное преобразование `char16_t` → многобайтовая строка; `wcrtomb` из `<wchar.h>` — обратное преобразование `wchar_t`; `mbrtoc32` — прямое преобразование многобайтовой строки → `char32_t`.
