## Определение

```c
#include <uchar.h>

typedef unsigned char char8_t;
```

## Описание

Тип `char8_t` — беззнаковый целый тип для хранения кодовых элементов Unicode в кодировке UTF-8. Введён в стандарте C23.

Гарантируется, что `char8_t` достаточно широк для представления любого 8-битного значения. Конкретная ширина определяется реализацией, но обычно это `unsigned char` (8 бит). Литералы типа `char8_t` создаются с префиксом `u8`: `u8'A'`, `u8'я'`.

Символы Unicode в UTF-8 могут занимать от 1 до 4 байт. Латинские символы занимают 1 байт, кириллица — 2 байта, некоторые символы — 3 или 4 байта.

## Примеры

```c
#include <stdio.h>
#include <uchar.h>

int main(void)
{
    char8_t c1 = u8'A';
    char8_t c2 = u8'я';
    char8_t c3 = u8'€';   // U+20AC, 3 байта в UTF-8

    printf("Размер char8_t: %zu байт\n", sizeof(char8_t));

    char8_t str[] = u8"Привет";
    printf("Размер строки: %zu байт\n", sizeof(str) - 1);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный тип C23 для UTF-8 | Переменная длина символа (1–4 байта) |
| Компактное представление ASCII | Нет функций манипуляции строками в стандарте |
| Совместимость с C++20/28 `char8_t` | Литералы `u8"..."` в C23 возвращают `const char8_t[]`, а не `char[]` |
