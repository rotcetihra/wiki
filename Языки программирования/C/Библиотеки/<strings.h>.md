## Описание библиотеки

Заголовочный файл `<strings.h>` — дополнительные функции работы со строками. В отличие от `<string.h>`, функции этого заголовка не чувствительны к регистру символов.

> [!NOTE]
> Этот заголовок не является частью стандарта C, но включён в POSIX и доступен на большинстве UNIX-подобных систем.

### Типы

| Тип | Описание |
|---|---|
| `locale_t` | Определяется в `<locale.h>` |
| `size_t` | Определяется в `<sys/types.h>` |

### Функции

| Функция | Описание |
|---|---|
| `ffs(int)` | Поиск первого установленного бита (least significant bit) |
| `strcasecmp(const char *, const char *)` | Сравнение строк без учёта регистра |
| `strcasecmp_l(const char *, const char *, locale_t)` | Сравнение с явной локалью |
| `strncasecmp(const char *, const char *, size_t)` | Сравнение строк без учёта регистра с ограничением длины |
| `strncasecmp_l(const char *, const char *, size_t, locale_t)` | То же с явной локалью |

## Исключения

- **NULL:** поведение при передаче `NULL` в качестве аргумента не определено.
- **Многопоточность:** функции не являются потокобезопасными; для безопасного использования требуют блокировки.
- **Локаль:** функции `_l` используют заданную локаль для определения регистра символов; поведение зависит от `LC_CTYPE`.
- **Возвращаемое значение:** `strcasecmp()` и `strncasecmp()` возвращают тот же результат, что и `strcmp()`, за исключением того, что регистр символов не учитывается.

## Стандарты

POSIX.1-2017, BSD 4.3.
