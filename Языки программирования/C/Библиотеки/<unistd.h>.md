## Описание библиотеки

Заголовочный файл `<unistd.h>` — стандартные символические константы и типы POSIX. Этот заголовок определяет множество констант, типов и функций, необходимых для переносимых POSIX-приложений.

### Константы доступа

| Константа | Описание |
|---|---|
| `F_OK` | Проверка существования файла |
| `R_OK` | Проверка права на чтение |
| `W_OK` | Проверка права на запись |
| `X_OK` | Проверка права на выполнение |

### Константы файловых дескрипторов

| Константа | Описание |
|---|---|
| `STDIN_FILENO` | Стандартный ввод (0) |
| `STDOUT_FILENO` | Стандартный вывод (1) |
| `STDERR_FILENO` | Стандартный вывод ошибок (2) |

### Типы

| Тип | Описание |
|---|---|
| `size_t` | Беззнаковый целочисленный тип размера |
| `ssize_t` | Знаковый целочисленный тип размера |
| `uid_t` | Идентификатор пользователя |
| `gid_t` | Идентификатор группы |
| `off_t` | Позиция в файле |
| `pid_t` | Идентификатор процесса |
| `intptr_t` | Знаковый тип для хранения указателя |

## Исключения

- **NULL:** функции, принимающие указатели, не определены для `NULL`.
- **errno:** при ошибке устанавливается `errno` (например, `EACCES`, `ENOENT`, `EINTR`).
- **Переполнение:** `read()`/`write()` могут прочитать/записать меньше байт, чем запрошено.
- **Fork:** `fork()` возвращает 0 в дочернем процессе и PID дочернего в родительском; при ошибке — -1.
- **exec:** все функции `exec*` заменяют образ процесса; при ошибке возвращают -1.
- **Многопоточность:** функции потокобезопасны, за исключением `getlogin()` (используйте `getlogin_r()`).

## Стандарты

POSIX.1-2017, XSI.
