## Описание библиотеки

Заголовочный файл `<stdint.h>` объявляет набор целочисленных типов с указанной шириной и определяет соответствующие наборы макросов. Он также определяет макросы, указывающие лимиты целочисленных типов, соответствующих типам, определённым в других стандартных заголовках.

> [!NOTE]
> «Ширина» целочисленного типа — это количество бит, используемых для хранения его значения в чистой двоичной системе; фактический тип может использовать больше бит (например, 28-битный тип может храниться в 32 битах). N-битный знаковый тип имеет значения в диапазоне от -2^(N-1) до 2^(N-1)-1, тогда как N-битный беззнаковый тип — от 0 до 2^N-1.

Типы определяются в следующих категориях:

- Целочисленные типы определённой точной ширины
- Целочисленные типы с указанной минимальной шириной
- Наиболее быстрые целочисленные типы с указанной минимальной шириной
- Целочисленные типы, достаточные для хранения указателей на объекты
- Целочисленные типы максимальной ширины

(Некоторые из этих типов могут обозначать один и тот же тип.)

### Типы целых чисел

**Типы точной ширины:**

Тип `intN_t` обозначает знаковый целочисленный тип шириной N бит без битов заполнения и с дополнительным кодом. Тип `uintN_t` обозначает беззнаковый целочисленный тип шириной N бит.

Обязательные типы: `int8_t`, `int16_t`, `int32_t`, `uint8_t`, `uint16_t`, `uint32_t`.

Типы `int64_t` и `uint64_t` обязательны, если реализация предоставляет 64-битные типы, соответствующие требованиям.

**Минимально вмещаемые типы:**

Тип `int_leastN_t` обозначает знаковый целочисленный тип шириной не менее N бит, такой, что ни один знаковый тип с меньшим размером не имеет указанной ширины.

Обязательные типы: `int_least8_t`, `int_least16_t`, `int_least32_t`, `int_least64_t`, `uint_least8_t`, `uint_least16_t`, `uint_least32_t`, `uint_least64_t`.

**Наиболее быстрые минимально вмещаемые типы:**

Каждый из следующих типов обозначает целочисленный тип, который обычно наиболее быстр для работы среди всех целочисленных типов с указанной минимальной шириной.

Обязательные типы: `int_fast8_t`, `int_fast16_t`, `int_fast32_t`, `int_fast64_t`, `uint_fast8_t`, `uint_fast16_t`, `uint_fast32_t`, `uint_fast64_t`.

**Типы, способные хранить указатели:**

Тип `intptr_t` обозначает знаковый целочисленный тип, в который можно преобразовать любой допустимый указатель на `void` и обратно с сохранением равенства.

Тип `uintptr_t` обозначает беззнаковый целочисленный тип аналогичным образом.

На XSI-совместимых системах эти типы обязательны; в остальных случаях — опциональны.

**Типы максимальной ширины:**

Тип `intmax_t` обозначает знаковый целочисленный тип, способный представлять любое значение любого знакового целочисленного типа.

Тип `uintmax_t` обозначает беззнаковый целочисленный тип, способный представлять любое значение любого беззнакового целочисленного типа.

Эти типы обязательны.

### Лимиты типов фиксированной ширины

Макросы указывают минимальные и максимальные лимиты типов, объявленных в `<stdint.h>`:

- `INTN_MIN` — точно -(2^(N-1))
- `INTN_MAX` — точно 2^(N-1)-1
- `UINTN_MAX` — точно 2^N-1

### Лимиты из других заголовков

- `PTRDIFF_MIN` — -65535, `PTRDIFF_MAX` — +65535
- `SIZE_MAX` — 65535
- Лимиты `sig_atomic_t`, `wchar_t`, `wint_t` зависят от реализации

### Макросы целочисленных константных выражений

Макросы `INTN_C(value)` и `UINTN_C(value)` раскрываются в целочисленные константные выражения, соответствующие типам `int_leastN_t` и `uint_leastN_t` соответственно.

Макросы `INTMAX_C(value)` и `UINTMAX_C(value)` раскрываются в выражения типа `intmax_t` и `uintmax_t`.

## Исключения

- **Лимиты:** определяются макросами `INT*_MIN`, `INT*_MAX`, `UINT*_MAX` для всех типов.
- **Размер указателя:** `intptr_t`/`uintptr_t` гарантированно вмещают указатель `void*`.
- **Порядок байтов:** типы фиксированной ширины не гарантируют одинакового порядка байтов (endianness) на разных платформах.
- **Опциональные типы:** `int8_t`, `int16_t`, `int32_t`, `int64_t` и их беззнаковые аналоги являются опциональными; обязательны только `int_least*_t` и `int_fast*_t`.
- **Многопоточность:** MT-Safe. Типы и макросы не требуют синхронизации.
