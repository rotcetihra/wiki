## Определение

```c
#define M_SQRT2 1.41421356237309504880
```

## Описание

Макрос — квадратный корень из числа 2, то есть √2. Приблизительно равно 1.41421. Широко используется в вычислениях с гипотенузами, нормализацией векторов и тригонометрических преобразованиях.

Это расширение POSIX/GNU, а не часть стандарта ISO C. Макрос доступен при компиляции с определением `_GNU_SOURCE` или в среде POSIX. Для переносимых вычислений можно использовать `sqrt(2.0)`.

## Примеры

```c
#define _GNU_SOURCE
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("M_SQRT2 = %.20f\n", M_SQRT2);
    printf("sqrt(2) = %.20f\n", sqrt(2.0));

    // Гипотенуза прямоугольного треугольника с катетами 1
    double hypotenuse = M_SQRT2;
    printf("Гипотенуза равностороннего треугольника: %.10f\n", hypotenuse);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
