## Определение

```c
#include <math.h>

double sqrt(double x);
float sqrtf(float x);         // C99
long double sqrtl(long double x); // C99
```

## Описание

Функция вычисляет неотрицательный квадратный корень аргумента x. Defined for x ≥ 0. При x < 0 результат является NaN (нечисло) и может возникать доменная ошибка.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("sqrt(0) = %f\n", sqrt(0.0)); // 0.0
    printf("sqrt(1) = %f\n", sqrt(1.0)); // 1.0
    printf("sqrt(2) = %f\n", sqrt(2.0)); // ~1.41421
    printf("sqrt(4) = %f\n", sqrt(4.0)); // 2.0
    
    // Проверка свойства sqrt(a*b) = sqrt(a)*sqrt(b) для a,b ≥ 0
    double a = 4.0, b = 9.0;
    printf("sqrt(%f * %f) = %f\n", a, b, sqrt(a * b));
    printf("sqrt(%f) * sqrt(%f) = %f\n", a, b, sqrt(a) * sqrt(b));
    
    return 0;
}
```
