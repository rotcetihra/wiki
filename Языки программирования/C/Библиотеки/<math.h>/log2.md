## Определение

```c
#include <math.h>

double log2(double x);
float log2f(float x);            // C99
long double log2l(long double x); // C99
```

## Описание

Функция вычисляет логарифм по основанию 2 аргумента x. Определена для x > 0. Результат — это показатель степени, в которую нужно возвести 2, чтобы получить x. Полезна при работе с бинарными данными и вычислении количества бит.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("log2(1) = %f\n", log2(1.0));      // 0.0
    printf("log2(2) = %f\n", log2(2.0));      // 1.0
    printf("log2(8) = %f\n", log2(8.0));      // 3.0
    printf("log2(1024) = %f\n", log2(1024.0)); // 10.0
    printf("log2(0.5) = %f\n", log2(0.5));    // -1.0

    // Определение количества бит для числа
    unsigned int n = 255;
    int bits = (int)ceil(log2(n + 1));
    printf("Для числа %u нужно %d бит\n", n, bits);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Точное вычисление для степеней двойки | Не определён для x ≤ 0 (результат -NaN или доменная ошибка) |
| Поддерживает все типы с плавающей точкой | Для дробных аргументов возможны погрешности округления |

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** При x ≤ 0 возникает доменная ошибка (`errno` = `EDOM`). При x = 0 реализация может установить `errno` = `ERANGE`.
- **Возвращаемое значение при ошибке:** При доменной ошибке возвращает NaN; при ошибке диапазона — −`HUGE_VAL`.
- **Многопоточность:** Функция является потокобезопасной.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<math.h>/log|log]] — натуральный логарифм, [[Языки программирования/C/Библиотеки/<math.h>/exp2|exp2]] — экспонента 2^x (обратная функция).
