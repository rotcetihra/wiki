## Определение

```c
#include <math.h>

double round(double x);
float roundf(float x);         // C99
long double roundl(long double x); // C99
```

## Описание

Функция округляет аргумент x до ближайшего целого числа. Если значение находится ровно посередине между двумя целыми, округление происходит в сторону положительной бесконечности (away from zero).

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("round(2.3) = %f\n", round(2.3)); // 2.0
    printf("round(2.5) = %f\n", round(2.5)); // 3.0
    printf("round(2.7) = %f\n", round(2.7)); // 3.0
    printf("round(-2.5) = %f\n", round(-2.5)); // -3.0
    printf("round(-2.3) = %f\n", round(-2.3)); // -2.0
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** Функция не устанавливает `errno` при стандартном использовании.
- **Возвращаемое значение при ошибке:** Результат всегда определён для всех конечных аргументов; для бесконечных возвращает ±∞, для NaN возвращает NaN.
- **Многопоточность:** Функция является потокобезопасной.
