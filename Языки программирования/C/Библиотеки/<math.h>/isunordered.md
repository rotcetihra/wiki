## Определение

```c
#include <math.h>

#define isunordered(x, y) /* implementation-defined */
```

## Описание

Макрос определяет, являются ли хотя бы один из аргументов нечисловым значением (NaN). Возвращает ненулевое значение, если хотя бы один из аргументов является NaN, и ноль в противном случае. Используется для безопасной проверки перед выполнением операций сравнения.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("isunordered(5.0, 3.0) = %d\n", isunordered(5.0, 3.0));   // 0 (ложь)
    printf("isunordered(NAN, 1.0) = %d\n", isunordered(NAN, 1.0));   // 1 (истина)
    printf("isunordered(1.0, NAN) = %d\n", isunordered(1.0, NAN));   // 1 (истина)
    printf("isunordered(NAN, NAN) = %d\n", isunordered(NAN, NAN));   // 1 (истина)
    printf("isunordered(INFINITY, INFINITY) = %d\n", isunordered(INFINITY, INFINITY)); // 0 (ложь)
    
    return 0;
}
```
