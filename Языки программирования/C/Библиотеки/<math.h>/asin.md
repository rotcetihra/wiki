## Определение

```c
#include <math.h>

double asin(double x);
float asinf(float x);         // C99
long double asinl(long double x); // C99
```

## Описание

Функция вычисляет арксинус (обратный синус) аргумента x. Defined for x ∈ [-1, 1]. Результат находится в диапазоне [-π/2, π/2].

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("asin(0) = %f\n", asin(0.0)); // 0.0
    printf("asin(1) = %f\n", asin(1.0)); // π/2 ≈ 1.5708
    printf("asin(-1) = %f\n", asin(-1.0)); // -π/2 ≈ -1.5708
    
    // Проверка свойства sin(asin(x)) = x для x ∈ [-1, 1]
    double x = 0.5;
    printf("sin(asin(%f)) = %f\n", x, sin(asin(x)));
    
    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** При |x| > 1 возникает доменная ошибка; реализация может установить `errno` = `EDOM`.
- **Возвращаемое значение при ошибке:** При |x| > 1 возвращает NaN.
- **Многопоточность:** Функция является потокобезопасной.
