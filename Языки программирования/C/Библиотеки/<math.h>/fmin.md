## Определение

```c
#include <math.h>

double fmin(double x, double y);
float fminf(float x, float y);            // C99
long double fminl(long double x, long double y); // C99
```

## Описание

Функция возвращает меньшее из двух аргументов. Если один из аргументов является нечисловым значением, возвращается другой аргумент.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("fmin(5.0, 3.0) = %f\n", fmin(5.0, 3.0));   // 3.0
    printf("fmin(3.0, 5.0) = %f\n", fmin(3.0, 5.0));   // 3.0
    printf("fmin(-1.0, -2.0) = %f\n", fmin(-1.0, -2.0)); // -2.0
    printf("fmin(0.0, -0.0) = %f\n", fmin(0.0, -0.0)); // -0.0
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
