## Определение

```c
#include <math.h>

double asinh(double x);
float asinhf(float x);         // C99
long double asinhl(long double x); // C99
```

## Описание

Функция вычисляет обратный гиперболический синус. Defined for все действительные числа x. Может быть выражена как asinh(x) = ln(x + √(x² + 1)).

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("asinh(0) = %f\n", asinh(0.0)); // 0.0
    printf("asinh(1) = %f\n", asinh(1.0)); // ~0.8814
    printf("asinh(-1) = %f\n", asinh(-1.0)); // -0.8814
    
    // Проверка свойства sinh(asinh(x)) = x для всех x
    double x = 2.5;
    printf("sinh(asinh(%f)) = %f\n", x, sinh(asinh(x)));
    
    return 0;
}
```
