## Определение

```c
#include <math.h>

double tanh(double x);
float tanhf(float x);         // C99
long double tanhl(long double x); // C99
```

## Описание

Функция вычисляет гиперболический тангенс: tanh(x) = sinh(x)/cosh(x) = (e^x - e^(-x))/(e^x + e^(-x)). Результат находится в диапазоне (-1, 1), приближаясь к ±1 при x → ±∞.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("tanh(0) = %f\n", tanh(0.0)); // 0.0
    printf("tanh(1) = %f\n", tanh(1.0)); // ~0.7616
    printf("tanh(-1) = %f\n", tanh(-1.0)); // -0.7616
    printf("tanh(10) = %f\n", tanh(10.0)); // ~0.999999996 (близко к 1)
    printf("tanh(-10) = %f\n", tanh(-10.0)); // ~-0.999999996 (близко к -1)
    
    // Проверка свойства tanh(-x) = -tanh(x)
    double x = 2.0;
    printf("tanh(-%f) = %f\n", x, tanh(-x));
    printf("-tanh(%f) = %f\n", x, -tanh(x));
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Точное вычисление для всего диапазона определения | Горизонтальные асимптоты при y=±1 достигаются только asymptotically |

| Результат всегда в [-1, 1], полезно для нормализации |  |

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** Функция не устанавливает `errno` при стандартном использовании.
- **Возвращаемое значение при ошибке:** Результат всегда в диапазоне (-1, 1) для конечных аргументов; для бесконечных возвращает ±1.
- **Многопоточность:** Функция является потокобезопасной.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<math.h>/sinh|sinh]] — гиперболический синус, [[Языки программирования/C/Библиотеки/<math.h>/cosh|cosh]] — гиперболический косинус, [[Языки программирования/C/Библиотеки/<math.h>/atanh|atanh]] — обратный гиперболический тангенс.
