## Определение

```c
#include <math.h>

double ldexp(double x, int exp);
float ldexpf(float x, int exp);            // C99
long double ldexpl(long double x, int exp); // C99
```

## Описание

Функция вычисляет значение x × 2^exp. Это обратная операция к `frexp`: если `frexp` разлагает число на мантиссу и показатель, то `ldexp` восстанавливает число по мантиссе и показателю. Функция удобна для быстрого умножения или деления на целые степени двойки.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("ldexp(1.0, 3) = %f\n", ldexp(1.0, 3));   // 8.0
    printf("ldexp(0.5, 4) = %f\n", ldexp(0.5, 4));   // 8.0
    printf("ldexp(2.0, -1) = %f\n", ldexp(2.0, -1)); // 1.0

    // Обратная операция к frexp
    int exp;
    double m = frexp(8.0, &exp);
    printf("frexp(8) -> %.1f, %d; ldexp -> %f\n", m, exp, ldexp(m, exp)); // 8.0

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрое вычисление x × 2^exp без обращения к `pow` | Возможное переполнение для больших exp |
| Поддерживает все типы с плавающей точкой | Для x = 0 возвращает 0 независимо от exp |

## Обработка ошибок

- **Поведение при передаче NULL:** Аргументы не являются указателями, поэтому передача NULL не применима.
- **Установление errno:** При переполнении результата реализация может установить `errno` = `ERANGE`.
- **Возвращаемое значение при ошибке:** При переполнении возвращает ±`HUGE_VAL` (соответственно знаку).
- **Многопоточность:** Функция является потокобезопасной.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<math.h>/frexp|frexp]] — обратная функция (разложение на мантиссу и показатель), [[Языки программирования/C/Библиотеки/<math.h>/scalbn|scalbn]] — x × 2^n.
