## Определение

```c
#include <math.h>

double pow(double x, double y);
float powf(float x, float y);         // C99
long double powl(long double x, long double y); // C99
```

## Описание

Функция вычисляет x^y (x в степени y). Для конечных аргументов результат определен как exp(y * log(x)). Особые случаи:
- Если x < 0 и y не является целым числом, результат — NaN
- Если x = 0 и y ≤ 0, результат — NaN или бесконечность в зависимости от реализации
- Если x = 0 и y > 0, результат — 0
- Если x = 1, результат — 1 для любого y
- Если y = 0, результат — 1 для любого x ≠ 0

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("pow(2, 3) = %f\n", pow(2.0, 3.0)); // 8.0
    printf("pow(4, 0.5) = %f\n", pow(4.0, 0.5)); // 2.0 (sqrt(4))
    printf("pow(10, 2) = %f\n", pow(10.0, 2.0)); // 100.0
    
    // Проверка свойства pow(a, b+c) = pow(a, b) * pow(a, c)
    double a = 2.0, b = 3.0, c = 4.0;
    printf("pow(%f, %f + %f) = %f\n", a, b, c, pow(a, b + c));
    printf("pow(%f, %f) * pow(%f, %f) = %f\n", a, b, a, c, pow(a, b) * pow(a, c));
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Универсальная функция возведения в степень | Сложные граничные случаи требуют осторожности |
| Поддерживает все типы с плавающей точкой | Для целых степеней часто эффективнее использовать циклы умножения |
