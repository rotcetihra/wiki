## Определение

```c
#include <math.h>

double fabs(double x);
float fabsf(float x);         // C99
long double fabsl(long double x); // C99
```

## Описание

Функция возвращает абсолютное значение аргумента x. Результат всегда неотрицателен: fabs(-5) = 5, fabs(5) = 5.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("fabs(5) = %f\n", fabs(5.0)); // 5.0
    printf("fabs(-5) = %f\n", fabs(-5.0)); // 5.0
    printf("fabs(0) = %f\n", fabs(0.0)); // 0.0
    printf("fabs(-3.14) = %f\n", fabs(-3.14)); // 3.14
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и быстрая операция | Результат всегда неотрицателен (теряется знак) |
| Поддерживает все типы с плавающей точкой |  |
