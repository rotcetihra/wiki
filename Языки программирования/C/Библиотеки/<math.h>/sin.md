## Определение

```c
#include <math.h>

double sin(double x);
float sinf(float x);         // C99
long double sinl(long double x); // C99
```

## Описание

Функция вычисляет синус угла x, измеренного в радианах. Результат находится в диапазоне [-1, 1]. Для больших значений x точность может ухудшаться из-за ошибок приведения аргумента к диапазону [0, 2π).

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    double x = M_PI / 2; // 90 градусов
    printf("sin(π/2) = %f\n", sin(x)); // 1.0
    
    x = M_PI; // 180 градусов
    printf("sin(π) = %f\n", sin(x)); // 0.0
    
    x = 0;
    printf("sin(0) = %f\n", sin(x)); // 0.0
    
    return 0;
}
```

| Поддерживает все типы с плавающей точкой |  |

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** Функция не устанавливает `errno` при стандартном использовании.
- **Возвращаемое значение при ошибке:** Результат всегда определён для конечных аргументов; для бесконечных аргументов возвращает NaN.
- **Многопоточность:** Функция является потокобезопасной.
