## Определение

```c
#define HUGE_VALL /* реализация-зависимое значение */
```

## Описание

Макрос — положительное значение огромной конечной величины типа `long double`. Аналог `HUGE_VAL` для двойной расширенной точности. Возвращается функциями с плавающей точкой, когда результат не может быть представлен конечным числом. Гарантировано, что `HUGE_VALL` имеет тип `long double`. В POSIX-системах обычно определяется как положительную бесконечность `(+__infl)`.

Макрос определён в C99 (ISO/IEC 9899:1999, раздел 7.12) и сохранён в C23 (ISO/IEC 9899:2024, раздел 7.12).

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void)
{
    long double result = powl(10.0L, 1000.0L);

    if (result == HUGE_VALL) {
        printf("Результат превышает диапазон long double\n");
    }

    printf("HUGE_VALL = %Le\n", HUGE_VALL);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная переносимая константа для `long double` (C99+) | Значение различается между реализациями |
| Типизирована как `long double` | Может генерировать исключение переполнения в вычислениях |
