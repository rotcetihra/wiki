## Определение

```c
#include <math.h>

double log1p(double x);
float log1pf(float x);            // C99
long double log1pl(long double x); // C99
```

## Описание

Функция вычисляет натуральный логарифм величины 1 + x, то есть ln(1 + x). Эта функция обеспечивает высокую точность при вычислении логарифма чисел, близких к 1, когда прямое вычисление `log(1 + x)` приводит к потере значащих цифр.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("log1p(0) = %f\n", log1p(0.0));      // 0.0
    printf("log1p(1) = %f\n", log1p(1.0));      // ~0.69315
    printf("log1p(e-1) = %f\n", log1p(M_E - 1)); // 1.0

    // Сравнение точности для малых x
    double x = 1e-15;
    printf("log1p(%g) = %.20f\n", x, log1p(x));
    printf("log(1 + %g) = %.20f\n", x, log(1 + x));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Высокая точность для малых x | Не определён для x ≤ −1 |
| Поддерживает все типы с плавающей точкой | Для больших x уступает `log` в точности |
