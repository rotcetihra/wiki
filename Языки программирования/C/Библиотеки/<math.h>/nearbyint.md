## Определение

```c
#include <math.h>

double nearbyint(double x);
float nearbyintf(float x);         // C99
long double nearbyintl(long double x); // C99
```

## Описание

Функция округляет аргумент x до ближайшего целого числа с использованием текущего направления округления ( установленного через fesetround ). В отличие от rint, не генерирует исключенияifting-point.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("nearbyint(2.3) = %f\n", nearbyint(2.3)); // 2.0
    printf("nearbyint(2.5) = %f\n", nearbyint(2.5)); // 2.0 (приRoundTowardZero)
    printf("nearbyint(2.7) = %f\n", nearbyint(2.7)); // 3.0
    printf("nearbyint(-2.3) = %f\n", nearbyint(-2.3)); // -2.0
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Не генерирует исключения floating-point | Учитывает текущее направление округления |
| Поддерживает все типы с плавающей точкой |  |
