## Определение

```c
#include <math.h>

double hypot(double x, double y);
float hypotf(float x, float y);         // C99
long double hypotl(long double x, long double y); // C99
```

## Описание

Функция вычисляет длину гипотенузы прямоугольного треугольника с катетами x и y: √(x² + y²). Реализация защищена от переполнения и потери точности при больших и малых значениях аргументов.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("hypot(3, 4) = %f\n", hypot(3.0, 4.0)); // 5.0
    printf("hypot(5, 12) = %f\n", hypot(5.0, 12.0)); // 13.0
    printf("hypot(0, 1) = %f\n", hypot(0.0, 1.0)); // 1.0
    printf("hypot(-3, 4) = %f\n", hypot(-3.0, 4.0)); // 5.0
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Защищена от переполнения и потери точности | Только для двух аргументов |
| Поддерживает все типы с плавающей точкой |  |
