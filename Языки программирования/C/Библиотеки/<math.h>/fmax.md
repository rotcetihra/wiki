## Определение

```c
#include <math.h>

double fmax(double x, double y);
float fmaxf(float x, float y);            // C99
long double fmaxl(long double x, long double y); // C99
```

## Описание

Функция возвращает большее из двух аргументов. Если один из аргументов является нечисловым значением, возвращается другой аргумент.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("fmax(5.0, 3.0) = %f\n", fmax(5.0, 3.0));   // 5.0
    printf("fmax(3.0, 5.0) = %f\n", fmax(3.0, 5.0));   // 5.0
    printf("fmax(-1.0, -2.0) = %f\n", fmax(-1.0, -2.0)); // -1.0
    printf("fmax(0.0, -0.0) = %f\n", fmax(0.0, -0.0)); // 0.0
    
    return 0;
}
```

## Плюсы и минусы
