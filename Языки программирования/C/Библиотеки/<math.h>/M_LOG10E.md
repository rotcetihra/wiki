## Определение

```c
#define M_LOG10E 0.43429448190325182765
```

## Описание

Макрос — логарифм числа _e_ по основанию 10, то есть log₁₀(e). Приблизительно равно 0.43429. Используется для преобразования натурального логарифма в десятичный логарифм: log₁₀(x) = M_LOG10E · log(x).

Это расширение POSIX/GNU, а не часть стандарта ISO C. Макрос доступен при компиляции с определением `_GNU_SOURCE` или в среде POSIX. Для переносимых вычислений можно использовать `log10(exp(1.0))`.

## Примеры

```c
#define _GNU_SOURCE
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("M_LOG10E = %.20f\n", M_LOG10E);
    printf("log10(exp(1)) = %.20f\n", log10(exp(1.0)));

    // Преобразование натурального логарифма в log10
    double x = 1000.0;
    double log10_x = M_LOG10E * log(x);
    printf("log10(%.0f) = %.10f\n", x, log10_x);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая константа для conversions логарифмов | Расширение POSIX/GNU, не ISO C |
| Высокая точность в определении | Доступна не во всех реализациях |
