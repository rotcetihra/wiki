## Определение

```c
#include <math.h>

#define isgreater(x, y) /* implementation-defined */
```

## Описание

Макрос определяет, является ли значение x строго больше значения y. Возвращает ненулевое значение, если `x > y`, и ноль в противном случае. Не вызывает ненормализованный результат для ненормализованных значений.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("isgreater(5.0, 3.0) = %d\n", isgreater(5.0, 3.0));   // 1 (истина)
    printf("isgreater(3.0, 5.0) = %d\n", isgreater(3.0, 5.0));   // 0 (ложь)
    printf("isgreater(5.0, 5.0) = %d\n", isgreater(5.0, 5.0));   // 0 (ложь)
    printf("isgreater(NAN, 1.0) = %d\n", isgreater(NAN, 1.0));   // 0 (ложь)
    printf("isgreater(1.0, NAN) = %d\n", isgreater(1.0, NAN));   // 0 (ложь)
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Безопасное сравнение (не вызывает исключений для NaN) | Возвращает только ненулевое значение или ноль |
