## Определение

```c
#include <math.h>

#define isnan(x) /* implementation-defined */
```

## Описание

Макрос проверяет, является ли аргумент нечисловым значением (NaN). Возвращает ненулевое значение, если аргумент является NaN.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("isnan(1.0) = %d\n", isnan(1.0));       // 0 (ложь)
    printf("isnan(NAN) = %d\n", isnan(NAN));         // 1 (истина)
    printf("isnan(0.0/0.0) = %d\n", isnan(0.0/0.0)); // 1 (истина)
    printf("isnan(INFINITY) = %d\n", isnan(INFINITY)); // 0 (ложь)
    printf("isnan(-123.456) = %d\n", isnan(-123.456)); // 0 (ложь)
    
    return 0;
}
```

## Плюсы и минусы
