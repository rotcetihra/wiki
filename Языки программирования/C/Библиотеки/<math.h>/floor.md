## Определение

```c
#include <math.h>

double floor(double x);
float floorf(float x);         // C99
long double floorl(long double x); // C99
```

## Описание

Функция возвращает наибольшее целое значение, меньшее или равное x (округление вниз). Для отрицательных чисел floor(-1.5) = -2.0, а не -1.0.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("floor(2.3) = %f\n", floor(2.3)); // 2.0
    printf("floor(2.9) = %f\n", floor(2.9)); // 2.0
    printf("floor(-2.3) = %f\n", floor(-2.3)); // -3.0
    printf("floor(-2.9) = %f\n", floor(-2.9)); // -3.0
    printf("floor(2.0) = %f\n", floor(2.0)); // 2.0
    
    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** Функция не устанавливает `errno` при стандартном использовании.
- **Возвращаемое значение при ошибке:** Результат всегда определён для всех конечных аргументов; для бесконечных возвращает ±∞, для NaN возвращает NaN.
- **Многопоточность:** Функция является потокобезопасной.
