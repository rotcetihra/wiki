## Определение

```c
#include <math.h>

double remquo(double x, double y, int *quo);
double remquof(float x, float y, int *quo);         // C99
long double remquol(long double x, long double y, int *quo); // C99
```

## Описание

Функция вычисляет остаток от деления x на y по формуле x - n * y, где n — ближайшее целое к отношению x/y. В указатель quo записывается n mod 128 (младшие 7 бит n). Результат имеет ту же знак, что и x.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    int quo;
    printf("remquo(5, 2, &quo) = %f, quo = %d\n", remquo(5.0, 2.0, &quo), quo); // 1.0, 1
    printf("remquo(5.5, 2, &quo) = %f, quo = %d\n", remquo(5.5, 2.0, &quo), quo); // -0.5, 3
    printf("remquo(10, 3, &quo) = %f, quo = %d\n", remquo(10.0, 3.0, &quo), quo); // 1.0, 3
    
    return 0;
}
```
