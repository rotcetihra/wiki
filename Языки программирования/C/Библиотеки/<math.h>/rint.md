## Определение

```c
#include <math.h>

double rint(double x);
float rintf(float x);         // C99
long double rintl(long double x); // C99
```

## Описание

Функция округляет аргумент x до ближайшего целого числа с использованием текущего направления округления ( установленного через fesetround ). В отличие от nearbyint, может генерировать исключенияifting-point при неподходящем округлении.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("rint(2.3) = %f\n", rint(2.3)); // 2.0
    printf("rint(2.5) = %f\n", rint(2.5)); // 2.0 (приRoundTowardZero)
    printf("rint(2.7) = %f\n", rint(2.7)); // 3.0
    printf("rint(-2.3) = %f\n", rint(-2.3)); // -2.0
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Учитывает текущее направление округления | Может генерировать исключенияfloating-point |
| Поддерживает все типы с плавающей точкой |  |
