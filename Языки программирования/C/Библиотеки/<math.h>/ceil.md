## Определение

```c
#include <math.h>

double ceil(double x);
float ceilf(float x);         // C99
long double ceill(long double x); // C99
```

## Описание

Функция возвращает наименьшее целое значение, большее или равное x (округление вверх). Для отрицательных чисел ceil(-2.3) = -2.0, а не -3.0.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("ceil(2.3) = %f\n", ceil(2.3)); // 3.0
    printf("ceil(2.9) = %f\n", ceil(2.9)); // 3.0
    printf("ceil(-2.3) = %f\n", ceil(-2.3)); // -2.0
    printf("ceil(-2.9) = %f\n", ceil(-2.9)); // -2.0
    printf("ceil(2.0) = %f\n", ceil(2.0)); // 2.0
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
