## Определение

```c
#include <math.h>

double cosh(double x);
float coshf(float x);         // C99
long double coshl(long double x); // C99
```

## Описание

Функция вычисляет гиперболический косинус: cosh(x) = (e^x + e^(-x))/2. Это четная функция, которая всегда больше или равна 1 и симметрична относительно y-оси.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("cosh(0) = %f\n", cosh(0.0)); // 1.0
    printf("cosh(1) = %f\n", cosh(1.0)); // ~1.5431
    printf("cosh(-1) = %f\n", cosh(-1.0)); // 1.5431 (четная функция)
    
    // Проверка свойства cosh^2(x) - sinh^2(x) = 1
    double x = 2.0;
    double left = cosh(x) * cosh(x) - sinh(x) * sinh(x);
    printf("cosh^2(%f) - sinh^2(%f) = %f\n", x, x, left);
    
    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** При переполнении результата (|x| слишком большой) реализация может установить `errno` = `ERANGE`.
- **Возвращаемое значение при ошибке:** При переполнении возвращает +`HUGE_VAL`.
- **Многопоточность:** Функция является потокобезопасной.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<math.h>/sinh|sinh]] — гиперболический синус, [[Языки программирования/C/Библиотеки/<math.h>/tanh|tanh]] — гиперболический тангенс, [[Языки программирования/C/Библиотеки/<math.h>/cos|cos]] — косинус (связь через мнимые единицы).
