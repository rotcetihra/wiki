## Определение

```c
#include <math.h>

double log(double x);
float logf(float x);         // C99
long double logl(long double x); // C99
```

## Описание

Функция вычисляет натуральный логарифм (логарифм по основанию e) аргумента x. Defined for x > 0. При x → 0+ результат стремится к -∞, при x = 1 результат равен 0.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("log(1) = %f\n", log(1.0)); // 0.0
    printf("log(e) = %f\n", log(M_E)); // 1.0
    printf("log(e^2) = %f\n", log(M_E * M_E)); // 2.0
    
    // Проверка свойства log(a*b) = log(a) + log(b)
    double a = 2.0, b = 3.0;
    printf("log(%f * %f) = %f\n", a, b, log(a * b));
    printf("log(%f) + log(%f) = %f\n", a, b, log(a) + log(b));
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Точное вычисление для широкого диапазона аргументов | Не определен для x ≤ 0 (результат -NaN или возникает доменная ошибка) |
| Поддерживает все типы с плавающей точкой | При x очень близком к 0 результат может быть неточным из-за пределов представления |
