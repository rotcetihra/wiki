## Определение

```c
#include <math.h>

double acos(double x);
float acosf(float x);         // C99
long double acosl(long double x); // C99
```

## Описание

Функция вычисляет арккосинус (обратный косинус) аргумента x. Defined for x ∈ [-1, 1]. Результат находится в диапазоне [0, π].

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("acos(0) = %f\n", acos(0.0)); // π/2 ≈ 1.5708
    printf("acos(1) = %f\n", acos(1.0)); // 0.0
    printf("acos(-1) = %f\n", acos(-1.0)); // π ≈ 3.1416
    
    // Проверка свойства cos(acos(x)) = x для x ∈ [-1, 1]
    double x = 0.5;
    printf("cos(acos(%f)) = %f\n", x, cos(acos(x)));
    
    return 0;
}
```
