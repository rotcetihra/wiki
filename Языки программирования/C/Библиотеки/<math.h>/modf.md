## Определение

```c
#include <math.h>

double modf(double x, double *iptr);
float modff(float x, float *iptr);            // C99
long double modfl(long double x, long double *iptr); // C99
```

## Описание

Функция разлагает число x на целую и дробную части. Целая часть записывается по указателю iptr и имеет тот же знак, что и x. Дробная часть возвращается как результат функции. Сумма возвращаемого значения и целой части равна исходному x.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    double intpart;

    printf("modf(3.7) -> дробная: %f, целая: %f\n",
           modf(3.7, &intpart), intpart); // 0.7, 3.0

    printf("modf(-2.3) -> дробная: %f, целая: %f\n",
           modf(-2.3, &intpart), intpart); // -0.3, -2.0

    printf("modf(5.0) -> дробная: %f, целая: %f\n",
           modf(5.0, &intpart), intpart); // 0.0, 5.0

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Одновременно получает целую и дробную части | Целая часть сохраняется по указателю, что менее удобно для простых задач |
| Поддерживает все типы с плавающей точкой | Для отрицательных чисел целая часть имеет знак минус |
