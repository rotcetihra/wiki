## Определение

```c
#include <math.h>

double expm1(double x);
float expm1f(float x);            // C99
long double expm1l(long double x); // C99
```

## Описание

Функция вычисляет значение e^x − 1, где e — основание натурального логарифма. Эта функция обеспечивает большую точность, чем вычисление `exp(x) - 1`, для малых значений x, где разница между e^x и 1 매우 мала и может привести к потере значащих цифр при прямом вычитании.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("expm1(0) = %f\n", expm1(0.0));      // 0.0
    printf("expm1(1) = %f\n", expm1(1.0));      // ~1.71828
    printf("expm1(-1) = %f\n", expm1(-1.0));    // ~-0.63212

    // Сравнение точности для малых x
    double x = 1e-15;
    printf("expm1(%g) = %.20f\n", x, expm1(x));
    printf("exp(x) - 1 = %.20f\n", exp(x) - 1);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Высокая точность для малых x | Переполнение для больших положительных x |
| Поддерживает все типы с плавающей точкой | Для больших отрицательных x результат стремится к −1 |

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** При переполнении результата (x слишком большой) реализация может установить `errno` = `ERANGE`.
- **Возвращаемое значение при ошибке:** При переполнении возвращает ±`HUGE_VAL`.
- **Многопоточность:** Функция является потокобезопасной.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<math.h>/exp|exp]] — экспонента e^x (прямое вычисление), [[Языки программирования/C/Библиотеки/<math.h>/log1p|log1p]] — ln(1+x) (обратная функция).
