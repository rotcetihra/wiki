## Определение

```c
#include <math.h>

double scalbln(double x, long n);
float scalblnf(float x, long n);            // C99
long double scalblnl(long double x, long n); // C99
```

## Описание

Функция вычисляет значение x × 2^n, где n — целое число типа long. Это вариант `scalbn` для показателей типа long, что позволяет работать с большими значениями показателя, не выходя за пределы диапазона int. На практике используется редко.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("scalbln(1.0, 3) = %f\n", scalbln(1.0, 3));     // 8.0
    printf("scalbln(0.5, 4) = %f\n", scalbln(0.5, 4));     // 8.0
    printf("scalbln(2.0, -1) = %f\n", scalbln(2.0, -1));   // 1.0

    // Работа с большими показателями
    long big_exp = 100;
    printf("scalbln(1.0, %ld) = %e\n", big_exp, scalbln(1.0, big_exp));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Поддержка больших показателей типа long | На практике `scalbn` и `ldexp` используются чаще |
| Поддерживает все типы с плавающей точкой | Возможное переполнение для очень больших n |
