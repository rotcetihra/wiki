## Определение

```c
#include <math.h>

double logb(double x);
float logbf(float x);            // C99
long double logbl(long double x); // C99
```

## Описание

Функция извлекает показатель экспоненты из двоичного представления числа x. Результат равен целой части логарифма по основанию 2 от абсолютного значения x, то есть `floor(log2(|x|))`. Для x = ±∞ возвращает ±∞, для x = ±0 возвращает −∞.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("logb(1) = %f\n", logb(1.0));       // 0.0
    printf("logb(8) = %f\n", logb(8.0));       // 3.0
    printf("logb(5) = %f\n", logb(5.0));       // 2.0
    printf("logb(0.25) = %f\n", logb(0.25));   // -2.0
    printf("logb(100) = %f\n", logb(100.0));   // 6.0

    // Использование для нормализации числа
    double x = 100.0;
    double normalized = x / pow(2, logb(x));
    printf("%f нормализовано: %f\n", x, normalized);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрое извлечение показателя без вычисления логарифма | Для x = 0 возвращает −∞ |
| Поддерживает все типы с плавающей точкой | Не нормализует результат (в отличие от `frexp`) |
