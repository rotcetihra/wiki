## Определение

```c
#include <math.h>

#define isnormal(x) /* implementation-defined */
```

## Описание

Макрос проверяет, является ли аргумент нормализованным числом с плавающей точкой (не нулём, не бесконечностью, не NaN и не денормализованным числом). Возвращает ненулевое значение, если аргумент является нормализованным числом.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("isnormal(1.0) = %d\n", isnormal(1.0));       // 1 (истина)
    printf("isnormal(0.0) = %d\n", isnormal(0.0));       // 0 (ложь)
    printf("isnormal(INFINITY) = %d\n", isnormal(INFINITY)); // 0 (ложь)
    printf("isnormal(NAN) = %d\n", isnormal(NAN));       // 0 (ложь)
    printf("isnormal(1e-300) = %d\n", isnormal(1e-300)); // 1 (истина)
    printf("isnormal(1e-310) = %d\n", isnormal(1e-310)); // 0 (ложь, денормализованное)
    
    return 0;
}
```
