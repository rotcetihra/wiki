## Определение

```c
#define NAN /* реализация-зависимое значение */
```

## Описание

Макрос — значение типа `float`, представляющее нечисло (Not-a-Number, NaN). Гарантировано, что `NAN` является signaling NaN или quiet NaN согласно IEEE-754; обычно это quiet NaN. NaN является результатом неопределённых математических операций, например `0.0 / 0.0`, `sqrt(-1.0)`, `INFINITY - INFINITY`. Сравнение NaN с любым значением (включая само себя) всегда даёт `false`.

Макрос определён в C99 (ISO/IEC 9899:1999, раздел 7.12) и сохранён в C23 (ISO/IEC 9899:2024, раздел 7.12).

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void)
{
    float nan_val = NAN;

    printf("NAN = %f\n", nan_val);           // nan
    printf("NAN == NAN: %d\n", nan_val == nan_val); // 0
    printf("NAN != NAN: %d\n", nan_val != nan_val); // 1
    printf("isnan(NAN): %d\n", isnan(nan_val));       // 1

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная переносимая константа NaN (C99+) | Тип только `float` — для `double` нужно приведение |
| Удобна для инициализации и сравнений | NaN не сравнивается с собой (`NaN != NaN`) |
