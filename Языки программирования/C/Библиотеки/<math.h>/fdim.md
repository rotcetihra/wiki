## Определение

```c
#include <math.h>

double fdim(double x, double y);
float fdimf(float x, long double y);            // C99
long double fdiml(long double x, long double y); // C99
```

## Описание

Функция вычисляет положительную разность аргументов: `x - y`, если `x > y`, и `+0` в противном случае. Результат не определён, если аргументы представляют собой бесконечность или нечисловые значения.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("fdim(5.0, 3.0) = %f\n", fdim(5.0, 3.0));   // 2.0
    printf("fdim(3.0, 5.0) = %f\n", fdim(3.0, 5.0));   // 0.0
    printf("fdim(5.0, 5.0) = %f\n", fdim(5.0, 5.0));   // 0.0
    printf("fdim(-1.0, -2.0) = %f\n", fdim(-1.0, -2.0)); // 1.0
    printf("fdim(10.0, 0.0) = %f\n", fdim(10.0, 0.0)); // 10.0
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и эффективная операция | Результат ограничен значением +0 при `x ≤ y` |
| Поддерживает все типы с плавающей точкой | Не определена для специальных значений |

## Обработка ошибок

- **Поведение при передаче NULL:** Аргументы не являются указателями, поэтому передача NULL не применима.
- **Установление errno:** Функция не устанавливает `errno` при стандартном использовании.
- **Возвращаемое значение при ошибке:** Результат не определён для специальных значений (±∞, NaN).
- **Многопоточность:** Функция является потокобезопасной.
