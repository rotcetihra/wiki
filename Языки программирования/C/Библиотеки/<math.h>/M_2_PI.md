## Определение

```c
#define M_2_PI 0.63661977236758134308
```

## Описание

Макрос — отношение двух к π, то есть 2/π. Приблизительно равно 0.63662. Используется в вычислении арктангенса и тригонометрических преобразованиях.

Это расширение POSIX/GNU, а не часть стандарта ISO C. Макрос доступен при компиляции с определением `_GNU_SOURCE` или в среде POSIX. Для переносимых вычислений можно использовать `2.0 / M_PI`.

## Примеры

```c
#define _GNU_SOURCE
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("M_2_PI = %.20f\n", M_2_PI);
    printf("2 / M_PI = %.20f\n", 2.0 / M_PI);

    // Интеграл арктангенса
    double x = 1.0;
    double integral = M_2_PI * atan(x);
    printf("(2/π)·atan(%.0f) = %.10f\n", x, integral);

    return 0;
}
```
