## Определение

```c
#define M_1_PI 0.31830988618379067154
```

## Описание

Макрос — обратная величина числа π, то есть 1/π. Приблизительно равно 0.31831. Используется в формулах, где требуется деление на π (например, в преобразованиях Фурье и интегрировании).

Это расширение POSIX/GNU, а не часть стандарта ISO C. Макрос доступен при компиляции с определением `_GNU_SOURCE` или в среде POSIX. Для переносимых вычислений можно использовать `1.0 / M_PI` или `acos(-1.0)` с последующим делением.

## Примеры

```c
#define _GNU_SOURCE
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("M_1_PI = %.20f\n", M_1_PI);
    printf("1 / M_PI = %.20f\n", 1.0 / M_PI);

    // Площадь круга через диаметр: S = π·r² = (π/4)·d²
    double d = 10.0;
    double area = M_PI * (d / 2.0) * (d / 2.0);
    printf("Площадь круга с диаметром %.0f: %.2f\n", d, area);

    return 0;
}
```
