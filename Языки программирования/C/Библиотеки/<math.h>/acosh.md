## Определение

```c
#include <math.h>

double acosh(double x);
float acoshf(float x);         // C99
long double acoshl(long double x); // C99
```

## Описание

Функция вычисляет обратный гиперболический косинус. Defined for x ≥ 1. Может быть выражена как acosh(x) = ln(x + √(x² - 1)).

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("acosh(1) = %f\n", acosh(1.0)); // 0.0
    printf("acosh(2) = %f\n", acosh(2.0)); // ~1.31696
    
    // Проверка свойства cosh(acosh(x)) = x для x ≥ 1
    double x = 3.0;
    printf("cosh(acosh(%f)) = %f\n", x, cosh(acosh(x)));
    
    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** При x < 1 возникает доменная ошибка; реализация может установить `errno` = `EDOM`.
- **Возвращаемое значение при ошибке:** При x < 1 возвращает NaN.
- **Многопоточность:** Функция является потокобезопасной.
