## Определение

```c
#include <math.h>

double atanh(double x);
float atanhf(float x);         // C99
long double atanhl(long double x); // C99
```

## Описание

Функция вычисляет обратный гиперболический тангенс. Defined for x ∈ (-1, 1). Может быть выражена как atanh(x) = 0.5 * ln((1+x)/(1-x)).

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("atanh(0) = %f\n", atanh(0.0)); // 0.0
    printf("atanh(0.5) = %f\n", atanh(0.5)); // ~0.5493
    printf("atanh(-0.5) = %f\n", atanh(-0.5)); // -0.5493
    
    // Проверка свойства tanh(atanh(x)) = x для x ∈ (-1, 1)
    double x = 0.3;
    printf("tanh(atanh(%f)) = %f\n", x, tanh(atanh(x)));
    
    return 0;
}
```
