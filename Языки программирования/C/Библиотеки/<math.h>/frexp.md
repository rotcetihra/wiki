## Определение

```c
#include <math.h>

double frexp(double x, int *exp);
float frexpf(float x, int *exp);            // C99
long double frexpl(long double x, int *exp); // C99
```

## Описание

Функция разлагает число x на нормализованную мантиссу m и целочисленный показатель экспоненты n такие, что x = m × 2^n, где 0.5 ≤ |m| < 1. Показатель n записывается по указателю exp. Эта функция полезна при работе с внутренним представлением чисел с плавающей точкой.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    int exp;
    double m;

    m = frexp(8.0, &exp);
    printf("8.0 = %.1f * 2^%d\n", m, exp); // 1.0 * 2^3

    m = frexp(5.0, &exp);
    printf("5.0 = %.1f * 2^%d\n", m, exp); // 0.625 * 2^3

    m = frexp(0.25, &exp);
    printf("0.25 = %.1f * 2^%d\n", m, exp); // 0.5 * 2^(-1)

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет извлечь мантиссу и показатель без обращения к представлению в памяти | Результат для x = 0 не определён стандартом |
| Работает для всех конечных чисел | Специальные значения (±∞, NaN) возвращаются без изменения |
