## Определение

```c
#include <math.h>

#define islessequal(x, y) /* implementation-defined */
```

## Описание

Макрос определяет, является ли значение x меньше или равно значению y. Возвращает ненулевое значение, если `x <= y`, и ноль в противном случае. Не вызывает ненормализованный результат для ненормализованных значений.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("islessequal(5.0, 3.0) = %d\n", islessequal(5.0, 3.0));   // 0 (ложь)
    printf("islessequal(3.0, 5.0) = %d\n", islessequal(3.0, 5.0));   // 1 (истина)
    printf("islessequal(5.0, 5.0) = %d\n", islessequal(5.0, 5.0));   // 1 (истина)
    printf("islessequal(NAN, 1.0) = %d\n", islessequal(NAN, 1.0));   // 0 (ложь)
    printf("islessequal(1.0, NAN) = %d\n", islessequal(1.0, NAN));   // 0 (ложь)
    
    return 0;
}
```

|---|---|
