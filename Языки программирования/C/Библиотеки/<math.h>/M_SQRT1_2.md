## Определение

```c
#define M_SQRT1_2 0.70710678118654752440
```

## Описание

Макрос — квадратный корень из половины, то есть √(1/2) = 1/√2. Приблизительно равно 0.707107. Используется в нормализации векторов, вычислениях с единичными векторами и тригонометрических преобразованиях.

Это расширение POSIX/GNU, а не часть стандарта ISO C. Макрос доступен при компиляции с определением `_GNU_SOURCE` или в среде POSIX. Для переносимых вычислений можно использовать `1.0 / sqrt(2.0)` или `sqrt(0.5)`.

## Примеры

```c
#define _GNU_SOURCE
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("M_SQRT1_2 = %.20f\n", M_SQRT1_2);
    printf("1 / sqrt(2) = %.20f\n", 1.0 / sqrt(2.0));
    printf("sqrt(0.5) = %.20f\n", sqrt(0.5));

    // cos(45°) = sin(45°) = 1/√2
    printf("cos(π/4) = %.10f\n", cos(M_PI_4));

    return 0;
}
```
