## Определение

```c
#include <math.h>

long lrint(double x);
long lrintf(float x);         // C99
long lrintl(long double x); // C99
```

## Описание

Функция округляет аргумент x до ближайшего целого числа типа long с использованием текущего направления округления ( установленного через fesetround ). Если результат не может быть представлен как long, поведение не определено.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("lrint(2.3) = %ld\n", lrint(2.3)); // 2
    printf("lrint(2.5) = %ld\n", lrint(2.5)); // 2 (приRoundTowardZero)
    printf("lrint(2.7) = %ld\n", lrint(2.7)); // 3
    printf("lrint(-2.3) = %ld\n", lrint(-2.3)); // -2
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Учитывает текущее направление округления | Поведение не определено при переполнении |
| Поддерживает все типы с плавающей точкой |  |
