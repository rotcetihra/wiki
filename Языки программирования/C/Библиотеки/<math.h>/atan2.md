## Определение

```c
#include <math.h>

double atan2(double y, double x);
float atan2f(float y, float x);         // C99
long double atan2l(long double y, long double x); // C99
```

## Описание

Функция вычисляет арктангенс y/x, используя знаки обоих аргументов для определения квадранта результата. Результат находится в диапазоне [-π, π]. Это более полная версия atan(y/x), которая корректно обрабатывает случаи, когда x = 0.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    // Точки в разных квадрантах
    printf("atan2(0, 1) = %f\n", atan2(0.0, 1.0));   // 0.0
    printf("atan2(1, 1) = %f\n", atan2(1.0, 1.0));   // π/4 ≈ 0.7854
    printf("atan2(1, 0) = %f\n", atan2(1.0, 0.0));   // π/2 ≈ 1.5708
    printf("atan2(1, -1) = %f\n", atan2(1.0, -1.0)); // 3π/4 ≈ 2.3562
    printf("atan2(0, -1) = %f\n", atan2(0.0, -1.0)); // π ≈ 3.1416
    printf("atan2(-1, -1) = %f\n", atan2(-1.0, -1.0)); // -3π/4 ≈ -2.3562
    printf("atan2(-1, 0) = %f\n", atan2(-1.0, 0.0)); // -π/2 ≈ -1.5708
    printf("atan2(-1, 1) = %f\n", atan2(-1.0, 1.0)); // -π/4 ≈ -0.7854
    
    return 0;
}
```

## Обработка ошибок

- **Поведение при передаче NULL:** Аргументы не являются указателями, поэтому передача NULL не применима.
- **Установление errno:** Функция не устанавливает `errno` при стандартном использовании.
- **Возвращаемое значение при ошибке:** Результат всегда определён для всех комбинаций конечных аргументов; для бесконечных аргументов возвращает значение, кратное π/2.
- **Многопоточность:** Функция является потокобезопасной.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<math.h>/atan|atan]] — арктангенс с одним аргументом, [[Языки программирования/C/Библиотеки/<math.h>/tan|tan]] — тангенс, [[Языки программирования/C/Библиотеки/<math.h>/asin|asin]] — арксинус.
