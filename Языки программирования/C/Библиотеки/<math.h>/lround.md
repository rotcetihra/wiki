## Определение

```c
#include <math.h>

long lround(double x);
long lroundf(float x);         // C99
long lroundl(long double x); // C99
```

## Описание

Функция округляет аргумент x до ближайшего целого числа типа long. Если значение находится ровно посередине между двумя целыми, округление происходит в сторону положительной бесконечности (away from zero).

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("lround(2.3) = %ld\n", lround(2.3)); // 2
    printf("lround(2.5) = %ld\n", lround(2.5)); // 3
    printf("lround(2.7) = %ld\n", lround(2.7)); // 3
    printf("lround(-2.5) = %ld\n", lround(-2.5)); // -3
    printf("lround(-2.3) = %ld\n", lround(-2.3)); // -2
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |

| Поддерживает все типы с плавающей точкой |  |

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** Если результат не может быть представлен как long, поведение не определено (стандарт не требует установки errno).
- **Возвращаемое значение при ошибке:** При переполнении поведение не определено (возможно исключениеSIGILL или возврат произвольного значения).
- **Многопоточность:** Функция является потокобезопасной.
