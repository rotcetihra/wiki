## Определение

```c
#include <math.h>

#define islessgreater(x, y) /* implementation-defined */
```

## Описание

Макрос определяет, является ли значение x строго меньше или строго больше значения y (т.е. не равно ему). Возвращает ненулевое значение, если `x < y` или `x > y`, и ноль в противном случае. Не вызывает ненормализованный результат для ненормализованных значений.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("islessgreater(5.0, 3.0) = %d\n", islessgreater(5.0, 3.0));   // 1 (истина)
    printf("islessgreater(3.0, 5.0) = %d\n", islessgreater(3.0, 5.0));   // 1 (истина)
    printf("islessgreater(5.0, 5.0) = %d\n", islessgreater(5.0, 5.0));   // 0 (ложь)
    printf("islessgreater(NAN, 1.0) = %d\n", islessgreater(NAN, 1.0));   // 0 (ложь)
    printf("islessgreater(1.0, NAN) = %d\n", islessgreater(1.0, NAN));   // 0 (ложь)
    
    return 0;
}
```

## Плюсы и минусы

|---|---|
