## Определение

```c
#include <math.h>

double exp2(double x);
float exp2f(float x);            // C99
long double exp2l(long double x); // C99
```

## Описание

Функция вычисляет значение 2 в степени x, то есть 2^x. Результат — это экспонента по основанию 2. При x = 0 результат равен 1.0. Функция полезна при работе с бинарными масками и битовыми операциями, а также при вычислении степеней двойки.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("exp2(0) = %f\n", exp2(0.0));    // 1.0
    printf("exp2(1) = %f\n", exp2(1.0));    // 2.0
    printf("exp2(3) = %f\n", exp2(3.0));    // 8.0
    printf("exp2(10) = %f\n", exp2(10.0));  // 1024.0
    printf("exp2(-1) = %f\n", exp2(-1.0));  // 0.5

    // Вычисление количества бит для числа
    unsigned int n = 42;
    int bits = (int)ceil(log2(n));
    printf("Для числа %u нужно %d бит\n", n, bits);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Точное вычисление для целочисленных степеней двойки | Переполнение для больших положительных x (результат → +∞) |
| Поддерживает все типы с плавающей точкой | Для отрицательных x результат стремится к 0, возможна потеря точности |

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** При переполнении результата (x слишком большой) реализация может установить `errno` = `ERANGE`.
- **Возвращаемое значение при ошибке:** При переполнении возвращает ±`HUGE_VAL`. При аргументе, стремящемся к −∞, результат стремится к +0.
- **Многопоточность:** Функция является потокобезопасной.
