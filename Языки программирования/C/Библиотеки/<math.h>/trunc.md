## Определение

```c
#include <math.h>

double trunc(double x);
float truncf(float x);         // C99
long double truncl(long double x); // C99
```

## Описание

Функция отбрасывает дробную часть аргумента x, возвращая ближайшее целое число по модулю не большее |x| (округление к нулю). trunc(2.7) = 2.0, trunc(-2.7) = -2.0.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("trunc(2.3) = %f\n", trunc(2.3)); // 2.0
    printf("trunc(2.9) = %f\n", trunc(2.9)); // 2.0
    printf("trunc(-2.3) = %f\n", trunc(-2.3)); // -2.0
    printf("trunc(-2.9) = %f\n", trunc(-2.9)); // -2.0
    printf("trunc(2.0) = %f\n", trunc(2.0)); // 2.0
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрое отбрасывание дробной части | Результат всегда целое число (может терять дробную часть) |
| Поддерживает все типы с плавающей точкой |  |

## Обработка ошибок

- **Поведение при передаче NULL:** Аргумент не является указателем, поэтому передача NULL не применима.
- **Установление errno:** Функция не устанавливает `errno` при стандартном использовании.
- **Возвращаемое значение при ошибке:** Результат всегда определён для всех конечных аргументов; для бесконечных возвращает ±∞, для NaN возвращает NaN.
- **Многопоточность:** Функция является потокобезопасной.
