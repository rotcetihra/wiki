## Определение

```c
#include <time.h>

time_t time(time_t *timer);
```

## Описание

Функция `time()` возвращает текущее календарное время в виде `time_t` — количество секунд с эпохи (обычно 00:00:00 1 января 1970 года, UTC). Если указатель `timer` не равен `NULL`, текущее время также записывается по этому адресу.

При ошибке возвращает `(time_t)(-1)`.

Точность — 1 секунда. Для наносекундной точности используйте `timespec_get()` (C11) или `clock_gettime()` (POSIX).

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    time_t now = time(NULL);
    printf("Текущее время (секунды с эпохи): %ld\n", (long)now);

    /* Сохранение времени в переменную */
    time_t t;
    time(&t);
    printf("То же: %ld\n", (long)t);

    return 0;
}
```

| Преимущество | Недостаток |

## Обработка ошибок

- **Поведение при передаче NULL:** допустимо — если `timer` равен `NULL`, текущее время только возвращается и не записывается по указателю.
- **Возвращаемое значение при ошибке:** `(time_t)(-1)`.
- **Установление errno:** при ошибке может установить `errno` (реализация-зависимо; стандарт не гарантирует конкретных значений).
- **Многопоточность:** потокобезопасна на большинстве платформ, но стандарт не гарантирует этого. На POSIX-системах `time()` является асинхронно-безопасной.
