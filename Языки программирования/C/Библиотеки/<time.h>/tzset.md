## Определение

```c
#include <time.h>

void tzset(void);
```

## Описание

Функция `tzset()` инициализирует информацию о часовом поясе из переменных окружения `TZ`, `TZDIR` и `LOCALTIME`. После вызова функции переменные `timezone`, `daylight` и `tzname` содержат соответствующие данные.

Переменные окружения:

| Переменная | Описание |
|---|---|
| `TZ` | Часовой пояс (например, `MSK-3`, `Europe/Moscow`) |
| `TZDIR` | Каталог с файлами часовых поясов (по умолчанию `/usr/share/zoneinfo`) |
| `LOCALTIME` | Альтернативный файл локального времени |

Функция вызывается автоматически при использовании `localtime()`, но может быть вызвана явно для принудительного обновления информации о часовом поясе. В POSIX-системах `tzset()` вызывается также при изменении переменной `TZ`.

> [!NOTE]
> Функция не входит в ISO C — это POSIX-расширение. В Windows `tzset()` доступна через MSVC CRT.

## Примеры

```c
#include <stdio.h>
#include <time.h>
#include <stdlib.h>

int main(void)
{
    /* Установка часового пояса */
    setenv("TZ", "Europe/Moscow", 1);
    tzset();

    time_t now = time(NULL);
    struct tm *tm = localtime(&now);
    printf("Москва: %02d:%02d\n", tm->tm_hour, tm->tm_min);

    /* Смена на UTC */
    setenv("TZ", "UTC", 1);
    tzset();

    tm = localtime(&now);
    printf("UTC: %02d:%02d\n", tm->tm_hour, tm->tm_min);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет управлять часовым поясом через переменные окружения | POSIX-расширение (не ISO C) |
| Автоматически обновляет переменные `timezone`, `daylight`, `tzname` | Побочные эффекты на глобальном уровне |
| Потокобезопасна в современных реализациях | Файлы часовых поясов могут отсутствовать |
