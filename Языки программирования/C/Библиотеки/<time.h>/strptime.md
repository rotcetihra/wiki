## Определение

```c
#define _XOPEN_SOURCE 500
#include <time.h>

char *strptime(const char *buf, const char *format, struct tm *tm);
```

## Описание

Функция `strptime()` разбирает строку с датой/временем в соответствии с шаблоном `format` и заполняет структуру `struct tm`. Возвращает указатель на символ, следующий за последним распознанным, или `NULL`, если разбор не удался.

Основные спецификаторы формата:

| Спецификатор | Описание |
|---|---|
| `%Y` | Год с веком (4 цифры) |
| `%m` | Месяц (01–12) |
| `%d` | День месяца (01–31) |
| `%H` | Час (00–23) |
| `%M` | Минуты (00–59) |
| `%S` | Секунды (00–60) |
| `%A` | Полное название дня недели |
| `%a` | Сокращённое название дня |
| `%B` | Полное название месяца |
| `%b` | Сокращённое название месяца |
| `%n` | Пробельные символы |

> [!NOTE]
> Функция не входит в ISO C — это POSIX-расширение. На Windows отсутствует. Для кроссплатформенного кода используйте `sscanf()`.

## Примеры

```c
#define _XOPEN_SOURCE 500
#include <stdio.h>
#include <string.h>
#include <time.h>

int main(void)
{
    struct tm tm = {0};
    char *ret;

    ret = strptime("20.08.2026 14:30", "%d.%m.%Y %H:%M", &tm);
    if (ret != NULL) {
        printf("Дата: %02d.%02d.%04d\n",
               tm.tm_mday, tm.tm_mon + 1, tm.tm_year + 1900);
        printf("Время: %02d:%02d\n", tm.tm_hour, tm.tm_min);
        printf("Остаток строки: «%s»\n", ret);
    }

    ret = strptime("August 20, 2026", "%B %d, %Y", &tm);
    if (ret != NULL) {
        printf("Разобрано: %02d.%02d.%04d\n",
               tm.tm_mday, tm.tm_mon + 1, tm.tm_year + 1900);
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Потокобезопасна (нет глобального состояния) | Не входит в ISO C (POSIX-расширение) |
| Гибкий формат | Не доступна на Windows |
| Указывает позицию остановки разбора | Не нормализует компоненты (в отличие от `mktime`) |
