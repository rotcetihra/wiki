## Определение

```c
#include <time.h>

#define CLOCKS_PER_SEC /* implementation-defined */
```

## Описание

Макрос `CLOCKS_PER_SEC` определяет количество тиков процессора в секунду. Используется для преобразования результата функции `clock()` в секунды: время в секундах равно `clock() / CLOCKS_PER_SEC`.

Значение зависит от реализации. В POSIX-системах (Linux, macOS) обычно равно 1 000 000 (микросекундное разрешение), в Windows — 1000 (миллисекундное разрешение).

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    printf("CLOCKS_PER_SEC = %ld\n", (long)CLOCKS_PER_SEC);

    clock_t start = clock();

    /* Загрузка */
    volatile long long sum = 0;
    for (long long i = 0; i < 100000000LL; i++)
        sum += i;

    clock_t end = clock();
    double cpu_sec = (double)(end - start) / CLOCKS_PER_SEC;
    printf("Время процессора: %.6f сек\n", cpu_sec);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Константа, определённая стандартом | Значение зависит от платформы |
| Необходима для переносимого преобразования тиков в секунды | Не отражает реальное время (только процессорное) |
