## Определение

```c
#include <time.h>

time_t timelocal(struct tm *timeptr);
```

## Описание

Функция `timelocal()` является синонимом `mktime()` в системах BSD и некоторых старых UNIX-системах. Преобразует `struct tm` в `time_t` в локальном часовом поясе, нормализуя компоненты даты.

Это устаревшая функция — во всех современных POSIX-системах рекомендуется использовать `mktime()`, которая является стандартной ISO C. `timelocal()` не гарантирована стандартом и может отсутствовать на некоторых платформах.

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    struct tm tm = {0};
    tm.tm_year = 126;
    tm.tm_mon = 7;
    tm.tm_mday = 20;
    tm.tm_hour = 12;
    tm.tm_isdst = -1;

    /* Предпочтительный способ: mktime */
    time_t t1 = mktime(&tm);
    printf("mktime: %ld\n", (long)t1);

    /* Устаревший способ: timelocal (если доступна) */
    #if defined(__BSD__) || defined(__linux__)
    time_t t2 = timelocal(&tm);
    printf("timelocal: %ld\n", (long)t2);
    #endif

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Прямой аналог `mktime()` в BSD | Устаревшая, не стандартная |
| | Отсутствует на многих платформах |
| | Нет преимуществ перед `mktime()` |

## Обработка ошибок

- **Поведение при передаче NULL:** поведение не определено (UB). Функция является синонимом `mktime()` и наследует её поведение.
- **Возвращаемое значение при ошибке:** `(time_t)(-1)`, как и `mktime()`.
- **Многопоточность:** не потокобезопасна — зависит от локали (глобальное состояние часового пояса). Как и `mktime()`.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<time.h>/mktime|mktime]] — стандартная альтернатива (ISO C); [[Языки программирования/C/Библиотеки/<time.h>/localtime|localtime]] — обратное преобразование `time_t` → `struct tm`.

> [!WARNING]
> Функция устаревшая и не гарантирована стандартом. Используйте `mktime()`.
