## Определение

```c
#include <time.h>

typedef /* integer or real type */ clock_t;
```

## Описание

Тип `clock_t` предназначен для представления времени процессора в тиках. Используется как результат функции `clock()`, которая возвращает количество тиков процессора, использованных программой с момента запуска.

Конкретный тип `clock_t` определяется реализацией — обычно это `long` или `unsigned long`. Для преобразования тиков в секунды необходимо делить значение на `CLOCKS_PER_SEC`.

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    clock_t start = clock();

    long long sum = 0;
    for (long long i = 0; i < 100000000LL; i++)
        sum += i;

    clock_t end = clock();
    double elapsed = (double)(end - start) / CLOCKS_PER_SEC;

    printf("Сумма: %lld\n", sum);
    printf("Время выполнения: %.3f сек\n", elapsed);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Единственный стандартный способ измерения времени процессора в ISO C | Разрешение зависит от реализации (может быть ~1 мс) |
| Портативен между платформами | Не измеряет реальное время (стоп-часы) |
| Не требует подключения дополнительных библиотек | Тип определяется реализацией, не гарантировано `long` |
