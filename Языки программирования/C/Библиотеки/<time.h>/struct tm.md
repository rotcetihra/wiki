## Определение

```c
#include <time.h>

struct tm {
    int tm_sec;   /* секунды — от 0 до 60 (60 для високосной секунды) */
    int tm_min;   /* минуты — от 0 до 59 */
    int tm_hour;  /* часы — от 0 до 23 */
    int tm_mday;  /* день месяца — от 1 до 31 */
    int tm_mon;   /* месяц — от 0 до 11 (январь = 0) */
    int tm_year;  /* годы с 1900 года */
    int tm_wday;  /* день недели — от 0 до 6 (воскресенье = 0) */
    int tm_yday;  /* день года — от 0 до 365 */
    int tm_isdst; /* флаг летнего времени: > 0 — летнее, 0 — зимнее, < 0 — неизвестно */
};
```

## Описание

Структура `struct tm` хранит компоненты календарного времени в разбитом виде. Используется функциями `localtime()`, `gmtime()`, `mktime()`, `strftime()` и `asctime()`.

Поля `tm_mon` и `tm_wday` отсчитываются от нуля: январь = 0, воскресенье = 0. Поле `tm_year` содержит количество лет, прошедших с 1900 года (например, 2026 годrepresented как 126). Поле `tm_isdst` указывает, действует ли в данный момент летнее время: положительное значение — летнее, ноль — зимнее, отрицательное — информация недоступна.

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    time_t now = time(NULL);
    struct tm *local = localtime(&now);

    printf("Дата: %02d.%02d.%04d\n",
           local->tm_mday, local->tm_mon + 1, local->tm_year + 1900);
    printf("Время: %02d:%02d:%02d\n",
           local->tm_hour, local->tm_min, local->tm_sec);
    printf("День недели: %d (0=вс)\n", local->tm_wday);
    printf("День года: %d\n", local->tm_yday);
    printf("Летнее время: %s\n", local->tm_isdst > 0 ? "да" : "нет");

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Человекочитаемое представление даты | Поля хранятся в нестандартном формате (месяц от 0, год от 1900) |
| Поддерживается полная информация о дате | Нет встроенного способа проверить корректность значений |
| Удобно для форматирования вывода | Указатель на статический буфер (`localtime`/`gmtime`) не потокобезопасен |
