## Определение

```c
#include <time.h>

time_t mktime(struct tm *timeptr);
```

## Описание

Функция `mktime()` преобразует `struct tm` в `time_t` в локальном часовом поясе. Поля структуры нормализуются: например, если задать `tm_hour = 25`, это будет преобразовано в следующий день с `tm_hour = 1`.

Поле `tm_isdst` влияет на результат: если `tm_isdst > 0`, предполагается летнее время; если `tm_isdst == 0`, зимнее; если `tm_isdst < 0`, функция сама определяет, действует ли летнее время.

При ошибке возвращает `(time_t)(-1)`.

Функция также определяет недостающие поля: `tm_wday` и `tm_yday` вычисляются автоматически.

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    struct tm tm = {0};
    tm.tm_year = 126;   /* 2026 */
    tm.tm_mon = 7;      /* август (от 0) */
    tm.tm_mday = 20;
    tm.tm_hour = 14;
    tm.tm_min = 30;
    tm.tm_sec = 0;
    tm.tm_isdst = -1;   /* автоопределение */

    time_t t = mktime(&tm);
    if (t != (time_t)(-1)) {
        printf("time_t: %ld\n", (long)t);
        printf("День недели: %d (0=вс)\n", tm.tm_wday);
        printf("День года: %d\n", tm.tm_yday);
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Нормализует компоненты даты | Работает только с локальным временем |

| Стандартная функция ISO C | Не потокобезопасна (зависит от локали) |

## Обработка ошибок

- **Поведение при передаче NULL:** поведение не определено (UB). Стандарт не описывает поведение `mktime()` при передаче `NULL` в `timeptr`.
- **Возвращаемое значение при ошибке:** `(time_t)(-1)`.
- **Установление errno:** функция не определяет значение `errno`.
- **Многопоточность:** не потокобезопасна, так как зависит от локали (глобальное состояние часового пояса, daylight saving time). Поведение может отличаться при параллельных вызовах.
