## Определение

```c
#include <time.h>

char *ctime(const time_t *timer);
```

## Описание

Функция `ctime()` преобразует указатель на `time_t` в строку фиксированного формата, эквивалентна вызову `asctime(localtime(timer))`. Формат строки:

```
Day Mon DD HH:MM:SS YYYY\n
```

Например: `Sun Aug 20 14:30:00 2026\n`.

Возвращаемый указатель указывает на статический буфер, который перезаписывается при каждом вызове `ctime()`, `asctime()`, `localtime()` или `gmtime()`. Функция не потокобезопасна — в POSIX-системах доступен потокобезопасный вариант `ctime_r()`.

> [!WARNING]
> Как и `asctime()`, формат строки зависит от локали и не подходит для машинного разбора. Используйте `strftime()` для гибкого форматирования.

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    time_t now = time(NULL);

    printf("Текущее время: %s", ctime(&now));

    time_t deadline = now + 3600;
    printf("Через час: %s", ctime(&deadline));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Компактный способ получить строку с датой | Фиксированный формат |
| Не нужна промежуточная `struct tm` | Возвращает указатель на статический буфер (не потокобезопасна) |
| | Зависит от локали |

## Обработка ошибок

- **Поведение при передаче NULL:** поведение не определено (UB). Стандарт не описывает поведение `ctime()` при передаче `NULL` в качестве `timer` — результат не определён.
- **Возвращаемое значение при ошибке:** `NULL`, если представление времени недоступно.
- **Многопоточность:** не потокобезопасна. Возвращает указатель на статический буфер, который перезаписывается при каждом вызове `ctime()`, `asctime()`, `localtime()` или `gmtime()`. В POSIX-системах используйте потокобезопасный аналог `ctime_r()`.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<time.h>/asctime|asctime]] — аналогичное преобразование из `struct tm`; [[Языки программирования/C/Библиотеки/<time.h>/localtime|localtime]] — промежуточное преобразование `time_t` в `struct tm`; [[Языки программирования/C/Библиотеки/<time.h>/strftime|strftime]] — безопасное форматирование по шаблону.
