## Определение

```c
#include <time.h>

char *asctime(const struct tm *timeptr);
```

## Описание

Функция `asctime()` преобразует структуру `struct tm` в строку фиксированного формата:

```
Day Mon DD HH:MM:SS YYYY\n
```

Например: `Sun Aug 20 14:30:00 2026\n`.

Возвращаемый указатель указывает на статический буфер, который перезаписывается при каждом вызове `asctime()`, `localtime()`, `gmtime()` или `ctime()`. Функция не потокобезопасна — в POSIX-системах доступен потокобезопасный вариант `asctime_r()`.

> [!WARNING]
> Формат строки зависит от локали и не подходит для машинного разбора. Для форматированного вывода используйте `strftime()`.

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    time_t now = time(NULL);
    struct tm *tm = localtime(&now);

    char *str = asctime(tm);
    printf("Текущее время: %s", str);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простой способ получить строку с датой | Фиксированный формат, нельзя настроить |
| Стандартная функция ISO C | Возвращает указатель на статический буфер (не потокобезопасна) |
| | Зависит от локали ( daylight saving time может добавить пробел) |

## Обработка ошибок

- **Поведение при передаче NULL:** поведение не определено (UB). Стандарт не описывает поведение `asctime()` при передаче `NULL` в `timeptr`.
- **Возвращаемое значение при ошибке:** `NULL`, если представление времени недоступно.
- **Многопоточность:** не потокобезопасна. Возвращает указатель на статический буфер, который перезаписывается при каждом вызове `asctime()`, `localtime()`, `gmtime()` или `ctime()`. В POSIX-системах используйте потокобезопасный аналог `asctime_r()`.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<time.h>/ctime|ctime]] — преобразует `time_t` напрямую (комбинация `localtime` + `asctime`); [[Языки программирования/C/Библиотеки/<time.h>/strftime|strftime]] — безопасное форматирование по шаблону с ограничением размера буфера.
