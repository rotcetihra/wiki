## Определение

```c
#include <locale.h>

#define LC_COLLATE /* константа категории локали */
```

## Описание

Константа `LC_COLLATE` определяет правила колляции (сортировки строк).

Используется как параметр функции `setlocale` для установки или запроса текущей локали, а также как параметр `localeconv` (косвенно, через `setlocale`).

`LC_COLLATE` можно комбинировать с другими категориями через побитовое ИЛИ, но стандарт не гарантирует, что значение `LC_COLLATE` является побитовой маской. Безопасный способ установить все категории -- передать `LC_COLLATE` как отдельный параметр.

## Пример

```c
#include <stdio.h>
#include <locale.h>

int main(void)
{
    if (setlocale(LC_COLLATE, "ru_RU.UTF-8") == NULL) {
        printf("Не удалось установить локаль\n");
        return 1;
    }

    printf("Категория LC_COLLATE установлена\n");
    printf("Текущая локаль: %s\n", setlocale(LC_COLLATE, NULL));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный способ управления локалью | Доступные локали зависят от операционной системы |
| Позволяет устанавливать категории по отдельности | Значение константы определяется реализацией |
| Совместим с `localeconv` и `setlocale` | -- |
