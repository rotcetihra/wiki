## Определение

```c
#include <locale.h>

#define NULL /* реализация-зависимое нулевое указательное значение */
```

## Описание

Макрос `NULL` определяет значение нулевого указателя. В `<locale.h>` он определяется для удобства -- его основное определение находится в `<stddef.h>`.

> [!NOTE]
> `NULL` -- это кросс-ссылка на стандартный заголовочный файл `<stddef.h>`. В `<locale.h>` он повторно определён для совместимости, но его каноническое определение -- в `<stddef.h>`.

Значение `NULL` гарантируется как ненулевой адрес, безопасно сравниваемый с указателями. В C23 `NULL` может быть определено как `nullptr`.

## Пример

```c
#include <stdio.h>
#include <locale.h>

int main(void)
{
    char *result = setlocale(LC_ALL, NULL);
    if (result != NULL) {
        printf("Текущая локаль: %s\n", result);
    }
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Универсальное значение нулевого указателя | Не различает `void*`, `char*` и другие типы указателей |
| Гарантированно безопасное сравнение | В C23 может быть заменён на `nullptr` |
| Стандартное определение (ISO C) | -- |
