## Определение

```c
#include <locale.h>

struct lconv *localeconv(void);
```

## Описание

Функция `localeconv` возвращает указатель на структуру `struct lconv`, содержащую параметры форматирования числовых и денежных значений для текущей локали.

Структура `lconv` заполняется на основе текущей категории `LC_NUMERIC` и `LC_MONETARY`. При多次 вызовах `localeconv` возвращает указатель на одну и ту же структуру (статический объект).

> [!WARNING]
> Указатели на члены структуры `lconv` могут стать невалидными после вызова `setlocale`, если.categories `LC_MONETARY` или `LC_NUMERIC` были изменены. Следует копировать нужные данные до следующего вызова `setlocale`.

## Пример

```c
#include <stdio.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "ru_RU.UTF-8");

    struct lconv *lc = localeconv();

    printf("Десятичный разделитель: \"%s\"\n", lc->decimal_point);
    printf("Разделитель тысяч: \"%s\"\n", lc->thousands_sep);
    printf("Группировка: \"%s\"\n", lc->grouping);
    printf("Символ валюты: \"%s\"\n", lc->currency_symbol);
    printf("Десятичный разделитель (валюта): \"%s\"\n", lc->mon_decimal_point);
    printf("Международный символ: \"%s\"\n", lc->int_curr_symbol);
    printf("Количество дробных знаков: %d\n", lc->frac_digits);

    return 0;
}
```

## Параметры

Функция не принимает параметров.

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `struct lconv *` | Указатель на статическую структуру с параметрами текущей локали |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Возвращает все параметры форматирования за один вызов | Указатели могут стать невалидными после `setlocale` |
| Стандартная функция ISO C | Возвращает указатель на статический объект (не потокобезопасно) |
| Работает с текущей локалью | Не все поля определены для каждой локали |
