## Описание библиотеки

Заголовочный файл `<ctype.h>` — «типы символов» (character types): функции классификации и преобразования одиночных символов. Классификация определяет, к какой категории относится символ: буква, цифра, пробельный символ, знак пунктуации и т. п. Преобразование переводит буквы из одного регистра в другой.

Все функции принимают код символа как `int`, но используют только младший байт (аргумент приводится к `unsigned char`): передача отрицательного значения, отличного от `EOF`, — неопределённое поведение. Функции не устанавливают `errno`.

Классификация зависит от текущей локали: в локали `C` буквами считаются только латинские `A–Z` и `a–z`, а в локалях с расширенными алфавитами (например, `ru_RU.UTF-8`) — также буквы национальных алфавитов. Базовые понятия классификации символов рассматриваются в статье [[Языки программирования/C/Глава 9. Стандартная библиотека C/10. Проверка символов и ctype.h|Проверка символов и ctype.h]] главы 9.

В POSIX-системах `<ctype.h>` расширяется функциями с явной локалью (`_l`): они классифицируют и преобразуют символы по правилам локали, переданной параметром, не затрагивая глобальную локаль процесса. Устаревшие функции `isascii()`, `toascii()`, `_tolower()`, `_toupper()` не входят в ISO C и не рекомендуются к использованию.

### Стандарт C

#### Классификация

| Функция | Возвращает ненулевое значение, если символ … |
|---|---|
| `isalnum()` | буква или цифра |
| `isalpha()` | буква |
| `isblank()` | пробел или табуляция (C99) |
| `iscntrl()` | управляющий символ (0x00–0x1F, 0x7F) |
| `isdigit()` | десятичная цифра `0`–`9` |
| `isgraph()` | печатный символ, отличный от пробела |
| `islower()` | строчная буква |
| `isprint()` | печатный символ (включая пробел) |
| `ispunct()` | знак пунктуации |
| `isspace()` | пробельный символ (`' '`, `'\t'`, `'\n'`, `'\v'`, `'\f'`, `'\r'`) |
| `isupper()` | заглавная буква |
| `isxdigit()` | шестнадцатеричная цифра (`0`–`9`, `a`–`f`, `A`–`F`) |

#### Преобразование регистра

| Функция | Описание |
|---|---|
| `tolower()` | Возвращает нижний регистр буквы; для не-букв — сам символ |
| `toupper()` | Возвращает верхний регистр буквы; для не-букв — сам символ |

### Расширения POSIX и GNU

#### Проверка с явной локалью

| Функция | Описание |
|---|---|
| `isalnum_l()` … `isxdigit_l()` | 12 функций классификации, выполняющих проверку по правилам локали `locale_t` |
| `tolower_l()`, `toupper_l()` | Преобразование регистра по правилам локали `locale_t` |

#### Устаревшие функции

| Функция | Описание |
|---|---|
| `isascii()` | Проверка, что код входит в 7-битный набор ASCII (0–127) |
| `toascii()` | Обрезает код до 7 бит (`c & 0x7F`) |
| `_tolower()` | Быстрое преобразование в нижний регистр без проверки аргумента |
| `_toupper()` | Быстрое преобразование в верхний регистр без проверки аргумента |
