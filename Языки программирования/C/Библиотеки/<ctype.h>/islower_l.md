## Прототип

```c
#include <ctype.h> // POSIX.1-2008

int islower_l(int c, locale_t locale);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Код символа для проверки (приводится к `unsigned char`) |
| `locale` | Локаль (тип `locale_t` из `<locale.h>`), по правилам которой выполняется классификация |

## Возвращаемое значение

Возвращает ненулевое значение, если символ `c` является строчной буквой по правилам локали `locale`; 0 — в противном случае.

Проверка выполняется по таблице символов явно переданной локали, а не глобальной, что позволяет классифицировать символы без изменения состояния процесса — например, распознавать буквы кириллицы в `ru_RU.UTF-8`.

## Что делает

Проверяет, является ли символ `c` строчной буквой. В локали `C` верно следующее: только `a`–`z`; для символов с двунаправленным регистром выполняется `tolower(c) == c`.

Аргумент приводится к `unsigned char`: передача отрицательного значения, отличного от `EOF`, — неопределённое поведение.

## Примеры

```c
#define _XOPEN_SOURCE 700
#include <locale.h>
#include <stdio.h>
#include <ctype.h>

int main(void)
{
    locale_t ru = newlocale(LC_ALL_MASK, "ru_RU.UTF-8", (locale_t)0);

    printf("islower_l('А', ru) = %d\n", islower_l((unsigned char)'А', ru));
    printf("islower_l('A', ru) = %d\n", islower_l('A', ru));

    freelocale(ru);
    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Если `c` не представим как `unsigned char` и не равен `EOF`, поведение не определено.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Не зависит от глобальной локали процесса | Доступна только в POSIX-системах |
| Потокобезопасна при отдельных локалях | Требует создания и освобождения `locale_t` |
