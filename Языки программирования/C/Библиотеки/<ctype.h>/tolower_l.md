## Прототип

```c
#include <ctype.h> // POSIX.1-2008

int tolower_l(int c, locale_t locale);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Код символа для преобразования (приводится к `unsigned char`) |
| `locale` | Локаль (тип `locale_t` из `<locale.h>`), по правилам которой выполняется преобразование |

## Возвращаемое значение

Возвращает код символа, преобразованного в нижний регистр по правилам локали `locale`. Если преобразование для символа не предусмотрено (например, символ уже в нужном регистре или не является буквой), возвращает `c` без изменений.

## Что делает

Преобразует одиночный символ в нижний регистр по правилам локали `locale`: для букв с двунаправленным регистром возвращает соответствующий символ другого регистра, для остальных символов — сам `c`. Работает только с одним символом: для преобразования строк целиком используются циклы или `strxfrm()`.

## Примеры

```c
#define _XOPEN_SOURCE 700
#include <ctype.h>
#include <locale.h>
#include <stdio.h>

int main(void)
{
    locale_t ru = newlocale(LC_ALL_MASK, "ru_RU.UTF-8", (locale_t)0);

    printf("%c\n", tolower_l('А', ru));
    printf("%c\n", tolower_l('a', ru));

    freelocale(ru);
    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Если `c` не представим как `unsigned char` и не равен `EOF`, поведение не определено.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Не зависит от глобальной локали процесса | Доступна только в POSIX-системах |
| Потокобезопасна при отдельных локалях | Требует создания и освобождения `locale_t` |

## Альтернативы

- **`tolower()`** — то же преобразование в текущей глобальной локали (ISO C)
