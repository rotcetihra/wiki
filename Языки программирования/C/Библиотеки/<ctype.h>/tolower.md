## Прототип

```c
#include <ctype.h>

int tolower(int c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Код символа для преобразования (приводится к `unsigned char`) |

## Возвращаемое значение

Возвращает код символа, преобразованного в нижний регистр. Если преобразование для символа не предусмотрено (например, символ уже в нужном регистре или не является буквой), возвращает `c` без изменений.

## Что делает

Преобразует одиночный символ в нижний регистр: для букв с двунаправленным регистром возвращает соответствующий символ другого регистра, для остальных символов — сам `c`. Работает только с одним символом: для преобразования строк целиком используются циклы или `strxfrm()`.

## Примеры

```c
#include <ctype.h>
#include <stdio.h>

int main(void)
{
    printf("%c\n", tolower('A'));
    printf("%c\n", tolower('z'));
    printf("%c\n", tolower('5'));   // 5 — не буква

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Если `c` не представим как `unsigned char` и не равен `EOF`, поведение не определено.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и быстрая | Преобразует только один символ |
| Стандартная (ISO C) | Не преобразует строки целиком |

## Альтернативы

- **`toupper()`** — обратное преобразование
- **цикл по строке** — преобразование всех символов строки
