## Определение

```c
#include <stdarg.h>

#define va_copy(dst, src) // C99
```

## Описание

Макрос (C99) — копирование состояния списка переменных аргументов: `dst` становится независимой копией `src` на текущей позиции. Нужен, когда список нужно обойти дважды (первый проход — подсчитать, второй — обработать) или сохранить для передачи дальше. Простое присваивание `dst = src` для `va_list` не переносимо (в glibc `va_list` — массив), поэтому используется только `va_copy()`.

Каждую копию необходимо закрывать собственным вызовом `va_end()`.

## Примеры

```c
#include <stdarg.h>
#include <stdio.h>

int sum_and_count(int count, ...)
{
    va_list ap, ap2;
    int total = 0;

    va_start(ap, count);

    va_copy(ap2, ap);          // копия для первого прохода
    for (int i = 0; i < count; i++) {
        (void)va_arg(ap2, int);
    }
    va_end(ap2);

    for (int i = 0; i < count; i++) {
        total += va_arg(ap, int);
    }
    va_end(ap);

    return total;
}

int main(void)
{
    printf("%d\n", sum_and_count(3, 5, 6, 7)); // 18

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет обойти список несколько раз | Каждая копия требует собственного `va_end()` |
