## Описание библиотеки

Заголовочный файл `<libgen.h>` — определения функций сопоставления шаблонов. Определяет функции `basename()` и `dirname()` для разбора строковых путей файлов.

### Функции

| Функция | Описание |
|---|---|
| `basename(char *)` | Возвращает указатель на последний компонент пути |
| `dirname(char *)` | Возвращает указатель на компонент каталога пути |

### Возвращаемое значение

- `basename()`: указатель на имя файла (последний компонент пути) или `"."` если путь пуст.
- `dirname()`: указатель на каталог (всё до последнего `/`) или `"."` если путь пуст.

### Использование

```c
#include <libgen.h>

char path[] = "/home/user/file.txt";
char *dir = dirname(path);   /* "/home/user" */
char *base = basename(path); /* "file.txt" */
```

## Исключения

- **NULL:** функции не принимают `NULL`.
- **Пустая строка:** `basename()` возвращает `"."`.
- **Только `/`:** `dirname()` возвращает `"//"`, `basename()` возвращает `"/"`.
- **Побочные эффекты:** функции могут изменять входную строку.
- **Альтернативы:** POSIX рекомендует `dirname()` и `basename()` из `<libgen.h>`, но также существуют версии в GNU C (которые могут работать иначе).
- **Многопоточность:** функции не потокобезопасны (изменяют входную строку).

## Стандарты

POSIX.1-2017.
