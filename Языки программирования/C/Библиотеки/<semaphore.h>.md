## Описание библиотеки

Заголовочный файл `<semaphore.h>` — семафоры. Определяет тип `sem_t` и функции для работы с семафорами POSIX.

### Тип `sem_t`

Тип `sem_t` используется для представления семафора. Может быть реализован через файловый дескриптор; в этом случае приложения могут открывать не более `{OPEN_MAX}` файлов и семафоров одновременно.

### Константы

| Константа | Описание |
|---|---|
| `SEM_FAILED` | Значение, возвращаемое при ошибке `sem_open()` (тип `sem_t *`) |

### Функции

| Функция | Описание |
|---|---|
| `sem_init(sem_t *, int, unsigned)` | Инициализация анонимного семафора с начальным значением |
| `sem_destroy(sem_t *)` | Уничтожение анонимного семафора |
| `sem_open(const char *, int, ...)` | Открытие/создание именованного семафора |
| `sem_close(sem_t *)` | Закрытие именованного семафора |
| `sem_unlink(const char *)` | Удаление именованного семафора из системы |
| `sem_wait(sem_t *)` | Уменьшение семафора (блокировка при 0) |
| `sem_trywait(sem_t *)` | Уменьшение без блокировки (возвращает `EAGAIN`) |
| `sem_timedwait(sem_t *, const struct timespec *)` | Уменьшение с таймаутом |
| `sem_post(sem_t *)` | Увеличение семафора (пробуждает ожидающий поток) |
| `sem_getvalue(sem_t *, int *)` | Получение текущего значения |

### Использование

```c
#include <semaphore.h>

sem_t sem;
sem_init(&sem, 0, 1);  /* Анонимный семафор, общность: процесс, начальное значение: 1 */

sem_wait(&sem);      /* Критическая секция */
sem_post(&sem);      /* Выход из критической секции */

sem_destroy(&sem);
```

## Исключения

- **NULL:** функции не принимают `NULL`.
- **errno:** при ошибке устанавливается `errno`.
- **EINVAL:** значение семафора отрицательно или аргументы неверны.
- **EAGAIN:** семафор уже заблокирован (для `sem_trywait()`).
- **EDEADLK:** обнаружен deadlock (при использовании `PTHREAD_MUTEX_ERRORCHECK`).
- **EINTR:** вызов прерван сигналом.
- **ETIMEDOUT:** таймаут (для `sem_timedwait()`).
- **ENOMEM:** недостаточно памяти для инициализации.
- **EPERM:** нет прав (для `sem_unlink()` или `sem_open()` с `O_CREAT`).
- **Многопоточность:** операции с семафорами атомарны.
- **fork:** семафоры не наследуются через `fork()`.

## Стандарты

POSIX.1-2017.
