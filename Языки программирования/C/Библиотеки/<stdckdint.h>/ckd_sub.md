## Определение

```c
#include <stdckdint.h>

bool ckd_sub(type1 *result, type2 a, type3 b); // макрос, C23
```

## Описание

Макрос (C23) — вычитание `a - b` с проверкой переполнения: сохраняет результат в `*result` и возвращает `true`, если результат не представим в типе результата (например, `INT_MIN - 1`). Без проверки такая операция — неопределённое поведение.

## Примеры

```c
#include <stdckdint.h>
#include <stdio.h>

int main(void)
{
    int x = INT_MIN;
    int result;

    if (ckd_sub(&result, x, 1)) {
        printf("Переполнение: %d - 1\n", x);
    } else {
        printf("Результат: %d\n", result);
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Единообразная проверка для знаковых и беззнаковых типов | Не обнаруживает переполнение уже продвинутых типов до записи в усечённый результат |
