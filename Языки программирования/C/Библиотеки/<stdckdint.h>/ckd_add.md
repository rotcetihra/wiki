## Определение

```c
#include <stdckdint.h>

bool ckd_add(type1 *result, type2 a, type3 b); // макрос, C23
```

## Описание

Макрос (C23) — сложение `a + b` с проверкой переполнения: выполняет операцию, сохраняет результат в `*result` (тип результата определяется типом операндов после продвижений, при необходимости усекается) и возвращает `false` при успехе или `true`, если результат не представим в типе результата. Надёжная замена «наивной» проверки `if (a > INT_MAX - b)`, которая ненадёжна для общего случая и типов.

## Примеры

```c
#include <stdckdint.h>
#include <stdio.h>

int main(void)
{
    int x = INT_MAX;
    int result;

    if (ckd_add(&result, x, 1)) {
        printf("Переполнение: %d + 1\n", x);
    } else {
        printf("Результат: %d\n", result);
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная проверка переполнения без `errno` | Доступна только с C23 (в старых стандартах — расширения компиляторов) |
| Работает с любыми целыми типами | Для дробной арифметики неприменима |
