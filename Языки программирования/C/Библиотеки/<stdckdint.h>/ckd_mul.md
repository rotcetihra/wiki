## Определение

```c
#include <stdckdint.h>

bool ckd_mul(type1 *result, type2 a, type3 b); // макрос, C23
```

## Описание

Макрос (C23) — умножение `a * b` с проверкой переполнения: сохраняет результат в `*result` и возвращает `true` при переполнении. Особенно важен для умножения — именно здесь переполнение легче всего пропустить (например, `100000 * 100000` не помещается в `int`, и результат обрезается без ошибки).

## Примеры

```c
#include <stdckdint.h>
#include <stdio.h>

int main(void)
{
    int a = 100000;
    int result;

    if (ckd_mul(&result, a, a)) {
        printf("Переполнение: %d * %d\n", a, a);
    } else {
        printf("Результат: %d\n", result);
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Отлавливает тихое обрезание результата | При умножении двух больших беззнаковых значений требует внимания к типу результата |
