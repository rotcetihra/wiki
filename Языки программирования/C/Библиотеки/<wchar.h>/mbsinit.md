## Определение

```c
#include <wchar.h>

int mbsinit(const mbstate_t *ps);
```

## Описание

Функция `mbsinit()` проверяет, находится ли состояние многобайтового преобразования `ps` в начальном состоянии. Возвращает ненулевое значение, если `ps` является начальным (т. е. ни одна незавершённая многобайтовая последовательность не ожидает продолжения), и `0` в противном случае.

Если `ps` равен `NULL`, поведение не определено.

> [!NOTE]
> Начальное состояние создаётся инициализацией `mbstate_t` нулевым выражением: `mbstate_t state = {0};`. После завершения преобразования всей строки состояние снова становится начальным.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>
#include <string.h>

int main(void)
{
    setlocale(LC_ALL, "");

    mbstate_t state = {0};
    printf("Начальное состояние: %s\n",
           mbsinit(&state) ? "да" : "нет");

    const char *partial = "\xE2";  /* First byte of U+20AC (€) in UTF-8 */
    wchar_t wc;
    size_t len = mbrtowc(&wc, partial, 1, &state);

    printf("После частичного прочтения: %s\n",
           mbsinit(&state) ? "начальное" : "не начальное");

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет проверить, завершено ли преобразование | Неинформативна при `NULL` (UB) |
| Стандартная функция ISO C | Простая проверка — не заменяет полное преобразование |
| Потокобезопасна | Зависит от текущей локали |
