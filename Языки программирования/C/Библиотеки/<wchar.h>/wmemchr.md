## Определение

```c
#include <wchar.h>

wchar_t *wmemchr(const wchar_t *s, wchar_t c, size_t n);
```

## Описание

Функция `wmemchr()` ищет первое вхождение宽окого символа `c` в массиве `s` размером `n` элементов. Возвращает указатель на найденный элемент или `NULL`, если символ не найден.

Функция является широкосимвольным аналогом `memchr()` из `<string.h>`. Работает с массивами фиксированного размера, а не с нуль-терминированными строками.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t data[] = {L'А', L'Б', L'В', L'Г', L'Д'};
    size_t n = sizeof(data) / sizeof(data[0]);

    wchar_t *found = wmemchr(data, L'Г', n);
    if (found)
        printf("Найдено на позиции: %td\n", found - data);

    wchar_t *not_found = wmemchr(data, L'Ж', n);
    printf("Не найдено: %s\n", not_found ? "да" : "нет");

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрый поиск в массивах фиксированного размера | Не работает с нуль-терминированными строками |
| Стандартная функция ISO C | Линейная сложность |
| Безопасна (ограничена размером `n`) | Возвращает указатель — не индекс |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** `NULL`, если символ не найден.
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `s`.
- **Многопоточность:** потокобезопасна (только чтение).
