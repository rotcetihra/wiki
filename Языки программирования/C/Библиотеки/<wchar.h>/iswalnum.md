## Определение

```c
#include <wchar.h>

int iswalnum(wint_t wc);
```

## Описание

Макрос/функция `iswalnum()` проверяет, является ли широкий символ `wc` буквой или цифрой. Возвращает ненулевое значение, если символ принадлежит к категории «буква или цифра» (эквивалент объединения `iswalpha()` и `iswdigit()`).

Параметр `wc` должен быть широким символом или значением `WEOF`. Передача некорректного значения — неопределённое поведение.

Классификация зависит от текущей локали: в локали `C` буквами считаются только латинские `A–Z` и `a–z`, а в локалях с расширенными алфавитами — также буквы национальных алфавитов.

> [!NOTE]
> Может быть реализован как макрос с множественным вычислением аргумента. Не используйте выражения с побочными эффектами в качестве аргумента.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wint_t tests[] = {L'A', L'z', L'5', L'!', L' ', L'Ω', WEOF};

    for (int i = 0; tests[i] != WEOF || i < 7; i++) {
        if (tests[i] == WEOF) break;
        printf("iswalnum('%lc') = %d\n", tests[i],
               iswalnum(tests[i]));
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая проверка принадлежности к буквам/цифрам | Зависит от текущей локали |
| Стандартный макрос/функция ISO C | Может быть макросом (побочные эффекты) |
| Удобна для фильтрации символов | Не различает буквы и цифры |
