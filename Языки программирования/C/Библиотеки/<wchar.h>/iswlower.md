## Определение

```c
#include <wchar.h>

int iswlower(wint_t wc);
```

## Описание

Макрос/функция `iswlower()` проверяет, является ли широкий символ `wc` строчной (маленькой) буквой. Возвращает ненулевое значение, если символ принадлежит к категории «строчная буква».

Классификация зависит от текущей локали: в локали `C` строчными считаются `a–z`, в расширенных локалях — также буквы национальных алфавитов.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    printf("iswlower('a') = %d\n", iswlower(L'a'));
    printf("iswlower('A') = %d\n", iswlower(L'A'));
    printf("iswlower('5') = %d\n", iswlower(L'5'));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая проверка регистра | Зависит от текущей локали |
| Стандартный макрос/функция ISO C | Может быть макросом |
| Удобна для нормализации текста | Не различает алфавиты |
