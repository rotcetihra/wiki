## Определение

```c
#include <wchar.h>

unsigned long wcstoul(const wchar_t *str, wchar_t **endptr, int base);
```

## Описание

Функция `wcstoul()` преобразует широкую строку `str` в беззнаковое значение типа `unsigned long`. Является широкосимвольным аналогом `strtoul()` из `<stdlib.h>`. Поведение идентично `wcstol()`, но результат — беззнаковый.

При переполнении возвращает `ULONG_MAX` и устанавливает `errno` в `ERANGE`.

> [!NOTE]
> Отрицательные числа обрабатываются корректно: знак `-` учитывается, результат приводится к `unsigned long` (дополнительный код).

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *str1 = L"  4294967295";
    const wchar_t *str2 = L"-1";

    wchar_t *end;

    unsigned long ul1 = wcstoul(str1, &end, 10);
    printf("'%ls' → %lu\n", str1, ul1);

    unsigned long ul2 = wcstoul(str2, &end, 10);
    printf("'%ls' → %lu\n", str2, ul2);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Беззнаковое преобразование — подходит для адресов и размеров | Ограничен диапазон `unsigned long` |
| Стандартная функция ISO C | Квадратичная сложность для длинных строк |
| Поддерживает любое основание 2–36 | Требует `<wchar.h>` |
