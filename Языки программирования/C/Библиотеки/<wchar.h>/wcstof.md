## Определение

```c
#include <wchar.h>

float wcstof(const wchar_t *str, wchar_t **endptr);
```

## Описание

Функция `wcstof()` преобразует широкую строку `str` в значение типа `float`. Является широкосимвольным аналогом `strtof()` из `<stdlib.h>`. Поведение идентично `wcstod()`, но результат — `float` (меньшая точность и диапазон).

Если `endptr != NULL`, в него записывается указатель на первый символ, не являющийся частью числа.

Возвращает преобразованное значение, `HUGE_VALF` при переполнении, `0` при ошибке.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *str = L"  3.14159abc";
    wchar_t *end;

    float f = wcstof(str, &end);
    printf("'%ls' → %f (осталось: '%ls')\n", str, f, end);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Возвращает `float` — удобно для работы с одинарной точностью | Меньшая точность, чем `wcstod()` |
| Стандартная функция ISO C | Квадратичная сложность для длинных строк |
| Указывает позицию остановки через `endptr` | Требует установки локали |
