## Определение

```c
#include <wchar.h>

size_t mbrlen(const char *s, size_t n, mbstate_t *ps);
```

## Описание

Функция `mbrlen()` определяет длину (в байтах) многобайтовой последовательности в начале строки `s`. Является удобной обёрткой над `mbrtowc()` с вызовом `mbrtowc(NULL, s, n, ps)`.

Параметры:

- `s` — указатель на многобайтовую строку;
- `n` — максимальное количество байт для анализа;
- `ps` — указатель на состояние преобразования (если `NULL`, используется внутренний статический объект).

Возвращает:

- `0`, если `s` указывает на нуль-терминатор;
- длину многобайтовой последовательности (от 1 до `n`);
- `(size_t)-2`, если последовательность неполная;
- `(size_t)-1`, если обнаружена некорректная последовательность.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const char *utf8_str = "Привет";
    mbstate_t state = {0};
    const char *p = utf8_str;

    while (*p) {
        size_t len = mbrlen(p, MB_LEN_MAX, &state);
        if (len == (size_t)-1 || len == (size_t)-2)
            break;
        printf("Символ: %.*s (%zu байт)\n", (int)len, p, len);
        p += len;
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простой способ узнать длину символа | Не преобразует символ (только длина) |
| Стандартная функция ISO C | Не потокобезопасна при `ps == NULL` |
| Удобна для навигации по строке | Зависит от текущей локали |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** `(size_t)-1` при некорректной последовательности, `(size_t)-2` при неполной.
- **Установление errno:** устанавливает `errno` в `EILSEQ` при обнаружении некорректной последовательности, `EINVAL` при невалидном состоянии `ps`.
- **Поведение при передаче NULL:** если `s` равен `NULL`, возвращает `0`. Если `ps` равен `NULL`, используется внутренний статический объект (не потокобезопасен).
- **Многопоточность:** потокобезопасна при использовании собственного `ps`; при `ps == NULL` не потокобезопасна.
