## Определение

```c
#include <wchar.h>

int iswspace(wint_t wc);
```

## Описание

Макрос/функция `iswspace()` проверяет, является ли широкий символ `wc` пробельным символом. Возвращает ненулевое значение для:

- `L' '` (пробел)
- `L'\t'` (горизонтальная табуляция)
- `L'\n'` (перевод строки)
- `L'\v'` (вертикальная табуляция)
- `L'\f'` (перевод страницы)
- `L'\r'` (возврат каретки)

В расширенных локалях могут поддерживаться дополнительные пробельные символы Unicode.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    printf("iswspace(' ') = %d\n", iswspace(L' '));
    printf("iswspace('\\t') = %d\n", iswspace(L'\t'));
    printf("iswspace('\\n') = %d\n", iswspace(L'\n'));
    printf("iswspace('A') = %d\n", iswspace(L'A'));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая проверка на пробельный символ | Зависит от текущей локали |
| Стандартный макрос/функция ISO C | Может быть макросом |
| Удобна для разбора строк | Включает все виды пробелов |
