## Определение

```c
#include <wchar.h>

int iswupper(wint_t wc);
```

## Описание

Макрос/функция `iswupper()` проверяет, является ли широкий символ `wc` заглавной (большой) буквой. Возвращает ненулевое значение, если символ принадлежит к категории «заглавная буква».

Классификация зависит от текущей локали: в локали `C` заглавными считаются `A–Z`, в расширенных локалях — также буквы национальных алфавитов.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    printf("iswupper('A') = %d\n", iswupper(L'A'));
    printf("iswupper('a') = %d\n", iswupper(L'a'));
    printf("iswupper('Ω') = %d\n", iswupper(L'Ω'));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая проверка регистра | Зависит от текущей локали |
| Стандартный макрос/функция ISO C | Может быть макросом |
| Удобна для нормализации текста | Не различает алфавиты |
