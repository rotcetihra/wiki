## Определение

```c
#include <wchar.h>

int iswalpha(wint_t wc);
```

## Описание

Макрос/функция `iswalpha()` проверяет, является ли широкий символ `wc` буквой. Возвращает ненулевое значение, если символ принадлежит к категории «буква».

Параметр `wc` должен быть широким символом или значением `WEOF`. Классификация зависит от текущей локали.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    printf("iswalpha('A') = %d\n", iswalpha(L'A'));
    printf("iswalpha('5') = %d\n", iswalpha(L'5'));
    printf("iswalpha('Ω') = %d\n", iswalpha(L'Ω'));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая проверка на принадлежность к алфавиту | Зависит от текущей локали |
| Стандартный макрос/функция ISO C | Может быть макросом |
| Удобна для валидации ввода | Не различает регистр |
