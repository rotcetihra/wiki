## Определение

```c
#include <wchar.h>

int iswgraph(wint_t wc);
```

## Описание

Макрос/функция `iswgraph()` проверяет, является ли широкий символ `wc` печатным символом, отличным от пробела. Возвращает ненулевое значение, если символ принадлежит к категории «печатный без пробела» (эквивалент `iswprint() && !iswblank() && !isspace()`).

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    printf("iswgraph('A') = %d\n", iswgraph(L'A'));
    printf("iswgraph(' ') = %d\n", iswgraph(L' '));
    printf("iswgraph('!') = %d\n", iswgraph(L'!'));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Отличает печатные символы от пробела | Зависит от текущей локали |
| Стандартный макрос/функция ISO C | Может быть макросом |
| Удобна для определения «видимых» символов | Не включает пробел |
