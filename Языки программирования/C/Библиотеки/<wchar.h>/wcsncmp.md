## Определение

```c
#include <wchar.h>

int wcsncmp(const wchar_t *s1, const wchar_t *s2, size_t n);
```

## Описание

Функция `wcsncmp()` сравнивает не более `n` широких символов в строках `s1` и `s2`. Сравнение прекращается при достижении различающихся символов, завершающего нуль-терминатора или после `n` символов.

Возвращает:

- значение `< 0`, если `s1` лексикографически меньше `s2`;
- `0`, если строки равны (в пределах `n` символов);
- значение `> 0`, если `s1` лексикографически больше `s2`.

Функция является широкосимвольным аналогом `strncmp()` из `<string.h>`.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *a = L"Привет";
    const wchar_t *b = L"Программирование";

    printf("Сравнение первых 4 символов: %d\n", wcsncmp(a, b, 4));  /* 0 */
    printf("Сравнение первых 6 символов: %d\n", wcsncmp(a, b, 6));  /* < 0 */

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Ограничивает количество сравниваемых символов | Не определяет полное равенство строк |
| Стандартная функция ISO C | Линейная сложность |
| Безопаснее `wcscmp()` для длинных строк | Результат зависит от `n` |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (возвращает отрицательное, нулевое или положительное значение).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `s1` или `s2`.
- **Многопоточность:** потокобезопасна при чтении неизменяемых строк; при параллельном изменении строк возможны гонки.
