## Определение

```c
#include <wchar.h>

wctrans_t wctrans(const char *property);
```

## Описание

Функция `wctrans()` создаёт дескриптор категории преобразования宽оких символов по строке `property`. Возвращает дескриптор типа `wctrans_t` или `0` (некорректный дескриптор), если категория не распознана.

Предопределённые категории:

| Строка | Описание |
|---|---|
| `"towlower"` | Преобразование в нижний регистр |
| `"towupper"` | Преобразование в верхний регистр |

Дополнительные категории могут быть определены текущей локалью.

> [!NOTE]
> `wctrans_t` — неполный тип. Дескриптор используется в функции `towctrans()`.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wctrans_t desc = wctrans("towlower");
    if (desc) {
        printf("Символ 'H' → '%lc'\n", towctrans(L'H', desc));
    }

    wctrans_t invalid = wctrans("nonexistent");
    printf("Некорректная категория: %d\n", invalid);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет создавать переиспользуемые дескрипторы | Только две предопределённые категории |
| Стандартная функция ISO C | Неинформативна при ошибке (возвращает 0) |
| Расширяема через локали | Требует вызова `towctrans()` для использования |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** `0` (некорректный дескриптор), если категория не распознана.
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `property`.
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние).
