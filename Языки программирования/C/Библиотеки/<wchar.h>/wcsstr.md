## Определение

```c
#include <wchar.h>

wchar_t *wcsstr(const wchar_t *haystack, const wchar_t *needle);
```

## Описание

Функция `wcsstr()` ищет первое вхождение подстроки `needle` в строке `haystack`. Возвращает указатель на начало первого вхождения или `NULL`, если подстрока не найдена.

Если `needle` — пустая строка, функция возвращает указатель на начало `haystack`.

Функция является широкосимвольным аналогом `strstr()` из `<string.h>`.

> [!NOTE]
> Алгоритм поиска определяется реализацией. В большинстве современных реализаций используется оптимизированный алгоритм (например, Two-Way), обеспечивающий линейное время в худшем случае.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *text = L"Привет, мир! Добро пожаловать в мир!";
    const wchar_t *word = L"мир";

    wchar_t *pos = wcsstr(text, word);
    if (pos)
        printf("Найдено на позиции: %td\n", pos - text);

    /* Поиск всех вхождений */
    const wchar_t *p = text;
    int count = 0;
    while ((p = wcsstr(p, word)) != NULL) {
        count++;
        p++;
    }
    printf("Всего вхождений: %d\n", count);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный поиск подстроки | Линейная сложность в худшем случае |
| Стандартная функция ISO C | Не potokobezopasna |
| Удобна для простого поиска | Не подходит для сложных паттернов |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** `NULL`, если подстрока не найдена.
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `haystack` или `needle`.
- **Многопоточность:** потокобезопасна (только чтение).
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<wchar.h>/wcschr|wcschr]], [[Языки программирования/C/Библиотеки/<wchar.h>/wcswcs|wcswcs]].
