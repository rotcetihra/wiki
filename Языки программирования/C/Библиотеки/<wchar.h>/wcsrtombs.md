## Определение

```c
#include <wchar.h>

size_t wcsrtombs(char *dest, const wchar_t **src, size_t len, mbstate_t *ps);
```

## Описание

Функция `wcsrtombs()` преобразует строку широких символов `src` в многобайтовую строку `dest`. Является обратным преобразованием к `mbsrtowcs()`.

Параметры:

- `dest` — буфер для записи результата (может быть `NULL` для определения требуемого размера);
- `src` — указатель на указатель на строку широких символов (обновляется);
- `len` — максимальное количество байт для записи;
- `ps` — указатель на состояние преобразования.

Если `dest == NULL`, функция возвращает требуемый размер буфера (без нуль-терминатора). Если `dest != NULL`, записывает до `len` байт и завершающий нуль-терминатор.

Возвращает количество записанных байт (не считая незавершённых последовательностей) или `(size_t)-1` при ошибке.

> [!NOTE]
> Если преобразование остановлено из-за заполнения буфера, указатель `*src` обновляется — его можно передать в следующий вызов для продолжения.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>
#include <stdlib.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *wstr = L"Привет, мир!";
    const wchar_t *src = wstr;

    /* Определяем требуемый размер */
    size_t len = wcsrtombs(NULL, &src, 0, NULL);
    printf("Требуется %zu байт\n", len);

    /* Преобразуем */
    char *mbuf = malloc(len + 1);
    src = wstr;
    wcsrtombs(mbuf, &src, len + 1, NULL);
    printf("Результат: %s\n", mbuf);

    free(mbuf);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Эффективно преобразует целые строки | Сложный интерфейс (4 параметра) |
| Потокобезопасна при собственном `ps` | Зависит от текущей локали |
| Позволяет определить размер до выделения памяти | Требует ручного управления буфером |
