## Определение

```c
#include <wchar.h>

wint_t towlower(wint_t wc);
```

## Описание

Функция `towlower()` преобразует широкий символ `wc` в соответствующий символ нижнего регистра (строчную букву). Если символ не является заглавной буквой, функция возвращает его без изменений.

Результат преобразования зависит от текущей локали: в локали `C` преобразуются только `A–Z` → `a–z`, в расширенных локалях — также буквы национальных алфавитов.

> [!NOTE]
> В отличие от функций классификации (`iswlower` и т. д.), `towlower()` всегда является функцией, а не макросом.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    printf("towlower('A') = '%lc'\n", towlower(L'A'));
    printf("towlower('Ω') = '%lc'\n", towlower(L'Ω'));
    printf("towlower('5') = '%lc'\n", towlower(L'5'));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простое преобразование регистра | Зависит от текущей локали |
| Стандартная функция ISO C | Не является макросом (нет «бесплатного» вызова) |
| Безопасна для любых символов | Не изменяет некириллические и нелатинские буквы в локали `C` |
