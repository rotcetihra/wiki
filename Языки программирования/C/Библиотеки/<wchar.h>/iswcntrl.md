## Определение

```c
#include <wchar.h>

int iswcntrl(wint_t wc);
```

## Описание

Макрос/функция `iswcntrl()` проверяет, является ли широкий символ `wc` управляющим символом. Возвращает ненулевое значение, если символ принадлежит к категории «управляющий символ» (коды 0x00–0x1F и 0x7F в ASCII, а также специальные Unicode-символы управления в расширенных локалях).

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    printf("iswcntrl('\\n') = %d\n", iswcntrl(L'\n'));
    printf("iswcntrl('\\t') = %d\n", iswcntrl(L'\t'));
    printf("iswcntrl('A') = %d\n", iswcntrl(L'A'));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая проверка на управляющий символ | Зависит от текущей локали |
| Стандартный макрос/функция ISO C | Может быть макросом |
| Удобна для фильтрации ввода | Ограниченная область применения |
