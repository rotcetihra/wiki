## Определение

Многобайтовая строка — это строка, в которой символы могут занимать разное количество байтов (от одного до нескольких). В отличие от фиксированных широких символов (`wchar_t`), многобайтовые кодировки более экономичны по памяти для смешанного текста.

## Описание

В C существуют три способа представления текста:

| Тип | Представление | Кодировка по умолчанию |
|---|---|---|
| `char` (узкая строка) | Многобайтовая последовательность | Зависит от локали (обычно UTF-8) |
| `wchar_t` (широкая строка) | Фиксированный размер символа | Платформо-зависимый (4 байта на Linux, 2 на Windows) |
| `char8_t` (C23) | UTF-8 (то же, что `unsigned char`) | UTF-8 |

Многобайтовые строки используются в стандартном вводе-выводе (`printf`, `fopen`, файловые системы), где текст хранится в компактной кодировке. Широкие строки удобны для обработки текста, где нужно работать с отдельными символами независимо от их размера в байтах.

### Многобайтовые кодировки

| Кодировка | Описание | Размер символа |
|---|---|---|
| ASCII | Латиница, цифры, знаки пунктуации | 1 байт |
| UTF-8 | Unicode (современный стандарт) | 1–4 байта |
| UTF-16 | Unicode (используется в Windows API) | 2 или 4 байта |
| Shift-JIS | Японская кодировка | 1 или 2 байта |
| KOI8-R | Кириллица (русская) | 1 или 2 байта |

### Соответствие между многобайтовыми и широкими символами

```
Многобайтовая строка        Широкая строка
┌───┬───┬───┬───┬───┐      ┌────┬────┬────┐
│'H'│'е'│'л'│'л'│'о'│  →   │ L  │ L  │ L  │
└───┴───┴───┴───┴───┘      └────┴────┴────┘
  1   2   2   2   1 байт     4    4    4 байта
  (UTF-8: 8 байт)            (12 байт)
```

### Состояние преобразования (mbstate_t)

Многобайтовые последовательности могут быть разбиты на части (например, при чтении из файла по частям). Для этого используется тип `mbstate_t`, который хранит промежуточное состояние преобразования.

```c
#include <wchar.h>

int main(void)
{
    const char *mbs = "Привет";           /* UTF-8: 12 байт */
    wchar_t wcs[8];
    mbstate_t state = {0};                /* Начальное состояние */

    /* Преобразование с сохранением состояния */
    const char *ptr = mbs;
    size_t len = mbsrtowcs(wcs, &ptr, 7, &state);
    printf("Преобразовано %zu символов\n", len);
    return 0;
}
```

### Когда использовать многобайтовые строки

- **Хранение в файлах** — UTF-8 является стандартом для файлов и URL
- **Взаимодействие с ОС** — файловые системы используют многобайтовые кодировки
- **Совместимость** — стандартный ввод-вывод (`printf`, `scanf`) работает с `char`
- **Экономия памяти** — латиница занимает 1 байт вместо 4

### Когда использовать широкие строки

- **Обработка текста** — когда нужно разделять на символы, менять регистр
- **Длина строки** — `wcslen` возвращает количество символов, не байтов
- **Сравнение** — `wcscmp` сравнивает кодовые точки, а не байты

## Примеры

### Простое преобразование

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");   /* Установка локали для поддержки UTF-8 */

    const char *mbs = "Привет, мир!";
    wchar_t wcs[32];

    /* Многобайтовая → широкая */
    size_t len = mbstowcs(wcs, mbs, sizeof(wcs) / sizeof(wcs[0]));
    printf("Ширина в символах: %zu\n", len);

    /* Широкая → многобайтовая */
    char back[64];
    wcstombs(back, wcs, sizeof(back));
    printf("Обратно: %s\n", back);

    return 0;
}
```

### Посимвольная обработка через mbrtowc

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const char *mbs = "Привет";
    mbstate_t state = {0};
    wchar_t wc;
    size_t len;

    printf("Символы: ");
    while ((len = mbrtowc(&wc, mbs, MB_LEN_MAX, &state)) > 0) {
        printf("U+%04X ", (unsigned)wc);
        mbs += len;
    }
    printf("\n");

    return 0;
}
```

### Чтение многобайтовой строки из файла

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    FILE *f = fopen("text.txt", "r");
    if (!f) return 1;

    wchar_t wcs[256];
    mbstate_t state = {0};
    size_t total = 0;

    char buf[64];
    while (fgets(buf, sizeof(buf), f)) {
        const char *ptr = buf;
        size_t n = mbsrtowcs(wcs + total, &ptr, 
                             sizeof(wcs)/sizeof(wcs[0]) - total, &state);
        if (n == (size_t)-1) {
            fprintf(stderr, "Ошибка кодировки\n");
            break;
        }
        total += n;
    }

    printf("Прочитано %zu широких символов\n", total);
    fclose(f);
    return 0;
}
```

## Функции `<wchar.h>` для работы с многобайтовыми строками

| Функция | Описание |
|---|---|
| `mbrtowc()` | Многобайтовая последовательность → широкий символ (потокобезопасно) |
| `wcrtomb()` | Широкий символ → многобайтовая последовательность (потокобезопасно) |
| `mbsrtowcs()` | Многобайтовая строка → массив широких символов |
| `wcsrtombs()` | Строка широких символов → многобайтовая строка |
| `mbrlen()` | Длина многобайтового символа |
| `mbsinit()` | Проверка начального состояния `mbstate_t` |
| `btowc()` | Однобайтовый символ → широкий |
| `wctob()` | Широкий символ → однобайтовый |

## Функции `<stdlib.h>` для работы с многобайтовыми строками

| Функция | Описание |
|---|---|
| `mbstowcs()` | Многобайтовая строка → массив широких символов (простой интерфейс) |
| `wcstombs()` | Массив широких символов → многобайтовая строка (простой интерфейс) |
| `mblen()` | Длина многобайтового символа |
| `mbtowc()` | Многобайтовый символ → широкий (простой интерфейс) |
| `wctomb()` | Широкий символ → многобайтовый (простой интерфейс) |

> [!NOTE]
> Функции с суффиксом `r` (`mbrtowc`, `wcrtomb`, `mbsrtowcs`, `wcsrtombs`) — потокобезопасны и поддерживают промежуточное состояние через `mbstate_t`. Старые функции (`mbtowc`, `wctomb`, `mbstowcs`, `wcstombs`) не потокобезопасны и используют скрытое глобальное состояние.

> [!WARNING]
> Многобайтовые строки **не являются** нуль-terminated для произвольных байтов — нуль-байт `\0` всегда означает конец строки. Однако в кодировках вроде UTF-8 байт `0x00` может встречаться только как завершающий нуль. В других кодировках (например, UCS-2) внутренние нули возможны, что делает их несовместимыми с функциями C.
