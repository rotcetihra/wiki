## Определение

```c
#include <wchar.h>

wchar_t *wmemset(wchar_t *s, wchar_t c, size_t n);
```

## Описание

Функция `wmemset()` заполняет первые `n` элементов массива `s`宽оким символом `c`.

Возвращаемое значение — указатель на `s`.

Функция является широкосимвольным аналогом `memset()` из `<string.h>`.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wchar_t buf[16];

    wmemset(buf, L'-', 10);
    buf[10] = L'\0';
    printf("Заполнение: %ls\n", buf);

    wmemset(buf, L'★', 5);
    buf[5] = L'\0';
    printf("Звёзды: %ls\n", buf);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрое заполнение массива одним символом | Работает с фиксированными массивами |
| Стандартная функция ISO C | Не добавляет нуль-терминатор |
| Простой интерфейс | Не оптимизирована для нулевого символа (в отличие от `memset`) |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (функция всегда возвращает `s`).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `s`.
- **Многопоточность:** потокобезопасна при использовании различных буферов; приshared.s не потокобезопасна.
