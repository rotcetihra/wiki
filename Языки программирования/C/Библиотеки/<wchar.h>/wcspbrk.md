## Определение

```c
#include <wchar.h>

wchar_t *wcspbrk(const wchar_t *str, const wchar_t *accept);
```

## Описание

Функция `wcspbrk()` ищет первое вхождение любого из символов строки `accept` в строке `str`. Возвращает указатель на первый найденный символ в `str` или `NULL`, если ни один из символов `accept` не найден.

Функция является широкосимвольным аналогом `strpbrk()` из `<string.h>`.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *text = L"Привет, мир! Добро пожаловать.";
    const wchar_t *delim = L" ,!.";

    wchar_t *token = wcspbrk(text, delim);
    if (token)
        printf("Первый разделитель на позиции: %td\n", token - text);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрый поиск любого из набора символов | Возвращает указатель, не индекс |
| Стандартная функция ISO C | Линейная сложность |
| Удобна для разбиения строк | Не модифицирует строку |
