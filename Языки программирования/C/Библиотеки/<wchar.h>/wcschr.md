## Определение

```c
#include <wchar.h>

wchar_t *wcschr(const wchar_t *str, wchar_t c);
```

## Описание

Функция `wcschr()` ищет первое вхождение宽окого символа `c` в строке `str` (включая завершающий нуль-терминатор). Возвращает указатель на найденный символ или `NULL`, если символ не найден.

Функция является широкосимвольным аналогом `strchr()` из `<string.h>`. Параметр `c` преобразуется к `wchar_t` перед сравнением.

> [!NOTE]
> Если `c` равно `L'\0'`, функция возвращает указатель на завершающий нуль-терминатор строки. Это позволяет использовать `wcschr()` для определения длины строки через `wcschr(str, L'\0') - str`.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *text = L"Привет, мир!";
    wchar_t *pos = wcschr(text, L'м');

    if (pos)
        printf("Символ 'м' найден на позиции: %td\n", pos - text);
    else
        printf("Символ не найден\n");

    /* Поиск нуль-терминатора */
    wchar_t *end = wcschr(text, L'\0');
    printf("Длина строки: %td\n", end - text);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрый поиск символа (líneal search) | Возвращает указатель — невозможно определить, найден символ или это `'\0'` без дополнительной проверки |
| Стандартная функция ISO C | Не потокобезопасна (возвращает указатель на внутренние данные) |
| Удобна для определения длины строки | Линейная сложность поиска |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** `NULL`, если символ не найден.
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `str`.
- **Многопоточность:** не потокобезопасна (возвращает указатель на внутренние данные строки; при параллельном доступе к строке возможны гонки).
