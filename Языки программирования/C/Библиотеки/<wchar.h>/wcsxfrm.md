## Определение

```c
#include <wchar.h>

size_t wcsxfrm(wchar_t *dest, const wchar_t *src, size_t n);
```

## Описание

Функция `wcsxfrm()` преобразует широкую строку `src` в форму, при которой побайтовое сравнение (`wcscmp()`) результатов даёт тот же результат, что и локализованное сравнение (`wcscoll()`).

Если `n > 0`, результат записывается в `dest` (включая завершающий нуль-терминатор). Если `n` равно `0`, `dest` может быть `NULL` — функция возвращает требуемый размер буфера (без нуль-терминатора).

Возвращает количество символов (без нуль-терминатора), необходимых для преобразования.

Функция является широкосимвольным аналогом `strxfrm()` из `<string.h>`.

> [!NOTE]
> Для многократного сравнения строк с одной локалью эффективнее вызвать `wcsxfrm()` один раз для каждой строки, а затем сравнивать результаты через `wcscmp()`, а не вызывать `wcscoll()` повторно.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>
#include <stdlib.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *words[] = {L"Ёлка", L"Абрикос", L"Банан"};
    int n = 3;

    /* Получаем требуемые размеры и преобразуем */
    wchar_t *buf = NULL;
    size_t bufsize = 0;

    for (int i = 0; i < n; i++) {
        size_t len = wcsxfrm(NULL, words[i], 0);
        if (len + 1 > bufsize) {
            bufsize = len + 1;
            buf = realloc(buf, bufsize * sizeof(wchar_t));
        }
        wcsxfrm(buf, words[i], bufsize);
        wprintf(L"%ls → %ls\n", words[i], buf);
    }

    free(buf);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет ускорить многократную сортировку | Требует дополнительного выделения памяти |
| Учитывает правила локали | Преобразование зависит от текущей локали |
| Стандартная функция ISO C | Сложнее в использовании, чем `wcscoll()` |
