## Определение

```c
#include <wchar.h>

wchar_t *wcscat(wchar_t *dest, const wchar_t *src);
```

## Описание

Функция `wcscat()` дописывает Wide-строку `src` в конец строки `dest`. Начальный нуль-терминатор `dest` заменяется первым символом `src`, и вся строка `src` копируется, включая завершающий нуль-терминатор.

Возвращаемое значение — указатель на `dest`.

Функция является широкосимвольным аналогом `strcat()` из `<string.h>`. Поведение определено, только если `dest` и `src` не перекрываются и оба указывают на корректные нуль-терминированные строки.

> [!WARNING]
> Функция не проверяет размер буфера `dest`. Если в `dest` недостаточно места — переполнение буфера (неопределённое поведение). Безопаснее использовать `wcsncat()`.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wchar_t buffer[64] = L"Привет";
    wcscat(buffer, L", мир!");
    printf("%ls\n", buffer);  /* Привет, мир! */

    wcscat(buffer, L" Добро пожаловать.");
    printf("%ls\n", buffer);  /* Привет, мир! Добро пожаловать. */

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая конкатенация двух строк | Нет проверки размера буфера (переполнение) |
| Стандартная функция ISO C | Квадратичная сложность при многократном дописывании |
| Возвращает указатель на начало результата | Не потокобезопасна (модифицирует строку) |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (функция всегда возвращает `dest`).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `dest` или `src`.
- **Многопоточность:** не потокобезопасна (модифицирует строку `dest`; необходимо синхронизировать доступ при использовании из нескольких потоков).
