## Определение

```c
#include <wchar.h>

long double wcstold(const wchar_t *str, wchar_t **endptr);
```

## Описание

Функция `wcstold()` преобразует широкую строку `str` в значение типа `long double`. Является широкосимвольным аналогом `strtold()` из `<stdlib.h>`. Поведение идентично `wcstod()`, но результат — `long double` (большая точность и диапазон).

Если `endptr != NULL`, в него записывается указатель на первый символ, не являющийся частью числа.

Возвращает преобразованное значение, `HUGE_VALL` при переполнении, `0` при ошибке.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *str = L"  3.14159265358979323846abc";
    wchar_t *end;

    long double ld = wcstold(str, &end);
    printf("'%ls' → %Lf (осталось: '%ls')\n", str, ld, end);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Максимальная точность среди типов с плавающей точкой | Квадратичная сложность для длинных строк |
| Стандартная функция ISO C | `long double` может не отличаться от `double` на некоторых платформах |
| Указывает позицию остановки через `endptr` | Требует установки локали |
