## Определение

```c
#include <wchar.h>

int wcscoll(const wchar_t *s1, const wchar_t *s2);
```

## Описание

Функция `wcscoll()` сравнивает две нуль-терминированные широкие строки `s1` и `s2` с учётом правил колляции текущей локали (категория `LC_COLLATE`). Возвращает:

- значение `< 0`, если `s1` лексикографически меньше `s2`;
- `0`, если строки равны;
- значение `> 0`, если `s1` лексикографически больше `s2`.

Функция является широкосимвольным аналогом `strcoll()` из `<string.h>`. В локали `C` поведение идентично `wcscmp()`.

Правила колляции могут учитывать регистр буквы, составные символы, диакритические знаки, специальные правила сортировки для конкретного языка.

> [!NOTE]
> Для многократного сравнения строк с одной локалью эффективнее использовать `wcsxfrm()`: преобразовать строки один раз, а затем сравнивать через `wcscmp()`.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *a = L"ёлка";
    const wchar_t *b = L"Ёлка";

    printf("wcscmp: %d\n", wcscmp(a, b));
    printf("wcscoll: %d\n", wcscoll(a, b));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Учитывает правила локали при сравнении | Медленнее `wcscmp()` из-за анализа локали |
| Позволяет корректно сортировать строки на разных языках | Поведение зависит от текущей локали (не потокобезопасна) |
| Стандартная функция ISO C | Квадратичная сложность при повторных вызовах (лучше `wcsxfrm`) |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (возвращает отрицательное, нулевое или положительное значение).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `s1` или `s2`.
- **Многопоточность:** потокобезопасна при чтении неизменяемых строк; зависит от текущей локали (категория `LC_COLLATE`), которая не должна изменяться во время выполнения.
