## Определение

```c
#include <wchar.h>

size_t wcsnlen(const wchar_t *str, size_t maxlen);
```

## Описание

Функция `wcsnlen()` возвращает количество широких символов в строке `str` (не считая завершающего нуль-терминатора), но не более `maxlen` символов.

Это безопасная версия `wcslen()`: если строка не содержит нуль-терминатора в пределах `maxlen`, функция вернёт `maxlen` вместо чтения за границами выделенной памяти.

Функция является широкосимвольным аналогом `strnlen()` из `<string.h>`. Является POSIX-расширением (не входит в стандарт C, но доступна в большинстве реализаций).

> [!NOTE]
> Функция полезна при работе с буферами фиксированного размера, где строка может не быть нуль-терминированной.

## Примеры

### Безопасное определение длины строки

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wchar_t buf[16];
    wcsncpy(buf, L"Длинная строка, которая не поместится", 16);
    /* buf может не содержать нуль-терминатор */

    /* Безопасно: не выйдем за границы buf */
    size_t len = wcsnlen(buf, 16);
    printf("Длина (не более 16): %zu\n", len);

    return 0;
}
```

### Сравнение с wcslen

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *str = L"Короткая строка";

    /* wcslen — без ограничения */
    printf("wcslen:   %zu\n", wcslen(str));      /* 15 */

    /* wcsnlen — с ограничением */
    printf("wcsnlen:  %zu\n", wcsnlen(str, 10)); /* 10 (обрезано) */
    printf("wcsnlen:  %zu\n", wcsnlen(str, 100)); /* 15 (полная длина) */

    return 0;
}
```

### Чтение строки из буфера без нуль-терминатора

```c
#include <stdio.h>
#include <wchar.h>

void process_buffer(const wchar_t *buf, size_t size)
{
    /* Узнаём реальную длину строки в буфере */
    size_t len = wcsnlen(buf, size);
    printf("Содержимое буфера (%zu символов): %.*ls\n", 
           len, (int)len, buf);
}

int main(void)
{
    wchar_t buf[32] = {L'П', L'р', L'и', L'в', L'е', L'т'};
    /* Нет нуль-терминатора! */

    process_buffer(buf, 32);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Безопасна: не читает за границами `maxlen` | POSIX-функция, не входит в стандарт C |
| Линейная сложность (O(n)), но не более O(maxlen) | Всё ещё O(n) в худшем случае |
| Удобна для буферов фиксированного размера | Не определяет, была ли строка обрезана |
