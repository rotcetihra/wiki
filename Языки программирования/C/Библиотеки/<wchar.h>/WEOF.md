## Определение

```c
#include <wchar.h>

#define WEOF /* unspecified value */
```

## Описание

Макрос `WEOF` определяет значение, возвращаемое функциями чтения широких символов (`fgetwc`, `getwc` и т. д.) при ошибке или достижении конца файла. Является широкосимвольным аналогом макроса `EOF` из `<stdio.h>`.

`WEOF` гарантированно отличается от любого допустимого значения широкого символа. Тип значения — `wint_t`. Обычно `WEOF` определяется как `(wint_t)-1`.

> [!NOTE]
> Все функции классификации широких символов (`iswalnum`, `iswalpha` и т. д.) корректно обрабатывают `WEOF` — они возвращают ненулевое значение только для допустимых символов, `WEOF` не классифицируется ни как буква, ни как цифра.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wint_t ch;
    int count = 0;

    while ((ch = fgetwc(stdin)) != WEOF) {
        count++;
        if (ch == L'\n')
            break;
    }

    if (ch == WEOF)
        printf("Достигнут конец файла\n");
    else
        printf("Прочитано %d символов до переноса строки\n", count);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Универсальный способ проверки ошибок и EOF для широких символов | Значение определяется реализацией (обычно `(wint_t)-1`) |
| Гарантированно отличается от любого допустимого символа | Может неочевидно различаться с `EOF` для начинающих |
| Стандартный макрос ISO C | Требует сравнения с `wint_t`, а не `wchar_t` |
