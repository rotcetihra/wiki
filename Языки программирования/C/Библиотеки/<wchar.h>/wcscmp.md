## Определение

```c
#include <wchar.h>

int wcscmp(const wchar_t *s1, const wchar_t *s2);
```

## Описание

Функция `wcscmp()` сравнивает две нуль-терминированные широкие строки `s1` и `s2` побайтово (по значению каждого символа). Возвращает:

- значение `< 0`, если `s1` лексикографически меньше `s2`;
- `0`, если строки равны;
- значение `> 0`, если `s1` лексикографически больше `s2`.

Функция является широкосимвольным аналогом `strcmp()` из `<string.h>`. Сравнение завершается при достижении различающихся символов или завершающего нуль-терминатора.

> [!NOTE]
> Для локализованного сравнения (с учётом правил конкретного языка) используйте `wcscoll()`.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *a = L"Абрикос";
    const wchar_t *b = L"Банан";
    const wchar_t *c = L"Абрикос";

    printf("%ls vs %ls: %d\n", a, b, wcscmp(a, b));  /* отрицательное */
    printf("%ls vs %ls: %d\n", a, c, wcscmp(a, c));  /* 0 */
    printf("%ls vs %ls: %d\n", b, a, wcscmp(b, a));  /* положительное */

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простое побайтовое сравнение | Не учитывает правила локали (регистр, диакритика) |
| Стандартная функция ISO C | Линейная сложность |
| Оптимизирована в большинстве реализаций | Не potokobezopasna (сравнивает два указателя) |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (возвращает отрицательное, нулевое или положительное значение).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `s1` или `s2`.
- **Многопоточность:** потокобезопасна при чтении неизменяемых строк; при параллельном изменении строк возможны гонки.
