## Определение

```c
#include <wchar.h>

int iswpunct(wint_t wc);
```

## Описание

Макрос/функция `iswpunct()` проверяет, является ли широкий символ `wc` знаком пунктуации. Возвращает ненулевое значение, если символ является печатным символом, не являющимся буквой, цифрой или пробелом (т. е. `iswgraph(wc) && !iswalnum(wc) && !iswblank(wc)`).

Классификация зависит от текущей локали: в локалях с расширенными алфавитами диапазон пунктуации может отличаться.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    printf("iswpunct('!') = %d\n", iswpunct(L'!'));
    printf("iswpunct('.') = %d\n", iswpunct(L'.'));
    printf("iswpunct('A') = %d\n", iswpunct(L'A'));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая проверка на знак пунктуации | Зависит от текущей локали |
| Стандартный макрос/функция ISO C | Может быть макросом |
| Удобна для разбора текста | Не включает пробел |
