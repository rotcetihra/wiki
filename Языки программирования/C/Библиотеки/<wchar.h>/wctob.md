## Определение

```c
#include <wchar.h>

int wctob(wint_t c);
```

## Описание

Функция `wctob()` определяет, является ли широкий символ `c` корректным однобайтовым многобайтовым символом в текущей локали.

Возвращает `EOF`, если `c` не является допустимым однобайтовым символом (т. е. его многобайтовое представление состоит более чем из одного байта), иначе — байтовое представление символа как `int`.

> [!NOTE]
> Обратная операция к `btowc()`. В локали `C` все значения `wchar_t` от 0 до 127 являются однобайтовыми. В UTF-8 локалях символы Unicode выше U+007F являются многобайтовыми.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    int c;

    c = wctob(L'A');
    printf("wctob(L'A') = %d ('%c')\n", c, c);

    c = wctob(L'Ω');
    if (c == EOF)
        printf("L'Ω' не является однобайтовым символом\n");

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрое определение однобайтовости символа | Работает только с текущей локалью |
| Стандартная функция ISO C | Возвращает `EOF` для большинства Unicode-символов в UTF-8 |
| Обратная операция к `btowc()` | Ограниченная область применения |
