## Определение

```c
#include <wchar.h>

int iswxdigit(wint_t wc);
```

## Описание

Макрос/функция `iswxdigit()` проверяет, является ли широкий символ `wc` шестнадцатеричной цифрой. Возвращает ненулевое значение для символов `L'0'`–`L'9'`, `L'a'`–`L'f'` и `L'A'`–`L'F'`.

> [!NOTE]
> В локали `C` поддерживается только стандартный набор шестнадцатеричных цифр. В расширенных локалях могут поддерживаться дополнительные цифры.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    printf("iswxdigit('A') = %d\n", iswxdigit(L'A'));
    printf("iswxdigit('f') = %d\n", iswxdigit(L'f'));
    printf("iswxdigit('g') = %d\n", iswxdigit(L'g'));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая проверка на шестнадцатеричную цифру | Зависит от текущей локали |
| Стандартный макрос/функция ISO C | Может быть макросом |
| Удобна для разбора hex-чисел | Ограниченный набор символов |
