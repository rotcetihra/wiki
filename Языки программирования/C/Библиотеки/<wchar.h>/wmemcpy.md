## Определение

```c
#include <wchar.h>

wchar_t *wmemcpy(wchar_t *dest, const wchar_t *src, size_t n);
```

## Описание

Функция `wmemcpy()` копирует `n` широких символов из массива `src` в массив `dest`. Поведение определено, только если массивы не перекрываются.

Возвращаемое значение — указатель на `dest`.

Функция является широкосимвольным аналогом `memcpy()` из `<string.h>`. Работает с массивами широких символов, а не с нуль-терминированными строками.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t src[] = {L'П', L'р', L'и', L'в', L'е', L'т'};
    wchar_t dest[8];

    wmemcpy(dest, src, 6);
    dest[6] = L'\0';

    printf("%ls\n", dest);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрое копирование массивов | Не обрабатывает перекрытие (UB при перекрытии) |
| Стандартная функция ISO C | Не добавляет нуль-терминатор |
| Работает с фиксированными массивами | Требует указания количества элементов |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (функция всегда возвращает `dest`).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `dest` или `src`.
- **Многопоточность:** потокобезопасна при использовании различных буферов; приshared.dest не потокобезопасна.
