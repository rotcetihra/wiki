## Определение

```c
#include <wchar.h>

wctype_t wctype(const char *property);
```

## Описание

Функция `wctype()` создаёт дескриптор категории классификации宽оких символов по строке `property`. Возвращает дескриптор типа `wctype_t` или `0` (некорректный дескриптор), если категория не распознана.

Предопределённые категории (строки `property`):

| Строка | Эквивалент |
|---|---|
| `"alnum"` | `iswalnum` |
| `"alpha"` | `iswalpha` |
| `"blank"` | `iswblank` |
| `"cntrl"` | `iswcntrl` |
| `"digit"` | `iswdigit` |
| `"graph"` | `iswgraph` |
| `"lower"` | `iswlower` |
| `"print"` | `iswprint` |
| `"punct"` | `iswpunct` |
| `"space"` | `iswspace` |
| `"upper"` | `iswupper` |
| `"xdigit"` | `iswxdigit` |

Дополнительные категории могут быть определены текущей локалью.

> [!NOTE]
> `wctype_t` — неполный тип. Дескриптор используется в функции `iswctype()` (не объявлена в `<wchar.h>`, но доступна в POSIX).

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wctype_t alpha = wctype("alpha");
    wctype_t digit = wctype("digit");

    if (alpha && digit) {
        printf("'A' — alpha: %d\n", iswctype(L'A', alpha));
        printf("'5' — digit: %d\n", iswctype(L'5', digit));
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет выбирать категорию классификации через дескриптор | Требует предварительного вызова `wctype()` |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** `0` (некорректный дескриптор), если категория не распознана.
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `property`.
- **Многопоточность:** потокобезопасна (не использует разделяемое состояние).
