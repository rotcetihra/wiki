## Определение

```c
#include <wchar.h>

int wmemcmp(const wchar_t *s1, const wchar_t *s2, size_t n);
```

## Описание

Функция `wmemcmp()` сравнивает первые `n` широких символов в массивах `s1` и `s2`. Сравнение прекращается при обнаружении различия или после `n` символов.

Возвращает:

- значение `< 0`, если `s1` лексикографически меньше `s2`;
- `0`, если массивы равны в пределах `n` символов;
- значение `> 0`, если `s1` лексикографически больше `s2`.

Функция является широкосимвольным аналогом `memcmp()` из `<string.h>`.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t a[] = {L'А', L'Б', L'В'};
    const wchar_t b[] = {L'А', L'Б', L'Г'};

    int result = wmemcmp(a, b, 3);
    printf("Сравнение: %d\n", result);  /* отрицательное */

    return 0;
}
```

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (возвращает отрицательное, нулевое или положительное значение).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `s1` или `s2`.
- **Многопоточность:** потокобезопасна (только чтение).
