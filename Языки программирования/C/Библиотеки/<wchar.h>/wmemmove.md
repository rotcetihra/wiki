## Определение

```c
#include <wchar.h>

wchar_t *wmemmove(wchar_t *dest, const wchar_t *src, size_t n);
```

## Описание

Функция `wmemmove()` копирует `n` широких символов из массива `src` в массив `dest`. В отличие от `wmemcpy()`, безопасно обрабатывает перекрытие массивов.

Возвращаемое значение — указатель на `dest`.

Функция является широкосимвольным аналогом `memmove()` из `<string.h>`.

> [!NOTE]
> Если массивы перекрываются, `wmemmove()` гарантирует корректное копирование. Если перекрытия нет, поведение идентично `wmemcpy()`.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wchar_t data[] = {L'А', L'Б', L'В', L'Г', L'Д', L'\0'};

    /* Сдвиг влево на 1 позицию (перекрытие) */
    wmemmove(data, data + 1, 4);
    data[4] = L'\0';

    printf("%ls\n", data);  /* БВГД */

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Безопасна при перекрытии массивов | Медленнее `wmemcpy()` (проверка направления) |
| Стандартная функция ISO C | Не добавляет нуль-терминатор |
| Гарантирует корректность при UB-сценариях | Требует указания количества элементов |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (функция всегда возвращает `dest`).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `dest` или `src`.
- **Многопоточность:** потокобезопасна при использовании различных буферов; приshared.dest не потокобезопасна.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<wchar.h>/wmemcpy|wmemcpy]], [[Языки программирования/C/Библиотеки/<wchar.h>/wcsncpy|wcsncpy]].
