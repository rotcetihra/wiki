## Определение

```c
#include <wchar.h>

size_t wcrtomb(char *s, wchar_t wc, mbstate_t *ps);
```

## Описание

Функция `wcrtomb()` преобразует широкий символ `wc` в его многобайтовое представление и записывает результат в буфер `s`.

Параметры:

- `s` — буфер для записи (не менее `MB_LEN_MAX` байт); если `NULL`, функция сбрасывает состояние `ps` в начальное;
- `wc` — широкий символ для преобразования;
- `ps` — указатель на состояние преобразования (если `NULL`, используется внутренний статический объект).

Возвращает количество байт, записанных в `s` (от 1 до `MB_LEN_MAX`), или `(size_t)-1` при ошибке.

> [!NOTE]
> Если `wc` равен `L'\0'`, функция записывает нуль-терминатор (один байт `0`) и сбрасывает состояние `ps` в начальное.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wchar_t chars[] = {L'Пр', L'и', L'в', L'е', L'т', L'\0'};
    char mb[MB_LEN_MAX];
    mbstate_t state = {0};

    for (int i = 0; chars[i] != L'\0'; i++) {
        size_t len = wcrtomb(mb, chars[i], &state);
        printf("'%lc' → %zu байт: ", chars[i], len);
        for (size_t j = 0; j < len; j++)
            printf("%02X ", (unsigned char)mb[j]);
        printf("\n");
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Основная функция преобразования в многобайтовую последовательность | Требует буфера足够的ного размера |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** `(size_t)-1` при ошибке преобразования.
- **Установление errno:** устанавливает `errno` в `EILSEQ` если `wc` не является допустимым широким символом в текущей локали.
- **Поведение при передаче NULL:** если `s` равен `NULL`, сбрасывает состояние `ps` в начальное. Если `ps` равен `NULL`, используется внутренний статический объект (не потокобезопасен).
- **Многопоточность:** потокобезопасна при использовании собственного `ps`; при `ps == NULL` не потокобезопасна.
