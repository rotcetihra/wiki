## Определение

```c
#include <wchar.h>

wint_t btowc(int c);
```

## Описание

Функция `btowc()` определяет, представляет ли значение `c` (приведённое к `unsigned char`) корректный однобайтовый многобайтовый символ в текущей локали.

Возвращает `WEOF`, если `c` не является допустимым однобайтовым символом, иначе — соответствующий широкий символ как `wint_t`.

> [!NOTE]
> В локали `C` (по умолчанию) все значения от 0 до 127 являются корректными однобайтовыми символами. В многобайтовых локалях (например, UTF-8) niektóre значения от 128 до 255 могут быть «продолжениями» многобайтовых последовательностей и не являться самостоятельными символами.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wint_t wc;

    wc = btowc('A');
    printf("btowc('A') = %lc\n", wc);

    wc = btowc(0x410);  /* кириллическая 'А' в Unicode */
    if (wc == WEOF)
        printf("0x410 не является однобайтовым символом\n");

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрое преобразование одиночного символа | Работает только с текущей локалью |
| Стандартная функция ISO C | В многобайтовых локалях большинство символов не являются однобайтовыми |
| Возвращает `WEOF` при ошибке | Ограниченная область применения |
