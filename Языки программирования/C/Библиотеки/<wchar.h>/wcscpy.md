## Определение

```c
#include <wchar.h>

wchar_t *wcscpy(wchar_t *dest, const wchar_t *src);
```

## Описание

Функция `wcscpy()` копирует широкую строку `src` в буфер `dest`, включая завершающий нуль-терминатор. Буфер `dest` должен быть достаточно большим для размещения всей строки `src`.

Возвращаемое значение — указатель на `dest`.

Функция является широкосимвольным аналогом `strcpy()` из `<string.h>`. Поведение определено, только если `dest` и `src` не перекрываются.

> [!WARNING]
> Функция не проверяет размер буфера `dest`. Для безопасного копирования используйте `wcsncpy()`.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *source = L"Привет, мир!";
    wchar_t dest[64];

    wcscpy(dest, source);
    printf("Скопировано: %ls\n", dest);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простое копирование всей строки | Нет проверки размера буфера |
| Стандартная функция ISO C | Не потокобезопасна |
| Возвращает указатель на начало результата | Возможное переполнение при длинной строке |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** не применимо (функция всегда возвращает `dest`).
- **Установление errno:** не устанавливает `errno`.
- **Поведение при передаче NULL:** поведение не определено (UB) при передаче `NULL` в качестве `dest` или `src`.
- **Многопоточность:** не потокобезопасна (модифицирует строку `dest`; необходимо синхронизировать доступ).
