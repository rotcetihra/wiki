## Определение

```c
#include <wchar.h>

wint_t towupper(wint_t wc);
```

## Описание

Функция `towupper()` преобразует широкий символ `wc` в соответствующий символ верхнего регистра (заглавную букву). Если символ не является строчной буквой, функция возвращает его без изменений.

Результат преобразования зависит от текущей локали.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    printf("towupper('a') = '%lc'\n", towupper(L'a'));
    printf("towupper('ж') = '%lc'\n", towupper(L'ж'));
    printf("towupper('5') = '%lc'\n", towupper(L'5'));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простое преобразование регистра | Зависит от текущей локали |
| Стандартная функция ISO C | Не является макросом |
| Безопасна для любых символов | Не изменяет неалфавитные символы |
