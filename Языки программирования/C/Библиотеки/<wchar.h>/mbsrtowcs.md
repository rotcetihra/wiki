## Определение

```c
#include <wchar.h>

size_t mbsrtowcs(wchar_t *dest, const char **src, size_t len, mbstate_t *ps);
```

## Описание

Функция `mbsrtowcs()` преобразует многобайтовую строку `src` в массив широких символов `dest`. Является расширенным вариантом `mbrtowc()`, предназначенным для преобразования целых строк.

Параметры:

- `dest` — буфер для записи результата (может быть `NULL` для определения требуемого размера);
- `src` — указатель на указатель на многобайтовую строку (обновляется);
- `len` — максимальное количество широких символов для записи;
- `ps` — указатель на состояние преобразования.

Если `dest == NULL`, функция возвращает требуемый размер массива (без нуль-терминатора). Если `dest != NULL`, записывает до `len` символов и завершающий нуль-терминатор. При достижении `len` запись прекращается.

Возвращает количество полностью обработанных многобайтовых символов (не считая незавершённых) или `(size_t)-1` при ошибке.

> [!NOTE]
> Если преобразование остановлено из-за заполнения буфера (`len`), указатель `*src` обновляется — его можно передать в следующий вызов для продолжения.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const char *utf8 = "Привет, мир!";
    const char *src = utf8;
    mbstate_t state = {0};

    /* Определяем требуемый размер */
    size_t len = mbsrtowcs(NULL, &src, 0, &state);
    printf("Требуется %zu широких символов\n", len);

    /* Преобразуем */
    wchar_t *wbuf = malloc((len + 1) * sizeof(wchar_t));
    src = utf8;
    state = (mbstate_t){0};
    mbsrtowcs(wbuf, &src, len + 1, &state);
    printf("Результат: %ls\n", wbuf);

    free(wbuf);
    return 0;
}
```

| Преимущество | Недостаток |

## Обработка ошибок

- **Возвращаемое значение при ошибке:** `(size_t)-1` при ошибке преобразования.
- **Установление errno:** устанавливает `errno` в `EILSEQ` при обнаружении некорректной последовательности, `EINVAL` при невалидном состоянии `ps`.
- **Поведение при передаче NULL:** если `dest` равен `NULL`, возвращает требуемый размер. Если `src` равен `NULL` или `*src` равен `NULL`, поведение не определено. Если `ps` равен `NULL`, используется внутренний статический объект (не потокобезопасен).
- **Многопоточность:** потокобезопасна при использовании собственного `ps`; при `ps == NULL` не потокобезопасна.
