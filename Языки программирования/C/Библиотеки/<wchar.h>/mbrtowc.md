## Определение

```c
#include <wchar.h>

size_t mbrtowc(wchar_t *pwc, const char *s, size_t n, mbstate_t *ps);
```

## Описание

Функция `mbrtowc()` преобразует многобайтовую последовательность из начала строки `s` в широкий символ. Является основной функцией посимвольного преобразования многобайтовых строк.

Параметры:

- `pwc` — указатель для записи результата (может быть `NULL`);
- `s` — указатель на многобайтовую строку;
- `n` — максимальное количество байт для анализа;
- `ps` — указатель на состояние преобразования (если `NULL`, используется внутренний статический объект).

Возвращает:

- `0`, если `s` указывает на нуль-терминатор;
- длину многобайтовой последовательности (от 1 до `n`);
- `(size_t)-2`, если последовательность неполная;
- `(size_t)-1`, если обнаружена некорректная последовательность.

> [!NOTE]
> Функция потокобезопасна при использовании собственного `ps` для каждого потока. При `ps == NULL` используется внутренний статический объект — не потокобезопасна.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const char *utf8 = "Привет";
    mbstate_t state = {0};
    const char *p = utf8;
    wchar_t wc;

    while (1) {
        size_t len = mbrtowc(&wc, p, MB_LEN_MAX, &state);
        if (len == 0) {
            printf("Достигнут нуль-терминатор\n");
            break;
        }
        if (len == (size_t)-2) {
            printf("Неполная последовательность\n");
            break;
        }
        if (len == (size_t)-1) {
            printf("Ошибка в кодировке\n");
            break;
        }
        printf("Символ: %lc (длина: %zu байт)\n", wc, len);
        p += len;
    }

    return 0;
}
```

## Обработка ошибок

- **Возвращаемое значение при ошибке:** `(size_t)-1` при некорректной многобайтовой последовательности, `(size_t)-2` при неполной последовательности.
- **Установление errno:** устанавливает `errno` в `EILSEQ` при обнаружении некорректной последовательности.
- **Поведение при передаче NULL:** если `s` равен `NULL`, функция эквивалентна `mbrtowc(NULL, "", 1, ps)`. Если `ps` равен `NULL`, используется внутренний статический объект (не потокобезопасен).
- **Многопоточность:** потокобезопасна при использовании собственного `ps` для каждого потока; при `ps == NULL` не потокобезопасна.
- **Связанные функции:** [[Языки программирования/C/Библиотеки/<wchar.h>/wcrtomb|wcrtomb]], [[Языки программирования/C/Библиотеки/<wchar.h>/mbsrtowcs|mbsrtowcs]].
