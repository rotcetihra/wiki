## Определение

```c
#include <wchar.h>

wchar_t *wcswcs(const wchar_t *haystack, const wchar_t *needle);
```

## Описание

Функция `wcswcs()` ищет первое вхождение подстроки `needle` в строке `haystack`. Является POSIX-расширением и выполняет ту же функцию, что и стандартная `wcsstr()`.

Возвращает указатель на начало первого вхождения или `NULL`, если подстрока не найдена.

> [!NOTE]
> В большинстве современных POSIX-реализаций `wcswcs()` реализована как макрос или обёртка над `wcsstr()`. Рекомендуется использовать стандартную `wcsstr()` для переносимости.

## Примеры

```c
#define _POSIX_C_SOURCE 200809L
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *text = L"Привет, мир!";
    const wchar_t *word = L"мир";

    wchar_t *pos = wcswcs(text, word);
    if (pos)
        printf("Найдено на позиции: %td\n", pos - text);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Доступна в POSIX-системах | Не входит в ISO C |
| Идентична `wcsstr()` по функциональности | Дублирует стандартную функцию |
| Может быть оптимизирована в реализации | Не рекомендуется для переносимого кода |
