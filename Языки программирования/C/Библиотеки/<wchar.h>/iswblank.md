## Определение

```c
#include <wchar.h>

int iswblank(wint_t wc);
```

## Описание

Макрос/функция `iswblank()` проверяет, является ли широкий символ `wc` символом-разделителем (пробелом или горизонтальной табуляцией). Возвращает ненулевое значение, если символ равен `L' '` (пробел) или `L'\t'` (горизонтальная табуляция).

Функция определена в C99 и расширяет `iswspace()` — она не включает вертикальную табуляцию, перевод строки и возврат каретки.

> [!NOTE]
> В POSIX-системах список пробельных символов может расширяться через локаль.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    printf("iswblank(' ') = %d\n", iswblank(L' '));
    printf("iswblank('\\t') = %d\n", iswblank(L'\t'));
    printf("iswblank('\\n') = %d\n", iswblank(L'\n'));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Точное определение «незначащих» пробелов (C99) | Ограниченный набор символов (пробел + табуляция) |
| Стандартный макрос/функция ISO C | Зависит от локали в POSIX |
| Удобна для парсинга чисел и строк | Может быть макросом |
