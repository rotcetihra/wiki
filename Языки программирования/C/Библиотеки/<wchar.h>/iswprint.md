## Определение

```c
#include <wchar.h>

int iswprint(wint_t wc);
```

## Описание

Макрос/функция `iswprint()` проверяет, является ли широкий символ `wc` печатным символом. Возвращает ненулевое значение, если символ принадлежит к категории «печатный символ» (включая пробел).

Печатные символы включают буквы, цифры, знаки пунктуации, математические символы, пробел и другие видимые символы. Не включают управляющие символы (0x00–0x1F, 0x7F).

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    printf("iswprint('A') = %d\n", iswprint(L'A'));
    printf("iswprint(' ') = %d\n", iswprint(L' '));
    printf("iswprint('\\n') = %d\n", iswprint(L'\n'));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая проверка на печатность | Зависит от текущей локали |
| Стандартный макрос/функция ISO C | Может быть макросом |
| Удобна для безопасного вывода текста | Включает пробел |
