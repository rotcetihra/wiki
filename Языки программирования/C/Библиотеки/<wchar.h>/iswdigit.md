## Определение

```c
#include <wchar.h>

int iswdigit(wint_t wc);
```

## Описание

Макрос/функция `iswdigit()` проверяет, является ли широкий символ `wc` десятичной цифрой. Возвращает ненулевое значение, если символ — одна из цифр `L'0'`–`L'9'`.

> [!NOTE]
> В локали `C` классификация десятичных цифр определяется таблицей ASCII. В других локалях могут поддерживаться десятичные цифры других письменностей.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    printf("iswdigit('5') = %d\n", iswdigit(L'5'));
    printf("iswdigit('A') = %d\n", iswdigit(L'A'));
    printf("iswdigit('٣') = %d\n", iswdigit(L'٣'));  /* арабская цифра 3 */

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая проверка на десятичную цифру | Зависит от текущей локали |
| Стандартный макрос/функция ISO C | Может быть макросом |
| Удобна для разбора чисел | Не различает основания системы счисления |
