## Описание библиотеки

Заголовочный файл `<regex.h>` — типы регулярных выражений POSIX. Определяет структуры и функции для работы с регулярными выражениями.

### Структуры

#### `regex_t`

```c
typedef struct {
    size_t   re_nsub;  /* Количество группирующих подвыражений */
    /* ... внутренние поля ... */
} regex_t;
```

#### `regmatch_t`

```c
typedef struct {
    regoff_t rm_so;    /* Смещение от начала строки до начала совпадения */
    regoff_t rm_eo;    /* Смещение до первого символа после совпадения */
} regmatch_t;
```

### Функции

| Функция | Описание |
|---|---|
| `regcomp(regex_t *, const char *, int)` | Компиляция регулярного выражения |
| `regexec(const regex_t *, const char *, size_t, regmatch_t *, int)` | Выполнение поиска совпадения |
| `regerror(int, const regex_t *, char *, size_t)` | Преобразование кода ошибки в строку |
| `regfree(regex_t *)` | Освобождение ресурсов, связанных с `regex_t` |

### Возвращаемое значение

- `regcomp()` возвращает `0` при успехе или код ошибки.
- `regexec()` возвращает `0` при совпадении или `REG_NOMATCH`.
- `regerror()` возвращает размер буфера, необходимого для сообщения.
- `regfree()` ничего не возвращает.

### Использование

```c
#include <regex.h>

regex_t regex;
regcomp(&regex, "^[0-9]+$", REG_EXTENDED);

regmatch_t match;
int ret = regexec(&regex, "12345", 1, &match, 0);
if (ret == 0) {
    /* Совпадение найдено: match.rm_so = 0, match.rm_eo = 5 */
}

regfree(&regex);
```

## Исключения

- **NULL:** функции не принимают `NULL` в качестве регулярного выражения (для `regcomp()`).
- **regexec:** если `nmatch = 0` или `pmatch = NULL`, подвыражения не сохраняются.
- **REG_NOSUB:** при использовании этого флага `regexec()` возвращает только `0` или `REG_NOMATCH`.
- **Память:** `regcomp()` выделяет память; `regfree()` обязателен для освобождения.
- **Многопоточность:** скомпилированное выражение `regex_t` может использоваться несколькими потоками (если не модифицируется).
- **REG_EXTENDED:** без этого флага используются POSIX Basic Regular Expressions (BRE).

## Стандарты

POSIX.1-2017.
