## Описание библиотеки

Заголовочный файл `<fts.h>` — обход иерархии файлов. Определяет функции для рекурсивного обхода каталогов (аналог `find` из POSIX).

### Структура `FTSENT`

```c
typedef struct _ftsent {
    unsigned short  fts_info;     /* Флаги описания типа */
    char           *fts_accpath;  /* Путь доступа из текущего каталога */
    char           *fts_path;     /* Путь относительно корня обхода */
    short           fts_pathlen;  /* Длина fts_path + fts_name */
    char           *fts_name;     /* Имя файла */
    short           fts_namelen;  /* Длина fts_name */
    short           fts_level;    /* Глубина (-1 до N) */
    int             fts_errno;    /* Ошибка файла */
    long            fts_number;   /* Пользовательское число */
    void           *fts_pointer;  /* Пользовательский указатель */
    struct _ftsent *fts_parent;   /* Родительский каталог */
    struct _ftsent *fts_link;     /* Следующая запись */
    struct _ftsent *fts_cycle;    /* Циклическая ссылка */
    struct stat    *fts_statp;    /* Информация [l]stat() */
} FTSENT;
```

### Функции

| Функция | Описание |
|---|---|
| `fts_open(char *const *path_argv, int options, int (*compar)(...))` | Открытие потока обхода |
| `fts_read(FTS *ftsp)` | Чтение следующего файла |
| `fts_children(FTS *ftsp, int instr)` | Список файлов каталога |
| `fts_set(FTS *ftsp, FTSENT *f, int instr)` | Управление обработкой файла |
| `fts_close(FTS *ftsp)` | Закрытие потока |

### Возвращаемое значение

- `fts_open()`: указатель на `FTS` или `NULL` при ошибке.
- `fts_read()`: указатель на `FTSENT` или `NULL` в конце иерархии.
- `fts_children()`: указатель на `FTSENT` или `NULL` если нет файлов.
- `fts_set()`: `0` при успехе или -1 при ошибке.
- `fts_close()`: `0` при успехе или -1 при ошибке.

### Использование

```c
#include <fts.h>

char *path[] = {"/home", NULL};
FTS *fts = fts_open(path, FTS_LOGICAL | FTS_NOCHDIR, NULL);
if (fts == NULL) {
    perror("fts_open");
    return 1;
}

FTSENT *entry;
while ((entry = fts_read(fts)) != NULL) {
    if (entry->fts_info & FTS_F) {
        printf("Файл: %s\n", entry->fts_path);
    }
}

fts_close(fts);
```

## Исключения

- **NULL:** `fts_read()` возвращает `NULL` в конце обхода или при ошибке.
- **fts_errno:** при ошибке чтения файла содержит номер ошибки.
- **FTS_DNR/FTS_ERR/FTS_NS:** являются терминальными (файл не будет посещён повторно).
- **fts_path:** гарантированно null-терминирован только для последнего `fts_read()`.
- **Многопоточность:** `fts_read()` и `fts_children()` не потокобезопасны (MT-Unsafe).
- **BSD:** функции изначально из BSD, не являются частью POSIX.

## Стандарты

BSD, glibc (не POSIX).
