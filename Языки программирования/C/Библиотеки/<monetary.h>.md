## Описание библиотеки

Заголовочный файл `<monetary.h>` — денежные типы. Определяет функции для форматирования денежных сумм в соответствии с настройками локали.

### Функции

| Функция | Описание |
|---|---|
| `strfmon(char *restrict, size_t, const char *restrict, ...)` | Форматирование денежной суммы в строку |
| `strfmon_l(char *restrict, size_t, locale_t, const char *restrict, ...)` | То же с указанной локалью |

### Возвращаемое значение

Возвращает количество записанных символов (не считая `\0`) или -1 при ошибке.

### Формат

Формат строки `format` поддерживает спецификаторы:
- `n` — денежная сумма (locale-dependent)
- `i` — международный формат суммы

### Использование

```c
#include <monetary.h>

char buf[64];
strfmon(buf, sizeof(buf), "%n", 1234.56);
/* Русская локаль: "1 234,56" */

strfmon(buf, sizeof(buf), "%i", 1234.56);
/* Международный: "USD 1,234.56" */
```

## Исключения

- **NULL:** функции не принимают `NULL`.
- **-1:** возвращается при ошибке (например, недостаточный размер буфера).
- **errno:** при ошибке устанавливается `errno`.
- **Буфер:** выходной буфер должен быть достаточно большим.
- **Многопоточность:** функции потокобезопасны.

## Стандарты
