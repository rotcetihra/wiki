## 1. Введение

Для хранения данных в языке Си используются **переменные**. Переменная характеризуется тремя свойствами: **типом**, **именем** и **значением**.

- **Тип** определяет, какие данные может хранить переменная: целые числа, числа с плавающей точкой, символы и т. д.;
- **Имя** позволяет обращаться к переменной в коде;
- **Значение** — собственно данные, хранящиеся в переменной.

## 2. Определение переменной

Перед использованием любую переменную необходимо **определить** — сообщить компилятору ее тип и имя. Синтаксис определения переменной:

```c
тип_переменной имя_переменной;
```

Например, простейшее определение переменной:

```c
int number;
```

Здесь определена переменная `number`, которая имеет тип `int` (целые числа). Определение переменной — это отдельная инструкция, поэтому после него ставится точка с запятой.

> [!NOTE]
> Тип `int` — один из базовых типов Си, предназначен для хранения целых чисел. Подробнее типы данных будут рассмотрены в отдельном уроке.

## 3. Имя переменной (идентификатор)

Имя переменной (в терминах языка — **идентификатор**) может представлять последовательность символов латинского алфавита, цифр и знака подчеркивания. При этом имя должно начинаться либо с буквы, либо со знака подчеркивания:

```c
int _number33;
```

### Ограничение длины

Нередко компиляторы имеют ограничение на длину имен переменных. По стандарту компилятор обязан различать идентификаторы по первым **31 значимому символу** (стандарт C90) или **63** (C99 и новее), а старые компиляторы и вовсе могли ограничивать имя 31 символом. Современные компиляторы (GCC, Clang) поддерживают имена практически любой длины, поэтому на практике это ограничение почти не ощущается.

### Регистрозависимость

Си — регистрозависимый язык: регистр символов имеет большое значение. В следующем коде определяются две разные переменные:

```c
int number;
int Number;
```

Переменная `Number` не представляет то же самое, что и переменная `number`.

> [!INFO]
> Стандарт C99 и новее допускает в идентификаторах и символы Юникода — современные компиляторы (GCC, Clang) позволяют использовать, например, кириллицу в именах переменных. Тем не менее такое именование считается дурным тоном: оно не переносимо и затрудняет чтение кода.

## 4. Ключевые слова

В языке есть ряд **зарезервированных слов** — ключевых слов, которые не могут использоваться в качестве имени переменной:

|`auto`|`break`|`case`|`char`|
|---|---|---|---|
|`const`|`continue`|`default`|`do`|
|`double`|`else`|`enum`|`extern`|
|`float`|`for`|`goto`|`if`|
|`int`|`long`|`register`|`return`|
|`short`|`signed`|`sizeof`|`static`|
|`struct`|`switch`|`typedef`|`union`|
|`unsigned`|`void`|`volatile`|`while`|

> [!INFO]
> Приведенный список — ключевые слова базового стандарта C90. Более новые стандарты добавляют собственные ключевые слова (например, `inline`, `restrict`, `_Bool`, `_Alignas`, `_Atomic`), которые также запрещено использовать в качестве имен переменных.

> [!INFO]
> Идентификаторы, начинающиеся с подчеркивания и заглавной буквы (например, `_Number`) или содержащие два подчеркивания подряд (`__name`), зарезервированы для реализации — использовать их в своих программах не рекомендуется.

## 5. Повторное определение и несколько переменных

Нельзя определить больше одной переменной с одним и тем же именем в одной области видимости:

```c
int number;
int number;
```

Подобное определение вызовет ошибку на этапе компиляции.

Можно определить сразу несколько переменных, перечислив их имена через запятую:

```c
int number1, number2, number3;
```

Здесь определены три переменные: `number1`, `number2` и `number3`.

## 6. Присваивание значения

При определении переменной ей присваивается **неопределенное значение** — память под переменную выделяется, но ее содержимое не задано.

> [!WARNING]
> Чтение значения неинициализированной переменной опасно: по стандарту использование неопределенного значения — неопределенное поведение, а на практике программа может вывести «мусор» — произвольные данные, оставшиеся в памяти.

Присвоить переменной конкретное значение можно с помощью операции присваивания `=`:

```c
int number;
number = 2;
```

Полная программа:

```c
#include <stdio.h>

int main(void)
{
    int number;
    number = 2;
    printf("number = %d \n", number);
    return 0;
}
```

Для вывода числа на консоль используется спецификатор `%d`, вместо которого подставляется значение переменной `number`, а `\n` обозначает перевод строки. Консольный вывод:

```
number = 2
```

## 7. Инициализация

Можно сразу при определении переменной задать ей начальное значение. Данный прием называется **инициализацией**:

```c
#include <stdio.h>

int main(void)
{
    int number = 2;
    printf("number = %d \n", number);
    return 0;
}
```

Инициализировать можно сразу несколько переменных:

```c
int number1 = 1, number2 = 2, number3 = 3;
```

## 8. Резюме

1. Переменная характеризуется типом, именем и значением; перед использованием ее необходимо определить: `тип имя;`.
2. Имя (идентификатор) состоит из латинских букв, цифр и знака подчеркивания и начинается с буквы или `_`; регистр символов значим.
3. Ключевые слова и зарезервированные идентификаторы не могут использоваться в качестве имен переменных.
4. Повторное определение переменной с тем же именем вызывает ошибку компиляции; несколько переменных можно определить одной инструкцией через запятую.
5. Значение присваивается операцией `=`, а задать начальное значение при определении позволяет инициализация.
6. Чтение неинициализированной переменной — неопределенное поведение; для вывода целого числа на консоль используется спецификатор `%d`.
