## 1. Введение

Язык Си поддерживает все основные арифметические операции. Они производятся над числами. Значения, которые участвуют в операции, называются **операндами**. Основные бинарные операции:

|**Операция**|**Описание**|**Пример**|
|---|---|---|
|`+`|сложение|`a + b`|
|`-`|вычитание|`a - b`|
|`*`|умножение|`a * b`|
|`/`|деление|`a / b`|
|`%`|остаток от деления|`a % b`|

## 2. Сложение и вычитание

Операция сложения возвращает сумму чисел:

```c
#include <stdio.h>

int main(void)
{
    int a = 67;
    int b = 33;
    int c = a + b + 7;
    printf("a + b + 7 = %d \n", c); // 107
    return 0;
}
```

Операция вычитания возвращает разность чисел:

```c
#include <stdio.h>

int main(void)
{
    int a = 67;
    int b = 33;
    int c = a - b;
    printf("a - b = %d \n", c); // 34
    return 0;
}
```

## 3. Умножение и деление

Операция умножения возвращает произведение чисел:

```c
int c = 15 * 3; // 45
```

Операция деления возвращает частное:

```c
#include <stdio.h>

int main(void)
{
    int a = 15 / 3;       // 5
    float d = 34.0 / 3.0; // 11.333333

    printf("a=%d \n", a);
    printf("d=%f \n", d);
    return 0;
}
```

При делении стоит быть внимательным: если в операции участвуют два целых числа, то результат деления усекается до целого числа (дробная часть отбрасывается), даже если результат присваивается переменной типа `float`:

```c
float f = 10 / 4;
printf("f = %f \n", f); // 2.0
```

Чтобы результат был вещественным, один из операндов должен представлять вещественное число:

```c
float f = 10.0 / 4;
printf("f = %f \n", f); // 2.5
```

> [!NOTE]
> Целочисленное деление усекает результат в сторону нуля: `-7 / 2 == -3`, а не `-4`.

> [!WARNING]
> Деление на ноль — неопределенное поведение: программа может упасть или выдать некорректный результат. Компилятор не обязан выявлять такую ошибку, поэтому следить за делителем должен программист.

## 4. Остаток от деления

Операция `%` возвращает результат деления двух чисел по модулю — остаток от деления:

```c
int a = 35 % 3; // 2 (35 = 33 + 2)
```

> [!WARNING]
> Операция `%` применима только к целочисленным операндам. Применение ее к числам с плавающей точкой (`float`, `double`) — ошибка компиляции.

> [!INFO]
> Знак результата в Си следует знаку делимого: `-7 % 3` равно `-1`, а `7 % -3` равно `1`.

## 5. Приоритет операций

Операции `*`, `/`, `%` имеют более высокий приоритет, чем `+` и `-`:

```c
int a = 8;
int b = 7;
int c = a + 5 * b; // 43
```

Здесь сначала вычисляется `5 * b = 35`, затем `a + 35 = 43`.

С помощью скобок можно переопределить порядок операций, чтобы операции с более низким приоритетом выполнялись раньше:

```c
int a = 8;
int b = 7;
int c = (a + 5) * b; // 91
```

Здесь сначала вычисляется `a + 5 = 13`, затем `13 * b = 91`.

Приоритеты рассмотренных операций (от высшего к низшему):

|**Уровень**|**Операции**|
|---|---|
|1|`()` скобки|
|2|`x++` `x--` (постфиксные)|
|3|`++x` `--x` (префиксные)|
|4|`*` `/` `%`|
|5|`+` `-` (бинарные)|

## 6. Инкремент и декремент

В Си есть специальные унарные операции над одной переменной: **инкремент** `++` и **декремент** `--`. Каждая имеет две разновидности — префиксную и постфиксную:

|**Операция**|**Название**|**Поведение**|
|---|---|---|
|`++x`|префиксный инкремент|увеличивает значение на 1; результатом выражения является новое значение|
|`x++`|постфиксный инкремент|увеличивает значение на 1; результатом выражения является старое значение|
|`--x`|префиксный декремент|уменьшает значение на 1; результатом выражения является новое значение|
|`x--`|постфиксный декремент|уменьшает значение на 1; результатом выражения является старое значение|

Префиксный инкремент:

```c
int a = 8;
int b = ++a;
printf("a = %d \n", a); // 9
printf("b = %d", b);    // 9
```

Постфиксный инкремент:

```c
int a = 8;
int b = a++;
printf("a = %d \n", a); // 9
printf("b = %d", b);    // 8
```

Префиксный декремент:

```c
int a = 8;
int b = --a;
printf("a = %d \n", a); // 7
printf("b = %d", b);    // 7
```

Постфиксный декремент:

```c
int a = 8;
int b = a--;
printf("a = %d \n", a); // 7
printf("b = %d", b);    // 8
```

Рассмотрим более сложный случай:

```c
int a = 8;
int b = 7;
int c = a+++b;
printf("a = %d \n", a); // 9
printf("b = %d \n", b); // 7
printf("c = %d \n", c); // 15
```

Компилятор разбирает выражение по правилу «максимальной длины» (maximal munch): `a+++b` трактуется как `(a++) + b`. Аналогично `a---b` разбирается как `(a--) - b`.

> [!WARNING]
> Изменять одну и ту же переменную несколько раз в одном выражении — неопределенное поведение. Например, `int c = a++ + a++;` или `a = a++;` могут дать непредсказуемый результат. Таких конструкций следует избегать.

## 7. Резюме

1. Основные бинарные арифметические операции: `+`, `-`, `*`, `/`, `%`.
2. При делении двух целых чисел дробная часть отбрасывается; для вещественного результата нужен вещественный операнд.
3. Деление на ноль — неопределенное поведение.
4. Операция `%` работает только с целыми числами; знак результата совпадает со знаком делимого.
5. `*`, `/`, `%` имеют более высокий приоритет, чем `+`, `-`; порядок вычислений можно менять скобками.
6. Префиксные и постфиксные `++` / `--` различаются тем, какое значение — новое или старое — становится результатом выражения.
7. Несколько изменений одной переменной в одном выражении — неопределенное поведение.
