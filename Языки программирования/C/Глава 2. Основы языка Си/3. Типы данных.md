## 1. Введение

Каждая переменная имеет определенный **тип**. Тип определяет:

- какие значения может принимать переменная (диапазон значений);
- сколько байт памяти она занимает.

Типы данных в Си можно разделить на три группы: **целочисленные**, **вещественные** (числа с плавающей точкой) и **символьные**. Отдельно стоит тип `void`.

## 2. Целочисленные типы

Целочисленные типы представляют целые числа — со знаком и без знака:

|**Тип**|**Размер (основные платформы)**|**Диапазон значений**|**Псевдонимы**|
|---|---|---|---|
|`char`|1 байт|зависит от реализации (обычно −128…127)|—|
|`signed char`|1 байт|−128…127|—|
|`unsigned char`|1 байт|0…255|—|
|`short`|2 байта (16 бит)|−32 768…32 767|`short int`, `signed short`, `signed short int`|
|`unsigned short`|2 байта (16 бит)|0…65 535|`unsigned short int`|
|`int`|4 байта (32 бита)|−2 147 483 648…2 147 483 647|`signed int`, `signed`|
|`unsigned int`|4 байта (32 бита)|0…4 294 967 295|`unsigned`|
|`long`|4 или 8 байт (см. примечание)|−2 147 483 648…2 147 483 647 или −9 223 372 036 854 775 808…9 223 372 036 854 775 807|`long int`, `signed long`, `signed long int`|
|`unsigned long`|аналогично `long`|0…4 294 967 295 или 0…18 446 744 073 709 551 615|`unsigned long int`|
|`long long`|как правило 8 байт (64 бита)|−9 223 372 036 854 775 808…9 223 372 036 854 775 807|`long long int`, `signed long long`, `signed long long int`|
|`unsigned long long`|как правило 8 байт (64 бита)|0…18 446 744 073 709 551 615|`unsigned long long int`|

> [!NOTE]
> Размеры в таблице — типичные для современных 64-разрядных платформ. Стандарт гарантирует лишь минимальные значения: `short` и `int` — не менее 16 бит, `long` — не менее 32 бит, `long long` — не менее 64 бит. При этом размер `long` не меньше размера `int`, а размер `int` — не меньше размера `short`.

> [!NOTE]
> На 64-разрядных системах действуют две модели данных: в Windows (LLP64) `long` занимает 4 байта, а в Linux и macOS (LP64) — 8 байт. Поэтому размер `long` — самый «непортируемый» из целочисленных типов.

## 3. Числа с плавающей точкой

Вещественные типы представляют числа с дробной частью:

|**Тип**|**Размер**|**Диапазон значений**|
|---|---|---|
|`float`|4 байта (32 бита)|±3,4E−38…3,4E+38 (одинарная точность)|
|`double`|8 байт (64 бита)|±1,7E−308…1,7E+308 (двойная точность)|
|`long double`|80 бит значения; в памяти зависит от платформы|±3,4E−4932…1,1E+4932|

> [!WARNING]
> Размер и диапазон `long double` сильно зависят от платформы: на x86-64 Linux (GCC) он хранится в 16 байтах (с 80-битной точностью), а в Windows (MSVC) `long double` фактически совпадает с `double` (8 байт).

## 4. Тип void

Тип `void` — тип без значения. Непосредственно переменную типа `void` определить нельзя. Он используется, когда значение отсутствует: функция, ничего не возвращающая, объявляется с типом `void`, а тип `void *` — «указатель на данные произвольного типа».

## 5. Суффиксы целочисленных литералов

Любое десятичное число по умолчанию рассматривается как значение одного из типов `int` / `long int` / `long long int` — выбирается первый тип, в диапазон которого вписывается число. При присвоении такого числа переменной другого типа выполняется преобразование. Чтобы явно указать тип числа, к нему добавляется суффикс:

|**Тип**|**Суффикс**|
|---|---|
|`long int`|`l` или `L`|
|`unsigned int`|`u` или `U`|
|`unsigned long int`|`ul` или `UL`|
|`long long int`|`ll` или `LL`|
|`unsigned long long int`|`ull` или `ULL`|

Применим суффикс. Например, если нужно хранить только положительные числа, можно взять тип `unsigned int` — для определения чисел этого типа применяется суффикс `u` или `U`:

```c
#include <stdio.h>

int main(void)
{
    unsigned number1 = 4294967294u;
    unsigned int number2 = 22U;
    printf("number1 = %u\n", number1);
    printf("number2 = %u\n", number2);
    return 0;
}
```

При выводе чисел типа `unsigned int` применяется спецификатор `%u`.

Зачем нужен суффикс, если можно обойтись без него? Без суффикса десятичное число рассматривается как значение одного из знаковых типов (`int` / `long` / `long long`), и при присвоении переменной типа `unsigned int` выполняется преобразование. Используя суффикс, мы избегаем ненужного преобразования.

## 6. Спецификаторы формата целочисленных типов

Для вывода значений целочисленных типов в функции `printf` применяются соответствующие спецификаторы:

|**Тип**|**Спецификатор**|
|---|---|
|`int`|`%d`|
|`unsigned int`|`%u`|
|`short`|`%hd`|
|`unsigned short`|`%hu`|
|`long`|`%ld`|
|`unsigned long`|`%lu`|
|`long long`|`%lld`|
|`unsigned long long`|`%llu`|

Пример определения переменных всех целочисленных типов с использованием различных псевдонимов и суффиксов:

```c
#include <stdio.h>

int main(void)
{
    unsigned short number1 = 1u;
    unsigned short int number2 = 2u;
    short number3 = 3;
    short int number4 = -4;
    signed short number5 = 5;
    signed short int number6 = -6;

    long number7 = -2147483648l;
    long int number8 = -2147483648L;
    signed long number9 = 2147483647l;
    signed long int number10 = 2147483647L;

    unsigned long number11 = 4294967295ul;
    unsigned long int number12 = 4294967295UL;

    long long number13 = -9223372036854775807ll;
    long long int number14 = 9223372036854775807ll;
    signed long long number15 = -9223372036854775807LL;
    signed long long int number16 = 9223372036854775807LL;

    unsigned long long number17 = 18446744073709551615ull;
    unsigned long long int number18 = 18446744073709551615ULL;

    printf("number1 = %hu\n", number1);
    printf("number2 = %hu\n", number2);
    printf("number3 = %d\n", number3);
    printf("number4 = %d\n", number4);
    printf("number5 = %d\n", number5);
    printf("number6 = %d\n", number6);
    printf("number7 = %ld\n", number7);
    printf("number8 = %ld\n", number8);
    printf("number9 = %ld\n", number9);
    printf("number10 = %ld\n", number10);
    printf("number11 = %lu\n", number11);
    printf("number12 = %lu\n", number12);
    printf("number13 = %lld\n", number13);
    printf("number14 = %lld\n", number14);
    printf("number15 = %lld\n", number15);
    printf("number16 = %lld\n", number16);
    printf("number17 = %llu\n", number17);
    printf("number18 = %llu\n", number18);
    return 0;
}
```

## 7. Числа в различных системах счисления

Си позволяет определять числа в разных системах счисления:

|**Система счисления**|**Префикс**|**Пример (число 11)**|
|---|---|---|
|Двоичная|`0b` или `0B`|`0b1011`|
|Восьмеричная|`0`|`013`|
|Десятичная|нет|`11`|
|Шестнадцатеричная|`0x` или `0X`|`0xB`|

```c
#include <stdio.h>

int main(void)
{
    int code1 = 0b1011; // двоичная система - число 11
    int code2 = 013;    // восьмеричная система - число 11
    int code3 = 11;     // десятичная система - число 11
    int code4 = 0xB;    // шестнадцатеричная система - число 11
    printf("code1 = %d\n", code1); // code1 = 11
    printf("code2 = %d\n", code2); // code2 = 11
    printf("code3 = %d\n", code3); // code3 = 11
    printf("code4 = %d\n", code4); // code4 = 11
    return 0;
}
```

Все четыре переменные хранят одно и то же число — 11, записанное в разных системах счисления.

> [!NOTE]
> Префикс `0b` для двоичных чисел стандартизирован только в стандарте C23; GCC и Clang поддерживают его и в более ранних режимах как расширение.

Значение переменной не должно выходить за пределы диапазона ее типа:

```c
unsigned short int number = -65535;
```

> [!WARNING]
> По стандарту преобразование значения, не помещающегося в беззнаковый тип, определено (остаток от деления на 2^N), однако для литералов, выходящих за диапазон, компиляторы GCC и Clang выдают предупреждение о переполнении — как правило, это признак ошибки в программе.

## 8. Символы

Символьные типы представлены тремя типами: `char`, `signed char` и `unsigned char`. На практике для работы с символами применяется тип `char`.

Знаковость типа `char` стандарт не определяет — она оставлена на усмотрение реализации. Как правило, `char` определяется как знаковый тип с диапазоном −128…127: так настроены GCC и Clang на большинстве платформ (в частности, в соответствии с System V ABI для Unix-систем). На некоторых платформах (например, ARM) `char` по умолчанию беззнаковый.

Значением переменной типа `char` служит **символьный литерал** — символ в одинарных кавычках:

```c
char letter = 'A';
```

В действительности переменная типа `char` хранит число — числовой код символа из таблицы, сопоставляющей символы и коды. Наиболее распространена таблица **ASCII**, которая сопоставляет символам коды от 0 до 127. Код символа `'A'` — 65:

```c
#include <stdio.h>

int main(void)
{
    char letter = 'A';
    printf("letter: %d \n", letter); // letter: 65
    printf("letter: %c \n", letter); // letter: A
    return 0;
}
```

Спецификатор `%d` выводит числовой код символа, а `%c` — сам символ. Вместо символа в одинарных кавычках можно присвоить переменной напрямую числовой код:

```c
char letter = 65;
```

Результат будет тем же.

> [!NOTE]
> Символьные литералы в Си (символ в одинарных кавычках) имеют тип `int`, а не `char`. Это отличие от C++, где символьные литералы имеют тип `char`.

## 9. Оператор typedef

Оператор `typedef` позволяет определить для существующего типа **псевдоним**. Это может потребоваться, например, когда имя типа длинное и его хочется сократить.

Общая форма оператора:

```
typedef существующий_тип псевдоним;
```

Например, зададим для типа `unsigned char` псевдоним `BYTE`:

```c
typedef unsigned char BYTE;
```

Псевдоним можно использовать как любой другой тип:

```c
#include <stdio.h>

typedef unsigned char BYTE;

int main(void)
{
    BYTE byte = 22;
    printf("byte = %d", byte);
    return 0;
}
```

## 10. Размер типов и оператор sizeof

Размеры типов разработчики компиляторов выбирают самостоятельно, исходя из аппаратных возможностей платформы; стандарт устанавливает лишь минимальные значения. Когда необходимо точно знать размер типа, применяется оператор **sizeof**, который возвращает размер памяти в байтах, занимаемый типом, переменной или результатом выражения.

Чтобы получить размер типа, он помещается в скобки после `sizeof`:

```c
#include <stdio.h>

int main(void)
{
    printf("sizeof(int): %zu\n", sizeof(int));
    printf("sizeof(long): %zu\n", sizeof(long));
    printf("sizeof(unsigned long long): %zu\n", sizeof(unsigned long long));
    return 0;
}
```

На 64-разрядном Linux мы получим следующий консольный вывод:

```
sizeof(int): 4
sizeof(long): 8
sizeof(unsigned long long): 8
```

Оператор `sizeof` возвращает размер в виде значения типа **size_t**. Тип `size_t` фактически не является самостоятельным типом, а представляет псевдоним: на 64-разрядном Linux это `unsigned long`, на 64-разрядной Windows — `unsigned long long`. Поэтому для хранения результата лучше использовать псевдоним `size_t`, а не конкретный тип:

```c
#include <stdio.h>

int main(void)
{
    size_t int_size = sizeof(int);
    printf("sizeof(int): %zu\n", int_size);
    return 0;
}
```

> [!WARNING]
> Для вывода значения типа `size_t` корректным спецификатором является `%zu` (стандарт C99). Спецификатор `%lu` работает на Linux, но неверен на Windows, где `size_t` — псевдоним для `unsigned long long`.

Также `sizeof` может вычислять размер объекта — например, переменной. В этом случае имя переменной передается в скобки либо указывается после оператора без скобок:

```c
#include <stdio.h>

int main(void)
{
    int number = 2;
    printf("sizeof(number): %zu\n", sizeof(number));
    printf("sizeof number: %zu\n", sizeof number);
    return 0;
}
```

Консольный вывод:

```
sizeof(number): 4
sizeof number: 4
```

> [!NOTE]
> Оператор `sizeof` не выполняет выражение, а вычисляет размер его результата. Например, `sizeof(printf("hello"))` вернет размер типа `int` — результата функции `printf` — при этом сама строка выведена не будет. Размер результата вложенного выражения, такого как `sizeof(sizeof(int))`, равен размеру типа `size_t` (на 64-разрядных системах — 8 байт).

## 11. Резюме

1. Тип переменной определяет диапазон допустимых значений и размер в памяти.
2. Целочисленные типы: `char`, `short`, `int`, `long`, `long long` и их беззнаковые варианты; размеры зависят от платформы, стандарт гарантирует лишь минимальные значения.
3. Вещественные типы: `float` (4 байта), `double` (8 байт), `long double` (размер зависит от платформы); тип `void` — тип без значения.
4. Суффиксы литералов (`u`, `l`, `ll`, `ul`, `ull`) позволяют явно указать тип целочисленного значения и избежать лишних преобразований.
5. Целые числа можно записывать в двоичной (`0b`), восьмеричной (`0`), десятичной и шестнадцатеричной (`0x`) системах счисления.
6. Переменная `char` хранит числовой код символа (например, по таблице ASCII); знаковость `char` зависит от реализации.
7. `typedef` создает псевдонимы типов, а `sizeof` возвращает размер типа или объекта в байтах; результат — тип `size_t`, для вывода используется спецификатор `%zu`.
