## 1. Введение

В прошлой теме рассматривались такие функции, как `calloc`, `malloc`, `realloc`, которые возвращали в качестве результата указатель. То есть функция может не только принимать указатели как параметры, но и возвращать указатель. Определение подобной функции выглядит следующим образом:

```c
тип *имя_функции (параметры)
{
    // тело функции
    тип *имя_указателя;
    return имя_указателя;
}
```

Преимуществом использования указателя как возвращаемого типа является то, что это позволяет получать из функции набор значений, в частности, массив. Например, пусть у нас в программе имеются два массива, и мы хотим их сложить с помощью специальной функции:

```c
#include <stdio.h>
#include <stdlib.h>

int *addArrays(int a[], int b[], int n)
{
    int *ptr = calloc(n, sizeof(int));

    for (int i = 0; i < n; i++)
        ptr[i] = a[i] + b[i];

    return ptr;
}

int main(void)
{
    int a[] = {3, 4, 5, 6, 7};
    int b[] = {1, 1, 1, 1, 1};

    int n = sizeof(a) / sizeof(a[0]);
    int *ptr = addArrays(a, b, n);

    for (int i = 0; i < n; i++)
        printf("%d \t", ptr[i]);

    free(ptr);
    return 0;
}
```

Функция `addArrays()` для хранения результатов сложения двух массивов выделяет динамическую память, на которую указывает указатель `ptr`. Затем эта динамическая память наполняется результатами сложения соответствующих элементов двух массивов. А возвращаемым значением служит указатель `ptr`.

В функции `main` мы можем получить возвращаемый указатель и перебрать все значения из динамической памяти:

```c
int *ptr = addArrays(a, b, n);
for (int i = 0; i < n; i++)
    printf("%d \t", ptr[i]);
```

Когда указатель становится не нужен, ранее выделенная динамическая память освобождается с помощью функции `free()`.

Результатом работы программы будет следующий вывод:

```
4	5	6	7	8
```

## 2. Ошибка: возврат адреса локальной переменной

Стоит отметить, что указатель, возвращаемый из функции, не должен представлять адрес локальной переменной. Потому что локальная переменная существует только во время работы этой функции. Например, изменим функцию `addArrays` так, чтобы она возвращала указатель на локальный массив:

```c
int *addArrays(int a[], int b[], int n)
{
    int ptr[n];
    for (int i = 0; i < n; i++)
        ptr[i] = a[i] + b[i];

    return ptr;
}
```

Однако мы даже не сможем скомпилировать данный пример, так как массив `ptr` здесь задан как локальная переменная.

## 3. Резюме

1. Функция может возвращать указатель: `тип *имя_функции (параметры)`, например `int *addArrays(...)`.
2. Возврат указателя позволяет получать из функции массивы и другие наборы значений, выделенные в динамической памяти.
3. Возвращаемый указатель не должен указывать на локальные переменные функции — они уничтожаются при выходе из функции.
4. Память, выделенную в функции, вызывающий код должен освободить через `free()`.
