При изменении размера хеш-таблицы, когда ее начальный размер не является степенью двойки, а является, к примеру, простым числом, все становится несколько сложнее. Для увеличения и уменьшения размера таблицы в два раза можно ввести еще один параметр - `β` и установить размер таблицы равным `β * m` при расширении таблицы и `m/β` при ее уменьшении, где `m` - начальный размер таблицы. Однако, проблема в том, что выражения `β * m` и `m/β` необязательно дадут другое простое число.

В качестве решения мы можем выбрать простые числа, близкие к этому значению (`β * m` и `m/β`), и составить таблицу простых чисел `p1, p2, ..., pN` таким образом, чтобы `pj-1 < pj/β` и `pj+1 > β*pj`.

Так, мы можем добавить таблицу простых чисел, основанную на выбранном вами значении β. Например, при β = 2 мы можете определить таблицу простых чисел следующим образом:

```c
// таблица простых чисел
int primes[] = 
{
    2, 5, 11, 23, 47, 97, 197, 397,
    797, 1597, 3203, 6421, 12853, 25717, 51437,
    102877, 205759, 411527, 823117, 1646237,
    3292489, 6584983, 13169977 
};
// количество простых чисел
unsigned int primes_num = sizeof(primes)/sizeof(int);
```

Теоретически можно, конечно, вычислять нужное простое число динамически, но это может быть довольно затратная операция. Использование готового набора с индексацией по этому набору облегчает работу и увеличивает производительность. Готовые списки простых чисел можно посмотреть по адресу [https://t5k.org/lists/](https://t5k.org/lists/)

Для работы с размерами и таблицей простых чисел в структуру хеш-таблицы можно добавить специальное поле, которое будет представлять индекс простого числа в таблице простых чисел:

```c
// структура хеш-таблицы
struct hash_table 
{
    struct bin *bins;       // массив ячеек таблицы
    unsigned int size;      // общий размер таблицы
    unsigned int count;     // общее количество элементов (удаленных и неудаленных)
    unsigned int active;    // количество активных (неудаленных) элементов
    unsigned int prime;     // индекс простого числа в таблице простых чисел
};
```

При вставке ключа (функция insert_key из прошлых статей) мы можем расширять таблицу следующим образом:

```c
if (table->count > table->size / 2) 
{
    assert(table->prime + 1 < primes_num );
    resize(table, primes[table->prime + 1]);
    table->prime = table->prime + 1;
}
```

Здесь в качестве фактора применяется `β = 2`. И если текущее количество превышает значение `m/β`, то с помощью `assert()` проверяем, что в таблице простых чисел есть индекс `prime + 1`. И, если есть, используем число по этому индексу в качестве нового размера.

Для удаления ключа (функция delete_key из прошлых статей) мы можем использовать следующие действия:

```c
if (table->active < table->size / 8 && table->prime > 0) 
{
    resize(table, primes[table->prime - 1]);
    table->prime = table->prime - 1;
}
```
