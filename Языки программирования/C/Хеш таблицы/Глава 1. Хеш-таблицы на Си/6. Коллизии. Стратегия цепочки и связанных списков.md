При работе с хеш-таблицами коллизии практически неизбежны. Поэтому при проектировании хеш-таблицы необходим способ обработки коллизий, чтобы можно было вставлять ключи, даже если ячейка хеш-таблицы уже занята. Один из самых простых способов разрешения коллизий — это размещение конфликтующих ключей в структуре данных, которая может их хранить, и наиболее простой структурой данных является связанный список. По сути каждый такой список представляет отдельную корзину хеш-таблицы, в которую помещаются хеш-ключи с одинаковым индексом корзины. Это так называемый метод цепочки или chaining. И здесь может быть множество различных способов реализаций, поэтому рассмотрим одну из простейших.

Для узла связанного списка (корзины) можно определить следующую структуру данных:

```c
struct node
{
    unsigned int key;
    struct node* next;
};
```

Это одна из самых простых реализаций элемента списка, хотя в зависимости от задачи, естественно конкретные реализации могут отличаться. Таким образом, каждый узел списка содержит хеш-ключ (key) и указатель на следующий элемент в списке. Значение NULL для поля next будет указывать, что мы находимся в конце списка.

Далее мы можем определить сам список, и тут опять же есть различные варианты. Наиболее частый вариант — это определение списка как указателя на node. В нашем случае мы определим список (корзину) в виде указателя на указатель на node:

```c
// определение корзины
typedef struct node** BIN;
```

Способ определения корзины как указателя на указатель упростит изменение предыдущих элементов списка (при вставке и удалении элементов необходим доступ к предыдущему элементу в списке). На что собственно будет указывать этот указатель? А он будет указывать на головной (начальный или первый) узел списка (корзины). Что-то вроде следующего:

```c
struct node** bin = malloc(sizeof *bin);
*bin = NULL;
```

Здесь указатель bin представляет указатель на первый элемент корзины, который мы можем получить с помощью операции разыменования *bin. Причем по умолчанию этот первый элемент будет равен NULL. Это также позволит упростить ряд операций, такие как вставка, поиск и удаление узлов из корзины.

Для работы со подобными связанными списками понадобятся следующие операции:

- Добавление нового ключа в список
- Проверка наличия ключа в списке
- Удаление ключа из списка

## Добавление элемента

При добавлении нового ключа его можно поместить в начало списка:

```c
// создаем новый узел в корзине
struct node* new_node(unsigned int key, struct node* next)
{
    struct node *node = malloc(sizeof *node);
    *node = (struct node){.key = key, .next = next};
    return node;
}
// добавляем новый узел в корзину
void add_node(BIN bin, unsigned int key)
{
    *bin = new_node(key, *bin);
}
```

Фактически добавление нового узла разбивается на два этапа: создание нового узла и его собственно добавление. Создание происходит в функции new_node(), в которую передается собственно хеш-ключ, который надо сохранить в корзине, и следующий элемент (параметр struct node* next). Функция add_node() берет корзину — BIN bin и ключ и в качестве следующего узла передает текущий головной элемент корзины. А после создания нового узла с помощью new_node() этот новый узел становится новым головным узлом корзины. А предыдущий головной узел корзины становится следующим.

Схематически это будет выглядеть примерно так:

```
BIN bin = malloc(sizeof *bin);  // корзина
*bin = NULL;                    // первый элемент корзины равен NULL

add_node(bin, 121);     // добавление ключа 121

// получаем список (предположим данные нового элемента расположены по адресу 0x100)

       addr = 0x100
      ----------------
0x100 | key = 121    |
      ----------------
0x108 | next = NULL  |
      ----------------
// в этом случае *bin = 0x100

add_node(bin, 123);     // добавление ключа 123
// получаем список (предположим данные нового элемента расположены по адресу 0x110)

        addr = 0x110             addr = 0x100
       ---------------          ----------------
0x110  | key = 123   |    0x100 | key = 121    |
       --------------           ----------------
0x118  | next= 0x100 |    0x108 | next = NULL  |
       ---------------          ----------------

// в этом случае *bin = 0x110
```

## Поиск и проверка элемента в корзине

Для поиска определенных ключей в списке необходимо пройтись по списку до тех пор, пока не будет найден нужный ключ:

```c
// поиск ключа в корзине
BIN find_key(BIN bin, unsigned int key)
{
    for (; *bin; bin = &(*bin)->next)
    {
        if ((*bin)->key == key) return bin;
    }
    return NULL;
}
// проверка наличия элемента
int contains_node(BIN bin, unsigned int key)
{
    return find_key(bin, key) != NULL;
}
```

Функция find_key() фактически перебирает все узлы корзины, пока не дойдет до того, который содержит нужный ключ. Для этого функция смотрит на головной узел списка в *bin и помещает его в параметр (переменную) bin. Соответственно выражение *bin будет возвращать значение поля next (указатель на следующий элемент node).

Поскольку в нашей конструкции списка указатель на самый последний элемент равен NULL, то, отслеживая NULL (for (; *bin; bin =), мы можем отследить конец связанного списка и возвратить NULL, если искомый хеш не найден.

А используя функцию contains_node(), мы можем проверить, находится ли элемент в списке. Если хеш найден, то возвращаем 1, иначе возвращаем 0.

## Удаление

Для удаления определим ряд функций:

```c
// удаляем начало (голову) корзины
void free_head(BIN bin)
{
    struct node *next = (*bin)->next;
    free(*bin);
    *bin = next;
}

// удаление элемента
void free_node(BIN bin, unsigned int key)
{
    if ((bin = find_key(bin, key)))
    {
        free_head(bin);
    }
}

// удаляем всю корзину
void free_bin(BIN bin)
{
    while (*bin)
    {
        free_head(bin);
    }
}
```

Ключевая здесь функция, от которой зависят остальные — это free_head(). Она удаляет головной элемент корзины таким образом, что после удаления головным элементом становится следующий элемент.

Функция free_node() необходима для удаления определенного хеш-значения, которое передается через параметр key. Для этого с помощью функции find_key() получаем указатель на указатель node удаляемого хеш-значения. Как мы помним, find_key() возвращает значение поля next (указатель на следующий элемент node).

Предположим, *bin = 0x110, а корзина представляет следующий список:

```
        addr = 0x110             addr = 0x100
       ---------------          ----------------
0x110  | key = 123   |    0x100 | key = 121    |
       --------------           ----------------
0x118  | next= 0x100 |    0x108 | next = NULL  |
       ---------------          ----------------

// удаляем элемент с хеш-значением 121
free_node(bin, 121);

// этот вызов функции для поиска обращается к find_key
find_key(bin, 121)

// find_key возвращает указатель bin, где
bin = 0x118
*bin = 0x100
```

Поскольку нужный элемент найден, выполняется удаление — вызов free_head:

```c
free_head(bin);
```

Это приведет к следующей последовательности вызовов:

```c
struct node *next = (*bin)->next;  // next = NULL
free(*bin);                           // удаление данных по адресу 0x100
*bin = next;        // по адресу 0x118 сохраняем NULL
```

В итоге получается следующий список (из одного элемента):

```
        addr = 0x110
       ---------------
0x110  | key = 123   |
       --------------
0x118  | next= NULL  |
       ---------------
```

Третья функция — free_bin проходит по всем узлам списка, освобождая их по одному. Причем здесь при проходе по элементам мы не перемещаем указатель напрямую по списку, как это обычно делается. Вместо этого, начало списка находится в переменной *bin. Пока *bin не равен NULL, в списке есть узлы, поэтому мы получаем второй элемент в списке и помещаем его в next, освобождаем начало списка, записываем второй узел в list и затем переходим к следующему элементу.

Итак, мы определили всю базовую инфраструктуру работы с корзинами хеш-таблицы, и теперь определим сам API хеш-таблиц.

## Обработка коллизий

Для обработки коллизий с помощью связанного списка определим следующую структуру хеш-таблицы:

```c
struct hash_table
{
    struct node** bins;
    unsigned int size;
};
```

Теперь поле bins — корзины хеш-таблицы представляет тип struct node**. Хотя это по сути тот же тип, для которого применяется псевдоним BIN — то есть тип списка. Однако в данном случае bins выступает в роли массива указателей на node. А вот указатель на один из элементов этого массива будет представлять список/корзину или BIN.

Далее определим функции создания и удаления хеш-таблиц, чтобы при инициализации ячейки хеш-таблицы представляли списки указателей на структуры node, а при удалении таблицы вся выделенная память освобождалась:

```c
// создание хеш-таблицы
struct hash_table* new_table(unsigned int size)
{
    struct hash_table *table = malloc(sizeof *table);
    table->bins = malloc(size * sizeof *table->bins);
    table->size = size;
    for (BIN bin = table->bins; bin < table->bins + table->size; ++bin)
    {
        *bin = NULL;
    }
    return table;
}
// удаление хеш-таблицы
void free_table(struct hash_table *table)
{
    for (BIN bin = table->bins; bin < table->bins + table->size; bin++)
    {
        free_bin(bin);
    }
    free(table->bins);
    free(table);
}
```

При создании хеш-таблицы в функции new_table выделяем память как для самой таблицы, так и для ее корзин. Кроме того, проходим по всем корзинам и инициализируем их значением NULL (*bin = NULL;). При удалении последовательно освобождаем память для всех узлов отдельных корзин, затем память для массива указателей bins и затем память для самой хеш-таблицы.

Затем для управления корзинами добавим еще ряд функций. Функция для получения корзины таблицы, которая содержит нужное хеш-значение:

```c
BIN get_bin(struct hash_table* table, unsigned int key)
{
    unsigned int mask = table->size - 1;
    unsigned int index = key & mask;
    return table->bins + index;
}
```

Эта функция будет в большей степени служебной. В ней мы получаем из хеш-значения key индекс корзины, в которой должен находиться хеш, и возвращаем указатель BIN, который указывает на корзину.

Также определим функцию для добавления ключа в корзину:

```c
void insert_key(struct hash_table *table, unsigned int key)
{
    // получаем указатель на корзину в хеш-таблице
    BIN bin = get_bin(table, key);
    // чтобы избежать дублирования проверяем наличие элемента в корзине
    if (!contains_node(bin, key))
    {
        add_node(bin, key); // добавляем хеш в корзину
    }
}
```

Чтобы избежать повторных добавлений одного и того же ключа перед добавлением проверяем его наличие.

Также добавим функцию для проверки наличия ключа в таблице:

```c
int contains_key(struct hash_table *table, unsigned int key)
{
    return contains_node(get_bin(table, key), key);
}
```

Здесь получаем индекс указатель на корзину и затем смотрим, есть ли в ней нужный нам хеш.

И последняя функция — функция удаления:

```c
void delete_key(struct hash_table *table, unsigned int key)
{
    BIN bin = get_bin(table, key);
    free_node(bin, key);
}
```

При удалении фактически делегируем основную работу функции free_node, которая проходит по узлам корзины и удаляет узел с искомым хеш-значением.

## Резюме

Теперь соберем все и посмотрим на примере:

```c
#include <stdio.h>
#include <stdlib.h>

// отдельный элемент корзины
struct node
{
    unsigned int key;
    struct node* next;
};
// определение корзины
typedef struct node **BIN;

// структура хеш-таблицы
struct hash_table
{
    struct node** bins;
    unsigned int size;
};

// создаем новый узел в корзине
struct node* new_node(unsigned int key, struct node *next)
{
    struct node *node = malloc(sizeof *node);
    *node = (struct node){.key = key, .next = next};
    return node;
}
// добавляем новый узел в корзину
void add_node(BIN bin, unsigned int key)
{
    *bin = new_node(key, *bin);
}

// поиск ключа в корзине
BIN find_key(BIN bin, unsigned int key)
{
    for (; *bin; bin = &(*bin)->next)
    {
        if ((*bin)->key == key) return bin;
    }
    return NULL;
}
// проверка наличия элемента
int contains_node(BIN bin, unsigned int key)
{
    return find_key(bin, key) != NULL;
}
// удаляем начало (голову) корзины
void free_head(BIN bin)
{
    struct node *next = (*bin)->next;
    free(*bin);
    *bin = next;
}

// удаление элемента
void free_node(BIN bin, unsigned int key)
{
    if ((bin = find_key(bin, key)))
    {
        free_head(bin);
    }
}

// удаляем всю корзину
void free_bin(BIN bin)
{
    while (*bin)
    {
        free_head(bin);
    }
}
// создание хеш-таблицы
struct hash_table* new_table(unsigned int size)
{
    struct hash_table *table = malloc(sizeof *table);
    table->bins = malloc(size * sizeof *table->bins);
    table->size = size;
    for (BIN bin = table->bins; bin < table->bins + table->size; ++bin)
    {
        *bin = NULL;
    }
    return table;
}
// удаление хеш-таблицы
void free_table(struct hash_table *table)
{
    for (BIN bin = table->bins; bin < table->bins + table->size; bin++)
    {
        free_bin(bin);
    }
    free(table->bins);
    free(table);
}
// получение корзины в хеш-таблице
BIN get_bin(struct hash_table *table, unsigned int key)
{
    unsigned int mask = table->size - 1;
    unsigned int index = key & mask;
    return table->bins + index;
}
// добавление данных в хеш-таблицу
void insert_key(struct hash_table *table, unsigned int key)
{
    BIN bin = get_bin(table, key);
    if (!contains_node(bin, key))
    {
        add_node(bin, key);
    }
}
// проверка наличия данных
int contains_key(struct hash_table *table, unsigned int key)
{
    return contains_node(get_bin(table, key), key);
}
// удаление ключа
void delete_key(struct hash_table *table, unsigned int key)
{
    BIN bin = get_bin(table, key);
    free_node(bin, key);
}
// получаем хеш-значение из строки
unsigned int hash_fnv1a(const char *str)
{
   unsigned int hash = 2166136261u;

    while (*str) {
        hash ^= (unsigned char)(*str++);
        hash *= 16777619;
    }

    return hash;
}

int main(void)
{
    char* red = "red";
    char* green = "green";

    unsigned int red_hash = hash_fnv1a(red);
    unsigned int green_hash = hash_fnv1a(green);

    unsigned int size = 4;
    struct hash_table* dict = new_table(size);

    insert_key(dict, red_hash);
    insert_key(dict, green_hash);

    int is_present = contains_key(dict, red_hash);
    printf("string `red` is %s\n", is_present?  "present" : "absent");

    delete_key(dict, red_hash);

    delete_key(dict, red_hash-2);
    is_present = contains_key(dict, red_hash);
    printf("string `red` is %s\n", is_present?  "present" : "absent");

    free_table(dict);

    return 0;
}
```

Здесь для примера добавляем пару строк и затем проверяем наличие одной из них в хеш-таблицы — до и после удаления.
