## 1. Введение

Директивы условной компиляции позволяют в зависимости от условий добавить в файл определенный код.

## 2. Директивы #if/#else/#endif

Прежде всего это такие директивы, как `#if`/`#else`/`#endif`, действие которых напоминает условную конструкцию `if`:

```c
#if условие
исходный_код
#endif
```

Если условие возвращает ненулевое значение (то есть оно истинно), то в итоговый исходный файл вставляется исходный код, который расположен между директивами `#if` и `#endif`:

```c
#include <stdio.h>
#define N 22

int main(void)
{
#if N == 22
    printf("N=22");
#endif
    return 0;
}
```

Директива `#else` позволяет задать альтернативный код, который компилируется, если условие не верно:

```c
#include <stdio.h>
#define N 22

int main(void)
{
#if N == 22
    printf("N=22");
#else
    printf("N is undefined");
#endif
    return 0;
}
```

## 3. Директива #elif

С помощью директивы `#elif` можно проверять дополнительные условия:

```c
#include <stdio.h>
#define N 24

int main(void)
{
#if N == 22
    printf("N = 22");
#elif N == 24
    printf("N=24");
#else
    printf("N is undefined");
#endif
    return 0;
}
```

## 4. Директива #ifdef

С помощью директивы `#ifdef` можно проверять, определен ли идентификатор, и если он определен, вставлять в исходный код определенный текст:

```c
#include <stdio.h>
#define DEBUG

int main(void)
{
#ifdef DEBUG
    printf("Debug mode");
#endif
    return 0;
}
```

## 5. Директива #ifndef

Обратным действием обладает директива `#ifndef` — она включает текст, если идентификатор не определен:

```c
#include <stdio.h>
//#define DEBUG

int main(void)
{
#ifndef DEBUG
    printf("Production mode");
#else
    printf("Debug mode");
#endif
    return 0;
}
```

## 6. Оператор defined

Если нам одновременно надо проверить значения двух идентификаторов, то можно использовать специальный оператор `defined`:

```c
#include <stdio.h>
#define BETA
#define DEBUG

int main(void)
{
#if defined DEBUG && !defined BETA
    printf("debug mode; final version");
#elif defined DEBUG && defined BETA
    printf("debug mode; beta version");
#else
    printf("undefined mode");
#endif
    return 0;
}
```

## 7. Резюме

1. Условная компиляция: `#if`/`#elif`/`#else`/`#endif` включают код в зависимости от значения условного выражения.
2. `#ifdef` включает код, если идентификатор определен; `#ifndef` — если не определен.
3. Оператор `defined` позволяет комбинировать проверки: `#if defined DEBUG && !defined BETA`.
