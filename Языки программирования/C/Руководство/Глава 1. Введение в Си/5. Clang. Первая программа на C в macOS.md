## Clang. Первая программа на MacOS

Рассмотрим создание первой программы на MacOS с помощью компилятора Clang.

### Установка Clang

На MacOS для компиляции программ на языке Си по умолчанию используется компилятор Clang, который входит в состав Xcode Command Line Tools. Чтобы установить Xcode Command Line Tools, откройте терминал и введите следующую команду:

```
xcode-select --install
```

После выполнения этой команды откроется диалоговое окно с предложением установить инструменты. Нажмите "Установить" и следуйте инструкциям.

После завершения установки можно проверить, что Clang установлен, введя в терминале:

```
clang --version
```

### Создание первой программы

Создадим папку для исходных файлов и в ней файл hello.c:

```c
#include <stdio.h>
int main(void)
{
	printf("Hello World! \\n");
	return 0;
}
```

Для компиляции программы перейдем в терминале в каталог с файлом и введем команду:

```
clang hello.c -o hello
```

Параметр `-o hello` указывает имя выходного файла. Если не указать его, файл будет называться по умолчанию a.out.

Для запуска программы введите:

```
./hello
```

На консоль будет выведена строка "Hello World!".
