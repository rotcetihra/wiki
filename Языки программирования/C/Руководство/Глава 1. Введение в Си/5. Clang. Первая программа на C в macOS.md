## 1. Введение

В операционной системе macOS основной и официальной средой для разработки на C, C++ и Objective-C является компилятор **Clang** (в составе набора утилит **Apple Clang**).

Clang развивается в рамках инфраструктуры **LLVM** и глубоко интегрирован в экосистему Apple. Он обеспечивает высочайшую скорость компиляции, информативные сообщения об ошибках, полную поддержку архитектур Apple Silicon (ARM64) и Intel (x86_64), а также реализацию современных стандартов языка C (C17, C23).

> [!NOTE]
> Когда вы вызываете в терминале macOS команду `gcc`, операционная система по умолчанию запускает `clang` (символьную ссылку на Apple Clang). Поэтому Clang является стандартом по умолчанию для macOS.

## 2. Шаг 1. Установка инструментария (Xcode Command Line Tools)

Для компиляции программ на C в macOS **не обязательно** устанавливать весь тяжеловесный пакет Xcode из App Store. Достаточно установить легкий набор консольных инструментов разработчика — **Xcode Command Line Tools**.

1. Откройте встроенное приложение **Терминал** (нажмите `Cmd + Space` и введите _Терминал_).
    
2. Запустите команду установки:
    
```Bash
xcode-select --install
```

3. В появившемся системном диалоговом окне нажмите кнопку **Установить** и примите лицензионное соглашение.
    
4. Дождитесь завершения автоматического скачивания и установки компонентов.
    

### Проверка установки

Чтобы убедиться, что компилятор Clang готов к работе, введите в терминале:

```Bash
clang --version
```

Вывод терминала покажет актуальную версию **Apple Clang**:

```Plaintext
Apple clang version 15.x.x (или выше)
Target: arm64-apple-darwin23.x.x (для Apple Silicon) или x86_64-apple-darwin
Thread model: posix
InstalledDir: /Library/Developer/CommandLineTools/usr/bin
```

## 3. Шаг 2. Создание первой программы

1. Создайте в домашнем каталоге папку для ваших проектов и перейдите в неё:
    
    ```Bash
    mkdir -p ~/c_projects
    cd ~/c_projects
    ```
    
2. Создайте файл исходного кода `hello.c`. Для этого можно использовать консольные редакторы (`nano`, `vim`), встроенный `TextEdit` или современный редактор **Visual Studio Code**:
    
    ```Bash
    nano hello.c
    ```
    
3. Наберите или вставьте следующий код программы:
    
```C
#include <stdio.h>

int main(void)
{
    printf("Привет, macOS!\n");
    return 0;
}
```

4. В редакторе `nano` сохраните файл, нажав `Ctrl + O` -> `Enter`, затем выберите выход: `Ctrl + X`.
    

### Разбор структуры кода

- **`#include <stdio.h>`** — директива препроцессора, подключающая заголовочный файл `stdio.h`. Он содержит декларацию функции вывода текста `printf`.
    
- **`int main(void)`** — точка входа в программу на Си.
    
    - `int` указывает на то, что функция возвращает целочисленный статус завершения операционной системе.
        
    - `(void)` показывает, что функция не принимает никаких входных параметров.
        
- **`printf("Привет, macOS!\n");`** — осуществляет вывод строки на консоль терминала. Символ `\n` служит для переноса строки. В macOS вывод кириллицы в терминале UTF-8 поддерживается без дополнительных настроек.
    
- **`return 0;`** — завершает работу функции `main` и возвращает статус `0`, что традиционно сигнализирует операционной системе macOS об успешном завершении выполнения.
    

## 4. Шаг 3. Компиляция и запуск через Терминал

Компиляция исходного кода в бинарный исполняемый файл выполняется напрямую из терминала.

### 1. Компиляция по умолчанию

Если передать компилятору только имя исходного файла:

```Bash
clang hello.c
```

В текущей папке автоматически создастся исполняемый файл с именем по умолчанию — **`a.out`**.

Запустить его можно командой:

```Bash
./a.out
```

> [!WARNING]
> Префикс `./` указывает системе запустить исполняемый файл именно из текущей папки (в целях безопасности macOS не ищет бинарные файлы в текущем каталоге без явного указания пути).

### 2. Компиляция с явным указанием имени файла (Флаг `-o`)

Чтобы задать скомпилированному файлу понятное имя (например, `hello` или `app`), используйте флаг `-o`:

```Bash
clang hello.c -o hello
```

Теперь запустить скомпилированную программу можно так:

```Bash
./hello
```

**Результат выполнения:**

```Plaintext
Привет, macOS!
```

## 5. Шаг 4. Современные практики компиляции и флаги Clang

В современной профессиональной разработке под macOS рекомендуется указывать стандарты языка и включать режим строгой проверки кода компилятором:

```Bash
clang -Wall -Wextra -std=c17 hello.c -o hello
```

- **`-Wall -Wextra`** — включат подробный набор предупреждений Clang, помогающий найти ошибки на этапе сборки.
    
- **`-std=c17`** (или `-std=c23`) — явно указывает компилятору стандарт языка C.
    

### Однострочная компиляция и запуск

Скомпилировать файл и сразу запустить его при успешной сборке можно с помощью оператора `&&`:

```Bash
clang -Wall hello.c -o hello && ./hello
```

### Использование санитайзера памяти (AddressSanitizer)

Clang в macOS содержит эффективные встроенные инструменты анализа. Например, для отслеживания ошибок работы с памятью добавьте параметр `-fsanitize=address`:

```Bash
clang -fsanitize=address -g hello.c -o hello
```

## 6. Рекомендуемый инструментарий для macOS

- **Терминалы:** Стандартный macOS Terminal, **iTerm2** или **Ghostty**.
    
- **Редакторы кода:**
    
    - **Visual Studio Code** (с расширениями _C/C++ Extension Pack_ или _clangd_).
        
    - **CLion** от JetBrains (отличная IDE с глубокой интеграцией CMake и Clang).
        
    - **Xcode** (для полноценных проектов и системной разработки под macOS/iOS).
