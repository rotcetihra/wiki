## Локализация и кириллица в консоли

При выводе русского текста в консоль могут возникнуть проблемы с отображением кириллицы. Рассмотрим способы решения этой проблемы на разных платформах.

### Windows

Для вывода русского текста в консоль на Windows необходимо установить кодовую страницу UTF-8. Для этого в начале программы можно вызвать функцию `SetConsoleOutputCP` из заголовочного файла `<windows.h>`:

```c
#include <stdio.h>
#include <windows.h>

int main(void)
{
    SetConsoleOutputCP(CP_UTF8);
    printf("Привет, мир!\n");
    return 0;
}
```

### Linux

В Linux по умолчанию используется кодировка UTF-8, поэтому проблемы с выводом кириллицы обычно не возникает. Но если вдруг возникли проблемы, можно установить локаль:

```c
#include <stdio.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");
    printf("Привет, мир!\n");
    return 0;
}
```

### macOS

На macOS также по умолчанию используется UTF-8, и проблемы с кириллицей обычно не возникают.

### Универсальный подход

Для кроссплатформенной программы можно использовать следующий подход:

```c
#include <stdio.h>

#ifdef _WIN32
#include <windows.h>
#endif

int main(void)
{
#ifdef _WIN32
    SetConsoleOutputCP(CP_UTF8);
#endif
    printf("Привет, мир!\n");
    return 0;
}
```
