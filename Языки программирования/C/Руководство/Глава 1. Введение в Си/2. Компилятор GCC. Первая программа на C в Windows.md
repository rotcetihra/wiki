## 1. Введение

Для разработки на языке C под операционную систему Windows требуется компилятор, преобразующий исходный код на C в исполняемый файл (`.exe`). Одним из самых популярных, стандартизированных и свободных компиляторов является **GCC (GNU Compiler Collection)**.

В современном окружении Windows 10 и 11 наиболее актуальным и рекомендуемым способом установки GCC является использование платформы **MSYS2** со средой **UCRT64** (Universal C Runtime). Это обеспечивает современную совместимость с системными библиотеками Windows, правильную работу с кодировкой UTF-8 и поддержку свежих стандартов языка (включая C17 и C23).

## 2. Шаг 1. Установка компилятора GCC через MSYS2

### 1. Скачивание и установка MSYS2

1. Перейдите на официальный сайт проекта [msys2.org](https://www.msys2.org/).
    
2. Скачайте актуальный инсталлятор (например, `msys2-x86_64-latest.exe`).
    
3. Запустите программу установки. По умолчанию MSYS2 устанавливается в каталог `C:\msys64`. Рекомендуется оставить этот путь без изменений.
    
4. Завершите установку и нажмите **Finish** (Завершить). На экране появится консольное окно терминала MSYS2.
    

> [!NOTE]
> Если окно не открылось автоматически, его можно запустить через меню «Пуск» (набрав _MSYS2 UCRT64_) или открыв файл `C:\msys64\ucrt64.exe`.

### 2. Установка пакета GCC

MSYS2 использует менеджер пакетов `pacman`. Чтобы установить актуальный набор компиляторов GCC для среды UCRT64, введите в открывшемся терминале MSYS2 команду:

```Bash
pacman -S mingw-w64-ucrt-x86_64-gcc
```

На запрос подтверждения нажмите `Y` и клавишу `Enter`.

После завершения установки в каталоге `C:\msys64\ucrt64\bin` появится исполняемый файл компилятора `gcc.exe`.

_(Опционально)_ Для полноценного набора системного разработчика (включающего отладчик `gdb` и утилиту сборки `make`) можно также установить пакет:

```Bash
pacman -S mingw-w64-ucrt-x86_64-gdb mingw-w64-ucrt-x86_64-make
```

## 3. Шаг 2. Настройка системных переменных среды (PATH)

Чтобы запускать компилятор `gcc` из любой папки через обычную Командную строку (CMD), PowerShell или встроенный терминал VS Code, необходимо добавить путь к нему в переменные среды Windows.

1. Нажмите клавиши `Win + R`, введите `sysdm.cpl` и нажмите `Enter` (либо найдите в поиске Windows _«Изменение переменных среды текущего пользователя»_).
    
2. В появившемся окне перейдите на вкладку **Дополнительно** и нажмите кнопку **Переменные среды...**.
    
3. В секции **Переменные среды пользователя** найдите переменную `Path` (или `PATH`), выделите её и нажмите **Изменить...**.
    
4. Нажмите кнопку **Создать** и вставьте путь к компилятору:
    
```Plaintext
C:\msys64\ucrt64\bin
```
    
5. Нажмите **ОК** во всех окнах, чтобы сохранить изменения.
    

### Проверка установки

Откройте **Командную строку (cmd)** или **PowerShell** и введите команду:

```PowerShell
gcc --version
```

Если настройка выполнена верно, консоль выведет информацию о версии компилятора GCC:

```Plaintext
gcc.exe (Rev..., Built by MSYS2 project) 13.x.x (или выше)
Copyright (C) 2023 Free Software Foundation, Inc.
```

## 4. Шаг 3. Написание первой программы на C

Для написания кода можно использовать любой удобный текстовый редактор: **Visual Studio Code**, **CLion**, **Sublime Text** или встроенный **Блокнот**.

1. Создайте на диске папку для ваших проектов, например: `C:\c_projects`.
    
2. В этой папке создайте файл `hello.c`.

Откройте файл `hello.c` и введите следующий код:

```C
#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```

### Разбор кода по строкам

- **`#include <stdio.h>`** — директива препроцессора, подключающая заголовочный файл стандартного ввода-вывода `stdio.h`. Он содержит объявление функции `printf`.
    
- **`int main(void)`** — точка входа в программу. Любое приложение на Си начинается с выполнения функции `main`.
    
    - `int` указывает, что функция возвращает целочисленный код завершения операционной системе.
        
    - `(void)` означает, что функция не принимает входных параметров.
        
- **`{ ... }`** — фигурные скобки выделяют тело функции `main`.
    
- **`printf("Hello, World!\n");`** — функция вывода строки на консоль. Символ `\n` означает перевод на новую строку.
    
- **`return 0;`** — завершение работы функции `main`. Возврат нуля (`0`) традиционно информирует операционную систему об успешном завершении программы.
    

> [!NOTE] Совет по кириллице в Windows
> 
> Если вы хотите выводить текст на русском языке в стандартной консоли Windows (CMD), добавьте в начало программы настройку кодировки UTF-8 через функцию `SetConsoleOutputCP(65001)` из заголовочного файла `<windows.h>`:

```C
#include <stdio.h>
#include <windows.h>

int main(void)
{
    SetConsoleOutputCP(65001); // Установка кодировки UTF-8 для консоли
    printf("Привет, мир!\n");
    return 0;
}
```

## 5. Шаг 4. Компиляция и запуск программы

1. Откройте Командную строку (CMD), PowerShell или Терминал Windows.
    
2. Перейдите в папку с вашей программой с помощью команды `cd`:
    
```PowerShell
cd C:\c_projects
```
    
3. Выполните компиляцию файла `hello.c`:
    
```PowerShell
gcc hello.c -o hello.exe
```
    
- Параметр `-o hello.exe` задает имя итогового исполняемого файла. Если опустить этот флаг, по умолчанию создастся файл `a.exe`.
        
4. Запустите скомпилированную программу:
    
    - **В Командной строке (CMD):**
        
        ```CMD
        hello.exe
        ```
        
    - **В PowerShell / Терминале:**
        
        ```PowerShell
        .\hello.exe
        ```
        

На экране появится вывод:

```Plaintext
Hello, World!
```

## 6. Современные практики компиляции (флаги GCC)

В профессиональной разработке на C рекомендуется всегда компилировать код с включенным выводом предупреждений и указанием стандарта языка:

```CMD
gcc -Wall -Wextra -std=c17 hello.c -o hello.exe
```

- **`-Wall -Wextra`** — включает подробные предупреждения о возможных ошибках и неоптимальном коде.
    
- **`-std=c17`** (или `-std=c23`) — явно указывает компилятору использовать актуальный стандарт языка C.
    

### Компиляция и запуск одной командой

Чтобы скомпилировать и сразу запустить программу, можно объединить команды:

- **В Командной строке (CMD):**
    
    ```CMD
    gcc hello.c -o hello.exe && hello.exe
    ```
    
- **В PowerShell:**
    
    ```PowerShell
    gcc hello.c -o hello.exe; if ($?) { .\hello.exe }
    ```
    

## 7. Рекомендации по настройке Visual Studio Code

Для комфортной разработки в **VS Code**:

1. Установите расширение **C/C++ Extension Pack** от Microsoft.
    
2. Для быстрой сборки и запуска кода установите расширение **Code Runner**.
    
3. В настройках Code Runner добавьте поддержку актуальных флагов компилятора (`gcc -std=c17 -Wall`).
    

Теперь ваша рабочая среда полностью настроена для изучения и разработки приложений на языке C!
