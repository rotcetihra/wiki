## 1. Введение

**Clang** — это современный, высокопроизводительный компилятор для языков C, C++ и Objective-C, разрабатываемый в рамках инфраструктуры **LLVM**. В индустрии разработки на C Clang завоевал огромную популярность благодаря:

- **Исключительным диагностическим сообщениям:** Clang выводит понятные, точные и информативные ошибки и предупреждения с указанием конкретного места в коде.
    
- **Высокой скорости компиляции:** Архитектура LLVM обеспечивает быструю сборку проектов.
    
- **Полной поддержке современных стандартов:** Отличная реализация стандартов C17, C23 и экспериментальных возможностей C2y.
    
- **Встроенным санитайзерам:** Простая интеграция инструментов поиска ошибок работы с памятью (AddressSanitizer, MemorySanitizer).
    

Рассмотрим процесс установки компилятора Clang в Windows и сборку первой программы.

## 2. Шаг 1. Установка компилятора Clang (LLVM)

В Windows установить Clang можно несколькими удобными способами: с помощью официального инсталлятора, через системный менеджер пакетов `winget` или в составе среды MSYS2.

### Важное предварительное условие (C Runtime)

Компилятор Clang использует системную библиотеку C (CRT) и заголовочные файлы (такие как `stdio.h`). В Windows компилятор Clang по умолчанию ищет заголовочные файлы **Windows SDK** или **MSVC**.

> [!NOTE] Рекомендация
> Если на вашем компьютере ещё не установлена **Visual Studio** или компонент **Build Tools for Visual Studio** (с рабочей нагрузкой _«Разработка классических приложений на C++»_), установить их можно бесплатно с официального сайта Microsoft. Альтернативно Clang можно использовать поверх среды **MSYS2**.

### Способ 1. Официальный инсталлятор LLVM (Рекомендуемый)

1. Перейдите в официальный репозиторий проекта LLVM на GitHub в раздел релизов:
    
    [github.com/llvm/llvm-project/releases](https://github.com/llvm/llvm-project/releases/)
    
2. Найдите последний стабильный релиз LLVM (например, LLVM 18.x / 19.x или свежее).
    
3. В секции **Assets** (при необходимости нажмите _Show all assets_) скачайте установочный файл для 64-битной Windows:
    
    `LLVM-XX.X.X-win64.exe`
    
4. Запустите инсталлятор и следуйте шагам мастера:
    
    - На шаге выбора опций обязательно отметьте пункт: **«Add LLVM to the system PATH for current user»** (или _for all users_). Это автоматически добавит путь к `clang.exe` в системные переменные среды.
        
    - Путь установки по умолчанию: `C:\Program Files\LLVM`.
        
5. Нажмите **Install** (Установить) и завершите процесс.
    

### Способ 2. Быстрая установка через менеджер пакетов `winget`

В Windows 10 и 11 можно установить LLVM одной командой в консоли без скачивания файлов вручную.

Откройте **PowerShell** или **Командную строку** от имени администратора и введите:

```PowerShell
winget install LLVM.LLVM
```

После завершения установки перезапустите терминал.

## 3. Шаг 2. Проверка установки

Чтобы убедиться, что компилятор Clang установлен и путь к нему доступен в системе, откройте новый терминал (CMD или PowerShell) и введите команду:

```CMD
clang --version
```

В ответ появится подробная информация о компиляторе:

```Plaintext
clang version 18.1.8 (или выше)
Target: x86_64-pc-windows-msvc
Thread model: posix
InstalledDir: C:\Program Files\LLVM\bin
```

Если консоль выдает ошибку _«clang не является внутренней или внешней командой»_, убедитесь, что при установке была выбрана опция добавления в `PATH`, или добавьте путь `C:\Program Files\LLVM\bin` в переменные среды вручную.

## 4. Шаг 3. Написание первой программы на C

Создадим простую программу, выводящую приветствие в консоль.

1. Создайте папку для проектов на диске, например: `C:\c_projects`.
    
2. Внутри папки создайте файл с именем `hello.c`.
    
3. Откройте `hello.c` в любом текстовом редакторе (Visual Studio Code, Notepad++, CLion или Блокнот) и введите код:
    

```C
#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```

### Разбор кода

- **`#include <stdio.h>`** — подключает заголовочный файл стандартной библиотеки ввода-вывода, содержащий объявление функции `printf`.
    
- **`int main(void)`** — главная функция, точка входа в программу.
    
    - `int` указывает на то, что функция возвращает целочисленный статус выполнения операционной системе.
        
    - `(void)` означает отсутствие входных аргументов.
        
- **`printf("Hello, World!\n");`** — выводит текст в консоль. Символ `\n` управляет переходом на новую строку.
    
- **`return 0;`** — сигнально завершает программу со статусом `0` (успешное выполнение).
    

> [!NOTE] Работа с кириллицей в Windows
> 
> Чтобы корректно отображать русский текст в стандартной консоли Windows при компиляции Clang, добавьте настройку кодировки UTF-8 через Windows API:

```C
#include <stdio.h>
#include <windows.h>

int main(void)
{
    SetConsoleOutputCP(65001); // Включение кодировки UTF-8 для вывода
    printf("Привет от компилятора Clang!\n");
    return 0;
}
```

## 5. Шаг 4. Компиляция и запуск через терминал

1. Откройте Командную строку (CMD) или PowerShell.
    
2. Перейдите в папку с проектом:
    
    ```CMD
    cd C:\c_projects
    ```
    
3. Выполните компиляцию исходного файла `hello.c`:
    
    ```CMD
    clang hello.c -o hello.exe
    ```
    
- Флаг `-o hello.exe` задает имя выходящего исполняемого файла. Если опустить этот параметр, Clang создаст файл с именем `a.exe`.
        
4. Запустите скомпилированную программу:
    
    - **В Командной строке (CMD):**
        
        ```CMD
        hello.exe
        ```
        
    - **В PowerShell / Терминале Windows:**
        
        ```PowerShell
        .\hello.exe
        ```
        

**Результат выполнения в консоли:**

```Plaintext
Hello, World!
```

## 6. Современные практики разработки и полезные флаги Clang

Одно из главных преимуществ Clang — развитые средства диагностики кода. При компиляции рекомендуется использовать следующие флаги:

```CMD
clang -Wall -Wextra -std=c17 hello.c -o hello.exe
```

- **`-Wall -Wextra`** — активирует широкий спектр предупреждений компилятора, помогающих обнаружить потенциальные баги и некорректную работу с памятью на этапе сборки.
    
- **`-std=c17`** (или `-std=c23`) — явно указывает используемый стандарт языка C.
    

### Однострочный запуск (компиляция + выполнение)

Чтобы не вводить команды раздельно, используйте связку команд:

- **Для Командной строки (CMD):**
    
    ```CMD
    clang -Wall hello.c -o hello.exe && hello.exe
    ```
    
- **Для PowerShell:**
    
    ```PowerShell
    clang -Wall hello.c -o hello.exe; if ($?) { .\hello.exe }
    ```
    

### Использование санитайзера памяти (AddressSanitizer)

Clang в Windows поддерживает поиск утечек памяти и выходов за пределы массива «из коробки». Добавьте флаг `-fsanitize=address`:

```CMD
clang -fsanitize=address -g hello.c -o hello.exe
```

## 7. Настройка окружения в Visual Studio Code (`clangd`)

Для идеального опыта разработки на C в **VS Code** рекомендуется использовать официальное расширение **clangd** вместо стандартного C/C++ Extension Pack:

1. Откройте панель расширений в VS Code (`Ctrl + Shift + X`).
    
2. Найдите и установите расширение **clangd** (от LLVM).
    
3. `clangd` предоставляет подцветку синтаксиса, мгновенный автодополняющий ввод, рефакторинг и быстрые подсказки об ошибках на базе движка Clang прямо во время печати кода.
