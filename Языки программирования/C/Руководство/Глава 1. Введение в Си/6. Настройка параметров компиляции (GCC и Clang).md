## Настройка параметров компиляции

При компиляции программ на Си с помощью компиляторов GCC и Clang можно задавать различные параметры, которые влияют на процесс компиляции и результат.

### Основные флаги

| Флаг | Описание |
|---|---|
| `-o <имя>` | Задает имя выходного файла |
| `-c` | Компилирует только в объектный файл (не связывает) |
| `-Wall` | Включает все предупреждения |
| `-Wextra` | Дополнительные предупреждения |
| `-O0`, `-O1`, `-O2`, `-O3` | Уровень оптимизации (от отключенной до максимальной) |
| `-g` | Включает отладочную информацию |
| `-std=c11`, `-std=c17`, `-std=c23` | Указывает стандарт языка Си |
| `-I<путь>` | Добавляет путь поиска заголовочных файлов |
| `-L<путь>` | Добавляет путь поиска библиотек |
| `-l<библиотека>` | Подключает библиотеку |

### Примеры использования

Компиляция с включением всех предупреждений и отладочной информацией:

```
gcc -Wall -g hello.c -o hello
```

Компиляция с оптимизацией уровня O2:

```
gcc -O2 hello.c -o hello
```

Компиляция с указанием стандарта C11:

```
gcc -std=c11 hello.c -o hello
```

Компиляция с подключением математической библиотеки:

```
gcc hello.c -lm -o hello
```

### Множественная компиляция

Можно компилировать несколько файлов одновременно:

```
gcc main.c utils.c -o program
```

Или компилировать каждый файл отдельно в объектный, а затем связывать:

```
gcc -c main.c
gcc -c utils.c
gcc main.o utils.o -o program
```
