# Глава 13. Взаимодействие с кодом Python

**Дата написания:** 04.08.2026

## 1. Обзор главы

Глава 14 — взаимодействие программ на C с кодом на Python. В ней рассматривается встраиваемый интерпретатор Python (Embedded Python): подключение заголовочного файла `Python.h`, инициализация интерпретатора, выполнение кода Python из программы на C, компиляция таких программ на Windows и Linux, а также выполнение внешних файлов со скриптами Python.
