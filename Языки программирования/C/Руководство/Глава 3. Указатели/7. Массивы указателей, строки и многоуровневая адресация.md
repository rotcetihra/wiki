## 1. Введение

Указатели сами по себе представляют значения, которые можно хранить в массивах, — так получаются массивы указателей. Кроме того, указатели могут указывать на другие указатели (многоуровневая адресация). Рассмотрим эти конструкции в данной теме.

## 2. Массивы указателей

Массив указателей определяется одним из трех способов:

```c
тип *имя_массива [размер];
тип *имя_массива [] = инициализатор;
тип *имя_массива [размер] = инициализатор;
```

Используем все эти способы:

```c
int array[] = {1, 2, 3, 4};
int *p1[3];
int *p2[] = { &array[1], &array[2], &array[0] };
int *p3[3] = { &array[3], &array[1], &array[2] };
```

Массив указателей `p1` состоит из трех элементов, но он не инициализирован и содержит неопределенные значения.

Массивы `p2` и `p3` в качестве элементов хранят адреса на элементы массива `array`.

Выведем на консоль значения, на которые ссылаются указатели:

```c
#include <stdio.h>

int main(void)
{
    int array[] = {1, 2, 3, 4};
    int *p[] = { &array[1], &array[2], &array[0] };

    for (int i = 0; i < 3; i++)
    {
        printf("%d", *p[i]);
    }
    return 0;
}
```

Здесь выражение `*p[i]` означает, что мы сначала обращаемся к i-му адресу в массиве `p`, а потом применяем операцию разыменования для получения данных по этому адресу. В итоге на консоль будет выведено:

```
231
```

Вместо `*p[i]` можно написать `**(p + i)`:

- `p + i` — к адресу в указателе `p` прибавляем число `i` и перемещаемся по указателям в массиве `p`;
- `*(p + i)` — разыменовываем i-й указатель в массиве и получаем адрес одного из элементов массива `array`;
- `**(p + i)` — получаем значение по адресу элемента массива `array`.

```c
#include <stdio.h>

int main(void)
{
    int array[] = {1, 2, 3, 4};
    int *p[] = { &array[1], &array[2], &array[0] };

    for (int i = 0; i < 3; i++)
    {
        printf("%d", **(p + i));
    }
    return 0;
}
```

## 3. Указатель на массив

От массива указателей следует отличать указатель на массив:

```c
int array[] = {11, 12, 13};
int (*pa)[3] = &array;  // указатель на массив с 3 элементами int
```

Переменная `pa` определена как указатель на массив из трех элементов типа `int` и инициализируется адресом массива `array`, который имеет 3 элемента. Размер массива является частью типа. Имя переменной заключается в скобки. Формализовать определение указателя на массив можно так:

```
тип_элементов_массива (*имя_переменной_указателя)[количество_элементов];
```

Если присвоить переменной адрес массива с другим размером, результат неопределен:

```c
int array2[] = {11, 12, 13, 14, 15};
int (*pa)[3] = &array2;  // несоответствие размеров
```

Например, компилятор GCC пропустит такое определение, но при этом выдаст предупреждение.

Можно не указывать количество элементов массива:

```c
int array2[] = {11, 12, 13, 14, 15};
int (*pa)[] = &array2; // указатель типа int (*)[]
```

> [!WARNING]
> В этом случае тип указателя — на массив неполного типа, и размер не «вычисляется автоматически»: обращаться к элементам через такой указатель без явного приведения (`int (*)[5]`) нельзя. Конструкция полезна разве что как промежуточный шаг приведения.

Что можно делать с указателем на массив? Естественно, манипулировать самим массивом, на который указывает указатель. Так, операция разыменования позволяет получить адрес первого элемента массива, и далее можно обращаться к элементам:

```c
int array[] = {11, 12, 13};
int (*pa)[3] = &array;  // указатель на массив

printf("array[0] = %d\n", (*pa)[0]);
printf("array[1] = %d\n", (*pa)[1]);
printf("array[2] = %d\n", (*pa)[2]);
```

Указатели на массив удобно использовать для обращения к подмассивам многомерных массивов:

```c
int array[3][2] = {{11, 12}, {13, 14}, {15, 16}};
int (*pa)[2] = array + 1;  // указатель на массив с двумя элементами

for (size_t i = 0; i < sizeof(*pa) / sizeof(*pa[0]); i++)
{
    printf("%d, ", (*pa)[i]);
}
printf("\n");
```

Здесь многомерный массив `array` состоит из 3 элементов, каждый из которых представляет массив из двух элементов. Указатель `pa` указывает на массив из двух элементов, и в данном случае ему присваивается адрес второго подмассива:

```c
int (*pa)[2] = array + 1;
```

То есть `pa` представляет подмассив `{13, 14}`.

Сравним указатель на массив и массив указателей:

```c
int array[] = {11, 12, 13};
int (*pa)[3] = &array;                // указатель на массив
int *pb[] = { &array[1], &array[2], &array[0] }; // массив указателей

// перебираем массив через указатель на массив
printf("Pointer to Array\n");
for (size_t i = 0; i < sizeof(*pa) / sizeof(*pa[0]); i++)
{
    printf("%d\n", (*pa)[i]);
}

// перебираем массив указателей
printf("Array of Pointers\n");
for (size_t i = 0; i < sizeof(pb) / sizeof(pb[0]); i++)
{
    printf("%d\n", *pb[i]);
}
```

## 4. Массивы строк

Соответственно, если указатель типа `char` можно представить в виде строки, то массив указателей типа `char` представляет собой массив строк:

```c
#include <stdio.h>

int main(void)
{
    char *fruit[] = {"apricot", "apple", "banana", "lemon", "orange"};
    for (int i = 0; i < 5; i++)
    {
        printf("%s \n", fruit[i]);
    }
    return 0;
}
```

Массив указателей `fruit` хранит пять строк — фактически пять адресов, по которым размещены начальные символы каждой строки. Результат работы программы:

```
apricot
apple
banana
lemon
orange
```

Также можно было бы написать:

```c
char *fruit[] = {"apricot", "apple", "banana", "lemon", "orange"};
for (int i = 0; i < 5; i++)
{
    printf("%s \n", *(fruit + i));
}
```

## 5. Указатели на указатели

Кроме обычных указателей в языке Си можно создавать указатели на другие указатели. Если указатель хранит адрес переменной, то указатель на указатель хранит адрес указателя, на который он указывает. Такие ситуации называются **многоуровневой адресацией**.

Например:

```c
int **ptr;
```

Переменная `ptr` представляет указатель на указатель на объект типа `int`. Две звездочки в определении говорят о том, что мы имеем дело с двухуровневой адресацией:

```c
#include <stdio.h>

int main(void)
{
    int x = 22;
    int *px = &x;       // указатель px хранит адрес переменной x
    int **ppx = &px;    // указатель ppx хранит адрес указателя px

    printf("Address of px: %p \n", (void *)ppx);
    printf("Address of x: %p \n", (void *)*ppx);
    printf("Value of x: %d \n", **ppx);
    return 0;
}
```

Указатель `ppx` хранит адрес указателя `px`. Поэтому через выражение `*ppx` можно получить значение, которое хранится в указателе `px`, — адрес переменной `x`. А через выражение `**ppx` — значение по адресу из `px`, то есть значение переменной `x`.

## 6. Резюме

1. Массив указателей — `int *p[]` — хранит адреса; доступ к значениям — `*p[i]` или `**(p + i)`.
2. Указатель на массив — `int (*pa)[3]` — хранит адрес массива целиком; размер массива входит в тип. Удобен для работы с подмассивами многомерных массивов.
3. Массив `char *fruit[]` — массив строк: каждый элемент — адрес первого символа строки.
4. Указатель на указатель (`int **`) дает двухуровневую адресацию: `*ppx` — адрес переменной, `**ppx` — значение.
