# Арифметика указателей

## 1. Введение

К указателям могут применяться некоторые арифметические операции: сложение, вычитание, инкремент, декремент. Однако сами операции производятся немного иначе, чем с числами, и многое здесь зависит от типа указателя. К указателю можно прибавлять целое число и вычитать из него целое число. Кроме того, можно вычитать из одного указателя другой указатель.

## 2. Инкремент и декремент

Рассмотрим операции инкремента и декремента на примере указателя на объект типа `int`:

```c
#include <stdio.h>

int main(void)
{
    int n = 10;

    int *ptr = &n;
    printf("address=%p \t value=%d \n", (void *)ptr, *ptr);

    ptr++;
    printf("address=%p \t value=%d \n", (void *)ptr, *ptr);

    ptr--;
    printf("address=%p \t value=%d \n", (void *)ptr, *ptr);

    return 0;
}
```

Операция инкремента `++` увеличивает значение на единицу. В случае с указателем увеличение на единицу означает увеличение адреса, который хранится в указателе, на размер типа указателя. Так как в данном случае указатель на тип `int`, а размер объектов `int` на большинстве архитектур равен 4 байтам, увеличение указателя типа `int` на единицу означает увеличение значения указателя на 4.

Возможный консольный вывод:

```
address=0060FEA8	value=10
address=0060FEAC	value=6356652
address=0060FEA8	value=10
```

После инкремента значение указателя увеличилось на 4: с `0060FEA8` до `0060FEAC`. А после декремента, то есть уменьшения на единицу, указатель получил предыдущий адрес в памяти.

Фактически увеличение на единицу означает, что мы хотим перейти к следующему объекту в памяти, который находится за текущим и на который указывает указатель. Уменьшение на единицу означает переход назад, к предыдущему объекту в памяти.

После изменения адреса мы можем получить значение, которое находится по новому адресу, однако это значение может быть неопределенным, как показано в консольном выводе программы выше.

Величина сдвига зависит от размера типа. Для указателя типа `int` увеличение/уменьшение на единицу означает изменение адреса на 4, для указателя типа `short` — на 2, а для указателя типа `char` — на 1:

```c
#include <stdio.h>

int main(void)
{
    double d = 10.6;
    double *pd = &d;
    printf("Pointer pd: address=%p \n", (void *)pd);
    pd++;
    printf("Pointer pd: address=%p \n", (void *)pd);

    char c = 'N';
    char *pc = &c;
    printf("Pointer pc: address=%p \n", (void *)pc);
    pc++;
    printf("Pointer pc: address=%p \n", (void *)pc);

    return 0;
}
```

Возможный консольный вывод:

```
Pointer pd: address=0060FEA0
Pointer pd: address=0060FEA8
Pointer pc: address=0060FE9F
Pointer pc: address=0060FEA0
```

Увеличение на единицу указателя типа `double` дало увеличение хранимого в нем адреса на 8 (размер объекта `double` — 8 байт), а увеличение на единицу указателя типа `char` — на 1 (размер типа `char` — 1 байт).

## 3. Сложение и вычитание чисел

Аналогично указатель изменяется при прибавлении или вычитании не единицы, а любого другого числа:

```c
#include <stdio.h>

int main(void)
{
    double d = 10.6;
    double *pd = &d;
    printf("Pointer pd: address=%p \n", (void *)pd);
    pd = pd + 2;    // перемещаем указатель вперед на 2 значения double (2 * 8 = 16 байт)
    printf("Pointer pd: address=%p \n", (void *)pd);

    char c = 'N';
    char *pc = &c;
    printf("Pointer pc: address=%p \n", (void *)pc);
    pc = pc - 3;        // перемещаем указатель назад на 3 значения char (3 * 1 = 3 байта)
    printf("Pointer pc: address=%p \n", (void *)pc);

    return 0;
}
```

Добавление к указателю типа `double` числа 2:

```c
pd = pd + 2;
```

означает, что мы хотим перейти на два объекта `double` вперед, что подразумевает изменение адреса на 2 * 8 = 16 байт.

Вычитание из указателя типа `char` числа 3:

```c
pc = pc - 3;
```

означает, что мы хотим перейти на три объекта `char` назад, что подразумевает изменение адреса на 3 * 1 = 3 байта.

Возможный консольный вывод:

```
Pointer pd: address=0060FEA0
Pointer pd: address=0060FEB0
Pointer pc: address=0060FE9F
Pointer pc: address=0060FE9C
```

## 4. Разность двух указателей

В отличие от сложения, операция вычитания может применяться не только к указателю и целому числу, но и к двум указателям одного типа:

```c
#include <stdio.h>

int main(void)
{
    int a = 10;
    int b = 23;
    int *pa = &a;
    int *pb = &b;
    ptrdiff_t c = pa - pb;  // разница между адресами

    printf("pa=%p \n", (void *)pa);
    printf("pb=%p \n", (void *)pb);
    printf("c=%lld \n", c);

    return 0;
}
```

Консольный вывод в одном из случаев:

```
pa=0060FEA0
pb=0060FE9C
c=1
```

Результатом разности двух указателей является «расстояние» между ними — количество значений типа указателя (в примере выше — типа `int`), которые могут поместиться между этими двумя указателями. В случае выше адрес из первого указателя на 4 больше, чем адрес из второго указателя (`0x0060FE9C + 4 = 0x0060FEA0`). Так как размер одного объекта `int` равен 4 байтам, расстояние между указателями равно `(0x0060FEA0 - 0x0060FE9C) / 4 = 1`.

Расстояние между указателями представляет тип `ptrdiff_t`.

> [!NOTE]
> Тип `ptrdiff_t` — псевдоним знакового целого типа, размер которого зависит от платформы: на 64-разрядном Linux это `long`, на 64-разрядной Windows — `long long` (в обоих случаях 8 байт). Для вывода значений `ptrdiff_t` используется спецификатор `%td`.

Или другой пример — нахождение расстояния между элементами массива:

```c
#include <stdio.h>

int main(void)
{
    int arr[64];
    int *ptr1 = &arr[10];
    int *ptr2 = &arr[40];
    ptrdiff_t dist = ptr2 - ptr1; // 30

    printf("dist=%td \n", dist);

    return 0;
}
```

Здесь находим разницу между указателями на 10-й и 40-й элементы массива. Расстояние будет равно 30 — 30 элементам `int`. Чтобы получить расстояние в байтах, надо умножить расстояние на размер типа указателя.

## 5. Операции с указателем и со значением по адресу

При работе с указателями надо отличать операции с самим указателем и операции со значением по адресу, на который указывает указатель:

```c
int a = 10;
int *pa = &a;
int b = *pa + 20;   // операция со значением, на которое указывает указатель
pa++;               // операция с самим указателем

printf("b=%d \n", b);   // 30
```

Через операцию разыменования `*pa` получаем значение, на которое указывает указатель, то есть число 10, и выполняем сложение. Это обычная операция сложения между двумя числами, так как выражение `*pa` представляет число.

Но есть особенности с операциями инкремента и декремента: операции `*`, `++` и `--` имеют одинаковый приоритет, и при размещении рядом выполняются справа налево.

Выполним постфиксный инкремент:

```c
int a = 10;
int *pa = &a;
printf("pa: address=%p \t value=%d \n", (void *)pa, *pa);
int b = *pa++;      // инкремент адреса указателя

printf("b: value=%d \n", b);
printf("pa: address=%p \t value=%d \n", (void *)pa, *pa);
```

В выражении `b = *pa++;` сначала к указателю прибавляется единица (к адресу добавляется 4, так как указатель типа `int`). Затем, так как инкремент постфиксный, с помощью операции разыменования возвращается значение, которое было до инкремента, — то есть число 10. Это число и присваивается переменной `b`:

```
pa: address=0060FEA4	value=10
b: value=10
pa: address=0060FEA8	value=6356648
```

Изменим выражение:

```c
b = (*pa)++;
```

Скобки изменяют порядок операций. Здесь сначала выполняется операция разыменования и получение значения, затем это значение увеличивается на 1 — теперь по адресу в указателе находится число 11. И так как инкремент постфиксный, переменная `b` получает значение, которое было до инкремента, то есть опять число 10. В отличие от предыдущего случая все операции производятся над значением по адресу, но не над самим указателем:

```
pa: address=0060FEA4	value=10
b: value=10
pa: address=0060FEA4	value=11
```

Аналогично будет с префиксным инкрементом:

```c
b = ++*pa;
```

Сначала с помощью операции разыменования получаем значение по адресу из указателя `pa`, к этому значению прибавляется единица. Теперь значение по адресу, который хранится в указателе, равно 11, затем результат операции присваивается переменной `b`:

```
pa: address=0060FEA4	value=10
b: value=11
pa: address=0060FEA4	value=11
```

Изменим выражение:

```c
b = *++pa;
```

Теперь сначала изменяется адрес в указателе, затем по этому адресу получаем значение и присваиваем его переменной `b`. Полученное значение в этом случае может быть неопределенным:

```
pa: address=0060FEA4	value=10
b: value=6356648
pa: address=0060FEA8	value=6356648
```

> [!WARNING]
> Запись `*pa++` эквивалентна `*(pa++)`: сначала сдвигается сам указатель, а потом разыменовывается его прежнее значение. Это частый источник ошибок — убедитесь, что инкремент применяется именно к тому, что нужно.

## 6. Арифметика указателей на void

Особо следует отметить работу с указателями на тип `void`, потому что `void` — неполный тип (incomplete type), и компилятор не может узнать его размер. За указателем на `void` может скрываться что угодно. Посмотрим на примере:

```c
#include <stdio.h>

int main(void)
{
    int num1 = 11;
    int num2 = 12;
    int num3 = 13;
    int num4 = 14;
    void *p_num = &num1;
    printf("*p_num: %d\n", *(int *)(p_num + 8));

    return 0;
}
```

Здесь определено 4 числа типа `int`. Поскольку значения помещаются в стек, в памяти они будут располагаться последовательно:

|**Переменная**|**Условный адрес в памяти**|
|---|---|
|`int num1 = 11`|0xff00|
|`int num2 = 12`|0xff04|
|`int num3 = 13`|0xff08|
|`int num4 = 14`|0xff0c|

Адреса условны, но суть в том, что значения располагаются по порядку, и адрес каждого последующего отличается от предыдущего на 4 (размер типа `int`).

Переменная `p_num` представляет указатель на тип `void` и указывает на адрес переменной `num1`:

```c
void *p_num = &num1;
```

При выводе на консоль мы прибавляем к этому указателю 8, преобразуем его в указатель на `int` и разыменовываем для получения значения:

```c
printf("*p_num: %d\n", *(int *)(p_num + 8));
```

Какой будет результат программы? В реальности все зависит от конкретного компилятора. GCC и Clang рассматривают размер типа `void` как 1. Соответственно выражение `p_num + 8` увеличит значение указателя на 8, то есть передвинет его на 8 байт вперед — на адрес переменной `num3`:

```
gcc test.c -o test && ./test
*p_num: 13
```

Вроде все работает без ошибок. Но формально `void` остается неполным типом, который не имеет размера. Если скомпилировать ту же программу с флагом `-pedantic`, который выводит потенциальные проблемы, то появится предупреждение:

```
gcc -pedantic test.c -o test && ./test
test.c: In function 'main':
test.c:11:43: warning: pointer of type 'void *' used in arithmetic [-Wpointer-arith]
   11 |     printf("*p_num: %d\n", *(int*)(p_num+8));
      |                                           ^
*p_num: 13
```

Программа по-прежнему работает, но мы видим предупреждение. Это конкретная версия GCC (в данном случае GCC 13), а как поведет себя конкретный компилятор или даже его конкретная версия — неизвестно. Поэтому если с указателем на `void` надо выполнить арифметические операции, лучше сначала привести его к типу данных, на которые он указывает:

```c
printf("*p_num: %d\n", *(((int *)p_num) + 2));
```

Здесь сначала преобразуем `p_num` в указатель на `int`, а затем прибавляем 2 (смещаемся на два значения `int` вперед).

> [!WARNING]
> Арифметические операции с указателем `void*` — неопределенное поведение по стандарту: поведение GCC и Clang (размер `void` = 1) — лишь расширение компиляторов. Приводите `void*` к конкретному типу перед арифметикой.

## 7. Резюме

1. Инкремент и декремент сдвигают указатель на размер типа, на который он указывает: `int*` — на 4 байта, `short*` — на 2, `char*` — на 1, `double*` — на 8.
2. Прибавление числа `n` сдвигает указатель на `n * sizeof(тип)` байт; вычитание сдвигает назад.
3. Разность двух указателей одного типа — расстояние между ними в элементах типа; результат имеет тип `ptrdiff_t` (выводится как `%td`).
4. Выражения `*pa++` и `(*pa)++` работают по-разному: в первом сдвигается указатель, во втором — значение по адресу.
5. Арифметика над `void*` — неопределенное поведение; перед операциями указатель следует привести к конкретному типу.
