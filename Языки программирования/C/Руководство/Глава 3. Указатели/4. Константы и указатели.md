## 1. Введение

Отдельно стоит сказать про указатели на константы и константные указатели. Прежде всего стоит отметить, что мы можем манипулировать значениями констант через указатели: несмотря на то, что константы вроде бы представляют неизменяемые сущности, указатели позволяют изменить их. Например:

```c
#include <stdio.h>

int main(void)
{
    const int cx = 10;
    // получаем адрес константы, преобразуем в указатель типа int* и изменяем по нему значение
    *(int *)&cx = 20;
    printf("cx: %d\n", cx);  // cx: 20

    // то же самое, только разбито на два этапа
    int *cx_p = &cx;
    *cx_p = 66;
    printf("cx: %d\n", cx); // cx: 66
    return 0;
}
```

> [!WARNING]
> Изменение значения константы через указатель — неопределенное поведение: стандарт не гарантирует результат. Компилятор вправе подставить значение константы на этапе компиляции или разместить ее в защищенной от записи памяти (тогда программа аварийно завершится). Такой код писать не следует.

## 2. Указатели на константы

Кроме переменных в программе на Си для хранения данных могут использоваться константы, которые предваряются ключевым словом `const`. Указатели также могут указывать на константы, но в этом случае перед определением указателя также ставится слово `const`:

```c
#include <stdio.h>

int main(void)
{
    const int a = 10;
    const int *pa = &a;
    printf("address=%p \t value=%d \n", (void *)pa, *pa);

    return 0;
}
```

Здесь указатель `pa` указывает на константу `a`. Поэтому даже если мы захотим изменить значение по адресу, который хранится в указателе, мы не сможем этого сделать:

```c
*pa = 34; // ошибка во время компиляции
```

Возможна также ситуация, когда указатель на константу на самом деле указывает на переменную:

```c
#include <stdio.h>

int main(void)
{
    int a = 10;
    const int *pa = &a;
    printf("value=%d \n", *pa);     // 10
    a = 22;
    printf("value=%d \n", *pa);     // 22
    // *pa = 34;                    // так делать нельзя

    return 0;
}
```

В этом случае переменную отдельно мы сможем изменять, однако по-прежнему изменить ее значение через указатель не сможем.

Через указатель на константу мы не можем изменять значение переменной или константы, но можем присвоить указателю адрес любой другой переменной или константы:

```c
int a = 10;
const int *pa = &a;     // указатель указывает на переменную a
const int b = 45;
pa = &b;                // указатель указывает на константу b
```

## 3. Константные указатели

Можно также определять константные указатели. Они не могут изменять адрес, который в них хранится, но могут изменять значение по этому адресу:

```c
int a = 10;
int *const pa = &a;
printf("value=%d \n", *pa);     // 10
*pa = 22;                       // меняем значение
printf("value=%d \n", *pa);     // 22

int b = 45;
// pa = &b;                     // так нельзя сделать
```

## 4. Константный указатель на константу

И объединение обоих предыдущих случаев — константный указатель на константу, который не позволяет менять ни хранимый в нем адрес, ни значение по этому адресу:

```c
int a = 10;
const int *const pa = &a;

// *pa = 22;    // так сделать нельзя

int b = 45;
// pa = &b;     // так сделать нельзя
```

## 5. Сравнение видов указателей

|**Определение**|**Изменение адреса в указателе**|**Изменение значения по адресу**|
|---|---|---|
|`int *pa`|можно|можно|
|`const int *pa`|можно|нельзя|
|`int *const pa`|нельзя|можно|
|`const int *const pa`|нельзя|нельзя|

Ключевое правило: слово `const` перед звездочкой запрещает менять значение по адресу, слово `const` после звездочки (перед именем указателя) запрещает менять сам адрес.

## 6. Резюме

1. `const int *pa` — указатель на константу: нельзя менять значение по адресу, но можно менять сам адрес.
2. `int *const pa` — константный указатель: нельзя менять адрес, но можно менять значение по нему.
3. `const int *const pa` — константный указатель на константу: нельзя менять ни адрес, ни значение.
4. Запись `const` до звездочки относится к значению по адресу, после звездочки — к самому указателю.
5. Изменение константы через указатель — неопределенное поведение.
