## 1. Введение

Для ввода данных с консоли используется функция `scanf()`. Она определена в заголовочном файле `stdio.h` (там же, где и функция `printf`) и имеет следующее формальное определение:

```c
scanf(форматная_строка, аргументы)
```

И форматная строка, и аргументы для функции `scanf` обязательны.

## 2. Форматная строка и спецификации преобразования

Форматная строка содержит **спецификации преобразования**, которые определяют вводимые данные. Общий вид спецификации преобразования:

```
% * ширина_поля модификатор спецификатор
```

Из этих элементов обязательны только два: знак процента `%` и спецификатор.

### Спецификаторы

Спецификатор определяет тип вводимых данных:

|**Спецификатор**|**Тип вводимых данных**|
|---|---|
|`%c`|один символ|
|`%d`|десятичное целое число|
|`%i`|целое число в любой системе (десятичной, шестнадцатеричной, восьмеричной)|
|`%u`|положительное целое число|
|`%e`, `%E`|число с плавающей точкой в экспоненциальной форме|
|`%f`, `%F`|число с плавающей точкой|
|`%g`, `%G`|число с плавающей точкой|
|`%o`|восьмеричное число|
|`%x`, `%X`|шестнадцатеричное число|
|`%s`|строка|
|`%%`|символ процента|

### Звездочка

Символ звездочки `*` в спецификации преобразования позволяет пропустить при вводе вводимые символы для типа, указанного через спецификатор:

```c
int age;
scanf("%*d %d", &age);
// вводим "33 44": первое число пропускается, в age попадает 44
```

### Ширина поля

Ширина поля представляет целое положительное число и позволяет определить, какое количество байтов будет учитываться при вводе:

```c
int age;
scanf("%2d", &age); // вводим 1234: будут учтены только первые два символа, age = 12
```

### Модификаторы

Модификаторы позволяют конкретизировать тип данных:

|**Модификатор**|**Назначение**|
|---|---|
|`h`|ввод значений типа `short int` (`%hd`)|
|`l`|ввод значений типа `long int` (`%ld`) или `double` (`%lf`, `%le`)|
|`L`|ввод значений типа `long double` (`%Lf`, `%Le`)|

## 3. Адрес переменной

В качестве аргументов в функцию `scanf()` передаются адреса переменных, которые будут получать введенные значения. Для получения адреса переменной перед ее именем ставится знак амперсанда `&`. Например, если переменная называется `age`, то ее адрес можно получить с помощью выражения `&age`.

> [!NOTE]
> Функция `scanf()` записывает значения по адресам, поэтому без амперсанда значение не изменится. Впрочем, есть исключение — строки: имя массива уже само по себе представляет адрес первого элемента, поэтому амперсанд не нужен (см. раздел о вводе строк).

## 4. Ввод числового значения

Введем с консоли числовое значение:

```c
#include <stdio.h>

int main(void)
{
    int age;
    printf("Input your age: ");
    scanf("%d", &age);

    printf("age = %d", age);
    return 0;
}
```

Здесь вводится значение для переменной `age`, которая представляет тип `int`, поэтому в форматную строку передается спецификатор `%d`. Не используются ни звездочка, ни ширина поля, ни модификаторы. Вторым параметром идет адрес переменной — `&age`.

После ввода значения его можно использовать, например, вывести на консоль:

```
Input your age: 44
age = 44
```

Аналогичен ввод данных других типов:

```c
#include <stdio.h>

int main(void)
{
    double price;
    long code;
    printf("Enter the product code: ");
    scanf("%ld", &code);
    printf("Enter the price: ");
    scanf("%lf", &price);
    printf("Product code: %ld \t price: %.2lf \n", code, price);
    return 0;
}
```

Консольный вывод:

```
Enter the product code: 1234
Enter the price: 234.567
Product code: 1234       price: 234.57
```

## 5. Ввод нескольких значений

Можно сразу вводить несколько значений. В этом случае в качестве разделителя используется пробел:

```c
#include <stdio.h>

int main(void)
{
    int count;
    double price;
    long code;
    printf("Enter product data: ");
    scanf("%ld %d %lf", &code, &count, &price);
    printf("Product code: %ld \tcount: %d \tprice: %.2lf\n", code, count, price);
    return 0;
}
```

При вводе данных в консоли функция `scanf` использует пробелы в качестве разделителей, чтобы извлечь из ввода значения для определенных переменных:

```
Enter product data: 1234 3 234.56
Product code: 1234      count: 3        price: 234.56
```

> [!WARNING]
> Функция `scanf()` возвращает количество успешно считанных значений (или `EOF` при ошибке ввода). Это значение стоит проверять: если пользователь ввел текст вместо числа, переменная останется неопределенной. Например:

```c
int age;
if (scanf("%d", &age) != 1)
{
    printf("Ошибка ввода \n");
    return 1;
}
```

## 6. Ввод строк

Функция `scanf()` позволяет вводить и строки:

```c
#include <stdio.h>

int main(void)
{
    char name[10];
    // вводим имя
    printf("Enter your name: ");
    scanf("%10s", name);

    printf("Name: %s \n", name);
    return 0;
}
```

Здесь для имени выделяется 10 символов. Теоретически можно ввести и большее количество символов, но чтобы только 10 из них учитывались, в форматную строку передается ширина поля, которая представляет 10 символов — `%10s`. Когда функция считает достаточное количество символов, она прекращает считывание.

Обратите внимание, что для ввода строки перед названием переменной не указывается символ адреса:

```c
scanf("%10s", name);
```

Потому что название массива уже само по себе представляет адрес его первого элемента.

Возможный консольный вывод:

```
Enter your name: Tom
Name: Tom
```

> [!WARNING]
> Без ширины поля спецификатор `%s` считывает сколько угодно символов и может выйти за границы массива, записав данные в память за ним. Всегда ограничивайте ввод строки шириной поля.

## 7. Ввод строки с пробелами

Однако при использовании этой функции можно столкнуться с рядом проблем. Прежде всего попробуйте ввести в предыдущем примере составное имя, в котором подстроки разделены пробелами, например, «Tom Smith»:

```
Enter your name: Tom Smith
Name: Tom
```

В массив попало только первое слово. Для решения этой проблемы можно использовать один хак:

```c
#include <stdio.h>

int main(void)
{
    char name[10];
    printf("Enter your name: ");
    scanf("%10[^\n]", name);

    printf("Name: %s \n", name);
    return 0;
}
```

Спецификатор `%10[^\n]` указывает, что мы по-прежнему считываем не более 10 символов. Квадратные скобки `[]` позволяют определить набор символов, которые будут извлекаться из ввода или, наоборот, игнорироваться. Выражение `[^\n]` говорит, что надо считывать ввод до тех пор, пока не встретится символ перевода строки `'\n'`, то есть пока пользователь не нажмет на клавишу Enter.

> [!NOTE]
> Такой способ ввода всей строки с пробелами — известное, но хрупкое решение: если пользователь введет больше символов, чем позволяет ширина поля, остаток останется в буфере ввода и будет прочитан следующей функцией `scanf`. Альтернатива — функция `fgets()`, о которой речь пойдет в одной из следующих глав.

## 8. Резюме

1. Функция `scanf()` считывает данные с консоли; обязательны форматная строка и аргументы.
2. Спецификатор определяет тип вводимых данных (`%d` — целое, `%f` — вещественное, `%s` — строка и т. д.); звездочка пропускает значение, ширина поля ограничивает количество считываемых символов, модификаторы (`h`, `l`, `L`) уточняют тип.
3. Для скалярных переменных передается адрес (`&age`); для строк амперсанд не нужен — имя массива уже является адресом.
4. Спецификатор `%s` читает строку до первого пробела; для ввода строки с пробелами применяется `%10[^\n]`.
5. Возвращаемое значение `scanf()` — число успешно считанных значений; его стоит проверять для обработки ошибок ввода.
