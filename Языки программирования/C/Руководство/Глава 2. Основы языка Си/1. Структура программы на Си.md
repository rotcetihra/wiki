## 1. Введение

Программа на языке Си состоит из набора **директив препроцессора**, **определений функций** и **глобальных объектов**:

- **Директивы препроцессора** управляют преобразованием текста до его компиляции;
- **Глобальные объекты** определяют данные или состояние программы;
- **Функции** определяют поведение или действия программы.

Простейшая программа на Си:

```c
#include <stdio.h>

int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```

## 2. Инструкции

Простейшим строительным элементом программы на Си являются **инструкции**. Каждая инструкция выполняет определенное действие. В конце инструкций ставится **точка с запятой** (`;`) — этот знак сообщает компилятору о завершении инструкции:

```c
printf("Hello, World!");
```

Вызов функции `printf`, выводящей на консоль строку, является инструкцией и завершается точкой с запятой.

Набор инструкций может образовывать **блок кода**. Блок оформляется фигурными скобками `{ }`, между которыми помещаются инструкции, составляющие тело блока:

```c
{
    printf("Hello, World!");
    printf("Bye World!");
}
```

В этом блоке две инструкции — обе представляют вызов функции `printf()` и выводят определенную строку на консоль.

> [!NOTE]
> Точка с запятой ставится после каждой инструкции, но не после фигурной скобки, закрывающей блок. Пропуск `;` — одна из самых частых ошибок начинающих программистов на Си.

## 3. Директивы препроцессора

Чтобы функция `printf()` стала доступна в программе, в начале файла с исходным кодом подключается заголовочный файл `stdio.h` с помощью директивы `#include`. Директива `#include` — лишь одна из директив препроцессора; к ним также относится, например, директива `#define`, объявляющая макрос:

```c
#define PI 3.14159
```

Правила оформления директив препроцессора:

- каждая директива размещается на одной строке;
- директива должна начинаться со знака решетки `#`;
- в отличие от инструкций языка Си, директива завершается не точкой с запятой, а переводом на новую строку.

### Заголовочные файлы

Директива `#include` определяет, какие файлы нужно включить в данном месте в текст программы. По умолчанию подключаются стандартные файлы из каталога **заголовочных файлов**, которые поставляются вместе со стандартными библиотеками компилятора. Файл `stdio.h` — один из таких заголовочных файлов.

Термин «заголовочный файл» предполагает включение текста файла именно в начало программы, поэтому заголовочные файлы подключаются, как правило, в начале исходного кода. Заголовочный файл должен быть подключен **до вызова** тех функций, которые он объявляет: файл `stdio.h` хранит объявление функции `printf`, поэтому его необходимо подключить до вызова `printf`.

> [!NOTE]
> Угловые скобки (`#include <stdio.h>`) предписывают препроцессору искать файл в системных каталогах заголовочных файлов компилятора, а кавычки (`#include "myfile.h"`) — в каталоге проекта. Кавычки используются для собственных заголовочных файлов.

### Как работает препроцессор

При компиляции исходного кода **вначале срабатывает препроцессор**, который сканирует исходный код на наличие строк, начинающихся с символа `#`. Эти строки расцениваются как директивы, и на их месте происходит преобразование текста: например, на месте директивы `#include <stdio.h>` вставляется содержимое файла `stdio.h`.

## 4. Функция main

**Стартовая точка** любой программы на языке Си — функция `main()`. Именно с нее начинается выполнение приложения. Имя `main` фиксировано и для всех программ на Си одинаково.

Функция также является блоком кода, поэтому ее тело обрамляется фигурными скобками, между которыми находится набор инструкций.

|**Определение**|**Статус по стандарту C**|**Комментарий**|
|---|---|---|
|`int main(void)`|Стандартное (рекомендуемое)|Функция без параметров, возвращает код завершения.|
|`int main()`|Стандартное|То же, что `int main(void)` (в Си пустые скобки — неопределенный список параметров).|
|`int main(int argc, char *argv[])`|Стандартное|С доступом к аргументам командной строки.|
|`void main()`|**Нестандартное**|Не соответствует стандарту ISO C.|

> [!WARNING]
> Определение `void main()` встречается в старой литературе и многих учебных примерах, и большинство компиляторов его примет, однако оно **не соответствует стандарту ISO C** — стандарт требует, чтобы `main` возвращала `int`. На некоторых компиляторах такая программа может завершиться ошибкой. Всегда используйте `int main(void)` (или `int main(int argc, char *argv[])`).

## 5. Комментарии

Программа может сопровождаться **комментариями** — описаниями кода. При компиляции комментарии не учитываются и не оказывают никакого влияния на работу программы, но дают программисту понимание того, как работает код.

В Си используется два типа комментариев:

- **Блочный** — заключается между символами `/* ... */`, может размещаться на нескольких строках:

```c
#include <stdio.h>

/* Функция main выводит
   на консоль строку Hello World */
int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```

- **Строчный** — помещается на одной строке после двойного слеша `//`:

```c
#include <stdio.h>            // подключаем заголовочный файл stdio.h

int main(void)                // определяем функцию main
{                             // начало функции
    printf("Hello, World!");  // выводим строку на консоль
    return 0;                 // выходим из функции
}                             // конец функции
```

## 6. Резюме

1. Программа на Си — это директивы препроцессора, определения функций и глобальные объекты.
2. Инструкции завершаются точкой с запятой `;`, а блоки кода оформляются фигурными скобками.
3. Директивы препроцессора начинаются с `#` и завершаются переводом строки; `#include` подключает заголовочные файлы до вызова объявленных в них функций.
4. Стартовая точка программы — функция `main()`; по стандарту ISO C она должна возвращать `int`.
5. Комментарии бывают блочные (`/* ... */`) и строчные (`//`).
