## 1. Введение

Отдельную группу операций в языке Си составляют **операции присваивания**. Они производятся над двумя операндами, причем левый операнд может представлять только **модифицируемое именованное выражение** — например, переменную.

## 2. Простое присваивание

Существует базовая операция присваивания `=`, которая присваивает значение правого операнда левому операнду:

```c
int x = 2 + 5;
```

Выражение `2 + 5` — правый операнд, и его значение присваивается левому операнду `x`.

Стоит отметить, что тип значения правого операнда не всегда совпадает с типом левого операнда. В этом случае компилятор преобразует значение правого операнда к типу левого операнда.

## 3. Множественное присваивание

Можно выполнять множественное присваивание:

```c
int a, b, c;
a = b = c = 34 + 7;
```

Операция присваивания правоассоциативна, поэтому выражение выполняется справа налево:

1. сначала вычисляется `c = 34 + 7` — переменная `c` получает значение 41;
2. затем вычисляется `b = c` — переменная `b` получает значение правого операнда `c` (41);
3. и в конце вычисляется `a = b` — переменная `a` получает значение 41.

В результате все три переменные получают значение 41.

## 4. Составные операции присваивания

Все остальные операции присваивания являются сочетанием простой операции присваивания с другими операциями:

|**Операция**|**Описание**|**Эквивалент**|
|---|---|---|
|`+=`|присваивание после сложения|`A = A + B`|
|`-=`|присваивание после вычитания|`A = A - B`|
|`*=`|присваивание после умножения|`A = A * B`|
|`/=`|присваивание после деления|`A = A / B`|
|`%=`|присваивание после деления по модулю|`A = A % B`|
|`<<=`|присваивание после сдвига разрядов влево|`A = A << B`|
|`>>=`|присваивание после сдвига разрядов вправо|`A = A >> B`|
|`&=`|присваивание после поразрядной конъюнкции|`A = A & B`|
|`\|=`|присваивание после поразрядной дизъюнкции|`A = A \| B`|
|`^=`|присваивание после исключающего ИЛИ|`A = A ^ B`|

> [!NOTE]
> Составное присваивание эквивалентно соответствующему простому выражению с той разницей, что левый операнд вычисляется только один раз. Для простых переменных разницы не видно, однако это важно для сложных выражений с побочными эффектами.

## 5. Пример

```c
int a = 5;
a += 10; // 15
a -= 3;  // 12
a *= 2;  // 24
a /= 6;  // 4
a <<= 4; // 64
a >>= 2; // 16
```

Каждая операция последовательно меняет значение `a`: после `a /= 6` переменная равна 4, поэтому `a <<= 4` дает `4 << 4 = 64`, а `a >>= 2` — `64 >> 2 = 16`.

## 6. Резюме

1. Левый операнд операции присваивания — модифицируемое именованное выражение, например переменная.
2. Операция `=` присваивает значение правого операнда левому; при несовпадении типов выполняется преобразование к типу левого операнда.
3. Множественное присваивание (`a = b = c = значение`) выполняется справа налево.
4. Составные операции присваивания (`+=`, `-=`, `*=`, `/=`, `%=`, `<<=`, `>>=`, `&=`, `|=`, `^=`) сочетают присваивание с соответствующей операцией: `A += B` эквивалентно `A = A + B`.
