## 1. Введение

Отличительным признаком переменных является то, что в течение работы программы их значение можно многократно изменять:

```c
#include <stdio.h>

int main(void)
{
    int number = 2;
    printf("number = %d \n", number);
    number = 55;
    printf("number = %d \n", number);
    number = -23;
    printf("number = %d \n", number);
    return 0;
}
```

Здесь переменная `number` последовательно меняет свое значение:

```
number = 2
number = 55
number = -23
```

В отличие от переменных значение **констант** устанавливается один раз при их определении и не может быть изменено в дальнейшем.

## 2. Ключевое слово const

Для определения константы используется ключевое слово **const**:

```c
#include <stdio.h>

int main(void)
{
    const int number = 2;
    printf("number = %d \n", number);
    return 0;
}
```

Если в коде будет содержаться изменение константы, компилятор не сможет скомпилировать подобную программу:

```c
const int number = 2;
number = 55; // ошибка компиляции: number - константа
```

> [!NOTE]
> `const` — квалификатор типа: он сообщает компилятору, что объект доступен только для чтения. Запись `const int number` эквивалентна записи `int const number`.

> [!WARNING]
> Изменение константы — нарушение ограничений стандарта, поэтому компилятор обязан выдать сообщение об ошибке (например, GCC выводит «assignment of read-only variable 'number'»).

## 3. Зачем нужны константы

Как правило, в виде констант определяются значения, которые должны оставаться постоянными в течение работы всей программы и не могут быть изменены. Например, если программа выполняет математические операции с числом PI, то оптимально определить это значение как константу — оно в принципе неизменно:

```c
const float PI = 3.14;
```

> [!NOTE]
> Константу необходимо инициализировать при определении: иначе значение нельзя будет ни задать, ни изменить.

> [!NOTE]
> По распространенному соглашению имена констант записывают заглавными буквами — так их легко отличить от переменных: `PI`, `MAX_SIZE`, `COUNT` и т. п.

## 4. Константы времени компиляции

`const`-переменная в Си — не обязательно **константа времени компиляции**: она не может использоваться там, где требуется константное выражение, например, в качестве размера объекта со статическим хранением:

```c
const int size = 10;
static int numbers[size]; // ошибка: для статического хранения требуется константа времени компиляции
```

> [!NOTE]
> Для настоящих констант времени компиляции в Си применяются директива препроцессора `#define` (она упоминалась в уроке «Структура программы на Си») и перечисления `enum`:

```c
#define PI 3.14

enum { SIZE = 10 };
```

> [!INFO]
> Начиная со стандарта C23 в языке появилось ключевое слово `constexpr`, которое позволяет объявлять константы времени компиляции напрямую: `constexpr int size = 10;`.

## 5. Резюме

1. Значение константы устанавливается один раз при определении и не может быть изменено.
2. Константы определяются с помощью ключевого слова `const`, которое является квалификатором типа (доступен только чтение).
3. Попытка изменить константу — ошибка компиляции.
4. В виде констант оформляются неизменяемые в течение работы программы значения, например число PI.
5. `const`-переменная не является константой времени компиляции; для этого используются `#define` и `enum`, а начиная с C23 — `constexpr`.
