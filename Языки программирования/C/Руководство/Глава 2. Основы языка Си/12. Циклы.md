## 1. Введение

**Циклы** позволяют выполнить одно действие множество раз в зависимости от определенного условия. В языке Си есть три типа циклов: `for`, `while` и `do...while`. Каждый отдельный проход цикла называется **итерацией**.

## 2. Цикл for

Цикл `for` имеет следующее формальное определение:

```
for (инициализация; условие; приращение)
{
    // тело цикла
}
```

Заголовок цикла состоит из трех частей:

- **инициализация** — выполняется один раз при начале цикла и представляет установку начальных условий; как правило, это инициализация счетчика — специальной переменной, которая используется для контроля над циклом;
- **условие** — выражение, при соблюдении которого выполняется цикл; обычно это операция сравнения: если она возвращает ненулевое значение (условие истинно), выполняется тело цикла, а затем третья часть;
- **приращение** — задает изменение параметров цикла; обычно здесь происходит увеличение счетчика.

Выведем числа от 0 до 5:

```c
#include <stdio.h>

int main(void)
{
    for (int i = 0; i < 6; i++)
    {
        printf("%d", i);
    }
    return 0;
}
```

- `int i = 0` — создает и инициализирует счетчик `i` значением 0. Счетчик необязательно должен представлять тип `int` — это может быть и другой числовой тип, например `float`.
- `i < 6` — условие: цикл выполняется, пока `i` не достигнет 6.
- `i++` — приращение счетчика на единицу. Приращение необязательно должно увеличивать счетчик на 1: можно уменьшать (`i--`) или изменять на другое значение (`i += 2`).

Блок цикла сработает 6 раз, пока значение `i` не станет равным 6, — это 6 итераций:

```
012345
```

Усложним цикл и выведем квадраты чисел от 0 до 8:

```c
#include <stdio.h>

int main(void)
{
    for (int i = 0; i < 9; i++)
    {
        printf("%d * %d = %d \n", i, i, i * i);
    }
    return 0;
}
```

Консольный вывод:

```
0 * 0 = 0
1 * 1 = 1
2 * 2 = 4
3 * 3 = 9
4 * 4 = 16
5 * 5 = 25
6 * 6 = 36
7 * 7 = 49
8 * 8 = 64
```

Необязательно указывать все три выражения в определении цикла — можно опустить одно или даже все:

```c
int i = 1;
for (; i < 9;)
{
    printf("%d * %d = %d \n", i, i, i * i);
    i++;
}
```

Формально определение цикла осталось тем же, только первая и третья части отсутствуют: `for (; i < 9;)`. Переменная-счетчик определена и инициализирована вне цикла, а ее приращение происходит в самом цикле.

> [!NOTE]
> Начиная со стандарта C99 счетчик, объявленный в первой части цикла (`for (int i = 0; ...)`), виден только внутри цикла.

> [!INFO]
> Цикл с пустыми частями — `for (;;)` — бесконечный цикл; выход из него выполняется оператором `break` (см. раздел «Операторы break и continue»).

Можно определять вложенные циклы. Например, выведем таблицу умножения:

```c
#include <stdio.h>

int main(void)
{
    for (int i = 1; i < 10; i++)
    {
        for (int j = 1; j < 10; j++)
        {
            printf("%d \t", i * j);
        }
        printf("\n");
    }
    return 0;
}
```

Внутренний цикл (по `j`) на каждой итерации внешнего цикла (по `i`) полностью отрабатывает свои девять итераций.

## 3. Цикл while

В отличие от цикла `do...while`, цикл `while` сразу проверяет истинность условия, и если условие истинно (не равно 0), код цикла выполняется:

```
while (условие)
{
    // выполняемые инструкции, если условие истинно
}
```

Выведем на консоль все числа от 6 до 1:

```c
#include <stdio.h>

int main(void)
{
    int i = 6;
    while (i > 0)
    {
        printf("%d \n", i);
        i--;
    }
    return 0;
}
```

Пока истинно условие `i > 0`, выполняются действия цикла — `printf` и `i--`.

## 4. Цикл do...while

В цикле `do...while` сначала выполняется код цикла, а потом происходит проверка условия в инструкции `while`. Пока это условие истинно (не равно 0), цикл повторяется:

```
do
{
    // действия цикла
}
while (условие);
```

```c
#include <stdio.h>

int main(void)
{
    int i = 6;
    do
    {
        printf("%d", i);
        i--;
    }
    while (i > 0);
    return 0;
}
```

Код цикла сработает 6 раз, пока `i` не станет равным нулю.

Важно отметить, что цикл `do...while` гарантирует хотя бы однократное выполнение действий, даже если условие ложно с самого начала:

```c
int i = -1;
do
{
    printf("%d", i);
    i--;
}
while (i > 0);
```

Хотя переменная `i` меньше нуля и условие `i > 0` ложно, цикл все равно выполнится один раз.

## 5. Сравнение циклов

|**Цикл**|**Когда проверяется условие**|**Минимальное число итераций**|
|---|---|---|
|`for`|перед каждой итерацией|0|
|`while`|перед каждой итерацией|0|
|`do...while`|после каждой итерации|1|

## 6. Операторы break и continue

Иногда возникает необходимость выйти из цикла до его завершения. В этом случае применяется оператор **break**. Например, выйдем из бесконечного цикла, когда счетчик превысит 5:

```c
int i = 1;
for (;;)
{
    printf("%d * %d = %d \n", i, i, i * i);
    i++;
    if (i > 5) break;
}
```

Когда значение переменной `i` станет больше 5, оператор `break` завершит цикл.

> [!WARNING]
> Оператор `break` прерывает только самый внутренний цикл (или конструкцию `switch`). Во вложенных циклах он не завершает внешние циклы.

В отличие от `break`, оператор **continue** не выходит из цикла, а переходит к следующей итерации. Например, посчитаем сумму только нечетных чисел из диапазона от 0 до 9:

```c
#include <stdio.h>

int main(void)
{
    int result = 0;
    for (int i = 0; i < 10; i++)
    {
        if (i % 2 == 0) continue;
        result += i;
    }
    printf("result = %d", result); // 25
    return 0;
}
```

Чтобы узнать, четное ли число, берется остаток от целочисленного деления на 2; если он равен 0, оператор `continue` переходит к следующей итерации цикла. Нечетные числа (1, 3, 5, 7, 9) складываются — результат равен 25.

> [!NOTE]
> В циклах `while` и `do...while` оператор `continue` передает управление проверке условия, а в `do...while` — проверке после тела цикла, а не просто пропускает инструкции.

## 7. Резюме

1. В Си три вида циклов: `for`, `while`, `do...while`; проход цикла называется итерацией.
2. Цикл `for` состоит из инициализации, условия и приращения; любую из частей можно опускать.
3. `while` проверяет условие перед каждой итерацией, а `do...while` — после, поэтому `do...while` выполняется минимум один раз.
4. Оператор `break` досрочно завершает цикл (или `switch`), оператор `continue` переходит к следующей итерации.
5. `break` прерывает только самый внутренний цикл.
