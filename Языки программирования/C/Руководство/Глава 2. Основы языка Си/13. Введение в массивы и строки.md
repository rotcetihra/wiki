## 1. Введение

Нередко возникает необходимость работы не с одиночными данными, а с наборами данных. Для этого в языке Си применяются **массивы**. Массив представляет набор однотипных значений.

Объявление массива выглядит следующим образом:

```
тип_переменной название_массива [длина_массива]
```

После типа переменной идет название массива, а затем в квадратных скобках — его размер. Например, определим массив из четырех чисел:

```c
int main(void)
{
    int numbers[4];
    return 0;
}
```

## 2. Обращение к элементам массива

Используя номера элементов в массиве, которые называются **индексами**, можно обращаться к отдельным элементам:

```c
#include <stdio.h>

int main(void)
{
    int numbers[4];
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    numbers[3] = 4;

    printf("numbers[0] = %d \n", numbers[0]); // 1 - первый элемент
    printf("numbers[2] = %d \n", numbers[2]); // 3 - третий элемент
    return 0;
}
```

Индексы указываются в квадратных скобках после названия массива и начинаются с нуля, поэтому для обращения к первому элементу используется выражение `numbers[0]`.

## 3. Инициализация массива

Можно сразу объявить и инициализировать массив значениями. Для этого применяется **инициализатор** — набор значений в фигурных скобках:

```c
int numbers[4] = { 1, 2, 3, 5 }; // инициализация массива
printf("numbers[2] = %d", numbers[2]); // 3
```

Внутри инициализатора через запятую перечисляются значения, которые последовательно присваиваются элементам массива:

|**Значение**|1|2|3|5|
|---|---|---|---|---|
|**Индекс**|0|1|2|3|

При инициализации массива можно явно не указывать его длину — в этом случае длина вычисляется исходя из количества элементов в инициализаторе:

```c
int numbers[] = { 1, 2, 3, 5 };
```

Необязательно инициализировать массив значениями для всех элементов:

```c
int numbers[5] = { 10, 12 }; // 10, 12, 0, 0, 0
```

В этом случае значения предоставляются для двух первых элементов, а остальные элементы по умолчанию получают значение 0.

Си также позволяет частично инициализировать элементы массива не по порядку, указывая индекс в квадратных скобках:

```c
int numbers[5] = { [1] = 11, [3] = 13 };
```

Инициализируются только элементы с индексами 1 и 3, остальные получают значение 0. Такой массив аналогичен следующему:

```c
int numbers[5] = { 0, 11, 0, 13, 0 };
```

> [!NOTE]
> Инициализация с указанием индексов (`[1] = 11`) — так называемые designated initializers, появившиеся в стандарте C99.

## 4. Размер и количество элементов массива

Не всегда размер массива известен заранее. В этом случае используется оператор `sizeof`, который возвращает размер массива в байтах в виде значения типа `size_t`:

```c
#include <stdio.h>

int main(void)
{
    int numbers[] = { 5, 6, 7 };
    size_t size = sizeof(numbers);
    printf("numbers size: %zu \n", size); // numbers size: 12
    return 0;
}
```

Для массива `{ 5, 6, 7 }` оператор `sizeof` возвращает 12 байт, так как массив содержит три значения типа `int`, каждое из которых обычно занимает 4 байта.

> [!NOTE]
> Тип `size_t` — псевдоним беззнакового целого типа, размер которого зависит от платформы: на 64-разрядном Linux это `unsigned long`, на 64-разрядной Windows — `unsigned long long`. Для вывода значений `size_t` используется спецификатор `%zu`.

Разделив размер массива на размер его элемента, можно получить количество элементов:

```c
#include <stdio.h>

int main(void)
{
    int numbers[] = { 5, 6, 7 };
    size_t size = sizeof(numbers);
    size_t count = sizeof(numbers) / sizeof(numbers[0]);
    printf("numbers size: %zu \n", size);   // numbers size: 12
    printf("numbers count: %zu \n", count); // numbers count: 3
    return 0;
}
```

Выражение `sizeof(numbers[0])` предпочтительнее, чем `sizeof(int)`: при изменении типа элементов массива его не придется менять.

## 5. Динамическое вычисление значений элементов

Элементы массива могут вычисляться динамически. Например, массив из размеров типов:

```c
int sizes[] = { sizeof(int), sizeof(long), sizeof(long long) }; // 4, 4 или 8, 8
sizes[1] = sizeof(char); // sizes[1] = 1
```

Каждый элемент массива вычисляется с помощью оператора `sizeof`, который возвращает размер соответствующего типа.

## 6. Перебор элементов массива

Используя циклы, можно перебрать массив:

```c
#include <stdio.h>

int main(void)
{
    int numbers[] = { 10, 12, 13, 54, 43 };
    size_t count = sizeof(numbers) / sizeof(numbers[0]);
    for (size_t i = 0; i < count; i++)
    {
        printf("numbers[%zu] = %d \n", i, numbers[i]);
    }
    return 0;
}
```

В качестве индекса рекомендуется использовать тип `size_t` — он допускает количество элементов, которое может не вписаться в диапазон `int` или `unsigned int`. Впрочем, на практике часто используется и `int`:

```c
for (int i = 0; i < count; i++)
{
    printf("numbers[%d] = %d \n", i, numbers[i]);
}
```

> [!NOTE]
> При сравнении знакового индекса (`int`) с беззнаковым количеством (`size_t`) компилятор GCC/Clang может выдать предупреждение `-Wsign-compare`. Его можно избежать, используя `size_t` для индекса либо явное преобразование типов.

## 7. Динамическая установка размера массива

Размер массива можно установить динамически с помощью переменной:

```c
#include <stdio.h>

int main(void)
{
    int maxSize = 3;
    int array[maxSize];
    array[0] = 1;
    array[1] = 2;
    array[2] = 3;
    for (int i = 0; i < maxSize; i++)
    {
        printf("%d", array[i]);
    }
    return 0;
}
```

При динамической установке размера нельзя инициализировать массив при определении:

```c
int maxSize = 3;
int array[maxSize] = { 1, 2, 3 }; // ошибка: так нельзя
```

> [!WARNING]
> Такие массивы называются массивами переменной длины (VLA, variable-length array): возможность появилась в стандарте C99, а в C11 стала опциональной. GCC и Clang поддерживают ее, но не на всех платформах. Память под VLA выделяется на стеке, поэтому размер лучше ограничивать разумными значениями.

## 8. Константные массивы

При необходимости после инициализации можно многократно изменять значения элементов массива:

```c
#include <stdio.h>

int main(void)
{
    int numbers[3] = { 11, 12, 13 };
    numbers[1] = 22; // изменяем второй элемент
    printf("numbers[1] = %d", numbers[1]); // numbers[1] = 22
    return 0;
}
```

Однако иногда изменение элементов массива не требуется или нежелательно. В этом случае массив определяется как константный:

```c
#include <stdio.h>

int main(void)
{
    const int numbers[3] = { 11, 12, 13 };
    // numbers[1] = 22; // нельзя изменить - массив константный
    printf("numbers[1] = %d", numbers[1]); // numbers[1] = 22
    return 0;
}
```

При попытке изменить элемент константного массива на этапе компиляции возникнет ошибка.

## 9. Многомерные массивы

Массивы могут быть многомерными: элементы таких массивов сами являются массивами. Чаще всего используются двумерные массивы, которые можно представить в виде таблицы:

```c
int numbers[3][2] = { {1, 2}, {4, 5}, {7, 8} };
```

Массив `numbers` имеет три элемента (3 строки), каждый из которых — массив из двух элементов (2 столбца):

|**Строка 0**|1|2|
|---|---|---|
|**Строка 1**|4|5|
|**Строка 2**|7|8|

Для обращения к элементам вложенного массива требуются два индекса:

```c
int numbers[3][2] = { {1, 2}, {4, 5}, {7, 8} };
printf("numbers[1][0] = %d \n", numbers[1][0]); // 4
```

Для перебора двумерного массива применяются вложенные циклы:

```c
#include <stdio.h>

int main(void)
{
    int numbers[3][2] = { {1, 2}, {4, 5}, {7, 8} };
    // проходим по 3 строкам таблицы
    for (int i = 0; i < 3; i++)
    {
        // проходим по 2 столбцам каждой строки
        for (int j = 0; j < 2; j++)
        {
            printf("numbers[%d][%d] = %d \n", i, j, numbers[i][j]);
        }
    }
    return 0;
}
```

Как и для одномерных массивов, можно применить оператор `sizeof` для поиска числа строк и столбцов:

```c
#include <stdio.h>

int main(void)
{
    int numbers[3][2] = { {1, 2}, {4, 5}, {7, 8} };
    size_t rows_count = sizeof(numbers) / sizeof(numbers[0]);           // 3
    size_t columns_count = sizeof(numbers[0]) / sizeof(numbers[0][0]);  // 2
    printf("rows count = %zu \n", rows_count);
    printf("columns count = %zu \n", columns_count);

    for (size_t i = 0; i < rows_count; i++)
    {
        for (size_t j = 0; j < columns_count; j++)
        {
            printf("numbers[%zu][%zu] = %d \n", i, j, numbers[i][j]);
        }
    }
    return 0;
}
```

Консольный вывод:

```
rows count = 3
columns count = 2
numbers[0][0] = 1
numbers[0][1] = 2
numbers[1][0] = 4
numbers[1][1] = 5
numbers[2][0] = 7
numbers[2][1] = 8
```

> [!NOTE]
> Многомерные массивы — это абстракция: в реальности все массивы одномерны и представляют сплошной блок памяти. Поэтому двумерный массив можно инициализировать и как одномерный:

```c
int numbers[3][2] = { 1, 2, 4, 5, 7, 8 };
```

## 10. Строки

С массивами остальных типов данных все аналогично числам, но отдельно стоит остановиться на массивах символов. В Си нет специального типа для строк: строка — это набор символов, то есть массив символов `char`:

```c
#include <stdio.h>

int main(void)
{
    char message[] = "Hello";
    printf("message: %s \n", message); // message: Hello
    return 0;
}
```

Строки определяются в двойных кавычках.

> [!NOTE]
> Кроме самих символов каждая строка содержит завершающий **нулевой символ** `\0` (нулевой байт, символ с кодом 0 в таблице ASCII). В Си нулевой байт служит признаком окончания строки. Поэтому в строке `"Hello"` на самом деле не 5 символов, а 6:

|H|e|l|l|o|\0|
|---|---|---|---|---|---|

Переберем все символы строки и выведем их десятичные коды ASCII:

```c
char message[] = "Hello";
size_t length = sizeof(message) / sizeof(char); // 6 символов
for (size_t i = 0; i < length; i++)
{
    printf("%d ", message[i]);
}
```

В конце вывода виден нулевой символ:

```
72 101 108 108 111 0
```

Тот же массив можно определить явно, перечислив символы и добавив в конец `\0`:

```c
char message[] = { 'H', 'e', 'l', 'l', 'o', '\0' };
```

> [!WARNING]
> Если массив символов не завершается нулевым символом, спецификатор `%s` не сможет определить конец строки и продолжит вывод «мусора» из соседних областей памяти. Следите за завершающим `\0`.

## 11. Задача: умножение матриц

Рассмотрим работу с массивами на примере умножения матриц. Первая матрица имеет три строки и два столбца, вторая — два столбца... две строки и один столбец:

```c
#include <stdio.h>

int main(void)
{
    const int r1 = 3,     // число строк в 1-й матрице
              c1r2 = 2,  // число столбцов в 1-й и число строк во 2-й матрице
              c2 = 1;    // число столбцов во 2-й матрице
    int matrix1[3][2] = { {1, 2}, {3, 4}, {5, 6} };
    int matrix2[2][1] = { {10}, {20} };
    int matmult[r1][c2];

    // инициализируем результирующую матрицу нулями
    for (int i = 0; i < r1; i++)
    {
        for (int j = 0; j < c2; j++)
        {
            matmult[i][j] = 0;
        }
    }

    // вычисляем произведение матриц
    for (int i = 0; i < r1; i++)
    {
        for (int j = 0; j < c2; j++)
        {
            for (int k = 0; k < c1r2; k++)
            {
                matmult[i][j] = matmult[i][j] + matrix1[i][k] * matrix2[k][j];
            }
        }
    }

    printf("Result \n");
    for (int i = 0; i < r1; i++)
    {
        for (int j = 0; j < c2; j++)
        {
            printf("%d ", matmult[i][j]);
        }
        printf("\n");
    }
    return 0;
}
```

При произведении матриц получается матрица, у которой число строк равно числу строк первой матрицы, а число столбцов — числу столбцов второй. Элемент результирующей матрицы на i-й строке и j-м столбце равен сумме произведений элементов i-й строки первой матрицы на соответствующие элементы j-го столбца второй матрицы.

В цикле по `i` проходим по всем строкам первой матрицы, в цикле по `j` — по всем столбцам второй матрицы, а во внутреннем цикле по `k` умножаем элемент из k-го столбца первой матрицы на элемент из k-й строки второй и прибавляем к результату. В итоге получаем матрицу из трех строк и одного столбца:

```
Result
50
110
170
```

## 12. Резюме

1. Массив — набор однотипных значений; элементы нумеруются индексами, начиная с нуля.
2. Инициализатор `{ ... }` задает начальные значения; пропущенные элементы получают 0; можно инициализировать элементы выборочно (designated initializers, C99).
3. Число элементов вычисляется как `sizeof(массив) / sizeof(массив[0])`.
4. Размер массива можно задать переменной (VLA), но такой массив нельзя инициализировать; константный массив объявляется с `const`.
5. Двумерные и прочие многомерные массивы удобно представлять как таблицы; в памяти они хранятся как сплошной блок.
6. Строка в Си — массив символов, завершающийся нулевым символом `\0`; для вывода строк используется `%s`.
