## 1. Введение

Для вывода на консоль в языке Си зачастую применяется функция **printf()**. Ее объявление находится в заголовочном файле `stdio.h`. Если с выводом простой строки особых проблем не возникает, то при выводе данных других типов есть свои особенности.

Формальное определение функции:

```
printf(строка_форматирования, список_аргументов);
```

Первый параметр — строка, которая может содержать произвольный текст в двойных кавычках:

```c
#include <stdio.h>

int main(void)
{
    printf("Hello world!");
    return 0;
}
```

## 2. Управляющие последовательности

Кроме обычного текста в строку форматирования можно включать **управляющие последовательности** — специальные группы символов, начинающиеся с обратного слеша:

|**Последовательность**|**Значение**|
|---|---|
|`\n`|перевод на новую строку|
|`\t`|табуляция|
|`\r`|возврат каретки (курсора) в начало строки|
|`\\`|обратный слеш|
|`\'`|одинарная кавычка|
|`\"`|двойная кавычка|

Например:

```c
#include <stdio.h>

int main(void)
{
    printf("The book \"The C Programming Language\"\nBrian Kernighan, Dennis Ritchie");
    return 0;
}
```

Консольный вывод:

```
The book "The C Programming Language"
Brian Kernighan, Dennis Ritchie
```

## 3. Спецификации преобразования

**Спецификации преобразования** позволяют задать формат вывода значений различных типов. Формальное определение:

```
%[флаги][ширина_поля][.точность][модификатор]спецификатор
```

Из перечисленных компонентов обязательными являются только `%` и спецификатор.

Доступные спецификаторы:

|**Спецификатор**|**Назначение**|
|---|---|
|`%c`|вывод отдельного символа (тип `char`)|
|`%s`|вывод строки|
|`%d`|вывод целого числа со знаком (тип `int`)|
|`%i`|вывод целого числа со знаком — аналог `%d`|
|`%u`|вывод целого положительного числа (тип `unsigned`)|
|`%f`|вывод числа с плавающей точкой (`float`, `double`)|
|`%F`|то же, что `%f`, но `INF` и `NAN` выводятся в верхнем регистре|
|`%e`|вывод числа с плавающей точкой в экспоненциальном представлении|
|`%E`|то же в верхнем регистре|
|`%g`|для вывода числа выбирается более короткий из форматов `%e` или `%f`|
|`%G`|для вывода числа выбирается более короткий из форматов `%E` или `%F`|
|`%o`|вывод восьмеричного числа без знака|
|`%x`|вывод шестнадцатеричного числа (цифры в нижнем регистре)|
|`%X`|вывод шестнадцатеричного числа (цифры в верхнем регистре)|
|`%%`|вывод знака процента|

Применим несколько спецификаторов:

```c
#include <stdio.h>

int main(void)
{
    float r = 71.8986;
    printf("x = %f \n", r);
    printf("x = %e \n", r);

    char symbol = 'r';
    printf("symbol = %c \n", symbol);

    unsigned int number = 23;
    printf("number = %u \n", number);

    printf("%s \n", "Hello World 2013");
    return 0;
}
```

Значения для спецификаторов передаются через аргументы, следующие вторым параметром в функции `printf`.

Консольный вывод:

```
x = 71.898598
x = 7.189860e+001
symbol = r
number = 23
Hello World 2013
```

> [!NOTE]
> Спецификаторы `%d` и `%i` при выводе полностью эквивалентны; различие между ними существует только при вводе функцией `scanf`.

> [!NOTE]
> В `printf` спецификаторы `%f` и `%lf` для значений `double` работают одинаково: аргументы `float` при передаче в функцию автоматически преобразуются в `double`. Во `scanf` они различаются: там `%f` читает значение во `float`, а `%lf` — в `double`.

> [!WARNING]
> Спецификатор должен соответствовать типу передаваемого значения. Несоответствие типов — неопределенное поведение: программа может вывести «мусор» или даже упасть. Например, `printf("%d", 3.14)` и `printf("%f", 42)` — некорректны. Компиляторы GCC и Clang с флагом `-Wformat` предупреждают о подобных ошибках.

## 4. Ширина поля и точность

Для вывода чисел с плавающей точкой можно использовать **ширину поля** и **точность**.

**Ширина поля** — целое положительное число, определяющее минимальную длину выводимого значения в символах. **Точность** — целое положительное число, определяющее количество цифр в дробной части. Например:

```c
float r = 71.8986;
printf("x = %4.2f \n", r); // 71.90
```

Здесь спецификация преобразования `%4.2f` означает: `4` — ширина поля, `2` — точность (две цифры в дробной части).

> [!NOTE]
> Ширина поля задает минимальную, а не максимальную длину: если значение длиннее указанной ширины, оно выводится полностью. Например, число `71.90` состоит из пяти символов, поэтому при ширине `4` выводится целиком.

## 5. Модификаторы длины

**Модификаторы** позволяют конкретизировать тип выводимого значения:

|**Модификатор**|**Назначение**|
|---|---|
|`h`|значения типа `short int` (например, `%hd`)|
|`l`|значения типа `long int` и `unsigned long int` (`%ld`, `%lu`)|
|`ll`|значения типа `long long int` и `unsigned long long int` (`%lld`, `%llu`)|
|`L`|значения типа `long double` (например, `%Lf`)|

Пример:

```c
short r = 7100;
printf("x = %hd", r);
```

## 6. Несколько аргументов

Необязательно передавать в `printf` по одному значению — можно передавать множество значений:

```c
printf("Name=%s \t Age=%d \t Weight=%3.2f", "Tom", 23, 63.3456);
```

Каждому спецификатору соответствует свой аргумент по порядку следования: первый спецификатор `%s` получает значение первого аргумента — строку `"Tom"`, второй спецификатор `%d` — второго аргумента, число 23, и так далее.

## 7. Флаги

Дополнительно можно использовать **флаги**, которые позволяют управлять форматированием вывода:

|**Флаг**|**Описание**|
|---|---|
|`-`|выравнивание по левому краю поля (по умолчанию — по правому)|
|`+`|выводить знак `+` или `-` для чисел; без флага знак выводится только для отрицательных значений|
|пробел|вставить пробел на месте знака перед положительными числами|
|`0`|дополнять ширину поля нулями (для чисел)|
|`#`|альтернативная форма вывода: для `%o`, `%x`, `%X` число выводится с префиксами `0`, `0x`, `0X`; для `%g`, `%G`, `%f` десятичная точка выводится, даже если в числе нет дробной части|

Пример использования флагов:

```c
#include <stdio.h>

int main(void)
{
    printf("%d \n", 8);
    printf("% d \n", 8);
    printf("%+d \n", +8);
    printf("%#o \n", 8);
    printf("%#f \n", 8.);
    printf("%09d \n", 8);

    printf("%9s %d \n", "Tom", 38);
    printf("%-9s %d \n", "Tom", 38);

    return 0;
}
```

Консольный вывод:

```
8
 8
+8
010
8.000000
000000008
      Tom 38
Tom       38
```

## 8. Резюме

1. Функция `printf` объявлена в `stdio.h`; ее первый параметр — строка форматирования, далее — список выводимых значений.
2. Управляющие последовательности (`\n`, `\t`, `\\` и др.) задают служебные символы в строке.
3. Спецификаторы (`%d`, `%u`, `%f`, `%c`, `%s` и др.) определяют формат вывода значения; обязательны только `%` и спецификатор.
4. Ширина поля и точность управляют длиной значения и количеством цифр в дробной части.
5. Модификаторы `h`, `l`, `ll`, `L` конкретизируют тип выводимого значения.
6. Каждому спецификатору соответствует аргумент по порядку; несоответствие типов — неопределенное поведение.
7. Флаги `-`, `+`, пробел, `0`, `#` управляют выравниванием и формой вывода.
