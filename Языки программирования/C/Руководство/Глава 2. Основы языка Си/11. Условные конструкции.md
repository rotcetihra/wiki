## 1. Введение

**Условные конструкции** позволяют направить ход программы по одному из возможных путей в зависимости от условия. В языке Си для этого есть несколько средств: оператор `if`, конструкция `switch...case` и тернарный оператор.

## 2. Оператор if

Оператор `if` проверяет истинность условия и, если оно истинно, выполняет блок инструкций. Сокращенная форма:

```
if (условие) инструкция;
```

В качестве условия может выступать любое выражение, возвращающее число. Если выражение возвращает ненулевое значение (выражение истинно), выполняется последующая инструкция; если выражение равно 0 (ложно), инструкция пропускается:

```c
#include <stdio.h>

int main(void)
{
    if (1) printf("Hello C \n");
    if (0) printf("Hello World \n");
    return 0;
}
```

В первом случае условие равно 1 — «истина» (любое число, кроме 0, представляет истину), поэтому на консоль выводится строка `Hello C`. Во втором случае условие равно 0 — «ложь», поэтому инструкция `printf("Hello World \n")` не выполняется.

В реальности в качестве условий выступает результат некоторых выражений — обычно операций сравнения или логических операций. Все они в конечном счете возвращают либо 0 (условие неверно), либо ненулевое значение (условие верно):

```c
#include <stdio.h>

int main(void)
{
    int n = 10;

    if (n == 20) printf("n = 20 \n");
    if (n == 10) printf("n = 10 \n");

    return 0;
}
```

В первом случае условие `n == 20` неверно и возвращает 0, поэтому инструкция не выполняется. Во втором случае операция `n == 10` возвращает 1, и инструкция выполняется.

Если в конструкции `if` необходимо выполнить не одну, а несколько инструкций, они оформляются в **блок кода** с помощью фигурных скобок:

```c
#include <stdio.h>

int main(void)
{
    int x = 60;

    if (x > 50)
    {
        printf("if statement \n");
        printf("x is greater than 50 \n");
    }
    return 0;
}
```

Условия могут быть более сложными:

```c
#include <stdio.h>

int main(void)
{
    int x = 50;
    int y = 60;
    if (x > 20 && y < 100)
    {
        printf("the condition is true\n");
    }
    return 0;
}
```

Здесь общее условие истинно, только если истинны оба условия — значение `x` больше 20 и значение `y` меньше 100 (операция `&&`).

## 3. Оператор if...else

Если нужно определить две пары действий — одни при истинном условии, другие при ложном, — применяется форма `if...else`:

```
if (условие)
    инструкция_1
else
    инструкция_2
```

Если условие истинно, выполняется инструкция после `if`; если ложно (возвращает 0) — инструкция после `else`:

```c
int x = 60;
if (x > 60)
    printf("x is greater than 60 \n");
else
    printf("x is less or equal 60 \n");
```

Для проверки альтернативных условий применяется ветвь `else if`:

```c
int x = 60;

if (x > 60)
    printf("x is greater than 60 \n");
else if (x < 60)
    printf("x is less than 60 \n");
else
    printf("x is equal 60 \n");
```

Полная программа с блоками инструкций:

```c
#include <stdio.h>

int main(void)
{
    int x = 60;

    if (x > 60)
    {
        printf("if statement \n");
        printf("x is greater than 60 \n");
    }
    else if (x < 60)
    {
        printf("else if statement \n");
        printf("x is less than 60 \n");
    }
    else
    {
        printf("else statement \n");
        printf("x is equal 60 \n");
    }
    return 0;
}
```

> [!NOTE]
> Ветвь `else` всегда относится к ближайшему `if` — эту особенность (известную как «проблема висячего else») следует учитывать при вложенных конструкциях.

## 4. Конструкция switch...case

Другую форму организации ветвления представляет конструкция `switch...case`:

```
switch (выражение)
{
    case константа_1: инструкции_1;
    case константа_2: инструкции_2;
    ...
    default: инструкции;
}
```

После ключевого слова `switch` в скобках идет сравниваемое выражение. Его значение последовательно сравнивается с константами после оператора `case`; если совпадение найдено, выполняется блок данного `case`. В качестве констант могут выступать значения типов `char`, `int` и `unsigned` — любые целочисленные константные выражения.

Проверим с помощью конструкции `switch` значение переменной:

```c
#include <stdio.h>

int main(void)
{
    int x = 2;

    switch (x)
    {
        case 1:
            printf("x = 1 \n");
            break;
        case 2:
            printf("x = 2 \n");
            break;
        case 3:
            printf("x = 3 \n");
            break;
    }
    return 0;
}
```

Значение переменной `x` последовательно сравнивается со значениями после операторов `case`:

1. сначала программа переходит к `case 1` — переменная `x` не равна 1, выполнение переходит дальше;
2. затем к `case 2` — переменная `x` равна 2, выполняются инструкции этого блока;
3. оператор `break` в конце блока завершает выполнение конструкции `switch...case`.

Консольный вывод:

```
x = 2
```

При определении блоков `case` следует не забывать про операторы `break`. Перепишем предыдущий пример без них:

```c
#include <stdio.h>

int main(void)
{
    int x = 2;

    switch (x)
    {
        case 1:
            printf("x = 1 \n");
        case 2:
            printf("x = 2 \n");
        case 3:
            printf("x = 3 \n");
    }
    return 0;
}
```

Так как `x = 2`, начинает выполняться блок после `case 2`. Но поскольку этот блок не завершается оператором `break`, выполнение «проваливается» (fallthrough) в следующие блоки, пока не встретит `break` или конец конструкции:

```
x = 2
x = 3
```

> [!WARNING]
> Не забывайте оператор `break` в конце каждого блока `case` — иначе выполнение продолжится со следующих блоков.

В конце конструкции `switch` может стоять блок `default`. Он необязателен и выполняется, если ни одного совпадения с блоками `case` не найдено:

```c
#include <stdio.h>

int main(void)
{
    int x = 5;

    switch (x)
    {
        case 1:
            printf("x = 1 \n");
            break;
        case 2:
            printf("x = 2 \n");
            break;
        case 3:
            printf("x = 3 \n");
            break;
        default:
            printf("x is undefined \n");
            break;
    }
    return 0;
}
```

Консольный вывод:

```
x is undefined
```

> [!NOTE]
> Блок `default` необязателен и может размещаться в любом месте конструкции, а не только в конце.

## 5. Тернарный оператор ?:

Тернарный оператор `?:` позволяет сократить определение простейших условных конструкций и использует сразу три операнда:

```
условие ? второй_операнд : третий_операнд
```

Если условие истинно (не равно 0), результатом выражения является второй операнд; если условие ложно (равно 0) — третий:

```c
#include <stdio.h>

int main(void)
{
    int x = 5;
    int y = 2;

    int z = x > y ? x - y : x + y;

    printf("z = %d", z); // z = 3
    return 0;
}
```

Условие `x > y` истинно, поэтому результатом тернарной операции становится второй операнд — `x - y`, и переменная `z` получает значение 3.

> [!NOTE]
> Тернарный оператор имеет низкий приоритет — ниже, чем у арифметических и логических операций, поэтому в выражении `x > y ? x - y : x + y` дополнительные скобки не требуются (но их можно ставить для читаемости).

## 6. Резюме

1. Оператор `if` выполняет инструкцию или блок инструкций, если условие истинно; ложь — это 0, истина — любое ненулевое значение.
2. Ветви `else` и `else if` обрабатывают ложное условие и альтернативные варианты.
3. Конструкция `switch...case` сравнивает выражение с целочисленными константами; `break` предотвращает проваливание в следующие блоки, а `default` обрабатывает отсутствие совпадений.
4. Тернарный оператор `?:` возвращает одно из двух значений в зависимости от условия и сокращает простейшие конструкции `if...else`.
