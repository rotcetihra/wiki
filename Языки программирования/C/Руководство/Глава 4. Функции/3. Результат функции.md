## 1. Введение

Функция может иметь результат — некоторое значение, которое она возвращает во внешний код. Для возвращения результата функция применяет оператор `return`, который имеет следующие способы использования:

```c
return;
return выражение;
```

Первая форма может использоваться в тех функциях, которые не возвращают никакого значения, то есть имеют в качестве возвращаемого типа `void`.

Вторая форма применяется, если функция имеет в качестве возвращаемого типа любой тип, кроме `void`. Выражение после оператора `return` представляет возвращаемое значение.

## 2. Возвращение значения

В прошлой теме была определена функция `sum`, которая в качестве возвращаемого типа имела тип `void`, то есть по факту ничего не возвращает:

```c
void sum(int x, int y)
{
    printf("%d + %d = %d \n", x, y, x + y);
}
```

Хотя эта функция не использует явно оператор `return`, компилятор сам добавляет его автоматически в конец функции:

```c
void sum(int x, int y)
{
    printf("%d + %d = %d \n", x, y, x + y);
    return;
}
```

Эти оба определения фактически равнозначны.

Но также функция может возвращать какое-то конкретное значение. Например, изменим функцию `sum`, чтобы она возвращала сумму чисел:

```c
#include <stdio.h>

int sum(int x, int y)
{
    return x + y;
}

int main(void)
{
    int x = 25;
    int y = 15;
    int result = sum(x, y);
    printf("%d + %d = %d \n", x, y, result);
}
```

Теперь функция `sum` в качестве возвращаемого типа имеет тип `int`. Если тип функции отличен от `void`, то функция обязательно должна возвращать значение данного типа. Для возвращения значения применяется оператор `return`, после которого указывается возвращаемое значение.

В данном случае функция `sum` возвращает сумму параметров:

```c
return x + y;
```

Если функция возвращает какое-либо значение, то при ее вызове мы можем получить это значение в переменную:

```c
int result = sum(x, y);
```

Прототип функции `sum` будет выглядеть так:

```c
int sum(int, int);
```

> [!WARNING]
> Если функция с типом, отличным от `void`, не возвращает значение на каком-то из путей выполнения, это неопределенное поведение: программа получит «мусорное» значение. Компилятор GCC/Clang предупреждает об этом (`-Wreturn-type`). Убедитесь, что оператор `return` сработает при любых аргументах.

## 3. Сложная логика возвращения результата

Логика возвращения результата может быть более сложной:

```c
#include <stdio.h>

int calculate(int x, int y, char operation)
{
    if (operation == '+')
    {
        return x + y;
    }
    else if (operation == '-')
    {
        return x - y;
    }
    else
    {
        return 0;
    }
}

int main(void)
{
    int x = 30;
    int y = 10;
    int result1 = calculate(x, y, '+');
    int result2 = calculate(x, y, '-');
    int result3 = calculate(x, y, 'g');

    printf("%d + %d = %d \n", x, y, result1);
    printf("%d - %d = %d \n", x, y, result2);
    printf("%d \n", result3);
}
```

Функция `calculate()` принимает три параметра. Первые два параметра представляют числа, над которыми выполняется арифметическая операция, а третий параметр — знак операции. В зависимости от знака операции функция возвращает либо сумму, либо разность чисел, либо число 0, если операция не поддерживается.

## 4. Резюме

1. Оператор `return;` используется в функциях с типом `void`; форма `return выражение;` — во всех остальных случаях.
2. Компилятор автоматически добавляет `return;` в конец функции с типом `void`.
3. Если тип функции отличен от `void`, она обязана вернуть значение этого типа — в противном случае неопределенное поведение.
4. Результат вызова функции можно сохранить в переменную: `int result = sum(x, y);`.
5. В функции может быть несколько операторов `return` — возвращается результат того из них, который сработал первым.
