## 1. Введение

Функция может принимать параметры. Параметры позволяют передать извне в функцию некоторые данные, настроить ее выполнение. Параметры перечисляются в скобках после имени функции и имеют следующее определение:

```c
тип имя_функции (тип параметр1, тип параметр2, ... тип параметрN)
```

Для каждого параметра сначала указывается тип, а затем название параметра. Через запятую определяется следующий параметр.

## 2. Передача параметров. Формальные параметры и аргументы

Допустим, мы хотим, чтобы функция выводила разные сообщения на консоль. Для этого определим функцию, которая в качестве параметра принимает массив символов:

```c
#include <stdio.h>

// функция принимает массив символов
void print_message(char message[])
{
    printf("%s\n", message);
}

int main(void)
{
    print_message("Hello METANIT.COM!");
    print_message("Hello World!");
    print_message("Hello work...");
}
```

Функция `print_message()` принимает один параметр, который называется `message` и имеет тип `char[]`. Параметр `message` еще называется **формальным параметром**.

В функции `main` три раза вызывается функция `print_message` с разными значениями — строками `"Hello METANIT.COM!"`, `"Hello World!"` и `"Hello work..."`. Эти значения называются **аргументами**. На консоль будут выведены три строки:

```
Hello METANIT.COM!
Hello World!
Hello work...
```

Прототип функции `print_message()` выглядел бы следующим образом:

```c
void print_message(char[]);
```

Полный пример с прототипом:

```c
#include <stdio.h>

// прототип функции print_message
void print_message(char[]);

int main(void)
{
    print_message("Hello METANIT.COM!");
}

// определение функции print_message
void print_message(char message[])
{
    printf("%s\n", message);
}
```

> [!NOTE]
> Параметр, объявленный как массив (`char message[]`), в Си на самом деле является указателем (`char *message`): при передаче массив не копируется, а «вырождается» в адрес первого элемента. Именно поэтому изменение элементов такого массива внутри функции затронет исходный массив в вызывающем коде.

## 3. Несколько параметров

Если необходимо несколько параметров, они перечисляются через запятую. Например, напишем функцию, которая вычисляет сумму двух чисел:

```c
#include <stdio.h>

void sum(int x, int y)
{
    printf("%d + %d = %d \n", x, y, x + y);
}

int main(void)
{
    sum(1, 2);
    sum(4, 5);
    sum(6, 2);
}
```

Функция `sum()` принимает два параметра типа `int`.

В функции `main` эта функция вызывается три раза, и каждый раз ей передается два разных аргумента для параметров `x` и `y`. Соответствие между аргументами и параметрами устанавливается по их расположению: первый аргумент передает значение для первого параметра, второй аргумент — для второго параметра и так далее. Консольный вывод программы:

```
1 + 2 = 3
4 + 5 = 9
6 + 2 = 8
```

Прототип функции `sum` выглядел бы следующим образом:

```c
void sum(int, int);
```

## 4. Соответствие по типу

Между передаваемыми в функцию аргументами и ее параметрами должно быть соответствие по типу. Если типы не совпадают, то компилятор пытается автоматически выполнить преобразование типов.

Например, выше использовалась функция `void sum(int, int)`. Если передать в `sum` значения другого типа, то компилятор будет пытаться привести их к типу `int`:

```c
int main(void)
{
    sum(1.4, 2.5);   // передаем значения double
    sum(1.4f, 2.5f); // передаем значения float
}
```

В обоих случаях фактически функция `sum` получит числа 1 и 2.

## 5. Передача параметров по значению

При передаче параметров следует учитывать, что они передаются в функцию **по значению**: функция не изменяет значения передаваемых аргументов. Рассмотрим следующий пример:

```c
#include <stdio.h>

void increase(int x)
{
    x = 2 * x;
    printf("Increase func: x = %d \n", x);
}

int main(void)
{
    int a = 25;
    increase(a);
    printf("Main func: a = %d \n", a);
}
```

Функция `increase` через параметр получает число и увеличивает его в два раза.

В функции `main` вызывается функция `increase`, которой передается значение переменной `a`. И после того как функция `increase` отработала и изменила значение своего параметра, проверяется значение переменной `a`.

При выполнении мы увидим, что изменения аргумента в функции `increase` действуют только в рамках этой функции. Вне ее значение переменной `a` остается неизменным:

```
Increase func: x = 50
Main func: a = 25
```

Почему так происходит? При компиляции функции для ее параметров выделяются отдельные участки памяти. При этом для параметров типа `float` формируются в памяти объекты типа `double`, а для параметров типов `char` и `short int` — объекты типа `int`.

При вызове функции вычисляются значения аргументов, которые передаются на место параметров, и значения аргументов заносятся в участки памяти, отведенные для параметров. При этом значения типа `float` преобразуются в объекты типа `double`, а объекты типов `char` и `short int` — в объекты типа `int`.

Если в вызов функции передается переменная, функция получает копию ее значения. Поэтому все манипуляции со значением параметра внутри функции никак не затронут оригинальную переменную.

После завершения работы функции память, выделенная для параметров, освобождается.

> [!WARNING]
> Чтобы функция могла изменять переданную переменную, нужно передавать не значение, а указатель на нее (например, `void change(int *p)`). Подробнее передача указателей в функции рассматривается в следующих темах.

## 6. Константные параметры

Мы можем изменить значение параметра внутри функции:

```c
void change(int n)
{
    n = n * 2;      // значение параметра изменяется
    printf("n = %d \n", n);
}
```

Однако подобное поведение не всегда желательно. Нередко возникают ситуации, когда надо гарантировать, что параметр сохранит свое значение на протяжении всей работы функции. В этом случае параметр можно объявить константным с помощью ключевого слова `const`:

```c
void change(const int n)
{
    // n = n * 2;    // теперь параметр n нельзя изменить
    int m = n * 2;
    printf("n = %d \n", n);
    printf("m = %d \n", m);
}
```

Если попробовать изменить значение константного параметра, то при компиляции мы столкнемся с ошибкой. Если же надо выполнять какие-то вычисления, можно использовать дополнительную переменную.

## 7. Резюме

1. Параметры перечисляются в скобках после имени функции в виде `тип имя`; значения, передаваемые при вызове, называются аргументами.
2. Соответствие аргументов и параметров устанавливается по расположению; компилятор автоматически преобразует типы при несовпадении.
3. Параметры передаются по значению: функция получает копию значения и не изменяет исходную переменную (кроме массивов, которые передаются как указатели).
4. Параметр можно объявить константным (`const int n`), запретив его изменение внутри функции.
