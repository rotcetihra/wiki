## 1. Введение

Каждая переменная имеет определенную **область видимости** (scope). Область видимости представляет участок программы, в рамках которого можно использовать переменную.

Переменные бывают глобальными и локальными, или автоматическими. Кроме того, выделяют статические переменные.

## 2. Локальные автоматические переменные

Локальные переменные определяются внутри блока кода (например, внутри функции) и существуют только в рамках этого блока. Эти переменные характеризуются автоматическим временем жизни: при входе в блок для этих переменных выделяется память (ее еще называют автоматической памятью), а после завершения работы этого блока выделенная память освобождается, а объекты удаляются:

```c
#include <stdio.h>

void printn()
{
    int n = 63;
    printf("n=%d \n", n);
}

int main(void)
{
    int a = 2;
    printn();               // n=63
    // n++;      так сделать нельзя, так как n определена в функции printn
    printf("a=%d \n", a);   // a=2
    return 0;
}
```

Здесь в функции `printn` определена автоматическая переменная `n`, в функции `main` — автоматическая переменная `a`. Вне своих функций переменные недоступны. Например, мы не можем использовать переменную `n` в функции `main`, так как ее область видимости ограничена функцией `printn`.

То же самое касается переменных, которые определены во вложенных блоках кода, например в условных конструкциях `if..else`, `switch..case`, циклах `for`, `while`, `do..while`:

```c
void printn()
{
    {
        int n = 20;     // локальная переменная
        printf("%d \n", n);
    }
    printf("%d \n", n); // ошибка: здесь переменная n не видна
}
```

Здесь переменная `n` по-прежнему является локальной и автоматической, но определена не просто в функции, а в блоке кода внутри функции. И вне этого блока кода, даже внутри функции, ее использовать нельзя, потому что после завершения блока она удаляется.

## 3. Глобальные переменные

Глобальные переменные определены в файле программы вне любой из функций и могут использоваться любой функцией из этого файла:

```c
#include <stdio.h>

int n = 5;

void printn()
{
    n++;
    printf("n=%d \n", n);
}

int main(void)
{
    printn();               // n=6
    n++;
    printf("n=%d \n", n);   // n=7

    return 0;
}
```

Здесь переменная `n` является глобальной и доступна из любой функции. При этом любая функция может изменить ее значение.

## 4. Сокрытие переменных

Автоматические переменные, определенные внутри блока кода, могут скрывать внешние переменные с тем же именем:

```c
#include <stdio.h>

int n = 5;

int main(void)
{
    int n = 10;
    printf("n=%d \n", n);       // n=10
    {
        int n = 20;
        printf("n=%d \n", n);   // n=20
    }
    return 0;
}
```

Здесь определены три переменных с именем `n`. Автоматическая переменная `n`, определенная на уровне функции `main` (`int n = 10;`), скрывает глобальную переменную `n`. А переменная `n`, определенная на уровне блока, скрывает переменную, определенную на уровне функции `main`.

> [!NOTE]
> Сокрытие работает и в обратную сторону: глобальная переменная в этом примере доступна лишь до тех пор, пока в области видимости не появилась локальная переменная с тем же именем. Чтобы избежать путаницы, лучше не создавать переменные с одинаковыми именами в разных областях видимости.

## 5. Статические переменные

Кроме глобальных и автоматических есть особый тип переменных — **статические**. Они определяются на уровне функций с помощью ключевого слова `static`. Если автоматические переменные определяются и инициализируются при каждом входе в функцию, то статические переменные инициализируются только один раз, а при последующих вызовах функции используется старое значение статической переменной.

Например, пусть будет функция со стандартной автоматической переменной:

```c
#include <stdio.h>

void display()
{
    int i = 0;
    i++;
    printf("i=%d \n", i);
}

int main(void)
{
    display();
    display();
    display();
    return 0;
}
```

Функция `display` вызывается три раза, и при каждом вызове программа повторно выделяет память для переменной `i`, определенной в функции. А после завершения работы `display` память для переменной `i` освобождается. Соответственно ее значение при каждом вызове будет неизменным:

```
i=1
i=1
i=1
```

Теперь сделаем переменную `i` статической:

```c
#include <stdio.h>

void display()
{
    static int i = 0;
    i++;
    printf("i=%d \n", i);
}

int main(void)
{
    display();
    display();
    display();
    return 0;
}
```

К переменной было добавлено ключевое слово `static`, поэтому при завершении работы функции `display` переменная не уничтожается, ее память не очищается, наоборот, она сохраняется в памяти. И результат работы программы будет иным:

```
i=1
i=2
i=3
```

> [!NOTE]
> Статическая локальная переменная отличается от автоматической и временем жизни, и инициализацией: она создается один раз до первого входа в функцию и сохраняет значение между вызовами. При этом область ее видимости по-прежнему ограничена функцией, в которой она определена.

## 6. Резюме

1. Локальные автоматические переменные живут только в рамках своего блока кода; память для них выделяется при входе в блок и освобождается при выходе.
2. Глобальные переменные определены вне функций и доступны всем функциям файла.
3. Локальная переменная с тем же именем скрывает (затеняет) внешнюю переменную.
4. Статические переменные (`static`) инициализируются один раз и сохраняют значение между вызовами функции.
