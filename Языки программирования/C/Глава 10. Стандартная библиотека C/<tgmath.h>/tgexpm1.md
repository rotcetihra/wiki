## Определение

```c
#include <tgmath.h>

#define tgexpm1(x) /* обобщённый макрос */
```

## Описание

Макрос `tgexpm1` — обобщённая версия «экспонента минус один». Автоматически выбирает функцию `expm1f`, `expm1` или `expm1l` в зависимости от типа аргумента `x`.

Вычисляет `e^x - 1`. Функция предназначена для точного вычисления значения, близкого к нулю, где прямое вычисление `exp(x) - 1` теряет точность из-за вычитания близких значений.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 1e-15;
    printf("exp(%.1e) - 1 = %.1e\n", x, tgexp(x) - 1.0);
    printf("expm1(%.1e)  = %.1e\n", x, tgexpm1(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Показатель степени. Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | `e^x - 1` |
| `double` | `e^x - 1` |
| `long double` | `e^x - 1` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Высокая точность для малых `x` | Только для вещественных типов |
| Автоматический выбор версии по типу аргумента | Для нечисловых аргументов поведение не определено |
