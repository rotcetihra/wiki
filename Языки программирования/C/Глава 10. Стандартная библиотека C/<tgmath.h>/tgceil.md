## Определение

```c
#include <tgmath.h>

#define tgceil(x) /* обобщённый макрос */
```

## Описание

Макрос `tgceil` — обобщённая версия округления вверх. Автоматически выбирает `ceilf`, `ceil` или `ceill` в зависимости от типа аргумента.

Округляет `x` к ближайшему целому числу, не меньшему `x`. Только для вещественных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    printf("ceil(2.3) = %.1f\n", tgceil(2.3));
    printf("ceil(-2.3) = %.1f\n", tgceil(-2.3));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | Ближайшее целое `≥ x` |
| `double` | Ближайшее целое `≥ x` |
| `long double` | Ближайшее целое `≥ x` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Только для вещественных типов |
| — | Результат может не помещаться в `int` |
