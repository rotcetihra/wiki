## Определение

```c
#include <tgmath.h>

#define tgfma(x, y, z) /* обобщённый макрос */
```

## Описание

Макрос `tgfma` — обобщённая версия fused multiply-add. Автоматически выбирает `fmaf`, `fma` или `fmal`.

Вычисляет `(x * y) + z` с одной операцией округления (вместо двух). Это обеспечивает большую точность и может быть быстрее на процессорах с поддержкой FMA. Только для вещественных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    printf("fma(2, 3, 4) = %.1f\n", tgfma(2.0, 3.0, 4.0));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Множитель. Конечное значение. |
| `y` | Множитель. Конечное значение. |
| `z` | Слагаемое. Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | `(x * y) + z` с одной операцией округления |
| `double` | `(x * y) + z` с одной операцией округления |
| `long double` | `(x * y) + z` с одной операцией округления |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Одна операция округления — выше точность | Только для вещественных типов |
| Может быть аппаратно ускорена | Не все платформы поддерживают аппаратную FMA |
