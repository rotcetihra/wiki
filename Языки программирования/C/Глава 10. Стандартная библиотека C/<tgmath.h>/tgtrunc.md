## Определение

```c
#include <tgmath.h>

#define tgtrunc(x) /* обобщённый макрос */
```

## Описание

Макрос `tgtrunc` — обобщённая версия усечения к нулю. Автоматически выбирает `truncf`, `trunc` или `truncl`.

Отбрасывает дробную часть, оставляя целую часть числа (усечение к нулю).

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    printf("trunc(2.7) = %.1f\n", tgtrunc(2.7));
    printf("trunc(-2.7) = %.1f\n", tgtrunc(-2.7));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | Целая часть (к нулю) |
| `double` | Целая часть (к нулю) |
| `long double` | Целая часть (к нулю) |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простое отбрасывание дробной части | Только для вещественных типов |
| — | Результат может не помещаться в `int` |
