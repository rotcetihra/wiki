## Определение

```c
#include <tgmath.h>

#define tgmodf(x, iptr) /* обобщённый макрос */
```

## Описание

Макрос `tgmodf` — обобщённая версия разделения на целую и дробную части. Автоматически выбирает `modff`, `modf` или `modfl`.

Разлагает `x` на целую и дробную части. Целая часть сохраняется по указателю `iptr`, дробная возвращается как результат. Целая часть усекается к нулю. Только для вещественных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double ipart;
    double fpart = tgmodf(3.14, &ipart);
    printf("Целая: %.1f, Дробная: %.2f\n", ipart, fpart);

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Конечное значение. |
| `iptr` | Указатель на `float`/`double`/`long double` для целой части. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | Дробная часть `x` (к нулю) |
| `double` | Дробная часть `x` (к нулю) |
| `long double` | Дробная часть `x` (к нулю) |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Разделяет целую и дробную части за один вызов | Только для вещественных типов |
| Обе части имеют тот же знак, что и `x` | — |
