## Определение

```c
#include <tgmath.h>

#define tgnearbyint(x) /* обобщённый макрос */
```

## Описание

Макрос `tgnearbyint` — обобщённая версия округления по текущему направлению. Автоматически выбирает `nearbyintf`, `nearbyint` или `nearbyintl`.

Округляет `x` к ближайшему целому числу, используя текущее направление округления (из `<fenv.h>`). В отличие от `rint`, не генерирует исключение `FE_INEXACT`.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    printf("nearbyint(2.3) = %.1f\n", tgnearbyint(2.3));
    printf("nearbyint(2.5) = %.1f\n", tgnearbyint(2.5));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | Ближайшее целое |
| `double` | Ближайшее целое |
| `long double` | Ближайшее целое |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Не генерирует `FE_INEXACT` | Только для вещественных типов |
| Учитывает направление округления | Результат зависит от настройки `<fenv.h>` |
