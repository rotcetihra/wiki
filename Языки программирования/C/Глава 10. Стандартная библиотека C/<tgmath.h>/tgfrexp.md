## Определение

```c
#include <tgmath.h>

#define tgfrexp(x, exp) /* обобщённый макрос */
```

## Описание

Макрос `tgfrexp` — обобщённая версия извлечения мантиссы и показателя. Автоматически выбирает `frexpf`, `frexp` или `frexpl`.

Разлагает число `x` на нормализованную мантиссу `m` и целый показатель `n`, такие что `x = m * 2^n`, где `0.5 ≤ |m| < 1`.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    int n;
    double m = tgfrexp(12.0, &n);
    printf("12.0 = %.1f * 2^%d\n", m, n);

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Конечное ненулевое значение. |
| `exp` | Указатель на `int` для сохранения показателя. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | Мантисса `m`, `0.5 ≤ |m| < 1` |
| `double` | Мантисса `m`, `0.5 ≤ |m| < 1` |
| `long double` | Мантисса `m`, `0.5 ≤ |m| < 1` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Разложение на мантиссу и показатель | Только для вещественных типов |
| Полезно для анализа представления числа | Не определён для 0 |
