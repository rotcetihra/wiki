## Определение

```c
#include <tgmath.h>

#define tgfmin(x, y) /* обобщённый макрос */
```

## Описание

Макрос `tgfmin` — обобщённая версия минимума из двух значений. Автоматически выбирает `fminf`, `fmin` или `fminl`.

Возвращает меньшее из двух значений. Если одно из значений `NaN`, возвращается другое значение. Только для вещественных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    printf("fmin(3, 7) = %.1f\n", tgfmin(3.0, 7.0));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Первый аргумент. Конечное значение. |
| `y` | Второй аргумент. Конечное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | `min(x, y)` |
| `double` | `min(x, y)` |
| `long double` | `min(x, y)` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргументов | Только для вещественных типов |
| Корректно обрабатывает `NaN` | — |
