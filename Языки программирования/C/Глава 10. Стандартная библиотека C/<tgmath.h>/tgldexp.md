## Определение

```c
#include <tgmath.h>

#define tgldexp(x, n) /* обобщённый макрос */
```

## Описание

Макрос `tgldexp` — обобщённая версия умножения на степень двойки. Автоматически выбирает `ldexpf`, `ldexp` или `ldexpl`.

Вычисляет `x * 2^n`. Только для вещественных типов.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    printf("ldexp(1.5, 3) = %.1f\n", tgldexp(1.5, 3));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Множитель. Конечное значение. |
| `n` | Целый показатель степени двойки. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| `float` | `x * 2^n` |
| `double` | `x * 2^n` |
| `long double` | `x * 2^n` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Может быть быстрее, чем `x * pow(2, n)` | Только для вещественных типов |
| Обратная операция к `frexp` | Переполнение при больших `n` |
