## Определение

```c
#include <tgmath.h>

#define tglog(x) /* обобщённый макрос */
```

## Описание

Макрос `tglog` — обобщённая версия натурального логарифма. Автоматически выбирает функцию `logf`, `log`, `logl`, `clogf`, `clog` или `clogl` в зависимости от типа аргумента `x`.

Натуральный логарифм вычисляет `ln(x)` — логарифм по основанию `e`. Аргумент `x` должен быть строго положительным.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 2.718281828459045;
    printf("ln(e) = %.4f\n", tglog(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Положительное значение. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | `ln(x)` |
| Комплексный | Комплексный логарифм |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Аргумент `x ≤ 0` приводит к ошибке |
| Работает с вещественными и комплексными типами | Для нечисловых аргументов поведение не определено |
