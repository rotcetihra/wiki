## Определение

```c
#include <tgmath.h>

#define tgacosh(x) /* обобщённый макрос */
```

## Описание

Макрос `tgacosh` — обобщённая версия обратного гиперболического косинуса. Автоматически выбирает функцию `acoshf`, `acosh` или `acoshl` в зависимости от типа аргумента `x`.

Обратный гиперболический косинус возвращает значение `≥ 0`, косинус которого равен `x`. Аргумент `x` должен быть `≥ 1`.

## Пример

```c
#include <stdio.h>
#include <tgmath.h>

int main(void)
{
    double x = 2.0;
    printf("acosh(%.1f) = %.4f\n", x, tgacosh(x));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Значение `≥ 1`. |

## Возвращаемое значение

| Тип | Результат |
|---|---|
| Вещественный | `≥ 0` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматический выбор версии по типу аргумента | Только для вещественных типов |
| Упрощает написание обобщённого кода | Аргумент `x < 1` приводит к ошибке домена |
