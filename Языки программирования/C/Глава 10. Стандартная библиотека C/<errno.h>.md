## Описание библиотеки

Заголовочный файл `<errno.h>` — «ошибки»: определяет переменную (или макрос) `errno` — целочисленную lvalue, хранящую код последней ошибки, и макросы кодов ошибок `E*`. Подключается практически в любой программе, работающей с системными вызовами или библиотечными функциями.

Стандарт C (C23) требует определения макроса `EDOM` (и положительных значений `EILSEQ` и `ERANGE`); POSIX.1 задаёт обязательный набор кодов (включая `E2BIG`, `EACCES`, `EAGAIN` и десятки других), а Linux/glibc добавляют расширения. Большинство значений платформенно-зависимы: переносимый код не должен полагаться на численные значения кодов.

В glibc `errno` реализован как макрос, раскрывающийся в вызов `__errno_location()` — переменная хранится в памяти потока, поэтому каждая нить имеет собственный код ошибки. Стандарт C допускает объявление макроса, но не требует потоковой локализации.

> [!WARNING]
> Внимание: системные вызовы и функции не обнуляют `errno` при успехе — значение до вызова не определено. Проверяйте `errno` только сразу после вызова, вернувшего признак ошибки (-1, `NULL` и т. п.).

### Коды стандарта C

| Код | Текст strerror | Описание |
|---|---|---|
| `EDOM` | Numerical argument out of domain | Аргумент вне области определения функции |
| `EILSEQ` | Invalid or incomplete multibyte or wide character | Недопустимая последовательность байт |
| `ERANGE` | Numerical result out of range | Результат вне представимого диапазона |

### Коды POSIX

| Код | Текст strerror | Типичная причина |
|---|---|---|
| `EPERM` | Operation not permitted | Не хватает привилегий |
| `ENOENT` | No such file or directory | Путь не существует |
| `EINTR` | Interrupted system call | Прерывание сигналом |
| `EIO` | I/O error | Ошибка устройства |
| `EBADF` | Bad file descriptor | Неверный дескриптор |
| `EAGAIN` | Resource temporarily unavailable | Ресурс временно недоступен |
| `ENOMEM` | Cannot allocate memory | Нехватка памяти |
| `EACCES` | Permission denied | Нет прав доступа |
| `EEXIST` | File exists | Файл существует |
| `EINVAL` | Invalid argument | Неверный аргумент |
| `ENOSPC` | No space left on device | Место закончилось |

### Реализация в glibc

```c
extern int *__errno_location(void) __THROW __attribute_const__;
#define errno (*__errno_location())
```

Макрос `errno` разворачивается в обращение к функции, возвращающей адрес переменной кода ошибки текущего потока. Дополнительно при `__USE_GNU` заголовок определяет `program_invocation_name` и `program_invocation_short_name` — полное и короткое имя программы, использованное при запуске.
