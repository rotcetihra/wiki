## Описание библиотеки

Заголовочный файл `<threads.h>` — поддержка потоков (C11 threading): базовый набор типов и функций для многопоточного программирования в стандартном C. Определяет типы для потоков (`thrd_t`), мьютексов (`mtx_t`), потокового хранилища (`tss_t`) и однократного выполнения (`once_flag`), а также константы кодов возврата и функции управления потоками, синхронизации и локального хранения данных.

Библиотека введена в стандарт C11 и предоставляет переносимую альтернативу POSIX-потокам (`pthread`). В отличие от `pthread`, API `<threads.h>` компактнее и не требует отдельной линковки (`-lpthread`), но менее функционален: нет условных переменных, барьеров, асинхронного отмены потоков и других расширенных возможностей.

На практике поддержка `<threads.h>` в реализациях ограничена: в glibc она отсутствует (по состоянию на 2026 год), в Microsoft Visual C++ поддерживается начиная с Visual Studio 2022 (v17.8). Для POSIX-систем рекомендуется использовать `pthread`.

> [!NOTE]
> Потоки, созданные через `thrd_create`, должны быть либо присоединены через `thrd_join`, либо отсоединены через `thrd_detach`. Невыполнение этого требования приводит к утечке ресурсов или неопределённому поведению.

> [!WARNING]
> Доступ к разделяемым данным из нескольких потоков должен быть синхронизирован (через мьютексы, атомарные операции или другие средства). Иначе возникает состояние гонки (data race) — неопределённое поведение по стандарту C11.

### Типы

| Тип | Описание |
|---|---|
| `thrd_t` | Идентификатор потока (неопределённый тип) |
| `mtx_t` | Мьютекс (неопределённый тип) |
| `tss_t` | Ключ потокового хранилища данных (неопределённый тип) |
| `once_flag` | Флаг для однократного выполнения функции (неопределённый тип) |
| `tss_dtor_t` | Тип функции-деструктора для элементов потокового хранилища: `void (*)(void *)` |
| `thrd_start_t` | Тип функции потока: `void *(*)(void *)` |

### Константы кодов возврата

| Константа | Описание |
|---|---|
| `thrd_success` | Операция выполнена успешно |
| `thrd_nomem` | Операция не выполнена из-за нехватки памяти |
| `thrd_error` | Произошла неуточнённая ошибка |
| `thrd_busy` | Запрашиваемый ресурс сейчас занят |
| `thrd_timedout` | Истекло время ожидания |

### Константы инициализации

| Константа | Описание |
|---|---|
| `mtx_plain` | Простой (нерекурсивный) мьютекс без поддержки времени ожидания |
| `mtx_recursive` | Рекурсивный мьютекс: один и тот же поток может блокировать его несколько раз |
| `mtx_timed` | Мьютекс с поддержкой блокировки по времени |
| `ONCE_FLAG_INIT` | Инициализатор для переменной `once_flag` |
| `MTX_INIT` | Инициализатор для переменной `mtx_t` (блокировка по умолчанию) |
| `TSS_DTOR_ITERATIONS` | Максимальное количество вызовов деструкторов для освобождения потокового хранилища |

### Функции потоков

| Функция | Описание |
|---|---|
| `thrd_create()` | Создание нового потока |
| `thrd_current()` | Получение идентификатора текущего потока |
| `thrd_detach()` | Отсоединение потока (освобождение ресурсов при завершении) |
| `thrd_equal()` | Сравнение двух идентификаторов потоков |
| `thrd_exit()` | Завершение текущего потока с кодом возврата |
| `thrd_join()` | Ожидание завершения потока и получение его кода возврата |
| `thrd_sleep()` | Приостановка потока на указанное время |
| `thrd_yield()` | Уступка процессора другому потоку |

### Функции мьютексов

| Функция | Описание |
|---|---|
| `mtx_init()` | Инициализация мьютекса с указанием типа |
| `mtx_lock()` | Блокировка мьютекса (ожидание, если занят) |
| `mtx_trylock()` | Попытка блокировки без ожидания |
| `mtx_timedlock()` | Блокировка с ограничением по времени |
| `mtx_unlock()` | Разблокировка мьютекса |
| `mtx_destroy()` | Уничтожение мьютекса и освобождение ресурсов |

### Функции потокового хранилища

| Функция | Описание |
|---|---|
| `tss_create()` | Создание ключа с деструктором |
| `tss_delete()` | Удаление ключа |
| `tss_get()` | Получение значения для текущего потока |
| `tss_set()` | Установка значения для текущего потока |

### Однократное выполнение

| Функция | Описание |
|---|---|
| `call_once()` | Гарантированное однократное выполнение функции ( потокобезопасная инициализация) |

> [!NOTE]
> Мьютексы `mtx_plain` и `mtx_recursive` не поддерживают блокировку по времени — вызов `mtx_timedlock` для них возвращает `thrd_error`. Для блокировки с тайм-аутом используйте мьютекс типа `mtx_timed`.
