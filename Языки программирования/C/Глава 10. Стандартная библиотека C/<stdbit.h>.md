## Описание библиотеки

Заголовочный файл `<stdbit.h>` предоставляет набор функций для битовых операций над беззнаковыми целочисленными типами. Был введён в стандарт C23 для обеспечения переносимости операций, которые ранее реализовывались через встроенные функции компиляторов (`__builtin_clz`, `__builtin_popcount` и т. д.).

Все функции из `<stdbit.h>` являются макросами и поддерживают generic selection — одна функция работает со всеми беззнаковыми типами (`unsigned char`, `unsigned int`, `unsigned long`, `unsigned long long`). Выбор конкретной реализации происходит автоматически на этапе компиляции.

> [!NOTE]
> Функции `<stdbit.h>` обязательны для реализации (в отличие от `_Generic`-макросов). Их можно использовать без дополнительных проверок возможностей компилятора.

> [!WARNING]
> Функции `stdc_first_leading_zero`, `stdc_first_leading_one`, `stdc_first_trailing_zero`, `stdc_first_trailing_one` возвращают 0, если соответствующий бит не найден.
