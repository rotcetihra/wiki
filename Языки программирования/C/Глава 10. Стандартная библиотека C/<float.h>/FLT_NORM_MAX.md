## Определение

```c
#include <float.h>

#define FLT_NORM_MAX 3.40282346638528859812e+38F // в glibc
```

## Описание

Константа (C23) — максимальное _нормализованное_ конечное значение типа `float`. На платформах IEEE-754 совпадает с `FLT_MAX`; введена в C23 для пары с `FLT_TRUE_MIN`/`FLT_MIN`, чтобы программа могла обращаться к нормализованному диапазону выборочно.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("Нормализованный максимум float: %.9g\n", FLT_NORM_MAX);

    return 0;
}
```
