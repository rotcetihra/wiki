## Определение

```c
#include <float.h>

#define LDBL_HAS_SUBNORM 1 // в glibc
```

## Описание

Константа (C11) — признак поддержки денормализованных чисел типа `long double`: 1 — поддерживаются, 0 — нет, −1 — не определяется стандартом. В формате x87 денормализованные значения лежат в диапазоне до `LDBL_TRUE_MIN` ≈ 3.65·10⁻⁴⁹⁵¹.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    if (LDBL_HAS_SUBNORM == 1) {
        printf("Денормализованные long double поддерживаются\n");
    }

    return 0;
}
```
