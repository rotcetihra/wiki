## Определение

```c
#include <float.h>

#define FLT_TRUE_MIN 1.40129846432481707092e-45F // в glibc
```

## Описание

Константа (C11) — минимальное положительное _денормализованное_ значение типа `float`: наименьшее представимое число, большее нуля. Для binary32 это 2⁻¹⁴⁹ ≈ 1.401·10⁻⁴⁵. Следующее деление на 2 даёт уже 0 (исчерпание диапазона).

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    float x = FLT_TRUE_MIN;

    printf("%.9g\n", x); // 1.40129846e-45
    x = x / 2.0f;
    printf("x / 2: %g\n", x); // 0

    return 0;
}
```
