## Определение

```c
#include <float.h>

#define FLT_SNAN __builtin_nansf("") // в glibc
```

## Описание

Константа (C23) — сигнализирующее NaN (signaling NaN) типа `float`. Любая арифметическая операция с ним возбуждает исключение с плавающей точкой, в отличие от тихого NaN. В glibc — через встроенную функцию GCC `__builtin_nansf()`. Используется для проверки обработчиков исключений (например, в паре с `<fenv.h>`).

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    float snan = FLT_SNAN;
    float qnan = __builtin_nanf("");

    printf("Тихое NaN: %g\n", qnan);

    return 0;
}
```

> [!WARNING]
> Выполнение любой операции с `FLT_SNAN` вызывает аппаратное исключение; без обработчика оно завершает программу.
