## Определение

```c
#include <float.h>

#define DBL_DIG 15 // в glibc
```

## Описание

Константа — количество десятичных цифр q, при котором значение `double` с q значащими цифрами можно округлить до того же `double` и обратно без изменения. Говоря проще, «надёжная» точность типа: сколько десятичных знаков можно печатать, не опасаясь потери точности. Для IEEE-754 binary64 значение равно 15 (стандарт гарантирует не меньше 10).

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    double x = 1.0 / 3.0;

    printf("%.*f\n", DBL_DIG, x); // 0.333333333333333

    return 0;
}
```
