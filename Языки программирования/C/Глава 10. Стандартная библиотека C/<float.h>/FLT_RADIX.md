## Определение

```c
#include <float.h>

#define FLT_RADIX 2 // в glibc
```

## Описание

Константа — основание системы счисления, в которой представляются все типы с плавающей точкой (`float`, `double`, `long double`). Все современные реализации используют двоичную арифметику (значение 2); стандарт допускает и другие значения (например, 10 или 16). Вместе с `*_MANT_DIG` определяет точность типа: `MANT_DIG` цифр по основанию `FLT_RADIX`.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("Основание: %d\n", FLT_RADIX);

    return 0;
}
```
