## Определение

```c
#include <float.h>

#define LDBL_MIN_10_EXP (-4931) // в glibc
```

## Описание

Константа — минимальное целое e такое, что 10ᵉ представимо как нормализованный `long double`. Для 80-битного x87 и binary128 — −4931. Стандарт гарантирует значение не больше −37.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("Нижняя граница long double: 10^%d\n", LDBL_MIN_10_EXP);

    return 0;
}
```
