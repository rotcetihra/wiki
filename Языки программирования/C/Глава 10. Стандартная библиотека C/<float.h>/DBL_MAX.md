## Определение

```c
#include <float.h>

#define DBL_MAX 1.79769313486231570815e+308 // в glibc
```

## Описание

Константа — максимальное конечное значение типа `double`. Для binary64 это (2−2⁻⁵²)·2¹⁰²³ ≈ 1.798·10³⁰⁸. Используется как верхняя граница при проверке переполнения: результат вычисления, больший `DBL_MAX`, — бесконечность. Стандарт гарантирует минимум 1e37.

## Примеры

```c
#include <float.h>
#include <math.h>
#include <stdio.h>

int main(void)
{
    double x = DBL_MAX * 2.0;

    if (isinf(x)) {
        printf("Переполнение double\n");
    }

    return 0;
}
```
