## Определение

```c
#include <float.h>

#define LDBL_MIN_EXP (-16381) // в glibc
```

## Описание

Константа — минимальное целое e такое, что `FLT_RADIX^(e−1)` — нормализованный `long double`. Для 80-битного x87 и binary128 — −16381 (минимальный нормализованный порядок 2⁻¹⁶³⁸², что и даёт `LDBL_MIN`). Ниже — денормализованные значения.

## Примеры

```c
#include <float.h>
#include <math.h>
#include <stdio.h>

int main(void)
{
    long double x = ldexpl(1.0L, LDBL_MIN_EXP - 1);

    printf("%.21Lg\n", x); // 3.36210314311209350626e-4932

    return 0;
}
```
