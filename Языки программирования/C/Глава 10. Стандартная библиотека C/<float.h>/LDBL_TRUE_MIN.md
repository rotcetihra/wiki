## Определение

```c
#include <float.h>

#define LDBL_TRUE_MIN 3.64519953188247460253e-4951L // в glibc на x86-64
```

## Описание

Константа (C11) — минимальное положительное _денормализованное_ значение типа `long double`: наименьшее число, большее нуля, представимое в типе. Для 80-битного x87 — 2⁻¹⁶⁴⁴⁵ ≈ 3.645·10⁻⁴⁹⁵¹ (x87 поддерживает денормализованные значения с 64-битной мантиссой); для binary128 — 6.47517511943802511092443895822764655e-4966L.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    long double x = LDBL_TRUE_MIN;

    printf("%.21Lg\n", x); // 3.64519953188247460253e-4951
    x = x / 2.0L;
    printf("x / 2: %Lg\n", x); // 0

    return 0;
}
```
