## Определение

```c
#include <float.h>

#define FLT_EVAL_METHOD 0 // обычно 0 или 1 в зависимости от платформы
```

## Описание

Константа (C99) — способ вычисления промежуточных значений выражений с плавающей точкой:

- 0 — промежуточные значения имеют тип и точность операндов;
- 1 — `float` и `double` при вычислениях повышаются до `double` (как на классических x86);
- 2 — все промежуточные значения вычисляются как `long double`;
- −1 — способ зависит от контекста и не определён.

В glibc — 0 (x86-64 с SSE), но на x86-32 без SSE значение равно 1. Важно при переносе кода, где результат зависит от промежуточной точности (например, `float`-вычисления, которые «вдруг» дают точность `double`).

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("Способ вычисления промежуточных значений: %d\n",
           FLT_EVAL_METHOD);

    return 0;
}
```
