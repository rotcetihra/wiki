## Определение

```c
#include <float.h>

#define DBL_NORM_MAX 1.79769313486231570815e+308 // в glibc
```

## Описание

Константа (C23) — максимальное _нормализованное_ конечное значение типа `double`; на платформах IEEE-754 совпадает с `DBL_MAX`. Отличие от `DBL_MAX` введено для полноты пары «нормализованный минимум/максимум»: в реализациях с особым представлением значений `DBL_NORM_MAX` может отличаться от максимума, достижимого через денормализованные значения.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("Нормализованный максимум double: %.17g\n", DBL_NORM_MAX);

    return 0;
}
```
