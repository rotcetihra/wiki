## Определение

```c
#include <float.h>

#define LDBL_MAX 1.18973149535723176502e+4932L // в glibc на x86-64
```

## Описание

Константа — максимальное конечное значение типа `long double`: (2−2⁻⁶³)·2¹⁶³⁸³ ≈ 1.1897·10⁴⁹³² для 80-битного формата x87; для binary128 — 1.18973149535723176508575932662800702e+4932L. Большие значения не представимы даже в самом широком стандартном типе.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("%.21Lg\n", LDBL_MAX); // 1.18973149535723176502e+4932

    return 0;
}
```
