## Определение

```c
#include <float.h>

#define FLT_DIG 6 // в glibc
```

## Описание

Константа — количество десятичных цифр q, при котором округление `float` до q цифр и обратно не меняет значение: «надёжная» точность типа. Для binary32 — 6 цифр (стандарт гарантирует не меньше 6). При выборе формата вывода `%f`/`%g` на практике достаточно 6 знаков — дальше печатается «шум» неточного представления.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    float x = 1.0f / 3.0f;

    printf("%.*f\n", FLT_DIG, x); // 0.333333

    return 0;
}
```
