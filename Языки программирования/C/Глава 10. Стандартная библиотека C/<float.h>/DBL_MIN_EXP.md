## Определение

```c
#include <float.h>

#define DBL_MIN_EXP (-1021) // в glibc
```

## Описание

Константа — минимальное целое e такое, что `FLT_RADIX^(e−1)` — нормализованное `double`. Для binary64: минимальный порядок нормализованных чисел 2⁻¹⁰²² (экспонента поля −1022, при смещении 1023). Ниже — денормализованные числа вплоть до `DBL_TRUE_MIN`.

## Примеры

```c
#include <float.h>
#include <math.h>
#include <stdio.h>

int main(void)
{
    // Нормализованный минимум double: 2^(DBL_MIN_EXP - 1)
    double x = ldexp(1.0, DBL_MIN_EXP - 1);

    printf("%.17g\n", x); // 2.2250738585072014e-308

    return 0;
}
```
