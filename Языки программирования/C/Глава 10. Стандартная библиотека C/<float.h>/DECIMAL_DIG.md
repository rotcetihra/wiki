## Определение

```c
#include <float.h>

#define DECIMAL_DIG 21 // в glibc на x86-64
```

## Описание

Константа (C99) — количество десятичных цифр, достаточное для однозначного представления любого значения типа с плавающей точкой с максимальной шириной (в glibc на x86-64 — `long double` 80-битного формата: 21 цифра). До C11, когда появились `*_DECIMAL_DIG`, `DECIMAL_DIG` использовался в качестве «максимальной точности» типа. На платформах, где `long double` — binary128, значение равно 36.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("Точность максимального типа: %d цифр\n", DECIMAL_DIG);

    return 0;
}
```
