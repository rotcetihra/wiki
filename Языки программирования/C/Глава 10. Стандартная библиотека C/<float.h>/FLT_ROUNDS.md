## Определение

```c
#include <float.h>

#define FLT_ROUNDS 1 // в glibc
```

## Описание

Константа — текущий режим округления для операций с плавающей точкой: −1 — не определяется; 0 — к нулю; 1 — к ближайшему; 2 — вверх (к +∞); 3 — вниз (к −∞). В glibc по умолчанию 1 («округление к ближайшему», round-to-nearest-even). Функция `fesetround()` из `<fenv.h>` может менять режим во время выполнения, и тогда значение макроса устаревает — это константа на момент компиляции.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("Режим округления: %d\n", FLT_ROUNDS); // 1

    return 0;
}
```
