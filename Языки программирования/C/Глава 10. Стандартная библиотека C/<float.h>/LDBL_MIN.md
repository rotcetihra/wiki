## Определение

```c
#include <float.h>

#define LDBL_MIN 3.36210314311209350626e-4932L // в glibc на x86-64
```

## Описание

Константа — минимальное _нормализованное_ положительное значение типа `long double`. Для 80-битного x87 — 2⁻¹⁶³⁸² ≈ 3.362·10⁻⁴⁹³²; для binary128 — 3.36210314311209350626267781732175260e-4932L. Меньшие числа — денормализованные, вплоть до `LDBL_TRUE_MIN`.

## Примеры

```c
#include <float.h>
#include <stdio.h>

int main(void)
{
    printf("%.21Lg\n", LDBL_MIN); // 3.36210314311209350626e-4932

    return 0;
}
```
