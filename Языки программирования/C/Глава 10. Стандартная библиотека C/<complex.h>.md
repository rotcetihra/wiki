## Описание библиотеки

Заголовочный файл `<complex.h>` — «комплексные числа» (complex numbers): функции для работы с комплексными числами. Введён в стандарте C99 как часть поддержки комплексной арифметики. Определяет тип `_Complex` для хранения комплексных чисел, макросы для конструирования комплексных чисел и мнимой единицы, а также набор математических функций для комплексных аргументов.

Комплексные числа в C представляются как `float _Complex`, `double _Complex` или `long double _Complex`. Каждая функция из `<complex.h>` имеет три варианта: `float`, `double` и `long double` (например, `cabsf`, `cabs`, `cabsl`). Макросы `Complex` и `I` удобны для создания комплексных литералов.

### Типы

| Тип | Описание |
|---|---|
| `float _Complex` | Комплексное число с одинарной точностью |
| `double _Complex` | Комплексное число с двойной точностью |
| `long double _Complex` | Комплексное число с расширенной точностью |

### Макросы

| Макрос | Описание |
|---|---|
| `Complex` | Конструирование комплексного числа из вещественных частей |
| `_Complex_I` | Мнимая единица типа `float _Complex` |
| `I` | Мнимая единица типа `float _Complex` (удобный синоним) |

> [!NOTE]
