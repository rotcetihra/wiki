## Определение

```c
#include <stdbool.h>

#define bool _Bool   // C99–C17
bool                // C23: ключевое слово
```

## Описание

Логический тип: хранит значения «истина» (1) или «ложь» (0). В C99–C17 `<stdbool.h>` определяет макрос `bool`, раскрывающийся в `_Bool`; в C23 `bool` — встроенное ключевое слово. Значения любого типа при приведении к `bool` дают 0 или 1; печать `bool` — через `%d`. Стандартный размер обычно 1 байт, но у типа нет гарантии размера.

В отличие от использования `int` для флагов, `bool` самодокументирует намерение «только истина/ложь», хотя обещает не больше (компилятор не запрещает запись любых значений).

## Примеры

```c
#include <stdbool.h>
#include <stdio.h>

bool is_even(int n)
{
    return n % 2 == 0;
}

int main(void)
{
    bool flag = is_even(4);

    printf("flag = %d\n", flag);          // 1
    printf("flag == true: %d\n", flag == true);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Понятное намерение в сигнатурах функций | Наивное сравнение с `true`/`false` избыточно (достаточно `if (flag)`) |
