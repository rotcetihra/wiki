## Определение

```c
#include <stdbool.h>

#define true 1  // C99–C17
true            // C23: ключевое слово
```

## Описание

Константа — логическая истина, значение 1. В C99–C17 `true` — макрос, раскрывающийся в 1; в C23 — ключевое слово. `true == 1`; при присваивании в `bool` даёт значение 1. Любое ненулевое значение «истинно» в условных выражениях, но приводится к `bool` как 1.

## Примеры

```c
#include <stdbool.h>
#include <stdio.h>

int main(void)
{
    bool ok = true;

    printf("ok: %d\n", ok);        // 1
    printf("true == 1: %d\n", true == 1); // 1

    while (ok) {
        printf("Цикл выполняется\n");
        ok = false;
    }

    return 0;
}
```
