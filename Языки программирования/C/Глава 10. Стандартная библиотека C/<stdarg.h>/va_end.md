## Определение

```c
#include <stdarg.h>

#define va_end(ap) // реализация
```

## Описание

Макрос — завершение работы со списком переменных аргументов: снимает состояние, созданное `va_start()` (или `va_copy()`). Вызов обязателен перед возвратом из функции, включая выходы через `return` и `goto`; пропуск `va_end()` — неопределённое поведение (на практике может привести к утечке кадров в регистровых архитектурах).

`va_end()` необходимо вызывать для каждой копии `va_list`, созданной `va_copy()`.

## Примеры

```c
#include <stdarg.h>
#include <stdio.h>

int max_of(int count, ...)
{
    va_list ap;
    int result = 0;

    va_start(ap, count);
    for (int i = 0; i < count; i++) {
        int x = va_arg(ap, int);
        if (x > result) {
            result = x;
        }
    }
    va_end(ap); // обязательно

    return result;
}

int main(void)
{
    printf("%d\n", max_of(4, 3, 8, 2, 5)); // 8

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Обязательное завершение ресурса списка | Пропуск вызова — тихая ошибка (неопределённое поведение) |
