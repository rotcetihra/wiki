## Определение

```c
#include <stdarg.h>

#define va_arg(ap, тип) // реализация
```

## Описание

Макрос — извлечение очередного аргумента из списка `va_list` как значения указанного типа; после вызова внутренний указатель списка перемещается к следующему аргументу. Тип должен совпадать с фактически переданным с учётом продвижения типов: `char`/`short` приходят как `int`, `float` — как `double`.

Проверить, что аргументы не закончились, невозможно — функция должна знать количество аргументов из других параметров или из форматной строки (как `printf()`). Неверный тип или перебор аргументов — неопределённое поведение.

## Примеры

```c
#include <stdarg.h>
#include <stdio.h>

void print_all(const char *prefix, int count, ...)
{
    va_list ap;

    va_start(ap, count);
    for (int i = 0; i < count; i++) {
        int x = va_arg(ap, int); // все целые — как int
        printf("%s%d\n", prefix, x);
    }
    va_end(ap);
}

int main(void)
{
    print_all("> ", 3, 1, 2, 3);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простой доступ к произвольному аргументу | Ошибка в типе — неопределённое поведение без предупреждения |
