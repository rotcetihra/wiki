## Определение

```c
#include <stdarg.h>

#define va_start(ap, last) // C89: инициализация
#define va_start(ap)       // C23: без последнего параметра
```

## Описание

Макрос — инициализация списка переменных аргументов: связывает объект `va_list` `ap` с началом необязательных аргументов функции. До C23 обязательным был второй параметр — имя последнего именованного параметра функции (`va_start(ap, count)`), по которому определяется адрес первых необязательных аргументов. В C23 этот параметр исключён: `va_start(ap)`.

Вызов `va_start()` разрешён только внутри функции с переменным числом аргументов. После обхода списка обязателен вызов `va_end()`.

## Примеры

```c
#include <stdarg.h>
#include <stdio.h>

double average(int count, ...)
{
    va_list ap;
    double sum = 0.0;

    va_start(ap, count);
    for (int i = 0; i < count; i++) {
        sum += va_arg(ap, double); // float продвигается в double
    }
    va_end(ap);

    return sum / count;
}

int main(void)
{
    printf("%.2f\n", average(3, 1.0, 2.0, 3.0)); // 2.00

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Единственный способ начать обход | Параметр `last` в C89–C17 — источник ошибок (при передаче в другую функцию) |
