## Определение

```c
#include <stdarg.h>

typedef __builtin_va_list va_list; // в GCC/glibc
```

## Описание

Тип — состояние доступа к переменным аргументам функции. В glibc это массив из одного элемента встроенного типа GCC `__builtin_va_list` (обычно указатель на область аргументов в стеке или регистрах). Объект `va_list` инициализируется макросом `va_start()`, «двигается» вызовами `va_arg()` и закрывается `va_end()`. Массив `va_list` нельзя напрямую присваивать и сравнивать — только через `va_copy()`.

`va_list` можно передавать в другие функции (например, в `vfprintf()`), поэтому функции-обёртки для функций с переменным числом аргументов пишутся через `v`-варианты (`vprintf()`, `vscanf()`).

## Примеры

```c
#include <stdarg.h>
#include <stdio.h>

int sum(int count, ...)
{
    va_list ap;
    int total = 0;

    va_start(ap, count);
    for (int i = 0; i < count; i++) {
        total += va_arg(ap, int);
    }
    va_end(ap);

    return total;
}

int main(void)
{
    printf("%d\n", sum(3, 10, 20, 30)); // 60

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Единственный способ доступа к переменным аргументам | Нет проверки количества и типов аргументов |
