## Описание библиотеки

Заголовочный файл `<uchar.h>` — «юникодные символы» (Unicode characters): типы и функции для работы с символами Unicode в кодировках UTF-16 и UTF-32. Введён в стандарте C11 как часть поддержки символов Unicode.

Библиотека определяет два целочисленных типа `char16_t` и `char32_t` для хранения кодовых элементов Unicode, а также четыре функции преобразования между многобайтовыми строками (в кодировке, определённой текущей локалью) и широкими символьными типами.

### Типы

| Тип | Описание |
|---|---|
| `char16_t` | Беззнаковый целый тип для символов UTF-16 (минимум 16 бит) |
| `char32_t` | Беззнаковый целый тип для символов UTF-32 (минимум 32 бита) |

### Функции

| Функция | Описание |
|---|---|
| `mbrtoc16()` | Многобайтовая последовательность → `char16_t` |
| `mbrtoc32()` | Многобайтовая последовательность → `char32_t` |
| `c16rtomb()` | `char16_t` → многобайтовая последовательность |
| `c32rtomb()` | `char32_t` → многобайтовая последовательность |

> [!NOTE]
> Для работы с широкими строками (`wchar_t`) и их классификацией см. `<wchar.h>` и `<wctype.h>`. Типы `char8_t` (для UTF-8) и литералы `u8"..."` введены в стандарте C23.
