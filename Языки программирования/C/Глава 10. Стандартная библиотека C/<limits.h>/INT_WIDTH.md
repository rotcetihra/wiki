## Определение

```c
#include <limits.h>

#define INT_WIDTH 32 // в glibc
```

## Описание

Константа (C23) — ширина типа `int`: количество битов в значении типа без учёта бита знака. По стандарту не меньше 16 (при гарантированном минимуме `INT_MAX` 32767); на всех распространённых платформах равна 32. От `sizeof(int) * CHAR_BIT` отличается тем, что не включает знаковый бит.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("Ширина int: %d\n", INT_WIDTH);

    return 0;
}
```
