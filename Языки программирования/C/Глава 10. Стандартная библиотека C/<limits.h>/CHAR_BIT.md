## Определение

```c
#include <limits.h>

#define CHAR_BIT 8 // на всех современных платформах
```

## Описание

Константа — количество битов в байте (в одном объекте типа `char`). Стандарт гарантирует, что `CHAR_BIT` не меньше 8. На всех современных платформах (x86, ARM, RISC-V) значение равно 8, поэтому `sizeof` в байтах совпадает с размером в битах, делённым на 8. Однако переносимая программа, работающая с битами, должна использовать `CHAR_BIT`, а не число 8.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    // Размер int в битах
    printf("int: %zu бит\n", sizeof(int) * CHAR_BIT);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет писать код, работающий на платформах с байтом не 8 бит | На практике всегда 8, что провоцирует игнорирование константы |
