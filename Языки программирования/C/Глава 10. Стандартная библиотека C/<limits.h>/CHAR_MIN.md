## Определение

```c
#include <limits.h>

#define CHAR_MIN (-128) // в glibc на Linux (char со знаком)
```

## Описание

Константа — минимальное значение типа `char`. Если `char` знаковый — совпадает с `SCHAR_MIN` (в glibc на Linux — −128), если беззнаковый — равна 0 (например, в MSVC). Стандарт гарантирует, что `CHAR_MIN` не больше 0 и не меньше −127.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("Минимум char: %d\n", CHAR_MIN);

    return 0;
}
```
