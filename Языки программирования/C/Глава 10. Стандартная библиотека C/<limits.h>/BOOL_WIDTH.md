## Определение

```c
#include <limits.h>

#define BOOL_WIDTH 1 // в glibc
```

## Описание

Константа (C23) — ширина типа `bool`: количество битов в значении этого типа; по стандарту всегда равна 1. Значение `TRUE`/`FALSE`... нет — хранится как 0 или 1, остальные биты отсутствуют, потому что `bool` — тип с одной двоичной цифрой.

## Примеры

```c
#include <limits.h>
#include <stdbool.h>
#include <stdio.h>

int main(void)
{
    bool flag = true;

    printf("Ширина bool: %d\n", BOOL_WIDTH);
    printf("Размер bool: %zu байт\n", sizeof flag);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантированная ширина 1 бит по стандарту | Не показывает, сколько памяти занимает тип (обычно 1 байт) |
