## Определение

```c
#include <limits.h>

#define LONG_WIDTH 64 // в glibc на 64-битных системах
```

## Описание

Константа (C23) — ширина типа `long`: количество битов в значении типа без учёта бита знака. На 64-битных платформах равна 64, на 32-битных — 32. Использование `LONG_WIDTH` (вместо `CHAR_BIT * sizeof(long)`) — идиоматический способ писать код подсчёта битов, переносимый между 32/64-битными системами.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("Ширина long: %d\n", LONG_WIDTH);

    return 0;
}
```
