## Определение

```c
#include <limits.h>

#define SHRT_MAX 32767 // в glibc
```

## Описание

Константа — максимальное значение типа `short`. Стандарт гарантирует, что `SHRT_MAX` не меньше 32767; на всех распространённых платформах `short` занимает 16 бит, и максимум равен 32767.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    short n = SHRT_MAX;

    printf("Максимум short: %d\n", SHRT_MAX);

    return 0;
}
```
