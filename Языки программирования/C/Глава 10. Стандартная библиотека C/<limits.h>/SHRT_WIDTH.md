## Определение

```c
#include <limits.h>

#define SHRT_WIDTH 16 // в glibc
```

## Описание

Константа (C23) — ширина типа `short`: количество битов в значении типа без учёта бита знака. По стандарту не меньше 15; на всех распространённых платформах равна 16.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("Ширина short: %d\n", SHRT_WIDTH);

    return 0;
}
```
