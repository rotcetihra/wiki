## Определение

```c
#include <limits.h>

#define MB_LEN_MAX 16 // в glibc
```

## Описание

Константа — максимальное количество байт, которое может занимать один многобайтовый символ в любой из поддерживаемых локалей. Стандарт гарантирует, что `MB_LEN_MAX` не меньше 1. Используется при выделении буферов для функций многобайтового преобразования (`mbtowc()`, `wcrtomb()` и т. п.). В glibc значение 16 позволяет работать с самыми длинными последовательностями (например, в нестандартных локалях).

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    char buf[MB_LEN_MAX];

    printf("Максимальная длина символа: %d\n", MB_LEN_MAX);

    return 0;
}
```
