## Определение

```c
#include <limits.h>

#define CHAR_MAX 127 // в glibc на Linux (char со знаком)
```

## Описание

Константа — максимальное значение типа `char`. Значение зависит от того, является ли `char` знаковым: если знаковый — совпадает с `SCHAR_MAX` (в glibc на Linux — 127), если беззнаковый — с `UCHAR_MAX` (255, например в MSVC). Стандарт гарантирует, что `CHAR_MAX` не меньше 127.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    char c = CHAR_MAX;

    printf("Максимум char: %d\n", CHAR_MAX);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет не знать, знаковый ли `char` на платформе | Значение различается между платформами (127 или 255) |
