## Определение

```c
#include <limits.h>

#define LONG_MIN (-LONG_MAX - 1L) // в glibc
```

## Описание

Константа — минимальное значение типа `long`. На 64-битных платформах равна −9223372036854775808, на 32-битных — −2147483648. Записана через `(-LONG_MAX - 1L)`, поскольку литерал «минус максимум минус один» в типе `long` не помещается.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("Минимум long: %ld\n", LONG_MIN);

    return 0;
}
```
