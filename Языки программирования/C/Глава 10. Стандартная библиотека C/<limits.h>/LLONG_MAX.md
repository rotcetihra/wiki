## Определение

```c
#include <limits.h>

#define LLONG_MAX 9223372036854775807LL // в glibc
```

## Описание

Константа (C99) — максимальное значение типа `long long`. Стандарт гарантирует, что `LLONG_MAX` не меньше 9223372036854775807; на всех распространённых платформах `long long` занимает 64 бита, и значение равно этому минимуму. Суффикс `LL` в определении гарантирует тип константы (при вычислениях с более узкими типами возможна потеря точности).

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    long long n = LLONG_MAX;

    printf("Максимум long long: %lld\n", LLONG_MAX);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Максимально широкий гарантированный целочисленный тип | На практике всегда 64 бита, значение не меняется |
