## Определение

```c
#include <limits.h>

#define ULONG_WIDTH 64 // в glibc на 64-битных системах
```

## Описание

Константа (C23) — ширина типа `unsigned long`: количество битов в значении типа. На 64-битных платформах равна 64, на 32-битных — 32. Как и для `LONG_WIDTH`, значение зависит от модели данных (`LP64`/`ILP32`).

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("Ширина unsigned long: %d\n", ULONG_WIDTH);

    return 0;
}
```
