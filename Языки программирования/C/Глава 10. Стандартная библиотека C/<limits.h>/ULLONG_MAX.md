## Определение

```c
#include <limits.h>

#define ULLONG_MAX 18446744073709551615ULL // в glibc
```

## Описание

Константа (C99) — максимальное значение типа `unsigned long long`. Стандарт гарантирует, что `ULLONG_MAX` не меньше 18446744073709551615; на всех распространённых платформах `unsigned long long` занимает 64 бита, и значение равно этому минимуму. Это наибольшее значение среди гарантированных типов — верхняя граница всех беззнаковых типов с фиксированным размером.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    unsigned long long n = ULLONG_MAX;

    printf("Максимум unsigned long long: %llu\n", ULLONG_MAX);

    return 0;
}
```
