## Определение

```c
#include <limits.h>

#define UINT_WIDTH 32 // в glibc
```

## Описание

Константа (C23) — ширина типа `unsigned int`: количество битов в значении типа. Для беззнаковых типов совпадает с полной шириной представления: на распространённых платформах это 32 бита.

## Примеры

```c
#include <limits.h>
#include <stdio.h>

int main(void)
{
    printf("Ширина unsigned int: %d\n", UINT_WIDTH);

    return 0;
}
```
