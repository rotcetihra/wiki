## Определение

```c
#include <limits.h>

#define ULONG_MAX 18446744073709551615UL // в glibc на 64-битных системах
```

## Описание

Константа — максимальное значение типа `unsigned long`. На 64-битных платформах (Linux x86-64, aarch64) равна 18446744073709551615, на 32-битных — 4294967295. Стандарт гарантирует минимум 4294967295. Значение этого макроса важно знать при работе с функциями, принимающими `unsigned long` (например, `strtoul()`), и при выборе типа для больших счётчиков.

## Примеры

```c
#include <limits.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    unsigned long n = strtoul("18446744073709551615", NULL, 10);

    if (n == ULONG_MAX) {
        printf("Переполнение при преобразовании\n");
    }

    return 0;
}
```
