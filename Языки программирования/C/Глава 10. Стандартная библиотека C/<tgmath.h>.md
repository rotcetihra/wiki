## Описание библиотеки

Заголовочный файл `<tgmath.h>` — обобщённая математическая библиотека (type-generic math): макросы, которые на основе типа аргумента автоматически выбирают нужную версию математической функции из `<math.h>` (для `float`, `double`, `long double`) или `<complex.h>` (для комплексных типов).

Механизм выбора реализован через макрос `_Generic` (C11). Например, макрос `tgsin(x)` при передаче `float` вызывает `sinf`, при `double` — `sin`, при `long double` — `sinl`, а при комплексном типе — `csin` / `csinf` / `csinl`. Это позволяет писать универсальный код, работающий с любым числовым типом, без необходимости явно указывать суффикс функции.

Библиотека введена в стандарт C99 и является основным способом написания обобщённого математического кода в C. До появления `<tgmath.h>` приходилось использовать макросы с `##` для конкатенации имён или писать отдельные версии для каждого типа.

> [!NOTE]
> Макросы `<tgmath.h>` не заменяют `<math.h>` и `<complex.h>` — для работы с конкретными типами по-прежнему можно вызывать функции напрямую. `<tgmath.h>` удобен, когда тип может меняться.

> [!WARNING]
> Макросы `<tgmath.h>` не определяют поведение для аргументов, не являющихся числами. Передача нечислового значения (например, `NULL`) приводит к неопределённому поведению.
