## Определение

```c
#include <stdio.h>

int snprintf(char *s, size_t n, const char *format, ...);
```

## Описание

Функция `snprintf` записывает форматированный текст в строку `s` размером не более `n` байт (включая завершающий нуль-символ). Если `n` равно 0, запись не происходит. Возвращает количество символов, которое было бы записано без ограничения (не считая `\0`).

## Пример

```c
#include <stdio.h>

int main(void)
{
    char buf[32];
    int len = snprintf(buf, sizeof(buf), "Число: %d", 42);
    printf("Буфер: %s\n", buf);
    printf("Требовалось символов: %d\n", len);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Целевая строка |
| `n` | Максимальный размер буфера |
| `format` | Строка формата |
| `...` | Аргументы для подстановки |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Положительное | Количество символов (без `\0`), которые были бы записаны |
| Отрицательное | Произошла ошибка |

| Преимущество | Недостаток |
