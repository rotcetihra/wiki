## Определение

```c
#include <stdio.h>

extern FILE *stdout;
```

## Описание

`stdout` — стандартный поток вывода. По умолчанию связывает программу с экраном (терминалом). По умолчанию используется построчная буферизация (`_IOLBF`), что означает сброс буфера при записи символа новой строки.

## Пример

```c
#include <stdio.h>

int main(void)
{
    printf("Обычный вывод\n");
    fprintf(stdout, "Вывод в stdout напрямую\n");
    puts("Вывод через puts");
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный канал вывода | Построчная буферизация может задерживать вывод |
| Может быть перенаправлен в файл | Не подходит для вывода ошибок |
| Стандартная часть ISO C | — |
