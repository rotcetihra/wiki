## Определение

```c
#include <stdio.h>
#include <stdarg.h>

int vfprintf(FILE *stream, const char *format, va_list arg);
```

## Описание

Функция `vfprintf` — аналог `fprintf`, принимающий `va_list` вместо переменного числа аргументов. Используется внутри пользовательских обёрток над `fprintf`.

## Пример

```c
#include <stdio.h>
#include <stdarg.h>

void log_message(FILE *fp, const char *fmt, ...)
{
    va_list args;
    va_start(args, fmt);
    vfprintf(fp, fmt, args);
    va_end(args);
}

int main(void)
{
    log_message(stdout, "Число: %d, Строка: %s\n", 42, "текст");
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Выходной поток |
| `format` | Строка формата |
| `arg` | Список аргументов `va_list` |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Положительное | Количество записанных символов |
| Отрицательное | Произошла ошибка |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет создавать обёртки с форматированием | Требует `<stdarg.h>` |
| Стандартная функция ISO C | Нет ограничения длины |
