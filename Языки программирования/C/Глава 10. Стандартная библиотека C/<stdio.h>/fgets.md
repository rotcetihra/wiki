## Определение

```c
#include <stdio.h>

char *fgets(char *s, int size, FILE *stream);
```

## Описание

Функция `fgets` считывает не более `size - 1` символов из потока `stream` и сохраняет их в строку `s` с завершающим `\0`. Чтение прекращается при достижении символа новой строки, конца файла или ограничения `size`. Символ `\n` включается в строку.

## Пример

```c
#include <stdio.h>

int main(void)
{
    char buf[64];
    printf("Введите строку: ");
    if (fgets(buf, sizeof(buf), stdin) != NULL) {
        printf("Прочитано: %s", buf);
    }
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Буфер для строки |
| `size` | Максимальный размер буфера |
| `stream` | Входной поток |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `s` | Строка успешно прочитана |
| `NULL` | Ошибка или конец файла |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|

| Стандартная функция ISO C | Нужно удалять `\n` вручную |
