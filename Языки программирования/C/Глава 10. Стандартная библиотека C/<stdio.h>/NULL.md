## Определение

```c
#include <stdio.h>

#define NULL /* implementation-defined null pointer constant */
```

## Описание

Макрос `NULL` определяет константу нулевого указателя. Может быть реализован как `(void*)0`, `0` или `__null` (в зависимости от компилятора). Используется для инициализации указателей, проверки возвращаемых значений функций (например, `malloc`, `fopen`) и обозначения отсутствия объекта.

В C23 определён также `nullptr` из `<stddef.h>`, который является предпочтительной константой нулевого указателя.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = NULL;

    fp = fopen("test.txt", "r");
    if (fp == NULL) {
        printf("Файл не найден\n");
    }

    int *ptr = NULL;
    if (ptr == NULL) {
        printf("Указатель не инициализирован\n");
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Портативная константа нулевого указателя | Может быть реализован как `0` (не `void*`) |
| Стандартная часть ISO C | В C23 предпочтительнее `nullptr` |
| Универсальна для всех типов указателей | — |
