## Определение

```c
#include <stdio.h>
#include <stdarg.h>

int vprintf(const char *format, va_list arg);
```

## Описание

Функция `vprintf` — аналог `printf`, принимающий `va_list` вместо переменного числа аргументов. Эквивалентна `vfprintf(stdout, format, arg)`.

## Пример

```c
#include <stdio.h>
#include <stdarg.h>

void debug(const char *fmt, ...)
{
    va_list args;
    va_start(args, fmt);
    vprintf(fmt, args);
    va_end(args);
}

int main(void)
{
    debug("Отладка: %d, %s\n", 42, "ок");
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `format` | Строка формата |
| `arg` | Список аргументов `va_list` |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Положительное | Количество выведенных символов |
| Отрицательное | Произошла ошибка |
