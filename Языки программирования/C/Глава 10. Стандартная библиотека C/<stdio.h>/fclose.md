## Определение

```c
#include <stdio.h>

int fclose(FILE *stream);
```

## Описание

Функция `fclose` закрывает поток `stream` и сбрасывает все его буферы. Все привязанные к потоку ресурсы освобождаются. Повторный вызов `fclose` с тем же указателем приводит к неопределённому поведению.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "w");
    if (fp == NULL) return 1;

    fprintf(fp, "Данные\n");
    if (fclose(fp) != 0) {
        perror("Ошибка закрытия");
        return 1;
    }
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Указатель на закрываемый поток |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Поток успешно закрыт |
| `EOF` | Произошла ошибка при сбросе |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Освобождает все ресурсы потока | Повторное закрытие — UB |
| Стандартная функция ISO C | Нельзя использовать после `fclose` |
| Сбрасывает буферы | — |
