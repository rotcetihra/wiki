## Определение

```c
#include <stdio.h>

char *gets(char *s);
```

## Описание

Функция `gets` считывает строку из `stdin` в буфер `s` до символа новой строки или конца файла. Символ `\n` удаляется, строка завершается `\0`.

> [!WARNING]
> Функция `gets` удалена из стандарта C23. Она небезопасна — невозможно ограничить длину ввода, что приводит к переполнению буфера. Всегда используйте `fgets` вместо неё.

## Пример

```c
#include <stdio.h>

int main(void)
{
    char buf[64];
    printf("Введите строку: ");
    gets(buf);
    printf("Вы ввели: %s\n", buf);
    return 0;
}
```

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `s` | Строка успешно прочитана |
| `NULL` | Ошибка или конец файла |

## Плюсы и минусы
