## Определение

```c
#include <stdio.h>

#define FILENAME_MAX /* целочисленная константа */
```

## Описание

Макрос `FILENAME_MAX` определяет максимальную длину имени файла (включая завершающий нуль-символ), которую гарантированно поддерживает реализация. Используется для выделения буфера под имя файла.

## Пример

```c
#include <stdio.h>

int main(void)
{
    char filename[FILENAME_MAX];
    printf("Максимальная длина имени файла: %d\n", FILENAME_MAX);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует безопасный размер буфера | Значение может быть чрезмерно большим |
| Стандартная часть ISO C | Не учитывает ограничения файловой системы |

## Похожие макросы

- `L_tmpnam` — размер буфера для имени временного файла
- `FOPEN_MAX` — максимальное количество открытых файлов
