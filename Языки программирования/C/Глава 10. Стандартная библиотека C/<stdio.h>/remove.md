## Определение

```c
#include <stdio.h>

int remove(const char *filename);
```

## Описание

Функция `remove` удаляет файл с именем `filename`. Если файл открыт, поведение не определено. Возвращает `0` при успешном удалении и ненулевое значение при ошибке.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("temp.txt", "w");
    fprintf(fp, "Данные\n");
    fclose(fp);

    if (remove("temp.txt") == 0) {
        printf("Файл удалён\n");
    } else {
        perror("Ошибка удаления");
    }
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `filename` | Имя удаляемого файла |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Файл успешно удалён |
| Ненулевое | Произошла ошибка |
