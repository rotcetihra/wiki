## Определение

```c
#include <stdio.h>

#define SEEK_SET /* целочисленная константа */
```

## Описание

Макрос `SEEK_SET` используется вторым аргументом функции `fseek` для указания, что смещение отсчитывается от начала файла.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "r");
    if (fp == NULL) return 1;

    fseek(fp, 0, SEEK_SET);
    printf("Позиция в начале: %ld\n", ftell(fp));

    fclose(fp);
    return 0;
}
```

## Похожие макросы

- `SEEK_CUR` — от текущей позиции
- `SEEK_END` — от конца файла
- `rewind` — перемотка в начало (эквивалент `fseek(fp, 0, SEEK_SET)`)
