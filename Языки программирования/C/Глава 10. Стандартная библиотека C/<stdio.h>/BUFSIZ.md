## Определение

```c
#include <stdio.h>

#define BUFSIZ /* целочисленная константа */
```

## Описание

Макрос `BUFSIZ` определяет размер стандартного буфера, используемого функциями ввода-вывода по умолчанию. Обычно это 8192 байта. Используется как аргумент для `setbuf`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    printf("Размер стандартного буфера: %d байт\n", BUFSIZ);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Оптимальный размер буфера по умолчанию | Значение зависит от реализации |
| Стандартная часть ISO C | Не подходит для всех сценариев |

## Похожие макросы

- `_IOFBF`, `_IOLBF`, `_IONBF` — стратегии буферизации
- `setvbuf` — установка размера буфера
