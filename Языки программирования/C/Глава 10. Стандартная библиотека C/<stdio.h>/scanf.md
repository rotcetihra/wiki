## Определение

```c
#include <stdio.h>

int scanf(const char *format, ...);
```

## Описание

Функция `scanf` считывает данные из `stdin` в соответствии с форматом `format`. Эквивалентна `fscanf(stdin, format, ...)`. Возвращает количество успешно считанных элементов.

## Пример

```c
#include <stdio.h>

int main(void)
{
    int age;
    printf("Введите возраст: ");
    scanf("%d", &age);
    printf("Ваш возраст: %d\n", age);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `format` | Строка формата |
| `...` | Указатели на переменные для чтения |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Количество элементов | Успешно считанные элементы |
| `EOF` | Ошибка или конец файла |
| `0` | Ни один элемент не был сопоставлен |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простой ввод данных | Переполнение буферов |
| Поддерживает多种 форматов | Нет проверки границ |
| Стандартная функция ISO C | Небезопасна для строк |
