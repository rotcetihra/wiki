## Определение

```c
#include <stdio.h>

int fseek(FILE *stream, long offset, int origin);
```

## Описание

Функция `fseek` устанавливает позицию в потоке `stream`. Параметр `origin` определяет начало отсчёта: `SEEK_SET` (начало файла), `SEEK_CUR` (текущая позиция) или `SEEK_END` (конец файла). `offset` — смещение в байтах.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "w+");
    fprintf(fp, "АБВГД");
    fseek(fp, 0, SEEK_SET);
    printf("Текущая позиция: %ld\n", ftell(fp));
    fseek(fp, 2, SEEK_SET);
    printf("После смещения: %ld\n", ftell(fp));
    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Поток |
| `offset` | Смещение в байтах |
| `origin` | Начало отсчёта (`SEEK_SET`, `SEEK_CUR`, `SEEK_END`) |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Позиция успешно установлена |
| Ненулевое | Произошла ошибка |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрое позиционирование | Для текстовых потоков `offset` должен быть получен через `ftell` |
| Стандартная функция ISO C | Поведение не определено для потоков, открытых только для записи |
