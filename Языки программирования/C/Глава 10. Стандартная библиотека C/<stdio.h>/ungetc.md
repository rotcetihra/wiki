## Определение

```c
#include <stdio.h>

int ungetc(int c, FILE *stream);
```

## Описание

Функция `ungetc` возвращает символ `c` обратно в поток `stream`. Следующее чтение из потока вернёт этот символ. Гарантируется возврат хотя бы одного символа. При возврате `EOF` ничего не происходит.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "w+");
    fprintf(fp, "ABC");
    rewind(fp);

    int ch = fgetc(fp);
    printf("Первый: %c\n", ch);

    ungetc(ch, fp);
    ch = fgetc(fp);
    printf("Повторно: %c\n", ch);

    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Возвращаемый символ (преобразуется в `unsigned char`) |
| `stream` | Поток |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `c` | Символ успешно возвращён в поток |
| `EOF` | Ошибка (символ не возвращён) |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет «заглянуть» в поток | Гарантирован только один возврат |
| Полезно для парсеров | Позиция файла не изменяется |
| Стандартная функция ISO C | Для бинарных потоков ограничено |
