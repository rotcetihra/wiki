## Определение

```c
#include <stdio.h>

int fprintf(FILE *stream, const char *format, ...);
```

## Описание

Функция `fprintf` записывает форматированный текст в поток `stream`. Параметр `format` определяет формат вывода, за которым следуют аргументы. Возвращает количество записанных символов или отрицательное значение при ошибке.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("log.txt", "w");
    int age = 25;
    fprintf(fp, "Имя: %s, Возраст: %d\n", "Иван", age);
    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Выходной поток |
| `format` | Строка формата |
| `...` | Аргументы для подстановки |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Положительное | Количество записанных символов |
| Отрицательное | Произошла ошибка |
