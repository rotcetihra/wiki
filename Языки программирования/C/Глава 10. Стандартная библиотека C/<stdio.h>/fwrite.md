## Определение

```c
#include <stdio.h>

size_t fwrite(const void *ptr, size_t size, size_t nmemb, FILE *stream);
```

## Описание

Функция `fwrite` записывает до `nmemb` элементов размером `size` байт из массива `ptr` в поток `stream`. Возвращает количество успешно записанных элементов.

## Пример

```c
#include <stdio.h>

int main(void)
{
    int data[] = {10, 20, 30, 40, 50};
    FILE *fp = fopen("data.bin", "wb");
    size_t written = fwrite(data, sizeof(int), 5, fp);
    printf("Записано %zu элементов\n", written);
    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `ptr` | Указатель на записываемые данные |
| `size` | Размер одного элемента в байтах |
| `nmemb` | Количество элементов для записи |
| `stream` | Выходной поток |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Количество элементов | Успешно записанные элементы (≤ `nmemb`) |

| Преимущество | Недостаток |

| Стандартная функция ISO C | Нужно вычислять количество элементов |
