## Определение

```c
#include <stdio.h>
#include <stdarg.h>

int vfscanf(FILE *stream, const char *format, va_list arg);
```

## Описание

Функция `vfscanf` — аналог `fscanf`, принимающий `va_list` вместо переменного числа аргументов. Используется для создания пользовательских обёрток над `fscanf`.

## Пример

```c
#include <stdio.h>
#include <stdarg.h>

int scan_ints(FILE *fp, int *a, int *b)
{
    return vfscanf(fp, "%d %d", a, b);
}

int main(void)
{
    FILE *fp = fopen("data.txt", "w+");
    fprintf(fp, "10 20");
    rewind(fp);
    int a, b;
    scan_ints(fp, &a, &b);
    printf("%d %d\n", a, b);
    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Входной поток |
| `format` | Строка формата |
| `arg` | Список аргументов `va_list` |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Количество элементов | Успешно считанные элементы |
| `EOF` | Ошибка или конец файла |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет создавать обёртки с чтением | Требует `<stdarg.h>` |
| Стандартная функция ISO C | Ошибки формата трудно обнаружить |
