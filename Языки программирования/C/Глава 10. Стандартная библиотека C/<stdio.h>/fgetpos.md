## Определение

```c
#include <stdio.h>

int fgetpos(FILE *stream, fpos_t *pos);
```

## Описание

Функция `fgetpos` сохраняет текущую позицию в потоке `stream` в переменную `pos`. Позиция может быть восстановлена позже через `fsetpos`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("test.txt", "w+");
    fprintf(fp, "АБВГД\n");

    fpos_t pos;
    fgetpos(fp, &pos);

    fprintf(fp, "ЕЖЗИЙ\n");
    fsetpos(fp, &pos);

    char buf[64];
    fgets(buf, sizeof(buf), fp);
    printf("С позиции: %s", buf);

    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `stream` | Поток |
| `pos` | Указатель на переменную для сохранения позиции |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Позиция успешно сохранена |
| Ненулевое | Произошла ошибка |
