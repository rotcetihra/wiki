## Определение

```c
#include <stdio.h>

void perror(const char *s);
```

## Описание

Функция `perror` выводит в `stderr` описание ошибки, соответствующей текущему значению `errno`. Если `s` не `NULL` и не пустая строка, перед описанием выводится строка `s`, двоеточие и пробел.

## Пример

```c
#include <stdio.h>

int main(void)
{
    FILE *fp = fopen("/nonexistent/path/file.txt", "r");
    if (fp == NULL) {
        perror("Ошибка открытия файла");
        return 1;
    }
    fclose(fp);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Префикс сообщения или `NULL` |

## Возвращаемое значение

Функция ничего не возвращает.

## Пример вывода

```
Ошибка открытия файла: No such file or directory
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простой способ вывести ошибку | Зависит от локали вывод |
| Работает с `errno` | Только для ошибок, установленных в `errno` |
| Стандартная функция ISO C | Вывод идёт только в `stderr` |

## Похожие функции

- `strerror` (в `<string.h>`) — возвращает строку описания ошибки
- [[Языки программирования/C/Глава 10. Стандартная библиотека C/<stdio.h>/ferror|ferror]] — проверка флага ошибки потока
- POSIX `strerror_r` — потокобезопасная версия `strerror`
