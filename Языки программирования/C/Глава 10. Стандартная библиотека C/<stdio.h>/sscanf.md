## Определение

```c
#include <stdio.h>

int sscanf(const char *s, const char *format, ...);
```

## Описание

Функция `sscanf` считывает данные из строки `s` в соответствии с форматом `format`. Возвращает количество успешно считанных элементов.

## Пример

```c
#include <stdio.h>

int main(void)
{
    const char *data = "25 Иван 3.14";
    int age;
    char name[32];
    double pi;

    sscanf(data, "%d %s %lf", &age, name, &pi);
    printf("Возраст: %d, Имя: %s, Pi: %.2f\n", age, name, pi);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Входная строка |
| `format` | Строка формата |
| `...` | Указатели на переменные для чтения |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Количество элементов | Успешно считанные элементы |
| `EOF` | Ошибка до первого преобразования |
| `0` | Ни один элемент не был сопоставлен |

## Плюсы и минусы

| Преимущество | Недостаток |

| Гибкий формат | Ошибки формата трудно обнаружить |
