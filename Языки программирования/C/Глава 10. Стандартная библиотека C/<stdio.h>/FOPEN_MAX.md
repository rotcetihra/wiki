## Определение

```c
#include <stdio.h>

#define FOPEN_MAX /* целочисленная константа */
```

## Описание

Макрос `FOPEN_MAX` определяет минимальное количество файлов, которые могут быть одновременно открыты в программе. По стандарту не менее 8.

## Пример

```c
#include <stdio.h>

int main(void)
{
    printf("Максимум открытых файлов: %d\n", FOPEN_MAX);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует минимальный лимит | Минимальное значение по стандарту — 8 |
| Стандартная часть ISO C | Реальное значение зависит от системы |

## Похожие макросы

- `FILENAME_MAX` — максимальная длина имени файла
- `TMP_MAX` — максимальное количество уникальных имён tmpnam
