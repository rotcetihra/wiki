## Определение

```c
#include <stdio.h>

int sprintf(char *s, const char *format, ...);
```

## Описание

Функция `sprintf` записывает форматированный текст в строку `s` без ограничения размера. Возвращает количество записанных символов (не считая `\0`).

> [!WARNING]
> Функция `sprintf` не ограничивает длину результирующей строки. При недостаточном размере буфера возникает переполнение буфера (buffer overflow). Всегда используйте `snprintf` вместо `sprintf`.

## Пример

```c
#include <stdio.h>

int main(void)
{
    char buf[64];
    sprintf(buf, "Результат: %d", 42);
    printf("%s\n", buf);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Целевая строка |
| `format` | Строка формата |
| `...` | Аргументы для подстановки |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Положительное | Количество записанных символов |
| Отрицательное | Произошла ошибка |
