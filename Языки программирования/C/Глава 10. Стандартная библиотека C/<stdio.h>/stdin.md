## Определение

```c
#include <stdio.h>

extern FILE *stdin;
```

## Описание

`stdin` — стандартный поток ввода. По умолчанию связывает программу с клавиатурой (терминалом). Используется функциями `scanf`, `getchar`, `fgets` и другими функциями чтения.

## Пример

```c
#include <stdio.h>

int main(void)
{
    char name[64];
    printf("Введите имя: ");
    fgets(name, sizeof(name), stdin);
    printf("Привет, %s", name);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Единый интерфейс ввода | Может быть перенаправлен из файла |
| Стандартная часть ISO C | Буферизация по умолчанию — построчная |
