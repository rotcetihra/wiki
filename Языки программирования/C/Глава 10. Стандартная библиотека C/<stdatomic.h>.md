## Описание библиотеки

Заголовочный файл `<stdatomic.h>` предоставляет средства атомарных операций и управления памятью для параллельного программирования. Был введён в стандарт C11 для поддержки многопоточности.

Атомарные операции гарантируют, что чтение и запись переменных выполняются как непрерывные (атомарные) действия — без промежуточных состояний, видимых другим потокам. Это основа для построения lock-free и wait-free алгоритмов.

Библиотека определяет тип `atomic_flag` (единственный обязательно атомарный тип), функции для работы с атомарными переменными (`atomic_store`, `atomic_load` и т. д.), а также барьеры памяти для управления порядком выполнения операций.

> [!NOTE]
> Тип `_Atomic` ( introduced в C11) позволяет объявлять любые скалярные типы как атомарные. `<stdatomic.h>` предоставляет макросы и функции для работы с ними. В C23 добавлен тип `atomic_ref` для атомарного доступа к неатомарным объектам.

> [!WARNING]
> Атомарные операции не отменяют необходимость синхронизации. Они гарантируют атомарность отдельных операций, но не порядок выполнения нескольких операций. Для этого необходимы барьеры памяти или мьютексы.
