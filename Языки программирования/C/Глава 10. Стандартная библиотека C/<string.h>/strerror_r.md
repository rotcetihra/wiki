## Прототип

```c
#include <string.h>

// POSIX-вариант (XSI):          // GNU-вариант (glibc):
int strerror_r(int errnum,       char *strerror_r(int errnum,
               char *buf,                       char *buf,
               size_t buflen);                  size_t buflen);
```

>[!WARNING]
>Существуют **два несовместимых** варианта `strerror_r()`: POSIX (XSI) возвращает `int` и записывает текст в буфер, GNU возвращает `char *`. Какой из них доступен, зависит от макросов тестирования возможностей. В glibc GNU-вариант выбирается при определении `_GNU_SOURCE`, POSIX — при `_POSIX_C_SOURCE >= 200112L` без `_GNU_SOURCE`.

## Параметры

| Параметр | Описание |
|---|---|
| `errnum` | Код ошибки |
| `buf` | Буфер для текста описания |
| `buflen` | Размер буфера |

## Возвращаемое значение

- **POSIX-вариант:** возвращает 0 при успехе; ненулевой код при ошибке (например, `ERANGE`, если буфер мал; `EINVAL`, если код неизвестен).
- **GNU-вариант:** возвращает указатель на текст — либо `buf`, либо статическую строку, если та помещается в `buflen`.

## Что делает

Потокобезопасная версия [[Языки программирования/C/Глава 10. Стандартная библиотека C/<string.h>/strerror|strerror()]]: текст ошибки записывается в предоставленный вызывающим буфер, а не в общий статический. Параллельные вызовы из разных потоков с разными буферами не конфликтуют.

## Примеры

### POSIX-вариант (рекомендуемый переносимый паттерн)

```c
#define _POSIX_C_SOURCE 200112L
#include <stdio.h>
#include <string.h>
#include <errno.h>

int main(void)
{
    FILE *file = fopen("missing.txt", "r");
    if (file == NULL) {
        char buf[256];
        if (strerror_r(errno, buf, sizeof(buf)) == 0) {
            printf("Ошибка: %s\n", buf);
        }
    }

    return 0;
}
```

### GNU-вариант

```c
#define _GNU_SOURCE
#include <stdio.h>
#include <string.h>
#include <errno.h>

int main(void)
{
    char buf[256];
    printf("Ошибка: %s\n", strerror_r(errno, buf, sizeof(buf)));

    return 0;
}
```

## Ошибки и errno

В POSIX-варианте при ошибке возвращается код (`ERANGE`, `EINVAL`), сам `errno` обычно не устанавливается. В GNU-варианте может установить `errno` в `ERANGE`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Потокобезопасна | Два несовместимых варианта |
| Переносимый паттерн (POSIX) | Зависит от макросов сборки |
| Не требует статического буфера | |
