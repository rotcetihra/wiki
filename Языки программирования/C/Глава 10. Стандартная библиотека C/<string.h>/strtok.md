## Прототип

```c
#include <string.h>

char *strtok(char *str, const char *delim);
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | Строка для разбора (при первом вызове) или `NULL` (при последующих) |
| `delim` | Строка, содержащая символы-разделители |

## Возвращаемое значение

Возвращает указатель на очередной токен или `NULL`, когда токены закончились.

## Что делает

Разбивает строку на токены по разделителям. При первом вызове `str` — строка для разбора; при последующих вызовах передаётся `NULL`, и функция продолжает разбор с того места, где остановилась. Состояние хранится внутри функции в статической переменной. Разделители заменяются нулевыми байтами — исходная строка модифицируется. Последовательные разделители сжимаются в один (пустые токены пропускаются).

> [!WARNING]
>`strtok()` не потокобезопасна: состояние разбора хранится в статической переменной, поэтому два параллельных разбора конфликтуют. Альтернативы — `strtok_r()` (POSIX) или собственная реализация.

> [!WARNING]
>Передавать строковый литерал в `strtok()` нельзя: функция модифицирует строку, а литералы в C неизменяемы. Копируйте строку в массив (как в примере) или в память из `malloc()`.

## Примеры

### Базовое разбиение

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char line[] = "apple,banana;cherry";
    char *token = strtok(line, ",;");

    while (token != NULL) {
        printf("%s\n", token); // apple, banana, cherry
        token = strtok(NULL, ",;");
    }

    return 0;
}
```

### Разбиение с разными разделителями

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char text[] = "one:two,,three;four";
    char *token = strtok(text, ":;,"); // Все разделители в одном наборе

    while (token != NULL) {
        printf("[%s]\n", token);
        token = strtok(NULL, ":;,");
    }

    return 0;
}
```

### Потокобезопасная версия (POSIX)

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char line[] = "apple,banana,cherry";
    char *saveptr;
    char *token = strtok_r(line, ",", &saveptr);

    while (token != NULL) {
        printf("%s\n", token);
        token = strtok_r(NULL, ",", &saveptr);
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Неопределённое поведение возникает при обращении по невалидному указателю.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая в использовании | Не потокобезопасна (статическая переменная) |
| Не требует выделения памяти | Модифицирует исходную строку |
| Пропускает пустые токены | Пропускает пустые токены (не всегда нужно) |

## Альтернативы

- **`strtok_r()`** (POSIX) — потокобезопасная версия с явным состоянием
- **`strtok_s()`** (C11 Annex K) — безопасная версия с проверкой размера
- **`strcspn()`/`strpbrk()`** — разбиение без модификации строки
