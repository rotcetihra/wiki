## Прототип

```c
#include <string.h>

char *strncpy(char *dest, const char *src, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dest` | Указатель на.destination-буфер |
| `src` | Указатель на.source-строку |
| `n` | Максимальное количество символов для копирования |

## Возвращаемое значение

Возвращает `dest`.

## Что делает

Копирует не более `n` символов из строки `src` в `dest`. Если `src` короче `n`, остаток буфера `dest` дополняется нулевыми байтами. Если `src` длиннее `n`, завершающий нуль **не записывается** — строка в `dest` не завершается.

> [!WARNING]
>`strncpy()` не гарантирует завершающий нуль: если исходная строка не короче `n`, результат не будет строкой. Всегда проверяйте или дописывайте `'\0'` вручную.

## Примеры

### Копирование с ограничением длины

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char truncated[4];
    strncpy(truncated, "привет", 3);
    truncated[3] = '\0'; // Нуль вручную — иначе UB при печати

    printf("%s\n", truncated); // при

    return 0;
}
```

### Копирование в поле фиксированной длины

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char field[6] = {0}; // Поле фиксированной длины

    strncpy(field, "hello world", sizeof(field) - 1); // Оставляем место под нуль
    printf("%s\n", field); // hello

    return 0;
}
```

### Разница между strcpy и strncpy

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char dest1[8];
    char dest2[8];

    strcpy(dest1, "hello");
    strncpy(dest2, "hello", sizeof(dest2) - 1);
    dest2[sizeof(dest2) - 1] = '\0';

    printf("%s\n", dest1); // hello
    printf("%s\n", dest2); // hello

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Неопределённое поведение возникает при недостаточном размере буфера `dest`.

| Функция | Копирует | Завершающий нуль | Остаток буфера |
|---|---|---|---|
| `strcpy()` | всю строку | всегда записывает | не трогается |
| `strncpy()` | не более `n` символов | только если `src` короче `n` | дополняется нулевыми байтами |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Ограничивает длину копирования | Не гарантирует завершающий нуль |
| Дополняет остаток нулями (при коротком `src`) | Дополнительная работа по обнулению остатка |
| Стандартная и переносимая | Медленнее `strcpy()` из-за обнуления |

## Альтернативы

- **`strcpy()`** — полное копирование без ограничения
- **`strlcpy()`** (BSD) — безопасное копирование с гарантированным нулём
- **`strncpy_s()`** (C11 Annex K) — проверка размера, код ошибки
- **`strndup()`** (C23) — динамическое копирование с ограничением длины
