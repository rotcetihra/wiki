## Прототип

```c
#include <string.h>

char *strrchr(const char *s, int c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Строка для поиска |
| `c` | Искомый символ (приводится к `char` перед сравнением) |

## Возвращаемое значение

Возвращает указатель на **последнее** вхождение символа `c` в строке `s`. Если символ не найден, возвращает `NULL`. Вхождение завершающего нуля считается: `strrchr(s, '\0')` возвращает указатель на завершающий нуль.

## Что делает

Ищет последнее вхождение символа `c` в строке `s`. В отличие от `strchr()` (первое вхождение), работает с конца строки. Возвращаемый указатель указывает внутрь исходной строки.

## Примеры

### Извлечение имени файла из пути

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *path = "/home/user/docs/report.txt";
    const char *slash = strrchr(path, '/');
    const char *filename = (slash != NULL) ? slash + 1 : path;

    printf("%s\n", filename); // report.txt

    return 0;
}
```

### Извлечение расширения

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *file = "image.png";
    const char *dot = strrchr(file, '.');
    if (dot != NULL) {
        printf("Расширение: %s\n", dot); // .png
    }

    return 0;
}
```

### Поиск последнего разделителя

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *text = "a,b,c,d";
    const char *last = strrchr(text, ',');
    if (last != NULL) {
        printf("Последний элемент: %s\n", last + 1); // d
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Неопределённое поведение возникает при обращении по невалидному указателю.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Удобна для извлечения имени/расширения | Линейная сложность O(n) |
| Учитывает завершающий нуль | Ищет только последнее вхождение |
| Стандартная и переносимая | |

## Альтернативы

- **`strchr()`** — поиск первого вхождения символа
- **`memchr()`** — поиск в ограниченном блоке памяти
- **Цикл с `strrchr()`** — ручной обход строки с конца
