## Прототип

```c
#include <string.h>

char *strerror(int errnum);
```

## Параметры

| Параметр | Описание |
|---|---|
| `errnum` | Код ошибки (обычно значение `errno` из `<errno.h>`) |

## Возвращаемое значение

Возвращает указатель на строку с текстовым описанием ошибки. Строка не должна изменяться вызывающим. Если код неизвестен, возвращается реализация-зависимая строка (например, `"Unknown error"`).

## Что делает

Переводит числовой код ошибки (`errno`) в человекочитаемое текстовое описание. Буфер статический — повторный вызов может перезаписать предыдущий результат, а параллельные вызовы из потоков конфликтуют.

## Примеры

### Базовое использование

```c
#include <stdio.h>
#include <string.h>
#include <errno.h>

int main(void)
{
    FILE *file = fopen("missing.txt", "r");
    if (file == NULL) {
        printf("Ошибка %d: %s\n", errno, strerror(errno));
    }

    return 0;
}
```

### Потокобезопасное использование (POSIX)

```c
#include <stdio.h>
#include <string.h>
#include <errno.h>

int main(void)
{
    FILE *file = fopen("missing.txt", "r");
    if (file == NULL) {
        char buf[256];
        strerror_r(errno, buf, sizeof(buf)); // Потокобезопасная версия
        printf("Ошибка %d: %s\n", errno, buf);
    }

    return 0;
}
```

### Обработка разных ошибок

```c
#include <stdio.h>
#include <string.h>
#include <errno.h>
#include <math.h>

int main(void)
{
    errno = 0;
    double result = sqrt(-1.0);

    if (errno != 0) {
        printf("math: ошибка %d: %s\n", errno, strerror(errno));
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno` — она лишь переводит уже полученный код в текст.

> [!WARNING]
>В многопоточных программах не вызывайте `strerror()` без синхронизации: статический буфер общий для всех потоков. Используйте `strerror_r()` (POSIX) или `strerror_s()` (C11 Annex K).

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая в использовании | Статический буфер — не потокобезопасна |
| Не требует выделения памяти | Повторный вызов перезаписывает результат |
| Стандартная и переносимая | |

## Альтернативы

- **`strerror_r()`** (POSIX) — потокобезопасная версия (два варианта: XSI и GNU)
- **`strerror_l()`** (POSIX.1-2008) — описание ошибки для указанной локали
- **`strerror_s()`** (C11 Annex K) — безопасная версия с проверкой размера буфера
- **`perror()`** — выводит ошибку в `stderr` (из `<stdio.h>`)
