## Прототип

```c
#include <string.h> // POSIX.1-2008

char *stpcpy(char *dest, const char *src);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dest` | Буфер, куда копируется строка |
| `src` | Копируемая строка |

## Возвращаемое значение

Возвращает указатель на завершающий нуль, записанный в `dest` (конец скопированной строки). В отличие от `strcpy()`, которая возвращает начало `dest`.

## Что делает

Копирует строку `src` в `dest` как `strcpy()`, но возвращает указатель на конец результата. Это позволяет последовательно строить строку «склейкой» без повторного прохода `strlen()` — типичный паттерн для буферов и сообщений.

## Примеры

### Последовательная сборка строки

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char buf[64];
    char *p = buf;

    p = stpcpy(p, "Hello");
    p = stpcpy(p, ", ");
    p = stpcpy(p, "world");

    printf("%s\n", buf); // Hello, world

    return 0;
}
```

### Подсчёт длины и копирование за один проход

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *src = "example";
    char dest[32];

    char *end = stpcpy(dest, src);
    printf("%s (длина %td)\n", dest, end - dest); // example (длина 7)

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Как и `strcpy()`, не проверяет размер буфера — переполнение при слишком длинной `src` даёт неопределённое поведение.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Возврат конца строки упрощает сборку | Не проверяет размер буфера |
| Заменяет связки `strcpy + strlen` | Только POSIX (нет в C) |
| | Области не должны перекрываться |
