## Прототип

```c
#include <string.h>

size_t strcspn(const char *s1, const char *s2);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1` | Строка, в которой ищется первый «незапрещённый» символ |
| `s2` | Набор символов-разделителей (каждый символ — возможный стоп-символ) |

## Возвращаемое значение

Возвращает длину начального сегмента строки `s1`, в котором **нет** ни одного символа из набора `s2`. Если первый же символ входит в набор, возвращает 0.

## Что делает

Ищет первый символ строки `s1`, который встречается в наборе `s2`. Возвращает количество символов до него. Это «обратный» поиск: `strcspn()` измеряет «безопасную» длину строки до первого разделителя.

В сочетании с `strpbrk()` образует удобный паттерн разбиения строки без её модификации (в отличие от `strtok()`).

## Примеры

### Базовое использование

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    printf("%zu\n", strcspn("xyzabc", "abc")); // 3 (до первого символа набора)
    printf("%zu\n", strcspn("abcxyz", "abc")); // 0 (первый символ в наборе)
    printf("%zu\n", strcspn("hello", "xyz"));  // 5 (ни один символ не в наборе)

    return 0;
}
```

### Разбиение строки на пары ключ-значение

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *str = "key1=value1;key2=value2";
    const char *rest = str;

    while (*rest != '\0') {
        size_t name_len = strcspn(rest, "=;");
        printf("ключ: %.*s\n", (int)name_len, rest);
        rest += name_len;

        if (*rest == '=') {
            rest++;
            size_t value_len = strcspn(rest, ";");
            printf("значение: %.*s\n", (int)value_len, rest);
            rest += value_len;
        }

        if (*rest == ';') {
            rest++;
        }
    }

    return 0;
}
```

### Подсчёт слов

```c
#include <stdio.h>
#include <string.h>
#include <ctype.h>

int main(void)
{
    const char *text = "  hello   world  foo  ";
    const char *p = text;

    while (*p) {
        p += strspn(p, " \t\n"); // Пропускаем пробелы
        size_t word_len = strcspn(p, " \t\n"); // Длина слова
        if (word_len > 0) {
            printf("Слово: %.*s\n", (int)word_len, p);
            p += word_len;
        } else {
            break;
        }
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Неопределённое поведение возникает при обращении по невалидным указателям.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Не модифицирует строку | Возвращает длину, а не указатель |
| Не требует завершающего нуля в `s2` | Сложная семантика («обратный поиск») |
| Быстрая | |

## Альтернативы

- **`strspn()`** — длина начального сегмента, состоящего только из символов набора
- **`strpbrk()`** — возвращает указатель на первый символ из набора
- **`strtok()`** — разбиение на токены с модификацией строки
