## Прототип

```c
#include <string.h> // GNU

void *memrchr(const void *s, int c, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Блок памяти для поиска |
| `c` | Искомый байт (приводится к `unsigned char`) |
| `n` | Количество байт для проверки |

## Возвращаемое значение

Возвращает указатель на **последнее** вхождение байта `c` в первых `n` байтах блока `s`. Если байт не найден — `NULL`.

## Что делает

Аналог [[Языки программирования/C/Глава 10. Стандартная библиотека C/<string.h>/memchr|memchr()]], но ищет с конца блока: возвращает не первое, а последнее вхождение байта. Работает с бинарными данными без завершающих нулей.

## Примеры

### Поиск последнего байта в блоке

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char data[] = {0x10, 0x20, 0x10, 0x30, 0x10};

    void *found = memrchr(data, 0x10, sizeof(data));
    if (found != NULL) {
        printf("Позиция: %td\n", (char *)found - data); // 4 (последний 0x10)
    }

    return 0;
}
```

### Поиск последнего разделителя в бинарных данных

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    char frame[] = {0x01, 0x00, 0x02, 0x00, 0x03, 0xFF};
    void *end = memrchr(frame, 0xFF, sizeof(frame));
    if (end != NULL) {
        printf("Фрейм заканчивается на позиции %td\n", (char *)end - frame);
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Передача невалидного указателя — неопределённое поведение.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Ищет последнее вхождение в блоке памяти | Только GNU-расширение |
| Работает с бинарными данными | Не переносится на BSD/Windows |
| | Линейная сложность O(n) |
