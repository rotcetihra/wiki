## Прототип

```c
#include <string.h>

char *strndup(const char *s, size_t n); // C23
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Строка для дублирования |
| `n` | Максимальное количество символов для копирования |

## Возвращаемое значение

Возвращает указатель на динамически выделенную копию строки `s`. Если строка короче `n`, копируется вся строка с завершающим нулём. Если длиннее — ровно `n` символов, после которых добавляется завершающий нуль. `strndup(s, 0)` возвращает пустую строку. При нехватке памяти возвращает `NULL` (в POSIX устанавливается `errno` в `ENOMEM`). Вызывающий обязан освободить память через `free()`.

## Что делает

Дублирует не более `n` символов строки `s`, выделяя память через `malloc()`. В отличие от `strncpy()`, всегда добавляет завершающий нуль и автоматически вычисляет размер буфера. Удобно, когда строка может быть длиннее ожидаемого.

> [!NOTE]
>До стандарта C23 функция `strndup()` была функцией POSIX. В C23 она вошла в стандартную библиотеку C.

## Примеры

### Базовое дублирование с ограничением

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    char *part = strndup("abcdef", 3);
    if (part != NULL) {
        printf("%s\n", part); // abc
        free(part);
    }

    return 0;
}
```

### Дублирование короткой строки

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    // n больше длины строки — копируется вся строка
    char *copy = strndup("hi", 100);
    if (copy != NULL) {
        printf("%s\n", copy); // hi
        free(copy);
    }

    return 0;
}
```

### Выделение пустой строки

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    char *empty = strndup("anything", 0);
    if (empty != NULL) {
        printf("Длина: %zu\n", strlen(empty)); // 0
        free(empty);
    }

    return 0;
}
```

## Ошибки и errno

- Возвращает `NULL` при нехватке памяти
- В POSIX устанавливает `errno` в `ENOMEM`
- Стандарт C не требует установки `errno`

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует завершающий нуль | Требует `free()` — утечка при забывании |
| Автоматически вычисляет размер | В C23 стандартная, до C23 — только POSIX |
| Ограничивает длину копии | При нехватке памяти возвращает `NULL` |

## Альтернативы

- **`strdup()`** (C23) — дублирование без ограничения длины
- **`malloc()` + `strncpy()` + ручной нуль** — более громоздко
- **`realloc()`** — перераспределение существующего блока
