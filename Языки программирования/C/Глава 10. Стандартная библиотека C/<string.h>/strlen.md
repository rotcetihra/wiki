## Прототип

```c
#include <string.h>

size_t strlen(const char *s);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Строка, длина которой определяется |

## Возвращаемое значение

Возвращает количество символов в строке `s` до завершающего нуля (сам нуль не учитывается). Тип `size_t` — беззнаковое целое; при печати используйте `%zu`.

## Что делает

Считает символы до первого нулевого байта. Если строка не завершена нулём — неопределённое поведение. Современные компиляторы (GCC, Clang, MSVC) оптимизируют `strlen()` через векторные инструкции (SSE2/AVX2/NEON), обрабатывая по 16–64 байта за такт.

> [!NOTE]
>`strlen()` считает именно байты, а не символы: для строки в UTF-8 она вернёт количество байтов, которое для кириллицы вдвое больше числа символов.

## Примеры

### Базовое использование

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    printf("%zu\n", strlen("hello")); // 5
    printf("%zu\n", strlen(""));      // 0

    return 0;
}
```

### Вычисление размера для динамического выделения

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main(void)
{
    const char *src = "Hello, world!";
    size_t len = strlen(src);

    char *copy = malloc(len + 1); // +1 для завершающего нуля
    if (copy != NULL) {
        memcpy(copy, src, len + 1);
        printf("%s\n", copy);
        free(copy);
    }

    return 0;
}
```

### Оптимизация: вычисление длины заранее

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *str = "example";
    size_t len = strlen(str); // Вычисляем один раз

    for (size_t i = 0; i < len; i++) {
        // Обработка каждого символа без пересчёта длины
        printf("%c ", str[i]);
    }

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Неопределённое поведение возникает при обращении по невалидному указателю или если строка не завершена нулём.

> [!WARNING]
>В выражениях вроде `for (size_t i = 0; i < strlen(s); i++)` длина пересчитывается на каждой итерации — O(n²). Вычисляйте длину заранее: `size_t len = strlen(s); for (size_t i = 0; i < len; i++)`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и быстрая (SIMD) | O(n) — нельзя использовать в условии цикла |
| Стандартная и переносимая | Считает байты, а не символы (для UTF-8) |
| | Требует завершающий нуль |

## Альтернативы

- **`strnlen()`** (C11) — безопасная версия с ограничением максимальной длины
- **`wcslen()`** — длина宽 символа (из `<wchar.h>`)
- **`sizeof`** — для массивов фиксированной длины (но не для указателей!)
