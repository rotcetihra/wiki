## Прототип

```c
#include <string.h> // GNU

void *rawmemchr(const void *s, int c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Блок памяти для поиска |
| `c` | Искомый байт (приводится к `unsigned char`) |

## Возвращаемое значение

Возвращает указатель на первое вхождение байта `c` в блоке памяти `s`. Если байт не найден — результат не определён (неопределённое поведение).

## Что делает

Ищет байт `c` в памяти, начиная с `s`, **без ограничения длины**. Скорость выше чем у `memchr()`, так как не нужно передавать и проверять `n`, но ответственность за наличие байта целиком на вызывающем: если байта нет, функция прочитает за пределами блока.

>[!WARNING]
>Вызывающий должен гарантировать, что символ `c` существует в памяти по адресу `s` до любого граничного байта. Иначе — неопределённое поведение и потенциальный сбой (segfault).

## Примеры

### Поиск символа в известной строке

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *msg = "hello world";

    // Пробел гарантированно есть в строке
    char *space = rawmemchr(msg, ' ');
    printf("Пробел на позиции %td\n", space - msg); // 5

    return 0;
}
```

### Поиск нулевого байта (конца строки)

```c
#include <stdio.h>
#include <string.h>

int main(void)
{
    const char *msg = "end";

    // Завершающий нуль есть всегда
    char *end = rawmemchr(msg, '\0');
    printf("Длина строки: %td\n", end - msg); // 3

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Главный риск — неопределённое поведение при отсутствии искомого байта.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Самый быстрый поиск (без счётчика) | UB при отсутствии байта |
| Простые вызовы | Только GNU-расширение |
| | Требует аккуратности от вызывающего |
