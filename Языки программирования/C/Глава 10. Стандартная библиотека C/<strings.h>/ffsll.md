## Прототип

```c
#include <strings.h>

int ffsll(long long int ll);
```

## Параметры

| Параметр | Описание |
|---|---|
| `ll` | Проверяемое целое |

## Возвращаемое значение

Позицию первого (наименее значимого) установленного бита с нумерацией от 1 или 0, если установленных битов нет.

## Что делает

Аналог `ffs()` для типа `long long`. В glibc доступна как расширение GNU (не входит в POSIX).

## Примеры

```c
#include <stdio.h>
#include <strings.h>

int main(void)
{
    printf("%d\n", ffsll(1LL << 62)); // 63 — 63-й бит
    printf("%d\n", ffsll(0LL));       // 0

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Работает с `long long` (всегда 64 бита) | Расширение GNU: не переносится на другие POSIX-системы |
