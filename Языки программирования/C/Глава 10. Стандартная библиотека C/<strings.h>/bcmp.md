## Прототип

```c
#include <strings.h>

int bcmp(const void *s1, const void *s2, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1`, `s2` | Сравниваемые блоки памяти |
| `n` | Количество сравниваемых байт |

## Возвращаемое значение

Возвращает 0, если первые `n` байт блоков совпадают, и ненулевое значение, если различаются. В отличие от `memcmp()`, не даёт информации о порядке — только «равно/не равно».

## Что делает

Сравнивает первые `n` байт двух блоков памяти — аналог `memcmp()`. Устаревшая (LEGACY) функция BSD: вместо неё следует использовать `memcmp()` из `<string.h>`.

## Примеры

```c
#include <stdio.h>
#include <strings.h>

int main(void)
{
    char a[] = "hello";
    char b[] = "hello";
    char c[] = "world";

    printf("%d\n", bcmp(a, b, 5)); // 0 — первые 5 байт равны
    printf("%d\n", bcmp(a, c, 5)); // ненулевое значение

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Результат не определён для некорректных указателей.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Короткое имя | Устаревшая (LEGACY): может отсутствовать вне BSD-систем |
| | Возвращает только «равно/не равно», без сравнения по порядку |

## Альтернативы

- **`memcmp()`** — стандартная замена из `<string.h>`
