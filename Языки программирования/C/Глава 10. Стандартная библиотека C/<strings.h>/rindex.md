## Прототип

```c
#include <strings.h>

char *rindex(const char *s, int c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Строка для поиска |
| `c` | Искомый символ (преобразуется в `unsigned char`) |

## Возвращаемое значение

Указатель на последнее вхождение символа `c` в строке `s` или `NULL`, если символ не найден.

## Что делает

Ищет последнее вхождение символа в строке — аналог `strrchr()`. Как и `strrchr()`, находит завершающий нуль: `rindex(s, '\0')` возвращает указатель на конец строки. Устаревшая (LEGACY) функция BSD: вместо неё следует использовать `strrchr()` из `<string.h>`.

## Примеры

```c
#include <stdio.h>
#include <strings.h>

int main(void)
{
    const char *text = "Hello, world!";

    printf("%s\n", rindex(text, 'o'));   // orld!
    printf("%p\n", (void *)rindex(text, 'z')); // NULL

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Короткое имя | Устаревшая (LEGACY) |
