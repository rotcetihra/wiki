## Описание библиотеки

Заголовочный файл `<locale.h>` предоставляет средства интернационализации: функции для установки текущей локали и получения информации о форматировании числовых, денежных и временных значений. Локаль определяет правила сортировки строк (`LC_COLLATE`), классификацию символов (`LC_CTYPE`), формат даты и времени (`LC_TIME`), формат денежных знаков (`LC_MONETARY`) и десятичный разделитель (`LC_NUMERIC`).

Библиотека введена в стандарт C89. Функция `setlocale` позволяет установить локаль по имени (например, `"ru_RU.UTF-8"`) или запросить текущую. Функция `localeconv` возвращает структуру `struct lconv` с параметрами форматирования. Константы `LC_*` определяют категории локали.

> [!NOTE]
> Вызов `setlocale(LC_ALL, "")` в начале программы автоматически определяет локаль по переменным окружения (`LANG`, `LC_*`, `LC_ALL`). Это стандартный способ интернационализации.

> [!WARNING]
> Указатели, возвращённые `localeconv`, могут стать невалидными после вызова `setlocale`. Следует копировать нужные данные до следующего вызова `setlocale`.

### Типы

| Тип | Описание |
|---|---|
| `struct lconv` | Структура с параметрами форматирования числовых и денежных значений |

### Константы категорий локали

| Константа | Описание |
|---|---|
| `LC_ALL` | Все категории локали |
| `LC_COLLATE` | Правила колляции (сортировки строк) |
| `LC_CTYPE` | Классификация и преобразование символов |
| `LC_MONETARY` | Форматирование денежных значений |
| `LC_NUMERIC` | Форматирование числовых значений (десятичный разделитель, группировка) |
| `LC_TIME` | Форматирование даты и времени |
| `NULL` | Нулевой указатель (определён в `<stddef.h>`, повторно в `<locale.h>` для совместимости) |

### Функции

| Функция | Описание |
|---|---|
| `localeconv()` | Возвращает указатель на `struct lconv` с параметрами текущей локали |
| `setlocale()` | Устанавливает или запрашивает текущую локаль |

> [!NOTE]
> Константы `LC_*` не обязательно являются побитовыми масками — для установки нескольких категорий используйте `LC_ALL`.
