## Описание библиотеки

Заголовочный файл `<stdlib.h>` — «общие утилиты» (general utilities): один из основных заголовков стандартной библиотеки. Определяет функции преобразования строк в числа и обратно, управления памятью, сортировки и поиска, завершения программы, работы с окружением, псевдослучайными числами, целочисленной математикой и многобайтовыми символами, а также сопутствующие типы и константы. Многобайтовые функции из `<stdlib.h>` дополняются более современными аналогами из `<wchar.h>` (см. статью [[Языки программирования/C/Глава 9. Стандартная библиотека C/8. Поддержка Unicode и кодировки UTF-8, UTF-16 и UTF-32|«Поддержка Unicode и кодировки UTF-8, UTF-16 и UTF-32»]]).

В POSIX-системах `<stdlib.h>` расширяет стандартную библиотеку C дополнительными функциями: управление памятью (`posix_memalign()`, `reallocarray()`), окружением (`setenv()`, `putenv()`, `unsetenv()`), генераторы случайных чисел (`random()`, семейство `drand48()`), создание временных файлов и каталогов (`mkstemp()`, `mkdtemp()`), работа с псевдо-терминалами (`posix_openpt()`, `grantpt()`, `unlockpt()`, `ptsname()`) и варианты функций преобразования строк с явной локалью (`strtod_l()`, `strtol_l()` и т. п.). Все они объявлены в том же файле `<stdlib.h>` и доступны в glibc при определении соответствующих макросов тестирования возможностей: `_POSIX_C_SOURCE`, `_XOPEN_SOURCE`, `_DEFAULT_SOURCE`, `_GNU_SOURCE`. Часть функций отмечена как устаревшие (LEGACY): `mktemp()`, `ecvt()`, `a64l()` — для новых программ они не рекомендуются.

Функции `ato*` просты, но не сообщают об ошибках (переполнение неотличимо от нуля) — для надёжного разбора чисел следует использовать `strto*`.

| `posix_memalign()` | Выделяет блок с выравниванием (степень двойки); код ошибки в возвращаемом значении |
| `reallocarray()` | `realloc()` с проверкой переполнения `nmemb × size` (BSD, glibc 2.26+) |

#### Окружение

| Функция | Описание |
|---|---|
| `setenv()` / `unsetenv()` | Установка/замена/удаление переменной; строки копируются |
| `putenv()` | Установка строки без копирования — следите за сроком жизни |
| `clearenv()` | Очистка всего окружения (GNU) |
| `secure_getenv()` | `getenv()`, возвращающий `NULL` в setuid-режиме (GNU) |

#### Случайные числа

| Функция | Описание |
|---|---|
| `random()` / `srandom()` | Генератор с 31-битным выходом; состояние управляемо |
| `initstate()` / `setstate()` | Установка состояния генератора |
| `drand48()` и семейство | 48-битные генераторы: `drand48`, `erand48`, `lrand48`, `nrand48`, `mrand48`, `jrand48`, `srand48`, `seed48`, `lcong48` |

#### Сортировка

| Функция | Описание |
|---|---|
| `qsort_r()` | `qsort()` с передачей контекста в функцию сравнения (GNU; сигнатура отличается от BSD) |

#### Временные файлы и каталоги

| Функция | Описание |
|---|---|
| `mkstemp()` | Создаёт файл атомарно (`O_EXCL`), права 0600; варианты `mkstemps()`, `mkostemp()`, `mkostemps()` |
| `mkdtemp()` | Создаёт каталог с правами 0700 |
| `mktemp()` | Только имя — устаревшая, небезопасная (LEGACY) |

#### Псевдо-терминалы

| Функция | Описание |
|---|---|
| `posix_openpt()` | Открывает master; `getpt()` — GNU-сокращение |
| `grantpt()` | Права доступа на slave |
| `unlockpt()` | Разблокирует slave для открытия |
| `ptsname()` / `ptsname_r()` | Имя slave-устройства; `_r` — потокобезопасная (GNU) |

#### Преобразование чисел с явной локалью

| Функция | Описание |
|---|---|
| `strtod_l()` / `strtof_l()` / `strtold_l()` | Вещественные числа по правилам заданной локали |
| `strtol_l()` / `strtoll_l()` / `strtoul_l()` / `strtoull_l()` | Целые числа по правилам заданной локали |

#### Прочие утилиты

| Функция | Описание |
|---|---|
| `getsubopt()` | Разбор подопций вида `имя=значение` через запятую (XSI) |
| `a64l()` / `l64a()` | Кодирование 36 бит в 6 символов (XSI, устаревшая) |
| `ecvt()` / `fcvt()` / `gcvt()` | Цифры числа без точки и знака (SVID, устаревшие) |
| `getloadavg()` | Средняя загрузка за 1/5/15 минут (BSD/GNU) |
