## Определение

```c
#include <signal.h>

#define SIG_IGN /* implementation-defined */
```

## Описание

Макрос `SIG_IGN` определяет обработчик сигнала, который игнорирует его. При установке `SIG_IGN` в качестве обработчика для сигнала он не будет доставлен программе — все сигналы данного типа будут отброшены.

Используется как аргумент функции `signal` для игнорирования сигналов. Например, `signal(SIGINT, SIG_IGN)` отключает обработку `Ctrl+C`.

> [!NOTE]
> Сигналы `SIGKILL` и `SIGSTOP` (POSIX) нельзя игнорировать или перехватывать — попытка установить для них обработчик игнорируется.

## Пример

```c
#include <stdio.h>
#include <signal.h>

int main(void)
{
    signal(SIGINT, SIG_IGN);
    printf("Ctrl+C не завершит программу. Нажмите Ctrl+\\ для выхода.\n");
    while (1) {}
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простой способ игнорировать сигналы | Не является функцией (макрос) |
| Можно временно отключить обработку | Некоторые сигналы нельзя игнорировать |
