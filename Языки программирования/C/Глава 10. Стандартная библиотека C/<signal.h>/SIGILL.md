## Определение

```c
#include <signal.h>

#define SIGILL /* implementation-defined */
```

## Описание

Макрос `SIGILL` определяет сигнал недопустимой инструкции (Illegal Instruction). Сигнал генерируется при попытке выполнения недопустимой, не распознанной или запрещённой машинной инструкции. Также может возникать при ошибке в коде или повреждении памяти.

Действие по умолчанию — завершение программы. Обработчик этого сигнала не должен пытаться вернуть управление в нормальный поток выполнения.

> [!NOTE]
> На платформах с поддержкой SIMD-инструкций `SIGILL` может генерироваться при попытке выполнения инструкций, которые не поддерживаются процессором (например, AVX на процессоре без AVX).

## Пример

```c
#include <stdio.h>
#include <signal.h>

void ill_handler(int sig)
{
    printf("Поймана недопустимая инструкция (сигнал %d)\n", sig);
    _Exit(1);
}

int main(void)
{
    signal(SIGILL, ill_handler);
    printf("Попытка выполнить недопустимую инструкцию...\n");
    __asm__ volatile("ud2");
    printf("Это не будет выведено\n");
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный способ обработки ошибок инструкций | Обработчик не может вернуть управление |
| Помогает обнаружить повреждение кода | Может возникнуть из-за багов компилятора |
