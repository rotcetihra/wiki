## Определение

```c
#include <signal.h>

#define SIG_ERR /* implementation-defined */
```

## Описание

Макрос `SIG_ERR` определяет значение, которое возвращает функция `signal` при невозможности установить обработчик для указанного сигнала. Используется для проверки ошибок при установке обработчиков.

> [!NOTE]
> `SIG_ERR` не является обработчиком — его нельзя передать в `signal` в качестве обработчика. Это значение используется только для сравнения с результатом `signal`.

## Пример

```c
#include <stdio.h>
#include <signal.h>

int main(void)
{
    if (signal(SIGINT, SIG_IGN) == SIG_ERR) {
        perror("Не удалось установить обработчик для SIGINT");
        return 1;
    }
    printf("Обработчик установлен успешно\n");
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный способ проверки ошибок `signal` | Не является функцией (макрос) |
| Позволяет определить причину ошибки | Значение определяется реализацией |
