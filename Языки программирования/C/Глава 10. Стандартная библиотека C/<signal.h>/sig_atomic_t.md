## Определение

```c
#include <signal.h>

typedef /* unspecified */ sig_atomic_t;
```

## Описание

Тип `sig_atomic_t` — целочисленный тип, доступ к которому является атомарным (непрерывным)即使 при прерывании обработчиком сигнала. Это единственный тип, безопасный для чтения и записи внутри обработчика сигнала.

Реализация определяет точное представление `sig_atomic_t`, но гарантирует, что операции чтения и записи будут выполнены за один атомарный шаг. Обычно это `int` или аналогичный тип.

> [!NOTE]
> Переменные типа `sig_atomic_t` неявно защищены от прерывания обработчиком сигнала, но не потокобезопасны. Для межпоточной синхронизации используйте атомарные операции из `<stdatomic.h>`.

## Пример

```c
#include <stdio.h>
#include <signal.h>

volatile sig_atomic_t counter = 0;

void handler(int sig)
{
    counter++;
}

int main(void)
{
    signal(SIGINT, handler);
    printf("Нажмите Ctrl+C несколько раз\n");

    for (int i = 0; i < 1000000; i++) {
        if (counter > 0) {
            printf("Сигнал получен, counter = %d\n", counter);
            break;
        }
    }
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантия атомарного доступа | Ограниченный набор типов (целочисленный) |
| Безопасен в обработчиках сигналов | Не потокобезопасен |
| Стандартная часть C89 | Размер и представление определяются реализацией |
