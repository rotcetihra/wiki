## Определение

```c
#include <signal.h>

#define SIGFPE /* implementation-defined */
```

## Описание

Макрос `SIGFPE` определяет сигнал арифметической ошибки (Floating Point Exception). Несмотря на название, сигнал относится ко всем арифметическим ошибкам, включая целочисленное деление на ноль.

Действие по умолчанию — завершение программы. Обработчик этого сигнала не должен пытаться вернуть управление в нормальный поток выполнения — это приведёт к неопределённому поведению.

> [!WARNING]
> Деление на ноль (`INT_MIN / -1` или `x / 0.0`) приводит к неопределённому поведению и может не генерировать `SIGFPE`. Стандарт не гарантирует генерацию этого сигнала.

## Пример

```c
#include <stdio.h>
#include <signal.h>

void fpe_handler(int sig)
{
    printf("Поймана арифметическая ошибка (сигнал %d)\n", sig);
    _Exit(1);
}

int main(void)
{
    signal(SIGFPE, fpe_handler);
    int x = 1;
    int y = 0;
    int result = x / y;
    printf("Результат: %d\n", result);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный способ обработки арифметических ошибок | Обработчик не может вернуть управление |
| Генерируется при делении на ноль (на многих платформах) | Не guaranteeируется для всех арифметических ошибок |
