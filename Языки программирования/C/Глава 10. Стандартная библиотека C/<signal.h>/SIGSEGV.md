## Определение

```c
#include <signal.h>

#define SIGSEGV /* implementation-defined */
```

## Описание

Макрос `SIGSEGV` определяет сигнал нарушения прав доступа к памяти (Segmentation Fault). Сигнал генерируется при попытке обращения к памяти, к которой программа не имеет доступа — например, разыменование нулевого указателя, обращение по невалидному адресу или запись в защищённую область памяти.

Действие по умолчанию — завершение программы. Обработчик этого сигнала не должен пытаться вернуть управление в нормальный поток выполнения.

> [!WARNING]
> `SIGSEGV` является индикатором критической ошибки (неопределённое поведение). Попытка «восстановиться» после этого сигнала практически всегда приводит к дальнейшим ошибкам.

## Пример

```c
#include <stdio.h>
#include <signal.h>

void segv_handler(int sig)
{
    printf("Нарушение доступа к памяти (сигнал %d)\n", sig);
    _Exit(1);
}

int main(void)
{
    signal(SIGSEGV, segv_handler);
    int *p = NULL;
    printf("Разыменование нулевого указателя...\n");
    *p = 42;
    printf("Это не будет выведено\n");
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный способ обработки ошибок памяти | Индикатор неопределённого поведения |
| Помогает отладить ошибки доступа к памяти | Обработчик не может вернуть управление |
