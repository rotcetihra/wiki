## Определение

```c
#include <uchar.h>

typedef unsigned short char16_t;
```

## Описание

Тип `char16_t` — беззнаковый целый тип для хранения кодовых элементов Unicode в кодировке UTF-16. Введён в стандарте C11.

Гарантируется, что `char16_t` достаточно широк для представления любого 16-битного значения. Конкретная ширина определяется реализацией, но обычно это `unsigned short` (16 бит). Литералы типа `char16_t` создаются с префиксом `u`: `u'A'`, `u'я'`.

Символы Unicode в UTF-16 могут занимать один или два 16-битных элемента (суррогатные пары). Для представления кодовых точек U+10000 и выше используются два элемента `char16_t`.

## Примеры

```c
#include <stdio.h>
#include <uchar.h>

int main(void)
{
    char16_t c1 = u'A';
    char16_t c2 = u'я';
    char16_t c3 = u'€';   // U+20AC, помещается в один элемент
    char16_t c4 = u'𝄞';   // U+1D11E, Requires surrogate pair

    printf("Размер char16_t: %zu байт\n", sizeof(char16_t));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный тип C11 для UTF-16 | Суррогатные пары усложняют обработку |
| Компактное представление латиницы и кириллицы | Не все символы Unicode помещаются в один элемент |
| Литералы с префиксом `u` | Длина строки в элементах не равна количеству символов |
