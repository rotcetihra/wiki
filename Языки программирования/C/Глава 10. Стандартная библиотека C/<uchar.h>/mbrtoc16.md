## Определение

```c
#include <uchar.h>

size_t mbrtoc16(char16_t *restrict pc16,
                const char *restrict s,
                size_t n,
                mbstate_t *restrict ps);
```

## Описание

Функция `mbrtoc16` преобразует многобайтовую последовательность, начинающуюся с позиции `s`, в символ `char16_t` (кодовый элемент UTF-16) и записывает результат в `pc16`.

Параметры:

- `pc16` — указатель на переменную `char16_t` для записи результата; может быть `NULL`.
- `s` — указатель на начало многобайтовой последовательности.
- `n` — максимальное количество байт для чтения из `s`.
- `ps` — указатель на состояние преобразования `mbstate_t`; если `NULL`, используется внутреннее статическое состояние.

Возвращаемое значение:

- `0` — преобразован нулевой символ (`L'\0'`).
-Between 1 и `n` — количество байт, составляющих обработанную многобайтовую последовательность.
- `(size_t)-1` — обнаружен неверный многобайтовый символ.
- `(size_t)-2` — прочитана неполная последовательность (недостаточно байт в `n`).

> [!NOTE]
> Функция может возвращать значение больше 1, если один символ UTF-16 требует суррогатной пары (два элемента `char16_t`). В этом случае вызов вернёт количество байт, необходимых для обеих частей суррогатной пары.

## Примеры

```c
#include <stdio.h>
#include <uchar.h>

int main(void)
{
    const char *utf8 = "Привет";
    mbstate_t state = {0};
    char16_t buf[32];
    size_t len = 0;
    const char *ptr = utf8;

    while (len < 31) {
        size_t ret = mbrtoc16(&buf[len], ptr, strlen(ptr), &state);
        if (ret == 0 || ret == (size_t)-1)
            break;
        ptr += ret;
        len++;
    }
    buf[len] = 0;

    printf("Преобразовано %zu символов UTF-16\n", len);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция C11 | Сложный интерфейс с состоянием `mbstate_t` |
| Поддерживает суррогатные пары UTF-16 | Может потребоваться несколько вызовов для одного символа |
| Потокобезопасна при использовании собственного `ps` | Зависит от настроек локали (`LC_CTYPE`) |
