## Определение

```c
#include <uchar.h>

typedef unsigned int char32_t;
```

## Описание

Тип `char32_t` — беззнаковый целый тип для хранения кодовых элементов Unicode в кодировке UTF-32. Введён в стандарте C11.

Гарантируется, что `char32_t` достаточно широк для представления любого кодового элемента Unicode. Конкретная ширина определяется реализацией, но обычно это `unsigned int` (32 бита). Литералы типа `char32_t` создаются с префиксом `U`: `U'A'`, `U'я'`, `U'𝄞'`.

В отличие от UTF-16, каждый символ Unicode в UTF-32 занимает ровно один элемент `char32_t`, что упрощает обработку, но увеличивает потребление памяти.

## Примеры

```c
#include <stdio.h>
#include <uchar.h>

int main(void)
{
    char32_t c1 = U'A';
    char32_t c2 = U'я';
    char32_t c3 = U'€';
    char32_t c4 = U'𝄞';   // U+1D11E, один элемент

    printf("Размер char32_t: %zu байт\n", sizeof(char32_t));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный тип C11 для UTF-32 | Один символ всегда занимает 4 байта |
| Один элемент = один символ Unicode | Избыточное потребление памяти для ASCII |
| Нет суррогатных пар | Меньше совместимости с системными API |
