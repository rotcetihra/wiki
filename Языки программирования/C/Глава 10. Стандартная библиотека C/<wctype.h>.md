## Описание библиотеки

Заголовочный файл `<wctype.h>` — «типы широких символов» (wide character types): функции классификации и преобразования широких символов (`wchar_t`). По функциональности является широкой версией `<ctype.h>`: каждая функция из `<ctype.h>` имеет аналог в `<wctype.h>`, принимающий `wint_t` вместо `int` и работающий с символами полноценного набора символов, а не только с байтами.

Аргументы всех функций имеют тип `wint_t`. Значение `WEOF` (аналог `EOF` для широких символов) не должно передаваться в функции классификации и преобразования — это неопределённое поведение.

Все функции классификации (начинающиеся с `isw`) доступны как функции, так и макросы. Макросы могут вычислять аргумент только один раз, но не гарантируют это — при необходимости многократного вычисления следует вызывать функцию.

### Функции классификации

| Функция | Возвращает ненулевое значение, если символ … |
|---|---|
| `iswalnum()` | буква или цифра |
| `iswalpha()` | буква |
| `iswblank()` | пробел или табуляция |
| `iswcntrl()` | управляющий символ |
| `iswdigit()` | десятичная цифра `0`–`9` |
| `iswgraph()` | печатный символ, отличный от пробела |
| `iswlower()` | строчная буква |
| `iswprint()` | печатный символ (включая пробел) |
| `iswpunct()` | знак пунктуации |
| `iswspace()` | пробельный символ |
| `iswupper()` | заглавная буква |
| `iswxdigit()` | шестнадцатеричная цифра |

### Преобразование регистра

| Функция | Описание |
|---|---|
| `towlower()` | Возвращает нижний регистр широкого символа; для не-букв — сам символ |
| `towupper()` | Возвращает верхний регистр широкого символа; для не-букв — сам символ |

### Описатели классификации и преобразования

| Функция | Описание |
|---|---|
| `wctype()` | Возвращает описатель `wctype_t` для заданной категории символов |
| `iswctype()` | Классифицирует символ по описателю `wctype_t` |
| `wctrans()` | Возвращает описатель `wctrans_t` для заданного преобразования |
| `towctrans()` | Преобразует символ по описателю `wctrans_t` |

> [!NOTE]
> Функции `<wctype.h>` работают с символами набораwchar_t, определённого реализацией. Для работы с кодовыми элементами Unicode (scalar values) см. `<uchar.h>`.
