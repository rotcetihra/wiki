## Описание библиотеки

Заголовочный файл `<stddef.h>` — «общие определения» (common definitions): минимальный заголовок стандартной библиотеки, который подключается почти в каждой программе. В отличие от остальных заголовков, определяет не функции, а **типы и макросы**: `size_t`, `ptrdiff_t`, `wchar_t`, `max_align_t` (C11), `nullptr_t` (C23) и макросы `NULL`, `offsetof()` и `unreachable()` (C23).

>[!NOTE]
>В GCC/glibc заголовок устроен так, чтобы другие заголовки могли «дозапросить» только нужный тип через макросы `__need_size_t`, `__need_ptrdiff_t` и т. п., не включая весь файл. Через `__need_wint_t` здесь может быть определён и `wint_t`, хотя по стандарту этот тип объявлен в `<wchar.h>`.

### Типы

| Тип | Описание | Стандарт |
|---|---|---|
| `size_t` | Беззнаковый тип размера объекта, результат `sizeof` | C89 |
| `ptrdiff_t` | Знаковый тип разности указателей | C89 |
| `wchar_t` | Широкий символ | C89 |
| `max_align_t` | Выравнивание не меньше любого стандартного типа | C11 |
| `nullptr_t` | Тип константы `nullptr` | C23 |

### Макросы

| Макрос | Описание | Стандарт |
|---|---|---|
| `NULL` | Константа нулевого указателя | C89 |
| `offsetof(тип, поле)` | Смещение поля в структуре в байтах | C89 |
| `unreachable()` | Пометка недостижимой точки кода | C23 |
