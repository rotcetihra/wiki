## Прототип

```c
#include <stdlib.h> // C23

int strfroml(char *restrict s, size_t n, const char *restrict format, long double value);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Буфер для результата |
| `n` | Размер буфера |
| `format` | Спецификатор формата: `"%f"`, `"%e"`, `"%g"`, `"%a"` (с необязательными модификаторами длины и точностью) |
| `value` | Преобразуемое число |

## Возвращаемое значение

Число символов, которые были бы записаны, если бы буфер был достаточно большим (без учёта завершающего `'\0'`).

## Что делает

Аналог `strfromd()` для типа `long double`: преобразует число с плавающей точкой в строку без учёта локали (всегда точка `.` как разделитель). Не добавляет завершающий ноль при обрезке по `n`. Доступна с C23.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char buf[64];

    int len = strfroml(buf, sizeof buf, "%.10Lg", 3.14159265358979323846L);
    printf("%s (длина %d)\n", buf, len); // 3.141592654 (длина 11)

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Не зависит от локали | Только базовые форматы — нет ширины/выравнивания |
| Не переполняет буфер | Не добавляет `'\0'` при обрезке |

## Альтернативы

- **`snprintf(buf, n, format, value)`** — более гибкий, но зависит от локали
