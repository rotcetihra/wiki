## Прототип

```c
#include <stdlib.h>

div_t div(int numer, int denom);
```

## Параметры

| Параметр | Описание |
|---|---|
| `numer` | Делимое |
| `denom` | Делитель |

## Возвращаемое значение

Структура `div_t` с полями `quot` (частное) и `rem` (остаток).

## Что делает

Выполняет целочисленное деление, гарантируя определённое поведение для отрицательных операндов: частное округляется в сторону нуля (усечение), а остаток берёт знак делимого (в отличие от оператора `/`, поведение которого при отрицательных операндах до C99 было не определено, а сейчас — усечение к нулю; но `div()` гарантирует это всегда). Значение остатка удовлетворяет соотношению `quot * denom + rem == numer`. Поведение при `denom == 0` не определено.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    div_t r = div(-7, 3); // -7 = -2 * 3 + (-1)

    printf("quot = %d, rem = %d\n", r.quot, r.rem); // quot = -2, rem = -1

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Определённое поведение для отрицательных чисел | Возвращает структуру, а не пару значений |
| Частное и остаток вычисляются за один вызов | Не определена для `denom == 0` |

## Альтернативы

- **Операторы `/` и `%`** — для неотрицательных операндов
- `ldiv()`, `lldiv()` — для `long` и `long long`
