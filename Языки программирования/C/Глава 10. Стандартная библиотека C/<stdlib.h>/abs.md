## Прототип

```c
#include <stdlib.h>

int abs(int n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `n` | Целое число |

## Возвращаемое значение

Абсолютное значение аргумента (модуль числа).

## Что делает

Возвращает модуль числа. Для `INT_MIN` результат не помещается в `int` — поведение не определено.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    printf("%d\n", abs(-5)); // 5
    printf("%d\n", abs(5));  // 5

    return 0;
}
```

>[!WARNING]
>`abs(INT_MIN)` — неопределённое поведение: модуль наименьшего значения `int` не представим в `int`.

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и быстрая | Неопределённое поведение для `INT_MIN` |
