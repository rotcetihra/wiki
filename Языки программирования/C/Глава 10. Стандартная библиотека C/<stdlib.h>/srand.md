## Прототип

```c
#include <stdlib.h>

void srand(unsigned seed);
```

## Параметры

| Параметр | Описание |
|---|---|
| `seed` | Зерно (начальное значение) генератора |

## Возвращаемое значение

Не возвращает значения.

## Что делает

Инициализирует генератор псевдослучайных чисел `rand()`. При одинаковом `seed` последовательность чисел полностью воспроизводится — удобно для отладки и воспроизводимых экспериментов. Вызов с `seed == 1` эквивалентен поведению без вызова `srand()` (генератор стартует с зерна 1). Рекомендуется вызывать один раз в начале `main()`.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void)
{
    // Разные запуски — разные последовательности
    srand((unsigned)time(NULL));

    printf("%d\n", rand());

    // Воспроизводимая последовательность
    srand(42);
    printf("%d\n", rand()); // всегда одинаково при seed = 42

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая инициализация | Не криптостойкая |
| Воспроизводимость при одинаковом зерне | `time(NULL)` даёт одинаковые зерна для быстрых последовательных запусков |

## Альтернативы

- **`rand_r()`** — потокобезопасный вариант (POSIX)
- Инициализация из `/dev/urandom`, `getrandom()` — для лучшего распределения зерна
