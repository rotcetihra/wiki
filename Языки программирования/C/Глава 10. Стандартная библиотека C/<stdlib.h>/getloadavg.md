## Прототип

```c
#include <stdlib.h> // BSD, GNU (в glibc — при __USE_MISC)

int getloadavg(double loadavg[], int nelem);
```

## Параметры

| Параметр | Описание |
|---|---|
| `loadavg[]` | Массив для значений средней загрузки |
| `nelem` | Количество запрашиваемых значений (не более 3) |

## Возвращаемое значение

Число записанных значений (от 1 до `nelem`) или -1 при ошибке.

## Что делает

Возвращает среднюю загрузку системы: первое значение — за последнюю 1 минуту, второе — 5 минут, третье — 15 минут. Расширение BSD, доступное в glibc (Linux); в стандарт POSIX не входит. Значения — числа типа `double`, усреднённые по экспоненциальной шкале ядра (аналогично выводу `uptime`). На некоторых системах (например, без поддержки ядра) возвращает -1.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    double load[3];

    int n = getloadavg(load, 3);
    if (n < 0) {
        return 1;
    }

    printf("%.2f %.2f %.2f\n", load[0], load[1], load[2]); // 1/5/15 минут

    return 0;
}
```

## Ошибки и errno

При неудаче возвращает -1; `errno` может быть установлен (в glibc — `ENOSYS` при отсутствии поддержки).

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простой доступ к загрузке системы | Только BSD/glibc — не переносима |
| Три временных окна одним вызовом | Загрузка — относительная метрика, зависит от числа процессоров |

## Альтернативы

- **Чтение `/proc/loadavg`** (Linux) — без специальных функций
- Команда `uptime` — для ручной проверки
