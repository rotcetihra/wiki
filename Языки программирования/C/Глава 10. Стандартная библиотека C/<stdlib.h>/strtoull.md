## Прототип

```c
#include <stdlib.h>

unsigned long long strtoull(const char *restrict str, char **restrict endptr, int base);
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | Строка для преобразования |
| `endptr` | Указатель на место для записи указателя на первый нераспознанный символ (или `NULL`) |
| `base` | Основание системы счисления (2..36) или 0 для автоопределения |

## Возвращаемое значение

Преобразованное значение или 0, если ничего не распознано.

## Что делает

Аналог `strtoul()` для типа `unsigned long long`. Допускает необязательный знак: минус отрицает результат по правилам беззнаковой арифметики, плюс — игнорируется. При переполнении возвращает `ULLONG_MAX` и устанавливает `errno = ERANGE`. Доступна с C99.

## Примеры

```c
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char *s = "18446744073709551615"; // ULLONG_MAX
    char *end;

    errno = 0;
    unsigned long long v = strtoull(s, &end, 10);
    if (errno == ERANGE) {
        printf("Переполнение\n");
    } else {
        printf("%llu; хвост: %s\n", v, end); // 18446744073709551615; хвост: ""
    }

    return 0;
}
```

## Ошибки и errno

Устанавливает `errno = ERANGE` при переполнении. Для полной проверки сбрасывайте `errno` перед вызовом.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Максимальный беззнаковый диапазон | Отрицательные числа «оборачиваются» |
| Обработка переполнения через `ERANGE` | Нужно проверять `endptr` и `errno` |

## Альтернативы

- **`strtoul()`** — для `unsigned long`
- `strtoll()` — когда нужен знак
