## Прототип

```c
#include <stdlib.h> // POSIX XSI, BSD

char *mkdtemp(char *template);
```

## Параметры

| Параметр | Описание |
|---|---|
| `template` | Строка вида `/tmp/dir-XXXXXX` (шесть символов `X` в конце) |

## Возвращаемое значение

Указатель на `template` с заменёнными `XXXXXX` на уникальное имя, или `NULL` при ошибке.

## Что делает

Создаёт временный каталог с уникальным именем: заменяет шесть завершающих символов `X` в `template` на случайные символы (алгоритм того же семейства, что `mkstemp()`), создаёт каталог с правами `0700` и возвращает строку с именем. При каждом следующем вызове с тем же шаблоном генерируется новое имя. Гарантированно не конфликтует с существующими каталогами (проверка и создание — атомарны на уровне системного вызова).

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char dir[] = "/tmp/wiki-XXXXXX";

    if (mkdtemp(dir) == NULL) {
        perror("mkdtemp");
        return 1;
    }

    printf("%s\n", dir); // /tmp/wiki-XXXXXXXX (уникальное имя)

    return 0;
}
```

## Ошибки и errno

При неудаче возвращает `NULL` и устанавливает `errno`: `EINVAL` — шаблон не заканчивается на `XXXXXX`; `EEXIST` — конфликт имён (обычно исчерпание попыток); `EACCES`/`EPERM` — нет прав на создание.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Уникальное имя без ручного подбора | Изменяет переданную строку (нужна копия) |
| Каталог сразу с правами 0700 | Шаблон обязан заканчиваться на `XXXXXX` |
| Проверка и создание атомарны | Не позволяет задать префикс длиннее возможного |
