## Прототип

```c
#include <stdlib.h> // POSIX, BSD

int mkstemp(char *template);
int mkstemps(char *template, int suffixlen); // GNU, BSD
int mkostemp(char *template, int flags);     // GNU
int mkostemps(char *template, int suffixlen, int flags); // GNU
```

## Параметры

| Параметр | Описание |
|---|---|
| `template` | Шаблон с шестью `X` в конце (до суффикса для `mkstemps`/`mkostemps`) |
| `suffixlen` | Длина суффикса после `XXXXXX` |
| `flags` | Дополнительные флаги `open()` (например, `O_CLOEXEC`) |

## Возвращаемое значение

Файловый дескриптор созданного файла (открыт с `O_RDWR | O_CREAT | O_EXCL`, права 0600) или -1 при ошибке.

## Что делает

Создаёт временный файл с уникальным именем: заменяет завершающие `XXXXXX` на случайные символы и атомарно создаёт файл (`O_EXCL` — никогда не открывает существующий, без гонок). Файл сразу открыт на чтение и запись; удалять его и закрывать — забота вызывающего (`unlink()` после открытия идёт немедленно — распространённый приём). Варианты: `mkstemps()` — суффикс после `XXXXXX` (GNU/BSD); `mkostemp()` — дополнительные флаги `open()` (GNU); `mkostemps()` — суффикс и флаги (GNU).

## Примеры

```c
#include <fcntl.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>

int main(void)
{
    char name[] = "/tmp/wiki-XXXXXX";

    int fd = mkostemp(name, O_CLOEXEC);
    if (fd < 0) {
        return 1;
    }

    unlink(name);          // имя больше не нужно — файл жив по дескриптору
    write(fd, "data", 4);  // работа с временным файлом
    close(fd);

    return 0;
}
```

## Ошибки и errno

При неудаче возвращает -1 и устанавливает `errno`: `EINVAL` — шаблон не заканчивается на `XXXXXX`; `EEXIST` — исчерпаны попытки генерации; прочие — от `open()`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Атомарное создание без конфликтов | Изменяет переданную строку-шаблон |
| Файл сразу открыт и с правами 0600 | Не создаёт каталог (в отличие от `mkdtemp()`) |
| `mkostemp()` позволяет `O_CLOEXEC` | Требует ручного `unlink()` для скрытия имени |
