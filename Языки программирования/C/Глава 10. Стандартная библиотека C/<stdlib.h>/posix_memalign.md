## Прототип

```c
#include <stdlib.h> // POSIX

int posix_memalign(void **memptr, size_t alignment, size_t size);
```

## Параметры

| Параметр | Описание |
|---|---|
| `memptr` | Указатель на переменную, куда записывается адрес выделенного блока |
| `alignment` | Выравнивание: степень двойки, кратная `sizeof(void *)` |
| `size` | Размер блока в байтах |

## Возвращаемое значение

0 при успехе или код ошибки (не `errno`): `EINVAL` — выравнивание не является степенью двойки или не кратно `sizeof(void *)`; `ENOMEM` — недостаточно памяти.

## Что делает

Выделяет `size` байт с выравниванием `alignment` и записывает адрес в `*memptr`. При ошибке `*memptr` остаётся без изменений. Освобождается обычной `free()`. В отличие от `aligned_alloc()` (C11): не требует, чтобы `size` был кратен `alignment`, и сообщает об ошибках кодом возврата, а не через `NULL`. Фактическая сторона: выделять с выравниванием свыше страницы (например, для SIMD, кэш-линии) работает на glibc.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    void *p;

    int rc = posix_memalign(&p, 64, 256); // 256 байт с выравниванием 64
    if (rc != 0) {
        return 1;
    }

    printf("%zu\n", (size_t)p % 64); // 0 — выравнивание соблюдено

    free(p);
    return 0;
}
```

## Ошибки и errno

Возвращает код ошибки напрямую (`EINVAL`, `ENOMEM`); `errno` не используется. Успех — только по нулевому возврату.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Не требует кратности `size` выравниванию (в отличие от `aligned_alloc()`) | Код ошибки возвращается значением — легко пропустить |
| Переносимая (POSIX.1-2001) | Только степени двойки |
| Освобождается `free()` | Не выделяет «выровненный» блок в C (нет гарантий сверх `malloc()`) больше `sizeof(void*)` без поддержки ОС |
