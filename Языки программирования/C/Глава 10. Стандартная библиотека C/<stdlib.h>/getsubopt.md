## Прототип

```c
#include <stdlib.h> // XSI

int getsubopt(char **optionp, char *const *tokens, char **valuep);
```

## Параметры

| Параметр | Описание |
|---|---|
| `optionp` | Указатель на строку с оставшимися подопциями (обновляется при каждом вызове) |
| `tokens` | Завершающийся `NULL`-элементом массив допустимых имён подопций |
| `valuep` | Указатель на место для значения подопции (или `NULL` при отсутствии `=`) |

## Возвращаемое значение

Индекс подопции в массиве `tokens`, или -1, если имя не распознано.

## Что делает

Разбирает строку подопций вида `подопция` или `подопция=значение`, разделённых запятыми (например, `"ro,nosuid,exec"` — аргумент `-o` в `mount(8)`). При каждом вызове извлекает одну подопцию, записывает в `*valuep` указатель на её значение (или `NULL`), а `*optionp` сдвигает к следующей запятой. Если имя не найдено в `tokens`, возвращает -1, но значение всё равно извлекается (что позволяет обнаружить неизвестные подопции). POSIX XSI-функция.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    char *option = "ro,nosuid,exec";
    char *const mounts[] = {"ro", "rw", "suid", "nosuid", NULL};
    char *value;

    int n = getsubopt(&option, mounts, &value);
    printf("%d %s\n", n, value ? value : "(нет значения)"); // 0 (нет значения)

    n = getsubopt(&option, mounts, &value);
    printf("%d %s\n", n, value ? value : "(нет значения)"); // 3 (нет значения)

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Переносимый разбор подопций | Значение фиксировано: имя опции без `=` не имеет значения |
| Игнорирует дубли и пробелы вокруг `=` | Ошибка распознавания обнаруживается только по возврату -1 |
