## Прототип

```c
#include <stdlib.h>

int mbtowc(wchar_t *restrict dst, const char *restrict s, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dst` | Указатель на буфер для широкого символа (в C23 — `wchar_t *`) |
| `s` | Указатель на многобайтовый символ (или `NULL` для сброса состояния) |
| `n` | Максимальное количество байт для анализа |

## Возвращаемое значение

- 0 — если `s` указывает на нулевой байт;
- количество байт в распознанном многобайтовом символе (1..n);
- -1 — если первые `n` байт не образуют полный многобайтовый символ;
- ненулевое значение при `s == NULL`, если в локали есть символы переменной длины.

## Что делает

Преобразует один многобайтовый символ в широкий (`wchar_t`) в текущей локали (категория `LC_CTYPE`). Вызов с `s == NULL` сбрасывает внутреннее состояние. В главе 9 многобайтовые строки рассматриваются в статье [[Языки программирования/C/Глава 9. Стандартная библиотека C/8. Поддержка Unicode и кодировки UTF-8, UTF-16 и UTF-32|«Поддержка Unicode и кодировки UTF-8, UTF-16 и UTF-32»]].

## Примеры

```c
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
#include <wchar.h>

int main(void)
{
    setlocale(LC_ALL, ""); // включаем UTF-8

    const char *multi = "П";
    wchar_t wc = 0;

    int len = mbtowc(&wc, multi, MB_CUR_MAX);
    if (len < 0) {
        printf("Недопустимый символ\n");
        return 1;
    }

    wprintf(L"len=%d wc=%lc\n", len, wc); // len=2 wc=П

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая работа с одним символом | Непотокобезопасна (нужен `mbrtowc()` из `<wchar.h>`) |
| | Требует следить за длиной символа для перехода к следующему |

## Альтернативы

- **`mbrtowc()`** из `<wchar.h>` — потокобезопасный вариант с явным состоянием
- `mblen()` — только длина символа без преобразования
