## Прототип

```c
#include <stdlib.h>

long double strtold(const char *restrict str, char **restrict endptr);
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | Строка для преобразования |
| `endptr` | Указатель на место для записи указателя на первый нераспознанный символ (или `NULL`) |

## Возвращаемое значение

Преобразованное значение или 0, если ничего не распознано.

## Что делает

Аналог `strtod()` для типа `long double`. Правила разбора те же: пробелы, знак, десятичная точка, экспонента, `INF`/`NAN`. При переполнении возвращает `±HUGE_VALL` и устанавливает `errno = ERANGE`.

## Примеры

```c
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char *s = "1.25e-3";
    char *end;

    errno = 0;
    long double ld = strtold(s, &end);
    if (errno == ERANGE) {
        printf("Переполнение\n");
    } else {
        printf("%.6Lf; хвост: %s\n", ld, end); // 0.001250; хвост: ""
    }

    return 0;
}
```

## Ошибки и errno

Устанавливает `errno = ERANGE` при переполнении или потере значимости. Для полной проверки сбрасывайте `errno` перед вызовом.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Максимальная точность среди семейства | Нужно проверять `endptr` и `errno` |
| Обработка переполнения через `ERANGE` | Требует осторожности с сужением до `long double` в разных реализациях (80-бит x87) |

## Альтернативы

- **`strtod()`** — для `double`
- `strtof()` — для `float`
