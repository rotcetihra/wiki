## Прототип

```c
#include <stdlib.h>

long strtol(const char *restrict str, char **restrict endptr, int base);
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | Строка для преобразования |
| `endptr` | Указатель на место для записи указателя на первый нераспознанный символ (или `NULL`) |
| `base` | Основание системы счисления (2..36) или 0 для автоопределения |

## Возвращаемое значение

Преобразованное значение или 0, если ничего не распознано.

## Что делает

Преобразует строку в `long` в системе счисления `base`. Если `base == 0`, основание определяется по префиксу: `0x`/`0X` — шестнадцатеричная, ведущий `0` — восьмеричная, иначе десятичная. `base == 16` допускает префикс `0x`/`0X`. Если `base == 2..36`, используется стандартный набор цифр (до `z`). Пропускает ведущие пробельные символы, разбирает необязательный знак. При переполнении возвращает `LONG_MAX`/`LONG_MIN` и устанавливает `errno = ERANGE`; `*endptr` указывает на первый нераспознанный символ (в glibc — на начало ошибочной последовательности).

## Примеры

```c
#include <errno.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    const char *s = "  0x1F остаток";
    char *end;

    errno = 0;
    long v = strtol(s, &end, 0); // base = 0 — автоопределение по 0x
    if (errno == ERANGE) {
        printf("Переполнение\n");
    } else {
        printf("%ld; хвост: %s\n", v, end); // 31; хвост: " остаток"
    }

    return 0;
}
```

## Ошибки и errno

Устанавливает `errno = ERANGE` при переполнении. Для полной проверки сбрасывайте `errno` перед вызовом.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Основание системы счисления (2..36, 0 — авто) | Нужно проверять `endptr` и `errno` |
| Обработка переполнения через `ERANGE` | Пустая строка и 0 неотличимы без `endptr` |

## Альтернативы

- **`strtoll()`** — для `long long`
- `strtoul()` / `strtoull()` — для беззнаковых типов
- `atoi()` — упрощённый вариант без проверок
