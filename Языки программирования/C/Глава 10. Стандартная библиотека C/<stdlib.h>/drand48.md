## Прототип

```c
#include <stdlib.h> // XSI (SVID)

double drand48(void);
double erand48(unsigned short xsubi[3]);
long lrand48(void);
long nrand48(unsigned short xsubi[3]);
long mrand48(void);
long jrand48(unsigned short xsubi[3]);
void srand48(long seedval);
unsigned short *seed48(unsigned short seed16v[3]);
void lcong48(unsigned short param[7]);
```

## Параметры

| Функция | Параметр | Описание |
|---|---|---|
| `erand48`/`nrand48`/`jrand48` | `xsubi[3]` | Явное состояние генератора (48 бит) у вызывающего |
| `srand48` | `seedval` | Начальное зерно |
| `seed48` | `seed16v[3]` | Полное 48-битное начальное состояние |
| `lcong48` | `param[7]` | Параметры: множитель, инкремент, модуль (3 слова) и начальное состояние (3 слова) + 1 запасающее |

## Возвращаемое значение

- `drand48()`/`erand48()` — число типа `double` из [0.0, 1.0);
- `lrand48()`/`nrand48()` — неотрицательное `long` из [0, 2³¹);
- `mrand48()`/`jrand48()` — знаковое `long` из [−2³¹, 2³¹);
- `seed48()` — указатель на предыдущее состояние.

## Что делает

Семейство генераторов псевдослучайных чисел на основе 48-битного линейного конгруэнтного генератора: `X[n+1] = (a·X[n] + c) mod 2⁴⁸`. Функции без параметра состояния используют скрытое глобальное состояние — не потокобезопасны (нужны варианты `_r`: `drand48_r()`, `lrand48_r()` и т. д.). `drand48()` делит состояние на 2⁴⁸, поэтому результат равномерен в [0, 1). Качество генератора невысокое (младшие биты коррелируют) — для серьёзных задач предпочтительнее другие генераторы.

>[!WARNING]
>Генератор не предназначен для криптографии и высококачественного моделирования. `mrand48()` использует знаковое 32-битное слово из 48-битного состояния — это историческое поведение, сохраняемое для совместимости.

## Примеры

```c
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    srand48(42); // инициализация зерном

    printf("%f\n", drand48()); // [0; 1)
    printf("%ld\n", lrand48()); // [0; 2^31)
    printf("%ld\n", mrand48()); // [-2^31; 2^31)

    return 0;
}
```

## Ошибки и errno

Функции не устанавливают `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Равномерное распределение double в [0; 1) | Глобальное состояние — не потокобезопасны без `_r` |
| Простая инициализация (`srand48()`, `seed48()`, `lcong48()`) | Устаревший алгоритм с корреляцией младших битов |
| Воспроизводимость при заданном зерне | 48-битный период (около 2,8·10¹⁴) |
