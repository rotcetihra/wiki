## Прототип

```c
#include <stdlib.h> // GNU (при _GNU_SOURCE)

double strtod_l(const char *restrict nptr, char **restrict endptr, locale_t loc);
float strtof_l(const char *restrict nptr, char **restrict endptr, locale_t loc);
long double strtold_l(const char *restrict nptr, char **restrict endptr, locale_t loc);
```

## Параметры

| Параметр | Описание |
|---|---|
| `nptr` | Строка для преобразования |
| `endptr` | Указатель на первый нераспознанный символ (или `NULL`) |
| `loc` | Локаль из `<locale.h>` (например, `newlocale()` или `uselocale()`), задающая правила разбора (разделитель, `INF`/`NAN` в локали) |

## Возвращаемое значение

Преобразованное число или 0, если распознавания не произошло; при переполнении — `±HUGE_VAL`/`HUGE_VALF`/`HUGE_VALL` с `errno = ERANGE`.

## Что делает

Варианты `strtod()`/`strtof()`/`strtold()` с явно заданной локалью — не зависят от текущей локали процесса и безопасны для многопоточных программ (не трогают `LC_NUMERIC`). GNU-расширение (не POSIX). Тип `locale_t` и функции `newlocale()`/`uselocale()` определены в `<locale.h>`.

## Примеры

```c
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    locale_t ru = newlocale(LC_NUMERIC_MASK, "ru_RU.UTF-8", (locale_t)0);
    if (ru == (locale_t)0) {
        return 1;
    }

    char *end;
    double d = strtod_l("  -42,5", &end, ru); // запятая — десятичный разделитель
    printf("%g\n", d); // -42.5

    freelocale(ru);
    return 0;
}
```

## Ошибки и errno

При переполнении возвращает `±HUGE_VAL*` и устанавливает `errno = ERANGE` (как стандартные версии). `endptr` фиксирует позицию остановки.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Разбор по правилам явной локали (без глобального состояния) | Только glibc — не переносима |
| Потокобезопасна | Требует управления объектом `locale_t` |
