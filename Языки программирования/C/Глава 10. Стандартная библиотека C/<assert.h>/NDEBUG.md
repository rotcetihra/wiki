## Определение

```c
#define NDEBUG // определить до #include <assert.h> или флагом -DNDEBUG
```

## Описание

Ключевое макроопределение: если `NDEBUG` определён до включения `<assert.h>`, макрос `assert()` разворачивается в пустоту, и все проверки компилируются в ноль кода. Не считается ошибкой, если `NDEBUG` не определён — тогда проверки активны.

Обычно `NDEBUG` задают флагом компилятора `-DNDEBUG` при сборке релизных версий (препроцессор определяет макрос для всех единиц трансляции). Отключать его выборочно (переопределяя перед конкретным `<assert.h>`) не рекомендуется, но возможно.

## Примеры

```bash
gcc -DNDEBUG program.c -o program   # сборка без проверок assert
```

```c
// В коде макрос остаётся, но исчезает из сборки:
#include <assert.h>

void print(int *p)
{
    assert(p != NULL); // пусто при -DNDEBUG
    printf("%d\n", *p);
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Нулевая стоимость проверок в релизе | Проверки не работают в продакшене |
