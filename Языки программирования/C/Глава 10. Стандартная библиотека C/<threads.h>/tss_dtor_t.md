## Определение

```c
#include <threads.h>

typedef void (*tss_dtor_t)(void *);
```

## Описание

Тип `tss_dtor_t` определяет функцию-деструктор для элементов потокового хранилища данных. Деструктор вызывается при завершении потока для каждого ненулевого значения, установленного через `tss_set`.

Деструктор не вызывается для значений, которые были установлены как `NULL`.

## Пример

```c
#include <stdlib.h>
#include <threads.h>

tss_t key;

void my_destructor(void *val)
{
    free(val);
}

int main(void)
{
    tss_create(&key, my_destructor);
    tss_delete(key);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматическое освобождение ресурсов при завершении потока | Количество вызовов ограничено `TSS_DTOR_ITERATIONS` |
| — | Порядок вызова деструкторов не определён |
