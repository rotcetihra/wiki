## Определение

```c
#include <threads.h>

#define MTX_INIT /* инициализатор */
```

## Описание

Макрос `MTX_INIT` является инициализатором для переменной типа `mtx_t`. Создаёт мьютекс по умолчанию (блокировка по умолчанию, как при `mtx_init` с флагом `mtx_plain`).

## Пример

```c
#include <threads.h>

mtx_t m = MTX_INIT;
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Статическая инициализация без вызова `mtx_init` | Тип мьютекса фиксирован (по умолчанию) |
