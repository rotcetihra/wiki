## Определение

```c
#include <threads.h>

#define TSS_DTOR_ITERATIONS /* реализация-зависимая константа */
```

## Описание

Макрос `TSS_DTOR_ITERATIONS` задаёт максимальное количество вызовов деструкторов потокового хранилища для освобождения всех ключей. Стандарт требует, чтобы значение было не менее 4.

Деструкторы вызываются итеративно: если деструктор устанавливает новое значение для другого ключа, этот ключ также будет обработан. Итерации прекращаются, когда все значения станут `NULL` или будет достигнут предел.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует освобождение ресурсов | Количество итераций ограничено |
| Стандартная константа | Порядок вызова деструкторов не определён |
