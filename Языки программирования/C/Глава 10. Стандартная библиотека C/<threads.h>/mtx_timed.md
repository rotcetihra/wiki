## Определение

```c
#include <threads.h>

#define mtx_timed /* константа */
```

## Описание

Константа `mtx_timed` задаёт тип мьютекса с поддержкой блокировки по времени. Позволяет использовать `mtx_timedlock` для ограничения времени ожидания блокировки.

Не поддерживает рекурсию — повторная блокировка тем же потоком приводит к неопределённому поведению.

## Пример

```c
#include <threads.h>

mtx_t m;
mtx_init(&m, mtx_timed);
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Поддержка блокировки по времени | Нет рекурсии |
| Позволяет избежать бесконечного ожидания | Нет поддержки рекурсии |
