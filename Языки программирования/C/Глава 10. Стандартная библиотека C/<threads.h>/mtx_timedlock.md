## Определение

```c
#include <threads.h>

int mtx_timedlock(mtx_t *mtx, const struct timespec *time_point);
```

## Описание

Функция `mtx_timedlock` пытается заблокировать мьютекс `mtx` с ограничением по времени. Если мьютекс не освободился до момента `time_point`, возвращается `thrd_timedout`.

Мьютекс должен быть инициализирован с типом `mtx_timed`. Поведение для `mtx_plain` или `mtx_recursive` не определено.

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `thrd_success` | Мьютекс заблокирован |
| `thrd_timedout` | Истекло время ожидания |
| `thrd_error` | Ошибка |

## Пример

```c
#include <stdio.h>
#include <threads.h>

int main(void)
{
    mtx_t m;
    mtx_init(&m, mtx_timed);

    struct timespec ts = { .tv_sec = 1, .tv_nsec = 0 };
    int res = mtx_timedlock(&m, &ts);
    if (res == thrd_success) {
        printf("Заблокировано\n");
        mtx_unlock(&m);
    } else if (res == thrd_timedout) {
        printf("Тайм-аут\n");
    }

    mtx_destroy(&m);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `mtx` | Мьютекс типа `mtx_timed` |
| `time_point` | Абсолютный момент времени (`struct timespec`) |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Не блокирует поток бесконечно | Только для мьютексов типа `mtx_timed` |
| Позволяет обработать тайм-аут | Зависит от точности системного таймера |
