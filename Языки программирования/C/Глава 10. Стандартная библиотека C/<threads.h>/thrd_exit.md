## Определение

```c
#include <threads.h>

_Noreturn void thrd_exit(int res);
```

## Описание

Функция `thrd_exit` немедленно завершает текущий поток с кодом возврата `res`. Вызывающий поток не должен иметь заблокированные мьютексы — иначе поведение не определено.

Для завершения main-потока используйте `return` или `exit`.

## Пример

```c
#include <stdio.h>
#include <threads.h>

int func(void *arg)
{
    printf("Перед завершением\n");
    thrd_exit(42);
    printf("Это не будет выведено\n");
}

int main(void)
{
    thrd_t t;
    thrd_create(&t, func, NULL);
    int res;
    thrd_join(t, &res);
    printf("Код возврата: %d\n", res);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `res` | Код возврата потока |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Немедленное завершение потока | Нельзя вызывать с заблокированными мьютексами |
| Код возврата доступен через `thrd_join` | `_Noreturn` — функция не возвращает управления |
