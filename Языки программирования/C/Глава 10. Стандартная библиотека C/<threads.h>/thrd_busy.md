## Определение

```c
#include <threads.h>

#define thrd_busy /* константа (ненулевое) */
```

## Описание

Константа `thrd_busy` возвращается, если запрашиваемый ресурс в данный момент занят. Например, `mtx_trylock` возвращает `thrd_busy`, если мьютекс уже заблокирован другим потоком.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет обработать «ресурс занят» без блокировки | — |
