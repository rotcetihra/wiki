## Определение

```c
#include <threads.h>

thrd_t thrd_current(void);
```

## Описание

Функция `thrd_current` возвращает идентификатор текущего потока. Значение может быть использовано для сравнения с другими идентификаторами через `thrd_equal`.

## Пример

```c
#include <stdio.h>
#include <threads.h>

int func(void *arg)
{
    thrd_t self = thrd_current();
    printf("ID текущего потока получен\n");
    return 0;
}

int main(void)
{
    thrd_t t;
    thrd_create(&t, func, NULL);
    thrd_join(t, NULL);
    return 0;
}
```

## Возвращаемое значение

Идентификатор текущего потока.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет получить ID текущего потока | Нельзя напрямую сравнить через `==` |
