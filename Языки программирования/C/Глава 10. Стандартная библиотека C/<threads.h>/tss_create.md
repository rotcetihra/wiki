## Определение

```c
#include <threads.h>

int tss_create(tss_t *key, tss_dtor_t dtor);
```

## Описание

Функция `tss_create` создаёт ключ потокового хранилища данных. Каждый поток может установить собственное значение для данного ключа через `tss_set`.

Параметр `dtor` — функция-деструктор, вызываемая при завершении потока для каждого ненулевого значения. Деструктор не вызывается для `NULL`.

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `thrd_success` | Ключ создан |
| `thrd_nomem` | Не хватило памяти |
| `thrd_error` | Другая ошибка |

## Пример

```c
#include <stdlib.h>
#include <stdio.h>
#include <threads.h>

tss_t key;

void destructor(void *val)
{
    free(val);
}

int func(void *arg)
{
    int *p = malloc(sizeof(int));
    *p = 42;
    tss_set(key, p);
    printf("Значение: %d\n", *(int *)tss_get(key));
    return 0;
}

int main(void)
{
    tss_create(&key, destructor);
    thrd_t t;
    thrd_create(&t, func, NULL);
    thrd_join(t, NULL);
    tss_delete(key);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `key` | Указатель для сохранения созданного ключа |
| `dtor` | Деструктор (или `NULL`) |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Автоматическое освобождение через деструктор | Деструктор вызывается не более `TSS_DTOR_ITERATIONS` раз |
| Потокобезопасное хранилище | Количество ключей может быть ограничено реализацией |
