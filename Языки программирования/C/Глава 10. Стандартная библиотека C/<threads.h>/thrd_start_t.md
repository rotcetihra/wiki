## Определение

```c
#include <threads.h>

typedef int (*thrd_start_t)(void *);
```

## Описание

Тип `thrd_start_t` определяет сигнатуру функции потока. Функция принимает один аргумент типа `void *` и возвращает `int` — код завершения потока.

## Пример

```c
#include <stdio.h>
#include <threads.h>

int my_func(void *arg)
{
    int n = *(int *)arg;
    printf("Поток получил: %d\n", n);
    return 0;
}

int main(void)
{
    int val = 42;
    thrd_t t;
    thrd_create(&t, my_func, &val);
    thrd_join(t, NULL);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая сигнатура для функции потока | Возврат только `int` — нельзя вернуть сложные данные |
| Через `void *` можно передать любой аргумент | Необходимость управления временем жизни аргумента |
