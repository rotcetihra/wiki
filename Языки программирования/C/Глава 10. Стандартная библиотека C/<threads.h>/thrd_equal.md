## Определение

```c
#include <threads.h>

int thrd_equal(thrd_t lhs, thrd_t rhs);
```

## Описание

Функция `thrd_equal` сравнивает два идентификатора потоков. Возвращает ненулевое значение, если оба идентификатора относятся к одному потоку.

> [!NOTE]
> Сравнивать идентификаторы через `==` нельзя — это не определено стандартом.

## Пример

```c
#include <stdio.h>
#include <threads.h>

int func(void *arg)
{
    thrd_t self = thrd_current();
    printf("Поток равен самому себе: %d\n", thrd_equal(self, self));
    return 0;
}

int main(void)
{
    thrd_t t;
    thrd_create(&t, func, NULL);
    thrd_join(t, NULL);
    return 0;
}
```

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Ненулевое | Идентификаторы относятся к одному потоку |
| `0` | Разные потоки |

## Параметры

| Параметр | Описание |
|---|---|
| `lhs` | Первый идентификатор потока |
| `rhs` | Второй идентификатор потока |
