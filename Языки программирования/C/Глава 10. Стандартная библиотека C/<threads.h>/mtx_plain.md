## Определение

```c
#include <threads.h>

#define mtx_plain /* константа */
```

## Описание

Константа `mtx_plain` задаёт тип простого (нерекурсивного) мьютекса при инициализации через `mtx_init`. Такой мьютекс не поддерживает блокировку по времени — попытка использовать `mtx_timedlock` с `mtx_plain` приводит к `thrd_error`.

## Пример

```c
#include <threads.h>

mtx_t m;
mtx_init(&m, mtx_plain);
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простейший тип мьютекса | Нет рекурсии — повторная блокировка тем же потоком приводит к dead-lock |
| Минимальные накладные расходы | Нет поддержки тайм-аута |
