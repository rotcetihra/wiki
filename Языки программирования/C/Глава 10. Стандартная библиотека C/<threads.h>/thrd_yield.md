## Определение

```c
#include <threads.h>

void thrd_yield(void);
```

## Описание

Функция `thrd_yield` уступает процессор другому потоку с тем же или более высоким приоритетом. Текущий поток не блокируется — он просто даёт возможность планировщику запустить другой поток.

Поведение зависит от планировщика потоков операционной системы. На системах с поддержкой вытесняющего планировщика вызов может не оказать заметного эффекта.

## Пример

```c
#include <stdio.h>
#include <threads.h>

int func(void *arg)
{
    for (int i = 0; i < 5; i++) {
        printf("Поток: итерация %d\n", i);
        thrd_yield();
    }
    return 0;
}

int main(void)
{
    thrd_t t;
    thrd_create(&t, func, NULL);
    thrd_join(t, NULL);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Неблокирующий вызов | Эффект зависит от планировщика ОС |
| Позволяет другим потокам выполниться | Может не оказать влияния |
