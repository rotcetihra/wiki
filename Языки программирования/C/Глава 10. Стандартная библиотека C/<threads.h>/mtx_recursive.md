## Определение

```c
#include <threads.h>

#define mtx_recursive /* константа */
```

## Описание

Константа `mtx_recursive` задаёт тип рекурсивного мьютекса. Один и тот же поток может заблокировать его несколько раз без dead-lock. Каждая блокировка должна быть соответствующим образом разблокирована.

Не поддерживает блокировку по времени.

## Пример

```c
#include <threads.h>

mtx_t m;
mtx_init(&m, mtx_recursive);
mtx_lock(&m);
mtx_lock(&m);  /* OK — рекурсивный */
mtx_unlock(&m);
mtx_unlock(&m);
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Безопасен для рекурсивных вызовов | Больше накладных расходов, чем `mtx_plain` |
| Предотвращает dead-lock в рекурсивных функциях | Нет поддержки тайм-аута |
