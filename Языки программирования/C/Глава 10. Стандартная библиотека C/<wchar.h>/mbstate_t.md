## Определение

```c
#include <wchar.h>

typedef /* unspecified structure type */ mbstate_t;
```

## Описание

Тип `mbstate_t` — неполный тип структуры, предназначенный для хранения состояния многобайтового преобразования. Используется функциями `mbrtowc()`, `wcrtomb()`, `mbsrtowcs()`, `wcsrtombs()` для отслеживания состояния при преобразовании между многобайтовыми и широкими строками.

Начальное состояние (символическое значение) создаётся инициализацией нулевым константным выражением:

```c
mbstate_t state = {0};
```

После инициализации `mbsinit(&state)` возвращает ненулевое значение.

> [!NOTE]
> Структура `mbstate_t` может содержать информацию о незавершённой многобайтовой последовательности. Это важно при посимвольном чтении: если последовательность прочитана не полностью, состояние сохраняется для следующего вызова.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>
#include <string.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const char *mb_str = "Привет";
    mbstate_t state = {0};

    wchar_t wc;
    const char *ptr = mb_str;
    size_t len;

    while ((len = mbrtowc(&wc, ptr, MB_LEN_MAX, &state)) > 0) {
        printf("Символ: %lc (байты: %zu)\n", wc, len);
        ptr += len;
    }

    if (mbsinit(&state))
        printf("Состояние начальное (все последовательности завершены)\n");

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет выполнять посимвольное преобразование | Структура определяется реализацией |
| Потокобезопасен (каждый вызов использует своё состояние) | Требует явной инициализации перед использованием |
| Стандартный тип ISO C | Не гарантируется тривиально копируемым |
