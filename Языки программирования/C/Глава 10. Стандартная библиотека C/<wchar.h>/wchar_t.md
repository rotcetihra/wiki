## Определение

```c
#include <stddef.h>
#include <wchar.h>

typedef /* integer type with the size of the smallest supported multibyte encoding */ wchar_t;
```

## Описание

Тип `wchar_t` — основной тип широкого символа в C. Предназначен для представления символов широкого набора символов (wide character set), включающего символы национальных алфавитов, знаки пунктуации и символы Unicode.

Минимальный размер `wchar_t` — 16 бит (по стандарту C), однако на POSIX-системах (Linux, macOS) он обычно составляет 32 бита и совпадает с `char32_t`, что позволяет напрямую представлять любой символ Unicode в одном значении. В Windows `wchar_t` — 16 бит и совпадает с `char16_t` (формат UTF-16).

Тип определён в `<stddef.h>`, но доступен и через `<wchar.h>`. Литералы широких символов записываются с префиксом `L`: `L'A'`, `L'Привет'`. Широкие строки — `L"Hello, мир"`.

> [!WARNING]
> Размер `wchar_t` различается на POSIX (32 бита) и Windows (16 бит). Код, который предполагает конкретный размер, не будет портативным.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wchar_t symbol = L'Ω';  /*希腊ская буква омега */
    wchar_t cyrillic = L'Ж';

    printf("Размер wchar_t: %zu бит\n", sizeof(wchar_t) * 8);
    printf("Широкий символ: %lc\n", symbol);
    printf("Кириллица: %lc\n", cyrillic);

    wchar_t str[] = L"Привет, мир!";
    printf("Длина строки: %zu\n", wcslen(str));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет представлять символы любого алфавита в одном типе | Размер определяется реализацией (16 или 32 бита) |
| Стандартный тип ISO C | Непортативность между Windows и POSIX из-за разного размера |
| Поддержка локалей через `setlocale()` | Занимает больше памяти, чем `char` |
