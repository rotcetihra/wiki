## Определение

```c
#include <wchar.h>

typedef /* unsigned integer type */ wint_t;
```

## Описание

Тип `wint_t` — беззнаковый целый тип, предназначенный для представления широких символов и специального значения `WEOF` (аналога `EOF` для широких символов). В отличие от `wchar_t`, `wint_t` гарантированно может представлять любое значение широкого символа, а также `WEOF`, что делает его удобным типом возвращаемого значения для функций классификации и чтения широких символов.

Тип определён в `<wchar.h>`. Функции классификации (`iswalnum`, `iswalpha` и т. д.) принимают и возвращают `wint_t`. Функция `fgetwc()` возвращает `wint_t` — `WEOF` при ошибке или конце файла.

> [!NOTE]
> `wint_t` обеспечивает корректную обработку ошибок через `WEOF`, тогда как `wchar_t` не может отличить некорректный символ от допустимого.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wint_t ch = fgetwc(stdin);
    if (ch == WEOF) {
        printf("Ошибка чтения или конец файла\n");
    } else {
        printf("Прочитан символ: %lc\n", ch);
    }

    wint_t upper = towupper(L'привет');
    printf("towupper от небуквенного символа: %lc\n", upper);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует представление `WEOF` | Тип определяется реализацией |
| Удобен для возврата из функций чтения | Может не совпадать по размеру с `wchar_t` |
| Стандартный тип ISO C | Требует подключения `<wchar.h>` |
