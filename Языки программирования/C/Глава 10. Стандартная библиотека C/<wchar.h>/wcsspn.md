## Определение

```c
#include <wchar.h>

size_t wcsspn(const wchar_t *str, const wchar_t *accept);
```

## Описание

Функция `wcsspn()` вычисляет длину начального сегмента строки `str`, который **содержит только** символы из строки `accept`. Если ни один из символов `str` не принадлежит `accept`, возвращается `0`.

Функция является широкосимвольным аналогом `strspn()` из `<string.h>`. Является «зеркальной» к `wcscspn()`: если `wcscspn(str, reject)` возвращает длину сегмента **без** символов `reject`, то `wcsspn(str, accept)` — длину сегмента **только из** символов `accept`.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *str = L"   Привет";
    const wchar_t *spaces = L" ";

    size_t skip = wcsspn(str, spaces);
    printf("Пропущено пробелов: %zu\n", skip);  /* 3 */
    printf("Непробельная часть: %ls\n", str + skip);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрый подсчёт допустимых символов | Возвращает только длину |
| Стандартная функция ISO C | Линейная сложность |
| Удобна для пропуска разделителей | Не модифицирует строку |
