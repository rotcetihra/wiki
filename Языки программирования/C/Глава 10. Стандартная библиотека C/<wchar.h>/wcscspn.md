## Определение

```c
#include <wchar.h>

size_t wcscspn(const wchar_t *str, const wchar_t *reject);
```

## Описание

Функция `wcscspn()` вычисляет длину начального сегмента строки `str`, который **не содержит** ни одного из символов строки `reject`. Если ни один из символов `reject` не найден, возвращается длина всей строки `str` (без нуль-терминатора).

Функция является широкосимвольным аналогом `strcspn()` из `<string.h>`.

> [!NOTE]
> Возвращаемое значение — количество символов от начала строки до первого вхождения любого из символов `reject`.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *str = L"Привет, мир!";
    const wchar_t *reject = L" ,!";

    size_t span = wcscspn(str, reject);
    printf("Длина сегмента без пробела и знаков: %zu\n", span);  /* 6 */

    /* Разбиение строки на токены */
    const wchar_t *delim = L" ,";
    const wchar_t *p = str;
    while (*p) {
        size_t len = wcscspn(p, delim);
        if (len > 0)
            printf("Токен: %.*ls\n", (int)len, p);
        p += len;
        if (*p)
            p++;
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрый поиск без аллокации памяти | Возвращает только длину, не указатель |
| Стандартная функция ISO C | Линейная сложность для каждой строки |
| Удобна для разбиения строк на токены | Не модифицирует строку (только чтение) |
