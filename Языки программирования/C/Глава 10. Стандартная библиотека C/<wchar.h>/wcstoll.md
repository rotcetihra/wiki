## Определение

```c
#include <wchar.h>

long long wcstoll(const wchar_t *str, wchar_t **endptr, int base);
```

## Описание

Функция `wcstoll()` преобразует широкую строку `str` в значение типа `long long`. Является широкосимвольным аналогом `strtoll()` из `<stdlib.h>`. Поведение идентично `wcstol()`, но результат — `long long` (расширенный диапазон).

При переполнении возвращает `LLONG_MAX` или `LLONG_MIN` и устанавливает `errno` в `ERANGE`.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *str = L"  9223372036854775807";
    wchar_t *end;

    long long ll = wcstoll(str, &end, 10);
    printf("'%ls' → %lld\n", str, ll);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Расширенный диапазон по сравнению с `wcstol()` | Квадратичная сложность для длинных строк |
| Стандартная функция ISO C | Тип `long long` может быть избыточен |
| Поддерживает любое основание 2–36 | Требует `<wchar.h>` |
