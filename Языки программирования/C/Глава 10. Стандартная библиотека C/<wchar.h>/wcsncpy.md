## Определение

```c
#include <wchar.h>

wchar_t *wcsncpy(wchar_t *dest, const wchar_t *src, size_t n);
```

## Описание

Функция `wcsncpy()` копирует не более `n` широких символов из строки `src` в буфер `dest`. Если строка `src` короче `n` символов, оставшиеся позиции заполняются нуль-терминаторами. Если `src` длиннее `n` символов, результат не будет нуль-терминирован.

Возвращаемое значение — указатель на `dest`.

Функция является широкосимвольным аналогом `strncpy()` из `<string.h>`.

> [!WARNING]
> Если `src` длиннее или равна `n`, строка `dest` не будет нуль-терминирована. Это может привести к переполнению при последующих операциях со строкой. Рекомендуется всегда дописывать `dest[n - 1] = L'\0'` после вызова.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wchar_t dest[16];
    const wchar_t *src = L"Привет, мир!";

    wcsncpy(dest, src, 15);
    dest[15] = L'\0';  /* Гарантируем нуль-терминатор */
    printf("%ls\n", dest);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Ограничивает количество копируемых символов | Не добавляет нуль-терминатор при полном копировании |
| Стандартная функция ISO C | Заполняет остаток нулями (может быть избыточно) |
| Возвращает указатель на начало результата | Требует ручного добавления `L'\0'` |
