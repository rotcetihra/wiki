## Определение

```c
#include <wchar.h>

wchar_t *wcsncat(wchar_t *dest, const wchar_t *src, size_t n);
```

## Описание

Функция `wcsncat()` дописывает не более `n` символов из строки `src` в конец строки `dest`. Завершающий нуль-терминатор `dest` заменяется первым символом `src`, копируется не более `n` символов, и в конце дописывается завершающий нуль-терминатор.

Возвращаемое значение — указатель на `dest`.

Функция является широкосимвольным аналогом `strncat()` из `<string.h>`. Безопаснее `wcscat()`, так как ограничивает количество дописываемых символов.

> [!NOTE]
> Параметр `n` ограничивает количество **копируемых** символов, а не общий размер буфера. В `dest` должно быть достаточно места для текущей строки + `n` символов + нуль-терминатор.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wchar_t buffer[32] = L"Привет";
    wcsncat(buffer, L", мир! Добро пожаловать", 6);
    printf("%ls\n", buffer);  /* Привет, мир! */

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Ограничивает количество дописываемых символов | `n` не учитывает размер буфера `dest` |
| Стандартная функция ISO C | Сложнее в использовании, чем `wcscat()` |
| Возвращает указатель на начало результата | Всё ещё возможен выход за пределы буфера |
