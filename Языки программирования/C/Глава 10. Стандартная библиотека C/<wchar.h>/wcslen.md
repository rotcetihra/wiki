## Определение

```c
#include <wchar.h>

size_t wcslen(const wchar_t *str);
```

## Описание

Функция `wcslen()` возвращает количество широких символов в строке `str` (не считая завершающего нуль-терминатора).

Функция является широкосимвольным аналогом `strlen()` из `<string.h>`. Является одним из наиболее часто используемых средств определения длины широкой строки.

> [!NOTE]
> Многие функции `wchar.h` определяют своё поведение только для строк фиксированной длины (не содержащих нуль-терминаторов) с помощью параметра `n`. `wcslen()` подходит только для нуль-терминированных строк.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *str = L"Привет, мир!";
    printf("Длина строки: %zu\n", wcslen(str));  /* 12 */

    wchar_t empty[] = L"";
    printf("Пустая строка: %zu\n", wcslen(empty));  /* 0 */

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простейший способ определить длину строки | Линейная сложность (O(n)) |
| Стандартная функция ISO C | Только для нуль-терминированных строк |
| Оптимизирована в большинстве реализаций (SIMD) | Не определяет, есть ли нуль-терминатор (UB при его отсутствии) |
