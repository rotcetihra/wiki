## Определение

```c
#include <wchar.h>

wchar_t *wcsrchr(const wchar_t *str, wchar_t c);
```

## Описание

Функция `wcsrchr()` ищет **последнее** вхождение宽окого символа `c` в строке `str` (включая завершающий нуль-терминатор). Возвращает указатель на найденный символ или `NULL`, если символ не найден.

Функция является широкосимвольным аналогом `strrchr()` из `<string.h>`.

> [!NOTE]
> Если `c` равно `L'\0'`, функция возвращает указатель на завершающий нуль-терминатор строки.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *path = L"/home/user/file.txt";
    wchar_t *slash = wcsrchr(path, L'/');

    if (slash)
        printf("Имя файла: %ls\n", slash + 1);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрый поиск символа с конца строки | Линейная сложность |
| Стандартная функция ISO C | Не potokobezopasna |
| Удобна для извлечения компонентов пути | Возвращает указатель — не индекс |
