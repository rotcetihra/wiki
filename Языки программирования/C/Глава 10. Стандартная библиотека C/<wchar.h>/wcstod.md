## Определение

```c
#include <wchar.h>

double wcstod(const wchar_t *str, wchar_t **endptr);
```

## Описание

Функция `wcstod()` преобразует широкую строку `str` в значение типа `double`. Аналогична `strtod()` из `<stdlib.h>`.

Процесс преобразования:

1. Пропускаются начальные пробельные символы (определённые через `iswspace()`).
2. Опциональный знак `+` или `-`.
3. Число может быть:
   - Десятичным: `3.14`, `.5`, `1e10`, `1.5E-3`
   - Шестнадцатеричным: `0x1.8p+1` (с показателем `p`/`P`)
   - Бесконечностью: `INFINITY`, `HUGE_VAL`
   - Не числом: `NAN`, `nan(...)`, `nanw(...)`
4. Если `endptr != NULL`, в него записывается указатель на первый символ, не являющийся частью числа.

Возвращает преобразованное значение, `HUGE_VAL` при переполнении, `0` при ошибке.

> [!NOTE]
> Шестнадцатеричные литералы используют показатель `p` (а не `e`), так как показатель определяет степень двойки, а не десятки.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *str1 = L"  3.14159";
    const wchar_t *str2 = L"0x1.921fb54442d18p+1";
    const wchar_t *str3 = L"1.5E-10abc";

    wchar_t *end;

    double d1 = wcstod(str1, &end);
    printf("'%ls' → %f (осталось: '%ls')\n", str1, d1, end);

    double d2 = wcstod(str2, &end);
    printf("'%ls' → %f\n", str2, d2);

    double d3 = wcstod(str3, &end);
    printf("'%ls' → %e (осталось: '%ls')\n", str3, d3, end);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Поддерживает десятичные и шестнадцатеричные форматы | Квадратичная сложность для длинных строк (legates к `strtod`) |
| Указывает позицию остановки через `endptr` | Не устанавливает `errno` при обычных ошибках |
| Стандартная функция ISO C | Требует установки локали для корректной работы с пробелами |
