## Определение

```c
#include <wchar.h>

long wcstol(const wchar_t *str, wchar_t **endptr, int base);
```

## Описание

Функция `wcstol()` преобразует широкую строку `str` в значение типа `long`. Является широкосимвольным аналогом `strtol()` из `<stdlib.h>`.

Параметр `base` определяет основание системы счисления:

- `0` — определение автоматически (prefикс `0` → восьмеричный, `0x` → шестнадцатеричный, иначе десятичный);
- `2`–`36` — указанные основание;
- `16` — шестнадцатеричные числа также распознают префикс `0x`/`0X`.

Если `endptr != NULL`, в него записывается указатель на первый символ, не являющийся частью числа.

При переполнении возвращает `LONG_MAX` или `LONG_MIN` и устанавливает `errno` в `ERANGE`. При пустой строке возвращает `0`.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>
#include <errno.h>

int main(void)
{
    setlocale(LC_ALL, "");

    const wchar_t *dec = L"  42abc";
    const wchar_t *hex = L"0xFF";
    const wchar_t *auto_base = L"010";

    wchar_t *end;

    long d = wcstol(dec, &end, 10);
    printf("'%ls' → %ld (осталось: '%ls')\n", dec, d, end);

    long h = wcstol(hex, &end, 16);
    printf("'%ls' → %ld\n", hex, h);

    long a = wcstol(auto_base, &end, 0);
    printf("'%ls' → %ld (автоопределение основания)\n", auto_base, a);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Поддерживает любое основание от 2 до 36 | Ограничен диапазон `long` |
| Автоопределение основания при `base == 0` | Квадратичная сложность для длинных строк |
| Стандартная функция ISO C | Устанавливает `errno` только при переполнении |
