## Определение

```c
#include <wchar.h>

wint_t towctrans(wint_t wc, wctrans_t desc);
```

## Описание

Функция `towctrans()` преобразует широкий символ `wc` в соответствии с категорией преобразования, заданной дескриптором `desc`. Дескриптор получается вызовом `wctrans()`.

Параметры:

- `wc` — широкий символ для преобразования;
- `desc` — дескриптор категории преобразования (возвращённый `wctrans()`).

Возвращает преобразованный символ или `wc`, если преобразование не применимо.

> [!NOTE]
> Предопределённые категории: `towlower` (в нижний регистр) и `towupper` (в верхний регистр). Категории зависят от текущей локали.

## Примеры

```c
#include <stdio.h>
#include <wchar.h>
#include <locale.h>

int main(void)
{
    setlocale(LC_ALL, "");

    wctrans_t lower = wctrans("towlower");
    wctrans_t upper = wctrans("towupper");

    if (lower && upper) {
        printf("towctrans('A', lower) = '%lc'\n",
               towctrans(L'A', lower));
        printf("towctrans('a', upper) = '%lc'\n",
               towctrans(L'a', upper));
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет выбирать категорию преобразования через дескриптор | Требует предварительного вызова `wctrans()` |
| Стандартная функция ISO C | Только две предопределённые категории |
| Расширяема через локаль | Может вернуть `wc` без изменений |
