## Определение

```c
#include <time.h>

double difftime(time_t time1, time_t time2);
```

## Описание

Функция `difftime()` вычисляет разность двух значений `time_t` в секундах: `time1 - time2`. Возвращает результат как `double` для точного представления дробной части (хотя `time_t` обычно целое).

Функция нужна, потому что арифметическое вычитание `time_t` не гарантировано быть переносимым — стандарт не определяет единицу измерения `time_t`.

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    time_t start = time(NULL);

    /* Загрузка */
    volatile long long sum = 0;
    for (long long i = 0; i < 100000000LL; i++)
        sum += i;

    time_t end = time(NULL);
    double elapsed = difftime(end, start);

    printf("Результат: %lld\n", sum);
    printf("Прошло секунд: %.0f\n", elapsed);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция ISO C, портативна | Разрешение — 1 секунда |
| Гарантированно корректное вычитание | Для высокоточных измерений нужна `clock_gettime()` |
| Возвращает `double` (дробная часть при промежуточных вычислениях) | |
