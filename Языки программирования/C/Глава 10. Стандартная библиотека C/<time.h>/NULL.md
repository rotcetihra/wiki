## Определение

```c
#include <time.h>

#define NULL /* implementation-defined */
```

## Описание

Макрос `NULL` определяет нулевой указатель — значение, гарантированно не указывающее ни на какой объект. В `<time.h>` он наследуется из `<stddef.h>` и используется, например, возвращаемым значением функций `localtime()` и `gmtime()` при ошибке.

Полное определение `NULL` см. в статье [[Языки программирования/C/Глава 10. Стандартная библиотека C/<stddef.h>/NULL|NULL]] (раздел `<stddef.h>`).

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    time_t t = time(NULL);
    struct tm *tm = localtime(&t);

    if (tm == NULL) {
        printf("localtime вернул NULL\n");
        return 1;
    }

    printf("Дата: %02d.%02d.%04d\n",
           tm->tm_mday, tm->tm_mon + 1, tm->tm_year + 1900);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Универсальная константа для проверки указателей | Не различает «ошибка» и «нулевой объект» |
| Стандартна во всех заголовках C | Значение зависит от реализации |
