## Определение

```c
#include <time.h>

int timespec_get(struct timespec *ts, int base);
```

## Описание

Функция `timespec_get()` получает текущее время с наносекундной точностью и записывает его в структуру `struct timespec`. Параметр `base` указывает временной пояс — стандарт определяет только `TIME_UTC` (значение `1`).

Поля `ts->tv_sec` содержат секунды (тип `time_t`), `ts->tv_nsec` — наносекунды (от 0 до 999 999 999).

Возвращает ненулевое значение при успехе и 0 при ошибке. Появилась в стандарте C11.

> [!NOTE]
> Для POSIX-альтернативы с поддержкой нескольких типов часов (монотонные, процессорные) используйте `clock_gettime()`.

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    struct timespec ts;

    if (timespec_get(&ts, TIME_UTC) != 0) {
        printf("Эпоха: %ld.%09ld\n", (long)ts.tv_sec, ts.tv_nsec);
    }

    /* Высокоточное измерение интервала */
    struct timespec start, end;
    timespec_get(&start, TIME_UTC);

    volatile long long sum = 0;
    for (long long i = 0; i < 100000000LL; i++)
        sum += i;

    timespec_get(&end, TIME_UTC);

    double elapsed = (double)(end.tv_sec - start.tv_sec) +
                     (double)(end.tv_nsec - start.tv_nsec) / 1e9;
    printf("Интервал: %.6f сек\n", elapsed);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Наносекундная точность | Только стандарт C11, не на всех платформах |
| Стандартная функция ISO C (в отличие от POSIX) | Поддерживает только `TIME_UTC` |
| Потокобезопасна | Не измеряет монотонное время или процессорное время |
