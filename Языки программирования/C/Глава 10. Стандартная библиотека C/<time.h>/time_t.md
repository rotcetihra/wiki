## Определение

```c
#include <time.h>

typedef /* integer or real type */ time_t;
```

## Описание

Тип `time_t` предназначен для представления календарного времени — количества секунд, прошедших с так называемой эпохи (обычно это 00:00:00 1 января 1970 года, UTC, «Unix-эпоха»). Конкретный тип определяется реализацией — обычно это `long` или `long long`.

Функция `time()` возвращает текущее календарное время как `time_t`. Функция `difftime()` вычисляет разность двух значений `time_t` в секундах. Функция `mktime()` преобразует `struct tm` в `time_t`.

Для разбиения `time_t` на компоненты используются `localtime()` (локальное время) и `gmtime()` (UTC).

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    time_t now = time(NULL);
    printf("Текущее время (секунды с эпохи): %ld\n", (long)now);

    time_t future = now + 86400;
    struct tm *tm_future = localtime(&future);
    printf("Завтра: %02d.%02d.%04d\n",
           tm_future->tm_mday, tm_future->tm_mon + 1, tm_future->tm_year + 1900);

    double diff = difftime(future, now);
    printf("Разность: %.0f секунд\n", diff);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Компактное представление времени (одно число) | Не хранит информацию о часовом поясе |
| Простое сравнение и арифметика | Разрешение — 1 секунда (нет наносекунд) |
| Стандартный тип ISO C | Значение 2038 года ограничено 32-битными реализациями |
