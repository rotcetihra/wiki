## Определение

```c
#include <time.h>

#define TIME_UTC 1
```

## Описание

Макрос `TIME_UTC` определён в стандарте C11 и используется как аргумент функции `timespec_get()` для указания, что время должно быть получено в формате UTC (协调世界时间). В C23 стандарт определяет только один временной пояс для `timespec_get()` — UTC.

Если `timespec_get()` поддерживает дополнительные временные пояса, они определяются реализацией через макросы `TIME_MONOTONIC`, `TIME_ACTIVE` и т. п.

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    struct timespec ts;

    if (timespec_get(&ts, TIME_UTC) != 0) {
        printf("UTC: %ld.%09ld\n", (long)ts.tv_sec, ts.tv_nsec);
    } else {
        printf("timespec_get не поддерживается\n");
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная константа ISO C11 | В C23 только UTC не поддерживается другими значениями |
| Гарантирует согласованность часовых поясов | Не предоставляет информации о локальном времени |
