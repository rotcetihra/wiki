## Определение

```c
#define _XOPEN_SOURCE 500
#include <time.h>

struct tm *getdate(const char *string);
```

## Описание

Функция `getdate()` разбирает строку с датой в соответствии с шаблонами, заданными в файле формата даты `$DATEMSK`. Файл содержит строки формата (такие же, как для `strftime()`) — по одной на строку. Функция перебирает шаблоны, пока один из них не распознает строку целиком.

При успешном разборе возвращает указатель на статическую `struct tm`. При ошибке возвращает `NULL` и устанавливает код ошибки в переменную `getdate_err`.

> [!WARNING]
> Функция не потокобезопасна (использует статическую память и глобальную переменную `getdate_err`). Рекомендуется использовать `strptime()` для переносимого кода.

## Примеры

```c
#define _XOPEN_SOURCE 500
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void)
{
    /* Установка формата: создать файл dateformat.txt со строкой %Y-%m-%d */
    setenv("DATEMSK", "dateformat.txt", 1);

    struct tm *result = getdate("2026-08-20");
    if (result != NULL) {
        printf("Дата: %02d.%02d.%04d\n",
               result->tm_mday, result->tm_mon + 1, result->tm_year + 1900);
    } else {
        printf("Ошибка (код: %d)\n", getdate_err);
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гибкий разбор по шаблонам из файла | Не потокобезопасна (глобальная переменная `getdate_err`) |
| Поддерживает локализованные форматы | Зависит от переменной окружения `$DATEMSK` |
| Стандартная POSIX-функция | Устаревшая — рекомендуется `strptime()` |
