## Определение

```c
#include <time.h>

struct timespec {
    time_t tv_sec;   /* секунды */
    long   tv_nsec;  /* наносекунды — от 0 до 999999999 */
};
```

## Описание

Структура `struct timespec` определена в стандарте C11 и представляет время с наносекундной точностью. Состоит из двух полей: `tv_sec` (секунды типа `time_t`) и `tv_nsec` (наносекунды, значение от 0 до 999 999 999).

Используется функциями `timespec_get()` (стандартная) и `clock_gettime()` (POSIX), а также в POSIX-функциях синхронизации (`pthread_mutex_timedlock`, `pthread_cond_timedwait`, `nanosleep`).

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    struct timespec ts;
    timespec_get(&ts, TIME_UTC);

    printf("Эпоха: %ld.%09ld\n", (long)ts.tv_sec, ts.tv_nsec);

    /* Вычисление времени выполнения операции */
    struct timespec start, end;
    timespec_get(&start, TIME_UTC);

    long long sum = 0;
    for (long long i = 0; i < 100000000LL; i++)
        sum += i;

    timespec_get(&end, TIME_UTC);

    double elapsed = (double)(end.tv_sec - start.tv_sec) +
                     (double)(end.tv_nsec - start.tv_nsec) / 1e9;
    printf("Сумма: %lld, время: %.6f сек\n", sum, elapsed);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Наносекундная точность | Появился только в C11 (не во всех реализациях) |
| Стандартный тип ISO C (в отличие от POSIX-специфичных часов) | Не все платформы поддерживают реальное разрешение в наносекундах |
| Удобен для вычисления длительности интервалов | Не содержит информации о часовом поясе |
