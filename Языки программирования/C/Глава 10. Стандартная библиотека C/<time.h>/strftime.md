## Определение

```c
#include <time.h>

size_t strftime(char *s, size_t maxsize, const char *format, const struct tm *timeptr);
```

## Описание

Функция `strftime()` форматирует содержимое `struct tm` в строку в соответствии с шаблоном `format`. Результат записывается в буфер `s` размером не более `maxsize` символов (включая нуль-терминатор).

Основные спецификаторы формата:

| Спецификатор | Описание | Пример |
|---|---|---|
| `%Y` | Год с веком | `2026` |
| `%m` | Месяц (01–12) | `08` |
| `%d` | День месяца (01–31) | `20` |
| `%H` | Час (00–23) | `14` |
| `%M` | Минуты (00–59) | `30` |
| `%S` | Секунды (00–60) | `00` |
| `%A` | Полное название дня недели | `Thursday` |
| `%a` | Сокращённое название дня | `Thu` |
| `%B` | Полное название месяца | `August` |
| `%b` | Сокращённое название месяца | `Aug` |
| `%c` | Дата и время в локальном формате | `Thu Aug 20 14:30:00 2026` |
| `%x` | Дата в локальном формате | `08/20/2026` |
| `%X` | Время в локальном формате | `14:30:00` |
| `%%` | Символ процента | `%` |

Возвращает количество записанных символов (без нуль-терминатора) или 0 при ошибке (размер слишком мал).

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    time_t now = time(NULL);
    struct tm *tm = localtime(&now);

    char buf[100];

    strftime(buf, sizeof(buf), "%d.%m.%Y %H:%M:%S", tm);
    printf("Дата и время: %s\n", buf);

    strftime(buf, sizeof(buf), "%A, %d %B %Y", tm);
    printf("Дата: %s\n", buf);

    strftime(buf, sizeof(buf), "%Y-%m-%dT%H:%M:%S%z", tm);
    printf("ISO 8601: %s\n", buf);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гибкий формат через шаблон | Зависит от локали (русские названия месяцев и т. д.) |
| Безопасна (ограничение размера буфера) | Не все платформы поддерживают все спецификаторы |
| Стандартная функция ISO C | |
