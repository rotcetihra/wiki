## Определение

```c
#include <time.h>

clock_t clock(void);
```

## Описание

Функция `clock()` возвращает приближённое время процессора, использованное программой с момента запуска. Значение выражается в тиках и делится на `CLOCKS_PER_SEC` для получения секунд.

Если время процессора недоступно, возвращается `(clock_t)(-1)`. Функция измеряет только процессорное время — время, в течение которого программа выполнялась на процессоре; время ожидания ввода-вывода не учитывается.

## Примеры

```c
#include <stdio.h>
#include <time.h>

int main(void)
{
    clock_t start = clock();

    /* Нагрузка */
    volatile double x = 0;
    for (int i = 0; i < 100000000; i++)
        x += 1.0 / (i + 1);

    clock_t end = clock();
    double cpu_sec = (double)(end - start) / CLOCKS_PER_SEC;

    printf("Результат: %.10f\n", x);
    printf("Время процессора: %.6f сек\n", cpu_sec);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция ISO C, портативна | Измеряет только процессорное время (не реальное) |
| Не требует подключения библиотек | Разрешение зависит от платформы (мс или мкс) |
| Удобна для бенчмарков CPU-bound кода | Не пригодна для измерения I/O-bound операций |
