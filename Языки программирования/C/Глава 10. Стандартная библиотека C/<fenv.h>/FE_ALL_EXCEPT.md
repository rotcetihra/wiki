## Определение

```c
#include <fenv.h>

#define FE_ALL_EXCEPT /* битовая маска */
```

## Описание

Константа `FE_ALL_EXCEPT` представляет битовую маску, объединяющую все поддерживаемые реализацией исключения с плавающей точкой. Обычно это побитовое ИЛИ констант `FE_DIVBYZERO | FE_INEXACT | FE_INVALID | FE_OVERFLOW | FE_UNDERFLOW`.

Используется как удобный способ обратиться ко всем исключениям одновременно — например, для их сброса (`feclearexcept(FE_ALL_EXCEPT)`) или проверки (`fetestexcept(FE_ALL_EXCEPT)`).

> [!NOTE]
> Реализация может поддерживать дополнительные (нестандартные) исключения. Константа `FE_ALL_EXCEPT` включает только те, которые определены в данной реализации.

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    feclearexcept(FE_ALL_EXCEPT);

    volatile double a = 0.0;
    volatile double b = 0.0;
    volatile double c = a / b;

    volatile double d = 1.0;
    volatile double e = 0.0;
    volatile double f = d / e;

    int active = fetestexcept(FE_ALL_EXCEPT);
    printf("Активные исключения: 0x%x\n", active);

    if (active & FE_INVALID)
        printf("  - FE_INVALID\n");
    if (active & FE_DIVBYZERO)
        printf("  - FE_DIVBYZERO\n");

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Удобный способ обратиться ко всем исключениям | Не включает нестандартные исключения, не определённые реализацией |
| Универсален для сброса, проверки и восстановления | Точное значение зависит от поддерживаемых исключений |
| Стандартная часть набора констант `<fenv.h>` | Нельзя использовать для установки (только для чтения/сброса) |
