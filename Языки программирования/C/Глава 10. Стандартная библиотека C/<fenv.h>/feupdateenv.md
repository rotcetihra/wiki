## Определение

```c
#include <fenv.h>

int feupdateenv(const fenv_t *envp);
```

## Описание

Функция `feupdateenv` восстанавливает среду из объекта `envp` и одновременно повторно генерирует все флаги исключений, которые были активны до вызова. Это позволяет восстановить среду (например, направление округления) и гарантировать, что сохранённые исключения не будут потеряны.

Поведение функции эквивалентно следующей последовательности:

1. Запомнить текущие активные флаги исключений.
2. Восстановить среду из `envp` через `fesetenv`.
3. Сгенерировать запомненные флаги через `feraiseexcept`.

Функция возвращает `0` при успешном выполнении и ненулевое значение при ошибке.

> [!NOTE]
> Эта функция наиболее удобна в связке с `feholdexcept`: сначала `feholdexcept` сохраняет среду и сбрасывает исключения, затем после выполнения кода `feupdateenv` восстанавливает среду и «поднимает» исключения, возникшие во время выполнения.

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    fenv_t saved;

    fegetenv(&saved);

    fesetround(FE_TOWARDZERO);
    volatile double a = 0.0;
    volatile double b = 0.0;
    volatile double c = a / b;

    printf("Исключения в FE_TOWARDZERO: 0x%x\n", fetestexcept(FE_ALL_EXCEPT));

    feupdateenv(&saved);
    printf("Среда восстановлена, исключения сохранены: 0x%x\n",
           fetestexcept(FE_ALL_EXCEPT));
    printf("Направление округления: %d\n", fegetround());

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `envp` | Указатель на ранее сохранённую среду (`fenv_t`) или `FE_DFL_ENV` |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Среда успешно восстановлена, исключения повторно сгенерированы |
| Ненулевое | Ошибка восстановления |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Сохраняет исключения при восстановлении среды | Повторная генерация может быть неожиданной |
| Идеальна в связке с `feholdexcept` | Сложнее в использовании, чем `fesetenv` |
| Атомарность операции | — |
