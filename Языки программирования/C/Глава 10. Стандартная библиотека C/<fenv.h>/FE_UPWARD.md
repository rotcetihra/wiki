## Определение

```c
#include <fenv.h>

#define FE_UPWARD /* целочисленная константа */
```

## Описание

Константа `FE_UPWARD` задаёт направление округления к плюс бесконечности («вверх»). При таком округлении любой результат, не являющийся целым числом, округляется к ближайшему большему целому.

Например:

- `3.2` → `4.0`
- `-3.2` → `-3.0` (не `-4.0`!)
- `3.0` → `3.0` (уже целое)

Это направление округления полезно для интервальных вычислений, где необходимо гарантировать, что результат не меньше точного значения.

Для установки направления округления используется функция `fesetround(FE_UPWARD)`.

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    fesetround(FE_UPWARD);
    printf("Направление: FE_UPWARD\n");

    double a = 1.0;
    double b = 3.0;
    printf("1.0 / 3.0 = %.20f\n", a / b);
    printf("(ожидается 0.334... с округлением вверх)\n");

    volatile double x = -2.7;
    printf("Округление -2.7 = %.1f\n", x);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует, что результат ≥ точного значения | Систематическая погрешность в сторону увеличения |
| Полезно для интервальных вычислений | Не является стандартным поведением IEEE 754 |
| Стандартная константа C99/C23 | Изменение направления влияет на все последующие операции |
