## Определение

```c
#include <fenv.h>

int fegetenv(fenv_t *envp);
```

## Описание

Функция `fegetenv` сохраняет текущую среду вычислений с плавающей точкой (направление округления и флаги исключений) в объект `envp` типа `fenv_t`.

Сохранённая среда может быть позднее восстановлена через `fesetenv`. Это стандартный способ реализации паттерна «сохранил — изменил — восстановил».

Функция возвращает `0` при успешном выполнении и ненулевое значение при ошибке.

> [!NOTE]
> Если необходим временный сброс исключений (без сохранения флагов), используйте `feholdexcept` — она сохраняет среду и одновременно сбрасывает флаги исключений.

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    fenv_t saved;

    fegetenv(&saved);

    fesetround(FE_TOWARDZERO);
    printf("Направление: FE_TOWARDZERO\n");

    double a = 1.0;
    double b = 3.0;
    printf("1.0/3.0 = %.20f\n", a / b);

    fesetenv(&saved);
    printf("Среда восстановлена\n");

    printf("1.0/3.0 = %.20f\n", a / b);

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `envp` | Указатель на объект `fenv_t` для сохранения среды |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Среда успешно сохранена |
| Ненулевое | Ошибка сохранения |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Сохраняет полную среду (округление + исключения) | Требует выделения объекта `fenv_t` |
| Позволяет безопасно изменять и восстанавливать среду | Не сбрасывает флаги — сохраняет текущее состояние |
| Стандартная функция ISO C99/C23 | — |
