## Определение

```c
#include <fenv.h>

int fesetenv(const fenv_t *envp);
```

## Описание

Функция `fesetenv` устанавливает текущую среду вычислений с плавающей точкой на основе ранее сохранённого значения `envp` (полученного через `fegetenv` или `feholdexcept`).

Если `envp` равен `FE_DFL_ENV`, устанавливается среда по умолчанию.

Функция не генерирует новых исключений — она лишь восстанавливает сохранённое состояние среды (направление округления и флаги исключений).

Функция возвращает `0` при успешном выполнении и ненулевое значение при ошибке.

> [!NOTE]
> Для восстановления среды с повторной генерацией сохранённых исключений используйте `feupdateenv`.

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    fenv_t saved;

    fegetenv(&saved);

    fesetround(FE_TOWARDZERO);
    feraiseexcept(FE_INVALID);
    printf("До fesetenv: round=%d, except=0x%x\n",
           fegetround(), fetestexcept(FE_ALL_EXCEPT));

    fesetenv(FE_DFL_ENV);
    printf("После FE_DFL_ENV: round=%d, except=0x%x\n",
           fegetround(), fetestexcept(FE_ALL_EXCEPT));

    fesetenv(&saved);
    printf("После восстановления: round=%d, except=0x%x\n",
           fegetround(), fetestexcept(FE_ALL_EXCEPT));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `envp` | Указатель на ранее сохранённую среду (`fenv_t`) или `FE_DFL_ENV` |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Среда успешно установлена |
| Ненулевое | Ошибка установки |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Восстанавливает полную среду за один вызов | Не генерирует исключения — только восстанавливает флаги |
| Поддерживает `FE_DFL_ENV` для сброса в начальное состояние | Не подходит, если нужно повторно сгенерировать исключения |
| Стандартная функция ISO C99/C23 | — |
