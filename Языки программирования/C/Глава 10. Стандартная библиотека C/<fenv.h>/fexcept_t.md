## Определение

```c
#include <fenv.h>

typedef /* unspecified object type */ fexcept_t;
```

## Описание

Тип `fexcept_t` представляет собой непроизвольный объект, хранящий состояние флагов исключений с плавающей точкой. Флаги представляют собой битовую маску, в которой каждый бит соответствует определённому типу исключения (`FE_DIVBYZERO`, `FE_INEXACT`, `FE_INVALID`, `FE_OVERFLOW`, `FE_UNDERFLOW`).

Значение `fexcept_t` получается через `fegetexceptflag` и устанавливается через `fesetexceptflag`. Это позволяет сохранить и восстановить конкретные флаги исключений без затрагивания остальных компонентов среды (направления округления и т. д.).

В отличие от `fenv_t`, тип `fexcept_t` не гарантирует сохранение направления округления — только флаги исключений.

## Пример

```c
#include <stdio.h>
#include <fenv.h>
#include <math.h>

int main(void)
{
    fexcept_t except_flags;

    feclearexcept(FE_ALL_EXCEPT);

    volatile double a = 0.0;
    volatile double b = 0.0;
    double result = a / b;

    printf("Результат: %f\n", result);

    fegetexceptflag(&except_flags, FE_ALL_EXCEPT);

    printf("Активные исключения: %d\n", fetestexcept(FE_ALL_EXCEPT));

    feclearexcept(FE_ALL_EXCEPT);
    printf("После сброса: %d\n", fetestexcept(FE_ALL_EXCEPT));

    fesetexceptflag(&except_flags, FE_INVALID);
    printf("После восстановления: %d\n", fetestexcept(FE_ALL_EXCEPT));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет сохранять и восстанавливать отдельные флаги исключений | Не хранит направление округления — только флаги |
| Не требует сохранения всей среды (`fenv_t`) | Реализация неизвестна — нельзя инициализировать вручную |
| Совместим с `fegetexceptflag`/`fesetexceptflag` | Значение не определено до вызова `fegetexceptflag` |
