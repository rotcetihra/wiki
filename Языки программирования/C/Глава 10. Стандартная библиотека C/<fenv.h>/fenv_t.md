## Определение

```c
#include <fenv.h>

typedef /* unspecified object type */ fenv_t;
```

## Описание

Тип `fenv_t` представляет собой непроизвольный объект, хранящий полную среду вычислений с плавающей точкой: текущее направление округления и состояние флагов исключений. Значение типа `fenv_t` получается с помощью функций `fegetenv` и `feholdexcept` и устанавливается через `fesetenv` и `feupdateenv`.

Конкретное внутреннее представление типа `fenv_t` определяется реализацией и не должно использоваться напрямую. Для работы со средой предназначены специализированные функции библиотеки `<fenv.h>`.

Единственное значение `fenv_t`, доступное без предварительного сохранения, — это `FE_DFL_ENV` (среда по умолчанию).

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    fenv_t saved_env;

    if (fegetenv(&saved_env) != 0) {
        fprintf(stderr, "Не удалось сохранить среду\n");
        return 1;
    }

    fesetround(FE_TOWARDZERO);
    printf("Направление округления установлено: FE_TOWARDZERO\n");

    double a = 1.0;
    double b = 3.0;
    printf("1.0 / 3.0 = %.20f\n", a / b);

    if (fesetenv(&saved_env) != 0) {
        fprintf(stderr, "Не удалось восстановить среду\n");
        return 1;
    }

    printf("Среда восстановлена по умолчанию\n");
    printf("1.0 / 3.0 = %.20f\n", a / b);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Сохранение и восстановление полной среды за один вызов | Реализация `fenv_t` неизвестна — нельзя копировать вручную |
| Позволяет временно изменить направление округления | Изменение среды может повлиять на результаты параллельных вычислений |
| Стандартная альтернатива платформо-зависимым средствам | Функции управления средой могут быть реализованы как макросы |
