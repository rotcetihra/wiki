## Определение

```c
#include <fenv.h>

int feholdexcept(fenv_t *envp);
```

## Описание

Функция `feholdexcept` сохраняет текущую среду вычислений в объект `envp` типа `fenv_t`, затем устанавливает среду по умолчанию (округление — `FE_TONEAREST`, флаги исключений сброшены).

Это комбинация `fegetenv` + `feclearexcept(FE_ALL_EXCEPT)` + `fesetenv(FE_DFL_ENV)` в одной атомарной операции. Функция возвращает предыдущее значение флагов исключений (как `int`), что позволяет определить, были ли активны исключения до сброса.

Функция полезна для временного выполнения кода, который может генерировать исключения, с последующим восстановлением исходной среды и проверкой того, что произошло.

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    fenv_t saved;
    int prev_exceptions;

    feraiseexcept(FE_INVALID | FE_DIVBYZERO);
    printf("До feholdexcept: 0x%x\n", fetestexcept(FE_ALL_EXCEPT));

    prev_exceptions = feholdexcept(&saved);
    printf("Предыдущие исключения: 0x%x\n", prev_exceptions);
    printf("После feholdexcept: 0x%x\n", fetestexcept(FE_ALL_EXCEPT));
    printf("Направление округления: %d (ожидается FE_TONEAREST)\n", fegetround());

    volatile double a = 0.0;
    volatile double b = 0.0;
    volatile double c = a / b;

    printf("Новые исключения: 0x%x\n", fetestexcept(FE_ALL_EXCEPT));

    fesetenv(&saved);
    printf("Среда восстановлена\n");

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `envp` | Указатель на объект `fenv_t` для сохранения среды |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Предыдущее значение флагов исключений | Побитовая маска активных исключений до сброса |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Сохраняет среду и сбрасывает исключения за один вызов | Возвращает флаги, а не код ошибки — нестандартный паттерн |
| Идеально подходит для изоляции кода | Сбрасывает среду по умолчанию — не произвольную |
| Атомарность операции | — |
