## Определение

```c
#include <fenv.h>

#define FE_DFL_ENV (&__fenv_default) /* const fenv_t * */
```

## Описание

Константа `FE_DFL_ENV` представляет собой указатель на объект типа `const fenv_t`, содержащий среду по умолчанию, установленную при запуске программы. Это единственное значение `fenv_t`, доступное без предварительного сохранения через `fegetenv`.

Передача `FE_DFL_ENV` в `fesetenv` восстанавливает начальную среду вычислений: направление округления — `FE_TONEAREST`, все флаги исключений сброшены, обработчики исключений отключены.

> [!NOTE]
> `FE_DFL_ENV` является уникальным объектом — его нельзя модифицировать. Для сохранения и изменения среды следует использовать `fegetenv`/`feholdexcept` и `fesetenv`/`feupdateenv`.

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    printf("Текущее направление: %d\n", fegetround());

    fesetround(FE_TOWARDZERO);
    printf("После FE_TOWARDZERO: %d\n", fegetround());

    fesetenv(FE_DFL_ENV);
    printf("После FE_DFL_ENV: %d\n", fegetround());

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Единственный способ получить среду по умолчанию без сохранения | Уникальный объект — нельзя создать собственный `FE_DFL_ENV` |
| Не требует предварительного вызова `fegetenv` | Восстанавливает только начальную среду, не произвольную |
| Гарантированно доступен в любой программе | Поведение «по умолчанию» зависит от реализации |
