## Определение

```c
#include <fenv.h>

int fegetexceptflag(fexcept_t *flagp, int excepts);
```

## Описание

Функция `fegetexceptflag` сохраняет текущее состояние указанных флагов исключений в объект `flagp` типа `fexcept_t`. Параметр `excepts` — побитовая маска интересующих исключений.

Сохранённые флаги можно позднее восстановить через `fesetexceptflag`. Это полезно для временного сброса исключений с последующим восстановлением — например, перед вызовом функции, которая может генерировать ложные исключения.

Функция возвращает `0` при успешном выполнении и ненулевое значение при ошибке.

## Пример

```c
#include <stdio.h>
#include <fenv.h>

int main(void)
{
    fexcept_t saved_flags;

    volatile double a = 0.0;
    volatile double b = 0.0;
    volatile double c = a / b;

    fegetexceptflag(&saved_flags, FE_ALL_EXCEPT);
    printf("Сохранены флаги: 0x%x\n", fetestexcept(FE_ALL_EXCEPT));

    feclearexcept(FE_ALL_EXCEPT);
    printf("После сброса: 0x%x\n", fetestexcept(FE_ALL_EXCEPT));

    fesetexceptflag(&saved_flags, FE_ALL_EXCEPT);
    printf("После восстановления: 0x%x\n", fetestexcept(FE_ALL_EXCEPT));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `flagp` | Указатель на объект `fexcept_t` для сохранения состояния флагов |
| `excepts` | Побитовая маска проверяемых исключений |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `0` | Флаги успешно сохранены |
| Ненулевое | Ошибка сохранения |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Сохраняет только указанные флаги — гибкость | Не сохраняет направление округления |
| Позволяет реализовать паттерн «сохранил-сбросил-восстановил` | Реализация `fexcept_t` неизвестна |
| Совместима с `fesetexceptflag` | — |
