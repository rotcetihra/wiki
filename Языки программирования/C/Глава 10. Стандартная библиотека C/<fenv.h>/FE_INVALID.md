## Определение

```c
#include <fenv.h>

#define FE_INVALID /* битовая маска */
```

## Описание

Константа `FE_INVALID` представляет битовую маску исключения недопустимой операции. Исключение возникает при вычислении выражений, результат которых математически не определён или не может быть корректно представлен в формате с плавающей точкой.

Типичные операции, вызывающие `FE_INVALID`:

- `0.0 / 0.0` — неопределённая форма
- `sqrt(-1.0)` — корень из отрицательного числа
- `log(-1.0)` — логарифм отрицательного числа
- `acos(2.0)` — аргумент вне области определения
- Операции с NaN (не числом)
- Сложение бесконечности с противоположной бесконечностью

В IEEE 754 результатом таких операций обычно является NaN (не число), но при включённом обработчике исключений генерируется сигнал.

## Пример

```c
#include <stdio.h>
#include <math.h>
#include <fenv.h>

int main(void)
{
    feclearexcept(FE_ALL_EXCEPT);

    volatile double a = 0.0;
    volatile double b = 0.0;
    double result = a / b;

    if (fetestexcept(FE_INVALID)) {
        printf("Обнаружено исключение недопустимой операции (0.0/0.0)\n");
    }

    feclearexcept(FE_ALL_EXCEPT);

    result = sqrt(-1.0);

    if (fetestexcept(FE_INVALID)) {
        printf("Обнаружено исключение недопустимой операции (sqrt(-1.0))\n");
    }

    printf("Результат: %f\n", result);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет обнаружить математически неопределённые операции | По умолчанию игнорируется |
| Охватывает широкий класс ошибок | Может срабатывать ложно при неаккуратном использовании NaN |
| Стандартный способ валидации вычислений | Точный набор операций зависит от реализации |
