## Определение

```c
#include <stddef.h> // C23

typedef typeof(nullptr) nullptr_t;
```

## Описание

Тип (C23) константы `nullptr` — типизированного нулевого указателя. Значение `nullptr` неявно преобразуется в любой тип указателя и `bool`, но не в целочисленные типы — это отличает его от `NULL` и литерала `0` и делает код безопаснее. Неопределённое поведение при попытке присвоить `nullptr_t` обычному целому. В обобщённых макросах (`_Generic`) позволяет различить нулевой указатель и целый ноль.

## Примеры

```c
#include <stddef.h>
#include <stdio.h>

void print_int(int *p)
{
    if (p == nullptr) {
        printf("нет данных\n");
    } else {
        printf("%d\n", *p);
    }
}

int main(void)
{
    print_int(nullptr); // нет данных

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Собственный тип — отличается от целого `0` | Требуется C23 |
| Неявное преобразование в любой указатель | Перегрузки нет: в C используется редко |

## Альтернативы

- **`NULL`** — классическая константа нулевого указателя (без собственного типа)
