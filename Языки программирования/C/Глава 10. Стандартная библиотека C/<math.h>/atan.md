## Определение

```c
#include <math.h>

double atan(double x);
float atanf(float x);         // C99
long double atanl(long double x); // C99
```

## Описание

Функция вычисляет арктангенс (обратный тангенс) аргумента x. Defined for все действительные числа x. Результат находится в диапазоне (-π/2, π/2).

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("atan(0) = %f\n", atan(0.0)); // 0.0
    printf("atan(1) = %f\n", atan(1.0)); // π/4 ≈ 0.7854
    printf("atan(-1) = %f\n", atan(-1.0)); // -π/4 ≈ -0.7854
    
    // Проверка свойства tan(atan(x)) = x для всех x
    double x = 0.5;
    printf("tan(atan(%f)) = %f\n", x, tan(atan(x)));
    
    return 0;
}
```
