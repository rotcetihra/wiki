## Определение

```c
#define M_PI_2 1.57079632679489661923
```

## Описание

Макрос — половина числа π, то есть π/2. Приблизительно равно 1.570796. Соответствует 90° в радианах. Используется в тригонометрических вычислениях и преобразованиях углов.

Это расширение POSIX/GNU, а не часть стандарта ISO C. Макрос доступен при компиляции с определением `_GNU_SOURCE` или в среде POSIX. Для переносимых вычислений можно использовать `acos(0.0)` или `M_PI / 2.0`.

## Примеры

```c
#define _GNU_SOURCE
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("M_PI_2 = %.20f\n", M_PI_2);
    printf("acos(0) = %.20f\n", acos(0.0));

    // Преобразование 90° в радианы
    double degrees = 90.0;
    double radians = degrees * M_PI_2 / 90.0;
    printf("%.0f° = %.10f радиан\n", degrees, radians);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Удобная константа для углов 90° | Расширение POSIX/GNU, не ISO C |
| Высокая точность в определении | Доступна не во всех реализациях |
