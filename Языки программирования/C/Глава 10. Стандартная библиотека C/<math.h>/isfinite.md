## Определение

```c
#include <math.h>

#define isfinite(x) /* implementation-defined */
```

## Описание

Макрос проверяет, является ли аргумент конечным числом. Возвращает ненулевое значение, если аргумент конечен (не является бесконечностью и не является нечисловым значением).

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("isfinite(1.0) = %d\n", isfinite(1.0));     // 1 (истина)
    printf("isfinite(0.0) = %d\n", isfinite(0.0));     // 1 (истина)
    printf("isfinite(INFINITY) = %d\n", isfinite(INFINITY)); // 0 (ложь)
    printf("isfinite(NAN) = %d\n", isfinite(NAN));     // 0 (ложь)
    printf("isfinite(-123.456) = %d\n", isfinite(-123.456)); // 1 (истина)
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая проверка конечности | Не различает нормализованные и денормализованные числа |
| Работает со всеми типами с плавающей точкой |  |
