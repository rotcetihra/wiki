## Определение

```c
#include <math.h>

long long llround(double x);
long long llroundf(float x);         // C99
long long llroundl(long double x); // C99
```

## Описание

Функция округляет аргумент x до ближайшего целого числа типа long long. Если значение находится ровно посередине между двумя целыми, округление происходит в сторону положительной бесконечности (away from zero).

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("llround(2.3) = %lld\n", llround(2.3)); // 2
    printf("llround(2.5) = %lld\n", llround(2.5)); // 3
    printf("llround(2.7) = %lld\n", llround(2.7)); // 3
    printf("llround(-2.5) = %lld\n", llround(-2.5)); // -3
    printf("llround(-2.3) = %lld\n", llround(-2.3)); // -2
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Округление до большого целого диапазона | Результат всегда целое (теряется дробная часть) |
| Поддерживает все типы с плавающей точкой |  |
