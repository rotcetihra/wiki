## Определение

```c
#include <math.h>

double sinh(double x);
float sinhf(float x);         // C99
long double sinhl(long double x); // C99
```

## Описание

Функция вычисляет гиперболический синус: sinh(x) = (e^x - e^(-x))/2. Это нечетная функция, которая быстро растет при больших положительных x и быстро убывает при больших отрицательных x.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("sinh(0) = %f\n", sinh(0.0)); // 0.0
    printf("sinh(1) = %f\n", sinh(1.0)); // ~1.1752
    printf("sinh(-1) = %f\n", sinh(-1.0)); // -1.1752
    
    // Проверка свойства sinh(-x) = -sinh(x)
    double x = 2.0;
    printf("sinh(-%f) = %f\n", x, sinh(-x));
    printf("-sinh(%f) = %f\n", x, -sinh(x));
    
    return 0;
}
```
