## Определение

```c
#define M_LOG2E 1.44269504088896340736
```

## Описание

Макрос — логарифм числа _e_ по основанию 2, то есть log₂(e). Приблизительно равно 1.44269. Используется для преобразования натурального логарифма в логарифм по основанию 2: log₂(x) = M_LOG2E · log(x).

Это расширение POSIX/GNU, а не часть стандарта ISO C. Макрос доступен при компиляции с определением `_GNU_SOURCE` или в среде POSIX. Для переносимых вычислений можно использовать `log2(exp(1.0))`.

## Примеры

```c
#define _GNU_SOURCE
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("M_LOG2E = %.20f\n", M_LOG2E);
    printf("log2(exp(1)) = %.20f\n", log2(exp(1.0)));

    // Преобразование натурального логарифма в log2
    double x = 100.0;
    double log2_x = M_LOG2E * log(x);
    printf("log2(%.0f) = %.10f\n", x, log2_x);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая константа для conversions логарифмов | Расширение POSIX/GNU, не ISO C |
| Высокая точность в определении | Доступна не во всех реализациях |
