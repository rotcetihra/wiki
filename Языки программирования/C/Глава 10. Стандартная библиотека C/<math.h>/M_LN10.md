## Определение

```c
#define M_LN10 2.30258509299404568402
```

## Описание

Макрос — натуральный логарифм числа 10, то есть ln(10). Приблизительно равно 2.302585. Используется для conversions между натуральным и десятичным логарифмом: log₁₀(x) = ln(x) / M_LN10.

Это расширение POSIX/GNU, а не часть стандарта ISO C. Макрос доступен при компиляции с определением `_GNU_SOURCE` или в среде POSIX. Для переносимых вычислений можно использовать `log(10.0)`.

## Примеры

```c
#define _GNU_SOURCE
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("M_LN10 = %.20f\n", M_LN10);
    printf("log(10) = %.20f\n", log(10.0));

    // Преобразование log10 в натуральный логарифм и обратно
    double x = 1000.0;
    double ln_x = log(x);
    double log10_x = ln_x / M_LN10;
    printf("log10(%.0f) = %.10f\n", x, log10_x);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая константа для conversions логарифмов | Расширение POSIX/GNU, не ISO C |
| Высокая точность в определении | Доступна не во всех реализациях |
