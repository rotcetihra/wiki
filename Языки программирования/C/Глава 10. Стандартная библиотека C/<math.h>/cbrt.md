## Определение

```c
#include <math.h>

double cbrt(double x);
float cbrtf(float x);         // C99
long double cbrtl(long double x); // C99
```

## Описание

Функция вычисляет кубический корень аргумента x. Определена для всех действительных значений x (включая отрицательные). Для отрицательных x результат также отрицателен: cbrt(-8) = -2.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("cbrt(0) = %f\n", cbrt(0.0)); // 0.0
    printf("cbrt(1) = %f\n", cbrt(1.0)); // 1.0
    printf("cbrt(8) = %f\n", cbrt(8.0)); // 2.0
    printf("cbrt(27) = %f\n", cbrt(27.0)); // 3.0
    printf("cbrt(-8) = %f\n", cbrt(-8.0)); // -2.0
    
    // Проверка свойства cbrt(a*b) = cbrt(a)*cbrt(b)
    double a = 8.0, b = 27.0;
    printf("cbrt(%f * %f) = %f\n", a, b, cbrt(a * b));
    printf("cbrt(%f) * cbrt(%f) = %f\n", a, b, cbrt(a) * cbrt(b));
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
