## Определение

```c
#define M_LN2 0.69314718055994530942
```

## Описание

Макрос — натуральный логарифм числа 2, то есть ln(2). Приблизительно равно 0.693147. Широко используется в вычислениях, связанных с логарифмами по основанию 2, и в алгоритмах, где требуется перевод между натуральным и двоичным логарифмом: log₂(x) = ln(x) / M_LN2.

Это расширение POSIX/GNU, а не часть стандарта ISO C. Макрос доступен при компиляции с определением `_GNU_SOURCE` или в среде POSIX. Для переносимых вычислений можно использовать `log(2.0)`.

## Примеры

```c
#define _GNU_SOURCE
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("M_LN2 = %.20f\n", M_LN2);
    printf("log(2) = %.20f\n", log(2.0));

    // Преобразование log2 в натуральный логарифм и обратно
    double x = 64.0;
    double ln_x = log(x);
    double log2_x = ln_x / M_LN2;
    printf("log2(%.0f) = %.10f\n", x, log2_x);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая константа для conversions логарифмов | Расширение POSIX/GNU, не ISO C |
| Высокая точность в определении | Доступна не во всех реализациях |
