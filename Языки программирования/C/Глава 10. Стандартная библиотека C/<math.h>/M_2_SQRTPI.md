## Определение

```c
#define M_2_SQRTPI 1.12837916709551257390
```

## Описание

Макрос — отношение двух к квадратному корню из π, то есть 2/√π. Приблизительно равно 1.12838. Используется в вычислениях, связанных с нормальным распределением и функциями ошибок (erf, erfc).

Это расширение POSIX/GNU, а не часть стандарта ISO C. Макрос доступен при компиляции с определением `_GNU_SOURCE` или в среде POSIX. Для переносимых вычислений можно использовать `2.0 / sqrt(M_PI)`.

## Примеры

```c
#define _GNU_SOURCE
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("M_2_SQRTPI = %.20f\n", M_2_SQRTPI);
    printf("2 / sqrt(M_PI) = %.20f\n", 2.0 / sqrt(M_PI));

    // Нормальное распределение (плотность вероятности)
    double sigma = 1.0;
    double coefficient = M_2_SQRTPI / (2.0 * sigma);
    printf("Коэффициент нормального распределения (σ=%.0f): %.10f\n",
           sigma, coefficient);

    return 0;
}
```

## Плюсы и минусы
