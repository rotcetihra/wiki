## Определение

```c
#define M_PI_4 0.78539816339744830962
```

## Описание

Макрос — четверть числа π, то есть π/4. Приблизительно равно 0.785398. Соответствует 45° в радианах. Используется в тригонометрических вычислениях и оптимизации для аргументов 45°.

Это расширение POSIX/GNU, а не часть стандарта ISO C. Макрос доступен при компиляции с определением `_GNU_SOURCE` или в среде POSIX. Для переносимых вычислений можно использовать `M_PI / 4.0`.

## Примеры

```c
#define _GNU_SOURCE
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("M_PI_4 = %.20f\n", M_PI_4);
    printf("M_PI / 4 = %.20f\n", M_PI / 4.0);

    // Тангенс 45° = 1.0
    printf("tan(π/4) = %.10f\n", tan(M_PI_4));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Удобная константа для углов 45° | Расширение POSIX/GNU, не ISO C |
| Высокая точность в определении | Доступна не во всех реализациях |
