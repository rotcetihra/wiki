## Определение

```c
#include <math.h>

double remainder(double x, double y);
double remainderf(float x, float y);         // C99
long double remainderl(long double x, long double y); // C99
```

## Описание

Функция вычисляет остаток от деления x на y по формуле x - n * y, где n — ближайшее целое к отношению x/y. Если результат находится ровно посередине между двумя целыми, выбирается четное n. Результат имеет ту же знак, что и x.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("remainder(5, 2) = %f\n", remainder(5.0, 2.0)); // 1.0
    printf("remainder(5.5, 2) = %f\n", remainder(5.5, 2.0)); // -0.5
    printf("remainder(-5, 2) = %f\n", remainder(-5.0, 2.0)); // -1.0
    printf("remainder(10, 3) = %f\n", remainder(10.0, 3.0)); // 1.0
    
    return 0;
}
```
