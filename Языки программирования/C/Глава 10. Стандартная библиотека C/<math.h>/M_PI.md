## Определение

```c
#define M_PI 3.14159265358979323846
```

## Описание

Макрос — математическая константа π (пи), отношение длины окружности к её диаметру. Приблизительно равно 3.14159265358979. Одна из наиболее часто используемых математических констант в программировании.

Это расширение POSIX/GNU, а не часть стандарта ISO C. Макрос доступен при компиляции с определением `_GNU_SOURCE` или в среде POSIX. Стандарт C не определяет константу π — для переносимых вычислений можно использовать `acos(-1.0)` или `4.0 * atan(1.0)`.

## Примеры

```c
#define _GNU_SOURCE
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("M_PI = %.20f\n", M_PI);
    printf("acos(-1) = %.20f\n", acos(-1.0));

    // Площадь круга
    double r = 5.0;
    double area = M_PI * r * r;
    printf("Площадь круга с радиусом %.0f: %.2f\n", r, area);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Удобная константа, не требует вычислений | Расширение POSIX/GNU, не ISO C |
| Высокая точность (20 значащих цифр) | Доступна не во всех реализациях |
