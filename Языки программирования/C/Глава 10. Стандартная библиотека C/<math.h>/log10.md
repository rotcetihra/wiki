## Определение

```c
#include <math.h>

double log10(double x);
float log10f(float x);            // C99
long double log10l(long double x); // C99
```

## Описание

Функция вычисляет десятичный логарифм (логарифм по основанию 10) аргумента x. Определена для x > 0. Результат — это показатель степени, в которую нужно возвести 10, чтобы получить x. Эквивалентна `log(x) / log(10)`.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("log10(1) = %f\n", log10(1.0));      // 0.0
    printf("log10(10) = %f\n", log10(10.0));    // 1.0
    printf("log10(100) = %f\n", log10(100.0));  // 2.0
    printf("log10(1000) = %f\n", log10(1000.0)); // 3.0
    printf("log10(0.1) = %f\n", log10(0.1));    // -1.0

    // Подсчёт количества десятичных цифр
    unsigned int n = 1234567;
    int digits = (int)floor(log10(n)) + 1;
    printf("Число %u содержит %d цифр\n", n, digits);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Точное вычисление для степеней десяти | Не определён для x ≤ 0 (результат -NaN или доменная ошибка) |
| Поддерживает все типы с плавающей точкой | Менее точна, чем `log1p` для значений близких к 1 |
