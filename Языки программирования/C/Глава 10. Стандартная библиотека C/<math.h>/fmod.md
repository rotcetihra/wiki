## Определение

```c
#include <math.h>

double fmod(double x, double y);
float fmodf(float x, float y);         // C99
long double fmodl(long double x, long double y); // C99
```

## Описание

Функция возвращает вещественный остаток от деления x на y: x - n * y, где n — целая часть отношения x/y. Результат имеет ту же знак, что и x. Если y = 0, результат не определен.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("fmod(5, 2) = %f\n", fmod(5.0, 2.0)); // 1.0
    printf("fmod(5.5, 2) = %f\n", fmod(5.5, 2.0)); // 1.5
    printf("fmod(-5, 2) = %f\n", fmod(-5.0, 2.0)); // -1.0
    printf("fmod(5, -2) = %f\n", fmod(5.0, -2.0)); // 1.0
    printf("fmod(10, 3) = %f\n", fmod(10.0, 3.0)); // 1.0
    
    return 0;
}
```

|---|---|
