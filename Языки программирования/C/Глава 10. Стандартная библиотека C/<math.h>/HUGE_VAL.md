## Определение

```c
#define HUGE_VAL /* реализация-зависимое значение */
```

## Описание

Макрос — положительное значение огромной конечной величины (самое большое значение типа `double`, доступное реализации). Возвращается математическими функциями, когда результат не может быть представлен конечным числом (например, `pow(10, 1000)`). Гарантировано, что `HUGE_VAL` имеет тип `double`. В POSIX-системах обычно определяется как положительную бесконечность `(+__inf__)`, что приводит к генерации исключения переполнения при использовании в вычислениях.

Макрос определён в C99 (ISO/IEC 9899:1999, раздел 7.12) и сохранён в C23 (ISO/IEC 9899:2024, раздел 7.12).

## Примеры

```c
#include <math.h>
#include <stdio.h>
#include <errno.h>

int main(void)
{
    double result = pow(10.0, 1000.0);

    if (result == HUGE_VAL) {
        printf("Результат превышает диапазон double\n");
    }

    printf("HUGE_VAL = %e\n", HUGE_VAL);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
