## Определение

```c
#include <math.h>

double exp(double x);
float expf(float x);         // C99
long double expl(long double x); // C99
```

## Описание

Функция вычисляет экспоненту e^x, где e — основание натурального логарифма (приблизительно 2.71828...). Это фундаментальная функция, описывающая экспоненциальный рост и распад.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("exp(0) = %f\n", exp(0.0)); // 1.0
    printf("exp(1) = %f\n", exp(1.0)); // ~2.71828
    printf("exp(-1) = %f\n", exp(-1.0)); // ~0.36788
    
    // Проверка свойства exp(a+b) = exp(a)*exp(b)
    double a = 2.0, b = 3.0;
    printf("exp(%f + %f) = %f\n", a, b, exp(a + b));
    printf("exp(%f) * exp(%f) = %f\n", a, b, exp(a) * exp(b));
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Точное вычисление для широкого диапазона аргументов | Переполнение для больших положительных x (result → HUGE_VAL) |
| Поддерживает все типы с плавающей точкой | При x < -745 для double результат может быть 0 из-за недостатка точности |
