## Определение

```c
#define INFINITY /* реализация-зависимое значение */
```

## Описание

Макрос — положительная бесконечность типа `float`. Гарантировано, что `INFINITY` является значением `float`, представляющим бесконечность (IEEE-754: положительная бесконечность `+∞`). В отличие от `HUGE_VAL`, который может быть конечным числом огромной величины, `INFINITY` обязательно является именно бесконечностью.

Макрос определён в C99 (ISO/IEC 9899:1999, раздел 7.12) и сохранён в C23 (ISO/IEC 9899:2024, раздел 7.12). Доступен при включении `<math.h>` или `<float.h>`.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void)
{
    float inf = INFINITY;

    printf("INFINITY = %f\n", inf);         // inf
    printf("INFINITY + 1 = %f\n", inf + 1); // inf
    printf("1.0 / INFINITY = %f\n", 1.0f / inf); // 0.000000
    printf("INFINITY == INFINITY: %d\n", inf == inf); // 1

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная переносимая константа бесконечности (C99+) | Тип только `float` — для `double` нужно приведение |
| Гарантированно представляет IEEE-754 бесконечность | Отрицательная бесконечность — `-INFINITY` |
