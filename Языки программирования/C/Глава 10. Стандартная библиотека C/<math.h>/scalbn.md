## Определение

```c
#include <math.h>

double scalbn(double x, int n);
float scalbnf(float x, int n);            // C99
long double scalbnl(long double x, int n); // C99
```

## Описание

Функция вычисляет значение x × 2^n, где n — целое число типа int. Это эквивалент функции `ldexp`, но с более ясным именем, указывающим на масштабирование. Функция удобна для быстрого умножения или деления на целые степени двойки без обращения к `pow`.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("scalbn(1.0, 3) = %f\n", scalbn(1.0, 3));     // 8.0
    printf("scalbn(0.5, 4) = %f\n", scalbn(0.5, 4));     // 8.0
    printf("scalbn(2.0, -1) = %f\n", scalbn(2.0, -1));   // 1.0
    printf("scalbn(100.0, -2) = %f\n", scalbn(100.0, -2)); // 25.0

    // Быстрое деление на степень двойки
    double value = 16.0;
    printf("%f / 2^2 = %f\n", value, scalbn(value, -2)); // 4.0

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрое вычисление x × 2^n | Возможное переполнение для больших n |
| Поддерживает все типы с плавающей точкой | Только для целочисленных показателей типа int |
