## Определение

```c
#include <math.h>

#define isgreaterequal(x, y) /* implementation-defined */
```

## Описание

Макрос определяет, является ли значение x больше или равно значению y. Возвращает ненулевое значение, если `x >= y`, и ноль в противном случае. Не вызывает ненормализованный результат для ненормализованных значений.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("isgreaterequal(5.0, 3.0) = %d\n", isgreaterequal(5.0, 3.0));   // 1 (истина)
    printf("isgreaterequal(3.0, 5.0) = %d\n", isgreaterequal(3.0, 5.0));   // 0 (ложь)
    printf("isgreaterequal(5.0, 5.0) = %d\n", isgreaterequal(5.0, 5.0));   // 1 (истина)
    printf("isgreaterequal(NAN, 1.0) = %d\n", isgreaterequal(NAN, 1.0));   // 0 (ложь)
    printf("isgreaterequal(1.0, NAN) = %d\n", isgreaterequal(1.0, NAN));   // 0 (ложь)
    
    return 0;
}
```
