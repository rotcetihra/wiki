## Определение

```c
#include <math.h>

#define isinf(x) /* implementation-defined */
```

## Описание

Макрос проверяет, является ли аргумент бесконечностью (положительной или отрицательной). Возвращает ненулевое значение, если аргумент является бесконечностью.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    printf("isinf(1.0) = %d\n", isinf(1.0));           // 0 (ложь)
    printf("isinf(INFINITY) = %d\n", isinf(INFINITY));   // 1 (истина)
    printf("isinf(-INFINITY) = %d\n", isinf(-INFINITY)); // 1 (истина)
    printf("isinf(NAN) = %d\n", isinf(NAN));             // 0 (ложь)
    printf("isinf(0.0) = %d\n", isinf(0.0));             // 0 (ложь)
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая проверка на бесконечность | Не различает положительную и отрицательную бесконечность |
| Работает со всеми типами с плавающей точкой |  |
