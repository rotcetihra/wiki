## Определение

```c
#define M_E 2.71828182845904523536
```

## Описание

Макрос — математическая константа _e_ (число Эйлера), основание натурального логарифма. Приблизительно равно 2.71828. Определяется как предел последовательности (1 + 1/n)^n при n → ∞.

Это расширение POSIX/GNU, а не часть стандарта ISO C. Макрос доступен при компиляции с определением `_GNU_SOURCE` или в среде POSIX. Для переносимых вычислений `e` можно получить через `exp(1.0)`.

## Примеры

```c
#define _GNU_SOURCE
#include <math.h>
#include <stdio.h>

int main(void)
{
    printf("M_E = %.20f\n", M_E);
    printf("exp(1) = %.20f\n", exp(1.0));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Быстрая константа, не требует вычислений | Расширение POSIX/GNU, не ISO C |
| Высокая точность в определении | Доступна не во всех реализациях |
