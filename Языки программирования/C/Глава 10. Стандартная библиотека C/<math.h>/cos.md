## Определение

```c
#include <math.h>

double cos(double x);
float cosf(float x);         // C99
long double cosl(long double x); // C99
```

## Описание

Функция вычисляет косинус угла x, измеренного в радианах. Результат находится в диапазоне [-1, 1]. Для больших значений x точность может ухудшаться из-за ошибок приведения аргумента к диапазону [0, 2π).

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    double x = 0; // 0 градусов
    printf("cos(0) = %f\n", cos(x)); // 1.0
    
    x = M_PI / 2; // 90 градусов
    printf("cos(π/2) = %f\n", cos(x)); // 0.0
    
    x = M_PI; // 180 градусов
    printf("cos(π) = %f\n", cos(x)); // -1.0
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Точное вычисление для стандартных углов | Потеря точности для больших аргументов из-за необходимости приведения к диапазону [0, 2π) |
| Поддерживает все типы с плавающей точкой |  |
