## Определение

```c
#include <math.h>

double tan(double x);
float tanf(float x);         // C99
long double tanl(long double x); // C99
```

## Описание

Функция вычисляет тангенс угла x, измеренного в радианах. Тангенс определен как sin(x)/cos(x) и имеет вертикальные асимптоты при x = π/2 + kπ, где k — целое число. При приближении к этим точкам функция стремится к ±∞.

## Примеры

```c
#include <math.h>
#include <stdio.h>

int main(void) {
    double x = 0; // 0 градусов
    printf("tan(0) = %f\n", tan(x)); // 0.0
    
    x = M_PI / 4; // 45 градусов
    printf("tan(π/4) = %f\n", tan(x)); // 1.0
    
    x = -M_PI / 4; // -45 градусов
    printf("tan(-π/4) = %f\n", tan(x)); // -1.0
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Точное вычисление для стандартных углов | Не определен в точках π/2 + kπ (вертикальные асимптоты) |
| Поддерживает все типы с плавающей точкой | Потеря точности для больших аргументов |
