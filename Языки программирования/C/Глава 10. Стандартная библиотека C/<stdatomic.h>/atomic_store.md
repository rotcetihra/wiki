## Определение

```c
#include <stdatomic.h>

void atomic_store(volatile A *object, C value);
void atomic_store_explicit(volatile A *object, C value, memory_order order);
```

## Описание

Функция `atomic_store` выполняет атомарную запись значения `value` в атомарную переменную `object`. Операция гарантированно выполнится целиком — другой поток не увидит промежуточного состояния.

Версия `atomic_store_explicit` позволяет указать модель памяти (`memory_order`) для управления порядком выполнения операций. По умолчанию используется `memory_order_seq_cst` (последовательно согласованный порядок).

> [!NOTE]
> `atomic_store` не может использоваться для инициализации — используйте `atomic_init` или статическую инициализацию.

## Пример

```c
#include <stdio.h>
#include <stdatomic.h>

atomic_int counter = ATOMIC_VAR_INIT(0);

int main(void)
{
    atomic_store(&counter, 10);
    printf("Значение: %d\n", atomic_load(&counter));
    atomic_store_explicit(&counter, 20, memory_order_relaxed);
    printf("После relaxed: %d\n", atomic_load(&counter));
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `object` | Указатель на атомарную переменную |
| `value` | Значение для записи |
| `order` | Модель памяти (только `_explicit` версия) |

## Возвращаемое значение

Функция ничего не возвращает.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантия атомарной записи | Не является инициализацией |
| Поддерживает модели памяти | Только для атомарных типов |
| Портативна (стандартная часть C11) | — |
