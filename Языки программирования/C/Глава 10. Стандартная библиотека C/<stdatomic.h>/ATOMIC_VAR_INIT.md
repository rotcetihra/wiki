## Определение

```c
#include <stdatomic.h>

#define ATOMIC_VAR_INIT(value) (value)
```

## Описание

Макрос `ATOMIC_VAR_INIT` был предназначен для инициализации атомарных переменных. В C11/C17 он обёртывал значение в конструкцию, обеспечивающую инициализацию без промежуточных состояний.

В C23 макрос был объявлен устаревшим — вместо него рекомендуется использовать обычную инициализацию: `atomic_int x = 42;`.

> [!WARNING]
> В современном коде (C23) использование `ATOMIC_VAR_INIT` не рекомендуется. Используйте прямую инициализацию переменных типа `_Atomic`.

## Пример

```c
#include <stdio.h>
#include <stdatomic.h>

atomic_int counter = ATOMIC_VAR_INIT(0);

int main(void)
{
    printf("Начальное значение: %d\n", atomic_load(&counter));
    atomic_fetch_add(&counter, 1);
    printf("После инкремента: %d\n", atomic_load(&counter));
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Портативная инициализация в C11/C17 | Устарел в C23 |
| Простой интерфейс | В C23 эквивалентен обычной инициализации |
