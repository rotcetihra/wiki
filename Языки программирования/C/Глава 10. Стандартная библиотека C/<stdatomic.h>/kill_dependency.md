## Определение

```c
#include <stdatomic.h>

Q kill_dependency(Q y);
```

## Описание

Макрос `kill_dependency` разрывает цепочку зависимостей между атомарными операциями. Возвращается значение `y`, но без сохранения зависимости от предыдущих атомарных операций.

Используется для оптимизации в ситуациях, когда зависимость между операциями не нужна — например, для передачи значения из атомарной переменной в неатомарную.

> [!NOTE]
> `kill_dependency` — это макрос, а не функция. Он не выполняет никаких операций в runtime — только разрывает зависимость на уровне компилятора.

## Пример

```c
#include <stdio.h>
#include <stdatomic.h>

atomic_int shared = 0;

int main(void)
{
    int local = atomic_load(&shared);
    int independent = kill_dependency(local);
    printf("local: %d, independent: %d\n", local, independent);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `y` | Значение для разрыва зависимости |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `Q` | То же значение, что и `y`, но без цепочки зависимостей |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет оптимизировать зависимости | Очень специализирован |
| Не требует runtime-операций | Сложно использовать правильно |
| Стандартная часть C11 | Практически не нужен в обычном коде |
