## Определение

```c
#include <stdatomic.h>

typedef struct { /* implementation-defined */ } atomic_flag;
```

## Описание

Тип `atomic_flag` — единственный обязательный атомарный тип в стандартной библиотеке C. Он представляет собой атомарный флаг, который может находиться в двух состояниях: установлен (`set`) или очищен (`clear`).

В отличие от других атомарных типов, `atomic_flag` гарантированно поддерживает операции без запоминания предыдущего значения (wait-free на всех платформах). Это делает его идеальным для построения spinlock и других примитивов синхронизации.

> [!NOTE]
> Структура `atomic_flag` определяется реализацией и может содержать дополнительные поля. Инициализация возможна только через `ATOMIC_FLAG_INIT` (в C11/C17) или `atomic_flag_clear` (в C23).

## Пример

```c
#include <stdio.h>
#include <stdatomic.h>

atomic_flag lock = ATOMIC_FLAG_INIT;

void acquire_lock(void)
{
    while (atomic_flag_test_and_set(&lock)) {
        /* вращение (spinlock) */
    }
}

void release_lock(void)
{
    atomic_flag_clear(&lock);
}

int main(void)
{
    acquire_lock();
    printf("Критическая секция\n");
    release_lock();
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Единственный обязательно атомарный тип | Ограниченный функционал (только флаг) |
| Wait-free на всех платформах | Нельзя хранить значение |
| Идеален для spinlock | Может привести к busy-waiting |
