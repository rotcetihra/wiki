## Определение

```c
#include <stdatomic.h>

void atomic_init(volatile A *object, C value);
```

## Описание

Макрос `atomic_init` выполняет инициализацию атомарной переменной в runtime. В отличие от статической инициализации (через `ATOMIC_VAR_INIT` или инициализатор), `atomic_init` может использоваться для динамически выделенной памяти.

> [!NOTE]
> `atomic_init` не является атомарной операцией — он не выполняется атомарно с другими атомарными операциями. Используйте только для начальной инициализации перед началом работы с переменной.

> [!WARNING]
> В C23 `atomic_init` объявлен устаревшим. Рекомендуется использовать `atomic_store` или статическую инициализацию.

## Пример

```c
#include <stdio.h>
#include <stdatomic.h>

int main(void)
{
    atomic_int x;
    atomic_init(&x, 42);
    printf("Значение: %d\n", atomic_load(&x));
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `object` | Указатель на атомарную переменную |
| `value` | Значение для инициализации |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет инициализировать в runtime | Не атомарна |
| Подходит для динамической памяти | Устарела в C23 |
| Простой интерфейс | Не потокобезопасна |
