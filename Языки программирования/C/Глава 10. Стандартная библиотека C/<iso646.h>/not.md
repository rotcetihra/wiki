## Определение

```c
#include <iso646.h>

#define not !
```

## Описание

Макрос (C95) — альтернативное написание унарного оператора логического НЕ `!`. `not x` эквивалентно `!x`.

## Примеры

```c
#include <iso646.h>
#include <stdio.h>

int main(void)
{
    int empty = 0;

    if (not empty) {
        printf("Не пусто\n");
    }

    return 0;
}
```
