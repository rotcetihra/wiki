## Определение

```c
#include <iso646.h>

#define not_eq !=
```

## Описание

Макрос (C95) — альтернативное написание оператора сравнения «не равно» `!=`. `a not_eq b` эквивалентно `a != b`.

## Примеры

```c
#include <iso646.h>
#include <stdio.h>

int main(void)
{
    int a = 5, b = 7;

    if (a not_eq b) {
        printf("Разные\n");
    }

    return 0;
}
```
