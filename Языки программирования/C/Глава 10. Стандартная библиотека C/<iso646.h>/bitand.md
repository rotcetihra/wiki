## Определение

```c
#include <iso646.h>

#define bitand &
```

## Описание

Макрос (C95) — альтернативное написание оператора побитового И `&`. `a bitand b` эквивалентно `a & b`.

## Примеры

```c
#include <iso646.h>
#include <stdio.h>

int main(void)
{
    int flags = 0b1100;
    int mask = 0b1010;

    printf("%d\n", flags bitand mask); // 8 (0b1000)

    return 0;
}
```
