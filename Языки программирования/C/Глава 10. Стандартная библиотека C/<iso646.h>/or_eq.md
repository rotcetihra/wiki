## Определение

```c
#include <iso646.h>

#define or_eq |=
```

## Описание

Макрос (C95) — альтернативное написание оператора присваивания с побитовым ИЛИ `|=`. `x or_eq y` эквивалентно `x |= y`.

## Примеры

```c
#include <iso646.h>
#include <stdio.h>

int main(void)
{
    int flags = 0b0001;
    int add = 0b0100;

    flags or_eq add; // flags |= add

    printf("%d\n", flags); // 5 (0b0101)

    return 0;
}
```
