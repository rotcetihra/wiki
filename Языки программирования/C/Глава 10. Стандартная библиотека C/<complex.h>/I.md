## Определение

```c
#include <complex.h>

#define I _Complex_I
```

## Описание

Макрос `I` определяет мнимую единицу типа `float complex`. Является более удобным синонимом макроса `_Complex_I` для записи комплексных чисел.

Использование `I` вместо `_Complex_I` делает код читабельнее: выражение `3.0 + 4.0 * I` нагляднее, чем `3.0 + 4.0 * _Complex_I`. Макрос `_Complex_I` является стандартным именем, а `I` — удобным вариантом, определённым тем же стандартом.

## Примеры

```c
#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z1 = 1.0 + 2.0 * I;
    printf("z1 = %.1f + %.1fi\n", creal(z1), cimag(z1));

    double complex z2 = 3.0 - 4.0 * I;
    printf("z2 = %.1f + %.1fi\n", creal(z2), cimag(z2));

    double complex sum = z1 + z2;
    printf("z1 + z2 = %.1f + %.1fi\n", creal(sum), cimag(sum));

    double complex product = z1 * z2;
    printf("z1 * z2 = %.1f + %.1fi\n", creal(product), cimag(product));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Удобный и компактный синтаксис | Требует умножения для записи мнимой части |
| Стандартный макрос, определён в `<complex.h>` | Less явный, чем `_Complex_I` |
| Портативен между реализациями | Может конфликтовать с пользовательским макросом `I` |
