## Определение

```c
#include <complex.h>

double cproj(double complex z);
float cprojf(float complex z);
long double cprojl(long double complex z);
```

## Описание

Функция `cproj` выполняет стереографическую проекцию комплексного числа на сферу Римана. Сфера Римана — это замыкание комплексной плоскости добавлением бесконечно удалённой точки.

Для всех конечных комплексных чисел проекция возвращает само число. Функция полезна для обработки бесконечно удалённых значений: бесконечно удалённые точки проектируются в северный полюс сферы (который является единственной точкой «бесконечности»).

Существуют три варианта функции: `cprojf` для `float complex`, `cproj` для `double complex` и `cprojl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z1 = 1.0 + 1.0 * I;
    double complex proj1 = cproj(z1);
    printf("cproj(1 + i) = %.1f + %.1fi\n", creal(proj1), cimag(proj1));

    double complex z2 = INFINITY + 0.0 * I;
    double complex proj2 = cproj(z2);
    printf("cproj(∞ + 0i) = %.1f + %.1fi\n", creal(proj2), cimag(proj2));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция для проекции на сферу Римана | Полезна только для обработки бесконечностей |
| Три варианта для разных точностей | Не изменяет конечные числа |
| Стандартное определение для всех конечных `z` | |
