## Определение

```c
#include <complex.h>

double cabs(double complex z);
float cabsf(float complex z);
long double cabsl(long double complex z);
```

## Описание

Функция `cabs` вычисляет модуль (абсолютное значение) комплексного числа. Модуль комплексного числа `z = x + yi` определяется как `|z| = sqrt(x² + y²)`.

Функция возвращает неотрицательное вещественное значение. Для вычисления используется формула квадратного корня из суммы квадратов действительной и мнимой частей.

Существуют три варианта функции: `cabsf` для `float complex`, `cabs` для `double complex` и `cabsl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>
#include <math.h>

int main(void)
{
    double complex z1 = 3.0 + 4.0 * I;
    printf("|%.1f + %.1fi| = %.1f\n", creal(z1), cimag(z1), cabs(z1));

    double complex z2 = 1.0 + 0.0 * I;
    printf("|%.1f + %.1fi| = %.1f\n", creal(z2), cimag(z2), cabs(z2));

    double complex z3 = 0.0 + 2.0 * I;
    printf("|%.1f + %.1fi| = %.1f\n", creal(z3), cimag(z3), cabs(z3));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
