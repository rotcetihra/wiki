## Определение

```c
#include <complex.h>

double ccosh(double complex z);
float ccoshf(float complex z);
long double ccoshl(long double complex z);
```

## Описание

Функция `ccosh` вычисляет косинус гиперболический комплексного числа. Косинус гиперболический комплексного числа `z = x + yi` определяется как `cosh(x) * cos(y) + i * sinh(x) * sin(y)`.

Результат является комплексным числом. Для вещественного аргумента `ccosh` эквивалентен `cosh`, а для чисто мнимого — `cos`.

Существуют три варианта функции: `ccoshf` для `float complex`, `ccosh` для `double complex` и `ccoshl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>
#include <math.h>

int main(void)
{
    double complex z = 1.0 + 0.0 * I;
    printf("cosh(1 + 0i) = %.4f + %.4fi\n", creal(ccosh(z)), cimag(ccosh(z)));

    z = 0.0 + M_PI * I;
    printf("cosh(0 + πi) = %.4f + %.4fi\n", creal(ccosh(z)), cimag(ccosh(z)));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция для косинуса гиперболического | Результат может быть неожиданным для больших вещественных частей |
| Три варианта для разных точностей | Для вещественных чисел лучше использовать `cosh` |
| Связь с гиперболическими функциями | |
