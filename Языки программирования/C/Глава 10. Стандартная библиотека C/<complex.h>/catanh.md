## Определение

```c
#include <complex.h>

double catanh(double complex z);
float catanhf(float complex z);
long double catanhl(long double complex z);
```

## Описание

Функция `catanh` вычисляет арктангенс гиперболический комплексного числа. Арктангенс гиперболический является обратной функцией к тангенсу гиперболическому: если `w = catanh(z)`, то `z = ctanh(w)`.

Результат представляет собой комплексное число, действительная часть которого лежит в диапазоне `(-π/2, π/2)`. Мнимая часть может быть положительной или отрицательной.

Существуют три варианта функции: `catanhf` для `float complex`, `catanh` для `double complex` и `catanhl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z = 2.0 + 1.0 * I;
    double complex result = catanh(z);
    printf("catanh(%.1f + %.1fi) = %.4f + %.4fi\n",
           creal(z), cimag(z), creal(result), cimag(result));

    return 0;
}
```
