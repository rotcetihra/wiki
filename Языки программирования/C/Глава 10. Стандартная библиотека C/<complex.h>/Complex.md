## Определение

```c
#include <complex.h>

#define Complex(real, imag) ((double complex)((double)(real) + _Complex_I * (double)(imag)))
```

## Описание

Макрос `Complex` предназначен для удобного конструирования комплексных чисел из вещественных частей. Принимает два аргумента: действительную и мнимую части, и возвращает комплексное число типа `double complex`.

Макрос является удобной обёрткой над стандартным литералом комплексного числа. Он вычисляет аргументы только один раз, что гарантирует безопасность при передаче выражений с побочными эффектами.

## Примеры

```c
#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z = Complex(3.0, 4.0);
    printf("z = %.1f + %.1fi\n", creal(z), cimag(z));

    double complex w = Complex(1.0, -2.0);
    printf("w = %.1f + %.1fi\n", creal(w), cimag(w));

    double complex sum = z + w;
    printf("z + w = %.1f + %.1fi\n", creal(sum), cimag(sum));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Удобный синтаксис для записи комплексных чисел | Определяет только `double complex`, не `float` или `long double` |
| Вычисляет аргументы один раз | Введён только в C11, не доступен в C99/C89 |
| Портативен между реализациями | Требует включения `<complex.h>` |
