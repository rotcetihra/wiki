## Определение

```c
#include <complex.h>

double csqrt(double complex z);
float csqrtf(float complex z);
long double csqrtl(long double complex z);
```

## Описание

Функция `csqrt` вычисляет квадратный корень комплексного числа. Квадратный корень комплексного числа `z = x + yi` определяется как комплексное число `w = u + vi`, такое что `w² = z`.

Результат является комплексным числом с неотрицательной действительной частью. Если действительная часть исходного числа неотрицательна, результат также имеет неотрицательную действительную часть.

Существуют три варианта функции: `csqrtf` для `float complex`, `csqrt` для `double complex` и `csqrtl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z1 = 4.0 + 0.0 * I;
    printf("sqrt(4 + 0i) = %.4f + %.4fi\n", creal(csqrt(z1)), cimag(csqrt(z1)));

    double complex z2 = -1.0 + 0.0 * I;
    printf("sqrt(-1 + 0i) = %.4f + %.4fi\n", creal(csqrt(z2)), cimag(csqrt(z2)));

    double complex z3 = 1.0 + 1.0 * I;
    printf("sqrt(1 + i) = %.4f + %.4fi\n", creal(csqrt(z3)), cimag(csqrt(z3)));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная функция для квадратного корня | Для вещественных чисел лучше использовать `sqrt` |
| Три варианта для разных точностей | Результат может быть неожиданным для отрицательных вещественных чисел |
| Работает с комплексными числами | |
