## Определение

```c
#include <complex.h>

double creal(double complex z);
float crealf(float complex z);
long double creall(long double complex z);
```

## Описание

Функция `creal` извлекает действительную часть комплексного числа. Для комплексного числа `z = x + yi` функция возвращает `x` как вещественное число.

Действительная часть является вещественным числом, а не комплексным. Это позволяет использовать результат в дальнейших вещественных вычислениях.

Существуют три варианта функции: `crealf` для `float complex`, `creal` для `double complex` и `creall` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z = 3.0 + 4.0 * I;
    printf("z = %.1f + %.1fi\n", creal(z), cimag(z));
    printf("Действительная часть: %.1f\n", creal(z));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и понятная операция | Возвращает `double`, даже для `float complex` |
| Три варианта для разных точностей | Не модифицирует исходное число |
| Стандартный способ извлечения действительной части | |
