## Определение

```c
#include <complex.h>

double cimag(double complex z);
float cimagf(float complex z);
long double cimagl(long double complex z);
```

## Описание

Функция `cimag` извлекает мнимую часть комплексного числа. Для комплексного числа `z = x + yi` функция возвращает `y` как вещественное число.

Мнимая часть является вещественным числом, а не комплексным. Это позволяет использовать результат в дальнейших вещественных вычислениях.

Существуют три варианта функции: `cimagf` для `float complex`, `cimag` для `double complex` и `cimagl` для `long double complex`.

## Примеры

```c
#include <stdio.h>
#include <complex.h>

int main(void)
{
    double complex z = 3.0 + 4.0 * I;
    printf("z = %.1f + %.1fi\n", creal(z), cimag(z));
    printf("Мнимая часть: %.1f\n", cimag(z));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и понятная операция | Возвращает `double`, даже для `float complex` |
| Три варианта для разных точностей | Не модифицирует исходное число |
| Стандартный способ извлечения мнимой части | |
