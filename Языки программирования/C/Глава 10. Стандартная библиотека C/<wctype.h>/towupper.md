## Определение

```c
#include <wctype.h>

wint_t towupper(wint_t wc);
```

## Описание

Преобразует широкий символ `wc` в верхний регистр. Широкая версия функции `toupper()` из `<ctype.h>`.

Для букв с двунаправленным регистром возвращает соответствующий символ другого регистра. Для символов, не имеющих регистра (цифры, пунктуация и т. д.), возвращает `wc` без изменений.

Аргумент `wc` не должен равняться `WEOF`.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wint_t chars[] = {L'a', L'я', L'5', L' '};
    size_t n = sizeof(chars) / sizeof(chars[0]);

    for (size_t i = 0; i < n; i++)
        printf("towupper(L'%lc') = '%lc'\n", (wint_t)chars[i], towupper(chars[i]));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная и портируемая | Преобразует только один символ |
| Поддерживает символы за пределами ASCII | Не преобразует строки целиком |
| Эквивалентна `towctrans(wc, wctrans("toupper"))` | Результат зависит от локали |
