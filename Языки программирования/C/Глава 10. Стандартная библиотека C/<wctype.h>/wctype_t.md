## Определение

```c
#include <wctype.h>

typedef /* unspecified */ wctype_t;
```

## Описание

Тип `wctype_t` — скалярный тип, представляющий описатель классификации широких символов. Используется как результат функции `wctype()` и аргумент функции `iswctype()`.

Конкретный тип определяется реализацией — обычно это указатель на внутреннюю структуру или целочисленный тип. Значение `0` не является допустимым описателем классификации.

Получить значение `wctype_t` можно только через функцию `wctype()`, передав ей имя категории (например, `"alpha"`, `"digit"`, `"space"`). Описатель позволяет вызывать классификацию без повторного разбора строкового имени.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wctype_t is_alpha = wctype("alpha");
    wctype_t is_digit = wctype("digit");

    if (is_alpha && is_digit) {
        wint_t ch1 = L'Я';
        wint_t ch2 = L'7';

        printf("iswctype(L'%lc', alpha) = %d\n", (wint_t)ch1, iswctype(ch1, is_alpha));
        printf("iswctype(L'%lc', digit) = %d\n", (wint_t)ch2, iswctype(ch2, is_digit));
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет кешировать описатель для повторного использования | Тип определяется реализацией, не портируем между платформами |
| Используется в связке `wctype()` + `iswctype()` для гибкой классификации | Не доступен везде: не все реализации поддерживают `wctype()` |
| Экономит время при классификации множества символов по одной категории | Нет стандартного способа проверить корректность значения |
