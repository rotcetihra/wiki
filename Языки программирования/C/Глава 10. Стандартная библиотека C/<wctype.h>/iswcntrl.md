## Определение

```c
#include <wctype.h>

int iswcntrl(wint_t wc);
```

## Описание

Проверяет, является ли широкий символ `wc` управляющим символом (код 0x00–0x1F или 0x7F, а также аналогичные коды в расширенных наборах символов). Широкая версия функции `iscntrl()` из `<ctype.h>`.

Аргумент `wc` должен быть представим как `wint_t` и не должен равняться `WEOF`.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wint_t chars[] = {L'\n', L'\t', L'\0', L'A'};
    size_t n = sizeof(chars) / sizeof(chars[0]);

    for (size_t i = 0; i < n; i++)
        printf("iswcntrl(...)= %d\n", iswcntrl(chars[i]));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная и портируемая | Работает с одним символом |
| Поддерживает символы за пределами ASCII | Проверяет только категорию, не конкретный управляющий символ |
