## Определение

```c
#include <wctype.h>

int iswprint(wint_t wc);
```

## Описание

Проверяет, является ли широкий символ `wc` печатным символом (включая пробел). Широкая версия функции `isprint()` из `<ctype.h>`.

В локали `C` печатными считаются символы с кодами 0x20–0x7E (пробел, буквы, цифры, знаки пунктуации, символы математики). В расширенных локалях — также символы национальных алфавитов и специальные символы.

Аргумент `wc` должен быть представим как `wint_t` и не должен равняться `WEOF`.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wint_t chars[] = {L'A', L' ', L'\n', L'Я'};
    size_t n = sizeof(chars) / sizeof(chars[0]);

    for (size_t i = 0; i < n; i++)
        printf("iswprint(L'...') = %d\n", iswprint(chars[i]));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная и портируемая | Работает с одним символом |
| Определяет, можно ли отобразить символ | Не различает категории печатных символов |
| Поддерживает полный набор символов `wchar_t` | Зависит от локали |
