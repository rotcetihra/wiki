## Определение

```c
#include <wctype.h>

int iswspace(wint_t wc);
```

## Описание

Проверяет, является ли широкий символ `wc` пробельным символом: пробел (`L' '`), горизонтальная табуляция (`L'\t`), перевод строки (`L'\n`), вертикальная табуляция (`L'\v'`), промотка страницы (`L'\f'`) или возврат каретки (`L'\r'`). Широкая версия функции `isspace()` из `<ctype.h>`.

В расширенных локалях могут распознаваться дополнительные пробельные символы (например, узкий пробел U+2009).

Аргумент `wc` должен быть представим как `wint_t` и не должен равняться `WEOF`.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wint_t chars[] = {L' ', L'\t', L'\n', L'A', L'Я'};
    size_t n = sizeof(chars) / sizeof(chars[0]);

    for (size_t i = 0; i < n; i++)
        printf("iswspace(...)= %d\n", iswspace(chars[i]));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная и портируемая | Работает с одним символом |
| Включает все стандартные пробелы | Не различает тип пробела |
| Полезна при разборе текста | Набор символов зависит от локали |
