## Определение

```c
#include <wctype.h>

typedef /* unspecified */ wctrans_t;
```

## Описание

Тип `wctrans_t` — скалярный тип, представляющий описатель преобразования широких символов. Используется как результат функции `wctrans()` и аргумент функции `towctrans()`.

Конкретный тип определяется реализацией — обычно это указатель на внутреннюю структуру или целочисленный тип. Значение `0` не является допустимым описателем преобразования.

Получить значение `wctrans_t` можно только через функцию `wctrans()`, передав ей имя преобразования (например, `"tolower"` или `"toupper"`).

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wctrans_t to_lower = wctrans("tolower");
    wctrans_t to_upper = wctrans("toupper");

    if (to_lower && to_upper) {
        wint_t ch = L'A';
        wint_t lower = towctrans(ch, to_lower);
        wint_t upper = towctrans(ch, to_upper);

        printf("'%lc' →tolower→ '%lc'\n", (wint_t)ch, lower);
        printf("'%lc' →toupper→ '%lc'\n", (wint_t)ch, upper);
    }

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет кешировать описатель для повторного использования | Тип определяется реализацией, не портируем между платформами |
| Используется в связке `wctrans()` + `towctrans()` для гибкого преобразования | Не доступен везде: не все реализации поддерживают `wctrans()` |
| Безопаснее передачи строковых имён преобразований при повторных вызовах | Нет стандартного способа проверить корректность значения |
