## Определение

```c
#include <wctype.h>

int iswlower(wint_t wc);
```

## Описание

Проверяет, является ли широкий символ `wc` строчной (маленькой) буквой. Широкая версия функции `islower()` из `<ctype.h>`.

В локали `C` верно следующее: только латинские буквы `a–z`. В локалях с расширенными алфавитами — также строчные буквы национальных алфавитов.

Аргумент `wc` должен быть представим как `wint_t` и не должен равняться `WEOF`.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wint_t chars[] = {L'a', L'z', L'A', L'Я'};
    size_t n = sizeof(chars) / sizeof(chars[0]);

    for (size_t i = 0; i < n; i++)
        printf("iswlower(L'%lc') = %d\n", (wint_t)chars[i], iswlower(chars[i]));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная и портируемая | Работает с одним символом |
| Поддерживает полный набор символов `wchar_t` | Зависит от локали |
| Используется совместно с `towlower()` | Не различает тип символа (буква или нет) |
