## Определение

```c
#include <wctype.h>

int iswgraph(wint_t wc);
```

## Описание

Проверяет, является ли широкий символ `wc` печатным символом, отличным от пробела. Широкая версия функции `isgraph()` из `<ctype.h>`.

Множество печатных символов без пробела — это все символы, для которых `iswprint()` возвращает ненулевое значение, за вычетом символов, для которых `iswspace()` возвращает ненулевое значение.

Аргумент `wc` должен быть представим как `wint_t` и не должен равняться `WEOF`.

## Примеры

```c
#include <stdio.h>
#include <wctype.h>

int main(void)
{
    wint_t chars[] = {L'A', L'5', L' ', L'\t', L'Я'};
    size_t n = sizeof(chars) / sizeof(chars[0]);

    for (size_t i = 0; i < n; i++)
        printf("iswgraph(L'%lc') = %d\n", (wint_t)chars[i], iswgraph(chars[i]));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная и портируемая | Работает с одним символом |
| Чёткое разделение: печатный без пробела | Не различает категории печатных символов |
