## Определение

```c
#include <locale.h>

#define LC_ALL /* константа категории локали */
```

## Описание

Константа `LC_ALL` определяет все категории локали.

Используется как параметр функции `setlocale` для установки или запроса текущей локали, а также как параметр `localeconv` (косвенно, через `setlocale`).

`LC_ALL` можно комбинировать с другими категориями через побитовое ИЛИ, но стандарт не гарантирует, что значение `LC_ALL` является побитовой маской. Безопасный способ установить все категории -- передать `LC_ALL` как отдельный параметр.

## Пример

```c
#include <stdio.h>
#include <locale.h>

int main(void)
{
    if (setlocale(LC_ALL, "ru_RU.UTF-8") == NULL) {
        printf("Не удалось установить локаль\n");
        return 1;
    }

    printf("Категория LC_ALL установлена\n");
    printf("Текущая локаль: %s\n", setlocale(LC_ALL, NULL));

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный способ управления локалью | Доступные локали зависят от операционной системы |
| Позволяет устанавливать категории по отдельности | Значение константы определяется реализацией |
| Совместим с `localeconv` и `setlocale` | -- |
