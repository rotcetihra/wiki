## Определение

```c
#include <locale.h>

char *setlocale(int category, const char *locale);
```

## Описание

Функция `setlocale` устанавливает или запрашивает текущую локаль. Параметр `category` определяет категорию локали (например, `LC_ALL`, `LC_NUMERIC`, `LC_TIME`), а параметр `locale` -- имя локали (например, `"ru_RU.UTF-8"`, `"C"`, `""`).

Если `locale` равен `NULL`, функция возвращает имя текущей локали без её изменения (запрос).

Если `locale` равен `""`, реализация пытается определить локаль по окружению (обычно переменные `LANG`, `LC_*`, `LC_ALL`).

Если `locale` равен `"C"`, устанавливается минимальная стандартная локаль (аналогичная начальному состоянию программы).

При успешной установке функция возвращает указатель на имя предыдущей локали. При ошибке возвращает `NULL` и текущая локаль не изменяется.

> [!NOTE]
> Вызов `setlocale(LC_ALL, "")` в начале программы автоматически определяет локаль по переменным окружения. Это стандартный способ интернационализации программ.

## Пример

```c
#include <stdio.h>
#include <locale.h>

int main(void)
{
    char *old = setlocale(LC_ALL, "");
    printf("Предыдущая локаль: %s\n", old ? old : "(нет)");

    old = setlocale(LC_ALL, "ru_RU.UTF-8");
    printf("Текущая локаль: %s\n", setlocale(LC_ALL, NULL));

    setlocale(LC_ALL, "C");
    printf("После сброса: %s\n", setlocale(LC_ALL, NULL));

    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `category` | Категория локали: `LC_ALL`, `LC_COLLATE`, `LC_CTYPE`, `LC_MONETARY`, `LC_NUMERIC`, `LC_TIME` |
| `locale` | Имя локали (например, `"ru_RU.UTF-8"`, `"C"`, `""`) или `NULL` для запроса |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `char *` | Имя предыдущей локали (указатель на статический объект) при успешной установке |
| `NULL` | Ошибка (текущая локаль не изменена) |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартный способ управления локалью | Возвращает указатель на статический объект (не потокобезопасно) |
| Поддерживает автоматическое определение локали через `""` | Доступные локали зависят от ОС и установленных пакетов |
| Позволяет устанавливать категории по отдельности | Частые вызовы могут быть дорогими |
