## Определение

```c
#include <stdalign.h>

#define alignof _Alignof // C11
alignof                  // C23: ключевое слово
```

## Описание

Оператор выравнивания: `alignof(тип)` — константное выражение (значение типа `size_t`), равное выравниванию типа — числу байт, кратному которому должен быть адрес объекта этого типа. Например, `alignof(double)` обычно 8, `alignof(int)` — 4. Выравнивание структуры — максимум выравниваний её членов; у `max_align_t` — максимальное выравнивание среди стандартных типов.

Применяется для вычисления сдвигов и размеров без ручных констант (например, при ручном выравнивании данных или сериализации).

## Примеры

```c
#include <stdalign.h>
#include <stddef.h>
#include <stdio.h>

struct S {
    char c;
    double d;
};

int main(void)
{
    printf("alignof(char): %zu\n", alignof(char));       // 1
    printf("alignof(double): %zu\n", alignof(double));   // 8
    printf("alignof(struct S): %zu\n", alignof(struct S)); // 8

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Переносимое вычисление выравнивания | Не имеет аналога для переменных — только для типов |
