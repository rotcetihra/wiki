## Определение

```c
#include <inttypes.h>

typedef struct {
    intmax_t quot;
    intmax_t rem;
} imaxdiv_t;
```

## Описание

Тип `imaxdiv_t` -- структура, содержащая результат деления двух значений типа `intmax_t`. Поле `quot` содержит частное, а поле `rem` -- остаток. Структура возвращается функцией `imaxdiv`.

Поведение при делении на ноль определяется реализацией. При переполнении результат также определяется реализацией.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    intmax_t a = 100;
    intmax_t b = 7;

    imaxdiv_t result = imaxdiv(a, b);
    printf("%jd / %jd = %jd (остаток %jd)\n", a, b, result.quot, result.rem);

    a = -100;
    result = imaxdiv(a, b);
    printf("%jd / %jd = %jd (остаток %jd)\n", a, b, result.quot, result.rem);

    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Позволяет получить частное и остаток за один вызов | Деление на ноль -- неопределённое поведение |
| Работает с типом максимальной ширины | Результат при переполнении не определён |
| Аналог `div_t`/`ldiv_t` для более широких типов | -- |
