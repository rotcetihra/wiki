## Определение

```c
#include <inttypes.h>

uintmax_t strtoumax(const char * restrict nptr, char ** restrict endptr, int base);
```

## Описание

Функция `strtoumax` -- преобразование строки в `uintmax_t`.

Функция `strtoumax` преобразует строку `nptr` в значение типа `uintmax_t`. Параметр `base` определяет основание системы счисления (от 2 до 36, или 0 для автоопределения по префиксу `0x`/`0`). Параметр `endptr`, если не равен `NULL`, получает указатель на первый необработанный символ. При переполнении возвращается `UINTMAX_MAX`, а `errno` устанавливается в `ERANGE`.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    uintmax_t value = strtoumax("0xFF", NULL, 16);
    printf("Значение: %ju\n", value);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `nptr` | Указатель на преобразуемую строку |
| `endptr` | Указатель на указатель, получающий первый необработанный символ (`NULL` если не используется) |
| `base` | Основание системы счисления (2--36 или 0 для автоопределения) |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Успешное преобразование | Значение типа `uintmax_t` |
| Переполнение | `UINTMAX_MAX`, `errno = ERANGE` |
| Неверный формат | `0`, `errno` не изменяется |
