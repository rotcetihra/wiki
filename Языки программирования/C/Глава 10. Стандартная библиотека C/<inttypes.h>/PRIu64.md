## Определение

```c
#include <inttypes.h>

#define PRIu64 /* строковый литерал, раскрываемый в спецификатор формата */
```

## Описание

Макрос `PRIu64` -- строковый литерал, используемый в строке формата функции `printf` (и родственных: `fprintf`, `snprintf`, `sprintf`). Заменяет собой спецификатор формата для типа `uint64_t` в формате **десятичный без знака**.

Макрос предназначен для переносимого форматирования целочисленных типов фиксированной ширины. На разных платформах один и тот же тип может объявляться как `long`, `long long` или другой тип, поэтому `PRIu64` подставляет корректный спецификатор автоматически.

Использование в строке формата:

```c
printf("%" PRIu64 "\n", value);
```

> [!NOTE]
> Макрос `PRIu64` не является самостоятельным строковым литералом и не должен использоваться отдельно. Он всегда подставляется внутрь строки формата.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    uint64_t value = 42;
    printf("Значение: %" PRIu64 "\n", value);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантированно корректный спецификатор для `uint64_t` | Требует конкатенации строк в строке формата |
| Переносимость между платформами | Некоторые компиляторы могут определять макрос как пустую строку |
| Стандартный способ (ISO C99/C23) | -- |
