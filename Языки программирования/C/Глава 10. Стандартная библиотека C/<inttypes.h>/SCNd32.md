## Определение

```c
#include <inttypes.h>

#define SCNd32 /* строковый литерал, раскрываемый в спецификатор формата */
```

## Описание

Макрос `SCNd32` -- строковый литерал, используемый в строке формата функции `scanf` (и родственных: `fscanf`, `sscanf`). Заменяет собой спецификатор формата для типа `int32_t` в формате **десятичный**.

Аргумент, соответствующий этому спецификатору, должен быть указателем на `int32_t`.

Макрос предназначен для переносимого чтения целочисленных типов фиксированной ширины. На разных платформах один и тот же тип может объявляться как `long`, `long long` или другой тип, поэтому `SCNd32` подставляет корректный спецификатор автоматически.

Использование в строке формата:

```c
int32_t value;
scanf("%" SCNd32, &value);
```

> [!NOTE]
> Макрос `SCNd32` не является самостоятельным строковым литералом и не должен использоваться отдельно. Он всегда подставляется внутрь строки формата.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    int32_t value;
    printf("Введите число: ");
    scanf("%" SCNd32, &value);
    printf("Вы ввели: %" SCNd32 "\n", value);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантированно корректный спецификатор для `int32_t` | Требует конкатенации строк в строке формата |
| Переносимость между платформами | Некоторые компиляторы могут определять макрос как пустую строку |
| Стандартный способ (ISO C99/C23) | -- |
