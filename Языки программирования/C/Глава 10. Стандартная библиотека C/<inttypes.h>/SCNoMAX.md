## Определение

```c
#include <inttypes.h>

#define SCNoMAX /* строковый литерал, раскрываемый в спецификатор формата */
```

## Описание

Макрос `SCNoMAX` -- строковый литерал, используемый в строке формата функции `scanf` (и родственных: `fscanf`, `sscanf`). Заменяет собой спецификатор формата для типа `intmax_t` в формате **восьмеричный**.

Аргумент, соответствующий этому спецификатору, должен быть указателем на `intmax_t`.

Макрос предназначен для переносимого чтения целочисленных типов фиксированной ширины. На разных платформах один и тот же тип может объявляться как `long`, `long long` или другой тип, поэтому `SCNoMAX` подставляет корректный спецификатор автоматически.

Использование в строке формата:

```c
intmax_t value;
scanf("%" SCNoMAX, &value);
```

> [!NOTE]
> Макрос `SCNoMAX` не является самостоятельным строковым литералом и не должен использоваться отдельно. Он всегда подставляется внутрь строки формата.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    intmax_t value;
    printf("Введите число: ");
    scanf("%" SCNoMAX, &value);
    printf("Вы ввели: %" SCNoMAX "\n", value);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантированно корректный спецификатор для `intmax_t` | Требует конкатенации строк в строке формата |
| Переносимость между платформами | Некоторые компиляторы могут определять макрос как пустую строку |
| Стандартный способ (ISO C99/C23) | -- |
