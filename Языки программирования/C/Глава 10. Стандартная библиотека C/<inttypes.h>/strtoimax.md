## Определение

```c
#include <inttypes.h>

intmax_t strtoimax(const char * restrict nptr, char ** restrict endptr, int base);
```

## Описание

Функция `strtoimax` -- преобразование строки в `intmax_t`.

Функция `strtoimax` преобразует строку `nptr` в значение типа `intmax_t`. Параметр `base` определяет основание системы счисления (от 2 до 36, или 0 для автоопределения по префиксу `0x`/`0`). Параметр `endptr`, если не равен `NULL`, получает указатель на первый необработанный символ. При переполнении возвращается `INTMAX_MAX` или `INTMAX_MIN`, а `errno` устанавливается в `ERANGE`.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    intmax_t value = strtoimax("12345", NULL, 10);
    printf("Значение: %jd\n", value);
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `nptr` | Указатель на преобразуемую строку |
| `endptr` | Указатель на указатель, получающий первый необработанный символ (`NULL` если не используется) |
| `base` | Основание системы счисления (2--36 или 0 для автоопределения) |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| Успешное преобразование | Значение типа `intmax_t` |
| Переполнение | `INTMAX_MAX` или `INTMAX_MIN`, `errno = ERANGE` |
| Неверный формат | `0`, `errno` не изменяется |
