## Определение

```c
#include <inttypes.h>

#define SCNu16 /* строковый литерал, раскрываемый в спецификатор формата */
```

## Описание

Макрос `SCNu16` -- строковый литерал, используемый в строке формата функции `scanf` (и родственных: `fscanf`, `sscanf`). Заменяет собой спецификатор формата для типа `uint16_t` в формате **десятичный без знака**.

Аргумент, соответствующий этому спецификатору, должен быть указателем на `uint16_t`.

Макрос предназначен для переносимого чтения целочисленных типов фиксированной ширины. На разных платформах один и тот же тип может объявляться как `long`, `long long` или другой тип, поэтому `SCNu16` подставляет корректный спецификатор автоматически.

Использование в строке формата:

```c
uint16_t value;
scanf("%" SCNu16, &value);
```

> [!NOTE]
> Макрос `SCNu16` не является самостоятельным строковым литералом и не должен использоваться отдельно. Он всегда подставляется внутрь строки формата.

## Пример

```c
#include <stdio.h>
#include <inttypes.h>

int main(void)
{
    uint16_t value;
    printf("Введите число: ");
    scanf("%" SCNu16, &value);
    printf("Вы ввели: %" SCNu16 "\n", value);
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантированно корректный спецификатор для `uint16_t` | Требует конкатенации строк в строке формата |
| Переносимость между платформами | Некоторые компиляторы могут определять макрос как пустую строку |
| Стандартный способ (ISO C99/C23) | -- |
