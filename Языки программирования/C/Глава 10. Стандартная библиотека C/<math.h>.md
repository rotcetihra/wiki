## Описание библиотеки

Заголовочный файл `<math.h>` — «математические функции»: функции для работы с числами с плавающей точкой, включая тригонометрические, гиперболические, экспоненциальные, логарифмические функции, функции округления, остатка, сравнения и классификации. В C23 расширен новыми функциями и улучшенной поддержкой типов с плавающей точкой.

Большинство функций имеют варианты для `float`, `double` и `long double` (например, `sinf()`, `sin()`, `sinl()`), хотя в этом справочнике описаны primarily версии для `double` для краткости; варианты для других типов доступны аналогично.

В C23 добавлены новые функции классификации и улучшена поддержка операций с плавающей точкой в соответствии со стандартом IEEE-754.

> [!NOTE]
> Для использования математических функций обычно требуется link с библиотекой математики (`-lm` при компиляции с GCC/Clang), так как многие функции реализованы в отдельной библиотеке libm.

### Тригонометрические функции
Все углы измеряются в радианах. Функции работают с гиперболическими и обычными тригонометрическими функциями.

### Гиперболические функции
Гиперболические функции связаны с круговыми функциями через мнимые единицы: sinh(x) = -i sin(ix), cosh(x) = cos(ix) и т.д.

### Функции экспоненты и логарифма
Экспоненциальная функция exp(x) вычисляет e^x. Логарифмические функции являются обратными к экспоненциальным.

### Функции возведения в степень
Функция pow(x, y) вычисляет x^y. Специальные случаи обрабатываются согласно стандарту.

### Округление и остаток от деления
Функции округления преобразуют числа с плавающей точкой в целые значения согласно различным правилам округления.

### Функции сравнения
Функции сравнения позволяют сравнивать числа с плавающей точкой без генерации исключений для NaN значений.

### Функции классификации
Функции позволяют определить тип числа с плавающей точкой (нормальное, subnormal, бесконечность, NaN, ноль).

### Макросы и специальные значения
Макросы определяют специальные значения: бесконечность, нечисло (NaN) и математические константы.
