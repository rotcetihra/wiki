## Определение

```c
#include <stdbit.h>

unsigned int stdc_trailing_ones(unsigned int value);
unsigned int stdc_trailing_ones(unsigned long value);
unsigned int stdc_trailing_ones(unsigned long long value);
```

## Описание

Макрос `stdc_trailing_ones` возвращает количество завершающих единичных битов в значении `value`. Завершающие единицы — это единичные биты младше младшего нулевого бита.

Для значения, в котором все биты равны 1, функция возвращает количество битов в типе.

## Пример

```c
#include <stdio.h>
#include <stdbit.h>

int main(void)
{
    unsigned int x = 0x0000000F;
    printf("stdc_trailing_ones(%#x) = %u\n", x, stdc_trailing_ones(x));
    return 0;
}
```

| Параметр | Описание |

| Значение | Описание |
