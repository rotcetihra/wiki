## Определение

```c
#include <stdbit.h>

unsigned int stdc_bit_floor(unsigned int value);
unsigned int stdc_bit_floor(unsigned long value);
unsigned int stdc_bit_floor(unsigned long long value);
```

## Описание

Макрос `stdc_bit_floor` возвращает наибольшую степень двойки, не превосходящую `value`. Если `value` уже является степенью двойки, возвращает его же.

Для `value` = 0 возвращает 0.

## Пример

```c
#include <stdio.h>
#include <stdbit.h>

int main(void)
{
    printf("stdc_bit_floor(5) = %u\n", stdc_bit_floor(5));
    printf("stdc_bit_floor(8) = %u\n", stdc_bit_floor(8));
    printf("stdc_bit_floor(100) = %u\n", stdc_bit_floor(100));
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `value` | Беззнаковое целочисленное значение |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `unsigned int` | Наибольшая степень двойки ≤ `value` |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Удобно для округления вниз до степени двойки | Только для беззнаковых типов |
| Работает со всеми беззнаковыми типами | — |
