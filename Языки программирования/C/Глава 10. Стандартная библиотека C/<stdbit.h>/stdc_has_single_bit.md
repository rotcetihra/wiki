## Определение

```c
#include <stdbit.h>

bool stdc_has_single_bit(unsigned int value);
bool stdc_has_single_bit(unsigned long value);
bool stdc_has_single_bit(unsigned long long value);
```

## Описание

Макрос `stdc_has_single_bit` проверяет, является ли значение `value` степенью двойки (то есть содержит ровно один установленный бит). Возвращает `true`, если `value` — степень двойки, и `false` в противном случае.

> [!NOTE]
> Значение 0 не является степенью двойки — функция вернёт `false`.

## Пример

```c
#include <stdio.h>
#include <stdbit.h>

int main(void)
{
    printf("4: %s\n", stdc_has_single_bit(4) ? "да" : "нет");
    printf("6: %s\n", stdc_has_single_bit(6) ? "да" : "нет");
    printf("8: %s\n", stdc_has_single_bit(8) ? "да" : "нет");
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `value` | Беззнаковое целочисленное значение |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `true` | Значение является степенью двойки |
| `false` | Значение не является степенью двойки |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая проверка степени двойки | Только для беззнаковых типов |
| Может оптимизироваться в одну инструкцию | — |
