## Определение

```c
#include <stdbit.h>

unsigned int stdc_leading_zeros(unsigned int value);
unsigned int stdc_leading_zeros(unsigned long value);
unsigned int stdc_leading_zeros(unsigned long long value);
```

## Описание

Макрос `stdc_leading_zeros` возвращает количество ведущих нулевых битов в значении `value`. Ведущие нули — это нулевые биты старше старшего единичного бита.

Для значения 0 функция возвращает количество битов в типе (например, 32 для `unsigned int`).

> [!NOTE]
> Эквивалент встроенных функций GCC: `__builtin_clz`. На архитектурах x86 реализуется инструкцией `BSR` или `LZCNT`.

## Пример

```c
#include <stdio.h>
#include <stdbit.h>

int main(void)
{
    unsigned int x = 0x00FF0000;
    printf("stdc_leading_zeros(%u) = %u\n", x, stdc_leading_zeros(x));
    printf("stdc_leading_zeros(%u) = %u\n", 0u, stdc_leading_zeros(0u));
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `value` | Беззнаковое целочисленное значение |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `unsigned int` | Количество ведущих нулевых битов |

| Преимущество | Недостаток |

| Работает со всеми беззнаковыми типами | Только для беззнаковых типов |
