## Определение

```c
#include <stdbit.h>

unsigned int stdc_leading_ones(unsigned int value);
unsigned int stdc_leading_ones(unsigned long value);
unsigned int stdc_leading_ones(unsigned long long value);
```

## Описание

Макрос `stdc_leading_ones` возвращает количество ведущих единичных битов в значении `value`. Ведущие единицы — это единичные биты старше старшего нулевого бита.

Для значения, в котором все биты равны 1, функция возвращает количество битов в типе.

## Пример

```c
#include <stdio.h>
#include <stdbit.h>

int main(void)
{
    unsigned int x = 0xFF000000;
    printf("stdc_leading_ones(%#x) = %u\n", x, stdc_leading_ones(x));
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `value` | Беззнаковое целочисленное значение |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `unsigned int` | Количество ведущих единичных битов |
