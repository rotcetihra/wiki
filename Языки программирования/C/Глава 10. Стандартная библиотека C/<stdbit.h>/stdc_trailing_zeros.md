## Определение

```c
#include <stdbit.h>

unsigned int stdc_trailing_zeros(unsigned int value);
unsigned int stdc_trailing_zeros(unsigned long value);
unsigned int stdc_trailing_zeros(unsigned long long value);
```

## Описание

Макрос `stdc_trailing_zeros` возвращает количество завершающих нулевых битов в значении `value`. Завершающие нули — это нулевые биты младше младшего единичного бита.

Для значения 0 функция возвращает количество битов в типе.

> [!NOTE]
> Эквивалент встроенных функций GCC: `__builtin_ctz`. На архитектурах x86 реализуется инструкцией `TZCNT` или `BSF`.

## Пример

```c
#include <stdio.h>
#include <stdbit.h>

int main(void)
{
    unsigned int x = 0x000000F0;
    printf("stdc_trailing_zeros(%#x) = %u\n", x, stdc_trailing_zeros(x));
    return 0;
}
```

## Параметры

| Параметр | Описание |
|---|---|
| `value` | Беззнаковое целочисленное значение |

## Возвращаемое значение

| Значение | Описание |
|---|---|
| `unsigned int` | Количество завершающих нулевых битов |

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Переносимая альтернатива встроенным функциям | Для 0 возвращает размер типа |
| Работает со всеми беззнаковыми типами | Только для беззнаковых типов |
