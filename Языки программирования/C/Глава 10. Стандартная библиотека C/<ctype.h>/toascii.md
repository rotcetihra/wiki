## Прототип

```c
#include <ctype.h> // POSIX

int toascii(int c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Код символа для преобразования |

## Возвращаемое значение

Возвращает `c` с обнулёнными старшими битами (значение `c & 0x7F`), то есть код символа в 7-битном ASCII.

## Что делает

Обрезает код символа до 7 бит: результат всегда находится в диапазоне 0–127. Функция устарела и не входит в ISO C; в glibc объявлена в `<ctype.h>` при определении `_DEFAULT_SOURCE`.

> [!WARNING]
> Обрезание старших битов искажает байты UTF-8 и национальных кодировок. Для перекодировки используйте `iconv()`, для сравнения без учёта регистра — `strcasecmp()`.

## Примеры

```c
#define _DEFAULT_SOURCE
#include <stdio.h>
#include <ctype.h>

int main(void)
{
    printf("%d\n", toascii('A'));    // 65
    printf("%d\n", toascii(0xC0));   // 64 (0xC0 & 0x7F)

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая и предсказуемая | Устаревшая, не входит в ISO C |
| — | Искажает многобайтовые кодировки |

## Альтернативы

- **`c & 0x7F`** — эквивалентная операция без вызова функции
- **`iconv()`** — корректная перекодировка текста
