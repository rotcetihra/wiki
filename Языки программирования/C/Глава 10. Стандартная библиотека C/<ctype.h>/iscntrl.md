## Прототип

```c
#include <ctype.h>

int iscntrl(int c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Код символа для проверки (приводится к `unsigned char`) |

## Возвращаемое значение

Возвращает ненулевое значение, если символ `c` является управляющим символом; 0 — в противном случае.

## Что делает

Проверяет, является ли символ `c` управляющим символом. В локали `C` верно следующее: коды 0x00–0x1F и 0x7F (DEL); управляющими не являются печатные символы.

Аргумент приводится к `unsigned char`: передача отрицательного значения, отличного от `EOF`, — неопределённое поведение.

## Примеры

```c
#include <stdio.h>
#include <ctype.h>

int main(void)
{
    unsigned char c1 = '\n';
    unsigned char c2 = '\t';

    printf("iscntrl(c1) = %d\n", iscntrl(c1));
    printf("iscntrl(c2) = %d\n", iscntrl(c2));

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Если `c` не представим как `unsigned char` и не равен `EOF`, поведение не определено.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная и переносимая | Работает с одним символом, а не со строкой |
| Зависит от локали, а не от языка программы | Проверяет только один байт, не многобайтовые символы |
| Может быть вызвана для любого символа таблицы локали | Результат зависит от текущей локали |

## Альтернативы

- **`iscntrl_l()`** — та же проверка в явно заданной локали (POSIX)
