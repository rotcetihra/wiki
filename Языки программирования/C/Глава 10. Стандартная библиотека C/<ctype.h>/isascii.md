## Прототип

```c
#include <ctype.h> // POSIX

int isascii(int c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Код символа для проверки |

## Возвращаемое значение

Возвращает ненулевое значение, если `c` входит в 7-битный набор ASCII (0–127); 0 — в противном случае.

## Что делает

Проверяет, входит ли код символа в 7-битный набор ASCII. В отличие от остальных функций `<ctype.h>`, принимает любые значения `c` без ограничений: приводить аргумент к `unsigned char` не требуется.

> [!WARNING]
> Функция устарела и не входит в ISO C. Для проверки печатных символов используйте `isprint()`/`isgraph()`, которые корректно работают с 8-битными кодировками.

## Примеры

```c
#define _DEFAULT_SOURCE
#include <stdio.h>
#include <ctype.h>

int main(void)
{
    printf("%d\n", isascii('A'));    // 1
    printf("%d\n", isascii(200));    // 0 (код > 127)

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Простая проверка «ASCII или нет» | Устаревшая, не входит в ISO C |
| Принимает любые значения `int` | Не различает категории внутри ASCII |

## Альтернативы

- **`(c >= 0 && c <= 127)`** — эквивалентная проверка без вызова функции
