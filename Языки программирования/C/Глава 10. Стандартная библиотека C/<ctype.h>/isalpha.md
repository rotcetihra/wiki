## Прототип

```c
#include <ctype.h>

int isalpha(int c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Код символа для проверки (приводится к `unsigned char`) |

## Возвращаемое значение

Возвращает ненулевое значение, если символ `c` является буквой; 0 — в противном случае.

## Что делает

Проверяет, является ли символ `c` буквой. В локали `C` верно следующее: только латинские буквы `A–Z` и `a–z`; в локалях с расширенными алфавитами — также буквы национальных алфавитов.

Аргумент приводится к `unsigned char`: передача отрицательного значения, отличного от `EOF`, — неопределённое поведение.

## Примеры

```c
#include <stdio.h>
#include <ctype.h>

int main(void)
{
    unsigned char c1 = 'A';
    unsigned char c2 = 'z';

    printf("isalpha(c1) = %d\n", isalpha(c1));
    printf("isalpha(c2) = %d\n", isalpha(c2));

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Если `c` не представим как `unsigned char` и не равен `EOF`, поведение не определено.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная и переносимая | Работает с одним символом, а не со строкой |
| Зависит от локали, а не от языка программы | Проверяет только один байт, не многобайтовые символы |
| Может быть вызвана для любого символа таблицы локали | Результат зависит от текущей локали |

## Альтернативы

- **`isalpha_l()`** — та же проверка в явно заданной локали (POSIX)
