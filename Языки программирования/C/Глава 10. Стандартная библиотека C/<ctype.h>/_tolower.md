## Прототип

```c
#include <ctype.h> // GNU

int _tolower(int c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Код символа для преобразования |

## Возвращаемое значение

Возвращает `c` со сдвигом в диапазон нижних букв (в ASCII — `c | 0x20`), если `c` — заглавная буква; в противном случае поведение не определено.

## Что делает

Быстрый аналог `tolower()` без проверки: предполагает, что аргумент — заглавная буква, и выполняет безусловное преобразование. Если передать символ, не являющийся заглавной буквой, результат не определён.

> [!WARNING]
> Функция устарела и не входит в ISO C. Используйте `tolower()`, которая безопасна для любых аргументов.

## Примеры

```c
#define _GNU_SOURCE
#include <ctype.h>
#include <stdio.h>

int main(void)
{
    printf("%c\n", _tolower('A'));   // a
    printf("%c\n", _tolower('Z'));   // z

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Для аргумента, не являющегося заглавной буквой, поведение не определено.

## Плюсы и минусы

| Преимущество | Недостаток |

| — | Устаревшая, не входит в ISO C |
