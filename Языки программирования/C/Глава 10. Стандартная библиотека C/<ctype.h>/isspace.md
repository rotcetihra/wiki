## Прототип

```c
#include <ctype.h>

int isspace(int c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Код символа для проверки (приводится к `unsigned char`) |

## Возвращаемое значение

Возвращает ненулевое значение, если символ `c` является пробельным символом; 0 — в противном случае.

## Что делает

Проверяет, является ли символ `c` пробельным символом. В локали `C` верно следующее: `' '`, `'\t'`, `'\n'`, `'\v'`, `'\f'`, `'\r'`; в отличие от `isblank()` включает перевод строки и вертикальную табуляцию.

Аргумент приводится к `unsigned char`: передача отрицательного значения, отличного от `EOF`, — неопределённое поведение.

## Примеры

```c
#include <stdio.h>
#include <ctype.h>

int main(void)
{
    unsigned char c1 = ' ';
    unsigned char c2 = '\t';

    printf("isspace(c1) = %d\n", isspace(c1));
    printf("isspace(c2) = %d\n", isspace(c2));

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Если `c` не представим как `unsigned char` и не равен `EOF`, поведение не определено.

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Стандартная и переносимая | Работает с одним символом, а не со строкой |
| Зависит от локали, а не от языка программы | Проверяет только один байт, не многобайтовые символы |
| Может быть вызвана для любого символа таблицы локали | Результат зависит от текущей локали |

## Альтернативы

- **`isspace_l()`** — та же проверка в явно заданной локали (POSIX)
