## Прототип

```c
#include <ctype.h> // GNU

int _toupper(int c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Код символа для преобразования |

## Возвращаемое значение

Возвращает `c` со сдвигом в диапазон верхних букв (в ASCII — `c & ~0x20`), если `c` — строчная буква; в противном случае поведение не определено.

## Что делает

Быстрый аналог `toupper()` без проверки: предполагает, что аргумент — строчная буква, и выполняет безусловное преобразование. Если передать символ, не являющийся строчной буквой, результат не определён.

> [!WARNING]
> Функция устарела и не входит в ISO C. Используйте `toupper()`, которая безопасна для любых аргументов.

## Примеры

```c
#define _GNU_SOURCE
#include <ctype.h>
#include <stdio.h>

int main(void)
{
    printf("%c\n", _toupper('a'));   // A
    printf("%c\n", _toupper('z'));   // Z

    return 0;
}
```

## Ошибки и errno

Функция не устанавливает `errno`. Для аргумента, не являющегося строчной буквой, поведение не определено.
