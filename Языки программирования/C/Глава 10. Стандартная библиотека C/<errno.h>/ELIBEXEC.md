## Определение

```c
#include <errno.h>

#define ELIBEXEC 83 // "Cannot exec a shared library directly"
```

## Описание

«Нельзя выполнить разделяемую библиотеку напрямую»: попытка `execve()` файла, являющегося разделяемой библиотекой, без главной программы (у библиотеки нет точки входа). Linux-специфичный код.

## Когда возникает

- `execve()` запускает ELF-файл типа `ET_DYN` без интерпретатора программы — оболочка/ядро вернут эту ошибку при несовместимой конфигурации.

## Похожие коды

- `ENOEXEC` — неверный формат исполняемого файла
- `ELIBBAD` — повреждённая библиотека
