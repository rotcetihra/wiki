## Определение

```c
#include <errno.h>

#define EBADRQC 56 // "Invalid request code"
```

## Описание

«Недопустимый код запроса» — код серии RFS/XENIX «exchange». На Linux сохраняется для совместимости; не возникает в современных программах. Не входит в POSIX.

## Когда возникает

- исторически — RFS/XENIX с неизвестным кодом операции; на современных Linux не встречается.

## Похожие коды

- `EBADE` — недопустимый обмен
- `EBADR` — недопустимый дескриптор запроса
- `EBADSLT` — недопустимый слот
