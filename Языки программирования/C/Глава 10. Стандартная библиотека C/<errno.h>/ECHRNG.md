## Определение

```c
#include <errno.h>

#define ECHRNG 44 // "Channel number out of range"
```

## Описание

«Номер канала вне диапазона» — код из набора STREAMS (System V): номер канала недоступен. На Linux сохраняется для совместимости; в современных программах не применяется. Не входит в POSIX.

## Когда возникает

- исторически — STREAMS: ссылка на несуществующий канал; на современных Linux не возникает.

## Похожие коды

- `ELNRNG` — номер звена вне диапазона (STREAMS)
- `EL2HLT`/`EL3HLT` — уровни STREAMS
