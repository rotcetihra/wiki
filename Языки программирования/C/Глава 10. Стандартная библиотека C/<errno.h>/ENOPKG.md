## Определение

```c
#include <errno.h>

#define ENOPKG 65 // "Package not installed"
```

## Описание

«Пакет не установлен» — исторический код RFS (не установлен пакет/поддержка на узле). На Linux сохраняется для совместимости, не используется. Не входит в POSIX.

## Когда возникает

- исторически — RFS: отсутствующий ПП/модуль; на современных Linux не возникает.

## Похожие коды

- `ENOSYS` — функция не реализована
- `ENODEV` — устройство отсутствует

## Источники

- Linux: `asm-generic/errno.h`
