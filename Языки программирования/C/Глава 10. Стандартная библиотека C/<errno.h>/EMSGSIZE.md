## Определение

```c
#include <errno.h>

#define EMSGSIZE 90 // "Message too long"
```

## Описание

«Сообщение слишком длинное». POSIX (XSI). Возвращается сокетными и IPC-вызовами, когда длина сообщения превышает допустимую.

## Когда возникает

- `send()`/`sendto()` на дейтаграммном сокете — размер больше `SO_SNDBUF`/MTU-лимита;
- `msgsnd()` — длина сообщения больше `MSGMAX` (Linux: 8192);
- `sendmsg()` с превышением лимита входящих данных `iovec` (связано с `UIO_MAXIOV`? — нет, это `EMSGSIZE` в `sendmsg()`).

## Похожие коды

- `EOVERFLOW` — значение не помещается в тип
- `ENOBUFS` — нет буферного пространства

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno.h`, man-страницы `send(2)`, `msgget(2)`
