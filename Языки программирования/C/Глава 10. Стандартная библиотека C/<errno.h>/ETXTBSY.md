## Определение

```c
#include <errno.h>

#define ETXTBSY 26 // "Text file busy"
```

## Описание

«Текстовый файл занят»: попытка модификации (запись, удаление, переименование) исполняемого файла, который в данный момент выполняется. POSIX-код. Название историческое (исполняемый файл называли «text file»).

## Когда возникает

- `open(O_WRONLY)`/`open(O_TRUNC)` на исполняемый бинарник запущенного процесса;
- `unlink()`/`rename()` исполняемого файла (на Linux — разрешено: inode остаётся); классика на старых системах;
- замена работающего бинарника запрещена, нужно `mv`+запись нового имени.

## Похожие коды

- `EBUSY` — ресурс занят
- `EACCES` — нет прав
- `EROFS` — ФС только для чтения
