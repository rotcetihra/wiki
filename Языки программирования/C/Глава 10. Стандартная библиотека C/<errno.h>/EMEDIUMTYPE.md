## Определение

```c
#include <errno.h>

#define EMEDIUMTYPE 124 // "Wrong medium type"
```

## Описание

«Неправильный тип носителя»: в устройстве носитель не того типа, который ожидается (например, DVD вместо CD). Linux-специфичный код.

## Когда возникает

- оптические приводы: запрошенный тип диска не вставлен;
- мультимедиа-устройства с несовместимым носителем.

## Похожие коды

- `ENOMEDIUM` — носитель отсутствует
- `ENXIO` — устройство недоступно
