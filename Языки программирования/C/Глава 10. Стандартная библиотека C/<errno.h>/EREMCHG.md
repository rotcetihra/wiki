## Определение

```c
#include <errno.h>

#define EREMCHG 78 // "Remote address changed"
```

## Описание

«Удалённый адрес изменился» — исторический код RFS/распределённых систем: адрес удалённого объекта изменился между операциями. На Linux существует для совместимости, не используется. Не входит в POSIX.

## Когда возникает

- исторически — RFS: изменение адреса сетевого ресурса; на современных Linux не возникает.

## Похожие коды

- `EREMOTE` — объект удалённый
- `ENOLINK` — связь разорвана
