## Определение

```c
#include <errno.h>

#define EISDIR 21 // "Is a directory"
```

## Описание

«Это каталог»: операции, неприменимые к каталогам, выполнены над каталогом. POSIX-код.

## Когда возникает

- `open()` с `O_WRONLY`/`O_RDWR` на каталог (запись в каталог запрещена);
- `open(O_CREAT)` — указан существующий каталог и `O_CREAT` без `O_EXCL`… (для `O_EXCL` будет `EEXIST`);
- `read()`/`write()` на каталог, открытый на чтение через `O_RDONLY` в старых ядрах (обычно `EISDIR` для write);
- `execve()` на каталог.

## Похожие коды

- `ENOTDIR` — компонента пути не каталог
- `EACCES` — нет прав
- `EEXIST` — файл уже существует (`O_CREAT|O_EXCL` на каталог)

## Источники

- POSIX.1-2024, раздел `errno.h`
