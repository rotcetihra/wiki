## Определение

```c
#include <errno.h>

#define EFAULT 14 // "Bad address"
```

## Описание

«Недопустимый адрес»: указатель, переданный системному вызову, указывает на недопустимую область памяти (не принадлежит процессу или не отображает страницу). POSIX-код. Часто — признак ошибки программирования (испорченный указатель).

## Когда возникает

- `read()`/`write()`/`sendto()` с буфером вне адресного пространства процесса;
- `ioctl()`/`fcntl()` с некорректным указателем на аргумент;
- стек или структура аргументов не отображены (например, после `setrlimit(RLIMIT_STACK)`).

## Похожие коды

- `SEGV` — это сигнал, не errno; при реальном обращении к недопустимому адресу процесс получает `SIGSEGV`, `EFAULT` возвращают только проверенные системой вызовы
- `EINVAL` — неверное значение аргумента
