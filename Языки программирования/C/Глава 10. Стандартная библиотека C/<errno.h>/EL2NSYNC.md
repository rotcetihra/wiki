## Определение

```c
#include <errno.h>

#define EL2NSYNC 45 // "Level 2 not synchronized"
```

## Описание

«Уровень 2 не синхронизирован» — код STREAMS System V. На Linux сохраняется для совместимости, не применяется. Не входит в POSIX.

## Когда возникает

- исторически — STREAMS: рассинхронизация уровня 2; на современных Linux не возникает.

## Похожие коды

- `EL2HLT` — уровень 2 остановлен
- `EL3HLT` — уровень 3 остановлен

## Источники

- Linux: `asm-generic/errno.h`
