## Определение

```c
#include <errno.h>

#define EALREADY 114 // "Operation already in progress"
```

## Описание

«Операция уже выполняется». Возвращается неблокирующим `connect()`, когда соединение уже устанавливается (повторный вызов до завершения). Также `send()`/`recv()` при установлении соединения в фоне. POSIX (XSI).

## Когда возникает

- повторный неблокирующий `connect()` на том же сокете;
- `getsockopt(SO_ERROR)` обычно возвращает 0/EISCONN в завершённом случае.

## Похожие коды

- `EINPROGRESS` — установление соединения началось (первый вызов)
- `EISCONN` — сокет уже соединён
- `ECONNREFUSED` — соединение отклонено
