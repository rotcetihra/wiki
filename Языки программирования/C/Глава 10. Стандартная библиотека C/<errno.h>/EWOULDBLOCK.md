## Определение

```c
#include <errno.h>

#define EWOULDBLOCK EAGAIN // "Operation would block" (11)
```

## Описание

Дубликат `EAGAIN` в glibc/Linux (`#define EWOULDBLOCK EAGAIN`, значение 11). Имя исторически означает «операция заблокировалась бы» — используется с неблокирующими дескрипторами. POSIX допускает, чтобы `EWOULDBLOCK` имел то же значение, что и `EAGAIN` (обязательное требование). Программы должны проверять оба имени для переносимости.

## Когда возникает

- те же ситуации, что и для [[Языки программирования/C/Глава 10. Стандартная библиотека C/<errno.h>/EAGAIN|EAGAIN]]: неблокирующие `read()`/`write()`/`accept()`/`connect()` без готовности данных.

## Похожие коды

- `EAGAIN` — основное имя кода 11 на Linux
- `EINTR` — прервано сигналом
