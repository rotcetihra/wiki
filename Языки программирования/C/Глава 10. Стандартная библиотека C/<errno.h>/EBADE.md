## Определение

```c
#include <errno.h>

#define EBADE 52 // "Invalid exchange"
```

## Описание

«Недопустимый обмен» — код из серии «exchange» (XENIX RFS): ошибка механизма обмена сообщениями. На Linux существует для совместимости с другими Unix-системами; в современных программах практически не встречается. Не входит в POSIX.

## Когда возникает

- на современных Linux — только при использовании исторических протоколов RFS/XENIX (фактически не возникает).

## Похожие коды

- `EBADR` — недопустимый дескриптор запроса
- `EXFULL` — очередь обмена полна
- `EBADRQC` — недопустимый код запроса
- `EBADSLT` — недопустимый слот
