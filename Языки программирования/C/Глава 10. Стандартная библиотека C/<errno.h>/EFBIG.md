## Определение

```c
#include <errno.h>

#define EFBIG 27 // "File too large"
```

## Описание

«Файл слишком большой»: размер файла превысил допустимый максимум (ограничение ФС или `RLIMIT_FSIZE`). POSIX-код.

## Когда возникает

- запись за пределы максимального размера файла ФС (например, 2 ГБ в старых ФС);
- `write()`/`truncate()` при достижении `RLIMIT_FSIZE` (тогда также подаётся сигнал `SIGXFSZ`).

## Похожие коды

- `ENOSPC` — нет места для данных
- `EDQUOT` — превышена квота
- `EOVERFLOW` — значение не помещается в тип данных

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno-base.h`, man-страница `write(2)`
