## Определение

```c
#include <errno.h>

#define ENOSYS 38 // "Function not implemented"
```

## Описание

«Функция не реализована»: системный вызов не реализован ядром или запрошенная возможность отсутствует (например, ФС не поддерживает операцию). POSIX-код.

## Когда возникает

- системный вызов отсутствует в ядре (безопасный вызов неизвестного номера);
- `mount()` с возможностями, не поддерживаемыми ФС (например, `O_TMPFILE` без поддержки ФС);
- «stub»-вызовы для неподдерживаемых архитектур.

## Похожие коды

- `EOPNOTSUPP` — операция не поддерживается (объект есть, возможность нет)
- `EINVAL` — неверный аргумент

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno.h`, man-страница `syscall(2)`
