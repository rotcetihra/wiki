## Определение

```c
#include <errno.h>

#define ENFILE 23 // "File table overflow"
```

## Описание

«Переполнена системная таблица файлов»: исчерпан глобальный лимит на открытые файлы в ядре (в отличие от `EMFILE` — лимит одного процесса). POSIX-код.

## Когда возникает

- `open()`/`socket()` при исчерпании системного лимита (fs.file-max);
- массовое открытие файлов множеством процессов.

## Похожие коды

- `EMFILE` — исчерпан лимит процесса
- `ENOMEM` — нехватка памяти ядра

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno-base.h`, man-страница `open(2)`
