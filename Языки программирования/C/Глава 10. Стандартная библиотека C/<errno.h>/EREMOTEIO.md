## Определение

```c
#include <errno.h>

#define EREMOTEIO 121 // "Remote I/O error"
```

## Описание

«Ошибка удалённого ввода-вывода»: сбой операций ввода-вывода с удалённым объектом (NFS и аналоги). Linux-специфичный код (добавлен для Linux/учёта ошибок сетевых ФС). Не входит в POSIX.

## Когда возникает

- NFS/CIFS: ошибка сервера, таймаут, повреждение данных на стороне сервера;
- сетевые ФС при недоступности сервера в момент операции.

## Похожие коды

- `EIO` — локальная ошибка ввода-вывода
- `ENOLINK` — связь разорвана
- `EHOSTUNREACH` — хост недостижим

## Источники

- Linux: `asm-generic/errno.h`, man-страница `nfs(5)`
