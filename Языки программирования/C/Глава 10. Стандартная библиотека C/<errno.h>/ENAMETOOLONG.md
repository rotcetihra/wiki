## Определение

```c
#include <errno.h>

#define ENAMETOOLONG 36 // "File name too long"
```

## Описание

«Имя файла слишком длинное»: компонента пути длиннее `NAME_MAX` (Linux: 255 байт) или весь путь длиннее `PATH_MAX` (4096). POSIX-код.

## Когда возникает

- `open()`/`stat()`/`rename()` с длинным именем компоненты;
- полный путь длиннее `PATH_MAX`;
- `getcwd()` в глубоких каталогах.

## Похожие коды

- `ELOOP` — слишком много уровней ссылок
- `ENOENT` — компонента пути отсутствует

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno.h`, man-страница `path_resolution(7)`
