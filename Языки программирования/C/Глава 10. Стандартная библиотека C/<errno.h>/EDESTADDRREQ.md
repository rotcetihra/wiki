## Определение

```c
#include <errno.h>

#define EDESTADDRREQ 89 // "Destination address required"
```

## Описание

«Требуется адрес назначения»: сокетный вызов, требующий явный адрес получателя, вызван без него. POSIX (XSI). Характерна для дейтаграммных сокетов, не подключённых через `connect()`.

## Когда возникает

- `sendto()`/`sendmsg()` на неподключённом сокете без указания адреса (или с нулевым адресом);
- `bind()` с пустым адресом в некоторых реализациях.

## Похожие коды

- `EISCONN` — сокет уже соединён (обратная ситуация для connect)
- `EINVAL` — неверный аргумент
