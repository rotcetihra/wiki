## Определение

```c
#include <errno.h>

#define EDOTDOT 73 // "RFS specific error"
```

## Описание

«Специфическая ошибка RFS»: исторический код Remote File Sharing, связанный с операциями над каталогами (`..`). На Linux существует для совместимости; не возникает в современных программах. Не входит в POSIX.

## Когда возникает

- исторически — некорректная операция с `..`-записями в RFS; на современных Linux не встречается.

## Похожие коды

- `EADV` — ошибка анонсирования (RFS)
- `ESRMNT` — ошибка srmount (RFS)
