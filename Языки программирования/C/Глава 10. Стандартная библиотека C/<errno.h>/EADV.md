## Определение

```c
#include <errno.h>

#define EADV 68 // "Advertise error"
```

## Описание

«Ошибка анонсирования» — код из набора ошибок Remote File Sharing (RFS) семейства Unix, возвращаемый при сбое механизма анонсирования ресурсов в распределённой файловой системе. На Linux существует для совместимости; в современных системах не используется. Не входит в POSIX.

## Когда возникает

- в системах с RFS — ошибка протокола анонсирования; на современных Linux не возникает.

## Похожие коды

- `ESRMNT` — ошибка srmount (RFS)
- `EDOTDOT` — специфическая ошибка RFS
- `ECOMM` — ошибка связи (RFS)
