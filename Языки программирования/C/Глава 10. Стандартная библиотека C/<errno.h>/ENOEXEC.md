## Определение

```c
#include <errno.h>

#define ENOEXEC 8 // "Exec format error"
```

## Описание

«Ошибка формата исполняемого файла»: файл не является корректным исполняемым для данной архитектуры (неверный магический номер/формат). POSIX-код. Оболочки используют его, чтобы понять, что файл — скрипт (тогда интерпретируют по шебанг-строке).

## Когда возникает

- `execve()` на файле с неподдерживаемым/повреждённым форматом;
- запуск бинарника другой архитектуры без подсистемы эмуляции;
- запуск скрипта без интерпретатора в шебанг-строке.

## Похожие коды

- `ELIBBAD` — повреждённая библиотека (ELF)
- `EACCES` — файл не исполняемый
- `ENOENT` — файл не найден
