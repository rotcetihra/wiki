## Определение

```c
#include <errno.h>

#define ENOANO 55 // "No anode"
```

## Описание

«Нет anode» — исторический код XENIX (anode — таблица анонимных узлов). На Linux сохраняется для совместимости, не используется. Не входит в POSIX.

## Когда возникает

- исторически — XENIX: исчерпание таблицы узлов; на современных Linux не возникает.

## Похожие коды

- `EXFULL` — очередь обмена полна (XENIX)
- `EBADE` — недопустимый обмен (XENIX)
