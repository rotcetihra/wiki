## Определение

```c
#include <errno.h>

#define ESOCKTNOSUPPORT 94 // "Socket type not supported"
```

## Описание

«Тип сокета не поддерживается»: запрошенный тип сокета (`SOCK_RAW`, `SOCK_PACKET`, `SOCK_SEQPACKET`...) не поддерживается семейством. POSIX (XSI).

## Когда возникает

- `socket()` с типом, недоступным для домена (например, `SOCK_RAW` в некоторых семействах без привилегий или поддержки);
- неподдерживаемые типы при создании сокетов.

## Похожие коды

- `EPROTONOSUPPORT` — протокол не поддерживается
- `EAFNOSUPPORT` — семейство адресов не поддерживается
- `EINVAL` — неверный тип
