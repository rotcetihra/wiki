## Определение

```c
#include <errno.h>

#define ESRCH 3 // "No such process"
```

## Описание

«Нет такого процесса»: ID процесса/потока, указанный в вызове, не существует. POSIX-код.

## Когда возникает

- `kill()` с несуществующим PID (классика — «kill: no such process»);
- `waitpid()`/`sched_*`/`setpgid()`/`getpriority()` с чужим или несуществующим процессом;
- операции с группами процессов.

## Похожие коды

- `ECHILD` — нет дочерних процессов
- `EINVAL` — неверный аргумент (например, отрицательный pid в waitpid)
