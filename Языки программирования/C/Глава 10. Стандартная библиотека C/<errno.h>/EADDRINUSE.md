## Определение

```c
#include <errno.h>

#define EADDRINUSE 98 // "Address already in use"
```

## Описание

«Адрес уже занят». Возвращается сокетными вызовами, когда локальный адрес (или порт) уже используется другим сокетом. Типична для серверов: попытка `bind()` повторно занять порт без флага `SO_REUSEADDR`. Не входит в стандарт C; определён в POSIX (XSI).

## Когда возникает

- `bind()`: порт уже слушается другим процессом;
- `connect()`: невозможно назначить локальный адрес;
- `bind()` на UNIX-сокет: файл сокета уже существует.

## Похожие коды

- `EADDRNOTAVAIL` — адрес не назначен интерфейсу
- `EAFNOSUPPORT` — семейство адресов не поддерживается
