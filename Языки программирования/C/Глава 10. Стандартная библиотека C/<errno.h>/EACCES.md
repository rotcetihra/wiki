## Определение

```c
#include <errno.h>

#define EACCES 13 // "Permission denied"
```

## Описание

«Доступ запрещён» — самый частый код ошибки: попытка выполнить операцию, на которую у процесса нет прав (проверка прав доступа к файлу по битам mode, `chmod(2)` и т. п.). Отличается от `EPERM`: `EACCES` — не хватает обычных прав доступа, `EPERM` — не хватает привилегий (root/CAP_*). Определён в POSIX.

## Когда возникает

- `open()`/`read()`/`write()` на файл без права чтения/записи;
- `execve()` без права выполнения (нет `x`);
- переход по пути через каталог без права `x`;
- запись в каталог без права `w`.

## Похожие коды

- `EPERM` — операция запрещена (нужны привилегии)
- `EROFS` — файловая система только для чтения
- `ETXTBSY` — файл исполняется
