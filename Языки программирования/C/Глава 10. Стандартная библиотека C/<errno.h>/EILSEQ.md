## Определение

```c
#include <errno.h>

#define EILSEQ 84 // "Invalid or incomplete multibyte or wide character"
```

## Описание

«Недопустимая или неполная многобайтовая (широкая) последовательность». Один из трёх кодов, определяемых стандартом C (наряду с `EDOM` и `ERANGE`): в стандарте действительно встречается код EILSEQ, хотя в POSIX-системах его значение 84. Устанавливается функциями, разбирающими последовательности байт, при нарушении кодировки (UTF-8 и др.).

## Когда возникает

- `mbrtowc()`/`mbtowc()` — недопустимая последовательность байт;
- `wcstombs()`/`wcrtomb()` — широкий символ без представления в текущей кодировке;
- `iconv()` — входные байты не соответствуют кодировке;
- функции `regex`/`strcoll` при некорректной последовательности в локали.

## Похожие коды

- `EDOM` — аргумент вне области определения (математика)
- `ERANGE` — результат вне диапазона
