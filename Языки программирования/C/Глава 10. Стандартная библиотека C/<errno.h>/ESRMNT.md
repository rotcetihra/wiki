## Определение

```c
#include <errno.h>

#define ESRMNT 69 // "Srmount error"
```

## Описание

«Ошибка srmount» — исторический код RFS (srmount — системный вызов монтирования удалённых ресурсов). На Linux существует для совместимости, не используется. Не входит в POSIX.

## Когда возникает

- исторически — RFS: сбой монтирования удалённого ресурса; на современных Linux не возникает.

## Похожие коды

- `EADV` — ошибка анонсирования (RFS)
- `EDOTDOT` — специфическая ошибка RFS
