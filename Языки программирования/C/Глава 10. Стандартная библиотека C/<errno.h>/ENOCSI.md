## Определение

```c
#include <errno.h>

#define ENOCSI 50 // "No CSI structure available"
```

## Описание

«Нет структуры CSI» — исторический код STREAMS (CSI — Common Stream Interface). На Linux существует для совместимости, не используется. Не входит в POSIX.

## Когда возникает

- исторически — STREAMS: отсутствие структуры CSI; на современных Linux не возникает.

## Похожие коды

- `ENOSTR` — устройство не поток (STREAMS)
- `ENODATA` — нет данных (STREAMS)

## Источники
