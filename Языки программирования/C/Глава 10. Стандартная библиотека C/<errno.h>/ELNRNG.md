## Определение

```c
#include <errno.h>

#define ELNRNG 48 // "Link number out of range"
```

## Описание

«Номер звена вне диапазона» — код STREAMS System V. На Linux существует для совместимости, не используется. Не входит в POSIX.

## Когда возникает

- исторически — STREAMS: номер звена вне допустимого диапазона; на современных Linux не возникает.

## Похожие коды

- `ECHRNG` — номер канала вне диапазона (STREAMS)
- `EL2NSYNC` — уровень 2 не синхронизирован

## Источники

- Linux: `asm-generic/errno.h`
