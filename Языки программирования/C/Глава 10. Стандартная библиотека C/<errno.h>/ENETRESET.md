## Определение

```c
#include <errno.h>

#define ENETRESET 102 // "Network dropped connection because of reset"
```

## Описание

«Сеть разорвала соединение из-за сброса»: сетевая подсистема сбросила соединение (например, при перезапуске стека или повторном подключении интерфейса). POSIX (XSI).

## Когда возникает

- перезапуск сетевого стека с активными соединениями;
- смена конфигурации интерфейса, приводящая к сбросу состояния соединения.

## Похожие коды

- `ECONNRESET` — партнёр сбросил соединение
- `ENETDOWN` — сеть не работает
- `ETIMEDOUT` — таймаут
