## Определение

```c
#include <errno.h>

#define ESTRPIPE 86 // "Streams pipe error"
```

## Описание

«Ошибка потока STREAMS» — код STREAMS System V: сбой чтения/записи в потоке. На Linux существует для совместимости, не используется (STREAMS отсутствует). Не входит в POSIX.

## Когда возникает

- исторически — STREAMS: ошибка pipe-потока; на современных Linux не возникает.

## Похожие коды

- `EPIPE` — разорванный канал
- `ENOSTR` — устройство не поток (STREAMS)

## Источники

- Linux: `asm-generic/errno.h`
