## Определение

```c
#include <errno.h>

#define EINTR 4 // "Interrupted system call"
```

## Описание

«Системный вызов прерван». Блокирующий системный вызов возвращен досрочно из-за прибытия сигнала, обрабатываемого без флага `SA_RESTART`. POSIX-код. Правильная реакция программы — повторный вызов (см. циклы вокруг `read()`/`write()`), если сигнал не означает завершение.

## Когда возникает

- `read()`/`write()`/`accept()`/`wait()` — пришёл сигнал (SIGINT, SIGTERM...);
- `nanosleep()`/`sleep()` — прерван сигналом;
- `open()`/`poll()` с длительным ожиданием.

## Похожие коды

- `EAGAIN` — ресурс временно недоступен
- `ECANCELED` — операция отменена асинхронно
