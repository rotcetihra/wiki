## Определение

```c
#include <errno.h>

#define EBADR 53 // "Invalid request descriptor"
```

## Описание

«Недопустимый дескриптор запроса» — код серии RFS/XENIX, связанный с механизмом «обмена» (exchange): дескриптор запроса не существует или недопустим. На Linux — только для обратной совместимости с историческими системами. Не входит в POSIX.

## Когда возникает

- на современных Linux не возникает; исторически — операции RFS/XENIX с некорректным дескриптором запроса.

## Похожие коды

- `EBADE` — недопустимый обмен
- `EBADRQC` — недопустимый код запроса
- `EBADSLT` — недопустимый слот
