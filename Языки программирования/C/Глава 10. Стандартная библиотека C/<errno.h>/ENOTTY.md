## Определение

```c
#include <errno.h>

#define ENOTTY 25 // "Not a typewriter" (ядро), "Inappropriate ioctl for device" (glibc)
```

## Описание

«Не терминал» / «неподходящий ioctl для устройства»: `ioctl()` с командой, не поддерживаемой устройством, или операция, требующая терминального устройства, над не-терминалом (например, `tcgetattr()`). POSIX-код.

## Когда возникает

- `ioctl()` с неизвестной командой (самый частый случай);
- `tcgetattr()`/`tcsetattr()`/`isatty()` на файле без терминала;
- программы на псевдотерминалах при попытке терминальных функций на обычном дескрипторе.

## Похожие коды

- `ENODEV` — нет устройства
- `EINVAL` — неверный аргумент
- `EBADF` — неверный дескриптор

## Источники

- POSIX.1-2024, раздел `errno.h`
- Linux: `asm-generic/errno-base.h`, man-страница `ioctl(2)`
