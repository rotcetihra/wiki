## Определение

```c
#include <errno.h>

#define EINPROGRESS 115 // "Operation now in progress"
```

## Описание

«Операция уже выполняется»: асинхронная операция началась и продолжит выполняться в фоне. POSIX (XSI). Ключевой код неблокирующего `connect()`: первый вызов возвращает `EINPROGRESS`, дальнейший прогресс отслеживается через `poll()`/`select()` и `getsockopt(SO_ERROR)`.

## Когда возникает

- неблокирующий `connect()` — соединение устанавливается в фоне;
- `send()` с `MSG_NONBLOCK` и неготовностью;
- системные вызовы с `O_NONBLOCK`, поддерживающие фоновое выполнение (например, `io_uring`).

## Похожие коды

- `EALREADY` — операция уже выполняется (повторный вызов)
- `EAGAIN` — данные ещё не готовы (повторите)
- `EISCONN` — сокет уже соединён
