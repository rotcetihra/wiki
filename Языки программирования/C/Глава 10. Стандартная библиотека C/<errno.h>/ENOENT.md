## Определение

```c
#include <errno.h>

#define ENOENT 2 // "No such file or directory"
```

## Описание

«Нет такого файла или каталога» — самый частый код ошибки при работе с путями: компонента пути не существует (включая разорванную символическую ссылку). POSIX-код.

## Когда возникает

- `open()`/`stat()`/`unlink()`/`access()` на несуществующий путь;
- `execve()` — исполняемый файл не найден;
- `chdir()` на несуществующий каталог;
- `getaddrinfo()` в некоторых реализациях для несуществующих узлов (через DNS).

## Похожие коды

- `ENOTDIR` — компонента пути не каталог
- `ELOOP` — слишком много уровней символьных ссылок
- `EACCES` — нет прав на компоненту пути

## Источники
