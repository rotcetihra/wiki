## Определение

```c
#include <errno.h>

#define EAFNOSUPPORT 97 // "Address family not supported by protocol"
```

## Описание

«Семейство адресов не поддерживается». Сокетный код: запрошенное семейство адресов (`AF_INET`, `AF_INET6`, `AF_UNIX`...) не поддерживается протоколом или системой. POSIX (XSI).

## Когда возникает

- `socket()` с неизвестным/неподдерживаемым семейством;
- `bind()`/`connect()` с адресом чужого семейства для данного сокета;
- ядро без поддержки `CONFIG_IPV6` при попытке `AF_INET6`.

## Похожие коды

- `EPROTONOSUPPORT` — не поддерживается протокол
- `ESOCKTNOSUPPORT` — не поддерживается тип сокета
- `EPFNOSUPPORT` — не поддерживается семейство протоколов

## Источники
