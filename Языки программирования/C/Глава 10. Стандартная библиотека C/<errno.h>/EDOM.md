## Определение

```c
#include <errno.h>

#define EDOM 33 // "Math argument out of domain of func"
```

## Описание

«Аргумент вне области определения функции». Один из трёх кодов, определяемых самим стандартом C (наряду с `EILSEQ` и `ERANGE`), и единственный из них, которому стандарт предписывает положительное значение, определяемое реализацией (на Linux = 33). Устанавливается математическими функциями при недопустимом аргументе: `sqrt(-1)`, `log(0)`, `acos(2)` и т. п.

## Когда возникает

- `sqrt()`, `log()`/`log10()`, `pow()` (с отрицательным основанием и нецелым показателем), `asin()`/`acos()` вне `[-1, 1]`, `fmod(x, 0)` и другие функции `<math.h>`;
- функции работы с окружением `strtod()` при пустой строке — нет, там 0 без errno; классические: `<math.h>`.

## Похожие коды

- `ERANGE` — результат вне представимого диапазона
- `EILSEQ` — недопустимая последовательность байт
