## Определение

```c
#include <errno.h>

#define EHWPOISON 133 // "Memory page has hardware error"
```

## Описание

«Страница памяти с аппаратной ошибкой»: доступ к странице, помеченной ядром как повреждённая (poisoned) из-за аппаратной ошибки памяти (ECC). Linux-специфичный код (добавлен для hwpoison-инфраструктуры).

## Когда возникает

- обращение к странице с аппаратной ошибкой, выявленной ECC/едeр-механизмами (`madvise(MADV_HWPOISON)` или реальная ошибка памяти).

## Похожие коды

- `EFAULT` — недопустимый адрес
- `ENOMEM` — нехватка памяти
- `EIO` — ошибка ввода-вывода

## Источники

- Linux: `asm-generic/errno.h`, man-страница `madvise(2)`
