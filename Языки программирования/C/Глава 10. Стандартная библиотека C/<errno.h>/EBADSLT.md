## Определение

```c
#include <errno.h>

#define EBADSLT 57 // "Invalid slot"
```

## Описание

«Недопустимый слот» — код серии RFS/XENIX. На Linux сохраняется для совместимости, практически не используется. Не входит в POSIX.

## Когда возникает

- исторически — RFS/XENIX: ссылка на несуществующий слот таблицы; на современных Linux не возникает.

## Похожие коды

- `EBADE` — недопустимый обмен
- `EBADR` — недопустимый дескриптор запроса
- `EBADRQC` — недопустимый код запроса
