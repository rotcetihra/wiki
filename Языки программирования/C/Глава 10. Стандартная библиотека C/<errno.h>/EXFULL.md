## Определение

```c
#include <errno.h>

#define EXFULL 54 // "Exchange full"
```

## Описание

«Очередь обмена полна» — код серии XENIX «exchange». На Linux существует для совместимости, не используется. Не входит в POSIX.

## Когда возникает

- исторически — XENIX: исчерпание очереди обмена; на современных Linux не возникает.

## Похожие коды

- `EBADE` — недопустимый обмен (XENIX)
- `ENOANO` — нет anode (XENIX)

## Источники

- Linux: `asm-generic/errno.h`
