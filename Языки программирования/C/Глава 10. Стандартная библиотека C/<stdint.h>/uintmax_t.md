## Определение

```c
#include <stdint.h>

typedef uintmax_t;
```

## Описание

Тип `uintmax_t` — uintmax_t. Гарантирует точное количество бит в знаковом/беззнаковом целочисленном представлении.

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    uintmax_t value = 42;
    printf("Размер: %zu бит\n", sizeof(value) * 8);
    printf("Минимум: %jd\n", (long long)UINTMAX_T_MIN);
    printf("Максимум: %jd\n", (long long)UINTMAX_T_MAX);
    printf("Значение: %jd\n", (long long)value);
    return 0;
}
```

## Лимиты

| Макрос | Описание |
|---|---|
| `UINTMAX_T_MIN` | Минимальное значение типа uintmax_t |
| `UINTMAX_T_MAX` | Максимальное значение типа uintmax_t |

| Преимущество | Недостаток |
