## Определение

```c
#include <stdint.h>

#define UINTMAX_C(value) /* целочисленный литерал */
```

## Описание

Макрос `UINTMAX_C` создаёт целочисленный литерал типа `uintmax_t`. Используется для формирования констант, которые гарантированно имеют тип `uintmax_t` независимо от размера целочисленного литерала.

Параметр `value` — целочисленное выражение, которое должно быть представимо в типе `uintmax_t`.

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    uintmax_t val1 = UINTMAX_C(42);
    uintmax_t val2 = UINTMAX_C(0xFF);
    
    printf("val1 = %jd\n", (long long)val1);
    printf("val2 = %jd\n", (long long)val2);
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует тип литерала | Значение должно быть представимо в типе |
| Портативен между платформами | Только для целочисленных констант |
| Стандартная часть C99/C23 | — |
