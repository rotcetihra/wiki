## Определение

```c
#include <stdint.h>

#define INT_LEAST16_MIN /* целочисленная константа */
```

## Описание

Макрос `INT_LEAST16_MIN` — минимальное значение типа `int_least16_t`. Представляет собой целочисленную константу, вычисляемую на этапе компиляции.

Значение определяется реализацией в соответствии со стандартом C23 (ISO/IEC 9899:2024).

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    printf("INT_LEAST16_MIN = %jd\n", (long long)INT_LEAST16_MIN);
    printf("Тип: int_least16_t\n");
    return 0;
}
```
