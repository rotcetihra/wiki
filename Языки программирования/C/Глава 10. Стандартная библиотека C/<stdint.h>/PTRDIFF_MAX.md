## Определение

```c
#include <stdint.h>

#define PTRDIFF_MAX /* целочисленная константа */
```

## Описание

Макрос `PTRDIFF_MAX` — максимальное значение типа `ptrdiff_t`. Представляет собой целочисленную константу, вычисляемую на этапе компиляции.

Значение определяется реализацией в соответствии со стандартом C23 (ISO/IEC 9899:2024).

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    printf("PTRDIFF_MAX = %jd\n", (long long)PTRDIFF_MAX);
    printf("Тип: ptrdiff_t\n");
    return 0;
}
```

| Преимущество | Недостаток |
