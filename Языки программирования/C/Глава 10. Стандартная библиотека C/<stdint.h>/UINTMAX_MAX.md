## Определение

```c
#include <stdint.h>

#define UINTMAX_MAX /* целочисленная константа */
```

## Описание

Макрос `UINTMAX_MAX` — максимальное значение типа `uintmax_t`. Представляет собой целочисленную константу, вычисляемую на этапе компиляции.

Значение определяется реализацией в соответствии со стандартом C23 (ISO/IEC 9899:2024).

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    printf("UINTMAX_MAX = %jd\n", (long long)UINTMAX_MAX);
    printf("Тип: uintmax_t\n");
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Вычисляется на этапе компиляции | Значение зависит от платформы |
| Гарантирует корректность для типа | Нельзя использовать в `#if` |
| Стандартная часть C99/C23 | — |

## Похожие макросы

- Все макросы `*_MIN` и `*_MAX` из `<stdint.h>`
- Макросы `<limits.h>` для стандартных целочисленных типов
