#include <stdint.h>

## Описание

Тип `int_fast16_t` — int_fast16_t. Гарантирует точное количество бит в знаковом/беззнаковом целочисленном представлении.

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    int_fast16_t value = 42;
    printf("Размер: %zu бит\n", sizeof(value) * 8);
    printf("Минимум: %jd\n", (long long)INT_FAST16_T_MIN);
    printf("Максимум: %jd\n", (long long)INT_FAST16_T_MAX);
    printf("Значение: %jd\n", (long long)value);
    return 0;
}
```

## Лимиты
