## Определение

```c
#include <stdint.h>

#define UINT8_C(value) /* целочисленный литерал */
```

## Описание

Макрос `UINT8_C` создаёт целочисленный литерал типа `uint_least8_t`. Используется для формирования констант, которые гарантированно имеют тип `uint_least8_t` независимо от размера целочисленного литерала.

Параметр `value` — целочисленное выражение, которое должно быть представимо в типе `uint_least8_t`.

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    uint_least8_t val1 = UINT8_C(42);
    uint_least8_t val2 = UINT8_C(0xFF);
    
    printf("val1 = %jd\n", (long long)val1);
    printf("val2 = %jd\n", (long long)val2);
    
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|
| Гарантирует тип литерала | Значение должно быть представимо в типе |
| Портативен между платформами | Только для целочисленных констант |
