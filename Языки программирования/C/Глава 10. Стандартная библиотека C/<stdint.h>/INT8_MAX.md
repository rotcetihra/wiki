## Определение

```c
#include <stdint.h>

#define INT8_MAX /* целочисленная константа */
```

## Описание

Макрос `INT8_MAX` — максимальное значение типа `int8_t`. Представляет собой целочисленную константу, вычисляемую на этапе компиляции.

Значение определяется реализацией в соответствии со стандартом C23 (ISO/IEC 9899:2024).

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    printf("INT8_MAX = %jd\n", (long long)INT8_MAX);
    printf("Тип: int8_t\n");
    return 0;
}
```

## Плюсы и минусы

| Преимущество | Недостаток |
|---|---|

| Гарантирует корректность для типа | Нельзя использовать в `#if` |
