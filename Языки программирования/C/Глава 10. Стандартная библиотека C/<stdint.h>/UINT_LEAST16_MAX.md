## Определение

```c
#include <stdint.h>

#define UINT_LEAST16_MAX /* целочисленная константа */
```

## Описание

Макрос `UINT_LEAST16_MAX` — максимальное значение типа `uint_least16_t`. Представляет собой целочисленную константу, вычисляемую на этапе компиляции.

Значение определяется реализацией в соответствии со стандартом C23 (ISO/IEC 9899:2024).

## Пример

```c
#include <stdio.h>
#include <stdint.h>

int main(void)
{
    printf("UINT_LEAST16_MAX = %jd\n", (long long)UINT_LEAST16_MAX);
    printf("Тип: uint_least16_t\n");
    return 0;
}
```
