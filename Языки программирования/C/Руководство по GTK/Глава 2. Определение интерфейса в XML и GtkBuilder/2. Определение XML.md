Файлы определения пользовательского интерфейса всегда используют кодировку UTF-8. Обычно в начало определения интерфейса добавляется стандартный элемент `<xml>` с указанием версии xml и кодировкой utf-8:

```xml
<?xml version="1.0" encoding="UTF-8"?>
```

Элемент верхнего уровня — `<interface>`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
 Здесь располагается определение интерфейса
</interface>
```

## Требования к библиотеке

С помощью элемента `<requires>` можно опционально задать требования к применяемой библиотеке. Атрибут `lib` этого элемента указывает рассматриваемую библиотеку виджетов (в настоящее время единственным поддерживаемым значением является `"gtk"`), а атрибут `version` указывает на целевую версию в форме `major.minor`. GtkBuilder выдаст ошибку, если требования к версии не будут выполнены. Например:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
    <requires lib="gtk" version="4.0" />
</interface>
```

## Объекты

Пользовательский интерфейс состоит из объектов, например, окна, кнопок, текстовых полей и других визуальных компонентов. Для определения объекта в XML фреймворк GTK использует элемент `<object>`. Объекты определяются как дочерние элементы внутри элемента `<interface>`. Для элемента `<object>` определены два важных атрибута:

- `class`: указывает на тип объекта. Например, окно представляет тип `GtkWindow`. Соответственно атрибут `class` объекта, который представляет окно, будет иметь это значение.
- `id`: произвольный идентификатор объекта, который соответствует имени переменной в коде на Си. Через идентификатор можно ссылать на объект. Стоит отметить, что GTK резервирует идентификаторы, начинающиеся и заканчивающиеся на `___` (три последовательных подчеркивания) для своих собственных целей.

Пример объекта, который представляет окно приложения:

```xml
<object class="GtkWindow" id="window">
<!-- здесь располагается содержимое окна -->
</object>
```

Таким образом, мы определили объект с именем `window`, который имеет тип `GtkWindow`.

## Свойства

Различные характеристика объекта доступны через его свойства. Для определения свойств объекта в XML применяется элемент `<property>`:

```xml
<property name="имя_свойства">значение_свойства</property>
```

С помощью атрибута `name` задается имя свойства, а внутри элемента `<property>` помещается значение.

Как узнать, какие свойства есть у конкретного визуального компонента? Для этого можно обратиться к документации, где для всех типов указываются их свойства. Но часто можно по имени функций узнать имя соответствующих свойств. Например, нам надо установить заголовок для окна. Какое свойство использовать? Если мы посмотрим на функцию, которая устанавливает заголовок — `gtk_window_set_title`, то мы можем увидеть следующий паттерн:

```
имя_типа_set_имя_свойства
```

То есть в нашем случае это свойство `title`. Однако этот паттерн не всегда соблюдается. Например, нам также надо установить размер окна. Соответствующая функция называется `gtk_window_set_default_size`, однако она устанавливает два свойства — `default-width` (ширину) и `default-height` (высоту). Таким образом, определение нашего окна будет выглядеть следующим образом:

```xml
<object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">300</property>
    <property name="default-height">250</property>
</object>
```

Стоит отметить, что в примере выше значения свойств задаются как обычный текст. Дело в том, что GtkBuilder может анализировать текстовые представления для наиболее распространенных типов свойств:

- символы;
- строки;
- целые числа;
- числа с плавающей точкой;
- логические значения (строки типа `"TRUE"`, `"t"`, `"yes"`, `"y"`, `"1"` интерпретируются как истинные значения, строки типа `"FALSE"`, `"f"`, `"no"`, `"n"`, `"0"` интерпретируются как ложные значения);
- списки строк (разделенные символом перевода строки `\n`);
- типы перечислений (могут быть указаны их полным идентификатором C, их кратким именем, используемым при регистрации типа перечисления или их целочисленным значением);
- типы флагов (могут быть указаны их идентификатором C или кратким именем, опционально объединенным с `|` для побитового ИЛИ, или одним целочисленным значением, например, `"GTK_INPUT_HINT_EMOJI|GTK_INPUT_HINT_LOWERCASE"` или `"emoji|lowercase"` или `520`);
- цвета (в формате, понимаемом `gdk_rgba_parse()`);
- `GFile` (файлы, например, в виде файлового пути).

В итоге типовое определение интерфейса простейшего окна будет выглядеть следующим образом:

```xml
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">300</property>
    <property name="default-height">250</property>
  </object>
</interface>
```

## Вложенные объекты

Посмотрим на определение чуть более сложных интерфейсов. Например, нам надо вывести простейший текст в окне. Для вывода текста можно использовать встроенный тип `GtkLabel`. Для создания `GtkLabel` применяется функция-конструктор `gtk_label_new()`, в которую передается отображаемый текст.

После создания объекта `GtkLabel`, нам надо добавить его в окно. Для этого GTK предоставляет функцию `gtk_window_set_child()`, в которую передается окно и добавляемый в него объект. Возьмем простейший пример:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    
    // создаем метку 
    GtkWidget *label = gtk_label_new ("Hello World");
    // добавляем метку в окно
    gtk_window_set_child (GTK_WINDOW (window), label);

    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

Мы получаем следующее окно с текстом по центру.

Из названия применяемой функции `gtk_window_set_child()` можно догадаться, что в данном случае устанавливается свойство `child` у окна (объекта `GtkWindow`). Соответственно мы можем использовать это свойство и в XML. Однако в данном случае мы имеем дело не просто текстом или числом, а сложным объектом `GtkLabel`. Другая сложность состоит, что также надо задать текст этого объекта. Для этого определим файл `builder.ui` со следующим кодом:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">250</property>
    <property name="default-height">200</property>
    <property name="child">
       <object class="GtkLabel" id="label">
          <property name="label">Hello Work</property>
        </object>
    </property>
  </object>
</interface>
```

Итак, для задания содержимого окна — свойства `child` применяем элемент:

```xml
<property name="child">
```

Значение свойства `child` определяется внутри данного элемента:

```xml
<object class="GtkLabel" id="label">
    <property name="label">Hello Work</property>
</object>
```

У `GtkLabel` текст хранится в свойстве `label`, поэтому устанавливаем это свойство.

Стоит отметить, что для установки текста в коде Си для типа `GtkLabel` применяется функция `gtk_label_set_text()`, тем не менее соответствующее свойство называется не `"text"`, а `"label"`.

В коде Си мы можем загрузить и использовать это определение интерфейса следующим образом:

```c
#include <gtk/gtk.h>

static void app_activate (GtkApplication *app, gpointer *user_data) {

    // Создаем объект GtkBuilder и загружаем определение интерфейса из файла builder.ui
    GtkBuilder *builder = gtk_builder_new_from_file("builder.ui");
    // получаем объект GtkWindow по идентификатору "window"
    GObject* window = gtk_builder_get_object (builder, "window");
    // GtkBuilder больше не нужен, удаляем его
    g_object_unref (builder);
    // устанавливаем окно приложения
    gtk_window_set_application (GTK_WINDOW (window), app);
    // отображаем окно
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

## Элемент child

Стоит отметить, что для объектов, которые имеют свойство `child`, вместо полного определения свойства:

```xml
<property name="child">
```

могут использовать элемент `<child>`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">250</property>
    <property name="default-height">200</property>
    <child>
       <object class="GtkLabel" id="label">
          <property name="label">Hello Work</property>
        </object>
    </child>
  </object>
</interface>
```
