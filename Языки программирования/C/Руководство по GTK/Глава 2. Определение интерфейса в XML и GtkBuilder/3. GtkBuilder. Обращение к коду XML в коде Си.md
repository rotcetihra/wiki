Для работы с интерфейсом в xml предназначен встроенный тип `GtkBuilder`. `GtkBuilder` выполняет парсинг текстового описания пользовательского интерфейса в формате XML.

## Функции-конструкторы

Для создания `GtkBuilder` применяется ряд функций-конструкторов:

`gtk_builder_new()` — создает новый пустой объект `GtkBuilder`.

`gtk_builder_new_from_file()` — создает новый объект `GtkBuilder` по определению из файла, путь к которому передается в функцию.

```c
GtkBuilder*
gtk_builder_new_from_file (
  const char* filename
)
```

`gtk_builder_new_from_resource()` — создает новый объект `GtkBuilder` по определению из ресурса, путь к которому передается в функцию.

```c
GtkBuilder*
gtk_builder_new_from_resource (
  const char* resource_path
)
```

`gtk_builder_new_from_string()` — создает новый объект `GtkBuilder` по определению из строки, которая передается в функцию.

```c
GtkBuilder*
gtk_builder_new_from_string (
  const char* string,
  gssize length         // длина строки
)
```

Таким образом, для создания `GtkBuilder` из описания пользовательского интерфейса, можно использовать функции `gtk_builder_new_from_file()`, `gtk_builder_new_from_resource()` или `gtk_builder_new_from_string()`.

## Загрузка из нескольких источников

Если добавить описания пользовательского интерфейса из нескольких источников в один и тот же `GtkBuilder`, можно вызвать `gtk_builder_new()`, а затем выполнить один или несколько вызовов следующих функций:

`gtk_builder_add_from_file()` — добавляет определение из файла, путь к которому передается в функцию.

```c
gboolean
gtk_builder_add_from_file (
  GtkBuilder* builder,
  const char* filename,
  GError** error
)
```

`gtk_builder_add_from_resource()` — создает новый объект `GtkBuilder` по определению из ресурса.

```c
gboolean
gtk_builder_add_from_resource (
  GtkBuilder* builder,
  const char* resource_path,
  GError** error
)
```

`gtk_builder_add_from_string()` — создает новый объект `GtkBuilder` по определению из строки, которая передается в функцию.

```c
gboolean
gtk_builder_add_from_string (
  GtkBuilder* builder,
  const char* buffer,   // строка с интерфейсом
  gssize length,        // длина строки
  GError** error
)
```

Все эти функции в качестве последнего параметра принимает указатель на массив ошибок — объектов `GError`. В случае возникновения ошибок, они помещаются в переданную в функцию переменную. Данный параметр может принимать `NULL`, если он не важен.

В качестве возвращаемого результата функции возвращают `TRUE` в случае успешного выполнения и `FALSE` при ошибке.

После окончания работы с `GtkBuilder`, когда он уже не нужен, его можно и надо удалить с помощью функции `g_object_unref()`.

## Получение объектов из GtkBuilder

`GtkBuilder` хранит ссылку на все объекты, которые он сконструировал. Для доступа к виджетам в интерфейсе по `id` можно использовать функции `gtk_builder_get_object()` и `gtk_builder_get_objects()`. Функция `gtk_builder_get_object()` принимает идентификатор объекта в виде строки и возвращает соответствующий объект:

```c
GObject*
gtk_builder_get_object (
  GtkBuilder* builder,
  const char* name // идентификатор объекта
)
```

Функция `gtk_builder_get_objects()` возвращает вообще все объекты в виде списка `GList`:

```c
GSList*
gtk_builder_get_objects (
  GtkBuilder* builder
)
```

## Определение интерфейса в строке

Определение интерфейса в файле XML рассматривалось в прошлых статьях, поэтому посмотрим вкратце определение интерфейса в виде простой строки:

```c
#include <gtk/gtk.h>

static void app_activate (GtkApplication *app, gpointer *user_data) {

    // определение интерфейса
    const char* xml = "<?xml version=\"1.0\" encoding=\"UTF-8\"?>"
"<interface>"
  "<object class=\"GtkWindow\" id=\"window\">"
    "<property name=\"title\">METANIT.COM</property>"
    "<property name=\"default-width\">250</property>"
    "<property name=\"default-height\">200</property>"
  "</object>"
"</interface>";

    // Создаем объект GtkBuilder и загружаем определение интерфейса из переменной xml
    GtkBuilder *builder = gtk_builder_new_from_string(xml, -1);

    // получаем объект GtkWindow по идентификатору "window"
    GObject* window = gtk_builder_get_object (builder, "window");

    // GtkBuilder больше не нужен, удаляем его
    g_object_unref (builder);
    // устанавливаем окно приложения
    gtk_window_set_application (GTK_WINDOW (window), app);
    // отображаем окно
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

В данном случае определение интерфейса определено в константе `xml`, которая передается в функцию `gtk_builder_new_from_string()`. Поскольку нам надо использовать всю строку, то в качестве второго параметра в функцию передается `-1`.

## Загрузка интерфейса из нескольких источников

Рассмотрим другую ситуацию, когда нам надо загрузить определение интерфейса из нескольких источников. Например, у нас есть несколько файлов с определением интерфейса, где мы независимо друг от друга создаем несколько отдельных компонентов и теперь решили использовать их в одном приложении. Для примера определим следующий файл `builder.ui`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">250</property>
    <property name="default-height">200</property>
  </object>
</interface>
```

Используем этот файл в качестве одного из источников:

```c
#include <gtk/gtk.h>

static void app_activate (GtkApplication *app, gpointer *user_data) {

    // определение интерфейса
    const char* xml_label = "<interface><object class=\"GtkLabel\" id=\"label\"><property name=\"label\">Hello Work</property></object></interface>";

    // Создаем объект GtkBuilder и загружаем определение интерфейса из переменной xml
    GtkBuilder* builder = gtk_builder_new_from_file("builder.ui");
    
    // загружаем определение интерфейса из xml_label
    gtk_builder_add_from_string(builder, xml_label, -1, NULL);

    // получаем объект GtkWindow по идентификатору "window"
    GObject* window = gtk_builder_get_object (builder, "window");

    // получаем объект GtkLabel по идентификатору "label"
    GObject* label = gtk_builder_get_object (builder, "label");

    // добавляем GtkLabel в GtkWindow программным образом
    gtk_window_set_child (GTK_WINDOW (window), GTK_WIDGET(label));

    // GtkBuilder больше не нужен, удаляем его
    g_object_unref (builder);
    // устанавливаем окно приложения
    gtk_window_set_application (GTK_WINDOW (window), app);
    // отображаем окно
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

Для примера `GtkBuilder` создается по файлу `builder.ui`, а затем добавляет определение интерфейса из константы `xml_label`. С помощью функции `gtk_builder_get_object()` можно получить объекты через их идентификаторы из обоих определений и некоторым образом использовать их. Так, в данном случае получаем `GtkLabel` и добавляем этот объект в окно приложения:

```c
GObject* window = gtk_builder_get_object (builder, "window");
GObject* label = gtk_builder_get_object (builder, "label");

gtk_window_set_child (GTK_WINDOW (window), GTK_WIDGET(label));
```
