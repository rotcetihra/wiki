При создании более сложного пользовательского интерфейса с десятками или сотнями виджетов код определения интерфейса на C становится громоздким, а внесение изменений становится практически невозможным.

К счастью, GTK поддерживает разделение макета пользовательского интерфейса от бизнес-логики, используя описания пользовательского интерфейса в формате XML, которые может анализировать тип GtkBuilder.

Например, возьмем код приложения из прошлых статей:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {
    // создаем окно
    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    // устанавливаем заголовок
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    // устанавливаем размер
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);
    // отображаем окно
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

Обратимся к коду, который касается определения интерфейса окна:

```c
GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
gtk_window_set_default_size(GTK_WINDOW (window), 300, 250);
```

Если формализовать процесс определения интерфейса, то мы определяем визуальный объект или виджет (в нашем случае окно) и затем применяем некоторые функции, которые определены в GTK для установки различных свойств визуального компонента. Так, в примере выше устанавливаются заголовок, ширина и высота окна. Теперь посмотрим, как нам создать такой же объект, только в xml.

Итак, пусть у нас будет файл `builder.ui` со следующим кодом:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">300</property>
    <property name="default-height">250</property>
  </object>
</interface>
```

Файл начинается со стандартного для xml-файлов элемента xml, который устанавливает версию и кодировку. А весь интерфейс представляет пустое окно.

Далее в файле приложения `app.c`, который располагается в одной папке с файлом `builder.ui`, определим следующий код:

```c
#include <gtk/gtk.h>

static void app_activate (GtkApplication *app, gpointer *user_data) {

    // Создаем объект GtkBuilder и загружаем определение интерфейса из файла builder.ui
    GtkBuilder *builder = gtk_builder_new_from_file("builder.ui");
    
    // получаем объект GtkWindow по идентификатору "window"
    GObject* window = gtk_builder_get_object (builder, "window");
    // устанавливаем окно приложения
    gtk_window_set_application (GTK_WINDOW (window), app);
    // GtkBuilder больше не нужен, удаляем его
    g_object_unref (builder);
    // отображаем окно
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

Вначале создаем объект `GtkBuilder` с помощью функции-конструктора `gtk_builder_new_from_file()`, в которую передается путь к файлу с определением интерфейса:

```c
GtkBuilder *builder = gtk_builder_new_from_file("builder.ui");
```

Затем получаем объект `GtkWindow` по идентификатору `"window"` с помощью функции `gtk_builder_get_object()`:

```c
GObject* window = gtk_builder_get_object (builder, "window");
```

Первый параметр функции — `GtkBuilder` с определением интерфейса, а второй — идентификатор объекта из xml (в нашем случае идентификатор окна — `"window"`).

Получив окно, устанавливаем его в качестве главного окна приложения:

```c
gtk_window_set_application (GTK_WINDOW (window), app);
```

После создания окна объект `GtkBuilder` больше не нужен, его можно и нужно удалить:

```c
g_object_unref (builder);
```

Дальше отображаем окно, и пользователь может взаимодействовать с приложением.

Таким образом мы отделяем построение интерфейса от собственно кода. В данном случае, конечно, мы имеем дело с простейшим интерфейсом, но по мере увеличения сложности интерфейса, увеличения количества визуальных компонентов соответственно будет увеличиваться выгода от подобного разделения.
