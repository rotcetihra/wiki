# Модель списка GListModel

Хотя мы можем работать с элементами списка в виджете GtkListBox как с отдельными виджетами, но для управления данными, особенно большими наборами однотипных данных предпочтительнее использовать GListModel или грубо говоря модель. GListModel представляет изменяемый список объектов GObject. Хотя этот тип служит моделью для виджета GtkListBox и других списочных виджетов, но его также можно использовать как удобный способ возврата списков данных с поддержкой обновлений.

При этом сам тип GListModel представляет лишь интерфейс. Но в GTK существуют уже готовые типы моделей как конкретных ситуаций, например GtkDirectoryList или GtkStringList. Также существуют общие реализации моделей списков, такие как GListStore, которые позволяют создавать списки произвольных объектов. Но при необходимости разработчики могут создавать и свои собственные типы моделей, заточенные под какие-то специфические ситуации.

К основным моделям стоит отнести следующие:

- **GListStore**: в ее основе лежит сбалансированное дерево (balanced tree). Достаточно хорошо работает для наборов данных размером в диапазоне 0-1 000 000 и может обрабатывать вставки и удаления. Использует кэшированный итератор для ускорения линейного доступа к элементам.
- **GtkStringList**: может обрабатывать только строки. В ее основе - динамически выделяемый массив. GtkStringList хорошо подходит для любого места, где в противном случае использовался бы тип `char*[]`, и лучше всего работает, если набор данных не очень динамичен.
- **GtkDirectoryList**: оборачивает результаты функции `g_file_enumerate_children_async()`. Она работает поверх объекта GListModel и асинхронно заполняет его данными типа GFile, возвращаемыми функцией `g_file_enumerate_children_async()`.

Если эти модели не соответствуют нужному варианту использования или требованиям масштабируемости, можно создать собственную реализацию GListModel. Это небольшой интерфейс, и его не очень сложно реализовать.

## Элементы модели

Каждый элемент в модели, то есть непосредственно отображаемые данные, представляет объект GObject. При этом все элементы в GListModel имеют один и тот же тип (или являются производными от него). Каждый элемент в модели имеет позицию, которая является беззнаковым целым числом, описывающим, где в модели находится элемент. Первый элемент в модели находится в позиции 0. Позиция элемента может меняться по мере добавления или удаления других элементов из модели. Важно понимать разницу между элементами и позициями, поскольку сопоставление позиции элементу не является постоянным, что важно учитывать при отслеживании элементов по позиции при работе с моделями.

Каждый объект в списке может также сообщать об своих изменениях через некоторый механизм (обычно сигнал `GObject::notify`). Если необходимо наблюдать изменения элементов, то надо подключить сигналы к интересующим элементам. А посредством сигнала `GListModel::items-changed` модель может уведомлять систему о произошедших изменениях среди элементов, таких как добавление или удаление.

## Фабрика

Другая важная часть виджетов-списков — это фабрика. Каждая фабрика представляет собой реализацию `GtkListItemFactory`. Фабрика отвечает за сопоставление элементов модели с виджетами. Для этого при отображении для каждого элемента создается объект `GtkListItem`. Для различных ситуаций есть различные типы фабрик.

## Модель выбора и активация

Виджеты поддерживают выбор элементов через модель выбора (selection model). Модель выбора — это реализация интерфейса `GtkSelectionModel` поверх интерфейса GListModel, которая позволяет отмечать каждый элемент в модели как выбранный или невыбранный. Как и обычные модели, это можно реализовать либо путем прямой реализации `GtkSelectionModel`, либо использования одной из моделей GTK, предоставленных для этих целей, например `GtkNoSelection` или `GtkSingleSelection`.

Модель выбора определяет процесс выбора элементов: можно выбирать только один элемент или же поддерживается множественный выбор. Состояние выбора элемента можно получить через свойство `GtkListItem:selected`.

Семантика GListModel близка к семантике массива: `g_list_model_get_n_items()` возвращает количество элементов в списке, а `g_list_model_get_item()` возвращает элемент в позиции (от 0). Кроме того, с помощью функции `g_list_model_get_item_type()` можно получить тип элементов. Тип может быть интерфейсом, в этом случае все объекты в списке должны его реализовывать.

## Производительность

Для коротких списков могут создаваться экземпляры виджетов для каждого элемента в модели. Однако в случае с большими моделями (до тысяч или миллионов элементов) или по мере разрастания модели это становится менее осуществимым. Из-за этого списочные виджеты создают только ограниченное количество элементов списка и повторно используют их, привязывая к новым элементам. В целом виджеты-представления пытаются сохранить элементы списка доступными только для тех элементов, которые фактически можно увидеть на экране.

Хотя такое поведение позволяет представлениям легко масштабироваться до огромных списков, оно накладывает ряд ограничений. Например, невозможно запросить представление для элемента списка, используемого для определенной позиции — его может не быть, и даже если он есть, этот элемент списка может вскоре быть повторно использован для новой позиции.

Также при наличии состояния, которое необходимо сохранить, его стоит сохранять в элементах модели, а не полагаться на виджеты, которые отображают эти элементы. Поскольку эти виджеты могут быть повторно использованы для новой позиции в любое время, что приведет к потере любого состояния.

## Установка модели

Для установки модели в GtkListBox применяется функция `gtk_list_box_bind_model()`:

```c
void
gtk_list_box_bind_model (
  GtkListBox* box,
  GListModel* model,
  GtkListBoxCreateWidgetFunc create_widget_func,
  gpointer user_data,
  GDestroyNotify user_data_free_func
)
```

Параметры функции:

- `model`: представляет объект GListModel, который будет привязан к виджету. Может принимать значение NULL.
- `create_widget_func`: представляет тип `GtkListBoxCreateWidgetFunc`. По сути это функция, которая создает виджеты для элементов. Может принимать значение NULL.
- `user_data`: указатель на данные (тип `gpointer`), которые передаются в `create_widget_func`. Может принимать значение NULL.
- `user_data_free_func`: функция для освобождения `user_data` в виде указателя на функцию `GDestroyNotify`

Если виджет уже привязан к модели, то старая привязка уничтожается. Виджет очищается и заполняется новыми элементами из новой модели. Если же модель имеет значение NULL, то виджет остается пустым. Также стоит отметить, что виджет обновляется при каждом изменении модели.

> [!WARNING]
> Обратите внимание, что использование модели несовместимо с функциональностью фильтрации и сортировки в GtkListBox. При использовании модели фильтрация и сортировка должны быть реализованы моделью.

Для примера в качестве реализации модели возьмем тип GtkStringList, который по сути представляет набор строк:

```c
#include <gtk/gtk.h>

// создаем виджет
GtkWidget* createRow (void* item, void* user_data){

    // создаем строку для списка
    GtkWidget* row = gtk_list_box_row_new();
    // получаем текст из GtkStringObject
    const char* text = gtk_string_object_get_string(item);
    // создаем метку для вывода в строке списка
    GtkWidget* label = gtk_label_new(text);
    gtk_widget_set_halign(label, GTK_ALIGN_START);
    // устанавливаем содержимое строки списка
    gtk_list_box_row_set_child(GTK_LIST_BOX_ROW(row), label);
    return row;
}

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget* window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);

    // данные для списка
    const char* langs[] = {"С", "Python", "C++", "JavaScript", NULL};
    // создаем GtkStringList
    GtkStringList* model =  gtk_string_list_new(langs);

    GtkWidget* listBox = gtk_list_box_new();
    gtk_list_box_bind_model(GTK_LIST_BOX(listBox), G_LIST_MODEL(model), createRow, NULL, NULL);

    gtk_window_set_child (GTK_WINDOW (window), listBox);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

Разберем основные моменты. Прежде всего создаем саму модель GtkStringList:

```c
const char* langs[] = {"С", "Python", "C++", "JavaScript", NULL};
GtkStringList* model =  gtk_string_list_new(langs);
```

Для создания модели применяется функция-конструктор `gtk_string_list_new()`, в которую передается массив строк. Причем важно, что последний элемент в массиве представляет значение NULL.

Далее после создания виджета устанавливаем для него модель:

```c
gtk_list_box_bind_model(GTK_LIST_BOX(listBox), G_LIST_MODEL(model), createRow, NULL, NULL);
```

В вызове функции преобразуем GtkStringList в GListModel с помощью макроса `G_LIST_MODEL`. Кроме того передаем функцию `createRow` в качестве фабрики. Так как каждый элемент виджета GtkListBox представляет объект GtkListBoxRow, а не простую строку. Соответственно нам нужна функция для конвертации типов:

```c
GtkWidget* createRow (void* item, void* user_data){

    // создаем строку для списка
    GtkWidget* row = gtk_list_box_row_new();
    // получаем текст из GtkStringObject
    const char* text = gtk_string_object_get_string(item);
    // создаем метку для вывода в строке списка
    GtkWidget* label = gtk_label_new(text);
    gtk_widget_set_halign(label, GTK_ALIGN_START);
    // устанавливаем содержимое строки списка
    gtk_list_box_row_set_child(GTK_LIST_BOX_ROW(row), label);
    return row;
}
```

Функция `createRow` принимает два параметра - оба указатели типа `void*`. Первый параметр - `item` представляет тип модели. В нашем случае модель - GtkStringList, поэтому объект представляет тип GtkStringObject - по сути некоторая обертка над строкой `char*`. И чтобы получить значение `char*`, применяем функцию `gtk_string_object_get_string()`. В остальном действия функции `createRow` сводятся в преобразование из полученной строки в объект типа GtkListBoxRow.
