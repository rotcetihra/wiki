Виджет GtkDropDown представляет выпадающий список. Для создания виджета предназначено две функции-конструкторы:

```c
GtkWidget* gtk_drop_down_new_from_strings (const char* const* strings)
```

В качестве параметра в функцию передается массив строк, которые собственно и будут представлять элементы списка.

```c
GtkWidget* gtk_drop_down_new (GListModel* model, GtkExpression* expression)
```

Принимает два параметра:

- `model`: используемая модель
- `expression`: используемое выражение в виде объекта GtkExpression

Используем первую функцию - `gtk_drop_down_new_from_strings()`:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);

    const char* langs[] = {"C", "C++", "JavaScript", "Python", NULL};
    GtkWidget* dropDownList = gtk_drop_down_new_from_strings(langs);
    gtk_widget_set_valign(dropDownList, GTK_ALIGN_START);
    
    gtk_window_set_child (GTK_WINDOW (window), dropDownList);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

В данном случае в качестве набора элементов для выпадающего списка служит массив `langs`:

```c
const char* langs[] = {"C", "C++", "JavaScript", "Python", NULL};
```

> [!NOTE]
> Обратите внимание, что последний элемент в этом списке - NULL. Фактически в списке будет размещаться 4 элемента.

В итоге у нас получится элемент, где по умолчанию выбран первый элемент, но нажав на список, мы можем выбрать и другие элементы.

Использование второй функции-конструктора - `gtk_drop_down_new` во многом аналогично:

```c
#include <gtk/gtk.h>
 
static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);

    // данные
    const char* langs[] = {"C", "C++", "JavaScript", "Python", NULL};
    // определяем модель
    GtkStringList *model =  gtk_string_list_new (langs);
    GtkWidget* dropDownList = gtk_drop_down_new(G_LIST_MODEL(model), NULL);

    gtk_widget_set_valign(dropDownList, GTK_ALIGN_START);
    
    gtk_window_set_child (GTK_WINDOW (window), dropDownList);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Модель для списка GtkDropDown представляет модель типа GListModel. В данном случае в качестве такой модели применяется объект GtkStringList - список строк. Второй параметр функции-конструктора `gtk_drop_down_new()` здесь не важен, поэтому для него передаем NULL.

## Определение виджета в XML

Создание аналогичного виджета в xml (файл `builder.ui`):

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">300</property>
    <property name="default-height">250</property>
    <child>
      <object class="GtkDropDown">
        <property name="valign">GTK_ALIGN_START</property>
        <property name="model">
          <object class="GtkStringList">
            <items>
              <item>C</item>
              <item>C++</item>
              <item>JavaScript</item>
              <item>Python</item>
            </items>
          </object>
        </property>
      </object>
    </child>
  </object>
</interface>
```

И основной файл программы, который загружает интерфейс:

```c
#include <gtk/gtk.h>

void app_activate (GtkApplication *app, gpointer *user_data) {

    GtkBuilder *builder = gtk_builder_new_from_file("builder.ui");
    GObject* window = gtk_builder_get_object (builder, "window");
    g_object_unref (builder);

    gtk_window_set_application (GTK_WINDOW (window), app);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

## Функционал виджета

Функционал виджета описывается его свойствами:

- `enable-search`: указывает, надо ли показывать поле поиска во всплывающем окне
- `expression`: выражение GtkExpression, которое применяется для добавления элементов в список
- `factory`: Фабрика для заполнения элементов списка
- `header-factory`: Фабрика для создания виджетов заголовков для всплывающего окна
- `list-factory`: Фабрика для заполнения элементов списка во всплывающем окне
- `model`: Модель для отображаемых элементов
- `search-match-mode`: Режим сопоставления для фильтра поиска
- `selected`: Позиция выбранного элемента
- `selected-item`: Выбранный элемент
- `show-arrow`: указывает, надо ли показывать стрелку в виджете.

Для получения и установки этих свойств применяются следующие функции:

- `gtk_drop_down_get_enable_search`: указывает, включен ли поиск
- `gtk_drop_down_get_expression`: возвращает набор выражений GtkExpression, который используется для получения строк из элементов
- `gtk_drop_down_get_factory`: возвращает фабрику, которая в данный момент используется для заполнения элементов списка
- `gtk_drop_down_get_header_factory`: возвращает фабрику, которая в данный момент используется для создания виджетов заголовков для всплывающего окна
- `gtk_drop_down_get_list_factory`: возвращает фабрику, которая в данный момент используется для заполнения элементов списка во всплывающем окне
- `gtk_drop_down_get_model`: возвращает модель, которая предоставляет отображаемые элементы
- `gtk_drop_down_get_search_match_mode`: возвращает режим соответствия, который использует фильтр поиска
- `gtk_drop_down_get_selected`: возвращает позицию выбранного элемента
- `gtk_drop_down_get_selected_item`: возвращает выбранный элемент. Если элемент не выбран, возвращается NULL
- `gtk_drop_down_get_show_arrow`: возвращает, отображать ли стрелку внутри виджета
- `gtk_drop_down_set_enable_search`: устанавливает, будет ли отображаться запись поиска во всплывающем окне, позволяющем искать элементы в списке
- `gtk_drop_down_set_expression`: устанавливает выражение GtkExpression, которое вычисляется для получения строк из элементов
- `gtk_drop_down_set_factory`: устанавливает фабрику GtkListItemFactory для использования при заполнении элементов списка
- `gtk_drop_down_set_header_factory`: устанавливает фабрику GtkListItemFactory для использования при создании виджетов заголовков для всплывающего окна
- `gtk_drop_down_set_list_factory`: устанавливает фабрику GtkListItemFactory для использования при заполнении элементов списка во всплывающем окне
- `gtk_drop_down_set_model`: устанавливает модель GListModel для использования
- `gtk_drop_down_set_search_match_mode`: устанавливает режим соответствия для фильтра поиска
- `gtk_drop_down_set_selected`: выбирает элемент в указанной позиции
- `gtk_drop_down_set_show_arrow`: устанавливает, будет ли отображаться стрелка в виджете

## Установка и получение выбранного элемента

Среди функциональности виджета следует отметить свойства `selected` и `selected-item`, которые представляют соответственно позицию выбранного элемента в виде значения guint и сам выбранный элемент в виде объекта GObject.

С помощью функции `gtk_drop_down_set_selected()` можно установить выбранный элемент по его индексу в модели:

```c
void gtk_drop_down_set_selected (GtkDropDown* self, guint position)
```

В качестве второго параметра передается индекс элемента, который должен быть выбран. Например:

```c
const char* langs[] = {"C", "C++", "JavaScript", "Python", NULL};
GtkWidget* dropDownList = gtk_drop_down_new_from_strings(langs);
// по умолчанию выбран элемент с индексом 3 - "Python"
gtk_drop_down_set_selected(GTK_DROP_DOWN(dropDownList), 3);
```

Для получения индекса выбранного элемента применяется функция `gtk_drop_down_get_selected`:

```c
guint gtk_drop_down_get_selected (GtkDropDown* self)
```

Проблема с данным виджетом состоит в том, что для него GTK не предоставляет сигнала для отслеживания выбранного элемента и его изменения. Однако в качестве решения мы можем отслеживать свойства `selected` и `selected-item` с помощью стандартного механизма уведомления об изменении свойств, который есть в GTK. Например, при изменении выбора выведем выбранный элемент на консоль:

```c
#include <gtk/gtk.h>
 
const char* langs[] = {"C", "C++", "JavaScript", "Python", NULL};

// обработчик изменения свойства selected
static void notify (GObject* self, GParamSpec* pspec, gpointer user_data){

    GtkDropDown* dropDownList = (GtkDropDown*) self;
    guint index = gtk_drop_down_get_selected(dropDownList); // получаем индекс нового выбранного элемента
    const char* selected = langs[index];  // получаем по индексу сам элемент
    g_print("selected: %s\n",selected);  // выводим его на консоль
}
static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);

    GtkWidget* dropDownList = gtk_drop_down_new_from_strings(langs);
    gtk_widget_set_valign(dropDownList, GTK_ALIGN_START);

    // устанавливаем сигнал для отслеживания изменения свойства selected
    g_signal_connect (dropDownList, "notify::selected", G_CALLBACK (notify), NULL);

    gtk_window_set_child (GTK_WINDOW (window), dropDownList);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Здесь также выводим в виджете список элементов из массива `langs`, который определен как глобальная переменная. С помощью функции `g_signal_connect` устанавливаем сигнал для отслеживания изменения свойства `selected`:

```c
g_signal_connect (dropDownList, "notify::selected", G_CALLBACK (notify), NULL);
```

Сигнал "notify::selected" означает, что будет вызываться сигнал `notify` для свойства `selected`. Обработчик этого сигнала представляет функцию `notify`:

```c
static void notify (GObject* self, GParamSpec* pspec, gpointer user_data){

    GtkDropDown* dropDownList = (GtkDropDown*) self;
    guint index = gtk_drop_down_get_selected(dropDownList); // получаем индекс нового выбранного элемента
    const char* selected = langs[index];  // получаем по индексу сам элемент
    g_print("selected: %s\n",selected);  // выводим его на консоль
}
```

Обработчик сигнала `notify` принимает три параметра. Второй параметр представляет спецификацию свойств в виде объекта GParamSpec. В самом обработчике с помощью функции `gtk_drop_down_get_selected()` получаем индекс нового выбранного элемента, затем получаем по индексу сам элемент и выводим его на консоль с помощью встроенной функции `g_print()`.

## Фабрика элементов списка

По умолчанию элементы списка представляют некоторую текстовую метку, которая отображается в списке. В реальности же мы можем настроить отображение элементов списка по своему желанию и использовать более сложные композиции виджетов для каждого элемента. Так, свойство `factory` у виджета позволяет настроить вид элементов в списке с помощью фабрики элементов - объекта GtkListItemFactory. GtkListItemFactory отвечает за создание виджетов для элементов, взятых из модели. Каждый создаваемый фабрикой виджет представляет тип GtkListItem. Причем поскольку GtkListView отображает не весь список сразу, а только несколько элементов, то GtkListView дает указание GtkListItemFactory создать виджеты именно для этих элементов, которые отображаются в данный момент. По мере изменения модели списка или прокрутки списка пользователем элементы будут меняться, и виджет списка даст указание фабрике привязать ранее созданные виджеты к этим новым элементам.

Существуют различные реализации GtkListItemFactory для разных сценариев. Наиболее распространенными реализациями являются GtkBuilderListItemFactory, которая для создания виджетов использует определение интерфейса в виде xml, и GtkSignalListItemFactory, которая позволяет подключаться к сигналам с помощью собственного кода и сохранять полный контроль над тем, как виджеты настраиваются и управляются.

Фабрика GtkSignalListItemFactory генерирует сигналы для управления элементами списка. Сигналы генерируются для каждого элемента списка в следующем порядке:

- **setup**: генерируется для настройки объекта GtkListItem. Обычно это означает создание виджетов, из которых будет состоять GtkListItem (например, вложенные метки) и добавление их в элемент списка. Эта настройка сохраняется, даже если экземпляр GtkListItem повторно используется (для привязки к другому элементу GListModel).
- **bind**: генерируется для привязки элемента в модели списка к виджету, созданному на предыдущем шаге. Для получения элемента применяется свойство `item` объекта GtkListItem. Этот сигнал также генерируется, когда GtkListItem создается заново или когда с элементом списка происходят какие-то изменения.
- **unbind**: генерируется для отмены всего, что сделано на предыдущем шаге. Обычно это означает отключение обработчиков сигналов. После вызова этого сигнала GtkListItem больше не будет использоваться в виджете списка. `bind` и `unbind` могут генерироваться повторно множество раз, чтобы связать GtkListItem для использования с новыми элементами. Повторное использование GtkListItem позволяет избежать потенциально затратной настройки.
- **teardown**: генерируется для удаления GtkListItem будет уничтожен и больше не будет использоваться.

Рассмотрим на примере:

```c
#include <gtk/gtk.h>
#include <string.h>

static void setup_listitem(GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget *label = gtk_label_new(NULL);
    gtk_widget_set_halign(label, GTK_ALIGN_START);
    gtk_list_item_set_child (listitem, label);
}
static void bind_listitem (GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget* label = gtk_list_item_get_child(listitem);
    // получаем данные из модели
    GtkStringObject* strobj = gtk_list_item_get_item (listitem);
    // получаем строку
    const char* lang = gtk_string_object_get_string(strobj);
    // для примера изменяем текст
    char lang_label[32] = "Язык ";
    strcat(lang_label, lang);
    // устанавливаем по этим данным текст метки
    gtk_label_set_text (GTK_LABEL (label), lang_label);
}

static void unbind_listitem (GtkSignalListItemFactory *self, GtkListItem *listitem, gpointer user_data) {
  // здесь ничего не делаем
}

static void teardown_listitem(GtkSignalListItemFactory *self, GtkListItem *listitem, gpointer user_data) {
  // здесь также ничего не делаем
  // GtkListItem вскоре будет удален. Явным образом его удалять или устанавливать в NULL его дочерний виджет не надо
}

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);

    // данные для списка
    const char* langs[] = {"C", "C++", "JavaScript", "Python", NULL};

    // Создание фабрики для вывода элемента
    GtkListItemFactory* factory = gtk_signal_list_item_factory_new();
    g_signal_connect (factory, "setup", G_CALLBACK (setup_listitem), NULL);
    g_signal_connect (factory, "bind", G_CALLBACK (bind_listitem), NULL);
    // установка следующих сигналов не нужна и приведена только для демонстрации
    g_signal_connect (factory, "unbind", G_CALLBACK (unbind_listitem), NULL);
    g_signal_connect (factory, "teardown", G_CALLBACK (teardown_listitem), NULL);

    GtkWidget* dropDownList =  gtk_drop_down_new_from_strings(langs); 
    gtk_widget_set_valign(dropDownList, GTK_ALIGN_START);

    // устанавливаем фабрику
    gtk_drop_down_set_factory (GTK_DROP_DOWN(dropDownList), factory);

    
    gtk_window_set_child (GTK_WINDOW (window), dropDownList);
    gtk_window_present (GTK_WINDOW (window));
}


int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Разберем основные моменты. Для создания объекта GtkListItemFactory применяется функция `gtk_signal_list_item_factory_new()`, которая не принимает параметров:

```c
GtkListItemFactory* factory = gtk_signal_list_item_factory_new();
```

Далее устанавливаем обработчики для всех сигналов. Сначала устанавливаем обработчик для сигнала `setup`:

```c
g_signal_connect (factory, "setup", G_CALLBACK (setup_listitem), NULL);
```

Это функция `setup_listitem`:

```c
static void setup_listitem (GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget *label = gtk_label_new(NULL);
    gtk_widget_set_halign(label, GTK_ALIGN_START);
    // устанавливаем виджет в GtkListItem, который будет представлять элемент списка
    gtk_list_item_set_child (listitem, label);
}
```

Функция-обработчик принимает два параметра - саму фабрику и создаваемый GtkListItem. В данном случае нам надо создать тот виджет, который будет помещаться в GtkListItem и который будет выводить данные. В данном случае это метка GtkLabel. С помощью вызова `gtk_list_item_set_child()` помещаем метку в GtkListItem в качестве дочернего виджета.

Итак, виджет, который будет представлять элемент списка, создан. И теперь надо связать его с непосредственными данными. Для этого устанавливаем обработчик сигнала `bind`:

```c
g_signal_connect (factory, "bind", G_CALLBACK (bind_listitem), NULL);
```

Это функция `bind_listitem`:

```c
static void bind_listitem (GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget* label = gtk_list_item_get_child(listitem);
    // получаем данные из модели
    GtkStringObject* strobj = gtk_list_item_get_item (listitem);
    // получаем строку
    const char* lang = gtk_string_object_get_string(strobj);
    // для примера изменяем текст
    char lang_label[32] = "Язык ";
    strcat(lang_label, lang);
    // устанавливаем по этим данным текст метки
    gtk_label_set_text (GTK_LABEL (label), lang_label);
}
```

Параметры функции те же. Здесь мы получаем из GtkListItem дочерний виджет. С помощью вызова `gtk_list_item_get_item()` получаем те данные, которые будут отображаться в строке списка. А в нашем случае это строки, обернутые в объект GtkStringObject. Для примера изменяем текст, добавляя к названию языка слово "Язык ", и полученную строку передаем в метку для вывода.

Обработка остальных сигналов здесь не используется, а их функции обработчиков приведены для демонстрации. В итоге перед каждым названием языка будет указано слово "Язык".

Подобным образом можно создавать и более сложные композиции виджетов.

## Отображение сложных данных

В примерах выше мы имели дело с наборами строк, которые по сути являются идеальным объектом для отображения в GtkDropDown. Однако мы можем отображать и более комплексные объекты. Например:

```c
#include <gtk/gtk.h>

/******** Начало определения типа Person ************/
typedef struct _Person {
    GObject parent_instance;
    char *name;
    int age;
} Person;
 
typedef struct _PersonClass {
    GObjectClass parent_class;
} PersonClass;
 
#define PERSON_TYPE person_get_type()
G_DEFINE_TYPE(Person, person, G_TYPE_OBJECT)  // Определяем новый тип GObject
 
// Функция инициализации объекта Person
static void person_init(Person *person) {
    person->name = NULL;
    person->age = 0;
}
 
// Функция финализации (удаления) объекта Person
static void person_finalize(GObject *object) {
    Person *person = (Person *)object;
 
    if (person->name) {
        g_free(person->name);  // освобождение памяти
    }
 
    G_OBJECT_CLASS(person_parent_class)->finalize(object);
}
// идентификаторы свойств
enum {
    PROP_NAME=1,
    PROP_AGE,
    N_PROPERTIES
};
// определение свойств
static GParamSpec* obj_properties[N_PROPERTIES] = { NULL, };
 
// установка свойств
static void person_set_property(GObject* object, guint prop_id, const GValue* value, GParamSpec* pspec) {
    Person* self = (Person*)object;
 
    switch (prop_id) {
        case PROP_NAME:
            g_free(self->name);
            self->name = g_value_dup_string(value);
            break;
        case PROP_AGE:
            self->age = g_value_get_int(value);
            break;
        default:
            G_OBJECT_WARN_INVALID_PROPERTY_ID(object, prop_id, pspec);
            break;
    }
}
 
// получение свойств
static void person_get_property(GObject* object, guint prop_id, GValue* value, GParamSpec* pspec) {
    Person* self = (Person*)object;
 
    switch (prop_id) {
        case PROP_NAME:
            g_value_set_string(value, self->name);
            break;
        case PROP_AGE:
            g_value_set_int(value, self->age);
            break;
        default:
            G_OBJECT_WARN_INVALID_PROPERTY_ID(object, prop_id, pspec);
            break;
    }
}
 
// инициализация класса
static void person_class_init(PersonClass *class) {
 
    GObjectClass* object_class = G_OBJECT_CLASS(class);
 
    // переопределяем функции set_property и get_property для GObject
    object_class->set_property = person_set_property;
    object_class->get_property = person_get_property;
 
    // определяем свойства
    obj_properties[PROP_NAME] = g_param_spec_string(
        "name", "Name", "Person name", NULL, G_PARAM_READWRITE);
    obj_properties[PROP_AGE] = g_param_spec_int(
        "age", "Age", "Person age", 0, G_MAXINT, 0, G_PARAM_READWRITE);
 
    g_object_class_install_properties(object_class, N_PROPERTIES, obj_properties);
 
    G_OBJECT_CLASS(class)->finalize = person_finalize;
}
 
// Функция-конструктор для объекта Person
Person* person_new(const char *name, int age) {
    Person *person = g_object_new(PERSON_TYPE, NULL);
    person->name = g_strdup(name);  // копируем строку
    person->age = age;
    return person;
}
/******** Завершение определения типа Person ************/

static void setup(GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget *label = gtk_label_new(NULL);
    gtk_widget_set_halign(label, GTK_ALIGN_START);
    gtk_list_item_set_child (listitem, label);
}
static void bind_name (GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget* label = gtk_list_item_get_child(listitem);
    Person* person = (Person*) gtk_list_item_get_item (listitem);
    gtk_label_set_text (GTK_LABEL (label), person->name);
}

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);

    // данные для модели
    // список данных типа Person
    GListStore *store = g_list_store_new(PERSON_TYPE); 
    // добавляем ряд объектов
    g_list_store_append(store, person_new("Tom", 40));
    g_list_store_append(store, person_new("Bob", 46));
    g_list_store_append(store, person_new("Sam", 28));

    // Создание фабрики для вывода элемента
    GtkListItemFactory* factory = gtk_signal_list_item_factory_new();
    g_signal_connect (factory, "setup", G_CALLBACK (setup), NULL);
    g_signal_connect (factory, "bind", G_CALLBACK (bind_name), NULL);

    GtkWidget* dropDownList =  gtk_drop_down_new(G_LIST_MODEL(store), NULL);
    // устанавливаем фабрику
    gtk_drop_down_set_factory (GTK_DROP_DOWN(dropDownList), factory);

    gtk_widget_set_valign(dropDownList, GTK_ALIGN_START);
    
    gtk_window_set_child (GTK_WINDOW (window), dropDownList);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Разберем основные моменты. Прежде всего здесь данные представлены структурой Person, которая имеет поля `name` и `age`:

```c
typedef struct _Person {
    GObject parent_instance;
    char *name;
    int age;
} Person;
```

Допустим, у нас есть набор подобных объектов и нам надо вывести в списке имя - значение поля `name`. В функции `app_activate` определяем список объектов Person - объект GListStore с некоторыми данными:

```c
GListStore *store = g_list_store_new(PERSON_TYPE); 

g_list_store_append(store, person_new("Tom", 40));
g_list_store_append(store, person_new("Bob", 46));
g_list_store_append(store, person_new("Sam", 28));
```

Теперь нам надо вывести эти данные в GtkDropDown. Для этого для каждого свойства структуры создаем отдельную фабрику:

```c
// Создание фабрики 
GtkListItemFactory* name_factory = gtk_signal_list_item_factory_new();
g_signal_connect (name_factory, "setup", G_CALLBACK (setup), NULL);
g_signal_connect (name_factory, "bind", G_CALLBACK (bind_name), NULL);
```

Для фабрики определены обработчики сигналов `setup` и `bind`. В функции `setup` устанавливаем виджет для вывода имени - виджет GtkLabel:

```c
static void setup(GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget *label = gtk_label_new(NULL);
    gtk_widget_set_halign(label, GTK_ALIGN_START);
    gtk_list_item_set_child (listitem, label);
}
```

В обработчике сигнала `bind` получаем элемент модели - объект Person и выводим значение его поля `name` в созданную метку:

```c
static void bind_name (GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget* label = gtk_list_item_get_child(listitem);
    Person* person = (Person*) gtk_list_item_get_item (listitem);
    gtk_label_set_text (GTK_LABEL (label), person->name);
}
```

## GtkExpression

В примере выше для вывода каждого объекта Person в выпадающий список мы использовали фабрику, которая для свойства `name` создавала определенный виджет - в нашем случае метку. И мы могли бы создать более сложную композицию, например, также вывести и значение поля `age` и т.д. Однако если нам надо просто вывести значение поля `name`, использовать фабрику нецелесообразно. Для этого GTK предоставляет другой подход на основе выражений или GtkExpression.

Тип GtkExpression предоставляет способ описания ссылок на значения. Существуют различные методы определения выражений: от простых констант через функцию `gtk_constant_expression_new()` до поиска свойств в GObject (даже рекурсивно) через `gtk_property_expression_new()` или предоставления пользовательских функций для преобразования и комбинирования выражений через `gtk_closure_expression_new()`. Например, нам надо установить выражение на поле `name` структуры Person. Соответственно нам надо использовать функцию `gtk_property_expression_new()`:

```c
GtkExpression* gtk_property_expression_new (
  GType this_type,
  GtkExpression* expression,
  const char* property_name
)
```

Функция принимает следующие параметры:

- `this_type`: тип, свойство которого надо получить
- `expression`: объект GtkExpression - выражение для вычисления, чтобы получить объект для запроса или NULL для запроса только к объекту `this_type`. Как правило, этот параметр применяется, если свойства объекта, в свою очередь, представляет сложный объект, из которого надо получить значение свойства.
- `property_name`: имя свойства - строка UTF-8

Например, возьмем ранее определенную программу и изменим ее следующим образом:

Отмечу ключевые моменты. Прежде всего создаем само выражение:

```c
GtkExpression* expr = gtk_property_expression_new(PERSON_TYPE, NULL, "name");
```

В нашем случае мы обращаемся к типу PERSON_TYPE (фактически к структуре Person). Второй параметр - дополнительное выражение для получения данных нам здесь не нужно, поэтому передаем NULL. То есть свойство `age` здесь использовать уже не получится, так как оно представляет число.
