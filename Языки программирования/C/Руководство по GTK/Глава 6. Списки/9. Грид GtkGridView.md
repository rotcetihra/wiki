Виджет GtkGridView представляет большую динамическую сетку элементов. Для создания виджета применяется следующая функция:

```c
GtkWidget* gtk_grid_view_new (GtkSelectionModel* model, GtkListItemFactory* factory)
```

Через параметры в функцию-конструктор передаются ключевые компоненты виджета - модель данных GtkSelectionModel и фабрика GtkListItemFactory, которая отвечает за создание элементов грида. GtkGridView использует свою фабрику для генерации одного дочернего виджета для каждого видимого элемента из модели и отображает их в сетке.

Основные свойства грида:

- `enable-rubberband`: указывает, надо ли разрешить выбор резиновой ленты
- `factory`: фабрика для заполнения элементов списка
- `max-columns`: максимальное количество столбцов в строке
- `min-columns`: минимальное количество столбцов в строке
- `model`: модель для отображаемых элементов
- `single-click-activate`: указывает, надо ли активировать строки по одиночному нажатию и выбирать их при наведении

Для управления этими свойствами для функции определены следующие функции:

- `gtk_grid_view_get_enable_rubberband`: указывает, можно ли выбирать строки, перетаскивая их мышью
- `gtk_grid_view_get_factory`: возвращает фабрику грида
- `gtk_grid_view_get_max_columns`: возвращает максимальное количество столбцов, которые будет использовать сетка
- `gtk_grid_view_get_min_columns`: возвращает минимальное количество столбцов, которые будет использовать сетка
- `gtk_grid_view_get_model`: возвращает модель грида
- `gtk_grid_view_get_single_click_activate`: указывает, будут ли элементы активированы при одиночном нажатии и выбраны при наведении
- `gtk_grid_view_scroll_to`: прокручивает до элемента в указанной позиции и выполняет действия, указанные во флагах
- `gtk_grid_view_set_enable_rubberband`: устанавливает, можно ли изменять выборки путем перетаскивания мышью
- `gtk_grid_view_set_factory`: устанавливает фабрику грида
- `gtk_grid_view_set_max_columns`: устанавливает максимальное количество используемых столбцов
- `gtk_grid_view_set_min_columns`: устанавливает минимальное количество используемых столбцов
- `gtk_grid_view_set_model`: устанавливает модель грида
- `gtk_grid_view_set_single_click_activate`: устанавливает, должны ли элементы активироваться при одиночном щелчке и выбираться при наведении

Таким образом, ключевыми элементами при создании грида являются модель и фабрика элементов.

## Модель GtkSelectionModel

Прежде всего для создания GtkGridView необходима модель - объект, который представляет интерфейс GtkSelectionModel и который инкапсулирует данные грида. GTK имеет три встроенных реализации этого интерфейса:

- **GtkMultiSelection**: устанавливает поддержку множественного выбора
- **GtkSingleSelection**: устанавливает поддержку одиночного выбора
- **GtkNoSelection**: без поддержки выбора элементов

Таким образом, в зависимости от того, сколько элементов может выбирать пользователь, мы можем выбрать один из этих типов. Они создаются с помощью другого GListModel с помощью следующих функций-конструкторов:

```c
GtkSingleSelection* gtk_single_selection_new (GListModel* model)

GtkMultiSelection* gtk_multi_selection_new (GListModel* model)

GtkNoSelection* gtk_multi_selection_new (GListModel* model)
```

Например, мы можем создать модель на основе массива строк:

```c
// данные для списка
const char* langs[] = {"С", "Python", "C++", "JavaScript", "Java", "C#", NULL};
// создаем GtkStringList
GtkStringList* list =  gtk_string_list_new(langs);
GtkSingleSelection* model = gtk_single_selection_new(G_LIST_MODEL(list));
```

В данном примере данные фактически представлены массивом `langs`. Сначала на основе этого списка создается объект GtkStringList, который обертывает каждую строку в объект GtkStringObject. Затем создаем объект GtkSingleSelection (модель одиночного выбора) с помощью функции-конструктора `gtk_single_selection_new()`, передавая в нее модель строк.

## Установка фабрики

Для создания виджета для каждого видимого элемента модели необходима фабрика - объект GtkListItemFactory. GTK предоставляет различные реализации GtkListItemFactory для разных сценариев. Наиболее распространенными реализациями являются GtkBuilderListItemFactory, которая для создания виджетов использует определение интерфейса в виде xml, и GtkSignalListItemFactory, которая позволяет подключаться к сигналам с помощью собственного кода и сохранять полный контроль над тем, как виджеты настраиваются и управляются.

### Фабрика GtkSignalListItemFactory

Фабрика GtkSignalListItemFactory генерирует сигналы для управления элементами списка. Сигналы генерируются для каждого элемента списка в следующем порядке:

- **setup**: генерируется для настройки объекта GtkListItem. Обычно это означает создание виджетов, из которых будет состоять GtkListItem (например, вложенные метки) и добавление их в элемент списка. Эта настройка сохраняется, даже если экземпляр GtkListItem повторно используется (для привязки к другому элементу GListModel).
- **bind**: генерируется для привязки элемента в модели списка к виджету, созданному на предыдущем шаге. Для получения элемента применяется свойство `item` объекта GtkListItem. Этот сигнал также генерируется, когда GtkListItem создается заново или когда с элементом списка происходят какие-то изменения.
- **unbind**: генерируется для отмены всего, что сделано на предыдущем шаге. Обычно это означает отключение обработчиков сигналов. После вызова этого сигнала GtkListItem больше не будет использоваться в виджете списка. `bind` и `unbind` могут генерироваться повторно множество раз, чтобы связать GtkListItem для использования с новыми элементами. Повторное использование GtkListItem позволяет избежать потенциально затратной настройки.
- **teardown**: генерируется для удаления GtkListItem будет уничтожен и больше не будет использоваться.

Рассмотрим на примере:

```c
#include <gtk/gtk.h>

static void setup_listitem (GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget *label = gtk_label_new(NULL);
    gtk_widget_set_halign(label, GTK_ALIGN_START);
    gtk_list_item_set_child (listitem, label);
}

static void bind_listitem (GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget* label = gtk_list_item_get_child(listitem);
    // получаем данные из модели
    GtkStringObject* strobj = gtk_list_item_get_item (listitem);
    // устанавливаем по этим данным текст метки
    gtk_label_set_text (GTK_LABEL (label), gtk_string_object_get_string(strobj));
}

static void unbind_listitem (GtkSignalListItemFactory *self, GtkListItem *listitem, gpointer user_data) {
  // здесь ничего не делаем
}

static void teardown_listitem(GtkSignalListItemFactory *self, GtkListItem *listitem, gpointer user_data) {
  // здесь также ничего не делаем
  // GtkListItem вскоре будет удален. Явным образом его удалять или устанавливать в NULL его дочерний виджет не надо
}

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);

    // данные для списка
    const char* langs[] = {"С", "Python", "C++", "JavaScript", "Java", "C#", NULL};
    // создаем GtkStringList
    GtkStringList* list =  gtk_string_list_new(langs);
    // создаем модель одиночного выбора
    GtkSingleSelection* model = gtk_single_selection_new(G_LIST_MODEL(list));

    // Создание фабрики для элементов списка
    GtkListItemFactory* factory = gtk_signal_list_item_factory_new();
    g_signal_connect (factory, "setup", G_CALLBACK (setup_listitem), NULL);
    g_signal_connect (factory, "bind", G_CALLBACK (bind_listitem), NULL);
    // установка следующих сигналов не нужна и приведена только для демонстрации
    g_signal_connect (factory, "unbind", G_CALLBACK (unbind_listitem), NULL);
    g_signal_connect (factory, "teardown", G_CALLBACK (teardown_listitem), NULL);

    // создаем грид, передавая ему модель и фабрику
    GtkWidget* grid_view = gtk_grid_view_new(GTK_SELECTION_MODEL(model), factory);

    gtk_window_set_child (GTK_WINDOW (window), grid_view);
    gtk_window_present (GTK_WINDOW (window));
}
int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

Разберем основные моменты. Для создания объекта GtkListItemFactory применяется функция `gtk_signal_list_item_factory_new()`, которая не принимает параметров:

```c
GtkListItemFactory* factory = gtk_signal_list_item_factory_new();
```

Далее устанавливаем обработчики для всех сигналов. Сначала устанавливаем обработчик для сигнала `setup`:

```c
g_signal_connect (factory, "setup", G_CALLBACK (setup_listitem), NULL);
```

Это функция `setup_listitem`:

```c
static void setup_listitem (GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget *label = gtk_label_new(NULL);
    gtk_widget_set_halign(label, GTK_ALIGN_START);
    // устанавливаем виджет в GtkListItem, который будет представлять элемент списка
    gtk_list_item_set_child (listitem, label);
}
```

Функция-обработчик принимает два параметра - саму фабрику и создаваемый GtkListItem. В данном случае нам надо создать тот виджет, который будет помещаться в GtkListItem и который будет выводить данные. В данном случае это метка GtkLabel. С помощью вызова `gtk_list_item_set_child()` помещаем метку в GtkListItem в качестве дочернего виджета.

Итак, виджет, который будет представлять элемент списка, создан. И теперь надо связать его с непосредственными данными. Для этого устанавливаем обработчик сигнала `bind`:

```c
g_signal_connect (factory, "bind", G_CALLBACK (bind_listitem), NULL);
```

Это функция `bind_listitem`:

```c
static void bind_listitem (GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget* label = gtk_list_item_get_child(listitem);
    // получаем данные из модели
    GtkStringObject* strobj = gtk_list_item_get_item (listitem);
    // устанавливаем по этим данным текст метки
    gtk_label_set_text (GTK_LABEL (label), gtk_string_object_get_string(strobj));
}
```

Параметры функции те же. Здесь мы получаем из GtkListItem дочерний виджет. С помощью вызова `gtk_list_item_get_item()` получаем те данные, которые будут отображаться в строке списка. А в нашем случае это строки, обернутые в объект GtkStringObject, которые мы передаем в метку для вывода.

### GtkBuilderListItemFactory

Этот тип фабрики создает виджеты из xml-описания интерфейса. Для создания фабрики можно использовать две функции:

```c
GtkListItemFactory* gtk_builder_list_item_factory_new_from_resource (GtkBuilderScope* scope, const char* resource_path)
GtkListItemFactory* gtk_builder_list_item_factory_new_from_bytes (GtkBuilderScope* scope, GBytes* bytes)
```

Функция `gtk_builder_list_item_factory_new_from_resource()` через второй параметр получает путь к ресурсу-файлу интерфейса. Функция `gtk_builder_list_item_factory_new_from_bytes()` через второй параметр получает набор байтов - объект GBytes - текстового описания интерфейса.

Первый параметр в обоих функциях представляет область видимости, его можно не использовать. Применим вторую функцию:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);

    // данные для списка
    const char* langs[] = {"С", "Python", "C++", "JavaScript", "Java", "C#", NULL};
    // создаем GtkStringList
    GtkStringList* list =  gtk_string_list_new(langs);
    GtkSingleSelection* model = gtk_single_selection_new(G_LIST_MODEL(list));

    const char* template = "<interface>"
    "<template class=\"GtkListItem\">"
      "<property name=\"child\">"
        "<object class=\"GtkLabel\">"
          "<property name=\"xalign\">0</property>"
          "<binding name=\"label\">"
            "<lookup name=\"string\" type=\"GtkStringObject\">"
              "<lookup name=\"item\">GtkListItem</lookup>"
            "</lookup>"
          "</binding>"
        "</object>"
      "</property>"
    "</template>"
  "</interface>";
    GBytes *gbytes = g_bytes_new_static(template, strlen (template));
    GtkListItemFactory *factory = gtk_builder_list_item_factory_new_from_bytes (NULL, gbytes);

    // создаем грид
    GtkWidget* grid_view = gtk_grid_view_new(GTK_SELECTION_MODEL(model), factory);

    gtk_window_set_child (GTK_WINDOW (window), grid_view);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

В итоге мы получим результат, аналогичный предыдущему. Шаблон интерфейса в xml-виде имеет некоторые особенности:

```xml
<interface>
    <template class=\"GtkListItem\">
      <property name=\"child\">
        <object class=\"GtkLabel\">
          <property name=\"xalign\">0</property>
          <binding name=\"label\">
            <lookup name=\"string\" type=\"GtkStringObject\">
              <lookup name=\"item\">GtkListItem</lookup>
            </lookup>
          </binding>
        </object>
      </property>
    </template>
</interface>
```

Шаблон элемента списка определяется через элемент `<template>`, у которого атрибут `class` устанавливается в "GtkListItem" (то есть задаем шаблон для класса GtkListItem). Данные в GtkListItem (то есть обычная строка текста) у нас помещаются в объект GtkLabel. Поэтому свойству `child` передается объект GtkLabel. Внутри элемента GtkLabel мы также, как и в стандартном определении интерфейса в xml, можем установить свойства объекта. Так, в данном случае устанавливается выравнивание по горизонтали с помощью свойства `xalign`.

Но особенностью является применение элемента `<binding>`, который устанавливает привязку к элементу из модели:

```xml
<binding name=\"label\">
```

Атрибут `name` задает свойство GtkLabel, к которому идет привязка - то есть к свойству `label` (которое хранит текст метки). Далее элемент `<lookup>` устанавливает, как будет идти поиск привязываемого к GtkLabel элемента модели:

```xml
<lookup name=\"string\" type=\"GtkStringObject\">
    <lookup name=\"item\">GtkListItem</lookup>
</lookup>
```

Внешний элемент `<lookup>` указывает, что свойство `label` в GtkLabel будет привязано к свойству `string` объекта GtkStringObject. А вложенный элемент `<lookup>` указывает что объект `string` ссылается на свойство `item` объекта GtkListItem. Таким образом, тег поиска выглядит следующим образом:

```
label <- string <- GtkStringObject <- item <- GtkListItem
```

Фактически это то же самое, что сделали обработчики сигналов `setup` и `bind` в GtkSignalListItemFactory.

Текстовый шаблон мы можем сконвертировать в набор байт в виде объекта GBytes:

```c
GBytes *gbytes = g_bytes_new_static(template, strlen (template));
```

И далее создать фабрику в виде соответствующей функции-конструктора:

```c
GtkListItemFactory *factory = gtk_builder_list_item_factory_new_from_bytes (NULL, gbytes);
```

## Определение GtkGridView в xml

Теперь рассмотрим создание аналогичного грида в xml. Для этого определим следующую программу:

```c
#include  <gtk/gtk.h>

static void app_activate (GtkApplication *app, gpointer *user_data) {

    GtkBuilder *builder = gtk_builder_new_from_file("builder.ui");
    GObject* window = gtk_builder_get_object (builder, "window");
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);

    gtk_window_set_application (GTK_WINDOW (window), app);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

Здесь только загружаем определение интерфейса из файла "builder.ui". А в файле `builder.ui` определим следующий код:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="visible">True</property>
    <property name="title">METANIT.COM</property>
    <property name="default-width">250</property>
    <property name="default-height">200</property>
    <child>
        <object class="GtkGridView">
          <property name="model">
            <object class="GtkSingleSelection">
              <property name="model">
                <object class="GtkStringList">
                  <items>
                    <item>C</item>
                    <item>Python</item>
                    <item>C++</item>
                    <item>JavaScript</item>
                    <item>Java</item>
                    <item>C#</item>
                  </items>
                </object>
              </property>
            </object>
          </property>

          <property name="factory">
            <object class="GtkBuilderListItemFactory">
              <property name="bytes"><![CDATA[
              <?xml version="1.0" encoding="UTF-8"?>
              <interface>
                <template class="GtkListItem">
                  <property name="child">
                    <object class="GtkLabel">
                        <property name="xalign">0</property>
                        <binding name="label">
                          <lookup name="string" type="GtkStringObject">
                            <lookup name="item">GtkListItem</lookup>
                          </lookup>
                        </binding>
                      </object>
                  </property>
                </template>
              </interface>
                  ]]>
              </property>
            </object>
                </property>
        </object>
      </child>
  </object>
</interface>
```

Здесь непосредственно в свойстве `model` определяем модель GtkSingleSelection с данными в виде GtkStringList. А для свойства `factory` применяем фабрику GtkBuilderListItemFactory, которая использует ранее рассмотренный шаблон элементов списка.

## Управление столбцами в гриде

Грид не обладает большими возможностями по управлению столбцами. Тем не менее с помощью свойств `max-columns` и `min-columns` мы можем установить соответственно максимальное и минимальное количество столбцов. Например, установим, что грид будет иметь не больше 2 столбцов. В коде Си для этого применяется функция `gtk_grid_view_set_max_columns()`:

```c
GtkWidget* grid_view = gtk_grid_view_new(GTK_SELECTION_MODEL(model), factory);
gtk_grid_view_set_max_columns(GTK_GRID_VIEW(grid_view), 2);
```

В XML для этого устанавливается соответствующее свойство:

```xml
<object class="GtkGridView">
    <property name="max-columns">2</property>
```
