GTK предоставляет ряд виджетов для работы со списками данных. Подобные виджеты позволяют отобразить множество объектов одинаковым образом. Списочные виджеты прекрасно подходят для использования в очень коротких списках всего из 2 или 3 элементов, но могут также применяться и для работы с миллионом элементов. Конечно, чем больше становится список, тем больше внимания нужно уделять выбору правильных структур данных для поддержания должной производительности. Причем списки могут отображать как статичные неизменяющиеся данные, так и данные, которые подвержены изменению - либо при добавлении/удалении элементов в списке, либо при редактировании уже существующих элементов. Такие списочные виджеты еще называют представления. Рассмотрим простейший списочный виджет - GtkListBox.

Виджет GtkListBox представляет вертикальный список. Каждый элемент в этом виджете представляет объект типа GtkListBoxRow - своего рода строку. Эти строки можно динамически сортировать и фильтровать, осуществлять по строкам навигацию и выбор с помощью клавиатуры и мыши. Хотя GtkListBox должен иметь только дочерние элементы GtkListBoxRow, в него можно добавить любой виджет, и он будет обернут в GtkListBoxRow.

Для создания виджета применяется конструктор без параметров:

```c
GtkWidget* gtk_list_box_new (void)
```

## Добавление элементов

Для добавления элементов в GtkListBox применяется ряд функций:

`gtk_list_box_append()`: добавляет виджет в конец списка. Добавляемый виджет передается через второй параметр функции:

```c
void gtk_list_box_append (GtkListBox* box, GtkWidget* child)
```

`gtk_list_box_prepend()`: добавляет виджет в начало списка. Имеет следующую сигнатуру:

```c
void gtk_list_box_prepend (GtkListBox* box, GtkWidget* child)
```

`gtk_list_box_insert()`: вставляет указанный виджет на определенную позицию в списке. Имеет следующую сигнатуру:

```c
void gtk_list_box_insert (GtkListBox* box, GtkWidget* child, int position)
```

Второй параметр представляет добавляемый виджет, а третий - позицию вставки.

> [!NOTE]
> Обратите внимание, что в любом случае добавляемый элемент должен представлять виджет.

Рассмотрим применение этих функций:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);

    GtkWidget* listBox = gtk_list_box_new();
    // добавляем в конец списка
    gtk_list_box_append(GTK_LIST_BOX(listBox), gtk_label_new("C++"));
    gtk_list_box_append(GTK_LIST_BOX(listBox), gtk_label_new("Python"));
    // добавляем в начало списка
    gtk_list_box_prepend(GTK_LIST_BOX(listBox), gtk_label_new("C"));
    // вставляем по индексу 1 (то есть второй элемент)
    gtk_list_box_insert(GTK_LIST_BOX(listBox), gtk_label_new("JavaScript"), 1);


    gtk_window_set_child (GTK_WINDOW (window), listBox);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{

    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

Здесь все добавляемые элементы представляют метки GtkLabel с некоторым текстом. В итоге мы получим следующий список.

Но, как можно увидеть из скриншота, по умолчанию ListBox растягивается по всей ширине/высоте окна-контейнера, и, кроме того, растягиваются и добавляемые метки. В итоге мы получаем растянутые метки с текстом по центру виджета. Чтобы должным образом упорядочить виджеты, мы можем использовать стандартные способы позиционирования, в частности, функции `gtk_widget_set_halign` и `gtk_widget_set_valign`. Например:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);

    GtkWidget* listBox = gtk_list_box_new();

    const char* langs[] = {"C", "C++", "JavaScript", "Python"};
    for(size_t i=0; i < sizeof(langs)/sizeof(langs[i]); ++i){
        GtkWidget* label = gtk_label_new(langs[i]);
        gtk_widget_set_halign(label, GTK_ALIGN_START); // выравнивание по левому краю
        gtk_list_box_append(GTK_LIST_BOX(listBox), label);
    }

    gtk_window_set_child (GTK_WINDOW (window), listBox);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

## Получение элементов

Для получения элементов списка GTK предоставляет для типа GtkListBox пару функций:

`gtk_list_box_get_row_at_index`: получает n-ный дочерний элемент в списке (не считая заголовков).

```c
GtkListBoxRow* gtk_list_box_get_row_at_index (GtkListBox* box, int index_)
```

В качестве второго параметра передается индекс элемента. Если `index_` отрицателен или больше количества элементов в списке, возвращается `NULL`.

`gtk_list_box_get_row_at_y`: получает строку в позиции y.

```c
GtkListBoxRow* gtk_list_box_get_row_at_y (GtkListBox* box, int y)
```

> [!NOTE]
> Обратите внимание, что каждая из этих функций возвращает объект типа GtkListBoxRow, в который оборачивается добавляемый виджет. Однако для этого типа доступна функция `gtk_list_box_row_get_child()`, которая позволяет получить непосредственно содержимое:

```c
GtkWidget* gtk_list_box_row_get_child (GtkListBoxRow* row)
```

Для примера просто выведем все элементы из списка на консоль сразу после его создания:

```c
#include <stdio.h>
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);

    GtkWidget* listBox = gtk_list_box_new();

    const char* langs[] = {"C", "C++", "JavaScript", "Python"};
    // наполняем список
    for(size_t i=0; i < sizeof(langs)/sizeof(langs[i]); ++i){
        GtkWidget* label = gtk_label_new(langs[i]);
        gtk_widget_set_halign(label, GTK_ALIGN_START); // выравнивание по левому краю
        gtk_list_box_append(GTK_LIST_BOX(listBox), label);
    }

    GtkListBoxRow* row = NULL;
    int i=0;
    // пока есть строки, получаем их в переменную row
    while((row = gtk_list_box_get_row_at_index(GTK_LIST_BOX(listBox), i++))){

        // получаем содержимое строки - выше добавленные метки
        GtkWidget* label = gtk_list_box_row_get_child(row);
        printf("Row %d: %s\n", i, gtk_label_get_text(GTK_LABEL(label)));
    }

    gtk_window_set_child (GTK_WINDOW (window), listBox);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{

    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

В итоге консоль выведет:

```
Row 1: C
Row 2: C++
Row 3: JavaScript
Row 4: Python
```

## Удаление элементов

Для удаления строк GTK предоставляет ряд функций:

`gtk_list_box_remove`: удаляет дочерний элемент, который передается через второй параметр.

```c
void gtk_list_box_remove (GtkListBox* box, GtkWidget* child)
```

`gtk_list_box_remove_all`: удаляет все строки из виджета

```c
void gtk_list_box_remove_all (GtkListBox* box)
```

Например, удаление второй строки (с индексом 1):

```c
GtkWidget* listBox = gtk_list_box_new();

const char* langs[] = {"C", "C++", "JavaScript", "Python"};
for(size_t i=0; i < sizeof(langs)/sizeof(langs[i]); ++i){
    GtkWidget* label = gtk_label_new(langs[i]);
    gtk_widget_set_halign(label, GTK_ALIGN_START); // выравнивание по левому краю
    gtk_list_box_append(GTK_LIST_BOX(listBox), label);
}

// удаление второй строки
GtkListBoxRow* row = gtk_list_box_get_row_at_index(GTK_LIST_BOX(listBox), 1);
gtk_list_box_remove(GTK_LIST_BOX(listBox), GTK_WIDGET(row));
```
