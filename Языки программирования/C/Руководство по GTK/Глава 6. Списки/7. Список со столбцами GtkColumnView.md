Виджет GtkColumnView представляет большой динамический список элементов с использованием нескольких столбцов с заголовками. Для каждого элемента списка GtkColumnView использует фабрики типа GtkListItemFactory для генерации виджетов в каждом столбце и отображает их вместе как строку для этого элемента. А для выбора элементов GtkColumnView применяет модели выбора типа GtkSelectionModel.

Для генерации виджета применяется функция `gtk_column_view_new()`:

```c
GtkWidget* gtk_column_view_new(GtkSelectionModel* model)
```

В качестве аргумента в функцию передается модель типа GtkSelectionModel, которая хранит данные для списка и управляет их жизненным циклом.

Отмечу основные свойства:

- `columns`: список столбцов в виде типа GListModel
- `header-factory`: фабрика для создания виджетов заголовков
- `model`: модель для отображаемых элементов
- `reorderable`: указывает, можно ли переупорядочивать столбцы
- `row-factory`: фабрика, используемая для настройки строк
- `show-column-separators`: указывает, надо ли показывать разделители между столбцами
- `show-row-separators`: указывает, надо ли показывать разделители между строками
- `single-click-activate`: указывает, надо ли активировать строки по одному нажатию и выбирать их при наведении
- `sorter`: объект сортировки типа GtkSorter, который указывает, как сортировать данные

И также отмечу основные функции, которые преимущественно предназначены для управления свойствами виджета:

- `gtk_column_view_append_column`: добавляет столбец в конец списка столбцов
- `gtk_column_view_get_columns`: возвращает список столбцов
- `gtk_column_view_get_header_factory`: возвращает фабрику, которая в данный момент используется для заполнения заголовков разделов
- `gtk_column_view_get_model`: возвращает модель, которая хранит отображаемые элементы
- `gtk_column_view_get_reorderable`: указывает, можно ли переупорядочивать столбцы
- `gtk_column_view_get_row_factory`: возвращает фабрику строк заголовков
- `gtk_column_view_get_show_column_separators`: указывает, должен ли список отображать разделители между столбцами
- `gtk_column_view_get_show_row_separators`: указывает, должен ли список отображать разделители между строками
- `gtk_column_view_get_single_click_activate`: указывает, будут ли строки активированы при одиночном щелчке и выбраны при наведении
- `gtk_column_view_get_sorter`: возвращает объект сортировки данных
- `gtk_column_view_insert_column`: вставляет столбец в указанную позицию в список столбцов
- `gtk_column_view_remove_column`: удаляет столбец из списка столбцов
- `gtk_column_view_set_header_factory`: устанавливает фабрику для использования при заполнении объектов GtkListHeader, используемых в заголовках разделов
- `gtk_column_view_set_model`: устанавливает модель для использования
- `gtk_column_view_set_reorderable`: устанавливает, следует ли изменять порядок столбцов путем перетаскивания
- `gtk_column_view_set_row_factory`: устанавливает фабрику, используемую для настройки строк заголовков
- `gtk_column_view_set_show_column_separators`: устанавливает, должен ли список отображать разделители между столбцами
- `gtk_column_view_set_show_row_separators`: устанавливает, должен ли список отображать разделители между строками
- `gtk_column_view_set_single_click_activate`: устанавливает, должны ли строки активироваться при одиночном нажатии и выбираться при наведении
- `gtk_column_view_set_tab_behavior`: устанавливает поведение клавиши Tab
- `gtk_column_view_sort_by_column`: устанавливает объект сортировки

Таким образом, для создания виджета нам достаточно установить модель с данными. Модель с данными, с которой связывается виджет GtkListView, представляет интерфейс GtkSelectionModel. Используем в качестве реализации этого интерфейса встроенный в GTK тип GtkSingleSelection, который позволяет выбирать один объект:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);

    // данные для списка
    const char* langs[] = {"С", "Python", "C++", "JavaScript", NULL};
    // создаем GtkStringList
    GtkStringList* list =  gtk_string_list_new(langs);
    // создаем модель одиночного выбора
    GtkSingleSelection* model = gtk_single_selection_new(G_LIST_MODEL(list));

    GtkWidget* column_view = gtk_column_view_new(GTK_SELECTION_MODEL(model));

    gtk_window_set_child (GTK_WINDOW (window), column_view);
    gtk_window_present (GTK_WINDOW (window));
}
int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

В качестве набора данных здесь применяется список строк GtkStringList, который обертывает каждую строку в объект GtkStringObject. Затем создаем объект GtkSingleSelection (модель одиночного выбора) с помощью функции-конструктора `gtk_single_selection_new()`, передавая в нее модель строк. Однако в реальности при запуске приложения мы увидим пустое окно.

Потому что наш виджет, который должен содержать набор столбцов, пока не содержит ни одного столбца. Поэтому добавим в него столбец для отображения данных.

## Определение столбцов

Каждый столбец представляет собой тип GtkColumnViewColumn. Причем, хотя этот тип также реализует функционал типа GObject, но виджетом не является, то есть не унаследован от типа GtkWidget и соответственно не имеет его функционала.

Для создания столбца применяется следующая функция:

```c
GtkColumnViewColumn* gtk_column_view_column_new (const char* title, GtkListItemFactory* factory)
```

Первый параметр представляет заголовок столбца, а второй - фабрика в виде объекта GtkListItemFactory, который сообщает, как создавать ячейки для этого столбца из элементов в модели.

Для настройки столбцов можно использовать ряд его свойств:

- `column-view`: родительский контейнер GtkColumnView
- `expand`: указывает, надо ли растягивать столбец на доступную ширину
- `factory`: фабрика для заполнения элементов списка
- `fixed-width`: если не равно -1, то представляет фиксированную ширину столбца, независимо от размера его содержимого
- `id`: идентификатор столбца
- `resizable`: указывает, можно ли изменять размер этого столбца
- `sorter`: объект для сортировки элементов по этому столбцу
- `title`: заголовок, отображаемый в заголовке
- `visible`: указывает, виден ли этот столбец

Для управления этими свойствами применяются следующие функции:

- `gtk_column_view_column_get_column_view`: возвращает родительский виджет GtkColumnView
- `gtk_column_view_column_get_expand`: показывает, должен ли этот столбец расширяться по всей доступной ширине
- `gtk_column_view_column_get_factory`: возвращает фабрику столбца
- `gtk_column_view_column_get_fixed_width`: возвращает фиксированную ширину столбца
- `gtk_column_view_column_get_id`: возвращает идентификатор столбца
- `gtk_column_view_column_get_resizable`: показывает, можно ли изменять размер столбца
- `gtk_column_view_column_get_sorter`: возвращает сортировщик, связанный со столбцом
- `gtk_column_view_column_get_title`: возвращает заголовок
- `gtk_column_view_column_get_visible`: показывает, является ли этот столбец видимым
- `gtk_column_view_column_set_expand`: устанавливает столбец для использования доступного дополнительного пространства
- `gtk_column_view_column_set_factory`: устанавливает фабрику столбца
- `gtk_column_view_column_set_fixed_width`: устанавливает фиксированную ширину столбца
- `gtk_column_view_column_set_id`: устанавливает идентификатор столбца
- `gtk_column_view_column_set_resizable`: устанавливает, следует ли изменять размер столбца путем перетаскивания
- `gtk_column_view_column_set_sorter`: устанавливает сортировщик
- `gtk_column_view_column_set_title`: устанавливает заголовок столбца
- `gtk_column_view_column_set_visible`: устанавливает, следует ли отображать этот столбец

Ключевым аспектом в работе столбца является фабрика GtkListItemFactory, которая отвечает за создание виджетов для элементов, взятых из модели. Существуют различные реализации GtkListItemFactory для разных сценариев. Наиболее распространенными реализациями являются GtkBuilderListItemFactory, которая для создания виджетов использует определение интерфейса в виде xml, и GtkSignalListItemFactory, которая позволяет подключаться к сигналам с помощью собственного кода и сохранять полный контроль над тем, как виджеты настраиваются и управляются.

### Фабрика GtkSignalListItemFactory

Фабрика GtkSignalListItemFactory генерирует сигналы для управления элементами списка. Сигналы генерируются для каждого элемента списка в следующем порядке:

- **setup**: генерируется для настройки объекта GtkListItem. Обычно это означает создание виджетов, из которых будет состоять GtkListItem (например, вложенные метки) и добавление их в элемент списка. Эта настройка сохраняется, даже если экземпляр GtkListItem повторно используется (для привязки к другому элементу GListModel).
- **bind**: генерируется для привязки элемента в модели списка к виджету, созданному на предыдущем шаге. Для получения элемента применяется свойство `item` объекта GtkListItem. Этот сигнал также генерируется, когда GtkListItem создается заново или когда с элементом списка происходят какие-то изменения.
- **unbind**: генерируется для отмены всего, что сделано на предыдущем шаге. Обычно это означает отключение обработчиков сигналов. После вызова этого сигнала GtkListItem больше не будет использоваться в виджете списка. `bind` и `unbind` могут генерироваться повторно множество раз, чтобы связать GtkListItem для использования с новыми элементами. Повторное использование GtkListItem позволяет избежать потенциально затратной настройки.
- **teardown**: генерируется для удаления GtkListItem будет уничтожен и больше не будет использоваться.

Рассмотрим на примере:

```c
#include <gtk/gtk.h>

static void setup_listitem (GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget *label = gtk_label_new(NULL);
    gtk_widget_set_halign(label, GTK_ALIGN_START);
    gtk_list_item_set_child (listitem, label);
}

static void bind_listitem (GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget* label = gtk_list_item_get_child(listitem);
    // получаем данные из модели
    GtkStringObject* strobj = gtk_list_item_get_item (listitem);
    // устанавливаем по этим данным текст метки
    gtk_label_set_text (GTK_LABEL (label), gtk_string_object_get_string(strobj));
}

static void unbind_listitem (GtkSignalListItemFactory *self, GtkListItem *listitem, gpointer user_data) {
  // здесь ничего не делаем
}

static void teardown_listitem(GtkSignalListItemFactory *self, GtkListItem *listitem, gpointer user_data) {
  // здесь также ничего не делаем
  // GtkListItem вскоре будет удален. Явным образом его удалять или устанавливать в NULL его дочерний виджет не надо
}

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);

    // данные для списка
    const char* langs[] = {"С", "Python", "C++", "JavaScript", NULL};
    // создаем GtkStringList
    GtkStringList* list =  gtk_string_list_new(langs);
    GtkSingleSelection* model = gtk_single_selection_new(G_LIST_MODEL(list));

    // Создание GtkColumnView
    GtkWidget* column_view = gtk_column_view_new(GTK_SELECTION_MODEL(model));

    // Создание фабрики для элементов списка
    GtkListItemFactory* factory = gtk_signal_list_item_factory_new();
    g_signal_connect (factory, "setup", G_CALLBACK (setup_listitem), NULL);
    g_signal_connect (factory, "bind", G_CALLBACK (bind_listitem), NULL);
    // установка следующих сигналов не нужна и приведена только для демонстрации
    g_signal_connect (factory, "unbind", G_CALLBACK (unbind_listitem), NULL);
    g_signal_connect (factory, "teardown", G_CALLBACK (teardown_listitem), NULL);

    // определяем один столбец, который будет называться Language
    GtkColumnViewColumn *column = gtk_column_view_column_new("Language", factory);
    // добавляем столбец
    gtk_column_view_append_column(GTK_COLUMN_VIEW(column_view), column);

    gtk_window_set_child (GTK_WINDOW (window), column_view);
    gtk_window_present (GTK_WINDOW (window));
}
int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

Разберем основные моменты. Для создания объекта GtkListItemFactory применяется функция `gtk_signal_list_item_factory_new()`, которая не принимает параметров:

```c
GtkListItemFactory* factory = gtk_signal_list_item_factory_new();
```

Далее устанавливаем обработчики для всех сигналов. Сначала устанавливаем обработчик для сигнала `setup`:

```c
g_signal_connect (factory, "setup", G_CALLBACK (setup_listitem), NULL);
```

Это функция `setup_listitem`:

```c
static void setup_listitem (GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget *label = gtk_label_new(NULL);
    gtk_widget_set_halign(label, GTK_ALIGN_START);
    // устанавливаем виджет в GtkListItem, который будет представлять элемент списка
    gtk_list_item_set_child (listitem, label);
}
```

Функция-обработчик принимает два параметра - саму фабрику и создаваемый GtkListItem. В данном случае нам надо создать тот виджет, который будет помещаться в GtkListItem и который будет выводить данные. В данном случае это метка GtkLabel. С помощью вызова `gtk_list_item_set_child()` помещаем метку в GtkListItem в качестве дочернего виджета.

Итак, виджет, который будет представлять элемент списка, создан. И теперь надо связать его с непосредственными данными. Для этого устанавливаем обработчик сигнала `bind`:

```c
g_signal_connect (factory, "bind", G_CALLBACK (bind_listitem), NULL);
```

Это функция `bind_listitem`:

```c
static void bind_listitem (GtkListItemFactory *factory, GtkListItem *listitem)
{
    GtkWidget* label = gtk_list_item_get_child(listitem);
    // получаем данные из модели
    GtkStringObject* strobj = gtk_list_item_get_item (listitem);
    // устанавливаем по этим данным текст метки
    gtk_label_set_text (GTK_LABEL (label), gtk_string_object_get_string(strobj));
}
```

Параметры функции те же. Здесь мы получаем из GtkListItem дочерний виджет. С помощью вызова `gtk_list_item_get_item()` получаем те данные, которые будут отображаться в строке списка. А в нашем случае это строки, обернутые в объект GtkStringObject, которые мы передаем в метку для вывода.

После создания фабрики и подключения сигналов определяем столбец, который будет иметь заголовок "Language" и который будет использовать выше определенную фабрику, и добавляем его в коллекцию столбцов виджета GtkColumnView:

```c
GtkColumnViewColumn *column = gtk_column_view_column_new("Language", factory);
gtk_column_view_append_column(GTK_COLUMN_VIEW(column_view), column);
```

### GtkBuilderListItemFactory

Этот тип фабрики создает виджеты из xml-описания интерфейса. Для создания фабрики можно использовать две функции. Функция `gtk_builder_list_item_factory_new_from_resource()` через второй параметр получает путь к ресурсу-файлу интерфейса:

```c
GtkListItemFactory* gtk_builder_list_item_factory_new_from_resource (GtkBuilderScope* scope, const char* resource_path)
```

Функция `gtk_builder_list_item_factory_new_from_bytes()` через второй параметр получает набор байтов - объект GBytes - текстового описания интерфейса:

```c
GtkListItemFactory* gtk_builder_list_item_factory_new_from_bytes (GtkBuilderScope* scope, GBytes* bytes)
```

Первый параметр в обоих функциях представляет область видимости, его можно не использовать. Применим вторую функцию:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);

    // данные для списка
    const char* langs[] = {"С", "Python", "C++", "JavaScript", NULL};
    // создаем GtkStringList
    GtkStringList* list =  gtk_string_list_new(langs);
    GtkSingleSelection* model = gtk_single_selection_new(G_LIST_MODEL(list));

    // Создание GtkColumnView
    GtkWidget* column_view = gtk_column_view_new(GTK_SELECTION_MODEL(model));

    const char* template = "<interface>"
    "<template class=\"GtkListItem\">"
      "<property name=\"child\">"
        "<object class=\"GtkLabel\">"
          "<property name=\"xalign\">0</property>"
          "<binding name=\"label\">"
            "<lookup name=\"string\" type=\"GtkStringObject\">"
              "<lookup name=\"item\">GtkListItem</lookup>"
            "</lookup>"
          "</binding>"
        "</object>"
      "</property>"
    "</template>"
  "</interface>";
    GBytes *gbytes = g_bytes_new_static(template, strlen (template));
    GtkListItemFactory *factory = gtk_builder_list_item_factory_new_from_bytes (NULL, gbytes);

    // определяем один столбец, который будет называться Language
    GtkColumnViewColumn *column = gtk_column_view_column_new("Language", factory);
    // добавляем столбец
    gtk_column_view_append_column(GTK_COLUMN_VIEW(column_view), column);

    gtk_window_set_child (GTK_WINDOW (window), list_view);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

В итоге мы получим результат, аналогичный предыдущему. Шаблон интерфейса в xml-виде имеет некоторые особенности:

```xml
<interface>
    <template class=\"GtkListItem\">
      <property name=\"child\">
        <object class=\"GtkLabel\">
          <property name=\"xalign\">0</property>
          <binding name=\"label\">
            <lookup name=\"string\" type=\"GtkStringObject\">
              <lookup name=\"item\">GtkListItem</lookup>
            </lookup>
          </binding>
        </object>
      </property>
    </template>
</interface>
```

Для задания шаблона применяется элемент `<template>`. Для этого элемента устанавливается атрибут `class` в "GtkListItem" (то есть задаем шаблон для класса GtkListItem). Данные в GtkListItem (то есть обычная строка текста) у нас помещаются в объект GtkLabel. Поэтому свойству `child` передается объект GtkLabel. Внутри элемента GtkLabel мы также, как и в стандартном определении интерфейса в xml, можем установить свойства объекта. Так, в данном случае устанавливается выравнивание по горизонтали с помощью свойства `xalign`.

Но особенностью является применение элемента `<binding>`, который устанавливает привязку к элементу из модели:

```xml
<binding name=\"label\">
```

Атрибут `name` задает свойство GtkLabel, к которому идет привязка - то есть к свойству `label` (которое хранит текст метки). Далее элемент `<lookup>` устанавливает, как будет идти поиск привязываемого к GtkLabel элемента модели:

```xml
<lookup name=\"string\" type=\"GtkStringObject\">
    <lookup name=\"item\">GtkListItem</lookup>
</lookup>
```

Внешний элемент `<lookup>` указывает, что свойство `label` в GtkLabel будет привязано к свойству `string` объекта GtkStringObject. А вложенный элемент `<lookup>` указывает что объект `string` ссылается на свойство `item` объекта GtkListItem. Таким образом, тег поиска выглядит следующим образом:

```
label <- string <- GtkStringObject <- item <- GtkListItem
```

Фактически это то же самое, что сделали обработчики сигналов `setup` и `bind` в GtkSignalListItemFactory.

Текстовый шаблон мы можем сконвертировать в набор байт в виде объекта GBytes:

```c
GBytes *gbytes = g_bytes_new_static(template, strlen (template));
```

И далее создать фабрику в виде соответствующей функции-конструктора:

```c
GtkListItemFactory *factory = gtk_builder_list_item_factory_new_from_bytes (NULL, gbytes);
```

## Настройка столбцов

Исходя из выше приведенных свойств и функций столбцов, понятно, какие у нас есть возможности по настройке столбцов. Приведу лишь один пример. Из выше приведенных скриншотов видно, что по умолчанию ширина столбца устанавливается исходя из его содержимого. В итоге образуется много не заполненного пространства, и получается не совсем красиво. С помощью функции `gtk_column_view_column_set_fixed_width()` можно установить точную ширину столбца через второй параметр:

```c
void gtk_column_view_column_set_fixed_width (GtkColumnViewColumn* self, int fixed_width)
```

Однако все равно в виджете может образоваться незаполненного пространство особенно при растяжении окна. Чтобы заполнить все доступное пространство, применяется функция `gtk_column_view_column_set_expand()`, в которую для второго параметра передается значение TRUE:

```c
void gtk_column_view_column_set_expand (GtkColumnViewColumn* self, gboolean expand)
```

Например, растянем столбец по всей ширине:

```c
GtkColumnViewColumn *column = gtk_column_view_column_new("Language", factory);
gtk_column_view_column_set_expand(column, TRUE);
```
