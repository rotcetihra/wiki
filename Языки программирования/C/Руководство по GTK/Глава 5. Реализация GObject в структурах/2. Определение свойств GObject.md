Выше мы определили базовый функционал для реализации функциональности GObject для структуры Person. Однако кроме того, нам могут понадобиться свойства, которые позволяют обращаться к полям структуры в различных ситуациях, например, при построении интерфейса в xml.

## Определение свойств

Обычно для определения свойств применяются идентификаторы, которые задаются в виде перечисления:

```c
enum {
    PROP_NAME=1,
    PROP_AGE,
    N_PROPERTIES
};

static GParamSpec *obj_properties[N_PROPERTIES] = { NULL, };
```

Идентификаторы должны начинаться с 1, так как 0 зарезервирован для внутреннего использования в GObject. Так, в данном случае у нас два идентификатора для полей name и age. А последнее поле указывает на количество свойств.

Определения свойств помещаются в массив указателей GParamSpec, где самый первый элемент равен NULL.

## Установка и получение свойств

Установка свойств производится в функции `префикс_class_init()` (в нашем случае в `person_class_init`). Для этого переопределяются методы `префикс_set_property()` и `префикс_get_property()` класса GObject.

Сначала определим функцию `person_set_property`, которая устанавливает свойства для объекта Person:

```c
static void person_set_property(GObject* object, guint prop_id, const GValue* value, GParamSpec* pspec) {
    Person* self = (Person*)object;

    switch (prop_id) {
        case PROP_NAME:
            g_free(self->name);
            self->name = g_value_dup_string(value);
            break;
        case PROP_AGE:
            self->age = g_value_get_int(value);
            break;
        default:
            G_OBJECT_WARN_INVALID_PROPERTY_ID(object, prop_id, pspec);
            break;
    }
}
```

Определение функции `set_property` следует определенным условностям и должна иметь данный набор параметров:

- `GObject* object`: объект, для которого устанавливается свойство
- `guint prop_id`: идентификатор свойства
- `const GValue* value`: значение свойства
- `GParamSpec* pspec`: массив определений свойств

В реализации функции смотрим, идентификатор какого свойства передан (идентификаторы соответствуют значениям в перечислении), и в зависимости от этого устанавливаем нужное свойство, извлекая для него значение из параметра `GValue* value`. В случае выше освобождаем ранее выделенную строку для имени и применяем функцию `g_value_dup_string()` для установки нового значения. Для установки age применяется встроенная функция `g_value_get_int()`.

Если передан неизвестный идентификатор, то используем макрос `G_OBJECT_WARN_INVALID_PROPERTY_ID`, который генерирует стандартное предупреждение о некорректном идентификаторе свойства.

Аналогично далее определим функцию `person_get_property`, которая получает значения свойств:

```c
static void person_get_property(GObject* object, guint prop_id, GValue* value, GParamSpec* pspec) {
    Person* self = (Person*)object;

    switch (prop_id) {
        case PROP_NAME:
            g_value_set_string(value, self->name);
            break;
        case PROP_AGE:
            g_value_set_int(value, self->age);
            break;
        default:
            G_OBJECT_WARN_INVALID_PROPERTY_ID(object, prop_id, pspec);
            break;
    }
}
```

Функция имеет аналогичные параметры, только третий параметр (`GValue* value`) применяется для получения значения свойства. Для этого применяются встроенные в GTK функции `g_value_set_string()`/`g_value_set_int()`

## Регистрация свойств

Далее нам надо зарегистрировать свойства объекта. Для этого в функции инициализации класса объекта (в нашем случае в `person_class_init`) применяется функция `g_object_class_install_properties()`. Так, изменим функцию `person_class_init` следующим образом:

```c
static void person_class_init(PersonClass *class) {

    GObjectClass* object_class = G_OBJECT_CLASS(class);

    // переопределяем функции set_property и get_property для GObject
    object_class->set_property = person_set_property;
    object_class->get_property = person_get_property;

    // определяем свойства
    obj_properties[PROP_NAME] = g_param_spec_string(
        "name", "Name", "Person name", NULL, G_PARAM_READWRITE);
    obj_properties[PROP_AGE] = g_param_spec_int(
        "age", "Age", "Person age", 0, G_MAXINT, 0, G_PARAM_READWRITE);

    g_object_class_install_properties(object_class, N_PROPERTIES, obj_properties);

    G_OBJECT_CLASS(class)->finalize = person_finalize;
}
```

В начале переопределяем функции `set_property` и `get_property` для GObject. Затем определяем свойства в `obj_properties` с помощью встроенных функций `g_param_spec_string` и `g_param_spec_int`, которые соответствуют типу свойства. Они во многом однотипны:

```c
GParamSpec* g_param_spec_string (const gchar* name, const gchar* nick, const gchar* blurb, 
    const gchar* default_value, GParamFlags flags)
GParamSpec* g_param_spec_int ( const gchar* name, const gchar* nick, const gchar* blurb, 
    gint minimum, gint maximum, gint default_value, GParamFlags flags )
```

Отмечу основные параметры обоих функций:

- `name`: имя свойства
- `nick`: псевдоним свойства
- `blurb`: описание свойства
- `default_value`: значение по умолчанию для свойства
- `flags`: флаги для свойства

И после определения свойств регистрируем их с помощью функции `g_object_class_install_properties`, которая принимает класс объекта, количество свойств и определения свойств в виде объекта GParamSpecs.

## Применение свойств

Соберем вместе все аспекты определения класса Person и на примере консольного приложения рассмотрим применение свойств. Конечно, в консольном приложении нет смысла обращаться к функциям `set_property` и `get_property`, учитывая, что мы напрямую можем обратиться к полям name и age, тем не менее я приведу код, чтобы было общее представление, а в следующей статье посмотрим на реальное применение свойств.

Итак, весь код приложения будет следующим:

```c
#include <gtk/gtk.h>

typedef struct _Person {
    GObject parent_instance;
    char *name;
    int age;
} Person;

typedef struct _PersonClass {
    GObjectClass parent_class;
} PersonClass;

#define PERSON_TYPE person_get_type()
G_DEFINE_TYPE(Person, person, G_TYPE_OBJECT)  // Определяем новый тип GObject

// Функция инициализации объекта Person
static void person_init(Person *person) {
    person->name = NULL;
    person->age = 0;
}

// Функция финализации (удаления) объекта Person
static void person_finalize(GObject *object) {
    Person *person = (Person *)object;

    if (person->name) {
        g_free(person->name);  // освобождение памяти
    }

    G_OBJECT_CLASS(person_parent_class)->finalize(object);
}
// идентификаторы свойств
enum {
    PROP_NAME=1,
    PROP_AGE,
    N_PROPERTIES
};
// определение свойств
static GParamSpec* obj_properties[N_PROPERTIES] = { NULL, };


// установка свойств
static void person_set_property(GObject* object, guint prop_id, const GValue* value, GParamSpec* pspec) {
    Person* self = (Person*)object;

    switch (prop_id) {
        case PROP_NAME:
            g_free(self->name);
            self->name = g_value_dup_string(value);
            break;
        case PROP_AGE:
            self->age = g_value_get_int(value);
            break;
        default:
            G_OBJECT_WARN_INVALID_PROPERTY_ID(object, prop_id, pspec);
            break;
    }
}

// получение свойств
static void person_get_property(GObject* object, guint prop_id, GValue* value, GParamSpec* pspec) {
    Person* self = (Person*)object;

    switch (prop_id) {
        case PROP_NAME:
            g_value_set_string(value, self->name);
            break;
        case PROP_AGE:
            g_value_set_int(value, self->age);
            break;
        default:
            G_OBJECT_WARN_INVALID_PROPERTY_ID(object, prop_id, pspec);
            break;
    }
}

// инициализация класса
static void person_class_init(PersonClass *class) {

    GObjectClass* object_class = G_OBJECT_CLASS(class);

    // переопределяем функции set_property и get_property для GObject
    object_class->set_property = person_set_property;
    object_class->get_property = person_get_property;

    // определяем свойства
    obj_properties[PROP_NAME] = g_param_spec_string(
        "name", "Name", "Person name", NULL, G_PARAM_READWRITE);
    obj_properties[PROP_AGE] = g_param_spec_int(
        "age", "Age", "Person age", 0, G_MAXINT, 0, G_PARAM_READWRITE);

    g_object_class_install_properties(object_class, N_PROPERTIES, obj_properties);

    G_OBJECT_CLASS(class)->finalize = person_finalize;
}

// Функция-конструктор для объекта Person
Person* person_new(const char *name, int age) {
    Person *person = g_object_new(PERSON_TYPE, NULL);
    person->name = g_strdup(name);  // копируем строку
    person->age = age;
    return person;
}

int main(int argc, char *argv[]) {

    // Создаем объект Person
    Person *person = person_new("Tom Smith", 40);

    // переменные для получения свойств
    GValue name = G_VALUE_INIT;
    GValue age = G_VALUE_INIT;
    g_value_init(&name,  G_TYPE_STRING);
    g_value_init(&age,  G_TYPE_INT);

    // проходим по всем свойствам и получаем значения свойств name и age
    for(size_t i = 0; i < N_PROPERTIES; i++){

        person_get_property(G_OBJECT(person), PROP_NAME, &name, obj_properties[i]);
        person_get_property(G_OBJECT(person), PROP_AGE, &age, obj_properties[i]);
    }

    // Обращаемся к свойствам объекта
    g_print("Name: %s\n", g_value_get_string(&name));
    g_print("Age: %d\n", g_value_get_int(&age));

    // Удаление объекта
    g_object_unref(person); 
    return 0;
}
```

Для получения свойств из объекта Person с помощью функции `get_property` определяем две переменных типа GValue, который представляет контейнер для хранения значений различных типов данных. Каждой из этих переменных присвоено значение `G_VALUE_INIT`. Фактически это макрос, который используется в библиотеке GLib (базовая библиотека, используемая в GTK) для инициализации структуры GValue.

```c
GValue name = G_VALUE_INIT;
GValue age = G_VALUE_INIT;
```

Для дальнейшего использования структуры GValue нужно вызвать функцию `g_value_init()`, чтобы установить конкретный тип данных структуры. Например:

```c
g_value_init(&name,  G_TYPE_STRING);
g_value_init(&age,  G_TYPE_INT);
```

Затем просто проходим по всем свойствам и получаем из них значения для свойств name и age:

```c
for(size_t i = 0; i < N_PROPERTIES; i++){

    person_get_property(G_OBJECT(person), PROP_NAME, &name, obj_properties[i]);
    person_get_property(G_OBJECT(person), PROP_AGE, &age, obj_properties[i]);
}
```

И в конце с помощью функций а-ля `g_value_get_ТИП` мы можем получить конкретное значение:

```c
g_print("Name: %s\n", g_value_get_string(&name));
g_print("Age: %d\n", g_value_get_int(&age));
```

И хотя в данном случае подобное получение свойств не имеет большого смысла, и вместо всей этой лабуды мы могли бы просто обратиться к полям name и age. Но в следующей статье мы рассмотрим применение свойств в определении xml-интерфейса.
