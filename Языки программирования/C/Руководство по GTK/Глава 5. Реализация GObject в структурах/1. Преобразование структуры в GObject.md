GObject представляет в GTK фундаментальный тип, который предоставляет общие атрибуты и методы для всех типов объектов в GTK. GObject предоставляет методы для создания и уничтожения объектов, методы доступа к свойствам и поддержку сигналов в некотором унифицированном виде. Так, виджеты и многие встроенные объекты в GTK представляют тип GObject. Реализация типами функционала GObject позволяет использовать объекты этих типов в различных сценариях, например, в виде элементов списков и т.д.

Допустим, у нас есть следующая структура, которая представляет человека:

```c
typedef struct Person {
    char *name;  // имя 
    int age;    // возраст
} Person;
```

Как нам превратить эту структуру в GObject? Преобразование простой структуры C в GObject в C включает создание класса GObject и реализацию некоторого шаблонного кода.

## Определение структуры и класса структуры

Для начала нам надо определить структуру как подтип (подкласс) типа GObject:

```c
typedef struct _Person {
    GObject parent_instance; // структура _Person - подкласс типа GObject
    char *name;
    int age;
} Person;
```

Обратите внимание, что поставив в начало структуры поле типа GObject, мы тем самым "унаследовали" структуру от GObject.

Далее нужно создать новую структуру-класс, которая наследуется от GObjectClass:

```c
typedef struct _PersonClass {
    GObjectClass parent_class;
} PersonClass;
```

Далее определяем тип объекта с помощью макроса G_DEFINE_TYPE:

```c
#define PERSON_TYPE person_get_type()
G_DEFINE_TYPE(Person, person, G_TYPE_OBJECT) 
```

Прежде всего определяем макрос PERSON_TYPE, через который будем передавать тип класса структуры Person. Для этого будет применяться автогенерируемая функция person_get_type()

Макрос G_DEFINE_TYPE регистрирует тип Person с помощью GObject. Макрос принимает название типа, префикс функций и родительский тип GType:

- Person: название типа, который регистрируется
- person: префикс, который будет применяться в функциях. Так, в определении предыдущего макроса использовалась функция person_get_type, которая согласно условностям названа по шаблону префикс_get_type (и далее применяются person_init или person_finalize)
- G_TYPE_OBJECT: родительский тип

Эти условности позволяют сократить объем необходимого шаблонного кода.

Затем надо определить функции инициализации и финализации:

```c
// Функция инициализации объекта Person
static void person_init(Person *person) {
    person->name = NULL;
    person->age = 0;
}

// Функция финализации (удаления) объекта Person
static void person_finalize(GObject *object) {
    Person *person = (Person *)object;

    if (person->name) {
        g_free(person->name);  // освобождаем память для поля name
    }

    G_OBJECT_CLASS(person_parent_class)->finalize(object);
}
```

Функция инициализации (в данном случае person_init) является конструктором для типа GObject. Она вызывается при создании объекта и инициализирует все переменные-члены. В нашем случае она устанавливает имя в NULL, а возраст в 0.

Функция финализации (в данном случае person_finalize) используется для очистки ресурсов при уничтожении объекта. В нашем случае она освобождает динамически выделенную память для строки имени. Для этого применяется встроенная в GTK функция g_free(), которая освобождает память аналогично библиотечной функции free()

И также определим функцию инициализации класса GObject:

```c
static void person_class_init(PersonClass *class) {
    G_OBJECT_CLASS(class)->finalize = person_finalize;
}
```

Эта функция используется для инициализации GObjectClass для Person и переопределяет finalize, чтобы обеспечить надлежащую очистку памяти.

## Определение конструктора

Функции-конструкторы - специальные функции для доступа к полям структуры в принципе необязательны, но упрощают создание структуры. Так, также определим функцию-конструктор:

```c
Person* person_new(const char *name, int age) {
    Person *person = g_object_new(PERSON_TYPE, NULL);
    person->name = g_strdup(name);  // копируем строку
    person->age = age;
    return person;
}
```

Здесь получаем значения для полей структуры Person и устанавливаем их. Для установки поля name применяем встроенную в GTK функцию g_strdup(), которая выделяет память под строку и возвращает указатель на эту строку (аналогично встроенной библиотечной функции strdup()).

Для создания объекта Person применяется функция g_object_new(). Она имеет следующий прототип:

```c
GObject* g_object_new (GType object_type, const gchar* first_property_name, ...)
```

Эта функция создает новый экземпляр подтипа GObject и задает его свойства. Первый параметр представляет идентификатор подтипа GObject - в данном случае применяем вышеопределенный макрос PERSON_TYPE

Второй параметр - first_property_name представляет имя первого свойства, а третий необязательный параметр - значение первого свойства, за которым могут следовать дополнительные пары имя/значение, завершающиеся значением NULL. В данном случае нам ничего такого устанавливать не надо, поэтому передаем NULL.

## Использование

Теперь соберем все вместе и для примера создадим один объект структуры и выведем его данные на консоль:

```c
#include <gtk/gtk.h>

typedef struct _Person {
    GObject parent_instance;
    char *name;
    int age;
} Person;

typedef struct _PersonClass {
    GObjectClass parent_class;
} PersonClass;

#define PERSON_TYPE person_get_type()
G_DEFINE_TYPE(Person, person, G_TYPE_OBJECT)  // Определяем новый тип GObject

// Функция инициализации объекта Person
static void person_init(Person *person) {
    person->name = NULL;
    person->age = 0;
}

// Функция финализации (удаления) объекта Person
static void person_finalize(GObject *object) {
    Person *person = (Person *)object;

    if (person->name) {
        g_free(person->name);  // очищаем память
    }

    G_OBJECT_CLASS(person_parent_class)->finalize(object);
}
// инициализация класса
static void person_class_init(PersonClass *class) {
    G_OBJECT_CLASS(class)->finalize = person_finalize;
}

// Функция-конструктор для объекта Person
Person* person_new(const char *name, int age) {
    Person *person = g_object_new(PERSON_TYPE, NULL);
    person->name = g_strdup(name);  // копируем строку
    person->age = age;
    return person;
}

int main(int argc, char *argv[]) {

    // Создаем объект Person
    Person *person = person_new("Tom Smith", 40);

    // Обращаемся к свойствам объектам через геттеры
    g_print("Name: %s\n", person->name);
    g_print("Age: %d\n", person->age);

    // Удаление объекта
    g_object_unref(person); 
    return 0;
}
```

Функция g_object_unref() удаляет ссылку на объект, что фактически приводит к удалению объекта из памяти.
