Для настройки окна приложения фреймворк GTK предоставляет множество функций для установки различных аспектов. Рассмотрим основные из них.

## Заголовок окна

Функция `gtk_window_set_title()` устанавливает заголовок окна:

```c
void gtk_window_set_title (GtkWindow* window, const char* title)
```

Первый параметр функции — окно, а второй — строка с заголовком. Применение:

```c
// создаем главное окно приложения
GtkWidget *window = gtk_window_new();

// устанавливаем заголовок окна
gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
```

## Размеры окна

Для установки размера окна по умолчанию можно с помощью функции `gtk_window_set_default_size`:

```c
void gtk_window_set_default_size ( GtkWindow* window, int width, int height)
```

В качестве параметров функция принимает окно, ширину и высоту в пикселях. Размер окна по умолчанию — это размер, который будет использоваться, если не применяются другие ограничения. Размер по умолчанию будет обновляться всякий раз, когда размер окна изменяется. Если минимальный размер окна больше, чем размер по умолчанию, то размер по умолчанию будет проигнорирован. Установка размера по умолчанию в значение <= 0 приведет к его игнорированию и вместо него будет использоваться естественный размер.

Для получения размеров по умолчанию применяется функция:

```c
void gtk_window_get_default_size ( GtkWindow* window, int* width, int* height)
```

Дополнительно функция `gtk_window_set_resizable()` позволяет указать, можно ли у окна динамически изменять размеры:

```c
void gtk_window_set_resizable (GtkWindow* window, gboolean resizable)
```

Первый параметр — окно, а второй — значение типа gboolean: TRUE (размер можно изменять) или FALSE (размер нельзя динамически изменять).

Применение функций:

```c
#include <gtk/gtk.h>

int main (int argc, char **argv)
{
    // инициализируем набор виджетов
    gtk_init ();

    // создаем главное окно приложения
    GtkWidget *window = gtk_window_new();

    // устанавливаем заголовок окна
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    // устанавливаем размеры окна: 300 - ширина, 200 - высота
    gtk_window_set_default_size(GTK_WINDOW (window), 300, 200);
    // запрещаем изменение размеров окна
    gtk_window_set_resizable(GTK_WINDOW (window), FALSE);

    // отображаем окно
    gtk_window_present (GTK_WINDOW (window));
   
    // получаем размеры 
    int width = 0;
    int height = 0;
    gtk_window_get_default_size(GTK_WINDOW (window), &width, &height);
    printf("Width: %d;  height: %d\n", width, height);


    // запускаем цикл прослушивания событий
    while (g_list_model_get_n_items (gtk_window_get_toplevels ()) > 0) {

        g_main_context_iteration(NULL, TRUE);
    }
    return 0;
}
```

Также есть ряд дополнительных функций, которые позволяют влиять на размер окна:

- `gtk_window_fullscreen()`: разворачивает окно на весь экран
- `gtk_window_maximize()`: разворачивает окно на максимально возможный размер
- `gtk_window_minimize()`: сворачивает окно
- `gtk_window_unfullscreen()`: сворачивает окно
- `gtk_window_unmaximize()`: сворачивает окно до предыдущего состояния
- `gtk_window_unminimize()`: разворачивает окно

Все эти функции однотипны и в качестве параметра принимают окно. Например:

```c
GtkWidget *window = gtk_window_new();

// разворачиваем окно на весь экран
gtk_window_fullscreen(GTK_WINDOW (window));
```

## Состояние окна

Ряд функций позволяют проверить текущее состояние окна:

- `gtk_window_is_active()`: возвращает, является ли окно активным
- `gtk_window_is_fullscreen()`: возвращает TRUE, если окно развернуто на весь экран
- `gtk_window_is_maximized()`: возвращает TRUE, если окно развернуто на максимальную величину

Все эти функции однотипны и возвращают значение типа gboolean (TRUE или FALSE).
