Основным строительным блоком в графическом интерфейсе на GTK являются виджеты. По сути это визуальные элементы, из которых состоит интерфейс, например, кнопки, текстовые поля, списки и т.д. И GTK обладает большим набором виджетов. Все эти виджеты представляют реализуют функционал базового типа GtkWidget. Какие-то виджеты могут впоследствии добавляться в новые версии GTK, а какие-то могут объявляться устаревшими и со временем исключаться из фреймворка.

Перечислю основные виджеты:

- **GtkLabel:** кнопка, которая представляет однострочную или многострочную надпись
- **GtkSpinner:** индикатор загрузки
- **GtkStatusbar:** строка статуса
- **GtkProgressBar:** индикатор прогресса
- **GtkScrollbar:** полоса прокрутки
- **GtkImage:** область для вывода изображения
- **GtkSeparator:** вертикальные и горизонтальные разделители
- **GtkTextView:** многострочное поле для редактируемого текста
- **GtkScale:** ползунок
- **GtkDrawingArea:** область для рисования
- **GtkVideo:** виджет для воспроизведения видео
- **GtkCalendar:** календарь
- **GtkPopoverMenu:** контекстное меню
- **GtkButton:** кнопка
- **GtkToggleButton:** кнопка-переключатель, которая может находиться в двух состояниях (вкл и выкл)
- **GtkLinkButton:** кнопка-ссылка
- **GtkCheckButton:** флажок/переключатель (радиокнопка), который может находиться в отмеченном (выбранном) и неотмеченном состоянии
- **GtkComboBox:** выпадающий список
- **GtkDropDown:** выпадающий список
- **GtkColorButton:** кнопка для выбора цвета
- **GtkFontButton:** кнопка для выбора шрифта
- **GtkEntry:** однострочное поле для ввода текста
- **GtkPasswordEntry:** однострочное поле для ввода пароля
- **GtkBox:** контейнер, который располагает вложенные элементы по горизонтали или вертикали
- **GtkGrid:** контейнер, который располагает вложенные элементы в виде сетки
- **GtkCenterBox:** контейнер, который центрирует вложенные элементы
- **GtkScrolledWindow:** окно с прокруткой
- **GtkPaned:** контейнер с двумя панелями, разделенных по вертикали или горизонтали
- **GtkFrame:** фрейм, который создает рамку вокруг вложенного элемента
- **GtkExpander:** контейнер, который позволяет скрывать и раскрывать вложенные элементы
- **GtkNotebook:** контейнер с вкладками
- **GtkListBox:** контейнер-список
- **GtkTreeView:** контейнер для вывода иерархических данных в виде дерева
- **GtkWindow:** стандартное окно
- **GtkDialog:** диалоговое окно
- **GtkMessageDialog:** окно с сообщением
- **GtkColorChooserDialog:** окно для выбора цвета
- **GtkFileChooserDialog:** окно для выбора файла
- **GtkFontChooserDialog:** окно для выбора шрифта

Как можно увидеть по неполному списку виджетов, одни виджеты (контейнеры) могут содержать другие. Так, возьмем контейнер верхнего уровня, в качестве которого выступает окно — GtkWindow. Этот контейнер может содержать только один виджет. Однако в качестве такого виджета могут выступать другие контейнеры, в которые, в свою очередь, можно поместить другие виджеты. Для установки вложенных элементов для типа GtkWindow применяется функция `gtk_window_set_child()`:

```c
void gtk_window_set_child (GtkWindow* window, GtkWidget* child)
```

В качестве второго параметра в функцию передается вложенный виджет. Например, возьмем простейший виджет — GtkButton, который представляет кнопку:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {
 
    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
     
    // создаем кнопку 
    GtkWidget *button = gtk_button_new_with_label("Click");
    // устанавливаем кнопку в качестве содержимого окна
    gtk_window_set_child (GTK_WINDOW (window), button);
 
    gtk_window_present (GTK_WINDOW (window));
}
 
int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Все действия по установке интерфейса окна производятся в обработчике запуска окна — в функции `app_activate`. Сначала мы создаем кнопку с помощью функции `gtk_button_new_with_label()`, передавая в нее текст кнопки. А потом с помощью функции `gtk_window_set_child()` устанавливаем эту кнопку в качестве содержимого окна:

```c
// создаем кнопку 
GtkWidget *button = gtk_button_new_with_label("Click");
// устанавливаем кнопку в качестве содержимого окна
gtk_window_set_child (GTK_WINDOW (window), button);
```

В итоге мы получим следующее окно. По умолчанию вложенный элемент центрируется и растягивается по всей площади окна.

Если мы используем другой подход — без GtkApplication, то мы могли бы написать следующим образом:

```c
#include <gtk/gtk.h> 

int main (int argc, char **argv)
{
    gtk_init ();

    GtkWidget *window = gtk_window_new();

    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size(GTK_WINDOW (window), 250, 200);

    // создаем кнопку 
    GtkWidget *button = gtk_button_new_with_label("Click");
    // устанавливаем кнопку в качестве содержимого окна
    gtk_window_set_child (GTK_WINDOW (window), button);

    gtk_window_present (GTK_WINDOW (window));

    while (g_list_model_get_n_items (gtk_window_get_toplevels ()) > 0) {

        g_main_context_iteration(NULL, TRUE);
    }
    return 0;
}
```
