В прошлой статье было рассмотрено создание и запуск приложения GTK, построенного на основе типа GtkApplication. Теперь рассмотрим, как мы можем с его помощью построить графический интерфейс.

Как было сказано в прошлой статье, при запуске приложения вызывается сигнал `activate`, в обработчике которого можно прописать некоторые действия, вызываемые при запуске приложения. В том числе в обработчике сигнала `activate` можно прописать создание графического интерфейса приложения. Так, в качестве примера создадим небольшое окно:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {
    // создаем окно
    GtkWidget *window = gtk_window_new();
    // установка заголовка окна
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    // установка размеров окна
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);
    // связываем окно с приложением GtkApplication
    gtk_window_set_application (GTK_WINDOW (window), GTK_APPLICATION (app));
    // отображаем окно
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    // создание приложения
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    // установка обработчика для сигнала activate приложения
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    // запуск приложения
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    // освобождение памяти
    g_object_unref(app);

    return status;
}
```

Здесь в обработчике сигнала `activate` — функции `app_activate` прописываем создание окна GtkWindow, у которого затем устанавливается ряд атрибутов — заголовок и размеры. В принципе создание и базовая работа с GtkWindow рассматривалась в прошлых статьях. Но кроме создания окна нам также надо связать объект GtkWindow с GtkApplication. Для этого применяется функция `gtk_window_set_application()`:

```c
gtk_window_set_application (GTK_WINDOW (window), GTK_APPLICATION (app));
```

Первый параметр функции — окно, а второй параметр — приложение GtkApplication, к которому надо привязать окно. После этого приложение GtkApplication будет управлять связанным окном.

В итоге при запуске приложения мы увидим простейшее окно.

Теперь вернемся к предыдущим статьям, где также создавался графический интерфейс, однако без использования GtkApplication:

```c
#include <gtk/gtk.h>

int main (int argc, char **argv)
{
    // инициализируем набор виджетов
    gtk_init ();

    // создаем главное окно приложения
    GtkWidget *window = gtk_window_new();

    // устанавливаем заголовок окна
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    // устанавливаем размеры окна: 300 - ширина, 250 - высота
    gtk_window_set_default_size(GTK_WINDOW (window), 300, 250);
    // отображаем окно
    gtk_window_present (GTK_WINDOW (window));
   
    // запускаем цикл прослушивания событий
    while (g_list_model_get_n_items (gtk_window_get_toplevels ()) > 0) {

        g_main_context_iteration(NULL, TRUE);
    }
    return 0;
}
```

Если мы сравним два подхода — с GtkApplication и без, то мы увидим ряд различий. Прежде всего в варианте кода без GtkApplication вначале в функции `main` вызывалась функция `gtk_init()`. При использовании объекта GtkApplication вызывать вручную `gtk_init()` не нужно, так как эта функция вызывается автоматически при регистрации объекта GtkApplication. В частности, `gtk_init()` вызывается в обработчике по умолчанию для сигнала `GApplication::startup`.

Также в варианте кода без GtkApplication для запуска цикла прослушивания событий и взаимодействия с пользователем применяется следующий цикл:

```c
while (g_list_model_get_n_items (gtk_window_get_toplevels ()) > 0)
    g_main_context_iteration (NULL, TRUE);
```

И преимуществом использования GtkApplication является то, что этот объект сам выполняет инициализацию и запуск и управление циклом прослушивания событий.

Таким образом, мы можем использовать оба подхода, однако применение GtkApplication позволяет упростить инициализацию и ряд других вещей и использовать их неявно.

## GtkApplicationWindow

В примере с GtkApplication для создания графического интерфейса применялся тип GtkWindow. Однако более рекомендуемым подходом является применение другого типа — GtkApplicationWindow. Этот тип "унаследован" ("использует функционал") от типа GtkWindow, поэтому все, что характерно для GtkWindow, также применяется к GtkApplicationWindow. Но при этом GtkApplicationWindow также имеет некоторые дополнительные возможности для лучшей интеграции с GtkApplication. В частности, для создания окна применяется функция `gtk_application_window_new()`, в которую в качестве параметра передается объект приложения, с которым надо установить связь:

```c
GtkWidget* gtk_application_window_new (GtkApplication* application)
```

Так, изменим предыдущий код, применив GtkApplicationWindow:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {
    // создаем окно
    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    // устанавливаем заголовок
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    // устанавливаем размер
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);
    // эта строка теперь не нужна
    // gtk_window_set_application (GTK_WINDOW (window), GTK_APPLICATION (app));
    // отображаем окно
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    // создание приложения
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    // установка обработчика для сигнала activate приложения
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    // запуск приложения
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    // освобождение памяти
    g_object_unref(app);

    return status;
}
```

Мы получили то же самое окно, однако теперь дополнительно нам не надо вызывать функцию `gtk_window_set_application()` для установки связи между окном и приложением, так как эта связь уже устанавливается при создании окна в функции `gtk_application_new()`.
