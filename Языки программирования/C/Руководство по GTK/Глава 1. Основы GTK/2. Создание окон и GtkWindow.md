Одним из ключевых компонентов графического приложения является окно, которое содержит все остальные компоненты управления типа кнопок, текстовых полей и т.д. и через которое пользователь взаимодействует с приложением. В GTK окно представлено типом GtkWindow.

На рисунке видно, что тип GtkWindow заимствует часть функционала от другого типа — GtkWidget, то есть также является виджетом, который при этом может содержать другие виджеты.

Для создания объекта GtkWindow применяется функция `gtk_window_new()`:

```c
GtkWidget *window = gtk_window_new();
```

Стоит отметить, что эта функция возвращает значение типа GtkWidget, которое представляет созданное окно. Чтобы из виджета получить непосредственно объект GtkWindow, применяется макрос `GTK_WINDOW`:

```c
GTK_WINDOW (window)
```

Для удаления объекта GtkWindow применяется функция `gtk_window_destroy()`:

```c
// удаляем окно
gtk_window_destroy(GTK_WINDOW (window));
```

## Инициализация

Перед использованием любых виджетов, в том числе окон, в приложении GTK необходимо выполнить инициализацию с помощью функции `gtk_init()`. Эта функция подключается к оконной системе, устанавливает локаль и выполняет другие задачи инициализации. `gtk_init()` завершает работу приложения в случае возникновения ошибок. Поэтому перед созданием окна необходимо вызвать эту функцию:

```c
#include <gtk/gtk.h>

int main (int argc, char **argv)
{
    // инициализируем набор виджетов
    gtk_init();

    // создаем главное окно приложения
    GtkWidget *window = gtk_window_new();
    // удаляем окно
    gtk_window_destroy(GTK_WINDOW (window));
    return 0;
}
```

## gtk_window_list_toplevels()

Все окна верхнего уровня, которые создаются с помощью функции `gtk_window_new()`, сохраняются во внутреннем списке окон. Этот список можно получить с помощью функции `gtk_window_list_toplevels()`. Мы можем пройтись по этому списку и выполнить с каждым окном в этом списке некоторые действия. Для примера используем другую встроенную функцию — `g_list_model_get_n_items()`, которая возвращает количество элементов в списке, то есть получим количество окон. Например, создадим пару окон:

```c
#include <gtk/gtk.h>

int main (int argc, char **argv)
{
    // инициализируем набор виджетов
    gtk_init ();

    // создаем два окна
    GtkWidget *window = gtk_window_new();
    GtkWidget *window2 = gtk_window_new();
   
    // получаем количество созданных окон
    size_t window_count = g_list_model_get_n_items (gtk_window_get_toplevels ());

    printf("Windows count: %lu\n", window_count);   // Windows count: 2

    return 0;
}
```

## Отображение окна

При создании окна оно явным образом автоматически не отображается. Нам надо отобразить на экране компьютера явным образом с помощью функции `gtk_window_present()`:

```c
void gtk_window_present (GtkWindow* window)
```

В качестве параметра в функцию передается окно, которое надо отобразить. Применение:

```c
#include <gtk/gtk.h>

int main (int argc, char **argv)
{
    // инициализируем набор виджетов
    gtk_init ();

    // создаем главное окно приложения
    GtkWidget *window = gtk_window_new();

    // отображаем окно
    gtk_window_present (GTK_WINDOW (window));

    return 0;
}
```

Однако при запуске приложения мы не увидим окна, так как приложение сразу же завершиться. Нам надо организовать цикл прослушивания обработки событий.

## Цикл прослушивания событий

GTK использует событийную модель программирования, то есть такую модель, где пользователь может взаимодействовать с приложением посредством событий. Когда приложение ничего не делает, GTK находится в "основном цикле" и ждет ввода. Если пользователь выполняет какое-либо действие, например, нажимает на кнопку мыши, то основной цикл передает событие в GTK. А GTK пересылает событие одному или нескольким виджетам.

Когда виджеты получают событие, они часто вызывают один или несколько сигналов. Сигналы уведомляют программу о том, что «что-то произошло что-то интересное», и вызывают функции, которые подключены к сигналу с помощью функции `g_signal_connect()`. Подобные подключенные к сигналам функции часто называются "обратными вызовами", коллбеками, обработчиками событий. И в принципе во многих фреймворках для создания графических приложений есть подобные конструкции.

После выполнения обработчика события GTK возвращается в основной цикл и продолжит взаимодействовать с пользователем.

Функция `g_main_context_iteration()` позволяет проверить, есть ли какие-то события, которые надо обработать (например, нажатие кнопки):

```c
gboolean g_main_context_iteration(GMainContext *context, gboolean may_block);
```

Первый параметр представляет контекст в виде набора источников, которые обрабатываются в основном цикле. Если параметру передается значение NULL, то используется контекст по умолчанию.

Второй параметр настраивает проверку источников событий. Если источники событий не готовы к обработке, а параметр имеет значение TRUE, то происходит ожидание готовности источника и возникновения событий. То есть, когда в приложении не происходит никаких событий, приложение будет их ожидать. Если передается значение FALSE, то ожидание источников событий не производится.

Итак, для взаимодействия с окном (банально закрыть окно при нажатии на крестик в правом верхнем углу окна) нам надо прослушивать события в цикле. В качестве условия для цикла мы можем проверять наличие окон во внутренней коллекции GTK — если окон нет, то прослушивать больше нечего и взаимодействовать не с чем. Соответственно приложение можно закрыть:

```c
#include <gtk/gtk.h>

int main (int argc, char **argv)
{
    // инициализируем набор виджетов
    gtk_init ();

    // создаем главное окно приложения
    GtkWidget *window = gtk_window_new();

    // отображаем окно
    gtk_window_present (GTK_WINDOW (window));
   
    // запускаем цикл прослушивания событий и взаимодействуем с пользователем
    // выходим из цикла, когда все окна приложения будут закрыты
    while (g_list_model_get_n_items (gtk_window_get_toplevels ()) > 0) {

        // ожидаем возникновение событий
        g_main_context_iteration(NULL, TRUE);
    }
    

    // когда окно приложения закрыто, выходим из приложения
    return 0;
}
```
