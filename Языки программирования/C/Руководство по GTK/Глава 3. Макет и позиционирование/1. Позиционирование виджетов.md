При создании виджетов и размещении их в окне приложения мы сталкиваемся с проблемой позиционирования. Так, при размещении виджета непосредственно внутри окна данный виджет по умолчанию центрируется. Например, возьмем кнопку:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);

    // определяем кнопку
    GtkWidget* btn = gtk_button_new_with_label("Hello World");

    gtk_window_set_child (GTK_WINDOW (window), btn);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

По результату мы видим, что кнопка центрируется и растягивается по всей площади окна:

Однако GTK определяет для виджетов ряд функций, которые позволяют эффективно позиционировать виджеты внутри контейнеров, например, внутри окна. Эти функции определены для типа GtkWidget, который по сути является базовым типом по отношению ко всем виджетам. Рассмотрим основные из них.

## Выравнивание виджета

Для установки выравнивания в типе GtkWidget, который является базовым для всех виджетов, определены два свойства:

- **halign**: выравнивание по горизонтали
- **valign**: выравнивание по вертикали

Оба свойства представляет перечисление GtkAlign, которое устанавливает принцип выравнивания и принимает следующие значения:

- **GTK_ALIGN_FILL**: растягивает виджет по всей площади контейнера, если не возможно растянуть, то центрирует виджет. Значение: 0
- **GTK_ALIGN_START**: прикрепляет виджет к левой (при выравнивании по горизонтали) или верхней (при выравнивании по вертикали) стороне контейнера, оставляя место справа или снизу. Значение: 1
- **GTK_ALIGN_END**: прикрепляет виджет к правой (при выравнивании по горизонтали) или нижней (при выравнивании по вертикали) стороне, оставляя место слева или сверху. Значение: 2
- **GTK_ALIGN_CENTER**: центрирует виджета внутри контейнера. Значение: 3
- **GTK_ALIGN_BASELINE_FILL/GTK_ALIGN_BASELINE**: выравнивает виджет по базовой линии. Значение: 4
- **GTK_ALIGN_BASELINE_CENTER**: растягивает по всей площади контейнера, но выравнивает по базовой линии. Значение: 5

Функция `gtk_widget_set_halign()` устанавливает свойство `halign`, то есть выравнивает виджет по горизонтали:

```c
void gtk_widget_set_halign (GtkWidget* widget, GtkAlign align)
```

Аналогично функция `gtk_widget_set_valign()` выравнивает виджет по вертикали, устанавливает свойство `valign`:

```c
void gtk_widget_set_valign (GtkWidget* widget, GtkAlign align)
```

Обе функции аналогичны. В качестве первого параметра передается виджет, а второй параметр представляет перечисление GtkAlign.

Нам необязательно использовать сразу обе функции: мы можем выравнивать виджет только по вертикали или только по горизонтали. Например, по умолчанию виджет центрируется, однако при этом также заполняет все пространство контейнера - окна. Но, допустим, нам надо только центрировать виджет без растяжения. В этом случае мы можем использовать значение `GTK_ALIGN_CENTER`:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    
    GtkWidget* btn = gtk_button_new_with_label("Hello World");
    // выравнивание по центру по горизонтали
    gtk_widget_set_halign(btn, GTK_ALIGN_CENTER); 
    // выравнивание по центру по вертикали
    gtk_widget_set_valign(btn, GTK_ALIGN_CENTER); 
    gtk_window_set_child (GTK_WINDOW (window), btn);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Аналогичная установка выравнивания в XML (файл "builder.ui"):

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">300</property>
    <property name="default-height">250</property>
    <child>
      <object class="GtkButton" id="button">
        <property name="label">Hello World</property>
        <property name="halign">GTK_ALIGN_CENTER</property>
        <property name="valign">GTK_ALIGN_CENTER</property>
      </object>
    </child>
  </object>
</interface>
```

И основной файл приложения, где загружается интерфейс:

```c
#include <gtk/gtk.h>

static void app_activate (GtkApplication *app, gpointer *user_data) {

    GtkBuilder* builder = gtk_builder_new_from_file("builder.ui");
    GObject* window = gtk_builder_get_object (builder, "window");
    g_object_unref (builder);
    gtk_window_set_application (GTK_WINDOW (window), app);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

Другой пример - разместим кнопку в самом начале окна - в левом верхнем углу окна. Для размещения виджета в начале применяется значение `GTK_ALIGN_START`. Для выравнивания по вертикали это выравнивание по верхней стороне, а при выравнивании по горизонтали - это расположение по левой кромке контейнера. Например:

```c
GtkWidget* btn = gtk_button_new_with_label("Hello World");
// выравнивание по левой стороне
gtk_widget_set_halign(btn, GTK_ALIGN_START); 
// выравнивание по верхней стороне
gtk_widget_set_valign(btn, GTK_ALIGN_START); 
```

Еще один пример - размещение виджета по центру внизу контейнера. В этом случае для размещения по горизонтали применяется значение `GTK_ALIGN_CENTER`, а по вертикали - `GTK_ALIGN_END` (размещение в конце - внизу по вертикали или справа по горизонтали)

```c
GtkWidget* btn = gtk_button_new_with_label("Hello World");
// размещение по центру
gtk_widget_set_halign(btn, GTK_ALIGN_CENTER); 
// размещение внизу
gtk_widget_set_valign(btn, GTK_ALIGN_END); 
```

## Отступы

Для управления отступами тип GtkWidget определяет следующие свойства:

- **margin-bottom**: отступ снизу
- **margin-end**: отступ от конца (в зависимости от направления - справа или слева)
- **margin-start**: отступ от начала (в зависимости от направления - справа или слева)
- **margin-top**: отступ сверху

Для установки этих свойств определены соответствующие функции:

- `gtk_widget_set_margin_bottom`: устанавливает отступ снизу
- `gtk_widget_set_margin_end`: устанавливает отступ справа
- `gtk_widget_set_margin_start`: устанавливает отступ слева
- `gtk_widget_set_margin_top`: устанавливает отступ сверху

Все они аналогичны:

```c
void gtk_widget_set_margin_start (GtkWidget* widget, int margin)
void gtk_widget_set_margin_end (GtkWidget* widget, int margin)
void gtk_widget_set_margin_top (GtkWidget* widget, int margin)
void gtk_widget_set_margin_bottom (GtkWidget* widget, int margin)
```

В качестве второго параметра передается значение отступа. Например:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    
    GtkWidget* btn = gtk_button_new_with_label("Hello World");

    // размещение в верхнем левом углу
    gtk_widget_set_halign(btn, GTK_ALIGN_START); 
    gtk_widget_set_valign(btn, GTK_ALIGN_START); 

    // отступ слева - 20
    gtk_widget_set_margin_start(btn, 20);
    // отступ сверху - 10
    gtk_widget_set_margin_top(btn, 10);

    gtk_window_set_child (GTK_WINDOW (window), btn);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

В данном случае устанавливаем отступ слева в 20 единиц:

```c
gtk_widget_set_margin_start(btn, 20);
```

и также отступ сверху в 10 единиц:

```c
gtk_widget_set_margin_top(btn, 10);
```
