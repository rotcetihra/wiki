Виджет GtkWindow позволяет установить содержимое окна с помощью функции `gtk_window_set_child()`. Однако одномоментно можно установить только один вложенный виджет, например, одну метку или кнопку. Если необходимо добавить два или более виджетов в окно, то нужен специальный виджет-контейнер. Фреймворк GTK имеет ряд контейнеров, и рассмотрим самым простой из них - виджет GtkBox. Он размещает два или более дочерних виджетов в строку или столбец.

Для создания GtkBox применяется функция

```c
GtkWidget* gtk_box_new (GtkOrientation orientation, int spacing)
```

Функция принимает два параметра. Параметр `orientation` представляет перечисление GtkOrientation и указывает, как вложенные элементы будут располагаться - в строку или в столбик. Оно может принимать два значения:

- **GTK_ORIENTATION_HORIZONTAL**: расположение в строку (значение 0)
- **GTK_ORIENTATION_VERTICAL**: расположение в столбик (значение 1)

Параметр `spacing` устанавливает отступы между элементами в строке/столбце.

Например, создание GtkBox расположением в строку и отступом между элементами в 10 единиц:

```c
GtkWidget* box = gtk_box_new(GTK_ORIENTATION_HORIZONTAL, 10);
```

Для добавления виджетов в GtkBox применяется функция `gtk_box_append()`:

```c
void gtk_box_append (GtkBox* box, GtkWidget* child)
```

Первый параметр - GtkBox, а второй - добавляемый в него виджет. Например, определим ряд кнопок:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);
    
    // создаем контейнер GtkBox, расположение в строку, отступ 10
    GtkWidget* box = gtk_box_new(GTK_ORIENTATION_HORIZONTAL, 10);
    gtk_widget_set_valign(box, GTK_ALIGN_START); // выравнивание по верхнему краю

    // создаем набор кнопок
    GtkWidget* btn1 = gtk_button_new_with_label("C");
    GtkWidget* btn2 = gtk_button_new_with_label("Java");
    GtkWidget* btn3 = gtk_button_new_with_label("Python");

    // добавляем все кнопки в GtkBox
    gtk_box_append (GTK_BOX (box), btn1);
    gtk_box_append (GTK_BOX (box), btn2);
    gtk_box_append (GTK_BOX (box), btn3);

    // устанавливаем GtkBox в качестве дочернего виджета для окна приложения
    gtk_window_set_child (GTK_WINDOW (window), box);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Здесь создаем три кнопки и последовательно добавляем их в GtkBox.

Единственное, что можно отметить, это то, что функция `gtk_box_new()`, как и многие другие функции создания виджетов, возвращает объект GtkWidget*. И для его преобразования в GtkBox применяется макрос `GTK_BOX`.

Аналогичное определение GtkBox в XML:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">300</property>
    <property name="default-height">250</property>
    <child>
      <object class="GtkBox" id="box">
        <property name="valign">GTK_ALIGN_START</property>
        <property name="orientation">GTK_ORIENTATION_HORIZONTAL</property>
        <property name="spacing">10</property>
        <child>
          <object class="GtkButton" id="btn1">
            <property name="label">C</property>
          </object>
        </child>
        <child>
          <object class="GtkButton" id="btn2">
            <property name="label">Java</property>
          </object>
        </child>
        <child>
          <object class="GtkButton" id="btn3">
            <property name="label">Python</property>
          </object>
        </child>
      </object>
    </child>
  </object>
</interface>
```

Для установки параметров GtkBox для виджета определено два свойства:

- **orientation**: направление виджета
- **spacing**: расстояние между вложенными виджетами

Аналогично можно расположить вложенные элементы в столбик:

```c
static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);
    
    // расположение в столбик, отступ 10
    GtkWidget* box = gtk_box_new(GTK_ORIENTATION_VERTICAL, 10);

    gtk_widget_set_halign(box, GTK_ALIGN_START); // выравнивание по левому краю

    GtkWidget* btn1 = gtk_button_new_with_label("C");
    GtkWidget* btn2 = gtk_button_new_with_label("Java");
    GtkWidget* btn3 = gtk_button_new_with_label("Python");

    gtk_box_append (GTK_BOX (box), btn1);
    gtk_box_append (GTK_BOX (box), btn2);
    gtk_box_append (GTK_BOX (box), btn3);

    gtk_window_set_child (GTK_WINDOW (window), box);
    gtk_window_present (GTK_WINDOW (window));
}
```

## Равномерное распределение пространства

Как видно на скриншоте выше, виджеты размещаются последовательно друг за другом с фиксированными отступами, но после последнего виджета есть много не занятого пространства. И может потребоваться равномерно распределить все виджеты по всей длине контейнера. Для этого применяется свойство `homogeneous` и соответственно функция `gtk_box_set_homogeneous()`

```c
void gtk_box_set_homogeneous (GtkBox* box, gboolean homogeneous)
```

Второй параметр - булевое значение TRUE или FALSE указывает, надо ли распределять виджеты равномерно по контейнеру. Например:

```c
static void app_activate (GApplication *app, gpointer *user_data) {
    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);

    GtkWidget* box = gtk_box_new(GTK_ORIENTATION_HORIZONTAL, 10);
    gtk_widget_set_valign(box, GTK_ALIGN_START);

    GtkWidget* btn1 = gtk_button_new_with_label("C");
    GtkWidget* btn2 = gtk_button_new_with_label("Java");
    GtkWidget* btn3 = gtk_button_new_with_label("Python");

    gtk_box_append (GTK_BOX (box), btn1);
    gtk_box_append (GTK_BOX (box), btn2);
    gtk_box_append (GTK_BOX (box), btn3);

    // равномерное распределение
    gtk_box_set_homogeneous (GTK_BOX (box), TRUE);

    gtk_window_set_child (GTK_WINDOW (window), box);
    gtk_window_present (GTK_WINDOW (window));
}
```

## Установка отступов

Функция `gtk_box_set_spacing()` позволяет установить отступы между элементами после создания контейнера:

```c
void gtk_box_set_spacing(GtkBox* box, int spacing)
```

Например:

```c
static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    
    // расположение в столбик, начальный отступ 0
    GtkWidget* box = gtk_box_new(GTK_ORIENTATION_VERTICAL, 0);

    gtk_widget_set_halign(box, GTK_ALIGN_START); // выравнивание по левому краю

    // добавляем ряд элементов
    GtkWidget* java = gtk_button_new_with_label("Java");
    GtkWidget* cpp = gtk_button_new_with_label("C++");
    GtkWidget* python = gtk_button_new_with_label("Python");

    gtk_box_append (GTK_BOX (box), cpp);
    gtk_box_append (GTK_BOX (box), java);
    gtk_box_append (GTK_BOX (box), python);

    // устанавливаем отступ в 20 единиц
    gtk_box_set_spacing(GTK_BOX (box), 20);

    gtk_window_set_child (GTK_WINDOW (window), box);
    gtk_window_present (GTK_WINDOW (window));
}
```

## Управление дочерними виджетами

Фреймворк GTK предоставляет ряд функций для управления вложенными виджетами:

- `gtk_box_prepend`: добавляет дочерний элемент в начало
- `gtk_box_remove`: удаляет дочерний виджет
- `gtk_box_insert_child_after`: вставляет дочерний элемент в указанную позицию

Первый параметр всех функций - контейнер GtkBox. Второй параметр функции `gtk_box_prepend()` - добавляемый в начало виджет:

```c
void gtk_box_prepend(GtkBox* box, GtkWidget* child)
```

Второй параметр функции `gtk_box_remove()` - удаляемый виджет:

```c
void gtk_box_remove(GtkBox* box, GtkWidget* child)
```

В функции `gtk_box_insert_child_after` второй параметр - добавляемый виджет, а третий параметр - виджет, после которого надо произвести вставку:

```c
void gtk_box_insert_child_after(GtkBox* box, GtkWidget* child, GtkWidget* sibling)
```

Пример применения:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    
    // расположение в столбик, отступ 10
    GtkWidget* box = gtk_box_new(GTK_ORIENTATION_VERTICAL, 10);

    gtk_widget_set_halign(box, GTK_ALIGN_START); // выравнивание по левому краю

    GtkWidget* java = gtk_button_new_with_label("Java");
    // добавляем в пустой контейнер java
    gtk_box_append (GTK_BOX (box), java);

    GtkWidget* cpp = gtk_button_new_with_label("C++");
    // добавляем С++ в самое начало
    gtk_box_prepend (GTK_BOX (box), cpp);

    GtkWidget* python = gtk_button_new_with_label("Python");
    // добавляем python после java
    gtk_box_insert_child_after(GTK_BOX (box), python, java);

    // удаляем java
    gtk_box_remove(GTK_BOX (box), java);

    gtk_window_set_child (GTK_WINDOW (window), box);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```
