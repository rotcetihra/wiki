Контейнер GtkGrid позволяет расположить вложенные виджеты в виде сетки. Его функция конструктора не принимает никаких параметров:

```c
GtkWidget* gtk_grid_new(void)
```

Для добавления виджетов применяется функция `gtk_grid_attach()`:

```c
void gtk_grid_attach (GtkGrid* grid,  
  GtkWidget* child,
  int column,
  int row,
  int width,
  int height
)
```

Параметры функции:

- **grid**: сам грид, в который добавляется виджет
- **child**: добавляемый виджет
- **column**: столбец грида, в который добавляется виджет
- **row**: строка грида, в который добавляется виджет
- **width**: количество столбцов, на которые растягивается виджет
- **height**: количество строк, на которые растягивается виджет

Например, определим грид, в который добавим три кнопки:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    
    // создаем грид
    GtkWidget* grid = gtk_grid_new ();


    GtkWidget* button1 = gtk_button_new_with_label ("Button 1");
    // помещаем кнопку в ячейку (0, 0) - 0-й столбец и 0-я строка, кнопка занимает один столбец и одну строку
    gtk_grid_attach (GTK_GRID (grid), button1, 0, 0, 1, 1);

    GtkWidget* button2 = gtk_button_new_with_label ("Button 2");
    // ячейка (0, 1) - 1-й столбец и 1-я строка 
    gtk_grid_attach (GTK_GRID (grid), button2, 1, 0, 1, 1);

    GtkWidget* button3 = gtk_button_new_with_label ("Button 3");
    // ячейка (1, 0) - 0-й столбец и 1-я строка
    gtk_grid_attach (GTK_GRID (grid), button3, 0, 1, 1, 1);

    gtk_window_set_child (GTK_WINDOW (window), grid);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Отсчет строк и столбцов начинается с 0. Например, для добавления первой кнопки применяется вызов:

```c
gtk_grid_attach (GTK_GRID (grid), button1, 0, 0, 1, 1);
```

То есть кнопка `button1` добавляется в ячейку грида, которая располагается на пересечении 0-й строки и 0-го столбца. При этом кнопка растягивается только на одну строку/на один столбец. Таким образом, каждая из 3-х кнопок занимает по одной ячейке.

```xml
          </object>
        </child>
```

Для установки расположения каждого виджета в XML внутри кода виджета применяется элемент `<layout>`, в котором с помощью свойств `row` и `column` устанавливается ячейка виджета:

```xml
<layout>
    <property name="column">1</property>
    <property name="row">0</property>
</layout>
```

И основной файл приложения, где загружается интерфейс:

```c
#include <gtk/gtk.h>

static void app_activate (GtkApplication *app, gpointer *user_data) {

    GtkBuilder* builder = gtk_builder_new_from_file("builder.ui");
    GObject* window = gtk_builder_get_object (builder, "window");
    g_object_unref (builder);
    gtk_window_set_application (GTK_WINDOW (window), app);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

Вкратце рассмотрим функционал виджета. Основные свойства:

- **baseline-row**: индекс строки, по которой выравниваются все остальные
- **column-homogeneous**: позволяет установить одинаковую ширину для всех столбцов
- **row-homogeneous**: позволяет установить одинаковую высоту для всех строк
- **row-spacing**: отступы между строками
- **column-spacing**: отступы между столбцами

Основные функции:

- `gtk_grid_attach`: добавляет виджет в грид.
- `gtk_grid_attach_next_to`: добавляет виджет в грид.
- `gtk_grid_get_baseline_row`: возвращает строку, по которой выравниваются остальные строки.
- `gtk_grid_get_child_at`: возвращает дочерний элемент грида, область которого располагается в ячейке грида в столбце, строке.
- `gtk_grid_get_column_homogeneous`: указывает, имеют ли все столбцы грида одинаковую ширину.
- `gtk_grid_get_column_spacing`: возвращает величину пространства между столбцами грида.
- `gtk_grid_get_row_homogeneous`: указывают, имеют ли все строки грида одинаковую высоту.
- `gtk_grid_get_row_spacing`: возвращает размер пространства между строками грида.
- `gtk_grid_insert_column`: вставляет столбец в указанную позицию.
- `gtk_grid_insert_next_to`: вставляет строку или столбец в указанную позицию.
- `gtk_grid_insert_row`: вставляет строку в указанную позицию.
- `gtk_grid_remove`: удаляет дочерний элемент из грида.
- `gtk_grid_remove_column`: удаляет столбец из грида.
- `gtk_grid_remove_row`: удаляет строку из грида.
- `gtk_grid_set_baseline_row`: устанавливает, какая строка определяет глобальную базовую линию для всей грида.
- `gtk_grid_set_column_homogeneous`: устанавливает, будут ли все столбцы грида иметь одинаковую ширину.
- `gtk_grid_set_column_spacing`: устанавливает величину пространства между столбцами грида.
- `gtk_grid_set_row_homogeneous`: устанавливает, будут ли все строки грида иметь одинаковую высоту.
- `gtk_grid_set_row_spacing`: устанавливает величину пространства между строками грида.

Разберем вкратце основной функционал виджета.

## Растяжение ячеек на несколько строк/столбцов

При необходимости виджет можно растянуть на ряд строк/столбцов:

```c
static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    
    // создаем грид
    GtkWidget* grid = gtk_grid_new ();

    //gtk_widget_set_halign(grid, GTK_ALIGN_START); // выравнивание по левому краю

    GtkWidget* button1 = gtk_button_new_with_label ("Button 1");
    gtk_grid_attach (GTK_GRID (grid), button1, 0, 0, 1, 1);

    GtkWidget* button2 = gtk_button_new_with_label ("Button 2");
    gtk_grid_attach (GTK_GRID (grid), button2, 1, 0, 1, 1);

    GtkWidget* button3 = gtk_button_new_with_label ("Button 3");
    // ячейка (1, 0) - растягиваем на 2 столбца
    gtk_grid_attach (GTK_GRID (grid), button3, 0, 1, 2, 1);

    gtk_window_set_child (GTK_WINDOW (window), grid);
    gtk_window_present (GTK_WINDOW (window));
}
```

Здесь кнопку `button3` растягиваем на 2 столбца:

```c
gtk_grid_attach (GTK_GRID (grid), button3, 0, 1, 2, 1);
```

Для растяжения виджета в XML применяются свойства:

- **column-span**: растягивает на определенное количество столбцов
- **row-span**: растягивает на определенное количество строк

Например, для растяжения последней кнопки на два столбца в XML мы могли бы написать так:

```xml
<object class="GtkButton" id="btn3">
    <property name="label">Button 3</property>
    <layout>
        <property name="column">0</property>
        <property name="row">1</property>
        <property name="column-span">2</property>
    </layout>
</object>
```

## Установка отступов

По умолчанию виджеты в ячейках прижимаются вплотную друг к другу. Но GtkGrid определяет свойства `column-spacing` и `row-spacing` для управления отступами между столбцами и строками соответственно. Для установки этих свойств предназначены функции `gtk_grid_set_column_spacing()` и `gtk_grid_set_row_spacing()`:

```c
void gtk_grid_set_row_spacing (GtkGrid* grid, guint spacing)
void gtk_grid_set_column_spacing (GtkGrid* grid, guint spacing)
```

Второй параметр устанавливается собственно отступ. Например:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    
    // создаем грид
    GtkWidget* grid = gtk_grid_new ();
    // отступ между строками в 20 единиц
    gtk_grid_set_row_spacing(GTK_GRID (grid), 20);
    // отступ между столбцами в 10 единиц
    gtk_grid_set_column_spacing(GTK_GRID (grid), 10);

    GtkWidget* button1 = gtk_button_new_with_label ("Button 1");
    gtk_grid_attach (GTK_GRID (grid), button1, 0, 0, 1, 1);

    GtkWidget* button2 = gtk_button_new_with_label ("Button 2");
    gtk_grid_attach (GTK_GRID (grid), button2, 1, 0, 1, 1);

    GtkWidget* button3 = gtk_button_new_with_label ("Button 3");
    gtk_grid_attach (GTK_GRID (grid), button3, 0, 1, 2, 1);

    gtk_window_set_child (GTK_WINDOW (window), grid);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

## Равномерное распределение виджетов

Также GtkGrid определяет два свойства для управления равномерным распределением строк и столбцов:

- **row-homogeneous**: если имеет значение TRUE, строки равномерно распределяются по всей высоте грида и имеют одну и ту же высоту
- **column-homogeneous**: если имеет значение TRUE, столбцы равномерно распределяются по всей ширине грида и имеют одинаковую ширину

Для установки этих свойств предназначены функции `set_row_homogeneous()` и `gtk_grid_set_column_homogeneous()`:

```c
void gtk_grid_set_row_homogeneous (GtkGrid* grid, gboolean homogeneous)
void gtk_grid_set_column_homogeneous (GtkGrid* grid, gboolean homogeneous)
```

Применение:

```c
static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    
    // создаем грид
    GtkWidget* grid = gtk_grid_new ();
    gtk_grid_set_row_spacing(GTK_GRID (grid), 20);
    gtk_grid_set_column_spacing(GTK_GRID (grid), 10);
    gtk_grid_set_column_homogeneous(GTK_GRID (grid), TRUE);
    gtk_grid_set_row_homogeneous(GTK_GRID (grid), TRUE);

    GtkWidget* button1 = gtk_button_new_with_label ("Button 1");
    gtk_grid_attach (GTK_GRID (grid), button1, 0, 0, 1, 1);

    GtkWidget* button2 = gtk_button_new_with_label ("Button 2");
    gtk_grid_attach (GTK_GRID (grid), button2, 1, 0, 1, 1);

    GtkWidget* button3 = gtk_button_new_with_label ("Button 3");
    gtk_grid_attach (GTK_GRID (grid), button3, 0, 1, 1, 1);

    GtkWidget* button4 = gtk_button_new_with_label ("Button 4");
    gtk_grid_attach (GTK_GRID (grid), button4, 1, 1, 1, 1);

    gtk_window_set_child (GTK_WINDOW (window), grid);
```

## Выравнивание виджетов в ячейках

По скриншоту из предыдущего примера можно увидеть, что виджеты (в данном случае кнопки) при помещении в ячейку грида растягиваются по всему пространству ячейки. Это стандартное поведение, тем не менее оно может быть нежелательным. Но с помощью стандартных свойств `halign` и `valign` и соответственно функций `gtk_widget_set_halign()` и `gtk_widget_set_valign()` мы можем управлять выравниванием виджетов внутри ячеек грида. Например, позиционируем один виджет строго в левом верхнем углу ячейки без растяжения на всю ячейку:

```c
static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    
    // создаем грид
    GtkWidget* grid = gtk_grid_new ();
    gtk_grid_set_row_spacing(GTK_GRID (grid), 20);
    gtk_grid_set_column_spacing(GTK_GRID (grid), 10);
    gtk_grid_set_column_homogeneous(GTK_GRID (grid), TRUE);
    gtk_grid_set_row_homogeneous(GTK_GRID (grid), TRUE);

    GtkWidget* button1 = gtk_button_new_with_label ("Button 1");
    gtk_grid_attach (GTK_GRID (grid), button1, 0, 0, 1, 1);
    gtk_widget_set_valign(button1, GTK_ALIGN_START);   // позиционирование вверху
    gtk_widget_set_halign(button1, GTK_ALIGN_START);   // позиционирование слева

    GtkWidget* button2 = gtk_button_new_with_label ("Button 2");
    gtk_grid_attach (GTK_GRID (grid), button2, 1, 0, 1, 1);

    GtkWidget* button3 = gtk_button_new_with_label ("Button 3");
    gtk_grid_attach (GTK_GRID (grid), button3, 0, 1, 1, 1);

    GtkWidget* button4 = gtk_button_new_with_label ("Button 4");
    gtk_grid_attach (GTK_GRID (grid), button4, 1, 1, 1, 1);

    gtk_window_set_child (GTK_WINDOW (window), grid);
    gtk_window_present (GTK_WINDOW (window));
}
```

В данном случае кнопка `button1` позиционируется в левом верхнем углу ячейки.
