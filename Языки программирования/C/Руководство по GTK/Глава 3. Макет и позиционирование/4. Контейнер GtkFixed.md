Контейнер GtkFixed в GTK представляет контейнер для размещения виджетов с абсолютным позиционированием. В отличие от других контейнеров, таких как GtkBox или GtkGrid, GtkFixed позволяет точно указывать координаты (X, Y) для каждого дочернего виджета и не выполняет автоматического управления макетом.

Основные характеристики GtkFixed:

- **Абсолютное позиционирование**: виджеты размещаются по точным координатам
- **Фиксированный размер**: контейнер не изменяет размеры автоматически
- **Простота концепции** и соответственно использования. Лучше использовать для простых форм или когда нужен полный контроль над позиционированием.
- **Низкая гибкость**: не подходит для адаптивных интерфейсов, в частности, для окон, которые должны менять размер, так как виджеты не будут перемещаться автоматически.

Для создания контейнера GtkFixed применяется функция `gtk_fixed_new()`, которая не принимает параметров:

```c
GtkWidget* fix = gtk_fixed_new();
```

Основные методы класса GtkFixed:

- `void gtk_fixed_put (GtkFixed* fixed, GtkWidget* widget, double x, double y)` — добавляет виджет на указанные координаты x и y
- `void gtk_fixed_move (GtkFixed* fixed, GtkWidget* widget, double x, double y)` — перемещает существующий виджет widget на точку с координатами x и y
- `void gtk_fixed_remove (GtkFixed* fixed, GtkWidget* widget)` — удаляет виджет
- `void gtk_fixed_get_child_position (GtkFixed* fixed, GtkWidget* widget, double* x, double* y)` — получает текущие координаты виджета

Таким образом, для добавления виджетов используется функция `gtk_fixed_put()`, которая принимает сам объект GtkFixed, добавляемый виджет и координаты X, Y:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    
    // создаем грид
    GtkWidget* fix = gtk_fixed_new ();

    GtkWidget* button1 = gtk_button_new_with_label ("Button 1");
    // Размещение кнопки в контейнере Fixed на координатах (50, 50)
    gtk_fixed_put(GTK_FIXED(fix), button1, 50, 50);

    GtkWidget* button2 = gtk_button_new_with_label ("Button 2");
    // Размещение кнопки в контейнере Fixed на координатах (150, 100)
    gtk_fixed_put(GTK_FIXED(fix), button2, 150, 100);

    gtk_window_set_child (GTK_WINDOW (window), fix);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

При абсолютном позиционировании мы можем применять к виджетам функцию `gtk_widget_set_size_request()` для установки абсолютных значений ширины и высоты:

```c
void gtk_widget_set_size_request (GtkWidget* widget, int width, int height)
```

Первый параметр - виджет, у которого устанавливаются размеры, а второй и третий - устанавливаемые ширина и высота соответственно. Эта функция задает значения свойств `width-request` и `height-request`. Пример применения:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    
    // создаем грид
    GtkWidget* fix = gtk_fixed_new ();

    GtkWidget* button1 = gtk_button_new_with_label ("Button 1");
    // ширина - 120 пикселей, высота - 30
    gtk_widget_set_size_request(button1, 120, 30);
    // Размещение кнопки в контейнере Fixed на координатах (50, 50)
    gtk_fixed_put(GTK_FIXED(fix), button1, 50, 50);

    GtkWidget* button2 = gtk_button_new_with_label ("Button 2");
    // ширина - 90 пикселей, высота - 50
    gtk_widget_set_size_request(button2, 90, 50);
    // Размещение кнопки в контейнере Fixed на координатах (150, 100)
    gtk_fixed_put(GTK_FIXED(fix), button2, 150, 100);

    gtk_window_set_child (GTK_WINDOW (window), fix);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

## Перемещение виджетов

С помощью функции `gtk_fixed_move()` можно перемещать уже добавленные виджеты:

```c
// Перемещение button1 на новые координаты (70, 70)
gtk_fixed_move(GTK_FIXED(fix), button1, 70, 70);
```
