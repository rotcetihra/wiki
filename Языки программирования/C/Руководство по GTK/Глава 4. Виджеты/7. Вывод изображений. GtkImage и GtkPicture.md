## GtkImage

Виджет GtkImage позволяет вывести изображение. Для создания виджета можно использовать одну из функций-конструкторов:

- `gtk_image_new`: создает пустой виджет GtkImage
- `gtk_image_new_from_file`: создает новый GtkImage, отображающий файл по определенному пути
- `gtk_image_new_from_gicon`: создает GtkImage, отображающий иконку из текущей темы иконок
- `gtk_image_new_from_icon_name`: создает GtkImage, отображающий иконку из текущей темы иконок
- `gtk_image_new_from_paintable`: создает новый GtkImage, отображающий объект для рисования GdkPaintable
- `gtk_image_new_from_resource`: создает новый GtkImage, отображающий файл ресурсов по определенному пути

Например, у меня одной папке с файлом программы располагается файл "flower.jpg". Используя функцию `gtk_image_new_from_file`, я могу вывести этот файл в приложении:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);

    // GtkImage отображает файл flower.jpg
    GtkWidget* imageView = gtk_image_new_from_file("flower.jpg");

    gtk_window_set_child (GTK_WINDOW (window), imageView);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Для установки источника изображения в XML можно использовать свойства, которые соответствуют применяемым конструкторам:

- file
- gicon
- resource
- paintable

Так, аналогичный пример интерфейса в XML (файл "builder.ui"):

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">250</property>
    <property name="default-height">200</property>
    <child>
        <object class="GtkImage" id="imageView">
          <property name="file">flower.jpg</property>
        </object>
    </child>
  </object>
</interface>
```

И основной файл приложения, где загружается интерфейс:

```c
#include <gtk/gtk.h>

static void app_activate (GtkApplication *app, gpointer *user_data) {

    GtkBuilder* builder = gtk_builder_new_from_file("builder.ui");
    GObject* window = gtk_builder_get_object (builder, "window");
    g_object_unref (builder);
    gtk_window_set_application (GTK_WINDOW (window), app);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

Стоит отметить, что мы можем динамически установить нужное изображение после создания виджета с помощью функции `gtk_image_set_from_file()`:

```c
void gtk_image_set_from_file (GtkImage* image, const char* filename)
```

## GtkPicture

Хотя виджет GtkImage и позволяет отобразить изображение, но больше подходит для отображения иконок и выводит изображение в том размере, который определяется приложением. Для более точной настройки вывода изображения лучше использовать другой виджет - GtkPicture.

Для GtkPicture также определен ряд функций-конструкторов:

- `gtk_picture_new`: создает новый пустой виджет GtkPicture
- `gtk_picture_new_for_file`: создает новый GtkPicture, отображающий указанный файл в виде объекта GFile*
- `gtk_picture_new_for_filename`: создает новый GtkPicture, отображающий файл по определенному пути
- `gtk_picture_new_for_paintable`: создает новый GtkPicture, отображающий объект GdkPaintable
- `gtk_picture_new_for_resource`: создает новый GtkPicture, отображающий ресурс по определенному адресу

Изменим GtkImage на GtkPicture:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);

    // GtkPicture отображает файл "flower.jpg"
    GtkWidget* imageView = gtk_picture_new_for_filename("flower.jpg");

    gtk_window_set_child (GTK_WINDOW (window), imageView);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

В отличие от GtkImage в GtkPicture изображение растягивается по ширине виджета с сохранением пропорций.

Аналогичный пример интерфейса в XML:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">250</property>
    <property name="default-height">200</property>
    <child>
        <object class="GtkPicture" id="imageView">
          <property name="file">flower.jpg</property>
        </object>
    </child>
  </object>
</interface>
```

Также, как и в случае с GtkImage, изображение можно установить динамически после создания виджета. Например, для установки файла по пути применяется функция `gtk_picture_set_filename()`:

```c
void gtk_picture_set_filename (GtkPicture* self, const char* filename)
```

## Управление размерами изображения

Ключевое отличие GtkPicture от GtkImage состоит в том, что GtkPicture позволяет изменять размеры выводимого изображения. В частности, функция `gtk_picture_set_content_fit()` устанавливает принцип размещения изображения внутри виджета:

```c
void gtk_picture_set_content_fit (GtkPicture* self, GtkContentFit content_fit)
```

Второй параметр может принимать одно из значений перечисления GtkContentFit:

- `GTK_CONTENT_FIT_FILL`: заполняет все пространство контейнера, не принимая во внимание соотношение сторон. Результирующее содержимое будет выглядеть растянутым, если его соотношение сторон отличается от соотношения сторон выделения. Значение: 0
- `GTK_CONTENT_FIT_CONTAIN`: масштабирует изображение, чтобы оно соответствовало размерам виджета, принимая во внимание его соотношение сторон. Значение: 1
- `GTK_CONTENT_FIT_COVER`: заполняет все пространство контейнера, принимая во внимание соотношение сторон содержимого. Результирующее содержимое будет выглядеть обрезанным, если его соотношение сторон отличается от соотношения сторон выделения. Значение: 2
- `GTK_CONTENT_FIT_SCALE_DOWN`: при необходимости масштабирует изображение, чтобы вписать его в размеры виджета. Если масштабирование не нужно, используется исходный размер изображения. Значение: 3

Например:

```c
GtkWidget* imageView = gtk_picture_new_for_filename("flower.jpg");
gtk_picture_set_content_fit(GTK_PICTURE(imageView), GTK_CONTENT_FIT_FILL);
```
