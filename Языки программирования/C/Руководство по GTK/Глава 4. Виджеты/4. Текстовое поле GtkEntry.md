Виджет GtkEntry представляет однострочное поле для ввода текста. Для создания виджета применяются две функции:

```c
GtkWidget* gtk_entry_new (void)

GtkWidget* gtk_entry_new_with_buffer (GtkEntryBuffer* buffer)
```

Функция `gtk_entry_new_with_buffer()` принимает буфер в виде объекта GtkEntryBuffer, в который добавляются вводимые символы. Например, простейшее текстовое поле:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    
    // создаем текстовое поле
    GtkWidget* text_box = gtk_entry_new();
    gtk_widget_set_valign(text_box, GTK_ALIGN_START);
    
    gtk_window_set_child (GTK_WINDOW (window), text_box);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

В итоге вверху окна появится текстовое поле ввода.

Определение метки в XML (файл "builder.ui"):

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">300</property>
    <property name="default-height">250</property>
    <child>
      <object class="GtkEntry" id="text_box">
        <property name="valign">GTK_ALIGN_START</property>
      </object>
    </child>
  </object>
</interface>
```

И основной файл приложения, где загружается интерфейс:

```c
#include <gtk/gtk.h>

static void app_activate (GtkApplication *app, gpointer *user_data) {

    GtkBuilder* builder = gtk_builder_new_from_file("builder.ui");
    GObject* window = gtk_builder_get_object (builder, "window");
    g_object_unref (builder);
    gtk_window_set_application (GTK_WINDOW (window), app);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

## Основные свойства виджета

Некоторые наиболее основные свойства виджета:

- attributes: список атрибутов Pango для применения к тексту поля.
- buffer: буфер, который фактически хранит текст.
- invisible-char: символ, который следует использовать при маскировке содержимого виджета («режим пароля»).
- invisible-char-set: установлен ли невидимый символ для GtkEntry.
- max-length: максимальное количество символов
- overwrite-mode: перезаписывается ли текст при вводе в GtkEntry.
- placeholder-text: текст, который будет отображаться в GtkEntry, когда он пуст и не получил фокус.
- text-length: Длина текста в GtkEntry.
- visibility: Должен ли виджет отображать «невидимый символ» вместо фактического текста («режим пароля»).

И также стоит отметить ряд свойств, которые унаследованы от базового типа GtkEditable:

- editable: можно ли редактировать содержимое виджета
- enable-undo: должны ли быть включены отмена/повтор для редактируемого элемента
- max-width-chars: максимальная ширина в символах
- text: текст виджета
- width-chars: количество символов, для которых нужно оставить место в виджете
- xalign: горизонтальное выравнивание от 0 (слева) до 1 (справа)

Из функций GtkEntry следует отметить следующие:

- `gtk_entry_get_alignment`: возвращает значение свойства xalign
- `gtk_entry_get_attributes`: возвращает список атрибутов GtkEntry
- `gtk_entry_get_buffer`: возвращает объект GtkEntryBuffer, который содержит текст виджета
- `gtk_entry_get_invisible_char`: возвращает символ, отображаемый вместо фактического текста в «режиме пароля»
- `gtk_entry_get_max_length`: возвращает максимально допустимую длину текста
- `gtk_entry_get_overwrite_mode`: возвращает, находится ли GtkEntry в режиме перезаписи
- `gtk_entry_get_placeholder_text`: возвращает текст, который будет отображаться, когда виджет пуст и не имеет фокус
- `gtk_entry_get_text_length`: возвращает текущую длину текста виджета
- `gtk_entry_get_visibility`: возвращает, виден ли текст
- `gtk_entry_set_alignment`: устанавливает значение свойства xalign
- `gtk_entry_set_attributes`: устанавливает PangoAttrList
- `gtk_entry_set_buffer`: устанавливает объект GtkEntryBuffer, который содержит текст для этого виджета
- `gtk_entry_set_invisible_char`: устанавливает символ, который будет использоваться вместо фактического текста в «режиме пароля»
- `gtk_entry_set_max_length`: устанавливает максимально допустимую длину содержимого виджета
- `gtk_entry_set_overwrite_mode`: устанавливает, будет ли текст перезаписываться при вводе в GtkEntry
- `gtk_entry_set_placeholder_text`: устанавливает текст, который будет отображаться в текстовом поле, когда оно пусто
- `gtk_entry_set_visibility`: устанавливает, будет ли видимо содержимое текстового поля или нет
- `gtk_entry_unset_invisible_char`: отменяет установку невидимого символа, чтобы снова использовался невидимый символ по умолчанию.

Кроме того, также можно отметить следующие функции из родительского типа GtkEditable:

- `gtk_editable_delete_selection`: удаляет текущий выделенный текст редактируемого
- `gtk_editable_delete_text`: удаляет последовательность символов
- `gtk_editable_get_chars`: возвращает последовательность символов
- `gtk_editable_get_enable_undo`: указывает, включены ли действия отмены/повтора для виджета
- `gtk_editable_get_max_width_chars`: возвращает желаемую максимальную ширину виджета в символах
- `gtk_editable_get_position`: возвращает текущую позицию курсора относительно начала содержимого виджета
- `gtk_editable_get_selection_bounds`: возвращает границу выделения виджета
- `gtk_editable_get_text`: возвращает содержимое виджета
- `gtk_editable_get_width_chars`: Получает количество символов пространства, зарезервированных для содержимого виджета
- `gtk_editable_insert_text`: вставляет переданный текст в содержимое виджета в определенную позицию
- `gtk_editable_select_region`: выбирает область текста
- `gtk_editable_set_enable_undo`: устанавливает, включены ли действия отмены/повтора для виджета
- `gtk_editable_set_max_width_chars`: устанавливает желаемую максимальную ширину в символах
- `gtk_editable_set_position`: устанавливает позицию курсора
- `gtk_editable_set_text`: устанавливает текст
- `gtk_editable_set_width_chars`: устанавливает длину в символах

## Установка/получение текста

Получение и установка текста для текстового поля являются одними из распространенных задач при работе с полем ввода. И здесь мы можем использовать свойство text, либо обратиться к функциям от базового типа GtkEditable - функциям `gtk_editable_set_text()` и `gtk_editable_get_text()`, которые управляют этим свойством:

```c
void gtk_editable_set_text (GtkEditable* editable, const char* text)

const char* gtk_editable_get_text (GtkEditable* editable)
```

Рассмотрим простое приложение, где по нажатию на кнопку введенный текст передается на метку:

```c
#include <gtk/gtk.h>

static GtkWidget* label;
static GtkWidget* entry;

static void click_button (GtkButton *btn) {
 
    if(!(entry&&label)) return;
    // получаем текст из текстового поля
    const char* text = gtk_editable_get_text(GTK_EDITABLE(entry));
    // устанавливаем этот текст для метки
    gtk_label_set_text(GTK_LABEL(label), text);
}

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    

    GtkWidget* box =  gtk_box_new(GTK_ORIENTATION_VERTICAL, 10);
    gtk_widget_set_valign(box, GTK_ALIGN_START); // выравнивание по верхнему краю

    // текст по умолчанию
    const char* text = "Hello";
    entry = gtk_entry_new();
    // устанавливаем текст по умолчанию
    gtk_editable_set_text(GTK_EDITABLE(entry), text);
    gtk_box_append (GTK_BOX (box), entry);

    label = gtk_label_new(text);
    gtk_box_append (GTK_BOX (box), label);


    GtkWidget* button = gtk_button_new_with_label("Set");
    // подключаем обработчик кнопки
    g_signal_connect (button, "clicked", G_CALLBACK (click_button), NULL);
    gtk_box_append (GTK_BOX (box), button);

    
    gtk_window_set_child (GTK_WINDOW (window), box);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Отмечу основные моменты. Прежде всего для упрощения кода метка и текстовое поле определены как глобальные переменные. При запуске приложения создаем текстовое поле и с помощью функции `gtk_editable_set_text()` устанавливаем текст по умолчанию:

```c
const char* text = "Hello";
entry = gtk_entry_new();
// устанавливаем текст по умолчанию
gtk_editable_set_text(GTK_EDITABLE(entry), text);
```

Для кнопки устанавливаем обработчик сигнала нажатия:

```c
g_signal_connect (button, "clicked", G_CALLBACK (click_button), NULL);
```

В обработчике нажатия - функции `click_button` с помощью функции `gtk_editable_get_text()` получаем введенный текст:

```c
const char* text = gtk_editable_get_text(GTK_EDITABLE(entry));
```

Таким образом, после ввода текста в текстовое поле и нажатия на кнопку этот текст также отобразится на метке.

Определение аналогичного интерфейса в XML:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">300</property>
    <property name="default-height">250</property>
    <child>
        <object class="GtkBox">
          <property name="orientation">vertical</property>
          <property name="spacing">10</property>
          <child>
              <object class="GtkEntry" id="entry">
                <property name="text">Hello</property>
              </object>
          </child>
          <child>
              <object class="GtkLabel" id="label"/>
          </child>
          <child>
              <object class="GtkButton" id="button">
                <property name="label">Set</property>
              </object>
          </child>
        </object>
    </child>
  </object>
</interface>
```

И основной файл приложения, где загружается интерфейс:

```c

    g_object_unref(app);
    return status;

```

## Обработка изменения текста

Для отслеживания изменения текста в текстовом поле для типа GtkEditable определен сигнал changed:

```c
void changed (GtkEditable* self, gpointer user_data)
```

Первый параметр сигнала - собственно текстовое поле ввода, а второй - дополнительные данные, передаваемые обработчику сигнала. Например, динамически обработаем ввод текста:

```c
#include <gtk/gtk.h>

void changed (GtkEditable* self, gpointer user_data) {

    // получаем текст из текстового поля
    const char* text = gtk_editable_get_text(self);
    GtkLabel* label = GTK_LABEL(user_data);
    // устанавливаем этот текст для метки
    gtk_label_set_text(label, text);
}
static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    
    GtkWidget* box =  gtk_box_new(GTK_ORIENTATION_VERTICAL, 10);
    gtk_widget_set_valign(box, GTK_ALIGN_START); // выравнивание по верхнему краю

    // текст по умолчанию
    const char* text = "Hello";
    GtkWidget* entry = gtk_entry_new();
    // устанавливаем текст по умолчанию
    gtk_editable_set_text(GTK_EDITABLE(entry), text);
    gtk_box_append (GTK_BOX (box), entry);

    GtkWidget* label = gtk_label_new(text);
    gtk_box_append (GTK_BOX (box), label);

    // подключаем обработчик ввода текста
    g_signal_connect (entry, "changed", G_CALLBACK (changed), label);

    gtk_window_set_child (GTK_WINDOW (window), box);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Отмечу основные моменты. Подключаем обработчик для сигнала "changed":

```c
g_signal_connect (entry, "changed", G_CALLBACK (changed), label);
```

В качестве дополнительного параметра передаем метку label, благодаря чему уходим от использования глобальных переменных. В обработчике сигнала получаем текстовое поле, метку и передаем в метку введенный текст:

```c
void changed (GtkEditable* self, gpointer user_data) {

    const char* text = gtk_editable_get_text(self);
    GtkLabel* label = GTK_LABEL(user_data);
    gtk_label_set_text(label, text);
}
```

## Текст-подсказка

Для установки текста-подсказки, который отображается при отсутствии ввода, применяется свойство `placeholder_text` и соответственно функция `gtk_entry_set_placeholder_text()`:

```c
void gtk_entry_set_placeholder_text (GtkEntry* entry, const char* text)
```

В качестве второго параметра передается текст подсказки:

```c
GtkWidget* text_box = gtk_entry_new();
gtk_entry_set_placeholder_text(GTK_ENTRY(text_box), "Введите текст");
```

## Выравнивание

В зависимости от письменности может различаться направление письма. Например, в европейсиких и многих других языках применяется левостороннее письмо с направлением слева направо. Однако в ряде языков, как в арабском, фарси и т.д. применяется правостороннее письмо. Для управления направлением текста GTK предоставляет свойство xalign и связанные с ним функции `gtk_entry_set_alignment()`(устанавливает направление) и `gtk_entry_get_alignment()` (возвращает тип направления):

```c
void gtk_entry_set_alignment (GtkEntry* entry, float xalign)

float gtk_entry_get_alignment (GtkEntry* entry)
```

В качестве значения xalign в первую функцию и в качестве результата из второй функции возвращается значение типа float - от 0 (выравнивание слева) до 1 (выравнивание справа). Например:

```c
static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);


    GtkWidget* entry = gtk_entry_new();
    gtk_widget_set_valign(entry, GTK_ALIGN_START);
    gtk_editable_set_text(GTK_EDITABLE(entry), "Hello World");
    // выравнивание справа
    gtk_entry_set_alignment(GTK_ENTRY(entry), 1);

    gtk_window_set_child (GTK_WINDOW (window), entry);
    gtk_window_present (GTK_WINDOW (window));
}
```

## Максимальная длина текста

Функции `gtk_entry_set_max_length()` и `gtk_entry_get_max_length()` управляют свойством `max-length` и позволяют соответственно установить и получить максимальную длину текста в символах:

```c
void gtk_entry_set_max_length (GtkEntry* entry, int max)
int gtk_entry_get_max_length (GtkEntry* entry)
```

Второй параметр функции `gtk_entry_set_max_length()` представляет максимальную длину, которая должна находиться в диапазоне 0-65536. Если значение 0, то ограничений на количество символов нет. Например, установим длину в 20 символов:

```c
GtkWidget* entry = gtk_entry_new();

gtk_entry_set_max_length(GTK_ENTRY(entry), 20);
```

## Управление видимостью символов

Свойство `visibility` при значении FALSE скрывает вводимые символы, заменяя их маскировочным символом. По умолчанию это символ "•" (то есть жирная точка). А свойство `invisible-char` позволяет установить другой маскировочный символ. Для установки этих свойств GTK предоставляет функции `gtk_entry_set_visibility()` и `gtk_entry_set_invisible_char()` соответственно. Вкратце применение функций:

```c
GtkWidget* entry = gtk_entry_new();
// Видимость вводимых символов (полезно для паролей)
gtk_entry_set_visibility(GTK_ENTRY(entry), FALSE);
// Замещающий символ для скрытого текста
gtk_entry_set_invisible_char(GTK_ENTRY(entry), 'x');
```

В итоге все вводимые символы будут заменяться на символ "x".

## Управление текстом GtkEntry

Рассмотрим основные функции для GtkEntry, которые позволяют управлять текстом:

```c
void gtk_editable_insert_text (GtkEditable* editable, const char* text, int length, int* position)
```

Вставка текста text длиной length (длина в байтах!) в текущую позицию курсора. Через параметр position возвращает позицию вставки. Если передается длина -1, то вставляется весь текст.

```c
void gtk_editable_delete_text (GtkEditable* editable, int start_pos, int end_pos)
```

Удаление текста между указанными позициями start_pos и end_pos.

Пример применения функций:

```c
GtkWidget* entry = gtk_entry_new();

// Вставка текста в текущую позицию курсора
const char* text = "новый текст";
int pos = 0;
gtk_editable_insert_text(GTK_EDITABLE(entry), text, -1, &pos);

int startPos = 0;  // начальная позиция
int endPos = 3; // конечная позиция

// Удаление текста между указанными позициями
gtk_editable_delete_text(GTK_EDITABLE(entry), startPos, endPos);
```
