Виджет GtkLabel является самым простым и представляет метку, предназначенную для вывода некоторого текста. Для создания метки применяется функция gtk_label_new(), в которую в качестве параметра передается текст метки. Например:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);
    
    // создаем метку 
    GtkWidget *label = gtk_label_new ("Hello World");
    // добавляем метку в окно
    gtk_window_set_child (GTK_WINDOW (window), label);

    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

В результате в окне по центру будет размещена метка с текстом "Hello World".

Определение метки в XML (файл "builder.ui"):

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">300</property>
    <property name="default-height">250</property>
    <child>
      <object class="GtkLabel" id="label">
        <property name="label">Hello World</property>
      </object>
    </child>
  </object>
</interface>
```

И основной файл приложения, где загружается интерфейс:

```c
#include <gtk/gtk.h>

static void app_activate (GtkApplication *app, gpointer *user_data) {

    GtkBuilder* builder = gtk_builder_new_from_file("builder.ui");
    GObject* window = gtk_builder_get_object (builder, "window");
    g_object_unref (builder);
    gtk_window_set_application (GTK_WINDOW (window), app);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

## Свойства и функции для GtkLabel

Вкратце рассмотрим функционал виджета. Основные свойства:

- attributes: список атрибутов стиля для применения к тексту метки
- ellipsize: предпочтительное место для многоточия строки, если в метке недостаточно места для отображения всей строки
- justify: выравнивание строк в тексте метки относительно друг друга
- label: содержимое метки (текст)
- lines: количество строк, которым должна быть ограничен многострочный текст метки
- max-width-chars: желаемая максимальная ширина в символах
- natural-wrap-mode: способ переноса строк
- selectable: можно ли выделить текст метки мышью
- single-line-mode: является ли текст однострочным 
- use-markup: использует ли текст метки вразметку Pango
- width-chars: желаемая ширина в символах
- wrap: указывает, будет ли текст метки будет переноситься, если станет слишком широким
- wrap-mode: управляет тем, как выполняется перенос строк
- xalign: горизонтальное выравнивание текста метки
- yalign: вертикальное выравнивание текста
 
Основные функции:

- gtk_label_get_attributes: возвращает список атрибутов метки
- gtk_label_get_justify: возвращает выравнивание метки
- gtk_label_get_label: возвращает текст из метки
- gtk_label_get_layout: возвращает макет Pango, используемый для отображения метки
- gtk_label_get_layout_offsets: возвращает координаты, в которых метка будет отображать свой макет Pango
- gtk_label_get_lines: возвращает количество строк, которым должна быть ограничена многострочная метка
- gtk_label_get_max_width_chars: возвращает максимальную ширину метки в символах
- gtk_label_get_natural_wrap_mode: возвращает естественный режим переноса строк, используемый меткой
- gtk_label_get_selectable: возвращает, можно ли выбрать метку
- gtk_label_get_selection_bounds: возвращает выбранный диапазон символов в метке
- gtk_label_get_single_line_mode: возвращает, находится ли метка в однострочном режиме
- gtk_label_get_text: возвращает текст метки
- gtk_label_get_use_markup: возвращает, интерпретируется ли текст метки как разметка Pango
- gtk_label_get_width_chars: возвращает желаемую ширину метки в символах
- gtk_label_get_wrap: возвращает, переносятся ли строки в метке автоматически
- gtk_label_get_wrap_mode: возвращает режим переноса строк, используемый меткой
- gtk_label_get_xalign: возвращает свойство xalign метки
- gtk_label_get_yalign: возвращает свойство yalign метки
- gtk_label_select_region: выбирает диапазон символов в метке, если метка выбираемая
- gtk_label_set_attributes: устанавливает атрибуты к тексту метки
- gtk_label_set_justify: устанавливает выравнивание строк в метке относительно друг друга
- gtk_label_set_label: устанавливает текст метки
- gtk_label_set_lines: устанавливает количество строк, которыми должна быть ограничена многострочная метка
- gtk_label_set_markup: устанавливает разметкиу метки
- gtk_label_set_max_width_chars: устанавливает максимальную ширину метки в символах
- gtk_label_set_natural_wrap_mode: Выбирает перенос строк для запроса естественного размера
- gtk_label_set_selectable: Делает текст в метке выбираемым
- gtk_label_set_single_line_mode: устанавливает, находится ли метка в однострочном режиме
- gtk_label_set_text: устанавливает текст метки
- gtk_label_set_use_markup: устанавливает, содержит ли текст метки разметку
- gtk_label_set_width_chars: устанавливает желаемую ширину в символах для метки
- gtk_label_set_wrap: устанавливает перенос строк внутри метки
- gtk_label_set_wrap_mode: управляет тем, как выполняется перенос строк
- gtk_label_set_xalign: устанавливает свойство xalign метки
- gtk_label_set_yalign: устанавливает свойство yalign метки

Разберем вкратце основной функционал виджета.

## Установка текста

Установить текст мы можем непосредственно при создании метки, передавая в функцию gtk_label_new() какую-нибудь строку. Однако также можно установить текст с помощью функции gtk_label_set_text(), в которую в качестве второго параметра передается устанавливаемый текст:

```c
GtkWidget *label = gtk_label_new("Hello Word");

gtk_label_set_text(GTK_LABEL(label), "Hello GTK!");
```

Данная функция может быть полезна, если нам надо динамически изменять ранее установленный текст.

С помощью стандартной последовательности переноса строки "\n" можно переносить текст на метке:

```c
GtkWidget *label = gtk_label_new ("Hello Word\nHello GTK!");
```

## Перенос текста

Метки могут автоматически переносить текст с помощью функции gtk_label_set_wrap(), если ширина метки не вмещает весь текст:

```c
void gtk_label_set_wrap (GtkLabel* self, gboolean wrap)
```

Второй параметр указывает, надо ли переносить текст (если значение TRUE) или нет (если значение FALSE). Например:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
    
    const char* text = "Ежели, положим, вы едете с охоты домой и желаете с аппетитом пообедать, "
                    "то никогда не нужно думать об умном; умное да ученое всегда аппетит отшибает.";
    GtkWidget* label = gtk_label_new (text);
    // расположение метки в верхнем левом углу
    gtk_widget_set_valign(label, GTK_ALIGN_START);
    gtk_widget_set_halign(label, GTK_ALIGN_START);
    // отступы по 10 единиц
    gtk_widget_set_margin_top(label, 10);
    gtk_widget_set_margin_start(label, 10);
    gtk_widget_set_margin_end(label, 10);

    gtk_label_set_wrap(GTK_LABEL(label), TRUE);  // включаем переносы

    gtk_window_set_child (GTK_WINDOW (window), label);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Кроме того, для меток доступна функция gtk_label_set_wrap_mode(), которая управляет переносом слов:

```c
void gtk_label_set_wrap_mode (GtkLabel* self, PangoWrapMode wrap_mode)
```

Второй параметр функции представляет перечисление PangoWrapMode, которое имеет следующие значения:

- PANGO_WRAP_WORD: переносит текст, разрывая строки между словами (значение по умолчанию)
- PANGO_WRAP_CHAR: переносит текст, разрывая строки везде, где может появиться курсор (обычно между символами)
- PANGO_WRAP_WORD_CHAR: переносит текст, разрывая строки между словами или, если этого недостаточно, также между графемами
- PANGO_WRAP_NONE: переносы отсутствуют

Например, в примере выше идет перенос по словам. Но установим перенос с разрывом между символами и для этого к определению метки добавим строку:

```c
gtk_label_set_wrap_mode(GTK_LABEL(label), PANGO_WRAP_CHAR); // переносы между символами
```

## Выравнивание текста

С помощью функции gtk_label_set_justify() можно задать выравнивание текста:

```c
void gtk_label_set_justify ( GtkLabel* self, GtkJustification jtype)
```

Второй параметр представляет перечисление, которое имеет следующие значения:

- GTK_JUSTIFY_LEFT Текст размещается по левому краю метки (Значение 0). Это значение по умолчанию
- GTK_JUSTIFY_RIGHT Текст размещается по правому краю метки (Значение 1)
- GTK_JUSTIFY_CENTER Текст размещается по центру метки (Значение 2)
- GTK_JUSTIFY_FILL Текст размещается и распределяется по всей метке (Значение 3)

Например, выравнивание текста по центру:

```c
GtkWidget *label = gtk_label_new ("That no man's fit to rule the world alone. A man will die, but not his ideas");
gtk_label_set_width_chars(GTK_LABEL(label), 42);
gtk_label_set_wrap(GTK_LABEL(label), TRUE);
gtk_label_set_justify(GTK_LABEL(label), GTK_JUSTIFY_CENTER);
```

Аналог в XML:

```xml
<object class="GtkLabel" id="label">
    <property name="width_chars">42</property>
    <property name="wrap">true</property>
    <property name="justify">GTK_JUSTIFY_CENTER</property>
    <property name="label">That no man's fit to rule the world alone. A man will die, but not his ideas</property>
</object>
```

## Выравнивание метки

Если надо задать, как метка в целом выравнивается в доступном пространстве, то можно применять функции gtk_label_set_xalign() (для выравнивание по горизонтали) и gtk_label_set_yalign (для выравнивания по вертикали):

```c
void gtk_label_set_xalign (GtkLabel* self, float xalign)

void gtk_label_set_yalign (GtkLabel* self, float yalign)
```

В качестве второго параметра обе функции принимают значение от 0 до 1, которое собственно и устанавливает выравнивание. Например, расположим метку ближе к верхнему левому углу окна:

```c
GtkWidget *label = gtk_label_new ("Hello METANIT.COM!");

gtk_label_set_xalign(GTK_LABEL(label), 0.1);
gtk_label_set_yalign(GTK_LABEL(label), 0.15);
```

Аналог в XML:

```xml
<object class="GtkLabel" id="label">
    <property name="xalign">0.1</property>
    <property name="yalign">0.15</property>
    <property name="label">Hello METANIT.COM!</property>
</object>
```

## Форматирование текста

GtkLabel поддерживает некоторое форматирование текста (изменение цветов, шрифтов и т. д.). Для форматирования текста можно применять функцию gtk_label_set_markup():

```c
void gtk_label_set_markup ( GtkLabel* self, const char* str)
```

Разметка, переданная в gtk_label_set_markup(), должна быть допустимым XML; например, литеральные символы <, > и & должны быть экранированы как &lt;, &gt; и &amp;. Например, применим форматирование шрифта текста на метке:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);
    
    // создаем метку 
    GtkWidget *label = gtk_label_new (NULL);
    gtk_label_set_markup (GTK_LABEL (label), "<span weight=\"bold\" font=\"Verdana 16\">Hello METANIT.COM</span>");

    gtk_window_set_child (GTK_WINDOW (window), label);

    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Обратите внимание, что изначально для метки не устанавливается текст, так как передается NULL: `gtk_label_new (NULL)`

При форматировании передаем разметку в xml, устанавливая два атрибута метки - weight и font:

```c
gtk_label_set_markup (GTK_LABEL (label), "<span weight=\"bold\" font=\"Verdana 16\">Hello METANIT.COM</span>");
```

`weight` устанавливает толщину текста. Так, значение "bold" устанавливает жирный текст. А атрибуту "font" передаются название стиля шрифта и размер шрифта (можно использовать одно из этих значений)

Если в gtk_label_set_markup() передается текст, полученный от пользователя, файла или сети, его следует экранировать с помощью `g_markup_escape_text()` или `g_markup_printf_escaped()`:

```c
static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);
    
    // создаем метку 
    GtkWidget *label = gtk_label_new (NULL);

    const char *str = "Hello bold";
    const char *format = "<span font=\"16\">%s</span>";
    char *markup = g_markup_printf_escaped (format, str);
    gtk_label_set_markup (GTK_LABEL (label), markup);
    g_free(markup);

    gtk_window_set_child (GTK_WINDOW (window), label);
    gtk_window_present (GTK_WINDOW (window));
}
```

Определение разметки в XML:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">300</property>
    <property name="default-height">250</property>
    <child>
      <object class="GtkLabel" id="label">
        <property name="use-markup">true</property>
        <property name="label"><span weight="bold" font="Verdana 16">Hello METANIT.COM</span></property>
      </object>
    </child>
  </object>
</interface>
```

Обратите внимание, что в этом случае также надо установить свойство `use-markup` в true, чтобы текст интерпертировался как разметка.
