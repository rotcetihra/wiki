Виджет GtkTextView представляет многострочное текстовое поле. Для создания виджета применяется одна из функций-конструкторов:

```c
GtkWidget* gtk_text_view_new (void)
GtkWidget* gtk_text_view_new_with_buffer (GtkTextBuffer* buffer)
```

Вторая функция в качестве параметра принимает объект GtkTextBuffer - своего рода текстовый буфер для текстового поля.

Например, создадим данный виджет:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);

    GtkWidget* textView = gtk_text_view_new ();

    gtk_window_set_child (GTK_WINDOW (window), textView);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

В результате мы получим пустое многострочное текстовое поле, в которое можем вводить текст.

Аналогичное создание виджета в XML (файл "builder.ui"):

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">250</property>
    <property name="default-height">200</property>
    <child>
      <object class="GtkTextView" id="textView" />
    </child>
  </object>
</interface>
```

И основной файл приложения, где загружается интерфейс:

```c
#include <gtk/gtk.h>

    GtkBuilder* builder = gtk_builder_new_from_file("builder.ui");
    GObject* window = gtk_builder_get_object (builder, "window");
    g_object_unref (builder);
    gtk_window_set_application (GTK_WINDOW (window), app);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

## Свойства GtkTextView

Из свойств виджета следует отметить следующие:

- buffer: текстовый буфер, который содержит введенный текст
- cursor-visible: отображается ли курсор
- editable: может ли пользователь изменять текст
- indent: величина отступа абзаца в пикселях
- justification: выравнивание по левому или правому краю или по центру
- monospace: должен ли текст отображаться моноширинным шрифтом
- overwrite: перезаписывает ли введенный текст существующее содержимое
- bottom-margin: отступ снизу
- left-margin: отступ слева
- right-margin: отступ справа
- top-margin: отступ сверху
- wrap-mode: режим переноса символов

Для управления этими свойствами GTK предоставляет следующие виджеты:

- `gtk_text_view_get_bottom_margin`: возвращает нижнее поле для текста в text_view
- `gtk_text_view_get_buffer`: возвращает текстовый буфер GtkTextBuffer, отображаемый этим текстовым представлением
- `gtk_text_view_get_cursor_visible`: возвращает TRUE, если курсор видимый, иначе возвращается FALSE
- `gtk_text_view_get_editable`: возвращает TRUE, если текст виджета доступен для редактирования
- `gtk_text_view_get_indent`: возвращает отступ по умолчанию для абзацев
- `gtk_text_view_get_justification`: возвращает выравнивание по умолчанию для абзацев
- `gtk_text_view_get_left_margin`: возвращает отступ слева
- `gtk_text_view_get_monospace`: возвращает TRUE, если используется шрифт monospace
- `gtk_text_view_get_overwrite`: возвращает TRUE, если виджет перезаписывает свой текст при вводе
- `gtk_text_view_get_right_margin`: возвращает отступ справа 
- `gtk_text_view_get_top_margin`: возвращает отступ сверху
- `gtk_text_view_get_wrap_mode`: возвращает режим переноса строк
- `gtk_text_view_remove`: удаляет дочерний виджет из text_view
- `gtk_text_view_set_bottom_margin`: устанавливает нижнее поле для текста в text_view
- `gtk_text_view_set_buffer`: устанавливает текстовый буфер виджета
- `gtk_text_view_set_editable`: устанавливает возможность редактирования
- `gtk_text_view_set_indent`: устанавливает отступ для абзацев
- `gtk_text_view_set_justification`: устанавливает выравнивание текста
- `gtk_text_view_set_left_margin`: устанавливает отступ слева
- `gtk_text_view_set_monospace`: устанавливает, должен ли использоваться шрифт monospace
- `gtk_text_view_set_overwrite`: устанавливает режим перезаписи GtkTextView
- `gtk_text_view_set_right_margin`: устанавливает отступ справа
- `gtk_text_view_set_top_margin`: устанавливает отступ сверху
- `gtk_text_view_set_wrap_mode`: устанавливает режим переноса строк

## Текстовый буфер

Если нам необходимо взаимодействовать с текстом виджета, то нам потребуется тип GtkTextBuffer, который представляет введенный в текстовое поле текст. Распространенная задача - установить для виджета начальный текст. В этом случае мы можем воспользоваться второй функцией-конструктором, которая принимает объект GtkTextBuffer. Либо в качестве альтернативы мы можем получить текстовый буфер у ранее созданного виджета с помощью функции `gtk_text_view_get_buffer()`:

```c
GtkTextBuffer* gtk_text_view_get_buffer (GtkTextView* text_view)
```

Воспользуемся вторым способом:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);

    // текст для вывода в текстовом поле
    char* text =
      "Не говорите, душа моя Григорий Саввич, утка или бекас могут гусю десять очков вперед дать. "
      "В гусином букете нет нежности и деликатности. Забористее всего пахнет молодой лук, когда, знаете ли, "
      "начинает поджариваться и, понимаете ли, шипит, подлец, на весь дом.";

    GtkWidget* textView = gtk_text_view_new ();

    // получаем текстовый буфер
    GtkTextBuffer* buffer = gtk_text_view_get_buffer (GTK_TEXT_VIEW (textView));
    // устанавливаем текстовый буфер
    gtk_text_buffer_set_text (buffer, text, -1);

    gtk_window_set_child (GTK_WINDOW (window), textView);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Вначале получаем текстовый буфер виджета с помощью функции `gtk_text_view_get_buffer()`:

```c
GtkTextBuffer* buffer = gtk_text_view_get_buffer (GTK_TEXT_VIEW (textView));
```

Затем устанавливаем текст виджета:

```c
gtk_text_buffer_set_text (buffer, text, -1);
```

Второй параметр представляет устанавливаемый текст. В качестве третьего параметра передается количество символов текста. Если же нам надо вывести весь текст, то передается -1, как в примере выше.

## Перенос текста

Но на скриншоте выше мы видим проблему: наш текст выходит за границы видимой области и не переходит на новую строку. Для управления размещением текста GTK предоставляет свойство `wrap-mode`. Для его установки применяется функция `gtk_text_view_set_wrap_mode()`:

```c
void gtk_text_view_set_wrap_mode (GtkTextView* text_view, GtkWrapMode wrap_mode)
```

В качестве второго параметра передается одно из значений перечисления GtkWrapMode:

- `GTK_WRAP_NONE`: переносы отсутствуют. Значение: 0
- `GTK_WRAP_CHAR`: переносит текст, разрывая строки везде, где может появиться курсор (обычно между символами). Значение: 1
- `GTK_WRAP_WORD`: переносит текст, разрывая строки между словами. Значение: 2
- `GTK_WRAP_WORD_CHAR`: переносит текст, разрывая строки между словами или, если этого недостаточно, также между графемами. Значение: 3

Например:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);

    // текст для вывода в текстовом поле
    char* text =
      "Не говорите, душа моя Григорий Саввич, утка или бекас могут гусю десять очков вперед дать. "
      "В гусином букете нет нежности и деликатности. Забористее всего пахнет молодой лук, когда, знаете ли, "
      "начинает поджариваться и, понимаете ли, шипит, подлец, на весь дом.";

    GtkWidget* textView = gtk_text_view_new ();

    GtkTextBuffer* buffer = gtk_text_view_get_buffer (GTK_TEXT_VIEW (textView));
    gtk_text_buffer_set_text (buffer, text, -1);

    // устанавливаем перенос по символам
    gtk_text_view_set_wrap_mode (GTK_TEXT_VIEW (textView), GTK_WRAP_WORD_CHAR);

    gtk_window_set_child (GTK_WINDOW (window), textView);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Аналогичная установка в XML:

```xml
<object class="GtkTextView" id="textView">
    <property name="wrap-mode">word-char</property>
    ...............
</object>
```

Или так:

```xml
<object class="GtkTextView" id="textView">
    <property name="wrap-mode">GTK_WRAP_WORD_CHAR</property>
    ...............
</object>
```

## Отступы

GTK также предоставляет ряд свойств, которые позволяют управлять отступами внутри виджета от его границ до текста:

- bottom-margin: отступ снизу
- left-margin: отступ слева
- right-margin: отступ справа
- top-margin: отступ сверху

Для их установки предназначены соответственно следующие функции:

- `gtk_text_view_set_bottom_margin()`: устанавливает отступ от нижней границы
- `gtk_text_view_set_left_margin()`: устанавливает отступ от левой границы
- `gtk_text_view_set_right_margin()`: устанавливает отступ от правой границы
- `gtk_text_view_set_top_margin()`: устанавливает отступ от верхней границы

Эти функции однотипны, и в качестве второго параметра принимают отступ в виде значения типа int:

## Размер строк

Свойство `pixels-inside-wrap` позволяет управлять высотой строк в рамках параграфа (пространством между строками). Для установки свойства применяется функция `gtk_text_view_set_pixels_inside_wrap()`:

```c
void gtk_text_view_set_pixels_inside_wrap (
  GtkTextView* text_view,
  int pixels_inside_wrap
)
```

Второй параметр представляет количество пикселей между строками. Например:

## Добавление прокрутки

Проблема GtkTextView заключается в том, что по умолчанию при увеличении количества строк, многострочное поле автоматически увеличивает в длине, чтобы вместить все строки. В примерах выше это автоматически приведет к увеличению длины окна, которое должно вместить удлинившееся многострочное поле. Это не очень удобно. Поэтому обычный сценарий заключается в том, чтобы поместить многострочное поле в виджет с прокруткой - GtkScrolledWindow:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);

    // текст для вывода в текстовом поле
    char* text =
      "Не говорите, душа моя Григорий Саввич, утка или бекас могут гусю десять очков вперед дать. "
      "В гусином букете нет нежности и деликатности. Забористее всего пахнет молодой лук, когда, знаете ли, "
      "начинает поджариваться и, понимаете ли, шипит, подлец, на весь дом.";

    GtkWidget* textView = gtk_text_view_new();
    GtkTextBuffer* buffer = gtk_text_view_get_buffer (GTK_TEXT_VIEW (textView));
    gtk_text_buffer_set_text (buffer, text, -1);
    // устанавливаем перенос по символам
    gtk_text_view_set_wrap_mode (GTK_TEXT_VIEW (textView), GTK_WRAP_WORD_CHAR);
    // устанавливаем отступы
    gtk_text_view_set_top_margin(GTK_TEXT_VIEW (textView), 10);
    gtk_text_view_set_bottom_margin(GTK_TEXT_VIEW (textView), 10);
    gtk_text_view_set_left_margin(GTK_TEXT_VIEW (textView), 15);
    gtk_text_view_set_right_margin(GTK_TEXT_VIEW (textView), 10);
    // отступы между строками
    gtk_text_view_set_pixels_inside_wrap(GTK_TEXT_VIEW (textView), 5);

    // создаем компонент с прокруткой
    GtkWidget* scrollView = gtk_scrolled_window_new();
    // добавляем в компонент с прокруткой текстовое поле
    gtk_scrolled_window_set_child (GTK_SCROLLED_WINDOW (scrollView), textView);

    // компонент с прокруткой добавляем в окно приложения
    gtk_window_set_child (GTK_WINDOW (window), scrollView);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

#include <gtk/gtk.h>

static void app_activate (GtkApplication *app, gpointer *user_data) {

    GtkBuilder* builder = gtk_builder_new_from_file("builder.ui");
    GObject* window = gtk_builder_get_object (builder, "window");
    g_object_unref (builder);
    gtk_window_set_application (GTK_WINDOW (window), app);

## Запрет редактирования

Из остальных свойств GtkTextView также можно отметить свойство `editable`, которое позволяет запретить или, наоборот, разрешить редактирование текста. Для его установки применяется функция `gtk_text_view_set_editable()`:

```c
void gtk_text_view_set_editable (GtkTextView* text_view, gboolean setting)
```

Если второму параметру передается значение FALSE, то редактирование запрещено, текст доступен только для просмотра. Если передается TRUE, то редактирование разрешено. Например:

```c
GtkTextBuffer* buffer = gtk_text_view_get_buffer (GTK_TEXT_VIEW (textView));
// запрещаем редактирование текста
gtk_text_view_set_editable (GTK_TEXT_VIEW (textView), FALSE);
```
