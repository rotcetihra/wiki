Если кнопка определяется в XML, то у нас есть два варианта. Во-первых, мы можем получить кнопку в коде на Си и также прикрепить для сигнала ее нажатия обработчик. Например, код в XML (файл "builder.ui"):

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">300</property>
    <property name="default-height">250</property>
    <child>
      <object class="GtkButton" id="button">
        <property name="label">Click Me</property>
      </object>
    </child>
  </object>
</interface>
```

И в основном файле приложения, где загружается интерфейс, получаем кнопку и прикрепляем к ней обработчик сигнала:

```c
#include <gtk/gtk.h>

void click_button (GtkButton *btn) {
    g_print ("Clicked.\n");
}

static void app_activate (GtkApplication *app, gpointer *user_data) {

    GtkBuilder* builder = gtk_builder_new_from_file("builder.ui");
    GObject* window = gtk_builder_get_object (builder, "window");

    GObject *button = gtk_builder_get_object (builder, "button");
    g_signal_connect (button, "clicked", G_CALLBACK (click_button), NULL);

    g_object_unref (builder);
    gtk_window_set_application (GTK_WINDOW (window), app);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

Проблема здесь заключается, что нам надо дополнительно две строки кода, которые получают виджет и привязывают обработчик сигнала. И второй подход заключается в том, чтобы установить эти вещи непосредственно в коде XML. Для привязки GTK предоставляет элемент `<signal>` в следующем виде:

```xml
<signal name="имя_сигнала" handler="имя_функции" />
```

Например, установка обработчика в XML для нашей кнопки будет выглядеть следующим образом:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">300</property>
    <property name="default-height">250</property>
    <child>
      <object class="GtkButton" id="button">
        <property name="label">Click Me</property>
        <signal name="clicked" handler="click_button" />
      </object>
    </child>
  </object>
</interface>
```

И в основном файле приложения достаточно будет прописать только функцию обработки сигнала:

```c
#include <gtk/gtk.h>

void click_button (GtkButton *btn) {
    g_print ("Clicked.\n");
}

static void app_activate (GtkApplication *app, gpointer *user_data) {

    GtkBuilder* builder = gtk_builder_new_from_file("builder.ui");
    GObject* window = gtk_builder_get_object (builder, "window");
    g_object_unref (builder);
    gtk_window_set_application (GTK_WINDOW (window), app);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

Но в этом случае у нас есть несколько ограничений. Прежде всего функция-обработчик должна быть нестатической. Если наша ОС - Windows, то функция-обработчик предваряется декоратором `G_MODULE_EXPORT`:

```c
G_MODULE_EXPORT 
void click_button (GtkButton *btn) {
    g_print ("Clicked.\n");
}
```

В этом случае функция будет добавлена в таблицу символов.

Если наша ОС - Linux/MacOS и другие Unix-подобные системы, то это не обязательно. Вместо этого приложения следует компилировать с аргументом `-Wl,--export-dynamic` внутри флагов компилятора и компоновать с модулем gmodule-export-2.0:

```bash
gcc -Wl,--export-dynamic $(pkg-config --cflags gtk4 gmodule-export-2.0) -o app app.c $(pkg-config --libs gtk4 gmodule-export-2.0)  && ./app
```
