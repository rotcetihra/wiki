Виджет GtkScrolledWindow представляет контейнер, который позволяет прокручивать свое содержимое. Для создания окна с прокруткой применяется функция `gtk_scrolled_window_new()`:

```c
GtkWidget* gtk_scrolled_window_new (void)
```

Для установки содержимого контейнер прокрутки применяет функцию `gtk_scrolled_window_set_child()`:

```c
void gtk_scrolled_window_set_child (GtkScrolledWindow* scrolled_window, GtkWidget* child)
```

В качестве второго параметра и передается прокручиваемое содержимое. Виджеты с собственной поддержкой прокрутки, то есть типы, которые реализуют интерфейс GtkScrollable, добавляются напрямую. Для других типов виджетов применяется в качестве адаптера тип GtkViewport, который предоставляет прокрутку другим виджетам.

`gtk_scrolled_window_set_child()` вычисляет, представляет ли добавленный дочерний элемент тип GtkScrollable. Если нет, то он оборачивает дочерний элемент в GtkViewport. Поэтому можно просто добавить любой дочерний виджет.

Прежде чем применить прокрутку, посмотрим, с какой распространенной проблемой мы можем столкнуться. Пусть у нас есть следующее приложение:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {
 
    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
 
 
    GtkWidget* box = gtk_box_new(GTK_ORIENTATION_VERTICAL, 10);
    gtk_widget_set_valign(box, GTK_ALIGN_START);
    gtk_widget_set_halign(box, GTK_ALIGN_START);

    char label_text[8]; // "Label  " + \0;  // текст метки
    for(int i=0; i < 15; i++){
        snprintf(label_text, 9, "Label %d", i);  // устанавливаем текст на основе переменной i
        GtkWidget* label = gtk_label_new(label_text);
        gtk_box_append(GTK_BOX(box), label);
    }

    gtk_window_set_child (GTK_WINDOW (window), box);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
 
    return status;
}
```

Здесь мы создаем и добавляем в контейнер GtkBox 15 текстовых меток. В итоге контейнер GtkBox будет растягиваться, чтобы вместить все текстовые метки, а вместе с ним будет расятиваться окно, чтобы вместить GtkBox.

Теперь применим GtkScrolledWindow для создания прокрутки:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {
 
    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 250, 200);
 
    GtkWidget* box = gtk_box_new(GTK_ORIENTATION_VERTICAL, 10);
    gtk_widget_set_valign(box, GTK_ALIGN_START);
    gtk_widget_set_halign(box, GTK_ALIGN_START);

    char label_text[8]; // "Label  " + \0;
    for(int i=0; i < 15; i++){
        snprintf(label_text, 9, "Label %d", i);
        GtkWidget* label = gtk_label_new(label_text);
        gtk_box_append(GTK_BOX(box), label);
    }

    // создаем компонент с прокруткой
    GtkWidget* scrollView = gtk_scrolled_window_new();
    // добавляем в компонент с прокруткой текстовое поле
    gtk_scrolled_window_set_child (GTK_SCROLLED_WINDOW (scrollView), box);

    gtk_window_set_child (GTK_WINDOW (window), scrollView);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
 
    return status;
}
```

В итоге, если окно не вмещает все содержимое вложенного компонента, то добавляются полосы прокрутки.

## Основные свойства и функции виджета

Отмечу некоторые основные свойства виджета:

- **max-content-height**: максимальная высота содержимого scrolled_window. Управляется функциями `gtk_scrolled_window_get_max_content_height`(геттер) и `gtk_scrolled_window_set_max_content_height` (сеттер)
- **max-content-width**: максимальная ширина содержимого scrolled_window. Управляется функциями `gtk_scrolled_window_get_max_content_width`(геттер) и `gtk_scrolled_window_set_max_content_width` (сеттер)
- **min-content-height**: минимальная высота содержимого scrolled_window. Управляется функциями `gtk_scrolled_window_get_min_content_height`(геттер) и `gtk_scrolled_window_set_min_content_height` (сеттер)
- **min-content-width**: минимальная ширина содержимого scrolled_window. Управляется функциями `gtk_scrolled_window_get_min_content_width`(геттер) и `gtk_scrolled_window_set_min_content_width` (сеттер)
- **overlay-scrolling**: указывает, включена ли прокрутка наложения или нет. Если равно TRUE (по умолчанию), то прокрутка накладывается на содержимое динамически, если FALSE, то прокрутка фиксированная. Управляется функциями `gtk_scrolled_window_get_overlay_scrolling`(геттер) и `gtk_scrolled_window_set_overlay_scrolling` (сеттер)
- **window-placement**: управляет размещением полос прокрутки и представляет перечисление GtkCornerType. Данное перечисление определяет следующее константы:
  - `GTK_CORNER_TOP_LEFT`: полосы прокрутки по правой и нижней границе виджета (поведение по умолчанию). Значение: 0
  - `GTK_CORNER_BOTTOM_LEFT`: полосы прокрутки по верхней и правой границе виджета. Значение: 1
  - `GTK_CORNER_TOP_RIGHT`: полосы прокрутки по левой и нижней границе виджета. Значение: 2
  - `GTK_CORNER_BOTTOM_RIGHT`: полосы прокрутки по верхней и левой границе виджета. Значение: 3

  Управляется функциями `gtk_scrolled_window_get_placement`(геттер) и `gtk_scrolled_window_set_placement` (сеттер)

Краткий пример применения функций:

```c
GtkWidget* scrollView = gtk_scrolled_window_new();
// минимальная высота - 150 единиц
gtk_scrolled_window_set_min_content_height(GTK_SCROLLED_WINDOW (scrollView), 150);

// устанавливаем фиксированные полосы прокрутки
gtk_scrolled_window_set_overlay_scrolling(GTK_SCROLLED_WINDOW (scrollView), FALSE);

// Расположение полос прокрутки справа и внизу
gtk_scrolled_window_set_placement(GTK_SCROLLED_WINDOW (scrollView), GTK_CORNER_BOTTOM_RIGHT);
```
