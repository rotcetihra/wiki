Виджет GtkSpinButton предназначен для ввода числовых значений. Хотя для ввода данных можно использовать рассмотренное в прошлых темах обычное текстовое поле GtkEntry, но GtkSpinButton заточен специально для ввода числовых значений и наделен соответствующей функциональностью.

## Конструкторы

Для создания виджета можно использовать одну из функций-конструкторов:

- `gtk_spin_button_new`
- `gtk_spin_button_new_with_range`

Первый конструктор имеет следующий прототип:

```c
GtkWidget* gtk_spin_button_new (GtkAdjustment* adjustment, double climb_rate, guint digits)
```

Параметры:

- `adjustment`: объект GtkAdjustment, который применяется для настройки параметров виджета, может быть равен NULL
- `climb_rate`: значение типа double, которое устанавливает ускорение приращения значения
- `digits`: значение типа guint, которое устанавливает количество отображаемых десятичных знаков

Ключевую роль в настройке виджета здесь играет объект GtkAdjustment. Для его создания применяется следующая функция-конструктор:

```c
GtkAdjustment*
gtk_adjustment_new (
  double value,
  double lower,
  double upper,
  double step_increment,
  double page_increment,
  double page_size
)
```

- `value`: начальное значение
- `lower`: минимальное значение
- `upper`: максимальное значение
- `step_increment`: шаг приращения
- `page_increment`: страничное приращение (с помощью клавиш Page Up и Page Down)
- `page_size`: размер страницы

Все значения представляют тип double. Посмотрим на примере:

```c
#include <gtk/gtk.h>

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget* window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);

    // мин - 0, макс - 100, текущее значение - 50
    GtkAdjustment* adjustment = gtk_adjustment_new (50.0, 0.0, 100.0, 1.0, 5.0, 0.0);
    GtkWidget* button = gtk_spin_button_new (adjustment, 1.0, 0);
    gtk_widget_set_valign(button, GTK_ALIGN_START);
    gtk_widget_set_halign(button, GTK_ALIGN_START);

    gtk_window_set_child (GTK_WINDOW (window), button);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

Здесь в качестве минимального значения устанавливаем 0.0, а в качестве максимального - 100. Текущее значение - 50.0.

```c
GtkAdjustment* adjustment = gtk_adjustment_new (50.0, 0.0, 100.0, 1.0, 5.0, 0.0);
```

При каждом нажатии на кнопки значение будет изменяться на 1:

```c
GtkWidget* button = gtk_spin_button_new (adjustment, 1.0, 0);
```

И основной файл приложения, где загружается интерфейс:

```c
#include <gtk/gtk.h>

static void app_activate (GtkApplication *app, gpointer *user_data) {

    GtkBuilder* builder = gtk_builder_new_from_file("builder.ui");
    GObject* window = gtk_builder_get_object (builder, "window");
    g_object_unref (builder);
    gtk_window_set_application (GTK_WINDOW (window), app);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);

    return status;
}
```

Второй конструктор немного проще:

```c
GtkWidget* gtk_spin_button_new_with_range (double min, double max, double step)
```

Параметры функции предусматривают установку минимального и максимального значения и шага приращения. Пример применения:

```c
// мин - 18, макс - 100, шаг приращения - 1, текущее значение = минимальному
GtkWidget* button = gtk_spin_button_new_with_range(18.0, 100.0, 1.0);
```

## Управление виджетом

GTK предоставляет ряд свойств для настройки и управления виджетом. Перечислю основные:

- `adjustment`: объект GtkAdjustment
- `climb-rate`: скорость ускорения при удерживании кнопки или клавиши
- `digits`: количество отображаемых десятичных знаков
- `numeric`: указывает, должны ли игнорироваться нечисловые символы
- `snap-to-ticks`: указывает, должны ли ошибочные значения автоматически изменяться на ближайшее валидное значение
- `value`: текущее значение
- `wrap`: указывает, будет ли зацикливаться перебор значений в виджете

Для установки этих свойств для виджета доступны следующие функции:

- `gtk_spin_button_configure()`: устанавливает объект GtkAdjustment*, ускорение приращения значения и количество отображаемых десятичных знаков (аналогично первому конструктору):

```c
void gtk_spin_button_configure (
  GtkSpinButton* spin_button,
  GtkAdjustment* adjustment,
  double climb_rate,
  guint digits
)
```

- `gtk_spin_button_set_adjustment()`: устанавливает только объект GtkAdjustment*:

```c
void gtk_spin_button_set_adjustment (
  GtkSpinButton* spin_button,
  GtkAdjustment* adjustment
)
```

- `gtk_spin_button_set_increments()`: устанавливает приращение значения и размер страницы:

```c
void gtk_spin_button_set_increments (
  GtkSpinButton* spin_button,
  double step,
  double page
)
```

- `gtk_spin_button_set_numeric()`: разрешает или запрещает ввод нечисловых символов. Если второму параметру передается значение TRUE, то разрешает, если FALSE - запрещает:

```c
void gtk_spin_button_set_numeric (
  GtkSpinButton* spin_button,
  gboolean numeric
)
```

- `gtk_spin_button_set_digits()`: устанавливает количество отображаемых десятичных знаков:

```c
void gtk_spin_button_set_digits (
  GtkSpinButton* spin_button,
  guint digits
)
```

- `gtk_spin_button_set_range()`: устанавливает минимальное и максимальное значения:

```c
void gtk_spin_button_set_range (
  GtkSpinButton* spin_button,
  double min,
  double max
)
```

- `gtk_spin_button_set_value()`: устанавливает текущее значение:

```c
void gtk_spin_button_set_value (
  GtkSpinButton* spin_button,
  double value
)
```

- `gtk_spin_button_set_wrap()`: позволяет зацикливать перебор значений в виджете. Для этого второму параметру передается значение TRUE:

```c
void gtk_spin_button_set_wrap (
  GtkSpinButton* spin_button,
  gboolean wrap
)
```

Например, виджет с зацикливанием значений:

```c
GtkWidget* button = gtk_spin_button_new_with_range(1.0, 100.0, 1.0);
gtk_spin_button_set_wrap(GTK_SPIN_BUTTON(button), TRUE);
gtk_spin_button_set_value(GTK_SPIN_BUTTON(button), 20.0);
```

## Обработка изменения значения

GTK предоставляет ряд сигналов для GtkSpinButton. В частности, сигнал `value_changed` применяется для обработки изменения текущего значения виджета:

```c
void value_changed (GtkSpinButton* self, gpointer user_data)
```

Например, выведем выбранное пользователем значение виджета:

```c
#include <gtk/gtk.h>
#include <stdio.h>

static void value_changed (GtkSpinButton* self, gpointer user_data){
    GtkLabel* label = GTK_LABEL(user_data);
    // получаем выбранное значение
    double value = gtk_spin_button_get_value(self);
    // буфер для конвертации из int в строку
    char str[4];
    // преобразуем число в строку
    sprintf(str, "%.*f", 0, value);
    // выводим строку на метке 
    gtk_label_set_text(label, str);
}

static void app_activate (GApplication *app, gpointer *user_data) {

    GtkWidget *window = gtk_application_window_new (GTK_APPLICATION (app));
    gtk_window_set_title (GTK_WINDOW (window), "METANIT.COM");
    gtk_window_set_default_size (GTK_WINDOW (window), 300, 250);

    GtkWidget* box =  gtk_box_new(GTK_ORIENTATION_VERTICAL, 10);

    GtkWidget* button = gtk_spin_button_new_with_range(1.0, 100.0, 1.0);
    gtk_spin_button_set_wrap(GTK_SPIN_BUTTON(button), TRUE);
    gtk_spin_button_set_value(GTK_SPIN_BUTTON(button), 20.0);
    gtk_box_append (GTK_BOX (box), button);

    GtkWidget* label =  gtk_label_new(NULL);
    gtk_box_append (GTK_BOX (box), label);

    // устанавливаем функцию-обработчик value_changed для обработки одноименного сигнала
    g_signal_connect (button, "value_changed", G_CALLBACK (value_changed), label);

    gtk_window_set_child (GTK_WINDOW (window), box);
    gtk_window_present (GTK_WINDOW (window));
}

int main (int argc, char **argv)
{
    GtkApplication *app = gtk_application_new ("com.metanit", G_APPLICATION_DEFAULT_FLAGS);
    g_signal_connect (app, "activate", G_CALLBACK (app_activate), NULL);
    int status = g_application_run (G_APPLICATION (app), argc, argv);
    g_object_unref(app);
    return status;
}
```

В данном случае для обработки сигнала `value_changed` применяется одноименная функция, в которую в качестве дополнительного параметра передается метка label. В функции-обработчике получаем текущее значение виджета в виде числа типа double и конвертируем его в строку. В конце выводим строку на метку label.

## Направление виджета

GtkSpinButton наследует функционал от другого типа - GtkOrientable и соответственно имеет свойство `orientation`, которое позволяет установить направление виджета с помощью значений перечисления GtkOrientation:

- `GTK_ORIENTATION_HORIZONTAL`
- `GTK_ORIENTATION_VERTICAL`

По умолчанию применяется горизонтальная ориентация (`GTK_ORIENTATION_HORIZONTAL`), но с помощью функции `gtk_orientable_set_orientation()` можно поменять направление виджета:

```c
void gtk_orientable_set_orientation (
  GtkOrientable* orientable,
  GtkOrientation orientation
)
```

Приведу пример в XML:

```xml

    <property name="title">METANIT.COM</property>
    <property name="default-width">250</property>
    <property name="default-height">200</property>
    
    <child>
        <object class="GtkSpinButton" id="button">

          <property name="orientation">GTK_ORIENTATION_VERTICAL</property>

          <property name="halign">GTK_ALIGN_START</property>

          <property name="climb-rate">1.0</property>

            </object>

    </child>
  </object>
</interface>
```
