## 1. Введение

В этой главе мы рассмотрим примеры некоторых распространенных макросов, которые могут применяться в программе или просто служить примером для создания макросов для других задач по аналогии.

## 2. Минимальное и максимальное значения

```c
#define MIN(a,b) ((a) < (b) ? (a) : (b))
#define MAX(a,b) ((a) > (b) ? (a) : (b))
```

Здесь макрос `MIN` принимает два параметра и затем сравнивает оба параметра с помощью операции `<`. А с помощью тернарной операции определяет, какой параметр будет возвращаться. Макрос `MAX` аналогичен, только использует операцию `>`.

Пример применения макросов:

```c
#include <stdio.h>

#define MIN(a,b) ((a) < (b) ? (a) : (b))
#define MAX(a,b) ((a) > (b) ? (a) : (b))

int main(void)
{
    int x = 2;
    int y = 6;

    printf("Min: %d\n", MIN(x,y));      // Min: 2
    printf("Max: %d\n", MAX(x,y));      // Max: 6
    return 0;
}
```

## 3. Побочные действия в макросах

При этом стоит учитывать побочные действия, которые могут выполняться операндами макросов. Например, возьмем следующий пример:

```c
#include <stdio.h>

#define MIN(a,b) ((a) < (b) ? (a) : (b))
#define MAX(a,b) ((a) > (b) ? (a) : (b))

int x = 2;
int get_x(void)
{
    x = x + x;
    return x;
}

int main(void)
{
    int y = 6;

    printf("Min: %d\n", MIN(get_x(), y));      // Min: 8
    printf("Max: %d\n", MAX(get_x(), y));      // Max: 32
    return 0;
}
```

Посмотрим на консольный вывод:

```
Min: 8
Max: 32
```

Очевидно, результат некорректный, потому что в качестве первого операнда передается вызов функции, которая выполняет побочные действия. Например, вызов макроса

```c
MIN(get_x(), y)
```

разворачивается в следующую конструкцию:

```c
get_x() < y ? get_x() : y
```

Таким образом, функция `get_x()` выполняется два раза — дважды увеличивает значение глобальной переменной `x` в два раза. Аналогично происходит и во втором макросе. Поэтому при создании макросов всегда следует учитывать побочные действия.

## 4. Преобразование в строку

```c
#define TOSTRING(value) #value
```

Символ `#` позволяет получить строковое представление операнда макроса. То есть то, что передается через `value`, макрос возвращает в виде строки. Рассмотрим применение:

```c
#include <stdio.h>

#define TOSTRING(value) #value

int main(void)
{
    int x = 2;
    int y = 6;

    printf("%s\n", TOSTRING(x));                 // x
    printf("%s\n", TOSTRING(x + y));             // x + y
    printf("%s = %d\n", TOSTRING(x + y), x + y); // x + y = 8
    printf("%s\n", TOSTRING(return 0));          // return 0
    return 0;
}
```

Консольный вывод:

```
x
x + y
x + y = 8
return 0
```

Обратите внимание, что даже если мы передаем в макрос сложные выражения и инструкции, типа `TOSTRING(x + y)` или `TOSTRING(return 0)`, эти выражения все равно рассматриваются как один операнд, для которого макрос возвращает строковое представление.

## 5. Конкатенация токенов

С помощью последовательности символов `##` можно объединить два токена:

```c
#define CONCAT(a, b) a##b
```

Простейший пример:

```c
#include <stdio.h>

#define CONCAT(a, b) a##b

int main(void)
{
    int x = 2;
    int y = 6;
    int xy = x + y;
    printf("xy = %d\n", CONCAT(x, y));  // 8
    return 0;
}
```

В данном случае макрос `CONCAT(x, y)` разворачивается в `x##y`, то есть в `xy`. В итоге мы получаем название переменной `xy`.

Другой пример конкатенации в макросе:

```c
#include <stdio.h>

#define SUM(T, a, b) T##_sum(a, b)

int int_sum(int a, int b){ return a+b;}
double double_sum(double a, double b){ return a+b;}

int main(void)
{
    int x = 2;
    int y = 6;
    printf("x + y = %d\n", SUM(int, x, y));  // 8

    double a = 1.1;
    double b = 2.3;
    printf("a + b = %g\n", SUM(double, a, b));  // 3.4
    return 0;
}
```

Здесь у нас есть две функции, которые вычисляют сумму чисел — чисел `int` и чисел `double`. Данные функции имеют одинаковый шаблон наименования и принимают два параметра. Для вызова этих функций в обобщенном виде определяем макрос `SUM`:

```c
#define SUM(T, a, b) T##_sum(a, b)
```

Его первый параметр представляет тип, для которого выполняется макрос. Остальные параметры — те значения, которые будут передаваться в функцию вычисления суммы. В коде макроса с помощью конкатенации `T##_sum` можно получить имя конкретной функции в зависимости от типа. Например, вызов макроса

```c
SUM(int, x, y)
```

разворачивается в следующий код:

```c
int_sum(x, y)
```

## 6. Получение длины массива

Получение длины массива является распространенной задачей, под которую проще написать макрос:

```c
#define ARRAY_SIZE(arr) (sizeof(arr) / sizeof((arr)[0]))
```

Пример применения:

```c
#include <stdio.h>

#define ARRAY_SIZE(arr) (sizeof(arr) / sizeof((arr)[0]))

int main(void)
{
    int data[] = {11, 12, 13, 14, 15, 16};

    printf("array size: %lu\n", ARRAY_SIZE(data));

    for (size_t i = 0; i < ARRAY_SIZE(data); ++i)
    {
        printf("%d\n", data[i]);
    }
    return 0;
}
```

Макрос `ARRAY_SIZE` в качестве параметра принимает массив; при этом его результатом является частное от деления размера всего массива (`sizeof(arr)`) на размер одного элемента (`sizeof((arr)[0])`). Подобный макрос безопаснее, чем ручная передача длины массива, поскольку компилятор всегда вычисляет реальный размер.

## 7. Обмен значениями переменных

Если нам надо обменять значениями две переменных независимо от типа, то для этой цели можно написать свой макрос:

```c
#define SWAP(a, b) {\
    if(sizeof(a) == sizeof(b)) {\
        char tmp[sizeof(a)]; \
        memcpy(tmp, &(a), sizeof(a)); \
        memcpy(&(a), &(b), sizeof(a)); \
        memcpy(&(b), tmp, sizeof(b));  \
    }\
}
```

В данном случае макрос называется `SWAP`, и он принимает 2 параметра — 2 объекта, значения которых надо поменять. Поскольку макрос содержит несколько строк кода, оформляем его в блок кода. В этом блоке сначала проверяем размер обоих объектов, и если он равен (то есть если тип объектов имеет один и тот же размер), то для обмена данными определяем массив нужного размера. Данный массив будет выполнять роль промежуточной переменной. И с помощью библиотечной функции `memcpy` копируем данные. Если же размер объектов отличается, то копирования не происходит.

> [!WARNING]
> В макросе используется массив переменной длины `char tmp[sizeof(a)]` — такая конструкция одобрена в C99 и разрешена в C11 на усмотрение компилятора. Для переносимости между компиляторами лучше выделять временное хранилище через `malloc` или пересмотреть реализацию обмена.

Простейший пример применения:

```c
#include <stdio.h>
#include <string.h>

#define SWAP(a, b) {\
    if(sizeof(a) == sizeof(b)) {\
        char tmp[sizeof(a)]; \
        memcpy(tmp, &(a), sizeof(a)); \
        memcpy(&(a), &(b), sizeof(a)); \
        memcpy(&(b), tmp, sizeof(b));  \
    }\
}
```

int main(void)
{
    int x = 2;
    int y = 6;
    SWAP(x, y);
    printf("x: %d\n", x);   // x: 6
    printf("y: %d\n", y);   // y: 2
    return 0;
}
```

## 8. Безопасная очистка памяти

Обычно после освобождения памяти по указателю с помощью встроенной функции `free()` указателю присваивается нулевое значение, что позволяет узнать, ссылается ли он на какие-либо данные. Поскольку оба действия нередко идут рука об руку, то их можно оформить в виде макроса:

```c
#define SAFE_FREE(p) do { free(p); (p) = NULL; } while(0)
```

Макрос через параметр принимает указатель, освобождает память, на которую он указывает, и присваивает ему нулевое значение. Чтобы оформить оба действия как единое целое, они определены в виде блока цикла `do..while`.

## 9. Получение смещения поля в структуре

Для получения смещения поля в структуре определим следующий макрос:

```c
#define OFFSETOF(type, member) ((size_t)&((type *)0)->member)
```

Макрос `OFFSETOF` принимает два параметра: `type` (имя структуры) и `member` (название поля структуры). В коде макроса сначала приводим `0` к типу указателя на нашу структуру и затем обращаемся к её полю. Далее получаем адрес поля с помощью операции взятия адреса `&` и приводим результат к числовому значению `size_t`. Пример применения:

```c
#include <stdio.h>

#define OFFSETOF(type, member) ((size_t)&((type *)0)->member)

typedef struct
{
    char* name;
    int age;
} Person;

int main(void)
{
    Person tom = {"Tom", 40};

    size_t name_offset = OFFSETOF(Person, name);
    size_t age_offset = OFFSETOF(Person, age);

    printf("name_offset: %lu\n", name_offset);  // 0
    printf("age_offset: %lu\n", age_offset);    // 8
    return 0;
}
```

Значение 0 у «имени» объясняется тем, что поле `name` — первое поле структуры, и оно располагается по смещению 0 относительно начала структуры. Поле `age` находится по смещению, равному размеру поля `name` (8 байт для указателя на 64-битной платформе).

## 10. Резюме

1. В макросах `MIN`/`MAX` параметры обязательно заключаются в скобки, а при передаче аргументов с побочными действиями (например, вызываемых функций) результат может быть некорректным.
2. Операция `#` превращает операнд в строку, операция `##` склеивает два токена в одну лексему.
3. Типовые макросы: `ARRAY_SIZE` (длина массива), `SWAP` (обмен значениями), `SAFE_FREE` (безопасное освобождение памяти), `OFFSETOF` (смещение поля в структуре).
