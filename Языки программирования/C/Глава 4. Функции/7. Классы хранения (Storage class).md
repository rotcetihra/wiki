## 1. Введение

**Класс хранения** (storage class) — это модификатор, который определяет жизненный цикл и область видимости переменных и функций. Он сообщает компилятору, где и как хранить переменную, ее начальное значение по умолчанию и кто может к ней обращаться.

В Си существует четыре основных класса хранения:

- `auto`;
- `extern`;
- `static`;
- `register`.

В принципе в предыдущих статьях мы уже частично рассматривали эти классы хранения. Теперь обобщим их использование.

## 2. auto

Класс хранения `auto` является классом по умолчанию для всех локальных переменных. Это означает, что если переменная объявлена внутри функции или блока без указания класса хранения, она автоматически принимает класс хранения `auto`. Основные характеристики:

- **Область видимости:** действие переменной ограничено блоком, в котором она объявлена (локальная видимость).
- **Жизненный цикл:** переменная создается при входе в блок и уничтожается при выходе из него.
- **Начальное значение:** если переменная не инициализирована явно, она содержит «мусорное» неопределенное значение.

Пример:

```c
void myFunction()
{
    int a; // то же самое, что и "auto int a;"
    a = 10;
    // a доступна только внутри myFunction
}
```

Поскольку `auto` используется по умолчанию для локальных переменных, его редко указывают в коде явно.

## 3. extern

Ключевое слово `extern` (от англ. external — внешний) используется для объявления глобальной переменной или функции, которая определена в другом файле. Это позволяет использовать одну и ту же глобальную переменную в нескольких исходных файлах. Основные характеристики:

- **Область видимости:** глобальная (доступна во всем проекте).
- **Жизненный цикл:** существует в течение всего времени выполнения программы.
- **Начальное значение:** определяется в месте ее инициализации. Если глобальная переменная не инициализирована явно, она получает значение 0.

Файл `file1.c` (определение переменной):

```c
#include <stdio.h>

int globalVar = 100; // определение и инициализация

void printGlobal()
{
    printf("globalVar из file1.c: %d\n", globalVar);
}
```

Файл `file2.c` (использование внешней переменной):

```c
#include <stdio.h>

extern int globalVar; // объявление, что переменная определена где-то еще

void displayGlobal()
{
    printf("globalVar из file2.c: %d\n", globalVar);
}

int main()
{
    displayGlobal();
    // printGlobal(); // предупреждение или ошибка
    return 0;
}
```

При компиляции этих двух файлов `extern` сообщает `file2.c`, что `globalVar` существует и будет доступна на этапе компоновки (linking):

```
gcc file1.c file2.c -o app && ./app
globalVar из file2.c: 100
```

Возьмем закомментированную строку:

```c
// printGlobal(); // предупреждение или ошибка
```

В примере выше функция `printGlobal()` определена в файле `file1.c`, однако в файле `file2.c` не объявлена. Если раскомментировать эту строку, то в зависимости от компилятора можно столкнуться либо с предупреждением (как в случае с GCC):

```
gcc file1.c file2.c -o app && ./app
file2.c: In function 'main':
file2.c:11:5: warning: implicit declaration of function 'printGlobal' [-Wimplicit-function-declaration]
   11 |     printGlobal(); // ошибка компиляции, если не объявлена
      |     ^~~~~~~~~~~
globalVar из file2.c: 100
globalVar из file1.c: 100
```

Либо с ошибкой (как в случае с Clang):

```
clang file1.c file2.c -o app && ./app
file2.c:11:5: error: call to undeclared function 'printGlobal'; ISO C99 and later do not support implicit function declarations [-Wimplicit-function-declaration]
   11 |     printGlobal(); // ошибка компиляции, если не объявлена
      |     ^
1 error generated.
```

> [!NOTE]
> Неявное объявление функций запрещено стандартом C99: современный Clang считает это ошибкой, GCC по умолчанию выдает лишь предупреждение. Поэтому для функций из других файлов всегда объявляйте прототип.

## 4. static

Ключевое слово `static` имеет два основных применения в зависимости от контекста: для локальных переменных и для глобальных переменных или функций.

### Локальные статические переменные

Когда `static` применяется к локальной переменной, он изменяет ее жизненный цикл, сохраняя значение между вызовами функции. Основные характеристики:

- **Область видимости:** локальная, как у переменных `auto`.
- **Жизненный цикл:** существует в течение всего времени выполнения программы, а не только внутри функции.
- **Начальное значение:** инициализируется только один раз при первом вызове функции; если не инициализирована явно, получает значение 0.

```c
#include <stdio.h>

void counter()
{
    static int count = 0; // инициализируется только один раз
    count++;
    printf("Count: %d\n", count);
}

int main()
{
    counter(); // Count: 1
    counter(); // Count: 2
    counter(); // Count: 3
    return 0;
}
```

### Глобальные переменные и функции со static

Когда `static` применяется к глобальной переменной или функции, он ограничивает их область видимости текущим файлом. Это означает, что к такой переменной или функции нельзя обратиться из другого файла с помощью `extern`. Характеристики:

- **Область видимости:** действие переменной или функции ограничено файлом, в котором они объявлены.
- **Жизненный цикл:** переменная или функция существует в течение всего времени выполнения программы.

Пусть у нас есть файл `file1.c`:

```c
// Файл file1.c
static int secret = 42; // доступна только в file1.c

static void secretFunction()  // доступна только в file1.c
{
    // ...
}
```

Такая инкапсуляция полезна для сокрытия деталей реализации модуля.

## 5. register

Класс хранения `register` является рекомендацией компилятору поместить переменную не в оперативную память, а в регистр процессора. Доступ к регистрам значительно быстрее, чем к памяти, поэтому это может оптимизировать производительность. Однако в современных компиляторах `register` почти не используется, так как они самостоятельно выполняют очень сложную оптимизацию и часто лучше программиста решают, какие переменные стоит помещать в регистры.

Пример применения:

```c
void fastLoop()
{
    register int i; // просьба к компилятору использовать регистр для i
    for (i = 0; i < 1000000; i++)
    {
        // ... какая-то быстрая операция
    }
}
```

Основные характеристики этого класса хранения:

- **Область видимости:** локальная.
- **Жизненный цикл:** локальный.

К `register`-переменной нельзя применить оператор взятия адреса `&`, так как у нее нет адреса в памяти:

```c
#include <stdio.h>

int main()
{
    register int i = 0; // просьба к компилятору использовать регистр для i
    printf("i addr: %p\n", &i);   // здесь будет ошибка
    return 0;
}
```

Компилятор может проигнорировать это указание, если нет свободных регистров или если тип данных не подходит для хранения в регистре.

> [!NOTE]
> В современном Си `register` — скорее пережиток: компиляторы и так размещают переменные в регистрах при оптимизации, а `register` сохранил лишь одно обязательное следствие — запрет на взятие адреса такой переменной.

## 6. Сводная таблица классов хранения

|**Класс**|**Область видимости**|**Жизненный цикл**|**Начальное значение**|
|---|---|---|---|
|`auto`|локальный блок|создается при входе в блок, уничтожается при выходе|неопределенное («мусор»)|
|`extern`|глобальная (проект)|вся программа|определяется местом инициализации; без нее — 0|
|`static` (локальная)|локальный блок|вся программа (инициализация один раз)|0 при отсутствии явной инициализации|
|`static` (глобальная)|один файл|вся программа|0 при отсутствии явной инициализации|
|`register`|локальный блок|как у `auto`|неопределенное; нельзя брать адрес|

## 7. Резюме

1. `auto` — класс по умолчанию для локальных переменных: создаются при входе в блок, уничтожаются при выходе, без инициализации содержат «мусор».
2. `extern` объявляет переменную или функцию, определенную в другом файле; глобальная переменная без инициализации получает 0.
3. `static` у локальной переменной сохраняет ее значение между вызовами функции; у глобальных переменных и функций ограничивает видимость текущим файлом.
4. `register` — рекомендация хранить переменную в регистре; в современном Си почти не используется, запрещает взятие адреса.
