## 1. Введение

Используя определение функции — ее возвращаемый тип и типы параметров — мы можем описать тип функций. Для этого применяется оператор `typedef`:

```c
typedef возвращаемый_тип (название)(типы_параметров);
```

Определение типа функции упрощает применение указателей на функции.

## 2. Простейший пример

Возьмем простейший пример:

```c
#include <stdio.h>

typedef void (message)(void);

void hello() { printf("Hello, World \n"); }
void goodbye() { printf("Good Bye, World \n"); }

int main(void)
{
    message *mes1 = &hello;    // указатель указывает на функцию hello
    message *mes2 = &goodbye;  // указатель указывает на функцию goodbye

    mes1();      // Hello, World
    mes2();      // Good Bye, World

    return 0;
}
```

Здесь определяется тип `message`, который фактически будет выступать в качестве псевдонима для функции, которая не принимает никаких параметров и ничего не возвращает (возвращаемый тип — `void`):

```c
typedef void (message)(void);
```

Далее этот тип можно использовать для определения переменных или параметров, которые представляют функцию без параметров и без возвращаемого результата. Так, для теста в программе определены две такие функции — `hello()` и `goodbye()`. Соответственно мы можем определить указатель на тип `message` и присвоить ему адрес одной из этих функций:

```c
message *mes1 = &hello;  // указатель указывает на функцию hello
```

Переменная `mes1` представляет указатель на функцию типа `message` и хранит адрес функции `hello`. Далее переменную `mes1` можно вызывать как стандартную функцию — в реальности будет вызываться функция, адрес которой хранится в переменной `mes1`:

```c
mes1();      // Hello, World
```

Консольный вывод:

```
Hello, World
Good Bye, World
```

## 3. Функции с параметрами и возвращаемым результатом

Рассмотрим другой пример — с параметрами и возвращаемым результатом:

```c
#include <stdio.h>

typedef int (binary_op)(int, int);  // определяем тип binary_op

int sum(int x, int y) { return x + y; }
int subtract(int x, int y) { return x - y; }

int main(void)
{
    int a = 10;
    int b = 5;
    int result;
    binary_op *op1 = &sum;
    binary_op *op2 = &subtract;

    result = op1(a, b);
    printf("result = %d \n", result);       // result=15

    result = op2(a, b);
    printf("result = %d \n", result);       // result=5

    return 0;
}
```

Здесь определяем тип `binary_op`, который будет представлять функцию, принимающую два параметра типа `int` и возвращающую значение типа `int`:

```c
typedef int (binary_op)(int, int);  // определяем тип binary_op
```

Далее этот тип можно использовать для определения переменных, которые будут указывать на функции с соответствующими типами параметров и возвращаемым типом:

```c
binary_op *op1 = &sum;
```

Переменная `op1` представляет указатель на функцию типа `binary_op`, и этой переменной присваивается адрес функции `sum`. Далее переменную `op1` можно вызывать как стандартную функцию, передавая в нее аргументы и получая результат:

```c
result = op1(a, b);
```

## 4. Прототип функции через typedef

Тип функции удобно применять, когда необходимо указать определение функции, однако полная запись выглядит несколько громоздкой. Например, тип функции можно использовать при указании прототипа:

```c
#include <stdio.h>

typedef int (binary_op)(int, int);

binary_op sum;  // прототип функции sum

int main(void)
{
    binary_op *op1 = &sum;
    printf("result = %d \n", op1(10, 5));       // result=15

    return 0;
}

int sum(int x, int y) { return x + y; }
```

## 5. Массивы функций

Подобным образом можно определить массив указателей на функции:

```c
#include <stdio.h>

typedef int (binary_op)(int, int);

int sum(int x, int y) { return x + y; }
int subtract(int x, int y) { return x - y; }
int multiply(int x, int y) { return x * y; }

int main(void)
{
    binary_op *operations[] = {&sum, &subtract, &multiply};   // массив функций binary_op
    printf("result = %d \n", operations[0](10, 5));       // result=15
    printf("result = %d \n", operations[1](10, 5));       // result=5
    printf("result = %d \n", operations[2](10, 5));       // result=50

    return 0;
}
```

## 6. Тип функции-указателя

Тип функции можно определить сразу как указатель:

```c
typedef int (*binary_op)(int, int);
```

Но стоит понимать, что в этом случае `binary_op` уже будет представлять указатель:

```c
#include <stdio.h>

typedef int (*binary_op)(int, int);

int sum(int x, int y) { return x + y; }

int main(void)
{
    binary_op op1 = &sum;   // op1 уже изначально представляет указатель
    printf("result = %d \n", op1(10, 5));       // result=15

    return 0;
}
```

> [!NOTE]
> Разница между `typedef int (binary_op)(int, int)` и `typedef int (*binary_op)(int, int)` — в том, как объявляются переменные: в первом случае нужна звездочка (`binary_op *op1`), во втором — нет (`binary_op op1`). Оба подхода эквивалентны по результату.

## 7. Резюме

1. `typedef` позволяет описать тип функции: `typedef возвращаемый_тип (имя)(типы_параметров);`.
2. Переменные такого типа объявляются как указатели: `binary_op *op = &sum;` и вызываются как обычные функции.
3. Тип функции можно использовать и для прототипа функции (`binary_op sum;`), и для массива указателей (`binary_op *operations[] = {...};`).
4. `typedef int (*binary_op)(int, int)` — сразу тип указателя на функцию, звездочка при объявлении переменных не нужна.
