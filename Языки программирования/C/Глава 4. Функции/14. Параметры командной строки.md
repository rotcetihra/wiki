## 1. Введение

Функция `main` позволяет получать извне при запуске некоторые значения. Для этого она имеет следующую сигнатуру:

```c
int main(int argc, char *argv[])
```

Параметр `argc` представляет количество аргументов командной строки, которые переданы приложению.

Параметр `argv` представляет указатель на массив строк, который представляет переданный набор аргументов.

## 2. Вывод аргументов командной строки

Например, выведем все аргументы из массива `argv` на консоль:

```c
#include <stdio.h>

int main(int argc, char *argv[])
{
    for (int i = 0; i < argc; i++)
    {
        printf("%s \n", argv[i]);
    }
    return 0;
}
```

Если приложению не передается ни одного аргумента, то `argc` равен 1. А элемент `argv[0]` представляет имя исполняемого файла. Например, пусть приложение компилируется в файл `hello.exe`; при запуске этого файла командой

```
hello
```

значение элемента `argv[0]` будет равно `"hello"`. Это будет единственный элемент в массиве.

Но передадим приложению некоторые аргументы. Например, запустим файл `hello.exe` с помощью следующей команды:

```
hello Tom Bob Sam
```

Тогда программа получит все строки через массив `argv` и выведет их на консоль:

```
hello
Tom
Bob
Sam
```

## 3. Резюме

1. `main` может принимать аргументы командной строки: `int main(int argc, char *argv[])`.
2. `argc` — количество аргументов (всегда не меньше 1, так как `argv[0]` — имя исполняемого файла).
3. `argv` — массив строк с переданными приложению аргументами; аргументы разделяются пробелами.
