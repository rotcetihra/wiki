## 1. Введение

Директива `#define` определяет идентификатор и последовательность символов, которые будут подставляться вместо идентификатора каждый раз, когда он встретится в исходном файле. Формальное определение директивы:

```c
#define идентификатор последовательность_символов
```

Определяемый идентификатор еще называют препроцессорным символом.

## 2. Простое определение идентификатора

Используем директиву `#define`:

```c
#include <stdio.h>

#define N 23

int main(void)
{
    int x = N;
    printf("Number: %d", x);   // Number: 23
    return 0;
}
```

Здесь определен один идентификатор `N`. В программе, где встречается этот идентификатор, он будет заменяться на число 23. Например, строка

```c
int x = N;
```

после обработки препроцессором будет иметь следующий код:

```c
int x = 23;
```

Более сложный пример:

```c
#include <stdio.h>

#define BEGIN {
#define END }
#define N 23

int main(void)
BEGIN
    int x = N;
    printf("Number: %d", x);   // Number: 23
    return 0;
END
```

Здесь определены три идентификатора: `BEGIN`, `END`, `N`. В итоге все вхождения последовательности символов `BEGIN` будут заменяться на открывающую фигурную скобку, `END` — на закрывающую, а символ `N` — на число 23.

Таким образом, после обработки препроцессора функция `main` приобретет следующий вид:

```c
int main(void)
{
    int x = 23;
    printf("Number: %d", x);
    return 0;
}
```

## 3. Макросы с параметрами

`#define` также может определять более сложные выражения — макросы с параметрами. Например:

```c
#include <stdio.h>

#define ADD(a, b) (a + b)

int main(void)
{
    int n1 = 10;
    int n2 = 5;
    printf("%d + %d = %d", n1, n2, ADD(n1, n2));  // 10 + 5 = 15
}
```

В данном случае выражение `ADD(a, b)` будет заменяться операцией сложения двух чисел `(a + b)`.

## 4. Определение размеров массивов

Особенно удобно использовать директиву `#define` для определения размеров массивов:

```c
#include <stdio.h>

#define N 4

int main(void)
{
    int numbers[N] = {1, 2, 3, 4};
    for (int i = 0; i < N; i++)
    {
        printf("%d ", numbers[i]);
    }
    return 0;
}
```

В данном случае, если захотим глобально поменять размер массива, достаточно изменить значение `N` в директиве `#define`.

## 5. Где замены не производятся

Следует учитывать, что директива препроцессора не заменяет последовательности символов в двойных и одинарных кавычках и в комментариях:

```c
#include <stdio.h>

#define N 4

int main(void)
{
    char symbol = 'N';
    printf("%c \n", symbol);    // N
    printf("N");                // N
    return 0;
}
```

Причем если идентификатор должен представлять одно слово, то его последовательность символов может состоять из нескольких слов или символов, разделенных пробелами:

```c
#define REAL long double
```

## 6. Директива #undef

В процессе работы мы можем многократно определять новое значение для одного идентификатора:

```c
#define N 23
#define N 32
#define N 55
```

Но некоторые компиляторы, в частности gcc, могут выдавать предупреждения при повторном определении идентификатора. Чтобы выйти из этой ситуации, мы можем использовать директиву `#undef` для отмены действия макроса. Эта директива имеет следующее определение:

```c
#undef идентификатор
```

Например:

```c
#include <stdio.h>

#define STRING "Good morning \n"

int main(void)
{
    printf(STRING);
    #undef STRING
    #define STRING "Good afternoon \n"
    printf(STRING);
    #undef STRING
    #define STRING "Good evening \n"
    printf(STRING);
    return 0;
}
```

## 7. Определение константы в командной строке

При использовании компилятора GCC можно с помощью флага `-D` определить константу аналогично тому, как это делается с помощью директивы `#define`. Для этого применяется выражение:

```
gcc -D ИДЕНТИФИКАТОР=ЗНАЧЕНИЕ
```

Например, определим следующую программу:

```c
#include <stdio.h>

int main(void)
{
    int x = NUMBER;

    printf("x = %d\n", x);
    return 0;
}
```

В данном случае переменной `x` присваивается значение некоторого идентификатора `NUMBER`. Обратите внимание, что он нигде не определен, и среда разработки или текстовый редактор могут подчеркивать этот идентификатор как некорректный.

Теперь скомпилируем данную программу с помощью следующей команды (допустим, исходный файл называется `app.c`):

```
gcc -D NUMBER=25 app.c -o app.exe && app.exe
```

В данном случае мы определяем препроцессорный символ `NUMBER` и присваиваем ему значение 25. В итоге программа успешно скомпилируется, а переменная `x` получит значение 25.

## 8. Резюме

1. `#define идентификатор последовательность` подставляет последовательность символов вместо идентификатора по всему файлу.
2. Макросы могут иметь параметры: `#define ADD(a, b) (a + b)`.
3. Замена не выполняется в кавычках, символьных литералах и комментариях.
4. `#undef` отменяет действие макроса и позволяет переопределить его без предупреждений.
5. Компилятор GCC позволяет определить константу через флаг `-D ИДЕНТИФИКАТОР=ЗНАЧЕНИЕ` в командной строке.
