## Описание

Нередко программе в течение работы довольно часто приходится выделять и освобождать память, и точное количество выделяемой памяти на момент компиляции неизвестно — оно становится известным в некоторый момент выполнения программы. Однако также нередко приходится выделять память **одного и того же размера**. Либо, хотя на момент компиляции мы не знаем точный размер выделяемой памяти, мы можем знать **максимальный размер** и быть уверены, что больше этого размера выделять память не придётся.

Частое выделение-освобождение памяти несёт дополнительные издержки, снижающие производительность. Кроме того, существует проблема **дефрагментации**: если размер наибольшего свободного фрагмента меньше размера запрошенной памяти, выделение памяти завершится неудачей, даже если совокупный размер всех свободных фрагментов больше. Потому что функция `malloc()` выделяет последовательный набор байтов.

В этом случае решением может быть применение **пула памяти** или паттерна **Memory Pool**.

## Размещение пула

Пул памяти может:

- Располагаться в **статической памяти**
- Выделяться в **динамической памяти**, а при завершении работы программы освобождаться с помощью функции `free()`

| Тип размещения | Достоинства | Недостатки |
|---|---|---|
| Статическая память | Быстрый доступ, нет издержек на выделение | Замедление старта, сложнее увеличить |
| Динамическая память | Возможность подгрузки дополнительной памяти | Необходимость освобождения, издержки на выделение |

## Реализация

В простейшем и общем случае реализацию пуля памяти можно представить следующим образом:

```c
#include <stdio.h>
#include <stdbool.h>
#include <stdlib.h>

#define MAX_ELEMENTS 10
#define ELEMENT_SIZE 255

typedef struct
{
    bool occupied;
    char memory[ELEMENT_SIZE];
} PoolBlock;

static PoolBlock memory_pool[MAX_ELEMENTS];

void* take(size_t size)
{
    if (size <= ELEMENT_SIZE)
    {
        for (size_t i = 0; i < MAX_ELEMENTS; i++)
        {
            if (memory_pool[i].occupied == 0)
            {
                memory_pool[i].occupied = 1;
                return &(memory_pool[i].memory);
            }
        }
    }
    return NULL;
}

void release(void *pointer)
{
    for (size_t i = 0; i < MAX_ELEMENTS; i++)
    {
        if (&(memory_pool[i].memory) == pointer)
        {
            memory_pool[i].occupied = 0;
            return;
        }
    }
}
```

Пул расположен в статической памяти и делится на блоки. Каждый блок представлен структурой `PoolBlock`. Поле `occupied` указывает, свободен ли блок. Массив `memory` — собственно память блока. Размер памяти блока задаётся значением `ELEMENT_SIZE`, а общее количество блоков — `MAX_ELEMENTS`.

### Функция take

Функция `take` получает размер памяти, которую надо выделить. Если этот размер меньше или равен размеру одного блока, проходим по всем блокам и ищем свободный. Если нашли свободный — возвращаем указатель на массив `memory` блока. В остальных случаях возвращаем `NULL`.

### Функция release

Функция `release` освобождает блок памяти. Она принимает указатель на блок, находит этот блок и сбрасывает его поле `occupied` в `0`, указывая, что блок свободен.

## Использование пула

Простейший пример использования пула:

```c
#include <stdio.h>
#include <stdbool.h>
#include <stdlib.h>

#define MAX_ELEMENTS 20
#define ELEMENT_SIZE 255

typedef struct
{
    int occupied;
    char memory[ELEMENT_SIZE];
} PoolBlock;

static PoolBlock memory_pool[MAX_ELEMENTS];

void* take(size_t size)
{
    if (size <= ELEMENT_SIZE)
    {
        for (size_t i = 0; i < MAX_ELEMENTS; i++)
        {
            if (memory_pool[i].occupied == 0)
            {
                memory_pool[i].occupied = 1;
                return &(memory_pool[i].memory);
            }
        }
    }
    return NULL;
}

void release(void *pointer)
{
    for (size_t i = 0; i < MAX_ELEMENTS; i++)
    {
        if (&(memory_pool[i].memory) == pointer)
        {
            memory_pool[i].occupied = 0;
            return;
        }
    }
}

int main(void)
{
    int bufSize = 16;
    char *buffer = take(bufSize);
    if (buffer)
    {
        printf("Enter name: ");
        fgets(buffer, bufSize, stdin);
        printf("Your name: %s\n", buffer);
        release(buffer);
    } else {
        printf("Unable to allocate memory\n");
    }
}
```

Запрашиваем в пуле память блок размером 16 байт и вводим в этот блок строку с консоли.

### Хранение данных других типов

Хотя память одного блока представляет массив `char`, в реальности мы можем разместить там данные любого типа, размер которого укладывается в размер блока:

```c
int main(void)
{
    unsigned *age = take(sizeof(unsigned));
    if (age)
    {
        printf("Enter age: ");
        scanf("%u", age);
        printf("Your age: %u\n", *age);
        release(age);
    } else {
        printf("Unable to allocate memory\n");
    }
}
```

Выделяем память под одно значение типа `unsigned`, на которое указывает переменная-указатель `age`.

## Преимущества и недостатки

| Преимущества | Недостатки |
|---|---|
| Уменьшение фрагментации | Нужно заранее знать максимальный размер |
| Быстрый доступ (статический пул) | Возможность неиспользования части блоков |
| Нет издержек на `malloc`/`free` | Увеличение времени запуска |
| Предсказуемость поведения | Блоки фиксированного размера |

> [!NOTE]
> Реализация пуля должна учитывать многопоточность: статическая память едина для всех потоков, поэтому доступ к пулу может потребовать механизмов разграничения (мьютексы, атомарные операции).
