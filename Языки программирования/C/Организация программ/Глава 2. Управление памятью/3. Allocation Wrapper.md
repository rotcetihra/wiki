## Описание

При многократном выделении динамической памяти в разных местах программы может возникнуть необходимость сразу же на месте обработать ошибки при выделении памяти. Однако таких мест в программе может быть много, и определять проверку в каждом месте может быть трудозатратным и вести к увеличению кода. Кроме того, в дальнейшем может возникнуть проблема: надо изменить механизм обработки ошибок, для чего придётся обновить все эти места.

Решением может быть создание **обёртки** над выделением памяти, где будет выполняться обработка ошибок выделения памяти или другие сопутствующие операции (например, логгирование). Данный паттерн называют **Allocation Wrapper**.

## Базовый пример

Можно определить функцию, которая проверяет выделение памяти:

```c
// обёртка над выделением памяти
void* allocation_wrapper(size_t size)
{
    void *pointer = malloc(size);
    assert(pointer && "Unable to allocate a memory");
    return pointer;
}

void some_function(void)
{
    char *buffer = allocation_wrapper(1024);
    // некоторая работа с buffer
    free(buffer);
}
```

Определяется функция-обёртка, в которой выделяется память. При неудачном выделении функция `malloc` возвращает `NULL`, и функция-обёртка обрабатывает этот результат. В примере выше для проверки применяется `assert()`: если выделение памяти прошло неудачно и `pointer` равен `NULL`, выполнение программы прерывается. Это **жёсткий** вариант реакции на ошибку.

## Мягкий вариант: пример с файлом

Рассмотрим программу, которая считывает текст из файла и выводит на консоль:

```c
#include <stdio.h>
#include <stdlib.h>
#include <assert.h>

void* create(size_t size)
{
    void *buffer = malloc(size);
    if (!buffer) printf("Unable to allocate memory\n");
    return buffer;
}

void delete(void *buffer)
{
    free(buffer);
    buffer = 0;
}

int getFileLength(FILE *fp)
{
    fseek(fp, 0, SEEK_END);
    int file_length = ftell(fp);
    return file_length;
}

void readFile(FILE *fp, char *buffer, int file_length)
{
    fseek(fp, 0, SEEK_SET);
    int read_elements = fread(buffer, 1, file_length, fp);
    buffer[read_elements] = '\0';
}

void printFile(char *filename)
{
    FILE *fp = 0;
    char *text = 0;

    assert(filename && "Invalid file name");
    fp = fopen(filename, "r");
    assert(fp && "Unable to open file!\n");

    int file_length = getFileLength(fp);
    if (file_length > 0)
    {
        text = create(file_length);
        if (text)
        {
            readFile(fp, text, file_length);
            printf("%s\n", text);
            delete(text);
        }
    }

    fclose(fp);
    fp = 0;
}

int main(void)
{
    char *filename = "test.txt";
    printFile(filename);
}
```

### Функция create

Функция `create()` выступает в роли функции-обёртки над `malloc()` и принимает размер выделяемой памяти:

```c
void* create(size_t size)
{
    void *buffer = malloc(size);
    if (!buffer) printf("Unable to allocate memory\n");
    return buffer;
}
```

Если выделение памяти прошло неудачно, логгируем на консоль сообщение об ошибке. И в любом случае возвращаем указатель.

### Функция delete

Функция `delete()` также является функцией-обёрткой, только над функцией `free()`:

```c
void delete(void *buffer)
{
    free(buffer);
    buffer = 0;
}
```

Освобождаем память и сбрасываем указатель в ноль, чтобы при последующих проверках он считался недействительным.

### Основная логика

Основная часть программы разворачивается в функции `printFile`. Полученную длину файла передаём в функцию-обёртку `create`:

```c
if (file_length > 0)
{
    text = create(file_length);
    if (text)
    {
        readFile(fp, text, file_length);
        printf("%s\n", text);
        delete(text);
    }
}
```

Мы определяем **единую точку** для обработки выделения и освобождения памяти в виде функций `create` и `delete`.

## Жёсткий вариант

В примере выше продемонстрирован мягкий вариант обработки ошибки: внешний код получает указатель из функции-обёртки и решает, что делать дальше. Но в ситуациях, где не требуется продолжать работу программы в случае ошибки, более предпочтительным может быть жёсткий подход — прерывание программы:

```c
#include <stdio.h>
#include <stdlib.h>
#include <assert.h>

void* create(size_t size)
{
    void *buffer = malloc(size);
    assert(buffer && "Unable to allocate memory");
    return buffer;
}

void delete(void *buffer)
{
    free(buffer);
    buffer = 0;
}

int getFileLength(char *filename)
{
    FILE *fp = fopen(filename, "r");
    assert(fp && "Unable to open file");
    fseek(fp, 0, SEEK_END);
    int file_length = ftell(fp);
    fclose(fp);
    return file_length;
}

void readFile(char *filename, char *buffer, int file_length)
{
    FILE *fp = fopen(filename, "r");
    assert(fp && "Unable to open file");
    int read_elements = fread(buffer, 1, file_length, fp);
    buffer[read_elements] = '\0';
    fclose(fp);
}

void printFile(char *filename)
{
    char *text = 0;
    assert(filename && "Invalid file name");

    int file_length = getFileLength(filename);
    if (file_length > 0)
    {
        text = create(file_length);
        readFile(filename, text, file_length);
        printf("%s\n", text);
        delete(text);
    }
}

int main(void)
{
    char *filename = "test.txt";
    printFile(filename);
}
```

Теперь в функции `create` проверяем выделение памяти с помощью `assert()`:

```c
void* create(size_t size)
{
    void *buffer = malloc(size);
    assert(buffer && "Unable to allocate memory");
    return buffer;
}
```

Если не удалось выделить память, прерываем программу, так как дальше продолжать нет смысла. Проверка на `NULL` после вызова `create` уже не нужна:

```c
int file_length = getFileLength(filename);
if (file_length > 0)
{
    text = create(file_length);
    // проверка на NULL уже не нужна
    readFile(filename, text, file_length);
    printf("%s\n", text);
    delete(text);
}
```

## Сравнение подходов

| Мягкий | Жёсткий |
|---|---|
| Возвращает указатель, вызывающий код проверяет на `NULL` | Использует `assert`, прерывает программу при ошибке |
| Больше кода (проверки в каждом месте) | Меньше кода |
| Подходит, когда можно восстановиться | Подходит, когда ошибки фатальны |

> [!NOTE]
> Allocation Wrapper позволяет集中 обработку ошибок выделения памяти в одном месте. При изменении механизма обработки достаточно обновить только функцию-обёртку, а не все места выделения памяти в программе.
