## Описание

Функция в C может возвращать только одно значение. Тем не менее, если нам надо получить из функции сразу несколько значений, мы можем использовать разные подходы. Основные из них — возвращение **комплексного объекта**, который инкапсулирует отдельные значения, либо использование **выходных параметров**.

## Объединение возвращаемых значений

Наиболее простой способ возвратить из функции несколько значений — определить структуру для хранения этих значений и возвратить её.

Например, нам надо получить из массива минимальное и максимальное значения:

```c
#include <stdio.h>
#include <assert.h>

typedef struct {
    int min;
    int max;
} MinMax;

MinMax getMinMax(int *array, size_t length)
{
    assert(length > 1 && "Array length is invalid");
    MinMax result;
    result.min = array[0];
    result.max = array[0];
    for (size_t i = 0; i < length; i++)
    {
        if (array[i] < result.min) result.min = array[i];
        if (array[i] > result.max) result.max = array[i];
    }
    return result;
}

int main(void)
{
    int array[] = {2, 3, 4, 5, 6, 9};
    size_t length = sizeof(array) / sizeof(int);
    MinMax data = getMinMax(array, length);

    printf("min=%d\n", data.min);
    printf("max=%d\n", data.max);
}
```

Для возвращения из функции минимального и максимального значения массива определена структура `MinMax`, которую возвращает функция `getMinMax`. Это наиболее простой и очевидный способ возвращения нескольких значений.

### Недостатки подхода

- Надо специально определять структуру под возвращаемые значения.
- При возвращении структуры происходит копирование её значений в стеке, что увеличивает объём потребляемой памяти.

## Выходные параметры

Другой способ — использование **выходных параметров** (out-параметров). Язык C как таковой не имеет концепции выходных параметров функции (как, например, C#), однако мы можем симулировать выходные параметры с помощью указателей:

```c
#include <stdio.h>
#include <assert.h>

void getMinMax(int *array, size_t length, int *min, int *max)
{
    assert(length > 1 && "Array length is invalid");
    *min = array[0];
    *max = array[0];
    for (size_t i = 0; i < length; i++)
    {
        if (array[i] < *min) *min = array[i];
        if (array[i] > *max) *max = array[i];
    }
}

int main(void)
{
    int array[] = {7, 3, 4, 5, 6, 8};
    size_t length = sizeof(array) / sizeof(int);

    int minVal = 0;
    int maxVal = 0;
    getMinMax(array, length, &minVal, &maxVal);
    printf("min=%d\n", minVal);
    printf("max=%d\n", maxVal);
}
```

### Механизм работы

Определяем в функции параметры-указатели:

```c
void getMinMax(int *array, size_t length, int *min, int *max)
```

Параметры-указатели `min` и `max` представляют выходные параметры. Внутри функции нам не важны их начальные значения — наоборот, функция **устанавливает** их значения.

При вызове функции определяются переменные, и их адреса передаются выходным параметрам:

```c
int minVal = 0;
int maxVal = 0;
getMinMax(array, length, &minVal, &maxVal);
```

## Сравнение подходов

| Критерий | Структура | Выходные параметры |
|---|---|---|
| Определение структуры | Требуется | Не требуется |
| Копирование в стек | Копируется вся структура | Копируются только значения |
| Читабельность вызова | `MinMax data = func()` | `func(..., &a, &b)` |
| Читабельность определения | Одно возвращаемое значение | Много параметров |
| Множественные возвраты | Одна структура на вызов | Каждый параметр отдельно |

> [!NOTE]
> Использование выходных параметров раздувает определение функции и может снизить её читабельность, особенно когда параметров много. В этом случае предпочтительнее структура.
