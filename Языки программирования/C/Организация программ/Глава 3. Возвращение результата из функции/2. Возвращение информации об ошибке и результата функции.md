## Описание

Если в процессе выполнения функции может произойти некоторая ошибка, мы захотим возвратить информацию об ошибке вызывающей стороне, чтобы вызывающий код мог узнать, что произошла ошибка, и как-то отреагировать на неё.

## Возврат статусного кода через значение возвращаемого типа

В самом простом случае решение состоит в том, чтобы для статуса ошибки использовать одно из значений возвращаемого типа.

Например, встроенная функция `getchar()` считывает один символ и возвращает его в виде значения типа `int`. Если же при считывании произошла ошибка, функция возвращает значение `EOF`, в качестве которого обычно используется число `-1`. Это число укладывается в значения типа `int` и в то же время не пересекается с возвращаемыми числовыми кодами символов.

### Пример: поиск в базе данных

```c
#include <stdio.h>
#include <string.h>
#include <assert.h>

#define USERS_NUMBER 5

typedef struct
{
    char *users[USERS_NUMBER];
} database;

int find(database *db, char*);

int main(void)
{
    database db = {.users = {"Tom", "Sam", "Bob", "Alice", "Kate"}};

    char *user = "Alice";
    int index = find(&db, user);
    if (index > -1)
    {
        printf("User index: %d\n", index);
    } else {
        printf("User not found\n");
    }
}

int find(database *db, char *user)
{
    assert(db != NULL && "Database is invalid");
    assert(user != NULL && "User is undefined");

    for (size_t i = 0; i < USERS_NUMBER; i++)
    {
        if (strcmp(db->users[i], user) == 0)
        {
            return i;
        }
    }
    return -1;
}
```

Функция `find` проходит по строкам в массиве `users` и с помощью `strcmp` сравнивает имя `user` с каждым элементом. Если пользователь найден — возвращается его индекс. Если не найден — возвращается `-1`.

Вызывающий код, получив результат, может идентифицировать, что строка найдена или не найдена в базе данных.

### Ограничения подхода

Подобный подход не всегда может использоваться. Например, если функция возвращает температуру в градусах, где валидные значения могут быть как положительными, так и отрицательными, и потенциально могут охватывать весь диапазон значений типа `int`, возникнет вопрос: какое именно значение использовать в качестве статуса ошибки?

## Возврат NULL для указателей

Если функция возвращает указатель, в качестве показателя ошибки можно возвращать значение `NULL`:

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <assert.h>

#define USERS_NUMBER 5

typedef struct
{
    char *users[USERS_NUMBER];
} database;

database* create_db(char*);

int main(void)
{
    database *db = create_db("Tom");
    if (db == NULL)
    {
        printf("Unable to create database\n");
        return -1;
    }

    for (size_t i = 0; i < USERS_NUMBER; i++)
    {
        printf("%s\n", db->users[i]);
    }
    free(db);
}

database* create_db(char *value)
{
    database *db = 0;
    if (value && (db = malloc(sizeof(database))))
    {
        for (size_t i = 0; i < USERS_NUMBER; i++)
        {
            db->users[i] = value;
        }
    }
    return db;
}
```

Функция `create_db` создаёт объект `database` и возвращает указатель на него. Если параметр `value` равен `NULL` или не удалось выделить память для структуры, возвращается `NULL`. Иначе возвращается указатель на объект `database`.

Значение `NULL` позволяет легко идентифицировать, что произошла ошибка в процессе создания объекта.

## Сравнение подходов

| Возвращаемый тип | Значение ошибки | Пример |
|---|---|---|
| `int` (индекс, код) | `-1` или специальное значение | `find()` возвращает `-1` |
| `int` (все значения валидны) | Невозможно использовать | Температура от `-273` до `+5000` |
| Указатель | `NULL` | `create_db()` возвращает `NULL` |

> [!NOTE]
> Если функция возвращает указатель, `NULL` — наиболее естественный способ указать на ошибку. Если функция возвращает целое число и все значения валидны, рассмотрите использование отдельного параметра для кода ошибки (например, `int *error_code`) или структуры с полем результата и полем ошибки.
