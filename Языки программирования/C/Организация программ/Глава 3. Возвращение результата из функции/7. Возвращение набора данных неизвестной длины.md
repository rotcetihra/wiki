## Описание

Иногда бывает необходимо получить большие или сложные по структуре данные **неизвестной длины**, которые могут изменяться в процессе работы программы.

- Статическая память с указателем — потребитель может столкнуться с несогласованностью данных.
- Структура из функции — стек ограничен, размер неизвестен.
- Буфер на стороне приёмника — приёмник должен узнать размер данных, который может измениться.

Решением может быть определение буфера для данных **на стороне компонента-источника данных**, поскольку только источник знает точный размер данных в текущий момент. Источник определяет функцию, которая возвращает буфер со скопированными данными и его размер.

## Вариант 1: через результат функции (структура)

### Определение структур (user.h)

```c
struct User {
    char *name;
    unsigned age;
};

struct UsersList
{
    struct User *buffer;
    size_t count;
};
```

### Источник данных (user.c)

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#include <assert.h>
#include "user.h"

static struct User data[] = {
    {"Tom", 39}, {"Bob", 43}, {"Sam", 29},
    {"Alice", 35}, {"Kate", 28}
};

struct UsersList getUsers(void)
{
    struct UsersList result;
    size_t data_size = sizeof(data);
    result.count = data_size / sizeof(struct User);
    result.buffer = malloc(data_size);
    assert(result.buffer != NULL && "Unable to allocate a memory");
    memcpy(result.buffer, data, data_size);
    return result;
}
```

Функция `getUsers` определяет размер данных и количество структур, выделяет динамическую память для буфера и копирует данные с помощью `memcpy`.

### Потребитель данных (app.c)

```c
#include <stdio.h>
#include <stdlib.h>
#include "user.h"

extern struct UsersList getUsers(void);

int main(void)
{
    struct UsersList result = getUsers();

    for (int i = 0; i < result.count; i++)
    {
        printf("%s - %u\n", result.buffer[i].name, result.buffer[i].age);
    }

    free(result.buffer);
}
```

Поскольку буфер выделен в динамической памяти, в конце освобождаем его.

### Вывод программы

```
Tom - 39
Bob - 43
Sam - 29
Alice - 35
Kate - 28
```

## Вариант 2: через выходные параметры

### Источник данных (user.c)

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#include <assert.h>
#include "user.h"

static struct User data[] = {
    {"Tom", 39}, {"Bob", 43}, {"Sam", 29},
    {"Alice", 35}, {"Kate", 28}
};

void getUsers(struct User **buffer, size_t *count)
{
    size_t data_size = sizeof(data);
    *count = data_size / sizeof(struct User);
    *buffer = malloc(data_size);
    assert(*buffer != NULL && "Unable to allocate a memory");
    memcpy(*buffer, data, data_size);
}
```

Функция `getUsers` получает адрес указателя на буфер и адрес переменной для количества структур.

### Потребитель данных (app.c)

```c
#include <stdio.h>
#include <stdlib.h>
#include "user.h"

extern void getUsers(struct User**, size_t*);

int main(void)
{
    struct User *buffer;
    size_t count = 0;
    getUsers(&buffer, &count);

    for (int i = 0; i < count; i++)
    {
        printf("%s - %u\n", buffer[i].name, buffer[i].age);
    }

    free(buffer);
}
```

## Вариант 3: буфер через параметр, размер через результат

### Источник данных (user.c)

```c
#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#include <assert.h>
#include "user.h"

static struct User data[] = {
    {"Tom", 22}, {"Bob", 43}, {"Sam", 29},
    {"Alice", 35}, {"Kate", 28}
};

size_t getUsers(struct User **buffer)
{
    size_t data_size = sizeof(data);
    size_t count = data_size / sizeof(struct User);
    *buffer = malloc(data_size);
    assert(*buffer != NULL && "Unable to allocate a memory");
    memcpy(*buffer, data, data_size);
    return count;
}
```

### Потребитель данных (app.c)

```c
#include <stdio.h>
#include <stdlib.h>
#include "user.h"

extern size_t getUsers(struct User**);

int main(void)
{
    struct User *buffer;
    size_t count = getUsers(&buffer);

    for (int i = 0; i < count; i++)
    {
        printf("%s - %u\n", buffer[i].name, buffer[i].age);
    }

    free(buffer);
}
```

## Сравнение подходов

| Вариант | Возврат буфера | Возврат размера | Читабельность |
|---|---|---|---|
| Структура-результат | Через поле `buffer` | Через поле `count` | Одно возвращаемое значение |
| Выходные параметры | Через `struct User**` | Через `size_t*` | Два параметра |
| Смешанный | Через `struct User**` | Через `return` | Один параметр, один результат |

> [!WARNING]
> Во всех вариантах **компонент-приёмник должен следить за освобождением памяти**. Буфер выделен в динамической памяти, и ответственность за его освобождение лежит на приёмнике.

> [!NOTE]
> Подход удобен в многопоточных системах: каждый поток, получив данные, работает с ними независимо от других потоков, и можно не беспокоиться, что данные изменятся извне.
