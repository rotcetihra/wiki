## Описание

Нередко выполнение функции зависит от некоторых **предусловий**. В качестве предусловий может выступать контекст, в котором запускается функция. В частности, это могут быть значения параметров или каких-то глобальных переменных.

Соответственно, проверка предусловий может быть очень важна: если предусловия не соблюдаются, то выполнение каких-то отдельных моментов функции или вообще всей функции не имеет смысла. Однако проблема часто заключается в том, что проверка предусловий **смешивается** с основным функционалом, что усложняет чтение и поддержку функции.

## Guard Clause

Общий механизм при работе с предусловиями состоит в их проверке в начале функции и немедленном выходе из функции, если предусловия не соблюдаются:

```c
void some_function(char *user_input)
{
    if (user_input == NULL) {
        return;
    }
    operate_on_data(user_input);
}
```

Подобный паттерн нередко называют **Guard Clause**.

## Пример: запись текста в файл

Рассмотрим программу, в которой функция `writeTextToFile()` записывает в файл строку:

```c
#include <stdio.h>

void writeTextToFile(char*, char*);

int main(void)
{
    char *filename = "test.txt";
    char *text = "hello";
    writeTextToFile(filename, text);
}

void writeTextToFile(char *file_name, char *text)
{
    FILE *file_pointer = 0;

    if (file_name)
    {
        if ((file_pointer = fopen(file_name, "w")))
        {
            if (text)
            {
                if (fputs(text, file_pointer) != EOF)
                {
                    printf("Success! Text has been written to the file!\n");
                }
            } else {
                printf("Error! Text is incorrect!\n");
            }
            fclose(file_pointer);
        } else {
            printf("Error! Unable to open file!\n");
        }
    } else {
        printf("Error! File name is incorrect!\n");
    }
}
```

Название файла и записываемый текст формируют предусловия, от которых зависит выполнение функции. Оба параметра не должны быть равны `NULL`. Функция проверяет эти предусловия, но проверка смешивается с основной логикой. Более того, корректность текста проверяется только **после** открытия файла.

## Вынос проверки предусловий

Определим проверку предусловий отдельно:

```c
#include <stdio.h>

void writeTextToFile(char*, char*);

int main(void)
{
    char *filename = "test.txt";
    char *text = "hello";
    writeTextToFile(filename, text);
}

void writeTextToFile(char *file_name, char *text)
{
    FILE *file_pointer = 0;

    // проверка предусловий
    if (file_name == NULL) {
        printf("Error! File name is incorrect!\n");
        return;
    }
    if (text == NULL) {
        printf("Error! Text is incorrect!\n");
        return;
    }

    // открываем файл
    if ((file_pointer = fopen(file_name, "w")))
    {
        // запись в файл
        if (fputs(text, file_pointer) != EOF)
        {
            printf("Success! Text has been written to the file!\n");
        }
        fclose(file_pointer);
    } else {
        printf("Error! Unable to open file!\n");
    }
}
```

Теперь в начале функции проверяются предусловия, и если они не соблюдаются, происходит выход. Мы избавились от глубокой вложенности `if`-ов, а предусловиями и основной логикой стало проще управлять.

## Guard Clause для каждого блока

Можно пойти дальше. На уровне основной части функции также есть предусловие — открыт файл или нет. Мы также можем подобным образом проверять предусловия к отдельным функциональным блокам:

```c
#include <stdio.h>

void writeTextToFile(char*, char*);

int main(void)
{
    char *filename = "test.txt";
    char *text = "hello";
    writeTextToFile(filename, text);
}

void writeTextToFile(char *file_name, char *text)
{
    // проверка предусловий
    if (file_name == NULL) {
        printf("Error! File name is incorrect!\n");
        return;
    }
    if (text == NULL) {
        printf("Error! Text is incorrect!\n");
        return;
    }

    // открываем файл
    FILE *file_pointer = fopen(file_name, "w");
    if (file_pointer == NULL) {
        printf("Error! Unable to open file!\n");
        return;
    }

    // запись в файл
    if (fputs(text, file_pointer) != EOF)
    {
        printf("Success! Text has been written to the file!\n");
    }

    // закрываем файл
    fclose(file_pointer);
}
```

Теперь каждый функциональный блок имеет собственную проверку предусловий с немедленным выходом. Код стал плоским и легко читается.

## Сравнение

| До | После |
|---|---|
| Каскад `if`/`else` | Плоская структура |
| Предусловия смешаны с логикой | Предусловия вынесены в начало |
| Глубокая вложенность | Минимальная вложенность |
| Сложно добавлять новые проверки | Каждая проверка — отдельный блок |

> [!NOTE]
> Guard Clause лучше всего работает, когда предусловия приводят к **немедленному выходу** из функции. Если предусловие требует альтернативной логики (а не выхода), стоит рассмотреть обычный `if`/`else`.
