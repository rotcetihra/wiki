## Описание

Если функция использует множество ресурсов, выделяет и освобождает для них память, а выделение одного ресурса зависит от успешности выделения другого, то на уровне кода программы это может вылиться в каскад вложенных конструкций `if`. Что, в свою очередь, затрудняет чтение и поддержку функции.

В прошлых темах в качестве возможного решения предлагалось применение оператора `goto` или ленивое выделение ресурсов. Тем не менее, при подобных подходах по мере возрастания количества используемых ресурсов повышается сложность функции и снижается её читабельность.

В качестве ещё одного решения можно применять концепцию **конструкторов и деструкторов**.

## Конструкторы и деструкторы в C

Конструкторы и деструкторы относятся больше к парадигме объектно-ориентированного программирования, к которой язык C не принадлежит. Например, в C++ на уровне классов определяются специальные функции — конструкторы, которые срабатывают при создании объекта и призваны выделять память и ресурсы. И также объект имеет специальную функцию деструктора, которая выполняется при удалении объекта и призвана освобождать используемые ресурсы.

На уровне программы на языке C мы можем определить подобные функции, которые будут совместно выделять и освобождать ресурсы:

```c
void some_function(void)
{
    allocate_resources();    // условный конструктор
    // некоторые основные действия
    free_resources();        // условный деструктор
}
```

Если ресурсы не представляют собой глобальные переменные, а определяются локально в функции, они передаются в конструктор/деструктор через параметры. Чтобы не передавать множество ресурсов по отдельности, можно определить один **сборный объект** (структуру). Если выделение какого-то ресурса прошло неудачно, эта информация сохраняется в переменную (например, в виде значения `NULL`). А при использовании или очистке ресурсов эта переменная проверяется на валидность.

## Пример: поиск слова в файле

Рассмотрим программу, которая ищет определённое слово в файле. Функция `find()` использует вложенные `if` для выделения ресурсов:

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <assert.h>

typedef enum { ERROR, FOUND, NOTFOUND } status;

status find(char*, char*, size_t);
status find_word(FILE*, char*, size_t, char*);

status find(char *file_name, char *word, size_t word_size)
{
    FILE *file_pointer = 0;
    char *buffer = 0;
    status result = ERROR;

    assert(file_name != NULL && "File name is invalid!");
    assert(word != NULL && "Word is invalid!");

    if ((file_pointer = fopen(file_name, "r")))
    {
        if ((buffer = malloc(word_size)))
        {
            result = find_word(file_pointer, word, word_size, buffer);
            free(buffer);
        }
        fclose(file_pointer);
    }
    return result;
}

status find_word(FILE *file_pointer, char *word, size_t word_size, char *buffer)
{
    while (fgets(buffer, word_size, file_pointer))
    {
        if (strcmp(word, buffer) == 0)
        {
            return FOUND;
        }
    }
    return NOTFOUND;
}

int main(void)
{
    char *filename = "test.txt";
    char word[] = "hello";
    size_t size = sizeof(word);

    status result = find(filename, word, size);

    switch (result)
    {
        case ERROR:
            printf("Error!\n");
            break;
        case NOTFOUND:
            printf("Text not found...\n");
            break;
        case FOUND:
            printf("Success! Text found!\n");
            break;
    }
}
```

Функция `find()` проверяет предусловия с помощью `assert`, тем самым нивелируя две конструкции `if`. Управление ресурсами и основные действия отделены вынесением поиска в отдельную функцию `find_word`. Тем не менее, применение вложенных `if` снижает читабельность:

```c
if ((file_pointer = fopen(file_name, "r")))
{
    if ((buffer = malloc(word_size)))
    {
        // ...
    }
    // ...
}
```

Кроме того, если рассматривать выделение ресурсов и их освобождение как две разные обязанности, то функция `find` не соответствует **принципу единой ответственности**.

## Применение конструктора и деструктора

Изменим программу, определив и применив функции конструктора и деструктора:

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <assert.h>

typedef enum { ERROR, FOUND, NOTFOUND } status;

typedef struct
{
    FILE *file_pointer;
    char *buffer;
    char *word;
    size_t word_size;
} Resources;

status find(char*, char*, size_t);
status find_word(Resources*);
Resources* constructor(char*, char*, size_t);
void destructor(Resources*);

Resources* constructor(char *file_name, char *word, size_t word_size)
{
    assert(file_name != NULL && "File name is invalid!");
    assert(word != NULL && "Word is invalid!");

    Resources *resources = malloc(sizeof(Resources));
    if (resources)
    {
        resources->file_pointer = fopen(file_name, "r");
        resources->buffer = malloc(word_size);

        if (!resources->file_pointer || !resources->buffer)
        {
            destructor(resources);
            return NULL;
        }

        resources->word = word;
        resources->word_size = word_size;
    }
    return resources;
}

void destructor(Resources *res)
{
    if (res)
    {
        if (res->buffer) {
            free(res->buffer);
        }
        if (res->file_pointer) {
            fclose(res->file_pointer);
        }
        free(res);
    }
}

status find(char *file_name, char *word, size_t word_size)
{
    status result;
    Resources *res = constructor(file_name, word, word_size);
    result = find_word(res);
    destructor(res);
    return result;
}

status find_word(Resources *res)
{
    if (res == NULL) {
        return ERROR;
    }
    while (fgets(res->buffer, res->word_size, res->file_pointer))
    {
        if (strcmp(res->word, res->buffer) == 0)
        {
            return FOUND;
        }
    }
    return NOTFOUND;
}

int main(void)
{
    char *filename = "test.txt";
    char word[] = "hello";
    size_t size = sizeof(word);

    status result = find(filename, word, size);

    switch (result)
    {
        case ERROR:
            printf("Error!\n");
            break;
        case NOTFOUND:
            printf("Text not found...\n");
            break;
        case FOUND:
            printf("Success! Text found!\n");
            break;
    }
}
```

## Разбор основных моментов

### Структура ресурсов

Для управления ресурсами определяется структура `Resources`:

```c
typedef struct
{
    FILE *file_pointer;
    char *buffer;
    char *word;
    size_t word_size;
} Resources;
```

Она хранит указатель на файл, указатель на выделенный (или не выделенный) буфер, указатель на искомое слово и размер слова.

### Конструктор

Объект структуры создаётся в функции конструктора:

```c
Resources* constructor(char *file_name, char *word, size_t word_size)
{
    assert(file_name != NULL && "File name is invalid!");
    assert(word != NULL && "Word is invalid!");

    Resources *resources = malloc(sizeof(Resources));
    if (resources)
    {
        resources->file_pointer = fopen(file_name, "r");
        resources->buffer = malloc(word_size);

        if (!resources->file_pointer || !resources->buffer)
        {
            destructor(resources);
            return NULL;
        }

        resources->word = word;
        resources->word_size = word_size;
    }
    return resources;
}
```

Функция конструктора принимает все значения, которые ранее передавались в функцию `find`, и с помощью `assert` проверяет предусловия. Затем выделяется память под структуру `Resources`. Если выделение прошло успешно, открывается файл и выделяется память для буфера.

Если либо открытие файла, либо выделение памяти прошло неудачно, очищаем выделенные ресурсы с помощью деструктора и возвращаем `NULL`:

```c
if (!resources->file_pointer || !resources->buffer)
{
    destructor(resources);
    return NULL;
}
```

Это гарантирует, что если, например, память для буфера была выделена, но файл не был открыт, то память буфера будет освобождена.

### Деструктор

Функция деструктора освобождает ранее выделенные ресурсы:

```c
void destructor(Resources *res)
{
    if (res)
    {
        if (res->buffer) {
            free(res->buffer);
        }
        if (res->file_pointer) {
            fclose(res->file_pointer);
        }
        free(res);
    }
}
```

Проверяем указатель на структуру на `NULL`, и только после этого освобождаем ресурсы.

### Функция find

В функции `find()` сначала вызывается конструктор, полученные ресурсы передаются в `find_word`, после чего вызывается деструктор:

```c
status find(char *file_name, char *word, size_t word_size)
{
    status result;
    Resources *res = constructor(file_name, word, word_size);
    result = find_word(res);
    destructor(res);
    return result;
}
```

В самой функции `find_word` сначала проверяется структура `Resources` на `NULL`:

```c
status find_word(Resources *res)
{
    if (res == NULL) {
        return ERROR;
    }
    // ...
}
```

## Преимущества подхода

| До | После |
|---|---|
| Каскад вложенных `if` | Плоская структура `find` |
| Выделение и освобождение смешаны | Чёткое разделение: конструктор / деструктор |
| Нарушение принципа единой ответственности | Каждая функция — одна задача |
| Сложно добавлять новые ресурсы | Добавление ресурса — изменение в двух местах |

> [!NOTE]
> Использование функций-конструкторов и функций-деструкторов может увеличить общее количество кода. Но взамен мы достигаем чёткого разделения между выделением и освобождением ресурсов, можем управлять этими процессами по отдельности, а также устраняем каскад вложенных конструкций `if`.
