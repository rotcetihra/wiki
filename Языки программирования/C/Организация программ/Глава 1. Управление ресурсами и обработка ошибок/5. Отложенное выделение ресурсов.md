## Описание

В предыдущей теме рассматривалась проблема, когда функция использует множество ресурсов, выделяет и освобождает для них память. Выделение одного ресурса зависит от успешности выделения другого: если выделение первого ресурса прошло удачно, выделяем второй ресурс. Но если получение второго ресурса прошло неудачно, память первого ресурса всё равно надо освободить.

В этом случае для управления ресурсами обычно напрашивается применение вложенных конструкций `if`, но это затрудняет чтение и поддержку функции. В прошлой теме в качестве ответа на эту проблему применялся оператор `goto`.

## Паттерн ленивого выделения

В качестве альтернативы можно использовать **ленивое выделение ресурсов** (lazy allocation), когда каждый последующий ресурс выделяется, если успешно был выделен предыдущий:

```c
void some_function(void)
{
    if ((resource1 = allocate_resource1()) && (resource2 = allocate_resource2()))
    {
        // основной код
    }

    if (resource1) {
        free_resource1();
    }
    if (resource2) {
        free_resource2();
    }
}
```

Когда начинает выполняться первая конструкция `if`, сначала выполняется выражение `resource1 = allocate_resource1()`, которое выделяет память для первого ресурса. Если выражение выполнилось успешно и возвратило ненулевое значение, выполняется второй операнд операции `&&` — выражение `resource2 = allocate_resource2()`. Если второй ресурс также успешно выделен, выполняется тело `if`.

После завершения первой конструкции `if` выполняется освобождение ресурсов, если они были успешно выделены. Таким образом, мы уходим от вложенности `if`-ов, а освобождение ресурсов выполняется **в одном месте** — в конце функции.

> [!NOTE]
> Если надо выделить много ресурсов, это перегружает условие в конструкции `if`, что может усложнить понимание и отладку.

## Пример: поиск слова в файле

Применим этот паттерн на примере программы, которая ищет определённое слово в файле:

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <assert.h>

typedef enum { ERROR, FOUND, NOTFOUND } status;

status find(char*, char*, size_t);
status find_word(FILE*, char*, size_t, char*);

status find(char *file_name, char *word, size_t word_size)
{
    FILE *file_pointer = 0;
    char *buffer = 0;
    status result = ERROR;

    assert(file_name != NULL && "File name is invalid!");
    assert(word != NULL && "Word is invalid!");

    // если удалось открыть файл и выделить память
    if ((file_pointer = fopen(file_name, "r")) && (buffer = malloc(word_size)))
    {
        result = find_word(file_pointer, word, word_size, buffer);
    }

    // секция освобождения ресурсов
    if (buffer) free(buffer);
    if (file_pointer) fclose(file_pointer);

    return result;
}

status find_word(FILE *file_pointer, char *word, size_t word_size, char *buffer)
{
    while (fgets(buffer, word_size, file_pointer))
    {
        if (strcmp(word, buffer) == 0)
        {
            return FOUND;
        }
    }
    return NOTFOUND;
}

int main(void)
{
    char *filename = "test.txt";
    char word[] = "hello";
    size_t size = sizeof(word);

    status result = find(filename, word, size);

    switch (result)
    {
        case ERROR:
            printf("Error!\n");
            break;
        case NOTFOUND:
            printf("Text not found...\n");
            break;
        case FOUND:
            printf("Success! Text found!\n");
            break;
    }
}
```

Функция `find()` открывает файл и выделяет буфер. И только если эти операции выполнились успешно, вызывается `find_word()`:

```c
if ((file_pointer = fopen(file_name, "r")) && (buffer = malloc(word_size)))
{
    result = find_word(file_pointer, word, word_size, buffer);
}
```

В конце функции проверяются выделенные ресурсы и очищаются:

```c
if (buffer) free(buffer);
if (file_pointer) fclose(file_pointer);
```

## Сравнение с goto

| Критерий | `goto` | Ленивое выделение |
|---|---|---|
| Вложенность `if` | Минимальная | Одно условие на все ресурсы |
| Освобождение ресурсов | В секции с метками | В конце функции |
| Читаемость при many ресурсах | Высокая | Снижается (длинное условие) |
| Точка выхода | Одна | Одна |

> [!NOTE]
> Ленивое выделение ресурсов хорошо работает, когда ресурсов немного (2–3). При большом количестве ресурсов рассмотрите `goto` или отдельные функции-обёртки.
