## 1. Установка Visual Studio

Одной из распространенных сред разработки для программирования на Windows является Visual Studio. В данном случае мы будем использовать бесплатную и полнофункциональную среду Visual Studio Community — актуальную версию можно загрузить по адресу https://visualstudio.microsoft.com/ru/vs/community/.

После загрузки и запуска установщика Visual Studio в нем необходимо отметить пункт **Разработка классических приложений на C++**:

```
[Скриншот: установка C++ в Visual Studio]
```

Выбрав все необходимые пункты, нажмем **ОК** для запуска установки.

## 2. Создание проекта

После установки Visual Studio создадим первый проект. Для этого откроем Visual Studio. На стартовом экране выберем тип **Empty Project** для языка C++.

```
[Скриншот: первый проект на Си в Visual Studio]
```

На следующем экране в поле для имени проекта дадим проекту имя `HelloApp` и, при желании, укажем расположение проекта. Затем нажмем **Create** для создания проекта.

## 3. Добавление исходного файла

После этого Visual Studio создаст пустой проект. Добавим в него текстовый файл для набора исходного кода. Для этого в окне **Solution Explorer** (Обозреватель решений) нажмем правой кнопкой мыши на узел **Source Files** и в контекстном меню выберем **Add -> New Item...**.

Затем откроется окно для добавления нового элемента. Здесь надо выбрать пункт **C++ File (.cpp)**, а внизу окна указать для файла имя `hello.c`. Как правило, исходные файлы на Си имеют расширение `.c` — оно указывает, что этот файл содержит исходный код на языке C, и он будет обрабатываться соответствующим компилятором.

## 4. Настройка проекта

После добавления файла изменим опции проекта. Для этого перейдем к пункту меню **Project -> Properties**.

В окне свойств проекта в левой части перейдем к секции **C/C++** и далее к пункту **Advanced**. В правой части окна для поля **Compile As** установим значение **Compile as C Code (/TC)**. Тем самым мы сообщаем Visual Studio, чтобы по умолчанию исходный код компилировался именно как код C, а не C++.

После установки этого значения нажмем на кнопку **Применить**, чтобы новые настройки конфигурации вступили в силу.

Для работы с языком Си может быть полезна еще одна настройка — установка стандарта языка. Перейдем к пункту **C/C++ -> Language**. Здесь в поле **C Language Standard** можно установить один из доступных стандартов для языка Си, который будет применяться для компиляции. Правда, в данном случае он не имеет значения, поэтому оставим для этого параметра настройку по умолчанию.

## 5. Структура проекта

После добавления файла `hello.c` проект будет иметь следующую структуру. Окно **Solution Explorer** отображает решение. В данном случае оно называется `HelloApp`. Решение может содержать несколько проектов. По умолчанию у нас один проект, который имеет то же имя — `HelloApp`. В проекте есть ряд узлов:

- **External Dependencies** — отображает файлы, которые используются в файлах исходного кода, но не являются частью проекта;
- **Header Files** — предназначена для хранения заголовочных файлов с расширением `.h`;
- **Resource Files** — предназначена для хранения файлов ресурсов, например, изображений;
- **Source Files** — хранит файлы с исходным кодом.

## 6. Определение кода программы

Теперь определим в файле `hello.c` простейший код, который будет выводить строку на консоль:

```c
#include <stdio.h>            // подключаем заголовочный файл stdio.h
int main(void)                      // определяем функцию main
{                                   // начало функции
    printf("Hello METANIT.COM!\n"); // выводим строку на консоль
    return 0;                       // выходим из функции
}                                   // конец функции
```

Этот код был рассмотрен в предыдущих темах про компиляцию с помощью GCC.

## 7. Запуск программы

Запустим программу. Для этого в Visual Studio нажмем на сочетание клавиш `Ctrl+F5` или выберем пункт меню **Debug -> Start Without Debugging**.

В итоге Visual Studio передаст исходный код компилятору, который скомпилирует из кода исполняемый файл `exe`, который потом будет запущен на выполнение. И мы увидим на запущенной консоли наше сообщение:

```
Hello METANIT.COM!
```

Затем в проекте в папке `x64/Debug` мы можем увидеть скомпилированный файл `exe`, который можно запускать независимо от Visual Studio. В данном случае файл `HelloApp.exe` как раз и представляет скомпилированный исполняемый файл.

## 8. Резюме

1. Для разработки на Си в Windows используется Visual Studio Community с установленным компонентом «Разработка классических приложений на C++».
2. Проект создается по шаблону Empty Project, исходный файл добавляется с расширением `.c`.
3. Чтобы код компилировался как C (а не C++), в свойствах проекта для пункта **Advanced** необходимо установить параметр **Compile As** в значение **Compile as C Code (/TC)**.
4. Программа запускается клавишами `Ctrl+F5`, скомпилированный файл `HelloApp.exe` находится в папке `x64/Debug`.
