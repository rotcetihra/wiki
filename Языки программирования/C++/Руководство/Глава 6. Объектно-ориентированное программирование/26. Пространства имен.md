## Пространства имен

Пространства имен (namespaces) представляют способ группировки похожих элементов под общим названием. Пространства имен могут группировать функции, классы, а также иные переменные и функции. Пространства имен снижают вероятность конфликтов имен.

Для создания пространства имен используется ключевое слово **namespace**:

```cpp
#include <iostream>
#include <string>

namespace nsCompany
{
    class Person
    {
    public:
        Person(std::string name): name{name}{}
        void print() const { std::cout << name << std::endl; }
    private:
        std::string name;
    };
    void print() {std::cout << "Company Print" << std::endl;}
}
namespace nsSchool
{
    class Student
    {
    public:
        Student(std::string subject): subject{subject}{}
        void print() const { std::cout << subject << std::endl; }
    private:
        std::string subject;
    };
    void print() {std::cout << "School Print" << std::endl;}
}

int main()
{
    nsCompany::Person tom{"Tom"};
    nsSchool::Student sam{"Math"};
    tom.print();
    sam.print();
    nsCompany::print();
    nsSchool::print();
}
```

Пространства имен company и school имеют одноименные классы, но так как они лежат в различных пространствах, это не вызывает конфликта имен.

### Директива using

Директива **using** позволяет подключить пространство имен:

```cpp
using namespace nsCompany;
```

Или подключить отдельный элемент:

```cpp
using nsCompany::Person;
```

### Пространства имен std

Стандартная библиотека C++ определена в пространстве имен **std**. Поэтому мы используем директиву using, чтобы подключить пространство имен std.
