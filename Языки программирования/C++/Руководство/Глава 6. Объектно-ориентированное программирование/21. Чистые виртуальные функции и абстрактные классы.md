## Чистые виртуальные функции и абстрактные классы

С++ позволяет создать класс, который не имеет какую-то логику (то есть функции определены, но их тела не определены). Такие классы называются абстрактными, а функции, которые в классе не имеют реализации, называются виртуальными чистыми функциями.

Чистые виртуальные функции определяются с использованием чистой функции, то есть при определении класса ей ставится знак "равно" и пустые скобки:

```cpp
class Figure
{
public:
    void draw() const = 0;  // чистая виртуальная функция
};
```

Классы, которые содержат хотя бы одну чистую виртуальную функцию, называются абстрактными классами. Абстрактные классы нельзя использовать для определения объектов. Их могут использоваться только в качестве базовых классов, которые впоследствии подклассируются.

```cpp
#include <iostream>

class Figure
{
public:
    virtual void draw() const = 0;
    virtual void printArea() const = 0;
};

class Circle : public Figure
{
public:
    Circle(unsigned r): radius{r}{}
    void draw() const override
    {
        std::cout << "Circle" << std::endl;
    }
    void printArea() const override
    {
        std::cout << "Area circle: " << 3.14 * radius * radius << std::endl;
    }
private:
    unsigned radius;
};

class Rectangle : public Figure
{
public:
    Rectangle(unsigned w, unsigned h): width{w}, height{h}{}
    void draw() const override
    {
        std::cout << "Rectangle" << std::endl;
    }
    void printArea() const override
    {
        std::cout << "Area rectangle: " << width * height << std::endl;
    }
private:
    unsigned width;
    unsigned height;
};

int main()
{
    Circle circle{10};
    Rectangle rect{20, 15};
    circle.draw();
    circle.printArea();
    rect.draw();
    rect.printArea();
}
```

Для каждого подкласса функции printArea() и draw() реализуются по-разному, в соответствии с типом фигуры.

### Виртуальные деструкторы для абстрактных классов

Для удаления абстрактного типа надо определить виртуальный деструктор:

```cpp
class Figure
{
public:
    virtual void draw() const = 0;
    virtual void printArea() const = 0;
    virtual ~Figure(){ }
};
```

### Чистая виртуальная функция для членов класса

Функции необязательно определять как виртуальные, главное - чтобы классы содержали хотя бы одну виртуальную функцию:

```cpp
class Figure
{
public:
    void draw() const = 0;      // чистая виртуальная функция
    virtual void printArea() const = 0;  // виртуальная чистая функция
};
```
