## Указатели на поля и методы класса

### Указатели на методы класса

В C++ существуют указатели на методы класса. Для создания указателя на метод используются круглые скобки и указание класса, к которому принадлежит метод:

```cpp
#include <iostream>
#include <string>

class Person
{
public:
    Person(std::string name): name{name}{}
    void greet() { std::cout << "Hello, " << name << std::endl; }
    void greet2() { std::cout << "Welcome, " << name << std::endl; }
private:
    std::string name;
};

int main()
{
    void (Person::*func)() = &Person::greet;
    Person tom{"Tom"};
    (tom.*func)();      // Hello, Tom
    func = &Person::greet2;
    (tom.*func)();      // Welcome, Tom
}
```

### Указатели на поля класса

```cpp
#include <iostream>
#include <string>

class Person
{
public:
    Person(std::string name, int age): name{name}, age{age}{}
    std::string name;
    int age;
};

int main()
{
    std::string Person::*ptr = &Person::name;
    Person tom{"Tom", 38};
    std::cout << tom.*ptr << std::endl;

    int Person::*ptrAge = &Person::age;
    Person bob{"Bob", 42};
    std::cout << bob.*ptrAge << std::endl;
}
```

### Указатели и умные указатели

Для smart-указателей определен оператор ->*, который позволяет вызывать методы через умные указатели:

```cpp
#include <iostream>
#include <string>
#include <memory>

class Person
{
public:
    Person(std::string name): name{name}{}
    void greet() { std::cout << "Hello, " << name << std::endl; }
private:
    std::string name;
};

int main()
{
    std::unique_ptr<Person> tom = std::make_unique<Person>("Tom");
    void (Person::*func)() = &Person::greet;
    (tom.get()->*func)();
}
```
