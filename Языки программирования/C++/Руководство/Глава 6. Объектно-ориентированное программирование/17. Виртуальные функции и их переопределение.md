## Виртуальные функции и их переопределение

### Статическое и динамическое связывание

Когда вызовы функций фиксируются до выполнения программы на этапе компиляции, это называется статическим связыванием (static binding), либо ранним связыванием (early binding).

Динамическое связывание (dynamic binding) позволяет на этапе выполнения решать, функцию какого типа вызвать. Для этого в языке С++ применяют виртуальные функции.

Для определения виртуальной функции в базовом классе функция определяется с ключевым словом **virtual**:

```cpp
#include <iostream>
#include <string>

class Person
{
public:
    Person(std::string name): name{name}
    { }
    virtual void print() const  // виртуальная функция
    {
        std::cout << "Name: " << name << std::endl;
    }
private:
    std::string name;
};
class Employee: public Person
{
public:
    Employee(std::string name, std::string company): Person{name}, company{company}
    { }
    void print() const
    {
        Person::print();
        std::cout << "Works in " << company << std::endl;
    }
private:
    std::string company;
};

int main()
{
    Person tom {"Tom"};
    Person* person {&tom};
    person->print();     // Name: Tom
    Employee bob {"Bob", "Microsoft"};
    person = &bob;
    person->print();    // Name: Bob
                        // Works in Microsoft
}
```

### Ключевое слово override

Чтобы явным образом указать, что мы хотим переопределить функцию, а не скрыть ее, в производном классе после списка параметров функции указывается слово **override**:

```cpp
void print() const override // явным образом указываем, что функция переопределена
```

Если override не указать, то компилятор будет считать, что речь идет о скрытии функции, и никаких ошибок не будет генерировать. Поэтому при переопределении виртуальной функции лучше указывать слово override.

### Принцип выполнения виртуальных функций

При создании объекта полиморфного класса в объекте создается специальный указатель, который указывает на таблицу указателей функций (vtable).

### Запрет переопределения

С помощью спецификатора **final** мы можем запретить определение в производных классах функций:

```cpp
class Person
{
public:
    virtual void print() const final
    { }
};
```
