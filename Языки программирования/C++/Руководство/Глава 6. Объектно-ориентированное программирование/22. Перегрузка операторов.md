## Перегрузка операторов

Для работы с пользовательскими типами данных в C++ есть возможность перегружать операторы. Перегрузка операторов аналогична определению функций:

```cpp
#include <iostream>

class Point
{
public:
    int x;
    int y;
    Point(int x, int y): x{x}, y{y}{}

    Point operator+(const Point& other) const
    {
        return Point{x + other.x, y + other.y};
    }
};

int main()
{
    Point p1{10, 20};
    Point p2{20, 30};
    Point p3 = p1 + p2;
    std::cout << "x: " << p3.x << "\t y: " << p3.y << std::endl;   // x: 30      y: 50
}
```

Сигнатура оператора должна включать ключевое слово **operator**, после которого идет оператор (в нашем случае - плюс).

### Логические операторы

```cpp
bool operator==(const Point& other) const
{
    return (x == other.x) && (y == other.y);
}
bool operator!=(const Point& other) const
{
    return !(*this == other);
}
bool operator>(const Point& other) const
{
    return x + y > other.x + other.y;
}
```

### Увеличение и уменьшение

```cpp
Point& operator++()     // префиксный инкремент
{
    x++;
    y++;
    return *this;
}
Point operator++(int)   // постфиксный инкремент
{
    Point temp {*this};
    ++(*this);
    return temp;
}
```

### Индексный оператор

```cpp
int operator[](int index) const
{
    switch(index)
    {
        case 0: return x;
        case 1: return y;
        default: throw "Invalid index";
    }
}
```

### Потоковый вывод

```cpp
friend std::ostream& operator<<(std::ostream& os, const Point& p)
{
    os << "(" << p.x << "; " << p.y << ")";
    return os;
}
```
