## Оператор индексирования

С++ позволяет реализовать для пользовательского типа оператор [], который позволяет получать доступ к элементам с помощью индекса. Формат оператора [] следующий:

```cpp
возвращаемый_тип operator[] (тип_индекса index)
{
    ...
}
```

Для индексации мы можем определить класс Array:

```cpp
#include <iostream>

class Array
{
public:
    Array(unsigned size)
    {
        this->size = size;
        data = new int[size]{};
    }
    int& operator[](unsigned index)
    {
        if(index >= size) throw "Index is out of range";
        return data[index];
    }
    unsigned getSize() const { return size; }
    void print() const
    {
        for(unsigned i = 0; i < size; i++)
            std::cout << data[i] << " ";
        std::cout << std::endl;
    }
    ~Array() { delete[] data; }
private:
    int* data;
    unsigned size;
};

int main()
{
    Array numbers{5};
    numbers[0] = 10;
    numbers[1] = 20;
    numbers[2] = 30;
    numbers.print();
}
```

Внутри оператора [] проверяется граница индекса, и если индекс выходит за границы массива, выбрасывается исключение. Если индекс корректен, то возвращается ссылка на элемент массива.
