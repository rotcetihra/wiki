## Прототип

```cpp
#include <cmath>

float pow(float base, float exp);
double pow(double base, double exp);
long double pow(long double base, long double exp);
```

## Параметры

| Параметр | Описание |
|---|---|
| `base` | Основание |
| `exp` | Показатель степени |

## Возвращаемое значение

`base^exp`.

## Что делает

Возводит основание в степень.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::pow(2.0, 10.0) << std::endl; // 1024
    std::cout << std::pow(9.0, 0.5) << std::endl;  // 3
}
```
