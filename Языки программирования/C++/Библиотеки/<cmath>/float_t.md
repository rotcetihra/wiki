## Прототип

```cpp
#include <cmath>

typedef /* float или double */ float_t;
```

## Параметры

Нет.

## Возвращаемое значение

Тип `float_t` — тип с плавающей точкой, не менее точный, чем `float`. Определяется реализацией в зависимости от флагов оптимизации.

## Что делает

Определяет тип `float_t`, который используется как тип возвращаемого значения для математических функций с аргументами `float`.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    float_t x = 3.14f;
    std::cout << sizeof(x) << std::endl;
}
```

## Исключения

- **Исключения:** тип определения, не функция.
