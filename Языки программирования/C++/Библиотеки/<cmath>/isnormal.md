## Прототип

```cpp
#include <cmath>

int isnormal(float x);
int isnormal(double x);
int isnormal(long double x);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Значение с плавающей точкой |

## Возвращаемое значение

Ненулевое значение, если `x` является нормализованным числом (не ноль, не бесконечность, не NaN, не поднормализованное).

## Что делает

Проверяет, является ли число нормализованным.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::isnormal(3.14) << std::endl;  // 1
    std::cout << std::isnormal(0.0) << std::endl;   // 0
}
```
