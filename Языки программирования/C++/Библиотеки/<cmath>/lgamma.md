## Прототип

```cpp
#include <cmath>

float lgamma(float arg);
double lgamma(double arg);
long double lgamma(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение |

## Возвращаемое значение

Натуральный логарифм абсолютного значения гамма-функции: `ln|Γ(arg)|`.

## Что делает

Вычисляет логарифм гамма-функции. Полезно для больших значений, когда `tgamma` переполняется.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::lgamma(1.0) << std::endl; // 0 (ln|Γ(1)| = ln(1) = 0)
}
```

- **Исключения:** может установить `EDOM` или `ERANGE`.
