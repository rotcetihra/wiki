## Прототип

```cpp
#include <cmath>

float rint(float arg);
double rint(double arg);
long double rint(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение с плавающей точкой |

## Возвращаемое значение

Ближайшее целое значение по текущему режиму округления.

## Что делает

Округляет до ближайшего целого числа. Может генерировать FP-исключение `FE_INEXACT`, если результат отличается от аргумента.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::rint(2.3) << std::endl; // 2
}
```

## Исключения

- **Исключения:** может генерировать `FE_INEXACT`.
