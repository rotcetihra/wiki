## Прототип

```cpp
#include <cmath>

float cbrt(float arg);
double cbrt(double arg);
long double cbrt(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение |

## Возвращаемое значение

Кубический корень `∛arg`. Работает для любых значений, включая отрицательные.

## Что делает

Вычисляет кубический корень числа.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::cbrt(27.0) << std::endl;  // 3
    std::cout << std::cbrt(-8.0) << std::endl;  // -2
}
```
