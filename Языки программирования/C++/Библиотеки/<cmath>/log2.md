## Прототип

```cpp
#include <cmath>

float log2(float arg);
double log2(double arg);
long double log2(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение (должно быть > 0) |

## Возвращаемое значение

Логарифм по основанию 2: `log₂(arg)`.

## Что делает

Вычисляет логарифм по основанию 2.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::log2(1024.0) << std::endl; // 10
    std::cout << std::log2(0.5) << std::endl;    // -1
}
```

## Исключения

- **Исключения:** может установить `EDOM` при `arg <= 0`.
