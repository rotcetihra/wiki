## Прототип

```cpp
#include <cmath>

long long llround(float arg);
long long llround(double arg);
long long llround(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение с плавающей точкой |

## Возвращаемое значение

Ближайшее значение типа `long long`.

## Что делает

Округляет до ближайшего целого числа типа `long long`.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::llround(2.7) << std::endl;  // 3
    std::cout << std::llround(-2.5) << std::endl; // -3
}
```
