## Прототип

```cpp
#include <cmath>

float trunc(float arg);
double trunc(double arg);
long double trunc(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение с плавающей точкой |

## Возвращаемое значение

Ближайшее значение с плавающей точкой, которое по модулю не больше модуля `arg`.

## Что делает

Отбрасывает дробную часть числа (округляет к нулю).

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::trunc(2.7) << std::endl;  // 2
    std::cout << std::trunc(-2.7) << std::endl; // -2
}
```
