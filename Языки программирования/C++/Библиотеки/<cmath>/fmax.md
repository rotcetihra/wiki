## Прототип

```cpp
#include <cmath>

float fmax(float x, float y);
double fmax(double x, double y);
long double fmax(long double x, long double y);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Первое значение |
| `y` | Второе значение |

## Возвращаемое значение

Большее из двух значений. Если одно из значений NaN, возвращает другое.

## Что делает

Возвращает большее из двух чисел. Если оба NaN, возвращает NaN.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::fmax(3.0, 5.0) << std::endl; // 5
}
```
