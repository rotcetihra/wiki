## Прототип

```cpp
#include <cmath>

float log10(float arg);
double log10(double arg);
long double log10(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение (должно быть > 0) |

## Возвращаемое значение

Десятичный логарифм `log₁₀(arg)`.

## Что делает

Вычисляет десятичный логарифм числа.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::log10(100.0) << std::endl; // 2
    std::cout << std::log10(1.0) << std::endl;    // 0
}
```

## Исключения

- **Исключения:** может установить `EDOM` при `arg <= 0`.
