## Прототип

```cpp
#include <cmath>

float log(float arg);
double log(double arg);
long double log(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение (должно быть > 0) |

## Возвращаемое значение

Натуральный логарифм `ln(arg)`.

## Что делает

Вычисляет натуральный логарифм числа.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::log(1.0) << std::endl;  // 0
    std::cout << std::log(2.71828) << std::endl; // ≈1
}
```

## Исключения

- **Исключения:** может установить `EDOM` при `arg <= 0`.
