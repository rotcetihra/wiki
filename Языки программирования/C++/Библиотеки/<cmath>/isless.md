## Прототип

```cpp
#include <cmath>

bool isless(float x, float y);
bool isless(double x, double y);
bool isless(long double x, long double y);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Левый операнд |
| `y` | Правый операнд |

## Возвращаемое значение

`true`, если `x < y`.

## Что делает

Безопасное сравнение «меньше». Не генерирует FP-исключения при участии NaN.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::isless(2.0, 3.0) << std::endl; // 1
}
```
