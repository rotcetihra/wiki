## Прототип

```cpp
#include <cmath>

#define FP_FAST_FMA /* если определено, fma быстрее чем a*b+c */
```

## Параметры

Нет.

## Возвращаемое значение

Макрос определён, если функция `fma` для `double` выполняется быстрее, чем отдельные умножение и сложение.

## Что делает

Указывает на наличие аппаратной поддержки fused multiply-add для `double`.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
#ifdef FP_FAST_FMA
    std::cout << "fma оптимизировано" << std::endl;
#endif
}
```

## Исключения

- **Исключения:** макрос определения, не функция.
