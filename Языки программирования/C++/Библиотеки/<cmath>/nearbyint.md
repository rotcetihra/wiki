## Прототип

```cpp
#include <cmath>

float nearbyint(float arg);
double nearbyint(double arg);
long double nearbyint(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение с плавающей точкой |

## Возвращаемое значение

Ближайшее целое значение (как float) по текущему режиму округления.

## Что делает

Округляет до ближайшего целого числа, используя текущий режим округления плавающей точки. Не изменяет `errno` и не генерирует FP-исключения.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::nearbyint(2.3) << std::endl;  // 2
    std::cout << std::nearbyint(2.5) << std::endl;  // 2 или 3 (зависит от режима)
}
```
