## Прототип

```cpp
#include <cmath>

float sqrt(float arg);
double sqrt(double arg);
long double sqrt(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Неотрицательное значение |

## Возвращаемое значение

Квадратный корень `√arg`.

## Что делает

Вычисляет квадратный корень числа.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::sqrt(25.0) << std::endl; // 5
    std::cout << std::sqrt(2.0) << std::endl;  // 1.41421
}
```

## Исключения

- **Исключения:** может установить `EDOM` при отрицательном аргументе.
