## Прототип

```cpp
#include <cmath>

float logb(float arg);
double logb(double arg);
long double logb(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение |

## Возвращаемое значение

Вещественная часть `log_r(|arg|)`, где `r = FLT_RADIX`.

## Что делает

Извлекает вещественный показатель мантиссы. Вещественный аналог `ilogb`.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::logb(1024.0) << std::endl; // 10
    std::cout << std::logb(0.25) << std::endl;   // -2
}
```

- **Исключения:** может установить `EDOM` при аргументе 0.
