## Прототип

```cpp
#include <cmath>

#define math_errhandling /* implementation-defined */
```

## Параметры

Нет.

## Возвращаемое значение

Макрос,代表ляющий текущую политику обработки ошибок. Может быть `MATH_ERRNO`, `MATH_ERREXCEPT`, их комбинацией или `0`.

## Что делает

Определяет, как обрабатываются ошибки математических функций: через установку `errno`, генерацию исключений плавающей точки или и то, и другое.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << "math_errhandling = " << math_errhandling << std::endl;
}
```

## Исключения

- **Исключения:** макрос определения, не функция.
