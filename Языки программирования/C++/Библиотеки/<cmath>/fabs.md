## Прототип

```cpp
#include <cmath>

float fabs(float arg);
double fabs(double arg);
long double fabs(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение с плавающей точкой |

## Возвращаемое значение

Абсолютное значение `|arg|`.

## Что делает

Возвращает абсолютное значение числа с плавающей точкой.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::fabs(-3.14) << std::endl; // 3.14
}
```
