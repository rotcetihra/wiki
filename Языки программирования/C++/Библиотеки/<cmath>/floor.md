## Прототип

```cpp
#include <cmath>

float floor(float arg);
double floor(double arg);
long double floor(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение с плавающей точкой |

## Возвращаемое значение

Наибольшее целое число (как float), не большее `arg`.

## Что делает

Округляет вниз до ближайшего целого числа.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::floor(2.7) << std::endl;  // 2
    std::cout << std::floor(-2.7) << std::endl; // -3
}
```
