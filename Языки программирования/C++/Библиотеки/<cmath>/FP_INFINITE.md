## Прототип

```cpp
#include <cmath>

#define FP_INFINITE /* значение.fpclassify == FP_INFINITE */
```

## Параметры

Нет.

## Возвращаемое значение

Константа,代表ляющая бесконечное значение в `fpclassify`.

## Что делает

Один из результатов `fpclassify`. Указывает, что число является бесконечным.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    double x = HUGE_VAL;
    if (std::fpclassify(x) == FP_INFINITE)
        std::cout << "x — бесконечность" << std::endl;
}
```
