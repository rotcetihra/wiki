## Прототип

```cpp
#include <cmath>

float fmin(float x, float y);
double fmin(double x, double y);
long double fmin(long double x, long double y);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Первое значение |
| `y` | Второе значение |

## Возвращаемое значение

Меньшее из двух значений. Если одно из значений NaN, возвращает другое.

## Что делает

Возвращает меньшее из двух чисел.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::fmin(3.0, 5.0) << std::endl; // 3
}
```
