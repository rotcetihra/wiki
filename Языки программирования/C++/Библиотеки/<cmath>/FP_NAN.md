## Прототип

```cpp
#include <cmath>

#define FP_NAN /* значение.fpclassify == FP_NAN */
```

## Параметры

Нет.

## Возвращаемое значение

Константа,代表ляющая NaN в `fpclassify`.

## Что делает

Указывает, что число является NaN (Not a Number).

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    double x = 0.0 / 0.0;
    if (std::fpclassify(x) == FP_NAN)
        std::cout << "x — NaN" << std::endl;
}
```
