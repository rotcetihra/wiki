## Прототип

```cpp
#include <cmath>

float ldexp(float arg, int exp);
double ldexp(double arg, int exp);
long double ldexp(long double arg, int exp);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Мантисса |
| `exp` | Показатель степени двойки |

## Возвращаемое значение

`arg * 2^exp`.

## Что делает

Вычисляет значение путём умножения числа на целую степень двойки.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::ldexp(1.0, 10) << std::endl; // 1024
    std::cout << std::ldexp(0.75, 3) << std::endl;  // 6
}
```

## Исключения

- **Исключения:** может установить `ERANGE` при переполнении.
