## Прототип

```cpp
#include <cmath>

int isfinite(float x);
int isfinite(double x);
int isfinite(long double x);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Значение с плавающей точкой |

## Возвращаемое значение

Ненулевое значение, если `x` конечно (не NaN и не бесконечность).

## Что делает

Проверяет, является ли число конечным (не `±∞` и не `NaN`).

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::isfinite(3.14) << std::endl;  // 1
    std::cout << std::isfinite(HUGE_VAL) << std::endl; // 0
}
```
