## Прототип

```cpp
#include <cmath>

float modf(float arg, float* iptr);
double modf(double arg, double* iptr);
long double modf(long double arg, long double* iptr);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение для разделения |
| `iptr` | Указатель на сохранение целой части |

## Возвращаемое значение

Дробная часть `arg` с тем же знаком. Целая часть сохраняется в `*iptr`.

## Что делает

Разделяет число на целую и дробную части.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    double integral;
    double frac = std::modf(3.14, &integral);
    std::cout << integral << " + " << frac << std::endl; // 3 + 0.14
}
```

- **Исключения:** не бросает исключений.

## Похожие функции

- `std::trunc` — только целая часть
- `std::floor` — целая часть (округление вниз)
