## Прототип

```cpp
#include <cmath>

float copysign(float x, float y);
double copysign(double x, double y);
long double copysign(long double x, long double y);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Значение (модуль берётся отсюда) |
| `y` | Значение (знак берётся отсюда) |

## Возвращаемое значение

Число с модулем `|x|` и знаком `y`.

## Что делает

Возвращает число с модулем первого аргумента и знаком второго. Корректно работает для `±0.0` и `NaN`.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::copysign(1.0, -2.0) << std::endl; // -1
    std::cout << std::copysign(-1.0, 2.0) << std::endl;  // 1
}
```

## Исключения

- **Исключения:** не бросает исключений.
