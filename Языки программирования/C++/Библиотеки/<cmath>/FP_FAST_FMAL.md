## Прототип

```cpp
#include <cmath>

#define FP_FAST_FMAL /* если определено, fmal быстрее */
```

## Параметры

Нет.

## Возвращаемое значение

Макрос определён, если функция `fma` для `long double` выполняется быстрее.

## Что делает

Указывает на наличие аппаратной поддержки fused multiply-add для `long double`.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
#ifdef FP_FAST_FMAL
    std::cout << "fmal оптимизировано" << std::endl;
#endif
}
```

## Исключения

- **Исключения:** макрос определения, не функция.
