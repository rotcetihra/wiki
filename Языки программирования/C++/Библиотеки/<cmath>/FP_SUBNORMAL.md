## Прототип

```cpp
#include <cmath>

#define FP_SUBNORMAL /* значение.fpclassify == FP_SUBNORMAL */
```

## Параметры

Нет.

## Возвращаемое значение

Константа,代表ляющая поднормализованное число в `fpclassify`.

## Что делает

Указывает, что число является поднормализованным (denormalized / subnormal) — слишком малым для нормализованного представления.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    double x = 5e-324; // самое малое положительное double
    if (std::fpclassify(x) == FP_SUBNORMAL)
        std::cout << "x — поднормализованное" << std::endl;
}
```
