## Прототип

```cpp
#include <cmath>

float tgamma(float arg);
double tgamma(double arg);
long double tgamma(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение |

## Возвращаемое значение

Гамма-функция `Γ(arg)`.

## Что делает

Вычисляет гамма-функцию Эйлера.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::tgamma(1.0) << std::endl; // 1 (Γ(1) = 0! = 1)
    std::cout << std::tgamma(5.0) << std::endl; // 24 (Γ(5) = 4! = 24)
}
```

- **Исключения:** может установить `EDOM` или `ERANGE`.
