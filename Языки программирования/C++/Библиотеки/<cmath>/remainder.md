## Прототип

```cpp
#include <cmath>

float remainder(float x, float y);
double remainder(double x, double y);
long double remainder(long double x, long double y);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Делимое |
| `y` | Делитель |

## Возвращаемое значение

Остаток round-to-nearest: `x - n*y`, где `n` — ближайшее целое к `x/y`.

## Что делает

Вычисляет остаток от деления с округлением к ближайшему целому (в отличие от `fmod`, который округляет к нулю).

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::remainder(5.3, 2.0) << std::endl;  // -0.7
    std::cout << std::fmod(5.3, 2.0) << std::endl;       // 1.3
}
```

## Исключения

- **Исключения:** может установить `EDOM` при `y = 0`.
