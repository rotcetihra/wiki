## Прототип

```cpp
#include <cmath>

float expm1(float arg);
double expm1(double arg);
long double expm1(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Показатель степени |

## Возвращаемое значение

`e^arg - 1`. Более точно, чем `exp(arg) - 1` для малых `arg`.

## Что делает

Вычисляет `e^arg - 1` с сохранением точности для малых значений аргумента.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::expm1(0.0) << std::endl; // 0
    std::cout << std::expm1(1.0) << std::endl; // 1.71828
}
```

## Исключения

- **Исключения:** может установить `ERANGE` при переполнении.
