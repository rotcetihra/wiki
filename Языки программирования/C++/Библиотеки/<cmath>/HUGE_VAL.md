## Прототип

```cpp
#include <cmath>

#define HUGE_VAL /* положительная бесконечность */
```

## Параметры

Нет.

## Возвращаемое значение

Макрос, равный положительной бесконечности `double` (`+∞`).

## Что делает

Представляет значение положительной бесконечности для типа `double`. Используется как возвращаемое значение математических функций при переполнении.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    double x = HUGE_VAL;
    std::cout << std::isinf(x) << std::endl; // 1
}
```
