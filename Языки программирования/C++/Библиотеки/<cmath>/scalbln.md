## Прототип

```cpp
#include <cmath>

float scalbln(float arg, long n);
double scalbln(double arg, long n);
long double scalbln(long double arg, long n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение |
| `n` | Целый показатель степени типа `long` |

## Возвращаемое значение

`arg * FLT_RADIX^n`.

## Что делает

Масштабирует число, умножая его на целую степень основания системы счисления. Аналог `scalbn`, но с показателем типа `long`.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::scalbln(1.0, 10) << std::endl; // 1024
}
```

## Исключения

- **Исключения:** может установить `ERANGE` при переполнении.
