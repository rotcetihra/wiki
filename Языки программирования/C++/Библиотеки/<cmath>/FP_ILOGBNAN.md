## Прототип

```cpp
#include <cmath>

#define FP_ILOGBNAN /* значение ilogb для NaN */
```

## Параметры

Нет.

## Возвращаемое значение

Значение, возвращаемое `ilogb(NaN)`.

## Что делает

Представляет значение, которое возвращает `std::ilogb(NaN)`.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::ilogb(NAN) << std::endl; // FP_ILOGBNAN
}
```
