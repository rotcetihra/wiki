## Прототип

```cpp
#include <cmath>

float ceil(float arg);
double ceil(double arg);
long double ceil(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение с плавающей точкой |

## Возвращаемое значение

Наименьшее целое число (как float), не меньшее `arg`.

## Что делает

Округляет вверх до ближайшего целого числа.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::ceil(2.3) << std::endl;  // 3
    std::cout << std::ceil(-2.3) << std::endl; // -2
}
```
