## Прототип

```cpp
#include <cmath>

#define NAN /* не число */
```

## Параметры

Нет.

## Возвращаемое значение

Макрос,代表ляющий значение «не число» (NaN) типа `float`.

## Что делает

Представляет значение NaN — результат неопредёлённых операций с плавающей точкой (например, `0.0/0.0`).

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    float x = NAN;
    std::cout << std::isnan(x) << std::endl; // 1
}
```
