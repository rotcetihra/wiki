## Прототип

```cpp
#include <cmath>

int isinf(float x);
int isinf(double x);
int isinf(long double x);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Значение с плавающей точкой |

## Возвращаемое значение

Ненулевое значение, если `x` является бесконечностью (`+∞` или `-∞`).

## Что делает

Проверяет, является ли число бесконечностью.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::isinf(HUGE_VAL) << std::endl;  // 1
    std::cout << std::isinf(3.14) << std::endl;      // 0
}
```
