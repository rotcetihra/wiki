## Прототип

```cpp
#include <cmath>

float scalbn(float arg, int n);
double scalbn(double arg, int n);
long double scalbn(long double arg, int n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение |
| `n` | Целый показатель степени |

## Возвращаемое значение

`arg * FLT_RADIX^n`.

## Что делает

Масштабирует число, умножая его на целую степень основания системы счисления (обычно 2).

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::scalbn(1.0, 10) << std::endl; // 1024
}
```

## Исключения

- **Исключения:** может установить `ERANGE` при переполнении.
