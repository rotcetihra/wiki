## Прототип

```cpp
#include <cmath>

float exp(float arg);
double exp(double arg);
long double exp(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Показатель степени |

## Возвращаемое значение

Elevated в степень `arg`: `e^arg`.

## Что делает

Вычисляет показательную функцию (e в степени arg).

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::exp(0.0) << std::endl; // 1
    std::cout << std::exp(1.0) << std::endl; // 2.71828
}
```

- **Исключения:** может установить `ERANGE` при переполнении.
