## Прототип

```cpp
#include <cmath>

float log1p(float arg);
double log1p(double arg);
long double log1p(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение (должно быть > -1) |

## Возвращаемое значение

`ln(1 + arg)`. Более точно, чем `log(1 + arg)` для малых `arg`.

## Что делает

Вычисляет натуральный логарифм `(1 + arg)` с сохранением точности для малых значений.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::log1p(0.0) << std::endl; // 0
    std::cout << std::log1p(1.0) << std::endl; // 0.693147
}
```

## Исключения

- **Исключения:** может установить `EDOM` при `arg <= -1`.
