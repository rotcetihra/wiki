## Прототип

```cpp
#include <cmath>

float frexp(float arg, int* exp);
double frexp(double arg, int* exp);
long double frexp(long double arg, int* exp);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение для разложения |
| `exp` | Указатель на целое число для сохранения показателя |

## Возвращаемое значение

Мантисса `x` в диапазоне `[0.5, 1.0)`, такой что `arg = x * 2^exp`.

## Что делает

Разлагает число на мантиссу и показатель степени двойки.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    int exp;
    double mantissa = std::frexp(12.5, &exp);
    std::cout << mantissa << " * 2^" << exp << std::endl; // 0.78125 * 2^4
}
```
