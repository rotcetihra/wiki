## Прототип

```cpp
#include <cmath>

int signbit(float x);
int signbit(double x);
int signbit(long double x);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Значение с плавающей точкой |

## Возвращаемое значение

Ненулевое значение, если знак `x` отрицательный (включая `-0.0`).

## Что делает

Проверяет знак числа. Работает корректно для всех значений, включая `-0.0`, `NaN` и бесконечности.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::signbit(-3.14) << std::endl; // 1
    std::cout << std::signbit(3.14) << std::endl;  // 0
    std::cout << std::signbit(-0.0) << std::endl;  // 1
}
```
