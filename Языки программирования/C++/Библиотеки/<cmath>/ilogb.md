## Прототип

```cpp
#include <cmath>

int ilogb(float arg);
int ilogb(double arg);
int ilogb(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение |

## Возвращаемое значение

Целая часть `log_r(|arg|)`, где `r = FLT_RADIX`.

## Что делает

Извлекает целочисленный показатель мантиссы. Аналог `frexp`, но возвращает только показатель.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::ilogb(1024.0) << std::endl; // 10
    std::cout << std::ilogb(0.5) << std::endl;    // -1
}
```

## Исключения

- **Исключения:** может установить `EDOM` и вернуть `FP_ILOGB0` или `FP_ILOGBNAN`.
