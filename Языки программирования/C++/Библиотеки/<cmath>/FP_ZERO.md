## Прототип

```cpp
#include <cmath>

#define FP_ZERO /* значение.fpclassify == FP_ZERO */
```

## Параметры

Нет.

## Возвращаемое значение

Константа,代表ляющая ноль в `fpclassify`.

## Что делает

Указывает, что число является нулём (+0 или -0).

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    double x = 0.0;
    if (std::fpclassify(x) == FP_ZERO)
        std::cout << "x — ноль" << std::endl;
}
```

- **Исключения:** макрос определения, не функция.
