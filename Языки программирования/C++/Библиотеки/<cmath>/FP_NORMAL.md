## Прототип

```cpp
#include <cmath>

#define FP_NORMAL /* значение.fpclassify == FP_NORMAL */
```

## Параметры

Нет.

## Возвращаемое значение

Константа,代表ляющая нормализованное число в `fpclassify`.

## Что делает

Указывает, что число является нормализованным (не ноль, не бесконечность, не NaN, не поднормализованное).

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    double x = 3.14;
    if (std::fpclassify(x) == FP_NORMAL)
        std::cout << "x — нормальное число" << std::endl;
}
```
