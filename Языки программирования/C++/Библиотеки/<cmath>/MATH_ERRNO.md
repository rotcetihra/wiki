## Прототип

```cpp
#include <cmath>

#define MATH_ERRNO 1
```

## Параметры

Нет.

## Возвращаемое значение

Константа `1`.

## Что делает

Битовая маска для `math_errhandling`. Указывает, что математические функции должны устанавливать `errno` при ошибках.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    if (math_errhandling & MATH_ERRNO)
        std::cout << "errno включено для math" << std::endl;
}
```

- **Исключения:** макрос определения, не функция.
