## Прототип

```cpp
#include <cmath>

float remquo(float x, float y, int* quo);
double remquo(double x, double y, int* quo);
long double remquo(long double x, long double y, int* quo);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Делимое |
| `y` | Делитель |
| `quo` | Указатель на сохранение части частного |

## Возвращаемое значение

Остаток от деления: `remainder(x, y)`. Младшие биты частного сохраняются в `*quo`.

## Что делает

Вычисляет остаток и сохраняет младшие биты целочисленного частного. Полезно для тригонометрических вычислений.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    int quo;
    double r = std::remquo(5.0, 3.0, &quo);
    std::cout << r << ", quo & 7 = " << (quo & 7) << std::endl; // 2, quo & 7 = 1
}
```

## Исключения

- **Исключения:** может установить `EDOM` при `y = 0`.
