## Прототип

```cpp
#include <cmath>

float hypot(float x, float y);
double hypot(double x, double y);
long double hypot(long double x, long double y);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Длина первой стороны |
| `y` | Длина второй стороны |

## Возвращаемое значение

Гипотенуза: `√(x² + y²)`.

## Что делает

Вычисляет длину гипотенузы прямоугольного треугольника. Безопасно от переполнения.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::hypot(3, 4) << std::endl; // 5
}
```

## Исключения

- **Исключения:** может установить `ERANGE` при очень больших значениях.
