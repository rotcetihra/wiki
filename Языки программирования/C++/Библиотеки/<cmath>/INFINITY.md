## Прототип

```cpp
#include <cmath>

#define INFINITY /* бесконечность */
```

## Параметры

Нет.

## Возвращаемое значение

Макрос, равный положительной или отрицательной бесконечности (implementation-defined).

## Что делает

Представляет значение бесконечности. Эквивалент `HUGE_VAL` или `HUGE_VALF` в зависимости от реализации.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    float x = INFINITY;
    std::cout << std::isinf(x) << std::endl; // 1
}
```

## Исключения

- **Исключения:** макрос определения, не функция.
