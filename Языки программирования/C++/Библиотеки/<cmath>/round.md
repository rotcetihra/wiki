## Прототип

```cpp
#include <cmath>

float round(float arg);
double round(double arg);
long double round(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение с плавающей точкой |

## Возвращаемое значение

Ближайшее целое значение (как float). При `.5` округляется от нуля.

## Что делает

Округляет до ближайшего целого числа, половинные значения округляются от нуля.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::round(2.3) << std::endl;  // 2
    std::cout << std::round(2.5) << std::endl;  // 3
    std::cout << std::round(-2.5) << std::endl; // -3
}
```
