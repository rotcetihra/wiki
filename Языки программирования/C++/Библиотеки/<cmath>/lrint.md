## Прототип

```cpp
#include <cmath>

long lrint(float arg);
long lrint(double arg);
long lrint(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение с плавающей точкой |

## Возвращаемое значение

Ближайшее значение типа `long` по текущему режиму округления.

## Что делает

Округляет до ближайшего целого числа типа `long`. При переполнении поведение не определено (может генерировать `FE_INVALID`).

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::lrint(2.7) << std::endl; // 3
}
```

## Исключения

- **Исключения:** может генерировать `FE_INVALID` при переполнении.
