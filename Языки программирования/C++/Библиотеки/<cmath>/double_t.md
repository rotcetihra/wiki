## Прототип

```cpp
#include <cmath>

typedef /* double или long double */ double_t;
```

## Параметры

Нет.

## Возвращаемое значение

Тип `double_t` — тип с плавающей точкой, не менее точный, чем `double`.

## Что делает

Определяет тип `double_t`, который используется как тип возвращаемого значения для математических функций с аргументами `double`.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    double_t x = 3.14;
    std::cout << sizeof(x) << std::endl;
}
```

## Исключения

- **Исключения:** тип определения, не функция.
