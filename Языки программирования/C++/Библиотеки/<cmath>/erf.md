## Прототип

```cpp
#include <cmath>

float erf(float arg);
double erf(double arg);
long double erf(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение |

## Возвращаемое значение

Функция ошибок `erf(arg) = 2/√π * ∫₀^arg e^(-t²) dt`.

## Что делает

Вычисляет функцию ошибок Гаусса.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::erf(0.0) << std::endl; // 0
    std::cout << std::erf(1.0) << std::endl; // 0.842701
}
```
