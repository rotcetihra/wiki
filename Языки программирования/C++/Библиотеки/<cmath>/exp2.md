## Прототип

```cpp
#include <cmath>

float exp2(float arg);
double exp2(double arg);
long double exp2(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Показатель степени |

## Возвращаемое значение

2 в степени `arg`: `2^arg`.

## Что делает

Вычисляет 2 в степени arg.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::exp2(10) << std::endl; // 1024
    std::cout << std::exp2(0.5) << std::endl; // 1.41421
}
```

- **Исключения:** может установить `ERANGE` при переполнении.
