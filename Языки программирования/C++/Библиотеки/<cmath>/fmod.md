## Прототип

```cpp
#include <cmath>

float fmod(float x, float y);
double fmod(double x, double y);
long double fmod(long double x, long double y);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Делимое |
| `y` | Делитель |

## Возвращаемое значение

Остаток от деления `x` на `y`: `x - n*y`, где `n` — целое, результат имеет тот же знак что и `x`.

## Что делает

Вычисляет остаток от деления с плавающей точкой (аналог `%` для целых).

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::fmod(5.3, 2.0) << std::endl;  // 1.3
    std::cout << std::fmod(-5.3, 2.0) << std::endl; // -1.3
}
```

## Исключения

- **Исключения:** может установить `EDOM` при `y = 0`.
