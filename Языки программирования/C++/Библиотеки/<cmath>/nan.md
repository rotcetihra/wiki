## Прототип

```cpp
#include <cmath>

float nanf(const char* tagp);
double nan(const char* tagp);
long double nanl(const char* tagp);
```

## Параметры

| Параметр | Описание |
|---|---|
| `tagp` | Строка (игнорируется в большинстве реализаций) |

## Возвращаемое значение

Значение `Quiet NaN` типа `float`, `double` или `long double`.

## Что делает

Создаёт значение Quiet NaN. Строка `tagp` может использоваться реализацией для кодирования информации.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    double x = std::nan("");
    std::cout << std::isnan(x) << std::endl; // 1
}
```
