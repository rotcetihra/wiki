## Прототип

```cpp
#include <cmath>

long long llrint(float arg);
long long llrint(double arg);
long long llrint(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение с плавающей точкой |

## Возвращаемое значение

Ближайшее значение типа `long long`.

## Что делает

Округляет до ближайшего целого числа типа `long long`.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::llrint(2.7) << std::endl; // 3
}
```

## Исключения

- **Исключения:** может генерировать `FE_INVALID` при переполнении.
