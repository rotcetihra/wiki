## Прототип

```cpp
#include <cmath>

long lround(float arg);
long lround(double arg);
long lround(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение с плавающей точкой |

## Возвращаемое значение

Ближайшее значение типа `long`. При `.5` округляется от нуля.

## Что делает

Округляет до ближайшего целого числа типа `long`. При переполнении поведение не определено.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::lround(2.3) << std::endl;  // 2
    std::cout << std::lround(2.5) << std::endl;  // 3
}
```
