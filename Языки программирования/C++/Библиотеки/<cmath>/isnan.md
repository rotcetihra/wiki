## Прототип

```cpp
#include <cmath>

int isnan(float x);
int isnan(double x);
int isnan(long double x);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Значение с плавающей точкой |

## Возвращаемое значение

Ненулевое значение, если `x` является NaN.

## Что делает

Проверяет, является ли число NaN (Not a Number).

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::isnan(NAN) << std::endl; // 1
    std::cout << std::isnan(3.14) << std::endl; // 0
}
```
