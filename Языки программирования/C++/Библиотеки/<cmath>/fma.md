## Прототип

```cpp
#include <cmath>

float fma(float x, float y, float z);
double fma(double x, double y, double z);
long double fma(long double x, long double y, long double z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Множитель |
| `y` | Множитель |
| `z` | Слагаемое |

## Возвращаемое значение

`(x * y) + z`, вычисленное как одна операция с одним округлением.

## Что делает

Выполняет fused multiply-add: умножение и сложение с одним округлением. Точнее, чем последовательные операции.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::fma(2.0, 3.0, 4.0) << std::endl; // 10
}
```

## Исключения

- **Исключения:** может установить `FE_OVERFLOW` или `FE_UNDERFLOW`.

## Похожие функции

- `x * y + z` — с двумя округлениями
