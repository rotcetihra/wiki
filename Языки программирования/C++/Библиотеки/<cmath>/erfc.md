## Прототип

```cpp
#include <cmath>

float erfc(float arg);
double erfc(double arg);
long double erfc(long double arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `arg` | Значение |

## Возвращаемое значение

Дополнительная функция ошибок: `1 - erf(arg)`.

## Что делает

Вычисляет `1 - erf(arg)` более точно, чем прямое вычитание.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::erfc(0.0) << std::endl; // 1
    std::cout << std::erfc(1.0) << std::endl; // 0.157299
}
```
