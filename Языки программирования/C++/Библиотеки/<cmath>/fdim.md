## Прототип

```cpp
#include <cmath>

float fdim(float x, float y);
double fdim(double x, double y);
long double fdim(long double x, long double y);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Первое значение |
| `y` | Второе значение |

## Возвращаемое значение

Положительная разность `x - y` или `+0.0`, если `x <= y`.

## Что делает

Возвращает положительную разность: `max(x - y, 0)`.

## Примеры

```cpp
#include <cmath>
#include <iostream>

int main()
{
    std::cout << std::fdim(5.0, 3.0) << std::endl; // 2
    std::cout << std::fdim(3.0, 5.0) << std::endl; // 0
}
```
