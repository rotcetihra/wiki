## Прототип

```cpp
#include <syslog.h>\nvoid syslog(int priority, const char *format, ... /* args */);
```

## Параметры

| Параметр | Описание |
|---|---|
| `priority` | приоритет (LOG_EMERG, LOG_ERR, LOG_INFO и т.д.) |\n| `format` | формат строки (как printf) |
## Возвращаемое значение

Нет возвращаемого значения.

## Что делает

Записывает сообщение в системный журнал.

## Примеры

### Базовое использование

```cpp
syslog(LOG_INFO, "Запуск приложения PID=%d", getpid());
```
