## Прототип

```cpp
#include <syslog.h>\nvoid openlog(const char *ident, int option, int facility);
```

## Параметры

| Параметр | Описание |
|---|---|
| `ident` | строка идентификатора (обычно имя программы) |\n| `option` | опции (LOG_PID, LOG_CONS, LOG_ODELAY) |\n| `facility` | категория (LOG_USER, LOG_DAEMON, LOG_LOCAL0) |
## Возвращаемое значение

Нет возвращаемого значения.

## Что делает

Открывает соединение с системным журналом.

## Примеры

### Базовое использование

```cpp
openlog("myapp", LOG_PID, LOG_USER);
```
