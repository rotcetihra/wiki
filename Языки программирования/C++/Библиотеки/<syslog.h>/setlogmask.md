## Прототип

```cpp
#include <syslog.h>\nint setlogmask(int maskpri);
```

## Параметры

| Параметр | Описание |
|---|---|
| `maskpri` | маска приоритетов (LOG_UPTO, LOG_MASK) |
## Возвращаемое значение

Предыдущее значение маски.

## Что делает

Устанавливает маску, которая определяет, какие приоритеты сообщений записываются в журнал.

## Примеры

### Базовое использование

```cpp
setlogmask(LOG_UPTO(LOG_INFO));
```

## Исключения

- **Исключения:** Возвращает предыдущее значение.\n- **Безопасность в C++11:** Потокобезопасна.
