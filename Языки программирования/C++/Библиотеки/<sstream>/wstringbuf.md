## Прототип

```cpp
#include <sstream>
using wstringbuf = std::basic_stringbuf<wchar_t>;
```

## Описание

`std::wstringbuf` — это псевдоним типа для `std::basic_stringbuf<wchar_t>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
