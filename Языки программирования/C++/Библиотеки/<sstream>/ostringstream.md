## Прототип

```cpp
#include <sstream>
using ostringstream = std::basic_ostringstream<char>;
```

## Описание

`std::ostringstream` — это псевдоним типа для `std::basic_ostringstream<char>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
