## Прототип

```cpp
#include <sstream>
std::basic_string<CharT, Traits, Allocator> str() const;
void str(const std::basic_string<CharT, Traits, Allocator>& s);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Строка для установки (для перегрузки setter) |

## Возвращаемое значение

Строка из буфера (для getter) или `void` (для setter).

## Что делает

Возвращает копию строки из внутреннего буфера или устанавливает содержимое буфера.

## Примеры

### Базовое использование

```cpp
std::stringstream ss;
ss.str("Hello, World!");
std::string s = ss.str();
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
