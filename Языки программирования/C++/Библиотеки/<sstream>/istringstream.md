## Прототип

```cpp
#include <sstream>
using istringstream = std::basic_istringstream<char>;
```

## Описание

`std::istringstream` — это псевдоним типа для `std::basic_istringstream<char>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
