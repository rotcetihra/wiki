## Прототип

```cpp
#include <sstream>
using wstringstream = std::basic_stringstream<wchar_t>;
```

## Описание

`std::wstringstream` — это псевдоним типа для `std::basic_stringstream<wchar_t>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
