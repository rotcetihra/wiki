## Прототип

```cpp
#include <sstream>
using wostringstream = std::basic_ostringstream<wchar_t>;
```

## Описание

`std::wostringstream` — это псевдоним типа для `std::basic_ostringstream<wchar_t>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
