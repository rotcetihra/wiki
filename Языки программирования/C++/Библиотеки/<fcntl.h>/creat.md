## Прототип

```cpp
#include <fcntl.h>\nint creat(const char *pathname, mode_t mode);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pathname` | путь к файлу |\n| `mode` | права доступа |
## Возвращаемое значение

Файловый дескриптор или -1 при ошибке.

## Что делает

Эквивалент `open(pathname, O_WRONLY | O_CREAT | O_TRUNC, mode)`.

## Примеры

### Базовое использование

```cpp
int fd = creat("file.txt", 0644);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
