## Прототип

```cpp
#include <fcntl.h>\nint open(const char *pathname, int flags, ... /* mode_t mode */);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pathname` | путь к файлу |\n| `flags` | флаги (O_RDONLY, O_WRONLY, O_RDWR, O_CREAT) |\n| `mode` | права (при O_CREAT) |
## Возвращаемое значение

Файловый дескриптор или -1 при ошибке.

## Что делает

Открывает файл и возвращает дескриптор.

## Примеры

### Базовое использование

```cpp
int fd = open("file.txt", O_RDONLY);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
