## Прототип

```cpp
#include <fcntl.h>\nint fcntl(int fd, int cmd, ... /* arg */);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор |\n| `cmd` | команда |\n| `arg` | аргумент |
## Возвращаемое значение

Зависит от команды.

## Что делает

Выполняет различные операции над дескриптором.

## Примеры

### Базовое использование

```cpp
int flags = fcntl(fd, F_GETFL);\nfcntl(fd, F_SETFL, flags | O_NONBLOCK);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
