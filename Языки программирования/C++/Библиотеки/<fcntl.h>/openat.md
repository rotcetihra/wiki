## Прототип

```cpp
#include <fcntl.h>\nint openat(int dirfd, const char *pathname, int flags, ... /* mode_t mode */);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dirfd` | дескриптор каталога |\n| `pathname` | путь к файлу |\n| `flags` | флаги |\n| `mode` | права |
## Возвращаемое значение

Файловый дескриптор или -1 при ошибке.

## Что делает

Аналог `open()`, но путь разрешается относительно каталога.

## Примеры

### Базовое использование

```cpp
int fd = openat(AT_FDCWD, "file.txt", O_RDONLY);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
