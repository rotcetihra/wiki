## Прототип

```cpp
#include <mutex>

template <class Mutex>
class lock_guard;

template <>
class lock_guard<mutex>;  // для std::mutex
```

## Параметры

| Параметр | Описание |
|---|---|
| `Mutex` | Тип мьютекса (например, `std::mutex`, `std::recursive_mutex`) |

## Возвращаемое значение

Не применимо (это класс).

## Что делает

`std::lock_guard` — это простая RAII-обёртка, которая блокирует мьютекс в конструкторе и разблокирует в деструкторе. Обеспечивает автоматическую разблокировку при выходе из области видимости, даже при исключениях.

Конструктор принимает мьютекс и (опционально) тег `std::adopt_lock_t`, который указывает, что мьютекс уже заблокирован. При использовании `adopt_lock` деструктор вызовет `unlock()`.

## Примеры

### Базовое использование

```cpp
#include <mutex>
#include <thread>
#include <iostream>

std::mutex mtx;
int shared_data = 0;

void safe_increment() {
    std::lock_guard<std::mutex> lock(mtx);
    ++shared_data;
    // автоматическая разблокировка при выходе
}

int main() {
    std::thread t1(safe_increment);
    std::thread t2(safe_increment);
    t1.join();
    t2.join();
    std::cout << shared_data << "\n";
}
```

## Исключения

- **Исключения:** Конструктор может бросить исключение, если мьютекс не заблокирован (без `adopt_lock`).
- **Безопасность в C++11:** Гарантирует разблокировку в деструкторе. Копирование запрещено.
