## Прототип

```cpp
#include <mutex>

inline constexpr try_to_lock_t try_to_lock{};
```

## Возвращаемое значение

Не применимо (это константа).

## Что делает

`std::try_to_lock` — это константное значение типа `std::try_to_lock_t`, используемое как тег для конструкторов `std::unique_lock` и `std::shared_lock`. Указывает, что конструктор должен попытаться заблокировать мьютекс без ожидания (вызов `try_lock()`).

## Примеры

### Базовое использование

```cpp
#include <mutex>
#include <iostream>

std::mutex mtx;

int main() {
    std::unique_lock<std::mutex> lock(mtx, std::try_to_lock);
    if (lock.owns_lock()) {
        std::cout << "Locked\n";
    } else {
        std::cout << "Not locked\n";
    }
}
```

## Исключения

- **Исключения:** Константа не бросает исключений.
- **Безопасность в C++11:** Используется как тег для конструкторов.
