## Возвращаемое значение

Не применимо (это константа).

## Что делает

`std::adopt_lock` — это константное значение типа `std::adopt_lock_t`, используемое как тег для конструкторов `std::unique_lock` и `std::shared_lock`. Указывает, что мьютекс уже заблокирован и обёртка должна просто принять владение им.

## Примеры

### Базовое использование

```cpp
#include <mutex>
#include <iostream>

std::mutex mtx;

int main() {
    mtx.lock();
    std::unique_lock<std::mutex> lock(mtx, std::adopt_lock);
    std::cout << "Adopted locked mutex\n";
    // mtx будет разблокирован в деструкторе lock
}
```

## Исключения

- **Исключения:** Константа не бросает исключений.
- **Безопасность в C++11:** Используется как тег для конструкторов.
