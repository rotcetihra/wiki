## Прототип

```cpp
#include <mutex>

inline constexpr defer_lock_t defer_lock{};
```

## Возвращаемое значение

Не применимо (это константа).

## Что делает

`std::defer_lock` — это константное значение типа `std::defer_lock_t`, используемое как тег для конструкторов `std::unique_lock` и `std::shared_lock`. Указывает, что мьютекс не должен блокироваться при создании обёртки.

## Примеры

### Базовое использование

```cpp
#include <mutex>
#include <iostream>

std::mutex mtx;

int main() {
    std::unique_lock<std::mutex> lock(mtx, std::defer_lock);
    std::cout << "Owns lock: " << lock.owns_lock() << "\n"; // 0
    lock.lock();
    std::cout << "Owns lock: " << lock.owns_lock() << "\n"; // 1
}
```

## Исключения

- **Исключения:** Константа не бросает исключений.
- **Безопасность в C++11:** Используется как тег для конструкторов.
