## Прототип

```cpp
#include <mutex>

template <class... Mutexes>
class scoped_lock;
```

## Параметры

| Параметр | Описание |
|---|---|
| `Mutexes` | Типы мьютексов (может быть несколько) |

## Возвращаемое значение

Не применимо (это класс).

## Что делает

`std::scoped_lock` — это RAII-обёртка, которая блокирует один или несколько мьютексов в конструкторе и разблокирует их в деструкторе. Использует алгоритм deadlock avoidance для безопасной блокировки нескольких мьютексов одновременно.

При блокировке нескольких мьютексов `scoped_lock` гарантирует отсутствие deadlock, используя алгоритм deadlock avoidance (analogously `std::lock`).

## Примеры

### Базовое использование

```cpp
#include <mutex>
#include <thread>
#include <iostream>

std::mutex mtx1, mtx2;

void safe_transfer(int& from, int& to) {
    std::scoped_lock lock(mtx1, mtx2);
    int temp = from;
    from = to;
    to = temp;
}

int main() {
    int a = 10, b = 20;
    std::thread t(safe_transfer, std::ref(a), std::ref(b));
    t.join();
    std::cout << "a=" << a << " b=" << b << "\n";
}
```

## Исключения

- **Исключения:** Конструктор может бросить исключение при ошибке блокировки.
- **Безопасность в C++11:** Гарантирует разблокировку всех мьютексов в деструкторе. Копирование запрещено.
