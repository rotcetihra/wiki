## Что делает

`std::mutex` — это базовый класс мьютекса (взаимного исключения), обеспечивающий эксклюзивный доступ к ресурсу. Один мьютекс может быть заблокирован только одним потоком одновременно. Другие потоки, пытающиеся заблокировать тот же мьютекс, блокируются до его разблокировки.

Основные операции: `lock()` — блокировка (с ожиданием), `try_lock()` — попытка блокировки без ожидания, `unlock()` — разблокировка. Копирование и перемещение запрещены.

## Примеры

### Базовое использование

```cpp
#include <mutex>
#include <thread>
#include <iostream>

std::mutex mtx;
int counter = 0;

void increment() {
    for (int i = 0; i < 1000; ++i) {
        std::lock_guard<std::mutex> lock(mtx);
        ++counter;
    }
}

int main() {
    std::thread t1(increment);
    std::thread t2(increment);
    t1.join();
    t2.join();
    std::cout << "Counter: " << counter << "\n";
}
```

## Исключения

- **Исключения:** `lock()` бросает `std::system_error` при ошибке блокировки.
- **Безопасность в C++11:** Копирование запрещено. Перемещение запрещено. Не является рекурсивным.
