## Прототип

```cpp
#include <mutex>

struct adopt_lock_t { explicit adopt_lock_t() = default; };
```

## Параметры

|---|---|
| — | Структура не имеет параметров |

## Возвращаемое значение

Не применимо (это тип).

## Что делает

`std::adopt_lock_t` — это тип тега, используемый для указания, что мьютекс уже заблокирован и `std::unique_lock` или `std::shared_lock` должен просто принять владение им. При уничтожении обёртки мьютекс будет разблокирован.

Полезен, когда мьютекс заблокирован вручную (например, через `mtx.lock()`) и необходимо передать управление RAII-обёртке.

## Примеры

### Базовое использование

```cpp
#include <mutex>
#include <iostream>

std::mutex mtx;

int main() {
    mtx.lock();
    std::unique_lock<std::mutex> lock(mtx, std::adopt_lock);
    // mtx будет разблокирован при выходе из scope
    std::cout << "Adopted\n";
}
```

## Исключения

- **Исключения:** Тип не бросает исключений.
- **Безопасность в C++11:** Используется как тег для конструкторов.
