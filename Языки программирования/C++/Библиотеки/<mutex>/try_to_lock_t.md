## Прототип

```cpp
#include <mutex>

struct try_to_lock_t { explicit try_to_lock_t() = default; };
```

## Параметры

| Параметр | Описание |
|---|---|
| — | Структура не имеет параметров |

## Возвращаемое значение

Не применимо (это тип).

## Что делает

`std::try_to_lock_t` — это тип тега, используемый для указания, что `std::unique_lock` или `std::shared_lock` должен попытаться заблокировать мьютекс без ожидания (вызов `try_lock()` в конструкторе). Если блокировка не удалась, обёртка создаётся в незаблокированном состоянии.

## Примеры

### Базовое использование

```cpp
#include <mutex>
#include <iostream>

std::mutex mtx;

int main() {
    std::unique_lock<std::mutex> lock(mtx, std::try_to_lock);
    if (lock.owns_lock()) {
        std::cout << "Successfully locked\n";
    } else {
        std::cout << "Failed to lock\n";
    }
}
```

## Исключения

- **Исключения:** Тип не бросает исключений.
- **Безопасность в C++11:** Используется как тег для конструкторов.
