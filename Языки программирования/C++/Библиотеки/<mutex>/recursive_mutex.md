## Что делает

`std::recursive_mutex` — это мьютекс, который может быть заблокирован одним потоком несколько раз. Каждая блокировка увеличивает внутренний счётчик, а каждая разблокировка уменьшает его. Мьютекс разблокируется только когда счётчик достигает нуля.

Полезен, когда один и тот же поток должен repeatedly блокировать мьютекс (например, в рекурсивных функциях или при вызове методов, которые сами блокируют мьютекс).

## Примеры

### Базовое использование

```cpp
#include <mutex>
#include <thread>
#include <iostream>

std::recursive_mutex rmtx;

void recursive_func(int n) {
    std::lock_guard<std::recursive_mutex> lock(rmtx);
    if (n <= 0) return;
    std::cout << "Depth: " << n << "\n";
    recursive_func(n - 1);
}

int main() {
    std::thread t(recursive_func, 3);
    t.join();
}
```

## Исключения

- **Исключения:** `lock()` бросает `std::system_error` при ошибке блокировки.
- **Безопасность в C++11:** Копирование и перемещение запрещены. Рекурсивная блокировка безопасна.
