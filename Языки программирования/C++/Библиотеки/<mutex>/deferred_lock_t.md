## Прототип

```cpp
#include <mutex>

struct defer_lock_t { explicit defer_lock_t() = default; };
```

|---|---|
| — | Структура не имеет параметров |

## Возвращаемое значение

Не применимо (это тип).

## Что делает

`std::defer_lock_t` — это тип тега, используемый для указания, что мьютекс не должен блокироваться при создании `std::unique_lock` или `std::shared_lock`. Блокировка откладывается до явного вызова `lock()` или `try_lock()`.

Это позволяет создать обёртку без мгновенной блокировки, что полезно для условных блокировок.

## Примеры

### Базовое использование

```cpp
#include <mutex>
#include <iostream>

std::mutex mtx;

int main() {
    std::unique_lock<std::mutex> lock(mtx, std::defer_lock);
    std::cout << "Locked: " << lock.owns_lock() << "\n"; // 0
    lock.lock();
    std::cout << "Locked: " << lock.owns_lock() << "\n"; // 1
}
```

## Исключения

- **Исключения:** Тип не бросает исключений.
- **Безопасность в C++11:** Используется как тег для конструкторов.
