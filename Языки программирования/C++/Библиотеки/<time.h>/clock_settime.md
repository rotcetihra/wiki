## Прототип

```cpp
#include <time.h>\nint clock_settime(clockid_t clk_id, const struct timespec *tp);
```

## Параметры

| Параметр | Описание |
|---|---|
| `clk_id` | часы |\n| `tp` | новое время |
## Возвращаемое значение

0 или -1.

## Что делает

Устанавливает время часов.

## Примеры

### Базовое использование

```cpp
clock_settime(CLOCK_REALTIME, &tp);
```
