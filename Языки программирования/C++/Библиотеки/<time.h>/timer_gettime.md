## Прототип

```cpp
#include <time.h>\nint timer_gettime(timer_t timerid, struct itimerval *curr_value);
```

## Параметры

| Параметр | Описание |
|---|---|
| `timerid` | ID |\n| `curr_value` | текущее значение |
## Возвращаемое значение

0 или -1.

## Что делает

Получает оставшееся время.

## Примеры

### Базовое использование

```cpp
timer_gettime(tid, &its);
```
