## Прототип

```cpp
#include <streambuf>
std::streamsize sgetn(char_type* s, std::streamsize n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Указатель на буфер |
| `n` | Количество символов |

## Возвращаемое значение

Количество обработанных символов.

## Что делает

Читает блок данных из буфера.

## Примеры

### Базовое использование

```cpp
char buffer[100];
std::streambuf* buf = std::cin.rdbuf();
std::streamsize n = buf->sgetn(buffer, 100);
```
