## Прототип

```cpp
#include <streambuf>
virtual std::basic_streambuf* setbuf(char_type* s, std::streamsize n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Указатель на буфер |
| `n` | Размер буфера |

## Возвращаемое значение

`this` или `nullptr` при ошибке.

## Что делает

Виртуальная функция для установки буфера. Переопределяется производными классами.

## Примеры

### Базовое использование

```cpp
// Переопределяется в производных классах
virtual std::filebuf* setbuf(char* buffer, std::streamsize n) override;
```
