## Прототип

```cpp
#include <streambuf>
int pubsync();
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Синхронизирует буфер (публичный интерфейс).

## Примеры

### Базовое использование

```cpp
std::filebuf buf;
int result = buf.pubsync();
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
