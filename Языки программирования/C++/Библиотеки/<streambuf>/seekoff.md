## Прототип

```cpp
#include <streambuf>
virtual pos_type seekoff(off_type off, std::ios_base::seekdir way, std::ios_base::openmode which = std::ios_base::in | std::ios_base::out);
```

## Параметры

| Параметр | Описание |
|---|---|
| `off` | Смещение |
| `way` | Направление поиска |
| `which` | Маска потока |

## Возвращаемое значение

Результирующая позиция или `pos_type(-1)` при ошибке.

## Что делает

Виртуальная функция для перемещения позиции. Переопределяется производными классами.

## Примеры

### Базовое использование

```cpp
// Переопределяется в производных классах
virtual pos_type seekoff(off_type off, std::ios_base::seekdir way) override;
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
