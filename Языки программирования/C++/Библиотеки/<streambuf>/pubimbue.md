## Прототип

```cpp
#include <streambuf>
std::locale pubimbue(const std::locale& loc);
```

## Параметры

| Параметр | Описание |
|---|---|
| `loc` | Локаль для установки |

## Возвращаемое значение

Предыдущая локаль.

## Что делает

Устанавливает локаль для буфера (публичный интерфейс).

## Примеры

### Базовое использование

```cpp
std::filebuf buf;
buf.pubimbue(std::locale("en_US.UTF-8"));
```

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
