## Прототип

```cpp
#include <streambuf>
std::streamsize in_avail();
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

Количество доступных символов или -1.

## Что делает

Возвращает количество символов, доступных для чтения без блокировки.

## Примеры

### Базовое использование

```cpp
std::streambuf* buf = std::cin.rdbuf();
std::streamsize avail = buf->in_avail();
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
