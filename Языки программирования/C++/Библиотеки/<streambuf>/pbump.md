## Прототип

```cpp
#include <streambuf>
void pbump(int count);
```

## Параметры

| Параметр | Описание |
|---|---|
| `count` | Смещение указателя записи |

## Возвращаемое значение

Количество обработанных символов.

## Что делает

Смещает указатель записи на заданное количество позиций.

## Примеры

### Базовое использование

```cpp
std::stringbuf buf;
buf.pbump(5);  // Сдвинуть указатель записи на 5
```
