## Прототип

```cpp
#include <streambuf>
int_type sputbackc(char_type c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Символ для возврата |

## Возвращаемое значение

Символ или `traits::eof()` при ошибке.

## Что делает

Возвращает символ в буфер ввода.

## Примеры

### Базовое использование

```cpp
std::streambuf* buf = std::cin.rdbuf();
int c = buf->sbumpc();
buf->sputbackc(c);
```
