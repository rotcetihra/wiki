## Прототип

```cpp
#include <streambuf>
virtual pos_type seekpos(pos_type sp, std::ios_base::openmode which = std::ios_base::in | std::ios_base::out);
```

## Параметры

| Параметр | Описание |
|---|---|
| `sp` | Абсолютная позиция |
| `which` | Маска потока |

## Возвращаемое значение

Результирующая позиция или `pos_type(-1)` при ошибке.

## Что делает

Виртуальная функция для установки абсолютной позиции.

## Примеры

### Базовое использование

```cpp
// Переопределяется в производных классах
virtual pos_type seekpos(pos_type sp) override;
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
