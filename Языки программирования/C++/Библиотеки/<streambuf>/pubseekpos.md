## Прототип

```cpp
#include <streambuf>
pos_type pubseekpos(pos_type sp, std::ios_base::openmode which = std::ios_base::in | std::ios_base::out);
```

## Параметры

| Параметр | Описание |
|---|---|
| `sp` | Абсолютная позиция |
| `which` | Маска потока |

## Возвращаемое значение

Результирующая позиция или `pos_type(-1)` при ошибке.

## Что делает

Устанавливает абсолютную позицию (публичный интерфейс).

## Примеры

### Базовое использование

```cpp
std::filebuf buf;
buf.pubseekpos(std::streampos(0));
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
