## Прототип

```cpp
#include <streambuf>
using streambuf = std::basic_streambuf<char>;
```

## Описание

`std::streambuf` — это псевдоним типа для `std::basic_streambuf<char>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
