## Прототип

```cpp
#include <streambuf>
using wstreambuf = std::basic_streambuf<wchar_t>;
```

## Описание

`std::wstreambuf` — это псевдоним типа для `std::basic_streambuf<wchar_t>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
