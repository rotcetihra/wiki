## Прототип

```cpp
#include <streambuf>
std::basic_streambuf* pubsetbuf(char_type* s, std::streamsize n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Указатель на буфер |
| `n` | Размер буфера |

## Возвращаемое значение

`this` или `nullptr` при ошибке.

## Что делает

Устанавливает внешний буфер для буфера потока (публичный интерфейс).

## Примеры

### Базовое использование

```cpp
char buffer[1024];
std::filebuf buf;
buf.pubsetbuf(buffer, 1024);
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
