## Прототип

```cpp
#include <streambuf>
std::streamsize sputn(const char_type* s, std::streamsize n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Указатель на данные |
| `n` | Количество символов |

## Возвращаемое значение

Количество обработанных символов.

## Что делает

Записывает блок данных в буфер.

## Примеры

### Базовое использование

```cpp
const char* data = "Hello";
std::streambuf* buf = std::cout.rdbuf();
std::streamsize n = buf->sputn(data, 5);
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
