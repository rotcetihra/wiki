## Прототип

```cpp
#include <streambuf>
int_type sungetc();
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

Символ или `traits::eof()` при ошибке.

## Что делает

Смещает позицию чтения назад на одну позицию.

## Примеры

### Базовое использование

```cpp
std::streambuf* buf = std::cin.rdbuf();
int c = buf->sbumpc();
buf->sungetc();
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
