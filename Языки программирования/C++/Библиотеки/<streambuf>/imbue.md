## Прототип

```cpp
#include <streambuf>
virtual void imbue(const std::locale& loc);
```

## Параметры

| Параметр | Описание |
|---|---|
| `loc` | Локаль для установки |

## Возвращаемое значение

Предыдущая локаль.

## Что делает

Виртуальная функция для установки локали. Переопределяется производными классами.
