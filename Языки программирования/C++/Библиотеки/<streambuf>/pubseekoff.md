## Прототип

```cpp
#include <streambuf>
pos_type pubseekoff(off_type off, std::ios_base::seekdir way, std::ios_base::openmode which = std::ios_base::in | std::ios_base::out);
```

## Параметры

| Параметр | Описание |
|---|---|
| `off` | Смещение |
| `way` | Направление поиска |
| `which` | Маска потока |

## Возвращаемое значение

Результирующая позиция или `pos_type(-1)` при ошибке.

## Что делает

Перемещает позицию чтения/записи на смещение (публичный интерфейс).

## Примеры

### Базовое использование

```cpp
std::filebuf buf;
buf.pubseekoff(-10, std::ios::cur);
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
