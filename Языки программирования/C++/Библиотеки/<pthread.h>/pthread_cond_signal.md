## Прототип

```cpp
#include <pthread.h>
int pthread_cond_signal(pthread_cond_t *cond);
```

## Параметры

| Параметр | Описание |
|---|---|
| `cond` | указатель на переменную условия |
## Возвращаемое значение

0 при успехе, код ошибки при неудаче.

## Что делает

Разблокирует один из потоков, ожидающих на переменной условия `cond`. Если ни один поток не ожидает, сигнал теряется.

## Примеры

### Базовое использование

```cpp
pthread_cond_signal(&cond);
```

- **Исключения:** Возвращает код ошибки.
- **Безопасность в C++11:** Потокобезопасна.
