## Прототип

```cpp
#include <pthread.h>
int pthread_detach(pthread_t thread);
```

## Параметры

| Параметр | Описание |
|---|---|
| `thread` | идентификатор потока |
## Возвращаемое значение

0 при успехе, код ошибки при неудаче.

## Что делает

Помечает поток как отсоединённый. Ресурсы потока автоматически освобождаются при завершении. Нельзя вызывать `pthread_join()` для отсоединённого потока.

## Примеры

### Базовое использование

```cpp
pthread_t tid;
pthread_create(&tid, NULL, func, NULL);
pthread_detach(tid);
```

## Исexceptions

- **Исключения:** Возвращает код ошибки (ESRCH, EINVAL).
- **Безопасность в C++11:** Потокобезопасна.
