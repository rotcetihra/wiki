## Прототип

```cpp
#include <pthread.h>
int pthread_cond_destroy(pthread_cond_t *cond);
```

## Параметры

| Параметр | Описание |
|---|---|
| `cond` | указатель на переменную условия |
## Возвращаемое значение

0 при успехе, код ошибки при неудаче.

## Что делает

Уничтожает переменную условия, освобождая связанные ресурсы.

## Примеры

### Базовое использование

```cpp
pthread_cond_destroy(&cond);
```

## Исexceptions

- **Исключения:** Возвращает код ошибки (EBUSY, EINVAL).
- **Безопасность в C++11:** Потокобезопасна для разных переменных.
