## Прототип

```cpp
#include <pthread.h>
int pthread_cond_wait(pthread_cond_t *cond,
                      pthread_mutex_t *mutex);
```

## Параметры

| Параметр | Описание |
|---|---|
| `cond` | указатель на переменную условия |
| `mutex` | указатель на заблокированный мьютекс |
## Возвращаемое значение

0 при успехе, код ошибки при неудаче.

## Что делает

Атомарно разблокирует мьютекс и блокирует вызывающий поток до тех пор, пока условие не будет разблокировано через `pthread_cond_signal()` или `pthread_cond_broadcast()`. Мьютекс автоматически блокируется при возврате.

## Примеры

### Базовое использование

```cpp
pthread_mutex_lock(&mutex);
while (!condition)
    pthread_cond_wait(&cond, &mutex);
// обработка условия
pthread_mutex_unlock(&mutex);
```

## Исexceptions

- **Исключения:** Возвращает код ошибки.
- **Безопасность в C++11:** Потокобезопасна для разных переменных.
