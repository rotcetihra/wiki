## Прототип

```cpp
#include <pthread.h>
int pthread_mutex_destroy(pthread_mutex_t *mutex);
```

## Параметры

| Параметр | Описание |
|---|---|
| `mutex` | указатель на мьютекс |
## Возвращаемое значение

0 при успехе, код ошибки при неудаче.

## Что делает

Уничтожает мьютекс, освобождая связанные ресурсы. Мьютекс должен быть разблокирован.

## Примеры

### Базовое использование

```cpp
pthread_mutex_destroy(&mutex);
```

## Исexceptions

- **Исключения:** Возвращает код ошибки (EBUSY, EINVAL).
- **Безопасность в C++11:** Потокобезопасна для разных мьютексов.
