## Прототип

```cpp
#include <pthread.h>
int pthread_cond_init(pthread_cond_t *cond,
                      const pthread_condattr_t *attr);
```

## Параметры

| Параметр | Описание |
|---|---|
| `cond` | указатель на переменную условия |
| `attr` | атрибуты (NULL — по умолчанию) |
## Возвращаемое значение

0 при успехе, код ошибки при неудаче.

## Что делает

Инициализирует переменную условия для синхронизации потоков.

## Примеры

### Базовое использование

```cpp
pthread_cond_t cond;
pthread_cond_init(&cond, NULL);
```

## Исexceptions

- **Исключения:** Возвращает код ошибки.
- **Безопасность в C++11:** Потокобезопасна для разных переменных.
