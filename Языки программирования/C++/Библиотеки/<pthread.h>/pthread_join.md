## Прототип

```cpp
#include <pthread.h>
int pthread_join(pthread_t thread, void **retval);
```

## Параметры

| Параметр | Описание |
|---|---|
| `thread` | идентификатор потока |
| `retval` | указатель на возвращаемое значение (или NULL) |
## Возвращаемое значение

0 при успехе, код ошибки при неудаче.

## Что делает

Блокирует вызывающий поток до тех пор, пока указанный поток не завершится. Возвращает возвращаемое значение потока через `retval`.

## Примеры

### Базовое использование

```cpp
pthread_t tid;
pthread_create(&tid, NULL, func, NULL);
// ... другие работы ...
pthread_join(tid, NULL);
```

## Исexceptions

- **Исключения:** Возвращает код ошибки (ESRCH, EINVAL, EDEADLK).
- **Безопасность в C++11:** Потокобезопасна.
