## Прототип

```cpp
#include <pthread.h>
int pthread_key_delete(pthread_key_t key);
```

## Параметры

| Параметр | Описание |
|---|---|
| `key` | ключ для удаления |
## Возвращаемое значение

0 при успехе, код ошибки при неудаче.

## Что делает

Удаляет ключ. Значения, связанные с ключом в потоках, не удаляются (деструкторы не вызываются).

## Примеры

### Базовое использование

```cpp
pthread_key_delete(key);
```

## Исexceptions

- **Исключения:** Возвращает код ошибки (EINVAL).
- **Безопасность в C++11:** Потокобезопасна.
