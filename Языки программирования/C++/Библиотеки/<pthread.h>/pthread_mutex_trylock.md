## Прототип

```cpp
#include <pthread.h>
int pthread_mutex_trylock(pthread_mutex_t *mutex);
```

## Параметры

| Параметр | Описание |
|---|---|
| `mutex` | указатель на мьютекс |
## Возвращаемое значение

0 при успехе, EBUSY если мьютекс заблокирован, другой код ошибки.

## Что делает

Пытается заблокировать мьютекс без блокировки. Если мьютекс уже заблокирован, возвращает EBUSY немедленно.

## Примеры

### Базовое использование

```cpp
if (pthread_mutex_trylock(&mutex) == 0) {
    // мьютекс заблокирован
    pthread_mutex_unlock(&mutex);
} else {
    // мьютекс занят
}
```

## Исexceptions

- **Исключения:** Возвращает EBUSY если мьютекс заблокирован.
- **Безопасность в C++11:** Потокобезопасна для разных мьютексов.
