## Прототип

```cpp
#include <pthread.h>
pthread_t pthread_self(void);
```

## Параметры

| Параметр | Описание |
|---|---|
Нет параметров.
## Возвращаемое значение

Идентификатор текущего потока (`pthread_t`).

## Что делает

Возвращает идентификатор вызывающего потока.

## Примеры

### Базовое использование

```cpp
pthread_t self = pthread_self();
printf("ID потока: %lu", (unsigned long)self);
```
