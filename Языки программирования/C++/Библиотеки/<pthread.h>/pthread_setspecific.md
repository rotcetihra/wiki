## Прототип

```cpp
#include <pthread.h>
int pthread_setspecific(pthread_key_t key, const void *value);
```

## Параметры

| Параметр | Описание |
|---|---|
| `key` | ключ |
| `value` | значение для установки |
## Возвращаемое значение

0 при успехе, код ошибки при неудаче.

## Что делает

Устанавливает значение для ключа в текущем потоке. Каждый поток имеет своё значение для каждого ключа.

## Примеры

### Базовое использование

```cpp
pthread_setspecific(key, strdup("hello"));
```

## Исexceptions

- **Исключения:** Возвращает код ошибки (EINVAL, ENOMEM).
- **Безопасность в C++11:** Потокобезопасна для разных ключей.
