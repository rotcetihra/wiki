## Прототип

```cpp
#include <pthread.h>
void pthread_exit(void *retval);
```

## Параметры

| Параметр | Описание |
|---|---|
| `retval` | возвращаемое значение потока |
## Возвращаемое значение

Нет возвращаемого значения (void).

## Что делает

Завершает текущий поток с указанным возвращаемым значением. Эквивалент `return retval` в функции потока.

## Примеры

### Базовое использование

```cpp
void *func(void *arg) {
    // ...
    pthread_exit(NULL);
}
```

## Исexceptions

- **Исключения:** Не определено поведение при невалидном указателе.
- **Безопасность в C++11:** Потокобезопасна.
