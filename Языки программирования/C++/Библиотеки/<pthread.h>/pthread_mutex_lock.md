## Прототип

```cpp
#include <pthread.h>
int pthread_mutex_lock(pthread_mutex_t *mutex);
```

## Параметры

| Параметр | Описание |
|---|---|
| `mutex` | указатель на мьютекс |
## Возвращаемое значение

0 при успехе, код ошибки при неудаче.

## Что делает

Блокирует мьютекс. Если мьютекс уже заблокирован другим потоком, вызывающий поток блокируется до разблокировки.

## Примеры

### Базовое использование

```cpp
pthread_mutex_lock(&mutex);
// критическая секция
pthread_mutex_unlock(&mutex);
```

## Исexceptions

- **Исключения:** Возвращает код ошибки (EINVAL, EDEADLK).
- **Безопасность в C++11:** Потокобезопасна для разных мьютексов.
