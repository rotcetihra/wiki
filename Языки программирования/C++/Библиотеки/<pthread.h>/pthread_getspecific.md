## Прототип

```cpp
#include <pthread.h>
void *pthread_getspecific(pthread_key_t key);
```

## Параметры

| Параметр | Описание |
|---|---|
| `key` | ключ |
## Возвращаемое значение

Указатель на значение или NULL, если значение не установлено.

## Что делает

Возвращает значение, установленное через `pthread_setspecific()` для текущего потока и указанного ключа.

## Примеры

### Базовое использование

```cpp
char *data = pthread_getspecific(key);
if (data != NULL)
    printf("%s", data);
```

## Исexceptions

- **Исключения:** Возвращает NULL если значение не установлено.
- **Безопасность в C++11:** Потокобезопасна для разных ключей.
