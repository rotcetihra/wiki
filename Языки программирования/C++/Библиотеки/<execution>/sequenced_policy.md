## Прототип

```cpp
#include <execution>

class sequenced_policy;
```

## Параметры

Нет.

## Возвращаемое значение

Политика, гарантирующая последовательное выполнение (без параллелизма).

## Что делает

Указывает, что алгоритм должен выполняться в одном потоке, без параллельных вычислений.

## Примеры

```cpp
#include <execution>
#include <vector>
#include <algorithm>

int main()
{
    std::vector<int> v = {5, 3, 1, 4, 2};
    std::sort(std::execution::seq, v.begin(), v.end());
}
```
