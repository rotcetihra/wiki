## Прототип

```cpp
#include <execution>

template<class F>
void execute(F&& f) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `f` | Функция (задача) для выполнения |

## Возвращаемое значение

Нет.

## Что делает

Запускает задачу `f` с использованием поставщика задач по умолчанию. Гарантирует, что `f` будет вызвана однажды.

## Примеры

```cpp
#include <execution>
#include <iostream>

int main()
{
    std::execution::execute([](){
        std::cout << "задача выполнена" << std::endl;
    });
}
```
