## Прототип

```cpp
#include <deque>

template<class T, class Allocator = std::allocator<T>>
class deque;
```

`std::deque` — двусторонняя очередь. Поддерживает случайный доступ, эффективную вставку/удаление в начало и конец. Итераторы не инвалидируются при вставке/удалении в начало/конец.

## Параметры шаблона

| Параметр | Описание |
|---|---|
| `T` | Тип элементов |
| `Allocator` | Аллокатор памяти (по умолчанию `std::allocator<T>`) |

## Примеры

### Базовое использование

```cpp
```cpp
#include <deque>
#include <iostream>

int main()
{
    std::deque<int> d = {1, 2, 3};
    d.push_front(0);
    d.push_back(4);
    for (int x : d) std::cout << x << ' '; // 0 1 2 3 4
}
```
```
- **Исключения:** конструкторы могут выбрасывать исключения.
- **Безопасность в C++11:** безопасный доступ через `at()`.
