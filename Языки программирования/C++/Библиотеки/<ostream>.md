## Описание библиотеки

Заголовочный файл `<ostream>` определяет класс `std::basic_ostream` — базовый класс для всех выходных потоков. Он предоставляет операторы вставки `<<` для вывода данных, а также функции `put`, `write`, `flush` и другие.

## Исключения

- **Исключения:** Функции вывода могут устанавливать `failbit` или `badbit`. Исключения бросаются при включённом исключении.
- **Безопасность в C++11:** Одновременный вывод через `<<` из нескольких потоков безопасен (каждый вызов `<<` — атомарная операция), но порядок вывода между потоками не определён.

## Стандарты

C++11, C++17, C++20, C++23.
