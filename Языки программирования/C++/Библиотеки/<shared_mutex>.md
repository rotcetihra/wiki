## Описание библиотеки

Заголовочный файл `<shared_mutex>` определяет мьютексы с поддержкой разделяемого (shared) и эксклюзивного (exclusive) доступа. Разделяемый мьютекс позволяет нескольким потокам одновременно拥有 доступ для чтения (shared lock), но эксклюзивный доступ (exclusive lock) для записи. Это оптимально для сценариев «много читателей — один писатель».

## Исключения

- **Исключения:** Мьютексы могут бросать `std::system_error` при ошибках синхронизации.
- **Безопасность в C++11:** Копирование и перемещение мьютексов запрещены. RAII-обёртки `std::shared_lock` и `std::shared_timed_lock` гарантируют разблокирование при выходе из области видимости.

## Стандарты

C++17 (`shared_mutex`), C++14 (`shared_timed_mutex`), C++20.
