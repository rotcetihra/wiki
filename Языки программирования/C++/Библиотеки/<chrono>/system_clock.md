## Прототип

```cpp
#include <chrono>

struct system_clock;
```

## Описание

Системные часы реального времени. Могут быть изменены пользователем (NTP, ручная установка). Подходят для измерения календарного времени.

## Методы

| Метод | Описание |
|---|---|
| `now()` | Текущее время |
| `to_time_t(time_point)` | Преобразование в `time_t` |
| `from_time_t(time_t)` | Преобразование из `time_t` |

## Примеры

```cpp
#include <chrono>
#include <iostream>
#include <ctime>

int main()
{
    auto now = std::chrono::system_clock::now();
    std::time_t t = std::chrono::system_clock::to_time_t(now);
    std::cout << std::ctime(&t);
}
```

## Исключения

- **Исключения:** `to_time_t` может бросать исключения при переполнении.
