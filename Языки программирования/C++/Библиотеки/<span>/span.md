## Прототип

```cpp
#include <span>

 template<class T, std::size_t Extent = std::dynamic_extent>
class span;
```

`std::span` — non-owning view на непрерывную последовательность элементов. Состоит из указателя и размера. Не владеет данными; не конструирует и не уничтожает элементы. Все операции `constexpr` (кроме `at`).

## Что делает

## Параметры шаблона

| Параметр | Описание |
|---|---|
| `T` | Тип элементов |
| `Extent` | Размер диапазона (константа времени компиляции или `dynamic_extent`) |

## Примеры

### Базовое использование

```cpp
```cpp
#include <span>
#include <iostream>

int main()
{
    int arr[] = {1, 2, 3, 4, 5};
    std::span<int> sp(arr);
    std::cout << sp.size() << "\n";  // 5
    std::cout << sp[2] << "\n";     // 3
    for (int x : sp) std::cout << x << ' '; // 1 2 3 4 5
}
```
```
- **Исключения:** `at()` выбрасывает `std::out_of_range`.
- **Безопасность в C++11:** безопасный доступ; размер известен.
