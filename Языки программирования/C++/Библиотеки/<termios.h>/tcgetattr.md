## Прототип

```cpp
#include <termios.h>\nint tcgetattr(int fd, struct termios *termios_p);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор терминала |\n| `termios_p` | указатель на структуру для результата |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Получает параметры терминала, связанные с файловым дескриптором.

## Примеры

### Базовое использование

```cpp
struct termios t;\ntcgetattr(STDIN_FILENO, &t);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
