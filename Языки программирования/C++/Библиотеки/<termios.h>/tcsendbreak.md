## Прототип

```cpp
#include <termios.h>\nint tcsendbreak(int fd, int duration);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор терминала |\n| `duration` | длительность break (0 — по умолчанию) |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Отправляет последовательность break-сигнала на терминал.

## Примеры

### Базовое использование

```cpp
tcsendbreak(fd, 0);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
