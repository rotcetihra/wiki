## Прототип

```cpp
#include <termios.h>\nint tcdrain(int fd);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор терминала |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Блокируется до тех пор, пока все записанные данные не будут переданы.

## Примеры

### Базовое использование

```cpp
tcdrain(fd);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
