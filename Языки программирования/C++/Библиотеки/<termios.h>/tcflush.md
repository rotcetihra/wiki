## Прототип

```cpp
#include <termios.h>\nint tcflush(int fd, int queue_selector);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор терминала |\n| `queue_selector` | TCIFLUSH, TCOFLUSH, TCIOFLUSH |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Очищает непрочитанные входные и/или невыходные выходные данные.

## Примеры

### Базовое использование

```cpp
tcflush(fd, TCIFLUSH);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
