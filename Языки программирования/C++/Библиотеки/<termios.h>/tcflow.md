## Прототип

```cpp
#include <termios.h>\nint tcflow(int fd, int action);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор терминала |\n| `action` | TCOOFF, TCOON, TCIOFF, TCION |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Управляет потоком ввода/вывода.

## Примеры

### Базовое использование

```cpp
tcflow(fd, TCOOFF);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
