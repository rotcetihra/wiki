## Прототип

```cpp
#include <termios.h>\nint tcsetattr(int fd, int optional_actions, const struct termios *termios_p);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор терминала |\n| `optional_actions` | TCSANOW, TCSADRAIN, TCSAFLUSH |\n| `termios_p` | указатель на новую структуру |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Устанавливает параметры терминала.

## Примеры

### Базовое использование

```cpp
t.c_lflag &= ~ECHO;\ntcsetattr(STDIN_FILENO, TCSANOW, &t);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
