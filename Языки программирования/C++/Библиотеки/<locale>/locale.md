## Прототип

```cpp
#include <locale>

class locale;
```

## Параметры

Нет.

## Возвращаемое значение

Класс `std::locale` — набор фасетов для международализации.

## Что делает

Представляет набор фасетов (классов) для форматирования, сортировки и преобразования данных в соответствии с правилами определённой локали.

## Примеры

```cpp
#include <locale>
#include <iostream>

int main()
{
    std::locale loc = std::locale::classic();
    std::cout << loc.name() << std::endl; // "C" или "en_US.UTF-8"
}
```

## Исключения

- **Исключения:** может бросать `std::runtime_error`.

## Похожие функции

- `std::locale::global()` — установка глобальной локали
