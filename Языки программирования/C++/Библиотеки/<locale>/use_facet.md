## Прототип

```cpp
#include <locale>

template<class Facet>
const Facet& use_facet(const locale& loc);
```

## Параметры

| Параметр | Описание |
|---|---|
| `loc` | Объект локали |

## Возвращаемое значение

Константная ссылка на фасет типа `Facet` из локали `loc`.

## Что делает

Извлекает фасет определённого типа из локали. Если фасет не найден, бросает `std::bad_cast`.

## Примеры

```cpp
#include <locale>
#include <iostream>

int main()
{
    auto& ct = std::use_facet<std::ctype<char>>(std::locale());
    std::cout << std::boolalpha << std::isalpha('a', ct) << std::endl; // true
}
```

## Исключения

- **Исключения:** бросает `std::bad_cast` если фасет отсутствует.
