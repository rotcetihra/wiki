## Прототип

```cpp
#include <locale>

template<class Facet>
bool has_facet(const locale& loc) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `loc` | Объект локали |

## Возвращаемое значение

`true`, если локаль `loc` содержит фасет типа `Facet`.

## Что делает

Проверяет наличие фасета определённого типа в локали.

## Примеры

```cpp
#include <locale>
#include <iostream>

int main()
{
    bool has = std::has_facet<std::ctype<char>>(std::locale());
    std::cout << std::boolalpha << has << std::endl; // true
}
```
