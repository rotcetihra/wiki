## Прототип

```cpp
#include <ios>
using ios = std::basic_ios<char>;
```

## Описание

`std::ios` — это псевдоним типа для `std::basic_ios<char>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
