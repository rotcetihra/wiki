## Прототип

```cpp
#include <ios>
using wios = std::basic_ios<wchar_t>;
```

## Описание

`std::wios` — это псевдоним типа для `std::basic_ios<wchar_t>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
