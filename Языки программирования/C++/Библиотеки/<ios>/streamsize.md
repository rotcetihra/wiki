## Прототип

```cpp
#include <ios>
using streamsize = std::ptrdiff_t;
```

## Описание

`std::streamsize` — это тип для представления размера потока (обычно `std::ptrdiff_t`).

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
