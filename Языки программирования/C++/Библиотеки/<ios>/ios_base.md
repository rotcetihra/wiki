## Прототип

```cpp
#include <ios>
class ios_base;
```

## Описание

Класс `std::ios_base` является базовым классом для всех потоков, не зависящим от типа символа. Он содержит флаги форматирования, состояние потока, и связанные типы.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
