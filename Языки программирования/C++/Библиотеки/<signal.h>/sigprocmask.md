## Прототип

```cpp
#include <signal.h>\nint sigprocmask(int how, const sigset_t *set, sigset_t *oldset);
```

## Параметры

| Параметр | Описание |
|---|---|
| `how` | действие (SIG_BLOCK, SIG_UNBLOCK, SIG_SETMASK) |\n| `set` | новый набор сигналов |\n| `oldset` | предыдущая маска (или NULL) |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Изменяет маску сигналов процесса. Позволяет блокировать или разблокировать сигналы.

## Примеры

### Базовое использование

```cpp
sigset_t mask;\nsigemptyset(&mask);\nsigaddset(&mask, SIGINT);\nsigprocmask(SIG_BLOCK, &mask, NULL);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
