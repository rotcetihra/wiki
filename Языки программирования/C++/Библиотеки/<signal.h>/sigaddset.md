## Прототип

```cpp
#include <signal.h>\nint sigaddset(sigset_t *set, int signum);
```

## Параметры

| Параметр | Описание |
|---|---|
| `set` | указатель на набор сигналов |\n| `signum` | номер сигнала для добавления |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Добавляет указанный сигнал в набор.

## Примеры

### Базовое использование

```cpp
sigset_t mask;\nsigemptyset(&mask);\nsigaddset(&mask, SIGINT);\nsigaddset(&mask, SIGTERM);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
