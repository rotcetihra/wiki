## Прототип

```cpp
#include <signal.h>\nint sigaction(int signum, const struct sigaction *act, struct sigaction *oldact);
```

## Параметры

| Параметр | Описание |
|---|---|
| `signum` | номер сигнала |\n| `act` | новое действие |\n| `oldact` | предыдущее действие (или NULL) |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Позволяет детально настроить обработку сигнала: установить обработчик, маску сигналов и флаги.

## Примеры

### Базовое использование

```cpp
struct sigaction sa;\nsa.sa_handler = my_handler;\nsigemptyset(&sa.sa_mask);\nsa.sa_flags = 0;\nsigaction(SIGINT, &sa, NULL);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
