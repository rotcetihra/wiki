## Прототип

```cpp
#include <signal.h>\nint sigismember(const sigset_t *set, int signum);
```

## Параметры

| Параметр | Описание |
|---|---|
| `set` | указатель на набор сигналов |\n| `signum` | номер сигнала |
## Возвращаемое значение

1 если сигнал в наборе, 0 если нет, -1 при ошибке.

## Что делает

Проверяет, входит ли указанный сигнал в набор.

## Примеры

### Базовое использование

```cpp
if (sigismember(&mask, SIGINT))\n    printf("SIGINT в наборе");
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
