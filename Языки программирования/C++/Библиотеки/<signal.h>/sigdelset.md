## Прототип

```cpp
#include <signal.h>\nint sigdelset(sigset_t *set, int signum);
```

## Параметры

| Параметр | Описание |
|---|---|
| `set` | указатель на набор сигналов |\n| `signum` | номер сигнала для удаления |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Удаляет указанный сигнал из набора.

## Примеры

### Базовое использование

```cpp
sigdelset(&mask, SIGINT);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
