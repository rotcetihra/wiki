## Прототип

```cpp
#include <signal.h>\nint sigemptyset(sigset_t *set);
```

## Параметры

| Параметр | Описание |
|---|---|
| `set` | указатель на набор сигналов |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Очищает набор сигналов (убирает все сигналы из набора).

## Примеры

### Базовое использование

```cpp
sigset_t mask;\nsigemptyset(&mask);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
