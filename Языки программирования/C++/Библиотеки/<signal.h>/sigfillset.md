## Прототип

```cpp
#include <signal.h>\nint sigfillset(sigset_t *set);
```

## Параметры

| Параметр | Описание |
|---|---|
| `set` | указатель на набор сигналов |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Заполняет набор сигналов всеми доступными сигналами.

## Примеры

### Базовое использование

```cpp
sigset_t mask;\nsigfillset(&mask);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
