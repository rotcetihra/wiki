## Прототип

```cpp
#include <libgen.h>\nchar *basename(char *path);
```

## Параметры

| Параметр | Описание |
|---|---|
| `path` | путь |
## Возвращаемое значение

Имя файла.

## Что делает

Извлекает имя из пути.

## Примеры

### Базовое использование

```cpp
char *n = basename("/a/b/c.txt");
```
