## Прототип

```cpp
#include <regex.h>\nint regexec(const regex_t *preg, const char *string, size_t nmatch, regmatch_t pmatch[], int eflags);
```

## Параметры

| Параметр | Описание |
|---|---|
| `preg` | скомпилированное выражение |\n| `string` | проверяемая строка |\n| `nmatch` | количество совпадений |\n| `pmatch` | массив совпадений |\n| `eflags` | флаги |
## Возвращаемое значение

0 при совпадении, REG_NOMATCH при несовпадении.

## Что делает

Проверяет строку на соответствие регулярному выражению.

## Примеры

### Базовое использование

```cpp
if (regexec(&reg, "12345", 0, NULL, 0) == 0)\n    printf("Совпадение");
```

## Исключения

- **Исключения:** Возвращает REG_NOMATCH при несовпадении.\n- **Безопасность в C++11:** Потокобезопасна.
