## Прототип

```cpp
#include <regex.h>\nint regcomp(regex_t *preg, const char *pattern, int cflags);
```

## Параметры

| Параметр | Описание |
|---|---|
| `preg` | указатель на regex_t |\n| `pattern` | строка шаблона |\n| `cflags` | флаги (REG_EXTENDED, REG_ICASE, REG_NOSUB) |
## Возвращаемое значение

0 при успехе, ненулевое значение при ошибке.

## Что делает

Компилирует регулярное выражение для последующего использования.

## Примеры

### Базовое использование

```cpp
regex_t reg;\nregcomp(&reg, "^[0-9]+$", REG_EXTENDED);
```

## Исключения

- **Исключения:** Возвращает ненулевое значение при ошибке.\n- **Безопасность в C++11:** Потокобезопасна для разных объектов.
