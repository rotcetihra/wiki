## Прототип

```cpp
#include <regex.h>\nsize_t regerror(int errcode, const regex_t *preg, char *errbuf, size_t errbuf_size);
```

## Параметры

| Параметр | Описание |
|---|---|
| `errcode` | код ошибки regcomp/regexec |\n| `preg` | регулярное выражение (или NULL) |\n| `errbuf` | буфер для сообщения |\n| `errbuf_size` | размер буфера |
## Возвращаемое значение

Требуемый размер буфера.

## Что делает

Возвращает строку с описанием ошибки регулярного выражения.

## Примеры

### Базовое использование

```cpp
char buf[256];\nregerror(err, &reg, buf, sizeof(buf));
```

## Исключения

- **Исключения:** Возвращает размер необходимого буфера.\n- **Безопасность в C++11:** Потокобезопасна.
