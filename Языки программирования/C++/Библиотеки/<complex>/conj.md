## Прототип

```cpp
#include <complex>

template<class T>
complex<T> conj(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Сопряжённое комплексное число `conj(z) = complex(real(z), -imag(z))`.

## Что делает

Возвращает комплексное число с тем же действительным и противоположным по знаку мнимым компонентом.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(3.0, 4.0);
    auto c = std::conj(z);
    std::cout << "conj(z) = " << c << std::endl; // (3,-4)
}
```
