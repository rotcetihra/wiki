## Прототип

```cpp
#include <complex>

template<class T>
T real(const complex<T>& z);

template<class T>
constexpr T real(const complex<T>& z) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Действительная часть комплексного числа `z`.

## Что делает

Возвращает действительную (вещественную) часть комплексного числа `z`. С裕合 с членом `std::complex<T>::real()`.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(3.0, 4.0);
    std::cout << "real(z) = " << std::real(z) << std::endl; // 3
}
```
