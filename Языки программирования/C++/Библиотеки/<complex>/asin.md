## Прототип

```cpp
#include <complex>

template<class T>
complex<T> asin(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Арксинус комплексного числа: `-i * log(i*z + sqrt(1 - z*z))`.

## Что делает

Вычисляет арксинус комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(0.5, 0.0);
    std::cout << std::asin(z) << std::endl; // (0.523599,0)
}
```
