## Прототип

```cpp
#include <complex>

template<class T>
complex<T> sinh(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Гиперболический синус комплексного числа `z`: `sinh(x)*cos(y) + i*cosh(x)*sin(y)`.

## Что делает

Вычисляет гиперболический синус комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(1.0, 0.0);
    std::cout << std::sinh(z) << std::endl; // (1.1752,0)
}
```
