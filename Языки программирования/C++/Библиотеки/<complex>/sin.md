## Прототип

```cpp
#include <complex>

template<class T>
complex<T> sin(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Синус комплексного числа `z`: `sin(x)*cosh(y) + i*cos(x)*sinh(y)`.

## Что делает

Вычисляет синус комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(1.0, 0.0);
    std::cout << std::sin(z) << std::endl; // (0.841471,0)
}
```
