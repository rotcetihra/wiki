## Прототип

```cpp
#include <complex>

template<class T>
complex<T> tan(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Тангенс комплексного числа `z`: `sin(z) / cos(z)`.

## Что делает

Вычисляет тангенс комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(1.0, 0.0);
    std::cout << std::tan(z) << std::endl; // (1.55741,0)
}
```
