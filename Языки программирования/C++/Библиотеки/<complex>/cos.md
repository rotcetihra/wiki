## Прототип

```cpp
#include <complex>

template<class T>
complex<T> cos(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Косинус комплексного числа `z`: `cos(x)*cosh(y) - i*sin(x)*sinh(y)`.

## Что делает

Вычисляет косинус комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(0.0, 1.0);
    std::cout << std::cos(z) << std::endl; // (1.54321,0)
}
```
