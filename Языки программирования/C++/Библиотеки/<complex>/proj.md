## Прототип

```cpp
#include <complex>

template<class T>
complex<T> proj(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Результат проецирования `z` на сферу Римана. Для конечных значений результат совпадает с `z`. Для бесконечных значений возвращает `complex(INFINITY, copysign(0.0, imag(z)))` или `complex(copysign(INFINITY, real(z)), copysign(0.0, real(z)))`.

## Что делает

Выполняет стереографическую проекцию комплексного числа на сферу Римана (однородную компактификацию комплексной плоскости).

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(3.0, 4.0);
    auto p = std::proj(z);
    std::cout << "proj(z) = " << p << std::endl; // (3,4)
}
```
