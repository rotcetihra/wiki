## Прототип

```cpp
#include <complex>

template<class T>
complex<T> acos(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Арккосинус комплексного числа: `π/2 - asin(z)`.

## Что делает

Вычисляет арккосинус комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(0.5, 0.0);
    std::cout << std::acos(z) << std::endl; // (1.0472,0)
}
```
