## Прототип

```cpp
#include <complex>

template<class T>
complex<T> acosh(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Обратный гиперболический косинус: `log(z + sqrt(z*z - 1))`.

## Что делает

Вычисляет обратный гиперболический косинус комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(2.0, 0.0);
    std::cout << std::acosh(z) << std::endl; // (1.31696,0)
}
```
