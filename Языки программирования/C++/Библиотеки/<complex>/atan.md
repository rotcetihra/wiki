## Прототип

```cpp
#include <complex>

template<class T>
complex<T> atan(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Арктангенс комплексного числа: `i/2 * log((i + z) / (i - z))`.

## Что делает

Вычисляет арктангенс комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(1.0, 0.0);
    std::cout << std::atan(z) << std::endl; // (0.785398,0)
}
```
