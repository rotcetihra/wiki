## Прототип

```cpp
#include <complex>

template<class T>
T imag(const complex<T>& z);

template<class T>
constexpr T imag(const complex<T>& z) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Мнимая часть комплексного числа `z`.

## Что делает

Возвращает мнимую часть комплексного числа `z`.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(3.0, 4.0);
    std::cout << "imag(z) = " << std::imag(z) << std::endl; // 4
}
```
