## Прототип

```cpp
#include <complex>

template<class T>
complex<T> sqrt(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Комплексный квадратный корень: `sqrt(|z|) * exp(i * arg(z) / 2)`.

## Что делает

Вычисляет главный квадратный корень комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(-1.0, 0.0);
    std::cout << std::sqrt(z) << std::endl; // (0,1)
}
```
