## Прототип

```cpp
#include <complex>

template<class T>
T hypot(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Гипотенуза (модуль) комплексного числа: `abs(z)`.

## Что делает

Вычисляет модуль комплексного числа — расстояние от начала координат до точки `z`. Эквивалентен `abs(z)`.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(3.0, 4.0);
    std::cout << std::hypot(z) << std::endl; // 5
}
```
