## Прототип

```cpp
#include <complex>

template<class T>
T abs(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Модуль (абсолютное значение) комплексного числа `z`, равный `sqrt(real(z)*real(z) + imag(z)*imag(z))`.

## Что делает

Вычисляет модуль комплексного числа — расстояние от начала координат до точки `z` на комплексной плоскости.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(3.0, 4.0);
    std::cout << "|z| = " << std::abs(z) << std::endl; // 5
}
```
