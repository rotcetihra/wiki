## Прототип

```cpp
#include <complex>

template<class T>
complex<T> asinh(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Обратный гиперболический синус: `log(z + sqrt(z*z + 1))`.

## Что делает

Вычисляет обратный гиперболический синус комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(1.0, 0.0);
    std::cout << std::asinh(z) << std::endl; // (0.881374,0)
}
```
