## Прототип

```cpp
#include <complex>

template<class T>
complex<T> log(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Натуральный логарифм: `log(|z|) + i*arg(z)`.

## Что делает

Вычисляет натуральный логарифм комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(1.0, 0.0);
    std::cout << std::log(z) << std::endl; // (0,0)
}
```
