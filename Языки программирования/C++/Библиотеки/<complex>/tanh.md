## Прототип

```cpp
#include <complex>

template<class T>
complex<T> tanh(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Гиперболический тангенс комплексного числа `z`: `sinh(z) / cosh(z)`.

## Что делает

Вычисляет гиперболический тангенс комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(1.0, 0.0);
    std::cout << std::tanh(z) << std::endl; // (0.761594,0)
}
```
