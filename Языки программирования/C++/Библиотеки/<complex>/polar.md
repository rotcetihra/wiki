## Прототип

```cpp
#include <complex>

template<class T>
complex<T> polar(const T& rho, const T& theta = T());
```

## Параметры

| Параметр | Описание |
|---|---|
| `rho` | Модуль (неотрицательное значение) |
| `theta` | Аргумент в радианах (по умолчанию 0) |

## Возвращаемое значение

Комплексное число `complex(rho * cos(theta), rho * sin(theta))`.

## Что делает

Создаёт комплексное число по полярным координатам (модуль и аргумент).

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    auto z = std::polar(5.0, 0.927295218);
    std::cout << "z = " << z << std::endl; // (3,4)
}
```
