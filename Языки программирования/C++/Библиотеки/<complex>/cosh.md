## Прототип

```cpp
#include <complex>

template<class T>
complex<T> cosh(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Гиперболический косинус комплексного числа `z`: `cosh(x)*cos(y) + i*sinh(x)*sin(y)`.

## Что делает

Вычисляет гиперболический косинус комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(1.0, 0.0);
    std::cout << std::cosh(z) << std::endl; // (1.54308,0)
}
```
