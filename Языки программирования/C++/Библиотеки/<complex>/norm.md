## Прототип

```cpp
#include <complex>

template<class T>
T norm(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Квадрат модуля комплексного числа `z`, равный `real(z)*real(z) + imag(z)*imag(z)`.

## Что делает

Вычисляет квадрат модуля комплексного числа (квадрат расстояния от начала координат до точки `z`). Это более быстрая альтернатива `abs(z) * abs(z)`, так как избегает вычисления квадратного корня.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(3.0, 4.0);
    std::cout << "norm(z) = " << std::norm(z) << std::endl; // 25
}
```
