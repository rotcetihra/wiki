## Прототип

```cpp
#include <complex>

template<class T>
complex<T> atanh(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Обратный гиперболический тангенс: `log((1 + z) / (1 - z)) / 2`.

## Что делает

Вычисляет обратный гиперболический тангенс комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(0.5, 0.0);
    std::cout << std::atanh(z) << std::endl; // (0.549306,0)
}
```
