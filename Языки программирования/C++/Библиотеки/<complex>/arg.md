## Прототип

```cpp
#include <complex>

template<class T>
T arg(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Аргумент (угол) комплексного числа `z` в радианах, в диапазоне `(-π, π]`.

## Что делает

Вычисляет аргумент комплексного числа — угол между положительной вещественной осью и вектором `z` на комплексной плоскости.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(0.0, 1.0);
    std::cout << "arg(z) = " << std::arg(z) << std::endl; // 1.5708 (π/2)
}
```
