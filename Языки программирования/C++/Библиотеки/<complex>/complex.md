## Прототип

```cpp
#include <complex>

template<class T>
class complex;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | Тип вещественного числа (`float`, `double`, `long double`) |

## Возвращаемое значение

Класс `std::complex<T>` хранит две переменные-члена типа `T`: действительную (`real`) и мнимую (`imag`) части.

## Что делает

Представляет комплексное число вида `real + imag * i`. Класс предоставляет конструкторы, арифметические операторы, математические функции и операции сравнения.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z1(3.0, 4.0);
    std::complex<double> z2(1.0, -2.0);

    auto sum = z1 + z2;
    auto prod = z1 * z2;

    std::cout << "z1 = " << z1 << std::endl;     // (3,4)
    std::cout << "z2 = " << z2 << std::endl;     // (1,-2)
    std::cout << "sum = " << sum << std::endl;    // (4,2)
    std::cout << "prod = " << prod << std::endl;  // (11,-2)
}
```
