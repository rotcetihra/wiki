## Прототип

```cpp
#include <complex>

template<class T>
complex<T> log10(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Десятичный логарифм: `log(z) / log(10)`.

## Что делает

Вычисляет десятичный логарифм комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(100.0, 0.0);
    std::cout << std::log10(z) << std::endl; // (2,0)
}
```
