## Прототип

```cpp
#include <complex>

template<class T>
complex<T> exp(const complex<T>& z);
```

## Параметры

| Параметр | Описание |
|---|---|
| `z` | Комплексное число |

## Возвращаемое значение

Показательная функция `e^z = e^x * (cos(y) + i*sin(y))`.

## Что делает

Вычисляет показательную функцию комплексного числа.

## Примеры

```cpp
#include <complex>
#include <iostream>

int main()
{
    std::complex<double> z(0.0, 3.14159265358979323846);
    std::cout << std::exp(z) << std::endl; // (-1,0) ≈ -1
}
```
