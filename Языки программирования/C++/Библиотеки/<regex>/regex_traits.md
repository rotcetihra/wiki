## Прототип

```cpp
#include <regex>
template<class CharT>
struct regex_traits;
```

## Параметры

| Параметр | Описание |
|---|---|
| `CharT` | тип символа |

## Возвращаемое значение

Объект с методами для работы с символами.

## Что делает

Предоставляет мета-информацию о типе символов для библиотеки regex.

## Примеры

### Базовое использование

```cpp
std::regex_traits<char> traits;
// Используется по умолчанию в basic_regex
```
