## Прототип

```cpp
#include <semaphore.h>\nint sem_init(sem_t *sem, int pshared, unsigned int value);
```

## Параметры

| Параметр | Описание |
|---|---|
| `sem` | семафор |\n| `pshared` | 0=потоки, !0=процессы |\n| `value` | начальное значение |
## Возвращаемое значение

0 или -1.

## Что делает

Инициализирует семафор.

## Примеры

### Базовое использование

```cpp
sem_t sem;\nsem_init(&sem, 0, 1);
```
