## Прототип

```cpp
#include <thread>

void detach();
```

## Параметры

| Параметр | Описание |
|---|---|
| — | Параметров нет |

## Возвращаемое значение

Не возвращает значения (`void`).

## Что делает

Отсоединяет поток от объекта `std::thread`. Поток продолжает выполняться в фоновом режиме, и его ресурсы освобождаются при завершении. После вызова `detach()` объект становится неприсоединяемым (`joinable()` возвращает `false`).

Отсоединённый поток не может быть присоединён позже. Если отсоединённый поток ещё выполняется при завершении программы, его выполнение прерывается (undefined behavior).

## Примеры

### Базовое использование

```cpp
#include <thread>
#include <iostream>
#include <chrono>

void background() {
    std::this_thread::sleep_for(std::chrono::seconds(1));
    std::cout << "Background done\n";
}

int main() {
    std::thread t(background);
    t.detach();
    std::cout << "Main continues\n";
    std::this_thread::sleep_for(std::chrono::seconds(2));
}
```

## Исключения

- **Исключения:** Бросает `std::system_error`, если поток не присоединяем.
- **Безопасность в C++11:** Должен вызываться один раз на присоединяемый поток.
