## Прототип

```cpp
#include <thread>

void swap(thread& other) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `other` | Другой объект `std::thread` для обмена |

## Возвращаемое значение

Не возвращает значения (`void`).

## Что делает

Обменивает содержимое двух объектов `std::thread`. Потоки,управляемые объектами, не затрагиваются — обмениваются только сами объекты. Эквивалентно `std::move(other)`.

Полезен для перестановки потоков и реализации паттернов перемещения.

## Примеры

### Базовое использование

```cpp
#include <thread>
#include <iostream>

void func1() { std::cout << "Func1\n"; }
void func2() { std::cout << "Func2\n"; }

int main() {
    std::thread t1(func1);
    std::thread t2(func2);
    t1.swap(t2);
    t1.join();
    t2.join();
}
```

## Исключения

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасна.
