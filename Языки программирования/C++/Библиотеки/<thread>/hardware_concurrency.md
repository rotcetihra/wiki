## Прототип

```cpp
#include <thread>

unsigned hardware_concurrency() noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| — | Параметров нет |

## Возвращаемое значение

Количество аппаратных потоков, поддерживаемых процессором. Возвращает 0, если значение не определено.

## Что делает

Возвращает рекомендуемое количество потоков для параллельного выполнения. Обычно соответствует числу аппаратных ядер или потоков (например, 8 для 8-ядерного процессора). Может возвращать 0, если информация недоступна.

Полезно для определения оптимального числа потоков в пуле.

## Примеры

### Базовое использование

```cpp
#include <thread>
#include <iostream>

int main() {
    unsigned cores = std::thread::hardware_concurrency();
    std::cout << "Hardware concurrency: " << cores << "\n";
}
```
