## Прототип

```cpp
#include <thread>

void join();
```

## Параметры

| Параметр | Описание |
|---|---|
| — | Параметров нет |

## Возвращаемое значение

Не возвращает значения (`void`).

## Что делает

Блокирует текущий поток до завершения потока,represented объектом `std::thread`. Вызов `join()` гарантирует, что поток завершит выполнение перед тем, как управление продолжится.

После вызова `join()` объект становится неприсоединяемым (`joinable()` возвращает `false`). Вызов `join()` на уже присоединённом потоке вызывает `std::system_error`.

## Примеры

### Базовое использование

```cpp
#include <thread>
#include <iostream>

void worker() {
    std::this_thread::sleep_for(std::chrono::seconds(1));
    std::cout << "Worker done\n";
}

int main() {
    std::thread t(worker);
    t.join();
    std::cout << "Main continues\n";
}
```

## Исключения

- **Исключения:** Бросает `std::system_error`, если поток не присоединяем или уже присоединён.
- **Безопасность в C++11:** Должен вызываться один раз на присоединяемый поток.
