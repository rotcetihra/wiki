## Что делает

`std::jthread` («joinable thread») — это поток, который автоматически вызывает `request_stop()` и `join()` в деструкторе. В отличие от `std::thread`, не требует явного вызова `join()` или `detach()` — это происходит автоматически при уничтожении объекта.

Поддерживает остановку через `std::stop_token` (C++20), что позволяет корректно завершать потоки.

## Примеры

### Базовое использование

```cpp
#include <thread>
#include <iostream>

void worker(std::stop_token stoken) {
    while (!stoken.stop_requested()) {
        std::cout << "Working...\n";
        std::this_thread::sleep_for(std::chrono::milliseconds(50));
    }
    std::cout << "Stopped\n";
}

int main() {
    std::jthread t(worker);
    // автоматически остановится и присоединится при выходе
}
```

## Исключения

- **Исключения:** Конструктор бросает `std::system_error` при ошибке создания потока.
- **Безопасность в C++11:** Копирование запрещено, перемещение допустимо. Деструктор автоматически вызывает `request_stop()` и `join()`.
