
## Возвращаемое значение

Не применимо (это класс).

## Что делает

`std::thread` — это класс, представляющий поток выполнения. При создании объекта `thread` запускается новый поток, который выполняет переданную функцию. Объект управляет жизненным циклом потока: до вызова `join()` или `detach()` поток считается «присоединяемым».

Копирование запрещено, перемещение допустимо. Деструктор неприсоединённого потока вызывает `std::terminate()`.

## Примеры

### Базовое использование

```cpp
#include <thread>
#include <iostream>

void hello() {
    std::cout << "Hello from thread\n";
}

int main() {
    std::thread t(hello);
    t.join();
    std::cout << "Hello from main\n";
}
```

## Исключения

- **Исключения:** Конструктор бросает `std::system_error` при ошибке создания потока. `join()` и `detach()` бросают `std::system_error` при ошибках.
- **Безопасность в C++11:** Копирование запрещено, перемещение допустимо. Деструктор неприсоединённого потока вызывает `std::terminate()`.
