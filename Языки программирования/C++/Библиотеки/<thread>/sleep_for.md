## Прототип

```cpp
#include <thread>

template <class Rep, class Period>
void sleep_for(const std::chrono::duration<Rep, Period>& sleep_duration);
```

## Параметры

| Параметр | Описание |
|---|---|
| `sleep_duration` | Относительная продолжительность сна |

## Возвращаемое значение

Не возвращает значения (`void`).

## Что делает

Приостанавливает выполнение текущего потока на указанное относительное время. Минимальная точность зависит от реализации и может быть больше указанного времени из-за таймера системы.

Эквивалентно `sleep_until(chrono::steady_clock::now() + sleep_duration)`.

## Примеры

### Базовое использование

```cpp
#include <thread>
#include <iostream>
#include <chrono>

int main() {
    std::cout << "Sleeping 1 second...\n";
    std::this_thread::sleep_for(std::chrono::seconds(1));
    std::cout << "Awake!\n";
}
```
