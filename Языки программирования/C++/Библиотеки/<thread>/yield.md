## Прототип

```cpp
#include <thread>

void yield() noexcept;
```

| Параметр | Описание |

| — | Параметров нет |

## Возвращаемое значение

Не возвращает значения (`void`).

## Что делает

Уступает текущий квант времени планировщику потоков. Полезно в циклах ожидания (busy-wait), чтобы не нагружать процессор. Не гарантирует, что поток будет приостановлен — поведение зависит от реализации.

Часто используется в сочетании с атомарными операциями для ожидания без блокировки.

## Примеры

### Базовое использование

```cpp
#include <thread>
#include <atomic>
#include <iostream>

std::atomic<bool> ready{false};

void waiter() {
    while (!ready.load()) {
        std::this_thread::yield();
    }
    std::cout << "Ready!\n";
}

int main() {
    std::thread t(waiter);
    std::this_thread::sleep_for(std::chrono::milliseconds(100));
    ready = true;
    t.join();
}
```
