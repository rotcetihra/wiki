## Прототип

```cpp
#include <thread>

template <class Clock, class Duration>
void sleep_until(const std::chrono::time_point<Clock, Duration>& sleep_time);
```

## Параметры

| Параметр | Описание |
|---|---|
| `sleep_time` | Абсолютный момент времени до которого длится сон |

## Возвращаемое значение

Не возвращает значения (`void`).

## Что делает

Приостанавливает выполнение текущего потока до указанного абсолютного момента времени. В отличие от `sleep_for`, принимает абсолютное время, что исключает проблемы с дрифтом времени.

Если `sleep_time` уже прошёл, функция вернётся немедленно.

## Примеры

### Базовое использование

```cpp
#include <thread>
#include <iostream>
#include <chrono>

int main() {
    auto deadline = std::chrono::steady_clock::now() + std::chrono::seconds(1);
    std::cout << "Sleeping until deadline...\n";
    std::this_thread::sleep_until(deadline);
    std::cout << "Awake!\n";
}
```
