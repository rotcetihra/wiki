## Прототип

```cpp
#include <iconv.h>\niconv_t iconv_open(const char *tocode, const char *fromcode);
```

## Параметры

| Параметр | Описание |
|---|---|
| `tocode` | целевая кодировка |\n| `fromcode` | исходная кодировка |
## Возвращаемое значение

iconv_t или (iconv_t)-1.

## Что делает

Открывает преобразование кодировок.

## Примеры

### Базовое использование

```cpp
iconv_t cd = iconv_open("UTF-8", "ISO-8859-1");
```
