## Описание библиотеки

Заголовочный файл `<flat_set>` определяет класс `std::flat_set` (C++23) — множество, хранящее отсортированные элементы в непрерывном массиве. В отличие от `std::set`, не использует дерево; поиск — бинарный. Кэш-дружелюбен, оптимизирован для чтения.

## Исключения

- **Исключения:** вставка может выбрасывать исключения при нехватке памяти.
- **Безопасность в C++11:** безопасный доступ через итераторы.
