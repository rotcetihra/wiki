## Прототип

```cpp
#include <sched.h>\nint sched_get_priority_min(int policy);
```

## Параметры

| Параметр | Описание |
|---|---|
| `policy` | политика |
## Возвращаемое значение

Минимальный приоритет или -1.

## Что делает

Минимальный приоритет для политики.

## Примеры

### Базовое использование

```cpp
int min = sched_get_priority_min(SCHED_FIFO);
```
