## Прототип

```cpp
#include <sched.h>\nint sched_get_priority_max(int policy);
```

## Параметры

| Параметр | Описание |
|---|---|
| `policy` | политика |
## Возвращаемое значение

Максимальный приоритет или -1.

## Что делает

Максимальный приоритет для политики.

## Примеры

### Базовое использование

```cpp
int max = sched_get_priority_max(SCHED_FIFO);
```
