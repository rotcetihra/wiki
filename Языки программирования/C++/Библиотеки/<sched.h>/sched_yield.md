## Прототип

```cpp
#include <sched.h>\nint sched_yield(void);
```

## Параметры

| Параметр | Описание |
|---|---|
Нет.
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Уступает процессор другому потоку.

## Примеры

### Базовое использование

```cpp
sched_yield();
```
