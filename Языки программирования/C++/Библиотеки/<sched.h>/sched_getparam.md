## Прототип

```cpp
#include <sched.h>\nint sched_getparam(pid_t pid, struct sched_param *param);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pid` | PID процесса |\n| `param` | параметры |
## Возвращаемое значение

0 или -1.

## Что делает

Получает параметры планирования.

## Примеры

### Базовое использование

```cpp
struct sched_param p;\nsched_getparam(0, &p);
```
