## Описание библиотеки

Заголовочный файл `<compare>` определяет типы и функции для трёхстороннего сравнения (spaceship operator `<=>`). Позволяет определять все операции сравнения через одну функцию `operator<=>`, возвращающую результат, который сравнивается с константами `strong_ordering`, `weak_ordering` или `partial_ordering`.

## Исключения

- **Исключения:** операторы сравнения не бросают исключений.
- **Безопасность:** типы ordering — lightweight value types.

## Стандарты

C++20, C++23.
