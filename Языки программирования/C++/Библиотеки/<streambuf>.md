## Описание библиотеки

Заголовочный файл `<streambuf>` определяет абстрактный базовый класс `std::basic_streambuf`, который является основой для всех классов буферов потоков. Буфер потока управляет чтением и записью данных, обеспечивая интерфейс между потоком и реальным источником/назначением данных (файлом, строкой, памятью и т. д.).

## Исключения

- **Исключения:** Базовый класс не бросает исключений. Конкретные реализации могут бросать исключения при ошибках ввода-вывода.
- **Безопасность в C++11:** Объекты буферов потоков не являются потокобезопасными.

## Стандарты

C++11, C++17, C++20, C++23.
