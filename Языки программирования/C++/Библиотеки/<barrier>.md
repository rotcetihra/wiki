## Описание библиотеки

Заголовочный файл `<barrier>` определяет класс `std::barrier` — механизм синхронизации потоков с понятием фаз. Барьер позволяет группе потоков синхронизироваться на определённых точках выполнения. Каждый поток вызывает `arrive_and_wait`, и когда все потоки прибыли, начинается новая фаза.

## Исключения

- **Исключения:** `arrive_and_wait` может выбрасывать исключения.
- **Безопасность:** объекты `barrier` не являются copyable/movable. Использование одного барьера из нескольких потоков безопасно при соблюдении семантики.
