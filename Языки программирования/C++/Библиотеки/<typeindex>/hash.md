## Прототип

```cpp
#include <typeindex>
template<> struct hash<type_index>;
```

## Возвращаемое значение

`std::size_t` — хеш-код.

## Что делает

Специализация хеш-функции для type_index.

## Примеры

### Базовое использование

```cpp
std::type_index ti(typeid(int));
std::size_t h = std::hash<std::type_index>{}(ti);
```
