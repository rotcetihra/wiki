## Прототип

```cpp
#include <typeindex>
bool operator!=(const type_index& lhs, const type_index& rhs) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `lhs` | левый |
| `rhs` | правый |

## Возвращаемое значение

`bool`.

## Что делает

Проверка неравенства.

## Примеры

### Базовое использование

```cpp
std::type_index a(typeid(int)), b(typeid(double));
std::cout << (a != b) << std::endl; // true
```

## Исключения

- **Исключения:** Не бросает исключений (`noexcept`).
- **Безопасность в C++11:** Потокобезопасен.
