## Прототип

```cpp
#include <list>

template<class T, class Allocator = std::allocator<T>>
class list;
```

`std::list` — двусвязный список. Каждый элемент хранит указатели на предыдущий и следующий элементы. Поддерживает `splice`, `merge`, `sort`, `unique` — операции, специфичные для списков.

## Параметры шаблона

| Параметр | Описание |
|---|---|
| `T` | Тип элементов |
| `Allocator` | Аллокатор памяти |

## Примеры

### Базовое использование

```cpp
```cpp
#include <list>
#include <iostream>

int main()
{
    std::list<int> lst = {1, 2, 3};
    lst.push_front(0);
    lst.push_back(4);
    for (int x : lst) std::cout << x << ' '; // 0 1 2 3 4
}
```
```
- **Исключения:** конструкторы могут выбрасывать исключения.
- **Безопасность в C++11:** нет `operator[]`; безопасный доступ через итераторы.
