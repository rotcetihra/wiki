## Описание библиотеки

Заголовочный файл `<list>` определяет класс `std::list` — двусвязный список. Поддерживает двустороннюю итерацию, вставку/удаление/перемещение элементов за O(1) при известной позиции. Не поддерживает доступ по индексу. Идеален для частых вставок/удалений в середине последовательности.

## Исключения

- **Исключения:** вставка/удаление могут выбрасывать исключения.
- **Безопасность в C++11:** нет `operator[]`; безопасный доступ через итераторы.

## Стандарты

C++11, C++17, C++20, C++23.
