## Прототип

```cpp
#include <aio.h>\nint aio_suspend(const struct aiocb *const list[], int nent, const struct timespec *timeout);
```

## Параметры

| Параметр | Описание |
|---|---|
| `list` | массив указателей на операции |\n| `nent` | количество операций |\n| `timeout` | тайм-аут (NULL — бесконечно) |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Блокирует поток до завершения хотя бы одной операции.

## Примеры

### Базовое использование

```cpp
const struct aiocb *list[1] = {&cb};\naio_suspend(list, 1, NULL);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
