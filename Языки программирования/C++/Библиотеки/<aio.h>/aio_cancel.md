## Прототип

```cpp
#include <aio.h>\nint aio_cancel(int fildes, struct aiocb *aiocbp);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fildes` | файловый дескриптор |\n| `aiocbp` | операция (или NULL для всех) |
## Возвращаемое значение

AIO_CANCELED, AIO_NOTCANCELED, AIO_ALLDONE или -1.

## Что делает

Пытается отменить асинхронные операции.

## Примеры

### Базовое использование

```cpp
aio_cancel(fd, &cb);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
