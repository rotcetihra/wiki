## Прототип

```cpp
#include <aio.h>\nssize_t aio_return(struct aiocb *aiocbp);
```

## Параметры

| Параметр | Описание |
|---|---|
| `aiocbp` | блок управления операцией |
## Возвращаемое значение

Результат (количество байт) или -1 при ошибке.

## Что делает

Возвращает результат завершённой операции.

## Примеры

### Базовое использование

```cpp
ssize_t r = aio_return(&cb);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
