## Прототип

```cpp
#include <aio.h>\nint aio_read(struct aiocb *aiocbp);
```

## Параметры

| Параметр | Описание |
|---|---|
| `aiocbp` | блок управления операцией |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Запускает асинхронную операцию чтения.

## Примеры

### Базовое использование

```cpp
struct aiocb cb;\ncb.aio_fildes = fd;\ncb.aio_buf = buf;\ncb.aio_nbytes = sizeof(buf);\naio_read(&cb);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна для разных объектов.
