## Прототип

```cpp
#include <aio.h>\nint aio_error(const struct aiocb *aiocbp);
```

## Параметры

| Параметр | Описание |
|---|---|
| `aiocbp` | блок управления операцией |
## Возвращаемое значение

Статус: 0 (успех), EINPROGRESS или код ошибки.

## Что делает

Возвращает статус завершённой асинхронной операции.

## Примеры

### Базовое использование

```cpp
int e = aio_error(&cb);
```

## Исключения

- **Исключения:** Не определено при NULL.\n- **Безопасность в C++11:** Потокобезопасна.
