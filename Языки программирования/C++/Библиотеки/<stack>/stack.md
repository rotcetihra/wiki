## Прототип

```cpp
#include <stack>

template<class T, class Container = std::deque<T>>
class stack;
```

`std::stack` — адаптер, ограничивающий доступ к операциям `push`, `pop`, `top`. LIFO-порядок. По умолчанию использует `std::deque`, но можно указать `std::vector` или `std::list`.

## Что делает

## Параметры шаблона

| Параметр | Описание |
|---|---|
| `T` | Тип элементов |
| `Container` | Внутренний контейнер (по умолчанию `std::deque<T>`) |

## Примеры

### Базовое использование

```cpp
```cpp
#include <stack>
#include <iostream>

int main()
{
    std::stack<int> s;
    s.push(1);
    s.push(2);
    std::cout << s.top() << "\n"; // 2
    s.pop();
    std::cout << s.top() << "\n"; // 1
}
```
```
- **Исключения:** `pop()` и `top()` на пустом стеке — неопределённое поведение.
- **Безопасность в C++11:** проверяйте `empty()` перед `top()`/`pop()`.
