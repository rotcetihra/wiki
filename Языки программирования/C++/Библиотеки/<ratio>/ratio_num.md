## Прототип

```cpp
#include <ratio>

template<class R>
struct ratio_num;
```

## Параметры

| Параметр | Описание |
|---|---|
| `R` | Тип `std::ratio` |

## Возвращаемое значение

Статическая constexpr константа `intmax_t` — числитель рационального числа `R`.

## Что делает

Извлекает числитель из типа `std::ratio`.

## Примеры

```cpp
#include <ratio>
#include <iostream>

int main()
{
    using r = std::ratio<7, 3>;
    std::cout << std::ratio_num<r>::value << std::endl; // 7
}
```
