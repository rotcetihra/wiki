## Прототип

```cpp
#include <ratio>

template<class R>
struct ratio_den;
```

## Параметры

| Параметр | Описание |
|---|---|
| `R` | Тип `std::ratio` |

## Возвращаемое значение

Статическая constexpr константа `intmax_t` — знаменатель рационального числа `R`.

## Что делает

Извлекает знаменатель из типа `std::ratio`.

## Примеры

```cpp
#include <ratio>
#include <iostream>

int main()
{
    using r = std::ratio<7, 3>;
    std::cout << std::ratio_den<r>::value << std::endl; // 3
}
```
