## Прототип

```cpp
#include <ratio>

template<intmax_t Num, intmax_t Den = 1>
class ratio;
```

## Параметры

| Параметр | Описание |
|---|---|
| `Num` | Числитель |
| `Den` | Знаменатель (не должен быть 0) |

## Возвращаемое значение

Шаблон `std::ratio` хранит рациональную константу `Num/Den` в нормализованном виде (с выводом знака в числитель, сокращением через НОД).

## Что делает

Представляет рациональную константу времени компиляции. Поля `num` и `den` — статические constexpr члены.

## Примеры

```cpp
#include <ratio>
#include <iostream>

int main()
{
    using r = std::ratio<3, 4>;
    std::cout << r::num << "/" << r::den << std::endl; // 3/4
}
```
