## Прототип

```cpp
#include <ratio>

template<class R1, class R2>
struct ratio_not_equal;
```

## Параметры

| Параметр | Описание |
|---|---|
| `R1` | Первый операнд |
| `R2` | Второй операнд |

## Возвращаемое значение

`std::true_type`, если `R1 != R2`.

## Что делает

Проверяет неравенство двух рациональных констант.

## Примеры

```cpp
#include <ratio>
#include <iostream>

int main()
{
    using r1 = std::ratio<1, 2>;
    using r2 = std::ratio<1, 3>;
    std::cout << std::ratio_not_equal<r1, r2>::value << std::endl; // 1
}
```
