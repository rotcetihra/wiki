## Прототип

```cpp
#include <ratio>

template<class R1, class R2>
struct ratio_equal;
```

## Параметры

| Параметр | Описание |
|---|---|
| `R1` | Первый операнд |
| `R2` | Второй операнд |

## Возвращаемое значение

`std::true_type`, если `R1::num * R2::den == R2::num * R1::den`.

## Что делает

Проверяет равенство двух рациональных констант времени компиляции.

## Примеры

```cpp
#include <ratio>
#include <iostream>

int main()
{
    using r1 = std::ratio<1, 2>;
    using r2 = std::ratio<2, 4>;
    std::cout << std::ratio_equal<r1, r2>::value << std::endl; // 1
}
```

## Исключения

- **Исключения:** операция времени компиляции.
