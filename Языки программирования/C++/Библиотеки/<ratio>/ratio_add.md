## Прототип

```cpp
#include <ratio>

template<class R1, class R2>
using ratio_add = /* typename */;
```

## Параметры

| Параметр | Описание |
|---|---|
| `R1` | Первый операнд типа `std::ratio` |
| `R2` | Второй операнд типа `std::ratio` |

## Возвращаемое значение

Новый тип `std::ratio`, представляющий сумму `R1 + R2`.

## Что делает

Складывает две рациональные константы времени компиляции.

## Примеры

```cpp
#include <ratio>
#include <iostream>

int main()
{
    using r1 = std::ratio<1, 3>;
    using r2 = std::ratio<1, 6>;
    using sum = std::ratio_add<r1, r2>;
    std::cout << sum::num << "/" << sum::den << std::endl; // 1/2
}
```

## Исключения

- **Исключения:** операция времени компиляции.
