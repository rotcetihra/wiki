## Прототип

```cpp
#include <string>
void reserve(size_type res_arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `res_arg` | минимальная ёмкость |

## Возвращаемое значение

Ничего не возвращает.

## Что делает

Резервирует память. Не изменяет размер и содержимое.

## Примеры

### Базовое использование

```cpp
std::string s;
s.reserve(100);
// s.size() == 0, но capacity() >= 100
```

## Исключения

- **Исключения:** Бросает `std::length_error` при слишком большом значении.
