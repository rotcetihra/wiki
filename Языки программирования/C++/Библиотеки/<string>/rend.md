## Прототип

```cpp
#include <string>
reverse_iterator rend() noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Обратный итератор на конец.

## Что делает

Возвращает обратный итератор перед первым элементом.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello";
std::cout << (s.rend() - s.rbegin()) << std::endl; // 5
```
