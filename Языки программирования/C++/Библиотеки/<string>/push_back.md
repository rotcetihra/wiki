## Прототип

```cpp
#include <string>
void push_back(CharT c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | добавляемый символ |

## Возвращаемое значение

Ничего не возвращает.

## Что делает

Добавляет символ в конец строки.

## Примеры

### Базовое использование

```cpp
std::string s = "Hi";
s.push_back('!');
std::cout << s << std::endl; // Hi!
```
