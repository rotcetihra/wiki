## Прототип

```cpp
#include <string>
basic_string& replace(size_type pos, size_type n1, const basic_string& str);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pos` | позиция |
| `n1` | количество заменяемых символов |
| `str` | строка замены |

## Возвращаемое значение

Ссылка на изменённую строку (`*this`).

## Что делает

Заменяет `n1` символов начиная с `pos` на строку `str`.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello World";
s.replace(6, 5, "C++");
std::cout << s << std::endl; // Hello C++
```
