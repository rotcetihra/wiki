## Прототип

```cpp
#include <string>
template<class CharT>
struct char_traits;
```

## Параметры

| Параметр | Описание |
|---|---|
| `CharT` | тип символа |

## Возвращаемое значение

Класс с методами для работы с символами.

## Что делает

Определяет свойства символов: сравнение, копирование, поиск, длину строки.

## Примеры

### Базовое использование

```cpp
using traits = std::char_traits<char>;
const char* s1 = "abc";
const char* s2 = "abd";
int cmp = traits.compare(s1, s2, 3);
std::cout << cmp << std::endl; // -1
```
