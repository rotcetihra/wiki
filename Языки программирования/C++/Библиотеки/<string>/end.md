## Прототип

```cpp
#include <string>
iterator end() noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Итератор на конец (past-the-end).

## Что делает

Возвращает итератор на элемент после последнего.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello";
std::cout << (s.end() - s.begin()) << std::endl; // 5
```
