## Прототип

```cpp
#include <string>
void resize(size_type n, CharT c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `n` | новый размер |
| `c` | символ дополнения |

## Возвращаемое значение

Ничего не возвращает.

## Что делает

Изменяет размер строки. Если `n` больше — дополняет символом `c`.

## Примеры

### Базовое использование

```cpp
std::string s = "Hi";
s.resize(5, '!');
std::cout << s << std::endl; // Hi!!!
```

## Исключения

- **Исключения:** Бросает `std::bad_alloc`.
