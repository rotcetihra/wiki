## Прототип

```cpp
#include <string>
size_type capacity() const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Ёмкость строки.

## Что делает

Возвращает количество символов, которые строка может хранить без перераспределения.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello";
std::cout << s.capacity() << std::endl; // >= 5
```
