## Прототип

```cpp
#include <string>
reverse_iterator rbegin() noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Обратный итератор на начало.

## Что делает

Возвращает обратный итератор на последний элемент.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello";
for (auto it = s.rbegin(); it != s.rend(); ++it)
    std::cout << *it;
// olleH
```
