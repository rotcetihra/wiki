## Прототип

```cpp
#include <string>
int compare(const basic_string& str) const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | строка для сравнения |

## Возвращаемое значение

Результат сравнения: `<0`, `0` или `>0`.

## Что делает

Сравнивает строки лексикографически.

## Примеры

### Базовое использование

```cpp
std::string a = "apple";
std::string b = "banana";
std::cout << a.compare(b) << std::endl; // отрицательное
```
