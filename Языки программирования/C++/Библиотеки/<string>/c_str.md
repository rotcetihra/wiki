```cpp
#include <string>

```

## Возвращаемое значение

Указатель на нуль-терминированную строку.

## Что делает

Возвращает C-style строку.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello";
const char* p = s.c_str();
std::cout << p << std::endl; // Hello
```
