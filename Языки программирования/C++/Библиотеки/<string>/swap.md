## Прототип

```cpp
#include <string>
void swap(basic_string& str) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | другая строка |

## Возвращаемое значение

Ничего не возвращает.

## Что делает

Обменивает содержимое за O(1).

## Примеры

### Базовое использование

```cpp
std::string a = "hello";
std::string b = "world";
a.swap(b);
std::cout << a << ' ' << b << std::endl; // world hello
```
