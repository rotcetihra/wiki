## Прототип

```cpp
#include <string>
basic_string& assign(const basic_string& str);
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | новое значение |

## Возвращаемое значение

Ссылка на изменённую строку (`*this`).

## Что делает

Заменяет содержимое строки на `str`.

## Примеры

### Базовое использование

```cpp
std::string s = "old";
s.assign("new");
std::cout << s << std::endl; // new
```
