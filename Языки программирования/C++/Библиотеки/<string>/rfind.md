## Прототип

```cpp
#include <string>
size_type rfind(const basic_string& str, size_type pos = npos) const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | подстрока |
| `pos` | позиция начала поиска назад |

## Возвращаемое значение

Позиция последнего вхождения или `npos`.

## Что делает

Находит последнее вхождение подстроки.

## Примеры

### Базовое использование

```cpp
std::string s = "abcabc";
std::cout << s.rfind("abc") << std::endl; // 3
```
