## Прототип

```cpp
#include <string>
iterator begin() noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Итератор на начало.

## Что делает

Возвращает итератор на первый элемент.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello";
for (auto it = s.begin(); it != s.end(); ++it)
    std::cout << *it;
// Hello
```
