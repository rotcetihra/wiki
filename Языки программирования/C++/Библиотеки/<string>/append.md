## Прототип

```cpp
#include <string>
basic_string& append(const basic_string& str);
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | строка для добавления |

## Возвращаемое значение

Ссылка на изменённую строку (`*this`).

## Что делает

Добавляет строку `str` в конец. Эквивалентно `operator+=`.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello";
s.append(" World");
std::cout << s << std::endl; // Hello World
```
