## Прототип

```cpp
#include <string>
size_type find(const basic_string& str, size_type pos = 0) const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | подстрока для поиска |
| `pos` | начальная позиция |

## Возвращаемое значение

Позиция начала подстроки или `npos`.

## Что делает

Находит первое вхождение подстроки в строке.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello World";
std::cout << s.find("World") << std::endl; // 6
```
