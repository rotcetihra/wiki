## Прототип

```cpp
#include <string>
void clear() noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Ничего не возвращает.

## Что делает

Очищает строку, делая её пустой.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello";
s.clear();
std::cout << s.empty() << std::endl; // 1
```
