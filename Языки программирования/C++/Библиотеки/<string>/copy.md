## Прототип

```cpp
#include <string>
size_type copy(CharT* s, size_type n, size_type pos = 0) const;
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | назначение |
| `n` | макс. символов |
| `pos` | начальная позиция |

## Возвращаемое значение

Количество скопированных символов.

## Что делает

Копирует до `n` символов в массив `s`.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello World";
char buf[6];
size_t n = s.copy(buf, 5, 6);
buf[n] = '\0';
std::cout << buf << std::endl; // World
```

## Исключения

- **Исключения:** Бросает `std::out_of_range`, если `pos > size()`.
