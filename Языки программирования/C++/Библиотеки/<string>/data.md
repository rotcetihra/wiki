## Прототип

```cpp
#include <string>
const CharT* data() const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Указатель на данные.

## Что делает

Возвращает указатель на массив символов. С C++11 гарантированно нуль-терминирован.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello";
const char* p = s.data();
std::cout << p << std::endl; // Hello
```
