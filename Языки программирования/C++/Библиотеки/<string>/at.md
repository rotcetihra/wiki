## Прототип

```cpp
#include <string>
const_reference at(size_type n) const;
```

## Параметры

| Параметр | Описание |
|---|---|
| `n` | индекс |

## Возвращаемое значение

Ссылка на символ.

## Что делает

Доступ по индексу с проверкой границ. Бросает `std::out_of_range`.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello";
std::cout << s.at(1) << std::endl; // e
```

## Исключения

- **Исключения:** `std::out_of_range` при `n >= size()`.
