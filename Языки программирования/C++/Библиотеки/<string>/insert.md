## Прототип

```cpp
#include <string>
basic_string& insert(size_type pos, const basic_string& str);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pos` | позиция вставки |
| `str` | вставляемая строка |

## Возвращаемое значение

Ссылка на изменённую строку (`*this`).

## Что делает

Вставляет строку перед позицией `pos`.

## Примеры

### Базовое использование

```cpp
std::string s = "Helo";
s.insert(2, "l");
std::cout << s << std::endl; // Hello
```
