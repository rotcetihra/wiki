## Прототип

```cpp
#include <string>
bool ends_with(basic_string_view x) const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | суффикс для проверки |

## Возвращаемое значение

`true`, если строка заканчивается суффиксом.

## Что делает

Проверяет конец строки. Доступно с C++20.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello World";
std::cout << std::boolalpha << s.ends_with("World") << std::endl; // true
```
