## Прототип

```cpp
#include <string>
const_reverse_iterator crend() const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Константный обратный итератор на конец.

## Что делает

Возвращает константный обратный итератор перед первым элементом.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello";
std::cout << (s.crend() - s.crbegin()) << std::endl; // 5
```
