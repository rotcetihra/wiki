## Прототип

```cpp
#include <string>
float stof(const string& str, size_t* idx = nullptr);
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | строка |
| `idx` | позиция |

## Возвращаемое значение

Значение `float`.

## Что делает

Преобразует строку в `float`. Поддерживает научные форматы.

## Примеры

### Базовое использование

```cpp
std::string s = "3.14159";
float val = std::stof(s);
std::cout << val << std::endl; // 3.14159
```

## Исключения

- **Исключения:** `std::invalid_argument`, `std::out_of_range`.
