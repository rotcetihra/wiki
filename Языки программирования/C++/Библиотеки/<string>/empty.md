## Прототип

```cpp
#include <string>
bool empty() const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

`true`, если строка пуста.

## Что делает

Возвращает `true` при `size() == 0`.

## Примеры

### Базовое использование

```cpp
std::string s;
std::cout << std::boolalpha << s.empty() << std::endl; // true
```
