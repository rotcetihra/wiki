## Прототип

```cpp
#include <string>
size_type size() const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Размер строки.

## Что делает

Возвращает количество символов.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello";
std::cout << s.size() << std::endl; // 5
```
