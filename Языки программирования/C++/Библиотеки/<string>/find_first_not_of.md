## Прототип

```cpp
#include <string>
size_type find_first_not_of(const basic_string& str, size_type pos = 0) const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `str` | множество символов |
| `pos` | начальная позиция |

## Возвращаемое значение

Позиция символа или `npos`.

## Что делает

Находит первый символ, не принадлежащий множеству `str`.

## Примеры

### Базовое использование

```cpp
std::string s = "   Hello";
std::cout << s.find_first_not_of(' ') << std::endl; // 3
```
