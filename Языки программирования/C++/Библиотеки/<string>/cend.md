## Прототип

```cpp
#include <string>
const_iterator cend() const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Константный итератор на конец.

## Что делает

Возвращает константный итератор на элемент после последнего.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello";
std::cout << (s.cend() - s.cbegin()) << std::endl; // 5
```
