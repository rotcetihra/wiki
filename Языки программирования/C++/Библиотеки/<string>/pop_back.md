## Прототип

```cpp
#include <string>
void pop_back();
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Ничего не возвращает.

## Что делает

Удаляет последний символ строки.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello!";
s.pop_back();
std::cout << s << std::endl; // Hello
```
