## Прототип

```cpp
#include <string>
template<class T>
class allocator;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип объекта |

## Возвращаемое значение

Объект аллокатора.

## Что делает

Стандартный аллокатор памяти. Управляет выделением через `allocate`/`deallocate`.

## Примеры

### Базовое использование

```cpp
std::allocator<char> alloc;
char* p = alloc.allocate(10);
alloc.deallocate(p, 10);
```

## Исключения

- ('bad_alloc', 'Бросает `std::bad_alloc` при ошибке выделения памяти.')
- ('safe', 'Потокобезопасна для разных объектов.')
