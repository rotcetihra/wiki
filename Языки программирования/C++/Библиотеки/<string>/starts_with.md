## Прототип

```cpp
#include <string>
bool starts_with(basic_string_view x) const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | префикс для проверки |

## Возвращаемое значение

`true`, если строка начинается с префикса.

## Что делает

Проверяет начало строки. Доступно с C++20.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello World";
std::cout << std::boolalpha << s.starts_with("Hello") << std::endl; // true
```
