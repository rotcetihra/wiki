## Описание библиотеки

Заголовочный файл `<valarray>` определяет класс `std::valarray` — однородный массив для числовых вычислений с возможностью автоматической оптимизации (SIMD). Поддерживает поэлементные операции, срезы и маскирование.

## Исключения

- **Исключения:** `std::valarray` может бросать `std::bad_alloc` при нехватке памяти. Операции с `bad_alloc` при нехватке памяти.
- **Безопасность в C++11:** обращение по невалидному индексу — неопределённое поведение.

## Стандарты

C++11, C++17, C++20, C++23.
