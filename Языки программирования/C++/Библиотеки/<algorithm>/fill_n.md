## Прототип

```cpp
#include <algorithm>

template<class OutputIt, class Size, class T>
OutputIt fill_n(OutputIt first, Size count, const T& value);
```

## Параметры

| Параметр | Описание |
|---|---|
| `first` | Начало выходного диапазона |
| `count` | Количество элементов для заполнения |
| `value` | Значение для заполнения |

## Возвращаемое значение

Итератор за последний заполненный элемент.

## Что делает

Присваивает `value` `count` элементам, начиная с `first`.

## Примеры

```cpp
#include <algorithm>
#include <vector>
#include <iostream>

int main()
{
    std::vector<int> v(5);

    std::fill_n(v.begin(), 3, 7);
    // v: {7, 7, 7, 0, 0}
}
```
