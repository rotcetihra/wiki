## Прототип

```cpp
#include <iterator>

template<class InputIt, class Distance>
void advance(InputIt& it, Distance n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `it` | Итератор для продвижения |
| `n` | Расстояние (положительное — вперёд, отрицательное — назад) |

## Возвращаемое значение

Не возвращает значения.

## Что делает

Продвигает итератор `it` на `n` позиций. Для итераторов ввода `n` должен быть неотрицательным.

## Примеры

```cpp
#include <vector>
#include <iostream>
#include <iterator>

int main()
{
    std::vector<int> v = {1, 2, 3, 4, 5};

    auto it = v.begin();
    std::advance(it, 2);
    std::cout << *it << std::endl; // 3
}
```
