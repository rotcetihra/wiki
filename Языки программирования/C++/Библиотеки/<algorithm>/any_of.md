## Прототип

```cpp
#include <algorithm>

template<class InputIt, class UnaryPredicate>
bool any_of(InputIt first, InputIt last, UnaryPredicate p);
```

## Параметры

| Параметр | Описание |
|---|---|
| `first`, `last` | Диапазон итераторов |
| `p` | Унарный предикат |

## Возвращаемое значение

`true` если `p` возвращает `true` хотя бы для одного элемента.

## Что делает

Проверяет, что предикат `p` возвращает `true` хотя бы для одного элемента в диапазоне.

## Примеры

```cpp
#include <algorithm>
#include <vector>

int main()
{
    std::vector<int> v = {1, 3, 5, 8, 9};

    bool any_even = std::any_of(v.begin(), v.end(), [](int x){ return x % 2 == 0; }); // true
}
```

## Исключения

- **Исключения:** не бросает исключений (если предикат не бросает).
