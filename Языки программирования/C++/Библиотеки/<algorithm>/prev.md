## Прототип

```cpp
#include <iterator>

template<class BidirIt>
BidirIt prev(BidirIt it,
             typename iterator_traits<BidirIt>::difference_type n = 1);
```

## Параметры

| Параметр | Описание |
|---|---|
| `it` | Итератор |
| `n` | Расстояние (по умолчанию 1) |

## Возвращаемое значение

Итератор, сдвинутый на `n` позиций назад.

## Что делает

Возвращает итератор, сдвинутый на `n` позиций назад от `it`.

## Примеры

```cpp
#include <vector>
#include <iostream>
#include <iterator>

int main()
{
    std::vector<int> v = {1, 2, 3, 4, 5};

    auto it = std::prev(v.end(), 2);
    std::cout << *it << std::endl; // 4
}
```
