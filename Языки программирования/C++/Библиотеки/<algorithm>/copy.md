## Прототип

```cpp
#include <algorithm>

template<class InputIt, class OutputIt>
OutputIt copy(InputIt first, InputIt last, OutputIt d_first);
```

## Параметры

| Параметр | Описание |
|---|---|
| `first`, `last` | Диапазон для копирования |
| `d_first` | Начало выходного диапазона |

## Возвращаемое значение

Итератор за последний скопированный элемент в выходном диапазоне.

## Что делает

Копирует элементы из диапазона `[first, last)` в выходной диапазон, начиная с `d_first`. Выходной диапазон должен иметь достаточный размер.

## Примеры

```cpp
#include <algorithm>
#include <vector>
#include <iostream>

int main()
{
    std::vector<int> src = {1, 2, 3, 4, 5};
    std::vector<int> dst(5);

    std::copy(src.begin(), src.end(), dst.begin());
    // dst: {1, 2, 3, 4, 5}
}
```
