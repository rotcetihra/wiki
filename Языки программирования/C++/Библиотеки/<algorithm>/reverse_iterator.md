## Прототип

```cpp
#include <iterator>

template<class Iterator>
class reverse_iterator;
```

## Описание

Обёртка над итератором, которая инвертирует направление: `++` становится `--` и наоборот. Позволяет обходить контейнер в обратном порядке.

## Примеры

```cpp
#include <vector>
#include <iostream>

int main()
{
    std::vector<int> v = {1, 2, 3, 4, 5};

    for (auto it = v.rbegin(); it != v.rend(); ++it)
        std::cout << *it << " ";
    // Вывод: 5 4 3 2 1
}
```
