## Прототип

```cpp
#include <iterator>

template<class InputIt>
InputIt next(InputIt it,
             typename iterator_traits<InputIt>::difference_type n = 1);
```

## Параметры

| Параметр | Описание |
|---|---|
| `it` | Итератор |
| `n` | Расстояние (по умолчанию 1) |

## Возвращаемое значение

Итератор, продвинутый на `n` позиций.

## Что делает

Возвращает итератор, сдвинутый на `n` позиций вперёд от `it`.

## Примеры

```cpp
#include <vector>
#include <iostream>
#include <iterator>

int main()
{
    std::vector<int> v = {1, 2, 3, 4, 5};

    auto it = std::next(v.begin(), 2);
    std::cout << *it << std::endl; // 3
}
```
