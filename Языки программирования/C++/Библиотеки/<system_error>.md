## Описание библиотеки

Заголовочный файл `<system_error>` определяет классы дляRepresentation и обработки системных ошибок: `error_code` для хранения кодов ошибок, `error_condition` для представления условий ошибок, `error_category` для группировки ошибок и `system_error` как исключение.

## Исключения

- **Исключения:** `std::system_error` — исключение, содержащее `error_code`.
- **Безопасность в C++11:** `error_code` — потокобезопасен для чтения/записи.

## Стандарты

C++11, C++17, C++20, C++23.
