## Прототип

```cpp
#include <spanstream>

template<class CharT, class Traits = std::char_traits<CharT>>
class basic_spanstream;

using spanstream = basic_spanstream<char>;
```

`std::spanstream` — базовый класс для потоков, работающих с `std::span`. Комбинирует `std::basic_istream` и `std::basic_ostream`.
