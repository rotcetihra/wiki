## Прототип

```cpp
#include <any>

void any::reset() noexcept;
```

## Параметры

Отсутствуют.

## Возвращаемое значение

Не возвращает значения.

## Что делает

Уничтожает хранимое значение (если оно есть). После вызова `has_value()` возвращает `false`.

## Примеры

```cpp
#include <any>
#include <iostream>

int main()
{
    std::any a = 42;
    std::cout << a.has_value() << std::endl; // 1

    a.reset();
    std::cout << a.has_value() << std::endl; // 0
}
```

## Исключения

- **Исключения:** не бросает исключений.
