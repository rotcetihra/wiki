## Прототип

```cpp
#include <any>

template<class T, class... Args>
any make_any(Args&&... args);
```

## Параметры

| Параметр | Описание |
|---|---|
| `args` | Аргументы для конструктора `T` |

## Возвращаемое значение

Объект `any`, содержащий значение типа `T`.

## Что делает

Создаёт объект `any`, содержащий значение типа `T`, построенное из переданных аргументов.

## Примеры

```cpp
#include <any>
#include <string>
#include <iostream>

int main()
{
    auto a = std::make_any<std::string>(5, 'a');
    std::cout << std::any_cast<std::string>(a) << std::endl; // aaaaa

    auto b = std::make_any<int>(42);
    std::cout << std::any_cast<int>(b) << std::endl; // 42
}
```

## Исключения

- **Исключения:** может бросать `std::bad_alloc` при нехватке памяти или исключения, брошенные конструктором `T`.
