## Прототип

```cpp
#include <any>

void swap(any& lhs, any& rhs) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `lhs`, `rhs` | Объекты `any` для обмена |

## Возвращаемое значение

Не возвращает значения.

## Что делает

Обменивает содержимое двух объектов `any`.

## Примеры

```cpp
#include <any>
#include <iostream>

int main()
{
    std::any a = 42;
    std::any b = std::string("hello");

    std::swap(a, b);

    std::cout << std::any_cast<std::string>(a) << std::endl; // hello
    std::cout << std::any_cast<int>(b) << std::endl; // 42
}
```
