## Прототип

```cpp
#include <any>

class any;
```

## Описание

`std::any` — типобезопасный контейнер для хранения значения произвольного типа. Значение можно извлечь с помощью `std::any_cast`.

## Конструкторы

| Конструктор | Описание |
|---|---|
| `any()` | Пустой контейнер |
| `any(const any& other)` | Копирующий конструктор |
| `any(any&& other)` | Перемещающий конструктор |
| `any(const T& value)` | Конструктор со значением |

## Методы

| Метод | Описание |
|---|---|
| `has_value()` | Проверка наличия значения |
| `type()` | Тип хранимого значения (`std::type_info`) |
| `reset()` | Очистка контейнера |
| `swap(any& other)` | Обмен содержимым |

## Примеры

```cpp
#include <any>
#include <iostream>

int main()
{
    std::any a = 42;
    std::cout << std::any_cast<int>(a) << std::endl; // 42

    a = std::string("hello");
    std::cout << std::any_cast<std::string>(a) << std::endl; // hello

    std::cout << "Тип: " << a.type().name() << std::endl;
}
```

## Исключения

- **Исключения:** конструкторы могут бросать `std::bad_alloc` при нехватке памяти. `any_cast` бросает `std::bad_any_cast` при несовпадении типа.
- **Безопасность:** не является потокобезопасным — один объект `any` не должен использоваться из нескольких потоков без синхронизации.
