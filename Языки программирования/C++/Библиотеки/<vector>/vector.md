## Прототип

```cpp
#include <vector>

template<class T, class Allocator = std::allocator<T>>
class vector;
```

`std::vector` — динамический массив с непрерывным хранением элементов. Автоматически расширяется при добавлении элементов. Поддерживает `reserve()` для предварительного выделения памяти. Самый часто используемый контейнер C++.

## Параметры шаблона

| Параметр | Описание |
|---|---|
| `T` | Тип элементов |
| `Allocator` | Аллокатор памяти |

## Примеры

### Базовое использование

```cpp
```cpp
#include <vector>
#include <iostream>

int main()
{
    std::vector<int> v = {1, 2, 3};
    v.push_back(4);
    for (int x : v) std::cout << x << ' '; // 1 2 3 4
}
```
```
- **Исключения:** `at()` выбрасывает `std::out_of_range`.
- **Безопасность в C++11:** безопасный доступ через `at()`.
