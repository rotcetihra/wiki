## Описание библиотеки

Заголовочный файл `<vector>` определяет класс `std::vector` — динамический массив с непрерывным хранением элементов. Самый используемый контейнер C++. Поддерживает случайный доступ, автоматическое расширение (при `push_back`), резервирование памяти (`reserve`). Итераторы инвалидируются при вставке/удалении (кроме `erase` возвращает валидный итератор).

## Исключения

- **Исключения:** `at()` выбрасывает `std::out_of_range`. `reserve()` может выбрасывать `std::length_error` или `std::bad_alloc`.
- **Безопасность в C++11:** безопасный доступ через `at()`.

## Стандарты

C++11, C++17, C++20, C++23.
