## Прототип

```cpp
#include <locale.h>\nchar *setlocale(int category, const char *locale);
```

## Параметры

| Параметр | Описание |
|---|---|
| `category` | категория (LC_ALL) |\n| `locale` | строка локали |
## Возвращаемое значение

Указатель на текущую локаль.

## Что делает

Устанавливает/получает локаль.

## Примеры

### Базовое использование

```cpp
setlocale(LC_ALL, "ru_RU.UTF-8");
```
