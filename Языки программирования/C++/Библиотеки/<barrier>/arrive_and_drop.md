## Прототип

```cpp
#include <barrier>

void arrive_and_drop();
```

## Параметры

Отсутствуют.

## Возвращаемое значение

Не возвращает значения.

## Что делает

Уведомляет барьер о прибытии текущего потока и отказывается от участия в следующей фазе. Количество потоков для завершения фазы уменьшается на 1.

## Примеры

```cpp
#include <barrier>
#include <iostream>
#include <thread>

int main()
{
    std::barrier b(3);

    std::thread t1([&b]{ b.arrive_and_wait(); });
    std::thread t2([&b]{
        b.arrive_and_drop(); // t2 больше не участвует
    });
    std::thread t3([&b]{ b.arrive_and_wait(); });

    t1.join(); t2.join(); t3.join();
}
```

## Исключения

- **Исключения:** может бросать исключения.
- **Безопасность:** один вызов `arrive_and_drop` на поток на фазу.
