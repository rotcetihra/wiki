## Прототип

```cpp
#include <barrier>

void arrive_and_wait();
```

## Параметры

Отсутствуют.

## Возвращаемое значение

Не возвращает значения.

## Что делает

Уведомляет барьер о прибытии текущего потока и блокирует его до тех пор, пока все потоки не прибудут. Эквивалентно `arrive() + wait()`.

## Примеры

```cpp
#include <barrier>
#include <iostream>
#include <thread>

int main()
{
    std::barrier b(2);

    std::thread t1([&b]{
        std::cout << "Поток 1 готов\n";
        b.arrive_and_wait();
        std::cout << "Поток 1 продолжает\n";
    });

    std::thread t2([&b]{
        std::cout << "Поток 2 готов\n";
        b.arrive_and_wait();
        std::cout << "Поток 2 продолжает\n";
    });

    t1.join();
    t2.join();
}
```

## Исключения

- **Исключения:** может бросать исключения.
- **Безопасность:** один вызов `arrive_and_wait` на поток на фазу.
