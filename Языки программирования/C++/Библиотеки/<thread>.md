## Описание библиотеки

Заголовочный файл `<thread>` определяет класс `std::thread`, который представляет поток выполнения, и класс `std::jthread` (C++20), который автоматически присоединяется при уничтожении. Заголовок также предоставляет вспомогательные функции: `std::this_thread::yield()` для уступки планировщику, `std::this_thread::sleep_for()` и `std::this_thread::sleep_until()` для приостановки потока, а также `std::thread::hardware_concurrency()` для определения количества аппаратных ядер.

## Исключения

- **Исключения:** `std::thread` бросает `std::system_error` при ошибке создания потока. `join()` и `detach()` бросают `std::system_error` при ошибках операций.
- **Безопасность в C++11:** Копирование потоков запрещено. Перемещение допустимо. Деструктор неприсоединённого потока вызывает `std::terminate()`. `std::jthread` автоматически вызывает `request_stop()` и `join()` в деструкторе.

## Стандарты
