## Описание библиотеки

Заголовочный файл `<any>` определяет класс `std::any` — типобезопасный контейнер для хранения значения произвольного типа. Значение можно извлечь с помощью `std::any_cast`. Класс появился в стандарт C++17.

## Исключения

- **Исключения:** `std::any_cast` бросает `std::bad_any_cast` при несовпадении типа. Конструктор `any` может бросить исключения при копировании хранимого значения.
- **Безопасность в C++11:** не применимо (контейнер C++17). `any` исключает многопоточный доступ к одному объекту без внешней синхронизации.

## Стандарты

C++17, C++20, C++23.
