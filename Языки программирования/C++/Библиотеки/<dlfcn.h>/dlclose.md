## Прототип

```cpp
#include <dlfcn.h>\nint dlclose(void *handle);
```

## Параметры

| Параметр | Описание |
|---|---|
| `handle` | дескриптор библиотеки |
## Возвращаемое значение

0 при успехе, ненулевое значение при ошибке.

## Что делает

Закрывает библиотеку и уменьшает счётчик ссылок.

## Примеры

### Базовое использование

```cpp
dlclose(h);
```

## Исключения

- **Исключения:** Ненулевое возвращаемое значение при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
