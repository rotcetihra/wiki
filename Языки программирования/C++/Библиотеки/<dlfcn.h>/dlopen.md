## Прототип

```cpp
#include <dlfcn.h>\nvoid *dlopen(const char *filename, int flag);
```

## Параметры

| Параметр | Описание |
|---|---|
| `filename` | путь к библиотеке |\n| `flag` | RTLD_LAZY или RTLD_NOW |
## Возвращаемое значение

Дескриптор или NULL при ошибке.

## Что делает

Загружает разделяемую библиотеку в адресное пространство процесса.

## Примеры

### Базовое использование

```cpp
void *h = dlopen("libm.so", RTLD_LAZY);
```

## Исключения

- **Исключения:** Возвращает NULL, ошибка через `dlerror()`.\n- **Безопасность в C++11:** Потокобезопасна.
