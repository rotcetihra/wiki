## Прототип

```cpp
#include <dlfcn.h>\nvoid *dlsym(void *handle, const char *symbol);
```

## Параметры

| Параметр | Описание |
|---|---|
| `handle` | дескриптор библиотеки |\n| `symbol` | имя символа |
## Возвращаемое значение

Указатель на символ или NULL.

## Что делает

Находит адрес функции или переменной в загруженной библиотеке.

## Примеры

### Базовое использование

```cpp
typedef double (*math_fn)(double);\nmath_fn sin_fn = (math_fn)dlsym(h, "sin");
```

## Исключения

- **Исключения:** Возвращает NULL, ошибка через `dlerror()`.\n- **Безопасность в C++11:** Потокобезопасна.
