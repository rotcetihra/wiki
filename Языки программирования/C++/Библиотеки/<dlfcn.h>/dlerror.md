## Прототип

```cpp
#include <dlfcn.h>\nchar *dlerror(void);
```

## Параметры

| Параметр | Описание |
|---|---|
Нет параметров.
## Возвращаемое значение

Строка ошибки или NULL.

## Что делает

Возвращает текст последней ошибки из группы `dlopen/dlsym/dlclose`.

## Примеры

### Базовое использование

```cpp
char *e = dlerror();\nif (e) fprintf(stderr, "%s", e);
```

## Исключения

- **Исключения:** Возвращает NULL при отсутствии ошибок.\n- **Безопасность в C++11:** Не потокобезопасна.
