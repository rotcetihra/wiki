## Прототип

```cpp
#include <valarray>

template<class T>
class indirect_array;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | Тип элементов |

## Возвращаемое значение

Класс-адаптер для доступа к элементам `valarray` по массиву индексов.

## Что делает

Предоставляет доступ к подмножеству элементов `valarray`, определённому массивом индексов.

## Примеры

```cpp
#include <valarray>
#include <iostream>

int main()
{
    std::valarray<int> v = {10, 20, 30, 40, 50};
    std::valarray<size_t> idx = {1, 3};
    v[idx] = 0; // обнуляет элементы с индексами 1 и 3
    for (int x : v) std::cout << x << " "; // 10 0 30 0 50
}
```
