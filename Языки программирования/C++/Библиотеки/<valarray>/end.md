## Прототип

```cpp
#include <valarray>

template<class T>
/* unspecified */ end(const valarray<T>& v);
```

## Параметры

| Параметр | Описание |
|---|---|
| `v` | Константная ссылка на `valarray` |

## Возвращаемое значение

Итератор за последний элемент.

## Что делает

Возвращает итератор за конец `valarray`.

## Примеры

```cpp
#include <valarray>
#include <iostream>

int main()
{
    std::valarray<int> v = {1, 2, 3};
    for (auto it = std::begin(v); it != std::end(v); ++it)
        std::cout << *it << " "; // 1 2 3
}
```
