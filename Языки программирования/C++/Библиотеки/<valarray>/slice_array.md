## Прототип

```cpp
#include <valarray>

template<class T>
class slice_array;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | Тип элементов |

## Возвращаемое значение

Класс `std::slice_array<T>` — адаптер для доступа к элементам `valarray` через `slice`.

## Что делает

Предоставляет доступ к подмножеству элементов `valarray`, определённому `slice`. Поддерживает присваивание и поэлементные операции.

## Примеры

```cpp
#include <valarray>
#include <iostream>

int main()
{
    std::valarray<int> v = {0, 1, 2, 3, 4, 5};
    v[std::slice(0, 3, 2)] = 99; // индексы 0, 2, 4
    for (int x : v) std::cout << x << " "; // 99 1 99 3 99 5
}
```
