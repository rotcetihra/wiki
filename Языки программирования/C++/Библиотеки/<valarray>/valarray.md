## Прототип

```cpp
#include <valarray>

template<class T>
class valarray;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | Тип элементов (скалярный тип) |

## Возвращаемое значение

Класс `std::valarray<T>` — однородный динамический массив для числовых вычислений.

## Что делает

Представляет массив фиксированного типа с поддержкой поэлементных арифметических операций и оптимизаций компилятора (SIMD).

## Примеры

```cpp
#include <valarray>
#include <iostream>

int main()
{
    std::valarray<int> v = {1, 2, 3, 4, 5};
    auto doubled = v * 2;
    for (int x : doubled) std::cout << x << " "; // 2 4 6 8 10
}
```

## Исключения

- **Исключения:** `bad_alloc` при нехватке памяти.
