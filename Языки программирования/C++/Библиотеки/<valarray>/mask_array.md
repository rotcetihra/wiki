## Возвращаемое значение

Класс-адаптер для доступа к элементам `valarray` по булевой маске.

## Что делает

Предоставляет доступ к подмножеству элементов `valarray`, определённому булевым массивом-маской.

## Примеры

```cpp
#include <valarray>
#include <iostream>

int main()
{
    std::valarray<int> v = {10, 20, 30, 40, 50};
    std::valarray<bool> mask = {true, false, true, false, true};
    v[mask] = 0; // обнуляет элементы с индексами 0, 2, 4
    for (int x : v) std::cout << x << " "; // 0 20 0 40 0
}
```
