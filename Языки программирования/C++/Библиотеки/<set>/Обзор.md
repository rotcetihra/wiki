## Описание библиотеки

Заголовочный файл `<set>` определяет класс `std::set` — множество, хранящее уникальные элементы в отсортированном порядке. Реализован как сбалансированное дерево. Элементы должны поддерживать оператор `<` (или использовать пользовательский компаратор). Поиск, вставка и удаление — O(log n).

## Исключения

- **Исключения:** вставка может выбрасывать исключения.
- **Безопасность в C++11:** безопасный доступ через итераторы.

## Стандарты

C++11, C++17, C++20, C++23.
