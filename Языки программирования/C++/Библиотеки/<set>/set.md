## Прототип

```cpp
#include <set>

template<class Key, class Compare = std::less<Key>,
         class Allocator = std::allocator<Key>>
class set;
```

`std::set` — множество уникальных элементов в отсортированном порядке. Элементы неизменяемы (const). Итераторы не инвалидируются при вставке/удалении (кроме удалённого элемента).

## Параметры шаблона

| Параметр | Описание |
|---|---|
| `Key` | Тип элементов |
| `Compare` | Функция сравнения |
| `Allocator` | Аллокатор памяти |

## Примеры

### Базовое использование

```cpp
```cpp
#include <set>
#include <iostream>

int main()
{
    std::set<int> s = {5, 3, 1, 4, 2};
    s.insert(6);
    for (int x : s) std::cout << x << ' '; // 1 2 3 4 5 6
}
```
```
- **Исключения:** вставка может выбросить `std::bad_alloc`.
- **Безопасность в C++11:** безопасный доступ через итераторы.
