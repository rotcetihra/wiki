## Прототип

```cpp
#include <poll.h>\nint poll(struct pollfd *fds, nfds_t nfds, int timeout);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fds` | массив структур pollfd |\n| `nfds` | количество элементов |\n| `timeout` | тайм-аут в мс (-1 — бесконечно) |
## Возвращаемое значение

Количество дескрипторов с событиями, 0 при тайм-ауте, -1 при ошибке.

## Что делает

Мониторит несколько дескрипторов на события.

## Примеры

### Базовое использование

```cpp
struct pollfd fds[1];\nfds[0].fd = fd;\nfds[0].events = POLLIN;\npoll(fds, 1, 5000);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
