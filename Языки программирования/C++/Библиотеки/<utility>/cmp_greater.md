## Прототип

```cpp
#include <utility>

template<class T, class U>
constexpr bool cmp_greater(T t, U u) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `t` | Первое значение |
| `u` | Второе значение |

## Возвращаемое значение

`true`, если `t > u`.

## Что делает

Безопасное сравнение «больше» для знаковых и беззнаковых типов.

## Примеры

```cpp
#include <utility>
#include <iostream>

int main()
{
    unsigned int a = 1;
    int b = -1;
    std::cout << std::cmp_greater(a, b) << std::endl; // 1 (1 > -1)
}
```
