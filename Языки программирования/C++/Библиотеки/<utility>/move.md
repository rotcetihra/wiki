## Прототип

```cpp
#include <utility>

template<class T>
constexpr std::remove_reference_t<T>&& move(T&& t) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `t` | Значение для перемещения |

## Возвращаемое значение

`std::remove_reference_t<T>&&&` — rvalue-ссылка.

## Что делает

Безусловно приводит аргумент к rvalue-ссылке. Сам по себе не перемещает — только позволяет использовать move-семантику.

## Примеры

```cpp
#include <utility>
#include <string>

int main()
{
    std::string a = "hello";
    std::string b = std::move(a); // move-конструктор
    // a теперь в "moved-from" состоянии
}
```
