## Прототип

```cpp
#include <utility>

template<class T1, class T2>
struct pair;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T1` | Тип первого элемента |
| `T2` | Тип второго элемента |

## Возвращаемое значение

Класс `std::pair<T1, T2>` с публичными членами `first` и `second`.

## Что делает

Объединяет два значения разных типов в одну структуру. Основной контейнер для возврата нескольких значений.

## Примеры

```cpp
#include <utility>
#include <iostream>

int main()
{
    std::pair<int, std::string> p{42, "hello"};
    std::cout << p.first << " " << p.second << std::endl; // 42 hello
}
```

## Исключения

- **Исключения:** зависит от типов элементов.
