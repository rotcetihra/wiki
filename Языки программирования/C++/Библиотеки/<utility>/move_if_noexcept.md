## Прототип

```cpp
#include <utility>

template<class T>
constexpr auto move_if_noexcept(T& x) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Значение |

## Возвращаемое значение

`const T&` если move-конструктор бросает исключения, иначе `T&&`.

## Что делает

Возвращает rvalue-ссылку, только если move-конструктор не бросает исключений (`noexcept`). Иначе возвращает const-ссылку для безопасного копирования.

## Примеры

```cpp
#include <utility>
#include <iostream>

int main()
{
    int x = 42;
    auto&& ref = std::move_if_noexcept(x);
    std::cout << ref << std::endl; // 42
}
```

## Исключения

- **Исключения:** не бросает исключений.
