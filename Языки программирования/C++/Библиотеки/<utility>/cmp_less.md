## Прототип

```cpp
#include <utility>

template<class T, class U>
constexpr bool cmp_less(T t, U u) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `t` | Первое значение |
| `u` | Второе значение |

## Возвращаемое значение

`true`, если `t < u`.

## Что делает

Безопасное сравнение «меньше» для знаковых и беззнаковых типов.

## Примеры

```cpp
#include <utility>
#include <iostream>

int main()
{
    int a = -1;
    unsigned int b = 1;
    std::cout << std::cmp_less(a, b) << std::endl; // 1 (-1 < 1)
}
```
