## Прототип

```cpp
#include <utility>

template<class R, class T>
constexpr bool in_range(T t) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `t` | Значение для проверки |

## Возвращаемое значение

`true`, если `t` представимо типом `R` (входит в диапазон `std::numeric_limits<R>::min()`..`max()`).

## Что делает

Безопасно проверяет, помещается ли целочисленное значение в указанный тип без потери данных.

## Примеры

```cpp
#include <utility>
#include <iostream>

int main()
{
    std::cout << std::in_range<int>(255) << std::endl;    // 1
    std::cout << std::in_range<int>(-1) << std::endl;     // 1
    std::cout << std::in_range<int>(1000000000LL) << std::endl; // 0 (если int 32-bit)
}
```
