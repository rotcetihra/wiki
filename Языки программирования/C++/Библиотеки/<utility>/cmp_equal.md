## Прототип

```cpp
#include <utility>

template<class T, class U>
constexpr bool cmp_equal(T t, U u) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `t` | Первое значение |
| `u` | Второе значение |

## Возвращаемое значение

`true`, если `t == u`.

## Что делает

Безопасное сравнение знаковых и беззнаковых целочисленных типов без предупреждений компилятора о сравнении знаковых и беззнаковых.

## Примеры

```cpp
#include <utility>
#include <iostream>

int main()
{
    int a = -1;
    unsigned int b = 1;
    std::cout << std::cmp_equal(a, b) << std::endl; // 0
}
```
