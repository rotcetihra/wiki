## Прототип

```cpp
#include <utility>

template<class T, T... Ints>
class integer_sequence;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | Целочисленный тип |
| `Ints` | Параметрический пакет значений |

## Возвращаемое значение

Шаблон, хранящий упорядоченную последовательность целочисленных значений.

## Что делает

Представляет последовательность целочисленных констант времени компиляции. Используется для unrolling пакетов параметров.

## Примеры

```cpp
#include <utility>
#include <iostream>

int main()
{
    using seq = std::integer_sequence<int, 1, 2, 3>;
    std::cout << std::tuple_size_v<std::tuple<int, int, int>> << std::endl;
}
```

## Исключения

- **Исключения:** операция времени компиляции.
