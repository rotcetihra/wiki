## Описание библиотеки

Заголовочный файл `<regex>` определяет классы и функции для работы с регулярными выражениями. Поддерживает несколько синтаксисов (ECMAScript, POSIX и др.) и предоставляет итераторы для обхода совпадений, замены и другие операции.

## Исключения

- **Исключения:** Бросает `std::regex_error` при ошибке компиляции регулярного выражения.
- **Безопасность в C++11:** Потокобезопасна для разных объектов.

## Стандарты

C++11, C++14, C++17, C++20, C++23.
