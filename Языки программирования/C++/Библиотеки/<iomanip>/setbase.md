## Прототип

```cpp
#include <iomanip>
/*unspecified*/ setbase(int base);
```

## Параметры

| Параметр | Описание |
|---|---|
| `base` | Основание системы счисления (2, 8, 10, 16) |

## Возвращаемое значение

Манипулятор для использования с `<<`.

## Что делает

Устанавливает основание системы счисления (2, 8, 10, 16).

## Примеры

### Базовое использование

```cpp
std::cout << std::setbase(16) << 255 << std::endl;  // ff
std::cout << std::setbase(8) << 255 << std::endl;   // 377
```
