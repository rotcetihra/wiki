## Прототип

```cpp
#include <iomanip>
template<class CharT>
/*unspecified*/ put_time(const std::tm* tmb, const CharT* fmt);
```

## Параметры

| Параметр | Описание |
|---|---|
| `tmb` | Указатель на `std::tm` |
| `fmt` | Форматная строка |

## Возвращаемое значение

Манипулятор для использования с `<<` / `>>`.

## Что делает

Выводит время в выходной поток согласно форматной строке.

## Примеры

### Базовое использование

```cpp
std::tm t = *std::localtime(&now);
std::cout << std::put_time(&t, "%Y-%m-%d %H:%M:%S") << std::endl;
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
