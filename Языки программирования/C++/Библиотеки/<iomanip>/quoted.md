## Прототип

```cpp
#include <iomanip>
template<class CharT, class Traits, class Allocator>
/*unspecified*/ quoted(const std::basic_string<CharT, Traits, Allocator>& s, CharT delim = CharT('"'), CharT escape = CharT('\\'));
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Строка для вывода |
| `delim` | Символ-кавычка |
| `escape` | Символ экранирования |

## Возвращаемое значение

Манипулятор для использования с `<<` / `>>`.

## Что делает

Выводит строку в кавычках с экранированием специальных символов.

## Примеры

### Базовое использование

```cpp
std::string s = "Hello, World!";
std::cout << std::quoted(s) << std::endl;  // "Hello, World!" 
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
