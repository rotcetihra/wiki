## Прототип

```cpp
#include <iomanip>
template<class Money>
/*unspecified*/ put_money(const Money& mon, bool intl = false);
```

## Параметры

| Параметр | Описание |
|---|---|
| `mon` | Денежная сумма |
| `intl` | Использовать международный формат |

## Возвращаемое значение

Манипулятор для использования с `<<` / `>>`.

## Что делает

Выводит денежную сумму в выходной поток.

## Примеры

### Базовое использование

```cpp
std::cout << std::put_money(12345.67L) << std::endl;
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
