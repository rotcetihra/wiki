## Прототип

```cpp
#include <iomanip>
template<class CharT>
/*unspecified*/ get_time(std::tm* tmb, const CharT* fmt);
```

## Параметры

| Параметр | Описание |
|---|---|
| `tmb` | Указатель на `std::tm` |
| `fmt` | Форматная строка |

## Возвращаемое значение

Манипулятор для использования с `<<` / `>>`.

## Что делает

Читает время из входного потока согласно форматной строке.

## Примеры

### Базовое использование

```cpp
std::tm t;
std::cin >> std::get_time(&t, "%Y-%m-%d %H:%M:%S");
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
