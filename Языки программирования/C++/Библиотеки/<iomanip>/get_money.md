## Прототип

```cpp
#include <iomanip>
template<class Money>
/*unspecified*/ get_money(Money& mon, bool intl = false);
```

## Параметры

| Параметр | Описание |
|---|---|
| `mon` | Денежная сумма |
| `intl` | Использовать международный формат |

## Возвращаемое значение

Манипулятор для использования с `<<` / `>>`.

## Что делает

Читает денежную сумму из входного потока.

## Примеры

### Базовое использование

```cpp
std::monetary_base::imbue(std::locale("en_US.UTF-8"));
long double amount;
std::cin >> std::get_money(amount);
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
