## Прототип

```cpp
#include <iomanip>
/*unspecified*/ setiosflags(std::ios_base::fmtflags mask);
```

## Параметры

| Параметр | Описание |
|---|---|
| `mask` | Флаги форматирования для установки |

## Возвращаемое значение

Манипулятор для использования с `<<`.

## Что делает

Устанавливает указанные флаги форматирования.

## Примеры

### Базовое использование

```cpp
std::cout << std::setiosflags(std::ios::hex) << 255 << std::endl;  // ff
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
