## Прототип

```cpp
#include <iomanip>
/*unspecified*/ setprecision(int n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `n` | Точность (количество знаков) |

## Возвращаемое значение

Манипулятор для использования с `<<`.

## Что делает

Устанавливает точность вывода чисел с плавающей точкой.

## Примеры

### Базовое использование

```cpp
std::cout << std::setprecision(3) << 3.14159 << std::endl;  // 3.14
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
