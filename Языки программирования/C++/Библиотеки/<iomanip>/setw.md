## Прототип

```cpp
#include <iomanip>
/*unspecified*/ setw(int n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `n` | Ширина поля |

## Возвращаемое значение

Манипулятор для использования с `<<`.

## Что делает

Устанавливает ширину следующего поля вывода.

## Примеры

### Базовое использование

```cpp
std::cout << std::setw(10) << 42 << std::endl;  //         42
```
