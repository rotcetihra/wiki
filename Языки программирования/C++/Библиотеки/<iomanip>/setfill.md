## Прототип

```cpp
#include <iomanip>
/*unspecified*/ setfill(CharT c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Символ заполнения |

## Возвращаемое значение

Манипулятор для использования с `<<`.

## Что делает

Устанавливает символ заполнения для полей.

## Примеры

### Базовое использование

```cpp
std::cout << std::setfill('*') << std::setw(10) << 42 << std::endl;  // ********42
```
