## Прототип

```cpp
#include <iomanip>
/*unspecified*/ resetiosflags(std::ios_base::fmtflags mask);
```

## Параметры

| Параметр | Описание |
|---|---|
| `mask` | Флаги форматирования для сброса |

## Возвращаемое значение

Манипулятор для использования с `<<`.

## Что делает

Сбрасывает указанные флаги форматирования.

## Примеры

### Базовое использование

```cpp
std::cout << std::resetiosflags(std::ios::hex) << 255 << std::endl;  // 255
```
