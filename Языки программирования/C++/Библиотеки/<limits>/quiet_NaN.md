## Прототип

```cpp
#include <limits>
template<class T>
static constexpr T numeric_limits<T>::quiet_NaN();
```

## Возвращаемое значение

`static constexpr T`.

## Что делает

Тихое значение NaN

## Примеры

### Базовое использование

```cpp
std::cout << std::numeric_limits<double>::quiet_NaN() << std::endl;
```

- **Безопасность в C++11:** Потокобезопасен.
