## Прототип

```cpp
#include <limits>
template<class T>
static constexpr T numeric_limits<T>::infinity();
```

## Возвращаемое значение

`static constexpr T`.

## Что делает

Бесконечность

## Примеры

### Базовое использование

```cpp
std::cout << std::numeric_limits<double>::infinity() << std::endl;
```
