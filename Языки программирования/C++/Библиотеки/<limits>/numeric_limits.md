## Прототип

```cpp
#include <limits>
template<class T>
struct numeric_limits;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | арифметический тип |

## Возвращаемое значение

Не применимо (это тип).

## Что делает

Шаблонный класс со свойствами арифметических типов.

## Примеры

### Базовое использование

```cpp
std::cout << std::numeric_limits<int>::max() << std::endl;
```
