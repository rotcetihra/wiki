## Прототип

```cpp
#include <tuple>
template<size_t I, class... Types>
struct tuple_element<I, tuple<Types...>>;
```

## Параметры

| Параметр | Описание |
|---|---|
| `I` | индекс |

## Возвращаемое значение

`type` — тип элемента по индексу.

## Что делает

Метатип с типом элемента кортежа.

## Примеры

### Базовое использование

```cpp
using T = std::tuple_element_t<1, std::tuple<int,double,char>>; // double
```
