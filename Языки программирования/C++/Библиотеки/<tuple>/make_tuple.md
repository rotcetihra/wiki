## Прототип

```cpp
#include <tuple>
template<class... Types>
tuple<VTypes...> make_tuple(Types&&... t);
```

## Параметры

| Параметр | Описание |
|---|---|
| `t` | значения |

## Возвращаемое значение

Кортеж из переданных значений.

## Что делает

Создаёт кортёж с выводом типов.

## Примеры

### Базовое использование

```cpp
auto t = std::make_tuple(1, 3.14, std::string("привет"));
```

## Исключения

- **Исключения:** Может бросить `std::bad_alloc`.
- **Безопасность в C++11:** Потокобезопасен.
