## Прототип

```cpp
#include <tuple>
template<class... Types>
void swap(tuple<Types...>& x, tuple<Types...>& y) noexcept(/*...*/);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | первый кортеж |
| `y` | второй кортеж |

## Возвращаемое значение

Ничего не возвращает.

## Что делает

Обмен содержимым двух кортежей.

## Примеры

### Базовое использование

```cpp
auto a = std::make_tuple(1,2), b = std::make_tuple(3,4);
std::swap(a, b);
```
