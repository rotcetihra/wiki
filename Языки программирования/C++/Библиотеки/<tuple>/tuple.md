## Прототип

```cpp
#include <tuple>
template<class... Types>
class tuple;
```

## Параметры

| Параметр | Описание |
|---|---|
| `Types` | типы элементов |

## Возвращаемое значение

Не применимо (это тип).

## Что делает

Фиксированный набор значений различных типов.

## Примеры

### Базовое использование

```cpp
std::tuple<int, double, std::string> t(1, 3.14, "привет");
std::cout << std::get<0>(t) << std::endl; // 1
```

## Исключения

- **Исключения:** Зависит от типов элементов.
- **Безопасность в C++11:** Не является потокобезопасным.
