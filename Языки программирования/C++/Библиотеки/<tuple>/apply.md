## Прототип

```cpp
#include <tuple>
template<class F, class Tuple>
constexpr decltype(auto) apply(F&& f, Tuple&& t);
```

## Параметры

| Параметр | Описание |
|---|---|
| `f` | функция |
| `t` | кортёж аргументов |

## Возвращаемое значение

Результат вызова f.

## Что делает

Вызывает функцию с аргументами из кортежа.

## Примеры

### Базовое использование

```cpp
auto t = std::make_tuple(1, 2);
auto r = std::apply(std::plus<int>{}, t); // 3
```

## Исключения

- **Исключения:** Зависит от вызываемой функции.
- **Безопасность в C++11:** Потокобезопасен.
