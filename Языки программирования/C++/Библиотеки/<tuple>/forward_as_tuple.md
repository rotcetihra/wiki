## Прототип

```cpp
#include <tuple>
template<class... Types>
tuple<Types&&...> forward_as_tuple(Types&&... t) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `t` | аргументы |

## Возвращаемое значение

Кортеж из ссылок.

## Что делает

Создаёт кортёж из ссылок на аргументы.

## Примеры

### Базовое использование

```cpp
int x = 10;
auto t = std::forward_as_tuple(x);
std::get<0>(t) = 20; // x = 20
```

## Исключения

- **Исключения:** Не бросает исключений (`noexcept`).
- **Безопасность в C++11:** Потокобезопасен.
