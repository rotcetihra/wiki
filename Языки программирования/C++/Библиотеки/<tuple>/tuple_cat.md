## Прототип

```cpp
#include <tuple>
template<class... Tuples>
tuple<CTs...> tuple_cat(Tuples&&... tups);
```

## Параметры

| Параметр | Описание |
|---|---|
| `tups` | кортежи |

## Возвращаемое значение

Объединённый кортёж.

## Что делает

Конкатенация нескольких кортежей.

## Примеры

### Базовое использование

```cpp
auto t1 = std::make_tuple(1,2);
auto t2 = std::make_tuple(3.0,4.0);
auto t3 = std::tuple_cat(t1,t2); // {1,2,3.0,4.0}
```

## Исключения

- **Исключения:** Может бросить `std::bad_alloc`.
- **Безопасность в C++11:** Потокобезопасен.
