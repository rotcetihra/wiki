## Прототип

```cpp
#include <tuple>
template<class... Types>
struct tuple_size<tuple<Types...>>;
```

## Возвращаемое значение

`std::size_t` — количество элементов.

## Что делает

Метатип с размером кортежа.

## Примеры

### Базовое использование

```cpp
constexpr auto sz = std::tuple_size_v<std::tuple<int,double,char>>; // 3
```
