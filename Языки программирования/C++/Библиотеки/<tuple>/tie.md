## Прототип

```cpp
#include <tuple>
template<class... Types>
tuple<Types&...> tie(Types&... t) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `t` | переменные |

## Возвращаемое значение

Кортёж из ссылок.

## Что делает

Создаёт кортёж ссылок для распаковки.

## Примеры

### Базовое использование

```cpp
int a; double b;
std::tie(a, b) = std::make_tuple(1, 3.14);
```

## Исключения

- **Исключения:** Не бросает исключений (`noexcept`).
- **Безопасность в C++11:** Потокобезопасен.
