## Прототип

```cpp
#include <tuple>
template<size_t I, class... Types>
tuple_element_t<I, tuple<Types...>>& get(tuple<Types...>& t) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `I` | индекс элемента |

## Возвращаемое значение

Ссылка на элемент по индексу.

## Что делает

Доступ к элементу кортежа по индексу или типу.

## Примеры

### Базовое использование

```cpp
auto t = std::make_tuple(1, 3.14);
std::cout << std::get<0>(t) << std::endl; // 1
```

## Исключения

- **Исключения:** Не бросает исключений (`noexcept`).
- **Безопасность в C++11:** Потокобезопасен.
