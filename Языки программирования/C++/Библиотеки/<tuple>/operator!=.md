## Прототип

```cpp
#include <tuple>
template<class... T1, class... T2>
constexpr bool operator!=(const tuple<T1...>& x, const tuple<T2...>& y);
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | первый кортеж |
| `y` | второй кортеж |

## Возвращаемое значение

`bool`.

## Что делает

Лексикографическое сравнение на неравенство.

## Примеры

### Базовое использование

```cpp
auto a = std::make_tuple(1,2), b = std::make_tuple(3,4);
std::cout << (a != b) << std::endl; // true
```
