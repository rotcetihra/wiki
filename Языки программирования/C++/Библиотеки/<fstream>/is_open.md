## Прототип

```cpp
#include <fstream>
bool is_open() const;
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

`true`, если файл открыт успешно, иначе `false`.

## Что делает

Возвращает `true`, если файловый поток связан с открытым файлом.

## Примеры

### Базовое использование

```cpp
std::ifstream file("example.txt");
if (file.is_open()) {
    std::cout << "Файл открыт" << std::endl;
}
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
