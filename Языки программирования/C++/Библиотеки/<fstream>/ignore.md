## Прототип

```cpp
#include <fstream>
std::basic_istream& ignore(std::streamsize n = 1, int_type delim = Traits::eof());
```

## Параметры

| Параметр | Описание |
|---|---|
| `n` | Количество символов для пропуска |
| `delim` | Символ-разделитель пропуска |

## Возвращаемое значение

Возвращает ссылку на поток (`*this`).

## Что делает

Пропускает до `n` символов из потока.

## Примеры

### Базовое использование

```cpp
std::cin.ignore(10, '\n');  // Пропустить 10 символов или до '\n'
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
