## Прототип

```cpp
#include <fstream>
pos_type tellg();
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

Текущая позиция в потоке.

## Что делает

Возвращает текущую позицию чтения.

## Примеры

### Базовое использование

```cpp
std::ifstream file("example.txt");
std::streampos pos = file.tellg();
```
