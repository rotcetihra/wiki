## Прототип

```cpp
#include <fstream>
std::ios_base::exceptions exceptions() const;
void exceptions(std::ios_base::exceptions except);
```

## Параметры

| Параметр | Описание |
|---|---|
| `except` | Маска исключений для установки |

## Возвращаемое значение

Текущая маска исключений (или новая маска для setter).

## Что делает

Управляет маской исключений, которые бросаются при изменении состояния потока.

## Примеры

### Базовое использование

```cpp
std::ifstream file("example.txt");
file.exceptions(std::ios_base::failbit | std::ios_base::badbit);
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
