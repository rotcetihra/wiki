## Прототип

```cpp
#include <fstream>
explicit operator bool() const;
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

`true`, если поток в хорошем состоянии.

## Что делает

Позволяет использовать поток в булевом контексте. Возвращает `true`, если поток готов к операциям.

## Примеры

### Базовое использование

```cpp
std::ifstream file("example.txt");
if (file) {
    // Файл открыт и готов к чтению
}
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
