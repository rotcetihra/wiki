## Прототип

```cpp
#include <fstream>
void open(const char* filename, std::ios_base::openmode mode = std::ios_base::in);
```

## Параметры

| Параметр | Описание |
|---|---|
| `filename` | Имя файла для открытия |
| `mode` | Режим открытия (`std::ios_base::in`, `out`, `app` и т. д.) |

## Возвращаемое значение

Возвращает ссылку на поток (`*this`).

## Что делает

Открывает файл с заданным именем и режимом. Если файл уже открыт, вызов игнорируется.

## Примеры

### Базовое использование

```cpp
std::ifstream file;
file.open("example.txt", std::ios::in);
if (file.is_open()) {
    // Файл успешно открыт
}
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
