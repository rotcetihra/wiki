## Прототип

```cpp
#include <fstream>
bool eof() const;
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

`true`, если достигнут конец потока.

## Что делает

Возвращает `true`, если достигнут конец потока (`eofbit` установлен).

## Примеры

### Базовое использование

```cpp
std::ifstream file("example.txt");
int x;
while (file >> x) {}
if (file.eof()) {
    std::cout << "Достигнут конец файла" << std::endl;
}
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
