## Прототип

```cpp
#include <fstream>
using wfilebuf = std::basic_filebuf<wchar_t>;
```

## Описание

`std::wfilebuf` — это псевдоним типа для `std::basic_filebuf<wchar_t>`.

## Исключения

- **Исключения:** См. описание родительского класса.
