## Прототип

```cpp
#include <fstream>
void clear(std::ios_base::iostate state = std::ios_base::goodbit);
```

## Параметры

| Параметр | Описание |
|---|---|
| `state` | Состояние для установки (по умолчанию `goodbit`) |

## Возвращаемое значение

Возвращает ссылку на поток (`*this`).

## Что делает

Сбрасывает состояние потока. По умолчанию устанавливается `goodbit`.

## Примеры

### Базовое использование

```cpp
std::cout.clear();  // Сбросить состояние
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
