## Прототип

```cpp
#include <fstream>
std::streambuf* rdbuf() const;
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

Указатель на буфер потока.

## Что делает

Возвращает указатель на внутренний объект `std::filebuf` (или `std::stringbuf`).

## Примеры

### Базовое использование

```cpp
std::ifstream file("example.txt");
std::streambuf* buf = file.rdbuf();
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
