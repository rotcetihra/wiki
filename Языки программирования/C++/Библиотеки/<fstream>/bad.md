## Прототип

```cpp
#include <fstream>
bool bad() const;
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

`true`, если `badbit` установлен.

## Что делает

Возвращает `true`, если установлен `badbit`.

## Примеры

### Базовое использование

```cpp
std::ifstream file("example.txt");
// ... чтение ...
if (file.bad()) {
    std::cerr << "Критическая ошибка" << std::endl;
}
```

- **Исключения:** См. описание конкретного потока.
