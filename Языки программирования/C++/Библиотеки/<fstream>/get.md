## Прототип

```cpp
#include <fstream>
int_type get();
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

Символ в виде `int_type` или `traits::eof()` при ошибке.

## Что делает

Извлекает следующий символ из потока без его удаления из буфера.

## Примеры

### Базовое использование

```cpp
char c;
std::cin.get(c);
std::cout << "Прочитан: " << c << std::endl;
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
