## Прототип

```cpp
#include <fstream>
using ifstream = std::basic_ifstream<char>;
```

## Описание

`std::ifstream` — это псевдоним типа для `std::basic_ifstream<char>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
