## Прототип

```cpp
#include <fstream>
using wifstream = std::basic_ifstream<wchar_t>;
```

## Описание

`std::wifstream` — это псевдоним типа для `std::basic_ifstream<wchar_t>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
