## Прототип

```cpp
#include <fstream>
bool good() const;
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

`true`, если состояние потока `goodbit`.

## Что делает

Возвращает `true`, если состояние потока равно `goodbit`.

## Примеры

### Базовое использование

```cpp
std::ifstream file("example.txt");
if (file.good()) {
    std::cout << "Поток в хорошем состоянии" << std::endl;
}
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
