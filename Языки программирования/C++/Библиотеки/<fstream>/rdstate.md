## Прототип

```cpp
#include <fstream>
std::ios_base::iostate rdstate() const;
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

Текущее состояние потока.

## Что делает

Возвращает текущее состояние потока как комбинацию `goodbit`, `badbit`, `failbit`, `eofbit`.

## Примеры

### Базовое использование

```cpp
std::ios_base::iostate state = std::cout.rdstate();
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
