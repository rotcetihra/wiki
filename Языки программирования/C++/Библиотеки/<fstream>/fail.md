## Прототип

```cpp
#include <fstream>
bool fail() const;
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

`true`, если `failbit` или `badbit` установлен.

## Что делает

Возвращает `true`, если установлен `failbit` или `badbit`.

## Примеры

### Базовое использование

```cpp
std::ifstream file("nonexistent.txt");
if (file.fail()) {
    std::cerr << "Ошибка открытия файла" << std::endl;
}
```
