## Прототип

```cpp
#include <fstream>
using filebuf = std::basic_filebuf<char>;
```

## Описание

`std::filebuf` — это псевдоним типа для `std::basic_filebuf<char>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
