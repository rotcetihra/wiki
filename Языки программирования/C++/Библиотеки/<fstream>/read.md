## Прототип

```cpp
#include <fstream>
std::basic_istream& read(char_type* s, std::streamsize n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Указатель на буфер |
| `n` | Количество символов для чтения |

## Возвращаемое значение

Возвращает ссылку на поток (`*this`).

## Что делает

Читает блок данных из потока в указанный буфер.

## Примеры

### Базовое использование

```cpp
char buffer[100];
std::cin.read(buffer, 100);
std::streamsize n = std::cin.gcount();
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
