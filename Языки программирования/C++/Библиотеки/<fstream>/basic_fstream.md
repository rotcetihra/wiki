## Прототип

```cpp
#include <fstream>
template<class CharT, class Traits = std::char_traits<CharT>>
class basic_fstream : public std::basic_iostream<CharT, Traits>;
```

## Описание

Класс `std::basic_fstream` предоставляет функциональность двунаправленного потока для чтения и записи данных в файлы.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
