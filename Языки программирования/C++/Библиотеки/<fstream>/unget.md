## Прототип

```cpp
#include <fstream>
std::basic_istream& unget();
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

Возвращает ссылку на поток (`*this`).

## Что делает

Возвращает последний извлечённый символ в поток.

## Примеры

### Базовое использование

```cpp
char c;
std::cin.get(c);
std::cin.unget();
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
