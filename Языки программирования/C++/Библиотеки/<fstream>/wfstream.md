## Прототип

```cpp
#include <fstream>
using wfstream = std::basic_fstream<wchar_t>;
```

## Описание

`std::wfstream` — это псевдоним типа для `std::basic_fstream<wchar_t>`.

## Исключения

- **Исключения:** См. описание родительского класса.
