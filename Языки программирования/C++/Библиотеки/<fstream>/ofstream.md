## Прототип

```cpp
#include <fstream>
using ofstream = std::basic_ofstream<char>;
```

## Описание

`std::ofstream` — это псевдоним типа для `std::basic_ofstream<char>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
