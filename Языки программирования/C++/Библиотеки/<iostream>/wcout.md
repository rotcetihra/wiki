## Прототип

```cpp
#include <iostream>
extern std::wostream wcout;
```

## Параметры

Объект (не функция, параметры отсутствуют).

## Возвращаемое значение

Глобальный объект потока.

## Что делает

Широкосимвольный аналог `std::cout`.

## Примеры

### Базовое использование

```cpp
std::wcout << L"Привет, мир!" << std::endl;
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
