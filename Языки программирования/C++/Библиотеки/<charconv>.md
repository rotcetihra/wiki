## Описание библиотеки

Заголовочный файл `<charconv>` определяет функции для преобразования между числовыми значениями и их текстовым представлением. Эти функции работают с сырыми символьными диапазонами (указателями) и оптимизированы для максимальной производительности.

## Исключения

- **Исключения:** функции не бросают исключений.
- **Безопасность:** `from_chars` возвращает `std::errc` вместо бросания исключений; `to_chars` не переполняет буфер — размер буфера определяется вызывающим кодом.
