## Прототип

```cpp
#include <format>
template<class Visitor, class Context>
declored(auto) visit_format_arg(Visitor&& vis, basic_format_arg<Context> arg);
```

## Параметры

| Параметр | Описание |
|---|---|
| `vis` | визитор |
| `arg` | аргумент форматирования |

## Возвращаемое значение

Результат вызова `vis`.

## Что делает

**Устарело в C++26.** Вызывает визитор с значением аргумента форматирования.
