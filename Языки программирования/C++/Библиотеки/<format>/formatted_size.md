## Прототип

```cpp
#include <format>
template<class... Args>
size_t formatted_size(format_string<Args...> fmt, Args&&... args);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fmt` | форматная строка |
| `args` | аргументы |

## Возвращаемое значение

Количество символов в отформатированной строке.

## Что делает

Возвращает количество символов, необходимых для хранения отформатированного представления.

## Примеры

### Базовое использование

```cpp
size_t sz = std::formatted_size("Hello, {}!", "World");
std::cout << sz << std::endl; // 13
```

## Исключения

- **Исключения:** Бросает `std::format_error` при ошибке форматирования.
