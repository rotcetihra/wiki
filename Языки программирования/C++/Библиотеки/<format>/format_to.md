## Прототип

```cpp
#include <format>
template<class Out, class... Args>
Out format_to(Out out, format_string<Args...> fmt, Args&&... args);
```

## Параметры

| Параметр | Описание |
|---|---|
| `out` | выходной итератор |
| `fmt` | форматная строка |
| `args` | аргументы |

## Возвращаемое значение

Итератор после последнего записанного символа.

## Что делает

Записывает отформатированное представление через выходной итератор.

## Примеры

### Базовое использование

```cpp
std::vector<char> buf(20);
auto result = std::format_to(buf.begin(), "Value: {}", 42);
std::string s(buf.begin(), result);
std::cout << s << std::endl; // Value: 42
```

## Исключения

- **Исключения:** Бросает `std::format_error` при ошибке форматирования.
