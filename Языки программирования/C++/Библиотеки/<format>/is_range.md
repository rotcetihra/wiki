## Прототип

```cpp
#include <format>
template<class T>
concept is_range = /* see description */;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | проверяемый тип |

## Возвращаемое значение

Концепт: `true`, если тип является диапазоном.

## Что делает

Концепт `is_range` определяет, что тип имеет `begin()` и `end()`. Используется для форматирования диапазонов (C++23).

## Примеры

### Базовое использование

```cpp
static_assert(std::is_range<std::vector<int>>);
static_assert(!std::is_range<int>);
```
