## Прототип

```cpp
#include <fnmatch.h>\nint fnmatch(const char *pattern, const char *string, int flags);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pattern` | шаблон |\n| `string` | строка |\n| `flags` | флаги (0, FNM_PATHNAME) |
## Возвращаемое значение

0 при совпадении, FNM_NOMATCH.

## Что делает

Сопоставляет имя файла с шаблоном.

## Примеры

### Базовое использование

```cpp
if (fnmatch("*.txt", "a.txt", 0) == 0) printf("match");
```
