## Описание библиотеки

Заголовочный файл `<print>` определяет функции для форматированного вывода данных. Он предоставляет функции `std::print` и `std::println`, которые являются более удобной и безопасной альтернативой `std::cout <<` и `printf`. Функции используют форматную строку из заголовка `<format>`.

## Исключения

- **Исключения:** Функции могут бросать исключения `std::format_error` при ошибке форматирования или `std::ios_base::failure` при ошибке вывода.
- **Безопасность в C++11:** Вызовы функций из разных потоков безопасны (каждый вызов — атомарная операция вывода).
