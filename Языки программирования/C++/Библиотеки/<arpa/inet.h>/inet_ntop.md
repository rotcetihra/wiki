## Прототип

```cpp
#include <arpa/inet.h>\nconst char *inet_ntop(int af, const void *src, char *dst, socklen_t size);
```

## Параметры

| Параметр | Описание |
|---|---|
| `af` | AF_INET или AF_INET6 |\n| `src` | указатель на адрес |\n| `dst` | буфер для строки |\n| `size` | размер буфера |
## Возвращаемое значение

Указатель на dst или NULL.

## Что делает

Преобразует адрес из числового представления в строку.

## Примеры

### Базовое использование

```cpp
char str[INET6_ADDRSTRLEN];\ninet_ntop(AF_INET, &addr, str, sizeof(str));
```

## Исключения

- **Исключения:** Возвращает NULL при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
