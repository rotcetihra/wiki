## Прототип

```cpp
#include <arpa/inet.h>\nint inet_pton(int af, const char *src, void *dst);
```

## Параметры

| Параметр | Описание |
|---|---|
| `af` | AF_INET или AF_INET6 |\n| `src` | строка с адресом |\n| `dst` | указатель для результата |
## Возвращаемое значение

1 при успехе, 0 при неверном формате, -1 при ошибке.

## Что делает

Преобразует строку с адресом в числовое представление.

## Примеры

### Базовое использование

```cpp
struct in_addr addr;\ninet_pton(AF_INET, "192.168.1.1", &addr);
```

## Исключения

- **Исключения:** Возвращает 0 или -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
