## Прототип

```cpp
#include <new>
struct nothrow_t;
constexpr nothrow_t nothrow;
```

## Возвращаемое значение

Не применимо (это константа).

## Что делает

Маркер для выделения без исключений.

## Примеры

### Базовое использование

```cpp
int* p = new (std::nothrow) int[1000000000000];
if (p == nullptr) std::cout << "Ошибка" << std::endl;
```

## Исключения

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасен.
