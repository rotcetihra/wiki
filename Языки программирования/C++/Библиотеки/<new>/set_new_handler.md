## Прототип

```cpp
#include <new>
new_handler set_new_handler(new_handler handler) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `handler` | новый обработчик |

## Возвращаемое значение

Предыдущий обработчик.

## Что делает

Устанавливает обработчик ошибок выделения памяти.

## Примеры

### Базовое использование

```cpp
std::set_new_handler([](){
    std::cerr << "Недостаточно памяти!" << std::endl;
    std::abort();
});
```

## Исключения

- **Исключения:** Не бросает исключений (`noexcept`).
- **Безопасность в C++11:** Потокобезопасен.
