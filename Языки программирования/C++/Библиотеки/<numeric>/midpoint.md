## Прототип

```cpp
#include <numeric>
template<class T>
constexpr T midpoint(T a, T b) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `a` | первое значение |
| `b` | второе значение |

## Возвращаемое значение

`T` — среднее значение.

## Что делает

Середина без переполнения (C++20).

## Примеры

### Базовое использование

```cpp
std::cout << std::midpoint(10, 20) << std::endl; // 15
```

## Исключения

- **Исключения:** Не бросает исключений (`noexcept`).
- **Безопасность в C++11:** Потокобезопасен.
