## Прототип

```cpp
#include <numeric>
template<class T>
constexpr T lerp(T a, T b, T t) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `a` | начальное значение |
| `b` | конечное значение |
| `t` | параметр [0,1] |

## Возвращаемое значение

`T` — результат интерполяции.

## Что делает

Линейная интерполяция (C++20).

## Примеры

### Базовое использование

```cpp
std::cout << std::lerp(0.0, 10.0, 0.5) << std::endl; // 5.0
```

- **Исключения:** Не бросает исключений (`noexcept`).
