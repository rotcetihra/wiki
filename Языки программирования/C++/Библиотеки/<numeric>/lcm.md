## Прототип

```cpp
#include <numeric>
template<class M, class N>
constexpr std::common_type_t<M, N> lcm(M m, N n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `m` | первое число |
| `n` | второе число |

## Возвращаемое значение

`std::common_type_t<M, N>` — НОК.

## Что делает

Наименьшее общее кратное (C++17).

## Примеры

### Базовое использование

```cpp
std::cout << std::lcm(12, 8) << std::endl; // 24
```
