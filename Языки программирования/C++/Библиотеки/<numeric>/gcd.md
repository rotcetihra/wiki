## Прототип

```cpp
#include <numeric>
template<class M, class N>
constexpr std::common_type_t<M, N> gcd(M m, N n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `m` | первое число |
| `n` | второе число |

## Возвращаемое значение

`std::common_type_t<M, N>` — НОД.

## Что делает

Наибольший общий делитель (C++17).

## Примеры

### Базовое использование

```cpp
std::cout << std::gcd(12, 8) << std::endl; // 4
```
