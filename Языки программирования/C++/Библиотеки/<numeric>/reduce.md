## Прототип

```cpp
#include <numeric>
template<class InputIt>
typename iterator_traits<InputIt>::value_type reduce(InputIt first, InputIt last);
```

## Параметры

| Параметр | Описание |
|---|---|
| `first` | начало |
| `last` | конец |

## Возвращаемое значение

Значение — результат редукции.

## Что делает

Параллельная свёртка (C++17).

## Примеры

### Базовое использование

```cpp
std::vector<int> v = {1,2,3,4,5};
int sum = std::reduce(v.begin(), v.end()); // 15
```
