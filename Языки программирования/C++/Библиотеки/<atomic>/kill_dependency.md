## Прототип

```cpp
#include <atomic>

template<class T>
T kill_dependency(T y) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `y` | Значение для разрыва цепочки |

## Возвращаемое значение

`y`.

## Что делает

Разрывает цепочку зависимостей порядка вычислений (sequence before). Используется для оптимизации в сложных цепочках атомарных операций.

## Примеры

```cpp
#include <atomic>

int main()
{
    int a = 1;
    int b = std::kill_dependency(a);
    // b гарантированно не зависит от a для целей order
}
```
