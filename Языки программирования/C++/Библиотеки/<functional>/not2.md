## Прототип

```cpp
#include <functional>
template<class Operation>
/* unspecified */ not2(const Operation& op);
```

## Параметры

| Параметр | Описание |
|---|---|
| `op` | бинарный предикат |

## Возвращаемое значение

Инвертирующий бинарный предикат.

## Что делает

`std::not2` — инвертирует результат бинарного предиката (устарел).

## Примеры

### Базовое использование

```cpp
auto less = std::less<int>{};
auto not_less = std::not2(less);
std::cout << not_less(3, 2) << std::endl; // true
```
