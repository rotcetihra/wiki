## Прототип

```cpp
#include <functional>
template<class T = void>
struct plus;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`T` — Результат сложения.

## Что делает

`std::plus` — объект-оператор для оператор сложения.

## Примеры

### Базовое использование

```cpp
std::plus<int> add;
std::cout << add(3, 4) << std::endl; // 7
```
