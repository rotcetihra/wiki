## Прототип

```cpp
#include <functional>
template<class T = void>
struct modulus;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`T` — Остаток от деления.

## Что делает

`std::modulus` — объект-оператор для оператор остатка.

## Примеры

### Базовое использование

```cpp
std::modulus<int> mod;
std::cout << mod(10, 3) << std::endl; // 1
```
