## Прототип

```cpp
#include <functional>
template<class T = void>
struct logical_not;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`bool` — Результат логического НЕ.

## Что делает

`std::logical_not` — объект-оператор для логическое НЕ.

## Примеры

### Базовое использование

```cpp
std::logical_not<bool> not_op;
std::cout << std::boolalpha << not_op(false) << std::endl; // true
```
