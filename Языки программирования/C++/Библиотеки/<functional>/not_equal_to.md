## Прототип

```cpp
#include <functional>
template<class T = void>
struct not_equal_to;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`bool` — Результат сравнения.

## Что делает

`std::not_equal_to` — объект-оператор для оператор неравенства.

## Примеры

### Базовое использование

```cpp
std::not_equal_to<int> ne;
std::cout << std::boolalpha << ne(5, 3) << std::endl; // true
```
