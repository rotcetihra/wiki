## Прототип

```cpp
#include <functional>
template<class T = void>
struct bit_not;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`T` — Результат побитового НЕ.

## Что делает

`std::bit_not` — объект-оператор для побитовое НЕ.

## Примеры

### Базовое использование

```cpp
std::bit_not<int> bnot;
std::cout << bnot(0b1010) << std::endl;
```
