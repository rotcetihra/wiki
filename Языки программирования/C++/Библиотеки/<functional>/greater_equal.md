## Прототип

```cpp
#include <functional>
template<class T = void>
struct greater_equal;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`bool` — Результат сравнения >=.

## Что делает

`std::greater_equal` — объект-оператор для оператор >=.

## Примеры

### Базовое использование

```cpp
std::greater_equal<int> ge;
std::cout << std::boolalpha << ge(5, 5) << std::endl; // true
```
