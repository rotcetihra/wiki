## Прототип

```cpp
#include <functional>
template<class T = void>
struct divides;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`T` — Результат деления.

## Что делает

`std::divides` — объект-оператор для оператор деления.

## Примеры

### Базовое использование

```cpp
std::divides<int> div;
std::cout << div(10, 3) << std::endl; // 3
```
