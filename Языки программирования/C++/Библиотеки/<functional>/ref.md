## Прототип

```cpp
#include <functional>
template<class T>
reference_wrapper<T> ref(T& t) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `t` | объект для оборачивания в ссылку |

## Возвращаемое значение

`std::reference_wrapper<T>` — обёртка над ссылкой.

## Что делает

`std::ref` — создаёт обёртку для передачи по ссылке.

## Примеры

### Базовое использование

```cpp
int x = 10;
auto inc = std::bind([](int& v) { ++v; }, std::ref(x));
inc();
std::cout << x << std::endl; // 11
```
