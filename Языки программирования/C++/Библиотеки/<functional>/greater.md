## Прототип

```cpp
#include <functional>
template<class T = void>
struct greater;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`bool` — Результат сравнения >.

## Что делает

`std::greater` — объект-оператор для оператор больше.

## Примеры

### Базовое использование

```cpp
std::greater<int> gt;
std::cout << std::boolalpha << gt(5, 3) << std::endl; // true
```
