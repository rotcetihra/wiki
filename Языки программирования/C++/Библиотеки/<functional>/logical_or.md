## Прототип

```cpp
#include <functional>
template<class T = void>
struct logical_or;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`bool` — Результат логического ИЛИ.

## Что делает

`std::logical_or` — объект-оператор для логическое ИЛИ.

## Примеры

### Базовое использование

```cpp
std::logical_or<bool> or_op;
std::cout << std::boolalpha << or_op(true, false) << std::endl; // true
```
