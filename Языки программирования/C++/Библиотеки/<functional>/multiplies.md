## Прототип

```cpp
#include <functional>
template<class T = void>
struct multiplies;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`T` — Результат умножения.

## Что делает

`std::multiplies` — объект-оператор для оператор умножения.

## Примеры

### Базовое использование

```cpp
std::multiplies<int> mul;
std::cout << mul(3, 4) << std::endl; // 12
```
