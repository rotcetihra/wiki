## Прототип

```cpp
#include <functional>
template<class T = void>
struct negate;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`T` — Результат смены знака.

## Что делает

`std::negate` — объект-оператор для оператор смены знака.

## Примеры

### Базовое использование

```cpp
std::negate<int> neg;
std::cout << neg(5) << std::endl; // -5
```
