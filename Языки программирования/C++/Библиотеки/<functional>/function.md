## Прототип

```cpp
#include <functional>
template<class R, class... ArgTypes>
class function<R(ArgTypes...)>;
```

## Параметры

| Параметр | Описание |
|---|---|
| `R` | тип возвращаемого значения |
| `ArgTypes` | типы аргументов |

## Возвращаемое значение

Объект, оборачивающий callable.

## Что делает

`std::function` — универсальная обёртка для callable-объектов.

## Примеры

### Базовое использование

```cpp
std::function<int(int, int)> add = [](int a, int b) { return a + b; };
std::cout << add(2, 3) << std::endl; // 5
```

## Исключения

- **Исключения:** `bad_function_call` при вызове пустой обёртки.
- **Безопасность в C++11:** Не является потокобезопасным.
