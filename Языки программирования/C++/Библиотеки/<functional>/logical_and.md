## Прототип

```cpp
#include <functional>
template<class T = void>
struct logical_and;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`bool` — Результат логического И.

## Что делает

`std::logical_and` — объект-оператор для логическое И.

## Примеры

### Базовое использование

```cpp
std::logical_and<bool> and_op;
std::cout << std::boolalpha << and_op(true, false) << std::endl; // false
```
