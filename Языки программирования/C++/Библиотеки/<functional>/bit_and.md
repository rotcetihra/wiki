## Прототип

```cpp
#include <functional>
template<class T = void>
struct bit_and;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`T` — Результат побитового И.

## Что делает

`std::bit_and` — объект-оператор для побитовое И.

## Примеры

### Базовое использование

```cpp
std::bit_and<int> band;
std::cout << band(0b1100, 0b1010) << std::endl; // 8
```
