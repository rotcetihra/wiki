## Прототип

```cpp
#include <functional>
template<class T>
struct hash;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип значения для хеширования |

## Возвращаемое значение

`std::size_t` — хеш-код.

## Что делает

`std::hash` — шаблон хеш-функции.

## Примеры

### Базовое использование

```cpp
std::hash<std::string> hasher;
std::cout << hasher("hello") << std::endl;
```
