## Прототип

```cpp
#include <functional>
template<class F, class... BoundArgs>
/* unspecified */ bind(F&& f, BoundArgs&&... bound_args);
```

## Параметры

| Параметр | Описание |
|---|---|
| `f` | функция |
| `bound_args` | аргументы для привязки |

## Возвращаемое значение

Объект-обёртка.

## Что делает

`std::bind` — создаёт обёртку с фиксированными аргументами.

## Примеры

### Базовое использование

```cpp
auto add = [](int a, int b, int c) { return a + b + c; };
auto add5 = std::bind(add, 5, std::placeholders::_1, std::placeholders::_2);
std::cout << add5(3, 7) << std::endl; // 15
```

## Исключения

- **Исключения:** Зависит от вызываемой функции.
- **Безопасность в C++11:** Не является потокобезопасным.
