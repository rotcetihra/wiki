## Прототип

```cpp
#include <functional>
template<class T = void>
struct minus;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`T` — Результат вычитания.

## Что делает

`std::minus` — объект-оператор для оператор вычитания.

## Примеры

### Базовое использование

```cpp
std::minus<int> sub;
std::cout << sub(10, 3) << std::endl; // 7
```
