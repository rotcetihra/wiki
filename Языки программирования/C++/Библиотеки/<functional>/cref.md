## Прототип

```cpp
#include <functional>
template<class T>
reference_wrapper<const T> cref(const T& t) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `t` | константный объект |

## Возвращаемое значение

`std::reference_wrapper<const T>` — обёртка.

## Что делает

`std::cref` — аналог `std::ref` для константных объектов.

## Примеры

### Базовое использование

```cpp
const int x = 10;
auto get = std::bind([](const int& v) { return v; }, std::cref(x));
std::cout << get() << std::endl; // 10
```
