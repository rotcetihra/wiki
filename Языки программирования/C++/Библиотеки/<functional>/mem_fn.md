## Прототип

```cpp
#include <functional>
template<class R, class T>
/* unspecified */ mem_fn(R T::* pm) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `pm` | указатель на член класса |

## Возвращаемое значение

Объект-обёртка для вызова метода.

## Что делает

`std::mem_fn` — создаёт обёртку для вызова метода.

## Примеры

### Базовое использование

```cpp
struct Person { std::string name; };
auto get_name = std::mem_fn(&Person::name);
Person p{"Алиса"};
std::cout << get_name(p) << std::endl;
```
