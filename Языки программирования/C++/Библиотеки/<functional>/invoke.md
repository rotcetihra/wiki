## Прототип

```cpp
#include <functional>
template<class F, class... Args>
std::invoke_result_t<F, Args...> invoke(F&& f, Args&&... args) noexcept(/*...*/);
```

## Параметры

| Параметр | Описание |
|---|---|
| `f` | вызываемый объект |
| `args` | аргументы вызова |

## Возвращаемое значение

Результат вызова `f(args...)`.

## Что делает

`std::invoke` — обобщённый вызов callable.

## Примеры

### Базовое использование

```cpp
auto add = [](int a, int b) { return a + b; };
std::cout << std::invoke(add, 2, 3) << std::endl; // 5
```

## Исключения

- **Исключения:** Зависит от вызываемого объекта.
- **Безопасность в C++11:** Потокобезопасен.
