## Прототип

```cpp
#include <functional>
template<class T = void>
struct less_equal;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`bool` — Результат сравнения <=.

## Что делает

`std::less_equal` — объект-оператор для оператор <=.

## Примеры

### Базовое использование

```cpp
std::less_equal<int> le;
std::cout << std::boolalpha << le(3, 5) << std::endl; // true
```
