## Прототип

```cpp
#include <functional>
template<class T = void>
struct bit_or;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`T` — Результат побитового ИЛИ.

## Что делает

`std::bit_or` — объект-оператор для побитовое ИЛИ.

## Примеры

### Базовое использование

```cpp
std::bit_or<int> bor;
std::cout << bor(0b1100, 0b1010) << std::endl; // 14
```
