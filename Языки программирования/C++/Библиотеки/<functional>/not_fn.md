## Прототип

```cpp
#include <functional>
template<class F>
/* unspecified */ not_fn(F&& f);
```

## Параметры

| Параметр | Описание |
|---|---|
| `f` | унарный предикат для инвертирования |

## Возвращаемое значение

Инвертирующий предикат.

## Что делает

`std::not_fn` (C++17) — инвертирует результат вызова.

## Примеры

### Базовое использование

```cpp
auto is_positive = [](int x) { return x > 0; };
auto is_not_positive = std::not_fn(is_positive);
std::cout << is_not_positive(-5) << std::endl; // true
```
