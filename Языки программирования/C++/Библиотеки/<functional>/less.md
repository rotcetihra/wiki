## Прототип

```cpp
#include <functional>
template<class T = void>
struct less;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип операндов |

## Возвращаемое значение

`bool` — Результат сравнения <.

## Что делает

`std::less` — объект-оператор для оператор меньше.

## Примеры

### Базовое использование

```cpp
std::less<int> lt;
std::cout << std::boolalpha << lt(3, 5) << std::endl; // true
```
