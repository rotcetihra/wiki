## Описание библиотеки

Заголовочный файл `<bit>` определяет набор функций для битовых манипуляций с целочисленными типами. Все функции constexpr и оптимизируются компилятором до соответствующих машинных инструкций.

## Исключения

- **Исключения:** все функции — noexcept.
- **Безопасность:** функции работают только с беззнаковыми целочисленными типами.

## Стандарты

C++20, C++23.
