## Прототип

```cpp
#include <memory>
template<class T>
class shared_ptr;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип объекта |

## Возвращаемое значение

Не применимо (это тип).

## Что делает

Разделяемый умный указатель с подсчётом ссылок.

## Примеры

### Базовое использование

```cpp
auto p1 = std::make_shared<int>(42);
auto p2 = p1;
std::cout << *p2 << std::endl; // 42
```

## Исключения

- **Исключения:** Может бросить `std::bad_alloc`.
- **Безопасность в C++11:** Счётчик ссылок потокобезопасен.
