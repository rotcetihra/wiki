## Прототип

```cpp
#include <memory>
template<class T>
class weak_ptr;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип объекта |

## Возвращаемое значение

Не применимо (это тип).

## Что делает

Слабый указатель, не увеличивающий счётчик ссылок.

## Примеры

### Базовое использование

```cpp
std::weak_ptr<int> wp;
{ auto sp = std::make_shared<int>(42); wp = sp; }
auto sp2 = wp.lock();
```

## Исключения

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасен.
