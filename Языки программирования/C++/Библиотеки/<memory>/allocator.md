## Прототип

```cpp
#include <memory>
template<class T>
class allocator;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип выделяемых объектов |

## Возвращаемое значение

Не применимо (это тип).

## Что делает

Стандартный аллокатор по умолчанию.

## Примеры

### Базовое использование

```cpp
std::allocator<int> alloc;
int* p = alloc.allocate(10);
alloc.deallocate(p, 10);
```

## Исключения

- **Исключения:** `std::bad_alloc` при нехватке памяти.
- **Безопасность в C++11:** Не является потокобезопасным.
