## Прототип

```cpp
#include <memory>
template<class T>
struct owner_less;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип умного указателя |

## Возвращаемое значение

`bool` — результат сравнения.

## Что делает

Сравнение умных указателей по владельцу.

## Примеры

### Базовое использование

```cpp
auto sp = std::make_shared<int>(1);
std::owner_less<std::shared_ptr<int>> less;
```
