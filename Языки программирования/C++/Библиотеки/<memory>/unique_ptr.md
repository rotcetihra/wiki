## Прототип

```cpp
#include <memory>
template<class T, class Deleter = default_delete<T>>
class unique_ptr;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип объекта |
| `Deleter` | тип удалителя |

## Возвращаемое значение

Не применимо (это тип).

## Что делает

Умный указатель с единоличным владением.

## Примеры

### Базовое использование

```cpp
auto p = std::make_unique<int>(42);
std::cout << *p << std::endl; // 42
```
