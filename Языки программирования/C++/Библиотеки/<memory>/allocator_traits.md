## Прототип

```cpp
#include <memory>
template<class Alloc>
struct allocator_traits;
```

## Параметры

| Параметр | Описание |
|---|---|
| `Alloc` | тип аллокатора |

## Возвращаемое значение

Не применимо (это метатип).

## Что делает

Интерфейс к аллокатору.

## Примеры

### Базовое использование

```cpp
using T = std::allocator_traits<std::allocator<int>>::value_type;
```

## Исключения

- **Исключения:** Зависит от аллокатора.
- **Безопасность в C++11:** Потокобезопасен.
