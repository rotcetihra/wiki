## Прототип

```cpp
#include <memory>
template<class ForwardIt>
void uninitialized_fill(ForwardIt first, ForwardIt last);
```

## Параметры

| Параметр | Описание |
|---|---|
| `first` | начало диапазона |
| `last` | конец диапазона |

## Возвращаемое значение

Ничего не возвращает.

## Что делает

Заполнение неинициализированной памяти

## Примеры

### Базовое использование

```cpp
alignas(int) char buf[5*sizeof(int)];
auto f = reinterpret_cast<int*>(buf);
std::uninitialized_fill(f, f+5, 42);
```

## Исключения

- **Исключения:** Выбрасывает при ошибке.
- **Безопасность в C++11:** Не является потокобезопасным.
