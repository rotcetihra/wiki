## Прототип

```cpp
#include <memory>
template<class T>
pair<T*, ptrdiff_t> get_temporary_buffer(ptrdiff_t n) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `n` | количество элементов |

## Возвращаемое значение

`std::pair<T*, ptrdiff_t>` — указатель и размер.

## Что делает

Временный буфер для n элементов.

## Примеры

### Базовое использование

```cpp
auto [buf, count] = std::get_temporary_buffer<int>(100);
if (count > 0) std::return_temporary_buffer(buf);
```

## Исключения

- **Исключения:** Не бросает исключений (`noexcept`).
- **Безопасность в C++11:** Потокобезопасен.
