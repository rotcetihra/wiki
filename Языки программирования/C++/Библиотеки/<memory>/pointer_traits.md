## Прототип

```cpp
#include <memory>
template<class Ptr>
struct pointer_traits;
```

## Параметры

| Параметр | Описание |
|---|---|
| `Ptr` | тип указателя |

## Возвращаемое значение

Не применимо (это метатип).

## Что делает

Информация о свойствах указателя.

## Примеры

### Базовое использование

```cpp
using T = std::pointer_traits<int*>::element_type; // int
```
