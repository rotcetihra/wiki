## Прототип

```cpp
#include <memory>
template<class OutputIt, class T>
class raw_storage_iterator;
```

## Параметры

| Параметр | Описание |
|---|---|
| `OutputIt` | тип итератора |
| `T` | тип элемента |

## Возвращаемое значение

Не применимо (это тип).

## Что делает

Итератор для записи в неинициализированную память.

## Примеры

### Базовое использование

```cpp
char buf[100];
std::raw_storage_iterator<int*> it(reinterpret_cast<int*>(buf));
*it = 42;
```
