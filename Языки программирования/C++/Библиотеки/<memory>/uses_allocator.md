## Прототип

```cpp
#include <memory>
template<class T, class Alloc>
struct uses_allocator;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип контейнера |
| `Alloc` | тип аллокатора |

## Возвращаемое значение

`std::true_type` или `std::false_type`.

## Что делает

Определяет, использует ли тип аллокатор.

## Примеры

### Базовое использование

```cpp
constexpr bool u = std::uses_allocator<std::vector<int>, std::allocator<int>>::value;
```

## Исключения

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасен.
