## Прототип

```cpp
#include <memory>
template<class T>
class enable_shared_from_this;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип класса |

## Возвращаемое значение

Не применимо (это тип).

## Что делает

Базовый класс для безопасного создания shared_ptr из this.

## Примеры

### Базовое использование

```cpp
struct MyClass : std::enable_shared_from_this<MyClass> {};
```

## Исключения

- **Исключения:** `bad_weak_ptr` при вызове без shared_ptr.
- **Безопасность в C++11:** Потокобезопасен.
