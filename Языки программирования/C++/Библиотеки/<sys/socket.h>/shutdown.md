## Прототип

```cpp
#include <sys/socket.h>\nint shutdown(int sockfd, int how);
```

## Параметры

| Параметр | Описание |
|---|---|
| `sockfd` | файловый дескриптор сокета |
| `how` | какую сторону закрыть (SHUT_RD, SHUT_WR, SHUT_RDWR) |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Закрывает одну или обе стороны дуплексного соединения.

## Примеры

### Базовое использование

```cpp
shutdown(sockfd, SHUT_WR);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
