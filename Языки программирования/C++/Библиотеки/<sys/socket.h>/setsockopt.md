## Прототип

```cpp
#include <sys/socket.h>\nint setsockopt(int sockfd, int level, int optname, const void *optval, socklen_t optlen);
```

## Параметры

| Параметр | Описание |
|---|---|
| `sockfd` | файловый дескриптор сокета |
| `level` | уровень |
| `optname` | имя опции |
| `optval` | значение опции |
| `optlen` | размер значения |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Устанавливает значение опции сокета.

## Примеры

### Базовое использование

```cpp
int optval = 1;\nsetsockopt(sockfd, SOL_SOCKET, SO_REUSEADDR, &optval, sizeof(optval));
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
