## Прототип

```cpp
#include <sys/socket.h>\nssize_t send(int sockfd, const void *buf, size_t len, int flags);
```

## Параметры

| Параметр | Описание |
|---|---|
| `sockfd` | файловый дескриптор сокета |
| `buf` | данные для отправки |
| `len` | количество байт |
| `flags` | флаги (0, MSG_DONTWAIT, MSG_NOSIGNAL) |
## Возвращаемое значение

Количество отправленных байт или -1 при ошибке.

## Что делает

Отправляет данные через соединённый сокет.

## Примеры

### Базовое использование

```cpp
send(sockfd, "Hello", 5, 0);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
