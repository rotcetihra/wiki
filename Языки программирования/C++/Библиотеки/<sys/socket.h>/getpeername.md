## Прототип

```cpp
#include <sys/socket.h>\nint getpeername(int sockfd, struct sockaddr *addr, socklen_t *addrlen);
```

## Параметры

| Параметр | Описание |
|---|---|
| `sockfd` | файловый дескриптор сокета |
| `addr` | адрес для результата |
| `addrlen` | размер структуры |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Возвращает адрес удалённого узла, с которым установлено соединение.

## Примеры

### Базовое использование

```cpp
struct sockaddr_in addr;\nsocklen_t len = sizeof(addr);\ngetpeername(sockfd, (struct sockaddr *)&addr, &len);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
