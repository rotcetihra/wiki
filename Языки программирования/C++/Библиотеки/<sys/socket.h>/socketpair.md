## Прототип

```cpp
#include <sys/socket.h>\nint socketpair(int domain, int type, int protocol, int sv[2]);
```

## Параметры

| Параметр | Описание |
|---|---|
| `domain` | семейство протоколов (AF_UNIX) |
| `type` | тип (SOCK_STREAM, SOCK_DGRAM) |
| `protocol` | протокол (0) |
| `sv` | массив из двух дескрипторов |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Создаёт пару связанных сокетов, которые можно использовать для межпроцессного взаимодействия.

## Примеры

### Базовое использование

```cpp
int sv[2];\nsocketpair(AF_UNIX, SOCK_STREAM, 0, sv);\nwrite(sv[0], "hello", 5);\nchar buf[1024];\nread(sv[1], buf, sizeof(buf));
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
