## Прототип

```cpp
#include <sys/socket.h>\nint connect(int sockfd, const struct sockaddr *addr, socklen_t addrlen);
```

## Параметры

| Параметр | Описание |
|---|---|
| `sockfd` | файловый дескриптор сокета |
| `addr` | адрес сервера |
| `addrlen` | размер структуры адреса |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Устанавливает соединение с удалённым сервером.

## Примеры

### Базовое использование

```cpp
struct sockaddr_in addr;\naddr.sin_family = AF_INET;\naddr.sin_port = htons(80);\naddr.sin_addr.s_addr = inet_addr("93.184.216.34");\nconnect(sockfd, (struct sockaddr *)&addr, sizeof(addr));
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
