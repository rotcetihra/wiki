## Прототип

```cpp
#include <sys/socket.h>\nint socket(int domain, int type, int protocol);
```

## Параметры

| Параметр | Описание |
|---|---|
| `domain` | семейство протоколов (AF_INET, AF_UNIX, AF_INET6) |
| `type` | тип сокета (SOCK_STREAM, SOCK_DGRAM, SOCK_RAW) |
| `protocol` | протокол (0 — автоматически) |
## Возвращаемое значение

Файловый дескриптор сокета или -1 при ошибке.

## Что делает

Создаёт сетевой сокет и возвращает его дескриптор.

## Примеры

### Базовое использование

```cpp
int sockfd = socket(AF_INET, SOCK_STREAM, 0);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
