## Прототип

```cpp
#include <sys/socket.h>\nint listen(int sockfd, int backlog);
```

## Параметры

| Параметр | Описание |
|---|---|
| `sockfd` | файловый дескриптор сокета |
| `backlog` | максимальная длина очереди соединений |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Переводит сокет в режим прослушивания входящих соединений.

## Примеры

### Базовое использование

```cpp
listen(sockfd, 10);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
