## Прототип

```cpp
#include <sys/socket.h>\nssize_t recv(int sockfd, void *buf, size_t len, int flags);
```

## Параметры

| Параметр | Описание |
|---|---|
| `sockfd` | файловый дескриптор сокета |
| `buf` | буфер для данных |
| `len` | размер буфера |
| `flags` | флаги (0, MSG_PEEK, MSG_DONTWAIT) |
## Возвращаемое значение

Количество полученных байт, 0 при закрытии соединения, -1 при ошибке.

## Что делает

Читает данные из соединённого сокета.

## Примеры

### Базовое использование

```cpp
char buf[1024];\nssize_t n = recv(sockfd, buf, sizeof(buf), 0);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
