## Прототип

```cpp
#include <sys/socket.h>\nint accept(int sockfd, struct sockaddr *addr, socklen_t *addrlen);
```

## Параметры

| Параметр | Описание |
|---|---|
| `sockfd` | файловый дескриптор сокета |
| `addr` | адрес клиента (или NULL) |
| `addrlen` | размер структуры адреса |
## Возвращаемое значение

Файловый дескриптор нового сокета или -1 при ошибке.

## Что делает

Принимает входящее соединение и создаёт новый сокет для общения с клиентом.

## Примеры

### Базовое использование

```cpp
int client_fd = accept(sockfd, NULL, NULL);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
