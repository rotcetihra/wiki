## Прототип

```cpp
#include <sys/stat.h>\nint mkdir(const char *pathname, mode_t mode);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pathname` | путь к новому каталогу |\n| `mode` | права доступа |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Создаёт новый каталог по указанному пути.

## Примеры

### Базовое использование

```cpp
mkdir("/tmp/mydir", 0755);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке (EEXIST если существует).\n- **Безопасность в C++11:** Потокобезопасна.
