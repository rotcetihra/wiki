## Прототип

```cpp
#include <sys/stat.h>\nint fchmod(int fd, mode_t mode);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор |\n| `mode` | права доступа |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Аналог `chmod()`, но принимает файловый дескриптор.

## Примеры

### Базовое использование

```cpp
fchmod(fd, 0644);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
