## Прототип

```cpp
#include <sys/stat.h>\nint chmod(const char *pathname, mode_t mode);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pathname` | путь к файлу |\n| `mode` | права доступа (S_IRWXU, S_IRUSR и т.д.) |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Изменяет права доступа к файлу.

## Примеры

### Базовое использование

```cpp
chmod("file.txt", 0644);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
