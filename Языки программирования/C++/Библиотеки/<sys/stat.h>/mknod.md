## Прототип

```cpp
#include <sys/stat.h>\nint mknod(const char *pathname, mode_t mode, dev_t dev);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pathname` | путь к файлу |\n| `mode` | тип файла и права |\n| `dev` | номер устройства (для block/char) |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Создаёт файл特殊ого типа: обычный файл, каталог, block/char устройство или именованный канал.

## Примеры

### Базовое использование

```cpp
mknod("/tmp/mydev", S_IFCHR | 0644, makedev(1, 3));
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
