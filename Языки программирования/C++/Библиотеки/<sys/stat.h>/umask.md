## Прототип

```cpp
#include <sys/stat.h>\nmode_t umask(mode_t cmask);
```

## Параметры

| Параметр | Описание |
|---|---|
| `cmask` | новая маска (022, 077 и т.д.) |
## Возвращаемое значение

Предыдущее значение маски.

## Что делает

Устанавливает маску прав доступа, которая маскирует права при создании файлов через `open()`, `mkdir()` и т.д.

## Примеры

### Базовое использование

```cpp
mode_t old = umask(022);
```

## Исключения

- **Исключения:** Возвращает предыдущее значение.\n- **Безопасность в C++11:** Потокобезопасна.
