## Прототип

```cpp
#include <sys/stat.h>\nint mkfifo(const char *pathname, mode_t mode);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pathname` | путь к файлу |\n| `mode` | права доступа |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Создаёт именованный канал (FIFO) для межпроцессного взаимодействия.

## Примеры

### Базовое использование

```cpp
mkfifo("/tmp/myfifo", 0644);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
