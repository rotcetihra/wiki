## Прототип

```cpp
#include <sys/time.h>\nint setitimer(int which, const struct itimerval *new_value, struct itimerval *old_value);
```

## Параметры

| Параметр | Описание |
|---|---|
| `which` | тип таймера |\n| `new_value` | новое значение |\n| `old_value` | предыдущее значение (или NULL) |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Устанавливает интервал таймера, который генерирует сигнал по истечении времени.

## Примеры

### Базовое использование

```cpp
struct itimerval t;\nt.it_interval.tv_sec = 5;\nt.it_interval.tv_usec = 0;\nt.it_value = t.it_interval;\nsetitimer(ITIMER_REAL, &t, NULL);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
