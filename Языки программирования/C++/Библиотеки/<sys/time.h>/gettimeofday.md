## Прототип

```cpp
#include <sys/time.h>\nint gettimeofday(struct timeval *tv, struct timezone *tz);
```

## Параметры

| Параметр | Описание |
|---|---|
| `tv` | указатель на структуру timeval |\n| `tz` | указатель на timezone (устаревшая, NULL) |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Получает текущее время с микросекундной точностью.

## Примеры

### Базовое использование

```cpp
struct timeval tv;\ngettimeofday(&tv, NULL);\nprintf("Секунды: %ld", tv.tv_sec);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
