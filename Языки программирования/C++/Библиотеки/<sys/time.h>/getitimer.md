## Прототип

```cpp
#include <sys/time.h>\nint getitimer(int which, struct itimerval *curr_value);
```

## Параметры

| Параметр | Описание |
|---|---|
| `which` | тип таймера (ITIMER_REAL, ITIMER_VIRTUAL, ITIMER_PROF) |\n| `curr_value` | текущее значение таймера |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Получает текущее значение и интервал таймера.

## Примеры

### Базовое использование

```cpp
struct itimerval t;\ngetitimer(ITIMER_REAL, &t);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
