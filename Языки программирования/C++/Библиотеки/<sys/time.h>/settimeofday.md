## Прототип

```cpp
#include <sys/time.h>\nint settimeofday(const struct timeval *tv, const struct timezone *tz);
```

## Параметры

| Параметр | Описание |
|---|---|
| `tv` | новое время |\n| `tz` | timezone (устаревшая, NULL) |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Устанавливает системное время. Требует привилегий root.

## Примеры

### Базовое использование

```cpp
struct timeval tv;\ntv.tv_sec = new_time;\ntv.tv_usec = 0;\nsettimeofday(&tv, NULL);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке (EPERM если нет прав).\n- **Безопасность в C++11:** Потокобезопасна.
