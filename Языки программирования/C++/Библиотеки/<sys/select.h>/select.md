## Прототип

```cpp
#include <sys/select.h>\nint select(int nfds, fd_set *readfds, fd_set *writefds, fd_set *exceptfds, struct timeval *timeout);
```

## Параметры

| Параметр | Описание |
|---|---|
| `nfds` | максимальный дескриптор + 1 |\n| `readfds` | дескрипторы для чтения |\n| `writefds` | дескрипторы для записи |\n| `exceptfds` | дескрипторы для ошибок |\n| `timeout` | тайм-аут (NULL — бесконечно) |
## Возвращаемое значение

Количество дескрипторов с событиями, 0 при тайм-ауте, -1 при ошибке.

## Что делает

Мониторит несколько файловых дескрипторов на события.

## Примеры

### Базовое использование

```cpp
fd_set fds;\nFD_ZERO(&fds);\nFD_SET(fd, &fds);\nstruct timeval tv = {5, 0};\nselect(fd + 1, &fds, NULL, NULL, &tv);\nif (FD_ISSET(fd, &fds))\n    // данные доступны
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
