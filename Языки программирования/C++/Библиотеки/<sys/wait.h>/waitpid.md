## Прототип

```cpp
#include <sys/wait.h>\npid_t waitpid(pid_t pid, int *wstatus, int options);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pid` | PID процесса (>0 — конкретный, -1 — любой, 0 — группа) |\n| `wstatus` | статус завершения (или NULL) |\n| `options` | WNOHANG, WUNTRACED, WCONTINUED |
## Возвращаемое значение

PID завершившегося процесса, 0 (при WNOHANG если не завершился), -1 при ошибке.

## Что делает

Ожидает завершения или изменения статуса указанного дочернего процесса.

## Примеры

### Базовое использование

```cpp
int status;\npid_t pid = fork();\nif (pid == 0) {\n    // дочерний\n} else {\n    waitpid(pid, &status, 0);\n    if (WIFEXITED(status))\n        printf("Код: %d", WEXITSTATUS(status));\n}
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
