## Прототип

```cpp
#include <sys/wait.h>\npid_t wait(int *wstatus);
```

## Параметры

| Параметр | Описание |
|---|---|
| `wstatus` | статус завершения (или NULL) |
## Возвращаемое значение

PID завершившегося процесса или -1 при ошибке.

## Что делает

Ожидает завершения любого дочернего процесса. Эквивалент `waitpid(-1, wstatus, 0)`.

## Примеры

### Базовое использование

```cpp
int status;\npid_t pid = wait(&status);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
