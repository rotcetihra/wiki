## Описание библиотеки

Заголовочный файл `<string>` определяет класс `std::basic_string` для хранения и манипулирования последовательностями символов. Предоставляет динамически изменяемый массив символов с автоматическим управлением памятью, поддержку Unicode, сравнение, поиск и преобразования.

## Исключения

- **Исключения:** Бросает `std::bad_alloc` при ошибке выделения памяти. Метод `at()` бросает `std::out_of_range`.
- **Безопасность в C++11:** Потокобезопасна для разных объектов.

## Стандарты

C++98, C++11, C++14, C++17, C++20, C++23.
