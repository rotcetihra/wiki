## Прототип

```cpp
#include <initializer_list>
template<class E>
class initializer_list;
```

## Параметры

| Параметр | Описание |
|---|---|
| `E` | тип элементов |

## Возвращаемое значение

Не применимо (это тип).

## Что делает

Легковесный non-owning указатель на константный массив.

## Примеры

### Базовое использование

```cpp
std::vector<int> v = {1, 2, 3, 4, 5};
```
