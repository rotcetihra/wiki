## Прототип

```cpp
#include <initializer_list>
template<class E>
constexpr const E* end(initializer_list<E> il) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `il` | список инициализации |

## Возвращаемое значение

`const E*` — указатель на элемент за последним.

## Что делает

Возвращает итератор на элемент за последним.

## Примеры

### Базовое использование

```cpp
std::initializer_list<int> il = {1, 2, 3};
auto it = std::end(il);
std::cout << *(it - 1) << std::endl; // 3
```

## Исключения

- **Исключения:** Не бросает исключений (`noexcept`).
- **Безопасность в C++11:** Потокобезопасен.
