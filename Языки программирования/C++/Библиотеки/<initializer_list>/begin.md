## Прототип

```cpp
#include <initializer_list>
template<class E>
constexpr const E* begin(initializer_list<E> il) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `il` | список инициализации |

## Возвращаемое значение

`const E*` — указатель на первый элемент.

## Что делает

Возвращает итератор на первый элемент.

## Примеры

### Базовое использование

```cpp
std::initializer_list<int> il = {1, 2, 3};
std::cout << *std::begin(il) << std::endl; // 1
```

## Исключения

- **Исключения:** Не бросает исключений (`noexcept`).
- **Безопасность в C++11:** Потокобезопасен.
