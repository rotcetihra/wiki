## Прототип

```cpp
#include <iosfwd>
template<class CharT, class Traits = std::char_traits<CharT>>
class basic_ios : public std::ios_base;
```

## Описание

Класс `std::basic_ios` является базовым классом для всех потоков. Он предоставляет общий интерфейс для управления состоянием потока, связывания с буфером и настройки форматирования.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
