## Прототип

```cpp
#include <iosfwd>
template<class CharT, class Traits = std::char_traits<CharT>>
class basic_filebuf : public std::basic_streambuf<CharT, Traits>;
```

## Описание

Класс `std::basic_filebuf` реализует буфер для файлового ввода-вывода. Он управляет чтением и записью данных через системные вызовы операционной системы.
