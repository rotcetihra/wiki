## Прототип

```cpp
#include <iosfwd>
template<class CharT, class Traits = std::char_traits<CharT>>
class basic_streambuf;
```

## Описание

Класс `std::basic_streambuf` является абстрактным базовым классом для всех буферов потоков. Он определяет интерфейс для чтения и записи символов.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
