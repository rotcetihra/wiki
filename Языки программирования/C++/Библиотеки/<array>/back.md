## Прототип

```cpp
reference back();
const_reference back() const;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Ссылка на последний элемент массива.

## Что делает

Возвращает ссылку на последний элемент. Поведение не определено для пустых массивов.

## Примеры

### Базовое использование

```cpp
```cpp
#include <array>
#include <iostream>

int main()
{
    std::array<int, 3> arr = {10, 20, 30};
    std::cout << arr.back() << "\n"; // 30
}
```
```
- **Исключения:** не бросает исключений.
- **Безопасность в C++11:** поведение не определено для пустых массивов.
