## Прототип

```cpp
reference at(size_type pos);
const_reference at(size_type pos) const;
```

## Параметры

| Параметр | Описание |
|---|---|
| Параметр | Описание |
|---|---|
| `pos` | Индекс элемента (начиная с 0) |

## Возвращаемое значение

Ссылка на элемент с индексом `pos`. Константная версия возвращает `const`-ссылку.

## Что делает

Проверяет, что `pos < size()`. Если условие не выполнено, выбрасывается `std::out_of_range`. В отличие от `operator[]`, выполняется проверка границ.

## Примеры

### Базовое использование

```cpp
```cpp
#include <array>
#include <iostream>

int main()
{
    std::array<int, 3> arr = {10, 20, 30};
    std::cout << arr.at(1) << "\n"; // 20
    // arr.at(5); // выбросит std::out_of_range
}
```
```
- **Исключения:** выбрасывает `std::out_of_range`, если `pos >= size()`.
- **Безопасность в C++11:** безопаснее `operator[]` за счёт проверки границ.
