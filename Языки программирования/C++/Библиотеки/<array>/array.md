## Прототип

```cpp
#include <array>

template<class T, std::size_t N>
struct array;
```

Объект `std::array<T, N>` — это контейнер с фиксированным размером, который хранит `N` элементов типа `T` непосредственно внутри объекта. Поведение совместимо с C-массивом: `data()` возвращает указатель на непрерывный блок памяти.

## Что делает

## Параметры шаблона

| Параметр | Описание |
|---|---|
| `T` | Тип элементов массива |
| `N` | Количество элементов (константа времени компиляции) |

## Примеры

### Базовое использование

```cpp
#include <array>
#include <iostream>

int main()
{
    std::array<int, 5> arr = {1, 2, 3, 4, 5};
    std::cout << "Size: " << arr.size() << "\n"; // 5
    std::cout << "Element: " << arr[2] << "\n";   // 3
}
```
- **Исключения:** конструкторы могут выбрасывать исключения при неудачном копировании/перемещении элементов.
- **Безопасность в C++11:** размер фиксирован и известен в времени компиляции; нет проверки границ в `operator[]`.
