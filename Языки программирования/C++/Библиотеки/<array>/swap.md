## Прототип

```cpp
void swap(array& other) noexcept(/* see below */);
```

## Параметры

| Параметр | Описание |
|---|---|
| Параметр | Описание |
|---|---|
| `other` | Другой массив того же типа и размера |

## Возвращаемое значение

Ничего не возвращает.

## Что делает

Обменивает содержимое с другим массивом того же типа `T` и размера `N`. Элементы обмениваются через `std::swap` или перемещение.

## Примеры

### Базовое использование

```cpp
```cpp
#include <array>
#include <iostream>

int main()
{
    std::array<int, 3> a = {1, 2, 3};
    std::array<int, 3> b = {4, 5, 6};
    a.swap(b);
    std::cout << a[0] << " " << b[0] << "\n"; // 4 1
}
```
```
- **Исключения:** не бросает исключений (если `std::nothrow_t` для элементов не исключает).
