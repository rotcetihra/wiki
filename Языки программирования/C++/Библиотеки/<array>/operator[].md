## Прототип

```cpp
reference operator[](size_type pos);
const_reference operator[](size_type pos) const;
```

## Параметры

| Параметр | Описание |
|---|---|
| Параметр | Описание |
|---|---|
| `pos` | Индекс элемента (начиная с 0) |

## Возвращаемое значение

Ссылка на элемент с индексом `pos`. Константная версия возвращает `const`-ссылку.

## Что делает

Возвращает ссылку на элемент с указанным индексом. Проверка границ не выполняется; поведение не определено при `pos >= size()`.

## Примеры

### Базовое использование

```cpp
```cpp
#include <array>
#include <iostream>

int main()
{
    std::array<int, 3> arr = {10, 20, 30};
    std::cout << arr[1] << "\n"; // 20
    arr[0] = 5;
}
```
```
- **Исключения:** не бросает исключений.
- **Безопасность в C++11:** не проверяет границы; предпочтительнее `at()` для безопасного доступа.
