## Прототип

```cpp
T* data() noexcept;
const T* data() const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Указатель на первый элемент массива (непрерывный блок памяти).

## Что делает

Возвращает `T*` на начало массива. Данные хранятся непрерывно, как в C-массиве. Можно использовать для передачи в C-функции.

## Примеры

### Базовое использование

```cpp
```cpp
#include <array>
#include <iostream>

int main()
{
    std::array<int, 5> arr = {1, 2, 3, 4, 5};
    int *p = arr.data();
    std::cout << *(p + 2) << "\n"; // 3
}
```
```
- **Исключения:** не бросает исключений.
