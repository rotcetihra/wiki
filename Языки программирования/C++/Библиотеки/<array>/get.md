## Прототип

```cpp
template<std::size_t I, class T, std::size_t N>
constexpr T& get(array<T, N>& a) noexcept;

// и константные/右值 версии
```

## Параметры

| Параметр | Описание |
|---|---|
| Параметр | Описание |
|---|---|
| `I` | Индекс элемента (константа времени компиляции) |
| `a` | Массив |

## Возвращаемое значение

Ссылка на элемент с индексом `I` в массиве `a`.

## Что делает

Свободная функция для доступа к элементу массива по индексу, известному в времени компиляции. Аналог `std::get` для `std::tuple`.

## Примеры

### Базовое использование

```cpp
```cpp
#include <array>
#include <iostream>

int main()
{
    std::array<int, 3> arr = {10, 20, 30};
    std::cout << std::get<1>(arr) << "\n"; // 20
}
```
```
- **Исключения:** не бросает исключений.
- **Безопасность в C++11:** проверка границ выполняется в времени компиляции; `I >= N` — ошибка компиляции.
