## Возвращаемое значение

Константный обратный итератор перед первым элементом.

## Что делает

```cpp
#include <array>
#include <iostream>

int main()
{
    std::array<int, 4> arr = {10, 20, 30, 40};
    for (auto it = arr.crend(); it != arr.crend(); ++it)
        std::cout << *it << " ";
    std::cout << "\n";
}
```
