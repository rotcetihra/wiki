## Возвращаемое значение

Ссылка на первый элемент массива.

## Что делает

Возвращает ссылку на первый элемент. Поведение не определено, если массив пуст (хотя `std::array` с `N > 0` всегда непуст).

## Примеры

### Базовое использование

```cpp
```cpp
#include <array>
#include <iostream>

int main()
{
    std::array<int, 3> arr = {10, 20, 30};
    std::cout << arr.front() << "\n"; // 10
}
```
```
- **Исключения:** не бросает исключений.
- **Безопасность в C++11:** поведение не определено для пустых массивов.
