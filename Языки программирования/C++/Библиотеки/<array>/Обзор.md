## Описание библиотеки

Заголовочный файл `<array>` определяет класс `std::array` — контейнер, представляющий фиксированный размер массива, совместимый с C-массивами. Элементы хранятся непосредственно внутри объекта (не в куче). Поддерживает случайный доступ, инкремент/декремент итераторов, а также интеграцию с `std::tuple`.

## Исключения

- **Исключения:** `at()` выбрасывает `std::out_of_range` при выходе за границы. Остальные методы не бросают исключений (кроме `swap` для нетривиально копируемых типов).
- **Безопасность в C++11:** `std::array` — безопасная замена C-массива; размер известен в времени компиляции через `std::tuple_size`.

## Стандарты

C++11, C++17, C++20, C++23.
