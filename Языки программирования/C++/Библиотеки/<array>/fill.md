## Прототип

```cpp
void fill(const T& value);
```

## Параметры

| Параметр | Описание |
|---|---|
| Параметр | Описание |
|---|---|
| `value` | Значение, которым заполняются все элементы |

## Возвращаемое значение

Ничего не возвращает.

## Что делает

Заполняет все `N` элементов массива значением `value`.

## Примеры

### Базовое использование

```cpp
```cpp
#include <array>
#include <iostream>

int main()
{
    std::array<int, 5> arr;
    arr.fill(42);
    for (int x : arr) std::cout << x << " "; // 42 42 42 42 42
}
```
```
- **Исключения:** может выбрасывать исключения при копировании/перемещении элементов.
