## Прототип

```cpp
#include <filesystem>

class path;
```

## Параметры

Нет.

## Возвращаемое значение

Класс `std::filesystem::path` для представления путей файловой системы.

## Что делает

Представляет путь файловой системы. Поддерживает конкатенацию (`/`), сравнение, разбиение на компоненты (корень, родитель, имя файла, расширение) и преобразования между кодировками.

## Примеры

```cpp
#include <filesystem>
#include <iostream

int main()
{
    namespace fs = std::filesystem;
    fs::path p = "/home/user/file.txt";
    std::cout << p.filename() << std::endl;    // "file.txt"
    std::cout << p.extension() << std::endl;   // ".txt"
    std::cout << p.stem() << std::endl;        // "file"
}
```

## Исключения

- **Исключения:** может бросать `filesystem_error` при ошибках.
