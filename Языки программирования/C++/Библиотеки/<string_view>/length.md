## Прототип

```cpp
#include <string_view>
constexpr size_type length() const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Длина строкового вида.

## Что делает

Эквивалентно `size()`.

## Примеры

### Базовое использование

```cpp
std::string_view sv = "Hello";
std::cout << sv.length() << std::endl; // 5
```
