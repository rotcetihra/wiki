## Прототип

```cpp
#include <string_view>
constexpr const_iterator end() const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Итератор на конец (past-the-end).

## Что делает

Возвращает константный итератор на элемент после последнего.

## Примеры

### Базовое использование

```cpp
std::string_view sv = "Hello";
std::cout << (sv.end() - sv.begin()) << std::endl; // 5
```
