## Прототип

```cpp
#include <string_view>
constexpr const_reverse_iterator crbegin() const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Константный обратный итератор на начало.

## Что делает

Возвращает константный обратный итератор.

## Примеры

### Базовое использование

```cpp
std::string_view sv = "Hello";
for (auto it = sv.crbegin(); it != sv.crend(); ++it)
    std::cout << *it;
// olleH
```
