## Прототип

```cpp
#include <string_view>
constexpr const CharT* data() const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Указатель на данные.

## Что делает

Возвращает указатель на массив символов.

## Примеры

### Базовое использование

```cpp
std::string_view sv = "Hello";
const char* p = sv.data();
std::cout << p << std::endl; // Hello
```
