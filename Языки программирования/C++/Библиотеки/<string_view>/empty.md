## Прототип

```cpp
#include <string_view>
constexpr bool empty() const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

`true`, если строковый вид пуст.

## Что делает

Эквивалентно `size() == 0`.

## Примеры

### Базовое использование

```cpp
std::string_view sv;
std::cout << std::boolalpha << sv.empty() << std::endl; // true
```
