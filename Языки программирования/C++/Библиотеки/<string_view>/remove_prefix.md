## Прототип

```cpp
#include <string_view>
constexpr void remove_prefix(size_type n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `n` | количество символов |

## Возвращаемое значение

Ничего не возвращает.

## Что делает

Сдвигает начало на `n` символов вперёд.

## Примеры

### Базовое использование

```cpp
std::string_view sv = "Hello World";
sv.remove_prefix(6);
std::cout << sv << std::endl; // World
```
