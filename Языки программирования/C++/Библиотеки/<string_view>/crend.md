## Прототип

```cpp
#include <string_view>
constexpr const_reverse_iterator crend() const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Константный обратный итератор на конец.

## Что делает

Возвращает константный обратный итератор перед первым символом.

## Примеры

### Базовое использование

```cpp
std::string_view sv = "Hello";
std::cout << (sv.crend() - sv.crbegin()) << std::endl; // 5
```
