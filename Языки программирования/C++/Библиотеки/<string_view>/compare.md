## Прототип

```cpp
#include <string_view>
constexpr int compare(basic_string_view s) const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | строка для сравнения |

## Возвращаемое значение

Результат сравнения: `<0`, `0` или `>0`.

## Что делает

Сравнивает строковые виды лексикографически.

## Примеры

### Базовое использование

```cpp
std::string_view a = "apple";
std::string_view b = "banana";
std::cout << a.compare(b) << std::endl; // отрицательное
```
