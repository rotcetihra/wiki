## Прототип

```cpp
#include <string_view>
using u16string_view = basic_string_view<char16_t>;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Алиас для `basic_string_view<char16_t>`.

## Что делает

Строковый вид для UTF-16 символов.

## Примеры

### Базовое использование

```cpp
std::u16string_view sv = u"Привет";
```
