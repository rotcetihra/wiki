## Прототип

```cpp
#include <string_view>
constexpr void swap(basic_string_view& s) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | другой строковый вид |

## Возвращаемое значение

Ничего не возвращает.

## Что делает

Обменивает содержимое двух строковых видов.

## Примеры

### Базовое использование

```cpp
std::string_view a = "hello";
std::string_view b = "world";
a.swap(b);
std::cout << a << ' ' << b << std::endl; // world hello
```

## Исключения

- ('bad_alloc', 'Бросает `std::bad_alloc` при ошибке выделения памяти.')
- ('safe', 'Потокобезопасна для разных объектов.')
