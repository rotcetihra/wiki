## Прототип

```cpp
#include <string_view>
constexpr const_iterator begin() const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|


## Возвращаемое значение

Итератор на начало.

## Что делает

Возвращает константный итератор на первый символ.

## Примеры

### Базовое использование

```cpp
std::string_view sv = "Hello";
for (auto it = sv.begin(); it != sv.end(); ++it)
    std::cout << *it;
// Hello
```
