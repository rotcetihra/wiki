## Прототип

```cpp
#include <string_view>
constexpr const_reference at(size_type pos) const;
```

## Параметры

| Параметр | Описание |
|---|---|
| `pos` | индекс |

## Возвращаемое значение

Ссылка на символ.

## Что делает

Доступ с проверкой границ. Бросает `std::out_of_range`.

## Примеры

### Базовое использование

```cpp
std::string_view sv = "Hello";
std::cout << sv.at(1) << std::endl; // e
```

## Исключения

- **Исключения:** `std::out_of_range` при `pos >= size()`.
