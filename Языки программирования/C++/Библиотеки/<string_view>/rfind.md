## Прототип

```cpp
#include <string_view>
constexpr size_type rfind(basic_string_view s, size_type pos = npos) const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | подстрока |
| `pos` | позиция начала поиска назад |

## Возвращаемое значение

Позиция последнего вхождения или `npos`.

## Что делает

Находит последнее вхождение подстроки.

## Примеры

### Базовое использование

```cpp
std::string_view sv = "abcabc";
std::cout << sv.rfind("abc") << std::endl; // 3
```
