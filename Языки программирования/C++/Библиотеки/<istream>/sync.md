## Прототип

```cpp
#include <istream>
int sync();
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Синхронизирует буфер с реальным источником данных.

## Примеры

```cpp
std::cin.sync();  // Синхронизировать буфер
```
