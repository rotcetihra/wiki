## Прототип

```cpp
#include <istream>
std::basic_istream& seekg(pos_type pos);
std::basic_istream& seekg(off_type off, std::ios_base::seekdir dir);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pos` | Абсолютная позиция |
| `off` | Смещение относительно `dir` |
| `dir` | Направление поиска (`beg`, `cur`, `end`) |

## Возвращаемое значение

Возвращает ссылку на поток (`*this`).

## Что делает

Устанавливает позицию чтения.

## Примеры

### Базовое использование

```cpp
std::ifstream file("example.txt");
file.seekg(0, std::ios::end);  // Перейти в конец
```
