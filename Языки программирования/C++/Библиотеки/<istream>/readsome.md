## Прототип

```cpp
#include <istream>
std::streamsize readsome(char_type* s, std::streamsize n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Указатель на буфер |
| `n` | Максимальное количество символов |

## Возвращаемое значение

Количество прочитанных символов.

## Что делает

Читает до `n` символов из потока, не блокируясь.

## Примеры

### Базовое использование

```cpp
char buffer[100];
std::streamsize n = std::cin.readsome(buffer, 100);
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
