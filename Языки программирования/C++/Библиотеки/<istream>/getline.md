## Прототип

```cpp
#include <istream>
std::basic_istream& getline(char_type* s, std::streamsize n, char_type delim);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Указатель на буфер для чтения |
| `n` | Максимальное количество символов |
| `delim` | Символ-разделитель (по умолчанию `\n`) |

## Возвращаемое значение

Возвращает ссылку на поток (`*this`).

## Что делает

Извлекает символы из потока и сохраняет их в буфер до встречи разделителя или конца потока.

## Примеры

### Базовое использование

```cpp
char buffer[256];
std::cin.getline(buffer, 256);
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
