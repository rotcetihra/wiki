## Прототип

```cpp
#include <istream>
template<class CharT, class Traits>
std::basic_istream<CharT, Traits>& ws(std::basic_istream<CharT, Traits>& is);
```

## Параметры

| Параметр | Описание |
|---|---|
| `is` | Входной поток |

## Возвращаемое значение

См. документацию.

## Что делает

Пропускает пробельные символы во входном потоке.

## Примеры

### Базовое использование

```cpp
int x;
std::cin >> std::ws >> x;  // Пропустить пробелы перед чтением
```
