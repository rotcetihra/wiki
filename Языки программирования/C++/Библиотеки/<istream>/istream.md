## Прототип

```cpp
#include <istream>
using istream = std::basic_istream<char>;
```

## Описание

`std::istream` — это псевдоним типа для `std::basic_istream<char>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
