## Прототип

```cpp
#include <istream>
std::basic_istream& putback(char_type c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Символ для возврата в поток |

## Возвращаемое значение

Возвращает ссылку на поток (`*this`).

## Что делает

Возвращает символ в поток.

## Примеры

### Базовое использование

```cpp
char c;
std::cin.get(c);
std::cin.putback(c);
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
