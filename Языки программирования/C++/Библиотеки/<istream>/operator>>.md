## Прототип

```cpp
#include <istream>
template<class CharT, class Traits, class T>
std::basic_istream<CharT, Traits>& operator>>(std::basic_istream<CharT, Traits>& is, T& value);
```

## Параметры

| Параметр | Описание |
|---|---|
| `is` | Входной поток |
| `value` | Объект для извлечения данных |

## Возвращаемое значение

Возвращает ссылку на поток (`*this`).

## Что делает

Извлекает данные из потока в объект.

## Примеры

### Базовое использование

```cpp
int x;
std::cin >> x;
std::string s;
std::cin >> s;
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
