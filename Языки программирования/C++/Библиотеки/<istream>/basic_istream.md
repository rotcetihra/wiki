## Прототип

```cpp
#include <istream>
template<class CharT, class Traits = std::char_traits<CharT>>
class basic_istream : virtual public std::basic_ios<CharT, Traits>;
```

## Описание

Класс `std::basic_istream` является базовым классом для всех входных потоков. Он предоставляет операторы извлечения `>>` и функции для форматированного и неформатированного ввода.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
