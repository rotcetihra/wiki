## Прототип

```cpp
#include <istream>
using wistream = std::basic_istream<wchar_t>;
```

## Описание

`std::wistream` — это псевдоним типа для `std::basic_istream<wchar_t>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
