## Прототип

```cpp
#include <istream>
std::streamsize gcount() const;
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

Количество символов, прочитанных последней операцией.

## Что делает

Возвращает количество символов, прочитанных последней не-форматной операцией.

## Примеры

### Базовое использование

```cpp
char buffer[100];
std::cin.read(buffer, 100);
std::streamsize n = std::cin.gcount();
std::cout << "Прочитано: " << n << " символов" << std::endl;
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
