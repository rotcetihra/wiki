## Прототип

```cpp
#include <istream>
int_type peek();
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

Следующий символ без его извлечения или `traits::eof()`.

## Что делает

Возвращает следующий символ без его извлечения из потока.

## Примеры

### Базовое использование

```cpp
int c = std::cin.peek();
if (c == '\n') {
    std::cout << "Следующий символ — перевод строки" << std::endl;
}
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
