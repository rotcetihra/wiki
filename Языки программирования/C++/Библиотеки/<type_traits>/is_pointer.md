## Прототип

```cpp
#include <type_traits>
template<class T>
struct is_pointer;
```

## Возвращаемое значение

`std::true_type` если указатель.

## Что делает

Проверка указателя.

## Примеры

### Базовое использование

```cpp
static_assert(std::is_pointer_v<int*>);
```

- **Безопасность в C++11:** Потокобезопасен.
