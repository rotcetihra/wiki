## Прототип

```cpp
#include <type_traits>
template<class T, unsigned N = 0>
struct extent;
```

## Возвращаемое значение

`std::size_t` — размер по измерению N.

## Что делает

Размер массива по измерению.

## Примеры

### Базовое использование

```cpp
constexpr auto e = std::extent_v<int[2][3], 1>; // 3
```
