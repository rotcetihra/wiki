## Прототип

```cpp
#include <type_traits>
template<class T>
struct add_volatile;
```

## Возвращаемое значение

Тип volatile.

## Что делает

Добавление volatile.

## Примеры

### Базовое использование

```cpp
using T = std::add_volatile_t<int>; // volatile int
```

## Исключения

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасен.
