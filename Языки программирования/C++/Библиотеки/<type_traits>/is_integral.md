## Прототип

```cpp
#include <type_traits>
template<class T>
struct is_integral;
```

## Возвращаемое значение

`std::true_type` если целочисленный тип.

## Что делает

Проверка целочисленного типа.

## Примеры

### Базовое использование

```cpp
static_assert(std::is_integral_v<int>);
```

- **Безопасность в C++11:** Потокобезопасен.
