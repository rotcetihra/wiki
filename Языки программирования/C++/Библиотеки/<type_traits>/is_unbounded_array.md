## Прототип

```cpp
#include <type_traits>
template<class T>
struct is_unbounded_array;
```

## Возвращаемое значение

`std::true_type` если массив непред. размера.

## Что делает

Проверка неизвестного массива.

## Примеры

### Базовое использование

```cpp
static_assert(std::is_unbounded_array_v<int[]>);
```

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасен.
