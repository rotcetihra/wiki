## Прототип

```cpp
#include <type_traits>
template<class T>
struct is_aggregate;
```

## Возвращаемое значение

`std::true_type` если агрегат (C++17).

## Что делает

Проверка агрегата.

## Примеры

### Базовое использование

```cpp
struct Agg { int x; };
static_assert(std::is_aggregate_v<Agg>);
```

## Исключения

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасен.
