## Прототип

```cpp
#include <type_traits>
template<class T>
struct is_reference;
```

## Возвращаемое значение

`std::true_type` если ссылка.

## Что делает

Проверка ссылки.

## Примеры

### Базовое использование

```cpp
static_assert(std::is_reference_v<int&>);
```
