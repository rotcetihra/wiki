## Прототип

```cpp
#include <type_traits>
template<class T>
struct is_final;
```

## Возвращаемое значение

`std::true_type` если final.

## Что делает

Проверка final-класса.

## Примеры

### Базовое использование

```cpp
struct Final final {};
static_assert(std::is_final_v<Final>);
```

## Исключения

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасен.
