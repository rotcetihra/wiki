## Прототип

```cpp
#include <type_traits>
template<class T>
struct add_const;
```

## Возвращаемое значение

Тип const.

## Что делает

Добавление const.

## Примеры

### Базовое использование

```cpp
using T = std::add_const_t<int>; // const int
```
