## Прототип

```cpp
#include <type_traits>
template<bool B, class T, class F>
struct conditional;
```

## Возвращаемое значение

Если `B==true` — `T`, иначе `F`.

## Что делает

Выбор типа по условию.

## Примеры

### Базовое использование

```cpp
using T = std::conditional_t<true, int, double>; // int
```

## Исключения

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасен.
