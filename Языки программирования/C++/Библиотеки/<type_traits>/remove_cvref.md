## Прототип

```cpp
#include <type_traits>
template<class T>
struct remove_cvref;
```

## Возвращаемое значение

Тип без const, volatile и ссылки (C++20).

## Что делает

Удаление cv и ссылки.

## Примеры

### Базовое использование

```cpp
using T = std::remove_cvref_t<const int&>; // int
```
