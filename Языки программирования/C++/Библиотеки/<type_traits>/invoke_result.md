## Прототип

```cpp
#include <type_traits>
template<class F, class... ArgTypes>
struct invoke_result;
```

## Возвращаемое значение

`type` — тип результата вызова.

## Что делает

Тип результата вызова (C++17).

## Примеры

### Базовое использование

```cpp
using R = std::invoke_result_t<int(*)(int), int>; // int
```
