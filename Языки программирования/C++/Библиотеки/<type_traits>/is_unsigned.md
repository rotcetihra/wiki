## Прототип

```cpp
#include <type_traits>
template<class T>
struct is_unsigned;
```

## Возвращаемое значение

`std::true_type` если беззнаковый.

## Что делает

Проверка беззнакового типа.

## Примеры

### Базовое использование

```cpp
static_assert(std::is_unsigned_v<unsigned>);
```
