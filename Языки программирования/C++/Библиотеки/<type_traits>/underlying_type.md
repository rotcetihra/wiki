## Прототип

```cpp
#include <type_traits>
template<class T>
struct underlying_type;
```

## Возвращаемое значение

Базовый тип перечисления.

## Что делает

Получение базового типа enum.

## Примеры

### Базовое использование

```cpp
enum class E : int {};
using T = std::underlying_type_t<E>; // int
```
