## Прототип

```cpp
#include <type_traits>
template<bool B, class T = void>
struct enable_if;
```

## Возвращаемое значение

Если `B==true` — `type` как `T`, иначе SFINAE.

## Что делает

Условное включение типа.

## Примеры

### Базовое использование

```cpp
template<class T, std::enable_if_t<std::is_integral_v<T>>* = void>
void f(T x) {}
```

## Исключения

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасен.
