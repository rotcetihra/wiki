## Прототип

```cpp
#include <type_traits>
template<class T>
struct is_literal_type;
```

## Возвращаемое значение

`std::true_type` если литеральный тип.

## Что делает

Проверка литерального типа (deprecated C++20).

## Примеры

### Базовое использование

```cpp
static_assert(std::is_literal_type_v<int>);
```

## Исключения

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасен.
