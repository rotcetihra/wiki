## Прототип

```cpp
#include <type_traits>
template<class T>
struct is_bounded_array;
```

## Возвращаемое значение

`std::true_type` если массив фикс. размера.

## Что делает

Проверка фиксированного массива.

## Примеры

### Базовое использование

```cpp
static_assert(std::is_bounded_array_v<int[5]>);
```

- **Безопасность в C++11:** Потокобезопасен.
