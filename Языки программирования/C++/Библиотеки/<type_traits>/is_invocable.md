## Прототип

```cpp
#include <type_traits>
template<class F, class... ArgTypes>
struct is_invocable;
```

## Возвращаемое значение

`std::true_type` если F вызываема.

## Что делает

Проверка вызываемости (C++17).

## Примеры

### Базовое использование

```cpp
static_assert(std::is_invocable_v<int(*)(int), int>);
```

## Исключения

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасен.
