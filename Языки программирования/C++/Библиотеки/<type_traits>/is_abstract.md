## Прототип

```cpp
#include <type_traits>
template<class T>
struct is_abstract;
```

## Возвращаемое значение

`std::true_type` если абстрактный.

## Что делает

Проверка абстрактного класса.

## Примеры

### Базовое использование

```cpp
struct Abs { virtual void f() = 0; };
static_assert(std::is_abstract_v<Abs>);
```
