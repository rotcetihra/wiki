## Прототип

```cpp
#include <type_traits>
template<class... T>
struct common_type;
```

## Возвращаемое значение

Тип, к которому приводятся все типы.

## Что делает

Общий тип для набора типов.

## Примеры

### Базовое использование

```cpp
using T = std::common_type_t<int, double>; // double
```

## Исключения

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасен.
