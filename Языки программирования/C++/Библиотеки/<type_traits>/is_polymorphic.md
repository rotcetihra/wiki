## Прототип

```cpp
#include <type_traits>
template<class T>
struct is_polymorphic;
```

## Возвращаемое значение

`std::true_type` если полиморфный.

## Что делает

Проверка полиморфного класса.

## Примеры

### Базовое использование

```cpp
struct Poly { virtual void f(); };
static_assert(std::is_polymorphic_v<Poly>);
```

## Исключения

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасен.
