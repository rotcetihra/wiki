## Прототип

```cpp
#include <type_traits>
template<class T>
struct is_pod;
```

## Возвращаемое значение

`std::true_type` если POD.

## Что делает

Проверка POD-типа.

## Примеры

### Базовое использование

```cpp
static_assert(std::is_pod_v<int>);
```

## Исключения

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасен.
