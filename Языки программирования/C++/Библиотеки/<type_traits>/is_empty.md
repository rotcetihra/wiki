## Прототип

```cpp
#include <type_traits>
template<class T>
struct is_empty;
```

## Возвращаемое значение

`std::true_type` если пустой класс.

## Что делает

Проверка пустого класса.

## Примеры

### Базовое использование

```cpp
struct Empty {}; static_assert(std::is_empty_v<Empty>);
```
