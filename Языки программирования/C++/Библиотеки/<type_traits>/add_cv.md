## Прототип

```cpp
#include <type_traits>
template<class T>
struct add_cv;
```

## Возвращаемое значение

Тип const volatile.

## Что делает

Добавление cv.

## Примеры

### Базовое использование

```cpp
using T = std::add_cv_t<int>; // const volatile int
```
