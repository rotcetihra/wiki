## Прототип

```cpp
#include <cstdlib>

lldiv_t lldiv(long long numer, long long denom);
```

## Параметры

| Параметр | Описание |
|---|---|
| `numer` | Числитель типа `long long` |
| `denom` | Знаменатель типа `long long` |

## Возвращаемое значение

Структура `lldiv_t` с полями `quot` (частное) и `rem` (остаток).

## Что делает

Выполняет целочисленное деление длинных длинных целых чисел и возвращает частное и остаток.

## Примеры

```cpp
#include <cstdlib>
#include <iostream>

int main()
{
    auto result = std::lldiv(1000000000000LL, 3000000000LL);
    std::cout << "quot = " << result.quot << ", rem = " << result.rem << std::endl;
}
```
