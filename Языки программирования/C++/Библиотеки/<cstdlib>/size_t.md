## Прототип

```cpp
#include <cstdlib>

// определено через <cstddef>
typedef /* беззнаковый целый тип */ size_t;
```

## Параметры

Нет.

## Возвращаемое значение

Беззнаковый целый тип, способный представить максимальный размер любого объекта в памяти.

## Что делает

Определяет тип `size_t` — результат оператора `sizeof`, тип для индексации массивов, размеров контейнеров и передачи размеров в функции памяти.

## Примеры

```cpp
#include <cstdlib>
#include <iostream>

int main()
{
    int arr[10];
    std::cout << sizeof(arr) << std::endl;      // 40
    std::cout << sizeof(size_t) << std::endl;    // 8 (на 64-бит)
}
```

## Исключения

- **Исключения:** тип определения, не функция.

## Похожие функции

- `std::ptrdiff_t` — знаковый тип расстояния между указателями
