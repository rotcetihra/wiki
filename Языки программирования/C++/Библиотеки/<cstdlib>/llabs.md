## Прототип

```cpp
#include <cstdlib>

long long llabs(long long n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `n` | Значение типа `long long` |

## Возвращаемое значение

Абсолютное значение `n` типа `long long`.

## Что делает

Возвращает абсолютное значение целого числа длинного длинного типа.

## Примеры

```cpp
#include <cstdlib>
#include <iostream>

int main()
{
    long long x = -9223372036854775807LL;
    std::cout << std::llabs(x) << std::endl; // 9223372036854775807
}
```
