## Прототип

```cpp
#include <cstdlib>

ldiv_t ldiv(long numer, long denom);
```

## Параметры

| Параметр | Описание |
|---|---|
| `numer` | Числитель типа `long` |
| `denom` | Знаменатель типа `long` |

## Возвращаемое значение

Структура `ldiv_t` с полями `quot` (частное) и `rem` (остаток).

## Что делает

Выполняет целочисленное деление длинных целых чисел и возвращает частное и остаток.

## Примеры

```cpp
#include <cstdlib>
#include <iostream>

int main()
{
    auto result = std::ldiv(1000000L, 300000L);
    std::cout << "quot = " << result.quot << ", rem = " << result.rem << std::endl; // quot = 3, rem = 100000
}
```
