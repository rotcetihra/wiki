## Прототип

```cpp
#include <cstdlib>

long labs(long n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `n` | Значение типа `long` |

## Возвращаемое значение

Абсолютное значение `n` типа `long`.

## Что делает

Возвращает абсолютное значение длинного целого числа.

## Примеры

```cpp
#include <cstdlib>
#include <iostream>

int main()
{
    long x = -123456789L;
    std::cout << std::labs(x) << std::endl; // 123456789
}
```
