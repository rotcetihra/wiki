## Прототип

```cpp
#include <cstdlib>

typedef /* тип максимального выравнивания */ max_align_t;
```

## Параметры

Нет.

## Возвращаемое значение

Тип, который гарантирует выравнивание, достаточное для любого объекта, подпадающего под стандартное выравнивание.

## Что делает

Определяет тип `max_align_t` — минимальное выравнивание, которое подходит для любых скалярных типов. Используется в `std::aligned_storage` и `std::aligned_alloc`.

## Примеры

```cpp
#include <cstdlib>
#include <iostream>

int main()
{
    std::cout << alignof(max_align_t) << std::endl; // обычно 16
}
```

## Исключения

- **Исключения:** тип определения, не функция.

## Похожие функции

- `alignof` — выравнивание типа
