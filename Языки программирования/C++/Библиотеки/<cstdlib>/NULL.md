## Прототип

```cpp
#include <cstdlib>

#define NULL /* реализация-зависимое значение */
```

## Параметры

Нет.

## Возвращаемое значение

Макрос `NULL` определяет значение нулевого указателя. В C++ обычно определяется как `0` или `nullptr`.

## Что делает

Представляет нулевое значение указателя. В современном C++ рекомендуется использовать `nullptr`.

## Примеры

```cpp
#include <cstdlib>
#include <iostream>

int main()
{
    int* p = NULL;
    std::cout << (p == nullptr) << std::endl; // 1
}
```

## Исключения

- **Исключения:** макрос определения, не функция.

## Похожие функции

- `nullptr` — современный нулевой указатель (C++11)
