## Прототип

```cpp
#include <cstdlib>

int abs(int n);
long abs(long n);
long long abs(long long n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `n` | Целое число |

## Возвращаемое значение

Абсолютное значение `n`. Если результат не представляется в возвращаемом типе, поведение не определено.

## Что делает

Возвращает абсолютное значение целого числа.

## Примеры

```cpp
#include <cstdlib>
#include <iostream>

int main()
{
    std::cout << std::abs(-42) << std::endl; // 42
    std::cout << std::abs(7) << std::endl;   // 7
}
```

## Исключения

- **Исключения:** не бросает исключений. Для `INT_MIN` поведение не определено.
