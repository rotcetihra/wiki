## Прототип

```cpp
#include <cstdlib>

div_t div(int numer, int denom);
```

## Параметры

| Параметр | Описание |
|---|---|
| `numer` | Числитель |
| `denom` | Знаменатель |

## Возвращаемое значение

Структура `div_t` с полями `quot` (частное) и `rem` (остаток).

## Что делает

Выполняет целочисленное деление и возвращает частное и остаток одновременно.

## Примеры

```cpp
#include <cstdlib>
#include <iostream>

int main()
{
    auto result = std::div(17, 5);
    std::cout << "17/5 = " << result.quot << " rem " << result.rem << std::endl; // 3 rem 2
}
```
