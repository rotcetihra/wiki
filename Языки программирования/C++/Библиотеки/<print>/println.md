## Прототип

```cpp
#include <print>
template<class... Args>
void println(std::ostream& os, std::format_string<Args...> fmt, Args&&... args);
```

## Параметры

| Параметр | Описание |
|---|---|
| `os` | Выходной поток |
| `fmt` | Форматная строка |
| `args...` | Аргументы для форматирования |

## Возвращаемое значение

`void`.

## Что делает

Форматирует и выводит данные с символом перевода строки.

## Примеры

### Базовое использование

```cpp
std::println(std::cout, "Hello, {}!", "World");
std::println(std::cout, 42);
```
