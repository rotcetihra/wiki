## Прототип

```cpp
#include <print>
template<class... Args>
void print_to(std::ostream& os, std::format_string<Args...> fmt, Args&&... args);
```

## Параметры

| Параметр | Описание |
|---|---|
| `os` | Выходной поток |
| `fmt` | Форматная строка |
| `args...` | Аргументы для форматирования |

## Возвращаемое значение

`void`.

## Что делает

Форматирует и вывод данные в указанный поток (базовая перегрузка).

## Примеры

### Базовое использование

```cpp
std::print_to(std::cout, "Формат: {}", 42);
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
