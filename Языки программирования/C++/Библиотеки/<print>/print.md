## Прототип

```cpp
#include <print>
template<class... Args>
void print(std::ostream& os, std::format_string<Args...> fmt, Args&&... args);
```

## Параметры

| Параметр | Описание |
|---|---|
| `os` | Выходной поток |
| `fmt` | Форматная строка |
| `args...` | Аргументы для форматирования |

## Возвращаемое значение

`void`.

## Что делает

Форматирует и выводит данные в указанный поток.

## Примеры

### Базовое использование

```cpp
std::print(std::cout, "Hello, {}!", "World");
std::print(std::cout, "Значение: {:.2f}", 3.14159);
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
