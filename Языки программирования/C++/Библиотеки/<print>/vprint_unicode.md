## Прототип

```cpp
#include <print>
void vprint_unicode(std::string_view fmt, std::format_args args);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fmt` | Форматная строка |
| `args` | Аргументы форматирования |

## Возвращаемое значение

`void`.

## Что делает

Выводит данные в Unicode-формате с использованием `va_list`.

## Примеры

### Базовое использование

```cpp
std::vprint_unicode("Hello, {}!", std::make_format_args("World"));
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
