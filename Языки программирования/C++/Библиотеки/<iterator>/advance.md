## Прототип

```cpp
#include <iterator>
template<class InputIt, class Distance>
void advance(InputIt& it, Distance n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `it` | итератор (по ссылке) |
| `n` | количество позиций |

## Возвращаемое значение

Продвигает итератор `it` на `n` позиций.

## Что делает

Продвигает итератор `it` на `n` позиций. Модифицирует итератор на месте. Для двунаправленных итераторов `n` может быть отрицательным.

## Примеры

### Базовое использование

```cpp
std::vector<int> v = {10, 20, 30, 40, 50};
auto it = v.begin();
std::advance(it, 3);
std::cout << *it << std::endl; // 40
```
