## Прототип

```cpp
#include <iterator>
template<class Container>
constexpr auto crbegin(const Container& c) -> decltype(std::rbegin(c));
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | контейнер |

## Возвращаемое значение

Возвращает константный обратный итератор на последний элемент.

## Что делает

Возвращает константный обратный итератор на последний элемент.

## Примеры

### Базовое использование

```cpp
std::vector<int> v = {10, 20, 30};
for (auto it = std::crbegin(v); it != std::crend(v); ++it)
    std::cout << *it << ' ';
// 30 20 10
```
