## Прототип

```cpp
#include <iterator>
template<class Container>
constexpr auto cbegin(const Container& c) -> decltype(std::begin(c));
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | контейнер |

## Возвращаемое значение

Возвращает константный итератор на первый элемент.

## Что делает

Возвращает константный итератор на первый элемент.

## Примеры

### Базовое использование

```cpp
std::vector<int> v = {10, 20, 30};
auto it = std::cbegin(v);
// *it = 42; // Ошибка: константный итератор
```
