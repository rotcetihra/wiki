## Прототип

```cpp
#include <iterator>
template<class Container>
class insert_iterator;
```

## Параметры

| Параметр | Описание |
|---|---|
| `Container` | тип контейнера |

## Возвращаемое значение

Адаптер итератора, вставляющий элементы перед указанной позицией через `insert`.

## Что делает

Адаптер итератора, вставляющий элементы перед указанной позицией через `insert`. Создаётся `std::inserter()`.

## Примеры

### Базовое использование

```cpp
std::vector<int> v = {1, 5};
auto it = std::inserter(v, v.begin() + 1);
*it = 2; // v = {1, 2, 5}
*it = 3; // v = {1, 2, 3, 5}
```
