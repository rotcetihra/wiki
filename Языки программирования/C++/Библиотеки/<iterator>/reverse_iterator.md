## Возвращаемое значение

## Что делает

Адаптер итератора, инвертирующий направление обхода: `++` движет назад, `--` — вперёд. Используется для обратного перебора.

## Примеры

### Базовое использование

```cpp
std::vector<int> v = {1, 2, 3, 4, 5};
for (auto it = v.rbegin(); it != v.rend(); ++it)
    std::cout << *it << ' ';
// 5 4 3 2 1
```
