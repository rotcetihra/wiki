## Прототип

```cpp
#include <iterator>
template<class Container>
constexpr auto data(const Container& c) -> decltype(c.data());
template<class T, size_t N>
constexpr T* data(T (&array)[N]);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | контейнер |
| `array` | массив |

## Возвращаемое значение

Возвращает указатель на первый элемент массива или непрерывного контейнера.

## Что делает

Возвращает указатель на первый элемент массива или непрерывного контейнера.

## Примеры

### Базовое использование

```cpp
std::vector<int> v = {10, 20, 30};
const int* p = std::data(v);
std::cout << p[0] << ' ' << p[2] << std::endl; // 10 30
```
