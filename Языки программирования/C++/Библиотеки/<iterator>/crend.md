## Прототип

```cpp
#include <iterator>
template<class Container>
constexpr auto crend(const Container& c) -> decltype(std::rend(c));
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | контейнер |

## Возвращаемое значение

Возвращает константный обратный итератор перед первым элементом.

## Что делает

Возвращает константный обратный итератор перед первым элементом.

## Примеры

### Базовое использование

```cpp
std::vector<int> v = {10, 20, 30};
auto it = std::crend(v);
--it;
std::cout << *it << std::endl; // 10
```
