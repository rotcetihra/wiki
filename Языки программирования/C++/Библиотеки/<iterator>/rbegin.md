## Прототип

```cpp
#include <iterator>
template<class Container>
constexpr auto rbegin(Container& c) -> decltype(c.rbegin());
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | контейнер |

## Возвращаемое значение

Возвращает обратный итератор на последний элемент.

## Что делает

Возвращает обратный итератор на последний элемент. Обход в обратном порядке.

## Примеры

### Базовое использование

```cpp
std::vector<int> v = {10, 20, 30};
for (auto it = std::rbegin(v); it != std::rend(v); ++it)
    std::cout << *it << ' ';
// 30 20 10
```
