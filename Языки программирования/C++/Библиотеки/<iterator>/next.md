## Прототип

```cpp
#include <iterator>
template<class ForwardIt>
ForwardIt next(ForwardIt it, typename std::iterator_traits<ForwardIt>::difference_type n = 1);
```

## Параметры

| Параметр | Описание |
|---|---|
| `it` | итератор |
| `n` | количество позиций (по умолчанию 1) |

## Возвращаемое значение

Возвращает итератор, смещённый на `n` позиций вперёд.

## Что делает

Возвращает итератор, смещённый на `n` позиций вперёд. Не модифицирует исходный итератор.

## Примеры

### Базовое использование

```cpp
std::vector<int> v = {10, 20, 30, 40, 50};
auto it3 = std::next(v.begin(), 3);
std::cout << *it3 << std::endl; // 40
```
