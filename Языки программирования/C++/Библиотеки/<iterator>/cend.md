## Прототип

```cpp
#include <iterator>
template<class Container>
constexpr auto cend(const Container& c) -> decltype(std::end(c));
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | контейнер |

## Возвращаемое значение

Возвращает константный итератор на элемент после последнего.

## Что делает

Возвращает константный итератор на элемент после последнего.

## Примеры

### Базовое использование

```cpp
std::vector<int> v = {10, 20, 30};
auto it = std::cend(v);
--it;
std::cout << *it << std::endl; // 30
```
