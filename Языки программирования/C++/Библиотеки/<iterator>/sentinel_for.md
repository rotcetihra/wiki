## Прототип

```cpp
#include <iterator>
template<class S, class I>
concept sentinel_for = /* see description */;
```

## Параметры

| Параметр | Описание |
|---|---|
| `S` | проверяемый тип сигнала |
| `I` | тип итератора |

## Возвращаемое значение

Концепт `sentinel_for<S, I>` определяет, что `S` является сигналом для итератора `I`.

## Что делает

Концепт `sentinel_for<S, I>` определяет, что `S` является сигналом для итератора `I`. Сигнал обозначает конец диапазона (`i == s`).

## Примеры

### Базовое использование

```cpp
static_assert(std::sentinel_for<int*, int*>);
```
