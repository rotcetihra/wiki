## Прототип

```cpp
#include <iterator>
template<class BidirectionalIt>
BidirectionalIt prev(BidirectionalIt it, typename std::iterator_traits<BidirectionalIt>::difference_type n = 1);
```

## Параметры

| Параметр | Описание |
|---|---|
| `it` | итератор |
| `n` | количество позиций (по умолчанию 1) |

## Возвращаемое значение

Возвращает итератор, смещённый на `n` позиций назад.

## Что делает

Возвращает итератор, смещённый на `n` позиций назад. Требуется двунаправленный итератор.

## Примеры

### Базовое использование

```cpp
std::vector<int> v = {10, 20, 30, 40, 50};
auto it2 = std::prev(v.end(), 2);
std::cout << *it2 << std::endl; // 40
```
