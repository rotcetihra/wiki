## Описание библиотеки

Заголовочный файл `<unordered_set>` определяет класс `std::unordered_set` — множество уникальных элементов, хранящихся в хеш-таблице. Элементы не отсортированы. В среднем O(1) для поиска, вставки и удаления. Элементы должны иметь хеш-функцию и оператор `==`.

## Исключения

- **Исключения:** вставка может выбрасывать `std::bad_alloc`.
- **Безопасность в C++11:** безопасный доступ через итераторы.

## Стандарты

C++11, C++17, C++20, C++23.
