## Прототип

```cpp
#include <ostream>
std::ostream* tie(std::ostream* tie_str = nullptr);
```

## Параметры

| Параметр | Описание |
|---|---|
| `tie_str` | Указатель на поток для привязки (по умолчанию `nullptr`) |

## Возвращаемое значение

Предыдущий привязанный поток (или `nullptr`).

## Что делает

Связывает указанный поток с текущим. Связанный поток сбрасывается перед каждой операцией ввода-вывода.

## Примеры

### Базовое использование

```cpp
std::istream& in = std::cin;
std::ostream& out = std::cout;
in.tie(&out);  // cout будет выведен перед каждым запросом cin
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
