## Прототип

```cpp
#include <ostream>
std::basic_ostream& flush();
```

## Параметры

Параметры отсутствуют.

## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Сбрасывает буфер выходного потока.

## Примеры

### Базовое использование

```cpp
std::cout << "Важное сообщение";
std::cout.flush();
```
