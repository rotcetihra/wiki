## Прототип

```cpp
#include <ostream>
std::basic_ostream& put(char_type c);
```

## Параметры

| Параметр | Описание |
|---|---|
| `c` | Символ для вывода |

## Возвращаемое значение

Возвращает ссылку на поток (`*this`).

## Что делает

Выводит один символ в поток.

## Примеры

### Базовое использование

```cpp
std::cout.put('A');
```
