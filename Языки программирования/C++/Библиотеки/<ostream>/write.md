## Прототип

```cpp
#include <ostream>
std::basic_ostream& write(const char_type* s, std::streamsize n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s` | Указатель на данные |
| `n` | Количество символов для записи |

## Возвращаемое значение

Возвращает ссылку на поток (`*this`).

## Что делает

Выводит блок данных из буфера в поток.

## Примеры

### Базовое использование

```cpp
const char* data = "Hello";
std::cout.write(data, 5);
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
