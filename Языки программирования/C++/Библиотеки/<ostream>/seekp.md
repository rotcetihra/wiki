## Прототип

```cpp
#include <ostream>
std::basic_ostream& seekp(pos_type pos);
std::basic_ostream& seekp(off_type off, std::ios_base::seekdir dir);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pos` | Абсолютная позиция |
| `off` | Смещение относительно `dir` |
| `dir` | Направление поиска (`beg`, `cur`, `end`) |

## Возвращаемое значение

Возвращает ссылку на поток (`*this`).

## Что делает

Устанавливает позицию записи.

## Примеры

### Базовое использование

```cpp
std::ofstream file("example.txt");
file.seekp(0, std::ios::beg);  // Перейти в начало
```
