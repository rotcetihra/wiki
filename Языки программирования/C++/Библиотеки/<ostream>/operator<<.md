## Прототип

```cpp
#include <ostream>
template<class CharT, class Traits, class T>
std::basic_ostream<CharT, Traits>& operator<<(std::basic_ostream<CharT, Traits>& os, const T& value);
```

## Параметры

| Параметр | Описание |
|---|---|
| `os` | Выходной поток |
| `value` | Объект для вставки данных |

## Возвращаемое значение

Возвращает ссылку на поток (`*this`).

## Что делает

Вставляет данные из объекта в поток.

## Примеры

### Базовое использование

```cpp
std::cout << "Hello, World!" << std::endl;
std::cout << 42 << " " << 3.14 << std::endl;
```

## Исключения

- **Исключения:** См. описание конкретного потока.
- **Безопасность в C++11:** Не является потокобезопасным.
