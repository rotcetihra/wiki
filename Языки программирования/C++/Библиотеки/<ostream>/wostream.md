## Прототип

```cpp
#include <ostream>
using wostream = std::basic_ostream<wchar_t>;
```

## Описание

`std::wostream` — это псевдоним типа для `std::basic_ostream<wchar_t>`.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
