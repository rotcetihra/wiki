## Прототип

```cpp
#include <ostream>
template<class CharT, class Traits = std::char_traits<CharT>>
class basic_ostream : virtual public std::basic_ios<CharT, Traits>;
```

## Описание

Класс `std::basic_ostream` является базовым классом для всех выходных потоков. Он предоставляет операторы вставки `<<` и функции для форматированного и неформатированного вывода.

## Исключения

- **Исключения:** См. описание родительского класса.
- **Безопасность в C++11:** Не является потокобезопасным.
