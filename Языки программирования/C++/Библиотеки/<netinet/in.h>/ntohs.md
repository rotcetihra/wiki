## Прототип

```cpp
#include <netinet/in.h>\nuint16_t ntohs(uint16_t netshort);
```

## Параметры

| Параметр | Описание |
|---|---|
| `netshort` | значение в сетевом порядке |
## Возвращаемое значение

Значение в хостовом порядке.

## Что делает

Сетевой в хостовый (16 бит).

## Примеры

### Базовое использование

```cpp
uint16_t port = ntohs(sa.sin_port);
```
