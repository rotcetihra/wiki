## Прототип

```cpp
#include <exception>
class bad_exception : public exception;
```

## Возвращаемое значение

Не применимо (это тип).

## Что делает

Исключение для обозначения неизвестного типа.

## Примеры

### Базовое использование

```cpp
std::exception_ptr eptr = std::current_exception();
```
