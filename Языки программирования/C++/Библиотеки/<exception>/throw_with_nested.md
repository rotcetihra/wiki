## Прототип

```cpp
#include <exception>
template<class T>
[[noreturn]] void throw_with_nested(T&& t);
```

## Параметры

| Параметр | Описание |
|---|---|
| `t` | объект исключения |

## Возвращаемое значение

Функция ничего не возвращает.

## Что делает

Выбрасывает исключение с вложенным предыдущим.

## Примеры

### Базовое использование

```cpp
std::throw_with_nested(std::runtime_error("ошибка"));
```

## Исключения

- **Исключения:** Выбрасывает исключение типа `T`.
- **Безопасность в C++11:** Потокобезопасен.
