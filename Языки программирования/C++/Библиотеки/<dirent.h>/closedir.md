## Прототип

```cpp
#include <dirent.h>\nint closedir(DIR *dirp);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dirp` | указатель на DIR |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Закрывает каталог и освобождает ресурсы.

## Примеры

### Базовое использование

```cpp
closedir(d);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.\n- **Безопасность в C++11:** Потокобезопасна.
