## Прототип

```cpp
#include <dirent.h>\nstruct dirent *readdir(DIR *dirp);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dirp` | указатель на DIR |
## Возвращаемое значение

Указатель на dirent или NULL (конец каталога).

## Что делает

Читает следующую запись из каталога.

## Примеры

### Базовое использование

```cpp
struct dirent *e;\nwhile ((e = readdir(d)) != NULL)\n    printf("%s", e->d_name);
```

## Исключения

- **Исключения:** Возвращает NULL при ошибке/конце.\n- **Безопасность в C++11:** Не потокобезопасна.
