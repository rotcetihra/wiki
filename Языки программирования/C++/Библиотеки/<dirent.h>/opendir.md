## Прототип

```cpp
#include <dirent.h>\nDIR *opendir(const char *dirname);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dirname` | путь к каталогу |
## Возвращаемое значение

Указатель на DIR или NULL.

## Что делает

Открывает каталог для чтения.

## Примеры

### Базовое использование

```cpp
DIR *d = opendir("/tmp");
```

## Исключения

- **Исключения:** Возвращает NULL при ошибке.\n- **Безопасность в C++11:** Потокобезопасна для разных объектов.
