## Прототип

```cpp
#include <optional>
template<class T>
constexpr T& optional<T>::value() &;
```

## Возвращаемое значение

`T&` — ссылка на значение.

## Что делает

Возвращает значение или бросает bad_optional_access.

## Примеры

### Базовое использование

```cpp
std::optional<int> opt = 42;
std::cout << opt.value() << std::endl; // 42
```

## Исключения

- **Исключения:** `bad_optional_access` при пустом.
- **Безопасность в C++11:** Не является потокобезопасным.
