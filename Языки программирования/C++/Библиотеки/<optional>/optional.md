## Прототип

```cpp
#include <optional>
template<class T>
class optional;
```

## Параметры

| Параметр | Описание |
|---|---|
| `T` | тип хранимого значения |

## Возвращаемое значение

Не применимо (это тип).

## Что делает

Контейнер, который может хранить значение или быть пустым.

## Примеры

### Базовое использование

```cpp
std::optional<int> opt = 42;
std::cout << *opt << std::endl; // 42
```

## Исключения

- **Исключения:** `bad_optional_access` при доступе к пустому.
- **Безопасность в C++11:** Не является потокобезопасным.
