## Прототип

```cpp
#include <optional>
template<class T>
constexpr T optional<T>::value_or(T&& default_value) const&;
```

## Параметры

| Параметр | Описание |
|---|---|
| `default_value` | значение по умолчанию |

## Возвращаемое значение

`T` — значение или default.

## Что делает

Возвращает значение или default.

## Примеры

### Базовое использование

```cpp
std::optional<int> opt;
std::cout << opt.value_or(10) << std::endl; // 10
```

## Исключения

- **Исключения:** Может бросить `std::bad_alloc`.
- **Безопасность в C++11:** Потокобезопасен.
