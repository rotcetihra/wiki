## Прототип

```cpp
#include <optional>
template<class T>
void optional<T>::swap(optional<T>& other) noexcept(/*...*/);
```

## Параметры

| Параметр | Описание |
|---|---|
| `other` | другой optional |

## Возвращаемое значение

Ничего не возвращает.

## Что делает

Обменивает содержимое двух optional.

## Примеры

### Базовое использование

```cpp
std::optional<int> a=1, b=2;
a.swap(b);
// a=2, b=1
```

## Исключения

- **Исключения:** Не бросает исключений (если swap не бросает).
- **Безопасность в C++11:** Не является потокобезопасным.
