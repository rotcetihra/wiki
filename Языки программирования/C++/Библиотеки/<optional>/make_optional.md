## Прототип

```cpp
#include <optional>
template<class T>
constexpr optional<T> make_optional(T&& v);
```

## Параметры

| Параметр | Описание |
|---|---|
| `v` | значение |

## Возвращаемое значение

`optional<T>`.

## Что делает

Создаёт optional с выводом типа.

## Примеры

### Базовое использование

```cpp
auto opt = std::make_optional(42);
std::cout << *opt << std::endl; // 42
```

## Исключения

- **Исключения:** Может бросить `std::bad_alloc`.
- **Безопасность в C++11:** Потокобезопасен.
