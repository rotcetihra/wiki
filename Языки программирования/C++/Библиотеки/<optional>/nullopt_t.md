## Прототип

```cpp
#include <optional>
struct nullopt_t { explicit constexpr nullopt_t(int) {} };
```

## Возвращаемое значение

Не применимо (это тип).

## Что делает

Тип константы `std::nullopt`.

## Примеры

### Базовое использование

```cpp
std::nullopt_t x = std::nullopt;
```
