## Прототип

```cpp
#include <optional>
template<class T>
constexpr optional<T>::operator bool() const noexcept;
```

## Возвращаемое значение

`bool` — `true` если значение есть.

## Что делает

Неявное преобразование в bool.

## Примеры

### Базовое использование

```cpp
std::optional<int> opt = 42;
if (opt) std::cout << *opt << std::endl;
```

## Исключения

- **Исключения:** Не бросает исключений (`noexcept`).
- **Безопасность в C++11:** Потокобезопасен.
