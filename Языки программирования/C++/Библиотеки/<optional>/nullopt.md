## Прототип

```cpp
#include <optional>
struct nullopt_t;
inline constexpr nullopt_t nullopt{};
```

## Возвращаемое значение

Не применимо (это константа).

## Что делает

Маркер для обозначения пустого optional.

## Примеры

### Базовое использование

```cpp
std::optional<int> opt = std::nullopt;
```
