## Прототип

```cpp
#include <optional>
template<class T>
void optional<T>::reset() noexcept;
```

## Возвращаемое значение

Ничего не возвращает.

## Что делает

Уничтожает значение, делая optional пустым.

## Примеры

### Базовое использование

```cpp
std::optional<int> opt = 42;
opt.reset();
std::cout << opt.has_value() << std::endl; // false
```

## Исключения

- **Исключения:** Не бросает исключений (`noexcept`).
- **Безопасность в C++11:** Не является потокобезопасным.
