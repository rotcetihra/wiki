## Прототип

```cpp
#include <optional>
template<class T>
template<class... Args>
T& optional<T>::emplace(Args&&... args);
```

## Параметры

| Параметр | Описание |
|---|---|
| `args` | аргументы конструктора |

## Возвращаемое значение

`T&` — ссылка на значение.

## Что делает

Конструирует значение на месте.

## Примеры

### Базовое использование

```cpp
std::optional<std::string> opt;
opt.emplace("привет");
std::cout << *opt << std::endl;
```

## Исключения

- **Исключения:** Может бросить при конструировании.
- **Безопасность в C++11:** Не является потокобезопасным.
