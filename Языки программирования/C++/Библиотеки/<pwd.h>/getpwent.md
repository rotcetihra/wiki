## Прототип

```cpp
#include <pwd.h>\nstruct passwd *getpwent(void);
```

## Параметры

| Параметр | Описание |
|---|---|
Нет.
## Возвращаемое значение

Указатель на passwd или NULL.

## Что делает

Следующая запись пользователя.

## Примеры

### Базовое использование

```cpp
struct passwd *pw;\nwhile ((pw = getpwent()) != NULL);
```
