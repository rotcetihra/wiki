## Прототип

```cpp
#include <pwd.h>\nstruct passwd *getpwuid(uid_t uid);
```

## Параметры

| Параметр | Описание |
|---|---|
| `uid` | UID |
## Возвращаемое значение

Указатель на passwd или NULL.

## Что делает

Ищет пользователя по UID.

## Примеры

### Базовое использование

```cpp
struct passwd *pw = getpwuid(0);
```
