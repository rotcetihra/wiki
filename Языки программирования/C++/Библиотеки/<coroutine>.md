## Описание библиотеки

Заголовочный файл `<coroutine>` (C++20) определяет основные типы и функции для поддержки корутин — функций, которые могут приостанавливаться и возобновляться. Включает `coroutine_handle` для управления корутинами, `coroutine_traits` для вывода типов и вспомогательные типы приостановки.

## Исключения

- **Исключения:** `coroutine_handle::resume()` может бросать исключения из возобновлённой корутины.
- **Безопасность:** уничтожение `coroutine_handle` без `destroy()` — неопределённое поведение.

## Стандарты

C++20, C++23.
