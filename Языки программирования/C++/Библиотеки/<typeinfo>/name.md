## Прототип

```cpp
#include <typeinfo>
const char* type_info::name() const noexcept;
```

## Возвращаемое значение

`const char*` — имя типа.

## Что делает

Возвращает реализация-зависимое имя типа.

## Примеры

### Базовое использование

```cpp
std::cout << typeid(int).name() << std::endl;
```

## Исключения

- **Исключения:** Не бросает исключений (`noexcept`).
- **Безопасность в C++11:** Потокобезопасен.
