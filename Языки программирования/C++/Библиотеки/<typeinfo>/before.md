## Прототип

```cpp
#include <typeinfo>
bool type_info::before(const type_info& rhs) const noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `rhs` | другой type_info |

## Возвращаемое значение

`bool` — лексикографический порядок.

## Что делает

Порядок типов для сортировки.

## Примеры

### Базовое использование

```cpp
bool b = typeid(int).before(typeid(double));
```

## Исключения

- **Исключения:** Не бросает исключений (`noexcept`).
- **Безопасность в C++11:** Потокобезопасен.
