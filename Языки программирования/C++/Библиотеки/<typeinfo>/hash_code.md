## Прототип

```cpp
#include <typeinfo>
std::size_t type_info::hash_code() const noexcept;
```

## Возвращаемое значение

`std::size_t` — хеш-код типа.

## Что делает

Возвращает хеш-код типа.

## Примеры

### Базовое использование

```cpp
const std::type_info& ti = typeid(int);
std::size_t h = ti.hash_code();
```

## Исключения

- **Исключения:** Не бросает исключений (`noexcept`).
- **Безопасность в C++11:** Потокобезопасен.
