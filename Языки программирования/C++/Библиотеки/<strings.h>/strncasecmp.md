## Прототип

```cpp
#include <strings.h>\nint strncasecmp(const char *s1, const char *s2, size_t n);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1`, `s2` | строки |\n| `n` | макс. символов |
## Возвращаемое значение

0, <0, >0.

## Что делает

Сравнение без учёта регистра с ограничением.

## Примеры

### Базовое использование

```cpp
strncasecmp("abc", "ABD", 2);
```
