## Прототип

```cpp
#include <strings.h>\nint ffs(int i);
```

## Параметры

| Параметр | Описание |
|---|---|
| `i` | значение |
## Возвращаемое значение

Номер первого бита (1-based) или 0.

## Что делает

Находит первый установленный бит.

## Примеры

### Базовое использование

```cpp
int b = ffs(0x10);
```
