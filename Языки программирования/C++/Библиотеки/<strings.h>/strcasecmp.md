## Прототип

```cpp
#include <strings.h>\nint strcasecmp(const char *s1, const char *s2);
```

## Параметры

| Параметр | Описание |
|---|---|
| `s1`, `s2` | строки |
## Возвращаемое значение

0, <0, >0.

## Что делает

Сравнение без учёта регистра.

## Примеры

### Базовое использование

```cpp
if (strcasecmp("abc", "ABC") == 0) printf("equal");
```
