## Описание библиотеки

Заголовочный файл `<atomic>` определяет типы и функции для атомарных операций, которые выполняются без упреждающего выполнения (data races). Атомарные операции гарантируют видимость изменений между потоками без использования мьютексов.

## Исключения

- **Исключения:** атомарные операции не бросают исключений.
- **Безопасность:** атомарные операции потокобезопасны поdesign. Объекты `atomic` не являются copyable/movable.

## Стандарты

C++11, C++20, C++23.
