## Описание библиотеки

Заголовочный файл `<condition_variable>` определяет типы и функции для синхронизации потоков с помощью переменных условиях. Переменная условия позволяет потокам ожидать наступления определённого условия, пока другой поток не уведомит о его изменении. Этот механизм является основой для построения producer-consumer паттернов и других многопоточных алгоритмов синхронизации.

## Исключения

- **Исключения:** Класс `std::condition_variable` не предоставляет自己的 исключения. Ошибки синхронизации приводят к неопределённому поведению.
- **Безопасность в C++11:** Операции ожидания и уведомления потокобезопасны. Переменная условия должна использоваться совместно с `std::mutex` для защиты разделяемых данных.

## Стандарты

C++11, C++17, C++20.
