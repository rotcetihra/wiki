## Прототип

```cpp
#include <unistd.h>
int dup2(int oldfd, int newfd);
```

## Параметры

| Параметр | Описание |
|---|---|
| `oldfd` | исходный файловый дескриптор |
| `newfd` | целевой файловый дескриптор |
## Возвращаемое значение

Новый файловый дескриптор (`newfd`) или -1 при ошибке.

## Что делает

Дублирует `oldfd` в `newfd`. Если `newfd` уже открыт, он закрывается.

## Примеры

### Базовое использование

```cpp
dup2(fd, STDOUT_FILENO);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
