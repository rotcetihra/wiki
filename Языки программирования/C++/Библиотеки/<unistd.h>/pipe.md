## Прототип

```cpp
#include <unistd.h>
int pipe(int pipefd[2]);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pipefd` | массив из двух дескрипторов (pipefd[0] — чтение, pipefd[1] — запись) |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Создаёт анонимный канал (pipe) для межпроцессного взаимодействия.

## Примеры

### Базовое использование

```cpp
int pipefd[2];
pipe(pipefd);
write(pipefd[1], "Hello", 5);
char buf[1024];
read(pipefd[0], buf, sizeof(buf));
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
