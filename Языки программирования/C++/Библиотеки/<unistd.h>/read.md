## Прототип

```cpp
#include <unistd.h>
ssize_t read(int fd, void *buf, size_t count);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор |
| `buf` | буфер для данных |
| `count` | максимальное количество байт для чтения |
## Возвращаемое значение

Количество прочитанных байт, 0 при EOF, -1 при ошибке.

## Что делает

Читает до `count` байт из файлового дескриптора `fd` в буфер `buf`.

## Примеры

### Базовое использование

```cpp
char buf[1024];
ssize_t n = read(fd, buf, sizeof(buf));
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке, устанавливает `errno`.
- **Безопасность в C++11:** Потокобезопасна для разных дескрипторов.
