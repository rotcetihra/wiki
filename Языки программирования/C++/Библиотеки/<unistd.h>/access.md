## Прототип

```cpp
#include <unistd.h>
int access(const char *pathname, int mode);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pathname` | путь к файлу |
| `mode` | режим проверки (R_OK, W_OK, X_OK, F_OK) |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Проверяет, имеет ли процесс права доступа к файлу.

## Примеры

### Базовое использование

```cpp
if (access("file.txt", R_OK) == 0)
    printf("Файл доступен для чтения");
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
