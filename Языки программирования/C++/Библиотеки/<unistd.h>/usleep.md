## Прототип

```cpp
#include <unistd.h>
int usleep(useconds_t usec);
```

## Параметры

| Параметр | Описание |
|---|---|
| `usec` | количество микросекунд для сна |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Приостанавливает выполнение текущего потока на указанное количество микросекунд. Устаревшая — используйте `nanosleep()`.

## Примеры

### Базовое использование

```cpp
usleep(500000); // 0.5 секунды
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
