## Прототип

```cpp
#include <unistd.h>
int chown(const char *pathname, uid_t owner, gid_t group);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pathname` | путь к файлу |
| `owner` | новый владелец (или -1 без изменений) |
| `group` | новая группа (или -1 без изменений) |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Изменяет владельца и группу файла.

## Примеры

### Базовое использование

```cpp
chown("file.txt", 1000, 1000);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
