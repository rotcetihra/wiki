## Прототип

```cpp
#include <unistd.h>
int chdir(const char *path);
```

## Параметры

| Параметр | Описание |
|---|---|
| `path` | путь к новому текущему каталогу |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Меняет текущий рабочий каталог процесса.

## Примеры

### Базовое использование

```cpp
chdir("/home/user");
char buf[1024];
getcwd(buf, sizeof(buf));
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
