## Прототип

```cpp
#include <unistd.h>
pid_t fork(void);
```

## Параметры

| Параметр | Описание |
|---|---|
Нет параметров.
## Возвращаемое значение

PID дочернего процесса в родительском, 0 в дочернем, -1 при ошибке.

## Что делает

Создаёт дочерний процесс, являющийся точной копией родительского.

## Примеры

### Базовое использование

```cpp
pid_t pid = fork();
if (pid == 0) {
    // дочерний процесс
} else if (pid > 0) {
    // родительский процесс
}
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
