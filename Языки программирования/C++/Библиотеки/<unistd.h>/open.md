## Прототип

```cpp
#include <fcntl.h>
int open(const char *pathname, int flags, ... /* mode_t mode */);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pathname` | путь к файлу |
| `flags` | флаги (O_RDONLY, O_WRONLY, O_RDWR, O_CREAT) |
| `mode` | права доступа (при O_CREAT) |
## Возвращаемое значение

Файловый дескриптор или -1 при ошибке.

## Что делает

Открывает файл и возвращает файловый дескриптор.

## Примеры

### Базовое использование

```cpp
int fd = open("file.txt", O_RDONLY);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна для разных дескрипторов.
