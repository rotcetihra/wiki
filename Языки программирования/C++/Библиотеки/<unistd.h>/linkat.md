## Прототип

```cpp
#include <fcntl.h>
int linkat(int olddirfd, const char *oldpath,
           int newdirfd, const char *newpath, int flags);
```

## Параметры

| Параметр | Описание |
|---|---|
| `olddirfd` | дескриптор исходного каталога |
| `oldpath` | исходный путь |
| `newdirfd` | дескриптор целевого каталога |
| `newpath` | целевой путь |
| `flags` | флаги (AT_SYMLINK_FOLLOW) |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Аналог `link()`, но пути разрешаются относительно указанных каталогов.

## Примеры

### Базовое использование

```cpp
linkat(AT_FDCWD, "file.txt", AT_FDCWD, "link.txt", AT_SYMLINK_FOLLOW);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
