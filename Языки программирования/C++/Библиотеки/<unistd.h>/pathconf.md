## Прототип

```cpp
#include <unistd.h>
long pathconf(const char *path, int name);
```

## Параметры

| Параметр | Описание |
|---|---|
| `path` | путь к файлу или каталогу |
| `name` | параметр (PC_LINK_MAX, PC_PATH_MAX и т.д.) |
## Возвращаемое значение

Значение параметра или -1 при ошибке.

## Что делает

Возвращает значение параметра конфигурации для указанного пути.

## Примеры

### Базовое использование

```cpp
long max_name = pathconf("/tmp", PC_NAME_MAX);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
