## Прототип

```cpp
#include <unistd.h>
int close(int fd);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Закрывает файловый дескриптор и освобождает связанные ресурсы.

## Примеры

### Базовое использование

```cpp
close(fd);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна для разных дескрипторов.
