## Прототип

```cpp
#include <unistd.h>
int unlink(const char *pathname);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pathname` | путь к файлу |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Удаляет файл по указанному пути. Если ссылки на файл больше нет, файл удаляется.

## Примеры

### Базовое использование

```cpp
unlink("/tmp/file.txt");
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
