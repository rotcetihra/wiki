## Прототип

```cpp
#include <unistd.h>
off_t lseek(int fd, off_t offset, int whence);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор |
| `offset` | смещение |
| `whence` | начало отсчёта (SEEK_SET, SEEK_CUR, SEEK_END) |
## Возвращаемое значение

Новая позиция или -1 при ошибке.

## Что делает

Устанавливает позицию чтения/записи в файле.

## Примеры

### Базовое использование

```cpp
lseek(fd, 0, SEEK_SET); // в начало файла
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна для разных дескрипторов.
