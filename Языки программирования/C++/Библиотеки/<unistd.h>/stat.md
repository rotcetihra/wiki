## Прототип

```cpp
#include <sys/stat.h>
int stat(const char *pathname, struct stat *statbuf);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pathname` | путь к файлу |
| `statbuf` | указатель на структуру для результата |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Получает информацию о файле (размер, права, времена и т.д.).

## Примеры

### Базовое использование

```cpp
struct stat st;
if (stat("file.txt", &st) == 0) {
    printf("Размер: %ld", st.st_size);
}
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
