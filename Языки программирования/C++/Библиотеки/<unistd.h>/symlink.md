## Прототип

```cpp
#include <unistd.h>
int symlink(const char *target, const char *linkpath);
```

## Параметры

| Параметр | Описание |
|---|---|
| `target` | путь, на который указывает ссылка |
| `linkpath` | путь к создаваемой ссылке |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Создаёт символьную ссылку `linkpath`, указывающую на `target`.

## Примеры

### Базовое использование

```cpp
symlink("/usr/bin/python3", "/usr/bin/python");
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
