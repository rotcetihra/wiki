## Прототип

```cpp
#include <unistd.h>
gid_t getgid(void);
```

## Параметры

| Параметр | Описание |
|---|---|
Нет параметров.
## Возвращаемое значение

Реальный идентификатор группы (`gid_t`).

## Что делает

Возвращает реальный GID текущего процесса.

## Примеры

### Базовое использование

```cpp
printf("GID: %d", getgid());
```
