## Прототип

```cpp
#include <unistd.h>
uid_t getuid(void);
```

## Параметры

| Параметр | Описание |
|---|---|
Нет параметров.
## Возвращаемое значение

Реальный идентификатор пользователя (`uid_t`).

## Что делает

Возвращает реальный UID текущего процесса (UID пользователя, запустившего процесс).

## Примеры

### Базовое использование

```cpp
printf("UID: %d", getuid());
```
