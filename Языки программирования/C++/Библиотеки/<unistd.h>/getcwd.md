## Прототип

```cpp
#include <unistd.h>
char *getcwd(char *buf, size_t size);
```

## Параметры

| Параметр | Описание |
|---|---|
| `buf` | буфер для пути |
| `size` | размер буфера |
## Возвращаемое значение

Указатель на `buf` при успехе, NULL при ошибке.

## Что делает

Возвращает полный путь текущего рабочего каталога.

## Примеры

### Базовое использование

```cpp
char buf[1024];
if (getcwd(buf, sizeof(buf)) != NULL)
    printf("Текущий каталог: %s", buf);
```

## Исключения

- **Исключения:** Возвращает NULL при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
