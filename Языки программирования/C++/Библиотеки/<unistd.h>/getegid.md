## Прототип

```cpp
#include <unistd.h>
gid_t getegid(void);
```

## Параметры

| Параметр | Описание |
|---|---|
Нет параметров.
## Возвращаемое значение

Эффективный идентификатор группы (`gid_t`).

## Что делает

Возвращает эффективный GID текущего процесса.

## Примеры

### Базовое использование

```cpp
printf("EGID: %d", getegid());
```
