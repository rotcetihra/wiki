## Прототип

```cpp
#include <unistd.h>
unsigned int alarm(unsigned int seconds);
```

## Параметры

| Параметр | Описание |
|---|---|
| `seconds` | количество секунд до отправки SIGALRM |
## Возвращаемое значение

Предыдущее значение таймера (количество оставшихся секунд).

## Что делает

Устанавливает таймер, который отправит сигнал `SIGALRM` процессу через указанное количество секунд.

## Примеры

### Базовое использование

```cpp
alarm(10); // SIGALRM через 10 секунд
```

## Исключения

- **Исключения:** Возвращает предыдущее значение таймера.
- **Безопасность в C++11:** Потокобезопасна.
