## Прототип

```cpp
#include <unistd.h>
int dup(int oldfd);
```

## Параметры

| Параметр | Описание |
|---|---|
| `oldfd` | исходный файловый дескриптор |
## Возвращаемое значение

Новый файловый дескриптор или -1 при ошибке.

## Что делает

Создаёт копию файлового дескриптора с наименьшим доступным номером.

## Примеры

### Базовое использование

```cpp
int new_fd = dup(fd);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
