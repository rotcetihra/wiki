## Прототип

```cpp
#include <fcntl.h>
int faccessat(int dirfd, const char *pathname, int mode, int flags);
```

## Параметры

| Параметр | Описание |
|---|---|
| `dirfd` | дескриптор каталога (AT_FDCWD — текущий) |
| `pathname` | путь к файлу |
| `mode` | режим проверки |
| `flags` | флаги (AT_EACCESS, AT_SYMLINK_NOFOLLOW) |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Аналог `access()`, но путь разрешается относительно каталога `dirfd`.

## Примеры

### Базовое использование

```cpp
if (faccessat(AT_FDCWD, "file.txt", R_OK, 0) == 0)
    printf("Доступен");
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
