## Прототип

```cpp
#include <unistd.h>
unsigned int sleep(unsigned int seconds);
```

## Параметры

| Параметр | Описание |
|---|---|
| `seconds` | количество секунд для сна |
## Возвращаемое значение

Оставшееся количество секунд, если сон был прерван сигналом.

## Что делает

Приостанавливает выполнение текущего потока на указанное количество секунд.

## Примеры

### Базовое использование

```cpp
printf("Ждём 5 секунд...\n");
sleep(5);
printf("Готово!\n");
```

## Исключения

- **Исключения:** Может возвращать оставшееся время при прерывании сигналом.
- **Безопасность в C++11:** Потокобезопасна.
