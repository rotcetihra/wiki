## Прототип

```cpp
#include <unistd.h>
int setuid(uid_t uid);
```

## Параметры

| Параметр | Описание |
|---|---|
| `uid` | новый идентификатор пользователя |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Устанавливает реальный и эффективный UID процесса.

## Примеры

### Базовое использование

```cpp
setuid(1000);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке (EPERM если недостаточно прав).
- **Безопасность в C++11:** Потокобезопасна.
