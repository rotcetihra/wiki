## Прототип

```cpp
#include <unistd.h>
int fchdir(int fd);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор каталога |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Меняет текущий каталог, используя открытый файловый дескриптор каталога.

## Примеры

### Базовое использование

```cpp
int dir_fd = open("/tmp", O_RDONLY);
fchdir(dir_fd);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
