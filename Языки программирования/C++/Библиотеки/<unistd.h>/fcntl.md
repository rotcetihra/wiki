## Прототип

```cpp
#include <fcntl.h>
int fcntl(int fd, int cmd, ... /* arg */);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор |
| `cmd` | команда (F_DUPFD, F_GETFD, F_SETFD, F_GETFL, F_SETFL) |
| `arg` | аргумент команды |
## Возвращаемое значение

Зависит от команды.

## Что делает

Выполняет различные операции над файловым дескриптором.

## Примеры

### Базовое использование

```cpp
int flags = fcntl(fd, F_GETFL);
fcntl(fd, F_SETFL, flags | O_NONBLOCK);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
