## Прототип

```cpp
#include <unistd.h>
pid_t getppid(void);
```

## Параметры

| Параметр | Описание |
|---|---|
Нет параметров.
## Возвращаемое значение

PID родительского процесса.

## Что делает

Возвращает PID родительского процесса текущего процесса.

## Примеры

### Базовое использование

```cpp
printf("PPID: %d", getppid());
```
