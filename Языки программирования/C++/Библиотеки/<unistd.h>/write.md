## Прототип

```cpp
#include <unistd.h>
ssize_t write(int fd, const void *buf, size_t count);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор |
| `buf` | данные для записи |
| `count` | количество байт для записи |
## Возвращаемое значение

Количество записанных байт или -1 при ошибке.

## Что делает

Записывает до `count` байт из буфера `buf` в файловый дескриптор `fd`.

## Примеры

### Базовое использование

```cpp
write(fd, "Hello", 5);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке, устанавливает `errno`.
- **Безопасность в C++11:** Потокобезопасна для разных дескрипторов.
