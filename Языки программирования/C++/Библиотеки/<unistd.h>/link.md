## Прототип

```cpp
#include <unistd.h>
int link(const char *path1, const char *path2);
```

## Параметры

| Параметр | Описание |
|---|---|
| `path1` | существующий файл |
| `path2` | путь к новой ссылке |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Создаёт новую жёсткую ссылку на файл.

## Примеры

### Базовое использование

```cpp
link("/tmp/original.txt", "/tmp/link.txt");
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
