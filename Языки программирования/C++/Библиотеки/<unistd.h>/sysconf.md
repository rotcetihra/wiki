## Прототип

```cpp
#include <unistd.h>
long sysconf(int name);
```

## Параметры

| Параметр | Описание |
|---|---|
| `name` | параметр конфигурации (_SC_ARG_MAX, _SC_OPEN_MAX и т.д.) |
## Возвращаемое значение

Значение параметра или -1 при ошибке.

## Что делает

Возвращает значение указанного параметра конфигурации системы.

## Примеры

### Базовое использование

```cpp
long max_files = sysconf(_SC_OPEN_MAX);
printf("Макс. открытых файлов: %ld", max_files);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
