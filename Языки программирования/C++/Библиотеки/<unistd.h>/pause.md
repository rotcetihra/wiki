## Прототип

```cpp
#include <unistd.h>
int pause(void);
```

## Параметры

| Параметр | Описание |
|---|---|
Нет параметров.
## Возвращаемое значение

-1 при ошибке (устанавливает `errno` = EINTR).

## Что делает

Приостанавливает выполнение текущего процесса до тех пор, пока не будет доставлен блокирующий сигнал.

## Примеры

### Базовое использование

```cpp
pause();
```

## Исключения

- **Исключения:** Возвращает -1 с errno = EINTR при прерывании сигналом.
- **Безопасность в C++11:** Потокобезопасна.
