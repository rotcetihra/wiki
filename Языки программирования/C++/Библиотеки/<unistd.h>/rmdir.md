## Прототип

```cpp
#include <unistd.h>
int rmdir(const char *path);
```

## Параметры

| Параметр | Описание |
|---|---|
| `path` | путь к каталогу |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Удаляет пустой каталог по указанному пути.

## Примеры

### Базовое использование

```cpp
rmdir("/tmp/mydir");
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке (ENOTEMPTY если каталог не пуст).
- **Безопасность в C++11:** Потокобезопасна.
