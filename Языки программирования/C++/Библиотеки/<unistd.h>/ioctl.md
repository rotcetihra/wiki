## Прототип

```cpp
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long request, ... /* arg */);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор |
| `request` | код операции |
| `arg` | аргумент операции |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Выполняет операцию управления устройством (например, получение размера терминала).

## Примеры

### Базовое использование

```cpp
struct winsize ws;
ioctl(STDOUT_FILENO, TIOCGWINSZ, &ws);
printf("%dx%d", ws.ws_col, ws.ws_row);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
