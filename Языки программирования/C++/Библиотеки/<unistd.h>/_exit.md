## Прототип

```cpp
#include <unistd.h>
void _exit(int status);
```

## Параметры

| Параметр | Описание |
|---|---|
| `status` | код завершения процесса |
## Возвращаемое значение

Нет возвращаемого значения (void).

## Что делает

Немедленно завершает процесс с указанным кодом завершения. Не вызывает обработчики `atexit()` и не очищает буферы потоков.

## Примеры

### Базовое использование

```cpp
_exit(0);
```

## Исключения

- **Исключения:** Не определено поведение.
- **Безопасность в C++11:** Потокобезопасна.
