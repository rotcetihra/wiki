## Прототип

```cpp
#include <unistd.h>
ssize_t readlink(const char *path, char *buf, size_t bufsiz);
```

## Параметры

| Параметр | Описание |
|---|---|
| `path` | путь к символической ссылке |
| `buf` | буфер для результата |
| `bufsiz` | размер буфера |
## Возвращаемое значение

Количество прочитанных байт или -1 при ошибке.

## Что делает

Читает содержимое символьной ссылки в буфер.

## Примеры

### Базовое использование

```cpp
char buf[1024];
ssize_t len = readlink("/usr/bin/python", buf, sizeof(buf) - 1);
buf[len] = '\0';
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
