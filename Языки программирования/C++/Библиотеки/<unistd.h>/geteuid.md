## Прототип

```cpp
#include <unistd.h>
uid_t geteuid(void);
```

## Параметры

| Параметр | Описание |
|---|---|
Нет параметров.
## Возвращаемое значение

Эффективный идентификатор пользователя (`uid_t`).

## Что делает

Возвращает эффективный UID текущего процесса (используется для проверки прав доступа).

## Примеры

### Базовое использование

```cpp
printf("EUID: %d", geteuid());
```
