## Прототип

```cpp
#include <unistd.h>
long fpathconf(int fd, int name);
```

## Параметры

| Параметр | Описание |
|---|---|
| `fd` | файловый дескриптор |
| `name` | параметр |
## Возвращаемое значение

Значение параметра или -1 при ошибке.

## Что делает

Аналог `pathconf()`, но принимает файловый дескриптор.

## Примеры

### Базовое использование

```cpp
long max_name = fpathconf(fd, PC_NAME_MAX);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
