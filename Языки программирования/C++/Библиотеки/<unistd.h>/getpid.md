## Прототип

```cpp
#include <unistd.h>
pid_t getpid(void);
```

## Параметры

| Параметр | Описание |
|---|---|
Нет параметров.
## Возвращаемое значение

Идентификатор текущего процесса (`pid_t`).

## Что делает

Возвращает PID текущего процесса.

## Примеры

### Базовое использование

```cpp
printf("PID: %d", getpid());
```
