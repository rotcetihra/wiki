## Прототип

```cpp
#include <sys/stat.h>
int lstat(const char *pathname, struct stat *statbuf);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pathname` | путь к файлу |
| `statbuf` | указатель на структуру для результата |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Аналог `stat()`, но если `pathname` является символьной ссылкой, возвращает информацию о самой ссылке, а не о файле, на который она указывает.

## Примеры

### Базовое использование

```cpp
lstat("symlink", &st);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
