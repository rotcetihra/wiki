## Прототип

```cpp
#include <unistd.h>
int setgid(gid_t gid);
```

## Параметры

| Параметр | Описание |
|---|---|
| `gid` | новый идентификатор группы |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Устанавливает реальный и эффективный GID процесса.

## Примеры

### Базовое использование

```cpp
setgid(1000);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
