## Прототип

```cpp
#include <unistd.h>
int execl(const char *path, const char *arg, ... /* NULL */);
int execlp(const char *file, const char *arg, ... /* NULL */);
int execle(const char *path, const char *arg, ... /* NULL, char *envp[] */);
int execv(const char *path, char *const argv[]);
int execvp(const char *file, char *const argv[]);
```

## Параметры

| Параметр | Описание |
|---|---|
| `path`/`file` | путь или имя файла для запуска |
| `arg`/`argv` | аргументы командной строки |
| `envp` | окружение (для `execle`) |
## Возвращаемое значение

-1 при ошибке (при успехе управление не возвращается).

## Что делает

Загружает и запускает новый процесс, заменяя текущий образ памяти. Группа `exec*`提供了不同的 способов передачи аргументов.

## Примеры

### Базовое использование

```cpp
execlp("ls", "ls", "-la", NULL);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
