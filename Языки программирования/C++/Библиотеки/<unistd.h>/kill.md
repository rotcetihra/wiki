## Прототип

```cpp
#include <signal.h>
int kill(pid_t pid, int sig);
```

## Параметры

| Параметр | Описание |
|---|---|
| `pid` | идентификатор процесса (или -1 для всех, 0 для группы) |
| `sig` | номер сигнала |
## Возвращаемое значение

0 при успехе, -1 при ошибке.

## Что делает

Отправляет сигнал указанному процессу или группе процессов.

## Примеры

### Базовое использование

```cpp
kill(pid, SIGTERM);
```

## Исключения

- **Исключения:** Возвращает -1 при ошибке.
- **Безопасность в C++11:** Потокобезопасна.
