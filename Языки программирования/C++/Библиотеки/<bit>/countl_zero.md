## Прототип

```cpp
#include <bit>

template<class T>
constexpr int countl_zero(T x) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Беззнаковое целое число |

## Возвращаемое значение

Количество ведущих нулевых бит в двичном представлении `x`. Для `x == 0` возвращает `sizeof(T) * 8`.

## Что делает

Подсчитывает количество нулей в старших разрядах перед первым единичным битом.

## Примеры

```cpp
#include <bit>
#include <iostream>

int main()
{
    std::cout << std::countl_zero(0b00010000u) << std::endl; // 3
    std::cout << std::countl_zero(0b10000000u) << std::endl; // 0
}
```
