## Прототип

```cpp
#include <bit>

template<class To, class From>
constexpr To bit_cast(const From& from) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `from` | Исходное значение |

## Возвращаемое значение

Значение типа `To`, полученное побитовым преобразованием `from`.

## Что делает

Выполняет побитовое преобразование между типами `From` и `To`. Типы должны иметь одинаковый размер и быть trivially copyable.

## Примеры

```cpp
#include <bit>
#include <iostream>

int main()
{
    float f = 3.14f;
    unsigned int bits = std::bit_cast<unsigned int>(f);

    std::cout << std::hex << bits << std::endl; // 4048f5c3
}
```
