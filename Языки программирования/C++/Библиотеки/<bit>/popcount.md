## Прототип

```cpp
#include <bit>

template<class T>
constexpr int popcount(T x) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Беззнаковое целое число |

## Возвращаемое значение

Количество единичных бит в двичном представлении `x`.

## Что делает

Подсчитывает количество бит со значением 1 (population count / Hamming weight).

## Примеры

```cpp
#include <bit>
#include <iostream>

int main()
{
    std::cout << std::popcount(0b10101010u) << std::endl; // 4
    std::cout << std::popcount(0b11111111u) << std::endl; // 8
    std::cout << std::popcount(0u) << std::endl;          // 0
}
```
