## Прототип

```cpp
#include <bit>

template<class T>
constexpr T bit_floor(T x) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Беззнаковое целое число |

## Возвращаемое значение

Большая степень двойки, не превосходящая `x`. Для `x == 0` возвращает 0.

## Что делает

Находит ближайшую степень двойки, которая не больше заданного числа.

## Примеры

```cpp
#include <bit>
#include <iostream>

int main()
{
    std::cout << std::bit_floor(5u) << std::endl;  // 4
    std::cout << std::bit_floor(8u) << std::endl;  // 8
    std::cout << std::bit_floor(0u) << std::endl;  // 0
}
```
