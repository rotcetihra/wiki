## Прототип

```cpp
#include <bit>

template<class T>
constexpr int countr_zero(T x) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Беззнаковое целое число |

## Возвращаемое значение

Количество завершающих нулевых бит. Для `x == 0` возвращает `sizeof(T) * 8`.

## Что делает

Подсчитывает количество нулей в младших разрядах перед первым единичным битом.

## Примеры

```cpp
#include <bit>
#include <iostream>

int main()
{
    std::cout << std::countr_zero(0b00010000u) << std::endl; // 4
    std::cout << std::countr_zero(0b00000001u) << std::endl; // 0
}
```
