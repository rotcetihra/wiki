## Прототип

```cpp
#include <bit>

template<class T>
constexpr bool has_single_bit(T x) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Беззнаковое целое число |

## Возвращаемое значение

`true` если `x` является степенью двойки (и не равно 0).

## Что делает

Проверяет, что в двичном представлении `x` ровно один бит установлен в 1.

## Примеры

```cpp
#include <bit>
#include <iostream>

int main()
{
    std::cout << std::has_single_bit(8u) << std::endl;  // 1 (степень двойки)
    std::cout << std::has_single_bit(6u) << std::endl;  // 0
}
```
