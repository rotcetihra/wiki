## Прототип

```cpp
#include <bit>

template<class T>
constexpr T rotl(T x, int s) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Беззнаковое целое число |
| `s` | Количество бит для циклического сдвига (положительное — влево, отрицательное — вправо) |

## Возвращаемое значение

Результат циклического сдвига `x` на `s` бит влево.

## Что делает

Выполняет циклический (ротационный) сдвиг влево. Биты, вытесненные за старший разряд, появляются в младшем.

## Примеры

```cpp
#include <bit>
#include <iostream>

int main()
{
    unsigned int x = 0b00000001u;
    unsigned int r = std::rotl(x, 3);
    // r: 0b00001000

    std::cout << r << std::endl; // 8
}
```
