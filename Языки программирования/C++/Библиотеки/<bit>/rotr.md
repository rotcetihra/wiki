## Прототип

```cpp
#include <bit>

template<class T>
constexpr T rotr(T x, int s) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Беззнаковое целое число |
| `s` | Количество бит для циклического сдвига |

## Возвращаемое значение

Результат циклического сдвига `x` на `s` бит вправо.

## Что делает

Выполняет циклический (ротационный) сдвиг вправо. Биты, вытесненные за младший разряд, появляются в старшем.

## Примеры

```cpp
#include <bit>
#include <iostream>

int main()
{
    unsigned int x = 0b10000000u;
    unsigned int r = std::rotr(x, 3);
    // r: 0b00000001

    std::cout << r << std::endl; // 1
}
```
