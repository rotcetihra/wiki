## Прототип

```cpp
#include <bit>

template<class T>
constexpr T bit_ceil(T x) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Беззнаковое целое число |

## Возвращаемое значение

Меньшая степень двойки, не меньшая `x`. Для `x == 0` возвращает 1.

## Что делает

Находит ближайшую степень двойки, которая не меньше заданного числа.

## Примеры

```cpp
#include <bit>
#include <iostream>

int main()
{
    std::cout << std::bit_ceil(5u) << std::endl;  // 8
    std::cout << std::bit_ceil(8u) << std::endl;  // 8
    std::cout << std::bit_ceil(1u) << std::endl;  // 1
}
```
