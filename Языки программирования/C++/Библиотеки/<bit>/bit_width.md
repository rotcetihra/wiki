## Прототип

```cpp
#include <bit>

template<class T>
constexpr int bit_width(T x) noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| `x` | Беззнаковое целое число |

## Возвращаемое значение

Минимальное количество бит, необходимых для представления `x`. Для `x == 0` возвращает 0.

## Что делает

Вычисляет `ceil(log2(x + 1))`.

## Примеры

```cpp
#include <bit>
#include <iostream>

int main()
{
    std::cout << std::bit_width(1u) << std::endl;   // 1
    std::cout << std::bit_width(5u) << std::endl;   // 3
    std::cout << std::bit_width(255u) << std::endl;  // 8
}
```
