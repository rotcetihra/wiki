## Прототип

```cpp
#include <map>

template<class Key, class T, class Compare = std::less<Key>,
         class Allocator = std::allocator<std::pair<const Key, T>>>
class map;
```

`std::map` — ассоциативный контейнер, хранящий пары «ключ-значение» в отсортированном порядке. Ключи уникальны. Операции поиска, вставки и удаления — O(log n). Итераторы не инвалидируются при вставке/удалении (кроме удалённого элемента).

## Параметры шаблона

| Параметр | Описание |
|---|---|
| `Key` | Тип ключей |
| `T` | Тип значений |
| `Compare` | Функция сравнения ключей (по умолчанию `std::less<Key>`) |
| `Allocator` | Аллокатор памяти |

## Примеры

### Базовое использование

```cpp
```cpp
#include <map>
#include <iostream>

int main()
{
    std::map<std::string, int> m;
    m["one"] = 1;
    m["two"] = 2;
    std::cout << m.at("one") << "\n"; // 1
    for (const auto& [k, v] : m)
        std::cout << k << ": " << v << "\n";
}
```
```
- **Исключения:** `at()` выбрасывает `std::out_of_range`.
- **Безопасность в C++11:** безопасный доступ через `at()`.
