## Описание библиотеки

Заголовочный файл `<map>` определяет класс `std::map` — ассоциативный массив (словарь), хранящий пары «ключ-значение» в отсортированном порядке по ключу. Реализован как сбалансированное дерево (красно-чёрное). Ключи должны поддерживать оператор `<` (или использовать пользовательский компаратор). Поиск, вставка и удаление — O(log n).

## Исключения

- **Исключения:** `at()` выбрасывает `std::out_of_range`. Вставка может выбрасывать исключения.
- **Безопасность в C++11:** безопасный доступ через `at()`.

## Стандарты

C++11, C++17, C++20, C++23.
