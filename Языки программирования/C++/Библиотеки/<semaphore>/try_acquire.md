## Прототип

```cpp
#include <semaphore>

bool try_acquire() noexcept;
```

## Параметры

| Параметр | Описание |
|---|---|
| — | Параметров нет |

## Возвращаемое значение

`true` — если захват выполнен успешно, `false` — если счётчик равен нулю.

## Что делает

Пытается уменьшить внутренний счётчик семафора на 1 без блокировки. Если счётчик больше нуля, уменьшает его и возвращает `true`. Если счётчик равен нулю, не блокирует поток и возвращает `false`.

Полезен, когда блокировка нежелательна и нужно проверить доступность ресурса.

## Примеры

### Базовое использование

```cpp
#include <semaphore>
#include <iostream>

std::counting_semaphore<1> sem(1);

int main() {
    if (sem.try_acquire()) {
        std::cout << "Acquired\n";
        sem.release();
    } else {
        std::cout << "Not available\n";
    }
}
```

## Исключения

- **Исключения:** Не бросает исключений.
- **Безопасность в C++11:** Потокобезопасна.
