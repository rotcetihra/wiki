## Описание библиотеки

Заголовочный файл `<string_view>` определяет класс `std::basic_string_view` — лёгкий не владеющий вид (non-owning view) на последовательность символов. Не управляет памятью и не изменяет данные. Идеально подходит для передачи строк по константной ссылке.

## Исключения

- **Исключения:** Метод `at()` бросает `std::out_of_range`. Деструктор не бросает исключений.
- **Безопасность в C++11:** Потокобезопасна для разных объектов. Не владеет данными.

## Стандарты

C++17, C++20, C++23.
