Для отрисовки графики нам необходим буфер кадров, который в Vulkan представлен объектом `VkFramebuffer`. Прикрепления, указанные во время создания прохода рендеринга, связываются путем их упаковки в объект `VkFramebuffer`.

Для создания буфера кадров применяется функция `vkCreateFramebuffer()`:

```cpp
VkResult vkCreateFramebuffer(
    VkDevice                                    device,
    const VkFramebufferCreateInfo*              pCreateInfo,
    const VkAllocationCallbacks*                pAllocator,
    VkFramebuffer*                              pFramebuffer);
```

Для создания буфера кадров необходима структура `VkFramebufferCreateInfo`:

```cpp
VkFramebufferCreateInfo framebufferInfo{};
framebufferInfo.sType = VK_STRUCTURE_TYPE_FRAMEBUFFER_CREATE_INFO;
framebufferInfo.renderPass = renderPass;
framebufferInfo.attachmentCount = 1;
framebufferInfo.pAttachments = &imageView;
framebufferInfo.width = extent.width;
framebufferInfo.height = extent.height;
framebufferInfo.layers = 1;

if (vkCreateFramebuffer(device, &framebufferInfo, nullptr, &framebuffer) != VK_SUCCESS) {
    throw std::runtime_error("Не удалось создать буфер кадров!");
}
```

Обычно создается по одному буферу кадров для каждого изображения в цепочке буферов.

Удаление буферов кадров:

```cpp
vkDestroyFramebuffer(device, framebuffer, nullptr);
```
