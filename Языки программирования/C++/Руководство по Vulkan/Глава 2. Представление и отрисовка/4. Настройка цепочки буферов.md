Перед созданием цепочки буферов необходимо определить ее ключевые настройки, которые зависят от выбранного устройства:

- Выбрать желаемый формат для изображений.
- Установить режим представления для управления тем, как изображения ставятся в очередь для представления.
- Установить размер (ширину и высоту) изображений.

## Формат поверхности

Формат поверхности определяется структурой `VkSurfaceFormatKHR`:

```cpp
typedef struct VkSurfaceFormatKHR {
    VkFormat           format;
    VkColorSpaceKHR    colorSpace;
} VkSurfaceFormatKHR;
```

Поле `format` указывает на цветовые каналы и типы в виде перечисления `VkFormat`. Поле `colorSpace` представляет перечисление `VkColorSpaceKHR`, которое указывает на цветовое пространство.

Поскольку стандартным цветовым пространством для просмотра и печати является sRGB, то в дальнейшем мы его также будем использовать. Мы будем использовать константу `VK_FORMAT_B8G8R8A8_SRGB` как один из наиболее распространенных типов формата sRGB.

Для выбора формата определим функцию:

```cpp
VkSurfaceFormatKHR chooseSwapSurfaceFormat(const std::vector<VkSurfaceFormatKHR>& availableFormats) {
    for (const auto& availableFormat : availableFormats) {
        if (availableFormat.format == VK_FORMAT_B8G8R8A8_SRGB && 
            availableFormat.colorSpace == VK_COLOR_SPACE_SRGB_NONLINEAR_KHR) {
            return availableFormat;
        }
    }

    return availableFormats[0];
}
```

## Режим представления

Режим представления (presentation mode) представляет перечисление `VkPresentModeKHR` и определяет фактические условия для отображения изображений на экране. Основные режимы:

- `VK_PRESENT_MODE_IMMEDIATE_KHR`: изображения отображаются немедленно, что может привести к разрывам экрана.
- `VK_PRESENT_MODE_FIFO_KHR`: цепочка буферов представляет очередь (FIFO). Этот режим обычно устраняет разрывы и подходит для большинства приложений.
- `VK_PRESENT_MODE_FIFO_RELAXED_KHR`: отличается от FIFO тем, что программа ждет очередного обновления дисплея, а берет изображение сразу же.
- `VK_PRESENT_MODE_MAILBOX_KHR`: еще одна вариация FIFO. Изображения в очереди заменяются более новыми. Обычно известно как "тройная буферизация".

```cpp
VkPresentModeKHR chooseSwapPresentMode(const std::vector<VkPresentModeKHR>& availablePresentModes) {
    for (const auto& availablePresentMode : availablePresentModes) {
        if (availablePresentMode == VK_PRESENT_MODE_MAILBOX_KHR) {
            return availablePresentMode;
        }
    }

    return VK_PRESENT_MODE_FIFO_KHR;
}
```

## Размеры

Размеры (swap extent) представляют разрешение изображений в пикселях. Они должны соответствовать разрешению поверхности или окна рендеринга. Диапазон возможных разрешений определяется в структуре `VkSurfaceCapabilitiesKHR`:

```cpp
typedef struct VkSurfaceCapabilitiesKHR {
    uint32_t                         minImageCount;
    uint32_t                         maxImageCount;
    VkExtent2D                       currentExtent;
    VkExtent2D                       minImageExtent;
    VkExtent2D                       maxImageExtent;
    ...
} VkSurfaceCapabilitiesKHR;
```

Пример выбора разрешения для окна GLFW:

```cpp
#include <cstdint>
#include <limits>
#include <algorithm>

VkExtent2D chooseSwapExtent(const VkSurfaceCapabilitiesKHR& capabilities) {
    if (capabilities.currentExtent.width != std::numeric_limits<uint32_t>::max()) {
        return capabilities.currentExtent;
    } else {
        int width, height;
        glfwGetFramebufferSize(window, &width, &height);

        VkExtent2D actualExtent = {
            static_cast<uint32_t>(width),
            static_cast<uint32_t>(height)
        };

        actualExtent.width = std::clamp(actualExtent.width, capabilities.minImageExtent.width, capabilities.maxImageExtent.width);
        actualExtent.height = std::clamp(actualExtent.height, capabilities.minImageExtent.height, capabilities.maxImageExtent.height);

        return actualExtent;
    }
}
```
