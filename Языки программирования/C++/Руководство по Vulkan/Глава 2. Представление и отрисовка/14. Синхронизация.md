Основная философия дизайна в Vulkan заключается в том, что синхронизация выполнения на GPU является явной. Порядок операций определяется нами с помощью различных примитивов синхронизации.

Для синхронизации операций на GPU используются семафоры, а для синхронизации между CPU и GPU — барьеры (fences).

- **Семафоры (`VkSemaphore`):** используются для упорядочивания выполнения операций очереди на GPU.
- **Барьеры (`VkFence`):** используются для синхронизации центрального процессора и графического процессора.

## Создание семафоров

```cpp
VkSemaphoreCreateInfo semaphoreInfo{};
semaphoreInfo.sType = VK_STRUCTURE_TYPE_SEMAPHORE_CREATE_INFO;

VkSemaphore mySemaphore;
if (vkCreateSemaphore(device, &semaphoreInfo, nullptr, &mySemaphore) != VK_SUCCESS) {
    throw std::runtime_error("Не удалось создать семафор!");
}
```

## Создание барьера

```cpp
VkFenceCreateInfo fenceInfo{};
fenceInfo.sType = VK_STRUCTURE_TYPE_FENCE_CREATE_INFO;

VkFence myFence;
if (vkCreateFence(device, &fenceInfo, nullptr, &myFence) != VK_SUCCESS) {
    throw std::runtime_error("Не удалось создать барьер!");
}
```

Для перевода барьера в сигнальное состояние сразу при создании:

```cpp
fenceInfo.flags = VK_FENCE_CREATE_SIGNALED_BIT;
```

## Удаление семафора и барьера

```cpp
vkDestroySemaphore(device, mySemaphore, nullptr);
vkDestroyFence(device, myFence, nullptr);
```
