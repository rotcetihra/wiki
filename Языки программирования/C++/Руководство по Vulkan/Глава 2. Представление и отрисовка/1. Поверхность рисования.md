Vulkan представляет прикладной интерфейс, который не зависит от платформы, он не может напрямую взаимодействовать с оконной системой, которая на каждой платформе может отличаться (даже в рамках одной операционной системы). Чтобы связать Vulkan и оконную систему для вывода графики на экране, нам нужно использовать расширения WSI (Window System Integration). Одно из таких расширений - `VK_KHR_surface` предоставляет объект `VkSurfaceKHR`, который представляет абстрактный тип поверхности для для отрисовки графики. Поверхность окна должна быть создана сразу после создания объекта `VkInstance`, так как она может повлиять на выбор физического устройства. Но стоит отметить, что поверхности окна являются необязательным компонентом в Vulkan, если нужен только рендеринг вне экрана.

## Создание поверхности окна

Итак, поверхность представляет тип `VkSurfaceKHR`, который представляет непрозрачный указатель (opaque handle). И сначала надо определить объект этого типа:

```cpp
VkSurfaceKHR surface;
```

Хотя объект `VkSurfaceKHR` и его использование не зависят от платформы, но его создание зависит от деталей оконной системы. И на разных платформах могут быть разные дополнительные расширения, которые позволяют создать поверхность рисования конкретно для этой платформы. По умолчанию Vulkan API предоставляет ряд функций для создания поверхности для определенных систем:

- `vkCreateAndroidSurfaceKHR`: создает поверхность для окна Android.
- `vkCreateIOSSurfaceMVK`: создает поверхность для iOS UIView.
- `vkCreateMacOSSurfaceMVK`: создает поверхность для macOS NSView.
- `vkCreateMetalSurfaceEXT`: создает обобщенную поверхность для CAMetalLayer (MacOS/iOS).
- `vkCreateWaylandSurfaceKHR`: создает поверхность для окна Wayland.
- `vkCreateWin32SurfaceKHR`: создает поверхность для окна в ОС Windows.
- `vkCreateXcbSurfaceKHR`: создает поверхность для окна X11 с использованием клиентской библиотеки XCB.
- `vkCreateXlibSurfaceKHR`: создает поверхность для окна X11 с использованием клиентской библиотеки Xlib.

Все эти функции унифицированы и однотипны, различаются только типом передаваемой конфигурации, которая зависит от конкретной платформы. Например, возьмем создание поверхности для ОС Windows, которая создается с помощью функции `vkCreateWin32SurfaceKHR()`:

```cpp
VkResult vkCreateWin32SurfaceKHR(
    VkInstance                                  instance,
    const VkWin32SurfaceCreateInfoKHR*          pCreateInfo,
    const VkAllocationCallbacks*                pAllocator,
    VkSurfaceKHR*                               pSurface);
```

В функцию передаются следующие параметры:

- `instance`: объект `VkInstance`, с которым необходимо связать поверхность.
- `pCreateInfo`: указатель на структуру `VkWin32SurfaceCreateInfoKHR`.
- `pAllocator`: распределитель памяти хоста, выделенной для объекта поверхности.
- `pSurface`: указатель на дескриптор `VkSurfaceKHR`, через который возвращается созданный объект поверхности.

И, конечно, мы можем использовать различные кроссплатформенные библиотеки с поддержкой Vulkan, которые предоставляют некоторую обобщенную функцию для создания поверхности от текущую ОС. Например, библиотека GLFW для создания поверхности применяет функцию `glfwCreateWindowSurface()`, которая позволяет абстрагироваться от конкретной платформы:

```cpp
VkResult glfwCreateWindowSurface(
    VkInstance instance, 
    GLFWwindow *window, 
    const VkAllocationCallbacks *allocator, 
    VkSurfaceKHR *surface)
```

В качестве параметров функция принимает объект `VkInstance`, указатель окна GLFW, распределитель памяти и указатель на переменную `VkSurfaceKHR`, через которую возвращается созданная поверхность.

## Удаление поверхности рисования

Для удаления поверхности рисования применяется функция `vkDestroySurfaceKHR`:

```cpp
void vkDestroySurfaceKHR(
    VkInstance                                  instance,
    VkSurfaceKHR                                surface,
    const VkAllocationCallbacks*                pAllocator);
```

В качестве параметров она принимает связанный объект `VkInstance`, удаляемую поверхность рисования `VkSurfaceKHR` и функцию аллокатора памяти.
