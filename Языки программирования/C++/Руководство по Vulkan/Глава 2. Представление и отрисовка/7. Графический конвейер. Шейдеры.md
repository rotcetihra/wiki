Для отрисовки графики в Vulkan применяется графический конвейер (graphics pipeline), который представляет последовательность операций по рендерингу графики. Графический конвейер предполагает ряд этапов:

- **Ассемблер входных данных (input assembler):** собирает из полученных буферов необработанные данные вершин и может также использовать индексный буфер.
- **Вершинный шейдер (vertex shader):** запускается для каждой вершины и обычно применяет преобразования для перевода позиций вершин из пространства модели в пространство экрана.
- **Тесселяционные шейдеры (tessellation shaders):** позволяют подразделять поверхности на мелкие части.
- **Геометрический шейдер (geometry shader):** запускается для каждого примитива (треугольник, линия, точка) и может отбросить его или разделить на большее количество примитивов.
- **Растеризация (rasterization):** разделяет примитивы на фрагменты.
- **Фрагментный шейдер (fragment shader):** вызывается для каждого фрагмента и определяет цвет и глубину для буфера кадра.
- **Смешивание цветов (color blending):** применяет операции для смешивания различных фрагментов.

Этапы с зеленым цветом представляют фиксированные функции. Этапы с оранжевым цветом являются программируемыми.

Графический конвейер в Vulkan практически полностью неизменяем, поэтому если надо изменить шейдеры, привязать различные буферы кадров или изменить функцию смешивания, то придется заново создать конвейер с нуля.

## Шейдеры

Шейдеры — это небольшие программы, выполняемые на GPU. В Vulkan шейдеры являются важнейшими компонентами для создания графики. Основные типы шейдеров:

- **Вершинный шейдер (Vertex Shader):** обрабатывает каждую вершину 3D-модели.
- **Фрагментный шейдер (Fragment Shader):** вычисляет окончательный цвет каждого фрагмента.
- **Геометрический шейдер (Geometry Shader):** может создавать, изменять или отбрасывать геометрию.
- **Вычислительный шейдер (Compute Shader):** используется для вычислений на GPU общего назначения.

Шейдеры в Vulkan обычно пишутся на языках **GLSL** (OpenGL Shading Language) или **SPIR-V**. Хотя для написания шейдеров наиболее простым вариантом является использование GLSL, но проблема заключается в том, что Vulkan понимает только байт-код SPIR-V. Компания Khronos выпустила компилятор glslangValidator, который компилирует GLSL в SPIR-V. Также нередко используется компилятор glslc от Google.

### Вершинный шейдер

```glsl
#version 450

vec2 positions[3] = vec2[](
    vec2(0.0, -0.5),
    vec2(0.5, 0.5),
    vec2(-0.5, 0.5)
);

void main() {
    gl_Position = vec4(positions[gl_VertexIndex], 0.0, 1.0);
}
```

Встроенная переменная `gl_Position` содержит позицию вершины в координатах отсечения. Переменная `gl_VertexIndex` содержит индекс текущей вершины.

### Фрагментный шейдер

```glsl
#version 450

layout(location = 0) out vec4 fragColor;

void main() {
    fragColor = vec4(1.0, 0.0, 0.0, 1.0);
}
```

Цвета в GLSL представляют собой 4-мерные векторы (vec4) с каналами R, G, B и альфа в диапазоне [0, 1].

### Компиляция шейдеров

```bash
glslc shader.vert -o vert.spv
glslc shader.frag -o frag.spv
```

### Загрузка шейдеров

```cpp
#include <fstream>

static std::vector<char> readFile(const std::string& filename) {
    std::ifstream file(filename, std::ios::ate | std::ios::binary);

    if (!file.is_open()) {
        throw std::runtime_error("Не удалось загрузить файл!");
    }
    size_t fileSize = (size_t) file.tellg();
    std::vector<char> buffer(fileSize);

    file.seekg(0);
    file.read(buffer.data(), fileSize);

    file.close();

    return buffer;
}
```
