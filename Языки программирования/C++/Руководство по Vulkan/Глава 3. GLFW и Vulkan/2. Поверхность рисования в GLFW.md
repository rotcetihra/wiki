Для создания поверхности рисования в приложении на GLFW применяется функция `glfwCreateWindowSurface()`:

```cpp
VkSurfaceKHR surface;

void createSurface() {
    if (glfwCreateWindowSurface(instance, window, nullptr, &surface) != VK_SUCCESS) {
        throw std::runtime_error("Не удалось создать поверхность окна!");
    }
}
```

Функция принимает объект `VkInstance`, указатель окна GLFW, распределитель памяти и указатель на переменную `VkSurfaceKHR`, через которую возвращается созданная поверхность.

Удаление поверхности:

```cpp
vkDestroySurfaceKHR(instance, surface, nullptr);
```
