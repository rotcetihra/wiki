Почти каждая операция в Vulkan, от рисования до загрузки текстур, требует отправки команд в очередь. Очереди используются для отправки буферов команд, которые содержат инструкции для графического процессора. Существуют различные типы и семейства очередей, и каждое семейство очередей допускает только определенный набор команд. Например, графическая очередь отвечает за команды рендеринга графики, в то время как вычислительная очередь обрабатывает рабочие нагрузки вычислительного шейдера. И перед работой необходимо проверить, какие семейства очередей поддерживаются устройством, и какое из семейств поддерживает требуемые команды.

Информация о семействе очередей представлена структурой `VkQueueFamilyProperties`:

```cpp
typedef struct VkQueueFamilyProperties {
    VkQueueFlags    queueFlags;
    uint32_t        queueCount;
    uint32_t        timestampValidBits;
    VkExtent3D      minImageTransferGranularity;
} VkQueueFamilyProperties;
```

Поля структуры:

- `queueFlags`: битовая маска `VkQueueFlagBits`, указывающая возможности очередей из этого семейства.
- `queueCount`: количество очередей в этом семействе (Каждое семейство очередей должно поддерживать как минимум одну очередь).
- `timestampValidBits`: число значимых битов в метках времени, записанных с помощью `vkCmdWriteTimestamp2` или `vkCmdWriteTimestamp`. Допустимый диапазон для числа — от 36 до 64 бит или значение 0, указывающее на отсутствие поддержки меток времени.
- `minImageTransferGranularity`: минимальная гранулярность, поддерживаемая для операций передачи изображений из этого семейства.

Таким образом, возможности очередей задаются, главным образом, полем `queueFlags`, которое представляет перечисление `VkQueueFlagBits`, где определены следующие константы:

```cpp
typedef enum VkQueueFlagBits {
    VK_QUEUE_GRAPHICS_BIT = 0x00000001,
    VK_QUEUE_COMPUTE_BIT = 0x00000002,
    VK_QUEUE_TRANSFER_BIT = 0x00000004,
    VK_QUEUE_SPARSE_BINDING_BIT = 0x00000008,
    VK_QUEUE_PROTECTED_BIT = 0x00000010,
    VK_QUEUE_VIDEO_DECODE_BIT_KHR = 0x00000020,
    VK_QUEUE_VIDEO_ENCODE_BIT_KHR = 0x00000040,
    VK_QUEUE_OPTICAL_FLOW_BIT_NV = 0x00000100,
} VkQueueFlagBits;
```

- `VK_QUEUE_GRAPHICS_BIT` указывает, что очереди в этом семействе очередей поддерживают графические операции.
- `VK_QUEUE_COMPUTE_BIT` указывает, что очереди поддерживают вычислительные операции.
- `VK_QUEUE_TRANSFER_BIT` указывает, что очереди поддерживают операции передачи данных через память.
- `VK_QUEUE_SPARSE_BINDING_BIT` указывает, что очереди поддерживают операции управления разреженной памятью (sparse memory).
- `VK_QUEUE_VIDEO_DECODE_BIT_KHR` указывает, что очереди поддерживают операции декодирования видео.
- `VK_QUEUE_VIDEO_ENCODE_BIT_KHR` указывает, что очереди поддерживают операции кодирования видео.
- `VK_QUEUE_OPTICAL_FLOW_BIT_NV` указывает, что очереди поддерживают операции оптического потока (optical flow).
- `VK_QUEUE_PROTECTED_BIT` указывает, что очереди поддерживают бит `VK_DEVICE_QUEUE_CREATE_PROTECTED_BIT`.

Vulkan API предоставляет ряд функций для работы с очередями. Так, функция `vkGetPhysicalDeviceQueueFamilyProperties()` предоставляет информацию о доступных семействах очередей, их возможностях и количестве очередей, которые можно создать из каждого семейства:

```cpp
void vkGetPhysicalDeviceQueueFamilyProperties(
    VkPhysicalDevice                            physicalDevice,
    uint32_t*                                   pQueueFamilyPropertyCount,
    VkQueueFamilyProperties*                    pQueueFamilyProperties);
```

Параметры функции:

- `physicalDevice`: дескриптор физического устройства.
- `pQueueFamilyPropertyCount`: указатель на целое число, через которое возвращается количество доступных или запрошенных семейств очередей.
- `pQueueFamilyProperties`: указатель на массив структур `VkQueueFamilyProperties`. Может быть NULL, если надо получить только количество доступных семейств очередей.

Например, получим поддерживаемые семейства очередей у определенного устройства:

```cpp
#include <vulkan/vulkan.h>
#include <iostream>
#include <vector>

// функция для получения первой видеокарты в списке устройств
VkPhysicalDevice selectFirstDevice(VkInstance* instance){

    uint32_t deviceCount = 0;
    vkEnumeratePhysicalDevices(*instance, &deviceCount, nullptr);
    if (!deviceCount)  return VK_NULL_HANDLE; 

    std::vector<VkPhysicalDevice> devices(deviceCount);
    vkEnumeratePhysicalDevices(*instance, &deviceCount, devices.data());

    return devices[0];
}

// функция для вывода информации о поддерживаемых семействах очередей физического устройства
void displayQueueFamily(VkPhysicalDevice device){

    uint32_t familyCount = 0;
    // сначала получаем количество поддерживаемых семейств
    vkGetPhysicalDeviceQueueFamilyProperties(device, &familyCount, nullptr);
    if (!familyCount)  return; 

    // определяем вектор для хранения семейств
    std::vector<VkQueueFamilyProperties> families(familyCount);
    vkGetPhysicalDeviceQueueFamilyProperties(device, &familyCount, families.data());

    // перебираем полученные семейства очередей
    for (const auto& family : families) {
        // выводим количество очередей в семействе и поддерживаемые флаги
        std::cout << "Queue count: " <<  family.queueCount <<  std::endl;
        std::cout << "Flags: " << std::hex <<  family.queueFlags << "\n\n";
    }
}

int main() {
    
    VkInstance instance;
 
    VkInstanceCreateInfo createInfo{};
    createInfo.sType = VK_STRUCTURE_TYPE_INSTANCE_CREATE_INFO;

    if(vkCreateInstance(&createInfo, nullptr, &instance)!= VK_SUCCESS){
        std::cout << "Unable to create VKInstance" << std::endl;
        return 1;
    }
    // получаем устройство
    VkPhysicalDevice physicalDevice = selectFirstDevice(&instance);
    // выводим поддерживаемые семейства
    displayQueueFamily(physicalDevice);

    vkDestroyInstance(instance, nullptr);
    return 0;
}
```

Здесь сначала получаем первое попавшееся устройство с помощью функции `selectFirstDevice`, а затем передаем его в функцию `displayQueueFamily`, где выводим все его поддерживаемые семейства очередей.

В `displayQueueFamily` сначала получаем количество семейств:

```cpp
uint32_t familyCount = 0;
vkGetPhysicalDeviceQueueFamilyProperties(device, &familyCount, nullptr);
if (!familyCount)  return; 
```

Далее определяем вектор для получения семейств и получаем их, затем выводим количество очередей в каждом семействе и флаги - поддерживаемую функциональность:

```cpp
std::vector<VkQueueFamilyProperties> families(familyCount);
vkGetPhysicalDeviceQueueFamilyProperties(device, &familyCount, families.data());

for (const auto& family : families) {
    std::cout << "Queue count: " <<  family.queueCount <<  std::endl;
    std::cout << "Flags: " << std::hex <<  family.queueFlags << "\n\n";
}
```

Для вывода флагов для наглядности применяем конвертацию в шестнадцатеричный формат. Например, вывод мог бы выглядеть так:

```
Queue count: 16
Flags: f

Queue count: 2
Flags: c

Queue count: 8
Flags: e

Queue count: 1
Flags: 2c

Queue count: 1
Flags: 10c
```

По выводу видно, что флаги могут сочетаться, следовательно, очереди могут поддерживать несколько функциональностей.

Но что, если нам надо выбрать семейство очередей, которые поддерживают именно графические возможности? В этом случае мы можем проверить установку флага `VK_QUEUE_GRAPHICS_BIT`:

```cpp
for (const auto& family : families) {
    if (family.queueFlags & VK_QUEUE_GRAPHICS_BIT) {
        // что-то делаем
    }
}
```
