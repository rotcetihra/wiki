Для проверки подключения в программе на C++ создадим первое приложение. Поскольку чтобы создать даже самое примитивное приложение, которое, к примеру, выводит несчастный треугольник на экран, потребуется написать сотни строк кода, то в данном случае мы сделаем очень примитивное приложение, которое просто выводит количество поддерживаемых расширений Vulkan на консоль. Рассмотрим пример как на Linux, так и на Windows. Хотя на обоих системах код не будет отличаться. Отличается только настройка окружения.

## Первое приложение на Linux

Определим каталог для нашего проекта. И создадим в нем файл, который назовем main.cpp и в котором будет следующий код:

```cpp
#include <vulkan/vulkan.h>  // подключаем заголовки Vulkan
#include <iostream>

int main() {
    uint32_t extensionCount{};    // переменная для получения количества расширений       
    // получаем количество доступных расширений Vulkan
    vkEnumerateInstanceExtensionProperties(nullptr, &extensionCount, nullptr);
    // выводим результат
    std::cout << extensionCount << " extensions available\n";

    return 0;
}
```

Разберем данный код. Прежде всего, чтобы задействовать функциональность Vulkan API, нам нужно подключить соответствующие заголовки:

```cpp
#include <vulkan/vulkan.h>
```

В данном приложении незадействуется какой-то большой функциональности, и все, что мы делаем - это получаем количество поддерживаемых расширений в текущей системе. Для этого определяем целочисленную переменную:

```cpp
uint32_t extensionCount{};
```

Затем вызываем функцию `vkEnumerateInstanceExtensionProperties`, которая, получив адрес переменной, в нее передает количество расширений:

```cpp
vkEnumerateInstanceExtensionProperties(nullptr, &extensionCount, nullptr);
```

Эта функция принимает три параметра, но два из них нам сейчас не важны, поэтому для этих параметров передаем значения `nullptr`.

В конце выводим количество расширений на консоль.

Для компиляции и запуска приложения на Linux выполним следующую команду:

```bash
g++ main.cpp -lvulkan -o app && ./app
```

В данном случае применяется компилятор g++ из набора компиляторов GCC GNU. С помощью опции `-lvulkan` при компоновки подключаем библиотеку Vulkan. Приложение компилируется в файл app, который затем сразу же запускается. В итоге консоль отобразит нам количество поддерживаемых расширений:

```
24 extensions available
```

## Создание проекта на Windows в Visual Studio

При разработке для Windows наиболее популярный и распространенный способ - использование Visual Studio для компиляции кода. Например, возьмем последнюю на момент написани данной статьи Visual Studio 2022 Community. В этой среде создадим для C++ новый проект по типу Empty Project.

Как-нибудь назовем проект, например, VulkanApp.

После создания проекта добавим в папку Source Files новый файл, который назовем main.cpp.

Для тестирования подключения Vulkan SDK определим в файле следующий код:

```cpp
#include <vulkan/vulkan.h>  // подключаем заголовки Vulkan
#include <iostream>

int main() {
    uint32_t extensionCount{};    // переменная для получения количества расширений       
    // получаем количество доступных расширений Vulkan
    vkEnumerateInstanceExtensionProperties(nullptr, &extensionCount, nullptr);
    // выводим результат
    std::cout << extensionCount << " extensions available\n";

    return 0;
}
```

По умолчанию Visual Studio не видит Vulkan SDK и все связанные с Vulkan заголовочные файлы. Соответственно нам надо указать расположение всех нужных файлов. Для этого перейдем к свойствам проекта. Для этого можно нажать в меню на пункт Project и дальше в выпадающем меню выбрать пункт "Properties".

Прежде всего в свойствах проекта сразу рекомендую установить один из последних стандартов C++ (как минимум C++17) причем для всех конфигураций (и для отладочных сборок и для релизов), потому что на момент написания данной статьи Visual Studio по умолчанию использует C++14. В моем случае это С++20.

Далее перейдем к полю C++ -> General -> Additional Include Directories и укажем в нем путь к заголовочным файлам Vulkan SDK, которые располагаются в папке "C:\VulkanSDK\x.x.x.x\Include".

Затем перейдем к полю Linker -> General и в поле Additional Library Directories укажем путь к библиотекам Vulkan, которые располагаются по пути "C:\VulkanSDK\x.x.x.x\Lib\".

И дальше перейдем к вкладке Linker -> Input и в поле Additional Dependencies укажем путь к библиотеке Vulkan, которая располагается по пути "C:\VulkanSDK\1.4.309.0\Lib\vulkan-1.lib".

Нажмем на кнопку "Применить". После настройки всех этих свойств запустим проект, и консоль нам должна вывести количество поддерживаемых расщирений Vulkan:

```
20 extensions available
```
