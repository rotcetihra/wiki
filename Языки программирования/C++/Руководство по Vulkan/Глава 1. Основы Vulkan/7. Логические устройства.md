Логическое устройство в Vulkan представляет собой соединение с физическим устройством (GPU) и служит основным интерфейсом для взаимодействия с этим GPU. Соответственно, чтобы взаимодействовать с физическим устройством, необходимо создать логическое устройство. Чтобы создать логическое устройство, необходимо указать его конфигурацию, включая желаемые очереди и их свойства. Можно даже создать несколько логических устройств для одного и того же физического устройства, если эти логические устройства должны поддерживать разные требования.

На уровне кода логическое представляет тип `VkDevice`:

```cpp
VkDevice device;
```

## Установка семейства очередей

Создание логического устройства вовлекает ряд структур, необходимых для конфигурации устройства. Одна из них - структура `VkDeviceQueueCreateInfo`, которая описывает количество очередей для одного семейства очередей:

```cpp
typedef struct VkDeviceQueueCreateInfo {
    VkStructureType             sType;   
    const void*                 pNext;
    VkDeviceQueueCreateFlags    flags;
    uint32_t                    queueFamilyIndex;
    uint32_t                    queueCount;
    const float*                pQueuePriorities;
} VkDeviceQueueCreateInfo;
```

Структура определяет следующие поля:

- `sType`: тип структуры (должен иметь значение `VK_STRUCTURE_TYPE_DEVICE_QUEUE_CREATE_INFO`).
- `flags`: битовая маска, указывающая поведение очередей.
- `queueFamilyIndex`: беззнаковое целое число, указывающее индекс семейства очередей, в котором будут созданы очереди на этом устройстве. Этот индекс соответствует индексу элемента массива `pQueueFamilyProperties`, который возвращается из функции `vkGetPhysicalDeviceQueueFamilyProperties()`.
- `queueCount`: беззнаковое целое число, указывающее количество очередей для создания в семействе очередей, указанном `queueFamilyIndex`.
- `pQueuePriorities`: указатель на массив нормализованных значений с плавающей точкой, указывающий приоритеты работы, которая будет отправлена ​​в каждую созданную очередь.

Общий процесс определения этой структуры выглядит следующим образом:

```cpp
uint32_t queueFamilyIndex = selectQueueFamily(physicalDevice);  

VkDeviceQueueCreateInfo queueCreateInfo{};
queueCreateInfo.sType = VK_STRUCTURE_TYPE_DEVICE_QUEUE_CREATE_INFO;
queueCreateInfo.queueFamilyIndex = queueFamilyIndex;  // устанавливаем индекс семейства очередей
queueCreateInfo.queueCount = 1;  // пусть будет использоваться только одна очередь
```

Доступные в настоящее время драйверы позволят создавать только небольшое количество очередей для каждого семейства, но обычно и не требуется больше одной. Причем далее нас будет интересовать пока только очередь с графическими возможностями.

Vulkan позволяет назначать приоритеты очередям, чтобы влиять на планирование выполнения буфера команд, используя числа с плавающей точкой от 0.0 до 1.0. Это необходимо, даже если есть только одна очередь:

```cpp
float queuePriority = 1.0f;
queueCreateInfo.pQueuePriorities = &queuePriority;
```

## Определение конфигурации

Для непосредственного создания логического устройства применяется другая структура - `VkDeviceCreateInfo`:

```cpp
typedef struct VkDeviceCreateInfo {
    VkStructureType                    sType;
    const void*                        pNext;
    VkDeviceCreateFlags                flags;
    uint32_t                           queueCreateInfoCount;
    const VkDeviceQueueCreateInfo*     pQueueCreateInfos;
    const VkPhysicalDeviceFeatures*    pEnabledFeatures;
} VkDeviceCreateInfo;
```

Основные поля структуры:

- `sType`: тип структуры (должен быть `VK_STRUCTURE_TYPE_DEVICE_CREATE_INFO`).
- `queueCreateInfoCount`: размер массива `pQueueCreateInfos`.
- `pQueueCreateInfos`: указатель на массив структур `VkDeviceQueueCreateInfo`, которые содержит очереди, запрашиваемые для создания вместе с логическим устройством.
- `pEnabledFeatures`: NULL или указатель на структуру `VkPhysicalDeviceFeatures`, которая содержит все функции, необходимые для подключения.

И для непосредственного создания логического устройства применяется функция `vkCreateDevice()`:

```cpp
VkResult vkCreateDevice(
    VkPhysicalDevice                            physicalDevice,
    const VkDeviceCreateInfo*                   pCreateInfo,
    const VkAllocationCallbacks*                pAllocator,
    VkDevice*                                   pDevice);
```

Параметры функции:

- `physicalDevice`: физическое устройство, для которого создается логическое устройство.
- `pCreateInfo`: указатель на выше рассмотренную структуру `VkDeviceCreateInfo` с конфигурацией устройства.
- `pAllocator`: управляет распределением памяти хоста.
- `pDevice`: указатель на `VkDevice`, через который возвращается созданное устройство.

## Удаление устройства

После завершения работы необходимо удалить логическое устройство с помощью функции `vkDestroyDevice`:

```cpp
vkDestroyDevice(device, nullptr);
```

Эта функция принимает собственно само устройство и объект, который управляет выделением памяти для хоста (объект `VkAllocationCallbacks*`).

## Создание логического устройства

Пример создания логического устройства с одной графической очередью:

```cpp
#include <vulkan/vulkan.h>
#include <iostream>
#include <vector>

// функция для получения первой видеокарты в списке устройств
VkPhysicalDevice selectFirstDevice(VkInstance* instance){

    uint32_t deviceCount = 0;
    vkEnumeratePhysicalDevices(*instance, &deviceCount, nullptr);
    if (!deviceCount)  return VK_NULL_HANDLE; 

    std::vector<VkPhysicalDevice> devices(deviceCount);
    vkEnumeratePhysicalDevices(*instance, &deviceCount, devices.data());

    return devices[0];
}

// выбираем семейство очередей с графической очередью
uint32_t selectQueueFamilyIndex(VkPhysicalDevice device){

    uint32_t familyCount = 0;
    vkGetPhysicalDeviceQueueFamilyProperties(device, &familyCount, nullptr);
    if (!familyCount)  return UINT32_MAX; 

    VkQueueFamilyProperties families[familyCount];
    vkGetPhysicalDeviceQueueFamilyProperties(device, &familyCount, families);

    for (int32_t i{}; i < familyCount; ++i) {
        if (families[i].queueFlags & VK_QUEUE_GRAPHICS_BIT) {
            return i;
        }
    }
    return UINT32_MAX;
}

// функция создания логического устройства
VkDevice createLogicalDevice(VkPhysicalDevice physicalDevice, uint32_t queueFamilyIndex){

    if(queueFamilyIndex == UINT32_MAX) return VK_NULL_HANDLE;

    VkDevice device = VK_NULL_HANDLE;

    VkDeviceQueueCreateInfo queueCreateInfo = {};
    queueCreateInfo.sType = VK_STRUCTURE_TYPE_DEVICE_QUEUE_CREATE_INFO;
    queueCreateInfo.queueFamilyIndex = queueFamilyIndex;
    queueCreateInfo.queueCount = 1;
    float queuePriority = 1.0f;
    queueCreateInfo.pQueuePriorities = &queuePriority;

    VkDeviceCreateInfo createInfo = {};
    createInfo.sType = VK_STRUCTURE_TYPE_DEVICE_CREATE_INFO;
    createInfo.queueCreateInfoCount = 1;
    createInfo.pQueueCreateInfos = &queueCreateInfo;

    if (vkCreateDevice(physicalDevice, &createInfo, nullptr, &device) != VK_SUCCESS) {
        std::cout << "Unable to create VkDevice..." << std::endl;
    }
    else{
        std::cout << "VkDevice created!" << std::endl;
    }
    return device;
}

int main() {
    
    VkInstance instance;
 
    VkInstanceCreateInfo createInfo{};
    createInfo.sType = VK_STRUCTURE_TYPE_INSTANCE_CREATE_INFO;

    if(vkCreateInstance(&createInfo, nullptr, &instance)!= VK_SUCCESS){
        std::cout << "Unable to create VKInstance" << std::endl;
        return 1;
    }
    VkPhysicalDevice physicalDevice = selectFirstDevice(&instance);
    uint32_t queueFamilyIndex = selectQueueFamilyIndex(physicalDevice);
    
    VkDevice device = createLogicalDevice(physicalDevice, queueFamilyIndex);

    if(device!= VK_NULL_HANDLE) vkDestroyDevice(device, nullptr);

    vkDestroyInstance(instance, nullptr);
    return 0;
}
```

Здесь весь код для наглядности вынесен в отдельную функцию `createLogicalDevice`, которая принимает физическое устройство, для которого создается логическое устройство, и индекс семейства очередей.
