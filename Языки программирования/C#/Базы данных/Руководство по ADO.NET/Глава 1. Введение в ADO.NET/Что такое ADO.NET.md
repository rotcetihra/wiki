ADO.NET (ActiveX Data Objects .NET) представляет собой набор классов .NET Framework, которые предоставляют доступ к данным. ADO.NET позволяет работать с различными источниками данных: реляционными базами данных, XML-файлами и т.д.

Основные компоненты ADO.NET:
-   **Connection**: подключение к источнику данных
-   **Command**: выполнение команд
-   **DataReader**: чтение данных
-   **DataAdapter**: заполнение DataSet
-   **DataSet**: хранилище данных в памяти
