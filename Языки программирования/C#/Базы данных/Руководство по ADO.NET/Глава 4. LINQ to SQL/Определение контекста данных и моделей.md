LINQ to SQL позволяет работать с данными через контекст DataContext:

```csharp
[Database(Name = "adonetdb")]
public class ApplicationContext : DataContext
{
    public ApplicationContext(string connectionString) : base(connectionString) { }
    public Table<User> Users => GetTable<User>();
}
```
