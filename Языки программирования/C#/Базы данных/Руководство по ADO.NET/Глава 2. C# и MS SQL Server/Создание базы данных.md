Для создания базы данных через C# используется команда CREATE DATABASE:

```csharp
using (SqlConnection connection = new SqlConnection(connectionString))
{
    connection.Open();
    SqlCommand command = new SqlCommand("CREATE DATABASE adonetdb", connection);
    command.ExecuteNonQuery();
}
```
