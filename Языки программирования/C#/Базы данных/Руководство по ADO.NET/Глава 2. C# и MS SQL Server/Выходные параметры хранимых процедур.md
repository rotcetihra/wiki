Хранимые процедуры могут использовать выходные параметры для возвращения результатов:

```csharp
SqlParameter minAgeParam = new SqlParameter("@minAge", SqlDbType.Int);
minAgeParam.Direction = ParameterDirection.Output;
command.Parameters.Add(minAgeParam);
```
