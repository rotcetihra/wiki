Для выходных параметров используется Direction = ParameterDirection.Output:

```csharp
SqlParameter idParam = new SqlParameter("@id", SqlDbType.Int);
idParam.Direction = ParameterDirection.Output;
command.Parameters.Add(idParam);
```
