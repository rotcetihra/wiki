Для защиты от SQL-инъекций используются параметры через SqlParameter:

```csharp
command.CommandText = "INSERT INTO Users (Name, Age) VALUES (@name, @age)";
command.Parameters.AddWithValue("@name", "Tom");
command.Parameters.AddWithValue("@age", 36);
command.ExecuteNonQuery();
```
