MongoDB является одной из наиболее популярных баз данных, которая характеризуется быстродействием, масштабируемостью, относительной простотой.

Для работы сначала необходимо установить саму MongoDB.

### Установка драйвера в проект

Для взаимодействия с сервером Mongo установим драйвер. Для этого необходимо через пакетный менеджер Nuget установить пакет MongoDB.Driver. Или с помощью .NET CLI:

```
dotnet add package MongoDB.Driver
```

### Подключение к базе данных. MongoClient

Для подключения к серверу MongoDB необходим класс MongoClient из пространства имен `MongoDB.Driver`. Строка подключения имеет следующий вид:

```
mongodb://[username:password@]hostname[:port][/database[?options]]
```

Например:

```csharp
using MongoDB.Driver;

MongoClient client = new MongoClient("mongodb://localhost:27017");
```

После создания MongoClient хранит пул подключений к серверу/серверам, которые указаны в строке подключения.

### Получение списка баз данных на сервере

```csharp
using MongoDB.Driver;

MongoClient client = new MongoClient("mongodb://localhost:27017");

using (var cursor = await client.ListDatabasesAsync())
{
    var databases = cursor.ToList();
    foreach (var database in databases)
    {
        Console.WriteLine(database);
    }
}
```

### Обращение к базе данных

Для получения базы данных применяется метод `GetDatabase`, в который передается название базы. Этот метод возвращает объект IMongoDatabase:

```csharp
using MongoDB.Driver;

MongoClient client = new MongoClient("mongodb://localhost:27017");
// получаем базу данных test
IMongoDatabase database = client.GetDatabase("test");
```

Если мы передадим имя базы данных, которая отсутствует, то она автоматически создается при первых операциях с ней.
