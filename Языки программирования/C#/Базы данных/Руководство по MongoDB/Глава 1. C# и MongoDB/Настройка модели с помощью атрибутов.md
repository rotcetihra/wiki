Используя атрибуты, мы можем управлять настройкой классов моделей C# и их сериализацией в документы mongodb. Все классы атрибутов расположены в пространстве имен MongoDB.Bson.Serialization.Attributes.

### Установка Id

```csharp
using MongoDB.Bson.Serialization.Attributes;

class Person
{
    [BsonId]
    public int PersonId { get; set; }
    public string Name { get; set; } = "";
}
```

### Исключение свойств

Атрибут BsonIgnore позволяет не учитывать свойство при сериализации:

```csharp
class Person
{
    public string Name { get; set; } = "";
    [BsonIgnore]
    public string Email { get; set; } = "";
}
```

### BsonElement

Атрибут BsonElement позволяет изменить название поля при сериализации:

```csharp
class Person
{
    public string Name { get; set; } = "";
    [BsonElement("Login")]
    public string Email { get; set; } = "";
}
```

### Игнорирование значений по умолчанию

Атрибуты BsonIgnoreIfNull и BsonIgnoreIfDefault позволяют исключить из сериализации свойства со значениями null или по умолчанию:

```csharp
class Person
{
    public string Name { get; set; } = "";
    [BsonIgnoreIfDefault]
    public int Age { get; set; }
    [BsonIgnoreIfNull]
    public Company? Company { get; set; }
}
```
