## Получение одного документа

Для получения одного документа применяются методы First()/FirstAsync(), Single()/SingleAsync(), FirstOrDefault()/FirstOrDefaultAsync(), SingleOrDefault()/SingleOrDefaultAsync().

```csharp
var user = await collection.Find("{}").FirstAsync();
var user33 = await collection.Find(new BsonDocument("Age",33)).FirstAsync();
```

## Skip

Метод Skip() пропускает при выборке определенное количество документов:

```csharp
var users = await collection.Find("{}").Skip(3).ToListAsync();
```

## Limit

Метод Limit() устанавливает максимальное количество документов:

```csharp
var users = await collection.Find("{}").Limit(3).ToListAsync();
```

## Постраничная навигация

Комбинация методов Skip() и Limit() позволяет извлечь определенную часть коллекции:

```csharp
var users = await collection.Find("{}")
    .Skip(2)        // пропускаем 2 документа
    .Limit(3)       // извлекаем следующие 3 документа
    .ToListAsync();
```
