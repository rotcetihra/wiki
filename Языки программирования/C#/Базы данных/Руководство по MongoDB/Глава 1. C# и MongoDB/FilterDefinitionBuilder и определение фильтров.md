Другим способом для создания фильтрации представляет применение класса FilterDefinitionBuilder - построителя фильтров:

```csharp
var builder = Builders<BsonDocument>.Filter;
var filter = builder.Eq("Name", "Tom");
```

### Операции сравнения

-   Eq: равно, Ne: не равно
-   Gt: больше, Gte: больше или равно
-   Lt: меньше, Lte: меньше или равно
-   In, Nin

### Логические операции

-   ! и Not: инвертирование условия
-   | и Or: дизъюнкция
-   & и And: конъюнкция

```csharp
var filter = builder.Eq("Name", "Tom") | builder.Gte("Age", 33);
```

### Операции с массивами

-   All: все элементы массива присутствуют
-   Size: определенное количество элементов
