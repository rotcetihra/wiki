Для сортировки документов применяется метод Sort(). Значение 1 указывает на направление сортировки - по возрастанию, -1 - по убыванию:

```csharp
var users = await collection.Find(new BsonDocument { })
    .Sort(new BsonDocument("Age", 1)).ToListAsync();
```

Методы SortBy()/SortByDescending() сортируют по возрастанию/убыванию:

```csharp
var users = await collection.Find("{}").SortBy(d => d["Name"]).ToListAsync();
```

### Последовательное применение нескольких критериев сортировки

```csharp
var sortDefinition = Builders<BsonDocument>.Sort.Ascending("Name").Descending("Age");
var users = await collection.Find("{}").Sort(sortDefinition).ToListAsync();
```
