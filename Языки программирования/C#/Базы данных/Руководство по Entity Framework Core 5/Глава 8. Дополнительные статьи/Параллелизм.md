Для решения проблемы параллелизма используется атрибут [ConcurrencyCheck] или метод IsConcurrencyToken():

```csharp
[ConcurrencyCheck]
public string? Name { get; set; }
```

```csharp
modelBuilder.Entity<User>().Property(b => b.Name).IsConcurrencyToken();
```
