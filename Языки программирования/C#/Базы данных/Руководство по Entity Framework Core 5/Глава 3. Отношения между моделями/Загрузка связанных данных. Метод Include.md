Для загрузки связанных данных (жадная загрузка) применяется метод Include():

```csharp
var users = db.Users
    .Include(u => u.Company)
    .ToList();
```

Для многоуровневой загрузки - ThenInclude():

```csharp
var users = db.Users
    .Include(u => u.Company)
        .ThenInclude(c => c!.Country)
    .ToList();
```
