Каскадное удаление представляет автоматическое удаление зависимой сущности после удаления главной. По умолчанию применяется, если наличие связанной сущности обязательно.

Для настройки через Fluent API:

```csharp
modelBuilder.Entity<User>()
    .HasOne(u => u.Company)
    .WithMany(c => c.Users)
    .OnDelete(DeleteBehavior.Cascade);
```

Доступные варианты: Cascade, SetNull, Restrict.
