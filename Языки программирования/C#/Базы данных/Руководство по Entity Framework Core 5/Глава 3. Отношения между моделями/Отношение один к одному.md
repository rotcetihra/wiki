Отношение один к одному: главная сущность ссылается только на один объект зависимой, и наоборот. У зависимой сущности устанавливается внешний ключ:

```csharp
public class UserProfile
{
    public int Id { get; set; }
    public string? Name { get; set; }
    public int UserId { get; set; }
    public User? User { get; set; }
}
```
