Для исключения свойства из модели используется метод Ignore() Fluent API или атрибут [NotMapped]:

```csharp
modelBuilder.Entity<User>().Ignore(u=>u.Address);
```

```csharp
[NotMapped]
public string? Address { get; set; }
```
