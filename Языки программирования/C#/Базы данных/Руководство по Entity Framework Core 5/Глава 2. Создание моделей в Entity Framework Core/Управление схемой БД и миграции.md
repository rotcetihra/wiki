Для приведения базы данных в соответствие с измененными моделями применяются миграции.

Для создания миграции в Visual Studio:

```
Add-Migration InitialCreate
```

Для выполнения миграции:

```
Update-Database
```

Для .NET CLI:

```
dotnet ef migrations add InitialCreate
dotnet ef database update
```
