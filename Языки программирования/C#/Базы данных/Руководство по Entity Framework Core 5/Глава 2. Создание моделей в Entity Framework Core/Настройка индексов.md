Для создания индекса используется атрибут [Index] или метод HasIndex():

```csharp
[Index("PhoneNumber")]
public class User
{
    public int Id { get; set; }
    public string? Name { get; set; }
    public string? PhoneNumber { get; set; }
}
```

```csharp
modelBuilder.Entity<User>().HasIndex(u => u.Passport);
```
