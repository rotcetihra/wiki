Все типы сущностей, для которых определены в контексте данных наборы DbSet, включаются в модель. Ссылочные типы также включаются, если на них есть ссылки в сущностях с DbSet.

Для исключения сущности из модели используется метод Ignore() или атрибут [NotMapped]:

```csharp
modelBuilder.Ignore<Company>();
```

Для включения сущности без DbSet:

```csharp
modelBuilder.Entity<Country>();
```
