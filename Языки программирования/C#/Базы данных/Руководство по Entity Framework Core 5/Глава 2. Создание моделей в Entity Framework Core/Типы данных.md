EF Core поддерживает множество типов данных C#, которые сопоставляются с типами столбцов SQL:

| Тип C# | Тип SQL |
|--------|---------|
| int | INTEGER |
| string | nvarchar(max) |
| bool | bit |
| DateTime | datetime2 |
| decimal | decimal(18,2) |
| double | float |
| byte[] | varbinary(max) |
| Guid | uniqueidentifier |
