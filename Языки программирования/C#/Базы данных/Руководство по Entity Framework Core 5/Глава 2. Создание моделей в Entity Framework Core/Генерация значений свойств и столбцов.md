Для свойств-ключей типа int или Guid значения генерируются автоматически. Для отключения используется атрибут [DatabaseGenerated] или метод ValueGeneratedNever():

```csharp
[DatabaseGenerated(DatabaseGeneratedOption.None)]
public int Id { get; set; }
```

```csharp
modelBuilder.Entity<User>().Property(b => b.Id).ValueGeneratedNever();
```

Для значений по умолчанию:

```csharp
modelBuilder.Entity<User>().Property(u => u.Age).HasDefaultValue(18);
```
