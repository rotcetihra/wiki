Для переименования таблицы используется атрибут [Table] или метод ToTable():

```csharp
[Table("People")]
public class User
{
    public int Id { get; set; }
    public string? Name { get; set; }
}
```

Для переименования столбца - атрибут [Column] или метод HasColumnName():

```csharp
[Column("user_id")]
public int Id { get; set; }
```
