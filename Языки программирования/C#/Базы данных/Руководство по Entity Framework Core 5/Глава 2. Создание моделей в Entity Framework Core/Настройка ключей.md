По умолчанию ключом является свойство Id или [Имя_класса]Id. Для установки другого ключа используется атрибут [Key] или метод HasKey():

```csharp
[Key]
public int Ident { get; set; }
```

```csharp
modelBuilder.Entity<User>().HasKey(u => u.Ident);
```

Составные ключи создаются только через Fluent API:

```csharp
modelBuilder.Entity<User>().HasKey(u => new { u.PassportSeria, u.PassportNumber});
```
