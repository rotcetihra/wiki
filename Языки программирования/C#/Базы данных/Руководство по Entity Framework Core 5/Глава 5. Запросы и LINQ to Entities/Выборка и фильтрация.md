Для фильтрации используется метод Where():

```csharp
var users = db.Users.Where(p => p.Company!.Name=="Google").ToList();
```

Для поиска по шаблону - EF.Functions.Like():

```csharp
var users = db.Users.Where(p => EF.Functions.Like(p.Name!, "%Tom%")).ToList();
```
