Для соединения - Join, для группировки - GroupBy:

```csharp
var users = db.Users.Join(db.Companies,
    u => u.CompanyId, c => c.Id,
    (u, c) => new { Name = u.Name, Company = c.Name, Age = u.Age });
```

```csharp
var groups = from u in db.Users group u by u.Company!.Name into g
             select new { g.Key, Count = g.Count() };
```
