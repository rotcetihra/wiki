Фильтры уровня модели определяются через HasQueryFilter():

```csharp
modelBuilder.Entity<User>().HasQueryFilter(u => u.Age > 17 && u.RoleId == RoleId);
```

Для отключения фильтра - IgnoreQueryFilters().
