Для установки конфигурации подключения можно применять два способа:

### Метод OnConfiguring

```csharp
protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
{
    optionsBuilder.UseSqlServer(@"Server=(localdb)\mssqllocaldb;Database=helloappdb;Trusted_Connection=True;");
}
```

### Передача конфигурации в конструктор

```csharp
public class ApplicationContext : DbContext
{
    public ApplicationContext(DbContextOptions<ApplicationContext> options)
        :base(options)
    {
        Database.EnsureCreated();
    }
}
```

### Файл конфигурации

Строку подключения можно вынести в файл appsettings.json:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Server=(localdb)\\mssqllocaldb;Database=helloappdb;Trusted_Connection=True;"
  }
}
```
