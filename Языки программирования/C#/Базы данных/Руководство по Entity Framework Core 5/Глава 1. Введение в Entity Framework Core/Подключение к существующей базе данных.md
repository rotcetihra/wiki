Для подключения к существующей базе данных MS SQL Server добавим два пакета: Microsoft.EntityFrameworkCore.SqlServer и Microsoft.EntityFrameworkCore.Tools.

Для реверса базы данных в Package Manager Console:

```
Scaffold-DbContext "Server=(localdb)\mssqllocaldb;Database=helloappdb;Trusted_Connection=True;" Microsoft.EntityFrameworkCore.SqlServer
```

После выполнения команды в проект будут добавлены классы моделей и контекста данных.
