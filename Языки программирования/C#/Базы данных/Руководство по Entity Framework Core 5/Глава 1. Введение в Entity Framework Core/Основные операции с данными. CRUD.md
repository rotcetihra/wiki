Entity Framework Core позволяет легко выполнять CRUD операции: добавление (Add), получение (ToList), обновление (SaveChanges), удаление (Remove).

```csharp
// Добавление
db.Users.Add(user1);
db.SaveChanges();

// Получение
var users = db.Users.ToList();

// Редактирование
User user = db.Users.FirstOrDefault();
user.Name = "Bob";
db.SaveChanges();

// Удаление
db.Users.Remove(user);
db.SaveChanges();
```

Если объект был получен в одном контексте, а обновляется в другом, то необходимо использовать метод Update:

```csharp
db.Users.Update(user);
db.SaveChanges();
```
