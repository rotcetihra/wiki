Для контроля операций контекста данных можно использовать логгирование. Метод LogTo() позволяет логгировать информацию:

```csharp
protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
{
    optionsBuilder.UseSqlServer(@"Server=(localdb)\mssqllocaldb;Database=helloappdb;Trusted_Connection=True;");
    optionsBuilder.LogTo(System.Console.WriteLine);
}
```

Можно задать уровень логгирования (Trace, Debug, Information, Warning, Error, Critical, None):

```csharp
optionsBuilder.LogTo(Console.WriteLine, LogLevel.Information);
```

Для фильтрации по категориям:

```csharp
optionsBuilder.LogTo(Console.WriteLine, new[] { RelationalEventId.CommandExecuted });
```
