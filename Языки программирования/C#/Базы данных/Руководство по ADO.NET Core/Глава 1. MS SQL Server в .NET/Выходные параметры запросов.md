Для определения типа параметра (входной/выходной) используется свойство Direction объекта SqlParameter со значениями:

-   **Input**: параметр является входным (по умолчанию)
-   **InputOutput**: параметр может быть как входным, так и выходным
-   **Output**: параметр является выходным
-   **ReturnValue**: параметр представляет результат выполнения выражения

```csharp
SqlParameter idParam = new SqlParameter
{
    ParameterName = "@id",
    SqlDbType = SqlDbType.Int,
    Direction = ParameterDirection.Output
};
command.Parameters.Add(idParam);
await command.ExecuteNonQueryAsync();
Console.WriteLine($"Id нового объекта: {idParam.Value}");
```
