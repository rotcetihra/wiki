Пул подключений позволяет использовать ранее созданные подключения. Если параметр `Pooling` в строке подключения равен `true` (по умолчанию), то после закрытия подключения оно возвращается в пул подключений, где оно готово к повторному использованию.

Для управления пулом:
-   `Max Pool Size`: максимальное количество подключений (по умолчанию 100)
-   `Min Pool Size`: минимальное количество подключений (по умолчанию 0)
-   `SqlConnection.ClearPool(connection)`: удаляет из пула конкретное подключение
-   `SqlConnection.ClearAllPools()`: полностью очищает пул подключений
