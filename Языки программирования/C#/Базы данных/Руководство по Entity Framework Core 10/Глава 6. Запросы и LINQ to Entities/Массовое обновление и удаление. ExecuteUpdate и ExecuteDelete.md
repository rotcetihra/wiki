В общем случае для обновления или удаления объектов в Entity Framework нам необходимо было сначала получить эти объекты. Контекст данных в EF Core по умолчанию отслеживает изменения в загруженных сущностях, а затем отправляет запросы на обновление в базу данных при вызове метода `SaveChange()`. Запросы на обновление отправляются только для тех свойств, которые действительно изменились. Кроме того, отслеживаемые объекты синхронизируются с изменениями, отправленными в базу данных. При этом изменения также группируются, чтобы уменьшить количество обращений к базе данных. Подобный механизм является довольно эффективным и удобным способом для работы с базой данных.

Однако нередко требуется просто обновить или удалить объекты без необходимости загружать их в контекст. В этом случае мы могли бы использовать sql-запросы. Но начиная с версии 7.0 в Entity Framework для типа IQueryable были добавлены два новых метода: ExecuteUpdate и ExecuteDelete и их асинхронные двойники ExecuteUpdateAsync и ExecuteDeleteAsync.

## ExecuteUpdate

Допустим, нам надо у всех пользователей увеличить свойство Age на 1:

```csharp
using (ApplicationContext db = new ApplicationContext())
{
    db.Users.ExecuteUpdate(s=>s.SetProperty(u=>u.Age, u=>u.Age +1));
}
```

Метод `ExecuteUpdate()` принимает делегат, параметр которого представляет набор выражений установки свойств. Через этот параметр вызываем метод SetProperty(), в котором устанавливаем новое значение свойства.

Если надо обновить не все, а какие-то определенные объекты, то перед вызовом `ExecuteUpdate()` определяем выборку. Например, обновим возраст только у тех объектов, у которых Name="Tom":

```csharp
using (ApplicationContext db = new ApplicationContext())
{
    db.Users.Where(u=>u.Name=="Tom")
        .ExecuteUpdate(s=>s.SetProperty(u=>u.Age, u=>u.Age +1));
}
```

С помощью дополнительных вызывов `SetProperty()` по цепочке можно обновлять несколько свойств одновременно:

```csharp
using (ApplicationContext db = new ApplicationContext())
{
    db.Users.Where(u =>u.Name == "Tom")
        .ExecuteUpdate(s => s
                .SetProperty(u => u.Age, u => u.Age + 1)
                .SetProperty(u=>u.Name, u => "Tomas"));
}
```

## ExecuteDelete

Метод ExecuteDelete() позволяет избежать ненужного промежуточного получения объектов для удаления. Мы сразу можем удалить их одним запросом:

```csharp
using (ApplicationContext db = new ApplicationContext())
{
    db.Users.Where(u => u.Name == "Tom").ExecuteDelete();
}
```

Можно сразу удалить все объекты:

```csharp
using (ApplicationContext db = new ApplicationContext())
{
    db.Users.ExecuteDelete();
}
```

### Недостатки методов

Выше говорилось о преимуществах методов ExecuteUpdate/ExecuteDelete. Но они также имеют недостатки. В частности, Любые отслеживаемые объекты в контексте данных не будут синхронизированы с теми изменениями, которые вызывают методы ExecuteUpdate/ExecuteDelete. Соответственно после изменения потребуется перезагружать данные из бд. Кроме того, возможно, потребуется отправить команды в правильном порядке, чтобы не нарушать ограничения базы данных. Например, удаленить зависимые сущности в БД до удаления привязанной главной сущности.
