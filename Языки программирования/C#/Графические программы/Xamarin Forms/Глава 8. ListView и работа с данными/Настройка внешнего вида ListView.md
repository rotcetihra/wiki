### Разделитель

По умолчанию все элементы списка разделяются горизонтальной чертой, которая служит в качестве разделителя. Однако с помощью свойства SeparatorVisibility 
можно отключить этот разделитель. Для этого оно получает значение `None`. В XAML:

```

```

В коде C#:

```
listView.SeparatorVisibility = SeparatorVisibility.None;
```

С помощью свойства SeparatorColor можно настроить цвет разделителя. В XAML:

```

```

В коде C#:

```
listView.SeparatorColor = Color.Red;
```

### Высота строк

Свойство RowHeight позволяет задать высоту строки в ListView. Но действовать оно будет только в том случае, если 
другое свойство в ListView - HasUnevenRows равно false.

Установка в XAML:

```

```

В коде C#:

```
listView.RowHeight = 100;
```

### Заголовок и футер в ListView

С помощью свойств Header и Footer у ListView можно задать соответственно заголовок и футер. В качестве значения мы можем задать обычные строки:

```

    
        
            
                
                    
                        
                            
                            
                            
                        
                    
                
            
        
    

```

Но в данном случае мы лишь увидим небольшие слаборазличимые надписи в начале и в конце списка:

Однако ListView позволяет задать шаблон для их отображения:

