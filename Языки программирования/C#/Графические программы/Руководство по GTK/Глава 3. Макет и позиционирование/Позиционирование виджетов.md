При создании виджетов и размещении их в окне приложения мы сталкиваемся с проблемой позиционирования. Так, при размещении виджета непосредственно внутри окна данный виджет по умолчанию центрируется и растягивается по всей поверхности окна. Но GTK предоставляет возможности для настройки позиционирования виджетов внутри контейнера.

## Выравнивание

Для всех виджетов GTK доступны два свойства, которые управляют выравниванием:

- Valign: выравнивание по вертикали
- Halign: выравнивание по горизонтали

В качестве значения эти свойства принимают одну из констант перечисления Align, которое устанавливает принцип выравнивания и принимает следующие значения:

- `Align.Fill`: растягивает виджет по всей площади контейнера, если не возможно растянуть, то центрирует виджет. Значение: 0 (В XML также соответствует значению `GTK_ALIGN_FILL`)
- `Align.Start`: прикрепляет виджет к левой (при выравнивании по горизонтали) или верхней (при выравнивании по вертикали) стороне контейнера, оставляя место справа или снизу. Значение: 1 (В XML - `GTK_ALIGN_START`)
- `Align.End`: прикрепляет виджет к правой (при выравнивании по горизонтали) или нижней (при выравнивании по вертикали) стороне, оставляя место слева или сверху. Значение: 2. (В XML - `GTK_ALIGN_END`)
- `Align.Center`: центрирует виджета внутри контейнера. Значение: 3ю (В XML - `GTK_ALIGN_CENTER`)
- `Align.BaselineFill`/`Align.Baseline`: выравнивает виджет по базовой линии. Значение: 4. (В XML - `GTK_ALIGN_BASELINE`)
- `Align.BaselineCenter`: растягивает по всей площади контейнера, но выравнивает по базовой линии. Значение: 5. (В XML - `GTK_ALIGN_BASELINE_CENTER`)

Нам необязательно использовать сразу обе функции: мы можем выравнивать виджет только по вертикали или только по горизонтали. Например, по умолчанию виджет центрируется, однако при этом также заполняет все пространство контейнера - окна. Но, допустим, нам надо только центрировать виджет без растяжения. В этом случае мы можем использовать значение `Align.Center`:

```csharp
using Gtk;

var app= Application.New("com.metanit", Gio.ApplicationFlags.DefaultFlags);

app.OnActivate += (sender, _) =>
{
    var window = new Window();
    window.Title = "METANIT.COM";
    window.DefaultWidth = 250;
    window.DefaultHeight = 200;

    var button = Button.NewWithLabel("Hello World");
    // выравнивание по центру по горизонтали
    button.Halign = Align.Center;
    // выравнивание по центру по вертикали
    button.Valign = Align.Center;

    window.Child = button;

    window.Application = (Application) sender;
    window.Show();
};

app.RunWithSynchronizationContext(null);
```

Другой пример - позиционируем виджет в верхнем левом углу. В этом случае нам надо установить выравнивание по левой стороне и по верху, что в обоих случаях соответствует значению `Align.Start`:

```csharp
var button = Button.NewWithLabel("Hello World");
// выравнивание слева по горизонтали
button.Halign = Align.Start;
// выравнивание в верху по вертикали
button.Valign = Align.Start;
```

### Установка выравнивания в XML

Аналогичная установка выравнивания по центру в XML (файл "builder.ui"):

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">300</property>
    <property name="default-height">250</property>
    <child>
      <object class="GtkButton" id="button">
        <property name="label">Hello World</property>
        <property name="halign">GTK_ALIGN_CENTER</property>
        <property name="valign">GTK_ALIGN_CENTER</property>
      </object>
    </child>
  </object>
</interface>
```

И основной файл приложения, где загружается интерфейс:

```csharp
using Gtk;

var app= Application.New("com.metanit", Gio.ApplicationFlags.DefaultFlags);

app.OnActivate += (sender, _) =>
{
    Builder builder = Builder.NewFromFile("builder.ui");
    Window? window = (Window?) builder.GetObject("window");
    if(window is null) return;

    window.Application = (Application) sender;
    window.Show();
};

app.RunWithSynchronizationContext(null);
```

## Управление отступами

Ряд универсальных свойств, которые имеются у всех виджетов, управляют отступами от краев контейнера:

- `MarginStart`: отступ от начала (слева) контейнера
- `MarginEnd`: отступ от конца (справа) контейнера
- `MarginTop`: отступ сверху
- `MarginBottom`: отступ снизу

Применение отступов:

```csharp
using Gtk;

var app= Application.New("com.metanit", Gio.ApplicationFlags.DefaultFlags);

app.OnActivate += (sender, _) =>
{
    var window = new Window();
    window.Title = "METANIT.COM";
    window.DefaultWidth = 250;
    window.DefaultHeight = 200;

    var button = Button.NewWithLabel("Hello World");

    button.Halign = Align.Start; // выравнивание слева по горизонтали
    button.Valign = Align.Start; // выравнивание в верху по вертикали

    button.MarginStart = 20;  // и на 10 единиц вниз
    button.MarginTop = 10;  // и на 10 единиц вниз

    window.Child = button;

    window.Application = (Application) sender;
    window.Show();
};

app.RunWithSynchronizationContext(null);
```
