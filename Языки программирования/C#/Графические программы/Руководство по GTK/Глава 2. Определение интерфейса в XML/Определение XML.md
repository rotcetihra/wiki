Файлы определения пользовательского интерфейса всегда используют кодировку UTF-8 (Но не "UTF-8 with BOM"). Обычно в начало определения интерфейса добавляется стандартный элемент `<xml>` с указанием версии xml и кодировкой utf-8:

```xml
<?xml version="1.0" encoding="UTF-8"?>
```

Элемент верхнего уровня - `<interface>`:

```xml
<?xml version="1.0" encoding="UTF-8">
<interface>
 Здесь располагается определение интерфейса
</interface>
```

## Объекты

Пользовательский интерфейс состоит из объектов, например, окна, кнопок, текстовых полей и других визуальных компонентов.Для определения объекта в XML фреймворк GTK использует элемент `<object>`. Объекты определяются как дочерние элементы внутри элемента `<interface>`. Для элемента `<object>` определены два важных атрибута:

- `class`: указывает на тип объекта. Например, окно представляет тип `GtkWindow`. Соответственно атрибут `class` объекта, который представляет окно, будет иметь это значение

Этому атрибуту передаются типы языка Си, которые в C# соответствуют названию класса плюс название пространства имен, где размещены эти классы. Например, в C# мы имеем класс "Window", который расположен в пространстве имен "GTK". Соответственно в языке Си ему будет соответствовать тип "GtkWindow". Аналогично, если в C# у нас есть класс кнопки "Gtk.Button", то в Си ему соответствует тип "GtkButton", и поэтому в XML указываем "GtkButton".

- `id`: произвольный идентификатор объекта, который соответствует имени переменной в коде на С#. Через идентификатор можно ссылать на объект. Стоит отметить, что GTK резервирует идентификаторы, начинающиеся и заканчивающиеся на ___ (три последовательных подчеркивания) для своих собственных целей.

Пример объекта, который представляет окно приложения:

```xml
<object class="GtkWindow" id="window">
<--! здеcь располагается содержимое окна -->
</object>
```

Таким образом, мы определили объект с именем window, который имеет тип GtkWindow.

## Свойства

Различные характеристика объекта доступны через его свойства. Для определения свойств объекта в XML применяется элемент `<property>`:

```xml
<property name="имя_свойства">значение_свойства</property>
```

С помощью атрибута `name` задается имя свойства, а внутри элемента `<property>` помещается значение.

И здесь стоит учитывать имя свойства. Если в C# общий стиль наименования - PascalCase или UpperCamelCase, при котором каждое подслово в имени свойства начинается с большой буквы, например, `DefaultWidth`, то в XML им будут соответствовать имена в "kebab-case", когда подслова начинаются с малой буквы и разлеояются дефисом, например, "default-width". Аналогично свойству `DefaultHeight` из C# в XML будет соответствовать свойство `default-height`.

Таким образом, определение нашего окна будет выглядеть следующим образом:

```xml
<object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">300</property>
    <property name="default-height">250</property>
</object>
```

Стоит отметить, что в примере выше значения свойств задаются как обычный текст. Дело в том, что Builder может анализировать текстовые представления для наиболее распространенных типов свойств:

- символы
- строки
- целые числа
- числа с плавающей точкой
- логические значения (строки типа "TRUE", "t", "yes", "y", "1" интерпретируются как истинные значения, строки типа "FALSE", "f", "no", "n", "0" интерпретируются как ложные значения)
- списки строк (разделенные символам перевода строки \\n)
- типы перечислений (могут быть указаны их полным идентификатором, их кратким именем, используемым при регистрации типа перечисления или их целочисленным значением)
- типы флагов (могут быть указаны их идентификатором или кратким именем, опционально объединенным с "|" для побитового ИЛИ, или одним целочисленным значением, например, "GTK\_INPUT\_HINT\_EMOJI|GTK\_INPUT\_HINT\_LOWERCASE" или "emoji|lowercase" или 520).
- цвета (в формате, понимаемом rgba)
- файлы, например, в виде файлового пути

В итоге типовое определение интерфейса простейшего окна будет выглядеть следующим образом:

```xml
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">300</property>
    <property name="default-height">250</property>
  </object>
</interface>
```

## Вложенные объекты

Посмотрим на определение чуть более сложных интерфейсов. Например, нам надо вывести простейший текст в окне. Для вывода текста можно использовать класс Label. Для создания объекта `Label` применяется статический метод Label New(string? str), в которую передается отображаемый текст.

После создания объекта Label, нам надо добавить его в окно. Для этого GTK предоставляет свойство Child(), которому передается добавляемый в окно объект. Возьмем простейший пример:

```csharp
using Gtk;

var app= Application.New("com.metanit", Gio.ApplicationFlags.DefaultFlags);

app.OnActivate += (sender, _) =>
{
    Window window = new Window();
    window.Title = "METANIT.COM";
    window.DefaultWidth = 250;
    window.DefaultHeight = 200;

    // создаем метку
    Label label = Label.New("Hello World");
    // добавляем метку в окно
    window.Child = label;

    window.Application = (Application) sender;
    window.Show();
};

app.RunWithSynchronizationContext(null);
```

Мы получаем следующее окно с текстом по центру:

![Добавление виджетов в окно в GTK и C#](./pics/3.1.png)

Поскольку в коде C# для добавления метки в окно нам надо установить свойство `Child` можно догадаться, то в XML аналогично надо установить свойство `child`. Однако в данном случае мы имеем дело не просто текстом или числом, а сложным объектом `Label` (которому в XML будет соответствовать "GtkLabel"). Другая сложность состоит, что также надо задать текст этого объекта. Для этого определим файл builder.ui со следующим кодом:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">250</property>
    <property name="default-height">200</property>
    <property name="child">
       <object class="GtkLabel" id="label">
          <property name="label">Hello Work</property>
        </object>
    </property>
  </object>
</interface>
```

Итак, для задания содержимого окна - свойства `child` применяем элемент

```xml
<property name="child">
```

Значение свойства child определяется внутри данного элемента:

```xml
<object class="GtkLabel" id="label">
    <property name="label">Hello Work</property>
</object>
```

У GtkLabel текст хранится в свойстве `label`, поэтому устанавливаем это свойство. (Стоит отметить, что для установки текста в коде С# для типа Label применяется свойство `Label_`).

В коде C# мы можем загрузить и использовать это определение интерфейса следующим образом:

```csharp
using Gtk;

var app= Application.New("com.metanit", Gio.ApplicationFlags.DefaultFlags);

app.OnActivate += (sender, _) =>
{
    Builder builder = new Builder("builder.ui");
    Window? window = (Window?) builder.GetObject("window");
    if(window is null) return;

    window.Application = (Application) sender;
    window.Show();
};

app.RunWithSynchronizationContext(null);
```

### Элемент child

Стоит отметить, что для объектов, которые имеют свойство `child`, вместо полного определения свойства

```xml
<property name="child">
```

могут использовать элемент `<child>`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">250</property>
    <property name="default-height">200</property>
    <child>
       <object class="GtkLabel" id="label">
          <property name="label">Hello Work</property>
        </object>
    </child>
  </object>
</interface>
```
