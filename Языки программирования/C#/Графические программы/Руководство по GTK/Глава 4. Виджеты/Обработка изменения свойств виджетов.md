Различные виджеты в GTK имеют различный набор свойств. И нередко возникает необходимость отследить изменение значения этих свойств наподобие того, как это делается с помощью реализации интерфейса `INotifyPropertyChanged` в стандартных классах на C#. В GirCore это сделать достаточно легко.

Прежде всего надо отметить, что для всех свойств виджетов предоставляет надстройка в виде объекта класса `Property<T, K>`. Этот класс типзируется двумя типами, где тип `T` - это тип свойства, а тип `K` - тип, где определено свойство.

Например, возьмем виджет `Entry`, у которого есть свойство `Text_` для хранения текста. Это свойство определено в интерфейсе `Editable`, который реализуется классом Entry. И в том же интерфейсе Editable для этого свойства определена обертка Text_PropertyDefinition

```csharp
public static readonly Property<string?, Editable> Text_PropertyDefinition
```

Из определения `Text_PropertyDefinition` мы видим, что оно представляет свойство с типом `string?`, которое определено в типе (в данном случае в интерфейсе) `Editable`

Аналогично для хранения текста кнопки в классе Button определено свойство Label

```csharp
public string? Label { get; set; }
```

И в тои же классе Button для этого свойства есть обертка в виде свойства LabelPropertyDefinition:

```csharp
public static readonly Property<string?, Button> LabelPropertyDefinition
```

Из этих примеров нетрудно увидеть, что в именовании подобных свойства есть определенный паттерн: имя свойства + "PropertyDefinition".

Теперь самое главное - зачем нам нужны эти свойства типа `Property<T, K>`? Этот класс предоставляет нам метод Notify для отслеживания изменения свойства:

```csharp
public void Notify(K sender, SignalHandler<Object, Object.NotifySignalArgs> signalHandler, bool after = false)
```

Параметры метода:

- `sender`: объект, свойство которого надо прослушивать
- `signalHandler`: делегат типа `SignalHandler<Object, Object.NotifySignalArgs>`, который представляет обработчик, вызываемый при изменении свойства
- `after`: булевое значение, которое указывает, должно ли действие обработчика сигнала вызываться до или после обработчика по умолчанию.

Итак, в этот метод нам надо передать объект, свойство которого надо прослушивать, и делегат `SignalHandler`.

Теперь посмотрим на конкретном примере - допустим, нам динамически надо обработать ввод текста в текстовое поле Entry (то есть отследить изменения в свойстве `Text_`):

```csharp
using Gtk;

var app= Application.New("com.metanit", Gio.ApplicationFlags.DefaultFlags);

Label label = Label.New(null);

app.OnActivate += (sender, _) =>
{
    var window = new Window();
    window.Title = "METANIT.COM";
    window.DefaultWidth = 250;
    window.DefaultHeight = 200;

    Box box =  Box.New(Orientation.Vertical, 10);
    box.Valign = Align.Start; // выравнивание по верхнему краю

    Entry entry = Entry.New();

    Editable.Text_PropertyDefinition.Notify(
        sender: entry,
        signalHandler: OnTextChanged
    );

    box.Append(entry);
    box.Append(label);

    window.Child = box;
    window.Application = (Application) sender;
    window.Show();
};

app.RunWithSynchronizationContext(null);
```

void OnTextChanged(GObject.Object sender, GObject.Object.NotifySignalArgs e)

```csharp
{
    // получаем текст из текстового поля и передаем метке
    Entry entry = (Entry) sender;
    label.Label_ = entry.Text_;
}
```

Отмечу основные моменты. Для отслеживания изменения текста в текстовом поле используем следующую конструкцию:

```csharp
Editable.Text_PropertyDefinition.Notify(
    sender: entry,
    signalHandler: OnTextChanged
);
```

То есть нам надо отслеживать свойство "Text_", которое класс Entry получает от интерфейса `Editable`. С этим свойством связано свойство-определение `Text_PropertyDefinition`, которое представляет тип `Property`. У объекта `Property` вызываем метод `Notify`. В этот метод параметру "sender" передаем объект entry (который одновременно является объектом Editable). А параметру "signalHandler" передаем метод OnTextChanged, который будет обрабатывать изменения свойства `Text_`:

```csharp
void OnTextChanged(GObject.Object sender, GObject.Object.NotifySignalArgs e)
{
    // получаем текст из текстового поля и передаем метке
    Entry entry = (Entry) sender;
    label.Label_ = entry.Text_;
}
```

Через первый параметр - sender мы можем получить объект, вызвавший событий (в нашем случае объект Entry) и получить его текст и далее передать его для отображения на текстовую метку. Второй параметр - объект NotifySignalArgs здесь не задействуется, но в целом через него можно получить дополнительную информацию об устанавливаемом свойстве.

В итоге при изменении текста в текстовом поле Entry также будет меняться текст на текстовой метке.
