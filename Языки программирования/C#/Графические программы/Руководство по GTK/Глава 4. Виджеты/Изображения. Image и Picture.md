## Image

Класс `Image` в GTK представляет виджет для вывода изображений. Он поддерживает различные форматы изображений и предоставляет гибкие возможности для работы с графикой в кроссплатформенных приложениях. Класс `Image` позволяет загружать изображения из файлов, отображать встроенные в приложение ресурсы, работать с изображениями в памяти, масштабировать и трансформировать изображения.

Для создания объекта `Image` можно использовать ряд статических методов:

- `Image.New()`
  Создает пустой объект Image, не привязанный изначально ни к какому изображению
- `Image.NewFromFile(string filename)`
  Получает изображение из указанного файла.
- `Image.NewFromGicon(Icon icon)`
  Создает виджет Image, который будет отображать иконку `Icon`.
- `Image.NewFromIconName(string? iconName)`
  Создает виджет Image, который будет отображать иконку по определенному имени.
- `Image.NewFromPaintable(Paintable? paintable)`
  Создает виджет Image, который будет отображать объект `Paintable`.
- `Image.NewFromPixbuf(Pixbuf? pixbuf)`
  Получает изображение из объекта `Gdk.Pixbuf`.
- `Image.NewFromResource(string resourcePath)`
  Создает виджет Image, который будет отображать ресурс по указанному пути.

Например, в папке проекта у нас находится файл "flower.jpg". Загрузим изображение в приложение:

```csharp
using Gtk;

var app= Application.New("com.metanit", Gio.ApplicationFlags.DefaultFlags);

app.OnActivate += (sender, _) =>
{
    var window = new Window();
    window.Title = "METANIT.COM";
    window.DefaultWidth = 250;
    window.DefaultHeight = 200;

    Image image = Image.NewFromFile("flower.jpg");

    window.Child = image;
    window.Application = (Application) sender;
    window.Show();
};

app.RunWithSynchronizationContext(null);
```

Для установки источника изображения в XML можно использовать свойства, которые соответствуют применяемым методам:

- file
- gicon
- resource
- paintable

Так, аналогичный пример интерфейса в XML:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">250</property>
    <property name="default-height">200</property>
    <child>
        <object class="GtkImage" id="imageView">
          <property name="file">flower.jpg</property>
        </object>
    </child>
  </object>
</interface>
```

Стоит отметить, что мы можем динамически установить нужное изображение после создания виджета с помощью соответствующих свойств класса Image:

```csharp
public string? File { get; set; }
public Icon Gicon { get; set; }
public string? IconName { get; set; }
public Paintable Paintable { get; set; }
public string? Resource { get; set; }
```

### Pixbuf

Проблема с виджетом `Image` заключается в том, что он не поддается масштабированию. Например, в примере выше, если изображение слишком большое - больше поверхности виджета, то просисходит растяжение виджета Image и соответственно размеров окна, чтобы вместить весь контент. Если изображение маленькое - меньше размеров виджета, то оно отображается как есть.

Но GTK позволяет управлять размером отображаемого изображения. Для этого применяется объекта= `GdkPixbuf.Pixbuf`, который по сути представляет пиксельный буфер. У этого класса есть пметод `ScaleSimple()`:

```csharp
public Pixbuf? ScaleSimple(int destWidth, int destHeight, InterpType interpType)
```

Этот метод измененяет размер изображения до новой ширины и высоты, которые передаются через первые два параметра. Третий параметр - значение типа `InterpType` представляет тип интерполяции и может принимать значения `InterpType.Bilinear` для разумного баланса между качеством и скоростью и `InterpType.Hyper`, который создает изображение более высокого качества, но работает медленнее. Результатом метода является новый объект `Pixbuf`, который можно установить в качестве источника изображения для виджета `Image`. Например:

```csharp
using Gtk;
using GdkPixbuf;

var app= Application.New("com.metanit", Gio.ApplicationFlags.DefaultFlags);

app.OnActivate += (sender, _) =>
{
    var window = new Window();
    window.Title = "METANIT.COM";
    window.DefaultWidth = 250;
    window.DefaultHeight = 200;

    Pixbuf? original = Pixbuf.NewFromFile("flower.jpg");
    // масштабируем изображение до размеров 2000х120
    Pixbuf? scaled = original.ScaleSimple(200, 180, InterpType.Bilinear);

    Image image = Image.NewFromPixbuf(scaled);

    window.Child = image;
    window.Application = (Application) sender;
    window.Show();
};

app.RunWithSynchronizationContext(null);
```

Здесь масштабируем изображение, устанавливая для него в качестве новой ширины 200 пикселей, а высоты - 180 пикселей:

```csharp
Pixbuf? scaled = original.ScaleSimple(200, 180, InterpType.Bilinear);
```

## Picture

Хотя виджет `Image` и позволяет отобразить изображение, но больше подходит для отображения иконок и выводит изображение в том размере, который определяется приложением. Для более точной настройки вывода изображения лучше использовать другой виджет - **Picture**.

Для **Picture** также определен ряд функций-конструкторов:

- `Picture.New()`: создает новый пустой виджет Picture
- `Picture.NewForFile(File? file)`: создает новый Picture, отображающий указанный файл в виде объекта `File*`
- `Picture.NewForFilename(string? filename)`: создает новый Picture, отображающий файл по определенному пути
- `Picture.NewForPaintable(Paintable? paintable)`: создает новый Picture, отображающий объект GdkPaintable
- `Picture.NewForResource(string? resourcePath)`: создает новый Picture, отображающий ресурс по определенному адресу
- `Picture.NewForPixbuf(Pixbuf? pixbuf)`: создает новый Picture, отображающий объект Pixbuf

Так, возьмем предыдущий пример и изменим `Image` на **Picture**:

```csharp
using Gtk;

var app= Application.New("com.metanit", Gio.ApplicationFlags.DefaultFlags);

app.OnActivate += (sender, _) =>
{
    var window = new Window();
    window.Title = "METANIT.COM";
    window.DefaultWidth = 250;
    window.DefaultHeight = 200;

    Picture image = Picture.NewForFilename("flower.jpg");

    window.Child = image;
    window.Application = (Application) sender;
    window.Show();
};

app.RunWithSynchronizationContext(null);
```

В отличие от GtkImage в Picture изображение растягивается по ширине виджета с сохранением пропорций:

Аналогичный пример интерфейса в XML:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<interface>
  <object class="GtkWindow" id="window">
    <property name="title">METANIT.COM</property>
    <property name="default-width">250</property>
    <property name="default-height">200</property>
    <child>
        <object class="Picture" id="imageView">
          <property name="file">flower.jpg</property>
        </object>
    </child>
  </object>
</interface>
```

Также, как и в случае с GtkImage, изображение можно установить динамически после создания виджета. Например, для установки файла по пути применяется свойство `gtk_picture_set_filename()`

```csharp
public File File { get; set; }
```

### Управление размерами изображения

Ключевое отличие **Picture** от Image состоит в том, что Picture позволяет изменять размеры выводимого изображения. В частности, свойство **ContentFit** устанавливает принцип размещения изображения внутри виджета:

```csharp
public ContentFit ContentFit { get; set; }
```

Это свойство принимает одно из значений перечисления **ContentFit**:

- `ContentFit.Fill`: заполняет все пространство контейнера, не принимая во внимание соотношение сторон. Результирующее содержимое будет выглядеть растянутым, если его соотношение сторон отличается от соотношения сторон выделения. Значение: 0
- `ContentFit.Contain`: масштабирует изображение, чтобы оно соответствовало размерам виджетаю, принимая во внимание его соотношение сторон. Значение: 1
- `ContentFit.Cover`: заполняет все пространство контейнера, принимая во внимание соотношение сторон содержимого. Результирующее содержимое будет выглядеть обрезанным, если его соотношение сторон отличается от соотношения сторон выделения. Значение: 2
- `ContentFit.ScaleDown`: при необходимости масштабирует изображение, чтобы вписать его в размеры виджета. Если масштабирование не нужно, используется исходный размер изображения. Значение: 3

Например:

```csharp
Picture image = Picture.NewForFilename("flower.jpg");
image.ContentFit = ContentFit.Cover;
```
