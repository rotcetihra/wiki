Для создания и управления окнами верхнего уровня в приложении в GTK применяется класс Window. Этот класс является основой для большинства графических приложений, так как используется для создания окон верхнего уровня, которые могут содержать другие элементы интерфейса (виджеты), такие как кнопки, текстовые поля, метки и т.д. Окно может быть главным окном приложения или диалоговым окном. Класс `Window` предоставляет методы и свойства для настройки внешнего вида, управления размером, положением, заголовком, поведением и взаимодействия окна с пользователем

Для создания окна можно использовать пустой конструктор:

```csharp
var window = new Window();
```

либо статический метод `New()`:

```csharp
var window = Window.New();
```

Для настройки внешнего вида и функциональности класс Window предоставляет множество свойств. Рассмотрим самые основные:

- Application: объект Application - приложение, к которому принадлежит окно
- Child: вложенный визуальный компонент в виде объекта типа `Widget`
- DefaultHeight: высота окна по умолчанию
- DefaultWidth: ширина окна по умолчанию
- Fullscreened: значение типа `bool`, которое указывает, переходит ли окно в полноэкранный режим
- Maximized: значение типа `bool`, которое указывает, разворачивается ли окно на максимально возможный размер
- Resizable: значение типа `bool`, которое указывает, можно ли изменять размер окна
- Title: заголовок окна

Среди методов следует отметить метод Show(), который унаследован от родительского класса Widget и который делает окно видимым, благодаря чему пользователь может увидеть его на экране и начать с ним взаимодействовать.

Простейший пример создания окна:

```csharp
using Gtk;

var app= Application.New("com.metanit", Gio.ApplicationFlags.DefaultFlags);

app.OnActivate += (sender, args) =>
{
    Window window = new Window();  // Создаем новое окно
    window.Title = "METANIT.COM";  // Устанавливаем заголовок окна

    window.DefaultWidth = 250;      // Устанавливаем начальную ширину окна
    window.DefaultHeight = 200;     // Устанавливаем начальную высоту окна

    // Свойство Application окна указывает на текущий объект приложения
    window.Application = (Gtk.Application) sender;

    window.Show();    // Отображаем окно на экране
};

return app.RunWithSynchronizationContext(null);
```

## Размеры окна

Свойства `DefaultWidth` и `DefaultHeight` устанавливают соответственно ширину и высоту по умолчанию. Размер окна по умолчанию — это размер, который будет использоваться, если не применяются другие ограничения. Размер по умолчанию будет обновляться всякий раз, когда размер окна изменяется. Если минимальный размер окна больше, чем размер по умолчанию, то размер по умолчанию будет проигнорирован. Установка размера по умолчанию в значение <= 0 приведет к его игнорированию и вместо него будет использоваться естественный размер.

Кроме данных свойств, для установки размеров можно использовать метод SetDefaultSize(), который устанавливает сразу и ширину, и высоту:

```csharp
void SetDefaultSize(int width, int height)
```

Применение:

```csharp
Window window = new Window();  // Создаем новое окно
window.SetDefaultSize(250, 200);  // ширина - 250, высота - 200
```

## Свойства окна

Выше для создания графического интерфейса применялся тип Window. Однако более рекомендуемым подходом является применение другого типа - ApplicationWindow. Этот тип наследуется от `Window`, поэтому все, что характерно для `Window`, также применяется к ApplicationWindow. Но при этом ApplicationWindow также имеет некоторые дополнительные возможности для лучшей интеграции с Application. В частности, для создания окна применяется статический метод `ApplicationWindow.New`, в которую в качестве параметра передается объект приложения, с которым надо установить связь:

```csharp
public static ApplicationWindow New(Application application)
```

Применение `ApplicationWindow`:

```csharp
using Gtk;

var app= Application.New("com.metanit", Gio.ApplicationFlags.DefaultFlags);

app.OnActivate += (sender, args) =>
{
    var window = ApplicationWindow.New(app);  // Создаем новое окно
    window.Title = "METANIT.COM";  // Устанавливаем заголовок окна
    window.SetDefaultSize(250, 200);  // устанавливаем размеры окна

    window.Show();    // Отображаем окно на экране
};

app.RunWithSynchronizationContext(null);
```
