GTK (GIMP Toolkit) — это кроссплатформенный фреймворк для создания графических пользовательских интерфейсов (GUI). Первоначально разработанный для GIMP (графического редактора) по мере развития GTK вышел за рамки проекта GIMP, превратился в самостоятельный инструментарий для создания пользовательского интерфейса и быстро зарекомендовала себя как надежный инструмент для создания приложений, поддерживающих различные операционные системы. В 1998 году вышла первая версия GTK. На сегодняшний день GTK является одним из наиболее используемых инструментов для создания пользовательского интерфейса. Например, на основе GTK построены рабочие окружения GNOME и Xfce.

GTK позволяет разработчикам создавать приложения с красивыми и функциональными интерфейсами, используя различные виджеты (кнопки, текстовые поля, меню и т. д.). Важно отметить, что GTK предназначен не только для Linux; он работает на Windows и macOS, что делает его отличным выбором для кроссплатформенной разработки.

Хотя базовым языком для разработки с GTK является язык C, в данном случае мы будем использовать язык C#. Поскольку, с одной стороны, C# — это современный, объектно-ориентированный язык программирования. Его синтаксис прост и понятен, а богатая стандартная библиотека и поддержка .NET делают его мощным инструментом для разработки разнообразных приложений. А с другой стороны, в сочетании с C# GTK становится отличным выбором для создания современных приложений

Изначально для создания приложений на C# с помощью GTK применялась такая технология как GTK# (GtkSharp). По сути GTK# — это набор .NET-обвязок для библиотеки GTK, который позволяет разработчикам использовать GTK с языками программирования .NET, такими как C#. И хотя эта библиотека довольно удобна для примененяи, она продолжительное время стагнирует и поддерживает только старые версии GTK - не выше GTK 3. В то время как текущей версией, применяемой в Linux-подобных системах уже долгое время является GTK 4. Поэтому в текущем руководстве вместо GTK# мы будем использовать лругой проект - Gir.Core. Это проект, целью которого является предоставление привязок C# для различных библиотек на основе типа `GObject` (ключевой тип в GTK) для создания пользовательских интерфейсов.

Gir.Core предоставляет доступ ко всем основным функциям GTK, но с удобным интерфейсом для C# и других языков .NET. Библиотека обрабатывает все основные аспекты взаимодействия с GTK, позволяя разработчикам сосредоточиться на логике приложения, а не на технических деталях интеграции с низкоуровневыми C API. Кроме того, тесно интегрируется с платформой .NET, что позволяет разработчикам использовать все ее возможности.

Преимущества использования Gir.Core и GTK:

- Кроссплатформенность: позволяет создавать приложения, которые могут работать на различных операционных системах без изменений кода. Это особенно важно для разработчиков, которые хотят охватить большую аудиторию, не ограничиваясь только одной операционной системой.
- Богатый набор виджетов: GTK предлагает широкий выбор готовых элементов интерфейса, таких как кнопки, поля ввода, меню и т.д.
- Простота использования: предоставляет удобный и интуитивно понятный API для работы с элементами интерфейса.
- Интеграция с .NET: распространяется как пакет через Nuget, соответственно может применяться в любом проекте на .NET.

Можно отметить, что такой относительно популярный редактор изображений на языке C#, как Pinta, (преимущественно заточенный под Linux, но не только) как раз использует Gir.Core.

Тем не менее нельзя не сказать, что `Gir.Core` еще ен преодолел порог 1 версии (на момент написания статьи это версия 0.6.3), и некоторые возможности GTK могут быть недоступны или работать нестально.

Но в конечном итоге, если вы хотите использовать C# для разработки графических приложений, особенно под Linux, то Gir.Core — это один из лучших выборов, который предоставляет вам все возможности для создания профессиональных, кроссплатформенных решений с минимальными усилиями.

Также стоит отметить, что Gir.Core развивается как проект с открытым кодом и доступен на в репозитории на github по адресу [https://github.com/gircore/gir.core](https://github.com/gircore/gir.core)

## Установка GTK и настройка окружения

Для работы с GTK и C# нам естественно потребуется установленный .NET SDK. Кроме того, нам надо установить сам GTK.

### Установка GTK на Linux

Для работы с GTK на Linux нам надо установить соответствующий пакет:

- Для Debian/Ubuntu это пакет **libgtk-4-dev**

```bash
sudo apt install libgtk-4-dev
```

- Для Fedora это пакет **gtk4-devel**:

```bash
dnf install gtk4-devel
```

### Установка GTK на Windows

Для создания приложений на GTK на Windows нам потребуется MSYS. Проект MSYS2 предоставляет UNIX-подобную среду разработки для Windows. Он предоставляет пакеты для многих программных приложений и библиотек, включая стек GTK.

Итак, загрузим установщик MSYS с сайта [https://www.msys2.org/](https://www.msys2.org/)

После загрузки запустим программу установки:

![Установка пакета mingw-w64 и msys2 на Windows](./pics/1.1.png)

На первом шаге установки будет предложено установить каталог для установки. По умолчанию это каталог C:\msys64:

![Установка компиляторов Си MSYS2 на Windows](./pics/1.2.png)

Оставим каталог установки по умолчанию (при желании можно изменить). На следующем шаге устанавливаются настройки для ярлыка для меню Пуск, и затем собственно будет произведена установка. После завершения установки нам отобразить финальное окно, в котором нажмем на кнопку Завершить

![Установка компиляторов MSYS2 на Windows](./pics/1.2.1.png)

Теперь нам надо установить собственно GTK и все его зависимости. Для этого в папке установки MSYS (по умолчанию `C:/msys64`) надо найти и запустить файл usrt\_64.exe:

![компиляторы MSYS2.exe на Windows](./pics/1.2.9.png)

В MSYS2 пакеты устанавливаются с помощью менеджера пакетов pacman. И для установки GTK в открывшуюся консоль введем команду

```bash
pacman -S mingw-w64-ucrt-x86_64-gtk4
```

![Установка GTK для создания графических приложений на С с помощью MSYS2.exe на Windows](./pics/1.3.1.png)

Также надо добавить в переменные среды путь "C:\msys64\ucrt64\bin".

Также для разработки на С нам потребуется установить еще пару пакетов

```bash
pacman -S mingw-w64-ucrt-x86_64-toolchain base-devel
```

### Установка GTK для MacOS

На MacOS самый простой способ - установка GTK через пакетный менеджер Homebrew (что подразумевает, что Homebrew уже должен быть установлен) с помощью следующей команды:

```bash
brew install gtk4
```

## Первое приложение на GTK

Создадим новый проект на .NET с помощью следующей команды:

```bash
dotnet new console -o gtkapp
```

Таким образом, в текущей папке будет создан новый каталог проекта, который будет называться "gtkapp". Перейдем в консоли в этот каталог и для добавления в проект функционала Gir.Core выполним команду

```bash
dotnet add package GirCore.Gtk-4.0
```

Данная команда добавить в проект последнюю версию пакета GirCore.Gtk-4.0

## Создание первого приложения

Откроем в проекте автосгенерированный файл Program.cs и изменим его код следующим образом:

```csharp
using Gtk; // подключаем пространство имен GTK

// создаем объект приложения
var app = Application.New("com.metanit.hello", Gio.ApplicationFlags.FlagsNone);

// обработчик активации приложения
app.OnActivate += (sender, args) =>
{
    Window window = new Window();  // Создаем новое окно
    window.Title = "METANIT.COM";  // Устанавливаем заголовок окна

    window.DefaultWidth = 250;      // Устанавливаем начальную ширину окна
    window.DefaultHeight = 200;     // Устанавливаем начальную высоту окна

    // Свойство Application окна указывает на текущий объект приложения
    window.Application = (Application) sender;

    window.Show();    // Отображаем окно на экране
};

// запускаем приложение
return app.RunWithSynchronizationContext(null);
```

Для упрощения доступа к функциональности необходимых классов подключаем пространство имен Gtk, которое содержит классы и методы для работы с графическим интерфейсом:

```csharp
using Gtk;
```

Кроме данного пространства имен в GirCore.Gtk есть еще ряд пространств, которые содержать используемую функциональность (например, `Gio`), но Gtk - основное пространство, где содержатся все виджеты, в частности, класс окна Window, а также класс приложения Application.

Сначала создаем объект приложения с помощью функции `Application.New()`:

```csharp
var app = Application.New("com.metanit", Gio.ApplicationFlags.FlagsNone);
```

Первый параметр представляет уникальный идентификатор приложения, используемый для идентификации приложения. В примере выше это строка "com.metanit".

Второй параметр - флаги, которые управляют некоторыми возможностями приложения. Здесь (и вообще в большинстве случаев) этот параметр не важен, поэтому передается значение `Gio.ApplicationFlags.FlagsNone`, которое указывает, что специальные флаги не используются.

Далее для приложения определяется обработчик события "OnActivate" приложения:

```csharp
app.OnActivate += (sender, args) =>
{
    .......................
}
```

Это событие срабатывает при запуске или активации приложения.

Далее создается окно - объект Window:

```csharp
Window window = new Window();  // Создаем новое окно
window.Title = "METANIT.COM";  // Устанавливаем заголовок окна

window.DefaultWidth = 250;      // Устанавливаем начальную ширину окна
window.DefaultHeight = 200;     // Устанавливаем начальную высоту окна
```

С помощью свойства `Title` у окна устанавливается заголовок, а через свойства `DefaultWidth` и `DefaultHeight` устанавливаются размеры окна (ширина в 250 пикселей и высота в 200 пикселей)

Затем устанавливается свойство `Application` окна на текущий экземпляр приложения (который передается в обработчик события через паарметр `sender`):

```csharp
window.Application = (Application) sender;
```

Это связывает окно с приложением, позволяя им работать вместе.

Далее метод `window.Show()` отображает окно и все его дочерние виджеты (в данном случае дочерних элементов нет, просто отображается окно):

```csharp
window.Show();
```

И в самом конце запускается приложение и вместе с ним основной цикл обработки событий GTK-приложения:

```csharp
return app.RunWithSynchronizationContext(null);
```

Этот метод обеспечивает правильную синхронизацию потоков для GTK. Единственному параметру метода передается дополнительные аргументы (обычно аргументы командной строки), но здесь это не важно, поэтому передаем `null`.

Запустим проект с помощью команды

```bash
dotnet run
```

И нам отобразится небольшое пустое окно
