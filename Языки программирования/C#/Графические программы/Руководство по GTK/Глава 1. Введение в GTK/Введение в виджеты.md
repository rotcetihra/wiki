Виджеты представляют основные строительные блоки приложения GTK, такие как кнопки, текстовые поля и т.д. Библиотека GTK обладает большим набором виджетов для всех основных сценариев. Все эти виджеты представляют подклассы базового типа Widget. Если же функциональности стандартных виджетов недостаточно, то можно создать более специализированные виджеты на основе уже существующих.

Основные виджеты в GTK:

- **Label**: метка, которая представляет однострочную или многострочную надпись
- **Spinner**: индикатор загрузки
- **Statusbar**: строка статуса
- **ProgressBar**: индикатор прогресса
- **Scrollbar**: полоса прокрутки
- **Image**: область для вывода изображения
- **Separator**: вертикальные и горизонтальные разделители
- **TextView**: многострочное поле для редактируемого текста
- **Scale**: ползунок
- **DrawingArea**: область для рисования
- **Video**: виджет для воспроизведения видео
- **Calendar**: календарь
- **PopoverMenu**: контекстное меню
- **Button**: кнопка
- **ToggleButton**: кнопка-переключатель, которая может находиться в двух состояниях (вкл и выкл)
- **LinkButton**: кнопка-ссылка
- **CheckButton**: флажок/переключатель (радиокнопка), который может находиться в отмеченном (выбранном) и неотмеченном состоянии
- **ComboBox**: выпадающий список
- **DropDown**: выпадающий список
- **ColorButton**: кнопка для выбора цвета
- **FontButton**: кнопка для выбора шрифта
- **Entry**: однострочное поле для ввода текста
- **PasswordEntry**: однострочное поле для ввода пароля
- **Box**: контейнер, который располагает вложенные элементы по горизонтали или вертикали
- **Grid**: контейнер, который располагает вложенные элементы в виде сетки
- **CenterBox**: контейнер, который центрирует вложенные элементы
- **ScrolledWindow**: окно с прокруткой
- **Paned**: контейнер с двумя панелями, разделенных по вертикали или горизонтали
- **Frame**: фрейм, который создает рамку вокруг вложенного элемента
- **Expander**: контейнер, который позволяет скрывать и раскрывать вложенные элементы
- **Notebook**: контейнер с вкладками
- **ListBox**: контейнер-список
- **TreeView**: контейнер для вывода иерархических данных в виде дерева
- **Window**: стандартное окно
- **Dialog**: диалоговое окно
- **MessageDialog**: осно с сообщением
- **ColorChooserDialog**: окно для выбора цвета
- **FileChooserDialog**: окно для выбора файла
- **FontChooserDialog**: окно для выбора шрифта

Как можно увидеть по неполному списку виджетов, одни виджеты (контейнеры) могут содержать другие. Так, возьмем контейнер верхнего уровня, в качестве которого выступает окно - **Window**. Этот контейнер может содержать только один виджет. Однако в качестве такого виджета могут выступать другие контейнеры, в которые, в свою очередь, можно поместить другие виджеты.

Для установки вложенных элементов для типа **Window** применяется свойство **Child**, которое может представлять любой виджет:

```csharp
public Widget? Child { get; set; }
```

Рассмотрим на примере простейшего виджета - кнопки, которая в GTK представлена типом Button:

```csharp
using Gtk;

var app= Application.New("com.metanit", Gio.ApplicationFlags.DefaultFlags);

app.OnActivate += (sender, _) =>
{
    var window = new Window();
    window.Title = "METANIT.COM";
    window.DefaultWidth = 250;
    window.DefaultHeight = 200;

    var button = Button.NewWithLabel("Click");
    window.Child = button;

    window.Application = (Application) sender;
    window.Show();
};

app.RunWithSynchronizationContext(null);
```

Для создания кнопки применяется метод `gtk_label_new()`, в который передается текст кнопки. А потом с помощью свойства `Child` устанавливаем эту кнопку в качестве содержимого окна:

```csharp
var button = Button.NewWithLabel("Click");
window.Child = button;
```
