**Вопрос 1**

Почему не компилируется следующая программа:

```csharp
struct Person
{
    public string name;
}
class Program
{
    static void Main(string[] args)
    {
        Person person;
        Console.WriteLine(person.name);
        person.name = "Bob";
    }
}
```

**Ответ**

Если для создания структуры не используется конструктор, то перед обращением к полю структуры необходимо проинициализировать данное поле.
