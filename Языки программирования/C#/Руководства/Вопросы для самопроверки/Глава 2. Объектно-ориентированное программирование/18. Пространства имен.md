**Вопрос 1**

Есть следующий код:

```csharp
using System;

namespace HelloApp
{
    class Program
    {
        static void Main(string[] args)
        {
        
        }
    }
}
namespace Foo
{
    namespace Boo
    {
        class Baz
        {

        }
    }
}
```

Как в методе Main можно обратиться к имени Baz (например, создать объект класса Baz)?

**Ответ**

Через `Foo.Boo.Baz`.
