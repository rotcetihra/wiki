**Вопрос 1**

Какие преобразования типов НЕ выполняются автоматически (возможно, несколько вариантов):

- Из `int` в `short`
- Из `short` в `int`
- Из `bool` в `string`
- Из `byte` в `float`

**Ответ**

Автоматически не выполняются следующие преобразования:

- Из `int` в `short`
- Из `bool` в `string`

**Вопрос 2**

Почему при попытке сложить две переменные типа `byte` и присвоить результат переменной того же типа возникает ошибка, даже если ожидаемый результат укладывается в диапазон значений типа `byte`?

- Операция сложения возвращает значение типа int, а не byte.
- Диапазон значений типа byte переполняется при сложении.
- В процессе сложения происходит автоматическое преобразование в double.
- Переменные типа byte нельзя складывать друг с другом.

**Ответ**

Операция сложения возвращает значение типа int, а не byte.

---

**Вопрос 3**

Какие два основных типа преобразований данных существуют и в чём заключается их принципиальное различие?

- Сужающие и расширяющие преобразования; явные и неявные преобразования
- битовые и байтовые преобразования
- прямые и обратные преобразования
- целочисленные и дробные преобразования

**Ответ**

Сужающие и расширяющие преобразования; явные и неявные преобразования.

---

**Вопрос 4**

Что такое неявные преобразования? (Опционально приведите примеры подобных преобразований)

- неявные преобразования используются только для сужающих преобразований.
- неявные преобразования могут привести к потере данных без предупреждений.
- неявные преобразования требуют явного указания типа в скобках.
- Неявные преобразования — это автоматические преобразования данных, например, из byte в int.

**Ответ**

Неявные преобразования — это автоматические преобразования данных, например, из byte в int.

---

**Вопрос 5**

В чём особенность явных преобразований типов данных и как они применяются в коде?

- Явные преобразования используются только для расширяющих преобразований.
- Явные преобразования не влияют на размер данных в памяти.
- Явные преобразования требуют ручного указания типа в скобках для преобразования значения.
- Явные преобразования выполняются автоматически компилятором.

**Ответ**

Явные преобразования требуют ручного указания типа в скобках для преобразования значения.
