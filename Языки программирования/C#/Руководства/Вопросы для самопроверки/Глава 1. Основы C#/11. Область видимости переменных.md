**Вопрос 1**

Какой результат работы будет у следующей программы и почему:

```csharp
class Program
{
    static void Main(string[] args)
    {
        string message = "Hello";
        Display();
        Console.ReadKey();
    }

    static void Display()
    {
        Console.WriteLine(message);
    }
}
```

**Ответ**

Приведенная выше программа не скомпилируется, так как переменная message является локальной для метода Main и может использоваться только в рамках метода Main, но она недоступна из метода Display.
