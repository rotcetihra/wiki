### Вопрос 57

Что будет выведено в результате выполнения программы:

```csharp
class Program
{
    static void Main(string[] args)
    {
        try
        {
            var array = new int[] { 1, 2 };
            Console.Write(array[5]);
        }
        catch(ApplicationException e)
        {
            Console.Write(1);
        }
        catch(SystemException e)
        {
            Console.Write(2);
        }
        catch(Exception e)
        {
            Console.Write(3);
        }
        Console.ReadLine();
    }
}
```

**Варианты ответов:**

1. 1
2. 2
3. 3
4. 123
