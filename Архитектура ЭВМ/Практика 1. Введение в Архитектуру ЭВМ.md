## 🛠 Практический блок (1 час)

### Блок 1: Пощупать регистры и цикл процессора в эмуляторе (25 минут)

Не нужно ставить сложные среды разработки. Для первого часа идеален веб-эмулятор **[CPUlator](https://cpulator.01xz.net/)** (выбери архитектуру **ARMv7** или **RISC-V**).

**Задание:**

1. Открой эмулятор.
    
2. Вставь простейшую программу (например, на ARM):
    
    Фрагмент кода
    
    ```
    MOV R1, #5      // Записать 5 в регистр R1
    MOV R2, #3      // Записать 3 в регистр R2
    ADD R3, R1, R2  // R3 = R1 + R2
    ```
    
3. Нажимай кнопку **Step** (Пошаговое выполнение) и следи за окном **Registers**:
    
    - Посмотри, как меняется значение **PC (Program Counter)** при каждом клике.
        
    - Посмотри, как в регистрах `R1`, `R2` и `R3` мгновенно возникают значения `5`, `3` и `8`.
        
    - Измени одно из чисел на негативное (например, `#-5`) и посмотри, как изменится окно флагов (Flags/CPSR) — там загорится флаг **N (Negative)**.
        

### Блок 2: Посмотреть, во что превращается твой код в C/Python (20 минут)

Пойми, как компилятор превращает абстракции в машинные команды.

**Задание:**

1. Открой сервис **[Compiler Explorer (Godbolt)](https://godbolt.org/)**.
    
2. В левом окне выбери язык **C** (или C++), а в правом — компилятор **gcc (x86-64)**.
    
3. Напиши простейшую функцию:
    
    ```C
	int add_numbers(int a, int b) {
		return a + b;
	}
    ```
    
4. Наблюдай за правым окном:
    
    - Наведи мышкой на строчку `return a + b;`. Сервис подсветит цветастые строчки Ассемблера справа!
        
    - Найди там знакомые инструкции: `mov` (переместить) и `add` (сложить).
        

### Блок 3: Интерактивное упражнение «Я — Устройство Управления» (15 минут)

Возьми листочек или пустую заметку в Obsidian и проведи **ручную трассировку** (дебаг на бумаге).

**Задание:**

У тебя есть память:

- `[0x04]` = 12
    
- `[0x08]` = 4
    
- Инструкция 1: `LOAD R1, [0x04]`
    
- Инструкция 2: `LOAD R2, [0x08]`
    
- Инструкция 3: `SUB R3, R1, R2` _(SUB — вычитание)_
    
- Инструкция 4: `STORE R3, [0x0C]`
    

Заполни табличку состояний для каждого такта:

1. Чему равен `PC` на каждом шаге?
    
2. Какие значения будут в `R1`, `R2`, `R3` после Шага 3?
    
3. Что будет записано в память по адресу `0x0C` на Шаге 4?
